本讲解析 Vivado 自定义 IP 的封装骨架，主角是 `ip_repo/AesCryptoCore_1.0/` 下的四个子目录：`component.xml`（IP-XACT/SPIRIT 元数据清单）、`hdl`（RTL 包装层）、`xgui`（参数化 GUI 脚本）、`bd`/`drivers`。核心结论有三：其一，`component.xml` 用四元组 VLNV（`xilinx.com:user:AesCryptoCore:1.0`）唯一标识 IP，并通过 busInterfaces 的 portMap 把 Verilog 物理端口映射为 AXI 逻辑总线，用 views/fileSets 把使用场景指到源文件；其二，顶层包装 `AesCryptoCore_v1_0.v` 纯粹地扁平暴露 AXI 端口并例化两个从机子模块——`S00_AXI`（寄存器从机，地址宽 4，即 4 个寄存器）与 `S_AXI_INTR`（中断从机，地址宽 5），其 `// Add user logic here` 留作接入算法核心；其三，`xgui/*.tcl` 以 `init_gui` 画界面、`update_MODELPARAM_VALUE` 把 GUI 参数灌入 Verilog `parameter`。关键现状：该 IP 的 fileSet 不含任何 `aes_*.v` 算法源、用户逻辑区为空，故封装层（`ip_repo/hdl`）与算法层（`hdl/src`）目前脱节，IP 仅是可被处理器读写 4 个寄存器、产生 1 个中断的空壳骨架，尚未接上真正的加密运算。后续讲义 u3-l2/l3/l4 分别承接 AXI 握手时序、中断寄存器与 C 驱动。
