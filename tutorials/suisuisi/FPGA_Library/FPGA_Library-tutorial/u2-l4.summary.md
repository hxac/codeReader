本讲讲解 AES-128 密钥扩展（Key Schedule）：用 128 位种子密钥确定性推导出 11 个轮密钥（共 44 个 32 位字 W₀~W₄₃）。递推核心是每组的第一个字 W′₀ = W₀ ⊕ g(W₃)，其余字链式异或 W′ᵢ = Wᵢ ⊕ W′ᵢ₋₁，使 g 注入的非线性雪崩式扩散至整组。涉及三个模块：key_schedule（纯组合逻辑，用 4 行 assign 实现链式异或，逐轮推进靠顶层 aes_top 的 round_key 寄存器与 round_counter 协作）；function_g（实现 RotWord + SubWord + Rcon，是密钥扩展唯一的非线性来源）；round_constants（把 GF(2⁸) 上反复 xtime 产生的 Rcon 序列 01,02,…,80,1B,36 展开为纯组合逻辑，不占 Block RAM）。关键术语包括轮密钥、字（word）、RotWord、SubWord、Rcon、xtime。需注意 RTL 偏离 FIPS-197 之处：密钥扩展把 encrypt 信号传入 function_g，使解密时改用逆 S-Box，而标准要求密钥扩展恒用正向 S-Box，最终结论以仿真比对黄金模型 ve_AES_Core.sv 为准。
