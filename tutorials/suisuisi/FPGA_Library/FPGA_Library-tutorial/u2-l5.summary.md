本讲打开 AES 单字节 S-Box（模块 bSbox）黑盒，讲解 Canright 复合域算法：弃查表、用组合逻辑「算」出 GF(2⁸) 求逆，省面积且抗侧信道。其结构为「输入侧基变换（合并正/逆仿射）→ GF(2⁸) 求逆 → 输出侧基变换」，靠 encrypt 经两次 select_not_8 切换加/解密，求逆对加解密对称。求逆走域塔递归 gf_inv_8→gf_inv_4→gf_inv_2，每层拆高低半部分、算子域分母、调子域求逆与两次乘法重组；乘法器 gf_mul_4 等亦递归并复用共享因子省门。关键恒等式：GF(2²) 正规基下「求逆＝平方＝交换两位」，故最底层仅一句位交换。本仓库为草稿级 RTL，有文件名/模块名不符、注释错乱、tb 重复例化等问题，须以仿真与 FIPS-197 表为准。
