本讲承接 u3-l1 的 IP 封装骨架，精读 Vivado 自动生成的 AXI4-Lite 寄存器从机 `S00_AXI`（数据 32 位、地址 4 位，对应 `slv_reg0~3` 共 4 个寄存器）。核心结论：AXI4-Lite 由 AW/W/B/AR/R 五个通道组成，每条通道都靠 VALID/READY 同拍为高才算一次传输，且发送方拉高 VALID 后不得撤回。写路径用 `aw_en` 作为「单事务屏障」——收下一笔写即关门，待 B 通道回应被确认才重新开门，保证不允许多笔未完成事务；AW 与 W 须同拍有效是模板的简化设计。地址译码取 `addr[3:2]` 选寄存器（`ADDR_LSB=2` 跳过字内字节偏移、`OPT_MEM_ADDR_BITS=1` 给出 4 个寄存器），字节写使能 WSTRB 控制逐字节写入；读路径用「组合选择 + 寄存器输出」，延迟约一拍，BRESP/RRESP 恒为 OKAY。最后指出 `// Add user logic here`（子模块与顶层两处）是把 AES 核心接入的钩子，目前均为空，IP 仍是能读写寄存器但不做运算的空壳，为 u3-l3 中断接口埋下伏笔。
