本讲是 FPGA 数学运算的入口，回答「Verilog 如何看待一个数」，不讲乘除算法本身。三个最小模块：signed 语义、位宽扩展与截断、定点数 Q 格式。关键结论：同一串比特在 unsigned 与 signed（二进制补码）下数值不同，`signed` 关键字改变解释与运算语义（符号扩展、算术比较），混用 signed/unsigned 会使整个表达式退化为无符号，故 projf 把端口统一标 signed。有符号数扩展靠复制符号位，两个 N 位数相乘得 2N 位乘积，需截取窗口丢低位、查高位溢出。定点数用 WIDTH（总位宽）与 FBITS（小数位）约定，IBITS=WIDTH−FBITS（含符号位），精度为 2^(−FBITS)，小数点只是设计者心中的隐含位置，底层全是整数运算。同 Q 格式加法直接相加；乘法后小数位翻倍，须右移截回原格式，并用高斯舍入（向偶舍入）消除统计偏差。引出的术语：二进制补码、符号扩展、WIDTH/FBITS/IBITS、Q 格式、截断窗口、高斯舍入、SMALLEST 检测，供 u7-l2 除法器与 u7-l3 平方根/DSP 乘法承接。
