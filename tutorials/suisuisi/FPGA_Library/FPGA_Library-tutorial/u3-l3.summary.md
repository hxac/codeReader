本讲精读 AXI 中断从机 `AesCryptoCore_v1_0_S_AXI_INTR`——Vivado 自动生成的中断控制器模板，把原始中断源 `intr` 整理成规范、可屏蔽、可确认的 `irq` 输出。其 AXI4-Lite 握手时序与 u3-l2 的 `S00_AXI` 完全同构，本讲聚焦新增的中断逻辑。

核心是 5 个按中断位数生成的可寻址寄存器：GIE（全局使能，总闸）、IER（单中断使能）、ISR（状态）、IAR（确认）、IPR（挂起）。地址用 `addr[4:2]` 译码，分别落在 0x00/0x04/0x08/0x0C/0x10；GIE/IER/IAR 可写，ISR/IPR 由硬件维护、只读。关键关系为 IPR = ISR & IER。

`irq` 生成是一条流水线：`intr → det_intr → ISR →(IER 与)→ IPR →(或)→ intr_all →(GIE 与)→ irq`。触发方式（电平/边沿、高/低有效）由 `C_INTR_SENSITIVITY`、`C_INTR_ACTIVE_STATE`、`C_IRQ_SENSITIVITY` 等参数决定，默认为电平高有效。中断采用锁存语义，保持到处理器写 IAR 确认；IAR 是单拍自清零脉冲，触发对 det_intr/ISR/IPR 的连锁清除并最终拉低 irq。

关键结论：当前 IP 唯一的中断源是模板自带的倒数计数器（命中 0xA 拉高 intr），并非 AES 运算完成；真正的 AES done 信号需填入两处空的 `// Add user logic here` 钩子。这再次印证 u3-l1/u3-l2 的结论——IP 仍是能产生中断、但中断源为占位示例的空壳骨架。
