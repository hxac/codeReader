本讲把仓库精确化为「施工地图」。根目录仅极简 README 与 MIT LICENSE（仅覆盖自研），下分三条技术路线：HDL/（手写 Verilog 打包 Vivado IP）、HLS/（C 高层综合生成 IP）、ThreePart/（第三方收录），一目录对应一路线。HDL/ 含 AES-128 加密核心（教学主线，封装为 AXI IP）与摄像头→颜色转换→DVI 视频链路；AES 工程遵循 UG892 最小版本控制，关键区分：hdl/src/ 为算法 RTL，ip_repo/.../hdl/ 为 AXI 包装（含 component.xml 与 C 驱动），即 Unit 2/3 分界。HLS/ 以 C 源码为中心（中值滤波带 Apache-2.0、Canny 检测）。ThreePart/ 含 projf 教程库（自述 MIT）、ISO 标准密码（学术）、digilent_ip（厂商）、hardwarebee（碎片来源）。关键术语：FPGA、HDL、IP 核、HLS、AXI、bitstream、TMDS、component.xml、UG892 工程模板。重要原则：复用前须逐子目录确认许可证。
