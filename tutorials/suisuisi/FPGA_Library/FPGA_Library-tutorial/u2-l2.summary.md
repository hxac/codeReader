本讲是 AES 数据通路的「字节级变换」专题，覆盖三个最小模块：`bSbox`（单字节 S-Box，用 Canright 复合域算法）、`aes_s_box128`（例化 16 个 `bSbox` 做整状态并行替换）、`aes_shift_rows`（纯组合连线实现行循环移位）。核心结论：SubBytes 用非线性 S-Box 逐字节替换，是 AES 安全性的来源；ShiftRows 对每行做左移（解密右移），把不同列字节打散，为 MixColumns 的扩散做准备。关键设计是加解密共用一条通路——靠 `encrypt` 信号让 S-Box 在正向/逆向间切换、让 ShiftRows 在左移/右移间切换，求逆模块 `gf_inv_8` 被加解密复用。关键术语包括：状态按列填入 4×4 矩阵、字节 x 占据比特 [8x+7:8x]（来自 `u8_MSB/u8_LSB` 宏）、仿射常数 0x63、跨列字节重排。本讲同时指出本仓库为草稿级 RTL，存在端口方向笔误、宏定义笔误及 `aes_shift_rows` 未接出 `data_out` 等隐患，需以仿真为准，为后续 MixColumns、Key Schedule 及复合域求逆讲义承接。
