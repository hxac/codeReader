本讲讲解 projf 库 display 分区的三个时序生成模块 `display_480p`、`display_720p`、`display_24x18`。显示器沿袭 CRT 的光栅扫描：逐像素从左到右扫一行、回扫换行、扫完一帧再回帧，回扫空档即消隐期。一行由 Active、Front Porch、Sync、Back Porch 四区间拼接，一帧同理（像素换成行）；这些参数是 VESA/CTA 工业标准，不可零散改动。帧率公式为像素时钟除以一帧总像素数（H_total×V_total）。模块用带符号坐标把有效区摆到 `sx/sy≥0`、消隐期藏进负坐标，四个 always_ff 分别生成 hsync/vsync（含极性）、控制信号 de/frame/line、带符号坐标计数、延迟对齐的 sx/sy。三者模块体逐字相同、仅 parameter 不同，即「同构不同参」；24x18 专为加速仿真而设。像素时钟由 clock_480p 等 PLL 模块提供，坐标与 de/frame/line 输出是后续 DVI/HDMI、绘图原语、帧缓冲的寻址基础。
