本讲围绕 projf memory 分区的三个最小存储模块展开：rom_async（异步 ROM，`always_comb` 组合读、无时钟）、rom_sync（同步 ROM，`always_ff` 打一拍读）、bram_sdp（简单双口 BRAM，一写口加一读口，支持双时钟）。三者共享 `WIDTH/DEPTH/INIT_F/ADDRW` 四个参数，地址位宽由 `$clog2(DEPTH)` 自动算出，内容经 `$readmemh` 从 `.mem` 文件初始化。核心工程经验：同步读（带输出寄存器）是让综合工具推断 Block RAM 的关键，异步读只能落到 LUTRAM（分布式 RAM），且存储阵列不应加复位，否则也会破坏 BRAM 推断。三者各司其职：rom_async 当调色板、rom_sync 当字模表、bram_sdp 当帧缓冲。引入的关键术语有 LUTRAM、Block RAM、简单双口/真双口、同步写、一拍读延迟，为后续显示与波形表讲义奠基。
