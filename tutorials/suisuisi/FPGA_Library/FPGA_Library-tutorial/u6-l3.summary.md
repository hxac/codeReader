本讲讲解 FPGA 上「硬件绘图」范式：状态机逐拍流式输出属于该形状的像素坐标 (x,y)，配 drawing 脉冲，由帧缓冲消费写入颜色，区别于 CPU 的「循环算 y」。所有绘图模块共享统一的 start/oe/(x,y)/drawing/busy/done 接口，坐标为有符号、位宽由 CORDW 参数化。核心模块包括：draw_line 用 Bresenham 算法维护整数误差项 err，仅靠加减法与比较画任意方向直线；draw_rectangle_fill 复用单向水平线子模块 draw_line_1d 逐行填充；draw_circle 用 Zingl 误差递推只算八分圆再镜像 4 象限，其 err 本质是隐式圆方程 x²+y²−r² 的增量形式（利用 (n+1)²−n²=2n+1 省乘法）；draw_triangle_fill 通过两条 draw_line 算左右边交点加水平线填充，体现「复杂形状由简单原语组合」的分层思想。这些模块不直接驱动显示器，而是产生坐标流供 u6-l4 帧缓冲写入，与 u6-l1 显示时序衔接成完整图像流水线。
