本讲精读 projf 库的三个 UART 模块（`uart_baud`、`uart_tx`、`uart_rx`），讲清异步串口收发的原理。核心概念：UART 无共享时钟线，收发靠约定波特率与过采样对齐，线路空闲为高电平、起始位靠下降沿触发；8N1 帧 = 起始位(0)+8 数据位(LSB first)+停止位(1)，共 10 个比特周期。`uart_baud` 用 DDS 累加器（而非整数分频）以同一增量 25770 配 24/28 位两种宽度，同时产出 16× 过采样节拍 `stb_sample` 与 1× 波特节拍 `stb_baud`，二者严格 16:1 相位锁定。`uart_tx` 用 IDLE/START/DATA/STOP 四状态机（被 `stb_baud` 门控）把并行字节逐位移位成串行帧，输出 `tx_busy`/`tx_next` 流控。`uart_rx` 最复杂：先用两级触发器同步器（承接 u5-l2）抗亚稳态，再用 16× `stb_sample` 过采样，在比特中央（采样点 6/7/8）采样，当前仅锁存中央样本 `sample_b`（`sample_a/c` 为后续多数表决抗噪声预留）。三模块由同一 `uart_baud` 的两节拍耦合，可拼成回显器。
