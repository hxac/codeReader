本讲解决「Vivado 工程哪些文件该进 Git」的问题，阐述源自 Xilinx UG892 的「最小化版本控制」思想：只版本控制源与设置，产物由脚本重建，`.gitignore` 负责落地。覆盖三个最小模块：其一为 `Vivado_project` 目录约定——`proj/` 放脚本、`src` 下放块设计与约束、顶层 `hdl/` 放算法 RTL、`ip_repo/` 放自定义 AXI IP，`hw_handoff`/`repo`/`sdk` 各司其职；其二为 `create_project.tcl` 用 Tcl 串起建工程、设器件、加源、建 run、建块设计等步骤从零重建工程，目标器件是 Zynq-7020/Zybo Z7-20，基于块设计，顶层为自动生成的 `aes_design_wrapper`；其三为 `cleanup` 脚本负责清场后重建。引入的关键术语有 Tcl、xpr 工程文件、块设计、wrapper、hw_handoff 硬件交接。核心警示：随仓库发布的脚本仅是示例，含 Windows 硬编码路径、目录名拼写不一致等 bug，须批判阅读、手工适配，遇文档与实际不符以实际为准。
