本讲义为整本手册建立认知地图。`suisuisi/FPGA_Library`（旧名 `Xilinx_Library`）是聚合型 FPGA 设计合集，根 README 极简，需用「读 README + 看目录结构 + 看 git 历史」三步法理解。仓库由三大顶层目录构成：`HDL`（自研 Verilog/VHDL 与 Vivado IP，含最适合精读的 `AesCryptoCore_1.0` 及一条摄像头采集→颜色转换→DVI 输出的视频链路）、`HLS`（用 C 写算法、工具生成 Verilog 的高层综合范式，含中值滤波与已综合成 IP 的 Canny 边缘检测）、`ThreePart`（第三方合集，教学价值最高的是 `projf-explore`）。引入的核心术语：FPGA、HDL、IP 核、HLS、bitstream、综合/实现、AXI。结论：根目录 MIT 许可证仅覆盖作者自研部分，各第三方子项目各自带许可证，复用前须逐一确认。
