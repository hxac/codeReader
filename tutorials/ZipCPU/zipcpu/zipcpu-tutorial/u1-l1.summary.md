本讲是《ZipCPU 学习手册》开篇，仅读 README 与 spec.tex 的引言及 Key Features 两处入口文档，不深入 RTL，旨在建立项目全貌地图。核心结论：ZipCPU 是小而轻的 32 位 RISC 软核，用 Verilog 写成、面向 FPGA、GPLv3 开源，并明确声明不是 RISC-V、不复制任何既有 ISA。设计目标为 32 位、以单周期为主的 RISC、load/store 架构、流水线、supervisor/user 双模式，并提供 Wishbone/AXI4-Lite/AXI4 三种总线封装。其独特之处是仅 29 条指令、几乎所有指令可条件执行、以双寄存器组替代中断向量。spec 相比 README 额外引入后续讲义将展开的属性：Big Endian 字节序、压缩指令子集 CIS、总线宽度可配置、可选调试接口与 OPT_* 高度可配置。仓库顶层含 rtl/（硬件）、sw/（工具链）、sim/（仿真器）、bench/（测试与形式化验证）、doc/（规范）五个目录。本讲引入的关键术语：软核 CPU、RTL、ISA、RISC、FPGA、总线、load/store 架构、双寄存器组中断模型。
