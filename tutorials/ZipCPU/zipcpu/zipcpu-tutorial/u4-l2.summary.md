本讲讲解 ZipCPU「开箱即用」的顶层封装 `zipsystem`：它在 `zipbones` 裸 CPU 基础上，把内核、一组片内外设与一个调试从端口挂到同一条内部 `sys` 总线上，经仲裁接出对外 Wishbone 主端口。内部有三类总线前缀：`gbl`（片外主存，取指与外部数据走此路）、`lcl`（CPU 命中 `0xFFxxxxxx` 段的本地外设访问）、`sys`（真正实现的外设总线，主设备为 CPU 本地路径与调试端口）。

四个最小模块：①三层总线全景；②两处仲裁——外部总线用双主优先级仲裁器 `wbpriarbiter dmacvcpu`（CPU 优先、DMA 蹭用），`sys` 总线用简单多路选择（CPU 优先、调试器等空隙），且取指从不走本地总线；③外设实例化与地址映射，CPU 字节地址＝`0xFF000000 + sys_addr×4`，外设经 `sel_*` 译码选中、读返回由 `ack_idx` 多路选择，中断经主/辅 PIC 合并为单线 `pic_interrupt`；④调试端口用 `dbg_addr[6:5]` 切成 CTRL/CPU/SYS 三段，CTRL 段经命令寄存器 `cmd_halt/cmd_step/cmd_reset` 控制 CPU，SYS 段复用 `sys` 总线访问外设。
