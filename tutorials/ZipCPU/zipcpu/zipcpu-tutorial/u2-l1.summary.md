本讲是 ZipCPU ISA 单元首讲，从规范层面讲清运行模式、寄存器组、状态寄存器 CC 三件事。ZipCPU 为双模式机器：supervisor 模式中断常关、复位即进入；user 模式中断常开、靠 RTU 指令进入；中断或异常会把 CPU 从 user 自动打回 supervisor 并停在原指令处，因此不需要中断向量表。寄存器组有 supervisor/user 两套，各 16 个 32 位通用寄存器，硬件特殊的是 PC（R15）与 CC（R14），工具链约定 R0=LR、R12=FP、R13=SP；模式切换即整套 16 个寄存器整体换组，GIE 位（CC 第 5 位）兼作寄存器地址的第 5 位，据此区分 user 组（16–31）与 supervisor 组（0–15）。CC 仅低 16 位有效：第 0–3 位为 Z/C/N/V 四个 ALU 标志，第 4–7 位为 SLEEP/GIE/STEP/BREAK 控制位，第 8–15 位为非法指令、陷阱、总线错、除零等异常状态位及清缓存命令位；其中 sCC.GIE 恒读 0、uCC.GIE 恒读 1，软件无法伪造当前模式。后续讲义将在本寄存器与状态字视图上展开指令编码、寻址与条件执行。
