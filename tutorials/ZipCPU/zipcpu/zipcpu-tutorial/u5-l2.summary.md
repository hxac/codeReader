本讲讲解 ZipCPU 基于 SymbiYosys（.sby）的形式化验证体系。它不跑具体输入，而用 SMT 求解器搜索是否存在任何输入序列违反断言，给出数学证明，与仿真互补。两种模式：prove（证明无反例，防做错）与 cover（验证状态可达，防死代码），depth 限定时间边界。四个原语：assert（自我承诺）、assume（约束环境）、cover（可达性）、$past（上拍值）。bench/formal/Makefile 用 TESTS 清单编排 30+ 模块，每模块按总线宽/流水/锁定/大小端拆为多个子任务，全部生成 PASS 才算通过。.sby 含五节 [tasks]/[options]/[engines]/[script]/[files]，用 tags + pycode 把同一份 RTL 在多种参数下逐一证明。核心是 fwb_master/fwb_slave：纯断言、零功能逻辑的契约检查器，把 Wishbone 协议从主/从两视角写成 assert/assume，靠 SLAVE_ASSUME/SLAVE_ASSERT 宏使两文件逐行对齐，并维护 f_nreqs/f_nacks/f_outstanding 探针供模块断言使用。模块在 FORMAL 块里实例化对应检查器接总线信号。新增证明只需三步：加 FORMAL 段、写 .sby、注册 Makefile。
