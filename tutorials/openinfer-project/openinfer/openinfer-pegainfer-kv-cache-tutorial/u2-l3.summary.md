本讲展开「三拍节奏」中 view 一拍：view.rs 的 KvView/KvViewDesc 与 pool.rs 的三个视图构造器。核心是「恰好覆盖」契约——页表行长度必须等于 seq_len 对 page_size 上取整，由 KvView::new 断言强制；内核按（页数−1）×page_size+末页长度反推序列长：多一页会让垃圾 K/V 参与注意力（软失败），少一页越界读（硬失败），即 #291 教训。末页长度在序列恰为 page_size 整数倍时取 page_size 而非 0，空序列取 0。KvViewDesc<'a> 以借用方式打包 KvLayout、显存基址、页表切片与 seq_len，零拷贝供内核读取。因 kvbm 积极预取下一生成块，请求原始块清单可比 KV 实际多一块，prefill/decode/speculative 三个视图构造器一律经 step_page_indices 裁剪，绝不直用原始清单；decode 视图 seq_len 为 kv_position+1（悬空 token 口径）。下一讲 u2-l4 承接 KvBuffer 物理层。
