本讲是学习手册第一讲，为 pegainfer-kv-cache 建立全景：只读仓库架构指南、依赖清单、19 行的 lib.rs 与各类型的文档注释。核心结论：PegaInfer 是纯 Rust+CUDA 推理引擎，各模型线自持调度器与请求状态；共享分页 KV 原语集中在本 crate，host/SSD/RDMA 卸载桥在 pegainfer-kv-offload。核心设计是逻辑/物理两层分离：BlockPool 管块的发放、共享与回收但不持显存，KvBuffer 一次性持有显存但不带分配器，两者靠块 ID 关联。引入词汇表：页几何 KvLayout、全注意力配对门面 KvCacheManager（MLA 模型绕过直用 BlockPool）、每请求 RequestKv 走调度→视图→应用生命周期、内核视图 KvView/KvViewDesc，以及前缀探测、加载预留等池类型和上游 kvbm-logical（本地 fork）的再导出。依赖单向：模型 crate→本 crate→kvbm-logical，故可被多条模型线复用。
