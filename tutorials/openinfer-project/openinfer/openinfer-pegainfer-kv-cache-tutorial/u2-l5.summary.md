本讲剖析 pegainfer-kv-cache 中 GPU 侧前缀缓存的最小闭环：块哈希、探测、匹配挂载与回收。缓存键是 lineage 哈希链——位置＋块内容＋父块哈希＋salt，共享前缀逐位相同、分叉即全变，尾部半块永不参与匹配。核心规则 cacheable=⌊(n−1)/b⌋ 在机制层强制：永远留最后一个 prompt token，保证首 token 采样并避免调度状态机死锁，一切复用口径受其钳制。LoRA 名作 salt 从链头混入，同 token 异适配器互相不可见，防止 K/V 被静默复用造成输出污染。probe_prefix 产出只读 PrefixProbe，区分 GPU 命中、钉住、可复用、CPU 查询窗口四个块数口径；match_and_add_prefix 须在首次 prefill 前调用，挂载命中块并前移 kv_position。回收双路：evict_inactive 显式冷冲刷、LRU 分配时隐性弹最旧；请求释放后整块进非活跃池，命中即复活。
