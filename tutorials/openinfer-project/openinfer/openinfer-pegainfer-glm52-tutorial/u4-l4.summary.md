本讲剖析 GLM5.2 DSA indexer 的三个模块：decode 前向 kernel 链、top-k 跨层共享、index-K 缓存写入。indexer 是 32 头×128 维的轻量 fp8 MQA 打分器（lightning indexer，逐位对齐 vLLM DeepseekV32Indexer），链路为：q/k 投影→带偏置 LayerNorm→RoPE→逐组 fp8 量化→权重折叠→DeepGEMM paged logits（融合逐头 ReLU）→确定性 top-2048→全局槽位换算。核心结论：top-k 的产物是全局 KV 槽位而非分数，所有层共用同一张 block table，故由谓词 max(layer-2,0)%4==0 选出的 21 个 full 层（{0,1,2}∪{6,10,…,74}）算出的槽位集合可被其余 57 个 shared 层逐字复用；carry 即 s.idx.global_slots 缓冲，carry_ready 守卫拒绝陈旧读，无字段的 Shared 变体使空引用在类型层面不可表示。index-K 每 token 每层 132 B（fp8 键＋f32 scale），与 MLA 切片同页（8 448 B/页/full 层）、写入与读取零拷贝；权重折叠搬到设备与 indexer 链在 AUX 流上并行，共同动机是 CUDA Graph 捕获与指针稳定。
