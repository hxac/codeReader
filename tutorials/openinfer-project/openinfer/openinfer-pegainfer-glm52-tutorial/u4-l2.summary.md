本讲围绕三块展开：页几何、slab 与层缓存、padding 页与悬空 token 契约。GLM5.2 的 KV 活在 rank 级页池（page-first 布局）：64 同时是 FlashMLA 稀疏页、index-K 缓存块与上下文对齐单位；一页 = 78 个 MLA 切片（各 41,984 B）+ 21 个 full-indexer 层的 index-K 切片（各 8,448 B）+ 第 78 层 MTP 镜像，共 3,502,592 B，页距 3,503,040 B（取 656 的倍数，尾填充从不搬运），页距是卸载 namespace 与 P/D fingerprint 的线格式身份。运行期寻址 = slab 基址 + 物理页号 × 页距 + 层偏移（Glm52KvSlab 配 Glm52LayerCaches）；页号是运行期数据、图安全，布局由 glm52_page_layout 单一构造。cap 必须 64 对齐（页表宽 = cap/64）；池 = slots×ceil((cap+1)/64)+1，两个「多一」分别是每 slot 的悬空 token 页（悬空 token 契约：admission 一次性预留全生命周期）与 0 号 padding 页（垃圾写入无人读）。
