本讲覆盖 mla_front.rs，即 MLA 前半场。查询链：hidden[T,6144] 经 q_a 压到 2048 维、RMSNorm 得 q_resid，再由 q_b 展开成 64 头×256 的 q_full（每头 = nope 192 + rope 64）；键值链：kv_a 输出 576 维 ckv，拆成做 norm 的 512 维 latent（kv_c）与不做 norm 的 64 维 rope 分量 k_pe。核心结论：latent KV 表示使每 token 每层只缓存 576 个 bf16、与头数无关，较逐头 MHA 压缩约 28 倍；kv_b 不驻留 fp8，装载时反量化为 bf16 吸收因子 W_UK/W_UV。Glm52MlaFront 是 78 层共享、指针稳定的持久 scratch（CUDA Graph 前提）；decode 拆成 front_q 与 front_rest 两段，其间插 DSA 索引器并行。q_a/kv_a 按行数分派 pair、打包 mma、wide GEMM、GEMV 四条 fp8 路径；qa_kva 打包 twin 约 1.2 GiB，须计入显存账本。
