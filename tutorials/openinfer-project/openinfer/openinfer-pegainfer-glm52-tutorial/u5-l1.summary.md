本讲拆解 GLM5.2 MoE 层中不发生跨卡通信的一半：noaux_tc 路由器、共享专家与专家库布局。路由为 sigmoid 打分，偏置 e_score_correction_bias 只决定选谁、不进权重；确定性取 top-8（值降序、id 升序决平局），再以不带偏置的 sigmoid 分数做 norm_topk_prob 归一化。缩放因子 2.5 在 EP decode 延后至收尾加法，TP prefill 则折进权重。路由结果 RoutedTopk（全局专家 id）永驻设备、padding 行静默，支撑整步 CUDA Graph 捕获。共享专家是每 rank 全量持有的 fp8 SwiGLU，decode 时 fork 到 aux 流与 DeepEP 通信重叠，join 时以 2.5·路由和+shared 一次加法合流。Glm52MoeExpertBank 收养 loader 落位的 region（专家数由尺寸反推），fp8 权重原地转成 DeepGEMM 契约的 UE8M0 scale，256 专家按 rank 分片。psum_expert 是 recv 行数按 64 对齐的设备端前缀和真值，host 只持协议上界 bound_rows；DeepEP dispatch/combine 链路留给 u5-l2。
