本讲建立 pegainfer-glm52 的源码地图：src 共 54 个文件，lib.rs 声明 27 个模块（4 个仅测试）。核心结论是三层落地：算子层（fp8、mla、indexer、layer、moe 及投机 dspark/mtp 等族）是不感知调度的 forward 积木，形状全部来自 config 编译期常量；执行层（model/ 目录）把积木组装成可被 CUDA Graph 捕获的整步 forward，引入 96 行步上限、离散 decode bucket 与步形状描述 Glm52StepShape；调度层（runner.rs 与 scheduler/ 的 admission、plan、slot、graph）决定每步喂哪些行。关键术语：引擎线程经 12 变体指令协议 Glm52RankCommand 驱动独占 CUDA 上下文的 worker 线程、free-running（引擎永不静默等待，空闲以 padding 行全速进场）、预捕获即会合、跨层 top-k 共享、oracle 精度门与测试同树（#[cfg(test)]，需 GPU 者带 #[ignore]）。记图钥匙是请求流：frontend → serve_loop → Step → run_step_body → TokenEvent。
