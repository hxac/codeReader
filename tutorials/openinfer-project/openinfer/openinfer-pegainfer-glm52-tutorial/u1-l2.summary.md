本讲讲清 GLM5.2 的构建与启动配置。核心结论：feature 门控在 server 组装层——本 crate 无自有 [features]，一经编译即通过依赖声明连带打开 pegainfer-kernels 的 glm52 feature，构建必须 --release、无需 Python。GLM5.2 经 augment_cli 向共享命令行注入 8 个专属 flag（Glm52Cli），核心是 --moe-topo 六档拓扑（ep4～ep64 与 tp4，默认 ep8），派生 tp/dp 合法值与每 rank 专家数，tp4 为 prefill-only 张量并行形态；11 个共享 flag 的语义归属由 consumed_shared_args 划定。运行期环境变量 GLM52_DECODE_SLOTS（1..=32，默认 8）与 GLM52_MTP_DRAFTS（1..=5，默认 5）经 OnceLock 只读一次，须满足 slots×(1+drafts)≤96 的行步预算并在启动期 fail-fast。引入的关键术语：ModelLine 的 probe/validate/serve_plan/launch 链路、Glm52MoeTopo 拓扑枚举、drafter 三态、--glm52-ranks 与 rendezvous 跨节点握手。全部组合规则由 18 个纯 CPU 单测与 topology_tests 兜底。
