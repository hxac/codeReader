本讲（手册收官篇）复盘 pegainfer-server 的三个架构决定，精读 main.rs 与 frontend 的 model_line.rs、engine/wiring.rs、vllm/mod.rs。其一：server 是纯分发二进制，只持有一列 ModelLine trait 对象，流程为检测→校验→启动→分发，serve 分派依据是 ServePlan 的服务形态字段而非模型名，代价是 trait 表达力即上限并失去穷尽匹配。其二：families() 是「必要的第二真相源」，为被编译掉的线硬编码身份表，在 NoMatch 时给出 feature 重建提示；它是 identity-only 的——只承诺身份归属，不承诺 checkpoint 可服务。其三：两代引擎契约经 LaunchedEngine 枚举共存，枚举写明删除条件（Handle 侧三线全迁、KvPrefix 落定）。关键术语：真相源、漂移、identity-only、迁移脚手架、编译可见性（ServePlan 用默认值展开）、注释是快照。
