本讲把前三讲的抽象骨架落到默认编译进二进制的 Qwen3Line 上，覆盖三个模块：Qwen3Cli 独占 CLI、validate 冲突矩阵、launch 选项折叠。核心结论：十三个独占 flag 分五组（LoRA 服务、KV P2P/PD、显存预算、batch-invariant、EAGLE-3），类型私有、拼写公开，取值解析器在读取 config.json 之前就拦截格式错误；validate 用 provided 出身集合交叉共享与独占两面的当前值判定跨 flag 语义冲突，违反即返回 CliError::rule，全部发生在引擎加载之前；launch 把 SharedArgs 与 Qwen3Cli 折叠成 Qwen3LaunchOptions 交给 crate::launch，返回 LaunchedEngine::Stepped，启动策略归模型 crate 所有。引入的关键术语：provided 出身语义、consumed_shared_args 消费面、arg_requirements 依赖边、P/D 分离、投机解码、batch-invariant、三层分层失败——Loading engine 横幅是校验期与加载期的可观察分界线。
