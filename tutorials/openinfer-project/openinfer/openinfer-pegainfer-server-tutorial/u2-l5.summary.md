本讲讲解 ModelLine 的 serve_plan：因 HTTP 前端装配与分钟级引擎加载并行，模型线只能凭 CLI 与 config.json 在加载前产出 ServePlan 四字段——分区数 scheduler_partition_count（逻辑 DP rank）、prefill_only（P/D 分离的 prefill 角色）、lora_modules、auto_tool_call_parser。main() 依此三分支：LoRA 命中则串行等引擎、engine_count 硬编码 1；prefill-only 与默认分支把分区数作 engine_count 传给 serve 函数族。工具解析器经 resolve_tool_call_parser 按「显式选择 > 线自带默认 > Auto」折算，防上游按模型路径子串错配。前端先按 engine_count（TransportMode::Bootstrapped）注册 engine identity，引擎就绪后与实际分区数对账，不符即取消服务——分区数是请求寻址参数，宁可死不带病服务；各线应以 ..ServePlan::default() 展开实现以防漂移。
