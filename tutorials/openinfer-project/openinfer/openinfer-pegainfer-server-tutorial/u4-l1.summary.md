本讲覆盖 pegainfer-frontend 的 vllm 模块：serve 函数族五个入口按 ServePlan 三分支被 main 选用（LoRA 串行、prefill-only、默认），最终收拢到唯一私有装配骨架 serve_model_on_host_with_router_extension。骨架以「引擎 Future」为参数，使秒级 HTTP 前端装配与分钟级引擎加载并发；它预绑定两个 unix socket 并把 fd 交给 vllm-server 领养，TCP 端口在引擎桥注册之后才 bind，故「端口可达＝引擎就绪」。引擎 resolve 后做计数对账：Handle 变体核对实际分区数、Stepped 变体核对 schedulers 数，与声明不符即取消服务、拒绝带病上线；30 分钟 ready_timeout 只兜底真正挂死的加载。shutdown 是 child_token 级联树：引擎失败只拉 server 侧令牌，桥失败双拉并排空剩余桥、再收割调度器线程；收尾时引擎错误优先于 server 的 Ok，IPC 目录无论成败必删。关键术语：引擎 Future、预绑定 fd、计数对账、ready_timeout、shutdown 级联、JoinSet。
