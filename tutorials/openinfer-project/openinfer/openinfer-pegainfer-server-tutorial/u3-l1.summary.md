本讲给出 pegainfer-frontend 引擎契约的总地图。engine 模块按内聚性拆成 13 个子模块，mod.rs 以 pub use 扁平 re-export，使 engine::X 外部路径不随分拆改变。契约分两代并存：新一代 step 驱动契约（step/ledger/request_lifecycle/metrics/wiring/driver/control）与迁移中的 legacy 每 token 契约（request/event/sink/kv/handle），stop 是不入组的共享词汇。核心类型 LaunchedEngine 是迁移期二选一枚举：Handle 变体装 legacy EngineHandle，Stepped 变体装 step 交接包 Engine（含 schedulers、EngineInfo、lora，Option 即能力），全部模型线迁完后该枚举将删除。普查结论：qwen3/qwen35/gemma4/k3 已返回 Stepped，deepseek-v2-lite/glm52/kimi-k2 仍为 Handle，qwen4 直接报错；LoRA 分支只认 Stepped。生产者是模型 crate 侧调度器，消费者是 frontend 协议栈。
