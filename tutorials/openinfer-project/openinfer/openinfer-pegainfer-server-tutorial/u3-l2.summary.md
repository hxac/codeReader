本讲覆盖 legacy 契约的三个线类型模块：GenerateRequest、TokenEvent 族与 TokenSink，辅读 SamplingParams 与 vllm 支构造点。核心结论：GenerateRequest 是纯数据请求本体，十二个字段不含引擎内部状态——data_parallel_rank 是路由指令（None 交 handle 选最低负载分区，桥恒绑 rank），token_tx 是唯一事件出口，trace_parent 携带可 Copy 的追踪上下文。TokenEvent 共七个变体，「Scheduled 先行、terminal（Finished/Error/Rejected）恰一次」在 legacy 侧只是约定而非类型保证；FinishReason（Length/Stop/Error）是被新契约复用的完结词汇；RequestTag=Arc<str> 使每事件打标只是一次引用计数。TokenSink 用一条共享打标通道加单一 demux 循环取代每请求通道，每步唤醒数由 N 降至约 1；取消从 drop 接收端改为每请求的原子 abort reason（None/Cancelled/Disconnected，Release 写 Acquire 读），tx.is_closed() 是引擎级信号，abort 才是每请求信号。这些类型仍服务于 deepseek-v2-lite、glm52、kimi-k2 三条未迁移模型线，也是 u4 引擎桥 demux 事件流的前提。
