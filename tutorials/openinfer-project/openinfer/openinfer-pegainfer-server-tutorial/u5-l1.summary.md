本讲覆盖引擎契约主干之外的三个模块：KvPrefix（KV 前缀解析结果）、请求生命周期三件套（RequestEnvelope / RequestControl / DeferredFinish）与 StopPolicy / StopCause（token 停止判定）。核心结论：hit_tokens 让退化解析只是「一个更小的数」，下游语义全由数字承载；hold 是除铸造方外只能 drop 的不透明 RAII 钉住把手，rank 因此是路由硬事实，submit_resolved 按已解析 rank＞调用方绑定 rank＞最低负载裁决，二者不一致属调用方 bug，仅 debug_assert。三件套守护铁律「未应答请求必以 Failed 终态浮出，绝不客户端挂起」：信封 drop 炸弹兜底死调度器上的新提交；RequestControl 用原子 abort 旗（Release 写 / Acquire 读）做无通道的单请求取消，调度器每步 is_aborted 后 retire 静默退役；DeferredFinish 折叠本步记录、迟发不乱序，被丢弃时终态改写为 Failed，因被扣的 Finished 是 P/D 屏障信号，不许伪造成功。StopPolicy 在请求边界把停止集排序去重进 Arc 共享、二分判定，主 EOS（EosPolicy 三档）优先于显式停止集；StopCause 随 Terminal::Finished 上行，并在迟到终态中原样保真。
