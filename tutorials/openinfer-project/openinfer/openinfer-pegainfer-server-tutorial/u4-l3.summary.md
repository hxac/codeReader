本讲覆盖 pegainfer-frontend 的两代引擎桥：桥把 PegaInfer 引擎伪装成 vLLM EngineCore，经 zmq Dealer/Push 双 socket 与 msgpack 跟上游 HTTP 层通信。传输层是两代共用的 BridgeLink——装配骨架先 bind 两个 unix listener，以 TransportMode::Bootstrapped 把 fd 交给 vllm-server 领养，桥待引擎就绪才 connect 并发握手。legacy 桥 LocalEngineBridge 消费共享打标事件流，做 demux 与折叠：一次唤醒排空就绪事件、按请求分桶、每请求折成至多一条输出、整批一条 zmq 消息；EOS 哨兵补齐 vLLM 删 Stop 末 token 的协议差异，孤立 Scheduled 元数据押后到首输出。stepped 桥 SteppedEngineBridge 因折叠已在引擎侧账本完成，只把 StepOutputs 一比一翻译成 EngineCoreOutputs；streams/names 双表支撑 abort，UnixAnchor 把单调 Instant 渲染成墙钟。StatsTracker 把累计计数器差分成按批 delta；stats 发布两代分叉：legacy 挂 watch 驱动任务，stepped 发批时现读。
