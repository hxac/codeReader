本讲为手册首篇，确立项目全景。PegaInfer 是纯 Rust + CUDA 的 LLM 推理引擎，对外提供 OpenAI 兼容的 /v1 API，无 PyTorch 与 Python 运行时；设计原则是「共享基础设施、每个模型拥有自己的执行」。请求自上而下穿过：pegainfer-server（约 300 行的纯分发二进制，只做模型检测、CLI 校验、启动引擎）→ frontend（协议、分词、引擎契约）→ 各模型线 crate（经 ModelLine trait 接入，自带调度器与 prefill/decode 执行）→ core/kernels 与 KV 基础设施。Cargo feature 矩阵决定二进制编入哪些模型线：default 仅含 qwen3，其余经 --features 拉入。代码侧 model_lines() 是 cfg 守卫的注册向量，families() 是记录 model_type 与 compiled 状态的「第二真相源」，检测失败时由 feature_gate_hint 提示用 --features 重建；另指出 README 列 7 条线而代码有 8 个 feature（qwen4 为实验线未列入文档）。
