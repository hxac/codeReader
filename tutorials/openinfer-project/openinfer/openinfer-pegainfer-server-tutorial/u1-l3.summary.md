本讲剖析 pegainfer-server 的 main.rs 启动主流程，覆盖三个最小模块：model_lines() 注册向量、main() 服务装配校验链、引擎加载与 Ctrl-C 两段式。核心结论：main() 是一条十余阶段的装配线——ModelLineRegistry 建表、clap 解析 CLI、读 config.json、detect 唯一认领模型线、三级校验（validate_provided 的 consume-or-reject、shared.validate 共享规则、line.validate 线内矩阵）、serve_plan 产出计划；廉价校验全部排在昂贵的引擎加载之前，且各阶段失败形态各异（clap 退出码 2、thiserror 模板、anyhow 上下文链、注册表启动 panic）。引擎加载放 spawn_blocking 与 HTTP 前端并行，前端在引擎注册后才 bind 端口以保持就绪语义；LoRA 分支因构建期需要控制平面而串行，且要求 LaunchedEngine::Stepped；Ctrl-C 在加载期保持默认 kill，引擎就绪后才挂优雅关停；tracing::flush 置于错误传播之前。引入的关键术语：trait 对象 ModelLine、provided_args、ServePlan、LaunchContext、LaunchedEngine 两代形态（Handle/Stepped），供后续单元承接。
