本讲精读 pegainfer-build 的私有函数 target_dirs()，它衔接 discover() 定根与 from_root() 布局探测，把「当前架构」翻译成 CUDA 工具包 targets/ 下的候选目录名。核心结论：CUDA 工具包除经典 include/lib64 外，还把架构相关文件收进 targets/<目录>/include 与 lib（conda 等渠道常用）；aarch64 特化为双候选 aarch64-linux 与 sbsa-linux（分别对应嵌入式与 SBSA 服务器发行渠道），其余架构仅 {arch}-linux 单候选。函数优先读构建目标架构变量 CARGO_CFG_TARGET_ARCH，缺失时回落宿主架构编译期常量 std::env::consts::ARCH；由此引入目标架构与宿主架构之别、环境变量按进程隔离两个概念——CARGO_CFG_* 只注入 build script 进程，测试二进制读不到便走宿主回落，故测试跟随宿主架构建假目录树。双候选可同时收录，探测不要求首个候选存在。
