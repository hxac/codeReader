本讲确立项目定位：PegaInfer 是纯 Rust + CUDA 的 LLM 推理引擎，各模型线为独立 crate、由 cargo feature 控制。核心结论：pegainfer-build 是构建期专用辅助库，与运行时无关，把定位 CUDA 工具包（nvcc、头文件、库目录）收敛为 CudaToolkit::discover()，回退链为 CUDA_HOME→CUDA_PATH→/usr/local/cuda，并适配经典、conda、HPC SDK 三种安装布局；其 root/nvcc/include_dirs 字段公有，lib_dirs 私有、仅经 link_search() 输出链接指令。工作区全景：根 Cargo.toml 共 21 个成员（default-members 仅有 pegainfer-server），版本由 [workspace.dependencies] 统一收口；全仓恰两个消费方——构建总管 pegainfer-kernels 与最小示范 pegainfer-cupti，均只在 build-dependencies 声明。本讲引入的关键术语：build.rs、cargo:rustc-link-search、dev 依赖 tempfile 及测试夹具 TempTree（模拟三种布局，7 个单测）；其极简形态（无 [lib] 段、publish=false、无 version）源于 Cargo 的约定。下一讲精读 discover() 与 from_root() 的实现。
