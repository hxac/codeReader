本讲精读 `from_root` 的统一探测：不为三种 CUDA 工具包布局写分支，而是把 classic（`include`/`lib64`/`lib`）、conda（`targets/<arch>` 下）、HPC SDK 三类目录候选按固定优先级拼进同一张列表，交 `existing_deduped` 收敛——列表顺序即优先级，不存在的候选静默丢弃，conda 空有其名的根部 `include/` 会被 `targets` 下的真 include 压过。HPC SDK 数学库在 CUDA 根之外的兄弟树 `<release>/math_libs/<ver>`，用 `file_name()` 复用版本号、`parent()` 上溯两级定位，路径太浅则静默跳过。nvcc 以 `is_file()` 判 `bin/nvcc`，缺失时回落为裸 `"nvcc"`，解析推迟到消费方 `Command::new` 时由 `$PATH` 完成。关键术语：候选列表、math_libs 兄弟树、nvcc 的 `$PATH` 回落、TempTree 布局测试；收敛与输出（`header_dir`、`link_search`）留待下一讲。
