本讲义收束 pegainfer-build 的 CUDA 工具包探测：from_root 的原始候选经私有函数 existing_deduped 收敛——is_dir 静默过滤不存在项，canonicalize 以规范化身份为键去重（conda 布局因符号链接产生重复），输出保留首次出现的原始路径，候选顺序即优先级。公有方法 header_dir 按具体头文件取第一命中目录，解决 conda「include 存在却缺 CUDA 头」的问题，其结果在 pegainfer-kernels/build.rs 化为 nvcc 的 -isystem 参数。link_search 是私有字段 lib_dirs 的唯一出口：空表仅发 cargo:warning 软失败，非空则逐目录发射 cargo:rustc-link-search=native=...，库名由消费方自行发射。行为由符号链接去重与 conda 布局等测试锚定。
