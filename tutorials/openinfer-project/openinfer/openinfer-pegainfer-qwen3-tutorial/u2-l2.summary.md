本讲承接 u2-l1 的 Config，核心模块是 weights.rs 与 sizing.rs。结论：Attention 把 Q/K/V 按行堆叠成单矩阵 qkv_proj，前向用行偏移 0/q_dim/q_dim+kv_dim 切读，零额外显存；MLP 把 gate/up 合存为 gate_up_proj；o_proj 与 down_proj 因输入不同源保持独立。Qwen3Model 只装权重、配置与常量表，请求状态归 executor——这是 CUDA Graph 指针稳定与 TP 每 rank 一份模型的前提。Qwen3MemoryOptions 三参数分工：gpu_memory_utilization 定总预算、margin 定画像外安全垫、page_size 定 KV 块粒度（仅 16/64，FlashInfer 约束）。关键术语：行偏移访问、融合矩阵、tie_word_embeddings（lm_head 复用词嵌入）、kv_bytes_per_block 唯一公式、sizing.rs 的 checked 乘加。Qwen3-4B 每层 QKV+MLP 约 172.5 MiB，36 层共约 6.06 GiB，为 u2-l4 显存画像铺垫。
