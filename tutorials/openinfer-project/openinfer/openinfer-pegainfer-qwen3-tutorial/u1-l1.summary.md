本讲确立 pegainfer-qwen3 的定位：它是 PegaInfer（纯 Rust+CUDA、全程无 Python 的推理引擎）中 Qwen3 模型线的模型 crate；「默认模型线」来自服务器 crate 的默认 feature 与工作区 default-members 的叠加，故 stock build 只编译 Qwen3，而本 crate 自身无默认 feature，仅有内核报告等工具性开关。核心结论：lib.rs 的 25 个模块可归为配置、权重、前向执行、调度、执行器、投机解码、LoRA、KV 数据面、契约接入、诊断十层；model_line 面向 CLI，frontend_adapter 承接引擎契约，scheduler 是不含契约的纯调度。引入的关键术语：prefill/decode 两阶段；plan/result 相位边界（纯数据、不含引擎句柄，使决策与执行解耦）；runtime 再导出层即公共执行边界——Qwen3Executor 与三对计划/结果类型由此暴露，调度器与模型本地基准共用该入口，服务器则走高层 launch。
