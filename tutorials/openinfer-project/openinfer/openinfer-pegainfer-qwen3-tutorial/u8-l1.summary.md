本讲讲解 Qwen3 的 batch-invariant：同一请求无论单跑还是与谁同批，输出 token 与 logprob 均逐位一致（默认 Tuned 按批形状挑最快算法，天然随批组合漂移）。机制靠两条腿：GEMM 轴上，进程全局 NumericPolicy::Pin（先于执行器构造与图捕获设置，由 tune_decode_gemm_algos 预热）让每个 (M,K) 只在代表点 N=32 钉一个算法服务所有 N，绝不静默回退；chunk 轴上，take_prefill_chunks 的 request_local 网格以「整段-or-跳过」让 chunk 边界只由请求自身长度决定。verify_pin_envelope 启动期用宿主侧 AlgoCheck 全量点检生产可达的 N。构建器守卫拒绝五条组合：decode-overlap、KV offload、TP、投机解码、前缀缓存（LoRA 另拒），并与 CLI 层、执行器 backstop 构成分层设防；草稿器拒绝已推广为覆盖 DFlash 与 EAGLE-3 的通用 speculative 拒绝；PerToken 是 N=1 诊断 oracle。
