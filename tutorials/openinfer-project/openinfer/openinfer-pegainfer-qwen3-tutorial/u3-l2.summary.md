本讲拆开 executor 与 GPU 之间的线程缝，涉及模块为 LocalQwen3Lane、RankWorker、三层通道协议与启动预捕获扫描。核心结论：车道（lane）把一台 GPU 的全部可变状态——模型、KV/解码缓冲、采样 scratch、dflash/eagle3 草稿车道——打包后独占一条 worker 线程，bufs 字段须先于 model drop 以满足 NCCL 析构约束；StepCommand 定“算什么”、WorkerCommand 是控制面、WorkerStepOutcome 承载结果，unbounded 命令通道加 bounded(1) 回信通道拼成 RPC；TP 扇出时主 rank 置 collect_result 回载荷、对端只回 Ack；启动预捕获按 Warmup→逐桶 Capture/Launch→Finalize 分相并配 600 秒看门狗防驱动锁死；bind_model_thread 与 CublasThreadGuard 构成线程入籍与 cuBLAS 句柄同线程销毁手续；worker 死亡时单卡以 WorkerLost 上抛并关停引擎，TP 直接 abort()。
