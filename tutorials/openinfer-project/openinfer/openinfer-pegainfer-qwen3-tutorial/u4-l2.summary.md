本讲覆盖 pegainfer-qwen3 调度器的 plan.rs：执行计划与投机门控。build_next_plan 是纯函数批形成策略，按「有无活跃请求×有无待prefill」与投机开关产出 ExecutionPlan 五变体（Prefill、Decode、SpeculativeDecode、GatedSpeculativeDecode、Unified）；prompt_logprobs 与投机捕获需求会定向否决 Unified，捕获路由故意取宽松超集，宁可多做专用 prefill 也不让投机静默失效；执行产出纯数据 ExecutionArtifacts 供 resolve 层承接。投机门控 speculation_decision_at 遵循全有-or-全无，三态 Speculate/Gated/NotReady 依次检查草稿器装载、max_draft_batch 批宽能力位（EAGLE-3 报 Some(1)、DFlash 报 None）、逐请求就绪（捕获/LoRA/logprobs）与负载门；Gated 用单 token verify 保住捕获以待恢复，宽批 NotReady 走纯解码牺牲捕获；采样参数不构成门。PEGAINFER_SPEC_* 旋钮经 OnceLock 只读一次、坏值拒绝启动。
