本讲覆盖 Qwen3 对接引擎契约的三个最小模块：launch 启动策略、start_qwen3 装配执行器、start_with_executor 铸造 Engine 并拉起调度线程。核心结论：契约三件套中 Engine 交出调度线程句柄与元数据，Scheduler 被驱动线程轮询 submit/step/metrics，RequestLedger 由驱动侧拥有、按 RequestId 记录裁定与 token；frontend_adapter 只承担账本写入与引擎装配两项契约职责。launch 把 DFlash 与 EAGLE-3 两条草稿路径折叠成互斥的单槽 DraftModel（两者共享目标隐藏态捕获管线与显存预留）。构建后三旋钮顺序不可乱：关前缀缓存、开 decode 重叠、最后装草稿，因装载草稿会强制关闭前缀缓存。关键术语：max_draft_batch 能力位（DFlash 不限、EAGLE-3 仅批一）、DeferredFinish 延迟完成、ModelExecutor 抽象与九段式 step，为 u2-u4 与 u6 铺路。
