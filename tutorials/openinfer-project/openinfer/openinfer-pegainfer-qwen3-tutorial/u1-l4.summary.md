本讲通过 lib.rs 的 launch 与 frontend_adapter.rs 的 start_qwen3、start_with_executor 三个最小模块，讲透 Qwen3 与 pegainfer-frontend 引擎契约的接缝。关键术语：契约三件套 Engine/Scheduler/RequestLedger——分别是交与服务器的调度器句柄与元数据、被驱动线程轮询的 submit/step/metrics、按 RequestId 记录裁定与 token 的账本；另有 apply_effects、DeferredFinish、ModelExecutor、servable_len。核心结论：启动链为 launch→start_engine_with_offload_inner→start_qwen3→start_with_executor→spawn_scheduler，launch 独占启动策略（设备映射、LoRA 强制关 CUDA 图、三条提前拒绝）；构建后三旋钮 set_no_prefix_cache→enable_decode_overlap→load_dflash_draft_model 顺序不可乱，因草稿装载会强制关前缀缓存；step 为八段式流水，账本写入与调度机制读写分离；取消是响应式的，完成事件有普通与 DeferredFinish 扣留两种出口。
