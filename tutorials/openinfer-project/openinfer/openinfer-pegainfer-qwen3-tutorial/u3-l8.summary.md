本讲覆盖解码步的三个路径决策模块。SplitKvConfig 定义 split-KV 切分公式 chunk(L)=max(下限, ⌈L/m⌉)，下限防切得过碎（归并开销），上限防块数超限；标签 split_kv_{chunk}x{max} 与 kernel 清单变体互逆，生产 Tuned 配置即 64x64。DecodeAttentionPath 解决非分区内核小批欠填充：Tuned 按批宽选路（≤32 走 split_kv，之上 non_partition），Pin/PerToken 无条件钉死 SplitKv 且 chunk 只依赖上下文上限，保证块数请求本地、批内逐位一致；每桶各持两条路径的 CUDA 图，工作区按构造期策略快照预留。DecodeProjectionPath 是 QKV 融合的失败关闭资格门：TP=1、Tuned、无重叠、无草稿器且 (SM, 几何) 逐行命中 QUALIFIED_QKV 认证表才 FusedQkv，否则退 Split 并报理由标签。本次提交把草稿器门从 dflash_enabled 推广为 draft_enabled（标签改 speculative），DFlash 与 EAGLE-3 走同一道门。
