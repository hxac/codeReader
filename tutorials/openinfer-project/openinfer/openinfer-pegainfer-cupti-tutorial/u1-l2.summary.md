本讲精读 pegainfer-cupti 仅 34 行的 build.rs，讲清 C++ 源码如何编成静态库、CUPTI 如何被找到并链接。CUDA 探测统一交给共享 crate pegainfer-build 的 CudaToolkit::discover()（单一事实来源），产出 root 与 include_dirs；CUPTI 属「观测用」组件，经典安装藏于 extras/CUPTI 目录，脚本用 is_dir() 做「存在才追加」，缺失时回落系统默认路径，失败被前置到编译期或链接期而非运行期（错误前置）；cc::Build 自动声明自产静态库的链接，cuda、cupti、stdc++ 三个外部库须由脚本显式声明；clippy 也要先执行构建脚本，故 CI 把本 crate 排除在 lint 之外。关键术语：cargo:rustc-link-lib/link-search、rerun-if-changed（一经发出即关闭默认全量重跑）。
