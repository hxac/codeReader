pegainfer-cupti 是 Rust 通向 NVIDIA CUPTI 的桥，职责只有一件事：把一段被命名的 GPU 区间采样成 Vec<f64> 硬件计数器值；吞吐基准与线上推理均不归它管。四个文件纵向分工：Cargo.toml 声明零运行时依赖；build.rs 探测 CUDA 工具链（CUPTI 藏于 extras 目录）并把 C++ 源编成静态库；range_profiler.cpp 承载 CUPTI 会话全流程并导出唯一 extern "C" 入口 pegainfer_cupti_profile_range；lib.rs 则把 12 个 C ABI 裸参数收敛成唯一公开函数 profile_range_with_prepare——闭包经蹦床回传、输出缓冲变返回值、错误合并为 CuptiProfilerError。因指标较多时 CUPTI 会多遍回放 kernel，launch 闭包必须可重复安全执行。它是 workspace 平级成员，唯一 Rust 消费方是 qwen3 的 kernel-report 工具（prepare 在区间外清 L2、launch 发射被测 kernel），经 optional 依赖、kernel-report feature 与 required-features 三层门控，把 CUPTI 完全挡在默认构建图之外。关键术语：硬件性能计数器、Range Profiler、C ABI、回放、蹦床回调、三层门控。
