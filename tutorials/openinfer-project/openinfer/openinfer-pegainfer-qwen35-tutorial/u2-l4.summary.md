本讲精读 qwen35 的层结构。核心模块是 TransformerBlock35：持有两种层共有的 input/post_attention 双 norm 与 MLP35，注意力子层封装为枚举 LayerKind（FullAttentionLayer / LinearAttentionLayer）；config.layer_types 在加载期决定装配成哪个变体（checkpoint 前缀分别为 self_attn / linear_attn），前向期 match 分派。贯穿性结论：层结构体只装不可变权重——全注意力的 K/V 写入模型级共享分页池（仅按全注意力层数开池，用 full_idx 索引），线性注意力（Gated DeltaNet）的递推状态与卷积状态外置于调度器侧的 RecurrentState（用 linear_idx 索引），这一权重与状态分离是 CUDA Graph 指针稳定和前缀缓存的前提。全注意力层引入 gated Q（q_proj 行含 per-head [q|gate] 交错块，TP 须按 head 整块切）、head 共享 QK-norm、partial RoPE 及「norm+RoPE+落页」融合预备内核。线性注意力层引入装载期 vstack 融合（in_proj_qkvz / in_proj_ba）、因果 depthwise conv1d、GDR chunkwise 递推与 z 门控 RMSNorm。所有 norm 为 (1+w) 变体；TP 通信点统一在回到 hidden 维处（o_proj / out_proj 后 all_reduce_hidden），prefill 与 decode 前向五步同构。
