本讲剖析 pegainfer-qwen35 调用 CUDA/Triton 内核的 FFI 胶水层，核心文件是 ops.rs 与 recurrent.rs。结论一：内核符号经「本 crate ffi → core → kernels」三级重导出，声明唯一集中在 kernels，Half=u16 为共享 ABI 类型，ops.rs 把 core 通用、kernels 专属、本 crate 自封装三类算子汇成目录页。结论二：device_ptr/device_ptr_mut 返回（指针， guard）二元组，guard 是登记在流上的借出凭据，必须活过 unsafe 发射并与发射同流，命名绑定是防御性惯例。结论三：GDR chunkwise 预填充由 prepare→cumsum→A→solve→recompute→state→output 七个 Triton AOT 内核编排，仅 state 阶段读写持久递推状态，scratch（GdrChunkwiseScratch35）随 seq_len 线性伸缩、块长 64。错误约定分两种：Triton 内核返回 CUresult，nvcc 内核返回 i32 码；形状断言集中在信息最全的 chunkwise 入口。
