本讲绘制 pegainfer-qwen35 的模块地图：src/ 共 31 个文件约 1.6 万行，按职责归为配置、权重、执行、调度、缓存、TP 六大类；TP、执行、调度各占约四分之一，配置最小却是所有路径必经之地。核心结论：lib.rs 的 mod 声明即 crate 目录页，可见性修饰本身就是 API 边界；公开面分三层——正门（model_line、start_engine*）给根服务器，runtime 与 runtime_ops 两个侧门仅供本 crate 测试、调试与基准。双路径分叉仅两处：启动函数按设备数分叉（单 GPU 先载权重再起调度器，TP 整体委托）与 SchedulerBackend 枚举；TP 专属模块仅 4 个，单 GPU 专属仅 unified_forward，其余皆为共享底座。关键术语：六大类、三层公开面、双路径分叉、控制器-worker 结构、三来源算子面（core 通用、kernels 专属、本 crate 封装）。后续单元按 config→weights→执行→scheduler→prefix_cache→tp_executor 顺序逐一放大此地图。
