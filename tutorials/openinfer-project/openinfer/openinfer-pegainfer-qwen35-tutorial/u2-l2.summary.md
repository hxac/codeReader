本讲精读 tp.rs，补上 Config35 所缺的 TP 几何一半，分三个最小模块：类型化校验、shard 切分公式、kernel 兼容门。TensorParallelConfig 以私有字段加唯一构造边界落实「不可表示非法状态」，world_size 为 0 或 rank 越界根本构造不出来，Default 即 TP1，单卡只是 W=1 特例。LocalGeometry 先过四条有序整除门——注意力头数、KV 头数、intermediate_size、线性 key 头数，失败即 TpIndivisible 且 fail-closed 拒绝复制（线性 value 头数凭上游倍数不变量免检）；再派生全部 local_* 维度，hidden_size 从不切分，GQA 组比率是 TP 不变量。P2c 门在执行器启动层而非 tp.rs：组比率不在编译清单 SUPPORTED_GQA_GROUP_SIZES 内时，降级到批量混合 eager 回退并禁止图捕获，而非拒绝启动。承接术语：rank、world_size、shard、LocalGeometry、P2c 门、批量 eager 回退。
