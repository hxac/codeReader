本讲建立 pegainfer-qwen35 的定位地图。PegaInfer 是纯 Rust + CUDA 推理引擎，请求经 frontend 契约（EngineHandle/TokenEvent）分派到各模型 crate。本 crate 是唯一混合架构线：全注意力层走分页 KV cache，Gated DeltaNet（GDN）线性注意力层以固定大小递推状态记忆历史，显存不随上下文增长（4B 为 8 full + 24 linear），故 crate 内并存 KV 与 recurrent 两套状态系统。Qwen3.8 因 model_type 与文本几何一致而共用此线。整个 crate 被 qwen35 feature 门控并转发至 kernels，构建期借 Python + Triton 生成 GDR chunkwise prefill 内核，默认构建保持无 Python。依赖边界：frontend 给契约、core 给共享算子、kernels 给专属内核、kv-cache 给分页 KV、sample 给采样。
