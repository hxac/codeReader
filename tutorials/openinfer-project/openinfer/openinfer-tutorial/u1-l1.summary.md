本讲确立 PegaInfer 的定位：纯 Rust + CUDA、无 PyTorch 与 Python 运行时的 LLM 推理引擎，对外提供 OpenAI 兼容 API，并铺垫了 prefill/decode 两阶段与 KV cache 等基础概念。核心结论：七条模型线（qwen3、qwen35、gemma4、deepseek-v2-lite、kimi-k2、glm52、k3）各由一个 cargo feature 按需编译，仅 qwen3 默认开启，启动时凭 checkpoint 的 config.json 识别模型家族，未编译的线由 feature_gate_hint 提示重建。全仓架构原则是「共享基础设施、模型自持执行」：20 个 workspace 成员分四层——前端契约（server/frontend/sim）、七个模型 crate、共享运行时（core/kernels/sample 等）与 KV 基础设施；依赖只自上而下，模型线互不依赖。协议与分词复用 vLLM 的 Rust frontend crates，server 只做纯分发，引擎契约（GenerateRequest/TokenEvent 与 ModelLine trait）是前端与模型之间的唯一接缝。
