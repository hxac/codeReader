本讲剖析共享 GPU 算子的三层结构：`kernels::ffi` 只声明 C ABI；`kernels::ops` 是唯一 unsafe 边界，负责几何校验、取指针、检查返回值；`core::ops` 做类型翻译并 re-export 符号，模型 crate 只依赖它。以 `prefill_attention_paged_into` 为标本展示全链：它一次打包 QK norm+RoPE、paged KV 追加与 FlashInfer 分页注意力，token 位置一律取 plan 的逐 token 数组。引入术语：`PrefillPagedPlan` 是构建一次、跨层共享的预填充计划，预分配加原地刷新保证指针稳定以支撑 CUDA Graph；`SplitKvCsr` 与 `build_split_kv_csr` 描述 split-KV 解码的 CSR 切分，槽总数恒为 padded_bs×cap；`KernelCall`/`TensorSpec` 是与显存无关的调用元数据 IR。FFI 约定：void 内核视为不可失败，i32 返回零为成功、-1 取回异常文本。
