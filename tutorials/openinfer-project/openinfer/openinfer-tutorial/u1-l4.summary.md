本讲是单元 1 收尾，讲如何在无 GPU 机器上体验 PegaInfer 全链路。模块上涉及 pegainfer-frontend 的 vllm::serve 服务入口、Scheduler trait（submit/step/metrics 三方法）与 drive 循环，以及 CPU-only 模拟引擎 pegainfer-sim。核心结论：sim 与真实模型共用同一 OpenAI 兼容前端（/v1/completions 与 /v1/chat/completions，SSE 流式以唯一一行 data: [DONE] 终止），端口可达即引擎就绪。关键术语：TTFT（首 token 延迟）与 TPOT（相邻 token 间隔），SimulatedEngineConfig 用 TTFT=base+prompt_len/prefill_rate 加固定 TPOT 三参数建模时序；SimScheduler 在准入时一次性计划补全，输出 token 按 prompt 循环（或剧本重放），每步每请求至多发一枚，以 1ms 停车切片平衡 CPU 占用与准入延迟。sim 只需 tokenizer.json、tokenizer_config.json、config.json 三个元数据文件，无需权重；它只验证协议与前端栈，不提供精度或真实吞吐证据。
