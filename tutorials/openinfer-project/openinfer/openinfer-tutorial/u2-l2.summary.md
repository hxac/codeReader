本讲拆解 server 与模型 crate 间的接缝——ModelLine trait：除身份方法 name 外含七个协议方法，probe 认领 config，launch 经 LaunchContext 取输入并启动引擎，其余管理私有 flag、共享 flag（SharedArgs）消费声明与校验；接入新模型线只需实现 trait 并在注册表加一行，server 零改动。ModelLineRegistry 是协议执行者：detect 实行唯一认领，两条线同时认领报 Conflict，零条认领报 NoMatch 并附逐线拒绝原因；consume-or-reject 要求显式提供的 flag 落在核心、该线消费或私有三集合之一，默认值不算提供；构造期以 panic 自检 flag id 与拼写冲突，因 release 下 clap 断言失效。Qwen3Line 是标准实现样本：probe 双重门（model_type 加 architectures），launch 返回 LaunchedEngine::Stepped；ServePlan 支撑 HTTP 前端与权重加载并行。
