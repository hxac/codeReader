本讲讲解 pegainfer-kernels 的 tensor.rs 张量与设备地基。DeviceContext 以 Arc 持有 CUDA context、单计算流与设备号，构造时先关事件跟踪再开流并初始化 cuBLAS；单流设计消除跨流同步，从根上保护 CUDA Graph 捕获。流覆盖机制用线程局部槽加 StreamOverrideGuard（保存旧值、Drop 恢复、可嵌套），算子统一经 active_cu_stream 取流，作用域内整体切流而签名零改动，是 Green Context SM 分区的基础。bf16 张量三件套 DeviceVec/DeviceMatrix/HiddenStates：HiddenStates 预分配最大、每步改写 seq_len，token i 偏移 i×d，cuBLAS 列主序直读；bf16→f32 无损支撑主机位级断言。const 泛型层 GpuTensor/GpuWeight/NormWeight 经门卫把形状检查从运行时搬到编译期（需 nightly 特性）；KernelCall 是与显存无关的擦除元数据。全部类型经 pegainfer-core re-export 给模型 crate。
