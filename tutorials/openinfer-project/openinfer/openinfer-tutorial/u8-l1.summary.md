本讲剖析 Qwen3.5（pegainfer-qwen35 crate）的混合注意力架构：24 层 Gated DeltaNet（GDR）线性注意力 + 8 层全注意力，由 layer_types 配置逐层运行时分派。线性层以固定大小循环状态 S 替代 KV cache，解码为带遗忘门与写入强度的 O(1) 单步递推（原生 CUDA、设备侧指针表批量），预填充为 64-token 七阶段 chunkwise 流水线（构建期 Triton AOT 生成、改编自 FLA，运行期零 Python），其 chunk_state 缓冲天然物化每块边界的状态快照。每请求 RecurrentState（f32 循环状态 + bf16 conv 状态，约 49 MiB）与上下文长度无关；前缀缓存命中须 KV 与循环/conv 快照在同一 256-token 边界并存（设计阶段，尚未落地）。TP 执行器复用 Qwen3 的 controller/worker 广播形状：线性状态按 value 头切分、从不 all-reduce，rank-0 独占采样，图模式用固定地址槽位并经预捕获四相位防死锁。#1046 后词表分 vocab_size/decodable_vocab/selection_vocab 三个宽度，采样 scratch 经 with_selection_width 携带双宽度（详见 u8-l7）。
