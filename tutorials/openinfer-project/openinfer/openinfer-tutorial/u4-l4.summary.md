本讲剖析 pegainfer-core 的权重装载模块，覆盖四个主题：一、safetensors 加载管线——shard 探测、mmap、反序列化三步只建零拷贝视图，单文件与分片布局在入口统一为「分片路径＋张量名→下标」；二、两条上传通道——load_tensor_2d_* 一族 pageable 直传，与 StagedWeightLoader 的 pinned 双缓冲 staging：上传意图先记录（校验前置、显存先分配），finish 一次性执行，两块 pinned 缓冲使 CPU 填充与 DMA 搬运重叠；三、TP 切分几何——row shard 切输出维（q/k/v、gate/up，免通信），col shard 切输入维（o_proj、down_proj，输出为部分和需 all-reduce），row stitch 从同一源张量拼多段行区间（qwen35 融合 QKV）；四、WeightPrefetch advisory 并行预读——RWF_NOWAIT 驻留探测、速率地板自律退出、Drop 聚合错误。核心结论：布局差异在入口抹平，staging 兼得校验前置与流水线重叠，切分方式决定 all-reduce 的位置。本讲为 u4-l5 CUDA Graph 的显存指针稳定性铺垫。
