本讲为前端单元收官，把请求旅程串成端到端十站：外部 vllm-server crate 负责 HTTP 路由、模板渲染与分词，经 ZeroMQ（DEALER/PUSH）进入 SteppedEngineBridge；桥先发 EngineCoreReadyResponse 冒充 vLLM 引擎完成握手，start_request 校验参数并翻译采样词表，不合格请求直接终态 Error、不进调度器；SchedulerHandle::submit 经 crossbeam 通道入南世界，drive 循环按排空→step→metrics→commit_step 节奏推进，RequestLedger 保证每请求恰一终态；每步一条 StepOutputs 经 tokio mpsc 回流，reduce_update 翻成 EngineCoreOutput，由外部 crate 增量解码成 SSE 流。核心结论：北 async、南同步两世界仅两条通道相连，EngineCore 前缀类型只许出现在桥里；HTTP 与引擎加载并行但端口可达即引擎就绪；submit 永不失败，drop bomb 兜底 Failed 终态；abort 是旗标且先摘表后翻旗；Stop 终态补哨兵 token 对冲 vLLM 删末 token 语义；元数据步搭车不发空输出。legacy 桥与新契约并存，Qwen3、Gemma 4、pegainfer-sim 已走新桥。
