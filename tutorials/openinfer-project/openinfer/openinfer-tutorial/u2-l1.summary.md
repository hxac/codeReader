本讲精读 server 入口的纯分发设计。main() 六步：注册（收集已编译模型线的 MODEL_LINE 静态 trait 对象组成 ModelLineRegistry）→ 合并解析 CLI → 读 config.json 探测唯一认领的模型线 → 三层校验（consume-or-reject、共享层、模型层）→ spawn_blocking 执行 launch 得 LaunchedEngine → 按 ServePlan 分发到 LoRA、prefill-only、常规三条 vLLM 前端入口。核心结论：server 永不出现模型 crate 的选项类型，这由依赖方向保证而非风格约定；ServePlan 只能从 CLI 推导，使 HTTP 前端与权重加载并行；探测 NoMatch 时 feature_gate_hint 按静态表提示用 --features 重建。引入术语：ModelLine、ModelLineRegistry、SharedArgs、LaunchContext、ServePlan、LaunchedEngine（Handle/Stepped 两变体）、DetectError（NoMatch/Conflict）、consume-or-reject。
