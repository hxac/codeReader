本讲义梳理 pegainfer-sim：一个纯 CPU、无 GPU 与模型权重的模拟推理引擎。HTTP 前端与请求契约走真实生产代码，并遵循与真实引擎一致的 step contract，仅 token 计算与定时被模拟，用于在无 GPU 环境验证前端协议、调度器行为与指标。引入术语 TTFT（首 token 延迟，由 prefill 决定）与 TPOT（逐 token 耗时，由 decode 步长决定）。核心结构：lib.rs 装配引擎并实现 SimScheduler，分两条互斥车道——legacy 车道按固定 TTFT/TPOT 节拍发 token，--profile 车道由 worker.rs 的确定性 vLLM V1 式调度状态机 WorkerState 决定每步内容，再经 profile.rs 的 JSON 档案（含 manifest 的 sha256 校验）三线性插值出步时长；logprobs.rs 是协议夹具，main.rs 仅是 CLI 壳。单元测试藏于这三个源文件；集成测试用 SimServer 真起 HTTP 服务做 e2e，fixtures 提供“档案+manifest”的 profile bundle。工作区 default-members 为 pegainfer-server，运行须带 -p pegainfer-sim。
