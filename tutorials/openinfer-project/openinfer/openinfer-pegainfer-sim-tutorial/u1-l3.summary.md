本讲覆盖 pegainfer-sim 中配置到 `Engine` 的装配层。`SimulatedEngineConfig` 是模拟引擎全部行为的单一定义点：三个定时参数在构造期即校验（非负、有限、吞吐严格为正），`with_*` 采用消费型 builder 模式，链式打开假想投机解码、前缀缓存、脚本化补全与档案车道等旋钮，其中仅 `with_engine_profile` 返回 Result（装载前先全量校验档案）。`start_engine` 及其分区版把配置按值克隆 N 份，每份经 `spawn_scheduler` 铸成一个具名调度器线程；partitions 即前端可见的引擎数，与前端声明不符则启动被拒。`EngineInfo` 中 `kv_capacity: None` 使前端跳过 batch-fit 检查、`servable_len: None` 使长度上限退回模型上下文窗口——None 是显式的能力声明而非遗漏。`Scheduler` trait 只需实现 submit/step/metrics 三方法，确立「循环留在前端、行为留在模型线」的分工；`step` 依配置中 profile 是否存在，在 legacy 定时车道与档案车道间分岔。
