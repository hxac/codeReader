本讲只读 Kimi-K2 crate 的 config.rs 一个文件，覆盖常量、配置探针与并行形状三部分。核心结论：模型几何全部写死为编译期常量——hidden 7168、Q 压缩秩 1536、KV 压缩秩 512、61 层（1 dense + 60 MoE）、384 个路由专家每 token 选 8 个另加 1 个共享专家、INT4 组 32——这既是 crate 与 checkpoint 之间的合同，也是后续 typed scratch 的前提。probe_config_json 是纯校验门：不读权重、不分配资源，接受 kimi_k25（text_config 包裹）与扁平 kimi_k2 两种配置身份，除几何外还锁定路由语义（noaux_tc、sigmoid）与量化格式。KimiK2ParallelShape 提供 tp8_ep8 与 tp1_dp8 两种拓扑，按头、专家、词表三条除法推出每个 rank 的本地切片，两种拓扑 local_experts 同为 48，体现 EP 与 TP/DP 正交；KimiLocalDims 进一步给出前向张量的真实宽度。此层刻意不挂 feature 门，无 GPU 也能编译测试，派生宽度由权重清单的 rank_plan 消费。
