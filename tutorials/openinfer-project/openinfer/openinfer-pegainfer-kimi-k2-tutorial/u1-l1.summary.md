本讲确立 PegaInfer 与 pegainfer-kimi-k2 crate 的定位。PegaInfer 是纯 Rust + CUDA 的 LLM 推理引擎（无 PyTorch），组织原则是「共享基础设施、模型自持执行」：workspace 共 21 个成员、8 个模型 crate；kimi-k2 承担 Kimi-K2.6 模型线，架构特征为 MLA 注意力、MoE（384 个专家每 token 激活 8 个）、Marlin INT4 量化与 8 卡专家并行，并支持双拓扑 TP8/DP1（MoE 走 NCCL）与 TP1/DP8（走 DeepEP）。请求链路是 HTTP → 前端 → EngineHandle 契约 → 模型自己的调度器 → TokenEvent。依赖清单即分工合同：frontend 提供契约、kernels 提供张量与 kernel FFI、kv-cache 提供分页 KV、core 提供运行时、sample 提供采样、bench 提供计时。feature 体系：default 为空；kimi-k2 门住运行时本体并向 kernels 传导 CUDA 编译；kernel-report 是观测超集；未开 feature 时 start_engine 只是报错桩。并行拓扑由 crate 的 launch 私有决策，服务器不硬编码。
