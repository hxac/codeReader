本讲沿「safetensors 分片 → mmap → 切片 → H2D → 权重包 → 前向缓存」的真实数据通路，串起五个最小模块：weights/load 的切片加载主循环、weights/context 的 rank GPU 上下文、weights/package 的三层权重包、worker 侧前向缓存构建，以及无 GPU 的纯 CPU 加载单测。核心结论：逐 shard mmap 流式上载，整张量自映射视图直达显存，行/列切片先在主机抽取成连续字节再 H2D；MoE 专家凑齐一层即 Marlin 打包并删 raw 副本以压峰值显存。引入的关键术语与概念：三层权重包——KimiRankGpuWeights（原始字节层）→ KimiRankExpertMarlinWeights（Marlin 专家层）→ KimiOneTokenForwardCache（类型化前向层），KimiRouterGpuWeights 作为 raw→typed 的借用视图且不量化；每 rank 独享 CUDA context/stream 并绑定 worker 线程；加载链路报错一律携带张量名与 rank 上下文，便于定位坏权重。
