本讲聚焦 src/weights/package.rs，讲清 Kimi-K2 专家 INT4 权重如何从 checkpoint 布局整形为 Marlin 显存缓冲。checkpoint 里每个投影是成对两份张量：weight_packed（I32，[out,in/8]，8 个 int4 装一个 int32）与 weight_scale（BF16，[out,in/32]，组大小 32）；gate/up 为 2048×7168，down 相反。核心流程是四缓冲流水：48 个本地专家先 D2D 拼接成专家主序 staging，再由 reorder_weight/reorder_scale 重排为 Marlin 布局（只换布局不压缩字节，nibble 序 LowThenHigh，实测 plan 与 EP8 manifest 合同双重核对），随后 fuse_w13 把 gate/up 融成一份缓冲，GEMM 输出宽 MARLIN_W13_OUT_DIM=4096。打包在分片加载循环内流式进行：凑齐一层即打包并删 raw，压住峰值显存。产物 KimiRankExpertMarlinWeights 逐层持有 w13 与 down，专家主序经强校验，供后续 MoE 后端零拷贝定位；router 权重不量化、不参与打包。
