本讲精读 pegainfer-kv-offload 的配置层。OffloadConfig 是实例级调参清单：身份字段（instance_id、namespace、device_id）加宿主字段（pinned 池容量、hugepages、线程数、p2p）；use_hugepages 是唯一公开字段，其余经构造参数或消费式 builder 设置——可见性即 API 设计。namespace 是内容寻址域：相同是互相命中的必要条件，不同则必互不可见；qwen3 把 KV 几何连同模型规格编入，防几何相同的不同模型静默串块。P2pConfig 三字段（MetaServer 地址、通告地址须字面 socket、RDMA 网卡）撑起 P/D 分离数据面，建宿主时过三道 fail-fast 校验：网卡非空、地址可解析、端口先 bind。host() 把宿主半边拆成 crate 私有的 HostConfig，身份字段留给 register；共享宿主走 with_arenas_on，不经 OffloadConfig，对应 DP-rank 共享模型。
