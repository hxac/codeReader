pegainfer-kv-offload 是 pegainfer 与 pegaflow 之间的进程内 KV 卸载桥：pegainfer 拥有 GPU 分页 KV（KvBuffer 与 kvbm BlockPool），pegaflow 拥有 host/SSD/RDMA 深层存储且语义无关，OffloadEngine 是决定何时搬哪些块的连接器大脑。v1 只覆盖 CPU 层，CPU 命中前缀叠加在 GPU 命中前缀之上且保持一段连续前缀，交错形态被刻意排除；save 尽力而为、fire-and-forget，load 强排序但不阻塞 admission，统一经可轮询的 OffloadHandle 在调度 tick 收账。lib.rs 以 6 个私有模块导出 11 个名字（8 自有加 3 个 pegaflow 再导出：EngineError、PegaEngine、QueryLeaseId），layout（KvArena）与 SaveHandle 刻意不导出，下游 qwen3 仅依赖本桥。Cargo.toml 三决策：git rev pin 保证可复现、default-features=false 避开 cudarc 版本冲突、rdma feature 支撑 P/D 分离数据面。关键术语：分页 KV、分层存储、内容寻址、再导出、进程内桥。
