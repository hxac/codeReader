本讲把 pegainfer-kv-offload 的验证环境搭对：测试分两层——src 内联 8 个纯 CPU 单测（layout 几何×3、vllm_hash×5 对 vLLM 黄金向量逐字节比对），任意机器可跑；tests/cpu_roundtrip.rs 是唯一需真实 CUDA 设备的集成测试，只走 lib.rs 公开 API，覆盖 GPU→CPU→GPU 字节级 roundtrip。pegaflow-core 是唯一非 workspace 依赖：git rev pin 钉死已知语义提交（P/D 生产者版本按此对齐），default-features=false 避开 cudarc selector 冲突，显式开 rdma（跨节点块抓取 + MetaServer 发现），Cargo.lock 再冻结一层，升级必为显式可评审修改；--release 是全仓库硬约定（debug 对 CUDA 极慢会超时）。引入的关键术语：rev pin、workspace member、feature、golden vector（黄金向量）、page-first 融合布局（SEGMENT_LEN/LAYER_STRIDE/PAGE_STRIDE 几何）、对账断言、期望值按逻辑序号而非物理块号生成、负向控制（未加载块保持全零），以及 --lib/--test 目标选择与 -- 后参数传给测试二进制的用法。
