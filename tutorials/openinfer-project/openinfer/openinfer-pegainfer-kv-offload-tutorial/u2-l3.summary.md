本讲精读 host.rs：HostConfig 的归宿是共享宿主 OffloadHost——三字段合一：持有 pinned 池的 PegaEngine、多线程 tokio Runtime、可选的 P2P 停机 oneshot。核心是 DP-rank 共享模型：一个宿主可挂任意多个 rank 级 OffloadEngine（私有 new 自建或 with_arenas_on 共享），块按 (namespace, hash) 寻址，namespace 相同即可跨 rank 命中；宿主类型公开而构造私有，只能经引擎构造函数诞生。PegaEngine 必须在 runtime.enter() 守卫内构建，否则其内部 tokio::spawn 直接 panic。P2P 启动三道 fail-fast：RDMA NIC 非空、advertise_addr 须为字面 SocketAddr、端口 bind 先行并经 ready channel 回话——坏配置活不过构造函数。GC 每分钟双清扫两类垃圾：对端崩溃遗留的过期传输锁（TTL 兜底）、本端被弃请求的孤儿预取条目（5 分钟兜底）。末句柄 drop 时 runtime 关闭：在途 save 被弃、对端退化本地 prefill、flush 屏障取消——宁显式失败不谎报就绪。
