本讲覆盖 engine.rs 的构造半边。`new` 路径私建 OffloadHost、从融合 KvBuffer 推导几何，qwen3 生产与测试共用；`with_arenas_on` 共享既有 host、由调用方声明 arena 列表，为 DP-rank 共享与 vLLM MLA namespace 预留，指针稳定、同池块号、page_first 对齐三条契约由文档注释承载。两路在私有 register 收口：17 个参数（身份/拓扑/逐层几何/传输/格式）一次性「烤进」pegaflow 注册表，此后地址按「基址+块号×步长」还原、永不刷新，故设备分配必须终身指针稳定，否则错字节以旧 hash 持久化即静默腐蚀。block_stride_bytes 解耦块间步长与拷贝大小；page_first 描述 host 侧存储格式（layer-first 或 page-first）；TransferMode 默认 Direct 走 DMA 引擎以避让 decode 的 SM，纯 prefill rank 应翻成 kernel（精确匹配，拼错静默落 Direct）。write_barrier 初始化为空，save/query/load/flush 四条链路留待后四讲。
