本讲解剖 pegainfer-kernels 的 src/ops.rs 与算子包装层。ops.rs 是包装层门面：cfg 门控的 mod 声明与 pub use 再导出成对出现，不开 feature 则符号根本不参与编译；尾部沉淀 checked_i32 与 FFI 错误解码工具。核心是 wrapper 标准五步：查形、取指针（守卫保活）、转类型、传 active_cu_stream 并 unsafe 调用、收 Result。讲义区分三代 wrapper 形态：第一代 FFI 返回 void、无错误回收；第二代用 CUresult 配 ensure!/checked_extent/checked_i32；分发代用 match 在 FFI 符号间选择（如 gated norm 的 SiLU/Sigmoid）。HiddenStates 布局约定「token i 连续存于偏移 i×hidden_dim」使 kernel 只需两个 i32 维度，stride 恒等于 hidden_dim；checked_extent 守住逻辑尺寸不超过背衬缓冲；Columns 列带需按父张量行宽寻址。融合 kernel 以位级等价（assert_bitwise）为正确性门禁，标本为 rms_norm_into。
