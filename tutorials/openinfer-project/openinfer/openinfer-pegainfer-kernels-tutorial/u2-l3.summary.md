本讲剖析 pegainfer-kernels 的 FFI 层与跨语言错误契约。最小模块：`src/ffi.rs` 门面（定义不透明类型 `Half`，即 `u16` 的 16 位浮点容器，声明按模型线 feature 门控分文件、统一 re-export）、C++ 侧 `ffi_guard.cuh` 宏与 `last_error` 存储、Rust 侧 `ops.rs` 解码器。核心结论：C++ 异常不能穿越 `extern "C"`（Rust 帧缺少 unwind 元数据，漏网即 abort 进程），`PEGAINFER_FFI_GUARD_BEGIN/END` 宏在 C++ 侧 try/catch 拦截，把 `e.what()` 写入 thread-local 的 `last_error` 并返回 `-1` 哨兵，进入时先清空防陈旧读取；错误码统一折叠到 `CUresult`：`map_cuda_error` 映射 runtime 错误，cuBLAS 状态以 `PEGAINFER_CUBLAS_STATUS_BASE=100000` 垫高，构成 0 成功、负哨兵、CUDA、cuBLAS 四段互斥区间。Rust 侧由 `ffi_exception_message`（消息指针须立即拷贝）与 `ffi_status_detail` 解码，wrapper 经 `anyhow::bail!` 收口上抛 `anyhow::Error`。
