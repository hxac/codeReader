本讲覆盖 pegainfer-kernels 共享算子层的四族算子：embedding 查表、elementwise 逐元素运算、argmax 贪心解码与 FlashInfer 随机采样。核心结论：embedding_batch 以设备端 u32 token id 查表并直写列主序输出以兼容下游 cuBLAS，满足整除与对齐条件时走 uint4 向量路径，TP 场景用词表分片加 all-reduce；elementwise 家族（softcap、gelu_tanh_mul 为标本）的纪律是舍入顺序与参考实现逐位对齐，参数校验前置到 wrapper 层；argmax 家族由单行、批式、两阶段 split 演进到 indexed 版，partials 携带全局下标，平局最小下标胜、NaN 永不赢；gpu_sample_batch_into 按行过滤，每行独立的 temperature/top_k/top_p/min_p，贪心行拒收，min_p 行独立成趟并派生新 seed。承接概念：列主序布局、向量派发条件、void 与 CUresult 两代 FFI 契约、KERNELS.md 算子索引表，以及贪心与随机采样在 core 层汇合为一个 select 入口。
