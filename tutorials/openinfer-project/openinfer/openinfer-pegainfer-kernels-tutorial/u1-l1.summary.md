PegaInfer 是纯 Rust+CUDA 的 LLM 推理引擎，pegainfer-kernels 是其跨语言的「算子地基」。按 KERNELS.md 的 Scope 段，本 crate 拥有五类资产：CUDA/Triton 构建产物（AOT 提前编译）、FFI 声明、kernel ABI 张量助手、paged-KV 布局元数据、Rust 算子包装层；KvPool、PagePool、SamplingParams 等运行时策略对象被明确排除——只管「怎么算」，不管「何时算、给谁算」。核心机制是 cargo feature 门控：每条模型线一个 feature、default 为空，qwen35 是唯一需要构建期 Python+Triton 的 feature，glm52/kimi-k2 共用 moe 底座而 k3 走 NVLink 例外，由此实现默认构建零 Python。分层上 kernels 管可复用算子、pegainfer-core 管调度与池化、模型 crate 组装各线 DAG，依赖方向自上而下指向 kernels；调用链为模型 crate→ops wrapper→FFI→CUDA 入口。
