本讲承接 nvcc 主干，剖析 pegainfer-kernels 构建管线的四条构建期代码生成通道：Triton AOT（qwen35，唯一强制构建期 Python）、TileLang AOT（gemma4/k3 的 TileLangFamily 家族表）、glm52 的 checked-in cubin 嵌入、vendored CUDA 头（DeepGEMM/FlashMLA）的 AOT 实例化。关键术语：TritonKernelSpec（七字段 kernel 编译处方）、生成器与 build.rs 间的文本协议（FUNC_NAME/C_PATH 与 KEY=VALUE manifest）、TileLang 三层梯队（generate/pregen/stub）及 checked_launchers、checked_manifest_fields 防错断言、cubin 转十六进制 C 数组头嵌入并由 cuModuleLoadData 内存加载。核心结论：PegaInfer 默认零 Python、零运行时 JIT，所有 AOT 环境变量遵循「显式设置即 fail-fast、全量声明 rerun-if-env-changed」的纪律。
