本讲是 pegainfer-kernels 的目录地图：根目录为「三文件 + 七目录」——Cargo.toml（feature 总开关）、build.rs（构建管线）、KERNELS.md（算子索引），加上 src、csrc、tools、cubin、third_party、examples、tests。核心结论：算子调用链是 ops 包装层→ffi 声明层→csrc 实现层，三层按模型线同名对齐；feature 与 csrc 目录是多对多映射——moe 底座同时对应 marlin 与 deepep 两组目录，glm52、kimi-k2 经 moe 传递拉起；Qwen3 复用常驻面、无专属 feature，lora 与 dflash2 家族亦常驻，marlin_face 挂 any(gemma4, kimi-k2)。lib.rs 含 7 个常驻模块与门控的 triton_cubin。tools 存构建期生成器、cubin 存预编译 GPU 二进制、third_party vendored 了 DeepEP 等五个上游项目，共同支撑「默认零 Python、按需 AOT」的构建哲学。tests 按模型线前缀分组、按 smoke/parity/trap/gate 等后缀分型，examples 与个别测试经 required-features 与 feature 绑定。引入的关键术语：cargo feature、AOT、cubin、vendored 源码、集成测试、文件名暗号（hd256/hd512 表示 head_dim 特化、sm100 表示目标架构、ep 数表示 EP 宽度）。
