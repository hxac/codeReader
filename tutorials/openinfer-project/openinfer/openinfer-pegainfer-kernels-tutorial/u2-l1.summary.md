本讲精读 pegainfer-kernels 的 tensor.rs：在 cudarc 之上搭起运行时地基。核心结论有三。一、DeviceContext 持 CUDA 上下文、唯一计算流与设备号，初始化五步（绑设备→建上下文→关事件追踪→建流→初始化 cuBLAS）锁定单流纪律，关事件追踪是为不破坏 CUDA Graph 捕获。二、张量层两代并存：非类型化 DeviceVec、DeviceMatrix、HiddenStates（维度是运行时字段）与常量泛型 GpuTensor、GpuWeight（u2-l2 展开）；HiddenStates 关键约定为 token i 连续存于偏移 i×D，同段内存即 cuBLAS 视角的 [hidden_dim, seq_len] 列主序矩阵，零转置直通 GEMM，checked_extent 保证逻辑尺寸不超背衬缓冲以维持指针稳定。三、StreamOverrideGuard 以 thread-local RAII 切流，Drop 恢复 previous 支持嵌套，是 Green Context SM 分区与并发 prefill 的前提；active_cu_stream 覆盖优先、回退默认流；stream_spin_wait 自旋 5ms 后阻塞兜底。
