本讲围绕 pegainfer-sample 解码循环中 token id 的 D2H 回读剖析 #704 事故：对 pageable（可换页）内存的 D2H 带同步拷贝语义，等待时长继承拷贝通道上所有前车的延迟，与 KV 恢复 bulk 洪流相撞时亚毫秒回读被拖成 23.6ms，冻结全部活跃流的 token 交付；修复是用 alloc_pinned 给 SampleScratch 分配 pinned（页锁定）落地槽双槽轮转，D2H 异步入队即返回，读取只阻塞在拷贝自身事件。关键术语：DMA、同步/异步拷贝语义、write-combined 页（CPU 读不经缓存，禁扩成热点读取结构，初始未定义、仅 D2H 落地后可读）、stream_spin_wait（pegainfer-kernels，自旋轮询至多 5ms、超时退回阻塞同步，把调度器唤醒移出步骤循环）、传递覆盖（同流按序执行，等回读完成即蕴含更早入队的 argmax 与 H2D 完成，等价旧版全流同步）、三档等待粒度（流级自旋、单拷贝事件、按需路径全设备同步）；另涉 kv-offload 恢复后端选择与 restore_commit 回归锚点。
