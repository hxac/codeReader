本讲围绕 `pegainfer-sample` 的 `mix_seed` 与 seeded 行单行调用，讲透采样确定性。`mix_seed` 是 6 行 SplitMix64：黄金伽马 0x9E3779B97F4A7C15 预扩散 step，两轮乘法-异或移位终结器保证雪崩，把 (seed, step) 混成统计独立的 philox 种子，pub 供自驱路径模型复刻同一语义。核心结论：FlashInfer 批式采样核整批只读一个标量种子，并把 blockIdx.x 折进 philox 子序列（min_p 两趟子序列均从 0 重启可证），行的随机流随批内压缩位置漂移，故 seeded 行必须发 n_rows=1 的单行调用，token 才是 (seed, step, 分布) 的纯函数，与批组合、邻居、引擎种子无关。两级种子分工：引擎种子每步新鲜、服务无种子批式行、行间靠子序列去相关；请求种子经 mix_seed 逐步换流、与批组合完全解耦。关键术语：philox 子序列、计数器式 PRNG、雪崩、可重放契约、纯函数、两级种子。
