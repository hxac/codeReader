本讲解读 pegainfer-sample 的 SampleScratch：构造时按 max_rows 与 vocab 上限一次分配、长期持有的解码采样缓冲，因 CUDA 图烘焙地址而要求指针稳定，每步只写不配。贪心链为行号表 row_indices、两阶段 split argmax 的 partials（定长公式 R×⌈V/4096⌉，随行数线性、随词表阶梯增长）、argmax_out 与 pinned 交替落地区；identity_rows 恒等表让全贪心分阶段路径复用同一 indexed argmax 核；非贪心行住进内嵌 BatchSamplingScratch（显存大头是 probs）。核心结论：vocab 是 arena 物理宽度、管全部形状与核校验；selection_width 是可发射宽度、只作 effectively_greedy（top_p ≤ 1/V 核坍缩判定）的路由分母——tile 垫宽列不可发射，错用 vocab 撑大分母会把本应坍缩为 argmax 的 top_p 行错推进采样器，在 bf16 并列峰上随机化（#1046）。贪心与采样缓冲不相交且顺序执行，一份 scratch 即可服务混合批。
