本讲介绍分阶段贪心采样四件套：greedy_argmax_ids（图内 indexed argmax 后用 DtoD 把结果写入下一步 embedding 的 id 缓冲，全程留设备）、greedy_stage_readback（图外把 argmax_out 异步 D2H 到双 pinned 槽之一并立即返回）、greedy_stage_resident（前两者组合入口）、greedy_collect_resident（纯主机收集，只阻塞在该次拷贝自身事件上）。核心结论：CUDA 图要求指针稳定、核参数固定、主机阻塞不入图，gemma4 因此按 2 的幂分桶捕获、SampleScratch 一次分配；恒等表 identity_rows 让同一 argmax 核兼服务 select_batch 的任意行子集与本路径的连续前缀；双槽轮转配合「先发射第 N+1 步、再收集第 N 步」构成两级流水；正确性全靠同一基流严格按序，各发射入口以 has_stream_override 拒绝跨流，封堵回读先于 argmax 完成的竞态。
