本讲讲解 pegainfer-sample 中 logprob 通道的主机端参考实现 token_logprob_from_row：输入一行未分片的全词表原始 logits 与被选 token 下标，返回契约类型 TokenLogprob（logprob、rank、top_logprobs），空行或越界返回 None。核心结论：logprob 等于被选 logit 减去 LSE（log-sum-exp），LSE 须先做 max 平移防溢出；约 16 万宽词表的指数和必须用 f64 累加，f32 累加的最坏误差会大到吃掉 GPU 对照测试的 5e-5 容差。rank 按 vLLM 约定统计原始 logit 不小于被选值的个数（含并列、含自己），且必须在减 LSE 之前用原始 logit 比较，以防 f32 舍入把「严格小于」塌缩成假并列；top-k 以「快速跳过＋partition_point 二分定位＋插入截断」维护，最坏 O(V·k)，并列按 token id 升序是被测试钉死的稳定契约。泛型约束 Copy＋Into＜f32＞让 Qwen 喂 f32、Kimi 喂 bf16 共用同一入口，免去 16 万元素加宽拷贝。本函数是下一讲设备端批式孪生 token_logprobs_batch 的正确性锚点。
