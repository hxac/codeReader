`pegainfer-sample` 是全部模型 crate 共享的采样策略层，承担两个模型无关职责：`select_batch`（logits arena 进、每行一个 token id 出，无逐行逃生舱）与 `token_logprobs_batch`（批式设备端 logprob 提取，配主机参考实现 `token_logprob_from_row`）。分层单向：`pegainfer-kernels` 拥有 .cu/FFI 与批式原语，本 crate 拥有策略（贪心/非贪心路由谓词 `effectively_greedy`、种子混合 `mix_seed`、logprob 数学）与可复用 `SampleScratch`，上层是 qwen3、qwen35、kimi-k2、glm52、gemma4 五个模型 crate。关键概念：logits arena、三路分发（贪心 argmax／无种子批式 FlashInfer／带种子单行可重放）、四条 `pub use` 再导出（`SamplingParams`、`BatchSamplingRow`、`BatchSamplingScratch`、`gpu_sample_batch_into`）——后门开在策略层门口，供自驱贪心路径的 Kimi-K2 使用；Kimi-K2 因分片词表仅豁免贪心路由，非贪心与 logprob 仍走本 crate。另注意模块文档中 `pegainfer-engine` 为整合前旧称，实际契约在 `pegainfer-frontend`。
