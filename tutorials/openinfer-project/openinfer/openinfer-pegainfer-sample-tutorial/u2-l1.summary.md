本讲剖析 pegainfer-sample 的采样路由决策，模块涉及前端契约 SamplingParams（temperature/top_k/top_p/min_p/seed，由本 crate 再导出，默认参数即贪心）、lib.rs 中的 effectively_greedy 谓词与 select_batch 路由点，以及两个 GPU 回归测试。核心结论是两级判定：契约层 is_greedy 只认显式贪心（temperature < 1e-5 或 top_k == 1，不知词表宽度）；策略层 effectively_greedy 追加核坍缩判据——softmax 最大概率恒 ≥ 1/V，故 0 < top_p ≤ 1/宽度 时核只剩 argmax 一个 token，须改道 argmax：既省一次 softmax，又因 argmax 按最低下标破 bf16 并列最大值而确定（拒绝采样器遇并列会随引擎种子随机挑）。路由宽度取 scratch.selection_width（可发射词表）而非 tile 对齐填充后的 arena 物理宽；谓词保守：零宽词表与 top_p 为 0/NaN/inf 一律不认领。关键术语：is_greedy、effectively_greedy、核坍缩、selection_width、bf16 并列与破并列，供后续 SampleScratch 布局与三路分发讲义承接。
