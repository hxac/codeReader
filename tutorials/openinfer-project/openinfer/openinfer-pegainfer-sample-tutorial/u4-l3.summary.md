本讲义是 pegainfer-sample 单元四的收束篇，回答采样与 logprob 机制「凭什么可信、有多快」。覆盖三个测试模块：select_batch 的 GPU 集成测试、gpu_logprobs 的 A/B 互证测试、criterion 微基准与延迟探针。核心结论：合成 arena 测试法用 make_arena、peak_row、noise_row 三个工具自造 logits（含单峰行与带并列的噪声行），不加载模型权重即可测策略层，是否构造 DeviceContext 即 CPU/GPU 测试分界；双实现互证以主机参考 token_logprob_from_row 为锚点对照设备核 token_logprobs_batch，实行分级相等性——rank 与 top-k id 序列严格相等，logprob 容差 5e-5，批组合无关性按位断言；回归测试即文档，注释讲历史、断言冻结局，三个案例（per-step philox 迁移、tile 垫宽、min_p 邻居扰动）均跨 64 个种子断言并配控制段作负对照；基准分 greedy/sampling/mixed 三档回答相对成本，#[ignore] 探针只打印绝对微秒数。关键术语：模型无关测试、双实现互证、分级相等性、控制段。
