本讲确立 PegaInfer 的定位：纯 Rust + CUDA、无 PyTorch 与推理框架的 LLM 推理引擎，提供 OpenAI 兼容 /v1/completions 接口，默认构建不含 Python；主链路为 HTTP 请求 → vLLM 前端 → EngineHandle → 各模型调度/执行器 → TokenEvent。dsv2-lite 在模型矩阵中的架构标签是 MoE + 专家并行（EP）、双卡 EP2，其 feature 开关 deepseek-v2-lite 由 server 一路接力传至 kernels，未开启时相关代码不进二进制。本讲引入的承接术语包括：prefill/decode 两阶段、token、KV cache、MoE top-k 路由、EP 与 TP 之别、CUDA/cuBLAS/FlashInfer/Triton、Cargo workspace 与编译期 feature。源码地图锁定 model_line.rs（ModelLine 派发接缝，probe 三重门校验 model_type、64 路由专家、hidden_size）与 ep.rs（每卡恰 32 专家、固定 0/1 两卡、NCCL 后端）等关键文件，并说明 pegainfer-core/kernels 供共享 GPU 算子与构建体系、pegainfer-kv-cache 抽出分页 KV 原语。下一讲 u1-l2 将动手编译该特性开关。
