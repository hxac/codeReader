本讲精读 pegainfer-core 最小的地基文件 page_pool.rs（195 行），回答 u2-l4 的遗留问题：宿主侧由谁记录页的所有权。三个角色：PageId 是不透明页号，转整数仅限 crate 内部；PagePool 是锁保护 free-list 的固定容量分配器，类型公开而方法全为 pub(crate)，页的进出只发生在 core 内部；OwnedPagePermit 是 RAII 租约，Drop 是唯一归还入口，提前返回与 panic 都会自动还页。核心结论：try_acquire_many 全有或全无，零页申请永不失败；absorb 断言同池并搬空旧租约；try_grow 失败时租约不变；rev() 构造配合 Drop 逆序归还，页升序发放、升序复用，是"构造性确定性"纪律的单卡样本。消费方 kv_pool 构造期用永久 padding_permit 取走 0 号页服务 CUDA Graph padding 槽，两段式准入失败靠 Drop 回滚。三个纯 CPU 单测锁住恢复、拒绝、grow 契约；下一讲 u3-l2 精读 kv_pool.rs。
