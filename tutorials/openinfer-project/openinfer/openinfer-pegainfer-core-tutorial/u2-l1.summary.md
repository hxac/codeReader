pegainfer-core 的 tensor.rs 全文件仅一行 `pub use pegainfer_kernels::tensor::*`，确立「core 拥有 API 门面、kernels 拥有实现」的分层边界：CUDA/cudarc 的纠缠全部下沉到 kernels 一个 crate，模型 crate 只依赖 core。由 core 内 19 处 `crate::tensor::` 反向引用可枚举 tensor 模块的公开面：DeviceContext、DeviceVec、DeviceMatrix、HiddenStates 及 active_cu_stream/has_stream_override；core 从不按名使用通用 Tensor，其字段表等 kernels 侧定义沙箱不可读、标注待确认。DeviceContext 有两个公开面：ctx.stream 负责流上分配 alloc_zeros 与 D2H 读回 clone_dtoh，ctx.ctx 负责 pinned 暂存 alloc_pinned 与事件 new_event；配合 CudaSlice 的 RAII 设备所有权、pinned 双缓冲异步 H2D 与流一致性纪律（分配流须与 stager 流相同），串成「宿主暂存→H2D→流上分配→D2H 读回」的完整往返链。关键术语：门面再出口、H2D/D2H、stream、pinned 内存、bf16、RAII。
