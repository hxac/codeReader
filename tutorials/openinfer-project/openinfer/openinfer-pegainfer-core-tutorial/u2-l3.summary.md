本讲总览 ops.rs：core 继 tensor、ffi 之后的第三张、也是唯一逐项点名的结构化门面——再出口 kernels 的 69 项算子，并入自研 attention、paged_plan 子模块的 6 个入口与 10 个 traced 包装器，共 85 个名字构成模型 crate 的稳定算子路径。核心机制是 cfg 换出口：kernel-call-trace feature 开启时，10 个热点符号（如 gemm_into、rms_norm_batch_into）改由 traced 提供同名同签名包装，运行期再由 is_enabled 守卫决定是否记录，随后委托 kernels，调用方代码零改动。关键术语：KernelCall 调用规格、TensorSpec 与 AxisTag 命名轴（词汇源自 kernels::tensor，单一事实源）、线程局部优先、全局互斥兜底的双通道记录、collect_result。算子命名后缀（_into、_batch、_rows、graphsafe、融合前缀）及归一化/激活类变体占比最高，映照前向以减少访存为核心的形态。attention 与 paged_plan 是 core 在再出口之外的自研实现，留待 u2-l4 精读。
