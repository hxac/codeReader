本讲义覆盖 pegainfer-core 的三个纯出口小模块，均只在装配期执行一次、不在解码热路径、遵循 fail-fast 纪律。rope.rs（RopeTableSpec、precompute_rope）在宿主侧按 theta^(-2i/F) 预生成 half-split 布局的 RoPE cos/sin 表，一次 H2D 上传后常驻显存，每步前向由旋转 kernel 只读查询旋转 Q/K。decodable_vocab.rs（decodable_vocab_width、aligned_logits_rows）不做 id→文本解码，而是镜像 frontend 分词器 schema 合并求「可解码词表宽度」，并把它变成输出投影 GEMM 行数与 logits 主维（128 对齐、词表封顶），decode 期的前缀 mask 归消费者负责。eos.rs 的 eos_token_ids 按三级回退从检查点解析 EOS 集合，保序去重保证确定性。三者串成链路：位置编码表→前向采样出 token id→词表宽度约束与命中 EOS 即 finish。
