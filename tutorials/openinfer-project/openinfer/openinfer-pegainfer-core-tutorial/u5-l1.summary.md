本讲以 pegainfer-core 的 page_pool.rs、kv_pool.rs、cuda_graph.rs 与 gemma4 的 kv.rs/serve.rs 为样本讲并发正确性：①两段式准入——try_reserve 跨池全量预约、任一失败即 drop 回滚，再 commit_reservation 统一过户，防御多池「占 A 等 B」的部分占用死锁；②RAII 归还——页所有权只存在于 OwnedPagePermit，Drop 保证零泄漏、free list 守恒无幽灵页；③padding 页在池构造期一次性预留、页号恒定、内容无害，是 CUDA Graph 回放「内容动地址不动」确定性的先决条件；④这些单卡纪律同构放大为 EP free-running 四不变量：不停止等待、固定集体链、launch 计数即时钟、padding 即协议面——可撤销决策全在 launch 前，launch 后零协商。关键术语：KvReservation、mispair、ensure_capacity 的分相位分工。
