本讲精读 core 的 attention 与 paged_plan 模块：分页注意力的「调度面」。核心结论：KV 数据整批共享一份，请求差异全部编码进 i32 索引数组——数据不动、索引动，由此换来零拷贝调度与 CUDA Graph 兼容。关键术语：三个薄包装注意力入口（预填充、批解码、split-KV 解码，core 只做一次几何转换）；PrefillPagedPlan 的预分配加原地重填、指针不变的图稳定用法；SplitKvCsr 纯 CPU 构造的 CSR 索引；KvDesc 单请求页表描述，desc 信任当前长度，desc_for_len 校验页数后按目标长度预演。契约：core 描述状态、kernels 消费状态，页号只在签发它的池内有效。
