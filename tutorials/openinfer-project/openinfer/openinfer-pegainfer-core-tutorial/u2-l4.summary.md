本讲覆盖 ops/attention.rs 与 ops/paged_plan.rs，即分页注意力的调度面。三个入口分别服务整段 prefill（norm+RoPE+写KV+注意力一体）、batch decode 与 split-KV decode（长 KV 切 chunk 提并行度、部分结果在线归并），封装仅把 KvLayout 译成 PagedKvLayout 后转发 kernels。计划侧是两个翻译器：build_split_kv_csr 纯宿主侧把各请求 kv_len 展开成 SplitKvCsr（CSR/indptr 结构，槽位补齐、填充槽 mask=0）；PrefillPagedPlan 是 kernels 类型的 newtype+Deref，支持批量构造与指针不变的原地重填（CUDA Graph 图稳定复用）。核心契约「计划与 KV 数据分离」：core 用 KvDesc（页表+last_page_len 的最小充分信息）描述状态，desc() 照实汇报、desc_for_len() 强校验页数，kernels 只消费扁平 i32 页表；合批只改描述层，KV 数据不动。
