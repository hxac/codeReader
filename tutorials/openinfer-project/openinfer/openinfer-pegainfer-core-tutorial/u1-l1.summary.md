PegaInfer 是纯 Rust + CUDA、无 PyTorch 的多模型 LLM 推理引擎；pegainfer-core 是供各模型 crate 复用的共享运行时层，上承模型 crate、下接 pegainfer-kernels。其 lib.rs 仅 15 行，13 个 pub mod 可分六组：tensor/ffi 门面（各一行转发 kernels）、ops 算子封装与再出口、page_pool/kv_pool 推理状态、cuda_graph 执行机制、装配出口（weight_loader/rope/decodable_vocab/eos）、宿主服务（cpu_topology/logging/tracing）。两条硬边界：HTTP 协议归 frontend（core 仅一处追踪开关联动）；CUDA 内核编译归 kernels 的 build.rs（core 无 build.rs）。本讲引入术语：prefill/decode、KV cache 与 KV 池、门面与再出口、CUDA Graph、safetensors、RAII。遗留待确认：core 自建的 kv_pool 与 pegainfer-kv-cache crate 的分工，留待 u3 处理。
