本讲是 verilog-ethernet 学习手册的开篇，建立项目全局地图。verilog-ethernet 是 Alex Forencich 维护的开源以太网 Verilog IP 库，用可综合 RTL 覆盖一块 FPGA 网卡所需的大部分硬件逻辑：MAC、PHY、ARP/IPv4/UDP 协议栈、PTP 时间同步组件，并附带完整的 cocotb 仿真平台。核心结论有三：其一，支持三档速率（1G/10G/25G）与两档数据通路宽度（8 位/64 位），速率与位宽绑定，吞吐量等于位宽乘时钟频率；其二，通过四类顶层模块快速定位成品——`eth_mac_*`（MAC）、`eth_phy_10g`（PCS/PMA PHY）、`ip_complete[_64]`（IP 栈）、`udp_complete[_64]`（UDP 栈），另有 `eth_mac_phy_10g` 合并 MAC 与 PHY；其三，命名后缀承载语义：`_64` 标识 64 位通路、`_fifo` 表示带跨时钟域缓冲、`_gmii`/`_rgmii`/`_xgmii` 表示对外物理接口，64 位通路特有信号 `tkeep` 用于标记末字有效字节。本仓库已被继任者 taxi 取代、停止维护，但二者架构与接口高度相似，且本库资料更丰富，是理解整套设计的最佳起点，新项目则应优先选用 taxi。所有顶层模块均可在 `rtl/` 目录找到对应 `.v` 文件，README 的 Source Files 清单是最权威索引。本讲引入的关键术语将以太网、MAC、PHY、AXI-Stream、PTP、数据通路宽度及命名约定，供后续讲义承接。
