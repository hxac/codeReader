本讲建立 verilog-ethernet 仓库的全局目录地图。六大顶层目录各司其职：`rtl/`（约 98 个 IP 核心源码，按 MAC、PHY、协议栈、PTP 四类组织）是被依赖的中心，`tb/` 和 `example/` 都引用它；`lib/axis/` 是第三方 verilog-axis 的内嵌（vendoring）副本，非 git 子模块，为所有 `_fifo` 后缀模块提供 `axis_fifo`/`axis_async_fifo` 等 AXI-Stream 通用构件；`tb/` 用 cocotb + Icarus Verilog 做仿真；`example/` 为每块开发板提供一份 UDP 回显参考设计（默认 IP `192.168.1.128`、端口 `1234`），核心逻辑集中在 `rtl/fpga_core.v`，通过实例化 `udp_complete` 组装协议栈；`syn/`（按 Quartus/Quartus Pro/Vivado 分 SDC/TCL）只服务综合、不参与仿真；`scripts/` 提供板级验收脚本。`README.md` 的 Source Files 段是最权威的「文件→功能」索引，`tox.ini` 用 pytest 把 `tb/` 和 `example/` 统一纳入回归测试。关键术语：RTL、testbench、综合约束、AXI-Stream、vendoring、fpga_core.v、udp_complete。
