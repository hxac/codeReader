本讲讲解 PTP 时间戳如何借助 AXI-Stream 的 tuser 旁带搭车到以太网帧上，覆盖三个最小模块。ptp_ts_extract：RX 侧将 tuser 右移 TS_OFFSET（默认 1，跳过坏帧位）取出时间戳，靠 frame_reg 保证每帧仅在首拍输出一次有效。ptp_tag_insert：TX 侧把 tag 写入 tuser 指定位段，靠 tag_valid_reg 与 s_axis_tready 耦合，实现「一帧一 tag、无 tag 则阻塞数据流」。eth_mac_1g 是布线层，把外部 ptp_clock 的 output_ts 接到 axis_gmii_rx/tx。核心结论：RX 时间戳在 SFD 锁存、走带内 tuser 高位随帧流出；TX 时间戳因发送时刻晚于 AXI 输入结束，只能经旁带总线 tx_axis_ptp_ts 配合 tag 异步回送，由应用按 tag 关联回帧。关键概念包括：tuser 位布局（bit0 为坏帧位，高位为时间戳或 tag，位宽随 PTP_TS_ENABLE 自动膨胀）、ToD 与相对两种时间戳格式、tag 关联机制，以及三个参数 PTP_TS_FMT_TOD（96/64 位）、TX_PTP_TS_CTRL_IN_TUSER（逐帧请求 vs 每帧都打）、TX_PTP_TAG_ENABLE。开流控时布线层强制将 tuser 控制位置 1；PTP_TS_ENABLE=0 时整个旁路零面积，10G MAC 同名同义。
