本讲以仓库板级参考设计 `example/Arty` 为例，把 PHY、MAC、成帧、UDP 协议栈四层积木拼成一个可上板的 UDP 回显系统。端到端数据通路为：PHY MII → `eth_mac_mii_fifo`（剥前导/FCS、跨时钟域）→ `eth_axis_rx/tx`（裸 AXI 帧与结构化以太网头之间的翻译器，二者「语言」不同，集成时最易遗漏）→ `udp_complete`（拆 IP/UDP 头）→ 应用。应用逻辑核心是三件事：端口匹配（组合 `match_cond` 判定目的端口=1234）、整帧锁存（寄存器 `match_cond_reg` 帧首采样并整帧保持，落实「整帧不拆」铁律）、载荷缓冲（一个 `axis_fifo` 解耦「先收后发」的收发时序）。回显语义即字段对调：目的 IP/端口取收到包的源 IP/端口，源 IP 用 `local_ip`，校验和填 0 交由 `udp_checksum_gen` 重算。网络身份 `local_mac/local_ip/gateway_ip/subnet_mask` 作为常量注入 `udp_complete` 配置端口；本设计把原始 IP 通路「读空+置无效」钉死，只跑 UDP。改监听端口只需动 `match_cond` 一处，改本机 IP 只需动 `local_ip` 一处。
