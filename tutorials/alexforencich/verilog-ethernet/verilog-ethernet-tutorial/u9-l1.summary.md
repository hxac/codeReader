本讲覆盖 XGMII 与 64 位 AXI-Stream 互转的四个模块（rx_64/tx_64 及 32 位变体 rx_32/tx_32）。XGMII 以「数据总线加逐 lane 控制位」结构，用 IDLE/START/TERM/ERROR 四个控制字符在一拍内完成帧定界，帧被 START 与 TERM 夹住。64 位通路允许帧从 lane 0 或 lane 4 起始，以配合 DIC 缺陷填充。接收侧靠两拍延时流水线加移位公式 tkeep=0xFF>>(4-t)（或 >>(12-t)）剥离末尾 4 字节 FCS，并用「8 魔数残留法」一次校验 CRC，前导码/SFD/FCS 均不进入 AXI 输出。发送侧为其逆运算：单拍打包前导码与 SFD、8 个并行 CRC 引擎处理变宽末拍并追加 ~crc_state 作 FCS、用 deficit_idle_count 实现 DIC。32 位变体因 lane 减半，仅支持 lane 0 起始、前导码需两拍、状态机多出 PREAMBLE 与 FCS_3 态、CRC 引擎与魔数各减为 4。
