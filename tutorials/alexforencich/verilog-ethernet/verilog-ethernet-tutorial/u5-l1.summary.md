本讲讲解 verilog-ethernet 中带 `_fifo` 后缀的 MAC 变体（如 `eth_mac_1g_fifo`）。它在 `eth_mac_1g` 两侧各挂一个 `axis_async_fifo_adapter`（异步 FIFO + 位宽适配），把应用侧解耦到新增的 `logic_clk`/`logic_rst` 时钟域，核心增值为：跨时钟域（CDC）、位宽适配（宽位 logic 接口 ↔ 8 位 GMII）、突发缓冲，并给原本线速不可反压的 RX 方向补上 `rx_axis_tready`（反压不等于停线，PHY 不可停）。关键构件 `axis_async_fifo` 用 Gray 码指针 + 2 级 `SHREG_EXTRACT=NO` 同步器实现双时钟域跨越；MAC 状态脉冲（如 `tx_error_underflow`）另用「翻转+同步+异或」闭环同步器跨域；慢变多位信号（如 `speed`）仅需普通 2 级寄存器同步。`FRAME_FIFO` 模式靠「写指针大胆前进、提交指针谨慎跟进」保证整帧不可拆，坏帧/超长帧可回滚丢弃，帧尾产出 `overflow`/`bad_frame`/`good_frame` 统计；TX/RX 的 `DROP_WHEN_FULL` 默认取值相反，源于生产者可反压而 PHY 不可停。代价是 PTP/PAUSE/PFC 旁带被截断（`USER_WIDTH` 降为 1），需 PTP 时间戳时应直接用 `eth_mac_1g`。同步版 `axis_fifo`（单时钟、二进制指针）与异步版（双时钟、Gray 指针）的差异决定了前者只适合同域整形、后者才是 MAC FIFO 的 CDC 选择。
