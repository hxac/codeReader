本讲讲解 UDP 层三个模块：`udp_ip_rx`（接收翻译器）、`udp_ip_tx`（发送翻译器）、`udp`（顶层布线层）。UDP 报文即 IP 载荷，前 8 字节为头（源端口、目的端口、长度、校验和各 2 字节），其后是应用载荷；UDP 长度含头，IP 总长度 = UDP 长度 + 20。收发子模块均用 `hdr_ptr`+`case` 在大端序下逐字节拆装头部，以 `word_count = udp_length - 8` 控制载荷字节数并吞掉以太网 padding，二者互为逆运算，且 `udp_ip_tx` 自动算出 IP 长度。顶层 `udp` 将其拼成收发双通路：RX 直连 `udp_ip_rx`，TX 按参数可选插 `udp_checksum_gen` 或直连，并将 IP 协议号硬编码为 17（0x11）。三者沿用全库统一的「并行头字段 + AXI-Stream 载荷 + 握手」接口风格。本讲只搬运校验和字段、不计算，真正的反码校验和计算留待 `udp_checksum_gen` 专题。
