`udp_checksum_gen`（8 位）与 `udp_checksum_gen_64`（64 位）在 UDP 发送路径上处于 `udp_ip_tx` 之前，负责一次性补齐四样东西：UDP 长度（由载荷字节计数得 8+载荷）、UDP 校验和、IP 总长（UDP 长度+20）、IP 协议号（硬编码 0x11），使应用层只需给端口、IP 和载荷。UDP 校验和采用 16 位反码求和，覆盖范围是「IP 伪头部 + UDP 头 + 载荷」：伪头部含源/目的 IP、全 0、协议 0x11、UDP 长度，其中 UDP 长度在伪头部与 UDP 头里各出现一次（求和中计两次），计算时校验和字段本身填 0。模块用「分期预扣」技巧——IDLE 时把累加器预置为 0x0011+0x0010，载荷每字节 +2，使长度贡献在流式处理中自然累计，无需帧末回头补加；帧末用 32 位累加器折叠取反定值，8 位版单状态收尾，64 位版因宽加法流水化需两状态排空。核心是双 FIFO：载荷 FIFO（深 2048）缓存流式载荷，头部 FIFO（深 8）缓存算完的头部，二者配对输出，化解「校验和须看完整帧才能定值」与「头部须与载荷同行送出」的矛盾。`UDP_CHECKSUM_GEN_ENABLE`（默认开）支持可旁路：关闭时 `udp` 顶层用 generate else 把模块退化为纯连线、零面积，由应用自供校验和。该反码求和与 IPv4 头校验和同源，但不依赖 FCS 的 CRC-32。
