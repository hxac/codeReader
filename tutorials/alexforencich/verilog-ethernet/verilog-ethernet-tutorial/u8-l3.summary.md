本讲（u8-l3）讲解成品级顶层 UDP 协议栈 `udp_complete`（千兆 8 位）及其 64 位变体 `udp_complete_64`（10G/25G）。它是一个纯布线层模块，把三块积木拼成完整 UDP 栈：`ip_complete`（IPv4 栈，含 ARP）、`udp`（UDP 收发核心）、`ip_arb_mux`（IP 帧层仲裁复用器）。

核心结论有三：其一，接收方向由 `ip_complete` 拆出 IP 帧后，按 IP 协议号 `ip_protocol == 0x11` 分流，UDP 帧送入 `udp` 模块从 `m_udp_*` 输出，其余从 `m_ip_*` 直通，选择在帧首锁存、整帧不拆；其二，发送方向上 `s_udp_*`（经 `udp` 转成的 IP 帧）与外部 `s_ip_*`（原始 IP 帧）同处 IP 帧层，须经 `ip_arb_mux` 合流（默认固定优先级、UDP 路 LSB 高优先级）再交给 `ip_complete` 套以太网头发出——这正是它与 `ip_complete` 内部 `eth_arb_mux`（以太网帧层）分层的原因。其三，校验和仅在顶层参数透传，真正的计算由 `udp` 模块内部 `generate` 选配的 `udp_checksum_gen` 完成，可由 `UDP_CHECKSUM_GEN_ENABLE` 旁路。

关键术语：三层头接口（`eth`/`ip`/`udp`）、`ip_arb_mux` 与 `eth_arb_mux` 的分层区别、UDP 协议号 `0x11`、整帧不拆的整帧选路原则。
