本讲剖析 aria2 的 Command 调度体系。Command 基类以 STATUS 状态位（INACTIVE/ACTIVE/REALTIME/ONESHOT_REALTIME）表达调度频率，以 read/write/error/hup 四个事件标志承接 EventPoll「只置位、不执行」的回调留言；statusMatch 按数值过滤，transitStatus 执行一次即降级 INACTIVE，防止忙等。核心所有权约定：execute() 返回 true 即销毁（清理都在析构），返回 false 必须已 addCommandSelf 重排。AbstractCommand::execute() 是模板方法骨架（终局检查→segment 刷新/换源→shouldProcess 分流→超时判定→executeInternal 协议钩子），三类异常出口决定去向：DlRetryEx 经 prepareForRetry 归还 segment、新建同 cuid 的 CreateRequestCommand 重试，DlAbortEx 走 tryReserved 换 URI，DownloadFailureException 整组停机。一次 HTTP 下载是 CreateRequest→Initiate(→Connect)→Request→Response→Download 四组命令接力，资源经构造参数传递，cuid 贯穿流水线。DownloadCommand 是「数据泵」，每轮读一块、经 StreamFilter 写盘、再自循环排队，靠 checkSocketRecvBuffer 升级实时状态实现零等待连续搬运；TimeBasedCommand 则是周期命令分支。
