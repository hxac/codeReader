DHTSetup::setup 是 DHT 唯一装配点，仅在首个 BT 任务初始化时执行一次：加载 dht.dat（失败则以随机节点 ID 冷启动）、绑定 UDP 端口、创建组件并互相接线、产出 6 条命令挂入 DHTRegistry，任一步失败整体回滚、静默禁用 DHT。自举（bootstrap）三步曲「解析 entry point → ping → 以自身 ID 做节点查找」由一次性命令完成，解析失败可由旧节点或种子 nodes 兜底、不致命。DHTInteractionCommand 是唯一常驻的 routine/REALTIME 命令，独占 UDP socket，按首字节是否为 'd' 分流 DHT 与 UDP tracker 报文。TokenUpdate、BucketRefresh、PeerAnnounce、AutoSave 四条周期命令分管 token 轮换、桶刷新、宣告清理与路由表保存，共用 TimeBasedCommand 骨架，默认 INACTIVE、每秒唤醒一次。dht.dat 只存本地 ID 与好节点扁平列表（56 字节头＋每节点 56 字节记录），原子写落盘，桶树加载时按分裂规则确定性重建。
