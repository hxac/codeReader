本讲承接 Metalink 解析产物，讲解 entry 如何变成多源下载任务：Metalinker::queryEntry 按 version/language/os 三条件做「消费式」过滤；资源优先级小者优（999999 最低），--metalink-location 与 --metalink-preferred-protocol 以减 999999 实现一票优先，排序前先随机洗牌以均衡同优先级镜像。装配核心是 Metalink2RequestGroup::createRequestGroup：丢弃不支持协议、--select-file 裁剪、按首条 metaurl 的 URL 分组，单文件与多文件两条路径把大小、digest、分块哈希、签名填入 DownloadContext，共享种子的组额外生成内存 torrent 任务并注入 BtDependency。Metalink/HTTP（RFC 6249）则从 Link 头取 rel=duplicate 镜像、Digest 头取整文件摘要，透明挂入进行中的下载，受 acceptMetalink 一次性闸门约束；MetalinkPostDownloadHandler 按 --follow-metalink 完成透明 Metalink 的任务派生。
