本讲下探 DHT 的线上字节层，拆解四个最小模块。其一，bencode2 编解码门面：所有 DHT 报文都是一个 bencode 字典，字符串「长度前缀 + 原始字节」保证二进制安全，Dict 键按字典序输出（a<q<r<t<v<y）使编码确定。其二，报文骨架：DHTAbstractMessage 以模板方法固定组装公共键 t（transaction id）、y（报文类型 q/r/e）、v（版本串），query 子类补 q（方法名）+a（参数），response 子类补 r；四类 RPC（ping、find_node、get_peers、announce_peer）的差异体现在 a 字典与 doReceivedAction；节点列表以紧凑格式（20 字节 ID + 6/18 字节地址）装入 nodes，peer 地址装入 values（上限 25 防 UDP 分片）；token 由 SHA-1(infohash+请求方地址+秘密) 生成防伪造宣告。其三，DHTMessageFactoryImpl 是「字典→消息对象」的唯一映射点，逐字段校验类型与长度，不合法报文归为 Unknown 丢弃；响应报文无 q 键，方法名由 tracker 条目传入。其四，transaction id 生命周期：4 字节随机生成、query 发出后登记 DHTMessageTracker、按 (tid, IP, port) 三元组配对，命中则构造响应、测 RTT 并喂回路由表健康度，超时则驱动节点判坏——RPC 会话与路由表保活合二为一，为下一讲的任务系统铺垫。
