本讲介绍 aria2 的库形态 libaria2：以 C++ 会话 API 把下载引擎直接嵌入宿主程序，与 CLI/RPC 共用同一引擎——sessionNew、run、sessionFinal 正是 CLI execute() 三段骨架的拆开。核心结论：会话生命周期（libraryInit、sessionNew、sessionFinal）三层严格配对，Session 是进程级单例，选项经 KeyVals 透传并复用同一套校验；RUN_ONCE 返回 1 表示命令队列未空、0 表示排空；keepRunning 靠自我重排的 KeepRunningCommand 占住队列，把批处理器变成常驻服务，shutdown 置停机标志令其退出；查询统一走 DownloadHandle，一接口两实现分别包装活任务与完结任务，用完须手动释放；六种下载事件经 Notifier 单例广播并适配成 C 回调，在 run 线程同步执行。关键纪律：引擎无内部线程且非线程安全，跨线程须用双队列转发；选型上，同进程 C++ 求低延迟选会话 API，跨语言或要进程隔离选 RPC。
