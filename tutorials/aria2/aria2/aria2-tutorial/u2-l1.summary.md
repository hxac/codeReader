本讲剖析 aria2 心脏 DownloadEngine::run() 的事件驱动主循环（Reactor 模式：单线程 I/O 多路复用，回调具体化为 Command 对象）。每圈三阶段：waitData 经事件轮询等 I/O；executeCommand 按状态过滤跑 commands_ 与 routineCommands_ 两条队列，任务命令平时仅执行 ACTIVE 状态，每秒一次全量刷新闸门唤醒 INACTIVE 睡眠者检查超时；afterEachIteration 消费 Ctrl-C 状态机实现两段式停机。两条队列同时排空即退出循环。核心约定：命令 execute() 返回 true 即销毁，返回 false 须已自我 requeue；超时命令抛 TIME_OUT，经 DlRetryEx 捕获后 prepareForRetry 重建 CreateRequestCommand 重试。DownloadEngineFactory 按选项装配引擎：事件后端由 --event-poll 与编译宏共同决定，AutoSave、TimedHalt 等周期命令随选项条件注册。
