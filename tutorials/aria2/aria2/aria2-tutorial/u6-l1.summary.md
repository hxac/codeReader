本讲拆解 .torrent 文件如何被解析成下载任务。bencode 只有字符串、整数、列表、字典四种类型；bencode2 提供 decode（字节流转成 ValueBase 树）与 encode 两条门面链路。infohash 定义为 info 字典重编码后的 SHA-1，Dict 基于 std::map 键天然有序，保证重编码与原文截取一致，原文另存为 metadata 供 magnet 分发。bittorrent_helper 的各 load 入口殊途同归于 processRootDictionary：校验根字典、按 20 字节切分 pieces、装配 FileEntry（含目录穿越防护与 piece 数一致性检查）、读 announce/nodes。产物分流：文件列表与分块哈希进 DownloadContext 公共字段，infohash、tracker 层级等 BT 专属信息挂入 TorrentAttribute 属性槽；magnet 仅产出含 infohash/name/announceList 的极简属性，处于元数据获取模式。AnnounceList 是解析快照之上的运行期游标机：tier 内互为备份、失败降层、成功者提至队首并归位第一层，AnnounceTier 的 event 状态机决定 announce 事件参数与 stopped/completed 发送资格。
