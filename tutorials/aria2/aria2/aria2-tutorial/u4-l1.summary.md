本讲走通 HTTP 下载的命令接力链：CreateRequestCommand 领 URI，HttpInitiateConnectionCommand 做 DNS 解析与连接池判定，ConnectCommand 确认非阻塞连接，HttpRequestCommand 完成 TLS 握手并发送请求，HttpResponseCommand 裁定状态码并定型文件名与长度，HttpDownloadCommand/DownloadCommand 作为数据泵自循环把响应体写盘。核心结论：每棒命令只推进一小步，以构造函数参数传递共享资源（Socket、Request、Segment、HttpConnection）作接力棒；cuid 全程不变，是日志追踪钥匙；连接池命中可跳过建连两棒；首响应区分定长分段与不定长流式两条路径；失败分三级出口——DlRetryEx 经 prepareForRetry 回第 0 棒重试，DlAbortEx 经 tryReserved 换 URI/镜像，DownloadFailureException 整组停机，恢复粒度从换 IP 到换 URI 递进。引入的关键术语：cuid、Request 池化、HttpConnection 会话与在途请求队列、StreamFilter 过滤链、keep-alive/pipelining，供 u4-l2 协议实现等后续讲义承接。
