本讲剖析 aria2 从命令行到 RequestGroup 集合的任务创建流水线。Context 构造函数按 torrent、metalink、input-file、URI 四级互斥分支调用 download_helper 的四个工厂函数，同一套工厂还被 RPC、libaria2 与派生任务复用，产出经 MultiUrlRequestInfo 移交引擎。UriListParser 定义 `-i` 输入文件语法：Tab 分隔的 URI 行、缩进选项行与注释，条目级覆盖仅限 initial option 白名单。createRequestGroupForUri 分三步：参数化 URI 展开、stable_partition 将流协议 URI 合并为一个多镜像任务（splitURI 按 `-s`/`-x` 复制 URI）、其余字符串交 ProtocolDetector 嗅探（scheme:// 结构判定、magnet 试解析、本地文件魔数）；`-Z` 则逐 URI 独立建任务。DownloadHandler 体系以 pre（改造当前任务）与 post（派生新任务）处理器衔接任务链，由 --follow-torrent/--follow-metalink 的 true|mem|false 控制，magnet 先下 metadata 再派生数据任务；一次性选项（如 --gid、--pause）在任务创建后即清理，避免污染后续派生任务。
