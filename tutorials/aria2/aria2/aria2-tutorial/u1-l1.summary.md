本讲是整套手册开篇，通过精读 README 特性清单、configure.ac、src/main.cc 与 FeatureConfig.cc 等文档型源码建立项目全貌。核心结论：aria2 是支持 HTTP(S)/FTP/SFTP/BitTorrent/Metalink 五类协议的命令行下载工具，核心卖点是「多源多协议并行下载」，且 HTTP 下载的数据会回哺 BT 网络。五类协议分两层：四个传输协议加一个元数据格式 Metalink（XML 镜像与校验和描述）。src/ 约九百个文件按文件名前缀划分子系统（Bt*、DHT*、Http* 等），协议差异被隔离在各协议的命令链层。功能与第三方库一一绑定：configure 探测库→定义编译宏→条件编译→--version 的 Features 行上报，故不同机器编译出的 aria2 特性集不同。本讲引入的关键术语：分段下载、DHT、RPC 控制面、编译期开关、Happy Eyeballs、命令链。版本号规则为 MAJOR.MINOR.PATCH，每月 15 日发版、5 日冻结，当前为 1.37.0。
