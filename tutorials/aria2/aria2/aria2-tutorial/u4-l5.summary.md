本讲剖析 aria2 的 FTP 与 SFTP 两条下载命令链。核心结论：FtpConnection 是 FTP 协议编解码器，负责命令拼装、应答码解析与粘包处理；FtpNegotiationCommand 是协议状态机，用 30 余个 Seq 状态驱动「USER/PASS/TYPE/PWD/CWD/SIZE/PASV/REST/RETR」完整协商，主动模式（PORT/EPRT）与被动模式（PASV/EPSV）的分歧只在数据连接由谁发起；数据泵复用 HTTP 链的 DownloadCommand，数据收满后仍需 FtpFinishDownloadCommand 等控制连接的 226 才回池。SFTP 是独立二进制协议而非「FTP over SSH」，其命令链是 FTP 链的同构压缩：握手、认证、open、fstat、seek 六步全在一条 SSH 连接内完成，断点续传用句柄 seek 替代 REST，全程遵循 libssh2 非阻塞 EAGAIN 三值约定。关键术语：控制/数据双通道、Seq 状态机、主机密钥指纹选项 ssh-host-key-md、连接池按用户名复用、SFTP 数据泵的写检查补偿。
