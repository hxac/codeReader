本讲从 kernel 视角回到 Python 模型层，讲解改造版 DynamicCache 与猴子补丁集成。改造版由官方 cache_utils.py 整文件复制加局部修改而来，每层维护 6 个缓存列表：新增 key/value_cache_pack（uint16 打包主缓存）与 key/value_cache_params（fp32 量化参数），复用原 key/value_cache 作 (b,s,h,d) 布局的 FP16 残余区。残余闭环由三个新方法构成：update_residual 沿 dim=-3 追加新 token；update_pack 四路拼接中 K 系沿 dim=-3、唯 v_params 沿 dim=-1（V 参数把序列放末维以保同组参数内存连续），传 None 时兼作主缓存读取器；clear_residual 清空残余区。量化由 kernel 完成，容器只管存与拼。集成采用“复制 modeling_llama.py 改导入＋猴子补丁替换 transformers.cache_utils 三类”两板斧，依据是 import 期快照与运行期解析之别；边界在于 get_seq_length 语义漂移，仅 flash_attention_2 且 generate 提供 cache_position 的路径安全。
