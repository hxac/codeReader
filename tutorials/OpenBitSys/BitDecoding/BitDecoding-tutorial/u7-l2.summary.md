本讲围绕性能测量展开，覆盖模型级基准、kernel 级微基准与消融基线三部分。模型级 bench_throughput 通过 config 注入注意力后端实现控制变量，把生成切成 prefill 与 decode 两段整段计时（墙钟 perf_counter 加 synchronize），换算吞吐并采样峰值显存，配合 shell 脚本批量扫描；需警惕 randn 计入计时区、decode 预热原地增长缓存等口径陷阱。kernel 级 bench_single_residual 用 cudaEvent 三段式测纯 GPU 时间，报 min/avg/max 三值并刻意保证残余路径执行；另一微基准是旧 9 参签名的 API 化石。关键术语：统计口径、warmup、empty_cache、reset_peak_memory_stats、有效比特数（num_bits+32/group_size）、消融。test_bitblas 与 test_marlin 只测打包/权重变换开销，不是完整注意力基线。核心结论：decode 注意力加速上界为 16/有效比特数（4bit 约 3.8×、2bit 约 5.3×），端到端收益会被权重读取稀释，口径不一致的数字不可比较。
