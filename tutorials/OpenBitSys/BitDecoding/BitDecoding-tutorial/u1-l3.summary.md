本讲是仓库「地图课」，梳理三个目录的分工：bit_decode/ 是极薄 Python 门面，csrc/bit_decode/ 是 pybind11 绑定加 CUDA kernel 的算法核心，evaluation/ 放改造版 HF 模型与评测脚本，语言层级为 Python→C++→CUDA。核心结论：Python 侧仅两个 API——kvcache_pack_int（prefill 量化打包）与 fwd_kvcache_int（decode 低比特注意力），按 num_bits 分流到 int2/int4 四个绑定函数。引入的关键概念：prefill/decode 双调用链（prefill 先跑 FP16 flash-attn 再打包，decode 依次启动残余、splitkv、combine 三个 kernel）；FP16 残余区攒满 residual_block_size 即量化回写主缓存并清空；Flash_fwd_params 结构体统一承载张量指针、stride 与量化配置；quant_mode、group_size、num_bits 是编译期模板参数，运行期经 if 链 dispatch 且当前仅启用 k-channel 与 group_size 128/32 组合；模型接入依赖 LlamaBitDecoding 注意力类、扩展版 DynamicCache、对 transformers.cache_utils 的猴子补丁及 LLAMA_ATTENTION_CLASSES 后端注册表。
