本讲为 BitDecoding 总览，拆解三个模块：项目定位与带宽瓶颈、README 四张图（overview/scheme 原理图与 4090/A100 kernel 性能图）、Python 包门面。核心结论：BitDecoding 是加速长上下文 LLM decode 阶段的 GPU kernel 系统，输入 2/4-bit 量化打包的 KV cache 与单 token Query，输出注意力结果，相对 Flash Attention v2 加速 3-9x（HPCA 2026）；decode 算术强度约 1 FLOP/Byte、属 memory-bound，低比特把 KV 读取字节降为 1/4（int4）或 1/8（int2）是加速主因，上下文越长、位宽越低收益越大。方案三要素：uint16 量化打包、FP16 残余区（最新 token 保精度、攒满一块再量化）、split-KV 切分并行后 LSE 合并。Python 侧仅暴露 kvcache_pack_int（打包）与 fwd_kvcache_int（每步解码）两个 API 及三个缓存类。引入的关键术语：2/4-bit、k-channel/k-tensor 量化模式、group_size、residual、LOP3、split-KV，均由后续单元逐一深入。
