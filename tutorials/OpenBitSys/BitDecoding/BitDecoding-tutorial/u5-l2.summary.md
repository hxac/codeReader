本讲精读 decode 阶段的核心 kernel `compute_attn_1rowblock_splitkv`，它处理已量化打包的主 KV cache。`BlockInfo` 把 decode 语义换算为 `seqlen_k_cache`（主缓存 token 数，拷贝谓词与掩码边界）和 `actual_seqlen_k`（含 FP16 残余的总长，块数上界），两者不可混用。每个 `n_split_idx` 负责块区间 [n_block_min, n_block_max)，从尾块倒序遍历：首段带掩码、其余满块直通；空 split 早退写 0/-inf 交 combine 忽略。主循环五阶段由 cp.async 软件流水衔接：K/V 打包数据 gmem→smem→寄存器（tSrK_pack/tOrVt_pack）→ LOP3 反量化 → Q·Kᵀ 累积 acc_s → 在线 softmax（softmax_rescale_o 维护 row_max/row_sum/acc_o，在 P·V 之前给 acc_o 乘 rescale 因子，基于 exp2）→ P 经 sAcc 中转 → P·V 累积 acc_o；反量化与 MMA 在 gemm_Kchannel/gemm_Vtensor 内融合，不回写 smem。epilogue 用 normalize_softmax_lse 归一化并产出 LSE，Split 模式写 gOaccum/gLSEaccum，由 combine kernel 按 e^(lse_i−L) 权重合并。FP16 残余区留给 residual kernel，LOP3 位操作细节在下一讲展开。
