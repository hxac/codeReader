本讲把残余机制与 split-KV 主循环拼成 decode 闭环：FP16 残余→注意力→原位再量化→回写主缓存。模块一讲 residual kernel：处理 FP16 残余区与本步新 token，grid 为 (num_m_block, b, h)、无 split 维，独占最后一个累积槽位 num_splits-1（u3-l3「+1 槽位」协议的兑现）；残余区恰占一块 tile（kBlockN_residual = residual_block_size，4-bit 为 128、2-bit 为 256），以 new_lens 掩掉补零对齐区，全程 FP16 MMA 保最新 token 精度。模块二讲原位（piggyback）再量化：当 new_lens 攒满 residual_block_size 时，kernel 把刚喂过 MMA 的 K/V 寄存器 fragment 复用第四单元原语（qpack_Kchannel_Vtensor、pack_Kchannel_store、pack_Vtensor_store）量化落盘为 *_new 四件套，零额外 kernel 启动、零额外显存读。模块三讲 Python 侧消费：fwd_kvcache_int 返回 5 元组，cur_residual_len 攒满时 update_pack 把四件套拼进主缓存（K 系沿 dim=-3、v_params 沿 dim=-1）并 clear_residual 清空残余区；*_new 缓冲在 prefill 末尾一次分配、跨步复用。全部槽位最终由 combine kernel 按 LSE 合并（u5-l5 承接）。
