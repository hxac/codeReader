本讲剖析改造版 DynamicCache 的双区缓存与残余（residual）机制。核心结论：量化误差会被近端 token 的高注意力权重放大，且新 token 若单独量化，组内样本不足、scale 不稳定，故最近若干 token 必须保留 FP16，攒满一块再统一量化；残余区复用原 key_cache/value_cache 字段，与四组低比特主缓存（pack/params）并存，长度恒不超过 residual_block_size。关键术语：residual_block_size（4-bit 取 128、2-bit 取 256，即 kernel 常量 kBlockN_pack，使两种位宽的打包 tile 同占 32 个 uint16 行，且被 pack_num 与 group_size 整除）；三个新方法 update_residual（沿 dim=-3 追加）、update_pack（四路拼接、v_params 沿 dim=-1，传 None 时兼作读取器）、clear_residual（置空列表）。闭环时序为「追加→攒满→kernel 内顺带量化写 *_new→拼回主缓存→清空」，由 cur_residual_len 等于块大小触发，残余区经补零对齐成固定形状输入 kernel。
