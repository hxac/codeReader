本讲打开 u3-l1 标出的 `Flash_fwd_params` 参数结构体：公有继承 `Qkv_params`，CPU 侧由 `set_params_fprop`、`set_params_fprop_qpack` 与 `mha_fwd_kvcache` 补填三路填充，GPU 侧经 `__grid_constant__` 按值传入 qpack/splitkv/residual/combine 四类 kernel。为低比特缓存新增 11 个数据指针、四级 stride（batch/row/head/dim）及 `quant_mode`/`group_size`/`new_lens` 三配置。核心结论：stride 字段按逻辑角色命名——K 系序列在 dim -3 而 `v_params` 形状为 (b, d/g, h, s)、序列在 dim -1，故其 row/dim 提取非对称（stride(-1)/stride(-3)），换取残余参数沿序列连续、合并访存友好；decode 路径注释 FP16 指针只读量化缓存，qpack 路径因 Python 折叠 batch 而手工重算 batch stride；`cu_seqlens_k` 被复用为每批次已打包主缓存长度（`is_seqlens_k_cumulative=false`），`seqlen_k` 是打包区总长标量，`new_lens` 才是残余有效长度且被 device 真实消费（掩码、加载谓词与“攒满即再量化”触发）；`new_*` 四件套与主缓存布局同构、提取逐行镜像；`quant_mode` 字符串仅在 host dispatch 比较，配置实际靠模板参数固化。
