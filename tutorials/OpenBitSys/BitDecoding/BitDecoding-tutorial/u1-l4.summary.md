本讲跑通最小闭环：test.py 是不加载大模型的 kernel 正确性测试，以朴素参考实现 attention_ref 逐轮比对平均绝对误差 MAE；example.py 借猴子补丁替换 transformers 缓存类，让 Qwen3/Llama 系列 8B 模型用低比特 KV cache 在 GSM8K 长提示上端到端生成，量化位宽、模式、分组大小与注意力后端经命令行参数和 config 注入。机制上，prefill 阶段 kvcache_pack_int 把 KV 量化打包进改造版 DynamicCache 的低比特主缓存；decode 每轮 update_residual 追加新 token 到 FP16 残余缓存，fwd_kvcache_int 计算注意力，残余攒满一个块才 update_pack 拼回主缓存并 clear_residual。结论：默认 32 轮测试不会触发拼回；MAE 非零是量化固有代价，2-bit 误差显著大于 4-bit，残余机制保证最新 token 始终精确。
