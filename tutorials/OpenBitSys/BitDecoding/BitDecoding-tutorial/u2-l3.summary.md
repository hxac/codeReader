本讲在 Python 层精读 bit_decode 仅有的两个入口，止步于 bit_decode_cuda 绑定层，不进入 CUDA kernel。kvcache_pack_int 在 prefill 阶段把 FP16 KV 量化写入调用方预分配的四个 pack/params out 参数，无返回值；fwd_kvcache_int 每轮 decode 调用，返回 5 元组：注意力输出 out_bit，以及仅当残余区攒满一个 residual_block_size 时才有效的四个 *_new 新量化块缓冲。本讲引入 out 参数、pybind11 绑定、模板参数与运行时参数之别等概念：num_bits 是编译期模板参数，须在 Python 层分流到 int2/int4 绑定；opt_seqlens_k 是已打包主缓存 token 数，new_lens 是残余区有效长度，二者之和为总 KV 长度。核心结论：当前仓库实际仅启用 k-channel 且 group_size∈{32,128}，传其他组合会静默无操作而非报错；每元素有效比特为 num_bits+32/group_size，group_size 越大越省带宽但误差越大。
