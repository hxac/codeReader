本讲讲解 BitDecoding 的构建与安装。setup.py 用 CUDAExtension 调 nvcc 现场编译出扩展 bit_decode_cuda（项目无预编译 wheel），源码为 pybind11 绑定层 decode_api.cpp 加 5 个 genfile `.cu` 模板实例化单元，拆文件以并行缩短编译。实例化覆盖 FP16 非量化前向、2/4-bit split-KV 解码与量化打包（qpack）三类 kernel，均为 k-channel 量化、group_size 128/32，模板参数序为 headdim/quant_mode/num_bits/group_size，与 decode_api.cpp 的运行时 dispatch 分支一一对应。构建门槛写死：CUDA ≥ 11.6、恒编 sm_80、≥11.8 追加 sm_90。install.sh 即清理旧产物后执行 setup.py install。libs/cutlass 是 header-only 的 git 子模块，kernel 依赖其 CuTe 头文件，自动初始化代码被注释且路径有误，须 clone --recursive 手动拉取，此为最常见安装失败原因。import bit_decode 会级联导入 bit_decode_cuda，可作安装冒烟验证。
