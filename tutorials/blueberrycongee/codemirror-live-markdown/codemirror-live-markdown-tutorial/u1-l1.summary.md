本讲义是整套手册首篇，不涉及源码，只通读 README、ROADMAP、CHANGELOG、package.json 四份文档，建立项目整体认识。核心结论围绕三个最小模块：其一，Live Preview（实时预览）是区别于源码模式与阅读模式的第三种视图——光标进入文本时原始语法以 CSS 过渡动画淡入、可编辑，离开时只显示渲染结果，由「装饰（Decorations）」和决策函数 `shouldShowSource` 统一控制。其二，本项目是为 CodeMirror 6 提供 Obsidian 风格 Live Preview 的「模块化插件集合」，奉行四条设计原则：模块化、零强制依赖、灵活集成、简单 API；按需导入而非全家桶。其三，依赖分层是硬约定：CodeMirror 5 个包为强制对等依赖（peerDependencies），`katex`、`lowlight` 为可选依赖（peerDependenciesMeta 标 optional）。功能矩阵含 9 项，分为 Core Extensions 与 Feature Extensions；当前真实版本为 0.5.2-alpha.1，CHANGELOG 严重滞后不可作依据，处于 0.x alpha 阶段、稳定性 Low。
