本讲详解 `livePreviewPlugin`（src/plugins/livePreview.ts）：控制 Markdown 标记显隐的 ViewPlugin。核心是区分「标记节点」（EmphasisMark、CodeMark、HeaderMark、ListMark、QuoteMark 等纯符号）与「内容节点」（StrongEmphasis 等结构容器），本插件只隐藏前者，内容样式交给下一讲 `markdownStylePlugin`，形成职责分离。

插件构造时 `build` 一次，`update` 时靠上一讲的 `checkUpdateAction` 判定 `rebuild`/`skip`/`none`，仅 `rebuild` 才重算装饰。`build` 用 `syntaxTree.iterate` 配 `markTypes` 名单过滤标记；`isInsideSkippedParent` 沿父链上爬跳过 `FencedCode`/`CodeBlock` 内标记，另有按文本判定的公式 `CodeMark` 例外让给 `mathPlugin`。

显隐用 `Decoration.mark` 套 `cm-formatting-inline`/`cm-formatting-block` 两态 CSS 类，靠 `max-width`/`font-size` 过渡完成动画，文本始终留在 DOM 可编辑；行内用 `shouldShowSource` 按区间相交判可见，块级用 `activeLines` 行级判断，均叠加 `!isDrag` 防闪烁。因只做「同字符显隐切换」，坚持 mark+CSS 而非 replace+Widget，后者留给 math/table/code 渲染场景。
