本讲讲解 `editorTheme`（src/theme/default.ts）如何用 `EditorView.theme({...})` 把整套样式定义为一个对象式 Extension：`&` 代表编辑器根元素，键是带作用域的 CSS 选择器，属性名用驼峰，`'@keyframes xxx'` 定义关键帧动画。

核心设计是颜色几乎全部写成 `hsl(var(--name, fallback))` 模式：CSS 变量存的是 HSL 通道值（如 `220 9% 9%`）而非十六进制，fallback 仅在变量未定义时触发（赋非法值不会回退，是常见踩坑点）。变量真正赋值由使用者页面的 `:root` 完成，`editorTheme` 只消费不定义，因此覆盖变量即可换肤，暗色模式（亮度大致取反）亦然，无需改源码。

标记显隐用 `max-width`（行内标记）/`font-size`（块级标记）的过渡动画，而非 `display:none`——后者不可过渡，且会移除布局盒导致标记无法被光标编辑；显示态由 `livePreviewPlugin` 切换 `cm-formatting-inline/block` 上的 `-visible` 类触发。引入的关键术语包括：标记节点 vs 内容节点、HSL 通道值、三层 fallback、`mathFadeIn` 与 `spin` 关键帧。本讲确立的职责分层是：插件贴类名（逻辑），主题给类名上色（表现）。
