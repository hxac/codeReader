本讲义首次打开源码，围绕三个最小模块讲解库的整体形态。第一，`src` 采用五层分层：`core` 存放被复用的纯逻辑（如 `shouldShowSource`、`collapseOnSelectionFacet`），`plugins` 是装饰编排者（遍历语法树产出 Decoration），`widgets` 是继承 `WidgetType` 的 DOM 渲染单元，`utils` 是纯函数与缓存（如 `mathCache`），`theme` 定义样式；各层依赖单向——plugins 依赖 core/widgets/utils，widgets 依赖 utils，底层不反向依赖上层。第二，`src/index.ts` 是桶文件（barrel），按 Core/Plugins/Theme/Utils 分类 re-export 五层导出，并用 `export type` 单独转发类型，是 `package.json` 指定的包入口；`livePreviewPlugin`、`mathPlugin`、`codeBlockField`、`imageField` 分别来自对应 plugins 文件。第三，依赖分层是硬约定：5 个 CodeMirror/Lezer 包为对等依赖（peerDependencies，宿主自备以共用同一实例），`katex`/`lowlight` 为可选依赖，运行时动态 import 实现优雅降级，刻意不设 `dependencies`。`tsconfig.json` 的 `rootDir: src` / `outDir: dist` 划定了源码到发布产物的边界。关键术语：五层分层、桶文件、单向依赖、对等依赖、可选依赖、优雅降级。
