本讲围绕块级公式渲染与 KaTeX 缓存展开。核心结论：块级公式必须用 `StateField`（`blockMathField`）而非 `ViewPlugin`，因为带 `block: true` 的 replace 装饰会改变行高，必须属于 `EditorState` 才能参与视口测量。`blockMathField.update` 用 Transaction 手动复刻 `checkUpdateAction` 的「结构性变化→拖拽→选区」判定顺序，省去 `viewportChanged` 检查。源码提取依赖 Lezer 语法树：从 `FencedCode` 节点取 `CodeInfo` 判定语言是否严格等于 `math`，取 `CodeText` 经 `trim()` 得到公式源码；行内公式则靠 `InlineCode` 文本特征识别，无此结构。渲染态用 `replace({ widget, block: true })`，源码态逐行加 `Decoration.line`（class `cm-math-source-block`），是否渲染由 `shouldShowSource` 统一决策。`mathCache` 用模块级 `Map` 缓存 KaTeX 渲染结果，键为 `'inline:src'` / `'block:src'` 以区分行内与块级，且只缓存成功结果以便重试。它与 `MathWidget.eq` 构成两级优化：`eq` 挡住 `toDOM` 执行，`mathCache` 在 widget 重建时挡住 KaTeX 重计算。
