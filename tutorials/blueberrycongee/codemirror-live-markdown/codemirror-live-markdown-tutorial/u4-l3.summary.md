本讲介绍 `tableEditorPlugin`：可编辑表格与 source mode 切换。它与只读 `tableField` 的根本区别是——源码态由显式按钮（`setTableSourceMode` Effect）触发而非光标位置驱动，故光标进入表格时仍保持渲染态、可继续编辑。

关键术语：「消息+状态」搭档——`setTableSourceMode`（StateEffect，载荷 `{from,to,showSource}`）只当消息载体、不存数据；`tableSourceModeField`（StateField）用一张区间数组记录「哪些表处于源码态」，在 update 中随文档变化 `mapPos` 平移区间、据 effect 增删，并配以纯函数 `rangesOverlap`/`addRange`/`removeRange`（统一闭区间相交公式）。

核心结论：装饰字段仅在 docChanged、reconfigured 或收到该 effect 时重建，不含选区变化；渲染态走 replace + 可编辑 Widget，源码态走切换按钮 Widget + 逐行 `cm-table-source`。`createEditableCell` 用 contenteditable 实现「休息态渲染内联格式、聚焦态显示原始文本」双视图，focus/blur/Enter 为三个提交时机；写回链路为 commitIfChanged（值变才提交）→ commitCell → cloneTableData → serializeMarkdownTable（整表重序列化并规整化）→ view.dispatch 替换整张表区间，`eq` 保证数据未变时复用 DOM，`ignoreEvent:true` 让 widget 自管单元格事件。
