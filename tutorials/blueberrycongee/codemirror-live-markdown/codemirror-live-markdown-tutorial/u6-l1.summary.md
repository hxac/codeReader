本讲围绕「远程图片从文本到画面」的全链路，拆解三个最小模块。其一，`parseImageSyntax` 是纯函数，用一条正则将 `![alt](url "title")` 拆成 `src/alt/title/isLocal` 四字段，支持可选标题、单双引号、URL 内含括号，失败返回 `null`；`isLocal` 凡非 http(s)/data 前缀即为本地。其二，`imageField` 是 `StateField<DecorationSet>`，遍历语法树的 `Image` 节点完成编排——因图片用 `Decoration.replace({block:true})` 块级装饰会改变行高，故必须用 StateField 而非 ViewPlugin。其三，`shouldShowSource` 统一裁决双模式：光标与图片区间相交时走源码态（`Decoration.line` + `cm-image-source`，文字可编辑），否则走渲染态（replace + widget）。`update` 以「文档变→拖拽结束→拖拽中冻结→选区」短路，拖拽期间冻结装饰是图片不闪的主防线。`ImageWidget.toDOM` 实现异步状态机：立即返回 loading 占位，`loadImage` 成功换 `<img>`（成功有缓存），失败换错误占位（不缓存、可重试）；`eq` 只比 `src/alt/title`（options 由字段实例缓存保证恒定），`ignoreEvent` 返回 `false` 以放行点击、触发源码态。本讲仅用 `loadImage` 的成败契约，其双缓存、超时与路径净化留给后续讲义。
