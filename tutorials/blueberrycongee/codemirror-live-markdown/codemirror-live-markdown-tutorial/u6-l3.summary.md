本讲讲解 `linkPlugin`，围绕三个最小模块展开。其一，标准链接 `[text](url)` 与 Wiki 链接 `[[target|display]]` 走两条不同解析路径：前者信任 Lezer 语法树的 `Link` 节点，后者因 Lezer 不识别，改用带 `g` 标志的全局正则对全文扫描，扫描前须重置 `lastIndex` 以免漏匹配。其二，`SKIP_PARENT_TYPES`（FencedCode/CodeBlock/InlineCode）先收集 `skipRanges`，再以「完全包含」判定 `isInSkipRange`，把代码块内的链接排除，两条路径共用此保护。其三，URL 安全采用黑名单策略：`isSafeUrl` 拦截 `javascript:`/`vbscript:`/`data:text/html`（大小写与空白无关，且精准拦截而非全禁 `data:` 以免误伤图片），`sanitizeUrl` 再过 `encodeURI` 并用 `try/catch` 兜底，危险 URL 不设 `href`、文字仍显但不可点。核心结论是「解析与安全分层」——解析层只认语法、对所有 URL 一视同仁不拦截，安全拦截发生在渲染层；Wiki 链接则另辟蹊径：`href` 置空、`preventDefault`、转交应用层 `onWikiLinkClick` 回调，target 不进 DOM。`linkPlugin` 为 `ViewPlugin`，用行内 `Decoration.replace` 渲染，渲染态与源码态的切换由 `shouldShowSource` 裁决，拖拽期间冻结装饰防抖动。
