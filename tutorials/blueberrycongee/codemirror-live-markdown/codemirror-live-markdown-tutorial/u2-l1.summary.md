本讲为「Live Preview 核心机制」单元建立 CodeMirror 6 词汇表。状态三件套：EditorState 是不可变状态快照，EditorView 是可变视图、唯一接触 DOM，二者用 Transaction（含 changes/selection/effects 三通道）单向更新——dispatch 后算出新 State、视图切换过去。Decoration 控制文本怎么显示，分 mark（加类名）、replace（替换/隐藏原文，可带 widget）、widget（零宽插入）、line（整行）四类，本项目最常用前三类。提供装饰有两条路：ViewPlugin 适合行内、随视口重算；StateField 的值属于 State、能进快照。核心结论是块级装饰必须用 StateField，因为视口在 ViewPlugin 运行前就要依 State 算出，而块级装饰会改变行垂直结构。另有 Facet（多输入 combine 的配置开关，collapseOnSelectionFacet 控总开关）、Compartment（走 effects 通道运行时重配扩展，做 Live/Source 模式切换）、syntaxTree（Lezer 语法树，插件靠 iterate 按 node.name 找区间产出装饰）。这些术语承接后续 shouldShowSource、livePreviewPlugin、markdownStylePlugin 等讲义。
