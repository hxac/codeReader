本讲讲解渲染态代码块的核心模块 `CodeBlockWidget`（定义于 codeBlockWidget.ts），它服务于 `auto` 与 `toggle` 两种 interaction 模式，`inline` 模式不构造它。输入契约为 `CodeBlockData`，含源码 `code`、语言、三个开关与位置字段，其中 `lineStarts`（每行在文档中的绝对起点）是点击换算的关键。

`toDOM` 拼出「容器 + 工具栏 + pre>code」三段结构，代码被**按行**切成带 `data-line-index` 的 span（起始围栏 -1、结束围栏 -2、正文 0..n），靠主题的 `display:block` 视觉换行。工具栏中「MD」按钮（toggle 模式）派发 `setCodeBlockSourceMode(true)` 切源码态；复制按钮优先 `navigator.clipboard`、失败回退 `execCommand`，全程 try/catch。

事件处理按模式分叉：`auto` 用捕获监听 `stopPropagation + preventDefault` 接管点击并跳转光标；`toggle` 用 `stopBubbleForBody` 只 `stopPropagation` 不 `preventDefault`，挡 CodeMirror 却保留浏览器原生选区；`ignoreEvent` 作为 CodeMirror 层兜底与之配合。`eq` 仅比较 `code/language/show*/from`，刻意省略派生字段 `to/lineStarts`。

点击列定位由 `measureClickOffset` 完成：用 Canvas `measureText` 配合上中位二分查找算字符偏移，Canvas 不可用时退化为 `fontSize*0.6` 等宽估算；最终文档位置为 `lineStarts[i] + charOffset`，必须以源码文本量宽才能对齐。源码态则由 `CodeBlockSourceToggleWidget` 承载「Code」按钮切回渲染态。
