本讲是入门单元收尾，把前三讲串成可用的 Live Preview 编辑器。接入即用 CodeMirror 6 两步法：`EditorState.create({ doc, extensions })` 建不可变状态，再 `new EditorView({ state, parent })` 挂载 DOM；接入本库本质就是正确填写 extensions。

最小核心扩展：`markdown()`（官方 `@codemirror/lang-markdown`，负责语法树）+ `collapseOnSelectionFacet.of(true)`（总开关）+ `mouseSelectingField` + `livePreviewPlugin`（控制 `**`、`#` 等标记显隐动画）+ `markdownStylePlugin`（给内容节点套样式类）+ `editorTheme`；前者管「标记藏不藏」、后者管「内容长什么样」，职责分离。math / table / code / image / link 等特性按需追加。

最易遗漏的必备步骤是 mouseSelecting 接线：CodeMirror 只认 transaction，须手动监听 `mousedown`（挂 `view.contentDOM`）与 `mouseup`（挂 `document`，套 `requestAnimationFrame`），派发 `setMouseSelecting`（StateEffect），由 `mouseSelectingField`（StateField）记录拖拽态；`shouldShowSource` 读到拖拽态一律返回 false，消除拖拽选区闪烁。

用 `Compartment` 的 `reconfigure` 可在运行时切换 Live / Source 模式而无需重建编辑器，Source 模式关键是移除 `livePreviewPlugin` 让原始语法全部可见。
