本讲补齐 Live Preview 的状态基础设施，覆盖 `src/core/` 三件套：`collapseOnSelectionFacet`、`mouseSelectingField`/`setMouseSelecting`、`checkUpdateAction`。`collapseOnSelectionFacet` 是用 `Facet.define` 定义的布尔总开关，`combine: values[0] ?? false` 表示「取第一个投递值、无则默认关」，是 `shouldShowSource` 的第一道关卡。`mouseSelectingField` 用 StateField+StateEffect 搭档记录「是否正在拖选」这一跨事务状态：外部派发 `setMouseSelecting.of(布尔)`，字段 `update` 识别该效果翻转值；读取普遍带第二参数 `false` 做防御性降级。`checkUpdateAction` 把更新归纳为 `rebuild/skip/none` 三动作，按「结构性变化→拖拽结束→拖拽中→选区改变→无」短路判定，拖拽判定位次先于选区判定以消除闪烁。该规则在 `blockMathField` 中用 Transaction 语言等价复刻，形成 ViewPlugin 与 StateField 共享的更新语义，被 `livePreviewPlugin`、`mathPlugin` 复用。
