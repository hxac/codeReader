本讲讲解代码块子系统的决策与状态层，核心模块是 `codeBlockField`（一个 StateField，因块级装饰会改变行高）。它遍历 Lezer 语法树，命中 `FencedCode` 节点后用 `CodeInfo` 子节点取语言、`CodeText` 子节点取代码正文；用 `SKIP_LANGUAGES`（目前含 `math`）把特殊语言主动让给其他插件，靠语言名划分模块管辖权。三种 `interaction` 模式的本质区别在于「谁触发源码态」与「渲染形态」：`auto` 跟光标走（复用 `shouldShowSource`），整块替换为 widget，走 HTML 高亮；`toggle` 跟显式按钮走，整块换 widget；`inline` 跟按钮走但只换围栏行、保留正文可原生编辑，走 HAST 高亮。三模式共用同一个 `update`：文档变化、配置重置或收到 `setCodeBlockSourceMode` effect 一律重建，此后 `toggle`/`inline` 立即返回、不响应选区与拖拽，仅 `auto` 继续处理选区（拖拽中冻结、结束时补建）。`auto` 的 `shouldShowSource(...) || isDrag` 与 update 冻结构成两层防护。源码态由 `setCodeBlockSourceMode`（StateEffect 消息）与 `codeBlockSourceModeField`（StateField，区间数组）这对搭档维护，区间随文档编辑平移、用闭区间相交公式增删查，与 `tableSourceModeField` 同构。
