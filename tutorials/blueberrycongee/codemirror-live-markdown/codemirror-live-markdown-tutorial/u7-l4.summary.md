本讲是手册收官篇，把前六单元零件组装成自定义 Live Preview 插件，以实现 `==高亮==` 语法为贯穿范例。核心结论是「五步法」：需求分析→选载体→识别语法→复用 core→产出装饰。硬规则是块级装饰（block:true）必须用 StateField、行内用 ViewPlugin；Lezer 认识的语法用 `syntaxTree.iterate` 按 `node.name` 定位，不认识的（`==高亮==`、`[[wiki]]`）用带 `g` 标志的正则全文扫描，且每次扫描前重置 `lastIndex`。引入的关键机制：`shouldShowSource` 一次调用免费拿到「Facet 开关+拖拽防闪+光标相交」三件事，`checkUpdateAction` 把更新归为 rebuild/skip/none 实现「只在必要时重建」，`mouseSelectingField` 做双层防护，skipRanges 用「完全包含」判定排除代码块。装饰策略上，同字符显隐选 mark+CSS，视觉全不同选 replace+Widget。插件须在 `src/index.ts` re-export 才可被导入，并在 demo（借 Vite 别名指向 src）接线 `mouseSelectingField` 与 `collapseOnSelectionFacet.of(true)` 后验证。`livePreviewPlugin` 是最简模板，`linkPlugin` 是最全模板，新插件应直接复用 core 而非手写等价逻辑。
