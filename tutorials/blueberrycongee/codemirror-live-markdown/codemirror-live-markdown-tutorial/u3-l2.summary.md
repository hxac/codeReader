本讲讲解行内数学公式插件 mathPlugin（ViewPlugin）。它复用 Lezer 的 InlineCode 节点：用户把公式写成 `` `$...$` ``，build 遍历语法树时对 InlineCode 节点按「以 `` `$ `` 开头、以 `` $` `` 结尾、长度 > 4」三步判定分流，命中后用 slice(2,-2) 剥出源码。更新由 checkUpdateAction 驱动：仅在其返回 rebuild 时重算，拖拽中（读 mouseSelectingField）返回 skip 冻结装饰。渲染态用 Decoration.replace + MathWidget（委托 renderMath 渲染 KaTeX），编辑态用 Decoration.mark + cm-math-source。核心是双层拖拽防护：shouldShowSource 内部已有拖拽短路，build 再加一道 !isDrag，刻意让拖拽中所有公式退回稳定的源码态，杜绝 widget 抖动。行内 replace 不带 block:true，故能走 ViewPlugin；块级公式（blockMathField、StateField）留待 u3-l3。
