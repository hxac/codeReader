本讲讲解 Live Preview 的「替换渲染」策略（区别于 `Decoration.mark` 的「加样式」）：用 `Decoration.replace` 把 Markdown 原文隐藏，替换成自定义 DOM。围绕 `MathWidget` 展开三个最小模块。其一，`WidgetType` 三件套：`toDOM` 从零造 DOM（需用 try/catch 兜底，禁止抛错），`eq` 判定能否复用旧 DOM，`ignoreEvent` 决定事件是否交给 CodeMirror（公式固定返回 `false` 以支持点击进入编辑；代码块则按事件类型区分）。其二，`replace` 分行内与块级：不带 `block` 走 `ViewPlugin`（如 `mathPlugin`），带 `block: true` 走 `StateField`（如 `blockMathField`），因为块级装饰改变行高、必须进入 EditorState 才能参与布局。同一语法节点依 `shouldShowSource` 与 `mouseSelectingField` 在「渲染态 replace+widget」与「源码态 mark 加提示类」间二选一。其三，`eq` 是重建闸门，核心心法是「`eq` 比较的字段集合须等于决定 `toDOM` 输出的字段集合」，多判漏更新、少判白重建。关键术语：WidgetType、eq/toDOM/ignoreEvent、Decoration.replace、block、StateField、shouldShowSource。
