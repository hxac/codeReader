本讲讲解 Live Preview 的「决策心脏」——纯函数 `shouldShowSource(state, from, to)`，它以三步短路判定决定某段 Markdown 区间显示源码（返回 `true`，标记可见可编辑）还是渲染结果（返回 `false`，标记隐藏）。第一步读 `collapseOnSelectionFacet`（总开关 Facet，`combine` 用 `values[0] ?? false`，默认关闭），未开则短路返回 `false`；第二步读 `mouseSelectingField`（由 `setMouseSelecting` StateEffect 改写的 StateField），拖拽中一律返回 `false` 以防闪烁；第三步遍历选区每个 Range，用相交判定 `range.from <= to && range.to >= from` 判定光标/选区是否触碰目标区间，端点含、多选区任一命中即返回 `true`。该函数无副作用、可独立测试，是全库「显示哪一面」的单一事实来源；调用方（如 `livePreviewPlugin`）仅据此切换 `cm-formatting-inline-visible` 等 CSS 类，实现决策与表现的彻底分离。本讲也提醒：读测试要警惕「名不副实」的用例，通过 ≠ 真正覆盖了所声称分支。
