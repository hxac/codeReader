本讲从「写测试证明行为」视角，讲解为 CodeMirror 插件与 Widget 编写可信自动化测试的方法，覆盖四个核心要点。一是环境：全仓库统一跑在 `vitest.config.ts` 配置的 jsdom 中，因 ViewPlugin 与 WidgetType.toDOM 必须有 DOM，`globals:true` 让测试 API 全局可用但项目仍显式 import。二是两种测试范式：测纯函数（如 `shouldShowSource`）只需 `EditorState.create`；测 ViewPlugin（如 `livePreviewPlugin`）必须 `new EditorView`，再经 `view.plugin(...).decorations.between()` 捕获装饰、读 `deco.spec.class` 断言。三是三种粒度 mock：`Object.defineProperty` 替换 `navigator.clipboard`、`vi.mock` 替换整模块依赖、替换 `globalThis.Image` 让被测代码真实跑通；改全局须「备份→篡改→恢复」，并用 `vi.useFakeTimers` 瞬时测超时。四是 `widget.eq` 直接断言，验证 CodeMirror 的「重渲染优化闸门」——eq 比较的字段集合须等于决定 toDOM 输出的字段集合，故刻意省略 CodeBlockWidget 的派生字段 `to/lineStarts`。引入的关键术语有测试运行器、jsdom、mock、widget.eq、确定性测试。
