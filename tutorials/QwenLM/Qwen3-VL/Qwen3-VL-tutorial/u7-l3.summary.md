本讲把 grounding（视觉定位）落地到源码层。核心结论：Qwen-VL 三代坐标口径各异——Qwen2-VL 用 0–1000 相对坐标，Qwen2.5-VL 输出 smart_resize 缩放后图上的绝对像素，Qwen3-VL 默认回归相对 0–1000；同一条数据的标注口径、提示语约定、反算分母三处必须一致，错位只会画飞框而程序不报错。关键术语：bbox_2d/point_2d JSON、XML points 点格式、bbox_3d 九元组（中心/尺寸/姿态，角度需 ×180 还原）、剥 markdown 围栏、截断容错解析、画框可视化验证、IoU、针孔投影。训练侧用 process_bbox 工具把 COCO 的 xywh 标注转角点后按 ÷宽高×1000 夹紧成相对口径 value 文本，为 u7-l4 微调闭环备料。
