本讲精读 ODinW-13 开放域检测评测目录。与选择题评测的本质差异：模型输出 bbox_2d JSON，判分是确定性几何计算（IoU + COCOeval mAP 指标族），无 LLM judge、无 common_utils.py。四个最小模块：①任务生成——类别清单注入固定模板 prompt，smart_resize 按 32 口径（1024 像素/token）预计算缩放尺寸存入 extra_info；②bbox 解析——ast.literal_eval 容错解析，坐标归一化两条分支（is_rel=0 除以 resized 宽高、is_rel=1 除以 1000），换算分母随 JSONL 持久化；③指标计算——xyxy→xywh、类别下标映射 cat_ids、score 恒置 1.0 使 mAP 为集合质量下界；④五目录同构律——数据侧三态、判分侧二态、推理侧逐字复用。关键术语：IoU、mAP_50/75/s/m/l、0-1000 相对坐标口径、odinw13_config.py。
