本讲总览微调单元，从推理跨入 SFT（有监督微调）。qwen-vl-finetune 是「源码即工程」的训练项目：核心包 qwenvl 分 train/（训练入口 train_qwen.py、参数定义、Trainer 补丁）与 data/（数据集注册表 data_dict、样本转张量、rope2d 位置编码）两子包，外围是 scripts 启动脚本、tools 数据工具与 demo 示例，须用 torchrun 从源码启动。依赖须照抄 README 锁定版本，因为框架以 monkey patch 改写 transformers 内部模块，flash_attn 是硬依赖。tools 三件套在训练前运行：check_image 校验媒体与占位符，pack_data 按 processor 真实估算 token 后装箱，process_bbox 转换 grounding 标注。train_qwen.py 按模型路径名自动判定 Qwen2-VL/Qwen2.5-VL/Qwen3-VL/MoE 四代并赋值 model_type（MoE 靠末段目录含字母 a 判定，易误判），主流程为解析参数、加载模型、注意力补丁、冻结、构建数据、Trainer 训练、保存权重与 processor，产物自洽可直接推理。全量微调三开关 tune_mm_vision/tune_mm_mlp/tune_mm_llm 分别控制视觉编码器、投影 merger、语言模型；LoRA 先全冻结再注入低秩适配器；MoE 不支持 ZeRO-3，只能用 zero2。
