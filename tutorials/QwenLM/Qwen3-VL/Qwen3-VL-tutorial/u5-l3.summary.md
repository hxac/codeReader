本讲拆解 LazySupervisedDataset 的数据加工链：update_processor_pixels 在初始化时以「属性＋size 字典」双通道把命令行像素、帧数预算写入 processor，默认值是 28 口径遗产，Qwen3-VL 应显式改用 32 口径；_build_messages 把 human 轮 `<image>`/`<video>` 占位符与媒体池按 FIFO 配对成 messages，双向失配抛错；preprocess_qwen_visual 分词后扫描 token id，自 77091（普通词 assistant）扫至 151645（`<|im_end|>`），把该轮 labels 从 -100（IGNORE_INDEX）恢复为真实 id，只监督「回复＋结束符＋换行」，user 轮与视觉 token 永不监督；`__getitem__` 三层容错重试，坏样本被静默换成相邻样本，训练前须先清洗。attention_mask 存的是序列长度而非 0/1 掩码；position_ids 与 collator 分别留给后两讲。
