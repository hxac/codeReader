本讲以 Qwen3-VL-2B-Instruct 跑通单图、多图、视频三种输入的推理。核心是 messages 数据结构：content 为列表，可混排 text、image、video 三类元素，顺序即模型接收顺序。推理调用链三步：apply_chat_template 把对话渲染为 input_ids 并附 pixel_values、grid_thw 等视觉张量，张量搬至模型设备后交 model.generate 自回归解码；generate 返回的是“输入＋新生成”的完整序列，必须逐样本用 out_ids[len(in_ids):] 裁剪前缀，再 batch_decode 得到文本。关键结论：一张 H×W 图约被压缩为 (H/32)×(W/32) 个视觉 token；多图只是 content 里多放 image 元素；视频元素默认按 fps=2 采样并做 2 倍时间压缩，可用 fps 或 num_frames 覆盖（二者互斥）。transformers 路径的视觉预处理由 processor 内部完成，无需 qwen-vl-utils——该库公共 API 仅 5 个函数，服务 vLLM 等手动传张量场景。batch 推理须设 tokenizer 左填充并启用 padding。
