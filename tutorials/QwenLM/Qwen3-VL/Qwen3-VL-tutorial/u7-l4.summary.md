本讲为全手册收官，把「数据制作→注册→LoRA 微调→合并导出→评测对比」缝合成可复现流水线：自制数据先经 check_image 静态校验，再挂入 data_dict 注册表；套官方三段式 shell 模板定制单卡 LoRA 脚本（LoRA 分支下 tune_mm 三开关失效）；用 merge_and_unload 把 adapter 增量并入同源基座、连同 processor 导出 vLLM 可直接加载的自洽目录；评测复用 MMMU 脚手架的 vLLM 输入三件套与 infer/eval 两段式 JSONL 接口跑自测集。核心结论：像素预算须按 32 口径（像素÷1024）换算，28 口径是遗产常数；模型目录末段含字母 a 会被路径嗅探误判为 MoE；output_dir 残留 checkpoint 会触发自动续训；评测须同输入、同采样参数（贪心）、按 question_id 配对比较，小样本下配对明细比总准确率更有信息量。引入术语：自测集、冒烟训练、有效批量、配对对比、adapter、merge。
