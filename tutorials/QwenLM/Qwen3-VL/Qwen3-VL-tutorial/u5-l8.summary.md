本讲为微调单元收官，解读 DeepSpeed 三档配置、多规格 sft 脚本与显存选型。全参训练状态含参数、梯度、优化器状态，静态开销约 16 字节/参数；ZeRO-1/2/3 逐级切分优化器状态、梯度、参数，offload 再卸载至 CPU 锁页内存；配置中的 auto 由 HF Trainer 按命令行填充。核心结论：MoE 模型（如 30B-A3B）不支持 ZeRO-3，只能用 ZeRO-2，故需 32×80G 卡，且 HF 实现暂缺 load balancing loss；显存上 ZeRO-2 每卡约 2P+14P/N、ZeRO-3 为 16P/N，单卡（N=1）无分摊收益，24G 跑 2B 全参须选 zero3_offload 或 LoRA；ZeRO-3 保存 checkpoint 需跨卡聚合完整权重。
