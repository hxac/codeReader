本讲精读 agent_function_call.py，讲解 GUI Agent 工具调用的协议层实现。核心是 qwen-agent 库的 BaseTool 契约四要素：description（property，动态注入虚拟分辨率）、parameters（JSON Schema 类属性）、call() 执行入口（经 _verify_json_format_args 归一化 str/dict）、@register_tool 注册；.function 把签名打包，经 NousFnCallPrompt 渲染进 system prompt，模型输出 <tool_call> JSON 供解析执行。mobile_use 含九个触摸语义动作，computer_use 含十四个鼠标键盘语义动作，call() 用 if/elif 分发到全为 NotImplementedError 空壳的私有方法，协议层与驱动层分离，子类覆盖即接入。schema 是写给模型看的：扁平结构、仅 action 必填、条件依赖写进 description、enum 锁边界。虚拟分辨率技巧：把屏幕声明为 999/1000 见方，模型输出的“像素坐标”即 0-1000 相对坐标，回投分母须与声明严格一致；手写 schema 快照会漂移，应由 tool.function 现场生成。综合实践为继承 BaseTool 实现 pc_use 工具。
