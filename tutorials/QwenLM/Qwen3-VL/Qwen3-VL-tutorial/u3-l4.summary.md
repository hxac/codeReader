本讲回答两个问题：输入超过原生 256K 上下文怎么办、注意力计算太慢太占显存怎么办。扩展靠 YaRN：训练零改动，只改 config.json 的 max_position_embeddings 与 rope_scaling（rope_type 取 yarn），其按波长分组缩放频率（高频保外推、低频内插、中间平滑）并加注意力温度校正，优于线性内插。Interleaved-MRoPE 下视觉块只把位置计数推进 max(t,h,w)，且 t 恒为 0、时间信息走文本时间戳，实际最大位置 id 远小于 token 数，故 factor 取 2~3 而非 4。vLLM 侧用 --rope-scaling 与 --max-model-len 成对开启（需 vllm≥0.11.0），并按公式预估 KV cache 显存。FlashAttention-2 通过分块计算把注意力显存从 O(L²) 降到近似 O(L) 且数学精确，transformers 加载路径用 attn_implementation 启用（限 fp16/bf16 与兼容 GPU），vLLM/SGLang 引擎自管注意力后端，不受该参数影响。
