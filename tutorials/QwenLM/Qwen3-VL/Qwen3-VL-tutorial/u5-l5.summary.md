本讲剖析两种 DataCollator。常规路径用 padding 把变长 batch 补齐：input 填 pad_token_id、labels 填 -100 免入损失，掩码为 0/1，仅此路径截断。拼接路径把 batch 沿序列维拼成单条 (1, ΣL) 序列，无填充无截断；attention_mask 被语义重载为首元素 0 的累计段长向量 cu_seqlens，供打补丁的 FlashAttention varlen 逐段隔离注意力、防标签泄漏。data_flatten 是运行时 batch 级拼接；data_packing 先离线装箱、再桶内桶间两级拼接，段边界仍精确到原始样本，两者均须搭配注意力替换补丁。收益：注意力计算量由 B·L_max² 降为 ΣLi²。
