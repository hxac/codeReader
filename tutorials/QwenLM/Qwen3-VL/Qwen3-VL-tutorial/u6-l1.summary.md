本讲剖析 Qwen3-VL 评测框架通用架构：evaluation/ 下五个基准目录均遵循「三件套」——run 脚本主流程、dataset_utils 数据侧、eval_utils 判分侧，common_utils 为可选公共件。run 脚本拆分 infer/eval 两个子命令：推理侧组装 prompt 交 vLLM 批量生成并落盘 JSONL，判分侧读回 JSONL 抽取选项、汇总准确率，两阶段以文件解耦 GPU 与 API 资源。数据侧按 MD5 校验下载 TSV 至 LMUData 根目录，以「cell 长度 ≤64」规则消解图像指针、幂等导出 base64 图像，并用 MMMU_preproc 把开放题改写为选择题。判分侧为三级瀑布：can_infer 规则抽取优先，OpenAI 兼容 LLM judge（temperature=0）兜底，随机选择保底并留审计标记。prepare_inputs_for_vllm 三字段模式被五个脚本逐字复用，是仓库级稳定惯用法，故读通一个目录即读通五个。
