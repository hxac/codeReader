本讲解读数据打包：变长多模态样本在 padding 训练下浪费算力，packing 把多条短样本拼进约 4096 token 的桶，本质是 NP 难的装箱问题，降序贪心即可获高填充率。四个最小模块：①长度预估 calculate_tokens＝常数 21＋逐轮模板文本 token＋视觉 token（grid_thw.prod()//4），像素预算须与训练侧一致，缺文件返 0、图文混合只计 image 均属保守低估；估长结果缓存 _count.json，重跑免解码。②to_constant_volume 按 256 条一批局部装箱，桶容量必须不超过 model_max_length。③_pack.json 为「桶列表×样本列表」两层结构，训练开 data_packing=True 后桶即训练单元，_get_packed_item 沿序列维拼接张量、attention_mask 记录各段长度；data_flatten 则是 collator 阶段拼接，二者区分。④check_image.py 前置校验媒体存在性、human 轮占位符配对、gpt 轮纯净性，产出 *_valid 与 *_problems。桶内样本防互相注意由 varlen 注意力接棒。
