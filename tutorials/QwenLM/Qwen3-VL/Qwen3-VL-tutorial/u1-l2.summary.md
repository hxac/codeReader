本讲义绘制 Qwen3-VL 仓库结构地图，核心结论：仓库是多合一工程集合，根目录无打包配置、不含模型代码，仅 README 与 web 演示等门面文件。四大子项目各司其职：qwen-vl-utils 是唯一可 pip 安装的输入预处理库，公共 API 仅 5 个函数，核心入口 process_vision_info（内部经 fetch_image/fetch_video 与 smart_resize 完成像素预算控制）；qwen-vl-finetune 是基于 HF Trainer 的 SFT 有监督微调框架，用 torchrun 直启 train_qwen.py，含数据集注册机制与 rope2d 位置编码；evaluation 是五个结构同构的评测脚手架（run_*.py + dataset_utils + eval_utils 三件套、Instruct/Think 双档脚本）；cookbooks 是按能力组织的提示词实战笔记本集。判断口诀：输入找 utils、训练找 finetune、跑分找 evaluation、用法找 cookbooks。关键术语：子项目、pip 可编辑安装、入口文件、SFT、LoRA、结构同构。
