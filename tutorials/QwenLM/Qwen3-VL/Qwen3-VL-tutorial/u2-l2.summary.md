本讲剖析 qwen-vl-utils 的图像预处理链路（vision_process.py）。fetch_image 把 PIL 对象、本地路径、file://、URL、base64 五种来源统一为 RGB 图：URL/base64 需 deepcopy 防流关闭，RGBA 贴白底合成而非丢 alpha。smart_resize 施加三重约束——宽高被对齐因子 factor（=2×patch，Qwen3-VL 为 32、Qwen2/2.5-VL 为 28）整除、总像素落在 [min_pixels, max_pixels] 区间、尽量保持长宽比；流程为先就近对齐（max(factor,·) 兜底防 0），超上限按 β 等比缩小配 floor，低于下限等比放大配 ceil，长宽比逾 200:1 报错，单遍执行不迭代。像素预算的真正单位是视觉 token：pixels = token 数×32×32，缺省 4~16384，min==max 即锁定目标 token 数，因 floor 实得略低。resized_height/resized_width 可绕过元素预算直控尺寸，值仍就近对齐到 32 的倍数，两键须成对否则静默走回预算路径。关键术语：factor、round/ceil/floor_by_factor（银行家舍入）、smart_resize、视觉 token、resized_*。
