本讲导航 ImageStitchBasedOnFPGA 仓库结构。核心结论是：这是一个「按模块收集的源码片段集」——共 9 个跟踪文件、约 1600 行代码，按功能分目录（DDR3控制、UART串口通信、动态规划法寻找最佳缝合线），无构建系统、无顶层集成模块、IP 核（cordic_0/clk_wiz_0/mig_7series_0）未收录，不能一键综合，但适合逐模块阅读。需注意根目录的 UART串口通信.v 是 0 字节空文件，真正的串口代码在同名目录下的 uart_rx.v/uart_tx.v。各模块角色：mem_burst.v（DDR3 突发读写控制器，封装 MIG 应用接口）配 mem_test.v（自检验证）管存储；圆柱面投影.v（硬件）与 圆柱面投影.cpp（OpenCV 软件参考实现）管投影；DynamicSeam.v 用动态规划找最佳缝合线；UART 收发器为独立调试旁路。本讲最关键的产出是「软件→硬件」对应表：浮点焦距尺度 scale↔定点常数 coe、sinf/cosf↔CORDIC IP、相机矩阵 K·R⁻¹↔定点系数 k_inv、dst_tl/br↔寄存器、双线性插值 weight 表↔weight_x/y，后续讲义将逐对验证。数据主线中「采集、24→64bit 异步 FIFO、融合」三段未收录或仅 README 描述，「存储、投影、缝合线」三段有完整文件。后续 u1-l3 用 UART 热身，u2~u5 逐段精读算法与硬件。
