本讲把 C++ 浮点反向上映射 mapBackward 逐字翻译为全程定点的 Verilog `project` 模块，每个时钟处理一个目标像素：算角度 → CORDIC 取 sin/cos → 矩阵乘 → 取邻居坐标。核心在于把一次性标定烧死成常数：`coe` 是焦距倒数（Q2.22），`k_inv0~k_inv8` 是 K·R⁻¹ 的 21 位定点系数（1 符号 + 12 整数 + 8 小数），可手工还原为焦距 2707.47、主点 550.5、对角 0/1，完美对应内参矩阵 K；CORDIC IP `cordic_0` 由相位 `phase_tdata` 输出打包在 48 位的 sin/cos。关键结论：`weight_xN/weight_yN` 名不副实，实为四个邻居的 floor/ceil 整数坐标（对应软件 addr 地址表），真正小数权重被丢弃，且跳过了 x/=z 透视除法，故本模块实为最近邻插值的简化教学原型，写法不可直接照抄。
