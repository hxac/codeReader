本讲精读 bin/packages.js——全仓库唯一的包清单数据源。它导出 core（12 个核心包）与 nonCore（24 个语言、主题等外围包）两组包名，拼成 36 项的 all，build-readme 仅限 nonCore。Pkg 类把包名实例化：dir 恒为仓库根下的包目录；入口文件 main 默认 null，包未克隆或属唯一的非 TS 包 legacy-modes 时保持 null，否则在 src 下按「唯一 .ts 文件、index.ts、剥 theme-/lang- 前缀的同名文件」的优先级探测，皆落空则抛错。loadPackages 返回 packages（全量）、packageNames（按名索引）、buildPackages（仅可构建包）三个视图，分别服务遍历仓库、按名查表与编译测试类命令；install 完成后须重新调用以刷新探测。根 package.json 的 workspaces 使各包免发布互相引用；该运行时探测与 tsconfig 的静态 paths 是两套独立机制。
