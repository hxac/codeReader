本讲剖析外围包 README 生成器 build-readme.js，由 cm.js 的 build-readme 命令触发，仅对 nonCore 包开放。核心结论：API 文档只存在于 TS 源码注释中，包根 README.md 是生成物，模板为 src/README.md，改文档要改模板而非 README。关键术语：上游工具 getdocs-ts 收集带注释的导出条目，builddocs 渲染 HTML；模板末尾的「@引用」占位块作大纲，被贪婪正则圈出后原位换成 $$$ 替换点；imports 三级解析器按序解析跨包类型链接——兄弟核心包链向 codemirror.net，lezer、style-mod、LSP 等外部依赖链向各自文档站，browserImports 兜底；后处理剥除 span 标签，并把 id 与页内 href 统一为 user-content- 前缀加小写，在生成端预演 GitHub 的锚点改写。legacy-modes 走另一分支：扫描 mode/ 下的 .d.ts 多入口，用 gatherMany 批量收集，锚点加模式名前缀防撞名，$$$ 尾接在模板末尾。
