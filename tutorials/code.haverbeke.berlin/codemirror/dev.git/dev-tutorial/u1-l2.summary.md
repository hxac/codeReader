本讲精读 bin/cm.js 的安装流程，并涉及 bin/packages.js 包注册表。核心结论：cm.js 顶层只 require Node 内置模块，工具依赖一律在函数体内惰性加载，install 因此能在 node_modules 缺失时运行；start() 以「命令→函数」映射分发子命令，除 install 与 --help 外都要先通过 assertInstalled() 的包目录守卫。关键封装 run() 基于 execFileSync：cwd 定工作目录，stdout 用 pipe 收集返回值或 inherit 直通终端，仅 Windows 跑 npm 时启用 shell。install() 分三阶段：逐包克隆（codemirror 包对应 basic-setup 仓库）或 fetch 后以 reset --hard 强制对齐远端并清理；npm install --ignore-scripts 借 workspaces 把 36 个包装配成 monorepo；重新 loadPackages() 探测各包入口 Pkg.main 后触发首次构建。需注意二次运行 install 会丢弃包内未提交修改。
