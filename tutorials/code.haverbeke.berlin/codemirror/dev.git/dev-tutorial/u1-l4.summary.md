本讲让编辑器首次在浏览器中跑起来。demo.ts 用 11 行创建 EditorView：doc 定初始文本、extensions 组合 basicSetup 与 javascript() 语言扩展、parent 指定挂载点，实例存于 window.view 供控制台调试。index.html 加载的 _m/demo.js 磁盘上并不存在：_m/ 是 esmoduleserve 的虚拟 URL 空间，服务器把 TS 即时编译为 JS 并递归服务整条依赖链。cm.js 的 devserver() 分两步——buildtool.watch 监视各包入口与 demo.ts，变化即重建各包 dist；startServer() 监听 8090 端口（默认只绑 127.0.0.1，设 OPEN 才对外），以三层路由处理请求：/test/ 动态生成测试页，其余先交 handleRequest 模块服务（返回值短路），再回退 serve-static 静态文件，最终 404。改 demo.ts 刷新即见，改包源码需等 watch 重建完成。
