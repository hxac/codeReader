本讲精读 CLI 入口 bin/cm.js 的命令分发骨架。start() 用「命令名→函数」对象映射表分发子命令（argv[2] 为命令名、slice(3) 为参数），--help 也是表项，实现函数靠函数声明提升可写在文件后部；参数下限校验复用函数 length 属性（默认值与 rest 参数不计入），上限不校验。实现函数经 Promise 包裹调用，同步 throw 与异步失败统一汇入 error()（stderr、退出码 1）。help(status) 一份文本两种退出码：求助 0、用法错误 1；help 文本与映射表手工同步，unreleased 有实现无文档，映射表才是权威清单。run() 以 execFileSync 封装子进程：cwd 默认仓库根、默认不走 shell、stdout 默认 pipe 捕获（可切 inherit 直通），stderr 恒直通；子进程非零退出抛异常同样落入 error()。除 install 与 --help 外均先过 assertInstalled() 包目录守卫。综合实践为新增 echo 子命令，走通注册、实现、更新帮助、验证的完整闭环。
