本讲精读 bin/cm.js 的 devserver 与 startServer 两个函数，拆解 dev server 的 HTTP 层。devserver 命令是「buildtool.watch 增量重建 + HTTP 服务」的组合，--source-map 只进入 watch 的 options，不影响 HTTP 层。startServer 以 demo/ 为根装配两个实例：esmoduleserve（`_m/` 虚拟 URL 空间、maxDepth=2，浅层依赖即时转译 TS，深层走 watch 重建的 dist）与 serve-static，构成三级级联回退路由：`/test/` 正则分支优先，其次 handleRequest 真值短路，最后 serveStatic 找不到文件时经回调返回 404。`/test/` 测试页无磁盘文件对应，请求时刻由 gatherTests 收集各包 browserTests、经 testHTML 现场生成 mocha 页面（注入隐藏 #workspace 工作区），mocha 资产靠 demo/test/ 下指向 node_modules 的符号链接纳入静态服务。监听 8090 端口硬编码于 listen 调用，默认绑 127.0.0.1，设 OPEN 才对局域网开放。gatherTests 与双轨测试概念为 u2-l4 讲 cm test 铺垫。
