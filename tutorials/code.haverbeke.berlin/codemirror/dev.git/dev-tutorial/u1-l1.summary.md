本仓库是 CodeMirror 的中央开发仓库：不含编辑器源码，只有开发脚本（入口 bin/cm.js）、bug 跟踪与 demo；编辑器本体分散在三十多个独立发版的 @codemirror/* 包仓库中，使用者直接装 npm 包即可，本仓库面向贡献者。三条核心命令：cm install 克隆全部包、装依赖并首次构建；cm build 全量重建；npm run dev（即 cm devserver）在 8090 端口起服务器并在代码变化时自动重建。根 package.json 的四个脚本 test、test-node、prepare、dev 均为 cm 子命令的别名，其中 prepare 是 npm 生命周期钩子，workspaces:["*"] 把克隆出的包目录收编为 npm 工作区、拼成逻辑 monorepo；cm.js 顶部只用 Node 内置模块，因为 install 必须在 node_modules 存在前可运行。贡献规范：论坛提问、issue 报 bug、一个 PR 只含一个改动、测试放各包 test/ 目录；项目明确不欢迎 AI 生成代码。
