本讲聚焦 typst-ide「点击渲染结果跳回源码」链路的入口层，仅覆盖 `src/jump.rs` 一个文件。核心结论有三：第一，跳转终点用 `Jump` 枚举表达，仅三类——`Jump::File`（跳回源码字节偏移）、`Jump::Url`（外链）、`Jump::Position`（分页文档页内坐标，无 HTML 版本），其中带 span 的图元经私有构造器 `Jump::from_span` 收尾为 `File`。第二，公共入口 `jump_from_click<D: JumpFromDocument>` 是纯分发层，函数体仅一行，把点击委托给 `document.resolve_position`，无需 `output` 参数。第三，typst-ide 用 sealed trait `JumpFromDocument` 统一 `PagedDocument` 与 `HtmlDocument` 两种后端：关联类型 `type Position` 将「文档类型↔位置类型」的配对交给类型系统静态保证（传 `PagedDocument` 必配 `PagedPosition`）；公开空壳 + 私有 supertrait 的两层结构使外部 crate 无法实现，从而封闭后端集合、保留演进自由；泛型入口经单态化实现零成本抽象——这正是它优于 enum 或两个自由函数的原因。本讲引入供后续承接的关键术语包括：`JumpFromDocument`（方法 `resolve_position`）与反向对称的 `JumpInDocument`（方法 `find_span`）、`AsOutput`/`Output` 抽象、`PagedPosition`/`HtmlPosition` 位置类型，以及被当作黑盒的 frame 命中函数 `jump_from_click_in_frame`（u7-l2 详讲）。
