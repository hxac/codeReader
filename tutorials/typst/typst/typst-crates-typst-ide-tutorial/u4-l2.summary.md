本讲承接 u4-l1 的定义分派骨架，"开箱"四条分支如何算出终点。第一级 named_items 实现"跨文件跳转"：NamedItem::Import（挑项/通配导入）的 span 取自源模块作用域的 binding.span()，故 import "foo": x 后点 #x 直达源文件；而 Module 项的 span 是本地别名，不跨文件。第二级 analyze_expr 在 named_items 落空时，靠 FieldAccess 父节点回溯把字段访问当整体去 trace，从 Content/Func 值上挖 span，并刻意用不带回退的版本（标准库兜底被单独做成第三级），两个守卫挡掉 detached 与自跳。第三级 globals 按光标 mode_after 在 library.math 与 library.global 间选作用域，返回 Definition::Std，顺序靠后故"用户定义优先于标准库"。ImportPath/IncludePath 经 analyze_import 用路径字符串的 span 作为相对路径解析基准，再由 module.file_id() 区分本地文件（Definition::File）与包路径（None）。Ref 是唯一依赖编译产物 output 的分支，用 Selector::Label 在 introspector 上 query_first 单点查询被引用元素，区别于 analyze_labels 的全量遍历。关键术语：NamedItem 四变体的 span 语义、binding.span()、mode_after、file_id() 分界、Selector::Label。
