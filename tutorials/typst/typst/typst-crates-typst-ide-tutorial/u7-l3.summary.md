本讲讲解 `jump_from_cursor`：给定源码光标，求它在渲染产物中的位置，是 `jump_from_click` 的逆方向，返回 `Vec<Position>`（一段源码可能被渲染多次）。`Span` 是连接源码节点与渲染字形（或 HTML 节点）的唯一桥梁。入口用 `is_text` 过滤，只认 `Text`/`MathText` 叶子，因为渲染字形只挂这些节点的 span。后端抽象 `JumpInDocument` 与 `JumpFromDocument` 镜像对称，同为 sealed trait，靠关联类型 `type Position` 让一个泛型函数同时服务 `PagedDocument`（`PagedPosition`）与 `HtmlDocument`（`HtmlPosition`）。分页后端 `find_in_frame` 按字形 span 命中起点坐标，对 `Group` 施加正向变换把子帧点映回父帧，与反方向的 invert 互逆。HTML 后端 `find_in_elem` 沿 DOM 深度优先遍历、用压栈弹栈维护当前路径，产出 `HtmlPosition`（DOM 索引路径 `element` + 节点内部定位 `inner`：`Frame(Point)` 或 `Character(usize)`）；正查只填路径（节点粒度），反查才填字符粒度。正方向无需 `world`，反方向需 `world` 把 span 翻译回字节偏移。
