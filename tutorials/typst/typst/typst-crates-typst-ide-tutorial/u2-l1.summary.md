本讲解决所有 IDE 功能的共同起点：把光标（字节偏移）映射到语法树节点，横跨 typst-syntax 底层实现与 typst-ide 调用方。核心链条：`Source::root()` 取出无类型语法树根 `SyntaxNode`；`LinkedNode::new()` 为其套上字节偏移、父节点、兄弟节点上下文（裸 `SyntaxNode` 缺乏位置与拓扑信息，无法满足向上找祖先、找兄弟的需求）；`leaf_at(cursor, side)` 递归下钻到光标所在叶子，内部分发到私有 `leaf_before`/`leaf_after`。引入的关键术语：字节偏移、叶子/内部节点、`LinkedNode`、`Side` 枚举（`Before` 在 token 交界处按终点归属前一个 token，`After` 按起点归属后一个 token）、trivia（空白、注释等无语义节点）。核心结论：`leaf_at` 不跳过 trivia，是否过滤是调用方策略（`tooltip` 用 `is_trivia()` 显式判定）。typst-ide 的标准写法是 `LinkedNode::new(source.root()).leaf_at(cursor, side)?`，是后续 `deref_target`、`named_items`、`tooltip`、`definition` 的地基。
