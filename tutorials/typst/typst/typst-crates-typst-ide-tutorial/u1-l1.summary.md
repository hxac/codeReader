`typst-ide` 是 Typst monorepo 中提供 IDE 能力的库 crate，定位是为外部语言服务器（如 tinymist、typst-lsp）服务，是工作区里的「叶子」crate——没有内部 crate 依赖它。本讲只涉及 `Cargo.toml` 和 `src/lib.rs` 两个文件，拆为三个最小模块：模块声明、再导出、依赖关系。

模块声明上，`lib.rs` 用 8 行无 `pub` 的 `mod` 把实现拆进私有子模块（analyze/complete/definition/docs/jump/matchers/tooltip/utils），另有 `#[cfg(test)] mod tests;` 仅测试时编译。`pub use`（再导出）则把挑选好的公共 API「摆上货架」，实现「实现私有、接口精简」。

核心结论是五大 IDE 能力及其入口函数一一对应：补全 `autocomplete`、悬停 `tooltip`、跳转定义 `definition`、双向跳转 `jump_from_click`/`jump_from_cursor`、表达式分析 `analyze_expr`/`analyze_import`/`analyze_labels`；外加共享匹配工具 `deref_target`/`named_items`。关键术语包括：`mod`（接文件）、`pub use`（摆上货架）、`IdeWorld`（所有公共函数首参，数据来源）、`output: Option<impl AsOutput>`（上次编译产物，缺失则功能降级）。

依赖关系揭示分工：`typst`+`typst-eval` 支撑补全/悬停/定义/分析；`typst-html`+`typst-layout` 专为双向跳转服务。`docs.rs`、`utils.rs` 虽无顶层导出，却是被各能力模块共用的内部辅助。
