本讲义只聚焦 `src/args.rs` 这一个文件，讲解 typst-cli 如何用 **clap 派生宏（derive macro）** 把命令行定义成强类型 Rust 结构，不涉及编译、导出等执行逻辑。核心结构是三层骨架：顶层 `CliArguments`（派生 `Parser`，含全局选项如 `--color`/`--cert` 与 `--version`）→ `Command` 枚举（派生 `Subcommand`，9 个子命令变体，编译时按条件 `hide`）→ 各子命令专属结构体。参数通过 `#[clap(flatten)]` 分组复用，像积木一样拼装：`CompileArgs`（最胖的核心组）、`WorldArgs`（编译环境，被 compile/watch/eval/query 共享）、`ProcessArgs`、`FontArgs`、`PackageArgs`。引入的关键术语与概念供后续承接：派生宏、`Parser`/`Subcommand`/`Args`/`ValueEnum` 四个派生 trait；`Input`/`Output` 枚举及其**自定义值解析器（value parser）**，用 `-` 区分 stdin/stdout 与真实路径；取值有限的枚举类型 `OutputFormat`/`Target`/`PdfStandard`/`Feature`/`DiagnosticFormat`，其中 `PdfStandard` 用 `#[value(name=...)]` 把命令行名与 Rust 变体名解耦，`display_possible_values!` 宏为之实现 `Display`；`Pages` 手写 `FromStr` 解析页面范围（如 `4-6`、`8-`、`-2`），内部用 `RangeInclusive<Option<NonZeroUsize>>`；`parse_sys_input_pair` 按「第一个等号」切分 `--input key=value`。关键约束：`args.rs` 同时被运行时与 build script 导入，因此只能 import 既是运行时又是构建依赖的 crate。后续讲义（u2-l1 SystemWorld、u2-l2 编译配置）将消费这些参数。
