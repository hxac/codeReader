本讲精读 world.rs，确立 SystemWorld 是 CLI 与编译器核心之间的核心桥梁。编译器仅依赖纯逻辑的 World 接口（七个回调方法），由 SystemWorld 作为其操作系统版实现，凭工作目录、标准库、惰性字体、文件存储、当前时间五个字段被动应答。关键术语有三层路径——真实路径、VirtualPath、全局驻留的 FileId，以及两种虚拟根 VirtualRoot（项目根、包根）。SystemFiles 负责解析项目根与主文件 FileId：真实路径经 virtualize 与 intern，stdin 与空输入则用 FileId::unique 创建的特殊 id。文件加载按虚拟根分流到磁盘根或包加载，DiagnosticWorld::name 再把 FileId 反向翻译成相对工作目录的人类可读路径。SystemWorld::new 分四步组装并以 WorldCreationError 统一报错，reset、dependencies、scan_fonts 则支撑 watch 模式的增量编译。
