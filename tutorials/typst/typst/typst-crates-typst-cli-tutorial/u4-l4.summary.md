本讲讲解 typst-cli 的自更新机制（`typst update`），覆盖 `src/update.rs` 全部核心逻辑，复用 u3-l3 的 `download::downloader()` 下载基础设施。主线为：备份当前二进制 → 查询 GitHub release → 比较 semver 版本 → 下载预编译资产 → 解压 → 用 `self_replace` 原地替换，错误一律以 `?` 冒泡为硬失败。自更新被 `self-update` feature 门控（默认关闭，拉入 `self-replace`/`xz2`/`zip` 三个可选依赖），关闭时 `main.rs` 提供直接 `bail!` 的同名占位 `mod update`，并在命令行帮助中隐藏该子命令。引入的关键概念：`determine_asset!` 宏用编译期常量 `env!("TARGET")` 把目标三元组映射为 release 资产名，并校正 gnu/musl 重定向；解压按平台分流——Windows 取 ZIP 内 `typst.exe`，其它平台对 `.tar.xz` 做 xz+tar 解包；备份置于 `<state/data 目录>/typst/typst_backup.part`，`--revert` 用它回滚后删除备份（一次性），`--force` 既绕过降级保护又绕过「已是最新」短路，`--backup-path`/`TYPST_UPDATE_BACKUP_PATH` 可覆盖默认备份位置。
