本讲剖析 typst-timing 跨平台取时间的核心抽象 `Timestamp`。关键结论有三：其一，私有结构体 `Timestamp` 用同一字段名 `inner` 配两条互斥 `#[cfg]`，在 native 下编译为 `SystemTime`、wasm 下编译为 `f64`（毫秒），实现零判别式的平台切换并派生 `Copy`。其二，取时双入口分工明确：通用 `now()` 不依赖上下文，`now_with(data)` 复用已有 `ThreadData` 引用；native 两者都落到 `SystemTime::now()`，wasm 必须经每线程的 `WasmTimer`，而 `now_with` 在 wasm 未启用 feature 时返回 `0.0` 实现优雅降级。`new_impl` 取 Start 时间、`Drop::drop` 取 End 时间据此选用不同入口。其三，`micros_since` 把任意时间差归一化为 Chrome Trace 所需微秒：native 纳秒 ÷1000、wasm 毫秒 ×1000，并以 `unwrap_or(Duration::ZERO)` 防御墙钟倒流。后续讲义将承接 `WasmTimer` 内部与 `export_json` 组装细节。
