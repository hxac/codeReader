本讲是 typst-timing u2 单元收尾，讲解将内存中的私有 `Event` 翻译并导出为业界标准 Chrome Trace Event JSON 的唯一对外门面 `export_json<W: Write>(writer, source)`。核心覆盖三个模块：一是函数签名设计，`W: Write` 泛型写入器支持磁盘或内存缓冲，`source: FnMut(NonZeroU64) -> (String, u32)` 闭包因 typst-timing 不能依赖 typst-syntax，被外包负责把裸 span 还原成 `(文件路径, 行号)`，对应 typst-kit 中的 `resolve_span(world, ...)`；二是 Chrome Trace 格式字段映射——`EventKind::Start/End` 直译为相位 `ph="B"/"E"`，`cat` 固定 `"typst"`、`pid` 固定 `1`，`tid` 取自自造 `u64`，`ts` 为相对首个事件的微秒差，有 span 时 `args` 序列化为 `{file, line}` 否则为 `null`；三是函数体内的私有序列化外壳 `Entry`/`Args`，字段多用 `&'static str` 配合 `serialize_seq` 边遍历边写入实现零额外堆分配，并用 `std::mem::take(&mut *EVENTS.lock())` 把事件搬出、将持锁时间压到最短，从而避免 `source` 反向触发 `timed!` 时因 parking_lot Mutex 不可重入而死锁，顺带清空全局缓冲区。
