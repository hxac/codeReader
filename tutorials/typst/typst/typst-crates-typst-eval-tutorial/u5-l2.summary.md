本讲拆解 typst-eval 的 SetRule 与 ShowRule 求值，二者输出类型分别为 Styles 与 Recipe。SetRule 先处理可选条件守卫（cast 成 bool，假则返回空 Styles），校验目标须为元素函数（Func::to_element），再由 Element::set 产出样式并 .liftable() 标记可上浮。ShowRule 求可选 selector（ShowableSelector 校验），求 transform——命中 SetRule 子规则走 Transformation::Style，其余 cast 成 Content/Func，组装为 Recipe。set/show 需作用于后续 tail，故在 Expr::eval 中被 forbidden 拦截，仅在 eval_code/eval_markup 语句流里以样式作用域作用于剩余内容。两条兼容性 lint 中，check_show_page_rule 检测无效的 show page，check_show_par_set_block 检测过时写法 show par: set block(spacing)——后者因依赖已求值 Styles 只能置于求值阶段。hint_if_shadowed_std 则在 cast 失败且标识符遮蔽标准库时附加修复提示。
