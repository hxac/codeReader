本讲精读 src/lib.rs 的两个求值入口：eval 把 Source 求值成 Module，eval_string 按语法模式（Code/Markup/Math）求值字符串返回 Value。二者均带 #[comemo::memoize]，靠 Tracked/TrackedMut 句柄让 World、Route、Sink、Traced 参与缓存判等并重放 sink 副作用。eval 分六步：循环防护、装配 Engine 与 Vm、收集错误与警告、求值 Markup、处理残留 flow 并装配 Module。Route 兼两职——contains(id) 沿调用链查循环求值，命中即 panic（编译器内部错误）；len 累加限深，超限返 Err（用户错误）。Vm::new 借 traced.get(id) 按文件过滤决定是否进入 inspect 模式，故 eval 仅在非 inspect 时因语法错提前返回，便于 IDE hover 在含错的被编辑文件中取到表达式值；求值后残留 flow（顶层裸 break/return）经 forbidden() 报错，否则以最外层作用域 vm.scopes.top 连同内容装配 Module。eval_string 则自行解析、用空 Route/Traced、有错即返、不做循环防护与 inspect 特例，并可注入调用者 scope。本讲引入 Eval、Vm、Engine、Route、Sink、Traced、Scopes、Context、FlowEvent、inspect 模式、SpanMode 等术语，供后续讲义承接。
