本讲义精读 `typst-eval/src/flow.rs`，覆盖 `if`/`while`/`for` 三类结构的求值。核心结论：条件求值把条件强制 `cast` 成 `bool`（Typst 不做真值判断），并在结尾把冒泡经过的 `Return` 事件降级为「条件 return」（其第三字段 `conditional`）。循环是表达式，输出靠 `ops::join` 逐轮累加，`None` 是其单位元，类型不兼容则报 `cannot join`。控制流采用 `vm.flow` 的保存-恢复模式：进入时 `take` 清空、循环内消费、结束后恢复；`break`/`continue` 被消费（清空 flow），`return` 保留并冒泡给函数。`while` 用两道关卡防死循环：静态关卡 `is_invariant && !can_diverge` 报 `condition is always true`，动态关卡 `i >= MAX_ITERATIONS(=10000)` 报 `loop seems to be infinite`。`for` 用 `match (pattern, iterable)` 分派数组/字典/字符串/字节四类，并用 `iter!` 宏复用「作用域 + `destructure` 解构 + 累加 + 消费 flow」骨架；字符串按字形簇（grapheme）迭代以符合文本语义，字节按 `u8` 整数迭代，二者只接受 `Normal`/`Placeholder` 模式。关键术语：`FlowEvent`（三态）、`conditional return`、`ops::join`、`is_invariant`/`can_diverge`、`iter!` 宏、`destructure`。
