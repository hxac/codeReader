本讲承接「`Eval` trait 与 `Vm`」，正式拆解 `code.rs` 中「最朴素的求值」——字面量与标识符这两类叶子节点。核心模块有四：一是 `ast::Expr::eval` 作为表达式总分发器，用一个大 `match` 将各变体派发到内层 `Eval` 实现，产出 `Content`/`Array`/`Dict` 的节点经 `.map(Value::...)` 适配成统一 `Value`，末尾统一 `.spanned(span)` 并调 `vm.trace_at` 满足 trace 调用约定；`set`/`show` 因依赖语句流中的后续 tail，在表达式上下文被 `forbidden` 闭包拦截报错。二是各类字面量（`None`/`Auto`/`Bool`/`Float`/`Numeric`/`Str`）求值极简，签名 `_: &mut Vm` 表明它们自包含、无需运行时状态。三是整数作为唯一可能失败的字面量：typst-syntax 的 `Int::get()` 区分溢出与非法数字，typst-eval 的 `int_literal_error` 借 `find_bad_digits` 与 `SubRange`/`DiagSpan` 实现「错误信息＋精确高亮＋修复提示」三要素诊断。四是标识符求值是首个真正用到 `Vm` 的叶子，经 `Scopes::get` 按「顶层→外层→标准库」逐层查找，`.at(span)` 贴位置，`read_checked` 做弃用检查，最后 `.clone()` 返回独立值。引入的关键术语包括总分发器、`trace_at` 调用约定、`forbidden`、`IntLiteralError`、`Binding`、`Scopes::get`/`read_checked`，为后续数组/字典、代码块作用域、markup 与 let 绑定讲义奠基。
