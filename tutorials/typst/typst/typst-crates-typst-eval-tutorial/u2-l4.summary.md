本讲覆盖 `typst-eval/src/markup.rs` 全部内容，核心是 Markup（标记）模式的求值机制。`Markup::eval` 委托给自由函数 `eval_markup`：它流式迭代标记表达式流，用 `Vec<Content>` 收集各片段，最后返回 `Content::sequence(seq)`。其结构与代码模式的 `eval_code` 高度同构——都做 flow 保存-恢复、都把 `set`/`show` 当作作用于后续 tail 的样式作用域（递归求值剩余表达式后用 `styled_with_map`/`styled_with_recipe` 包裹）；差别只在累加器：标记模式是 `Vec<Content>` + `sequence`，代码模式是 `Value::None` + `ops::join`。文本类叶子节点（Text/Space/Strong/Emph/Heading/List/Enum/Term/Raw/Link）求值套路是「读数据→构造强类型 `NativeElement`→`pack()` 成 `Content`」，自包含者签名用 `_: &mut Vm`，带子体者用 `vm: &mut Vm` 递归求 body。`Escape`/`Shorthand` 返回 `Value::Symbol` 而非 Content，靠默认分支 `value.display()` 转成可见内容；`#let` 返回 `Value::None`，display 后为空，故不输出。本讲难点是 Label 回溯附加：`<label>` 不产生内容，而是被 `eval_markup` 的 `Value::Label` 分支从 seq 末尾向前找到第一个未实现 `Unlabellable` trait 的元素（由 `Content::can` 判定）并经 `labelled` 贴上；目标已有标签或找不到可标记元素时分别触发两条警告。`@ref` 求值直接产出 `RefElem`，其 target 与标签共用 `Label` 类型，为排版期交叉引用查找奠定基础。
