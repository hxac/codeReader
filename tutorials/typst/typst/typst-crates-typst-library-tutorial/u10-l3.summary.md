本讲义覆盖 typst-library 中 `src/math/ir/` 子模块，讲解 Typst 为数学公式在 `Content` 与 `Frame` 之间插入的「数学中间表示（Math IR）」层。核心结论是：typst-library 只负责把类型擦除的 `Content` 树构建为一棵强类型、带预算样式的 `MathItem` 树，真正的排版算法住在行为 crate（typst-math/typst-layout），经 `Routines` 回调消费，延续 u10-l1/u10-l2 的 crate 分离设计。入口为 `resolve_equation`，返回值生命周期绑定调用方提供的 `Arenas`。

引入的关键术语：数据类型族 `RawMathItem`（工作缓冲，含临时 `Linebreak`/`Align` 标记）→ `MathItem`（顶层四变体）→ `MathComponent{kind, props, styles}` → `MathKind`（约 18 个具体种类）及共享属性 `MathProperties`；Scripts/Accent 等会从 base 继承 class。

构建流程为两段式递归下降：先经 `routines.realize(Math)` 把 `Content` 展平成 `Vec<Pair>`，再用 `resolve_realized` 大分派表翻译各叶子元素。`process.rs` 按 TeXBook 规则用 `preprocess` 计算符号间距（`THIN`/`MEDIUM`/`THICK` 查表）、把前有操作数的 `Vary` 运算符升格为 `Binary`，并在 script 尺寸下关闭大部分间距。`multiline.rs` 把 `&`/`&&` 归一为 `Align`，由 `split_at_align` 切出右/左对齐交替的列（`AlignedRow`），并用 `SharedFenceSizing` 让跨行定界符共享同一伸缩高度。
