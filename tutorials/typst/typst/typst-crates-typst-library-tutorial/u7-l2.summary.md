本讲承接 u7-l1（TextElem 产出 FontVariant），回答"拿着这个 variant，Typst 如何在字体集合里挑出最合适的面并实例化它"，全部位于 `src/text/font/` 子模块。核心要点：FontBook 是只含 FontInfo 元数据的轻量索引（族名小写化→面索引映射 + 元数据数组），发现（select_family）与匹配（select/select_fallback）分离，发现时不读字体字节。匹配打分是三元组 (similarity, Reverse(distance), is_variable) 字典序取最大，distance 又按 (style, stretch, weight) 排序、style 最重要；变量字体占优的根源是 FontAxis::distance——目标落在轴区间内即零距离，但距离才是主因，距离更大时静态字体会反超。FontInfo::from_ttf 一次性抽取族名（用 typographic_family 剥离样式后缀而非 Name ID 16）、style（综合关键词而非 is_italic）、flags（PANOSE 判衬线）、Coverage（游程编码的码点集）与轴，并用例外表修正错误字体。FontMetrics 在实例化阶段由 from_ttf 抽取，垂直量一律用 Em，cap_height/x_height 缺失回退 ascender，MathConstants 经 OnceLock 惰性初始化、无 MATH 表时用 MathML Core 默认值兜底。FontVariations::resolve 将 variant+字号映射到 wght/wdth/ital/slnt/opsz 坐标，每步 clamp 进轴区间，用户自定义坐标经 normalized 反向去重覆盖自动值，最终在 Font::instantiate_impl 喂给 rustybuzz。关键术语：face、instance、Coverage、FontAxis、StandardAxes、FontVariations::resolve。
