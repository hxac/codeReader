本讲承接 u9-l1，进入 Typst 内省系统的「可变状态」部分，覆盖 Counter、State、MetadataElem 三个模块。Counter 抽象随文档推进而变化的整数编号（页码、标题号、图号），其值恒为多级数组——CounterState 即 SmallVec<[u64;3]>，step 通过 truncate(level) 在回高层时清零深层。Counter 与 State 共用「整条轨迹一次算完、用 query_count_before 按位置取偏移」的模型：sequence_impl 按排版顺序折叠所有匹配 locatable 元素的更新并标 #[comemo::memoize]，把多点读值从 O(n²) 降到 O(n)。二者边界在于：Counter 受约束（只数整数、带 step/display/display_at、特判页码），State 是泛化（值为任意 Value、仅 Set/Func 两种更新）。关键约定：step/update 只生成待插入元素、无需 context，而 get/at/final/display 需 context 取位置；依赖前值时优先用函数式更新以利于收敛。MetadataElem 是极小的「带 Locatable 能力、隐形、唯一字段 value」容器，经 query 或 typst query 命中，是 Typst 与外部交换任意数据的通道。三者统一于「插入不可见 locatable 元素 → 内省器索引 → engine.introspect 读上一轮的值 → 收敛循环验证」这一模型，未收敛时各自的 diagnose 产出带历史值的警告，通向下一讲 u9-l3。引入的关键术语有：CounterKey、CounterUpdate、Count 能力、CounterUpdateElem、StateUpdate、StateUpdateElem、sequence、SmallVec、truncate、display_at 等。
