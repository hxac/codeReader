本讲覆盖 typst-library 三组「与外界打交道」的设施。`sys` 模块只暴露 `version`（编译期烘焙的版本号）与 `inputs`（宿主注入的字典），均在标准库装配期定死、运行期只读，这体现纯函数原则——故 Typst 不提供随机数等副作用能力。`plugin()` 用 wasmi 解释器把 WASM 字节加载成匿名 Module，每个导出函数成为 `PluginFunc`，host/guest 经线性内存与两个导入函数交换字节，状态码区分成败。插件纯函数约束由两处机制共同强制：`PluginFunc::call` 的 comemo 记忆化（同参只执行一次）与多线程实例池（实例间无共享状态）；transition API 是纯函数世界里做受控变更的官方出口。符号数据由外部 codex crate 提供：`codex::ROOT` 注入全局产出 sym/emoji 子模块，`codex::SYM` 直铺进数学作用域产出裸符号，而 math.sym 可用源于作用域回退到全局。`Symbol` 运行时类型有 Single/Complex/Modified 三种形态，修饰符用 ModifierSet 做顺序无关的最佳匹配，`Symbol` 是值而 `SymbolElem` 负责把字符送进排版流水线。
