本讲聚焦 `foundations/styles.rs`，讲清 `set` 规则在编译期如何被存储与查询。核心结论：一条 `set` 规则经 `Styles::set` 变成 `Property { elem, id, value: Block }` 被推入有序的 `Styles` 列表（`EcoVec<LazyHash<Style>>`）；`Style` 枚举含 `Property`/`Recipe`/`Revocation` 三种条目，本讲只讲 `Property`。`StyleChain` 是零分配的链表视图（`head` 切片 + `tail` 引用，`Copy`），把多层样式串联，按「最内层优先」查询，`PartialEq` 仅比指针以支撑 comemo 增量记忆化。取值分两路：覆盖式 `get_unfolded`（取首个匹配）与折叠式 `get_folded`（`reduce(fold)`），由编译期常量 `E::FOLD` 分派。关键术语：`Fold`（同类型合并、须满足结合律，如 `TextSize::fold` 将两个线性函数相乘实现相对字号层层放大）、`Resolve`（异类型、吃整条 `StyleChain`，把相对值解析成绝对值，`Em::resolve` 在 em 为 0 时触底止递归）、`Smart<T>`（`Auto`/`Custom` 表达「智能默认」，`auto` 在 `get_cloned` 原样保留，到 resolve 才由消费方推导，如方向由 `lang` 推出）。`get_cloned` 内先 fold 后 resolve。
