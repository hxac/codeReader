本讲解析 Typst 文档内容的内核。`Content` 是面向用户的稳定外壳，以 `#[repr(transparent)]` 包裹底层 `RawContent`，一切标记与函数调用的产物皆是它。`+` 运算符按两边是否已为序列分四种情况，复用 `SequenceElem` 保持 content 树扁平，`StyledElem` 同理合并样式避免嵌套。`RawContent` 是手写的 `Arc<dyn Element>`：栈上 `ptr`/`elem`/`span` 三字段加堆上 `Inner<E>`（含 `Header` 计数、`Meta` 与 `data`），靠首成员偏移为 0 在指针间转换，提供引用计数、写时复制（`make_unique`）与哈希惰性缓存。元信息分处存放——`span` 因高频访问置栈上，`label`/`location`/`lifecycle` 置堆上 `Meta`；`label` 被特判为保留字段 ID 255，`query` 经 `Selector::Label` 调 `Content::label()` 比相等来定位元素，location 则在排版后由编译器回填。字段访问分按 ID 与按名字两路，错误为 `Unknown`（无此字段）与 `Unset`（字段未赋值）。本讲只及表示与拼接，将 vtable 与 `Element`/`NativeElement` 留至 u3-l2，elem 宏与 `Packed<T>` 留至 u3-l3，样式折叠留至 u4。
