本讲承接 `Value` 枚举，讲解四个容器变体：`Array`、`Dict`、`Bytes`、`Label`。核心主线是它们如何用「引用计数 + 写时复制」实现 O(1) 克隆，又如何沿不同机制把哈希成本逐步降到 O(1)。内部表示上，`Array` 用 `EcoVec<Value>`（派生 `Clone/PartialEq/Hash`，相等与哈希均为 O(n)）；`Dict` 用 `Arc<IndexMap<Str,Value,FxBuildHasher>>`，强调保留插入序、`make_mut` 触发深拷贝、手写 `Hash` 保证内容确定性，并提供 `finish`/`unexpected_keys` 做未知键校验；`Bytes` 用 `Arc<LazyHash<dyn Bytelike>>`，以 trait 对象零拷贝复用不同来源、`StrWrapper` 跳过 UTF-8 校验、`LazyHash` 缓存哈希；`Label` 内部即 `PicoStr(NonZeroU64)`，靠字符串驻留（interner）让克隆、相等、哈希全为 O(1)，并用 `Unlabellable` 标记 trait 实现「标签附给最近非空白元素」。本讲引入的关键术语——`EcoVec`、`IndexMap`、`LazyHash`、`PicoStr`、写时复制、字符串驻留——为后续内省（query）与类型转换系统（cast）讲义铺底。
