本讲承接 u6-l1 度量原语，建立布局「输入区域→输出帧」的核心词汇。输入侧 `Region`（`size`+`expand`）描述单块空间；`Regions` 以四字段表达一串同宽区域：`size` 为当前剩余高度、`full` 为当前完整高度、`backlog` 为后续有限队列、`last` 为无限重复的末区域，`next()` 从 backlog 摘取高度、耗尽后退回不消费的 `last`。`expand: Axes<bool>` 控每轴填充或收缩，`measure` 探针设 false 以测内容自然大小；`may_break`/`may_progress`/`is_full` 是分页决策三把尺。输出侧 `Frame` 借 `Arc<LazyHash<Vec<(Point,FrameItem)>>>` 兼顾廉价克隆与可哈希，`FrameItem` 六变体(Group/Text/Shape/Image/Link/Tag)构成帧树，Group 为唯一非叶子，软硬 `FrameKind` 决定渐变坐标系。`Fragment` 是 `Vec<Frame>` 新类型，对应多区域→多帧，`into_frame` 以 `assert_eq!(len,1)` 守护单帧契约。这四个类型是 typst-library 与 typst-layout 共享的接口词汇，分页循环的具体编排留待后续讲义。
