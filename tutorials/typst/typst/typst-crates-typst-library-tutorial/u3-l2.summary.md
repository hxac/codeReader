本讲在 u3-l1「Content 外壳 / RawContent 内核」基础上补全元素类型层与能力查询，涉及 typst-library 的 content/{element,vtable,raw,mod}.rs 与 typst-macros 的 elem.rs。Element 是 Copy 的类型擦除元素句柄，仅持一张指向 static ContentVtable 的指针，代表「元素类型」而非实例。ContentVtable 是自造的 #[repr(C)] 虚函数表，既装函数指针又装纯数据，经 erase() 用 transmute 统一布局，unsafe 边界收敛于 Handle。NativeElement 是 Rust 类型化源头（const ELEM + pack，强制 Construct/Set），元素按需为 Packed<E> impl 能力 trait。关键术语：can::<C>() 查能力有无；with::<C>() 经 fat::from_raw_parts 现场拼出 &C 胖指针调用方法；is::<E>() 用指针相等判具体元素。能力分三类归宿：Locatable/Unqueriable/Tagged 走内省布尔，Debug/PartialEq/Hash/Construct/Set/Repr/LocalName 走 vtable 专用槽（FORBIDDEN 列表），其余进 capability 查询表；Unqueriable 须配 Locatable。字段系统与 Packed 留给 u3-l3。
