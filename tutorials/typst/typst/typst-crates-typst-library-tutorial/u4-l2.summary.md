本讲承接 u4-l1，讲「样式如何进入 `Styles`」。`Style` 列表混存三种条目：`Property`（set 规则产）、`Recipe`（show 规则产）、`Revocation`（禁用某 recipe）。set 规则经 `Element::set`→`Set`→`Field::set`→`Property::new`，打包「元素句柄 + 字段编号（`id: u8` 的 const generic 常量）+ 类型擦除值（`Block(Box<dyn Blockable>)`）」；`liftable`/`outside` 标记决定样式能否抬升到页眉页脚等主干区。`Selector::Elem(elem, fields)` 为常见选择器，`.where(...)` 经 `Func::where_` 把字段名译成编号，`matches` 用 `Content::get` 逐字段比相等，需文档位置的变体（`Regex`/`Before`/`After`/`Within`）返回 false 留给 query；`ShowableSelector`/`LocatableSelector` 把关上下文约束。`Recipe` 装 `selector + transform`，`Transformation` 分 `Content`/`Func`/`Style`（show-set 复用 `Property`）；无选择器的捕获式 show 被 `styled_with_recipe` 立即应用，其余挂载待 realization 匹配，`Recipe::apply` 把命中元素作为 `it` 喂给变换。`NativeRuleMap` 是「`(元素, Target) → Rust show 函数`」内置规则表，`NativeShowRule` 用 `transmute` 擦除 `ShowFn<T>`；`Library.rules` 由 `(routines.rules)()` 函数指针装配，运行期注入 layout/html 的 register 以打破 crate 循环依赖。本讲止于数据构造与查询，set/show 求值循环与 recipe 调度在 `typst-realize`。
