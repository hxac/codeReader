本讲是 typst-library layout 模块度量原语层的基础，覆盖 Abs、Em、Length、Rel、Ratio、Angle、Fr、Dir、Alignment 九类类型。度量皆为 8 字节 newtype：绝对长度 Abs 以整数倍尺度的「原始单位」存储，单位换算只在构造/读取边界发生，避免浮点误差；相对量则延迟到布局时解析，故 Em::resolve、Length::resolve、Alignment::resolve 均须吃 StyleChain 取字号或文字方向。Length={abs,em} 是关于字号的一次函数，字号自身经 TextSize::fold 折叠相乘；Rel<T>={rel:Ratio,abs:T} 再叠加百分比维度，20%+5cm 经 Ratio+Length 升级构造，relative_to 代入容器宽、resolve 代入字号，两个维度独立。Fr::share 按份数瓜分剩余空间，区别于 Ratio::of 的固定比例。Dir（ltr/ttb 为正）确定轴与方向，Alignment 用 + 合成二维、start/end 经 fix(dir) 随文字方向翻转。这些原语普遍派生 Copy/Hash/Resolve/Fold，是后续 Region/Frame 布局引擎的公共词汇。
