本讲聚焦 typst-realize 的对外入口 realize()：它接收 RealizationKind、engine、locator、arenas、content、styles，依 kind 选用静态规则表（BUNDLE/FLOW/PAR/MATH_RULES），搭建可变状态 State 后交由 visit() 递归、finish() 收尾，移动 s.sink 返回 Vec<Pair<'a>>，函数体本身不含递归。引入的关键类型与术语：RealizationKind 五变体（Bundle/Document/Fragment/Par/Math），其中 Document、Fragment 携带可变引用以回填 DocumentInfo 与 FragmentKind；FragmentKind 仅 Inline/Block 两值，内容全行内时由 finish 改写为 Inline；Pair<'a>=(&'a Content, StyleChain<'a>) 是输出清单的基本单元；Arenas（typed_arena 与 bumpalo::Bump）用于把 show 规则新产出内容的生命周期延长至 'a，须在返回结果处理完毕前一直存活；State 中的 outside 字段仅对 Document kind 初始为 true，决定页面样式能否被提升到 page 层。本讲止于入口与类型，visit() 调度细节留待后续讲义。
