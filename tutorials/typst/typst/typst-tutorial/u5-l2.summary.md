本讲覆盖 typst-render（PNG 栅格化）与 typst-svg（SVG 序列化）两个纯消费 PagedDocument 的导出 crate。共同输入是 Frame 的六类图元（Group/Text/Shape/Image/Link/Tag），两侧遍历几乎镜像：Link 仅 SVG 渲染为链接，Tag 均忽略。栅格化按 pixel_per_pt＝ppi/72 换算画布，State 携带变换、容器变换（服务 RelativeTo::Parent 渐变，区分软硬帧）与遮罩递归；形状经 tiny-skia 先填充后描边，小字号字形走 pixglyph 亚像素位图加手工混合，图像先重采样为纹理再作图案。SVG 侧是序列化而非绘制：SVGRenderer 用 Deduplicator 去重字形、渐变、平铺与裁剪路径，字形以 symbol＋use 复用，渐变拆成源定义与带变换引用两层，数字定点化保证输出字节确定。png 的 ppi 与 svg 的 pretty 选项经 Format 元素机制与 CLI 在 resolve 合并；tests 的 render、svg stage 分别调用 render_merged 与 svg_merged，参考产物以文件和哈希两种方式存放。
