本讲读 typst-cli 的三个文件，追踪从命令行到一次编译的调用链。main.rs 是刻意做薄的入口：子命令各对应一个同名模块文件，全局 ARGS 用 LazyLock 惰性解析一次，dispatch 以 match 分发，退出码经线程局部变量 EXIT 中转。args.rs 用 clap 派生宏实现「数据结构即接口」：compile 与 watch 借 flatten 共享 CompileArgs，Input/Output 枚举把 stdin/stdout 与文件路径统一进类型。compile.rs 的主干是先由 CompileConfig（按 --format、输出扩展名、默认 PDF 之序推断格式与输出路径）与 SystemWorld 备好环境，再执行 compile_once：compile_and_export 调 typst::compile::<T>，以泛型参数区分产出物类型（分页文档、HTML、Bundle），导出统一收敛到 Output::write。compile_once 是被 compile 与 watch 复用的单次编译单元；SystemWorld 的实现细节留待下一讲。
