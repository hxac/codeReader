本讲拆解函数作为一等公民的底层机制，核心是 Func、Args 与 cast 三模块，兼及求值侧 call.rs 与 #[func] 过程宏。函数值统一为 Func，内部有原生、元素、闭包、插件、with 绑定五种形态，调用时由 call_impl 按形态派发，用户闭包经 Routines 指针表进入求值器以规避循环依赖。Args 实行消费式参数协议：实参分位置与命名，spread 按运行时类型展开，被调方用 expect、named 等方法取走即删并完成类型转换，finish 兜底报多余参数，重复命名取最后一个。cast 体系以 Reflect/IntoValue/FromValue 三 trait 与 cast! 宏连接 Value 与 Rust 类型；#[func] 宏据此自动生成参数解析代码、元数据与同名零变体枚举，返回值经 IntoResult 统一附调用点 span。实践部分示范了在 Rust 测试中手工构造 Args 直接调用内置函数 upper，验证整条消费链路。
