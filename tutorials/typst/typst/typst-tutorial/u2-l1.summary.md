本讲覆盖 typst-syntax 的三个模块：Source 与 Lines 的源码快照、Span 与 DiagSpan 的位置表示、FileId 与包路径的文件身份。Source 是文本、行表、语法树的不可变快照，包在 Arc<LazyHash> 中令克隆与哈希近乎零成本，服务记忆化编译；edit 走写时复制与增量重解析；Lines 负责行列与字节的双向换算，列按字符计数。Span 为 8 字节：高 16 位 FileId，低 48 位编号，分 Detached、节点编号、区间等形态，经 SpanKind 与 DiagSpanKind 解包；以节点编号替代字节区间，使编号在编辑后基本稳定、保住缓存命中，DiagSpan 以 extra 补存区间终点或 SubRange。FileId 是驻留 RootedPath（VirtualRoot 为 Project 或 Package，加规范化的 VirtualPath）所得的 2 字节句柄：new 去重复用，unique 不复用，new_for_test 供测试；VirtualPath 的构造不变量把路径词法锁死在根内。包身份另由 PackageSpec 与 PackageManifest 定义。
