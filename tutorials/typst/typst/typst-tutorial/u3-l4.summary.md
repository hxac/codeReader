本讲聚焦 typst-library 的 foundations 模块（content.rs、elem.rs、selector.rs、label.rs），以 HeadingElem 为解剖样本。核心结论：Content 用 ContentInner 五个变体（Text、Element、Styled、Empty、Sequence）统一表示整篇文档，它不可变、可哈希、克隆廉价，既是 typst-eval 与 typst-layout 的交接数据，也是 comemo 增量缓存的前提。Element 是元素类型的运行时句柄（全局注册表加索引定位类型、随实例携带字段值）；#[elem] 宏从结构体声明自动生成构造函数、每字段 getter/setter 与 NativeElementData 元数据，required 与 settable 字段之别即脚本必选/可选参数的真相。Label 基于驻留字符串，LabelError 支持精确报错；Selector 是九变体的可组合数据，支撑 show 规则、where 过滤与 query 查询。后续讲义将承接 Func/Args、Styles 与 realize。
