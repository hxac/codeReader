本讲精读 typst-syntax 的 reparser.rs、lines.rs、highlight.rs 三个模块，增量更新入口为 Source::edit：先更新行信息，再增量重解析，返回实际重解析区间。核心结论：重解析采用三级策略——向下找完全包住编辑的最小单元、Markup 层指数外扩、失败回退全量解析；安全约束为括号配平、边界状态一致、Span 编号空隙充足，窗口外子树连同 Span 原样保留，为后续 comemo 增量编译命中缓存铺路。Lines 每行存字节与 UTF-16 双偏移，坐标换算二分定位行、编辑后仅重扫后缀，整文件替换经前后缀 diff 降级为最小编辑。highlight 基于 LinkedNode 做上下文敏感的 Tag 标注（同一符号依父节点定色、按位置推断函数名），Tag 同时映射 TextMate scope 与 CSS class。
