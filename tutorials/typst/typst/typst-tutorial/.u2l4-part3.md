**① AstNode trait：类型化视图的契约**

[crates/typst-syntax/src/ast.rs:L99-L117](https://github.com/typst/typst/blob/64c5e8c02fe0394d913ead36e42ef8c1334d2107/crates/typst-syntax/src/ast.rs#L99-L117) 定义了所有 AST 节点的公共接口：from_untyped 尝试把无类型节点转成视图、to_untyped 借回底层节点引用，span() 是默认方法——直接委托给底层节点的 span，placeholder() 提供容错兜底。

```rust
pub trait AstNode<'a>: Sized {
    /// Convert a node into its typed variant.
    fn from_untyped(node: &'a SyntaxNode) -> Option<Self>;

    /// A reference to the underlying syntax node.
    fn to_untyped(self) -> &'a SyntaxNode;

    /// The source code location.
    fn span(self) -> Span {
        self.to_untyped().span()
    }

    /// A placeholder for this node type. ...
    fn placeholder() -> Self;
}
```

**② cast / is：挂在 SyntaxNode 上的通用转换接口**

[crates/typst-syntax/src/ast.rs:L120-L129](https://github.com/typst/typst/blob/64c5e8c02fe0394d913ead36e42ef8c1334d2107/crates/typst-syntax/src/ast.rs#L120-L129) 给 SyntaxNode 加了两个泛型方法：is::<T>() 问「能不能转」，cast::<T>() 真正去转，全部工作只是转发 T::from_untyped(self)：

```rust
impl SyntaxNode {
    /// Whether the node can be cast to the given AST node.
    pub fn is<'a, T: AstNode<'a>>(&'a self) -> bool {
        self.cast::<T>().is_some()
    }

    /// Try to convert the node to a typed AST node.
    pub fn cast<'a, T: AstNode<'a>>(&'a self) -> Option<T> {
        T::from_untyped(self)
    }
```

紧接着的 [crates/typst-syntax/src/ast.rs:L131-L149](https://github.com/typst/typst/blob/64c5e8c02fe0394d913ead36e42ef8c1334d2107/crates/typst-syntax/src/ast.rs#L131-L149) 是四个 crate 内部辅助：try_cast_first/try_cast_last 在孩子里找第一个/最后一个可转换节点（find_map，天然跳过 trivia 和不认识的 kind），cast_first/cast_last 找不到时用 T::placeholder() 兜底——语义访问器不 panic 的秘密就在这里。

**③ node! 宏：批量生产包装类型**

[crates/typst-syntax/src/ast.rs:L165-L196](https://github.com/typst/typst/blob/64c5e8c02fe0394d913ead36e42ef8c1334d2107/crates/typst-syntax/src/ast.rs#L165-L196) 的声明宏为每个「与 SyntaxKind 同名」的结构生成全套实现。注意 repr(transparent)——这就是零成本包装：

```rust
macro_rules! node {
    ($(#[$attr:meta])* struct $name:ident) => {
        #[derive(Debug, Copy, Clone, Eq, PartialEq, Hash)]
        #[repr(transparent)]
        $(#[$attr])*
        pub struct $name<'a>(&'a SyntaxNode);

        impl<'a> AstNode<'a> for $name<'a> {
            #[inline]
            fn from_untyped(node: &'a SyntaxNode) -> Option<Self> {
                if node.kind() == SyntaxKind::$name {
                    Some(Self(node))
                } else {
                    Option::None
                }
            }
            // to_untyped 直接返回 self.0（L183-L186）
            // placeholder 用 static PLACEHOLDER 兜底（L188-L193）
        }
    };
}
```
