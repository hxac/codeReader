本讲解读 typst-syntax 的高亮模块（`src/highlight.rs`），核心结论是：高亮是语法分析之后的一道只读工序，不重新做词法/语法分析，而是直接遍历已有的 CST、按节点贴一个 `Tag` 标签，配色交给下游。

四个最小模块：(1) `Tag` 枚举——高亮的「调色板」，22 个变体，粒度比 137 个的 `SyntaxKind` 粗，体现「显示口径 vs 解析口径」分离，配套三套一一对应的输出：`LIST`（稳定下标）、`tm_scope`（编辑器 TextMate 作用域）、`css_class`（网页 CSS 类）。(2) `highlight(node: &LinkedNode) -> Option<Tag>`——核心的单点查询纯函数，按 `SyntaxKind` 主分派，结构容器与纯文本返回 `None`。(3) 上下文相关高亮：同一字符颜色取决于树中位置，`highlight_ident` 用「紧贴 `(`/`[`、点号传播、`#` 插值、show 冒号」判定标识符，`highlight_hash` 让 `#` 借用它引导表达式最左叶子的颜色。(4) `highlight_html` 把树拍平成 HTML，靠 `leaf_text()` 二分保证不重不漏，并刻意不给 `Tag::Error` 包 span，把错误标记留给诊断系统。

引入的关键术语：`Tag`、`highlight`、`highlight_html`、`highlight_ident`/`highlight_hash`、TextMate 作用域、`tm_scope`/`css_class`、`leaf_text`。
