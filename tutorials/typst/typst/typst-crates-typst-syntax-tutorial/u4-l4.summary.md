本讲精读 `src/parser.rs` 中 Code 与 Math 两种解析模式（交叉引用 `ast.rs` 算符表与 `set.rs` 集合）。核心结论：Code 是带优先级与结合性的表达式语言，由 `code_exprs` 主循环（用 `AtNewline::ContextualContinue` 让 `else`/`.` 续行，遇换行/分号切分语句）、`code_expr_prec` 优先级爬升、`code_primary` 主表达式分发三层构成；`#` 嵌入经 `embedded_code_expr` 以 `atomic` 标志限制只吃一条表达式，但语句（`STMT` 集合，含 `let`/`set`/`show`/`import`/`include`/`return`；注意 `if`/`while`/`for` 视为表达式）内部改用非 atomic 解析。关键术语：优先级爬升（结合性靠抬高递归门槛实现，左结合 `prec+1`、右结合 `prec`）、后缀三类（`FuncCall`/`FieldAccess`/`Binary`）、闭包语法糖（`let f(x)=body` 等价 `let f=(x)=>body`）。Math 是独立语言：算符只有 `/`（分式 `MathFrac`）、`^`/`_`（附着 `MathAttach`）、撇号、`!`，`+`/`*` 仅为文本；`math_op` 给独立优先级表，另有「可续接」隐式调用、链式附着合并、`math_delimited` 重解释括号、`math_unparen` 去除多余圆括号、`math_args` 解析参数（单表达式参数不包 `Math` 以免改类型）。本讲产物仍是 CST。
