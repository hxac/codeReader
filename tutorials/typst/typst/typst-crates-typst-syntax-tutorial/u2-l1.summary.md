本讲精读 `src/kind.rs`，覆盖 `SyntaxKind` 枚举全貌。核心结论：它是 lexer 产出的 token 与 parser 构建的 CST 节点共用的统一标签类型，让词法与语法共用同一套词汇表。枚举以 `#[repr(u8)]` 紧凑表示，当前共 137 个变体（判别值 0–136）。变体按通用（多为 trivia）、Markup、Math、Code 四类归位。产生方三法则：lexer 产原子 token（标点、关键字、字面量、`*Marker` 引导符），parser 产结构节点（容器、包裹、复合表达式、语句），少数两边皆可（`Error`、`Text`、`Raw`）。命名规律是分辨钥匙：`*Marker` 是 lexer 引导 token，关键字 token `Let` 对应 parser 语句节点 `LetBinding`，`Root` token 对应 `MathRoot` 节点。另有工程后果：`SyntaxSet` 基于 `u128`，仅容纳判别值 <128 的 kind，末尾 9 个变体无法入集。本讲引入的关键术语包括 SyntaxKind、判别值、trivia、`*Marker`、SyntaxSet、`mode_after`，为后续 u2-l2（分类方法）、u2-l3（位集）、U3（Lexer）奠定共同词汇基础。
