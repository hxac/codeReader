本讲聚焦 Typst CST 的唯一节点类型 `SyntaxNode`（源码仅来自 `src/node.rs`），核心结论是其采用「对外门面 + 内部形态」的三层结构：`SyntaxNode` 是公开外壳，只含 `data: Node` 与 `span: Span` 两字段；私有 `enum Node` 定义四种形态 `Leaf / Inner / Error / Warning`。关键工程取舍是 `span` 提顶层保证访问高效、`SyntaxKind` 刻意留在 `Node` 内部以省约 8 字节，代价是 `Warning` 层重复存一份 kind。引入的关键术语：四种形态（Leaf 文本 token、Inner 带 children 结构、Error 错误节点、Warning 半透明装饰层）、不变量「非 Error 变体永不为 Error kind」、私有三变体只读视图 `NodeRef`。两个下钻助手尤为关键：`node_ref()` 用 `loop` 穿透（可叠加的）Warning 返回剥干净的视图，使 `len()`/`children()` 等访问器对 Warning 透明；`inner_and_span_mut()` 借 `Arc::make_mut` 做写时复制，并刻意同时返回 `&mut InnerNode` 与 `&mut Span` 以规避借用冲突。`Warning` 的「半透明」特性是：无自身文本/子节点，仅复制 kind 并贴消息（及可选 `SubRange`），故 `kind()` 不下钻、其余访问器需下钻——`diagnosis()` 是少数察觉 Warning 的方法。
