本讲是 typst-syntax 的全景地图，精读 lib.rs 门面并据 README 定位 14 个源文件职责。核心结论：lib.rs 用三层可见性管理 API——`pub mod` 公开 ast、package，私有 `mod` 隐藏其余 11 个模块，`pub use` 把私有模块里的类型（Source、Span、SyntaxKind 等）挂牌到 crate 根，实现「模块私有、类型对外」；README 提到的 file.rs 当前不存在，功能已并入 path.rs，应以 mod 声明为权威。引入的关键术语：Token、CST（SyntaxNode，无损真相来源）、AST（CST 的惰性视图）、Span（节点稳定标识）、FileId、SyntaxMode（Markup/Math/Code）。主数据流为「文本→Lexer→Parser→numberize→Lines→Source」，ast/highlight/reparser 是消费 CST 的旁路；source.rs 是依赖总成，Source 靠 lines 做行列位置查询、靠 reparser 做最小增量重解析。解析器借鉴 rust-analyzer、增量重解析源自学位论文，为后续讲义伏笔。
