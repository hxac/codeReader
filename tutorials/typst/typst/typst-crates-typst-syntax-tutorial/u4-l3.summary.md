本讲聚焦 typst-syntax 的 Markup（正文）模式解析。骨架是 markup_exprs 主循环：不断调用 markup_expr 解析表达式，用 at_start（行首状态，由 had_newline 派生）驱动分发；markup_expr 按当前 token 的 SyntaxKind 选分支。

核心是「行首标记两道关卡」：lexer 看 `=`/`-`/`+`/`/` 后续是否空白产生 HeadingMarker/ListMarker/EnumMarker/TermMarker，parser 再看 at_start 决定当结构还是当文本，行中则兜底 convert_and_eat 成 Text。heading/list_item/enum_item/term_item 结构相似，差异在换行模式——标题用 Stop 单行结束，列表/枚举用 RequireColumn(列) 判定续行缩进，term_item 嵌套 with_nl_mode 分别控制 term 与 description。

strong/emph 是成对包裹典型：用 StopParBreak 允许跨行、wrap_trivia 无损圈入 trivia、expect_closing_delimiter 处理未闭合。模式切换由 enter_modes 完成——`#` 切 Code、`$` 切 Math（equation）、`[` 切 Markup（content_block，多从 Code 进入）、`@` 产生 reference（可带紧贴内容块）；退出时回退 lexer 游标重 lex，因同段文本在不同 SyntaxMode 下切成不同 token。
