本讲只读 src/lexer.rs，梳理 typst 词法器骨架。Lexer 是有状态迭代器：底层为 unscanny::Scanner 游标，外加三块状态——mode（Markup/Math/Code，决定字符分派）、newline（上个 token 是否含换行，供 Parser 终止语句）、error（当前 token 的错误与提示暂存区）。next() 为分发枢纽：吃一个首字符后，按「注释/空白/raw 公共前缀优先，再按模式分派到 markup/math/code」选分支；普通路径统一收尾（截文本、据暂存区造 leaf 或 Error 节点），raw 与带子树 math token 提前返回、自带节点。词法错误不抛异常，而是产出 SyntaxKind::Error token，由 error() 开暂存区、hint() 追加提示，守「一 token 只 error 一次、先 error 后 hint、收尾用 take 清空」三不变量。Lexer 与 CST 共用 SyntaxKind 词汇表，为 pub(super) 内部类型，外部经 parse/parse_code/parse_math 调用。三模式规则与 raw 细节留待后续讲义。
