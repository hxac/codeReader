本讲义下钻 typst 解析器最底层的积木，聚焦 `parser.rs` 中的三个私有数据结构与一组原语。`Marker` 是 Copy 的 `usize` 新类型，作为「事后圈子树」的位置戳：在 eat 子节点前用 `marker()` 记下 `nodes.len()`，全部 eat 完再 `wrap(m, kind)` 打包成内部节点，使解析函数不必在入口承诺边界、利于错误恢复。`Token` 是单 token 前瞻，缓存当前 token 的 kind/node 及前置 trivia 计数 `n_trivia` 与换行信息 `newline`，反直觉的关键是 trivia 已在 `lex()` 阶段落入 `nodes`，Token 仅用计数指回。`marker()`（不含 trivia）与 `before_trivia()`（含 trivia）两个位置戳配合 `flush_trivia()` 决定 trivia 归属哪层子树。原语分前瞻查询（`current`/`at`/`at_set`）、消费推进（`eat`/`assert`/`eat_if`/`convert_and_eat`）、圈子树（`marker`/`wrap`/`before_trivia`）三类。`convert_and_eat` 原地改写 kind 再 eat，用于按上下文重解释字符。`AtNewline` 换行模式枚举经 `stop_at` 仲裁后，由 `lex` 把 token 的 kind 临时伪造成 `End` 叫停上层循环，但真实 kind 仍存于 node、退出 `with_nl_mode` 时恢复，使换行得以参与语法判定。全讲以 `strong()` 为贯穿示例。
