本讲是 typst-syntax 的全局导览，只读 README.md 与 src/lib.rs 两个文件。核心结论：typst-syntax 属于 Typst 编译前端，职责是把源码文本解析成语法树，并提供 span 定位、文件身份（FileId）、增量重解析、语法高亮等基础设施，但不负责最终排版。它同时维护两棵树——CST（具体语法树，无损，载体是 SyntaxNode，服务于高亮、重解析、IDE 等工具）是唯一真相来源；AST（抽象语法树，类型化、按需从 CST 转换）服务于下游求值。引入的关键术语包括 Token、CST、AST、Span（源码区间）。SyntaxMode 枚举有 Markup（正文）、Math（公式）、Code（`#` 后代码）三种模式，决定同一字符在不同上下文的解析规则，贯穿后续词法与语法讲义。lib.rs 是 crate 门面：用 pub mod 整体公开 ast、package 两个模块，用 mod 加 pub use 选择性暴露 Source、parse、SyntaxNode、Span、SyntaxKind、SyntaxMode 等核心类型，而 Lexer 等为内部私有引用。设计上借鉴 rust-analyzer 的事件式解析器与一篇增量重解析论文，为后续讲义铺垫。
