本讲义是 typst-syntax Parser 单元首篇，只读 src/parser.rs 的骨架，建立解析器的宏观架构认知。核心范式为「递归下降 + marker 事件式」混合：函数按语法嵌套递归组织，子树则先把 token 推进扁平的 nodes 向量，再用 marker 记下位置戳、由 wrap 事后打包成内部节点，使函数不必在入口承诺子树边界，利于错误恢复与增量重解析。对外暴露三个结构对称的入口 parse/parse_code/parse_math，分别绑定 SyntaxMode（Markup/Code/Math）、一个顶层解析函数与根 SyntaxKind，经 lib.rs 的 pub use 公开。Parser 是私有结构体，持有 8 个状态字段：text/lexer、token（单 token 前瞻并缓存 trivia 信息）/nl_mode、nodes/balanced/memo/depth。收尾用 finish_into(kind)，先断言已读到 End 再把 nodes 包成根 inner 节点；finish 则供 reparser 取裸节点序列。两道防护：MAX_DEPTH=256 配合 increase_depth/defer 守卫防栈溢出（超限由 depth_check_error 保证向前推进并产出错误）；memo（MemoArena）仅在括号场景局部启用 packrat 记忆化，把猜测-回溯最坏时间从 O(2ⁿ) 降到 O(2n)。具体解析规则留待后续讲义展开。
