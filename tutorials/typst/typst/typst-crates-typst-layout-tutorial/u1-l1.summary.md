typst-layout 是 Typst 的分页排版引擎，处在流水线中段：上游 typst-syntax 解析、typst-eval/typst-realize 求值得到已 realized 的 Content，typst-layout 将其排成 PagedDocument（若干 Page/Frame），再交 typst-pdf 等导出；它既不读源码也不写 PDF。关键依赖各司其职：typst-library 提供类型骨架，comemo 做记忆化缓存以支撑增量与并行排版，rustybuzz 负责文本整形，icu_segmenter 检测断行点，unicode-bidi 处理双向文字，kurbo 做几何。lib.rs 仅导出 7 个符号：产物 Page、PagedDocument；文档级入口 layout_document、layout_document_for_bundle；片段级入口 layout_fragment 及其单区域封装 layout_frame；以及 PagedIntrospector 与 register（把 show 规则挂到 Target::Paged，是 layout 与 library 的粘合层）。入口函数普遍把 Engine 拆成 Tracked 参数后调用带 #[comemo::memoize] 的 _impl 函数。
