本讲串起 typst-layout 文档级排版的全链路，覆盖 routines、pages、document 三个最小模块。核心数据流为：`layout_document → layout_document_common → realize → layout_pages → PagedDocument::new`。realize（现实化）是排版前的「翻译层」，把任意 Content 展开成扁平的 `Vec<Pair>`（Pair = 已知元素 + StyleChain），它不算几何、不画东西；`RealizationKind::Document` 还会回填 DocumentInfo 元信息。`layout_pages` 采用三段式：collect 按分页符把 children 切成 `Item::Run`/`Tags`/`Parity`；`engine.parallelize` 对每个 Run 并行调用 `layout_page_run`，产出仅缺物理页号的 `LayoutedPage`；finalize 再串行依赖物理页号完成左右页边距互换、计数器步进与标签挂载，得到最终 `Page`。并行得以成立的根因，是 realize 把样式随元素一起扁平化，使各 page run 自带上下文、彼此独立。最后 `PagedDocument::new` 把 pages 与 info 打包，并派生 introspector（内省器）；introspector 是纯派生物、不参与 Hash，这是 comemo 缓存正确的前提。
