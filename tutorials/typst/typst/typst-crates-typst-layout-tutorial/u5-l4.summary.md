本讲聚焦四段管线 `prepare` 阶段的整形（shaping），把字符变为带位置与字形的 `ShapedText`。涵盖五个最小模块：整形产物 `ShapedText`/`Glyphs`/`ShapedGlyph`（借整段文本切片、克隆廉价，`Glyphs` 用 `Cow`+`kept` 区间裁剪但不删行尾空白，供 PDF 选取）；`shape_range` 按 BiDi level 与 script 切 run，每 run 经 rustybuzz 整形，shape plan 与文本无关故被 comemo 缓存；字体回退 `get_font_and_covers` 按 `covers` 判定覆盖，tofu 子串递归换字体重整、`used` 列表防死循环；按需 `reshape` 优先借 `safe_to_break` 边界零拷贝复用字形，仅危险断点（如合字内部）才重整；软连字符 `shy` 平时零宽，断行时由 `line.rs` 调 `ShapedText::hyphen` 现场追加 `-`，`soft` 标志决定导出码位 U+00AD 或 U+002D。核心结论：段落只在 prepare 阶段整形一次，靠 `safe_to_break` 标志与 plan 缓存支撑任意断行与高性能。
