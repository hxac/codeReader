本讲聚焦 `layout_flow` 三段式的第二步 `collect`（主角 `src/flow/collect.rs`）：把 realize 产出的异构多态 `Vec<Pair>` 一次性拆包分类，翻译成结构化 `Vec<Child>`，并提前做完所有「与高度无关」的工作（解析样式、分配 locator、给段落断行），高度相关判断（块如何断、能放几行）推迟到每区域的 compose/distribute。引入的关键术语与结论：`Collector` 状态机经 `to_packed::<T>()` 长链做类型分派；`par_situation`（First/Consecutive/Other）随段落、块、列断元素流转，决定首行缩进是否生效；`Child` 是九变体枚举，大变体统一 bump-boxed 以控制枚举体积。间距携带 weakness `u8`（越小越强，分级为 手动 v < 块 fr < 块 rel < 段落间距 < 行距），供 `Distributor` 在断点折叠相邻间距。块按 breakable/Fr 分流为不可断裂的 `SingleChild`（单帧）与可断裂的 `MultiChild`（多帧 + `MultiSpill` 跨区域接力）。`PlacedChild` 的 `PlacementScope` 仅 Column/Parent 两变体，配合 float 开关决定 compose 阶段的页级/列级浮动插入。
