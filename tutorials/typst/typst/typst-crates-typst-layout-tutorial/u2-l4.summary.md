本讲为 Typst 内省（query、counter、outline、footnote）的底层地基，含四部分。其一，Location 是元素 128 位的稳定身份，由 Locator/SplitLocator 以分层哈希加 disambiguator 生成，无全局可变状态、可并行；disambiguator 使循环生成的重复元素各得不同身份。Locator 故意不实现 Clone，强制在 split（多内容各自身份）与 relayout（复用身份/测量）间显式选择，LocatorLink 跨 memoize 边界按需取外层信息以保住缓存命中。其二，Tag（Start/End 携 TagFlags）是「不可见但有序」的 FrameItem，随内容流过 collect→distribute 落入 frame，其 pos 即元素位置，introspectable flag 决定是否进索引，且不占布局空间。其三，PagedIntrospector 是 &[Page] 的纯派生物，由 discover_frame 经 discover_tag 记录 Start/End，并借 group.parent 的 start/end_insertion 把跨多帧元素整体插到父元素之后以修正内省顺序，且不参与 Hash。其四，migrate_unterminated_tags 用稳定排序把分页符前未终止的 start tag 迁到分页符之后，修正 show 规则导致的页号归属错误。
