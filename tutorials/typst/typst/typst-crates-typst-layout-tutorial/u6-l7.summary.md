本讲讲三类「对已排好的 Frame 做二次加工」的排版器。**shapes（图形）**：从用户参数构造 `Geometry`（Line/Rect/Curve 等）配 `Stroke`/`Fill` 包成 `Shape` 推进帧；line/curve/polygon 是「路径＋描边」的简单图形，rect/square/ellipse/circle 统一走 `layout_shape`，能包子内容（先 `shrink` 缩小 region 排版再 `grow` 涨回），支持圆角与四边不同描边（一致用矩形原图元，否则 `segmented_rect` 分段绘制）。**transforms（变换）**：对已排好的帧施加 `Transform`（6 元组仿射），核心套路是「用 `compute_bounding_box` 反向变换放大 region → 排版 → 绕锚点施加复合变换 `translate(x,y)∘T∘translate(-x,y)`」；`reflow` 开关决定最终帧尺寸取变换后包围盒还是保持原尺寸，`move` 是例外只 `translate_visual`。**modifiers（修饰符）**：`FrameModifiers`（link/hide）是与几何无关的帧级修饰，必须由 flow/inline/math 三个手动管理子样式的排版器各自经 `layout_and_modify` 施加，其他排版器依赖父级代为施加，`hide` 保留 Tag 故隐藏内容仍可被 query 查到。另有 **image**（contain/cover/stretch 三种 fit，无尺寸时按 DPI 换算）、**pad**（先缩后排完再涨回，`grow` 用代数式反解相对 padding）、**repeat**（用 ⌊(F+g)/(w+g)⌋ 算份数）。
