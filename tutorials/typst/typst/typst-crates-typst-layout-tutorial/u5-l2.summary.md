本讲义深入 Typst 段落排版四段管线（collect → prepare → linebreak → finalize）的前两段，聚焦三个最小模块：`inline/collect`、`unicode-bidi`、`inline/prepare`。核心结论是：`collect` 把异构的 `&[Pair]` 压扁成一条逻辑字符串，非文本内容用占位符顶替（间距→空格、盒子→对象替换符 `\u{FFFC}`、标签→空串），真实几何与样式另存进 `Segment`/`Item`，并通过 `SpanMapper` 把字节偏移回映到源码 `Span`。之所以必须先收集全段文本，是因为 BiDi 算法的方向 level（embedding level，偶数为 LTR、奇数为 RTL）取决于整段上下文。`prepare` 跑 BiDi 并由 `shape_range` 在 level 与 script 边界切分文本 run 后整形，装配出以字节偏移为主键的 `Preparation` 结构，其 `items`（带字节区间的整形文本与 item）、`indices`（字节→item 下标的 O(1) 反查表）和 `spans` 三张表对齐于同一字节轴。本讲引入的关键术语包括：替换字符表、embedding level、shape run、`Preparation`、`SpanMapper`，以及定宽 box 立即排版而 Fr 宽 box 延后到断行的分工。产物 `Preparation` 将交由下一篇 u5-l3（linebreak 断行算法）消费。
