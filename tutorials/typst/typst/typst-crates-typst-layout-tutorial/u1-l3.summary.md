本讲聚焦 typst-layout 的对外「门面」`lib.rs`：它仅通过 5 条 `pub use` 暴露 8 个公共符号，分三类——产物（`Page`、`PagedDocument`）、入口（文档级 `layout_document` / `layout_document_for_bundle`、片段级 `layout_fragment` / `layout_frame`）、粘合层（`register`、`PagedIntrospector`）。文档级入口不接收 `Regions`，画布由样式链的 `page` 配置决定；片段级入口必须传 `Regions`，其中 `layout_frame` 只是 `layout_fragment` 的单区域便捷封装。核心判据是 `Fragment::into_frame` 的「恰好一帧」断言：内容可能跨区域断裂必须用 `layout_fragment`，注定单帧才用 `layout_frame`。所有入口都遵循「公开薄封装 → `#[comemo::memoize]` 的 `*_impl`」模式，先把 `&mut Engine` 拆成可追踪参数再进缓存层。`register` 则是 layout 与 library 的真正粘合层，把 `*_RULE` 挂到 `Target::Paged`，其中「挂 layouter 型」规则（如 `GRID_RULE`）通过 `BlockElem::multi_layouter` 把未导出的 layouter 接进排版流程，这解释了门面里为何没有 `layout_grid`。引入的关键术语包括：入口函数、Region/Regions、Frame/Fragment、realize、Engine、`pub use` 门面、comemo 记忆化。
