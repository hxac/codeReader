本讲精读 typst-layout 段落四段管线（collect → prepare → linebreak → finalize）的第三段「断行」，产出 `Vec<Line>`（仅含测量信息，不含最终帧）。

核心结论：断行入口按 `config.linebreaks` 派发到两种策略——`Simple`（first-fit 贪心，快但局部、行间参差）与 `Optimized`（Knuth-Plass 风格动态规划，全局成本最优但慢），默认随 `justify` 推导：两端对齐时用 Optimized，否则 Simple。

引入的关键术语：`Breakpoint` 三变体 `Normal`/`Mandatory`/`Hyphen(l,r)`，决定行尾裁剪 `Trim { layout, shaping }`（保持 `layout <= shaping`，兼顾布局零宽与复制还原）；断点来源 `breakpoints`——ICU LSTM 行分割器的 UAX #14 断点、`hypher` 的词内连字符断点、URL 专用断点，中文/日文走修正弯引号属性的专用 `CJ_SEGMENTER`。

成本模型是本讲核心：行成本 = (1+badness+penalty)²，badness 由拉伸/压缩比 ratio 算出（100|r|³，溢出给 10⁶），penalty 来自孤行、连字（贴边再叠加）、连续连字符。关键常量 `DEFAULT_HYPH_COST=135`、`DEFAULT_RUNT_COST=100`、`MIN_RATIO=-1`——连字成本刻意高于论文的 50，因 Typst 无 glue 概念、ratio 分布不同，沿用 50 会过度连字。Optimized 采用「近似上界（累积数组 O(1) 估度量）+ bounded 精确搜索」两阶段剪枝，上界失效时退化为无界 DP 保证正确。
