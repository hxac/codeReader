本讲承接 Regions（排版输入）转向「排版输出」，核心心智模型是：排版结果就是一棵 Frame 树。Frame 是带尺寸、基线、FrameKind（Soft 跟随父级 / Hard 自身尺寸）的透明画布，内容由 Arc 包裹、克隆廉价且可哈希，通过 push、push_frame、translate、resize、transform、set_parent 等操作构造。FrameItem 有六种变体（Text/Shape/Image/Link/Tag/Group），其中 Group(GroupItem) 是唯一的非叶子节点，让画布成树，并携带 transform/clip/label/parent。Fragment 是 Vec&lt;Frame&gt; 的新类型：into_frame 带单帧断言（layout_frame 用它强制单帧契约），into_frames 取全部（可断裂 layouter 用它）。页面 finalize 用 Frame::hard 建整页容器，按 background→header→inner→footer→foreground 顺序 push_frame 拼装，顺序直接决定内省与计数器解析。FrameParent 与 set_parent 把跨多帧的逻辑元素（表格单元格、脚注）包成带 parent 的 group，配合内省器的 start/end_insertion 实现「整体插在父元素 start tag 之后」，纠正跨帧内省顺序；Inherit 决定子内容是否继承父级样式。这些类型实际定义在 typst-library，typst-layout 只负责消费与构造。
