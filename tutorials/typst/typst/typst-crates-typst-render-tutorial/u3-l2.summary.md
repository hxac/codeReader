本讲讲 typst-render 如何把 Typst 平铺图案（Tiling）光栅化。核心结论：平铺与渐变同构，同样走「形状用 Pattern 着色器、文本快路径用 PaintSampler 逐像素采样」两路径分流，区别仅是把「位置→颜色」换成「位置→瓦片像素」并多一层周期性回卷。关键术语：PaintSampler 统一纯色/渐变/平铺三种逐像素采样，TilingSampler 是其第三实现；render_tiling_frame 开独立画布、造根 State、复用主派发 render_frame 把瓦片「当一页渲染」成纹理，画布含 spacing 而内容只占 size，间距由此变透明缝；形状路径用 Pattern 配 SpreadMode::Repeat 与 Nearest，经 fill_transform→pattern_transform→pre_scale(1/pp)→base_offset 贴回 pt 几何；文本路径用 rem_euclid 以瓦片尺寸为周期折回像素索引，是 Repeat 的逐像素实现且正确处理负坐标。该函数未像渐变 cached 那样被 comemo 缓存，每次填充都重渲染瓦片（预告 u3-l4）。
