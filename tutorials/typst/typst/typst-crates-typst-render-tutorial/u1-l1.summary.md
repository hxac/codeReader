本讲建立 typst-render 的全局观，含三个最小模块：定位、依赖全景、渲染入口与 CLI 调用链。

它是 Typst 唯一的**光栅图像导出器**，将 typst-layout 排版产出的矢量场景 `Page`/`Frame` **光栅化（rasterization）**为像素缓冲 `tiny-skia::Pixmap`，进而编码成 PNG（typst-pdf/typst-svg 则输出矢量）。一句话：typst-layout 负责「排」，typst-render 负责「画成像素」。

crate 体量极小（`src/` 仅 5 文件），核心能力靠组合外部库获得：**tiny-skia** 作 2D 光栅化地基（提供 Pixmap/Path/Transform/Mask/Stroke），**pixglyph** 管字形光栅化，**resvg** 栅格化嵌入的 SVG，**hayro** 栅格化嵌入的 PDF，**image** 管光栅图解码与重采样，**comemo** 做记忆化缓存；内部由 `image/paint/shape/text` 四个子模块按场景元素类型分派处理。

公共入口 `render(page, opts) -> Pixmap` 依页面尺寸、出血区（bleed）与 `pixel_per_pt` 算出画布像素尺寸 `round(pixel_per_pt×size).max(1.0)`（`.max(1.0)` 防零尺寸画布 panic）后递归渲染整页。`RenderOptions` 仅两个旋钮：`pixel_per_pt`（分辨率，默认 2.0）与 `render_bleed`（默认 false）。命令行 `--ppi`（默认 144）经 `pixel_per_pt = ppi/72.0` 换算（1 inch = 72 pt），故 144/72 恰为 2.0，由 CLI 链 `export_image_page → render → encode_png` 落地为 PNG 文件。本讲不涉渲染算法细节，`State` 坐标变换与 `render_frame` 派发留待后续讲义展开。
