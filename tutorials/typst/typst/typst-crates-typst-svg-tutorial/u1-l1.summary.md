typst-svg 是 Typst 的 SVG 矢量导出器，处在排版流水线末端：它消费 typst-layout 产出的 Page / Frame，将其翻译成一段 SVG 字符串（String），自身不做排版决策、不接触文件系统。它与 typst-render（位图 PNG）、typst-pdf（PDF）并列，区别只在翻译的目标格式。

依赖上，typst-svg 上游依赖 6 个 typst 家族 crate（typst-layout 提供 Page/Frame，另有 typst-library、typst-assets、typst-utils、typst-macros、typst-timing），下游被 typst-cli、typst-bundle、typst-html 调用。关键洞察是：typst-html 既用 svg_in_html 在 HTML 内嵌 SVG，又复用 typst-svg 公开的 WebImage / convert_image_scaling 图像处理组件。

源码共 7 个文件（约 2198 行）：lib.rs 为入口，write.rs 为输出抽象地基，path / shape / text / paint / image 按「原语→形状→文本→绘制→图像」分层，各文件均以 `impl SVGRenderer` 为同一个被拼装出来的类型添加方法。公共 API 含 4 个导出函数（svg、svg_merged、svg_in_bundle、svg_in_html）与配置 SvgOptions（render_bleed、pretty）。单页导出遵循 page_bleed → new → svg_header → State::new → render_page → finalize → end_document 的 7 步骨架，其中 finalize 把渲染过程中去重后的字形、裁剪路径、渐变等定义统一写入 `<defs>`。
