本讲解析 typst-svg 的去重基础设施 Deduplicator。核心结构 Deduplicator<T> 只对值类型 T 泛型，任意键类型 K 在调用点经 typst_utils::hash128 归约为 u128 存入 IndexMap<u128,T>，故一个结构定义即可服务 7 种键形状迥异的资源，靠 kind: char 字段区分 ID 命名空间。核心 API insert_with 与 insert_with_val 把「按 key 哈希查重」与「闭包惰性构造值」绑定，闭包仅在 key 首次出现时执行，重复出现零开销，两者均标 #[must_use]。选用固定密钥 SipHasher13 而非随机化哈希、且 usize 当 u64 哈希，换取省内存、统一泛型、输出可复现三重收益。资源身份证 DedupId(char, u128) 经 SvgDisplay 编码为「kind 字符 + 大端大写十六进制 + 去前导零」，kind 字符 g/c/f/r/s/t/p 划分七个互不碰撞的命名空间，并由 SvgUrl/SvgIdRef 包成 url(#id) 与 #id 引用。关键不变量：渲染期只登记并写引用，finalize 阶段才用 iter() 按登记顺序集中写出 <defs> 真身。
