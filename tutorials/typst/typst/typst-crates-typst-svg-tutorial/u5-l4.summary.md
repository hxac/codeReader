本讲拆解 typst-svg 如何把 Typst 的**圆锥渐变（conic gradient）**翻译成 SVG——由于 SVG 标准无原生 conic 元素，故采用离散化近似：将整圈颜色切成 `NUM_CONIC_SEGMENTS = 360` 段（经验值）扇形，装入一个 `<pattern>` 源定义。每段扇形由 `move_to(圆心) → line_to(弧端) → arc → close` 拼成，端点用 `-2·cos / +2·sin` 参数化，`correct_tiling_pos` 把 Ratio 坐标换算到 pattern 的 [0,1] 绘图系（`r → (r+0.5)·0.5`）。角度修正用 `inverse_ratio = aspect_ratio.recip()`，方向与线性渐变相反（圆锥是「乘」，线性是「除」），并取负转为 SVG 顺时针。每段配一个**双停靠点子渐变** `SVGSubGradient`，因相邻段 `c1_i == c0_{i+1}` 保证颜色连续、避免辐条锯齿。圆锥在去重体系占三层：源 pattern（`'f'`）、引用 pattern（`'r'`，带 `patternTransform`+`href`）、子渐变（`'s'`）；`write_subgradients` 必须在 `write_gradients` 之后，因为子渐变在源 pattern 循环里登记。承接 u5-l3 的线/径向两层模型，并预告 u5-l5 平铺与 u6-l3 去重机制。
