本讲义聚焦 typst-svg 的输出抽象层 `write.rs`，它是整个 crate 把内存结构翻译成合法 SVG 文本的工具模块，本身不渲染任何对象。核心包含四个最小模块：`SvgElem` 借助 RAII 与 `Drop`，构造即开标签、析构即关标签，把 XML 标签配对变成编译期保证；`LazySvgElem` 用 `initialized` 标志实现按需 `init`，在不确定是否需要某层 `<g>` 时避免输出空标签，`init` 幂等、`lazy()` 可跳过本层。底层写入靠 `SvgWrite` trait，核心是 `push_num` 的精度归一（乘以 10⁹ 舍入、整数走 itoa 快路径、浮点走 ryu 最短表示）与 `escape_str` 对 `&`/`<` 的转义，`SvgFormatter` 是其在 `attr_with` 闭包中的实现。值格式化靠 `SvgDisplay` trait，是 `attr(name, value)` 对 value 的要求；`SvgTransform`/`SvgUrl`/`SvgIdRef` 三个 newtype 适配器为 typst 内部类型临时套上 SVG 语义，其中 `SvgTransform` 会挑选最短的 scale/translate/matrix 写法压缩体积。这些工具为后续 path.rs、shape.rs、paint.rs 等渲染模块提供统一的「笔」。
