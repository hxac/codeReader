本讲（第 5 单元收尾篇）拆解 `typst-svg` 如何把 Typst 的 `Paint::Tiling`（重复填充图案）翻译为 SVG `<pattern>`，源码集中在 `src/paint.rs`。

核心模块与结论：①入口 `write_fill` 对 `Paint` 三变体（`Solid`/`Gradient`/`Tiling`）分发，平铺调 `push_tiling` 取 `DedupId`，用 `SvgUrl` 适配器包成 `fill="url(#...)"`。②`push_tiling` 采用「源 + 引用」两层去重（承接 u5-l2）：使用变换 `ts` 为单位矩阵时直接返回源 ID（命名空间 `'t'`），否则插入引用（命名空间 `'p'`）。③**渲染两次**：第一次 `render_tiling_frame` 发生在 `finalize` 前，目的是**预分配资源**（把瓷砖内部字形/渐变登记进全局去重表，因 `write_glyph_defs` 先于 `write_tilings` 执行）并产出去重键；第二次在 `write_tilings` 内真正流式写入 `<pattern>`。④去重键用「渲染结果字符串 + 尺寸 + 偏移 + 角度」，而非 `Tiling` 结构体本身，因后者含不稳定的 `Location`。⑤**`patternTransform` 覆盖陷阱**：带 `href` 的引用 `<pattern>` 会用自身 `patternTransform` 整体覆盖被引用方的，故代码用 `ts.pre_concat(tiling.transform())`（即 T_s·T_tiling）把源变换拼进引用——这是平铺与渐变（源不带变换）的关键差异。⑥`correct_tiling_pos`（r↦0.5(r+0.5)pt）把单位方形 Ratio 坐标映射到 pattern 绘图坐标，主要服务圆锥渐变（u5-l4）。

关键术语：`<pattern>`、`patternUnits`/`patternTransform`/`viewBox`、源/引用两层去重、`render_tiling_frame`、`write_tilings`/`write_tiling_refs`、`TilingRef`、`pre_concat`、命名空间 `'t'`/`'p'`、`finalize` 写出顺序。
