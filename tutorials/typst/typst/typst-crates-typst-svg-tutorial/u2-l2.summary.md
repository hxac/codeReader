本讲义聚焦 typst-svg 的渲染编排层（全部位于 src/lib.rs）：render_frame 作为 Frame 树的无状态调度器，遍历 (Point, FrameItem) 二元组，逐条用 state.pre_translate(pos) 生成新 State 快照后，按六种 FrameItem 分发到 render_group/render_text/render_shape/render_image/render_link，其中 Tag 被忽略。核心是 render_group 对 FrameKind 的分流：软 frame 仅把变换吸收进累积变换、不产生任何 <g>（变换摊平进后代）；硬 frame（page/block/box）强制生成 <g>，把完整变换 T 写到 transform 属性，并将 state.transform 重置为单位矩阵、size 更新为自身尺寸，以确立新坐标系、避免深层浮点误差累积，并为 RelativeTo::Parent 渐变提供新参照。引入的关键术语包括：State（携带 transform 与 size 的渲染快照）、LazySvgElem（惰性 <g>，调用 init 才输出）、软/硬 frame、DedupId/Deduplicator（clip 以 (curve,offset) 为键去重，渲染期只写 clip-path 引用、finalize 阶段由 write_clip_path_defs 集中定义）。链接侧 render_link 生成 <a> + 透明 <rect>，Url 直接写 href/xlink:href 兼容新旧标准，Location 须经 link_resolver 三步解析否则成哑链接；render_anchor 生成带 id 的空 <g> 命名锚点，仅供 bundle/html 集成使用。
