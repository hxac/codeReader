本讲聚焦 typst-svg 的 crate 内部类型 `SvgPathBuilder`（`src/path.rs`），它是把几何坐标翻译成 SVG `<path>` 的 `d` 属性字符串的工具。核心动机是用**相对坐标**压缩体积：每个命令只写「相对上一终点的增量」而非大绝对坐标。实现关键依赖 `typst_utils::defer`——它把「更新 `last_point`」推迟到命令末尾 drop 时，使 `map`（增量 = scale × (目标 − last_point)）始终基于旧值计算，天然隔离读写。六个命令 `move_to`/`line_to`/`curve_to`/`quad_to`/`arc`/`close` 统一走「defer 登记 → map 算增量 → drop 提交」三步走；其中 `line_to` 在纯水平/垂直时退化为 `h`/`v`（只写一个数），`move_to` 在增量为零时整条跳过，构成第二层优化。三种构造方式分工明确：`with_translate` 供已知绝对起点的形状、`with_scale` 供需预缩放的字形、`empty` 供自定义拼接。末尾 `outline` 子模块为 `SvgPathBuilder` 实现 `ttf_parser::OutlineBuilder`，让字形轮廓经回调复用相对坐标压缩，并用 `with_scale(text.size / units_per_em)` 把字体单位换算到 pt，使路径可直接被描边/填充并以 `<symbol>`+`<use>` 复用。
