本讲聚焦 typst-svg 的 `src/image.rs`，讲解 Typst 内部 `Image` 如何转成 SVG 中的 `<image>` 元素，核心是五个最小模块：`WebImage`/`WebImageFormat` 作为图像的「Web 归一化」中间表示，把 `ImageKind`（Raster 的 Exchange/Pixel、Svg、Pdf）抹平为浏览器支持的少数格式；`WebImage::new` 按分支归一化——Exchange 与 Svg 零成本透传、Pixel 经 `PngEncoder`（尽量保留 ICC profile，失败降级）重编码为 PNG、Pdf 经 `pdf_to_svg`(hayro) 转 SVG（见 u6-l2）；`to_base64_url` 把图片内联成 `data:{mime};base64,...` data URL，使 SVG 自包含，代价是体积约 4/3 膨胀；`render_image` 组装出含 `xlink:href`、pt 单位 `width`/`height`、`preserveAspectRatio="none"`、可选 `transform` 与 `image-rendering` 的 `<image>`，并在页面图片与图像字形两处复用；`convert_image_scaling` 把 `Smart<ImageScaling>`(Auto/Smooth/Pixelated) 映射到 CSS `image-rendering`，Auto 不写属性。关键结论：`WebImage` 与 `convert_image_scaling` 是 typst-svg 对 typst-html 公开的两个图像工具；`new` 与 `to_base64_url` 均被 `#[comemo::memoize]`，使重编码与 base64 编码在重复图片时只执行一次——图像去重靠 comemo，而非进入 Deduplicator 表（对比 u6-l3）。
