本讲讲解 typst-kit 的 `diagnostics` 模块（受 `emit-diagnostics` 门禁）——它是一个纯粹的「输出端」积木，不参与编译，只负责借助 `codespan-reporting` 把 `typst-library` 产出的结构化诊断渲染成带颜色的终端报告。核心含四个最小模块：① `DiagnosticWorld: World` 子 trait，仅新增 `name(id)`，把「文件 id → 给人看的名字」这一展示职责从 `World` 干净隔离，集成方各自实现命名策略即可复用全部美化逻辑；② `DiagnosticFormat`（默认 `Human` 与 `Short`），通过切换 codespan 的 `display_style` 改变渲染风格，而非两套代码；③ `emit()` 入口，把每条 `SourceDiagnostic` 拆解成 codespan 的主标签、次标签、备注与 tracepoint，其中 detached hints 走底部备注、带 span 的 hints 走代码标注，二者靠 span 是否 detached 区分；④ `WorldFiles` 适配器，将 typst 的 `World` 伪装成 codespan 的 `Files`，并借 `range()`（`&mut` 写缓存预热）与 `lines()`（`&` 读缓存）的分工实现性能优化。关键结论：tracepoint（`Call`/`Show`/`Import` 等调用栈帧）只在 `Human` 下由自定义的 `emit_trace` 输出，画成 `at file:line:column` 加单行灰色上下文；`Short` 为保单行紧凑而完全跳过 trace。关键术语：`DiagnosticWorld`、`DiagnosticFormat`、`SourceDiagnostic`、`DiagSpan`（`Detached`/`Number`/`Range`）、`WorldFiles`、tracepoint。
