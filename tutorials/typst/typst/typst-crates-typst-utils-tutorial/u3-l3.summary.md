本讲覆盖 `typst-utils` 的两个工具。其一为 `Deferred<T>`，本质是 `Arc<OnceCell<T>>` 的薄包装：`new` 用 `rayon::spawn` 把 `FnOnce` 闭包送进 rayon 后台线程惰性求值（预计算），`Clone` 仅复制 `Arc`，所有副本共享同一结果。`wait` 采用"快速路径 `get` → 协作让出 `rayon::yield_now` 循环 → `OnceCell::wait` 阻塞兜底"三段式，其中 `yield` 专为单线程 / WASM 平台而设，避免 `spawn` 任务与调用方同线程时死锁。其二为 `defer(&mut T, F)`，返回实现了 `DerefMut` 的私有句柄 `DeferHandle`，允许像 `&mut T` 般临时改写目标值，并在句柄 `Drop` 时自动执行还原闭包，是 RAII 式"临时修改-自动还原"模式，典型场景为 `typst-svg` 还原 `last_point`、`typst-pdf` 绘图状态栈 `pop`。底层技巧在于 `DeferHandle::drop` 用 `Option<F>` + `std::mem::take` + `expect` 解决"`&mut self` 下无法 move 出 `FnOnce`"的难题。设计上呼应 u3-l2 的 `Protected`：都用值与类型的形状把使用纪律编码进 API，前者约束还原，后者约束访问。
