本讲义覆盖 typst-utils 的声明式辅助宏（`src/macros.rs` 与 `src/lib.rs`），共四类。`singleton!(T, value)` 基于 `LazyLock` 生成「按调用点全局唯一、惰性初始化」的 `&'static T`，仅返回共享引用，可写场景须搭配 `Mutex` 等内部可变性容器。`sub_impl!(A - B -> C)` 依减法恒等式 `a-b=a+(-b)`，从已有 `Neg`+`Add` 派生 `Sub`。`assign_impl!(A op= B)` 从普通运算符派生赋值运算符，隐含前提是类型 `Copy`（展开体 `*self = *self + other`）。`display!` 把 `format!` 风格参数包成惰性 `impl Display`；`display_possible_values!` 则为 clap `ValueEnum` 枚举一行生成 `Display`。关键术语包括：声明式宏 `macro_rules!`、片段分类符（`:ty`/`:expr`/`:ident`/`:tt`）、重复语法 `$()*`、`#[macro_export]` 与 `$crate` 卫生性范式、派生链（手写 Add/Neg → sub_impl → assign_impl）。核心结论：宏只负责代码生成，类型约束仍由编译器照常校验。
