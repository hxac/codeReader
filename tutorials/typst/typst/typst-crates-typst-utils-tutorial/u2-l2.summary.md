本讲讲解 `typst-utils/src/round.rs` 中的两个舍入函数，延续上一讲 `Scalar` 的「跨平台逐位确定性」主题。`round_with_precision(value: f64, precision: i16)` 用「搬小数点 → `f64::round()` → 搬回去」实现：正精度乘 `10^p` 再除（保留小数位），负精度除 `10^|p|` 再乘（保留到十/百/千位），统一遵循「半数远离零」；负精度选除法是为利用 `MAX_10_EXP(308) > |MIN_10_EXP|(307)` 的微小不对称多支持一档精度。入口一串 `||` 短路守卫把无穷、NaN、`|value| ≥ 2^53` 的整数、`precision ≥ 15`(即 `f64::DIGITS`)、`precision < -308` 等输入原样挡回，并连带保证后续乘法不会溢出为 inf；`precision < -308` 时用 `value * 0.0` 保留正负零符号。`round_int_with_precision(value: i64, precision: i16) -> Option<i64>` 为整数版：正精度直接 no-op，负精度通过除 `10^(n-1)` 多留一位做进位判断，用 `checked_add`/`checked_mul` + `?` 在溢出时返回 `None`（如 `i64::MAX` 以 7 结尾在 `-1` 精度上进位即溢出）。关键术语：短路守卫、半数远离零、正/负精度、checked 算术、`libm::exp10`。两处 `10^k` 均用纯 Rust 的 `libm::exp10`（非标准库 `powi`），与 `Scalar::powi` 选 LLVM 算法同理，避免平台数学库的末位差异。该函数将被下一讲 `duration.rs` 的时长格式化复用以保留两位小数。
