本讲解析 typst-utils 中 `bitset.rs` 的两个位压缩集合。`BitSet` 用 `ThinVec<usize>` 将一串位切成「每字 `usize::BITS` 位」的块，存值 `v` 落在第 `v/BITS` 个字、字内第 `v%BITS` 位；`insert` 用 `word |= 1 << within` 置位（必要时 `resize` 补零），`contains` 用 `get` 安全取字、按位与测试，两者共享定位逻辑且只增不删，内存占用取决于「最大值」而非元素个数。`SmallBitSet` 采用「内联 + 溢出」混合策略：`low: usize` 直接存 `< BITS` 的值实现零分配，`>= BITS` 的值减去 `BITS` 后委托给内部 `hi: BitSet`，以消除两者范围重叠。`Debug` 不维护元素列表，而是遍历 `0 .. chunks*BITS` 逐个 `contains` 还原，`SmallBitSet` 总字数为 `1 + hi.0.len()`。核心设计哲学是针对「期望很小」的集合做 fast/slow path 双路优化。
