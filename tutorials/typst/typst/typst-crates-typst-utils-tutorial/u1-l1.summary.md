本讲是 typst-utils 学习手册首篇，建立全局认知。typst-utils 是 Typst 工作区最底层的工具基础库，被几乎所有 typst-* crate 依赖，自身却不依赖任何 typst-* crate，从而保证依赖图无环；其源码采用「一文件一主题」结构，13 个 .rs 文件分布在 src/ 下，后续讲义各聚焦其一。核心讲解四个最小模块：一是 Cargo 工作区继承，清单大量用 { workspace = true } 从根 Cargo.toml 复用版本与依赖，升级只改一处；二是 build.rs 通过 cargo:rustc-env 将 TYPST_VERSION/TYPST_COMMIT_SHA 注入编译期环境变量，遵循「外部设置优先、build.rs 兜底」原则，version.rs 再用 env!/option_env! 在编译期读回；三是 singleton! 宏（基于 LazyLock）保证 version() 全局只解析一次。关键术语包括：工作区继承、编译期环境变量、env!/option_env! 宏、rerun-if-env-changed、singleton!、以及 lib.rs 的「私有 mod + 选择性 pub use」公开 API 模式（含 version_ 下划线命名避开与 version 函数重名的小技巧）。下一篇将转入 lib.rs 内联的扩展 trait 与辅助函数。
