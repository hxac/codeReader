本讲聚焦 typst-html 的属性系统，覆盖 dom.rs、attr.rs、charsets.rs、lib.rs 四个文件，核心结论有四点。其一，`HtmlAttr` 是 `PicoStr` 的 newtype，将 HTML 属性名驻留成 8 字节、可 `Copy`、O(1) 整数比较的句柄，与上一讲的 `HtmlTag` 机制对称；它有运行期 `intern`（逐字符校验、返回 `StrResult`）和编译期 `constant`（`const fn`、失败 `panic`）两条创建路径。关键差异在于属性名字符规则是黑名单（`charsets::is_valid_in_attribute_name` 禁空格、引号、`>`/`/`/`=` 等语法分隔符），比标签名白名单宽松，两者不可共用校验函数。其二，`HtmlAttrs` 是 `EcoVec<(HtmlAttr, EcoString)>`，保留插入顺序、不去重，提供 `push`/`push_front`/`get`/`get_mut`，`get` 取第一个匹配；`get_mut` 借 `make_mut()` 处理写时复制。其三，`HtmlElem.attrs` 标记 `#[fold]`，`Fold for HtmlAttrs` 的语义是「内层优先、外层补缺」：同名属性内层胜出，外层仅补缺，合并后属性名唯一，且满足结合律。其四，attr.rs 用 `HtmlAttr::constant` 把上百个标准属性名预定义为编译期常量（含 `mathml` 子模块与 `r#for` 等原始标识符），配 `HtmlElem::with_attr`/`with_optional_attr` 实现零成本、可读的引用。此外需区分两个 `with_attr`：lib.rs 的 `HtmlElem` 服务于构造 Content 阶段，dom.rs 的 `HtmlElement` 服务于直接拼装 DOM；`cast!` 实现 `HtmlAttrs` 与 Typst `Dict` 双向互转，是 `html.elem(attrs: (...))` 字典语法的基础。
