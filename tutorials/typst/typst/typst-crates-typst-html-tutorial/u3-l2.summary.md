本讲聚焦 typst-html 编译主链路中 `convert_to_nodes` 之后的「装订」环节 `finalize_dom`，覆盖四个最小模块，全部位于 src/document.rs。`finalize_dom` 接收裸 DOM 节点（EcoVec<HtmlNode>），以「非 Tag 节点个数」count 为判定量，按 (标签, count) 三分派：默认情况下自动包裹 <html>、<head>、<body> 并向 <body> 末尾注入由全局单例 FootnoteContainer 编译出的默认脚注；用户手写 <body> 时跳过新建与脚注注入但仍补外壳；手写唯一 <html> 时原样返回完全不加工；<html>/<body> 必须是文档唯一真实元素否则报错。`head_element` 按固定顺序从 DocumentInfo 翻译出 charset、viewport、title、description、authors（复数、逗号 join）、keywords 等 meta，lang 则写在 <html> 上。`footnotes_unsupported_with_custom_dom` 通过内省查询 FootnoteMarker，在自定义 DOM 下有脚注即报错以防静默丢失。结果存入 `HtmlOutput{nodes, root_index}` 的扁平数组加根下标结构，root_index 在自定义 <html> 分支取用户元素下标、其余取 0，root_mut 经 make_mut 处理写时复制，供后续 resolve_inline_styles 与方程 CSS 注入使用。
