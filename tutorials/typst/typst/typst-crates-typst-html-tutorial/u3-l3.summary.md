本讲聚焦 `src/convert.rs`，打开编译主链路中夹在 `realize` 与 `finalize_dom` 之间的黑盒 `convert_to_nodes`——一个递归流式翻译器，把具象化的 `Content` 序列逐个译为 `HtmlNode`。核心是两个旋钮：`ConversionLevel`（Block 自带引号机、Inline 携 `&mut SmartQuoter` 与外层共享）决定智能引号状态是否自包含；`Whitespace`（Normal 折叠并按需 pre-wrap 保护、Pre 原样输出且一旦黏住不再回退）决定空白是否需保护。`convert_to_nodes` 为唯一入口，职责很薄：构造 `Converter` 状态机→逐个 `handle`→`finish` 收尾→仅在 Block+Normal 时跑 `protect_spaces`。`handle()` 是类型探测链，分派 Tag/HtmlElem/Text/Space/Linebreak/SmartQuote/Box/Block/Frame 等十类元素，并以 `warn` 兜底优雅降级无法 HTML 化的内容。`handle_html_elem` 按标签默认 `display` 把 body 分流到 block/inline/math 三条递归 fragment 路径，块级结束后重置 `quoter`，最终手工装配出 `HtmlElement`，这是 DOM 树层层展开的机制。关键术语：ConversionLevel、Whitespace、Converter 状态机、handle 调度链、handle_html_elem、trailing 尾随空白、last_char、quoter 重置。空白保护三态、display 提升与 fragment 缓存留待后续讲义。
