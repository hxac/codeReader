本讲聚焦 typst-html 的 `src/css/` 子模块，专门管理「编译器生成的 CSS」并最终将其变成内联 `style` 属性。核心区分是：用户手写的 `style` 进入普通属性表 `attrs`，而编译器生成的样式（如空白保护 `white-space`、display 提升）单独存放在 `HtmlElement.css` 字段。模块门面 `mod.rs` 重导出 `Properties`、`ToCss`、`resolve_inline_styles`，`encode` 与 `resolve` 为私有子模块。

关键概念包括：`Properties` 是按属性名排序、自动去重的列表，`push` 用二分查找实现「命中覆盖、未命中插入」，保证输出确定、可哈希；`PropertiesBuilder` 配合 `ToCss`/`CssWriter` 把长度、颜色等 Typst 强类型值序列化成 CSS，序列化失败时经 `WarningSink` 发警告并跳过该属性，实现优雅降级；`to_inline()` 把列表拼成 `name: value; name: value` 文本。最后 `resolve_inline_styles` 在 `finalize_dom` 之后递归遍历 DOM（仅对 `Element` 孩子），把每个元素的 `css` 写成 `style` 属性；与用户已有 `style` 合并时编译器 CSS 在前、用户值在后（后写覆盖先写，故用户优先）。
