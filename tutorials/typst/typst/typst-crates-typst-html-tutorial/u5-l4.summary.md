本讲讲清 typst-html 中「为被文档内链接指向的元素分配可跳转锚点（fragment ID）」的事后步骤。入口 create_link_anchors 在编译主链路末尾运行：link_targets() 算出被链接目标，遍历 DOM 挂 id，再 set_anchors() 写回内省器，整个过程就地改写 DOM。

核心是三套机制。Work 队列用 enqueue/drain/remove 把被链接元素与其首个真实 DOM 节点对应：drain 将全部欠条结算到首个节点，故嵌套的被链接元素共享同一 id；remove 为「不产生任何节点」的元素在 Tag::End 之后插入空 span 兜底。traverse 对 Tag::Start/Tag::End/Element/Text/Frame 五类节点分派，文本被包进 span、元素挂 id 后递归进孩子。AnchorGenerator 优先用合法且唯一的 Typst 标签作 id，重复标签加 -序号，无标签或非法标签走 loc-序号，disambiguate 防与已存在标签撞名，assign 还尊重元素已有的 id。traverse_frame 处理 html.frame 内的链接，把内省器算好的帧内坐标与 id 配对存入 HtmlFrame.anchors，编码时交给 SVG 生成器。

引入的关键术语包括：文档内链接、锚点 ID、Tag::Start/Tag::End 内省哨兵、Work 欠条队列、AnchorGenerator 及其 identify/assign/disambiguate、HtmlFrame.anchors 与 InnerHtmlPosition::Frame。
