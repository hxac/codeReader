本讲讲解 typst-html 如何把 Typst 的 table/image 映射为 `<table>`/`<img>`，聚焦 rules.rs 的两条 show 规则 TABLE_RULE 与 IMAGE_RULE。核心结论：表格导出不重新解析，而是接手 typst-library 已算好的 CellGrid IR——`show_cellgrid` 用 chunks 切行、drain 切段，按 footer→连续表头→主体顺序产出 `<tfoot>`/`<thead>`/`<tbody>`；从首行起连续的表头进 `<thead>`，中间或断开的表头降级为 `<tbody>` 内的 `<th>` 行（由 take_while 判定）。has_gutter 时表头/页脚范围须经 /2 与 div_ceil(2) 做物理与逻辑行号换算。`show_cell` 借 Entry::as_cell 过滤合并占位（Entry::Merged），并以 (n != 1) 惯用省略值为 1 的 colspan/rowspan。图片导出把 Image 归一为复用自 typst-svg 的 WebImage（Exchange 直接复用字节、Pixel 重编码为 PNG、PDF 转为 SVG），再编码成 data: base64 URL 嵌入 `<img>`；HTML width/height 属性取整数像素供浏览器占位，CSS 样式控制最终显示尺寸，二者相互独立，相关函数均经 comemo 缓存。
