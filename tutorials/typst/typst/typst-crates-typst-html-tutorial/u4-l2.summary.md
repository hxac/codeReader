本讲解析 typst-html 如何用 CSS `display` 属性把 Typst 的 `block`/`box` 意图翻译成浏览器的块级/行内渲染，只涉及两个文件：`property.rs` 的 `Display` 枚举与 `default_for` 查表，以及 `convert.rs` 的提升函数。`Display` 枚举按 CSS Display Level 3 与 MathML Core 分组，`as_str()` 负责序列化（注意 `inline math`/`block math` 带空格）；`default_for(tag)` 是 HTML 规范 §15 用户代理样式表的 Rust 翻译，未知标签返回 `None`，它是所有提升决策的驱动源。`set_display` 只写编译器的 `css` 字段、不碰用户 `attrs`，最终由 `resolve_inline_styles` 合并。提升核心是：`to_lone_element` 用 `split_prefix_suffix` 剥掉首尾内省 `Tag`、判定内核是否恰为单个元素，是就地改 display 的前提；`make_block_level` 把行内（含未知标签）升为 `Block`、行内数学升为 `BlockMath`，对 `Ruby`/表格内部等无法提升的值返回 `Err(Unblockable)`，交由 `handle_block` 兜底外包 `<div>`；`make_inline_level` 总成功，多靠清 display 恢复默认。数学公式依 `<math>` 的 HTML `display` 属性而非 CSS 区分块级/行内。设计原则是：能就地改就改，不能改就外包中性容器，绝不破坏语义化 display 值。
