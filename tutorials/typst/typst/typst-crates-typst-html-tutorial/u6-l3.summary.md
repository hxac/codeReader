本讲深入 typst-html 的 typed.rs，讲清类型化 HTML 属性的值如何被校验并序列化。核心是 `AttrType` 枚举：它充当属性类型的动态分派中心，经 `const fn convert` 把规范静态类型 `data::Type` 翻译成五个可执行变体 `Presence / Native / Strings / Union / List`，统一暴露 `input / castable / cast` 三个查询接口；其中 `cast` 返回 `Option<EcoString>`，`None` 表示省略该属性。关键 trait `IntoAttr: FromValue` 把职责切成校验（复用 Typst 的 `FromValue`）与字符串化（`into_attr`）两段，`Native` 变体由三个函数指针组成的虚表 `NativeType` 支撑。本讲重点区分四种布尔编码：`Presence` 传 `false` 即省略属性，而 `TrueFalseBool / YesNoBool / OnOffBool` 的假仍写字面量。`ListType` 把 Typst 数组用空格或逗号拼成 token 串，主动拒绝含分隔符的项（HTML token 无转义机制），逗号规范化为 `", "`，`shorthand` 允许单值简写。此外 `UnionType` 取首个匹配成员委托转换，`StringsType` 用 `[start, end)` 切片索引全局 `ATTR_STRINGS` 表建模枚举，`Duration`、`Datetime`、`IconSize`、`HorizontalDir`、`ImageCandidate`、`SourceSize` 则按 WHATWG/HTML 规范格式定制序列化。
