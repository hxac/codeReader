`html.frame`（`FrameElem`）是 typst-html 的「保真逃生舱」：不把内容翻译成 HTML 标签，而是交给分页排版引擎布局后以内联 SVG 嵌入，适合图表等依赖精确定位的内容。它走过四站：`handle` 分支临时把 `Target` 切回 `Paged` 并在无限大区域调 `layout_frame`（为防 `show …: html.frame` 无限嵌套，`FrameElem` 自身被注册为 Paged 下的 no-op）；结果包成 `HtmlFrame` 节点；最后由 `write_frame` 委托 `typst_svg::svg_in_html` 生成 SVG，并刻意生成后再补缩进以保证产物可缓存复用。关键术语：`HtmlFrame` 五字段中 `text_size`（调用点字号）用于把帧绝对尺寸折算成 em（`width=frame.width()/text_size` em），使 SVG 随外层字号等比缩放、帧内外文字比例自洽；`anchors`（由 `traverse_frame` 填充、`render_anchor` 渲染为 `<g id transform>` 锚点）让文档内链接能精确跳进 SVG 内部；`html_span_filled` 是服务于代码高亮的 HTML 文本着色临时方案，体现语义化与可控性的取舍。
