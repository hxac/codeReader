本讲讲解 typst-html 如何将 Typst 公式转换为浏览器可渲染的 MathML Core 元素。核心结论：typst-html 不重新解析公式，而接手 typst-library 的 `MathItem` IR——它与分页导出共享同一份公式分析，分叉点在 `resolve_equation` 之后。唯一数学 show 规则 `EQUATION_RULE` 取 IR、调转换器、包成 `<math>`（块级带 `display="block"` 且外套 BlockElem）。转换入口 `convert_math_to_nodes` 极薄，承重的是 `MathContext` 状态机与 `CssContext` 三轴（math_style / math_shift / math_depth），仅在子元素目标上下文与当前不一致时才输出属性以保持简洁。IR 到 MathML 有明确对照：Fraction→`<mfrac>`、Radical→`<msqrt>`/`<mroot>`、Scripts→`<msub>` 等、Table→`<mtable>`，叶子映射为 token 元素，`make_mo` 按「与算符字典默认值不同才写属性」生成 `<mo>`。`EQUATION_CSS_STYLES` 是按需注入 `<head>` 的 CSS，覆盖 MathML Core UA 样式在对齐、表格缩放、多行行距、分数留白、重音 dtls 上与分页导出的偏差。本讲引入的关键术语：MathItem IR、MathContext 状态机、CssContext 三轴、UA stylesheet、算符字典、`EQUATION_CSS_STYLES`。
