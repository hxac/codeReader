本讲解读 typst-html 的 `tag.rs`，它分两层：上百个通过 `HtmlTag::constant` 在编译期驻留的预定义标签常量（含 `mathml` 子模块），以及一组按 HTML 规范整理的分类函数。后者分三组：一是**语法分类**（`is_void`/`is_raw`/`is_escapable_raw`/`is_foreign`，对应规范 §13.1.2），直接驱动 `encode.rs` 的自闭合与编码路径、`convert.rs` 的空白模式（`script/style/textarea/title` 强制 `Pre`）、`typed.rs` 的 body 参数生成；二是**内容模型分类**（`is_flow_content`/`is_phrasing_content` 等，对应 §3.2.5.2），彼此不互斥，当前多作忠实于规范的公共 API 保留，唯 `is_metadata_content`/`is_phrasing_content` 被内部复用；三是建立在 `Display::default_for` 之上的**非标准分类**（`is_whitespace_collapsing`/`should_group_into_pars`/`is_replaced`），把内容模型与渲染层级粘合，分别服务空白保护状态机与段落分组。核心结论：须区分「规范分类」（结构）与「display 渲染」二者正交；阅读分类函数须检索调用点，方能区分「真正生效」与「定义待用」。
