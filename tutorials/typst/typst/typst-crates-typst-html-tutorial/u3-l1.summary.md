本讲走通 typst-html 的编译主链路，即把一份 Typst `Content` 转换为 `HtmlDocument`。主链路由三层函数构成：外层 `html_document` 拆解带可变状态的 `Engine`，中层 `html_document_impl` 以 `#[comemo::memoize]` 作为缓存边界，内层 `html_document_common` 真正干活并被 bundle 路径复用；memoize 只包在中层，以隔离副作用与可变状态。

核心 `html_document_common` 依次执行 realize → convert_to_nodes → finalize_dom → resolve_inline_styles → 方程 CSS 注入 → `HtmlDocument::new`，其中内联样式必须在 finalize_dom 之后解析，因为后者会新增带样式节点。引入的关键概念有：realize 借 `RealizationKind::Document { info }` 边具象化边收集文档元信息，根级样式须经 `styles.outside()` 标记才能在文档级合法使用；`DocumentInfo` 由 `populate` 与 `populate_locale` 按需填充；含数学公式时用内省查询判定 `has_equations`，条件性向 `<head>` 注入 `EQUATION_CSS_STYLES`。创建 `HtmlDocument` 后，中层还做 `create_link_anchors` 与 `set_anchors` 两步锚点后处理，bundle 路径则跳过。
