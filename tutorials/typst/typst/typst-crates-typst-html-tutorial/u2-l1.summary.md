本讲定义 typst-html 的 DOM 数据骨架，仅涉 dom.rs 与 document.rs 两个文件，拆为五个最小模块。HtmlNode 是 DOM 节点的统一枚举，四变体 Tag/Text/Element/Frame 分别承担内省元数据、纯文本、嵌套元素与内联 SVG；其中 Tag 不产生 HTML 输出，仅供内省。HtmlElement 为承重类型，七字段分三组：内容组（tag、attrs、children）、样式组（css，编译器生成、与用户 style 分开存放）、元信息组（parent、span、pre_span），用消费 self 的 builder 链构造。HtmlOutput 以扁平节点数组加 root_index 表示文档而非显式树，因用户自带 html 元素时根元素前可能排着内省 Tag。HtmlSliceExt::iter_with_dom_indices 是状态机，把数组下标对齐到真实 DOM 孩子序号：Tag 不前进、相邻 Text 共享序号、结构节点结清文本组后前进。HtmlDocument 是编译最终产物，封装 output、info 与 Arc 内省器，实现 Output 转发 html_document，但不实现 Hash，因内省器不可哈希且 root_mut 会事后改 DOM，故 comemo 缓存只包在 html_document_impl 层。前置概念：EcoVec/EcoString 为写时复制容器，HtmlTag 内部是驻留的 PicoStr。
