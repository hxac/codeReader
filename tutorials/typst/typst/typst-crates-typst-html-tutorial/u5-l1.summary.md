本讲覆盖 typst-html 的最小模块 `encode.rs`，核心是把内存中的 DOM 树序列化成合法 HTML 字符串，即编译主链路的「最后一公里」。入口 `html()` 与 `html_in_bundle()` 共用 `html_impl`，后者无条件注入 `<!DOCTYPE html>` 以保证标准模式，再递归编码根元素。关键术语包括：携带 `buf`/`level`/`link_resolver`/`pretty` 四字段的 `Writer` 状态机；按 HtmlNode 四变体分派的 `write_node`（其中 `Tag` 节点不产出 HTML）；处理属性空值简写、void/foreign 自闭合的 `write_element`；由 `allows_pretty_inside`（规范驱动，基于 display）与 `wants_pretty_around`（叠加偏好）配合 `indent` 游标决定换行的 `write_children` pretty 算法。核心结论：换行只在块级子元素前后插入以避免破坏行内渲染；`escape=pre_span` 把空白保护 span 编码为数字字符引用；raw 文本元素经 `find_closing_tag` 防注入，Frame 节点交由 `typst_svg::svg_in_html` 生成内联 SVG 并按行重缩进。
