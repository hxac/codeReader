本讲从目录层面剖析 typst-html 的模块组织。crate 共有 18 个源文件，由 `src/lib.rs` 顶部的模块声明串成骨架：其中 **3 个公开模块**（`attr`、`property`、`tag`）都是供外部按名字引用的常量表（标签、属性、类型化 CSS 属性）；其余 **12 个私有模块**（`convert`、`document`、`dom`、`encode`、`fragment`、`introspect`、`link`、`mathml`、`rules`、`charsets`、`typed` 及 `css`）承担内部实现。核心组织手法是 **门面模式**：私有模块保持隐藏，由 `lib.rs` 用一组 `pub use` 把少数对外类型/函数（如 `html_document`、`html`、`HtmlIntrospector`、`register`）重新暴露到 crate 根。其中 `pub use self::dom::*;` 实现了"模块私有、类型公开"，使 `HtmlElement` 等数据模型类型可经 `typst_html::HtmlElement` 使用，内部重构也不破坏 API。`css` 是唯一的目录型私有模块，三层组成：`mod.rs` 汇总重导出、`encode.rs` 做 Typst→CSS 类型序列化、`resolve.rs` 把样式写成内联 `style` 属性。本讲引入的关键术语包括公开/私有模块、门面模式、模块私有而类型公开，并按数据流将文件归为数据模型、编译主链、规则与特殊内容、样式、输出与内省五组，为后续逐字段精读 `dom.rs` 等奠定导航基础。
