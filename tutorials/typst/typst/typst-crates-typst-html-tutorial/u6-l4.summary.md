本讲解释 typst-html 缓存层：comemo 的 `#[comemo::memoize]` 以**参数哈希**为键缓存返回值，故返回类型无需 `Hash`，但每个参数都必须可哈希，且函数须近似纯函数。由此引出**三层夹心**：公开入口拆解 `&mut Engine` → `_impl`（缓存边界）→ `common`（共享实现，含 bundle 复用）。`Engine` 的六字段须逐个转成 `Tracked`/`TrackedMut`（`world/library/introspector/traced/sink/route`）才能进缓存键，少一个即脏缓存。`HtmlDocument` 故意不实现 `Hash`：其内省器既不可哈希、也不全由输出派生（`root_mut` 用于交叉链接，对应 issue #7951），但这不影响它被缓存，仅使其不能再作别的 memoize 参数；锚点注入等副作用被折叠进 `_impl` 体，只在未命中时跑一次。片段层面，`html_block_fragment_impl` 因独立定位子树与自建 `SmartQuoter` 可缓存，而 `html_inline_fragment`/`html_math_fragment` 借共享 `&mut SplitLocator` 与 `&mut SmartQuoter`、输出非纯函数而不可缓存；三者均先 `check_html_depth`（上限 72）。
