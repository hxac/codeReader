本讲从使用者视角讲解 typst-html 暴露的两个用户侧原生元素。`html.elem`（`HtmlElem`）是手写任意 HTML 标签的万能逃生舱，由 `#[elem]` 定义并经 `module()` 注册，也是 `html.div` 等类型化构造函数的底层基础；其字段分用户可见组（必填的 `tag`、`#[fold]` 可叠加的 `attrs`、可选 `body`）与内部组（`css`、`parent`、`role`）。`tag` 经 `HtmlTag::intern` 做合法性校验，含连字符的标签被判为自定义元素。`with_attr`/`with_optional_attr` 是面向 Rust 的 builder 方法，便于程序化、按条件添加属性。`html.frame`（`FrameElem`）将内容切回 `Target::Paged` 排版成 Frame，连同 `text_size` 等元数据封装成 DOM 节点 `HtmlFrame`，最终以内联 SVG 嵌入，保证视觉保真。核心结论：`html.elem` 语义优先、`html.frame` 保真优先，二者共同决定用户对「结构 vs 图像」的全部控制权。

需要说明：讲义中的代码示例存在明显笔误，特别是括号不匹配（如 `#box baseline: 0pt)[A]`），实际编译前应修正为合法 Typst 代码（`#box(baseline: 0pt)[A]`）。
