本讲是 typst-html（Typst 的 HTML 导出器）学习手册开篇，只读源码建立全局认知。typst-html 输入已排版的 Typst 文档内容（Content/Document），输出合法 HTML 字符串，内部先把文档转成 HTML DOM 树再编码。它依赖 7 个 typst-* 兄弟 crate：typst-svg 提供运行时能力（图片转 base64、把内容渲染成内联 SVG），typst-assets 提供 HTML 规范数据以自动生成 html.div 等类型化构造函数；它与 typst-pdf 互不依赖，二者是平级导出器。版本上 html.elem/html.frame 自 0.13.0、类型化 API 自 0.14.0 引入，当前工作区为 0.15.1。

本讲精读三个基础积木：module() 是标准库模块组装入口，注册 HtmlElem、FrameElem 并经 typed::define 批量注册类型化函数，本身不参与导出主线（html_document 编译成 HtmlDocument，再由 html 序列化成字符串）。HtmlElem（html.elem）让用户手写任意 HTML 元素，含 tag/attrs/body 字段，若用户自建 html/body 标签则 Typst 省略自动生成的外层标签；FrameElem（html.frame）把内容经排版引擎布局后以内联 SVG 嵌入，底层依赖 typst_svg::svg_in_html。关键术语：HTML DOM 树、Module/Scope、原生元素（#[elem]）、类型化构造函数、HtmlTag/HtmlAttrs、内联 SVG、导出主线。
