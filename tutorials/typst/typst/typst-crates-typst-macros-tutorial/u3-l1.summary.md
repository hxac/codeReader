本讲是 `#[func]` 宏系列第一部分，专注「解析」阶段，源码仅涉及 lib.rs、func.rs、util.rs。核心是 func::parse 把 `#[func(..)]` 元数据（Meta）与 syn::ItemFn 翻译成 Func 中间结构。关键术语：Meta（函数级元配置）、Func（完整画像）、Param、SpecialParams、Binding（Owned/Ref/RefMut，仅对 self 有意义）。参数被分两类：运行时特殊参数（self/engine/context/args/span）进 SpecialParams，普通用户参数进 params；其中 engine/context/args/span 纯按名字识别、不看类型，self 接收者必须有 parent，否则报错。普通参数的四种属性 `#[named]`/`#[default]`/`#[variadic]`/`#[external]` 被取出后用 validate_attrs 兜底。「positional 且 required」是默认行为，由 `positional=!named`、`required=!named && default.is_none()` 在代码生成阶段派生，解析阶段只记录 named 与 default 两个原始事实。本讲只做读懂输入，下一讲（u3-l2）的 create 才消费这些中间数据生成 NativeFuncData 与包装闭包。
