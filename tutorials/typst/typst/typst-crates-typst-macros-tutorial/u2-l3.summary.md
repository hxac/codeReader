本讲覆盖 `typst-macros` 的 `cast!` 函数式过程宏，它是连接 Rust 强类型与 Typst 运行时统一 `Value` 的双向转换桥梁，自动生成 `Reflect`、`IntoValue`、`FromValue` 三个 trait 的 impl。输入语法分三段：目标类型（可带 `type` 前缀）、可选的 `self => expr` 转出臂、若干 `pattern => expr` 转入臂，解析为中间结构 `CastInput`。转入臂有两种模式：`Pattern::Str`（字符串字面量匹配）与 `Pattern::Ty`（`绑定: 类型` 匹配，可递归委托）。`type` 前缀置 `dynamic = true`，同时打开三个 impl 的生成开关。`castable`（廉价布尔预判）与 `from_value`（真正转换）共用同一套判断顺序：dynamic 检查 → 字符串匹配 → 各类型臂按声明顺序 → 兜底，保证二者契约一致。`input` 将每条转入臂翻译成 `CastInfo` 候选，驱动自动补全与错误提示；`output` 在非 dynamic 时复用 `input`。本讲引入的术语 `CastInput`、`Cast`、`Pattern`、`dynamic`、`CastInfo` 将被 u2-l4 `#[derive(Cast)]`（委托 `cast!`）和 u3-l1 `#[func]`（参数需 `FromValue`）承接。
