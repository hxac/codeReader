本讲拆解 `#[ty]` 属性宏如何把 Rust 类型注册为 Typst 类型——它是首个围绕被装饰项生成完整 trait impl 的宏，沿用 parse→create 骨架，源码集中在 `ty.rs`。入口按 `syn::Item` 分流四分支：Struct/Type/Enum 三者 `keep=true` 原样保留原项，Verbatim（裸 `type Name;`，由 `BareType` 解析）`keep=false` 被吞掉。括号参数解析成 `Meta`（scope/cast/name/title/since/keywords 六字段），合并 ident 与文档得中间结构 `Type`；`parse` 推导三个名字：name（kebab 短名）、title（Title Case）、不可配的 long（title 小写，供诊断用）。`create` 用开关拼 `NativeTypeData` 字面量：scope 决定 constructor/scope 来源；cast 标志为 true 表示用户自写 `cast!`、宏便不再补默认的 `cast! { type #ident, }`，否则会与手写版重复生成 Reflect/IntoValue/FromValue。生成 `impl NativeType` 时，`data()` 用 `static DATA` 满足 `&'static` 返回，constructor/scope 用 `LazyLock` 延迟求值以规避类型间互引用的初始化顺序问题。本讲为 cast! 函数式宏（u2-l3）与 #[scope]（u3-l3）奠基。
