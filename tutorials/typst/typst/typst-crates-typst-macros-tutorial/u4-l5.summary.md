本讲是 typst-macros 手册收官篇，将七个过程宏（func/ty/elem/scope/cast/derive_cast/time）统一到同一架构图下。核心结论：七宏共用「parse 解析成中间结构（Func/Elem/Type 等）→ create 用 quote! 生成」的两段式骨架，入口共享「解析→转发→to_compile_error 兜底」三行模板。本讲引入的关键概念包括：trait 契约——宏在编译期产出、运行时 typst_library::foundations 消费，靠 NativeFunc/NativeType/NativeElement/NativeScope 等 trait 签名对接，foundations 是 util.rs 定义的、展开为绝对路径的路径简写；DefSite 与 def_site_key 用「文件内唯一键」（类型名、函数名、父::子、父::方法::参数）而非行号定位定义点，抗宏展开扭曲与源码编辑；static DATA 承载编译期常量以满足 &'static，LazyLock 包裹跨类型引用或需运行时求值的字段以规避初始化顺序问题；错误处理铁律是绝不 panic，用 bail! 造带 span 的错误并回传为编译错误。整体架构定性为「重代码生成 + 运行时 trait 契约」：换来零反射开销与强类型校验，代价是宏实现复杂、编译开销增加。
