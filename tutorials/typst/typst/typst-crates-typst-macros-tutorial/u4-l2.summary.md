本讲承接 u4-l1，进入 `#[elem]` 宏代码生成第一站——结构体改写与构造方法，代码集中于 `src/elem.rs`。

`create` 输出两段：裸 struct 置模块顶层，所有 impl 包进 `const _: () = { ... };` 匿名作用域，防止宏内部辅助定义泄漏进用户命名空间。

字段在生成 struct 里有三种存储形态：required 用裸类型，synthesized 用 `Option<ty>`，普通 settable 用 `Settable<Self, I>`（其中 const generic 索引 I 使每个 settable 字段成为唯一单态化类型，是后续 vtable 槽位定位的基础）；ghost 与 external 不进 struct。`new()` 仅以 required 字段为参数，函数体按三态分别用取参数、`None`、`Settable::new()` 初始化全部字段。`with_X` 链式构造器仅为非 required 的 struct 字段生成，settable 调 `.set()`、synthesized 用 `= Some(...)` 赋值。Field 常量（`Field<Self, I>` 句柄，如 `Self::columns`）为所有非 external 的 real_fields 生成（含 ghost、synthesized），单独置于带 `#[expect(non_upper_case_globals)]` 的 impl 块。

关键术语：字段三态（required/synthesized/settable）、`Settable<Self, I>`、const generic 索引、字段过滤器链（real_fields ⊃ struct_fields ⊃ accessor_fields）、Field 常量句柄、`const _` 匿名作用域。本讲不涉及 vtable 注册（u4-l3）与 Construct/Set 解析（u4-l4）。
