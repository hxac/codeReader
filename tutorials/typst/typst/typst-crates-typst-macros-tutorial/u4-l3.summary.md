本讲覆盖 `typst-macros/src/elem.rs` 中 `#[elem]` 宏的「注册」环节，承接 u4-l2 生成的可构造 Rust 类型，把它登记进运行时的虚表体系。核心结论：`create_native_elem_impl` 生成 `unsafe impl NativeElement`，产出 `const ELEM: Element = Element::from_vtable(&VTABLE)`，其中 `VTABLE` 是 `static ContentVtable`，由 `ContentVtable::new(..).with_*(..).erase()` 组装，运行时凭 vtable 指针完成元素的构造、set、clone、能力查询。Typst 弃用 `dyn Trait` 而手写自定义 vtable，是为了容纳字段子虚表切片并静态存纯数据，使 `is` 判断退化为指针比较。

引入的关键概念：元素的字段在 vtable 中由二元组描述——`fields: &[FieldVtable]` 切片按下标 `u8` 取槽位，`field_id` 闭包把字段名翻译成索引（编译期 `match` 利于优化）。切片槽位经六路分支选定 `XxxFieldData::<Self, i>::vtable()`（external/variadic/required/synthesized/ghost/普通 settable）。`create_field_impl` 为每个字段生成对应 trait impl 与 `FIELD` 常量，通过 const generic 索引 `I` 与 u4-l2 的 `Field::new()` 句柄相连。

settable 字段三个条件项：每字段独立 `OnceLock` slot 缓存默认值、`with_fold`（仅 `#[fold]`）、`RefableProperty`（仅非 fold），后二者由 `field.fold` 与 `!field.fold` 反向控制而互斥——折叠字段最终值需合并整条样式链，无法给出稳定引用。能力系统由 `create_capable_func`（`FORBIDDEN` 名单过滤后用 `NonNull::dangling()` 悬垂胖指针安全提取原生虚表）与 `create_introspection_capabilities`（`Locatable`/`Unqueriable`/`Tagged` 三布尔，校验 `Unqueriable` 必须搭配 `Locatable`）组成。本讲不展开 `construct`/`set` 函数体（留待 u4-l4）。
