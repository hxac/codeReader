本讲讲派生宏 `#[derive(Cast)]` 如何为枚举生成字符串↔变体的双向转换。核心模块有三：一是入口接收 `DeriveInput`，原枚举项原样保留、只追加 impl（与函数式宏 `cast!` 消费宏体根本不同），且硬约束只支持枚举；二是中间结构 `Variant { ident, string, docs }`——字符串默认取变体名的 kebab-case，可用 `#[string("...")]` 覆盖，带显式 discriminant 的变体被 `bail!` 拒绝（转换只认名字，fail fast）；三是遍历一次生成两个方向：`strs_to_variants` 产字符串→变体的转入臂（即 `cast!` 的 `Pattern::Str`），`variants_to_strs` 产变体→字符串的 match 臂，二者共用同一份映射表保证正逆一致。核心结论：`derive_cast` 自己不写任何 impl，只拼出一句带 `foundations::` 路径前缀的 `cast!` 调用，把 `Reflect`/`IntoValue`/`FromValue` 的生成委托回 u2-l3 的 `cast!`，实现一次实现、两处复用。
