typst-macros 是 Typst 的过程宏 crate，在编译期把 Rust 代码翻译并注册成 Typst 运行时能识别的函数、类型、元素，核心是「代码生成 + 运行时 trait 契约」。它依赖 syn（解析）、quote（生成）、proc-macro2（桥接）、heck（命名转换）四个 crate。

对外暴露七个宏：属性宏 func/ty/elem/scope/time、函数式宏 cast、派生宏 derive_cast，分别实现 NativeFunction、NativeType、NativeElement、NativeScope、Reflect/FromValue/IntoValue 等 trait。入口共享同一模板：parse_macro_input! 解析 → 调用对应子模块 → 出错用 to_compile_error 回传而绝不 panic。

配置层面，Cargo.toml 的 [lib] proc-macro=true 是过程宏 crate 的身份证；lib.rs 顶部 extern crate proc_macro 链接编译器内置 crate，#[macro_use] mod util 使工具宏对后续模块可见，BoundaryStream 别名点明编译器 TokenStream 与 proc-macro2 TokenStream 的转换边界；func 能生成与函数同名的空 enum，得益于 Rust 值命名空间与类型命名空间互不冲突。
