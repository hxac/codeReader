本讲讲解 typst-macros 七个入口共享的工作流骨架，仅涉 lib.rs 与 util.rs。三类过程宏各有定式：属性宏（func/ty/elem/scope/time）双参 stream+item，函数式 cast 单参 stream，派生 derive_cast 单参 item；约定 stream 指属性参数或宏调用体，item 指被装饰/派生的真实代码项。关键术语 BoundaryStream 是编译器 TokenStream 的别名，标记类型边界：入口用 .into() 转入 proc_macro2 版 TokenStream（syn/quote 仅认它，且利于单元测试与 span 定位），返回再转回。解析靠 parse_macro_input! 把 token 流结构化为对应 syn 语法树节点，失败则自动生成编译错误并提前返回。错误回传统一为：子模块返回 syn::Result，用 util.rs 定义、经 #[macro_use] 暴露的 bail! 宏造带 span 的 syn::Error，入口以 .unwrap_or_else(|err| err.to_compile_error()) 转成 compile_error!，全程绝不 panic。
