本讲梳理 Clang 源码骨架，确立「库优先」核心设计：编译器被拆成 lib/ 下 30 余个子库（clangBasic、clangLex、clangAST、clangSema、clangCodeGen、clangFrontend 等），按依赖顺序在 lib/CMakeLists.txt 注册，分为基础层、前端管线、编排层、工具扩展、静态分析五层。include/clang 与 lib/ 近乎一一镜像——头文件是公共 API，lib 是实现；两个例外是 lib/Headers（编译器自带 C/C++ 头，无对应 include）与 include/clang/Config（构建期生成 config.h，无对应 lib）；include/clang-c 则是 libclang 的稳定 C ABI。tools/ 产出可执行程序，driver 构建 clang 主程序并派生 clang++/clang-cl 等符号链接，工具「胖瘦」取决于复用的子库多少；add_clang_library、add_clang_tool 是关键构建宏。
