本讲通过阅读 README.md、docs/index.rst、CMakeLists.txt 三个入口文件，建立 Clang 的整体认知，覆盖三个最小模块。

**项目定位**：Clang 是 LLVM 项目中负责 C/C++/Objective-C（C 家族语言）的编译器前端，核心任务是让计算机"读懂"源代码，并把源码翻译成 LLVM IR；它不负责优化与生成机器码。其内部流水线为 Lex（词法分析，切 Token）→ Parse（语法分析，构建 AST）→ Sema（语义分析，类型与名字检查）→ CodeGen（生成 IR），是后续讲义的主干。

**与 LLVM 的关系**：Clang 是 LLVM 的子项目，构建期单向依赖 LLVM 的库与 llvm-tblgen 工具，运行期把 IR 交由 LLVM 中端/后端处理；它用 C++17 编写，且是 LLVM 与 libc++ 的自举编译器。

**工具生态**：Clang 不只是编译器，更是一个源码级工具平台——它把词法、AST、语义等能力封装为可复用的 C++ 库，并提供稳定 C 接口 libclang，由此衍生出静态分析器、clang-format、clang-tidy、代码索引、重构等工具。文档据此分为编译器/库/工具/设计四类。

本讲引入的关键术语：前端、LLVM IR、AST、Lex/Parse/Sema/CodeGen、libclang、LibTooling、ASTMatchers、Clang Transformer、TableGen、子项目，供后续讲义承接。
