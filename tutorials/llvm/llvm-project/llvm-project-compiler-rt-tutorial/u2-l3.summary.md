本讲讲解 compiler-rt 软浮点内建函数：目标平台无 FPU 或缺相应指令时，编译器插入这类用纯整数运算模拟浮点的函数。地基是 fp_lib.h 的 toRep/fromRep（用 union 把浮点位当整数）与由尾数位数派生的位掩码（implicitBit、significandMask、infRep、qnanRep），据此区分规格化数、次正规数、无穷与 NaN。算术代表 __addsf3 的真身是参数化的 __addXf3__，核心三步为：对齐阶码（移出位压缩成 sticky 位）→ 尾数同号相加、异号相减 → 规格化并按舍入模式取整，左移 3 位腾出 round/guard/sticky 三件套，是正确实现「就近、偶数优先」舍入的关键。转换类 __floatdidf 与 __fixdfdi 用 __SOFTFP__ 切分硬件路径（2^52 技巧、可设 FP 标志）与软浮点路径（纯位运算、复用 __floatXiYf__/__fixint），因为即便有 FPU 也未必有 64 位整数与浮点互转的单条指令。clz 规格化、无分支取绝对值等手法承接上一讲整数内建。
