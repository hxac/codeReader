compiler-rt（Compiler Runtime）是 Clang/LLVM 工具链的运行时支撑库，专门提供「编译器在生成机器代码时插入调用的那些帮手函数」（如 32 位机上做 64 位除法时插入的 `__udivdi3`）。它是 GCC libgcc 在 LLVM 工具链中的对应物，与 libc 职责不重叠：libc 管程序员主动调用的标准函数（printf/malloc），compiler-rt 管编译器偷偷插入的运行时函数。它并非单一库，而是一组约 28 个可裁剪的子库，按用途分为 builtins（低级运算帮手）、sanitizer 家族（内存/线程/UB/专用检测器及公共设施 sanitizer_common、interception）、加固与分配器（cfi、safestack、scudo、gwp_asan）、剖析覆盖率（profile、ctx_profile）、libFuzzer、XRay、ORC、BlocksRuntime 等。顶层 CMakeLists.txt 用 `COMPILER_RT_BUILD_*` 开关控制构建范围。项目采用维护者负责制（见 Maintainers.md，条目与子库非一一对应），许可证为 Apache-2.0 + LLVM Exception（另有历史 UIUC/MIT 双许可），允许静态链接后分发。本讲为后续逐模块深入提供全局地图。
