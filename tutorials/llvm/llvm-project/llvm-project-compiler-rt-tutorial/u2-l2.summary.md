本讲解读 compiler-rt `lib/builtins` 中 64 位整数运算的可移植兜底实现，服务于缺少 64 位除法/乘法/移位/位计数硬件指令的 32 位目标。贯穿全讲的技巧是用 `dwords`/`udwords` 联合体把 64 位数拆成高、低两个 32 位「字」。除法采用二进制长除法（shift-and-subtract）：无符号 `__udivdi3` 经内联 `__udivXi3`，有符号 `__divdi3` 转发按字分解的 `__udivmoddi4`，两者均先以 clz 估商位数、用分支无跳减法逐位定商。乘法 `__muldi3` 用 `__muldsi3` 拆 16 位半字实现 32×32→64 再以交叉项组合出低 64 位。移位 `__ashldi3`/`__lshrdi3` 靠「跨字搬运」并规避移位量等于位宽的未定义行为。位计数 `__clzdi2` 用掩码无分支选高/低字并加偏移，底层 `__clzsi2` 用二分实现，并演示了重定义 `__builtin_clz` 以切断编译器 lowering 自指递归的技巧。clz、分支无跳、字分解是贯穿 builtins 并将由后续软浮点讲义承接复用的三大核心手法。
