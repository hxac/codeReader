本讲讲解如何用 CMake 构建 compiler-rt。顶层 `CMakeLists.txt` 是一条「判别构建模式→声明组件开关→探测平台能力→挂载子目录」的配置流水线，核心结论是：最终构建范围等于「用户意图」与「工具链能力」的交集。组件开关 `COMPILER_RT_BUILD_*`（默认全开）表达意图，由 `lib/CMakeLists.txt` 翻译成 `add_subdirectory`；`config-ix.cmake` 通过试编译/试链接探测出 `COMPILER_RT_SUPPORTED_ARCH` 与 `COMPILER_RT_HAS_*`，构成 `compiler_rt_build_runtime()` 内的第二道闸门。三种构建模式各有判据：in-tree 靠 `LLVM_TREE_AVAILABLE`、standalone 需 `load_llvm_config()` 定位已安装 LLVM（依赖 `LLVM_CMAKE_DIR`）、runtimes 靠 `LLVM_RUNTIMES_BUILD` 识别。`base-config-ix.cmake` 拼装输出/安装路径，库目录默认带 `lib/<os>` 段（Android 映射为 `linux`），产物落入 Clang 资源目录。引入的关键术语：target triple、Clang 资源目录、`COMPILER_RT_SANITIZERS_TO_BUILD`、`COMPILER_RT_INCLUDE_TESTS`。本讲为后续运行测试与读源码的前置。
