本讲承接项目总览，讲清 LLVM 如何用 CMake 把源文件构建成 opt、llc 等工具，不涉及 C++ 逻辑。含三个最小模块：构建树骨架、常用变量与预设、从源码到可执行文件的链路。核心结论：顶层 CMakeLists.txt 管项目、版本、C++17 与输出目录，再用 add_subdirectory 递归挂入各子目录；目录约定为实现进 lib/、头文件进 include/、驱动进 tools/、示例进 examples/，lib/ 各子目录对应一个组件库（如 LLVMCore）；工具与示例用 add_llvm_tool / add_llvm_example 定义，靠 LLVM_LINK_COMPONENTS 声明依赖，产物落 build/bin/ 与 build/lib/。关键术语：构建生成器（推荐 Ninja）、配置→构建→安装、cache 变量、target、组件 component、TableGen/llvm-tblgen、CMAKE_BUILD_TYPE（默认 Release）、LLVM_TARGETS_TO_BUILD（默认 all）、LLVM_ENABLE_PROJECTS、LLVM_ENABLE_ASSERTIONS、INCLUDE_*/BUILD_* 开关对，以及 hidden 预设需本地 CMakeUserPresets.json 继承。
