本讲讲清 LLVM IR 在内存中的四层树状结构：Module → Function → BasicBlock → Instruction。Module 是一段 IR 的顶层容器（本身非 Value），后三者都是 Value。父子间用侵入式链表 SymbolTableList 维持「归属」（销毁父节点即回收整棵子树），子节点借 getParent() 回指祖先，三层 getParent() 可从一条指令一路爬回 Module。基本块必须以恰好一条终结指令收尾，PHI 节点须集中在块首。指令以整数 opcode 分类，各大类占据连续区间，opcode 的真相来源是 X-Macro 文件 Instruction.def，可用 isTerminator/isBinaryOp 等做 O(1) 区间判别；类型识别依赖 Value::SubclassID（ValueTy 枚举）与各类的 classof，配合 isa/cast/dyn_cast。遍历有四种迭代器：逐函数、逐基本块、逐指令，以及跨块扁平的 inst_iterator（instructions(F)）。关键术语 Module/Function/BasicBlock/Instruction、SymbolTableList、终结指令、opcode、Instruction.def、inst_iterator、ValueTy/classof 供后续 u2-l2 类型系统与 Value 承接。
