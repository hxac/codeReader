本讲承接 u3-l1 的新 Pass 管理器骨架，教读者亲手编写一个可被 opt 调用的 pass，围绕 examples/IRTransforms/SimplifyCFG 展开三个最小模块。

一是 PassInfoMixin 与 run 签名：新 PM 无统一 pass 基类，继承 CRTP 的 PassInfoMixin（或 Optional/RequiredPassInfoMixin）即获得 name()、isRequired() 等元信息；run 首参类型决定 IR 单元（Function& 即 FunctionPass），次参是对应的分析管理器，用 FAM.getResult<分析>(F) 取结果，返回 PreservedAnalyses 声明保留集。

二是注册到 pipeline：经 PassPluginLibraryInfo 用 registerPipelineParsingCallback 把名字映射成 addPass（供 -passes=xxx 显式调用），或用扩展点回调（如 registerPipelineStartEPCallback）自动注入默认 -O2 流水线；两者由 extern "C" llvmGetPassPluginInfo 暴露，opt 以 -load-pass-plugin 加载 add_llvm_pass_plugin 产出的 .so。

三是统计与调试：STATISTIC 配 -stats 看全局计数，LLVM_DEBUG 配 -debug-only 看逐函数细节，二者共享文件级 DEBUG_TYPE 标签；综合实践 CountInstPass 将三模块串联落地。
