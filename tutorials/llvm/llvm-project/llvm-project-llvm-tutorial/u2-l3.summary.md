本讲讲解如何用 `IRBuilder` 安全便捷地生产 LLVM IR，承接 u2-l1（四层归属树 Module→Function→BasicBlock→Instruction）、u2-l2（类型系统与 Value）和 u1-l4（ModuleMaker 手工构造）。

核心结论是 `IRBuilder = 自动插入 + 自动折叠`，解决了手工构造的两个痛点。最小模块有三块：一是插入点与折叠机制——插入点由 `BB + InsertPt`（基本块与块内迭代器）共同确定，用 `SetInsertPoint` 设定，`saveIP`/`restoreIP` 或 RAII `InsertPointGuard` 临时切换并还原；折叠由模板参数 `FolderTy` 策略化，默认 `ConstantFolder`（两边皆常量才折叠），可换 `NoFolder`（永不折叠，便于学习与精确控制）。关键细节是 `Insert(Constant*)` 的空操作重载，使「折叠成功就不产生指令」在类型层面自然成立。二是 `Create*` 工厂方法分族——算术（`CreateAdd/Sub/Mul`，可带 `nuw`/`nsw`）、比较（`CreateICmp*`）、控制流（`CreateBr/CreateCondBr/CreateRet`）、调用（`CreateCall`）、聚合（`CreatePHI` 配 `addIncoming`），大多返回 `Value *` 并接受 `Name`。三是 Fibonacci 示例对比——它用手工构造（逐条显式传块）拼递归 fib，IRBuilder 把插入点抽象成状态、写法更短。最终用 `verifyModule` 校验 SSA、终结指令、类型等结构性约束，并完成阶乘函数的构造与位码序列化。本讲为后续 Pass 流水线（变换类 pass 内部普遍用 IRBuilder 重写 IR）奠定直接基础。
