本讲首次把 LLVM 当作 C++ 库来**生产** IR。最小示例 ModuleMaker 从零构造一个只含 `main` 的 Module：先创建 `LLVMContext`（IR 对象的容器与类型唯一性保证）与 `Module`（一段 IR 的根），二者构成树形**归属**——Module 拥有 Function，Function 拥有 BasicBlock，BasicBlock 拥有 Instruction，销毁 Module 即回收整棵树。函数创建遵循「先 `FunctionType` 描述签名、后 `Function::Create`」两步，把父对象作为最后参数即可自动挂接。最关键的 API 模式是**创建指令与插入指令分离**：`BinaryOperator::Create` 只造出游离指令，须再 `Instruction::insertInto` 才挂入基本块；常量用 `ConstantInt::get`，每个基本块以 `ReturnInst` 等终结指令收尾。最后 `WriteBitcodeToFile` 把 Module 序列化为 `.bc`，用 `llvm-dis` 验证。ModuleMaker 只构造不优化，输出保留手写指令，简化须交给 `opt`。后续讲义将承接 `IRBuilder`（手工 insertInto 的升级版）与 `verifyModule`（IR 验证器）。
