本讲讲解同一棵 IR 树在磁盘上的两种等价格式：人类可读的文本 `.ll` 与紧凑二进制的位码 `.bc`，二者可无损互转。核心组件有三：`IRReader`（lib/IRReader/IRReader.cpp）作为统一读取门面，靠文件头魔数（`isBitcode`，原始位码为 `BC 0xc0 0xde`，包装位码为 `0xDE 0xC0 0x17 0x0B`）自动分发；`AsmParser`（Parser.cpp/LLParser.cpp）以「词法+递归下降」解析文本，`parseTopLevelEntities` 按 `define`/`declare`/全局变量等关键字分派；`BitcodeReader/Writer` 用 Bitstream 容器，以 block/record 组织，VBR 变长编码使其紧凑。关键结论：文本格式无法惰性加载且依赖值名字（受 `shouldDiscardValueNames` 限制）；位码把每个函数体独立写入 `FUNCTION_BLOCK` 并记录偏移，从而支持惰性加载（写侧 `writeFunction`、读侧 `parseModule` 跳过、`parseFunctionBody` 按需解码）。错误统一为 `SMDiagnostic`。工具为薄壳：`llvm-as`=AsmParser 读+BitcodeWriter 写，`llvm-dis`=BitcodeReader 读+`Module::print` 写。
