本讲拆解 LLVM-libc 并发同步的四个最小模块：底层锁原语（SpinLock、RawMutex）、Futex 封装、Thread 线程对象、pthread 映射。SpinLock 是纯用户态 TTAS 自旋锁，全程零 syscall；RawMutex 用 UNLOCKED/LOCKED/IN_CONTENTION 三态字配合「先自旋后 futex 阻塞」策略，使无竞争快路径仅一次 CAS、零 syscall，竞争时才阻塞。Futex 把一条 futex 系统调用包成 wait/notify_one/notify_all/requeue_to 四原语，用 FUTEX_WAIT_BITSET 支持绝对超时、靠用户态预检加内核二次比对关闭丢唤醒竞态，并直接调 syscall_impl 裸调用、错误分类自理。Mutex 私有继承 RawMutex，追加 POSIX 递归/检错/owner 跟踪。Thread 用 clone（带 CLONE_CHILD_CLEARTID）创建线程，靠 clear_tid futex 实现 join，用三态 detach_state 协调 join/detach/回收。pthread 入口点全是 reinterpret_cast 薄壳，靠 static_assert 钉死布局一致、把内部 MutexError 翻译成 errno 返回。核心调用链 pthread_mutex_lock→Mutex::lock→RawMutex::lock→Futex::wait→futex 系统调用，每层职责单一、只加一种语义。
