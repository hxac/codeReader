本讲聚焦 LLVM-libc 中字符串与整数互转两个方向，核心结论是「公共算法下沉」：所有 `atoi/strtol/strtoul` 等入口点都只是薄壳，真正逻辑下沉到 `__support`。

字符串→整数由 `__support/str_to_integer.h` 的 `strtointeger<T>` 模板承担，靠模板实参区分返回类型与有无符号；它返回 `StrToNumResult<T>`（同时携带值、错误码、已解析长度），供入口点设置 `errno` 与 `str_end`。关键术语包括「两步阈值预检查」（`abs_max_div_by_base` 与 `abs_max - digit`，在溢出发生前拦截）与「无符号域处理有符号不对称」（`|MIN|=|MAX|+1`）；`infer_base` 按 `0x/0b/前导0` 推断进制。

反向的整数→字符串由 `__support/integer_to_string.h` 的 `IntegerToString<T, Fmt>` 承担，引入 `radix::Dec/Hex/Oct/Bin` 格式族与嵌套导航（`WithPrefix/WithWidth/Uppercase`），采用「反向写入」适配低位优先提取，用 `bit_cast` 解决 `INT_MIN` 取负，栈上定长缓冲保证构造永不失败。

两工具均以 `add_header_library` 注册为内部头文件库，被 stdlib/inttypes/wchar/printf/scanf/strftime 等多处复用，`str_to_integer.h` 更跨项目与 libc++ 共享。其下游消费者以 `printf_core/int_converter.h` 为典型，承接下一讲 u7-l2。
