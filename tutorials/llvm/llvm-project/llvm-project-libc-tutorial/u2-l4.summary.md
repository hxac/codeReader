本讲解析 LLVM-libc 平台配置树 `config/<os>/<arch>/`：它把「某平台支持哪些函数、用何实现」外化为可审查的纯数据/CMake 脚本，使「换平台」≈「换 config 树」。四个最小模块各司其职：`entrypoints.txt` 是支持范围的**事实来源**，用条件块按 Full/Overlay 模式、硬件类型、experimental 开关组装全限定名名单 `TARGET_LLVMLIBC_ENTRYPOINTS`（一阶裁剪），并派生 SKIP 短名名单 `TARGET_ENTRYPOINT_NAME_LIST`；`exclude.txt` 用 `try_compile`/`check_symbol_exists` 做运行环境探测，将不支持项追加到 `TARGET_LLVMLIBC_REMOVED_ENTRYPOINTS` 做二阶裁剪；`headers.txt` 列头文件点分名，Full 模式强制、Overlay 可选回退系统头，与入口点名单解耦；`config.json` 是实现细节旋钮，走「全局→OS→架构」三层覆盖、命令行最高优先，选项须先在全局声明。前三者管「范围（清单）」，后者管「细节（旋钮）」，共同落实入口点生命周期的配置（WHETHER）阶段。
