本讲拆解把单个函数编译进静态归档(.a)的 CMake 规则链。其一，add_entrypoint_object 完成入口点「注册」，输入 SRCS/HDRS/DEPENDS，输出点分全限定名(FQ 名，如 libc.src.ctype.isalpha)的目标，自动追加 __support.common，并构建内部与公开两个 object library。其二，SKIP 机制：函数短名不在由 entrypoints.txt 推导的 TARGET_ENTRYPOINT_NAME_LIST 中时只建空壳目标、不编译，是平台裁剪的第一层。其三，DEPENDS 同时承担构建顺序与头文件路径、编译选项的接口传播，分绝对名与相对名(.开头)两种写法。其四，add_entrypoint_library 把显式列出的入口点连同递归内部对象依赖聚合成 STATIC 归档，隐式入口点依赖不会自动进库；lib/CMakeLists.txt 再按 Full/Overlay 模式产出 libc.a/libm.a/libmvec.a 或 libllvmlibc.a，目标名与产物名经 ARCHIVE_OUTPUT_NAME 解耦，另有脚本层 return() 构成第二层裁剪。
