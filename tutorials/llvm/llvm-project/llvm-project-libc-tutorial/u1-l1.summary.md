LLVM-libc 是 LLVM 项目中**从零开始（from-scratch）、用现代 C++** 重新实现的 C 标准库，定位是一个 **retargetable（可重定向）** 的 libc 实现——即用平台无关的算法实现搭配可替换的平台底层（如 syscall、启动代码），从而能重新瞄准新平台。它给自己定了三大设计目标：**模块化（modular，任一部分可独立使用）**、**多平台（multiplatform，覆盖 Linux/GPU/baremetal/UEFI 等）**、**现代 C++（追求正确性、性能、安全）**；内部用 C++ 但对外仍暴露标准 C 接口。它当前主要面向静态链接场景，与系统 libc 的关系不止「完整替换」，还包括 **Overlay 模式（仅覆盖少数函数做增补）** 与在无 libc 环境里独立提供。文档以「actively used in production」与「coverage is still growing」并置，诚实标明成熟度：它已在静态链接 Linux 服务、GPU（AMDGPU/NVPTX）、baremetal、UEFI 等场景生产使用，但 regex、locale、宽字符 I/O 等尚未实现，无法完整替代通用桌面系统 libc；开发集中在 Linux，macOS/Windows 仅有部分支持。项目采用**首席维护者（Michael Jones）+ 领域维护者（按 baremetal、GPU、math、threading、hdrgen 等划分）**结构，社区入口为 GitHub（libc 标签）、Discourse、Discord 与 Buildbot。本讲仅建立项目认知，不涉及具体代码实现。
