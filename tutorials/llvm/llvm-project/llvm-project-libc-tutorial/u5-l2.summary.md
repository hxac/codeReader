本讲剖析 LLVM-libc 统一管理 `memcpy`/`memset`/`memmove`/`memcmp`/`bcmp`/`bzero` 六个内存函数的 mem\* 框架，含构建块、作用域、尺寸分派、架构特化四个模块。

核心是四个构建块：`block`（起点定宽处理 SIZE 字节）、`tail`（处理尾部 SIZE 字节）、`head_tail`（首尾各写 SIZE）、`loop_and_tail`（循环 `block` 后用 `tail` 收尾）。四者层层组合，只有 `block` 须真正实现，其余是建在 `block` 之上的高阶函数；显式命名同时为各架构提供定制点（customization points）。

作用域为同一构建块提供可替换实现：`builtin`（交 Clang 内建如 `__builtin_memcpy_inline`）、`generic`（纯 C++ 整数/向量扩展，可移植）、架构特化（x86 的 `rep;movsb`、SIMD intrinsic，性能最高但可移植性低），原则是「能 builtin 就不用 asm」。

`memcpy` 入口走两级分派：`inline_memcpy.h` 在编译期按开关与架构选定实现（带 `[[gnu::flatten]]` 内联以消除分发开销），运行期再按 `count` 选不同 SIZE 的构建块——小尺寸 `block`、中等 `head_tail`、大尺寸 `loop_and_tail`。其中 `head_tail` 用两次定宽操作覆盖 (SIZE, 2·SIZE] 区间，首尾重叠写对 `memcpy`/`memset` 幂等无害；`rep;movsb` 则是可配置阈值、默认关闭的整段加速。`memory_utils` 以 `add_header_library` 注册为内部头文件库，延续 `__support` 设计哲学。
