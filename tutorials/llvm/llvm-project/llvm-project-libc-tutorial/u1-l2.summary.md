本讲绘制 LLVM-libc 仓库全局地图，分三个最小模块。其一，顶层目录按关注点拆分：src 放入口点实现，include/hdr 管公共头文件规范与生成，config 用 entrypoints.txt、headers.txt、exclude.txt 表达平台裁剪，lib/startup 负责组装与启动，test/fuzzing/benchmarks 提供质量保障，cmake/utils 是构建规则与工具。其二，src 遵循「按公共头文件名分目录」的导航约定（string.h → src/string/），据此可由函数名推出实现、内部头、镜像测试与平台注册的「四件套」；入口点注册名 libc.src.string.memcpy 即目录路径的点分形式，代码导航与配置共用同一套坐标；src/__support 为不对应任何头文件的私有工具库特例。其三，顶层 CMakeLists.txt 以 FATAL_ERROR 拒绝「根在 libc/」、强制走 runtimes，设定 C++17 标准与内部命名空间 __llvm_libc，按依赖顺序 add_subdirectory 串起各目录，最终在 lib/ 聚合成 libc.a/libm.a（Full）或 libllvmlibc.a（Overlay）。本讲引入的关键术语为后续讲义承接：entrypoint（入口点）、平台裁剪、Full/Overlay 构建模式、runtimes 构建体系、函数「四件套」。
