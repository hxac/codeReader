本讲讲解 LLVM-libc 自带内存分配器的四层结构。BlockRef 是地基，以「prev/next 偏移 + 偷占尺寸低两位做标志位」的紧凑块头切分、合并连续内存，支持带对齐的 allocate，并让已用块吞掉下一块 prev 字段来省空间。FreeList 是同尺寸循环 FIFO 链表，Node 直接 overlay 在块可用空间里；FreeTrie 按尺寸范围二分组成「链表之 trie」，对范围宽度取对数实现 best-fit。FreeStore 按尺寸分级组合二者：小块走 FreeList 数组精确桶、大块走 FreeTrie，因此二者是互补而非二选一。FreeListHeap 将其装成可用堆，惰性初始化，allocate 为 best-fit 取块加切分加残余回插，free 为标记空闲加与左右合并加回插以对抗碎片。Scudo 集成发生在构建期入口点层面而非运行时：baremetal/GPU 用 freelist_heap，Linux 开启 Scudo 时 malloc 入口点改由 compiler-rt 的 RTScudoStandalone 提供。引入术语：BlockRef、FreeList、FreeTrie、FreeStore、FreeListHeap、best-fit、overlay、入口点替换、add_entrypoint_external。本讲为单线程实现，下讲进入线程同步原语。
