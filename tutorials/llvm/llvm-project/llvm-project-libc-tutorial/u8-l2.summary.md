本讲解析 LLVM-libc 程序启动流程，覆盖四个最小模块：启动对象 crt1.o、装配函数 do_start、TLS 初始化、应用描述结构 AppProperties。核心结论：crt1.o 非单一源文件，而是 start/tls/irelative/do_start/gnu_property_section 五组件经构建期可重定位合并（cc -r）焊成，crti.o/crtn.o 当前为空占位。架构相关的 _start 仅取栈参数并对齐栈，随即跳入架构无关的 do_start，二者经全局变量 app 传递状态。do_start 依次完成 gettid、解析 argv/envp/auxv、由程序头算加载偏移 base 并定位 PT_TLS、处理 ifunc 重定位、init_tls 物化 TLS 并 set_thread_ptr 设线程指针、登记主线程、先 atexit(fini) 再跑 init_array，最后调 main 并 exit。关键约束：TLS 就绪线之前禁用任何会设 errno 的函数（errno 本身由 TLS 实现），故 init_tls 全程用裸 syscall 的 ErrorOr 薄封装。引入术语：PT_TLS、load bias、线程指针（x86_64 经 arch_prctl 设 FS 基址）、TLSImage/Args/TLSDescriptor、init/fini 数组反向析构顺序。
