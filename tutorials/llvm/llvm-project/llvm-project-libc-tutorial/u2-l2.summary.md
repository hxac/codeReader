本讲承接入口点（entrypoint）机制，规定入口点实现代码的写法，含五个最小模块。首先，所有内部实现必须包进 `LIBC_NAMESPACE_DECL` 命名空间——它由 CMake 注入的 `LIBC_NAMESPACE`（带版本后缀、以 `__llvm_libc` 开头）加上 `[[gnu::visibility("hidden")]]` 构成，以避免 GOT 间接跳转，并借版本化命名空间隔离系统 libc 同名符号。其次，`LLVM_LIBC_FUNCTION(type,name,arglist)` 经 `GET_FIFTH` 分派到 `IMPL_4`，用 `asm(c_alias)` 把实现体 `__name_impl__` 改名成公开 C 符号、用 `[[gnu::alias]]` 让命名空间内名指向同一符号，实现「一个实现、两个名字」且不用 `extern "C"`；冲突靠 C++ 命名空间隔离与 Overlay 链接顺序覆盖两层避免。再次，入口点遵循「实现头 `.h`（守卫镜像路径）+ 实现文件 `.cpp`（用宏定义）」的固定骨架。最后，新增的 `LLVM_LIBC_ADD_FUNCTION_C_ALIAS(name,c_alias)` 用 `extern "C"`+`gnu::alias` 为同一入口点追加公开别名（如 `fscanf`→`__isoc99_fscanf`），由 `LIBC_COPT_SCANF_PROVIDE_ISOC99_ALIASES` 开关控制，仅在 Linux Overlay 构建下默认打开。
