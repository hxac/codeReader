本讲以 ctype.h 字符函数为样本，把「入口点 + __support 下沉 + CMake 依赖」三件套落到具体函数族，含三个最小模块。其一，入口点薄壳（如 isalpha）只做 unsigned char 区间守卫与 int↔char 类型转换，再把判定委托给 `__support/ctype_utils.h` 的 internal:: 函数，算法下沉后被多个公开入口点（含 locale 版 _l 及 isxdigit/ispunct 组合型判定）共享复用。其二，ctype_utils 用逐字符 case switch 写法，刻意不用 case 区间，以达成「编码无关」（ASCII/EBCDIC 通用）并信任编译器优化；它由 add_header_library 声明为不产生公开符号的内部头库。其三，边界非对称约定：判定函数（is*）越界返回 0、守卫 [0,UCHAR_MAX]，转换函数（to*）越界原样返回 c、守卫 [CHAR_MIN,CHAR_MAX]，分别对应各自 C 标准语义；守卫不可省，否则越界 int 强转 char 会误判（如 323→'C'）。引入的关键术语：入口点薄壳、算法下沉、ctype_utils、internal:: 命名空间、逐字符 case、编码无关、判定/转换函数、边界非对称、区间守卫。
