本讲深入 `__support/FPUtil`，数学库最底层的浮点地基。核心 `FPBits<T>` 用多层类模板（FPLayout→FPStorage→FPRepSem→FPRepImpl→FPBits）把任意 IEEE-754 浮点按位重解释为无符号整数，靠掩码读写符号/指数/尾数三段，以 `cpp::bit_cast` 与原生浮点互转，并用 `static_assert` 钉死「掩码互不相交、合并覆盖全位」的不变量；唯 x86 80 位扩展精度因显式存储前导 1 而需特化。架构特化遵循「同接口、换实现」：顶层分派器在编译期按目标平台宏从 builtin（`__builtin_elementwise_sqrt`）、内联汇编、`generic/` 纯算法三级实现中三选一，运行期零分支开销，`constexpr` 上下文自动回落到 generic 的 shift-and-add 正确舍入算法。`BasicOperations.h`（abs/fmax/totalorder 等）则是完全基于 `FPBits` 写成的 `constexpr` 模板，先按位判定再比较。关键术语：FPBits、指数偏移 bias、次正规数 subnormal、intrinsic、`generic::` 嵌套命名空间、正确舍入。
