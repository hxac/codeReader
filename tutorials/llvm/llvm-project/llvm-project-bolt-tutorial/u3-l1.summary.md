`RewriteInstance::run()` 是 BOLT 处理 ELF 二进制的总调度函数，遵循「发现 → profile/调试预处理 → 反汇编+CFG → 优化 → 发射链接 → 落盘」线性顺序，共 20 个主干阶段（如 `discoverFileObjects`、`disassembleFunctions`、`buildFunctionsCFG`、`processProfileData`、`runOptimizationPasses`、`emitAndLink`、`rewriteFile`）。阶段间严格顺序依赖，返回 `Error` 的阶段失败会向上冒泡终止整条管线。核心结论是「四种模式共用一条管线」：正常优化走全程；`AggregateOnly`（perf2bolt）在 `processProfileData` 内 `exit(0)`；`DiffOnly`（boltdiff）与 `BinaryAnalysisMode`（binary-analysis）在 run() 主体 return；前 14 阶段（函数+CFG+profile 底图）是公共前置。每个阶段用 `NamedRegionTimer`（RAII）计时，由 `-time-rewrite`（组 rewrite）启用，CFG 构建另用 `-time-build`（组 buildfuncs）。本讲为单元 3 总纲，后续 u3-l2/l3/l4 分别展开发现、反汇编与 CFG、重定位细节。
