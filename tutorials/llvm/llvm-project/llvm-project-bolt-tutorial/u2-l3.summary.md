本讲拆开 `BinaryFunction` 内部，讲解 CFG 节点 `BinaryBasicBlock`。它身上同时挂三样东西：有序指令序列 `Instructions`（`MCInst` 的 vector，含 CFI/伪指令）、出边 `Successors` 与入边 `Predecessors` 两个块指针数组、以及与 `Successors` 等长按下标对齐的 `BranchInfo`（边级 profile 计数），外加标签/地址/对齐/CFI/`ExecutionCount` 等属性。核心不变量有二：边的双向一致性——唯一改边入口 `addSuccessor`/`removeSuccessor` 等内部成对维护双侧数组，调用方不直接戳单侧；以及 `Successors` 与 `BranchInfo` 等长对齐。分支类型用后继个数与下标约定隐式表达：0 个为出口、1 个为无条件/顺序、2 个为条件分支（`[0]`=taken、`[1]`=fall-through），跳转表后继为去重后的全部表项目标；分支语义经 `analyzeBranch` 委托给目标后端 `MIB`。计数有块级 `ExecutionCount` 与边级 `BinaryBranchInfo`，含特殊值 `COUNT_NO_PROFILE`/`COUNT_INFERRED`。支配树 `BinaryDominatorTree` 与循环信息 `BinaryLoopInfo` 并非自研，而是经 `GraphTraits` 特化接入 LLVM 通用模板，由 `constructDomTree`/`calculateLoopInfo` 构造并贴上 profile 计数；取支配者用 `getDomTree().getNode(BB)->getIDom()`，取所属循环用 `getLoopInfo().getLoopFor(BB)`。该类受 `static_assert(sizeof <= 256)` 约束，是后续优化 pass 与 MCPlus 元数据挂载的载体。
