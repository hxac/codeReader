本讲定位 BOLT（Binary Optimization and Layout Tool）：它是一个 post-link（后链接）的 profile-guided 二进制优化器，工作在链接之后，优化对象是代码布局，而非编译器式的指令改写。其流程为反汇编 → 重建控制流图（CFG）→ 叠加运行 profile → 重排基本块与函数 → 重生成 ELF。与编译期 -O3/PGO 互补：编译器管函数内/内联，BOLT 管全程序布局。输入要求：X86-64/AArch64 的 ELF、符号表未 strip（最低要求），以及加 `--emit-relocs`（`-q`）保留重定位（最大收益要求）；代码不得依赖布局属性。核心收益来自指令缓存局部性提升与分支预测改善，通过 ext-tsp 块重排、函数重排、热冷分离实现，收益高度依赖 profile 质量，可用 `-dyno-stats` 评估。
