本讲建立 BOLT 的「目录地图＋程序入口」心智模型。源码按子系统分层：lib/Core（数据结构，含 BinaryContext、BinaryFunction）、lib/Passes（优化 pass）、lib/Profile（profile 聚合）、lib/Rewrite（重写主管线）、lib/Target（X86/AArch64/RISCV 后端）、lib/Utils（命令行选项），include/ 与之对应。唯一程序入口是 tools/driver/llvm-bolt.cpp 的 main()；perf2bolt、llvm-boltdiff 只是它的符号链接，main() 据 argv[0] 名字前缀分发到 perf2boltMode/boltDiffMode/boltMode——「一个二进制，三种人格」，共用同一份机器码。三模式函数仅做配置（隐藏无关选项、置全局开关 AggregateOnly/DiffOnly），真正干活的是共享的重写代码。随后以 BOLT_TARGET 宏配合构建期生成的 TargetConfig.def，把选中架构展开为运行期 LLVMInitialize 注册；再经 createBinary 打开文件，用 dyn_cast 按格式分流：ELF 交 RewriteInstance::run()（返回 Error），Mach-O 交 MachORewriteInstance::run()（返回 void）。核心主线是 main() 把控制权交给 RewriteInstance::run()，后续逻辑均在 run() 内部，为单元 2（数据结构）与单元 3（重写管线）铺垫。
