MCPlus 是 BOLT 在不改 `MCInst` 内存布局的前提下挂载元数据的核心机制：在指令 operand 列表末尾追加「不参与汇编」的额外 operand 当注释容器。注释起点用一个哨兵标记——`isInst()` 为真但 inst 指针为 `nullptr` 的空子指令 operand；其后每个注释是一个 immediate，把信息编码进 64 位（高 8 位 Index 表种类、低 56 位 Value 装值或指针）。注释分两类：一等注释（如 `kJumpTable`、`kEHLandingPad`、`kTailCall`，预留固定索引，影响语义、删了出错）与补充注释（按名字动态分配、`>= kGeneric`，Value 存 arena 上 `MCSimpleAnnotation` 对象指针，可承载任意复杂类型、随时丢弃仅降优化质量，profile 即属此类）。`MCPlusBuilder` 把上述细节封装为目标无关的高层接口，并用 `AnnotationAllocator`（BumpPtrAllocator+pool）统一管理注释对象生命周期；其 allocator id 机制让每个并行任务拥有独立分配器以避免多线程冲突。
