本讲介绍 BOLT 的中枢对象 `BinaryContext`：几乎所有模块都通过引用 `BC` 访问共享状态。它持有六大类状态——函数集合、section/symbol/relocation 索引、MC 层工具箱（`MCContext`、`DisAsm`、`MIA`）、调试信息（`DWARFContext`）、运行时状态标志（`HasRelocations`、`IsStripped` 等）和日志流（`BC.outs/errs`，经 `JournalingStreams` 统一收口）。

核心结论：函数对象由四套并行索引维护——按地址的 `BinaryFunctions`（`std::map` 值语义且有序）、按符号的 `SymbolToFunctionMap`（含 ICF 折叠、配互斥锁）、按名字的 `GlobalSymbols`、按地址查符号数据的 `BinaryDataMap`，分别对应 `getBinaryFunctionAtAddress`、`getBinaryFunctionContainingAddress`（`upper_bound` 区间定位）、`getFunctionForSymbol` 等接口。目标后端经 `initializeTarget` 在外部把 `MCPlusBuilder` 注入成员 `MIB`，刻意置于 `libRewrite` 而非 `libCore`，以避免与 `libTarget` 循环依赖；对象构造由静态工厂 `createBinaryContext` 完成。

承接术语：`BinaryContext`、`MCPlusBuilder`(`MIB`)、`DWARFContext`、四套函数索引、ICF 折叠、`initializeTarget`。
