本讲承接 u1-l3 的「读 IR → 跑 pass → 写 IR」管道，正式讲解 `.mlir` 文本 IR 的读与写，是「读写 MLIR」的第一课。核心是 operation（操作）这一最基本积木：其通用语法骨架为 `%results = "dialect.op"(operands) <{properties}> {attrs} : (operand-types) -> (result-types) loc(...)`，其中函数类型签名不可省略。方言可为已注册操作提供更可读的自定义装配形式（如 `arith.addi`），与通用形式在内存中是同一操作，从而支持可靠的 round-trip。

关键术语包括：SSA（`%` 值名只赋值一次、且不持久化）；开放的类型系统（所有操作共用 `function-type` 写法，整数 `i32` 是 signless，符号语义交给操作）；属性（分 inherent 不带方言前缀与 discardable 带前缀，新近的 properties 用 `<{...}>` 将固有属性存为操作类的直接成员）；函数与控制流（`func.func` 的函数体是一个 Region，内含若干 Block，用块参数 `^bb(args):` 代替传统 PHI 节点，终止符如 `func.return`、`cf.br`、`cf.cond_br`）；以及注释（`//`）、标识符 sigil（`%@^#!` 防撞）和位置信息（`loc("file":line:col)` 是可调试性基础）。本讲只覆盖文本语法的皮相，方言操作语义与内存数据结构留待后续 u2 单元。
