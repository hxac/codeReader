本讲为 MLIR 全册首篇，仅建立「MLIR 是什么」的心智模型，不涉及编译运行。核心结论：MLIR（Multi-Level IR，多层中间表示）是 LLVM 项目下「可扩展的」编译器基础设施，官方首选「多层 IR」而非「机器学习 IR」。它不谋求一层 IR 表达一切，而以同一套共享基础设施表示从高层计算图到接近机器的多个抽象层级，通过逐步降低（progressive lowering）在方言间迁移；设计上混合传统三地址 SSA 与多面体循环优化（仿射映射为第一等公民）。它与 LLVM IR 同源但定位不同：后者是写死的低级 IR，仅是 MLIR 的目标之一而非被替代者；结构上以 block arguments 代替 PHI 节点、采用 signless 整数（符号由操作解释）。可扩展性经 Dialect 落地，生态覆盖 AI（TOSA/Linalg）、循环优化（Affine）、异构计算（GPU/SPIR-V）与最终代码生成（LLVM 方言）；让任意变换不失控的关键是 Traits 与 Interfaces 将操作语义抽象化。Operation、Value、Block、Region、Dialect、Pass、lowering 等术语将在后续讲义精确定义。
