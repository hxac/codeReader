本讲是第 2 单元「核心数据结构」开篇，把 .mlir 文本语法映射到内存数据结构、建立全局地图，单个类的内存细节留待 u2-l2~u2-l6。核心结论：MLIR 的 IR「既是图又是树」——图由 Operation（节点）与 Value（边）表达数据流，树由 Operation→Region→Block→Operation 递归嵌套表达结构。Operation 是基本执行单元，持有操作数、结果、区域、属性与位置；Region「很轻」，只装一串 Block 加父操作指针；Block 装一串 Operation 加块参数与终止符；Value 统一表示 SSA 值，身份只有 OpResult 与 BlockArgument 两种，block argument 取代了 PHI。贯穿 IR 的第二条边是 def-use 链。Dialect 是 Operation/Type/Attribute 的命名空间；关键规则为类型挂 Value、属性挂 Operation（分固有与可丢弃两种存储）。遍历用 walk()（默认后序、可按类型过滤、可中断），沿数据流走用 getDefiningOp()/getUsers()，use 链为双向链表使 RAUW 高效。
