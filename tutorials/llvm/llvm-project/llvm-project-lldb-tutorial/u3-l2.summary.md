本讲从 `Execute` 入口向内拆解 LLDB 命令对象与选项系统，覆盖四个核心模块。其一，`CommandObject` 基类采用模板方法模式，固定生命周期为 `CheckRequirements → ParseOptions → DoExecuteStatusCheck → DoExecute → Cleanup`，子类只填 `DoExecute` 钩子，`CommandFlags` 声明前置需求。其二，命令分三种形态：`CommandObjectParsed`（选项加位置参数）、`CommandObjectRaw`（取原始串，如 `expression`）、`CommandObjectMultiword`（容器转发子命令，如 `breakpoint`）。其三，`CommandReturnObject` 是命令与外界唯一信封，封装输出/错误流双写与 `ReturnStatus` 状态码，`AppendError` 自动置失败。其四，选项系统为四层结构：`OptionDefinition` 描述开关、`Options` 用 getopt 解析、`OptionGroup`/`OptionGroupOptions` 组合可复用积木、`OptionValue` 类型化存值，后者兼撑 `settings` 设置树。关键术语：`DoExecute`、`GetOptions`、option set、`OptionValue` 多态值。
