本讲是 LLDB 手册开篇，建立总览认知。核心定位：LLDB 是 LLVM 生态中下一代、高性能调试器，也是 macOS Xcode 默认调试器，支持 C/C++/Objective-C。最关键的设计哲学是「组件复用而非重新发明编译器」：LLDB 将 DWARF 调试信息转换为 Clang 类型，内嵌整套 Clang 编译器来求值表达式，并复用 LLVM 反汇编器、JIT 与 ABI 处理；表达式执行遵循「能 JIT 就 JIT，否则解释执行 IR」的回退策略。其能力被封装为公共 C++ API（SB* 类，受严格 ABI 规则约束：不可继承、无虚函数、单一成员），命令行 lldb 与 Python 脚本共用同一套 API，故既是调试器也是可复用库。源码划分为 Utility、Host、Core、API、Symbol、Target、Breakpoint、Expression、Platform 等分组，构成后续各单元的导航地图。项目采用 Apache 2.0 with LLVM Exceptions 许可证，首席维护者为 Jonas Devlieghere。
