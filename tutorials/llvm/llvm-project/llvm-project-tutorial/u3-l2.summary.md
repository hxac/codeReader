本讲讲解 LLVM IR 对象模型的继承根基：`Value` 是几乎所有 IR 对象（Function、Instruction、Constant、BasicBlock、Argument）的公共根基类，自带类型、可选名字、use-list 头与子类 ID 四样属性；为压榨到 24 字节，它没有虚析构，改用 `SubclassID` 派发的 `deleteValue()` 销毁，同一套 ID 也支撑 `isa<>`/`dyn_cast<>`。`Use` 是 def-use 图上的一条边，同时挂在 `User` 的操作数数组（维度一，答「我用了谁」）与所指向 `Value` 的 use-list（维度二，答「谁在用我」），构成「二维链表」；`User` = `Instruction` ∪ `Constant`。须区分 use（边）与 user（使用方），二者数量未必相等。`replaceAllUsesWith`（RAUW）靠 use-list 完备性一次性改写全部引用，改完即空方可安全删除——这是 SSA「每值定义一次、引用可全枚举」的内存体现，也是优化 Pass 改写 IR 的基础。
