本讲承接 u3-l1（IR 层级）与 u3-l2（Value/Use），专门讲清每个 IR 值的两项身份属性：类型（Type）与编译期已知值（Constant）。核心结论是：**Type 不是 Value，Constant 是 Value**——类型描述值的形态，常量本身就是值（`Constant : public User`），二者都不可变且在 `LLVMContext` 内唯一化，但分属两条独立类层次。

类型系统部分：类型分原始（void/浮点/label 等）与派生（整数、指针、数组、定长/可伸缩向量、结构体、函数类型、目标扩展类型）两大类，由 `TypeID` 枚举标识。**唯一化（uniquing）**是最核心设计——原始类型是 `pImpl` 预置单例，派生类型按结构键查 `LLVMContextImpl` 的表，结构相同即同一对象，因此类型判等只需比指针。结构体特例：字面结构体（`StructType::get`，按结构唯一化、必有体）与命名结构体（`StructType::create`，有身份、可先 opaque 再 setBody 以支持自引用）。现代 LLVM 用不透明指针（opaque pointer），统一打印为 `ptr`。

常量部分：分 `ConstantData`（无操作数、数据内联，如 `ConstantInt`/`ConstantPointerNull`）与有操作数常量（`ConstantExpr`、聚合常量）。`ConstantInt` 内含 `APInt`，零/一值走专用表。`ConstantExpr` 复用指令操作码，构造时**先尝试常量折叠（constant folding）**：算得出就退化为更简常量（`1+2→3`），算不出（如 `ptrtoint(ptr @g to i64)`）才保留为表达式节点。这些概念是后续 u3-l4 IRBuilder 的直接前提。
