本讲讲解 LLVM 如何用 CMake 完成「配置→构建→安装」三步流程。构建入口是 `llvm/CMakeLists.txt`（非仓库根目录），必须用 `-B` 指定独立构建目录（out-of-source），在源码目录内构建会被主动拒绝。

核心围绕四个 cache 变量：`LLVM_ENABLE_PROJECTS` 选构建期组件（如 clang），经相对路径 `../<项目名>` 挂载 monorepo 子项目，并由 `LLVM_TOOL_<NAME>_BUILD` 控制是否编译；`LLVM_ENABLE_RUNTIMES` 选运行时库（如 compiler-rt），需用已编好的 clang 自举；`LLVM_TARGETS_TO_BUILD` 决定支持哪些 CPU 架构，默认 all 展开为全部正式目标，选中后扫描 `lib/Target/<架构>` 生成 `Targets.def` 动态注册目标；`CMAKE_BUILD_TYPE` 默认 Release，`LLVM_ENABLE_ASSERTIONS` 仅 Debug 默认开启，可用 `-UNDEBUG` 抵消 NDEBUG 在优化构建中保留断言。

构建推荐 Ninja 生成器，配合 `LLVM_PARALLEL_LINK_JOBS` 限制并发链接；`CMAKE_EXPORT_COMPILE_COMMANDS` 默认开启，生成 `compile_commands.json`。引入的关键术语：生成器、cache 变量、out-of-source、自举、目标后端、断言与 NDEBUG。本讲产出的 opt/llc 等工具为后续讲义所依赖。
