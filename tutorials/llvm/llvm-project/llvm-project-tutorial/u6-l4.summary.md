本讲讲解 MC（机器代码）层——后端流水线的最后一公里，负责把后端 IR（MachineInstr）经 AsmPrinter 降级为 MCInst，再发射成目标汇编（.s）或目标文件（.o）。三大核心模块：MCContext 是容器与唯一化场所，构造时按 triple 锁定对象格式环境（IsELF/IsCOFF/IsMachO 等），集中持有各 MC 子系统、符号表与各格式段去重表；MCStreamer 是统一的流式发射抽象，分汇编流与对象流（MCObjectStreamer）两支，对象流经 MCAssembler 完成字节编码、fixup 记录与布局落盘；TargetRegistry 用一张全局单链表注册所有后端，工具凭 triple 查表拿到装满构造函数指针的 POD Target，再按需创建 MC 各组件。引入的关键术语包括 MCInst、fixup/relaxation、EmitToStreamer（MIR 与 MC 的分界线）、triple、对象文件格式与 RegisterTarget 注册机制，供后续 TableGen 及新增后端讲义承接。
