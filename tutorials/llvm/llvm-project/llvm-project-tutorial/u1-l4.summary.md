本讲覆盖 LLVM 五个核心命令行工具，分两个最小模块。关键前置概念是：LLVM IR 有三种形态——内存 `Module` 对象、`.ll` 文本汇编、`.bc` 位码，三者以 `Module` 为中介无损互转，本讲工具本质都是这三种形态之间的转换器与处理器。

模块一（格式转换与执行）：`llvm-as` 把 `.ll` 汇编成 `.bc`，`llvm-dis` 反之，两者都先读进内存 `Module` 再写出；`lli` 不落盘成机器码，而通过 JIT（默认 ORC v2）直接执行 IR，默认入口为 `main`，返回值作为退出码。

模块二（两个驱动）：`opt` 是优化驱动，读 IR、用 `PassBuilder` 解析 `-passes` 文本流水线跑 pass、输出更优的 IR；`llc` 是代码生成驱动，读 IR、用 `TargetMachine::addPassesToEmitFile` 装配一整套后端 pass、产出 `.s`/`.o`。两者都调用 `PassManager.run`，但塞入的 pass 决定产物。核心结论：`driver`（编排者）与 `pass`（流水线工序）是承接后续讲义的关键术语，而这些工具都是薄壳，真正逻辑下沉到 `lib/`。
