本讲回答"如何变换与下降 MLIR"，引入变换三件套。Pass 框架是调度外壳：PassManager 与 OpPassManager 按操作类型分层嵌套，由 OpToOpPassAdaptor 下钻执行；Pass 经 OperationPass<OpT> 锚定具体操作，被调度操作须带 IsolatedFromAbove 特征以支持多线程。RewritePattern 表达 match+rewrite 的局部图重写规则，OpRewritePattern 提供类型安全接口，改写必须经 PatternRewriter 完成；canonicalizer 贪心驱动器把一批模式反复应用到不动点，规则可用 C++ 或 TableGen DRR 声明式描述。Conversion/Lowering 在其上增加 ConversionTarget（合法性目标）与 OpConversionPattern（带已转换操作数的 OpAdaptor），由 applyPartialConversion 驱动整批跨方言改写。三者层层叠加：Pass 管调度，RewritePattern 管局部规则，Conversion 是带目标的成批改写，共同支撑渐进式下降，为后续 Toy 全流程 Lowering 作铺垫。
