本讲义讲解 LLVM 的链接时优化（LTO），核心是把过程间优化推迟到链接期，使优化器首次拥有整个程序的视野。对比两种实现：全 LTO 把所有位码合并成单一巨型 Module 做串行优化，质量高但慢且难并行增量；ThinLTO 用「摘要索引」替代完整 IR 做跨模块分析，拆分为 thin link（分析）与后端（搬运+优化）两阶段，可并行、省内存、增量友好。引入的关键术语包括：ModuleSummaryIndex（摘要索引容器）、FunctionSummary（记录 instCount 指令数与 calls 调用边及热度）、GUID（符号名哈希的跨模块主键）、FunctionImport（按带阈值衰减的 DFS 决策：NewThreshold = Threshold × 热度乘数，热边放大十倍、冷边归零，用 IRMover 搬运选中函数），以及 promote/internalize/import/opt/precodegen 后端钩子。核心源码文件涵盖 ModuleSummaryAnalysis、ThinLTOBitcodeWriter 与 FunctionImport。本讲承接新 Pass 管理器，为后续 LLD 链接器讲义铺垫 IRMover 与符号协作机制。
