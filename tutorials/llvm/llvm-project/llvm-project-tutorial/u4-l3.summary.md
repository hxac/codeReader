本讲义巡礼 LLVM 四个最经典的优化 pass，核心线索是「作用域 → 手段」的对应：单指令 / 跨基本块 / 跨循环 / 跨函数。InstCombine 是 worklist 驱动的局部代数化简器，把多条指令并成更少、更简单的等价指令且不改 CFG，靠「化简一条、把相关指令重新入队」将涟漪传播到不动点，并兼做规范化。GVN（全局值编号）用 ValueTable 给等价计算分配相同编号，消除跨基本块的完全冗余，附带冗余 load 消除与 PRE。LICM 是 Loop 层 pass，把循环不变量上提到 preheader、下沉到 exit，并做内存标量提升，安全性依赖支配关系与 MemorySSA（loop-mssa）。Inliner 是 CGSCC 层过程间优化，把被调函数体抄进调用点以消除调用开销、暴露化简机会，且「动作」（Inliner.cpp）与「决策」（InlineAdvisor/InlineCost 代价模型）分离。关键概念包括 worklist、值编号与 leader、支配关系、preheader/exit、CGSCC 自底向上处理、PreservedAnalyses 的落地，以及优化流水线需迭代到不动点的协同本质。
