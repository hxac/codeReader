LLD 是 LLVM 的模块化跨平台链接器，单个二进制封装 ELF/COFF/Mach-O/Wasm 四套链接器，靠 flavor 机制同名异构派发：由 argv[0] 或 -flavor 推断 Flavor 枚举，再从 LLD_ALL_DRIVERS「flavor→link 函数指针」表查出入口，跨过 unsafeLldMain 调用即进入对应格式驱动。

以 ELF 驱动为主线，链接核心三段为：解析输入、符号决议、合并段并写出文件。符号解析由全局 SymbolTable 承担，核心动作 addSymbol＝insert＋resolve，采用就地覆盖而非换指针；resolve(LazySymbol) 会抽取 archive 成员，实现「自动从静态库找实现」，符号优先级为 Defined＞Shared＞Common＞Lazy＞Undefined，强符号可覆盖弱符号。

段合并与输出在模板化 link 流水线完成：parseFiles 填符号表、衔接 u8-l2 LTO 的 compileBitcodeFiles、汇拢段、markLive 做垃圾回收、processSectionCommands 按链接脚本归并输出段、可选 ICF 折叠等价函数，最终 writeResult 交 Writer 排序段、分配虚拟地址与文件偏移、生成 PT_LOAD 程序头并落盘。
