本讲揭示 LLVM IR 在内存中的对象模型，核心是分清两套层次。一是包含层次（has-a）：IR 是一棵树 Module ⊃ Function ⊃ BasicBlock ⊃ Instruction，每层用 SymbolTableList（带符号表的侵入式链表）同时管理所有权与按名查找。二是继承层次（is-a）：Function（经 GlobalObject→GlobalValue→Constant→User）与 BasicBlock 都最终派生自 Value，因此可被命名、被引用、用 isa&lt;&gt;/dyn_cast 识别。遍历 API 高度统一：每层把最主要的子对象绑定到 begin/end（Module 遍历函数、Function 遍历基本块、BasicBlock 遍历指令），其余对象用 globals() 等命名 range；每个节点可 O(1) 反查父节点（getParent）。inst_iterator/instructions(F) 把「函数→块→指令」两层循环拍平。指令总数层层累加，即 Module 与 Function 的 getInstructionCount 实现。Value 作为公共根基类及 User/Use 构成的 SSA def-use 链，留待下讲展开。
