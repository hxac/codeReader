本讲是新 PM 架构（u4-l1）的动手篇，讲解如何编写并注册一个自定义 LLVM Pass，分为三个模块。其一，新 PM Pass 骨架：不再继承虚函数基类，而采用「基于概念的多态」——通过 CRTP 混入 `OptionalPassInfoMixin`（可被 `optnone` 跳过）或 `RequiredPassInfoMixin`（不可跳过，如 `AlwaysInlinerPass`），并实现 `run(IRUnit&, AnalysisManager&)`；管理器自动把 FunctionPass 应用到每个函数。其二，`STATISTIC` 宏配合 `#define DEBUG_TYPE` 提供分组计数，用 `opt -stats` 查看；`run()` 必须返回 `PreservedAnalyses` 声明副作用：只读返回 `all()`，大改返回 `none()`，精确保活用 `preserve<T>()`，流水线累计保活为各 pass 保活集合的交集。其三，注册赋予 pass 在 `-passes=` 中的名字：路径 A 在 `PassRegistry.def`（被 `PassBuilder.cpp` 多次 `#include` 的宏展开表）加宏，需重编 LLVM；路径 B 做插件用 `registerPipelineParsingCallback` 回调认领名字，不重编。HelloWorld 与 Bye 分别是最简骨架与完整注册范例。
