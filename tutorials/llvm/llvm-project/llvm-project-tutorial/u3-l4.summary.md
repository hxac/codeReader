本讲介绍 `IRBuilder`——LLVM 中「构造指令 + 插入基本块」一体化的便捷 API。其核心设计为「三件套」：`IRBuilderBase` 持有状态并提供 `CreateXxx` 方法，Folder（折叠器）决定操作能否折叠成常量，Inserter（插入器）决定新指令落到何处；二者经模板参数替换，默认组合为 `ConstantFolder` + `IRBuilderDefaultInserter`。

插入点（Insertion Point）由「`BasicBlock*` + 块内迭代器」共同确定，用 `SetInsertPoint` 定位，`saveIP`/`restoreIP` 或 RAII 守卫 `InsertPointGuard` 临时切换并恢复；未设插入点时生成的指令会悬空。

`CreateXxx` 统一遵循「传操作数、收 `Value*`」模式，覆盖运算、内存三件套（`alloca`/`store`/`load`）、终结指令（`ret`/`br`）、类型转换、比较、`GEP` 等；整数运算可带 `nuw`/`nsw` 溢出标志。

关键结论是常量折叠（Constant Folding）：操作数全为 `Constant` 时，Folder 直接返回折叠结果，不产生任何指令，`Insert(Constant*)` 这一空操作重载确保「常量不进基本块」。可用 `IRBuilder<NoFolder>` 强制保留每条指令。构造结果以 `verifyFunction` 校验、`Module::print` 输出。后续讲义中，IRBuilder 将在 Pass 内部用于改写已有 IR。
