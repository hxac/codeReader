本讲讲解 Clang 语义分析 Sema。承接 u5-l3，Parser 解析出半成品后回调 `ActOnXxx`，由 Sema 充当 AST 节点工厂与语义裁判；其海量方法拆到数十个 `Sema*.cpp` 却扩展同一个类，诊断出口 `Diag(Loc,DiagID)<<...` 与公共工具收于基类 `SemaBase`，所有节点从 `ASTContext` 内存竞技场分配、挂到 `TranslationUnitDecl`。核心四机制：名字查找 `LookupName` 沿作用域链向上搜索、结果存 `LookupResult`（含遮蔽、`FoundOverloaded`/`Ambiguous` 等种类）；类型检查经 `ActOnBinOp→BuildBinOp→CreateBuiltinBinOp`，声明走 `HandleDeclarator`，不过则 `Diag` 报错；C++ 重载决议分「收集候选、算隐式转换序列 ICS、择优」三步，结局为 `OR_Success/No_Viable/Ambiguous/Deleted`；模板实例化采用「用到才实例化＋延迟队列 `PendingInstantiations`」，由 `PerformPendingInstantiations` 排空，逐个调 `InstantiateFunctionDefinition` 代换实参，且函数模板先经 `DeduceTemplateArguments` 推导才参与重载。Sema 产出的校验后 AST 将交 u5-l5 CodeGen 翻译为 LLVM IR。
