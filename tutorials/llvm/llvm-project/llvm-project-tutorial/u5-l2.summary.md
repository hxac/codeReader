本讲讲解 cc1 如何把源文件字符流切成 Token 流，由 Lexer 与 Preprocessor 协作。Lexer 只做字面切分（翻译阶段 1–3，在字符读取中顺带折叠三字符组与行续接），核心是 `LexTokenInternal` 里按首字符分发的大 `switch`；它仅在行首遇到 `#` 和读出特殊标识符时回调 Preprocessor。Preprocessor 用主循环配合函数指针 `CurLexerCallback`，在源文件 Lexer、宏体 TokenLexer、缓存等 Token 来源间调度，以「返回 false 就再调一次」的约定表达「处理副作用但不立即产出 Token」，用循环代替递归。指令处理上，`#define` 建一个 `MacroInfo`、`#include` 经 `LookupFile` 与 `EnterSourceFile` 压入包含栈、`#if` 靠条件栈与 raw 模式快速跳过。宏展开采用「Token 再注入」：宏体以 Token 串存于 `MacroInfo`，展开时由 `TokenLexer` 回放并推入主流，并以 `IsDisabled` 标志防止自递归。最终 Token 流交给后续 Parser（见 u5-l3）。
