本讲讲解 LLVM `.ll` 文本 IR 的读与写，核心理念是：`.ll` 只是内存 `Module` 的可读序列化形式，理解它应同时对照「写」它的 AsmWriter 与「读」它的 LLParser——两者互为镜像，构成 `.ll` 语法的权威定义。

讲义分两个最小模块。其一为文本语法：`.ll` 严格分层为「模块头 → 全局声明 → 函数（签名 + 基本块 + 指令）」；`target triple`/`datalayout` 带语义，`@` 表全局符号、`%` 表局部符号，每个操作数显式带类型（即类型显式汇编）。其二为基本块与 SSA：基本块由标签、顺序指令和唯一的终结指令（ret/br/switch）构成；SSA 要求每个 `%` 值只定义一次，`phi` 在控制流汇合点按来源块选值，是表达分支/循环变量的标准手段，且必须是块内首条指令。

引入的关键术语包括 Module、BasicBlock、终结指令、SSA、phi、AsmWriter/LLParser、前向引用。寄存器命名 `%名字` 与 `%数字` 语义等价，编号按定义顺序分配（参数在前、指令在后）。配合 `clang -S -emit-llvm` 生成、`llvm-as`/`llvm-dis` 往返验证，培养手工读写 IR 的能力，为下一讲 IR 内存对象模型（Module/Function/BasicBlock 与 Value-Use 链）铺垫。
