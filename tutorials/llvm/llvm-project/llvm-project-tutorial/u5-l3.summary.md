本讲承接 u5-l2，讲解 Clang 如何把词法分析产出的 Token 流组织成抽象语法树（AST）。核心结论有三：其一，`clang::ParseAST` 是语法分析总入口，它构造 `Sema` 与 `Parser`，用循环反复调用 `ParseTopLevelDecl`，每解析出一个声明就经 `ASTConsumer` 流式推送下游。其二，Clang 采用手写递归下降：每条文法规则对应一个 `Parse...` 方法，方法内用 `switch` 按首 Token 分发，从顶层声明层层下降到语句、表达式；表达式层额外用优先级爬升（`ParseRHSOfBinaryExpression` 的循环与 `MinPrec` 参数）统一处理二元运算符结合性。其三，Parser 与 Sema 严格分工：Parser 只认 Token 和文法，真正构造 AST 节点与语义检查由 `Actions.ActOnXxx` 完成。引入的关键术语有：AST、Parser、Sema（语义动作）、`Decl`（声明）与 `Stmt`/`Expr`（语句/表达式，`Expr` 继承自 `Stmt`）两大节点谱系、`DeclContext`（多重继承混入，使 `FunctionDecl` 等既“是声明”又“能装声明”）、`ASTContext`（节点内存竞技场并持有 `TranslationUnitDecl` 根）、`Decl::Kind`/`Stmt::StmtClass` 枚举 ID（支撑 `isa<>`/`dyn_cast<>` 与 `-ast-dump`）。Sema 内部细节留待 u5-l4，AST 到 IR 的转换见 u5-l5。
