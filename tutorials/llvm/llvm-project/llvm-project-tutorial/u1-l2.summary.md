本讲讲解 llvm/ 子项目的目录组织，含三个最小模块：lib/ 与 include/ 的镜像布局、tools/ 的薄壳驱动设计、examples/ 与 test/ 的学习样本。核心结论：include/llvm/ 放公共头契约，lib/ 放实现，两者按功能一一镜像，且头文件路径即物理路径；每个 lib/ 子目录被打包成组件库，但目录名与组件名不总一致（lib/IR 对应组件 LLVMCore）；opt、llc 等命令行工具只是薄壳，main 仅解析参数并转发，真正逻辑下沉到 lib/，其 CMakeLists.txt 给出工具到库的依赖清单。本讲引入头文件、实现文件、组件、驱动、include 路径等术语，该布局在 clang/、mlir/ 同样适用；Kaleidoscope 为渐进式入门样本，test/ 为行为说明书。本讲是后续读源码讲义的基础，下一讲 u1-l3 讲构建系统。
