本讲讲解 Clang 如何把校验后的 AST 翻译成 `llvm::Module`，即 CodeGen 流水线，分三层。触发层：CodeGen 是一种 `CodeGenAction`（`ASTFrontendAction` 子类），其 `EmitLLVMAction` 等子类对应不同输出格式；它经 `ParseAST` 把 AST 流式喂给 `BackendConsumer`（一个 `ASTConsumer`），后者将回调转发给 `CodeGeneratorImpl`（同时持有 `Module` 与 `CodeGenModule`，是二者之桥），TU 末尾由 `emitBackendOutput` 把 Module 交接后端。模块级 `CodeGenModule`（CGM）是贯穿整个翻译单元的长寿总管，管 `QualType`→`llvm::Type` 类型映射、mangling、各语言 Runtime 与虚表；`EmitTopLevelDecl` 派发声明，`EmitGlobal` 用 `MustBeEmitted` 决策立即或延迟发射，延迟发射用工作表到不动点补齐所有可达代码。函数级 `CodeGenFunction`（CGF）是逐函数的短命对象，核心为其 `Builder`（即 u3-l4 的 `IRBuilder` 子类 `CGBuilderTy`）；`EmitStmt` 用大 switch 把 `Stmt`/`Expr` 译成指令：控制流走 `EmitXxxStmt` 造基本块与跳转，表达式经 `EmitIgnoredExpr`，声明经 `EmitDecl`→`EmitAutoVarDecl` 产出 `alloca`+`store`。关键结论：每条 IR 都能反推回某个 AST 节点；`-O0` 下局部变量的 `alloca`/`load`/`store` 冗余留待 u4 优化 pass 消除。
