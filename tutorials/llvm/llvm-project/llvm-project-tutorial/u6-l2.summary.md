本讲拆解 LLVM 后端最成熟的指令选择框架 SelectionDAG，它是基本块级框架：每块建一张临时 DAG 再销毁。核心积木为 SDNode（操作码+类型+操作数，建节点即 CSE）与 SDValue（节点+结果号），chain 与 glue 两类边分别串接副作用顺序与强制紧邻。总调度 `CodeGenAndEmitDAG` 是固定流水线：combine1→类型合法化→向量合法化→操作合法化→指令选择→调度→发射，DAGCombiner 穿插多次以捕获合法化改写后新暴露的化简机会。DAG 构建由 `SelectionDAGBuilder` 按「操作数→getNode→setValue」三段式完成。合法化分两层：先类型后操作，操作处置为 Legal/Promote/Expand/Custom/LibCall 且 Custom→Expand→LibCall 逐级兜底，均迭代到不动点。指令选择本质是一台字节码模式匹配机：`SelectCodeCommon` 用 TableGen 编译出的 MatcherTable，以 `OPC_Scope` 回溯择优、`OPC_MorphNodeTo` 就地把通用 ISD 节点变形为目标 MachineSDNode，末尾经 pre-RA 启发式调度与 `EmitSchedule` 落成 MachineInstr。可用 `llc -debug-only=isel` 观测各阶段产物。
