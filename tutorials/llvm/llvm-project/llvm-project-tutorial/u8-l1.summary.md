本讲介绍 LLVM 的 JIT（即时编译）：在运行期把 IR 不落盘编译成机器码、链进可执行内存并立即执行，由 ExecutionEngine 抽象承载，现代实现为 ORC v2。核心结论是"按需编译"——addIRModule 仅把符号登记为未物化状态，真正的编译发生在 lookup 查找符号时，经物化派发回调各层 emit 产出机器码，复用的就是离线后端的 TargetMachine。架构分两个正交维度：核心层（ExecutionSession + JITDylib）只管符号簿记、查找状态机与物化调度；可叠加的层（IRLayer/ObjectLayer）各暴露一个 emit 沿层下放，IRCompileLayer 把 IR 编译成目标文件再交对象链接层。LLJIT 把这些层按序焊成开箱即用的预制 JIT 栈，用法四步闭环：建栈 → addIRModule → lookup → toPtr 调用；LLLazyJIT 再叠 CompileOnDemandLayer 实现惰性编译。关键术语：JIT、ORC、JITDylib、物化（Materialization）、ThreadSafeModule、IRCompileLayer、ResourceTracker、LLJIT/LLLazyJIT，供后续 LTO、LLD 讲义承接。
