GlobalISel 是 LLVM 函数级、基于 gMIR 的新一代指令选择框架。gMIR 复用 MIR 数据结构，但用一整套目标无关的 `G_` 通用操作码（如 `G_ADD`、`G_LOAD`），且虚拟寄存器只带低层类型 LLT、不绑定寄存器类。其核心是固定四阶段流水线：**IRTranslator** 把 LLVM IR 几乎逐条翻译成 gMIR（ABI 经目标 `CallLowering`）；**Legalizer** 依目标 `LegalizerInfo` 与 `LegalizeAction` 枚举，用 worklist 把非法操作塑形成目标支持的形态；**RegBankSelect** 给每个通用 vreg 选定寄存器库（Fast/Greedy 两模式），尽量减少跨库拷贝；**InstructionSelect** 依目标 `InstructionSelector` 做最终拍板，gMIR 收紧为 MIR。阶段间靠 `MachineFunctionProperties` 维护可校验的契约链 `IsSSA → +Legalized → +RegBankSelected → +Selected`，失败时经 `ResetMachineFunctionPass` 回退 SelectionDAG。相比 SelectionDAG 的基本块级临时 DAG，GlobalISel 以更直接的 MIR 集成、更好可观测性与编译速度为目标，代价是多一步寄存器库选定、优化深度仍在追赶。
