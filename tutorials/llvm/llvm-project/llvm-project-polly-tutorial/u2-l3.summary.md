本讲放大 u2-l1 流水线中的 `prepare` 阶段，回答「ScopDetection 运行前 IR 被塑造成什么样」。涉及两个最小模块：一是 LLVM 规范化 pass 串，由 `buildCanonicalicationPassesForNPM` 装配，核心为 mem2reg（栈槽提升为 SSA 寄存器）与 IndVarSimplify（归纳变量规范化），使 SCEV 能把循环边界与数组下标表达成仿射式；该组 pass 仅挂载于 early 位置，before-vectorizer 靠 LLVM -O3 已完成规范化。二是 CodePreparation，目前只做拆分函数入口块，为代码生成的 alloca 预留干净空间，且具幂等性。分析保持策略上，DT/LI 因 ScopDetection 持其引用而 preserve，RI 因被检测改写故每次重算、不缓存。重要事实校正：`-polly-canonicalize` 作为独立 pass 已随 LPM 一并移除。
