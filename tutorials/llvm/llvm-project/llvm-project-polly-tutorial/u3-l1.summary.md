本讲聚焦 Polly 流水线的 `detect` 阶段，讲清 SCoP 概念与 `ScopDetection` 类的设计。核心结论：**SCoP**（静态控制部分）是控制流图中控制流在编译期完全确定、可用多面体模型描述的子图；它必须是**单入口单出口的 Region**，且循环边界、分支条件与数组下标都要满足**仿射**（迭代变量与不变参数的线性组合加常数）。这是多面体模型用线性不等式组刻画迭代空间的数学前提，**SCEV** 负责把 IR 值翻译成符号表达式供仿射判定。`Region/RegionInfo` 提供区域树作为几何边界，Polly 沿树自顶向下搜索，且检测会改写区域树，故 RegionInfo 不能用 Pass Manager 缓存版本。`ScopDetection` 构造时绑定 DT/SE/LI/RI/AA/ORE 六个分析，`detect()` 用「先试整体、不合法再下降、找到后向上扩展」的算法把**最大合法区域**填入 `ValidRegions`，并以 `isMaxRegionInScop` 做单点查询；最后经可获利性筛除不划算区域。本讲确立了关键分工：**检测只判定「能不能」，建模（`ScopInfo`/`ScopBuilder`，U4）才构造真正的多面体对象**，前者为后者提供合法区域清单。逐条 `isValid*` 判定细节留给 u3-l2。
