本讲讲清 Polly 流水线如何被压成单个 LLVM Pass 及其阶段开关如何解析。第一块介绍 `OptionalPassInfoMixin`：它把 `isRequired()` 钉为 `false`，使 `PollyFunctionPass`/`PollyModulePass` 可被跳过（尤其 O0）。第二块说明这两个封装 pass 把 u2-l1 的 17 阶段流水线对 NPM 呈现为原子单元，`run()` 转调自由函数 `runPollyPass`，模块版逐函数复用。第三块讲 `PollyPassOptions`：其核心是 `PhaseEnabled` 位集（位下标按 `idx(P)-idx(Prepare)` 平移），配三预设 `enableEnd2End`/`enableDefaultOpts`/`disableAfter` 批量置位，并由 `checkConsistency` 依 `dependsOnDependenceInfo` 等依赖规则拒绝非法组合。第四块是重头 `parsePollyOptions`，按"命令行 cl::opt→隐式依赖→预设→显式覆盖→stopafter→一致性检查"六步合并；三态 `optional<bool>` 数组是"显式覆盖预设"的关键；`polly` 默认开两预设、`polly-custom` 全 opt-in，二者仅 `Opts` 不同，且阶段必须按枚举序、不可重复。
