本讲义是 Polly 学习手册的第一篇，覆盖两个最小模块：多面体模型基础与 LLVM 流水线定位。核心结论是：Polly 是 LLVM 的多面体循环优化器，吃 LLVM-IR、吐优化后的 LLVM-IR，不碰源码与机器码。

它引入了整套供后续讲义承接的关键术语：多面体模型用「迭代域（Domain）+ 访问关系（Access Relation）+ 调度（Schedule）」三件套把循环核抽象为数学对象；其中循环变换的本质就是在依赖安全的前提下改调度，等价于改循环结构（交换/分块/并行/向量化）。讲义还定义了 SCoP（静态控制部分）、仿射（线性加常数，是 Polly 能否处理一段循环的关键判据）、依赖分析（用于数学证明变换安全，U5 详述），以及 ISL（Integer Set Library，多面体在代码里的样子，对应 isl_set/isl_map 等类型）。Polly 端到端流程为：检测→建模→变换→代码生成。

第二模块讲清了标准 `-O3` 流水线分规范化、内联循环、目标特化（向量化在此段）三阶段，Polly 默认挂在 early 位置（贴近源码、循环核不易被改坏，但编译时间略增、吃不到内联红利），可选 before-vectorizer（享受内联、几乎不增编译时间，但 IR 带额外标量依赖致效率打折）。源码精读从 U2 的 PhaseManager 开始，沿「检测→建模→依赖→变换→代码生成」主线逐目录深入。
