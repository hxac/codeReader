本讲义建立 libunwind 的宏观心智模型：它是 LLVM 运行时子项目，专做「栈展开」——从当前指令沿调用链逐帧重建寄存器状态，是 C++ 异常处理与 backtrace 的底层基石。它对外两层 API：高级 `_Unwind_*`（声明于 unwind.h，服务 C++ 异常，由 libc++abi 调用，分搜索与清理两阶段）与低级 `unw_*`（声明于 libunwind.h，服务通用回溯），二者底层共用同一套游标机制。源码集中于 src/ 约 20 个文件，用 CMake 构建；虽用 C++ 编写却刻意不依赖 C++ 运行时。核心引擎是模板化的 `UnwindCursor<A, R>`（A 为地址空间、R 为寄存器集合），适配 15+ 架构，`step()` 经编译期 `#if/#elif` 分发到 Compact/SEH/TBTable/DWARF/EHABI 等多套展开机制；`AbstractUnwindCursor` 提供统一对外接口，`AddressSpace` 负责按 PC 定位展开段。本讲引入的关键术语包括：栈帧、CFA（规范帧地址）、personality function、landing pad，以及 DWARF CFI、Compact、EHABI、SEH、TBTable、SjLj 等多种展开元数据格式。
