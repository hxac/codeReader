本讲解析 nextgen 通用插件框架（plugins-nextgen/common/）——上层 libomptarget 与各硬件后端之间的统一抽象层。核心设计是模板方法模式：每个能力由「非虚外壳（承载异步包装、JIT、RPC、OMPT 回调、环境变量等公共逻辑）+ 纯虚 Impl（仅翻译为厂商运行时 API）」成对构成。一次调用纵向穿越三层方法：用户面 DeviceTy → GenericPluginTy 的 int32_t C 边界函数（做 UserId→RTLDeviceID 转换并降级错误）→ GenericDeviceTy 的 Error 外壳（公共编排）→ 后端纯虚 Impl（碰硬件）。GenericPluginTy 代表一个后端，负责探测硬件、预留设备槽、创建 GlobalHandler/JIT/RPC，暴露 initImpl/createDevice/getMagicElfBits/getTripleArch 等插件级契约；GenericDeviceTy 代表一张卡，是最庞大的基类，外壳承担大量公共编排。横切机制：AsyncInfoWrapperTy 借 LocalAsyncInfo 与 finalize 把同步统一为异步的特例，GenericDeviceResourceManagerTy 池化队列与事件，llvm::Error/Expected 配 OffloadError/ErrorCode 贯穿错误传播、仅在最外层降级为 OFFLOAD_SUCCESS/FAIL 并打印文案，InfoTreeNode 树统一描述设备信息。引入的关键术语供后续讲义承接：模板方法模式、三层方法、外壳与纯虚 Impl 契约、GenericPluginTy/GenericDeviceTy/GenericKernelTy/PluginContextTy、AsyncInfoWrapperTy。
