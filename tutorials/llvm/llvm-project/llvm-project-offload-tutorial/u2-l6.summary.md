本讲走读 OpenMP `target` 内核启动链路。入口 `__tgt_target_kernel` 极薄，仅按 `nowait` 选异步上下文类型（阻塞型 `AsyncInfoTy` 或挂 OpenMP task 的 `TaskAsyncInfoWrapperTy`），转发给 `targetKernel` 模板；后者先用 `upgradeKernelArgs` 依据 `KernelArgsTy` 首字段 `Version` 做 ABI 版本协商，补全旧结构并追加隐式 dyn_ptr 参数，使主流程始终拿到统一格式。核心 `target()` 经翻译表完成 HostPtr 到设备内核地址的两步查找：`getTableMap` 先查 `HostPtrToTableMap` 缓存、未命中再扫库得到 `(TranslationTable, Index)`，按 `DeviceId` 取该设备已加载入口视图，最终从 `EntriesBegin[Index].Address` 取得设备内核地址。启动前后由 `processDataBefore`/`processDataAfter` 直接复用 u2-l5 的 `targetDataBegin`/`targetDataEnd` 搬运数据，按 `ArgType` 分流参数（LITERAL 按值传、PRIVATE 交 `PrivateArgumentManagerTy` 打包传输、TARGET_PARAM 查设备指针），私有内存释放推迟到同步后。边界处 `DeviceTy::launchKernel` 作为 Facade 仅一行转发，完成用户面 `DeviceID` 到插件内 `RTLDeviceID`、富 `AsyncInfoTy` 到裸 `__tgt_async_info` 的降级，交给 `GenericPluginTy::launch_kernel`（衔接 u3-l1）；真正等待内核跑完由 `targetKernel` 的 `synchronize()` 完成。
