本讲讲清如何编译运行 OpenMP 卸载程序并观测运行时。编译核心是 `clang -fopenmp -fopenmp-targets=<三元组>`，设备三元组须与某插件登记的三元组匹配；host 插件把主机 CPU 当设备，适合无 GPU 学习。`llvm-offload-device-info` 枚举设备属性，走 liboffload 新 API（`olInit`/`olIterateDevices`/`olGetDeviceInfo`/`olShutDown`），仅链接 `LLVMOffload`，与旧的 `__tgt_*` 是两条路径。`Envar<Ty>` 模板（含 `BoolEnvar`/`StringEnvar` 等别名）把「读环境变量→解析→失败回退默认」收敛为一行声明。最易混淆的是三套观测手段分属两条上层：`LIBOMPTARGET_INFO` 是 `OpenMPInfoType` 位掩码（`63`≈全开），默认可用；`LIBOMPTARGET_DEBUG` 需编译期定义 `OMPTARGET_DEBUG`（Debug 构建或 `-DLIBOMPTARGET_ENABLE_DEBUG=ON`），Release 下被编译消除；`OFFLOAD_TRACE` 仅属 liboffload，只追踪 `ol*` 调用，三者不可混用。
