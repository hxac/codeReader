本讲建立 Clang 与 libomptarget 的"编译器-运行时契约"地图，只读头文件、不涉实现，含三个最小模块。其一，`__tgt_*` 函数族分四类：注册/生命周期、数据搬运（begin/end/update）、内核启动（`__tgt_target_kernel`）、辅助；双方靠 `omptarget.h` 与 `APITypes.h` 的 C ABI 解耦演进，`KernelArgsTy` 首字段 `Version` 加 `static_assert` 锁死布局以保 ABI 稳定。其二，`tgt_map_type` 是 `uint64_t` 位掩码，把 map 子句的 `to/from/always/present` 压成每变量一个整数，低 16 位为行为开关、高 16 位编码结构体成员序号。其三，"两张表+一段镜像"具象为 `__tgt_device_image`、`__tgt_bin_desc`（总账本）、`__tgt_target_table`（设备加载后的入口视图），表中条目 `EntryTy`/`OffloadEntryTy` 记录 Address、Size、SymbolName、Flags。核心结论：运行时不翻译代码，只搬运数据并分发预编译镜像；`HostPtr` 是把主机某处调用与镜像内核精确对应的粘合剂。
