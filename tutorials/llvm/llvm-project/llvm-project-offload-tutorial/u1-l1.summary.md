本讲建立 LLVM Offload 子项目的全局认识，覆盖三个最小模块。模块一定位：为加速器与协处理器提供工具、运行时和 API，把代码运行在与主机架构可能不同的设备上；对 OpenMP 卸载用户已成熟，统一 API 仍在开发，设备架构支持 CPU（x86_64/Power/AArch64）与 GPU（NVIDIA/AMD），主机仅在 Linux 测试。模块二执行模型：编译期已生成设备镜像（device image），运行时依据 `target` 指令触发设备内核启动、依据 `map` 子句（to/from/tofrom/alloc）控制主机↔设备间的数据搬运，运行时只负责调度、搬运与启动，而非翻译。模块三内部分层：libomptarget 是绑定 OpenMP 的成熟运行时，liboffload 是不绑定 OpenMP 的开发中通用新 API，二者共享同一套底层设备插件（plugins-nextgen）。本讲仅建立全局认识，未涉及编译运行与源码实现细节。
