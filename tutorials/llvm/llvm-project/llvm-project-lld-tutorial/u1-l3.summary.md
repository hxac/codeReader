本讲拆开 LLD 目录骨架，把代码分为三类：公共层（`Common/` 及唯一公共头 `include/lld/Common/`）、分发器（`tools/lld/`）、四个后端 `ELF/COFF/MachO/wasm` 与薄包装 `MinGW/`。顶层 CMake 用 `add_subdirectory` 串联，Common 最先、后端互相独立。核心结论：四后端是同一设计图的四份独立实现，共享设计而非代码，故 `Driver/SymbolTable/Writer/InputFiles` 等同名文件反复出现却互不共享；「输入段」概念相同而命名各异——ELF/MachO 叫 `InputSection`、COFF 叫 `Chunk`、wasm 叫 `InputChunks`，仅 ELF 与 MachO 有 `Arch/` 多架构子目录，COFF 另有 PDB/DLL 等 Windows 专有模块。唯一公共契约是 `lldMain()` 与把五个签名一致的 `link()` 登记成一张按 `Flavor` 路由分发表的 `LLD_ALL_DRIVERS` 宏。测试分两套：`test/` 以 lit+FileCheck 端到端测链接行为，`unittests/` 以 gtest 把 LLD 当库测接口，经 `test/Unit` 桥接由 `check-lld` 统一运行。
