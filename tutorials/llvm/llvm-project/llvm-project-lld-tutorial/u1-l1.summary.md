本讲是 LLD 学习手册的开篇，只读文档与顶层目录以建立全局地图，含三个最小模块。其一，定位：LLD 是 LLVM 项目的高性能模块化链接器，旨在直接替换 GNU ld、link.exe、ld64 等系统链接器，核心特性是快、可作为库嵌入（lld::lldMain）、始终是交叉链接器。其二，格式与后端：同一个二进制内含四个链接器，分别处理 ELF、PE/COFF、Mach-O、WebAssembly，对应 ELF/、COFF/、MachO/、wasm/ 四个目录，外加公共层 Common/ 与分发器 tools/lld/；四个后端"共享设计、几乎不共享代码"，没有抽象公共层，故手册以 ELF 为主线讲解。其三，NewLLD 概念地图：三条设计原则为原生实现共享设计不共享代码、Speed by design（少做事胜过高效做事，体现为惰性求值）、高效静态库处理（记住全部符号、按需即时提取，使 --start-group 基本成为 no-op）；关键数据结构有 Symbol（分 Defined/Undefined/Lazy，用 placement new 就地替换使旧指针自动指向解析结果）、SymbolTable、InputSection（ELF）/Chunk（COFF）、OutputSection；三个角色为 InputFile、Driver、Writer，Driver 以六步（解析命令行→建符号表→建 InputFile→查未定义符号→建 Writer→写出结果）驱动全流程。若需确认输出是否由 LLD 链接，可查看输出 .comment 段中的 Linker: LLD 标记。
