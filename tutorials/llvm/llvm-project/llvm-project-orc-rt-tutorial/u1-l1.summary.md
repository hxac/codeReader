orc-rt（LLVM ORC Runtime）是为 LLVM ORC JIT API 提供执行端支持的运行时。核心心智模型是 controller/executor 二分：控制端（controller）链接 LLVM ORC 库（如 LLJIT），负责编译与链接 JIT 代码；执行端（executor）链接 orc-rt，负责执行 JIT 代码并管理其运行时资源，两者可同进程或跨进程。执行端的根对象为 orc_rt::Session，必须先于任何 JIT 代码创建、后于其全部执行完毕后销毁，其下挂多个 Service 管理 JIT 内存、unwind 信息、动态库等资源，并通过 ControllerAccess 与控制端做双向 RPC，配合 wrapper function 实现统一调用签名。跨进程通信不对称：控制端→执行端按地址调用，执行端→控制端按 tag 调用，体现最小权限设计。项目仍处实验阶段，ABI/API 不稳定，必须与同一次构建的 ORC 库配套使用。构建要求 CMake ≥ 3.20、C++17（无编译器扩展）、推荐 Clang 16+，默认开启 RTTI 与异常，日志后端默认为 none（日志被编译掉）。
