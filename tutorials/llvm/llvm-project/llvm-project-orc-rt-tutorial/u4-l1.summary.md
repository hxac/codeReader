本讲拆解 orc-rt 支撑 Session 安全关闭的托管代码 Token 协议。托管代码指 Session 管理其生命周期的 JIT 机器码及关联库代码；关闭时若栈帧仍活却释放其内存会引发 use-after-free。

机制由 TaskGroup、Token、TokenSource 三者构成：TaskGroup 是「计数+关闭+完成回调」追踪器；Token 是持有 shared_ptr<TaskGroup> 的 RAII 令牌，构造计数+1、析构−1，故有令牌在则组不灭、计数非零、回调不触发；TokenSource 仅强引用保活、不占计数。核心不变量：OnComplete 恰在「已关闭且计数归零」时触发一次，close 之后不再发新令牌。

Session 持有一个 ManagedCodeTaskGroup，以 callManagedCode 同步包裹领令牌运行 JIT 代码（void 返回 bool、非 void 返回 optional<T>），令牌被拒则不调用函数。关键边界：令牌只覆盖同步执行栈，不跨异步续体，调用续体的一方须自领新令牌。shutdown 的 Drain 阶段即对该组 close 并挂 proceedToShutdown 回调，在飞令牌会把 onShutdown（而非 onDetach）推迟到令牌释放后才执行。
