本讲讲解 SPS（Simple Packed Serialization）：它是 wrapper function（u5-l1）之上的「类型还原」层，把任意 C++ 值打包成一串小端字节、再原样还原。三个最小模块自底向上：(1) 物理地基——零所有权字节游标 SPSOutputBuffer（带溢出检查）与 SPSInputBuffer（带下溢检查，data()/skip() 支持零拷贝视图）；(2) 核心契约——主模板 SPSSerializationTraits<SPSTagT, ConcreteT> 的三件套 size/serialize/deserialize，配以「先量后写」的两阶段精确分配，SPSArgList 用递归粘合多字段；(3) 标签词汇表——SPSTuple、SPSSequence、SPSString、SPSMap、SPSOptional 等正交原语：原语小端原样、序列为「uint64 长度+逐元素」、元组「逐字段无填充」、可选「bool 哨兵+条件值」。核心原则是「标签与具体类型分离」，一个标签可映射多个宿主类型。该 wire 格式须与控制端 llvm/ExecutionEngine/Orc/Shared 一致，为下一讲 SPSWrapperFunction 的类型安全跨进程调用做铺垫。
