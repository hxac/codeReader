本讲义只涉及一个纯头文件 `ExecutorAddress.h`，它是 orc-rt 全库的「地址语言」基础设施，覆盖三个最小模块。其一是 `ExecutorAddr`——「类型安全的地址整数」，内部以 `uint64_t` 存储（可跨进程序列化），通过 `explicit` 构造、`fromPtr`（指针经 `uintptr_t` 两段转换打包）与 `toPtr`（用 SFINAE 区分对象指针与函数类型两条还原路径）显式互转，并配套别名 `ExecutorAddrDiff` 表示偏移量，用「地址 ± 偏移 = 地址、地址 − 地址 = 偏移」的严格运算符在编译期杜绝「地址相加」等语义错误。其二是 `ExecutorAddrRange`，采用半开区间 `[Start, End)` 约定（`size() = End − Start` 无需修正），提供 `contains`（左闭右开、含区间完全包含）、`overlaps`（取反不相交，共享端点不算重叠）与 `toSpan<T>()`（把区间重解释为 `span<T>` 视图，带长度整除断言）。其三是 `Tag`/`Untag`——可选的带标签指针策略，分别按位或加标签、按位与剥标签，默认 `rawPtr` 恒等，仅在 ARM64 TBI 等平台显式传入。这些类型是后续 Service、SPS 序列化与跨进程调用的共同词汇。
