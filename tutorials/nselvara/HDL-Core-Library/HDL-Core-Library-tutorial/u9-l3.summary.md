本讲拆解异步 FIFO 的厂商无关行为级实现 `own_behavioural_async_fifo`，落地 Clifford Cummings 的异步 FIFO 设计方法，覆盖四个最小模块。读写分处两时钟域，跨域传递指针必须用格雷码：二进制指针多比特同翻会被「数据撕裂」采样成源端从未产生的值，导致丢数据或重复读；格雷码相邻值汉明距离恒为 1，跨域至多慢一拍、绝不撕裂。互换用位运算实现：`binary_to_gray` 即 b⊕(b≫1)，`gray_to_binary` 为从高到低累积异或（须用 variable）。由 `ff_synchroniser_vector` 建立写指针→读域、读指针→写域两条对称同步链，`in_data_valid` 恒接高。关键术语「折回位」：指针比地址多一位；空=两格雷码指针相等，满=最高两位不同且低位相同，二者因同步滞后而保守但不影响正确性。存储底座为 `dual_clock_dual_port_ram`，地址取指针低位、丢弃折回位。移植陷阱：叶子同步器被硬编码为 Xilinx 架构，仍依赖 xpm 库。
