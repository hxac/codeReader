本讲剖析上电复位控制器 `reset_on_startup`：上电后强制维持一段可配置长度的复位窗口，结束后把外部 `rst_in` 延迟一拍直通到 `rst_out`。模块含三块：饱和式启动计数器、一拍延迟直通寄存器 `rst_delayed`、按极性合并的组合输出。关键概念：复位极性 `RESET_POLARITY`（active-low/active-high）被抽象为单一值，「有效」即等于它、「无效」即取反，无需 if-else 分支即可双极性兼容；计数器以 `subtype'high` 让窗口长度随 generic `RESET_TIME_IN_CLK_CYCLES` 自动伸缩，避免硬编码。核心结论：`rst_out` 是组合输出，模块对 `rst_in` 的一拍延迟完全来自 `rst_delayed`，该寄存器兼作本地复位树的扇出缓冲；跨厂商兼容不走 u2 的「多 architecture」模式，而在 `rst_delayed` 上同时挂 `dont_touch`（Xilinx）与 `preserve`（Intel）双综合属性，单份 RTL 即可在两家工具下保住该寄存器；测试台用 `generate` 循环同例化两种极性 DUT，以「立即检查仍为旧值、一拍后才跟随」的断言验证一拍延迟。
