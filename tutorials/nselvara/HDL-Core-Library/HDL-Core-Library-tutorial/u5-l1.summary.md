本讲围绕时钟使能/门控模块 `clock_enable` 展开。它采用单一 `behavioural` 架构，靠两层 `if generate` 嵌套，在编译期由两个 boolean generic（外层 `ENABLE_INTERNAL_CLOCK_GATING`、内层 `USE_XILINX_CLK_GATE_AND_NOT_INTERNAL`）裁剪出三种实现：Xilinx `BUFGCE` 全局门控（仅在完整周期边界启停，无毛刺）、组合门控（`clk_out <= clk_in when en else '0'`，有毛刺风险）、以及直通。四种 generic 组合实际只产生三种结果——外层关闭时内层取值被忽略，恒走直通。引入的关键术语：时钟门控（clock gating）、毛刺/窄脉冲、`BUFGCE` 原语、`unisim` 库、寄存器使能。核心结论：Intel 不推荐直接门控时钟，应改用寄存器使能引脚（时钟常转、寄存器按需保持）；该模块是本库「同一实体多架构」之外的另一种等价厂商适配手段（单架构 + 编译期 `if generate`）。其唯一真实例化点在 `spi_tx` 主模式，以 `not spi_chip_select_n` 作使能，实现「仅传输期间放行 SPI 时钟」。下一讲 u5-l2 讲 PLL 生成新频率/相位时钟，与本讲「开关时钟」相对。
