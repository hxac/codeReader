本讲为《HDL-Core-Library 学习手册》开篇，为后续讲义建立全局地图。HDL-Core-Library 是一套可复用的 VHDL-2008 IP 核库，MIT 许可证、可商用，价值在于「可复用 + 经验证 + 跨厂商 + 统一接口」。其核心设计模式是「同一 entity（端口契约）配多套 architecture（实现）」，提供 Xilinx、Intel 与自研行为级三套实现以实现跨厂商移植；自研行为级实现不依赖厂商库、可开箱仿真。验证闭环由 VHDL-2008 + VUnit（自动发现并批量跑测试台）+ OSVVM（随机化激励）构成。IP 核分四大功能类：存储器（单/双口 RAM、双时钟 RAM、同步/异步 FIFO、ROM）、同步与时序（FF 同步器、时钟生成 PLL、上电复位、时钟使能）、通信接口（SPI）、输入处理（消抖器），另含工具包。引入的关键术语有：HDL、IP 核、RTL、FPGA、CDC（跨时钟域）、entity/architecture、自研行为级实现。两个要点：PLL 是全库唯一无自研行为级实现的 IP（硬核模拟资源）；utils_pkg 与 tb_utils 实际来自外部 git 子模块 ip/vhdl_utils。
