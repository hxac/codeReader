本讲是「共享工具包与基础设施」单元首讲，聚焦本库自带共享包 `memories_pkg` 及其核心非约束数组类型 `rom_t`。先引入 VHDL 包机制：`package` 声明对外接口（类型、常量、函数签名），`package body` 放实现，只声明类型时 body 可空；别的文件用 `use work.memories_pkg.all` 复用，实现单一真相源。

核心类型定义为 `type rom_t is array (natural range <>) of std_ulogic_vector`，深度（索引范围）与位宽（元素位宽）两个维度同时留空，依赖 VHDL-2008 的「数组元素本身也可非约束」特性。使用时以「两对括号」一次性约束：第一对定深度、第二对定位宽，如 `rom_t(0 to 15)(7 downto 0)`。

`rom.vhd` 将约束推迟到例化时刻：深度由 `2 ** address'length` 推导、位宽由 `q'range` 推导，使一份源码服务任意容量 ROM；`load_rom` 在 elaboration 期求值为只读常量表，`rom_reg'subtype` 可继承已约束子类型。引入的关键术语包括 package/package body、work 库、非约束数组、双维度约束、端口推导尺寸，供后续 `utils_pkg`、ROM 文件初始化及 RAM 讲义承接。
