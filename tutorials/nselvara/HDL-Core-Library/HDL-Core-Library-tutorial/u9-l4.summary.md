本讲（u9-l4）是 FIFO 设计单元的收尾，承接 u9-l3 的格雷码指针，讲解异步 FIFO（`fifo_async` 的 `own_behavioural_async_fifo` 架构）三个核心问题。**满空标志判定**：空为两个格雷码指针完全相等，满为最高两位镜像、低位全同——满判定可由「写指针领先深度 D 步、二进制仅最高位不同」经格雷码换算严格推出；`empty` 属读时钟域、`full` 属写时钟域，各自用本域指针加同步链传来的对端指针计算，遵循「谁用就在谁的域算」的 CDC 铁律，两者因同步滞后而保守（提前拉高，绝不溢出或读空）。**words_stored 填充水位**：在读域把同步过来的写指针格雷码经 `gray_to_binary` 转回二进制、减去读指针，满时钳位到深度 D，是保守偏小的近似值。**reset_read_pointer 数据重放**：在读域把读指针清零、保留写指针与 RAM 内容，使同一批数据可重读，优先级低于 `aclr`、高于普通读；其典型消费者为 SPI 多片选广播。关键结论：三套架构重放行为不一致，仅自研行为级实现真正无损重放，Xilinx 版退化为读屏蔽、Intel 版完全忽略，移植时须留意。
