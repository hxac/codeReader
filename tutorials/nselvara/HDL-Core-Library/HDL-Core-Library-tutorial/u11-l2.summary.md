本讲承接 u11-l1，解决测试台「造激励、判对错」两件事。其一，引入 OSVVM 保护类型 RandomPType 作带状态随机源：用 InitSeed(tb_path & random'instance_name) 播种，RandSlv 造数据、RandInt 造时序与计数；种子确定即可复现、不同则覆盖更广，专攻定向测试够不到的并发与时序边角。其二，VUnit 的 check_equal(got, expected, msg) 比对实际值与期望值并接入用例 pass/fail 统计，失败记 error、汇入 CI 报告，info 仅打日志不判对错；本库约定 msg 必写、以 std_ulogic 的 '-' 当 don't-care 哨兵封装可复用检查过程。其三，设计源码内的 report 断言用 -- synthesis off/on 包裹，综合时整段丢弃、零面积，仿真时按 severity warning 提醒但不自动判失败；真正防溢出/下溢的硬件保护是可综合的 not full / not empty 屏蔽逻辑，二者职责不同、不可混淆。下一讲 u11-l3 将把 check_equal 的失败结果接入 CI/xunit 闭环。
