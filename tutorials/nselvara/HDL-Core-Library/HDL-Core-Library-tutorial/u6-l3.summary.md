本讲讲解 `dual_clock_dual_port_ram`：一块读写两口分别由两个相互独立的时钟 `write_clk` 与 `read_clk` 驱动的双口 RAM，读写分处不同时钟域。核心结论有三：其一，存储体 `ram_reg` 声明为 signal（非上一讲 `dual_port_ram` 的 variable），由 `write_process` 唯一驱动、`read_process` 只读；因读写分属不同时钟进程，不存在「同周期同地址读写」顺序问题，故无需 variable 与顺序控制。其二，地址端口为 `std_ulogic_vector`，寻址须先经 `unsigned()` 转为无符号数再 `to_integer`。其三，端口刻意极简——无复位、无使能、无读使能，读口每拍无条件输出。这种只管存取、不管策略的「哑存储」正是异步 FIFO 最理想的存储底座：满空标志、指针管理、跨域同步（格雷码指针）全交由上层 FIFO 完成，本模块干净映射为双口 BRAM。它被 `fifo_async` 以真双时钟例化，又被 `fifo_sync` 把两时钟都接 `sys_clk` 复用，一份原语服务两种 FIFO，为第 8 单元同步器与第 9 单元 FIFO 设计埋下伏笔。
