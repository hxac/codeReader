本讲精读 ROM 模块（`rom.vhd`）。核心结论：ROM 的「只读」通过将存储体声明为 `constant` 实现——常量在精化期（elaboration，仿真时间 0 之前）一次性求值并冻结，源码中无任何赋值，天然只读，与 RAM 的可写数组形成对比。常量内容由 `impure function load_rom` 在精化期从外部 hex 文件加载；该函数必须标 `impure`（文件 I/O 是副作用），全仿真期仅被调用一次。

文件读取基于 VHDL `std.textio` 四件套：`file_open` → `while not endfile` → `readline` → `hread`，每行一个十六进制值填入对应地址；存储深度 `ROM_DEPTH = 2^address'length` 由非约束地址端口反推。

引入的关键术语：精化期求值、`impure` 函数、`rom_t` 双维度非约束数组、`'subtype` 属性。

为解决「常量不可运行时改写」与「仿真需灵活注入数据」的矛盾，模块以 `SIMULATION_MODE` 切换两条路径：常量路径（真实/综合，只读，从 `MEM_INIT_FILE_PATH` 加载）与仿真信号路径（`rom_reg_only_for_simulation`，可被测试台用 `<= force` 覆盖）。测试台借助 VHDL-2008 层次化信号引用 `<< signal ... >>` 钻进 DUT 内部注入随机数据做全覆盖校验。
