本讲讲解单比特跨时钟域同步器 `ff_synchroniser`，把单比特信号安全搬入另一时钟域。引入三大概念：跨时钟域（CDC）、亚稳态（采样撞进建立/保持窗口，触发器输出停在半电压值、经不可预测时间才塌缩）、衡量故障概率的 MTBF。模块用「同一 entity 多架构」配两套实现：Xilinx 例化黑盒 `xpm_cdc_single`，可靠性交由厂商宏保证；Intel 用显式移位同步链加 `preserve`、`altera_attribute`（SDC 假路径与同步器识别）手动保护。`SYNC_SHIFT_FF`（范围 2~10，默认 4）同时决定链长、延迟与内部向量位宽，链越长延迟越大但 MTBF 指数级提升；`SRC_INPUT_REG` 仅对 Xilinx 架构生效，Intel 架构无条件含源域寄存进程。核心结论：同步链只压低亚稳态危害，救不回被目的域漏采的窄脉冲——后者属事件覆盖问题，需握手机制或基于电平翻转的 CDC 解决。测试台用 100 MHz→25 MHz 快→慢跨域配置。
