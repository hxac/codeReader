本讲讲解多比特同步器 ff_synchroniser_vector，承接 u8-l1 单比特同步器，解决"整条总线跨时钟域"问题。多比特若逐比特各挂独立同步器，会因各比特采样步调不一致产生**数据撕裂（data tearing）**，目的域会看到源端从未产生过的混搭值；只有每次仅翻转一比特（汉明距离为 1）时才不撕裂。模块核心技巧是把 `in_data_valid` 与 `in_data` 拼接成 `(N+1)` 位向量整条过同一同步链，使 valid 与数据延迟严格一致、同拍到达——这是"valid+数据同链同步"可靠的硬件基础。它有两套架构：Xilinx 版封装 `xpm_cdc_array_single`（需厂商库），Intel 版手写"源域寄存+目的域移位同步链"（厂商无关、可开箱仿真，本讲实践基于它）。`fifo_async` 用它同步写/读指针的**格雷码**：格雷码保证相邻值只翻一比特而天然免撕裂，故 `in_data_valid` 恒接 `'1'`、`out_data_valid` 悬空，判空可直接比格雷码相等无需反变换。引入的关键概念：数据撕裂、valid+数据同链同步、二进制↔格雷码变换、MTBF。移植陷阱：`own_behavioural_async_fifo` 的叶子同步器被硬编码为 Xilinx 架构，转 Intel 需手动改两处例化。
