本讲精读本库最简单的时序模块——消抖器 `debouncer`：仅三端口（`clk_in`/`input`/`output`），无复位、无厂商原语、无内部例化，仅一套 `behavioural` 架构与单个时钟进程，是「厂商无关行为级实现」的纯粹样本。去抖原理为「计数器稳定判定」：用 `input_sync_d` 保存输入上一拍的值做逐拍变化检测，本拍与上一拍不等即清零计数器，否则累加；连续稳定 2^N 拍后才将 `input` 提交至 `input_sync`，再由 `output` 镜像输出。哪怕一拍窄毛刺也会令计数器清零，这正是滤除毛刺的根本。两个 generic 是仅有的可调旋钮：`DEBOUNCE_SYNC_BITS`（N，计数器位宽）决定稳定周期数 2^N 与稳定时间门槛 T=2^N/f_clk；`POLARITY` 无默认值，只定义静止电平与所有寄存器的上电初值（`not POLARITY`），使同一模块既能接高有效也能接低有效按键。注意内部仅一拍寄存调理，并非多级亚稳态同步链，跨时钟域输入须先经同步器再消抖。测试台取 N=4 以加速仿真，并用 `test_bouncy_transition` 验证「毛刺被滤、稳定窗口满才翻转」的边界。
