本讲讲解本库唯一「无自研行为级实现」的 IP——时钟生成器 `pll`。PLL（锁相环）是 FPGA 内部的硬核模拟资源，具备倍频、分频、移相、去抖动能力，VHDL 代码只是在「例化并配置」它，而非描述其内部工作。`pll` entity 提供 5 个倍频/分频 generic（`IN_CLK_PERIOD_PS`、`CLK_MULTIPLY`、`CLK_DIVIDE`、`OUT_CLK_0_DIVIDE`、`OUT_CLK_1_DIVIDE`），对外给出两路时钟 `out_clk_0/1` 与一个 `locked` 锁定指示。两套厂商架构差异显著：Xilinx 侧用 `PLLE2_BASE` + `BUFG`，公式为 f_out = f_in × M/(D·Oₓ)，反馈取自内部 `clkfbout`，需显式挂全局缓冲；Intel 侧用 `altclklock`，公式简化为 f_out = f_in × M/D，缺少「输出再分频」一级，`OUT_CLK_1_DIVIDE` 不被映射，且由 Quartus 自动推断全局网络。因此同一组 generic 在两家语义不同，移植时必须重算。关键术语包括 BUFG、VCO、`unisim`/`altera_mf` 仿真库。由于 PLL 无法用纯 VHDL 精确建模，它是全库唯一无 `own_behavioural`、且因 NVC 缺 `PLLE2_BASE` 绑定而唯一被 CI 排除的模块，只能依赖本地厂商工具链验证。
