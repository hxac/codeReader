本讲围绕全库最基础的存储原语——单口 RAM（single_port_ram）展开。其核心约束是同一时钟周期只能读或写，由单信号 write_and_not_read 仲裁方向（为 1 写、为 0 读），en 控总使能，读写天然互斥，不存在同周期读写冒险。

关键设计思想是「非约束端口」：entity 将 address、write_data、read_data 声明为不带范围的非约束类型，真实位宽推迟到例化时刻由外部连线决定，使一份源码服务任意位宽；architecture 内再用属性反推——以 address'length 算出存储深度 RAM_DEPTH = 2**address'length，以 write_data'subtype 定义元素位宽，构造出局部存储数组类型 ram_t，并用 assert RAM_DEPTH <= natural'high 防止地址过宽导致整数溢出。

读写由对 sys_clk 敏感的同步进程驱动，读出数据寄存一拍输出（晚地址一个周期）。复位分支刻意写 null 而不清空整块 RAM，目的是引导综合工具将 ram_reg 推断为 FPGA 片上 BRAM 资源；代价是复位后内容未定义，使用方须先写后读。本讲建立了「非约束端口＋内部推导存储类型＋同步读写」的基本范式，为后续双口 RAM（u6-l2）处理同地址同时读写的新问题奠定基础。
