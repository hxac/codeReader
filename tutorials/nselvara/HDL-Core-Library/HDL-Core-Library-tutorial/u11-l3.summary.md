本讲是验证方法学单元收尾，把视角从单机命令行仿真抬升到工程化、可视化与持续集成，核心覆盖四块。其一，`.do` 波形脚本本质是 Tcl 命令清单，遵循「接口→内部→测试台内部→视图设置」四段式，靠 `-divider` 分段、`-group` 折叠、`-radix` 设进制、`/tb/DUT/...` 层次路径探查设计内部信号，`gui=True` 下 `do` 一键重放波形布局。其二，三层调用链：`test_runner(_ci_cd).py` 薄包装填参数 → 子模块 `run_all_testbenches_lib` 编排 VUnit → VUnit 执行，两个顶层脚本均不直接 import VUnit。其三，CI 选用开源、支持 VHDL-2008 但不能编译 Verilog 的 NVC 仿真器，靠克隆 grlib/gplgpu 为厂商原语补纯 VHDL 行为模型并经 `nvc --install` 入库。其四，xunit XML 报告与匹配文件名的 `excluded_list`（`tb_pll.vhd`/`pll.vhd` 因 `PLLE2_BASE` 无 VHDL 模型被排除）构成验证闭环，三个报告步骤均带 `if: always()`，确保失败时也能拿到报告。
