本讲精读同步 FIFO 的厂商无关行为级实现 `own_behavioural_sync_fifo`：它把 `dual_clock_dual_port_ram` 的两个时钟端口都接 `sys_clk`，使双口 RAM 退化为单时钟存储底座。核心结论是满空标志完全由填充水位计数器 `fifo_fill_level` 决定（满＝水位≥深度，空＝水位＝0），无需指针比较，因此 `FIFO_DEPTH` 不必是 2 的幂。写/读请求先被满空屏蔽成 `fifo_write_request`/`fifo_read_request`，满写、空读被安全忽略；同时读写时水位保持不变（两指针各 +1），是稳态下每拍吞吐 1 字的关键，该分支在 `fifo_ctrl_proc` 中刻意置首。`words_stored` 满时钳位到深度。`UNDER_AND_OVERFLOW_ASSERTIONS` 断言块由 `-- synthesis off` 包裹、默认关闭、severity 为 `warning`，仅作仿真自检、不影响综合。本讲引入填充水位、指针折回、请求屏蔽等关键术语，并为 u9-l3 异步 FIFO 的格雷码指针法埋下对照伏笔。
