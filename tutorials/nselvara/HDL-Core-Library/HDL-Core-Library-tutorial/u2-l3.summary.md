本讲覆盖三个模块：上电复位 reset_on_startup、单比特跨域同步器 ff_synchroniser、时钟门控 clock_enable。核心结论是：综合工具会自主删除、合并、重定时寄存器，从而破坏同步链与复位拓扑，须用综合属性在综合阶段旁路优化——属性仅在综合阶段生效、仿真不可见。

引入的关键术语：preserve（boolean，Intel/Quartus）与 dont_touch（string，Xilinx/Vivado）是两类"请勿优化"标签，类型差异源于两家历史约定，reset_on_startup 将二者同挂于 rst_delayed 以实现跨厂商通吃。altera_attribute 是 Intel 的赋值透传通道，承载 SYNCHRONIZER_IDENTIFICATION（标记同步器、紧凑布局）与内嵌 SDC set_false_path（屏蔽亚稳态首级的假违例）。同步链长度须如实保留以维持 MTBF：ff_synchroniser 用 preserve 顶住 src_reg/sync_chain，而首级 meta_stable_reg 本身无 preserve，仅靠 SDC 假路径保护。

时钟门控两种哲学：Xilinx 用全局网络原语 BUFGCE（CE 由原语内部安全切换、无毛刺），Intel 不推荐直接门控、应改用寄存器使能或 PLL 使能，手写 `clk <= clk_in when en else '0'` 是有毛刺风险的兜底。clock_enable 用两层嵌套 if generate 在 elaboration 期裁剪出 BUFGCE/通用门控/直通三种模式，这是"多 architecture"之外另一种等价的厂商适配手段（换厂商只改 generic）。
