本讲讲解 SPI 子系统的发送模块 `spi_tx`，承接前置的 `spi_pkg` 通用包（四种 SPI 模式、位序、`bit_index` 三过程）与 `clock_enable`（时钟门控）。`spi_tx` 只有一套 `behavioural` 架构，厂商差异通过透传两个 generic 下放到例化的 `clock_enable`，换厂商只改类属、不动 RTL。

其核心职责是把一个并行字逐比特搬到串行线 `serial_data_out`（默认 `'Z'`，故用 `std_logic`；片选为 `inout` 以兼主从）。握手靠 `tx_data_valid`/`tx_data_ack` 单拍脉冲完成。串行化用单进程 + 变量 `bit_index`（由 `reset_bit_index`/`last_bit_index`/`update_bit_index` 驱动），状态机变量 `tx_started` 立即生效，使捕获与首位输出发生在同一上升沿。

关键结论：因 Xilinx 综合器无法从通用边沿函数推断触发器（会综合成锁存器），串行数据与片选的对齐改用 `case generate` 为每种模式显式写出 `rising_edge`/`falling_edge`；模式 1 额外用 `postpone` 进程规避同沿竞争。片选由「断言路」与「解除断言路」相与产生，窗口干净包住时钟脉冲。主机 SPI 时钟由 `clock_enable` 门控 `spi_clk_in` 得到，使能取 `not spi_chip_select_n`。现有测试台仅覆盖模式 0，其余模式待补。

引入的关键术语：`tx_data_ack`/`tx_is_ongoing` 握手、`bit_index` 移位、`case generate` 边沿对齐、`postpone` 进程、片选对齐与门控时钟。
