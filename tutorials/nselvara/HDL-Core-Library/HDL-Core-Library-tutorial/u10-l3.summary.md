本讲是 SPI 子系统第三讲，承接 u10-l1（spi_pkg）与 u10-l2（spi_tx），专讲从机的接收方向。spi_rx 唯一职责是串并转换：在 SPI 时钟驱动下逐位采样 serial_data_in，按 MSB/LSB 位序填入 rx_data，收满一字拉高 rx_data_valid 一拍；含四个 generic——CPOL、CPHA、DATA_WIDTH、MSB_FIRST_AND_NOT_LSB。采样边沿由包函数 rx_active_edge(spi_clk, CPOL, CPHA) 门控，与发送方换数边沿错开半拍，模式 0 下为上升沿。架构内就地例化一份与 generic 同步的包实例，使内部变量 bit_index 随位宽自动伸缩，位序与边界判断封装于 reset_bit_index/update_bit_index/last_bit_index。机制上，rst_n 无效或 spi_chip_select_n 撤销都把 bit_index 复位到起点，故传输中途撤销片选即作废当前字、重新对齐；rx_data_valid 借"最后赋值胜出"语义形成单拍脉冲；因 bit_index 是变量，写 rx_data 与末位判定须先于推进。测试台 tb_spi_rx 用 transmit_and_check_data 逐位校验，并以千轮随机片选抖动覆盖打断重收，但模式 2/3 仍未被仿真验证。
