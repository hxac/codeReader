本讲是 SPI 子系统收尾篇，讲解顶层集成模块 `spi_interface`。它用一条六状态 FSM（`idle`、`fetch_data`、`wait_for_data`、`wait_for_acknowledge`、`reset_for_next_chip`、`wait_for_transfer_end`）把 `spi_tx`、`spi_rx` 与异步 FIFO 三块积木缝合，对外提供"写 FIFO＋单脉冲触发＋查忙结束"的接口。关键术语包括：多片选 FSM（`selected_chips` 位图，`spi_chip_select_n` 为低有效 `inout` 向量）、`get_next_selected_chip`（靠 `get_lowest_active_bit` 与逐位上扫，按索引升序一次只选一片）、`spi_busy`（等价于非 idle）、广播重放（`tx_fifo_write_blocked` 封锁写口、`reset_read_pointer` 仅回卷读指针使数据无损重读）。核心结论是：广播重放语义只在 `own_behavioural_async_fifo` 架构中成立，故显式选定该架构；Xilinx/Intel 版本会退化为屏蔽读或忽略，移植需重评。
