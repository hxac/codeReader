本讲聚焦 SPI 子系统的公共包 `spi_pkg`，不讲控制器本身，而是为后续 spi_tx/spi_rx/spi_interface 铺设术语与工具。`spi_pkg` 被设计成 VHDL-2008 的 generic package，带 `DATA_WIDTH` 与 `MSB_FIRST_AND_NOT_LSB` 两个类属，各使用方（spi_tx、spi_rx、测试台）用 `package … is new work.spi_pkg generic map(…)` 各自例化一份，互不干扰。讲义引入的关键概念包括：SPI 主从全双工、CPOL（时钟极性）与 CPHA（时钟相位）组合出的四种 SPI 模式、前导/后导边沿随 CPOL 翻转的规则。核心结论有三：其一，`tx_active_edge`/`rx_active_edge` 把模式表翻译成 `rising_edge`/`falling_edge`，参数必须声明为 `signal` 才能检测跳变；spi_tx 因 Xilinx 综合的边沿识别问题，额外用 `case generate` 手写对齐。其二，`last_bit_index`/`update_bit_index` 借一个布尔类属与 `'subtype` 属性，使同一份过程同时支持 MSB/LSB 位序与任意位宽，过程体不写死数字。其三，经与标准模式表核验，`rx_active_edge` 在 CPOL=1（模式 2/3）分支返回的边沿与标准相反，且现有测试台只配置了模式 0，模式 2/3 从未被仿真覆盖——这是后续值得补测试之处。
