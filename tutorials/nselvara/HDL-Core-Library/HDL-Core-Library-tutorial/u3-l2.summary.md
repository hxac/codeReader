本讲讲清 `utils_pkg` 的来源与两个核心函数。该包不在本仓库，而由 git 子模块 `ip/vhdl_utils`（VHDL-Utils 仓库）提供，`.gitmodules` 仅记其 path/url 指针、不检入源码；故 `clone` 后须执行 `git submodule update --init`（或 `clone --recursive`）填充子模块，否则 `use work.utils_pkg.all;` 编译失败，`test_runner.py` 的 Python 导入也抛 `ModuleNotFoundError`。关键概念是「VHDL 库是编译期逻辑容器、与磁盘目录无强绑定」：子模块里的 `.vhd` 一旦被仿真脚本编译进 `work` 库，即可被全库任意文件复用。两个函数中，`to_bits(n)` 返回表示自然数 n 所需的最少位数（约 ⌈log₂(n+1)⌉），在 FIFO 中有地址位宽 `to_bits(DEPTH-1)`、计数位宽 `to_bits(DEPTH)`（二者差 1）、generic 上界 `to_bits(natural'high)`（≈31）三类用法；`get_lowest_active_bit(vec)` 返回向量中最低有效位的索引，用于 SPI 顶层接口多片选轮询中「回到最低有效片」。二者具体实现均在子模块内、本讲标注为待确认；验证侧的 `tb_utils` 留待 u3-l3 讲解，FIFO 指针折回位与 SPI 完整 FSM 分别承接至 u9、u10。
