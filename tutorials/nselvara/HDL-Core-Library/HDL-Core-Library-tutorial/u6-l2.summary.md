本讲围绕 `dual_port_ram.vhd` 展开三个最小模块。其一，**双口 RAM** 为读、写各设一套独立地址与使能（`write_address`/`write_enable` 与 `read_address`/`read_enable`），读写是两条并列 `if` 而非互斥 `elsif`，因而同拍可并行读写，区别于单口 RAM 的「单地址 + 单方向」。其二，存储体 `ram_reg` 用 VHDL **variable（`:=` 立即更新）**而非 signal（`<=` 延迟到 delta），使进程内语句顺序能精确控制同周期同地址读写的取值；类型声明因此搬入进程说明区，而输出 `read_data` 仍为信号寄存器、晚地址一拍。其三，**读写顺序决定读改写（read-during-write）语义**：读块在前为 **read-first（读旧值）**，写块在前为 **write-first（穿透读新值）**，后者会引入同周期 `write_data→read_data` 耦合（读写冒险）并可能破坏 BRAM 推断。核心结论：当前代码刻意写成 read-first 以贴合 BRAM 行为，故源码注释警告不得调换读写块顺序；复位只把输出置 don't-care、不清存储体，以引导 BRAM 推断；现有测试台未覆盖同周期同地址读写，是验证盲区。关键术语：双口 RAM、variable/signal、read-first、write-first、读写冒险、读改写、BRAM 推断。
