本讲解决「如何在该 VHDL IP 核库中定位文件」。核心结论：所有 IP 集中在 `ip/` 下，按功能大类分一级子目录，`memories/` 再分 `fifo/ram/rom` 三级。每个 IP 遵循三件套约定：设计源码 `<ip>.vhd`（可综合）放目录根，测试台 `tb/tb_<ip>.vhd`（仅仿真、用 VUnit 编写）与波形脚本 `tb/tb_<ip>.do` 放进 `tb/` 子文件夹并加 `tb_` 前缀，使 `test_runner.py` 能用 `tb_*.vhd` 通配符自动发现并运行测试。引入的关键术语：设计源码（会被综合成电路）、测试台（只参与仿真）、仿真与综合的区别。包文件就近放置：大类共享的 `memories_pkg.vhd` 在 `memories/` 顶层，模块专用的 `spi_pkg.vhd` 在 `spi/` 下。`.do` 是 ModelSim/QuestaSim 的 Tcl 波形脚本，用 `add wave -divider` 与 `-group` 把信号按「接口/内部/测试台」分层展示。重要例外：`clock_enable`、`dual_clock_dual_port_ram`、`ff_synchroniser_vector` 无独立测试台，靠使用方间接覆盖；README 目录树为简化版，读源码以 `git ls-files` 真实结构为准。
