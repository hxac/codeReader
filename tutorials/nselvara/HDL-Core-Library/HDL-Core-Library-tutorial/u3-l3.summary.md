本讲专讲验证侧工具包 `tb_utils`（来自 `ip/vhdl_utils` 子模块，本仓库未检入源码）。核心结论有四：其一，`tb_utils` 是仿真专用包，内含带 `wait`/`time`/`real` 的**过程**，不可综合，因此全库 12 个测试台均 `use work.tb_utils.all`，而 0 个设计源码引用它——与可综合、设计/验证共用的 `utils_pkg` 形成硬边界。其二，`generate_advanced_clock` 是一条**并发过程调用**，写在 architecture 并发区，等价于独立后台进程，与 `main`/`checker`/DUT 并行翻转时钟。其四参数契约为 `clk`（signal，被驱动）、`frequency`（real，Hz）、`phase`（time）、`enable`（signal，门控），全库 17 处调用写法一致；本库从未拉低使能，时钟自由跑到仿真结束。其三，频率到半周期换算 T_half=1/(2f)。其四，过程形参的 **signal 类别**（持续关联，可改 `clk`、随 `enable` 反应）与 **constant 类别**（按值传一次）之别。附带概念：`frequency_t` 物理类型与 `to_real`/`to_time` 转换。`tb_utils.vhd` 过程体实现标注为「待确认（位于子模块）」。
