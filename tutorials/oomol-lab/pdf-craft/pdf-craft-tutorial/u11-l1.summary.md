pdf_craft_tool 是仓库本地 CLI，不随 pdf-craft 包发布，是官方调用 PDFCraft 门面公开 API 的最完整使用示范；核心原则是库不读环境变量、由 CLI 层装配显式配置对象。本讲覆盖三模块：cli.py 定义子命令树，按输入类型分组为 pdf 的提取/转换/翻译、package 的翻译/回写/渲染、epub 翻译与 smoke 冒烟组（下讲主角），靠 handler 绑定分发、参数附加器在兄弟命令间复用；runtime.py 负责环境装配，手写 .env 解析并以 setdefault 加载（进程环境优先于 .env），按 PDF_CRAFT_OCR_MODE 把六种 OCR 模式映射为六种配置类，LLM 走命名 profile 并支持别名递归，OOMOL 凭据经 oo 命令现取不落盘；paths.py 管运行目录双轨制，缺省在 pdf-craft-output 下按「标签-日期-序号」原子分配新目录，显式 --work-dir 复用时以所有权文件 .pdf-craft-tool-run.json 的指纹（源路径、大小、mtime 与 OCR 设置）防止 OCR 缓存被误用到他书。
