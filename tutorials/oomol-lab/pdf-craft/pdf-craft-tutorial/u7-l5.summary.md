回填 LLM 输出的 XML 常有缺块、多块、标签错等缺陷，本讲讲清评分、修复与落地三步。两套评分要分清：分组分数（结构 token 数加每 id 80 分，占位值保证只依赖结构）服务切组预算；完成度权重（错误按严重度分级，权重为 3 的 level 次幂，缺块类再乘缺失数）度量回填质量。HillClimbing 爬山修复逐块记账，仅当权重严格下降才替换最优版本，块权重单调不增、避免修复震荡；已改善块错误等级减 LEVEL_DEPTH 沉底，注意力让位给未修复块。每次失败发 FillFailedEvent，重试耗尽发最终事件且不抛异常，未记账块映射为 None、降级保留原文。提交器区分 peak 与 platform 结构，落地方式有 REPLACE 与 APPEND_TEXT/APPEND_BLOCK，非内联子元素（表格/图片）永远保留。
