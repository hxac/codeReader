本讲讲解 pdf-craft 的 Markdown 段落模型与 HTML 安全过滤。因 OCR 文本是不可信输入、可能夹带 XSS 载荷，parser.py 手写字符级扫描器 parse_raw_markdown：先整体删除注释、处理指令、CDATA、声明四类危险构造，再按四类策略分流标签——tagfilter 九个危险标签只把开头 < 换成 &lt;，忽略集合（left/center/right）剥壳保留子内容，63 个白名单标签构造 HTMLTag，其余未知标签转义显示但子内容照常递归解析；解析失败一律退回字面文本，永不抛错。白名单分三层：标签白名单、属性白名单（通用∪元素专属，class/style/on*/data-* 全被丢弃）、URL 协议白名单（仅 http/https/mailto 与相对路径，违者整条属性丢弃）。产物 HTMLTag[P] 泛型容器用 P 槽位贯通文本解析（P 为空）与章节 XML 解码（P 为公式、脚注引用）两条通路，配套 flatten/decode/encode。核心结论「容器即安全凭证」：能成为 HTMLTag 的内容必已过白名单，下游渲染无需重复安检。
