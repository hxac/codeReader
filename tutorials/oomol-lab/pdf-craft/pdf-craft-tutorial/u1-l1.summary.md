本讲为手册首讲，覆盖三个模块：项目定位、核心工作流、文档地图。核心结论：pdf-craft 是以 PDF 为中心的 Python 转换库，专为扫描书籍与学术/技术文档设计，三大能力为 PDF 转 Markdown/EPUB、内容翻译、译文按原版式回写 PDF。五种工作流均由门面类 PDFCraft 驱动：convert_pdf_to_markdown、convert_pdf_to_epub（可挂 TranslationStep 边转边译）、translate_epub、extract_pdf 加 translate_pdf（回写）。关键术语：OCR 负责认字、LLM 负责翻译，两者是独立配置；Poppler 是系统级依赖，凡以 PDF 为输入的工作流必需；提取结果落成中间包 DocumentPackage，默认存临时目录并自动清理，传 package_path 才保留；SubmitKind 决定译文替换或附加。文档分两层：README 管定位与上手，docs/en 专题指南管具体任务；公开 API 边界由 pdf_craft/__init__.py 划定。
