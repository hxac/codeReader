本讲讲解 pdf-craft 中唯一的声明式配置类 LLM：必填参数 key、url、model、token_encoding 用于接入 OpenAI 兼容服务，另有采样、超时、重试与缓存、日志目录等可选项；构造期不发任何请求，但会急切创建目录并用 tiktoken 加载编码器，请求执行交给 LLMRuntime。核心概念 token 与 tiktoken：token 数在本地估算，编码器经 LLM.encoding 传给流式分组器 XMLStreamMapper，按片段分数（XML 渲染 token 数加带 id 父标签各 80 分）把全书切成默认每组 2600 token 的翻译组。缓存与日志让翻译可复算、可排查：缓存键是覆盖消息与协议版本的 sha256，仅完整成功的结果落盘，修复请求绕过缓存；日志以七类 JSON 行还原每次请求。LLM 还兼任模板宿主，为 XMLTranslator 加载 jinja 提示词。
