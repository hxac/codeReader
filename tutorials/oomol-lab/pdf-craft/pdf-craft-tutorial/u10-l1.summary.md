本讲是「PDF 翻译与回写」单元首讲，聚焦 `PDFTranslationPipeline` 如何把 DocumentPackage 变成一列 `PDFReplacement` 替换项。核心模块有三：一是 translate 与 patch 双入口——前者接受 callable 文本回调或 `ChapterTransformer`（以 `callable()` 分派，带来「译文等于原文则跳过该块」的可见差异），后者零转换纯收集；门面 `PDFCraft.translate_pdf` 实际走两段式路径：先用 `_TextChapterTransformer` 包装回调、经 `translate_package` 复制-改写出翻译包，再调 patch 入口回写，且在任何文件操作前拒绝 `APPEND_BLOCK`。二是序列化器 `_to_patch_text`：摊平块内容时公式保留 Markdown 定界符、脚注引用保留打印编号、HTML 剥壳递归保子，未知类型抛 `TypeError` 拒绝静默丢弃；收集仅覆盖 `text`/`sub_title` 段落块。三是页几何兜底：`bbox` 来自 OCR 检测框 `block.det`，`page_pixel_size` 优先取 `document.json` 的 `page_pixel_sizes`，缺页时由 PDF handler 按管线 dpi（默认 300）现场渲染补齐（仅内存态）；门面预检 `_validate_package_for_pdf` 则让缺几何在兜底前快败。本讲还引入两套坐标系（图像像素坐标 vs PDF 点坐标）与叠层回写概念，坐标换算用页面总宽比加 y 轴翻转，真正的绘制留给下一讲 `PDFPatcher`。
