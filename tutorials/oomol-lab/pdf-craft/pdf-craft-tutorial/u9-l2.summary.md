本讲拆解 translate_epub 的地基：EPUB 适配层与两类文本修正机制。适配层五模块分工：Zip 用源只读、目标只写的双句柄保证失败安全，mimetype 须首个迁移且保持不压缩，退出时兜底迁移其余文件；common 定位 OPF（经 container.xml）并剥除 XML 命名空间；spines 解析 manifest 与 spine 产出章节文档流；toc 兼容 EPUB 2 的 NCX 与 EPUB 3 的 nav 两种目录，统一为 Toc 树；metadata 跳过语言、标识符等技术字段，按 tag 分桶回写。修正一为引号解包 unwrap_french_quotes，仅作用于目录与元数据译文：双层包裹符删除、单层升级，text 与 tail 都要改写，正文不清洗。修正二为片段拦截器 XMLInterrupter，以三个依赖注入钩子接入格式无关引擎：送译前把 MathML 片段截走换成 LaTeX 占位片段，写回时行内嫁接、块级整体替换回原始 MathML。
