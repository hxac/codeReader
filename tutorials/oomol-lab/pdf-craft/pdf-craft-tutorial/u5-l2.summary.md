本讲精读 Jointer 及其配套模块（jointer、mergeable、reading_serials、content、expression）：它把按页按块的 OCR 输出（body_layouts / footnotes_layouts）重组为按自然段与资源组织的 ParagraphLayout / AssetLayout 流，正文与脚注各建一个 Jointer 实例。核心结论：主循环以「持有—吞并—冲刷」状态机跨阅读序号组合并段落，资源经 override 机制推迟到段落定型后输出，不打断自然段；能否合并由纯函数 check_mergeable 裁决——句尾符号或编号开头阻止合并，续行符号或 Unicode 连字符断词强制合并，其余默认合并，断词在冲刷前物理拼接；split_reading_serials 以 x 轴高度加权直方图在波谷处分栏，组内再按宽度变异系数二次切分被图片挤压的块；表格标题与脚注凭「正则说像＋几何验证（上方、贴近、水平相关）」归位到资源的 title / caption 字段；LaTeX 公式先以 PUA 占位符保护、再过 Markdown 解析，最终还原为 InlineExpression。合并后的块保留 page_index 与 det 坐标，产出供下一讲章节生成流程消费。
