本讲讲解 Markdown 渲染器：门面 `MarkdownRenderer` 先校验 `DocumentPackage`（Markdown 渲染不要求 `toc.xml`）再委托编排函数 `render_markdown_file`，流程为资源路径计算 → 第一遍扫描收集全书脚注 → 第二遍逐章渲染 → 追加 References 脚注区 → 复制封面。核心结论：资源复制目的地与图片链接引用路径分离计算（`assets_path` 决定目的地，链接由 `relpath` 从输出文件位置推算，不依赖工作目录）；脚注按 (page_index, order) 全书统一编号，章节文件经读取器工厂读两遍；表格先试 GFM 管道表格，遇 colspan/rowspan、多 tbody 或非法属性值即抛复杂度异常降级保留原始 HTML，宁丑勿丢数据，且因 HTMLTag 白名单而无风险；标题层级为 min(章级 level, 2) 加段落级 level 再封顶 6；文本成员分派为转义文本、公式定界符包裹、`[^n]` 脚注；`_normalize_paragraph` 折叠片段内换行并按汉字邻接补空格。三层结构 render_markdown_file → render_layouts → render_markdown_paragraph 是下一讲 EPUB 渲染器对比的基线。
