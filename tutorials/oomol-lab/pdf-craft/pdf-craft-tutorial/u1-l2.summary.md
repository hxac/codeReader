本讲搭建 pdf-craft 运行环境并完成首次转换。安装分两档：标准安装走 vendor OCR（远程服务、无需 GPU），local 扩展仅补齐本地 OCR 运行时且需自装 CUDA 版 PyTorch，Python 限 3.11–3.13。Poppler 是系统级依赖，pdf2image 调它把 PDF 页面渲染成图像，pip 装不了，用 pdfinfo -v 验证。库不读环境变量，.env.template 仅服务仓库 CLI；凭据一律经 PDFOptions(ocr=DeepSeekOCRVendorConfig(...)) 显式传入，其 api_key 以 field(repr=False) 屏蔽防泄漏。首次转换用门面方法 convert_pdf_to_markdown 一步完成提取与渲染：默认临时目录用完即删，传 package_path 可保留 DocumentPackage 中间包（chapters、assets、toc.xml、document.json，后者含 schema 与 page_pixel_sizes 字段）；返回 OCRTokensMetering 记录 OCR 输入输出 token 以估算成本。PDFCraft 构造是惰性的，真正提取时才校验配置。
