本讲对照阅读 multiply.py 与 arth.py 两个数值任务的数据生成脚本。两者共享按位数分层抽样的 get_random_num：用 DIGIT 控制目标位数，LESS_OR_EQUAL 决定采样下界——True 为 0（允许更短位数），False 为 max_num//10（强制恰好该位数）。multiply 只生成乘法，产出三元组 (num1, num2, result)，prompt 中运算符写死为 *；arth 设计上支持加减乘，产出含 operation 字段的四元组，prompt 用 {op} 变量从数据取运算符，但出厂仅配置乘法，真正开启加减乘只需改一行，减法分支还通过交换两数保证结果非负。两脚本的 prompt 均以未闭合的 <think> 结尾作为续写钩子，引导模型先输出思维链再给 <answer>。核心结论：两个 data_source（yolo/multiply-3_digit 与 yolo/arithmetic-3_digit）都路由到同一个奖励函数 multiply.compute_score，它只比较 <answer> 内整数与 ground_truth 是否相等，与运算符完全无关，因此扩展运算符无需改动任何奖励代码。读源码时需警惕注释陈旧与潜在 bug。
