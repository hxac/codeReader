本讲是「数据与任务定义」单元收口，讲解规则奖励函数：如何用确定性 Python 代码把模型回答转成训练分数。countdown 的 compute_score 走「提取→校验→求值→分级打分」：extract_solution 从生成文本抠出最后一个 `<answer>` 等式，validate_equation 校验等式所用数字是否与题目给定完全一致（防偷数字），evaluate_equation 用正则白名单加受限 eval 安全求值，按 |result−target|<1e-5 判定是否正确。打分分 0/0.1/1.0 三级。引入关键术语：稀疏奖励、奖励塑形（format_score 作为稠密的起步信号，设太高会诱发只刷格式的奖励黑客）、奖励路由（按 data_source 子串匹配选用哪个 compute_score）。RewardManager 调用判分后，把标量分数挂到回答最后一个有效 token 上，供后续优势函数计算承接。
