本讲拆解 fit() 中两个关键步骤。apply_kl_penalty 把任务分翻译成 RL 奖励：token_level_rewards = token_level_scores − beta·kld·response_mask，即在 score 上扣除 token 级 KL 罚，只作用于 response 段有效 token（response_mask 由 attention_mask 末尾切出）。关键术语：score（任务分）≠ reward（含 KL 罚的奖励）；KL 散度约束训练策略不偏离冻结的参考策略；kl_penalty 函数族提供 kl（默认、无偏但可为负）、abs、mse、low_var_kl（低方差，GRPO loss 端默认）四种估计。use_kl_loss=True 时跳过 KL penalty、令 reward 直接等于 score，避免 KL 在 loss 端重复计数，这也是 GAE 与 GRPO 路线的分水岭。compute_advantage 是分发器：gae 分支需 critic 做 GAE 反向递推，沿序列逐 token 优势不同；grpo 分支无需 critic，按 uid 对同 prompt 的 n 次采样做组内归一化，序列内优势为常数；returns = advantages + values 须用归一化前的 A。本讲产出 advantages 与 returns，供后续策略损失、价值损失讲义承接。
