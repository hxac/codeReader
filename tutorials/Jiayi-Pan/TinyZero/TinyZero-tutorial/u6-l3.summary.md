本讲聚焦 PPO 的 Critic（价值网络），它在 TinyZero 中是独立 CriticWorker，不在混合引擎内。它用 AutoModelForTokenClassification 设 num_labels=1 构造 value head，复用与 actor 相同的 backbone，但输出头由 hidden→vocab 改为 hidden→1，使每个 token 输出一个价值标量。底层 _forward_micro_batch 对整条序列前向后，用切片 [:, -response_length-1:-1] 取出恰好 response_length 个价值标量。compute_values 是只读估值（eval()+no_grad()），产出 values 供 GAE 算优势并乘 mask 清零 response 段的 pad；update_critic 以 GAE 的 returns 为监督目标，调用 clipped MSE 形式的 compute_value_loss 做带梯度的回归更新，走 mini→micro→梯度累积结构。关键结论：actor 与 critic 取 response 段切片完全一致，使 advantage、log-prob、value 在同一时间步对齐；critic 没有 ratio（它是确定性回归、不需重要性采样），但有「价值 clip」（cliprange_value 默认 0.5）限制单步更新幅度。本讲仅适用于 GAE 路线（use_critic=True），GRPO 路线不需要 critic。
