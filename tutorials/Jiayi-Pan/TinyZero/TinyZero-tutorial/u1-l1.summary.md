本讲是学习手册首篇，建立 TinyZero 的项目心智模型，不涉及代码。核心结论：TinyZero 是 DeepSeek R1 Zero 的轻量化复现实验，在 countdown（数字凑数）与 multiplication（乘法）两个任务上，用 3B 参数的 Qwen2.5 基座模型，验证「纯强化学习涌现推理」在小尺度、低成本（不到 30 美元）下同样成立、人人可复现。关键术语：R1 Zero 路线（完全跳过 SFT、直接在基座模型上做 RL，仅靠规则奖励信号让模型自学）；Aha moment（顿悟时刻，指模型自发涌现出自我验证 self-verification 与搜索 search 能力，伴随回答变长、奖励上升的指标信号）。技术栈上，训练框架基于开源的 veRL（HybridFlow 开源版，提供 PPO/GRPO 训练引擎与 vLLM 生成），基座用 Qwen2.5。仓库本质是「veRL + 任务数据 + 规则奖励函数」，真正属于 TinyZero 自己的代码仅集中在数据预处理与奖励打分两处，选择这两类任务是因为它们能给出精确、即时、自动的奖励信号（这是 RL 训练前提）。项目已标注弃用，建议生产直接用上游 veRL，因此学习价值主要在于读懂实现与思路，且 TinyZero 代码本是 veRL 子集。本讲只读 README 与 OLD_README 两个文档，后续 u1-l2 起逐层进入目录结构与源码。
