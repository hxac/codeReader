本讲承接「TinyZero＝veRL 框架＋任务数据＋规则奖励」的心智模型，专注环境安装与目录地图，不涉及任何算法代码。安装是分层的：conda 提供 Python→torch 提供 GPU 运行时→vllm 提供推理→ray 提供分布式编排→`pip install -e .` 把 verl 以可编辑方式（editable install）链入环境；关键约束是 vllm 必须在 verl 之前装，避免 torch 版本打架。三个构建文件职责不同：`requirements.txt` 是依赖清单（带 `tensordict<0.6`、`transformers<4.48`、`vllm<=0.6.3` 上限约束），`pyproject.toml` 是现代化主入口，`setup.py` 是备用兜底；两者描述同一个包 verl，版本号统一读自 `verl/version/version`（`0.1`），构成单一数据源；`package_data` 负责把 yaml 配置等非 .py 资源打进包。仓库目录分工清晰：`scripts/` 入口脚本、`examples/` 数据预处理与示例（TinyZero 贡献集中地）、`verl/` 是 vendored 进来的框架核心，内含 `trainer`（训练入口与 PPO 主循环）、`workers`（Actor/Critic/Rollout 等角色）、`utils`（含 `reward_score/` 规则奖励）、`single_controller`（Ray 调度）、`protocol.py`（DataProto 数据协议）。本讲为后续源码阅读篇建立导航基础。
