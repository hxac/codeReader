本讲剖析 RayPPOTrainer.fit() 在 driver 进程上的训练主循环：fit 自身不算梯度，只通过 RPC 调度 worker group（actor_rollout_wg、ref_policy_wg、critic_wg、rm_wg）并做本地轻量计算。一个 step 依次为：generate 对每个 prompt 采样 n 条回答；repeat(n, interleave=True) 复制 prompt 侧以对齐，uid 须在 repeat 前赋值供 GRPO 分组；_balance_batch 用 Karmarkar-Karp 在分片前重排，均衡各 DP rank 有效 token 数并写入 meta_info 的 global_token_num；ref/critic 前向；reward_fn 打稀疏 score（仅挂末位 token）；apply_kl_penalty 扣 KL 得 token_level_rewards；compute_advantage 算 advantage（gae 用 values，grpo 用 uid 组内归一化）；update_critic/update_actor 反向更新（含 critic_warmup 门控）；最后 validate/checkpoint。reward_fn 与 val_reward_fn 同属 RewardManager，验证用贪心且恒走规则奖励。_timer 配合 compute_timing_metrics 将各阶段耗时折算为 ms/token 以定位瓶颈。
