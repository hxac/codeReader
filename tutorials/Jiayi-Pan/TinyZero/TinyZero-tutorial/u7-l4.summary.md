本讲把 TinyZero 从默认的 FSDP+规则奖励拓宽到 Megatron 后端与神经网络奖励模型。其一，`strategy`（fsdp/megatron）在 main_ppo 装配处决定 import 哪份 Worker 类与哪种 WorkerGroup，fit() 训练主循环对后端无感知；actor 与 critic 必须同后端，而 reward_model.strategy 独立解耦。其二，Megatron 的 ActorRolloutRefWorker 仍用 role 标志做混合引擎，但多了 `mpu` 建立的 3D 并行（world_size=DP×TP×PP），actor 兼 rollout 时用 AllGatherPPModel 收拢流水线段，并配以 NVMegatronRayWorkerGroup 及 MEGATRON_COMPUTE_PROTO、MEGATRON_PP_AS_DP_PROTO 两个专用 Dispatch 变体。其三，RewardModelWorker 加载冻结的 AutoModelForTokenClassification（输出头 num_labels=1），前向得逐 token 标量，取末位有效 token 后展开回 token 级，产出与规则奖励同形状的 `rm_scores`。核心结论：model-based 与 rule-based 奖励串接而非互斥——开启 RM 时先注入 `rm_scores`，再由 reward_fn（RewardManager）见之即短路返回；默认关闭 RM，但 reward_fn 恒定创建且 countdown/multiply 规则奖励自足，故训练照常进行。
