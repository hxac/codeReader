本讲讲清 verl 的配置流动机制：配置由「`ppo_trainer.yaml` 默认值 + 命令行覆盖」两部分经 Hydra（底层 OmegaConf）在 `main_ppo.py` 的 `@hydra.main` 处拼合，最终 `resolve` 后交给训练逻辑。`ppo_trainer.yaml` 含六个顶层分组：`data`（数据/序列长度）、`actor_rollout_ref`（Actor+Rollout+Ref 三角色混合引擎）、`critic`（价值网络）、`reward_model`（神经网络 RM，TinyZero 默认关，改用规则奖励）、`algorithm`（RL 核心）、`trainer`（训练循环）。关键术语包括：覆盖（override）、变量插值（`${}`，覆盖后解析、一改全改）、混合引擎。命令行三种写法须区分：`a.b.c=v` 覆盖已有键、`+a.b.c=v` 新增键、`$VAR` 是 bash Shell 变量替换（与 Hydra 无关）。三个核心配置项为：`rollout.n`（每 prompt 采样数，GRPO 入口）、`adv_estimator`（`gae`/`grpo`，决定是否需要 critic）、`kl_ctrl`（嵌套字典，控制 KL 系数）。本讲是后续源码阅读篇的配置层导航。
