本讲是手册终篇，解读 R1 Zero"Aha moment"涌现机制，含四模块。①`compute_score` 三级打分 `{0,0.1,1.0}` 是涌现的物质基础：定义"什么算赢"，用稀疏结果奖励配策略梯度放大正确轨迹，越过容量临界点后行为质变。②`format_score=0.1` 是奖励塑形，给冷启动一个非零台阶；调过高诱发"只刷格式"的奖励黑客，调到 0 则消灭黑客却引入冷启动困难，关键看相对比例而非绝对值。③`kl_coef=0.001` 是 reward 端温和 KL 缰绳，公式 `token_level_rewards = token_level_scores - β·kld` 把策略拴在冻结的参考策略附近防灾难漂移，前提是已建 ref policy。④涌现是相变、有容量门槛：3B 能涌现自我验证与搜索，0.5B 不能；可观测签名为 `response_length/mean` 与 `critic/score/mean` 两条曲线同时上升。关键术语：结果奖励、奖励塑形、奖励黑客、相变。
