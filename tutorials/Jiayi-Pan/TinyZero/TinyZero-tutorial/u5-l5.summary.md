本讲实现 veRL 训练循环中的 GRPO 算法分支。核心思想是用「同一 prompt 的多次采样做组内归一化」替代 critic 价值网络：对同一 prompt 的 n 条回答，用组均值做基线、组标准差做归一化得到 z-score 形式的序列级常数优势，再广播到所有 response token，从而省掉整个价值模型（use_critic=False）。关键术语包括：compute_grpo_outcome_advantage（按 uid 分组、用 id2mean/id2std 归一化）、uid 分组机制（必须在 repeat 之前赋值，配合 DataProto.repeat(interleave=True) 与 generate_sequences 的连续 n 条回答对齐）、单样本兜底（mean=0、std=1 以避免除零，也是 GRPO 必须 rollout.n>1 的根因）。第三个模块是 loss 端 KL：use_kl_loss=True 让 reward 不扣 KL（token_level_rewards=token_level_scores），改在 actor 的 update_policy 中以 kl_loss*kl_loss_coef（默认 low_var_kl 低方差估计）加进策略损失，与组内归一化的相对优势尺度更协调。核心结论：启用 GRPO 的最小必改项为 adv_estimator=grpo + use_kl_loss=True + rollout.n>1。
