本讲是「核心计算单元」单元第一讲，解决复数存储与旋转因子来源两个基础问题。核心编码约定是：一个复数被拼成 `2*W` 位整数，**实部占高 W 位、虚部占低 W 位**（高实低虚），`butterfly.v` 的 `[2*X_WDTH-1:0]` 端口即据此拆分。数据通道由 `c_to_int` 编码，采用近似 Q1.(width-1) 格式（`1.0 ≈ 2^(width-1)`），并强制实虚部幅度落在 [-1,1]。旋转因子由 `f_to_istr` 仅量化幅度（Q2.(width-2) 格式，`1.0 = 2^(width-2)`，能精确表示 ±1.0），正负号与幅度解耦，由 `make_twiddle_factor_file` 单独记录、最终渲染成 `-N'sd...` 有符号字面量。两套定点尺度相差一倍但位宽必须相等（`tf_width == x_width`），由蝶形运算中 `>>> (X_WDTH-2)` 右移对齐。最后用 jinja2 模板把 N/2 个旋转因子（因 `W^(k+N/2) = -W^k`，只需 N/2 个）渲染成时钟驱动的 `case` 查表 ROM `twiddlefactors_N.v`，该文件必须在 iverilog 编译前生成。这些脚本为 Python 2 代码。引入的关键术语：旋转因子 W_N^k、定点数/Q 格式、高实低虚、X_WDTH/TF_WDTH、查表 ROM。
