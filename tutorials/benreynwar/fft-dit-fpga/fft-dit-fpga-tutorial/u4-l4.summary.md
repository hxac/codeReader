本讲（参数化扩展）是「仿真验证与扩展」单元收尾，讲清 FFT 核参数的定义、流动与约束。项目有两种参数化：`dit`/`butterfly` 用 Verilog `parameter`（编译期可改），`twiddlefactors` 则是「生成时固化」，其 N 与位宽由 `generate_twiddlefactors.py` 渲染 jinja2 模板时烧死进 `case` 查表，换 N 必须重新生成文件。可调参数为 `N`、`NLOG2`、`X_WDTH`、`TF_WDTH`、`DEBUGMODE`，`butterfly` 的 `M_WDTH` 由 `dit` 按 `3+2*NLOG2` 自动算出。两条硬约束贯穿全讲：`TF_WDTH == X_WDTH`（根因是蝶形单元数据与旋转因子共用单一位宽参数），以及 `N` 必须为 2 的幂（地址位运算前提）。防溢出靠每级右移一位的定标，总缩小 N 倍，故硬件输出为「真值÷N」，测试台把 numpy 金标准相应除以 N；输入过快则置 `overflow` 信号使测试失败。参数经 Python 测试台、iverilog 宏、`dut_dit.v` 外壳传至子模块，其中 `dut_dit.v` 位置参数第 3、4 位与 `dit` 参数名交叉（两宽相等时无害）。改 N 往往只需改 `nlog2` 一处即可联动，其余由 `prepare()` 与生成脚本联动；脚本为 Python 2 语法，Py3 下待验证。
