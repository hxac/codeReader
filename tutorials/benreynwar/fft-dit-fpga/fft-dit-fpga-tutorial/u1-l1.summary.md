本讲建立项目全局地图：用 Verilog 在 FPGA 上实现一个按时域抽取（DIT）的基-2 FFT，核心是三个模块。butterfly 是单步蝶形运算（YA=XA+W·XB、YB=XA−W·XB），即 FFT 的计算原子；twiddlefactors 由 Python 脚本把旋转因子 e^(−i2πk/N) 预量化成定点查表模块，编译前必须先生成；dit 是顶层主控，例化上述两者，配合输入/工作/输出三级缓冲与四状态机，按 NLOG2 级逐级合并。引入的关键概念：DFT、FFT、基-2、DIT、旋转因子（twiddle factor）、蝶形运算、级（stage）、定点量化。核心结论：为防溢出，每级右移定标使输出整体缩小约 N 倍；复数按实部高位、虚部低位编码，且 TF_WDTH 须等于 X_WDTH；子模块间不直接连线，所有数据经 dit 内部 wire 中转；README 中的 buffer.v 实际对应 butterfly.v。
