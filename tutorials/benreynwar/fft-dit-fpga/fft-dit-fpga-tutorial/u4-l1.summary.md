本讲讲透 MyHDL 与 Verilog 协同仿真的数据通路。其一，dut_dit.v 是协同仿真顶层模块，给被测设计 dit 套一层外壳：声明 7 个信号，用 $from_myhdl/$to_myhdl 登记方向，按位置例化 dit（in_x/out_x 改名为 din/dout）。其二，方向约定以 Python 为参照：$from_myhdl 登记 Python→Verilog 的输入，须为 reg（4 个）；$to_myhdl 登记 Verilog→Python 的输出，由 DUT 驱动为 wire（3 个）。二者只在 initial 中登记清单，真正逐拍搬运信号的是 VPI 模块 myhdl.vpi。其三，simulate() 用 Cosimulation 把 Python 的 Signal 与 Verilog 信号按名字绑定——关键字参数名等于 Verilog 信号名、参数值承载 Python 数据——再把 DUT、clk_driver、control 三路生成器并发运行。核心结论：Python 写的 4 个 reg 恰为 dit 输入、DUT 驱动的 3 个 wire 恰为 dit 输出，三者环环相扣使数据通路闭合。关键术语：顶层模块、DUT、reg/wire、VPI、Cosimulation、Signal、生成器。
