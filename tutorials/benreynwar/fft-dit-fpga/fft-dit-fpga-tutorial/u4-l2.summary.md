本讲介绍 `pyfft.py`——一个仅 46 行的纯 Python 浮点 DIT 参考模型（金标准）。它解决的核心问题是：`numpy.fft.fft` 只能验证最终结果对不对，而 `fftstages` 能算出**每一级中间结果**，从而像剥洋葱一样把 `dit` 硬件逐级与精确答案对照，精准定位错误级别。

三个最小模块：（1）**DIT 合并等式**——$X_k=E_k+W_N^kO_k$、$X_{k+N/2}=E_k-W_N^kO_k$，同时写在 `dit.v` 注释和 `pyfft` 的 `fs` 块里；`pyfft` 后半段用下标 $k-N/2$ 配 $\text{tf}=W_N^k$ 代替显式减号，代数等价。（2）**递归与逐级输出**——`fftstages` 用 `cs[::2]`/`cs[1::2]` 抽取偶/奇子序列，用 `chain(*zip(es,os))` 把子级交错拼回，返回 NLOG2+1 个数组：`stages[0]`=原始输入，`stages[-1]`=完整 FFT，`stages[-2]`=$E_k/O_k$ 的交错排列。（3）**与硬件逐点对应**——`pyfft.stages[i]` 恰等于 `dit` 做完第 $i$ 级蝶形后缓冲的内容（$N=8$ 时各级对应 $S=4,2,1$），因为两边共用同一种 $k\cdot S+j$ 交错布局。

引入的关键术语：参考模型/金标准、级（stage）、抽取（decimation）、交错拼接、定标差异。核心结论：硬件每级右移一位防溢出（总定标缩小 $N$ 倍），故比对规则为「硬件第 $i$ 级 $\times 2^i$ = `pyfft.stages[i]`」，最终级乘 $N$；每一级用的旋转因子都是 $W_N^k$，与 u3-l3 的 `tf_addr=kS`、u2-l1 的 $N/2$ 个旋转因子自洽。
