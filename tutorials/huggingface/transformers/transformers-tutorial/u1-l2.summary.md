本讲把「transformers 是模型定义框架」的认知落到可运行环境，只解决「把项目跑起来」。硬门槛为 Python ≥ 3.10、PyTorch ≥ 2.4，分别由 setup.py 的 python_requires 与 `"torch>=2.4"` 把关。安装有四条主流路径：基础安装、带 torch 的 extras 安装、源码安装、可编辑安装（-e，本地开发用），另有 CPU-only 与 conda 两种特例。

setup.py 用 `_deps` 集中声明依赖，用 `extras` 字典（torch/vision/audio/video/all/dev）按需分组，`install_requires` 仅列 9 个无条件硬依赖（tokenizers、safetensors、huggingface-hub 等），把 torch 留作可选——这正是「轻量核心、重量级后端可选」理念在打包层的体现。安装后即获得 `transformers` CLI（含 env/serve/chat 等子命令），可用官方一句话 `pipeline('sentiment-analysis')` 验证安装是否成功。

模型默认从 Hugging Face Hub 下载并缓存到 `HF_HUB_CACHE`（默认 `~/.cache/huggingface/hub`），缓存路径优先级为 `HF_HUB_CACHE` > `HF_HOME` > `XDG_CACHE_HOME`；设 `HF_HUB_OFFLINE=1` 或 `local_files_only=True` 可走纯离线。本讲引入的 pipeline、extras、硬依赖、Hub 缓存、离线模式等术语，供后续讲义承接。
