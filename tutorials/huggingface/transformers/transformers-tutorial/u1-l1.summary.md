本讲建立理解 transformers 仓库的认知坐标，覆盖三个最小模块。其一，定位：transformers 是「模型定义框架（model-definition framework）」，而非训练框架或推理引擎——它集中定义模型结构、超参与预处理，使该定义被整个生态共同接受，成为连接各类工具的「枢纽（pivot）」，核心理念即「集中化模型定义」。其二，设计哲学：PyTorch-first、忠实论文、好用好改；每个模型由三类核心对象构成——Configuration（配置）、Model（模型）、Preprocessing（预处理），三者共享 from_pretrained / save_pretrained / push_to_hub 统一接口；评审遵循八条核心准则（如 One Model One File、Code is the Product、Standardize Don't Abstract、DRY*），解释了源码中反直觉的设计。其三，生态枢纽：训练框架、推理引擎、相邻建模库三类工具均复用这份模型定义，项目亦划有明确使用边界（非积木箱、训练 API 仅服务其 PyTorch 模型、示例仅为示例）。
