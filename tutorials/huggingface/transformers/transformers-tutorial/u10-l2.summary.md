本讲讲解 transformers 的导出子系统 exporters/：把 PyTorch 模型追踪成目标运行时可消费的静态计算图，回答「导出格式」与「导出参数」两个问题。格式由 ExportFormat 枚举（dynamo/onnx/executorch）表达，作为配置序列化往返的类型标签；参数由配置数据类表达，都继承 ExportConfigMixin。核心是继承复用：DynamoExporter 为基座，调 torch.export 产出 ExportedProgram；OnnxExporter 与 ExecutorchExporter 都继承它，先复用基座追踪、再各自降级为 ONNX 或 .pte，配置链 DynamoConfig ← OnnxConfig/ExecutorchConfig 与之同构。HfExporter 抽象基类统一 export(model, sample_inputs, config) 接口并在构造时校验环境，export_for_generation 把生成式模型拆成 prefill/decode 组件分别导出。AutoExportConfig 与 AutoHfExporter 复用全库 Auto 范式，靠两张对齐映射表按 export_format 自动选类，并可用 register 装饰器注册自定义后端。该体系目前为实验性，含大量绕开上游 bug 的补丁。
