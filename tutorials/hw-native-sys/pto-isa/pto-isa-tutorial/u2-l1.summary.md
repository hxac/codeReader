本讲建立 PTO 跨后端的类型与常量基础，覆盖 common 层三个头文件。type.hpp 在 CPU/CostModel 分支将 half、aclFloat16、float16_t 映射为 `_Float16`、float32_t 映射为 float，bfloat16_t 按工具链能力三档取值，NPU 分支则零定义、直接用 CCE 内建类型，实现「一份代码多后端」；AICORE、PTO_INST、PTO_INTERNAL、OP_NAME 等宏让同一函数声明在两种编译器下都合法，PTO_STATIC_ASSERT/PTO_CPU_ASSERT 统一诊断格式。核心结论：dtype 白名单检查位于各 NPU 后端的 Check 函数（A2A3 比 A5 窄），CPU 模拟器不拦截，故「CPU 跑通」不等于全后端合法。constants.hpp 定义 32 字节块、256 字节 repeat、REPEAT_MAX=255 及新增 BIT_TO_BYTE 等度量衡，指令实现按 256/sizeof(T)、32/sizeof(T) 推导 elementsPerRepeat 等参数，UB/L1 总容量另在 buffer_limits.hpp。指令签名共用的聚合类型必须定义在 common 层：MrgSortExecutedNumList 承载 TMRGSORT 变长归并的逐 list 进度续传协议，TRandomKey/TRandomCounter 是 TRANDOM 的种子别名。kernel_meta.hpp 以 16 字节 TLV 写入 `.ascend.meta` 段，向运行时声明 SYNCALL 内核的核型（AIC/AIV/混合）与任务配比。另引入 TileType、BLayout、RoundMode、Layout 行为枚举与五维 GlobalTensorDim 几何约束，供后续讲义承接。
