本讲精读 type.hpp、constants.hpp、kernel_meta.hpp 三个公共头文件，建立 PTO 的类型与常量地基。类型别名上，内核统一书写 half、bfloat16_t、float32_t 等名字：CPU 模拟分支给出等价 C++ 定义（bfloat16_t 依工具链三档取值，默认 _Float16 占位），NPU 分支直用 CCE 内建类型，实现一份代码多后端编译；AICORE、PTO_INST 等修饰宏与断言宏 PTO_STATIC_ASSERT 让同一函数签名跨编译器合法、诊断消息可检索。核心结论：dtype 白名单在各 NPU 后端的 Check 函数中，A2A3 与 A5 不同且 A5 更宽，CPU 模拟器不查类型，故 CPU 跑通不等于全后端合法。constants.hpp 定义 32 字节块、256 字节 repeat、每块 16 元素等硬件度量衡，指令实现按 256/sizeof(T) 现场推导参数，片上缓冲总容量另在 buffer_limits.hpp，UB 尾部还有 PTO 自留的 8KB 临时区。kernel_meta.hpp 用 16 字节 TLV 结构写入 ELF 的 .ascend.meta 段，链接期向运行时声明 SYNCALL 内核的核型（AIC/AIV/混合主核）与 AIC:AIV 任务配比。TileType、BLayout、RoundMode 等行为枚举在此点名，留待后续讲义展开。
