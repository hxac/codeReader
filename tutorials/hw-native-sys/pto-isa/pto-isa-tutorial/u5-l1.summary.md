本讲剖析 PTO-ISA 的 ST(单指令测试)体系。ST 用例目录由「四件套」构成——main.cpp(gtest 用例、aclrt 生命周期与结果比对)、kernel 文件(device 侧指令实现)、gen_data.py(生成输入与 golden)、CMakeLists.txt(一行注册)，靠「TEST_F 用例名 = golden 数据目录名 = gen_data 参数」的命名契约衔接，新增或修改用例须三处同步。golden 由 numpy 按指令数学语义独立计算，固定随机种子保证可复现，且只填 tile 有效区域。比对分两类：浮点走 ResultCmp(eps 容差、错误配额、zeroCount 哨兵)，整数走 ResultCmpExact 逐位精确，公共实现在各后端共享的 test_common.h。驱动脚本 run_st.py 以 -r/-v/-t/-g 完成「构建→生成 golden→运行」三段式并按 -v 路由 a2a3/a5 目录，CPU 模拟器同构入口是 run_cpu.py(-r sim 指 NPU 仿真器而非 CPU 模拟器)，run_st.sh 的 simple/all 是冒烟清单。本版本 A5 ST 扩容三事：int64/uint64 用例(寄存器对仿真配套，经 if constexpr 分流精确比对)、gen_data 的 custom_name 机制、新增 tpushpop_subblock_dispatch 用例验证 TPUSH/TPOP 固定派发到逻辑 sub-block 0;A5 侧 kernel 由 ccec 编成动态库再与 main 链接，不同于 CPU 侧单目标编译。
