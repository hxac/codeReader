本讲覆盖 manual 模式下的片上内存规划。TASSIGN(tile, addr) 把只有编译期形状、不拥有内存的 Tile 绑定到片上缓冲的具体字节偏移，地址相对各自缓冲从 0 编号，TileType 决定落点（Vec→UB、Acc→L0C 等）；它是绑定不是分配，不查重叠与越界，NPU 上偏移被重解释为 __ubuf__ 等地址空间限定指针，CPU 模拟器则映射进 NPUMemoryModel 模拟区域。容量约束查 buffer_limits.hpp：A2A3 UB 192KB、A5 256KB，一律 32 字节对齐，A2A3 的 UB 尾部 0x2E000 起 8KB 是 PTO 自留临时区，不可压占。乒乓双缓冲为每个 tile 预留两个不重叠槽位，TASSIGN 在循环外一次绑好、循环内只切下标。安全靠两层编译期防线：框架的 TASSIGN<Addr>(tile) 触发 SA-0351~0354 检查（仅 NPU 生效），用户 static_assert 自算总账且全后端生效；CPU 模拟器故意不模拟容量紧缺，跑通不代表地址规划合法。
