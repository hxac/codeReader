本讲讲 GM 侧数据抽象，与下一讲片上侧 Tile 互为镜像，覆盖五个最小模块：五维坐标系、Shape、Stride、GlobalTensor 打包与 TASSIGN 移动窗口。PTO 把 GM 张量统一建模为五维（二维惯用法：前三维为 1，行在 DIM_3、列在 DIM_4）；GlobalTensor 由 `__gm__` 指针、Shape、Stride 与 Layout 提示打包，是不拥有内存的轻量视图，由 TLOAD/TSTORE 消费。Shape/Stride 采用「静态维进类型、动态维（DYNAMIC=-1）留运行期」的混合设计，构造实参个数须等于动态维个数。步长单位是元素，offset=Σi_d·S_d；窗口 Shape 描述搬运块大小，Stride 描述其在大矩阵中的走法（行步长为整矩阵列数）；TileShape2D 是 Shape 助手，BaseShape2D 实为 Stride 助手。查询分静态维模板版与动态维运行期版两套。TASSIGN 一词两用：Tile 收整数 UB 偏移，GlobalTensor 收同类型指针整体平移窗口。步长错误在 CPU 模拟器上即可暴露。
