本讲区分 PTO-ISA 三种运行模式并跑通最易上手的 CPU 模拟器：板端（npu）需真机与 CANN，NPU 模拟器（sim）仅需 CANN，CPU 模拟器跨平台且免昇腾环境。关键机制：PTO 是 header-only 模板库，编译时定义 `__CPU_SIM` 宏，同一份内核即在本机以 C++ 语义执行，模拟器并非独立程序，而是编入每个测试/demo 二进制。入口 `tests/run_cpu.py` 的两种模式互斥：默认 ST 单指令测试模式（探测编译器→CMake 构建→gen_data.py 生成 golden→gtest 运行→汇总），`--demo` 模式则全新构建并运行 GEMM/FlashAttention/MLA 示例。demo 展示「GlobalTensor/Tile 描述数据，TASSIGN/TLOAD/计算指令/TSTORE 写回」的编程范式，FlashAttention 以 TMATMUL 加在线 softmax 指令链实现完整算子。结论：脚本级耗时含编译不可比性能，perf 行的 avg_ms/gflops 才是有效指标；`./build.sh --cpu` 为 CI 全量入口。
