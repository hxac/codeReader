本讲承接点对点通信，覆盖异步指令族与集合通信。TPUT/TGET_ASYNC 由 DMA 引擎（SDMA/URMA/RDMA）在 GM 间直达，UB 仅存 scratch tile 控制元数据；编程模型为 BuildAsyncSession 一次构建 AsyncSession、多次提交 AsyncEvent、按 quiet 语义 Wait(session) 排空——同 session 按提交顺序完成，事件不能作后续指令变参。TPUT_ASYNC_NOTIFY 合并搬载荷与置远端 int32 信号，保证载荷先于信号；NotifyOp 分 Set 与 AtomicAdd（RDMA 仅 Set）；peer 在 SDMA 被忽略，在 URMA/RDMA 用于选队列与注册内存（MR）。两套等待不可混用：AsyncEvent::Wait 等本地提交完成，TWAIT/TTEST 等远端信号到达，与 TNOTIFY 配对。TREDUCE 是指令级集合（ParallelGroup、root 单方执行、乒乓 tile）；allgather 是算法级集合，由点对点原语组合出多核 PUT/GET 与环算法，SDMA 靠 HCCL 窗口翻译远端地址，URMA 靠注册内存基址加对称布局偏移，环算法轮间目前依赖 host barrier。
