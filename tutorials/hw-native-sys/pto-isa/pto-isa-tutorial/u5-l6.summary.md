本讲围绕 A5（Ascend 950）后端四个模块：A5 与 a2a3 差异（Cube+Vector 混合核、目录独立、指令覆盖交错而非包含，移植第一步是查指令×后端状态表）；MX（microscaling）格式（fp4 两元素打包一字节，每 32 个元素共享一个 float8_e8m0_t scale，scale tile 由 GetScaleAddr 绑定数据 tile、随乒乓槽切换）；TMATMUL_MX 低精度 matmul（CheckMadMxValid 要求 C 恒 float、K 为 64 的倍数，性能内核示范 TLOAD→TEXTRACT→TMATMUL_MX→TSTORE 四级流水）；TPUSH/TPOP 的 TileSplitAxis 切分语义与本版本「no-split 固定派发逻辑 sub-block 0」修复。核心结论：「一份签名、多套实现」只保 API 形状一致，不保各后端可用性与约束刻度一致，a2a3→A5 适配需按 dtype、scale tile、GM 偏移、布局、粒度、写回流水等八条清单逐项核对。
