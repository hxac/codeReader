PTO（Parallel Tile Operation）是 Ascend CANN 定义的跨代际 Tile 级虚拟 ISA；本仓库是它的 header-only 模板实现库（含示例、测试与文档），目标是让算子代码在 A2/A3/A5 等 Ascend 芯片间平滑迁移，同时不隐藏底层能力——tile 尺寸、形状与指令排布仍由程序员控制。三个权威查询位置：项目定位看根 README；指令清单看 docs/PTOISA.md，当前共 149 条指令、11 个大类（Elementwise、Tile-Scalar、Axis Reduce/Expand、Matrix Multiply、Memory、Communication 等）；逐指令平台可用性看 include/README.md 状态表，后端为 CPU、Costmodel、A2、A3、A5、Kirin 六列，取值 Yes/TODO/No/留空，A2 与 A3 共用实现故两列恒同，CPU 与 NPU 列并非子集关系。生态上本仓库是指令底座，上层集成 PyPTO、TileLang Ascend、PTOAS、pto-dsl 四个项目；注意通信分两条线：TPUSH/TPOP 是单 NPU 内 Cube-Vector 核间 FIFO，TPUT/TGET/TREDUCE 等是跨 NPU 传输。
