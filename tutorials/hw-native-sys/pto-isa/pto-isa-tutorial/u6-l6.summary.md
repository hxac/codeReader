本讲走读 A5 混合核（AIC+AIV）上的端到端 MoE 融合算子 dispatch_mega_combine：把 token 量化、路由交换、分组 FFN、合并还原压进一个 kernel，流水为 FrontReorder→Dispatch→GMM1→SwiGLU→GMM2→Combine→Unpermute；AIC 负责矩阵乘，AIV0 兼任 Dispatch、元数据与 producer，AIV1 为配对 CV 消费者。核心术语：CV pipe——TMOV 定向搬运为数据面、intra-block 旗标为控制面，构成深度 1 的 AIC→AIV1 单槽 FIFO，红线是旗标必须后于数据；GMM 任务邮箱——P2C/C2P 票据表加六状态车道状态机做设备侧动态派发，GMM1→GMM2 凭票据区间无缝切换、无全局 barrier；MPI 只做 host bootstrap，HCCL window 以 RemotePtr 平移和独占缓存行信号区承载跨 rank 数据面。核心结论：256×256 tile 使握手与票据次数减半、算术强度翻倍，配合 x/gate 共享 L0C 累加器与 depth=1 单槽，在 256 KiB UB 约束下同降占用与等待，大 M 实测提升 11%~17%。
