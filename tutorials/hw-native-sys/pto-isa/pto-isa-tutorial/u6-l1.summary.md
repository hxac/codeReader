本讲建立单元六的通信 ISA 全景地图：跨 NPU 通信被做成指令而非运行时库调用，按「参与方×完成方式」分四象限——同步点对点 TPUT/TGET（数据必经 UB 中的 staging tile 中转，大张量由指令内部 2D 滑窗分块）；集合 TGATHER/TSCATTER/TBROADCAST/TREDUCE（以 ParallelGroup 组织、仅 root 执行）；信号 TNOTIFY/TWAIT/TTEST（int32、无数据载荷）；异步 *_ASYNC（DMA 引擎 GM 直达、返回 AsyncEvent），与同步路径复用 MTE 流水线形成对照。装配层 pto_comm_instr_impl.hpp 按 A2A3/A5/CPU 三宏互斥选拨后端，声明层 #if 须与之咬合，故 TPUT_ASYNC_NOTIFY 无 CPU 实现。本版本关键变化：新增 RDMA 引擎（仅支持 Set 通知，HNS1825 后端），notify 实现头改由 pkg_inc 相对路径解析。引入的关键术语：rank/peer、staging tile、MR、DmaEngine/CollEngine，以及运行时三件套 AsyncSession/BuildAsyncSession/AsyncEvent，供 u6-l2/l3/l5 承接展开。
