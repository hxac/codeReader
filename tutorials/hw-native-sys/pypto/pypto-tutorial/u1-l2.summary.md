本讲讲清 PyPTO「纯 Python 层 + nanobind 编译的 pypto_core 扩展」的双层构建链路，分四个最小模块：其一，pyproject.toml 构建声明，由 scikit-build-core 在隔离环境中驱动 CMake，「兼容区间」与钉死版本约束两份文件分工，保证构建可复现；其二，根 CMakeLists.txt 一份脚本双模式运行（pip 触发的 scikit 模式与手动原生 cmake 模式），新增 C++ 源文件必须登记进 PYPTO_SOURCES 清单，msgpack-c 与 libbacktrace 以 git 子模块方式接入；其三，nanobind 绑定层把约 250 个源文件整体编成 pypto_core 模块，import 瞬间执行算子注册表自检、快速失败；其四，测试并行度由 load-env.sh 按机器限定，禁止裸用 -j 与 -n auto。核心结论：改 python/pypto 纯 Python 层即时生效，改 C++ 部分必须重新编译；开发模式安装只省重装、不省重编。
