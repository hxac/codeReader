本讲给出 PyPTO 全景：它是面向 AI 加速器的编译框架而非 Python 计算库，`@pl.jit` 标记的 DSL 被解析成多级 IR，经 Pass 流水线降级，由 CodeGen 生成 PTO 虚拟指令。核心是 PTO 范式与 Tile 编程模型：Tensor 为全局内存整块数组，Tile 为片上硬件感知数据块；显式写法遵循 load→计算→store 三段式，计算须置于 `pl.at` 作用域内，输出用 `pl.Out` 原地写回。分层抽象服务三类开发者：算法用 Tensor 级、性能用 Tile 级、系统用 Block/ISA 级，层级间由编译 Pass（如 ConvertTensorToTileOps）自动衔接，图变换链为 Tensor Graph → Tile Graph → Block Graph → Execution Graph。生态含五仓库：pypto 编译、pypto-lib 模型库、PTOAS 汇编、pto-isa 指令集、simpler 运行时；InCore 函数经 `.pto` 契约走向 AICore，编排函数经 PTO2 运行时 API 走向 AICPU，最终以 MPMD 三程序模型调度执行；正确性验证以 torch.allclose 对照为基本套路。
