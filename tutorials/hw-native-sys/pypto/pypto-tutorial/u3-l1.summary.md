本讲讲清 PyPTO 把 Python DSL 源码变成 IR 的完整路径：装饰器入口（`@pl.function`/`@pl.program` 用 inspect 抓源码）与文本入口（`pl.parse`/`pl.parse_program` 经 exec 复用装饰器链）最终汇入同一个 `ASTParser`——入口负责拿源码，解析器负责翻译。核心是三张映射表：`parse_statement` 把 for/if/赋值分别映射为 ForStmt/IfStmt/AssignStmt（ForKind 由迭代器查 `_ITERATOR_TO_KIND` 决定，if 有无 `pl.yield_` 决定生成 phi 还是把变量泄漏给 ConvertToSSA）；`parse_op_call` 按属性链段数与命名空间（`pl.`、`pl.tile.`、`pld.`、`pl.builtin.` 等）路由算子调用；`invoke_dsl` 把解析器的 ir.Expr 包装成 DSL 的 Tensor/Tile/Scalar 后调用包装函数，类型检查与分发权住在包装层而非解析器。本讲重点更新（PR #2526）补上了 `pl.builtin.<ns>.<op>` 回读路径 `_parse_builtin_op`：经 `_create_internal_op_call` 构建、封闭于 builtin. 注册命名空间、前置校验 device 与 arg_directions 不变量，使 Pass 42 降级出的 internal_only 算子打印后可再解析；但 CommDomainScopeStmt 被打成注释、window_buffer 回引不打印，整程序往返结构相等仍不成立，相关测试固定用 BEFORE_AND_AFTER 模式。
