本讲为 Pass 流水线单元首讲，回答 47 个 Pass 接力改写 IR 时编译器靠什么保证不出错。核心结论：PassContext 是线程本地栈式作用域配置，承载仪器、验证等级、诊断配置、内存规划器与后端句柄，with 进出栈、嵌套覆盖，compile() 继承外层配置；Instrument 是挂在 Pass 前后的回调。两级验证开关须分清：VerificationLevel 定流水线自动验证强度（Basic 对轻量属性每属性恰验一次），VerificationMode 定逐 Pass 验证时机且连带全部结构属性。PropertyVerifierRegistry 以 IRProperty 到工厂的单例映射组织验证规则，诊断携带 span，把 IR 违规定位回作者源码行列。PassProperties 用 required/produced/invalidated 声明契约，流水线只验 produced 且已验即跳过，「先失效再重产」才换来第二次验证窗口，AccCompactValid（L0C 紧凑契约）与 AivSplitValid 均循此模式。
