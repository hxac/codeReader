本讲讲 IR 的二进制往返与结构化比较，与 u4-l7 的文本往返互为姊妹篇，含四个最小模块：序列化器把 IR 图压平成 MessagePack 字节，每个对象带递增 id 只写一次，重复引用写 `{"ref": id}`，从而保留指针共享与 MemRef 的分配身份（指针先登记再递归，可处理环）；反序列化器查 id 到指针的引用表、按类型注册表重建图，旧格式 blob 退化为按 base 名字驻留；节点级 `structural_equal`/`assert_structural_equal` 按反射字段描述符递归比较，忽略 Span 与名字类字段，IgnoreField 恒等、DefField 强制开启变量自动映射、UsualField 跟随调用方开关，断言版失配时报出字段路径与两侧打印；表达式级 `AreExprsEqual` 手工选择比较粒度——ConstInt 按值、二元/一元/Call 按结构、其余按指针，本版本新增一元（Cast）分支且必须比较结果 dtype。核心结论：往返比较须传 `enable_auto_mapping=True`（反序列化的 Var 全是新指针），Pass 的 before/after 测试默认关闭即可；相等与哈希必须逐分支同步（`HashExprForAreExprsEqual` 新增对应标签分支），否则「相等而哈希不同」会让 set/dict 与 CSE 缓存把相等对象当成两个键。
