本讲确立数据布局的本质：把张量逻辑索引映射到物理位置的函数；布局决定访存合并、bank 冲突与硬件格式，性能可差一个数量级。①Shape-Stride 模型记号 S[(shape):(strides)]：物理位置＝索引与步长的点积，行主序、列主序只是两组参数，转置等视图操作只改元数据、不搬数据。②分块（tiling）是对索引再切分：坐标经 flatten/unflatten 拆成 tile_row、row_in_tile、tile_col、col_in_tile 四维，分块布局仍是同一记号。③一般布局函数 f_D(x)：先按 shape 做 unflatten 再与 strides 点积；shape 管索引怎么切、strides 管数据怎么摆，二者正交，行主序只是退化特例。本讲仅映射到一维线性地址，命名轴、复制/偏移、swizzle 留待后续讲义扩展。
