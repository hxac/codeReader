本讲收尾单元三，含三个模块。优化阶梯把逼近屋顶的路排为四级：更好的算法、更高并行、更合适的引擎、重叠与资源调优，低级不做则高级无从谈起，结构性改动可能先搭骨架后兑现；书中 GEMM 九步为实例，前四步（并行与 TMA）约 142×，后五步（软件流水线、持久内核、warp 特化、双 CTA cluster、多消费者）约 5×，终对齐 cuBLAS。重叠消除的是空闲而非依赖：TMA 加载、MMA 计算、epilogue 回写三路并发处理相邻 tile，靠 full/empty 双向屏障与多级 SMEM 流水（PIPE_DEPTH）交接缓冲所有权，稳态吞吐由最慢段决定。occupancy 是隐藏延迟的另一途径，受寄存器、SMEM、TMEM 列与 warp/CTA 槽位的资源压力约束，每 SM 驻留 CTA 数取各资源上限的最小值，最小项即绑定资源；现代 Tensor Core 内核常故意以低 occupancy 换显式重叠，occupancy 本身不是质量度量，判据是关键硬件单元是否活跃。由此与 roofline 三步分析法合成「先定级、再体检」的方法论。
