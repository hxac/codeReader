本讲讲解 GPU 六级线程执行层级：thread（以 warp 内 lane ID 标识）、warp（32 线程 SIMT 锁步发射、可逐 lane 掩蔽，分支发散需串行）、warpgroup（4 warp/128 线程，wgmma 发起单位，对齐 TMEM 的 128 lane）、CTA（驻留单 SM、私有 SMEM）、cluster（跨 SM，经 DSMEM 互访）、grid（一次 launch 全体）。并介绍 Blackwell SM 内 CUDA core、Tensor Core、SMEM、TMEM、寄存器堆、TMA 引擎六类单元及其加载/回写数据通路。核心结论是操作 scope：TMA 单线程发起、CTA 级受益；tcgen05.mma 单线程提交、硬件分发 128 lane；tcgen05.ld 各 warp 读 32-lane 窗口；2-CTA 协作 MMA 跨 CTA 对。发起与执行分离是异步的硬件根源；scope 与数据布局、派发机制合看，构成后续 TIRx 三要素。
