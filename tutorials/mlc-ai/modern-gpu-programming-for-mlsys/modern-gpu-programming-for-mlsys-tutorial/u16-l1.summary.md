本讲讲教材可视化资产的生产机制，分三模块。模块一为静态图产线：img/scripts 下的 matplotlib 脚本是图的源码，图片只是构建产物；参数集中在文件头，可复现、可参数化，改图先改脚本，注意相对路径保存需在脚本目录运行、以 __file__ 推算则随处可跑。模块二为交互演示：_extra/demo 下 19 个自包含 HTML 采用“状态对象＋纯重绘函数”模式，公共样式与行为外置于 viz-base 公共库；swizzle 演示的全部数学是 bank=c 与 c⊕r，周期数等于 bank 分桶后的最大多重度，直观呈现列读 8-way 冲突与 XOR swizzle 解法。模块三为挂载机制：Sphinx 以 html_extra_path 把 _extra 原样拷入站点根并保留目录结构（相对引用因此在源码树与站点同样成立），正文用 {raw} html 块内嵌 iframe、按约定路径 /demo/ 引用，站点侧 demo-embed 自动套缩放查看器，演示内部经 postMessage 上报 demoHeight 消息实现高度自适应；中文站另挂 demo_zh 汉化镜像。关键术语：脚本即源码、自包含演示、状态对象＋重绘函数、html_extra_path、demoHeight 上报、XOR swizzle 最小同构模型。
