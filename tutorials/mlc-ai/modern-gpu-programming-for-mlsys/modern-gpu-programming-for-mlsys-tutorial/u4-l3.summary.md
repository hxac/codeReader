本讲打破「一个逻辑元素只有一个物理位置」的限制，为命名轴布局引入两类扩展：replication（复制）用 R[shape : strides] 引入独立于逻辑索引的副本坐标 r，产生偏移 r·s@axis，让同一元素出现在多个物理位置；offset（偏移，记 O）只对基础坐标做固定平移，不产生副本。布局语义由此升级为集合 L(x)={D(x)+r+O | r∈R}；layout.apply() 只算基础坐标，副本信息留在 layout.replica，由 tile 操作处理。硬件动机是 Blackwell block-scaled MMA（MXFP8/NVFP4）的 scale factor：SFA/SFB 按 local_lane=m%32、TCol=m//32、byte=sfk 打包进 32-lane 基础 tile，再经 .warpx4（即 R[4:32@TLane]）复制到 TMEM 四个 32-lane 分区；须区分「Mgroup 沿 TCol 打包」与「分区沿 TLane 复制」这两组语义不同的「4」。同一套 S+R+O 记号还能统一描述多设备 GPU mesh 上的按轴分片、跨设备复制与平移摆放（设备轴与 @TLane、@laneid 同为命名轴）。另外 8-bit 元素布局的 @TCol 以 buffer 元素为单位，4 个元素占一个 32-bit 硬件列。
