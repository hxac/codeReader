本讲为数据布局单元收官，处理「同一 tile 既要按行读、又要按列读」时任何简单布局无法兼顾的矛盾。SMEM 划分为 32 个 bank（bank=(addr//4)%32），同一 wavefront 内落进同 bank 不同地址的访问被串行化，冲突重数即所需周期数；行主序利行伤列，简单布局只能讨好一方。XOR swizzle 以 mapped_col = c ⊕ r 重排地址：双射性同时保住行读与列读（列读由 8 周期降至 1 周期），自反性使读写两端共用同一条公式。8×8 演示（1 元素=1 bank）与真实 SWIZZLE_128B 同构：XOR 作用于 16 B sector（占 4 bank），atom 是 8 行×N B 的最小地址重复单元，按连续维字节宽度在 128B/64B/32B 模式中选最大可支撑者。关键结论：XOR 置换非仿射，不属于 S[...] 布局本身，而是与之组合的独立地址变换；同一 tile 的所有访问必须用同一 swizzle 模式，否则读错数据。sector、atom、wavefront、bank conflict 等术语将由 ldmatrix、wgmma 描述符与 TMA 各讲承接。
