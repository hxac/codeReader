Step 5 用双缓冲软件流水线解除 Step 4 的存储冲突：SMEM 只有一对操作数 tile，下一次 load 没有独立落点，因此给 A、B 缓冲加 PIPE_DEPTH 前导维构成环形缓冲（三要素中仅 layout 变化，scope 与 dispatch 不变）。协议是启动 prefetch 注满各级 stage，主循环按 stage=k mod S 消费，再把第 k+S 块 tile 装回刚释放的 stage，尾部自然排空。每个 stage 配一道 tma_bar，使数据、字节账本与相位在 stage 粒度对齐；MMA 因 TMEM 累加器唯一而共用一道 mma_bar。两个相位变量速率不同：phase_mma 每迭代翻转，phase_tma 扫完一圈才翻转。单 warpgroup 仍串行且无显式 empty 屏障，load 与 MMA 尚未真正重叠，完整重叠待 Step 7 拆分 warp 角色；SMEM 成本约为 S×32KB+32KB（B200 每 SM 上限 228KB）；Step 6 持久内核要求每 tile 屏障使用偶数次才能把相位复位为 0。
