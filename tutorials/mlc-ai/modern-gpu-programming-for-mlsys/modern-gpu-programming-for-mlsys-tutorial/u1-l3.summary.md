本讲是环境课，不写内核但支撑后续全部实践，含四个模块：①TIRx 编译器安装——它并非独立包，而是 Apache TVM wheel 中的 `tvm.tirx` 模块，须与 `cuda-bindings`（NVRTC 绑定）同装并钉死 `apache-tvm==0.26.0`，用 `tvm.__file__` 排查旧检出污染；②sm_100a 硬件门槛——书中内核依赖 `tcgen05.mma`、TMEM 等 Blackwell 专属特性，工具链装好不等于内核能跑；③内核运行五步回路——构造 PrimFunc，经 `tvm.compile(tir_pipeline="tirx")` 编译，`ex.mod` 直接收 PyTorch 张量，`assert_close` 对照 fp32 参考断言，并可检视 lowering 前后两级代码；因 TIRx 依赖 Python 源码检视解析内核，内核必须写在文件或 notebook 单元格，不能塞进 `python -c`；④可选参考内核仓库 tirx-kernels，其 revision 与 TVM 版本成对钉死，FA4 等章正文即节选自它。无 Blackwell GPU 者依环境限制清单改走源码推演路径。
