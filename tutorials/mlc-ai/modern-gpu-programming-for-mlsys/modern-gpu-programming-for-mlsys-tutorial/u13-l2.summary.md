本讲精读 hgemm_v8：在 Step 7 三角色流水线骨架不变的前提下，把协作范围从单 CTA 扩到双 CTA cluster，用 cta_group=2 的协作 MMA 一次产出 256×256 输出 tile，实测 0.23→0.104 ms（约 2.2 倍）。切分规则为 A 沿 M 对半、各 CTA 就近读取，B 的两个切片被双方输出共用，硬件经 DSMEM 跨 CTA 读对端 Bsmem，使 staged 操作数复用翻倍（算术强度 64→128 FLOP/byte）；加载地址 m_st/n_st 由 cbx 选切片，回写块 n_st_epi 仅由 no 选择、不含 cbx。关键概念：cluster 与 DSMEM、cta_group::2（MMA 仍由 CTA 0 单线程发起）、remote_view(0) 单点账本（tma2mma、ld2mma）与 cta_mask=3 双副本广播（mma2tma、mma2ld）两类跨 CTA 屏障机制。核心结论：expect_tx 字节数须乘 CTA_GROUP 合账登记（65536 字节，一道账本管两家 TMA），少登则静默错果，多登或漏广播则挂死。
