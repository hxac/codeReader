本讲承接 u7-l1，讲清 tcgen05.mma 的 cta_group 限定符与 block-scaled 放置规则。核心结论：cta_group::1 只用当前 CTA 的 SMEM/TMEM，::2 使用 cluster 内 rank 仅差最低位的 CTA 对（一偶一奇，对端须保持活跃），且不改变单线程发起语义。累加器 TMEM 映射由 cta_group、M、A 是否 dense、是否 .ws 共同决定，本讲覆盖四种配置：cg1 M=128 恒等映射、cg1 M=64 Layout F（四组 16 行、对齐 0/16 互补，两块 tile 可共用同批 TMEM 列）、cg2 M=256 Layout A（M 连续对半切）、cg2 M=128 Layout B（M 对半加 N 对折进 Lane 轴），epilogue 的 tcgen05.ld 须用兼容地址与形状读回。block-scaled MMA（MXFP8/NVFP4）中 A/B 走 SMEM、SFA/SFB 经 tcgen05.cp 进 TMEM：SFA 沿 M 分片，SFB 完整 N 组播到 CTA 对双方，每 CTA 内再以 .warpx4 复制到四个 32-lane 分区。串联 cp/mma/ld 需满足指向正确 CTA、布局一致、先走完成与排序三条件，检查口诀为三问法。
