本讲沿 FA4 的「QKᵀ MMA → softmax → PV MMA」计算链精读中间的数值内容。模块一：WG3 warp 0 以一条 `Tx.warp.gemm_async(dispatch="tcgen05")` 用 SMEM 中的 Q/K（各 128×HEAD_DIM）算出 128×128 的 fp32 score tile `S` 写入 TMEM 的 `S_region[q_stage]`，行对 query、列对 key，不含 1/√d 缩放；完成信号由 `elect_sync` 选出的单线程发 `tcgen05.commit` 挂到 `s_ready`（TCGen05Bar），softmax 组等到即「S 可读」。模块二：在线 softmax 逐行递推，每行一线程持有整行 score；核心是 α=log₂e/√d、δ=(r_old−r_c)α、acc_scale=2^δ 三件套，δ≥−8 保留旧参考且 acc_scale 显式置精确 1.0，δ<−8 才换参考并重缩放旧 row_sum/O；−inf 参考取 row_max_safe=0 保证掩码行安全；P=exp2((S−ref)·α) 以 fp16 写回 TMEM。模块三：base-2 改写仅为代数变形，真正优化是把指数元素拆给硬件 exp2 与 FMA 三次多项式（ex2_emulation_2）两条执行路径并发分摊，所有递推公式不变。这些为 u14-l4（PV MMA 与 TMEM 布局复用）铺垫。
