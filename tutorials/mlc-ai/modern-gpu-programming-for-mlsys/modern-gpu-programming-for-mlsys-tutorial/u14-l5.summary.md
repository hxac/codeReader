本讲承接 u14-l4 的 PV MMA，补齐 WG2 对 TMEM 累加器 O 的校正与最终写回。条件 rescaling：换参考判据为 delta=(r_old−r_c)·scale_log2，delta≥−8 时保留旧参考、acc_scale=1、旧 O 不动；delta<−8 才乘 exp2(delta) 重缩放——这是性能优化而非数学近似。校正循环：softmax 把 per-row acc_scale 写入 SMEM mailbox（sScale），以硬件命名屏障报就绪、softmax_corr.empty 归还槽；WG2 用行级阈值加 warp 级 any_sync 两级过滤决定是否执行 TMEM→寄存器→TMEM 的读-乘-写（每 warp 凭 32-lane 访问窗口负责 32 行），跳过数据路径但不跳过同步——两道 arrive 无条件执行，softmax_corr.empty 归还的是另一 stage 的槽以维持交替。epilogue：non-causal 由 WG2 等最终 row_sum、o_ready、corr_epi.empty 后归一化、转 fp16、写 O_smem，经 corr_epi.full 放行 WG3 的 TMA store；causal 则移回 WG0/WG1。核心结论：稳态 K/V 迭代中 O 的显式搬运为 0 或一次片上往返，整个任务 O 仅一次单向写出 GMEM、从不读回；LSE=log(row_sum)+r_i/√d 可从现有状态恢复，延迟 rescaling 不影响其正确性。
