本讲精读 GEMM 系列第一个内核 hgemm_v1：单 CTA 同步计算 128×128、K=64 的输出 tile，作为后续八步的正确性基线。四个模块：一是单 tile 数据流，按「分配/加载/计算发起/回写/释放」四部件无循环走通 GMEM→SMEM→TMEM→RF→GMEM 路径，三处 cta_sync 各守一道交接；二是 SMEMPool 分配，控制对象（tmem_addr、mma_bar）占低地址，操作数经 move_base_to(1024) 摆放，TMEM 一律申请 512 列再切片，mma_shared_layout 绑定的 128B swizzle 同时约束读写两端；三是 MMA 发起与等待，双层守卫（warp_id==0 加 elect_sync）使恰好一个线程发射 Tx.gemm_async 与 tcgen05.commit，全体线程在 mbarrier 上 try_wait，gemm_async 按 ⌈BLK_K/16⌉ 展开为 tcgen05.mma 指令；四是 TMEM 读回，Dreg 经 view 套 tid_in_wg 布局成 warpgroup 集体视图，tcgen05.ld 异步须 wait::ld，每线程持有一整输出行。核心结论（章末练习 1）：加载由 128 线程协作而 MMA 由单线程发起，cta_sync 提供汇合与内存可见性双重保障，mma_bar 只追踪输出侧完成。关键术语：正确性基线、epilogue、elect_sync、cta_group、accum、launch 权收敛。四条局限（单 K tile、M/N 钉死、同步拷贝、无重叠）分别由 Step 2/3/4/5 解决，相位翻转为下一讲伏笔。
