本讲是单元二「GPU 执行模型」收尾，回答「真正干活的硬件是什么、如何配合」。核心结论有三：其一，SM 内三类引擎各司其职——CUDA Core 跑标量/向量指令与控制流，Tensor Core 以 tile 粒度做矩阵乘累加（吞吐高约一个量级，Blackwell tcgen05 指令把累加器放入 TMEM），TMA 引擎负责异步整块搬运；分工原则是矩阵乘交 Tensor Core、杂务交 CUDA Core、搬运交 TMA。其二，一个 GEMM tile 的生命期分三段：Load（TMA 将 GMEM 数据搬入 SMEM）、Compute（MMA 从 SMEM 累加进 TMEM）、Epilogue（读回寄存器、转输出 dtype、经 SMEM 由 TMA store 写回），可展开为七步数据路径。其三，数据依赖只在同一 tile 内部，流水线可让三引擎分别处理相邻 tile（k-1/k/k+1）重叠执行，稳态吞吐由最慢段决定；每个交接处需完成信号（字节计数 barrier、MMA 完成信号、stage 复用信号）保障正确性。关键术语：流水线、重叠、空闲、完成信号、epilogue、stage 缓冲，均为后续 GEMM 优化单元的地基。
