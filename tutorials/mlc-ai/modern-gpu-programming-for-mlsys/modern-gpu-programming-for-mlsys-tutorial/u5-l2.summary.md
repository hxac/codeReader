本讲进入 Hopper 世代：wgmma.mma_async 由 warpgroup（4 个 warp、128 线程）协同执行。输入路径升级为矩阵描述符：B 一律经描述符直读 SMEM，A 可来自 SMEM（SS 形式）或寄存器（RS 形式），内核不再用 ldmatrix 拼 B 的 fragment。描述符是装在寄存器里的 64 位值，含 start address、ldo、sdo、base offset、swizzle mode 五个字段，三个地址字段均以 16 字节为单位编码（addr≫4）；K-major swizzled 布局下 ldo 固定编码 1，sdo 为相邻 8 行 atom 的间距（SWIZZLE_128B 的 atom 是 8×128B 的 1KB 连续块）。核心原则是描述符必须与 SMEM 实际字节一致，否则字节到了、元素认错。C/D 累加器仍分布在每线程寄存器中，Hopper 内核因此同时维护描述符与寄存器 fragment 两套布局表示；输入描述符化并未减轻累加器带来的寄存器压力，这正是 Blackwell 把累加器搬进 TMEM 的直接动机。
