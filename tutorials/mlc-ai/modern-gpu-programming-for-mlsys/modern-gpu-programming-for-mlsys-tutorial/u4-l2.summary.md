本讲引入「命名轴（named axes）」，将布局函数的返回值从单个线性地址推广为按轴名累加的坐标字典：记法仍是 S[(shape):(strides)]，只是给每个 stride 标注归属的物理轴（如 4@laneid），同一轴被多个 iter 引用时贡献相加，shape/strides 的点积规则不变；线性地址只是所有 stride 同落一根 @m 轴的退化特例。两个应用现场：其一，TMEM 是 128 Lane × 512 Column 的二维地址空间，用 @TLane 与 @TCol 描述，TMEM 的 Lane 是数据侧地址坐标而非线程的 laneid；其二，寄存器 fragment 的数据散布在 warp 各线程的寄存器中，需 @laneid 与 @reg（lane 本地槽位）共同定位，典型布局 S[(8,4,2):(4@laneid,1@laneid,1@reg)] 即 laneid = row·4 + col//2、reg = col%2，warp 级布局再引入 @warpid（TIRx API 中以默认轴 m 代替 reg）。双射性（元素总数等于各轴取值数之积）是检验布局的基本工具。这些记号将被后续的复制/偏移、swizzle 与 Tensor Core fragment 布局分析直接沿用。
