本讲回答“数据放在哪里”这一根本问题，比较四种存储空间的取舍：GMEM 归整个 device，是大容量 HBM 显存；SMEM 归单个 CTA，作低延迟的 tile 暂存与 TMA 中转；TMEM 归 CTA，专存 MMA 累加器；RF 每线程私有，最快但容量最小。内核优化的核心是让数据停留在离计算最近的层级。TMEM 是 Blackwell 新增的二维片上空间（128 lane × 最多 512 列 × 每列 32 bit），tcgen05 把累加器写入其中以卸下寄存器压力；它须显式分配与释放，epilogue 阶段由 4 个 warp 各读自己的 32-lane 窗口。DSMEM 允许同 cluster 的 CTA 跨 SM 互访对方 SMEM（不合并分配）；2-CTA GEMM 中每个 CTA 存自己的 A/B 切片并读对端 B 切片，以一次 cta_group::2 协作 MMA 产出更大的输出 tile。TIRx 中这四个空间对应 buffer 的 scope 参数。
