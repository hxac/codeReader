本讲义围绕 u9-l1 的 `hgemm_v1` 内核解决「怎么编译、怎么验证」两个问题，含三个最小模块。模块一讲 `tvm.compile(tvm.IRModule({"main": kernel}), target="cuda", tir_pipeline="tirx")` 背后的流水线：引入 `PrimFunc`、`IRModule`、pass 等术语，说明 `tirx_pipeline` 共 19 个 pass，核心是首个 pass `LowerTIRx`（= `TilePrimitiveDispatch` 选具体实现 + `LowerTIRxCleanup` 把逻辑布局变物理索引、抽象线程标识变线程绑定），后经 `FlattenBuffer`、`SplitHostDevice` 拆出 host 启动器与 device 内核，产出可直接调用的 `Executable`。模块二讲验证纪律：`ex.mod(...)` 直接收 PyTorch 张量，参考实现先 `.float()` 升 fp32 再乘、最后 `.half()`，与内核 fp32 累加对齐，用 `torch.testing.assert_close` 断言，容差 `rtol=2e-2, atol=1e-2`，先打印 max_err 再断言。模块三讲两级检视：`kernel.show()`/`kernel.script()` 看 lowering 前 tile 级 IR，`ex.mod.imports[0].inspect_source()` 看生成 CUDA，可验证「一条 `Tx.gemm_async` 展开为 4 条 `tcgen05.mma`」「`cta_sync()` 变 `__syncthreads()`」等映射。核心结论：编译通过不等于算对，每次编译后必须立即数值对照；无 Blackwell GPU 时 IR 构造与检视仍可学习。
