本讲指出该仓库的产品是文档站点而非软件包，组织上遵循「一章一目录」（正文为各 chapter 目录下的 index.md）与「中英同构镜像」（中文路径即英文路径加 zh 前缀）两条约定，首页 toctree 声明全书骨架。本地构建三步：安装依赖、sphinx-build 生成 HTML、起本地服务器预览，全程无需 GPU 与 tvm（运行书中内核才需要，属下一讲主题）。关键机制：conf.py 的 exclude_patterns 使英文构建排除 zh 等非正文，html_extra_path 把交互演示原样拷入站点供正文 iframe 嵌入。zh 是可独立构建的中文源树，按章发布，语言切换按钮按对方同名文件是否存在决定同页跳转或回首页。CI 对每次 push/PR 做两轮警告即失败的严格构建，仅 main 分支的 push 经 gh-pages 发布上线。
