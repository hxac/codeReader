本讲补齐 FA4 的收尾机制，含三个模块。causal 掩码采用右下对齐，K/V 块分「全有效／部分有效／跳过」两类处理：get_n_block_max 截断 K/V 循环、整块跳过无效块，边界块照常计算、由 softmax 在指数化前把无效列置 −∞（不进 row_max、p 为 0，对在线 softmax 零副作用）；causal 还把 PV 拆分改为 64+64、epilogue 移入 WG0/WG1。GQA 把 128 行 Q tile 重释为「序列位置 × 组内 query head」，由 GQA_RATIO 与 SEQ_Q_PER_TILE 刻画、按 row//GQA_RATIO 拆包；Q 加载与 O 回写用 4D 视图翻译坐标，K/V 不复制、整 tile 共享，MMA 与 softmax 完全无感知。调度按任务成本分家：non-causal 任务等价，用线性 persistent 调度器；causal 成本随 m_block 递增，用 LPT 调度器（反转 m_block 先重后轻、L2_SWIZZLE 分组保 L2），二者接口相同、差异全在 next_tile()。编译验证有硬约束：GQA_RATIO 为整数且整除 128、HEAD_DIM 为 128、non-causal 需序列长被 128 整除（causal 靠列掩码豁免）；数值误差偏大应先查 softmax 交接屏障而非本讲机制。
