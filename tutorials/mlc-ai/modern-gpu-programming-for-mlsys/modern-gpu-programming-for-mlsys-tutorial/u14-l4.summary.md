本讲读完 FA4 计算链末段 PV MMA（O←O+PV）：P 在 TMEM（fp16 权重）、V 在 SMEM、O 为 TMEM fp32 累加器，由 WG3 warp0 以 tcgen05 发起；归约维按 K_SPLIT（causal 64 / non-causal 96）切成两段，第一段等 kv_load.full 与 p_o_rescale，第二段只加等 p_ready_2 且恒 accum=True。同一 512 物理列 TMEM 经 move_base_to(0) 建立 tmem/tmem_as_f16 双视图，fp16 视图列 c 对应物理列 ⌊c/2⌋，128 个 fp16 恰占 64 物理列。因 2×(128_S+128_O) 已排满 512 列，P 不设独立区域而覆写 S 后半：S0=[0,128)、P0=[64,128)、S1=[128,256)、P1=[192,256)、O0/O1 独占后 256 列，重叠是时序复用，S 与 P 从不同时占用同一些位。防护屏障为 s_ready、写 P 后的 tcgen05.wait::st 加 p_o_rescale（256 次到达，含 WG2 对 O 的放行）、p_ready_2、同线程固定 tcgen05 序列与 o_ready；FA4 相比 GEMM 多出的屏障大多围绕 softmax。这些屏障的 WG2 半与 o_ready 之后的路径是下一讲（条件 rescaling 与 writeback）的入口。
