本讲拆解 TIRx 主仿射布局对象 TileLayout 的构造，完整写法是 S、R 与 offset 三件套，内部把每个 iter 存为（extent、stride、axis）三元组；记号与命名轴（laneid、warpid、tid_in_wg、TLane、TCol 及默认轴 m）都是参与 Python 求值的真实对象，非仿射的 swizzle 则留给 ComposeLayout。shard 由 S 构造，回答每个逻辑元素落在哪：求值经行主序展平、按 extent 拆分、按轴记账（同轴相加）三步得到基础坐标 D(x)；逻辑 shape 与 iter 个数解耦，约束是元素数守恒。replica 登记独立于逻辑索引的副本，offset 只做整体平移，完整语义为集合 L(x)={D(x)+r+O}；apply 只算 D(x)+O，副本留给消费布局的 tile 操作处理，典型现场是 scale factor 复制到四个 32-lane 分区。布局经 pool.alloc、T.decl_buffer 与 view 三个挂载点附到 buffer 上随其携带，tmem_datapath_layout 等构造器只是便捷包装。
