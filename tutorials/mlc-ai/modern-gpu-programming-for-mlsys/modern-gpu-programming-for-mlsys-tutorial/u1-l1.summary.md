本讲为全套手册的开篇导航。该仓库是面向 Blackwell GPU（sm_100a）的开源内核编程教材，用 TIRx——一个在 IR 层面编写内核的 Python DSL——承载“理解硬件 → 学会编程 → 写出 SOTA 内核”的教学主线；硬件是主角，DSL 是载体。全书递进：Part I 建立硬件直觉，Part II 讲 TIRx 编程模型，Part III 将 GEMM 经九步优化做到对齐 cuBLAS，Part IV 构建 Flash Attention 4，附录按需查阅。本讲引入的关键术语包括 GPU 内核、GEMM、Flash Attention、DSL、IR 与 Blackwell。贯穿后续讲义的两条主线内核是 GEMM 与 Flash Attention，三个核心优化思想是数据布局、异步数据搬运、异步协调。此外强调 TIRx 依赖 Python 源码检视解析内核，示例必须写在文件或 notebook 单元格中，不能放入 `python -c`。
