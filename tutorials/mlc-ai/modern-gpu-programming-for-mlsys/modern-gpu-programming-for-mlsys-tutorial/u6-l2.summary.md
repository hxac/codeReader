本讲承接 u6-l1 的 box 宽度约束，分三个模块。模块一定义 swizzle atom：SWIZZLE_128B 以 8 行×128B（1024B）为重复单元，地址重排只发生在 atom 内部，故 box 最内维不得超过 swizzle 宽度（fp16 下 64 个元素）；64B/32B 模式 atom 更窄、XOR 键按 row//2、row//4 共享。模块二用 3D TMA 搬更宽的行：按 group = j // 64 切组，把切片重解释为 (group,row,col) 三维视图，数据不动、只改 tensor map 的坐标解释，一条 cp.async.bulk.tensor.3d 一次搬完多个 atom，两个 group 在 SMEM 中是连续的 2KB 块；维度从内到外排列（globalDim=[64,16,4]，指令坐标 {col,row,group}）。模块三比较行布局：XOR 键 = 128B 跨度编号 % 8，行距 128B 时键每行 +1、8 行取遍 8 个 bank sector 无冲突；保留 256B 行步长则键 +2、仅剩 4 个、2-way 冲突——行步长决定冲突。关键术语：sector（16B）、swizzle atom、group、bank sector；核心公式 physical_sector = logical_sector XOR (row % 8)。结论：窄数据仍按完整 swizzle 宽度预留 SMEM，tensor map、SMEM 布局与 MMA 指令须描述同一物理排布。
