本讲是「TMA 异步数据搬运」单元第一讲，只讲 2D TMA 基本模型，分三个模块。模块一：tensor map 描述符是静态、可跨大量拷贝复用的“档案”，登记 dtype、globalDim（维度从最内维数起）、globalStrides（以字节计）、单次拷贝的 boxDim 与 swizzle 模式；每次拷贝变化的只是指令参数——tile 起始坐标与 SMEM 目的地址。模块二：TMA 引擎数据路径——warp 内单个线程提交 cp.async.bulk.tensor（其余线程瞬间掩蔽），引擎异步完成 box 内全部地址计算与搬运，发起与执行分离；传输完成须靠 mbarrier 字节计数追踪，CTA 栅栏无效。模块三：写入时 swizzle——引擎按 physical_sector = col XOR row 在写 SMEM 路径上顺带重排，数据到达即符合 MMA 期望排布，跨行访问从 8-way bank 冲突降为无冲突，线程无需手算 XOR。关键术语：sector（16 字节最小搬运单位）、box、swizzle atom。一致性纪律：tensor map、SMEM 布局与 MMA 指令必须描述同一物理排布；SWIZZLE_128B 下 box 最内连续维不得超过 128 字节（fp16 恰 64 元素）。多 swizzle atom 的 3D TMA 与 load/store 完成机制留待后两讲。
