本讲为「Blackwell Tensor Core 与 TMEM」单元首讲，分三个模块。模块一：tcgen05.mma 是单线程语义的 tile 级指令，由 elect_sync 选出的唯一线程发出，硬件完成整个矩阵乘累加；操作数不含寄存器——A、B 经 SMEM 描述符 a-desc/b-desc 读取，累加器地址为 d-tmem，idesc 打包 M/N/K 与类型，enable-input-d 即 accum 标志。模块二：长寿命累加器从寄存器搬进 CTA 级 TMEM（128 Lane×512 Col、每格 32 bit），主循环不再占用寄存器，epilogue 用 tcgen05.ld 读回；cta_group::1、M=128 时行 m 直映 TLane、N 沿列展开，K 每步更新同一区域，首步 accum=0 写入、其后 accum=1 累加，最后一步后才得到完整 C。模块三：MMA 异步执行，tcgen05.commit 把该线程已发异步操作挂到 mbarrier，硬件完成后主动到达（与 TMA 靠字节计数归零不同）；消费者先 try_wait 相位（复用须翻转相位）、再 tcgen05.fence::after_thread_sync 排序、后 tcgen05.ld 并 wait::ld。另：Tx.gemm_async 是 tile 操作，会降级为一串 k16 指令。
