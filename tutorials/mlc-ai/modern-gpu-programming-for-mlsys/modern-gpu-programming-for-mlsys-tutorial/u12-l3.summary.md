本讲（Step 6）将 GEMM 内核从「一 CTA 一 tile」改为持久内核（persistent kernel）：launch 固定 SM_COUNT=148 个一维 CTA，SMEM、屏障、TMEM 等初始化由每 tile 一次摊销为每 CTA 一次，CTA 经外层 while 循环连续认领输出 tile，内层 K 流水线不变。核心新概念是 tile scheduler（ClusterPersistentScheduler2D），以 init/valid/m_idx/n_idx/next_tile 接口把 tile 分配移入内核，属静态调度。l2_group_size=8 决定的遍历顺序让共享同一 B tile 的任务相邻、整组 A 工作集（约 8 MiB）在 L2 反复命中，是统计性改善而非保证。屏障跨 tile 复用带来相位复位约束：每 tile 使用次数须为偶数，奇偶才能归零，对应断言 K_TILES % (2*PIPE_DEPTH)==0。三要素中仅 scope 变，layout 与 dispatch 不变。4096×4096 输出共 1024 个 tile，平均每 CTA 约 6.9 个。
