本讲为「Blackwell Tensor Core 与 TMEM」单元收官，讲解 TMEM 与寄存器之间唯一的常规数据通道 tcgen05.ld/st。核心结论：二者是 warp 集体指令，warp 内 32 个线程执行同一条指令、提供同一个 [taddr]，硬件按各线程 lane ID 分发数据，因此不能用单线程发起；一次搬运量由 .shape（参与 lane 数与每 lane 位宽）和 .num（重复次数）决定，可据此算出每线程寄存器用量，这是硬件搬运形状，须与 MMA 的 M×N×K 逻辑形状区分。针对 16-bit 数据，.pack::16b / .unpack::16b 把相邻两列的 16-bit 片段打包进或拆出一个 32-bit 寄存器，FA4 用 tmem 与 tmem_as_f16 双视图寻址同一块物理存储，换算规则为 fp16 视图列 j 对应物理列 ⌊j/2⌋、槽位 j mod 2，128 个 fp16 恰占 64 个物理列。异步纪律：使用目的寄存器前须 wait::ld，依赖 TMEM 写入完成前须 wait::st，两条 wait 各自覆盖当前线程此前发出的全部同类操作；若数据要跨线程消费，还需 barrier arrive/wait 与 tcgen05.fence 建立顺序，这直接引出下一单元的 mbarrier。
