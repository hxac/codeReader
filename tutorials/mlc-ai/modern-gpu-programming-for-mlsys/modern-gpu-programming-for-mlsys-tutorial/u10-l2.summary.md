本讲承接 u10-l1 的 TileLayout 三件套（S/R/offset），聚焦命名轴语义与 apply() 前向映射。命名轴不是匿名维度：laneid、warpid、tid_in_wg 等属线程侧坐标，TLane、TCol 属 TMEM 数据侧；轴名是布局的一部分，不同轴上的相同整数代表不同硬件位置，同一根轴被多个 iter 引用时贡献相加；默认轴 m 的语义随 buffer scope 变化，挂在 local buffer 上即线程本地线性槽位，取代旧 @reg 记号。apply() 前向映射四步：行主序展平、按 shard extents 切分、分量按 stride@axis 记账、叠加 offset；它只返回基础坐标 D(x)+O，replica 留给消费布局的 tile 操作枚举。TMEM 布局无特殊语法：累加器是纯 shard 且维度可非 2 的幂（TCol=112a+c，两段 112 列恰覆盖 224 列）；scale factor 在同一 TLane/TCol 空间加 R[4:32@TLane]，四副本覆盖四个 32-lane 分区。存储轴 stride 以 buffer 元素计，硬件 TMEM 列固定 32 bit，元素宽 w 时每列打包 32/w 个元素；元素数守恒可检验布局双射性。下讲 u10-l3 进入 ComposeLayout 与 XOR swizzle。
