本讲是 TIRx 语言参考第二篇，覆盖控制流与线程同步。核心结论：TIRx 控制流是「薄」的直译层——if/else、四种循环（T.serial、T.unroll、T.vectorized、T.grid）、while 各映射到对应 CUDA 结构，T.if_then_else 只选值不分支，编译器不会自动添加线程守卫。关键概念：均匀（uniform）与发散（divergent）控制流、协作范围——集体操作（如 cta_sync、warpgroup 集体 tile 操作）必须被其范围内全部线程一致到达，放进发散分支即死锁，检查方法是「守卫集合须等于集体操作要求的到达集合」。引入 T.cuda.* / T.ptx.* 内置函数命名空间（同步、mbarrier、归约、PTX 数据搬运）与 T.cuda.func_call 内联 CUDA 兜底。四个高频易错语义：mbarrier 相位（try_wait 等待相位不同，复用须翻转本地 phase）、elect_sync 选举 warp 内单 lane 而非 lane 0、命名屏障 warpgroup_sync(id) 的 ID 纪律、三种 fence 的排序分工。实践方法是用「代码行 / 语义 / 协作范围」三列表格标注 hgemm_v1 与 GEMM Step 7 的守卫与同步。
