本讲为 GEMM 系列开篇。约定：全书统一 D=AB^T（A 为 M×K、B 为 N×K、D 为 M×N），B 按 N×K 存储以免去运行时转置；fp16 存储输出、fp32 累加，吞吐按 TFLOPS=2MNK/t 换算。Blackwell 数据路径为 GMEM→SMEM→TMEM→RF→GMEM 六站五跳，各跳由 TMA 引擎、Tensor Core、CUDA Core 分工执行，末两跳合称 epilogue；后续各步优化只改某跳的执行方式，路径站点序列不变。九步优化路线：Step 1–3 搭正确性骨架（单 tile、K 循环、空间分块），4–6 引入 TMA、双缓冲流水线、持久内核，7–9 做 warp 特化、双 CTA cluster、多消费者；每步以 scope/layout/dispatch 三要素记录变化。B200 上 4096³ fp16 从 70 ms 优化到 0.094 ms（约 744×），对齐 cuBLAS。
