本讲为 Tensor Core 布局三代演进的收官，聚焦 Blackwell：`tcgen05.mma` 沿用 Hopper 的矩阵描述符从 SMEM 读 A/B（部分模式 A 也可来自 TMEM），而 C/D 累加器搬进 TMEM，寄存器 fragment 退居 epilogue 边界，由异步的 `tcgen05.ld` 读回并须先 `wait::ld`，纪律是写的布局必须等于读的布局。block-scaled MMA 的 SFA/SFB 也必须驻留 TMEM，而 TMA 止步 SMEM，故需 `tcgen05.cp`（`.32x128b.warpx4`）补上「最后一公里」，一条指令同时完成打包与四分区组播；CTA pair 中 SFA 沿 M 分片、SFB 复制到两侧。`scale_vec` 的 1X/2X/4X 决定 32-bit 字内字节打包，`SFA_ID` 选起始字节；并须区分三种独立的「重复」——字内字节重复、跨分区组播、scale 对整个 K 块的数学复用。
