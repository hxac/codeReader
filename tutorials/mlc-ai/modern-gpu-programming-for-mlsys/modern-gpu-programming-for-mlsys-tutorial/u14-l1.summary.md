本讲为 FA4 系列首讲，覆盖在线 softmax 分块递推、tile 数据流与三代 FA 演进。核心结论：完整 L×L score 矩阵不落盘，每行仅携带 row_max/row_sum/O 三个状态；换指数参考时旧状态需乘 acc_scale=2^δ，FA4 的条件 rescaling 在 δ≥−8 时沿用旧参考、推迟重缩放，属性能优化不改数学结果。数据流上 TMEM 是两个 MMA 间的传送带：QKᵀ MMA 写 S 入 TMEM，softmax 读 S 至寄存器算出 P 写回，PV MMA 用 TMEM 的 P 与 SMEM 的 V 累加 O；这些 TMEM↔寄存器往返是 FA4 相对 GEMM 的全部额外搬运，也是条件 rescaling 与指数双路径的靶子。双 Q stage 在飞、K/V 倒序流式；三代 FA 算法骨架不变，映射随 Tensor Core 三级跳。warp 角色与屏障协议留给下一讲。
