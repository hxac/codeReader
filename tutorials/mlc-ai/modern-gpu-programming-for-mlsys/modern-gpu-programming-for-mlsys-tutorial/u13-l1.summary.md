本讲精读 GEMM Step 7（hgemm_v7），主题是 warp specialization（warp 特化）：一次纯 scope 重构，layout（SMEM 环 + TMEM 累加器）与 dispatch（TMA + tcgen05）沿用 Step 5/6，只把单 warpgroup 串行控制权拆成三个并发角色——WG1 warp3 做 TMA producer、WG1 warp0 做 MMA consumer、WG0 全体 128 线程做回写，以 if 守卫划分、单线程发起（elect_sync），稳态下三段硬件同时忙碌。正确性靠四道按 source2destination 命名的屏障，构成两个 full/empty 资源圈：SMEM 环（深度 2）用 tma2mma/mma2tma，TMEM 单缓冲用 mma2ld/ld2mma；屏障类型由完成者决定——TMA 引擎用带字节计数的 TMABar（一次登记 A、B 共 32768 字节），Tensor Core 用靠 tcgen05.commit 的 TCGen05Bar（硬件在 MMA 真正完成后到达），普通线程用 MBarrier（ld2mma 需集齐 128 次到达）。PipelineState 把 stage 与 phase 捆绑推进，初始相位规则是「资源起始可用的一端给 1、不可用的一端给 0」，设错会死锁或静默读旧数据。回写分支内不能用 cta_sync（另一 warpgroup 永不到达），须用 named barrier warpgroup_sync(10)，即 bar.sync 10,128，两道分别保证 Dsmem 整 tile 写齐后才发 TMA store、store 排空后才覆写 Dsmem。SMEM 成本约 S×32+32 KB，深度 6 的 224 KB 已逼近 B200 每 SM 228 KB 上限。本讲的 cta_mask=0 将在下一讲 Step 8 升级为 cta_mask=3 以支持双 CTA cluster 协作。
