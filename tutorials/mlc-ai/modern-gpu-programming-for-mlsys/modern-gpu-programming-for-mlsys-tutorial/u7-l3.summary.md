本讲覆盖三个模块：TMEM 分配生命周期、尺寸限制、warp 的 lane 访问窗口。TMEM 是运行期按列动态分配的资源：先在 SMEM 预留 tmem_addr 槽，warp 0 集体执行阻塞式 tcgen05.alloc 把基地址写入槽，经 fence 与 cta_sync 发布后用 decl_buffer 绑定布局，用完先 relinquish 交出分配许可再 dealloc。尺寸上 n_cols 仅 32/64/128/256/512 五档，同一 CTA 多次分配须单调不增，应起步即定最大需求，故书中内核一律 512 列再按列切片，满配 256 KiB、与 SMEM 独立记账。cta_group::2 时 CTA 对两侧各出一 warp 执行同一 alloc/dealloc。tcgen05.ld/st 限定 warpgroup 内编号 w 的 warp 只能访问 TLane∈[32w,32w+31]，列向开放，读 128 行累加器需四次 warp 级访问，mma 走 Tensor Core 通路不受此限。
