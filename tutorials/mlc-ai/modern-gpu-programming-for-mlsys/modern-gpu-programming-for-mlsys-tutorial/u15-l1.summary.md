本讲是手册型讲义，系统梳理 TIRx 语言参考前三块：解析工具、数据类型与 buffer。核心结论是「buffer 是指针之上的元数据」，地址由 data 指针、偏移与 layout 算出。四个解析期工具：T.meta_var 把 Python 值内联为编译期 meta，@T.inline 在调用点展开函数，@T.meta_class 把 buffer 与标量打包成状态对象，T.constexpr 供 specialize 烘焙；range 是串行循环，T.unroll 才会展开。dtype 描述比特（含 float32x4 等向量形式），type 区分标量与指针，原始地址须经 T.reinterpret 转成带 scope 的类型化指针。声明 API 两条：alloc_buffer 分配存储，decl_buffer 在已有指针上声明视图。五种 scope 各有生命周期：global 由调用方传入，shared 静态定尺寸，shared.dyn 仅允许一个 arena，local 是每线程寄存器（标量是单元素糖，let 是不可变绑定），tmem 只能用 decl_buffer 加强制的 allocated_addr 声明、且仅经 tcgen05 访问。buffer 方法均为编译期元数据操作；综合实践以 hgemm_v1 为对象逐条核对 buffer 声明并整理成速查表。
