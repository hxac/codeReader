本讲承接 u8-l1 的 mbarrier 状态机，核心是相位（phase）复用与多级流水线的 stage 复用。同一道屏障每完成一相（pending 与 tx-count 同时归零）即由硬件原子翻入下一相并重装 pending，无需重新 init；软件以奇偶（parity）区分先后轮次，关键判据是 `try_wait(P)` 在屏障离开相位 P 后返回，阻塞当且仅当前 parity 等于 P。完整的缓冲复用协议为每个 stage 配 full/empty 两道屏障：full 把数据交给消费者，empty 把缓冲归还生产者，二者相位须分开跟踪且初始奇偶刻意相反（生产者起步 1 立即放行、消费者起步 0 强制阻塞）。深度 S 的环满足 stage=k mod S、phase=⌊k/S⌋ mod 2，仅在扫完最后一个 stage 时翻转。漏翻相位的两种故障：消费者侧提前放行、静默读旧数据；生产者侧循环等待死锁。真实内核用 PipelineState 捆绑 stage 与 phase 以防 off-by-one。
