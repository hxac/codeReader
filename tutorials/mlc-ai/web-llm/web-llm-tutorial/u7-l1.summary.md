本讲解读 `src/error.ts` 的 68 个错误类：组织近乎全平铺，仅 ConfigValueError 与 FeatureSupportError 两个小家族；按环境不支持、配置非法、消息不合法、模型未就绪、功能不支持五分类审视，采样参数与多模态校验均为引擎/协议层与管线层双层设防。识别错误优先 instanceof，name 与消息匹配仅作兜底（存在类名与 name 不一致的陷阱）；Worker 边界会把错误退化为字符串，只剩消息匹配或前置预检。WebGPU 环境错误在 reload 链路 fail-fast，DeviceLostError 将异步设备丢失收敛为末尾同步抛出。模型未就绪族属引擎状态机而非故障，resetChat 吞错、reload 静默中止是库内降级样板。
