本讲精读 WebLLM 协议层，覆盖三个模块。其一，门面类：Chat/Completions 纯转发，engine.chat.completions.create() 等价于 engine.chatCompletion()，协议类型直接取自 openai-node，私有扩展收进 extra_body。其二，postInitAndCheckFields 八道关卡做结构校验（消息顺序、stream 与 n 组合、response_format 配对、tools 白名单），且会原位改写请求——Hermes 函数调用注入系统消息并覆写 response_format。其三，流式/非流式在类型层靠以 stream 为判别字段的可辨识联合加函数重载区分，运行时按同一字段分支。核心结论为三层校验架构：协议层管结构、引擎层 postInitAndCheckGenerationConfigValues 管数值范围（temperature 仅查下界）、会话层 getConversationFromChatCompletionRequest 管角色分发并抛 UnsupportedRoleError。关键事实：chat 的未支持字段黑名单为空，UnsupportedFieldsError 仅在 completion 接口生效。
