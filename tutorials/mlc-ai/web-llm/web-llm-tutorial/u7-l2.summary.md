本讲分三模块讲解 WebLLM 引擎的多模型管理。其一，reload 切换模型是全量换血：先无条件 unload，逐 pipeline 执行 dispose 并 await sync 等待 GPU 真正销毁，期间用 deviceLostIsError 标志屏蔽计划内设备丢失，末尾 abort 进行中的下载；设备丢失被收敛为 reload 结尾同步抛出的 DeviceLostError。其二，引擎多模型状态存于四个以 modelId 为键的 Map，每模型一把 CustomLock，跨模型请求并行、同模型 FCFS 排队；请求经 getModelIdToUse 三分支路由，歧义抛 UnclearModelToUseError，多模型显存约为各模型权重与满额 KV cache 之和。其三，interruptGenerate 是引擎级单一标志，多模型并行时一按全停；恢复靠三层自动复位，中断的部分回复经 finishReply 闭环进历史，可续接 KV cache。
