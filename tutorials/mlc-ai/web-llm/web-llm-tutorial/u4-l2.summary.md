本讲解读 `src/cache_util.ts` 的缓存查询与删除 API。`hasModelInCache` 只探测 `webllm/model` 作用域的权重张量缓存，键为经 `cleanModelUrl` 规范化的 URL，modelId 不在 model_list 时抛 `ModelNotFoundError` 而非返回 false。删除侧为「一组合＋三单件」：`deleteModelInCache` 清权重与两个 tokenizer 文件、`deleteModelWasmInCache` 清 wasm、`deleteChatConfigInCache` 清聊天配置、`deleteModelAllInfoInCache` 顺序组合三者。核心结论：查、删、载必须使用同一 appConfig 才能对上缓存键；删缓存≠卸载模型，已加载引擎照常运行，差异到下次 reload 才显现；cross-origin 后端不支持删除。内部函数 `asyncLoadTokenizer` 在 reload() 中经 `fetchWithCache`（命中读缓存、未命中走网络并回填）加载 tokenizer，tokenizer.json 严格优先于 tokenizer.model，皆无则抛 `UnsupportedTokenizerFilesError`；若配置了 integrity.tokenizer 哈希则先校验后交付，为下一讲完整性校验埋下伏笔。
