本讲以 examples/get-started 为例跑通 WebLLM 首个示例：npm install 后 npm start，由 Parcel 在 8888 端口起服务，前提是浏览器支持 WebGPU。围绕四个最小模块展开：示例工程与启动方式、CreateMLCEngine 创建引擎、initProgressCallback 汇报加载进度、chatCompletion 发起首次对话。核心结论：CreateMLCEngine 等价于 new MLCEngine() 加 reload()，返回前已完成查 ModelRecord、下载配置/wasm/权重、检测 GPU、编译 shader；换模型即改 model_id 字符串，选型看 prebuiltAppConfig.model_list 中的 vram_required_MB 与 required_features（缺 shader-f16 会抛错）。InitProgressReport 含 progress、timeElapsed、text 三字段；engine.chat.completions.create 只是 engine.chatCompletion 的 OpenAI 风格门面，finish_reason 分 stop、length、tool_calls、abort；模型缓存于 CacheStorage 的 webllm/config、webllm/wasm、webllm/model 三个作用域，二次加载显著提速。
