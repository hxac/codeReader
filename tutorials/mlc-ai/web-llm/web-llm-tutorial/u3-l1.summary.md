本讲下钻推理管线 LLMChatPipeline 的初始化。引擎侧按序完成：下载 model_lib 的 wasm，经 tvmjs.instantiate 实例化运行时，detectGPUDevice 校验 shader-f16 等特性后 initWebGPU 绑定 GPU 设备；管线内再以 tvm.webgpu() 取回 DLDevice。管线构造函数只做「接线」不做计算：创建 VirtualMachine、调 _metadata 读模型自述，按 kv_state_kind 与 wasm 实际导出的函数解析模型 ABI，据此绑定 prefill/decoding 与采样族等 PackedFunc（字段 this.prefill 背后可能是 batch_prefill），随后装载权重、按窗口配置一次性分配满分页 KV cache。函数句柄分两类：模型 VM 函数与 vm.builtin 运行时内建；权重与 KV cache 均驻留 storage buffer，规模受 maxStorageBufferBindingSize 与总显存制约，getGPUVendor 等查询不依赖已加载模型。asyncLoadWebGPUPipelines 在管线构造之后、注册之前异步预热全部 shader，故 reload 返回即「句柄、权重、shader」齐备。
