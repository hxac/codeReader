本讲为第二单元收官，覆盖 WebLLM 嵌入接口的最小模块：协议层 Embeddings 门面与请求字段校验、EmbeddingPipeline（embedStep 批量前向）、引擎 embedding() 分发与 getModelStates 双重校验，以及 ModelType 枚举和嵌入专属错误族。核心结论：嵌入管线与 LLMChatPipeline 平行，仅持有 prefill 一个 PackedFunc，无 KV cache、无解码循环、无采样，一次前向后取第一个 token 的隐状态作为句向量（CLS 式池化）；正因无 KV cache，构造期强制 prefillChunkSize 等于 contextWindowSize，并拒绝滑动窗口与分块。关键术语：余弦相似度、padding 与 attention mask、max_batch_size（对应 b4/b32 版本命名）、ModelType.embedding、IncorrectPipelineLoadedError（chat 模型上调嵌入接口即触发）、WebLLM 扩展字段 prefill_tokens_per_s。预置嵌入模型为 snowflake-arctic-embed 家族四条，上下文均为 512；Worker 消息协议含独立 embedding kind，为后续 Worker 单元做铺垫。
