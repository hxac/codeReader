本讲承接非流式 chatCompletion，讲其流式分支：`stream: true` 借可辨识联合将返回类型收窄为 AsyncIterable<ChatCompletionChunk>，用 for await...of 逐帧消费。引擎在入口处即获取模型互斥锁，调用 asyncGenerate 只得到惰性执行的生成器对象，锁直到流被完整消费才在生成器末尾释放。管线本身不产增量：它维护完整消息 outputMessage，生成器用 prevMessageLength 游标切片出每帧 delta；末尾出现不完整 emoji（U+FFFD 计数非 4 的倍数）时跳帧。流的骨架为：首帧约等于 TTFT，中间帧 finish_reason 为 null，空 delta 收尾帧给出终止原因，可选 usage 帧；流式限定 n 为 1，否则抛 StreamingCountError。interruptGenerate 属协作式取消：仅置 interruptSignal 布尔标志，循环每轮 decode 前检查，命中即 triggerStop()，finishReason 置 "abort"，部分消息经 finishReply 闭合进对话历史，流正常收尾不抛错，getMessage() 可取回部分内容。WebLLM 保留 OpenAI 的 chunk 数据结构，仅把 SSE 载体换成 AsyncIterable。
