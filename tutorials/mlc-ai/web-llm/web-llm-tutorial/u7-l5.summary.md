本讲为全手册收官篇，围绕三个模块展开：rollup 构建链、三层质量门禁、二次开发扩展点清单。核心结论：`npm run build` 分两步——rollup 以 index.ts 桶文件（barrel file）为唯一入口，把 tvmjs 等依赖内联成 ESM 单文件（npm 包只发布 lib/，运行时依赖仅 loglevel），再用 sed 清洗脚本抹掉残留的 require、perf_hooks 等 Node 专有代码，否则 Next.js、SvelteKit、Parcel 等环境会崩。质量门禁分三层：pre-commit 钩子（Husky＋lint-staged）、CI 的 Linter/Tests/Build 三个 workflow、jest 覆盖率硬阈值。新增引擎 API 须「五处打通」：接口契约、管线 getter、引擎实现（经 getLLMStates 路由）、Worker 消息协议、Handler 路由与代理；综合实践以 getContextTokensLeft 为例走完 fork、编码、单测、门禁、构建、验证的完整闭环，剩余 token＝contextWindowSize−filledKVCacheLength，滑动窗口模型返回 −1。最后梳理七类扩展点（新 API、LogitProcessor、新模型、Worker 自定义消息、结构化输出、缓存后端、新示例）及本地包联调指引。
