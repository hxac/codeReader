WebLLM 是完全跑在浏览器里的 LLM 推理引擎：模型下载到本地、经 WebGPU 加速、无服务器参与，接口兼容 OpenAI API。生态上 TVMjs 提供运行时底座，MLC LLM 负责编译模型（WebLLM 是其伴侣库），WebLLM Chat 是基于它的应用，README 声明的特性均可对应到 src/ 下的具体模块。核心概念 ModelRecord 把「一个模型」拆成三类产物：model（HuggingFace 权重仓库，含聊天配置与 tokenizer）、model_lib（wasm 模型库，同架构变体可共用）与 overrides（运行时覆盖）。prebuiltAppConfig.model_list（167 条记录）是预置模型兼容性的唯一事实来源；量化后缀如 q4f16_1 表示权重位宽与激活精度，选型依据 vram_required_MB 与 required_features（如 shader-f16）。docs/ 为 Sphinx 文档站，与源码不一致时以 config.ts 为准。
