本讲拆解 WebLLM 的提示词编码机制：语言模型只认整段字符串，必须按各模型自己的对话模板把 messages 数组拍平。模块一，ConvTemplateConfig 是对话格式的规格书，以 system_template、roles、seps 等字段区分 Llama-2 的 [INST] 风格与 ChatML 风格，MessagePlaceholders 占位符在编码时被替换为真实内容。模块二，Conversation 类以 [Role, 角色串， content] 三元组维护历史，undefined 哨兵表示等待模型接话的空回复头，由 finishReply 回填闭环；getPromptArray 做全量编码，getPromptArrayLastRound 做增量编码，后者是 KV cache 复用的前提；含图片的消息编码为字符串与 ImageURL 的混合数组。模块三，getConversation 工厂以 conv_config 覆盖合并装配会话，getConversationFromChatCompletionRequest 把 OpenAI 请求译为会话（system 消息写入 override_system_message，默认排除最后一条），compareConversationObject 深比两会话状态，引擎据此决定复用还是清空 KV cache。stop_str 与 stop_token_ids 将在解码环节消费。
