本讲绘制 web-llm 源码地图：仓库是「npm 库＋示例集＋文档站」三合一，src/ 约 1.24 万行，最大的三个文件 config.ts、llm_chat.ts、engine.ts 分别对应模型分发、推理管线、引擎编排三大复杂度。核心是库入口 index.ts——63 行纯再导出的「barrel file」，导出可归为引擎类、Worker 类、配置类、缓存工具、OpenAI 协议、完整性校验六类；LLMChatPipeline、Conversation 及绝大多数错误类均未导出，属内部实现。运行时呈三层加代理分层：协议门面层（Chat/Completions/Embeddings 门面，门面模式）→ 引擎层（MLCEngine，以 loadedModelIdToPipeline 持有管线）→ 管线层（LLMChatPipeline 经 tvmjs 的 PackedFunc 调 WebGPU）；Worker 代理层与真身实现同一 MLCEngineInterface，页面可无感切换到 worker。构建上 rollup 以 index.ts 为入口打包出 ESM 单文件 lib/index.js，npm 仅发布 lib 目录，cleanup-index-js.sh 做浏览器兼容文本修补。关键术语：barrel file、ESM、门面模式、MLCEngineInterface、WorkerRequest/WorkerResponse 消息协议、prebuiltAppConfig。
