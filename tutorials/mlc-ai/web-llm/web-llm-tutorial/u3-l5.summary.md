本讲沿数据流拆解 WebLLM 采样控制的三个模块。参数层：请求中的采样字段摘入 `GenerationConfig`，引擎层由 `postInitAndCheckGenerationConfigValues` 在生成前校验非法值并补默认（如双 penalty 互补为 0），管线层采样时再复核，以覆盖低层 API 入口。采样链：`sampleTokenFromLogits` 按固定顺序执行 grammar 掩码 → LogitProcessor（CPU）→ logit_bias → 三种惩罚 → softmax → top-p 抽样，均为 GPU 端 PackedFunc；惩罚只作用于本轮已生成 token（`appearedTokensFreq` 每轮清空），temperature 钳至 1e-6，seed 经 tvmjs RNG 固定随机序列实现复现。扩展点：`LogitProcessor` 是有状态接口三件套（`processLogits`、`processSampledToken`、`resetState`），按 modelId 注册并随管线注入，每步产生一次 GPU↔CPU 往返，Worker 场景必须在 Worker 脚本内注册。
