本讲剖析 WebLLM 测试体系：18 个 jest 测试文件全部不加载真实模型、不需要 WebGPU，可在纯 Node 的 CI 跑通；真实模型的端到端验证由 jest 之外的 sanity_checks 浏览器页面（独立 package.json）承担。测试分三层：纯函数单测（零 mock，以 postInitAndCheckGenerationConfigValues 为样板）、原型替身测试（Object.create 绕过构造函数、手工填私有字段）、模块级 mock 测试（jest.mock 兄弟模块，配 requireActual 保留真实层）。关键术语：测试替身、_hasValue 哨兵（保证 temperature=0 合法，除零由管线层 Math.max(1e-6,T) 钳制消除）、覆盖率硬门禁（engine.ts 门槛更高）、fake timer 与伪造 postMessage。核心结论：测试断言是最精确的行为文档，可据此反推 API 预期行为。
