本讲是第四单元收官，分三个模块讲清自定义模型接入全链路：mlc_llm 编译流程、model_lib 上传与 URL 配置、AppConfig 自定义注入。核心结论：WebLLM 只做下载与实例化，编译由 MLC LLM 完成，产出权重目录（model 指向，内含 mlc-chat-config.json）与 wasm 模型库（model_lib 指向）；按「四要素」（架构、量化、metadata、平台）是否与预置库相同，选路线 A（变体复用现成 wasm）或路线 B（自行编译）。model_id 仅是 model_list 里的逻辑查找键，同一权重可注册多条记录；model URL 经 cleanModelUrl 补全 /resolve/main/ 后派生配置、tokenizer 与权重三类下载，localhost 的 wasm 不缓存。自定义 AppConfig 是整体替换而非合并；overrides（记录级）与 chatOpts（调用级）同仓库配置浅合并、后写者赢；模板微调走 conv_config，整套替换才写 conv_template；q4f16 模型须声明 required_features。
