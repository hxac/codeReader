本讲拆解 WebLLM 配置体系的三个模块。其一，ModelRecord 是单个模型的「身份证」：model_id 是逻辑名，model 与 model_lib 分别指向 HuggingFace 权重仓库和 wasm 模型库，二者可自由组合，同一份权重配不同 overrides 即构成不同记录；required_features、model_type、integrity 声明运行要求，vram_required_MB 仅供选型参考，引擎不做显存预检。其二，AppConfig 聚合 model_list 白名单与 cacheBackend 缓存后端，缺省兜底为 prebuiltAppConfig（官方 163 条记录），它是预置模型与当前 npm 版本兼容性的唯一事实来源。其三，ChatOptions 是 ChatConfig 的任意子集，经「仓库 mlc-chat-config.json → 记录级 overrides → reload 传入的 chatOpts」三层展开合并，后写者赢，覆盖是否生效可由上下文窗口超限报错验证。本讲还区分了加载期 ChatOptions 与请求级 GenerationConfig。
