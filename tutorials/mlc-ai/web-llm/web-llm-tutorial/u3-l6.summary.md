本讲是单元三收官篇，讲解 WebLLM 的多模态输入管线。多模态入口是 user 消息的 content 数组（text 与 image_url part），协议层 postInitAndCheckFields 以 ModelType.VLM 做门禁，并校验 URL 前缀、拒绝 detail 字段、限制单消息仅一个 text part。Conversation 将其拍平为字符串与 ImageURL 混合的 prompt 数组；管线先预载图片（imageDataCache 在单次 prefill 内去重），把 RGBA 摘成 RGB、构造 NHWC 像素张量，交可选核 image_embed 编码成与文本同空间的 embedding，拼接后进 prefill 并写入 KV cache，故后续纯文本追问无需重编码图片。phi3_v 按分辨率折算图片 token（正方形最多 2509），固定 token 模型则读配置 mm_tokens_per_image。核心约束是「token 可切、图片原子不可切」：单图 token 超过 wasm 固化的 prefillChunkSize 即抛 PrefillChunkSizeSmallerThanImageError；六个多模态错误类分协议、管线、分块三层拦截。关键术语：VLM、BOI/EOI、image_embed、imageDataCache。
