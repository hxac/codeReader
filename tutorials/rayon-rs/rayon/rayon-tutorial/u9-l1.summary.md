本讲是单元九的毕业设计入口，以 RepeatN（重复元素生成器）为范本，从零实现一个完整的自定义索引并行迭代器。内容分三层：迭代器结构体为自有类型实现 ParallelIterator 与 IndexedParallelIterator 的 Item、drive_unindexed、opt_len、len、drive、with_producer（into_par_iter 由 blanket 实现自动获得）；Producer 契约为 split_at 按值切分、下标相对自身、恒有 index ≤ N，总长由框架记账，IntoIter 必须双端且精确长度；再手写最小 Consumer 三件套（split_at/into_folder/full）配 Folder 与 Reducer。核心结论：with_producer 是迭代器世界与生产者世界的唯一交换口；drive/drive_unindexed 几乎总是一行 bridge；opt_len 只影响 collect 快慢不影响正确性；全量消费 n 个元素恰好 n−1 次克隆，与切分刀数无关。验证姿势：与 std::iter::repeat().take(n) 对照、用 is_indexed 做编译期断言、覆盖 n=0 边角。
