本讲为使用层收尾，主题是 Rayon 对失败的两档处理。可恢复失败由 try_fold 与 try_reduce 家族（含 _with 变体）传播 Result / Option：fold 侧是惰性适配器，只在本地切片内短路；reduce 侧是立即执行消费者，凭共享 AtomicBool 与 plumbing 层的 full() 钩子（Consumer::full / Folder::full）实现全局短路，底层靠私有 Try trait 把可失败类型统一为 ControlFlow。while_some 把第一个 None 变为全管道停止信号，且无 indexed 实现。panic 属不可恢复档：halt_unwinding 捕获后以 JobResult::Panic 跨线程搬运，最终在调用点由 resume_unwinding 重放；join 中一支 panic 后必须等另一支结束以保借用安全，故其余任务默认照跑。panic_fuse 用 Drop 守卫加共享标志做尽力而为的快速止损。多个并行错误同时存在时返回哪一个不确定。
