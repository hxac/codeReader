本讲精读 `src/slice/sort.rs` 中 `par_sort` 的稳定归并实现 `par_mergesort`，三阶段流程：按 `CHUNK_LENGTH=2000` 分块并行执行串行 TimSort（`with_max_len(1)` 锁定粒度）→ 按 `MergeSortResult` 三态（NonDescending/Descending/Sorted）拼接相邻自然游程实现自适应 → `merge_recurse` 并行归并。`MAX_INSERTION=20` 与 `MAX_SEQUENTIAL=5000` 分别界定插入排序与归并的粒度下限：单位工作量越小，阈值越大（20<2000<5000）。核心算法 `split_for_merge` 在较长侧取中点、较短侧二分定位，使左右两半可无锁独立归并、输出精确拼接目标区间，关键路径 O(log³n)。缓冲区是一块容量 n、长度恒为 0 的 `Vec`，靠 `into_buf` 逐层翻转让数据在 v 与 buf 间乒乓；长度恒 0 使浅拷贝不被重复析构（旧概念 out_of_buf 已不存在）。稳定性由「相等取左」（split_for_merge 分派方向与串行归并）等三处合力保证；panic 安全由 `InsertionHole`、`MergeHole`、`State` 等 Drop 守卫构成链条——正常路径 `mem::forget`、panic 展开时回填，切片元素恰好守恒。rayon-demo 的 mergesort 是同构教学标本与调参底板。
