# u4-l1 · 数值实验：NS 迭代系数、收敛行为与 bfloat16 精度

## 1. 本讲目标

u2-l2 已经**逐行读懂**了 `zeropower_via_newtonschulz5`；本讲换一副眼镜，把它当成研究对象，用**数值实验**拆解它。我们的路线是「先用手算的标量理论做出预言，再用矩阵实验裁决」——这正是读研究型代码最有效的方式：不是问「这行代码是什么」，而是问「如果我去动它，会发生什么」。

读完本讲，你应该能够：

1. **把系数 \(a,b,c\) 的作用定量化**：推出迭代映射 \(h(\sigma)=3.4445\sigma-4.7750\sigma^3+2.0315\sigma^5\) 的极值点、不动点与不变区间，从而严格解释 docstring 里「超过收敛临界点继续加大零点斜率反而有效」这句话的几何含义。
2. **用 `torch.linalg.svdvals` 实测** `ns_steps` 增大时输出奇异值如何逼近 1 **附近的窄带**（并亲手测出这条带子究竟多宽、在哪里），检验 docstring「\(S'_{ii}\sim\mathrm{Uniform}(0.5,1.5)\)」这一经验说法的精确程度。
3. **解释并实测 bfloat16 的稳定性**：为什么 0.4% 相对精度的低精度运算放进这个迭代毫发无伤，以及为什么精度损失根本不是瓶颈（系数设计带来的「带宽」才是）。
4. **动手改系数**：把五次迭代换成经典三次 Newton-Schulz，量化「处处收敛但要更多步」与「带内漫游但只要 5 步」的取舍，理解默认 `ns_steps=5` 是精度与速度的经验折中。

| 概念 | 通俗解释 |
|---|---|
| 一维离散动力系统 | 反复施加同一个标量映射 \(\sigma\leftarrow h(\sigma)\)。「轨道」= 从某个初值出发得到的一串值；「不动点」= 满足 \(h(\sigma^*)=\sigma^*\) 的点。 |

| `torch.linalg.svdvals` | 只算奇异值、不算 \(U,V\) 的接口，比完整 `svd` 便宜，是本讲的「测量仪器」。（API 名是 `svdvals`，没有下划线。） |
| 对拍 | 让两个独立实现跑同一输入、逐位比较输出。本讲让「矩阵实验」与「标量理论预言」对拍。 |
| 浮点格式 | bfloat16 = 1 符号 + 8 指数 + 7 尾数；fp16 = 1 + 5 + 10；float32 = 1 + 8 + 23。详见 4.3 节对照表。 |

## 4. 核心概念与源码讲解

### 4.1 标量显微镜：把 h(σ) 当一维动力系统，解剖系数 a、b、c

#### 4.1.1 概念说明

u2-l2 已经证明：迭代在奇异值层面等价于反复施加 \(h(\sigma)=a\sigma+b\sigma^3+c\sigma^5\)。当时我们只算了两个数字（\(h'(0)=3.4445\)、两个不动点）。本节把 \(h\) 彻底画清楚——之后所有矩阵实验的「理论预言」都从这里来。

对 \(h(\sigma)=3.4445\sigma-4.7750\sigma^3+2.0315\sigma^5\) 求导：

\[
h'(\sigma) = 3.4445 - 14.3250\,\sigma^2 + 10.1575\,\sigma^4 .
\]

令 \(t=\sigma^2\)，解二次方程 \(10.1575t^2-14.3250t+3.4445=0\)，得两个临界点；代回 \(h\) 得极值。全部手算结果汇总如下（建议用 4.1.4 的脚本复核到更高位数）：

| 对象 | 位置 σ | 值 h(σ) | 含义 |
|---|---|---|---|
| 局部极大点 | ≈ 0.554 | ≈ **1.202** | \(h\) 在整个 \((0,\infty)\) 上可达的最大值 |
| 局部极小点 | ≈ 1.050 | ≈ **0.682** | 极小值，也是「振荡带」的下沿 |
| 正不动点 ① | ≈ 0.868 | = σ | \(h' \approx -1.58\)，**斥性** |
| 正不动点 ② | ≈ 1.264 | = σ | \(h' \approx +6.47\)，**斥性** |
| h(1) | 1 | ≈ 0.701 | 谱范数已归一化的最大奇异值第一步被压到 0.7 |

由这张表可以严格推出四个结论（**全部手工可证，不依赖运行**）：

**结论 1（输出硬上界）**：归一化保证输入 \(\sigma\le 1\)，而 \(h((0,1])\subset(0,\,1.202]\)，且 \((0,1.202]\) 在 \(h\) 下不变（极大值 1.202 就在区间内取到，端点 \(h(1.202)\approx 0.95\)）。因此**无论迭代多少步，输出奇异值恒 ≤ ≈1.202**（精确算术下；bfloat16 再加约 0.4% 噪声）。

**结论 2（不变区间）**：记 \(m=0.682\)（极小值）、\(M=1.202\)（极大值），则区间 \(I=[m,\ h(m)]\approx[0.682,\ 1.134]\) 满足 \(h(I)\subseteq I\)（\(h\) 在 \([m,1.050]\) 上递减、在 \([1.050, h(m)]\) 上递增，像恰好落回 \(I\)）。轨道一旦进入 \(I\) 就永不离开；落在 \((1.134,\,1.202]\) 的值一步之内也会被吸进 \(I\)。

**结论 3（为什么不收敛）**：两个正不动点都是斥性的（\(|h'|\approx 1.58\) 与 \(6.47\)，均大于 1），零点也是斥性的（\(h'(0)=3.4445\)）。**整个系统没有吸引不动点**，轨道只能在不变区间内永远漫游（近似二周期地高低弹跳，又不严格重复）。这正是 docstring「不再处处收敛到 1」的动力学根源——不是步数不够，而是**故意没有给轨道安排终点**。

**结论 4（低尾来源）**：线性放大约 ×3.4445/步，5 步共 ×485，所以归一化后 \(\tilde\sigma_0\gtrsim 1/485\approx 0.002\) 的奇异值能在 5 步内进入不变区间；比这更小的值第 5 步时还在「爬坡」途中（例如 \(\tilde\sigma_0=0.001\)，手工迭代轨迹 ≈ \(0.001\to 0.0034\to 0.0119\to 0.0409\to 0.1406\to 0.471\)，5 步后仍低于带下沿）。**输出谱中低于 0.682 的「低尾」全部来自这些未爬完的小奇异值**。

现在可以精确翻译 docstring 里那句最令人困惑的话了——

> [muon.py:L8-L10](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L8-L10) —— 「系数按最大化零点斜率选取；经验上把零点斜率加大到**超过迭代能处处收敛到 1 的临界点**反而更利于减少步数。」

「收敛临界点」指的是：存在一族系数使 \(h\) 单调收敛到 1（比如 4.3 节的经典三次 \(1.5\sigma-0.5\sigma^3\)）。把斜率继续加大，\(h(1)\) 就偏离 1、不动点变成斥性——收敛性「坏了」。但坏得恰好：轨道被关进 \([0.682, 1.134]\) 的窄带里出不去，而窄带以 1 为中心、宽约 ±20%。**「处处收敛」换来的是每步 1.5 倍的爬坡速度；「带内漫游」换来的是每步 3.44 倍**。对小奇异值占多数的真实梯度谱，5 步 × 3.44 的覆盖力才是刚需，±20% 的带宽无所谓——这就是取舍。

最后，结论 1 还顺带「审判」了 docstring 的另一个说法：

> [muon.py:L11-L13](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L11-L13) —— 「产出近似 \(US'V^\top\)，\(S'_{ii}\sim\mathrm{Uniform}(0.5,1.5)\)」。

按结论 1，输出奇异值**永远到不了 1.5**（上界 ≈1.202）；按结论 2 与 4，主体应落在 \([0.682, 1.134]\)，低尾由未爬完的小奇异值贡献。所以 \(\mathrm{Uniform}(0.5,1.5)\) 是一句**定性概括**（原文也用了 "something like" 和 "~"）：它想说的是「奇异值散布在 1 附近、跨度约 ±50%」。真实分布什么样，4.2 节实测。这种「文档说法 vs 精确预言 vs 实验裁决」的三方对照，是本讲反复使用的套路。

#### 4.1.2 核心流程

研究一个标量迭代映射的标准流程（也是你日后分析任何「多项式迭代」的通用方法论）：

```text
1. 写出 h(σ) 与 h'(σ)
2. 解 h'(σ)=0            → 临界点与极值          → 得到输出的上下界（结论 1）
3. 解 h(σ)=σ, σ>0         → 不动点；算 |h'(σ*)|   → 判断吸引/斥性（结论 3）
4. 用极值构造不变区间 I     → h(I) ⊆ I？          → 轨道的活动范围（结论 2）
5. 线性化分析原点附近       → h'(0)^k = 爬坡速度   → k 步覆盖阈值 1/h'(0)^k（结论 4）
6. 数值打印轨道验证 2–5
```

把第 5 步写成公式：初值 \(\tilde\sigma_0\)（归一化后）经过 \(k\) 步大约被放大 \(h'(0)^k = 3.4445^k\) 倍，于是

\[
\text{5 步入带阈值} \;\approx\; \frac{1}{3.4445^5} \;=\; \frac{1}{485} \;\approx\; 0.002 .
\]

#### 4.1.3 源码精读

本节解剖的正是这一行：

```python
a, b, c = (3.4445, -4.7750,  2.0315)
```

> [muon.py:L16](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L16) —— 三个系数完全决定了 \(h\) 的形状，也就完全决定了本节的所有结论：\(a=3.4445\) 同时是零点斜率（爬坡速度）与原点的斥性强度；\(a+b+c=h(1)=0.701\) 决定了「已归一化到 1 的奇异值第一步被压到 0.7」；三者联立给出极值 \(1.202/0.682\)、不变区间 \([0.682,1.134]\) 与两个斥性不动点。注意系数的**奇函数结构**（\(\sigma,\sigma^3,\sigma^5\)）与 \((XX^\top)^kX\) 的奇数次幂结构严格对应（u2-l2 的归纳证明），不是随意挑的五次多项式。

以及它们被使用的地方：

```python
    # Perform the NS iterations
    for _ in range(steps):
        A = X @ X.mT
        B = b * A + c * A @ A # quintic computation strategy adapted from suggestion by @jxbz, @leloykun, and @YouJiacheng
        X = a * X + B @ X
```

> [muon.py:L24-L27](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L24-L27) —— 循环体把标量映射 \(h\) 逐「层」装配到矩阵上：`a * X` 是 \(a\sigma\) 项；`b * A` 与 `c * A @ A` 组合出 \(b\sigma^3+c\sigma^5\) 项（因为 \(A=XX^\top\) 对应 \(\sigma^2\)，`B @ X` 再乘回 \(X\) 恰好把幂次补成 3 和 5）。行内注释说明这组系数来自 speedrun 社区的实验（@jxbz、@leloykun、@YouJiacheng），不是教科书推导——这正是 4.3 节「你也可以改系数」的合法性来源：这本来就是实验调出来的经验值。

#### 4.1.4 代码实践：打印轨道，验证四个结论

**实践目标**：用纯 Python（**不需要 PyTorch**）复核本节全部数字，并亲眼看到「斥性不动点」与「带内漫游」。

**操作步骤**（示例代码，保存为 `ns_scalar.py`，`python3 ns_scalar.py` 即可运行）：

```python
# 示例代码：ns_scalar.py —— 标量显微镜，无需 PyTorch
import math

A, B, C = 3.4445, -4.7750, 2.0315
h  = lambda s: A*s + B*s**3 + C*s**5
dh = lambda s: A + 3*B*s**2 + 5*C*s**4

# 1) 临界点：解 10.1575 t^2 - 14.325 t + 3.4445 = 0 (t = s^2)
disc = math.sqrt(14.3250**2 - 4*10.1575*3.4445)
t1, t2 = (14.3250 - disc)/(2*10.1575), (14.3250 + disc)/(2*10.1575)
print(f"局部极大点 {math.sqrt(t1):.4f}, h = {h(math.sqrt(t1)):.4f}")   # ≈ (0.554, 1.202)
print(f"局部极小点 {math.sqrt(t2):.4f}, h = {h(math.sqrt(t2)):.4f}")   # ≈ (1.050, 0.682)

# 2) 不动点：解 2.0315 t^2 - 4.775 t + 2.4445 = 0 (t = s^2, h(s)=s)
disc2 = math.sqrt(4.7750**2 - 4*2.0315*2.4445)
for t in [(4.7750 - disc2)/(2*2.0315), (4.7750 + disc2)/(2*2.0315)]:
    s = math.sqrt(t)
    print(f"不动点 {s:.4f}: |h'| = {abs(dh(s)):.3f}  (斥性: >1)")

# 3) 轨道：不同起点的 12 步轨迹
for s0 in [0.001, 0.005, 0.7, 1.0]:
    s, traj = s0, [s0]
    for _ in range(12):
        s = h(s); traj.append(round(s, 4))
    print(f"σ0={s0:<6}", traj)

# 4) 5 步覆盖阈值验证：1/3.4445^5
print(f"1/485 = {1/A**5:.6f},  5步放大 = {A**5:.1f}")
```

**需要观察的现象**：
- 极值点/不动点数值与 4.1.1 表格一致（小数点后 3 位）；
- `σ0=0.7` 与 `σ0=1.0` 的轨道进入 \([0.68, 1.14]\) 后**高低弹跳、永不重复、永不收敛**（高值约 1.09–1.12，低值约 0.70–0.73）；
- `σ0=0.001` 的轨道第 5 步 ≈ 0.47（带下爬坡中，未入带），第 6–7 步才进入带内；
- `σ0=0.005` 第 5 步已入带（手工值 ≈ 1.16）。

**预期结果**：与 4.1.1 的结论 1–4 完全吻合；特别地，任何轨道的任何一步都 ≤ ≈1.203（待本地验证到你喜欢的位数）。

#### 4.1.5 小练习与答案

**练习 1**：为什么迭代不可能收敛到 1？给出一个只用到「不动点斜率」的论证。

**答案**：迭代若收敛，极限必是不动点。\(h\) 的不动点为 0、0.868、1.264——注意 **1 根本不是不动点**（\(h(1)=0.701\ne 1\)）；而 0.868 与 1.264 处 \(|h'|\approx 1.58\) 与 \(6.47\) 均大于 1，是斥性不动点，轨道无法逼近。没有吸引不动点 ⟹ 不收敛，只能在不变区间内漫游。

**练习 2**：docstring 说 \(S'_{ii}\sim\mathrm{Uniform}(0.5,1.5)\)，但本节断言输出奇异值不可能超过 ≈1.202。两者矛盾吗？听谁的？

**答案**：不矛盾，但精确的是本节。\(\mathrm{Uniform}(0.5,1.5)\) 是定性概括（原文措辞是 "something like" 与 "~"）。上界 1.202 是推导结果：\(h\) 在可达集上的最大值是局部极大值 \(h(0.554)\approx 1.202\)，且 \((0,1.202]\) 在 \(h\) 下不变，故任意步数的输出都不超过它。4.2 节实验实测分布，预期主体在 \([0.68,1.14]\)、最大值 ≈1.2（待本地验证）。

**练习 3**：手算：归一化后的 \(\tilde\sigma_0=0.01\)，5 步后落在哪里？它入带了吗？

**答案**：轨迹 ≈ \(0.01\to 0.0344\to 0.1185\to 0.4001\to 1.0934\to 0.6996\)（u2-l2 的 4.3.2 表格同源）。第 4 步冲到 1.09（已入带），第 5 步弹回 0.70，仍在带内——入了带，但具体停在全带哪个位置取决于「相位」，这正是 \(S'\) 有分布的原因。

### 4.2 矩阵实验：用 svdvals 实测 ns_steps、输入尺度与 S′ 的真实分布

#### 4.2.1 概念说明

4.1 的标量理论给出了一组明确预言；现在回到矩阵世界，用 `torch.linalg.svdvals` 当测量仪器逐一检验。三个实验问题：

**问题一：`ns_steps` 增大时，输出奇异值怎样「逼近 1」？**
准确的说法是**逼近以 1 为中心的窄带**，而不是逐点趋于 1。随步数增大：(a) 输出的**最小**奇异值单调上升——因为低尾那些「未爬完」的小奇异值获得了更多爬坡步数（结论 4），最终全体汇入 \([0.682, 1.134]\)；(b) 输出的**最大**奇异值几乎不动——它被硬上界 ≈1.202 封顶（结论 1），从第 1 步起就贴着上界。所以谱的整体形状是「下沿抬升、上沿封顶、逐步压进窄带」。这也解释了 u2-l2 练习 3 的观察：steps=10 并不比 steps=5 更「正交」——上不去了，多花的每步 3 次矩阵乘只用于抬高那一小撮低尾。

**问题二：输入的尺度（谱范数 0.1 / 1 / 10）影响输出吗？**
不影响——这就是 u2-l3 讲过的**正交化尺度不变性**，其来源就在源码里：

> [muon.py:L21-L22](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L21-L22) —— 进入迭代前先除以 Frobenius 范数（+1e-7）。输入 \(G\) 换成 \(cG\)，范数也变成 \(|c|\) 倍，商不变：奇异值的**相对结构**（\(\sigma_i/\|G\|_F\)）才是迭代的真正输入。因此谱范数 0.1、1、10 的三个输入应给出**几乎相同**的输出与直方图，仅剩的差异来自 bfloat16 对不同尺度输入的舍入（≈0.4% 量级，待本地验证）。

这个实验同时是给 u2-l3 那句「更新幅度仅取决于形状与 lr」做的底层注脚。

**问题三：\(S'\) 的真实分布是什么？docstring 的 \(\mathrm{Uniform}(0.5,1.5)\) 准不准？**
标量理论预言：对 `randn` 输入，归一化后的谱主体位于 \([0.002, 0.125]\) 量级（256×256 时 \(\|G\|_F\approx 256\)、最大奇异值 \(\approx 2\sqrt{256}=32\)），全部能在 5 步内入带；只有少数**极小**奇异值（随机矩阵谱的下边缘）爬不完，拖出一条低于 0.682 的低尾。因此预测直方图：**主峰铺满 \([0.68, 1.14]\)，低尾稀疏地向左延伸，右侧在 ≈1.2 处硬截止**。与 \(\mathrm{Uniform}(0.5,1.5)\) 相比：左半边「形状」大致同源（低尾存在），右半边明显更窄。实验裁决（待本地验证）。

还有一个把标量理论和矩阵实验**直接缝合**的杀手锏——**受控谱对拍**：构造 \(G = U\,\mathrm{diag}(s)\,V^\top\)（\(U,V\) 取随机正交阵），则输入奇异值严格等于 \(s\)，于是输出的奇异值应当**恰等于** \(h^{\circ 5}(s_i/\|s\|_F)\)。如果矩阵实验与标量预言逐位吻合（至 bfloat16 精度），那么 4.1 的整套理论就被实验封印了。

#### 4.2.2 核心流程

```text
实验 A（尺度不变性 + 直方图）:
  G0 ← randn(128,128)
  for 目标谱范数 t ∈ {0.1, 1, 10}:
      G ← G0 × (t / σmax(G0))          # 精确控制输入谱范数
      X ← NS5(G)
      测 svdvals(X) → min/max/mean + 直方图
  断言: 三组输出几乎逐位相同

实验 B（ns_steps 扫描）:
  for k ∈ {1,2,3,5,10,20}:
      测 svdvals(NS_k(G)) 的 min / max
  断言: min 单调升 → 趋向 0.68；max 恒 ≲ 1.21

实验 C（受控谱对拍）:
  s ← linspace(1e-3, 1, n);  G ← U diag(s) V^T
  实测 svdvals(NS5(G))  vs  标量预言 h∘h∘h∘h∘h(s_i/‖s‖_F)
  断言: 最大误差 ~ 1e-2（bfloat16 量级）
```

其中实验 C 的对拍公式：

\[
\mathrm{svdvals}\big(\texttt{NS5}(U\,\mathrm{diag}(s)\,V^\top)\big) \;\approx\; \Big[\,h^{\circ 5}\!\Big(\frac{s_i}{\|s\|_F + 10^{-7}}\Big)\Big]_{i=1}^{n}.
\]

（注意 `svdvals` 按降序返回，比较前要把预言值同样降序排列。）

#### 4.2.4 代码实践：三个矩阵实验

**实践目标**：实测尺度不变性、ns_steps 扫描行为、\(S'\) 真实分布，并与标量预言对拍。

**操作步骤**（示例代码，需已按 u1-l2 安装 muon；建议存为 `ns_matrix.py`）：

```python
# 示例代码：ns_matrix.py
import torch
from muon import zeropower_via_newtonschulz5 as ns5

torch.manual_seed(0)

# ---- 实验 A：谱范数 0.1 / 1 / 10 → NS5 → 直方图 ----
G0 = torch.randn(128, 128)
sv0 = torch.linalg.svdvals(G0)
outs = []
for t in [0.1, 1.0, 10.0]:
    G = G0 * (t / sv0[0])                       # 精确控制谱范数 = t
    X = ns5(G, steps=5).float()
    outs.append(X)
    s = torch.linalg.svdvals(X)
    hist = torch.histc(s, bins=10, min=0.0, max=2.0)
    print(f"输入谱范数 {t:>4}: 输出 min={s.min():.3f} max={s.max():.3f} "
          f"mean={s.mean():.3f} 直方图[0,2)={[int(n) for n in hist]}")
print("谱范数 0.1 与 10 的输出最大绝对差:",
      (outs[0] - outs[2]).abs().max().item())

# ---- 实验 B：ns_steps 扫描 ----
G = torch.randn(256, 256)
for k in [1, 2, 3, 5, 10, 20]:
    s = torch.linalg.svdvals(ns5(G, steps=k).float())
    print(f"steps={k:>2}: min={s.min():.4f} max={s.max():.4f} mean={s.mean():.4f}")

# ---- 实验 C：受控谱对拍 ----
n = 128
s_in = torch.linspace(1e-3, 1.0, n)             # 已知谱：0.001 到 1
U_ = torch.linalg.qr(torch.randn(n, n))[0]
V_ = torch.linalg.qr(torch.randn(n, n))[0]
Gc = U_ @ torch.diag(s_in) @ V_.T

out_sv = torch.linalg.svdvals(ns5(Gc, steps=5).float())

A, B, C = 3.4445, -4.7750, 2.0315               # 标量预言（Python 标量版）
h = lambda x: A*x + B*x**3 + C*x**5
pred = s_in / (s_in.norm() + 1e-7)
for _ in range(5):
    pred = h(pred)
pred, _ = torch.sort(pred, descending=True)     # 与 svdvals 的降序对齐
print("受控谱对拍最大误差:", (out_sv - pred).abs().max().item())
print(f"预言: min={pred.min():.3f} max={pred.max():.3f}")
```

**需要观察的现象**：
- 实验 A：三组 `min/max/mean/直方图` 几乎相同；输出最大奇异值 ≈ 1.1–1.2（不超过 1.21）；直方图主体铺在 \([0.68, 1.2]\)，低尾稀疏；
- 实验 B：`min` 随步数单调上升（steps=1 时极小，steps≥10 后逼近 0.68 附近），`max` 从 steps=1 起就 ≈1.2 几乎不动；
- 实验 C：对拍误差在 1e-2 量级（bfloat16 舍入水平），且 `linspace` 谱里最小的几个 \(\tilde\sigma\)（\(s_i/\|s\|_F < 0.002\)，约 1–2 个）对应预言值明显低于 0.68——低尾肉眼可见。

**预期结果**（具体数值待本地验证）：
- 尺度不变性成立，最大绝对差 ≈ 1e-3–1e-2（纯 bfloat16 舍入）；
- steps 扫描的 min 序列呈「爬坡」形状，max 序列近乎常数；
- 对拍误差 ≈ 5e-3–2e-2；若误差显著大于此（如 >0.05），优先检查是否忘了给预言值排序或忘了 `.float()`。

#### 4.2.5 小练习与答案

**练习 1**：为什么 `svdvals` 而不是 `svd`？两者在本实验里的差别是什么？

**答案**：`svd` 同时返回 \(U, S, V^\top\)，`svdvals` 只返回 \(S\)。测量输出谱不需要奇异向量，`svdvals` 更便宜也更直接。只有 4.3 节要构造 \(UV^\top\) 真值时才需要完整 `svd`。

**练习 2**：steps 从 5 加到 20，输出谱「更正交」了吗？训练上值得这么做吗？

**答案**：只有低尾受益：`min` 从 ≈0.1–0.3 升到 ≈0.68（窄带下沿），`max` 恒 ≤ ≈1.202 不变。代价是每参数每步从 15 次矩阵乘涨到 60 次（4 倍计算）。README 的建议（[README.md:L46](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/README.md#L46)）是 5 步默认即可——抢救 1–2% 的低尾奇异值不值 4 倍开销，因为 Muon 只要求「谱范数量级可控、方向配对保留」。

**练习 3**：实验 C 里为什么用 `qr(randn)` 构造正交阵，而不直接 `randn` 当 \(U, V\)？

**答案**：对拍要求输入奇异值**严格等于** \(s\)。任意矩阵 \(M=U\Sigma V^\top\)，只有 \(U, V\) 正交时 \(\mathrm{svd}(U\,\mathrm{diag}(s)\,V^\top)\) 的奇异值才是 \(s\) 本身。`torch.linalg.qr` 对 `randn` 做 QR 分解给出的 \(Q\) 是均匀分布（Haar）的随机正交阵——既满足正交性又保留随机性。

### 4.3 bfloat16 精度与系数变体：稳定性、精度瓶颈与收敛速度的取舍

#### 4.3.1 概念说明

**（1）bfloat16 为什么「敢用」：吸引带吸掉舍入误差。**
先看官方理由：

> [muon.py:L50-L53](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L50-L53) —— `Muon` 类 docstring：选用 Newton-Schulz 迭代做正交化的优点，是它**能在 GPU 上以 bfloat16 稳定运行**。

这句话的机理要靠 4.1 的动力系统来解释：迭代拥有不变区间 \([0.682, 1.134]\)，每一步都把值**拉回带内**——这是一种自校正结构。bfloat16 的 0.4% 舍入误差在每步引入微小扰动后，下一步马上被映射拉回带内，**误差不会累积放大**。对比两类反例：(a) 显式矩阵求逆/除法这类「一步定终身」的运算，误差直接进结果；(b) SVD 这类分解算法需要把全部奇异向量分辨到高精度，低精度输入下结果不可靠（这正是 u2-l2 放弃 SVD 的理由之二）。

**（2）精度根本不是瓶颈：算一笔误差预算。**
系数设计本身允许输出奇异值偏离 1 多达 ±0.32（不变区间 \([0.682, 1.134]\)）；bfloat16 舍入只贡献约 0.4%（≈0.004）的相对噪声。两者相差约 80 倍——**就算用 float32 把舍入误差消灭 50 倍，输出离 \(UV^\top\) 的距离几乎纹丝不动**，因为距离由带宽主导。所以低精度是「免费」的：它加在一个本来就 ±20% 粗糙的结果上，而训练（u2-l3/u2-l5：更新 RMS ≈ lr/√n）对此毫无感觉。

**（3）为什么是 bfloat16 而不是 fp16。**

| 格式 | 符号/指数/尾数 | 相对精度 | 动态范围 |
|---|---|---|---|
| float32 | 1 / 8 / 23 | ≈ \(2^{-24}\) | ≈ \(10^{\pm 38}\) |
| bfloat16 | 1 / 8 / **7** | ≈ \(2^{-8}\approx 0.4\%\) | ≈ \(10^{\pm 38}\)（指数位与 float32 相同） |
| fp16 | 1 / **5** / 10 | ≈ \(2^{-11}\) | 最大 65504，最小正常数 ≈ \(6.1\times 10^{-5}\) |

fp16 的尾数其实**更精**（10 位 vs 7 位），但指数只有 5 位、动态范围窄，遇到大梯度易溢出、小梯度易下溢。bfloat16 的取舍是「**要范围、舍精度**」——对一个目标精度只有 ±20% 的迭代，精度可以舍，范围不能舍。此外现代 GPU 的 bf16 矩阵乘吞吐远高于 fp32，正交化在每个参数每一步都跑，这笔性能账很关键。

**（4）改系数实验：五次 vs 经典三次。**
经典 Newton-Schulz 三次迭代是 \(h_3(\sigma)=\tfrac32\sigma-\tfrac12\sigma^3\)：在 \((0,\sqrt3)\) 上单调收敛到 1，且 \(h_3'(1)=0\)（超吸引）——**处处收敛**的模范生。代价是零点斜率只有 1.5：覆盖 \(\tilde\sigma_0\ge 1/438\) 需要 15–16 步（\(1.5^{15}\approx 438\approx 485\)）。算总账：

| 方案 | 每步矩阵乘 | 达到「覆盖 1/485」所需步数 | 总矩阵乘 | 输出谱 |
|---|---|---|---|---|
| 五次 NS（Muon，[muon.py:L16](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L16)） | 3（`A`、`A@A`、`B@X`） | 5 | **15** | \([0.68, 1.14]\) 带内漫游 |
| 三次 NS | 2（`A`、`A@X`） | 15–16 | 30–32 | 精确收敛到 1（±浮点噪声） |
| 三次 NS 只跑 5 步 | 2 | —（覆盖不足） | 10 | 谱远未拉平（小奇异值仍 ~1e-3） |

结论：五次方案用「放弃逐点收敛」换来约 **2 倍**的计算节省，而放弃的精度（±20% 带宽）对 Muon 的学习率语义毫无影响——这就是「默认 5 步」背后的完整账本，也解释了为什么 README 说 ns_steps 基本不用调（[README.md:L46](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/README.md#L46)）。

#### 4.3.2 核心流程

精度对比实验的设计（差分法）：

```text
真值:  ref = U @ V^T                    # float32 完整 SVD 构造的正交化
选手1: X_bf16 = 官方 NS5(G)              # 内部强制 bfloat16（L17）
选手2: X_f32  = NS5 复刻版, 不做 .bfloat16()   # 其余逻辑逐行相同
测量:  svdvals(X) 的 min/max/mean          # 谱形状
       ‖X - ref‖ 的逐元素最大误差          # 离真值的距离
预期:  ‖X_bf16 - X_f32‖ ≈ 1e-3..1e-2      # 纯舍入差
       ‖X_bf16 - ref‖ ≈ ‖X_f32 - ref‖ ≈ 0.1..0.3   # 都被带宽主导 → 精度不是瓶颈
```

系数变体实验的设计（公平对拍）：

```text
同一个 G, 同一套预处理（归一化/转置）, 只改循环体:
  五次: A = X@X.mT; B = bA + cA@A; X = aX + B@X      # 3 matmul/步
  三次: A = X@X.mT; X = 1.5X - 0.5(A@X)              # 2 matmul/步
对比: 步数 × {5, 16}, 输出谱 + 距 UV^T 的误差 + 矩阵乘次数
```

#### 4.3.3 源码精读

bfloat16 路径在源码中的两处：

```python
    X = G.bfloat16()
```

> [muon.py:L17](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L17) —— 入口第一步就降精度：此后归一化、迭代、返回全程在 bfloat16 上进行（返回值也是 bfloat16，u2-l2 已注明这个细节会一路传到 `p.add_`）。注意它是**硬编码**的——没有 dtype 参数，想做 float32 对比必须复刻整个函数（4.3.4 的做法），这本身也说明作者对 bf16 的信心。

```python
    # Ensure spectral norm is at most 1
    X = X / (X.norm(dim=(-2, -1), keepdim=True) + 1e-7)
```

> [muon.py:L21-L22](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L21-L22) —— 归一化是 bf16 安全性的另一半：除以 Frobenius 范数把所有元素压到 \([-1,1]\)、所有奇异值压到 \(\le 1\)，此后每步迭代的中间量都有界（\(A\) 的元素 \(\le 1\)、迭代值不超过极值 ≈1.202），**离 bfloat16 的溢出上限（≈\(3.4\times10^{38}\)）十万八千里**。u2-l2 的反面实验（跳过归一化两三步就 `inf`）从反方向证明了这行的必要性：溢出风险从来不来自精度格式，而来自忘记归一化。

循环体（改系数的现场，再贴一次便于对照）：

```python
    for _ in range(steps):
        A = X @ X.mT
        B = b * A + c * A @ A # quintic computation strategy adapted from suggestion by @jxbz, @leloykun, and @YouJiacheng
        X = a * X + B @ X
```

> [muon.py:L24-L27](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L24-L27) —— 换成三次迭代时：`c=0` 使 `A @ A` 项消失，循环退化为 `A = X @ X.mT; X = 1.5*X - 0.5*(A @ X)`，每步从 3 次矩阵乘降到 2 次。注释里的署名（@jxbz、@leloykun、@YouJiacheng）提醒我们：现役系数是社区实验筛选出来的，并非唯一解——你自己的系数变体（4.3.4 第 3 问）延续的是同一传统。

#### 4.3.4 代码实践：精度对比与系数变体

**实践目标**：(a) 证明 bf16 舍入不是精度瓶颈；(b) 量化五次 vs 三次的收敛速度与成本。

**操作步骤**（示例代码，存为 `ns_precision.py`）：

```python
# 示例代码：ns_precision.py
import torch
from muon import zeropower_via_newtonschulz5 as ns5

def ns(G, steps, quintic=True, dtype=torch.bfloat16):
    """复刻版 NS：与官方逐行等价，但 dtype 与系数可改。"""
    a, b, c = (3.4445, -4.7750, 2.0315) if quintic else (1.5, -0.5, 0.0)
    X = G.to(dtype)
    transposed = G.size(-2) > G.size(-1)
    if transposed: X = X.mT
    X = X / (X.norm(dim=(-2, -1), keepdim=True) + 1e-7)
    for _ in range(steps):
        A = X @ X.mT
        if quintic:
            B = b * A + c * A @ A
            X = a * X + B @ X            # 3 次矩阵乘/步
        else:
            X = a * X + (b * A) @ X      # 2 次矩阵乘/步
    return X.mT if transposed else X

torch.manual_seed(0)
G = torch.randn(256, 256)
U, S, Vh = torch.linalg.svd(G)           # float32 真值
ref = U @ Vh

def report(name, X, n_matmul):
    X = X.float()
    sv = torch.linalg.svdvals(X)
    print(f"{name:<22} 谱[{sv.min():.3f},{sv.max():.3f}] 均值{sv.mean():.3f} "
          f"距UV^T最大误差{(X-ref).abs().max():.4f} 矩阵乘×{n_matmul}")

report("官方NS5 bf16",   ns5(G, 5),                              15)
report("NS5 float32",    ns(G, 5, True,  torch.float32),         15)
report("三次NS5 bf16",   ns(G, 5, False, torch.bfloat16),        10)
report("三次NS16 bf16",  ns(G, 16, False, torch.bfloat16),       32)

# bf16 vs float32 的纯舍入差
d = (ns5(G, 5).float() - ns(G, 5, True, torch.float32).float()).abs().max()
print("NS5: bf16 与 float32 输出最大绝对差:", d.item())
```

**需要观察的现象**：
- `官方NS5 bf16` 与 `NS5 float32`：奇异值范围几乎一样（都在 ≈\([0.1\text{–}0.3,\ 1.2]\)，均值 ≈0.95），**距 \(UV^\top\) 的最大误差也几乎一样**（≈0.1–0.3 量级）；
- 两者的直接差 `d`：约 1e-3–1e-2，远小于各自到真值的距离——精度瓶颈是带宽，不是舍入；
- `三次NS5`：谱范围极宽（min 仍是 1e-3 量级）——5 步远没拉平，距真值误差最大；
- `三次NS16`：谱精确收在 \([0.99, 1.01]\) 附近、距真值误差 ≈1e-2（只剩 bf16 噪声），但矩阵乘 32 次，是五次方案的 2 倍多。

**预期结果**（具体数值待本地验证）：上表四个方案的对比应复现 4.3.1 的账本——「五次 5 步 = 15 次矩阵乘 + ±20% 带宽」对「三次 16 步 = 32 次矩阵乘 + 近乎精确」，以及「bf16 舍入（~0.4%）≪ 带宽（±20%）」。若你有 GPU，可再加 `time.perf_counter()` 对 4.2.4 的大矩阵（如 2048×2048）计时，观察 bf16 的吞吐优势（CPU 上差距很小，计时仅供参考）。

#### 4.3.5 小练习与答案

**练习 1**：同样是低精度运算，为什么 bf16 放在 NS 迭代里安全，放在 SVD 里危险？

**答案**：NS 迭代有自校正结构——不变区间把每步的舍入扰动重新拉回带内，误差不累积（且归一化后所有中间量远离溢出区）。SVD 是「分解类」算法，要把全部奇异向量/奇异值分辨到高精度，输入的 0.4% 扰动会直接污染分解结果；且 SVD 无法利用低精度矩阵乘的吞吐优势。这也是 [muon.py:L52-L53](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L52-L53) 明说选 NS 的原因。

**练习 2**：三次迭代要多少步、多少次矩阵乘才能覆盖与五次 5 步相同的小奇异值范围？

**答案**：覆盖阈值 \(1/h_3'(0)^k\)，需 \(1.5^k\gtrsim 485\)，即 \(k\ge 15\)（\(1.5^{15}\approx 438\)，取 15–16 步）。三次每步 2 次矩阵乘，共 30–32 次；五次 5 步只要 15 次。约 2 倍差距，这就是 Muon 选五次的量化理由。

**练习 3**：把系数改成你自己的（例如 \(a=3.0\) 并相应调整 \(b,c\)），按 4.1 的流程判断它是否可用，再实验验证。

**答案**：判断步骤——(i) \(h(1)\) 是否接近 1（不接近则已归一化的主奇异值会被压偏）；(ii) 极大值是否仍 \(\lesssim 1.5\)（上界决定谱范数可控性）；(iii) 是否存在吸引不动点或不变区间（决定轨道有界）；(iv) \(h'(0)\) 决定覆盖阈值 \(1/a^5\)。例如随意加大 \(a\) 会让 \(h(1)\) 偏离 1、带上沿抬高，更新谱范数失稳；随意减小则覆盖不足。结论：\((3.4445, -4.7750, 2.0315)\) 是在「带宽、覆盖、步数」三角里调出来的折中——具体取舍留给你的实验表格（待本地验证）。

## 6. 本讲小结

- **标量显微镜**：迭代映射 \(h(\sigma)=3.4445\sigma-4.7750\sigma^3+2.0315\sigma^5\)（[muon.py:L16](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L16)）的完整画像——局部极大 \(h(0.554)\approx1.202\)、局部极小 \(h(1.050)\approx0.682\)、两个**斥性**不动点 0.868/1.264、不变区间 \([0.682, 1.134]\)、5 步覆盖阈值 \(1/485\approx0.002\)。
- **「超过收敛临界点反而有效」的严格含义**：斜率加大后不动点全部斥性、轨道不收敛，但被关进以 1 为中心、宽约 ±20% 的不变区间；换来每步 3.44 倍的爬坡速度，5 步即可覆盖 \(\tilde\sigma\ge 0.002\)。
- **输出分布的真相**：奇异值主体落 \([0.68, 1.14]\)、上界 ≈1.202 封顶、低尾来自未爬完的极小奇异值；docstring 的 \(\mathrm{Uniform}(0.5,1.5)\) 是定性概括（上界到不了 1.5）——用 `svdvals` + 受控谱对拍实测封印。
- **ns_steps 的边际效应递减**：加步数只抬高 min（低尾爬坡），max 恒被封顶；每步 3 次矩阵乘，所以默认 5（[muon.py:L34](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L34)、[README.md:L46](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/README.md#L46)）。
- **bfloat16 安全的三重保险**：吸引带自校正（舍入误差不累积）＋归一化后中间量远离溢出区＋指数 8 位的大动态范围；且 0.4% 舍入 ≪ ±20% 带宽，精度根本不是瓶颈——[muon.py:L17](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L17) 与 [muon.py:L50-L53](https://github.com/KellerJordan/Muon/blob/f98f1cacc0263b04290753e32be8d498c1efc806/muon.py#L50-L53) 的设计因此成立。
- **系数是可改的经验值**：三次 NS 处处收敛但需 15–16 步（30–32 次矩阵乘），五次 5 步只要 15 次就以 ±20% 带宽为代价省一半计算——「默认 5 步」是精度与速度的实验折中。
