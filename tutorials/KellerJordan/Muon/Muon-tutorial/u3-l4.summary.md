本讲是 u3 单元收官实战，讲解按 README「替换配方」把 AdamW 训练脚本迁移为 MuonWithAuxAdam 单优化器模式（单机用 SingleDeviceMuonWithAuxAdam）：唯一必改处是优化器构造——旧 AdamW 超参原样继承给 use_muon=False 组，隐藏二维权重单独成 use_muon=True 组，训练循环 zero_grad/backward/step 一行不改，梯度裁剪、调度器、checkpoint 语义全部保持。参数划分用两层判据：ndim≥2 是必要条件，embedding 与输出头虽为二维仍按语义归入 adam 组，划分后需用「不重不漏」断言自检。调参方法论：momentum、nesterov、ns_steps 免调（后两者 API 未暴露），只调 muon 组的 lr（谱范数量纲，于 0.005～0.1 网格搜索）与 weight_decay，尺度因子带来 muP 式宽度无关性；两组 lr 量纲不同不可互抄（0.02 与 3e-4 约差 67 倍）。
