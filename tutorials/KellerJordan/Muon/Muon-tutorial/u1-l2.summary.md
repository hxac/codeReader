本讲承接 u1-l1，解决 Muon 项目的安装与首次运行。setup.py 用 py_modules 将单文件 muon.py 打包为发行包 muon-optimizer，确立「发行包名（pip 层面）与导入名（import 层面）相互独立」的关键概念；因未声明依赖，必须先装 PyTorch，再用 pip 从 git 仓库安装。import muon 可得 3 个函数（zeropower_via_newtonschulz5、muon_update、adam_update）与 4 个优化器类（分布式版 Muon、MuonWithAuxAdam，单机版 SingleDeviceMuon、SingleDeviceMuonWithAuxAdam）；单机版不调用 torch.distributed，无 GPU 的 CPU 环境即可学习验证。正交化要求参数 ndim≥2，一维参数（如 bias）会在 step 时触发断言错误，故实验模型须 bias=False。综合实践用 SingleDeviceMuon 在 toy 回归任务上跑通 50 步训练、loss 明显下降，为后续讲义建立可复用的实验环境；README 配方按 use_muon 标志把参数拆成两组，Muon 组学习率（约 0.02）与 AdamW 组（约 3e-4）量纲不同。
