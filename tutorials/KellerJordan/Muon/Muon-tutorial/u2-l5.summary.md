本讲精读 muon.py 中唯一不含分布式代码的优化器类 SingleDeviceMuon，它是四个类中「Muon 优化器最小骨架」的最佳标本。构造函数仅组装 defaults 并调父类；分布式 Muon 多出的「params 必须为显式列表」断言与按 size 降序排序，分别服务于按下标取参和 all_gather 形状一致。step 主循环：p.grad 为 None 时填零而非跳过（强制同步设计，避免分布式各 rank 集合通信序列错位致死锁；单机语义为梯度缺失≠冻结参数，衰减与动量衰减照常）；momentum_buffer 惰性初始化（len(state)==0 判据）；调 muon_update 得到更新后 reshape 回参数形状，再执行两行原地更新 p←(1-lr·wd)p-lr·u。核心结论：这是 AdamW 式解耦权重衰减，必须放在 Newton-Schulz 正交化之外做，否则尺度不变的正交化会摧毁衰减强度语义；数值直觉为更新 RMS≈lr/√n，开衰减后权重 RMS 平衡点≈√(lr/(2·wd·n))。ns_steps 与 nesterov 未在构造函数暴露，固定为 5 和 True。
