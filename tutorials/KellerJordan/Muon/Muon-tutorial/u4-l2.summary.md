本讲把 SGD+momentum、AdamW、Shampoo/SOAP、Muon 放进同一个「预处理器」谱系做理论与实证双线对比。核心结论：优化器可拆为「归一化器＋学习率」，SGD 无归一化器、更新继承梯度尺度；AdamW 做逐坐标对角白化（更新≈±1）；Muon 做整矩阵谱白化（更新 RMS≈1/√n，lr 单位为谱范数），故两套 lr 量纲差约 67 倍不可互抄，Muon 另具 muP 式宽度无关性且只存一份动量。代数上可证瞬时 Shampoo 更新恰等于正交化 UV^T——Muon 即免累积二阶统计、免矩阵幂逆的全矩阵瞬时白化，NS 迭代仅用矩阵乘、bf16 下稳定。实证侧按玩具实验、speedrun、124M 受控基准、工业报告四级证据分级批判阅读 README 战果，沉淀大规模注意事项：embedding 与输出头归 AdamW、两组 lr 独立调、权重衰减并入更新、更新 RMS 裁剪、分布式分片摊薄 NS 开销。综合实践为三优化器各 3 种子的微型基准。
