本讲解剖 CUDAMicroBench 微基准的三件套骨架：host 主程序（.c，实验控制器）、kernel 文件（.cu，GPU 实现与主机包装函数）、接口头文件（.h，双方契约）。host 程序遵循五阶段模板：数据初始化（固定种子可复现）、串行基线（计时外）、warmup（消化首次启动开销）、计时循环（num_runs 次取平均，read_timer_ms 毫秒墙钟）、check 校验（归一化差值）。包装函数 axpy_cuda 呈五段式：cudaMalloc、H2D 拷贝、逐 kernel 启动并同步、D2H、cudaFree。头文件用 extern "C" 解决 C/C++ 混编的符号名修饰差异，REAL 宏为精度开关且在 .h 与 .c 双处定义须同步修改。核心结论：host 墙钟时间大于纯 kernel 时间，后者需 nvprof 拆分；CoMem_AXPY 四个 kernel 共享 d_y 反复叠加，checksum 远大于 0，check 只是差值探针；与 MemAlign 比对证实骨架同构、差异集中于被测变量，即微基准控制变量方法论。Common/ 是 CUDA Samples helper 头文件的本地副本，实际服务 GSOverlap、TaskGraph、Shuffle、Conkernels。
