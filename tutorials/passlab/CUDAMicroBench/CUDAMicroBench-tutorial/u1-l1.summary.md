本讲是学习手册起点，只读文档与目录，无需 GPU。核心结论：CUDAMicroBench 是 IPDPSW 2021 论文配套的 14 个 CUDA 教学微基准（UNC Charlotte 与 LLNL 合作，BSD 三条款开源），无统一入口，须进入单个目录编译运行。README 汇总表把性能挑战分为三大类：饱和大规模并行（4 个，如 warp 分支发散）、利用 GPU 内部深存储层次（6 个，如非合并访存）、安排 CPU-GPU 数据搬运（4 个）；每个基准均成对演示“反模式与优化技术”。关键术语：微基准、反模式、kernel、host/device。文档与实地有三处偏差：14 个基准名对应 16 个代码目录（CoMem、ReadOnlyMem 各拆两实例）；6 个目录缺 test.sh；Common（源自 CUDA Samples 的 helper 头）实际服务 4 个基准而非 README 所列 3 个，Conkernels 引用路径疑多一级。读文档须用 ls、grep 亲手核验。
