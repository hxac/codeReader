本讲精读 Shuffle/cuda_shuffle 的 reduction_kernel.cu：reduce0~reduce6 七个求和 kernel 构成单变量演进的优化阶梯，每级针对上一级暴露的瓶颈——reduce0 患模运算与交错分支发散；reduce1 活跃线程改连续却引入 bank 冲突；reduce2 折半顺序寻址归零冲突；reduce3 装载即归约（每线程 2 元素）并用 warp shuffle 把块栅栏从 9 次降到 1 次；reduce4/5 让归约树止于 32、末 warp 以 shuffle 收尾并以模板参数完全展开；reduce6 用 grid-stride 循环每线程累积多元素、块数钳到 maxBlocks，即 Brent 定理的形状。核心结论：实现级优化改寻址、同步与指令而不动工作量分布；算法级优化改变每线程元素数即并行形状，收益最大；能降到 warp 内的操作绝不用块级机制。测量口径：代码默认 kernel 为 3 而非 6，归档 result.txt 全是 kernel 3 数据；程序打印的 Time 是含多级归约级联的流水线均值，非单 kernel 时间。
