本讲以 BankRedux 为例讲清测量口径：程序打印行中 checksum 是 GPU 归约结果与串行基线之差（含浮点非结合性与越界归并两个噪声源，只能作定性探针），time 是十轮完整调用的平均墙钟时间，包含显存分配与拷贝，远大于纯 kernel 时间——Carina 实测 56.80ms 中三个 kernel 每次合计仅约 9.55µs，大头是首次 cudaMalloc 的上下文创建摊销。nvprof 概览把耗时拆成 GPU activities 与 API calls 两段表，Calls 列可反向核对程序结构；nvprof --metrics 采集 branch_efficiency（未发散分支占比）等硬件计数器，与时间拆解互补（新工具链由 nsys/ncu 取代 nvprof）。仓库自带的 .output.carina/fornax.txt 终端转录可作无 GPU 环境的云实验数据，读时注意 stdout/stderr 错位，跨机器只能比相对结论；归档数据显示带 bank 冲突的归约比无冲突版慢 12%–24% 且随规模上升。
