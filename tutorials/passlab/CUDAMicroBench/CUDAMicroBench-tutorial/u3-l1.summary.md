本讲以 WarpDivRedux 微基准讲解 warp 分支发散。warp 是 32 个线程（lane）组成的 GPU 调度与执行基本单位（SIMT）；同一 warp 内线程对分支条件意见不一时，硬件串行执行各臂，即分支发散，发散区段利用率可低至两臂耗时之比，而跨 warp 的分歧不产生损失。三个 kernel 形成对照：warmingup 为预热 kernel 且两臂各含完整访存与计算，发散最重；warpDivergence 以 tid%2 分支为教科书级反模式，每个 warp 必然 16/16 分裂，但两臂仅寄存器赋值；noWarpDivergence 用 0/1 布尔值乘加做算术选择（手工谓词化）消灭分支，PTX 中只有 selp、无 bra。核心结论：发散代价取决于两臂长度与 kernel 访存受限程度，本基准消除发散仅带来约 5% 提速；Makefile 的 -G 关闭优化以保真演示分支形态；check 是弱校验（y==x 使所有分支都输出 5x，且 GPU 版与串行参考映射本不相同）；README 记载的「以 warp 大小为步长」（如 (tid/32)%2 使整 warp 同侧）是除算术选择外另一条消除发散的路线。量化工具为 nvprof 的 branch_efficiency 指标。
