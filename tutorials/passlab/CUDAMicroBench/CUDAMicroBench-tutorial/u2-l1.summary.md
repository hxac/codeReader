本讲以 AXPY 微基准解剖第一个 kernel：AXPY 各元素计算独立，最朴素的并行化是「每线程一个元素」（1perThread 策略），串行 for 循环被折叠进线程维度；函数体与之一字不差的 warmingup 是独立 kernel，用于消化首次启动的一次性开销，便于计时与观测。核心概念：`__global__` 声明在设备上执行、由 host 用三尖括号语法调用的 kernel，返回值必须为 void；线程按 grid→block→thread 两级层级组织，内建变量 threadIdx.x、blockIdx.x、blockDim.x、gridDim.x 经公式 i = blockDim.x*blockIdx.x + threadIdx.x 回答「我是谁」，该编号分段连续、无缝无重叠。启动配置 `<<<grid, block>>>` 两个参数依次是块数与每块线程数，(n+255)/256 是整数向上取整技巧，保证线程总数不少于 n，因此 kernel 内 if (i<n) 边界检查不可省略。结论：此 kernel 每线程仅 2 次运算却搬 24 字节，属访存受限（memory-bound），块大小在 128~512（32 的倍数，warp 为 32 线程调度单位）间变化对性能影响很小；block/cyclic 两种固定网格的划分策略留给下一讲 u2-l2。
