本讲以 CoMem_AXPY 与 MemAlign 这对同构基准为例，讲正确性验证与计时方法。串行基线（serial baseline）是单线程朴素参考实现，只作正确性参照（oracle）、不参与计时，区别于性能基线，且两条路径须从同一初值出发（memcpy 复制）、覆盖范围对齐被测 kernel。check() 计算相对 L1 误差（差值绝对值和除以参考数组绝对值和），与数据规模无关；实测 checksum（CoMem 约 36~39、MemAlign 恒为 1.99838）是计时多轮叠加、内部多 kernel 与两侧调用次数不对称的结构性产物，并非浮点误差，原 assert 阈值判定已被注释。计时三件套：read_timer_ms 墙钟计时、num_runs=10 多轮平均、warmingup 预热；首轮 cudaMalloc 的上下文创建摊入均值，kernel 仅占约 0.2%，时间主要耗在分配与搬运。REAL 宏在 .h 与 .c 双处定义，切换精度须同步修改，否则 extern "C" 会静默掩盖类型不一致。
