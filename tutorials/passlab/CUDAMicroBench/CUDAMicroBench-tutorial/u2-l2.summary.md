本讲围绕 AXPY 讲解一维数据的三种任务划分：每线程一个元素（1perThread，线程数随 n 增长）、连续块分布（block，每线程承包 B=n/T 的连续区间）与循环分布（cyclic，即 grid-stride loop，步长为总线程数 T）。核心结论：block kernel 的 n/T 向下取整会在 n 不整除时静默漏算尾部元素，修复可改为向上取整加边界判断，或让前 r 个线程多摊一个元素；cyclic 对任意 n 不重不漏、线程数与 n 解耦，是 CUDA 标准范式。因四个 kernel 共享 d_y 顺序叠加，验证单个 kernel 须隔离运行。引入术语：任务划分、总线程数 T、grid-stride loop、隔离验证，并为合并访问专题埋伏笔。
