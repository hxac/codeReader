本讲含三个模块：①AppWindow 命令面——根节点注册 `*IDN`、`*RST` 与 `DEVice` 子树（设备连接、模式切换、状态与能力上限查询），驱动专属命令随设备连接动态挂载/移除，命令面随连接状态伸缩；②三模式即三命名空间——`Mode` 继承 `SCPINode` 并在构造时挂根，`:VNA:`、`:SA:`、`:GENerator:` 子树永远在线，SCPI 与鼠标 UI 是同一前端（写同一 settings 结构），但仅激活且运行的模式才驱动设备；③43 行的 `TCPServer`——仅凭 received→input、output→send 两根信号线与 SCPI 框架解耦，换行分帧（canReadLine/readLine）解决 TCP 粘包与半包，单连接、后来者顶替，无超时与行长保护。核心结论：设置命令成功无应答、失败只置 `*ESR` 标志，脚本须按此设计读写节奏；SCPI 服务默认启用、监听 19542 端口，`--no-gui` 只关窗口而 Qt 事件循环照常，无头 GUI 即一台网络可控仪器。
