本讲覆盖 GUI 侧 Trace 体系的三个模块：Trace、TraceModel 与轴类型。Trace 即一条曲线，按 X 升序存「x+线性复数 y」样本，来源分实时/文件/数学/校准四种，同频点替换分覆盖、峰值保持、最小保持三策略。Trace 继承 TraceMath、是数学链第 0 级，对外读取一律委托链末端 lastMath，数据变更经 dataChanged 触发图表重绘。TraceModel 三位一体：既是界面 Trace 列表的表格模型，又是 Trace 容器与测量数据分发中枢，并经 requiredExcitation 反推激励端口、反向重配设备。轴是数据到屏幕的翻译层：X 轴五类、Y 轴二十余类复数换算，可用组合受「数据源×X 类型」闸门约束。lastMath 委托与轴类型矩阵为后续绘图（u8-l2）与数学运算框架（u8-l5）讲义承接。
