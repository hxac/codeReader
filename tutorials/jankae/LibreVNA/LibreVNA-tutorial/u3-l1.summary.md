本讲解读 LibreVNA GUI 唯一的设备抽象 DeviceDriver：七个纯虚函数（getDriverName、connectTo、getInfo 等）是必须实现的契约；配置类虚函数默认返回 false 或空容器以表达「不支持」，配合 Feature 枚举、supports()、Info::Limits 与 Flag 完成能力协商和优雅降级。测量数据同样硬件无关：VNAMeasurement 存线性复数、SAMeasurement 存线性电压（1.0 即 0dBm），以字符串为键的 map 适配任意端口数，union 兼容零扫宽；数据经 Qt 信号推送，配置采用「请求＋回调」。驱动注册靠 getDrivers() 手写懒加载单例，驱动名须全局唯一；connectDevice() 以静态 activeDriver 仲裁全局唯一活动设备，isIndepedentDriver 为复合驱动旁路。核心结论：依赖倒置使各模式只持有 DeviceDriver 指针；驱动继承分两层——LibreVNADriver 承载协议逻辑，USB/TCP 子类补齐发现与连接。
