本讲拆解 GUI 的「多人格」架构。Mode 基类三重继承 QObject、Savable、SCPINode，把界面元素管理、SCPI 命令子树与 JSON 持久化打包进同一生命周期：构造时自动挂上命令树，finalize 把中央界面注册进中央 QStackedWidget 并隐藏全部专属元素。activate/deactivate 为 protected，仅由 ModeHandler 调度；切换铁律是先 deactivate（布局写入 QSettings、设备 setIdle）再 activate（恢复布局、initializeDevice），保证同一时刻只有一个活动模式。具体模式须实现六个纯虚函数：getType、initializeDevice、setAveragingMode、preset 以及 Savable 的 toJSON/fromJSON。ModeHandler 兼任工厂（createNew 按 Type 枚举分发），ModeWindow 是纯 UI 切换器，二者靠信号双向同步。SaveSetup 以模式列表加 activeMode 名做工作区持久化，模式名必须唯一（nameAllowed）。VNA、频谱仪、信号源三种内置模式复杂度递减；新增自定义模式需同时修改 Type 枚举、TypeToName、工厂 switch 与 SetInitialState 四处，UI 菜单则自动生效。
