本讲绘制 LibreVNA 仓库地图。核心是三大子树对应三大组件，构成 FPGA→MCU→USB→PC 三站数据链路：PC_Application 为 PC 端 Qt GUI（负责校准、绘图、数学运算），VNA_embedded 为 STM32 上的 FreeRTOS 固件（负责调度与数据预处理），FPGA 为 VHDL 逻辑（实时采样、射频时序与片上 DFT）。关键结论：GUI 子树按功能域分目录（VNA、SpectrumAnalyzer、Traces、Calibration、Device 等），LibreVNA-GUI.pro 是一份“活的文件索引”，且 GUI 与固件共同编译 Protocol.hpp，从机制上保证 USB 协议两端定义同源；固件子树区分 CubeMX 生成代码与 Application 手写代码两层，main.c 在 USER CODE 区调用 App_Start() 交棒进入项目自有代码，芯片驱动集中在 Application/Drivers/；FPGA 子树以 top.vhd 为顶层，连接 Sweep、Sampling、Windowing、DFT、MAX2871 等功能块，且各配 Test_* testbench；根目录 AssembleFirmware.py 把 bitstream 与 MCU 固件拼成 combined.vnafw 刷机包。本讲引入的术语：三站数据链路、功能域定位口诀、USER CODE 区、testbench；USB/Device/FPGA 三份协议文档位于 Documentation/DeveloperInfo/。通用定位方法：先判断功能属于哪一站，再按目录名望文生义，最后用 .pro 文件或目录浏览验证。
