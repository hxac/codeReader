本讲讲解 LibreVNA-GUI 设置体系的三个模块：Savable 接口、Preferences 系统、Setup 保存/加载。核心结论：持久化分两级——Preferences 是全局偏好单例，常规经 QSettings 自动存取，另有 .vnapref JSON 备份通道；Setup 是工作区快照，由 AppWindow::SaveSetup/LoadSetup 把各模式 JSON 聚合成 .setup 文件。nlohmann::json 是统一中间表示，Savable 以 toJSON/fromJSON 两个纯虚函数规定「对象↔JSON」契约；SettingDescription 声明式描述表配合 QPointerVariant 实现点分路径到成员变量的双向映射，缺项自动回退默认值，构成向后兼容基础。setup 有菜单、--setup 命令行、SCPI 命令、启动自动加载、退出自动保存五种入口，全部收敛到同一对函数；文件人可读、可用脚本改写，是自动化配置的正门。关键术语：QSettings、QVariant、单例、SettingDescription 描述表、updated() 观察者信号、activeMode、driverSpecificSettings 驱动扩展点。
