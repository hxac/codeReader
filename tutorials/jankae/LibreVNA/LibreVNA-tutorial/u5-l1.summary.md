本讲剖析 LibreVNA 固件（STM32G431、FreeRTOS）从复位到事件主循环的启动链路，覆盖三个模块：CubeMX 生成代码与 USER CODE 区、App 启动与任务初始化、中断与同步。核心结论：固件分 ST 生成骨架与项目自有代码两层，仅靠 main.c 的 USER CODE 区衔接；App_Init 十五步完成初始化（USB 最早就绪，B 版硬件从 Flash 灌 FPGA bitstream，失败以四档 LED 错误码指示），随后进入 App_Process 事件主循环。全固件仅 defaultTask 与 LedStatusTask 两个任务，实时工作几乎都在中断上下文。关键约束为 FreeRTOS 红线：中断优先级数字小于 5 者禁调内核 API，STM::DispatchToInterrupt 以函数指针 FIFO 挂起 COMP4 软中断实现二级分发来跨越它；任务同步仅用 xTaskNotify 位标志；TIM17 与 SysTick 构成双 1ms 心跳。
