本讲对比 LibreVNA GUI 的频谱分析仪（SA）模式与 VNA 模式在设置结构、驱动接口、数据结构三层的差异：SA 测绝对功率（dBm）而非 S 参数比值，故 `SAMeasurement` 是端口名到线性电压的映射（1.0 即 0 dBm），无相位。配置链沿用「Set* 槽 → SASettings → 100ms 防抖 → ConfigureDevice → setSA()」骨架，但 SASettings 无点数/功率扫描，多出 RBW、窗、检波器、跟踪源（TG）四块；点数由驱动按 min(span+1, 1001) 自定；窄 RBW 会置 UseDFT 位切换设备内部处理路径。数据上行 `NewDatapoint` 有三重守卫，依次做线性域平均、零扫宽时间归零、归一化，再交 `TraceModel::addSAData`。归一化是双状态机：先直通测量按点号收集参考，后逐点除以参考并缩放到目标电平，span/点数变化由四道保险兜底。它只修幅度，是 SOLT 校准的极小子集；VBW 在代码中不存在，平滑由平均与检波器承担。
