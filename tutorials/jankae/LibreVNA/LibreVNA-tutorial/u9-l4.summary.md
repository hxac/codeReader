本讲覆盖 LibreVNA 去嵌入插件框架的三个最小模块：一是 DeembeddingOption 接口，以 getAffectedPorts、transformDatapoint（就地修改测量点，多选项按列表顺序接力）、getType 三个纯虚函数为契约，edit() 与 measurementCompleted() 为可选能力，可经 triggerMeasurement 信号预约一次扫描；类型身份由 Type 枚举与 TypeToString 字符串双轨定义，新增类型仅需改枚举、工厂、字符串、.pro 四处，对话框菜单与持久化自动生效。二是 Deembedding 容器与设置对话框，负责选项增删换序、SCPI 按 1..n 重编号、toJSON 按序持久化。三是与校准管线衔接，核心结论为“平均→校准→写入 data→去嵌入→写入 deembeddingData”：去嵌入作用于校准后数据，Trace 双数据集并存，由 deembeddingActive 标志切换读取；需要实测的选项按 pointNum 收集整条扫描后回调；手动去嵌入可对导入 Trace 复用同一数学，是无硬件验证路径。端口延伸（√f 损耗模型、反射参数除以 c²）为参照实现，u9-l5 将精读四个内置选项的数学。
