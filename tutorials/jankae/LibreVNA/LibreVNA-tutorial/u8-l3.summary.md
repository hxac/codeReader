本讲义剖析 LibreVNA GUI 的 Marker（游标）系统，覆盖三个模块。其一是读数机制：Marker 本质是「Trace 指针 + X 位置」，不复制数据，每次 Trace 变化时经 interpolatedSample 现算读数；位置落在采样点之间时由 TraceMath 的 getInterpolatedSample 做复数域线性插值（实虚部分别插值），但默认偏好 interpolatePoints=false 会先把位置吸附到最近采样点，插值默认不生效；Marker 的域随父 Trace 输出类型自动变化。其二是自动搜索：13 种类型（Manual、Maximum、Delta、PeakTable、Bandpass、TOI、P1dB、Flatness 等）共享一个 update() 分发器，重活由 Trace 侧的 findExtremum/findPeakFrequencies 承担；峰值判定是「过门限 + 回落超 3 dB 谷深」的状态机；复杂类型用 helper marker（子游标，后缀如 1a、l/h/c）动态增删地呈现多点结果；类型可用性受域、反射测量、Live-SA 三重闸门约束。其三是 MarkerGroup 编组：让多条 Trace 上同域、可移动（Manual/Delta）的游标共享位置，靠 positionChanged 广播同步，用 adjustingMarkers 布尔护栏阻断 Qt 同步直连信号的递归回环；成员违规自动退组，空组销毁，组本身不持久化而由成员记录的组号推导重建。MarkerModel 兼任树形表格模型、容器与组的工厂，模式层仅在扫描完成时批量刷新。后续讲义将承接 Trace 数学链（lastMath）与 Touchstone 格式。
