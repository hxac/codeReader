本讲拆解最简的读带宽微基准，五件套为：契约头 krnl_config.h、HLS 内核、OpenCL 主机、连线表 ini 与 Makefile。契约由 v++ 与 g++ 两端共享：DWIDTH 定端口位宽，WIDTH_FACTOR 负责 int 与宽元素单位换算，NUM_ITERATIONS 放大时长并藏进带宽公式系数。内核以两个 m_axi 端口在 DATAFLOW 下并行读；主机先初始化，再按 payload 倍增扫 11 档，数据搬运不计时，启动内核等完成后算带宽。ini 的 slr/sp/nk 仅构建期生效，定 CU（计算单元）位置与端口到 DDR 的连线；主机须与 ini 手工对齐 CU 名与内存通道两点，改参须两端联动。
