本讲逐行精读读带宽微基准内核 krnl_ubench.cpp。内核用两份互不依赖的读循环配两个异名 bundle（gmem0/gmem1），在 DATAFLOW 下构成两台并发读引擎：bundle 名是端口数量的开关，每循环独占一个 volatile 临时变量则是 dataflow 无依赖的前提。内层 PIPELINE II=1 使每端口每拍发出一个 512-bit 读请求，连续地址被自动合并为 16 拍的 AXI 突发，300 MHz 双端口理论峰值 38.4 GB/s。防优化采用双保险：volatile 指针保证读请求必发出，volatile 临时变量保证读到的值被消费，两者齐拆则循环可被死代码消除；NUM_ITERATIONS=10000 做时间放大，并以魔数 0.000010000 的身份进入主机带宽公式，改动须联动。size 参数单位是宽字个数，主机送参前要除以 WIDTH_FACTOR=16。FPGA 的 m_axi 读通路无 cache，重复读同一数据不污染测量。DDR 与 HBM 两工程内核源码逐字节相同（已用 git diff 实测），内存类型差异全落在链接期 ubench.ini 的 sp/slr 与运行期主机 flags 绑定上；且两版双端口均接同一通道，测的是共享通道争用而非跨通道聚合峰值。
