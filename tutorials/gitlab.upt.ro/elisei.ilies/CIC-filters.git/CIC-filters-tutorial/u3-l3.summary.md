本讲在 100 MHz、Open-source CIC 单一方案下做参数扫描:固定方案/频率/器件/阶段,只让级数 N(主)与抽取率 R(辅)变化,记录 LUT/寄存器/CARRY4 与 WNS。核心是区分两类响应——资源是"数"出来的,可复现且随参数严格单调;WNS 是"跑"出来的,依赖布局布线、带路径依赖噪声,只呈总体趋势。结论:资源随 N 近线性增长(寄存器最小二乘拟合 Reg≈112N−112,根因为每级多 2 个定宽累加器,叠加位宽公式 ⌈N·log₂(MR)⌉ 的缓慢加宽),随 R 则次线性(对数型),影响远弱于 N;WNS 及由它估得的 fmax≈1000/(Tclk−WNS) 随 N 总体下降(fmax 从约 391 跌到 149 MHz),关键路径的逻辑级数(CARRY4 堆叠)是其物理证据。引入的关键术语:参数扫描、受控/自/响应变量、路径依赖噪声、对数型增长、fmax 估值、逻辑级数。一句话:CIC 选大 N 换更陡的滤波,代价是面积近线性增长、最高频率显著走低。
