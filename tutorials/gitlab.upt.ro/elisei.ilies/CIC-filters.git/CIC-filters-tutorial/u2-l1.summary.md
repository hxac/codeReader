本讲教学生在 Vivado 时序报告中判断设计是否满足时序约束，主分析对象为实现阶段报告 `timing_impl_R16_N4.txt`（CIC Compiler、R=16、N=4、100 MHz）。核心结论：判断收敛只需看 `Design Timing Summary`——当 `WNS`（最差建立裕量）与 `WHS`（最差保持裕量）均为正、`TNS/THS Failing Endpoints` 均为 0、且出现 `All user specified timing constraints are met.`，即代表时序收敛。本设计实测 `WNS=6.274 ns`、`WHS=0.044 ns`，全部满足。引入的关键术语包括：建立时间与保持时间检查、Slack（裕量，标注 MET/VIOLATED）、`TNS`/`THS`（违例规模）、`Requirement`（等于时钟周期 10 ns）、`Data Path Delay`（拆分 logic/route）、`Logic Levels`、`Source Clock Delay`。要点：建立松弛量方向为 `required − arrival`，保持为 `arrival − required`；多角分析中建立取 Slow 角最差值、保持取 Fast 角最差值，需留意 `Path Type` 标注。综合与实现两份报告的差异在于后者含真实布线延迟，布线占比更高、`WNS` 更小。
