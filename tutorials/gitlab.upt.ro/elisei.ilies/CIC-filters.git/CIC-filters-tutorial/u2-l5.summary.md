本讲从「实验设计层面」俯瞰整批 Vivado 报告，回答这批数据在什么条件下采集、覆盖哪些组合、缺口在哪。核心分四个模块：其一，时钟周期与频率互为倒数，T(ns)=1000/f(MHz)，三档频率 100/290/300 MHz 对应周期 10.000/3.448/3.333 ns；报告内频率因周期取整显示为 290.023/300.030 等非整数，脚本匹配须用周期或容差而非精确相等。其二，实验是「频率(3档) × 抽取率R(5档:{4,8,16,32,64}) × 级数N(5档:{2..6}) × 实现方案(3种)」的多维矩阵，理论满阵 225 点。其三，覆盖不均：100 MHz 是唯一三方案齐全的频率点（故横向对比须以此为基准），290 MHz 仅有 CIC Compiler，300 MHz 缺 Open-source；各方案 R×N 组合数为 MATLAB 25（最全）、Open-source 24（仅缺 R4_N2）、CIC Compiler 11（受 Xilinx IP 限制，整段缺 R4 与 N2，最稀疏）。其四，缺口分两类：结构性缺口（真没数据，须如实说明）与卫生型陷阱——290 MHz 的 CIC Compiler 下存在 to_delete/ 重复副本，全量统计必须用排除路径，否则重复计数。所有数据均来自同一器件 7a100t-csg324（Artix-7），保证跨频率、跨方案比较的器件一致性。关键术语：时钟周期、频率换算、WNS、实验矩阵、覆盖矩阵、结构性缺口、卫生型缺口、to_delete/ 副本陷阱。
