## 2. 前置知识

本讲是原理入门，会用到一点「信号」的直觉。下列概念了解即可，不必精通：

- **采样率（sampling rate / 采样频率）**：每秒采多少个样本，单位 Hz。例如音频常用 48 kHz，表示每秒 48000 个样本。
- **数字滤波器**：对一串数字样本做某种运算，得到一串新的样本。例如「求平均」「求差分」都是最朴素的滤波。
- **累加（accumulate）**：把新样本不断加到一个「累积和」上：`总和 = 总和 + 新样本`。
- **差分（difference）**：用当前样本减去若干拍之前的样本：`差 = 当前样本 − 旧样本`。
- **寄存器（register）**：FPGA 里存储一个数的单元，相当于「一个能记住数值的小盒子」。在 [u1-l1](u1-l1-project-overview.md) 里我们已经知道本实验最终要跑在 FPGA 上。

> 不熟悉 z 变换的读者：本讲会出现 \(z^{-1}\) 这种记号，你可以把它**直觉地理解为「延迟一拍（一个采样周期）」**。例如 \(z^{-1}\,x[n]\) 就是「上一拍的样本」。只要抓住「\(z^{-1}\) = 延迟一拍」这层含义，下面的公式都能读懂。

本讲按四个最小模块展开：先讲构成 CIC 的两个「半身」——积分器与梳状器；再把它们放进多速率（抽取/插值）的框架里串成完整通路；最后聚焦 R、N、M 三个参数，并把它们落到本仓库真实的报告文件上。

### 4.1 积分器（Integrator）

#### 4.1.1 概念说明

**积分器（Integrator）** 是 CIC 的第一个「半身」，它本质上就是一个**累加器（accumulator）**：每来一个新样本，就把它加到累积和上。用差分方程写就是：

\[
y[n] = y[n-1] + x[n]
\]

即「这一拍输出 = 上一拍输出 + 这一拍输入」。它在不断「累加」所有历史输入，因此在数字信号处理里被形象地叫作「积分」。

从电路看，积分器只需要两样东西：一个**加法器**和一个**寄存器**（记住上一拍的累积和）——**没有乘法器**。这正是 CIC 又快又省的根源。

> 名字里的「积分」取的是「累加」之意，和微积分里的积分是同一种直觉（连续累加 → 离散累加）。

#### 4.1.2 核心流程

单个积分器一拍的处理流程：

```text
读入 x[n]
   │
   ▼
[ + ] ◄──── 寄存器里保存的 y[n-1]（上一拍累积和）
   │
   ▼
和 = x[n] + y[n-1]
   │
   ▼
输出 y[n] = 和，并把「和」写回寄存器，供下一拍使用
```

用 z 变换表示，单个积分器的传递函数为：

\[
H_I(z) = \frac{1}{1 - z^{-1}}
\]

记住「\(z^{-1}\) = 延迟一拍」，分母 \((1 - z^{-1})\) 就表达了「这一拍输出依赖上一拍输出」这种**递归（反馈）**关系。所以积分器是一个**无限脉冲响应（IIR）**环节。

#### 4.1.4 代码实践

这是「编写型」实践（仓库无可运行代码），用一小段 Python 直观感受积分器的「累加」行为。代码为**示例代码**，非仓库原有内容。

1. **实践目标**：亲眼看到积分器把一个输入序列「累积」成一条不断增长（或随输入趋势漂移）的曲线。
2. **操作步骤**：把下面代码存为 `integrator_demo.py` 并运行。

   ```python
   # 示例代码：单个 CIC 积分器的累加行为
   x = [1, -1, 1, -1, 1, 1, 1, 1]   # 输入序列（注意里面有直流偏置）
   y = 0                              # 累积和，相当于寄存器初值
   out = []
   for n in range(len(x)):
       y = y + x[n]                   # y[n] = y[n-1] + x[n]
       out.append(y)
   print("integrator out:", out)
   ```

3. **需要观察的现象**：前几个 `1, -1` 来回抵消，累积和上下波动；当连续输入 `1, 1, 1, 1` 时，累积和开始**单调上升**——这就是积分器对「直流/低频」特别敏感、对高频来回振荡会相互抵消的直觉。
4. **预期结果**：输出大致为 `[1, 0, 1, 0, 1, 2, 3, 4]`（待本地验证，依你填的输入而定）。
5. **延伸思考**：把输入换成纯 `1, -1, 1, -1...`，观察累积和是否始终在 0/1 之间跳——这说明积分器对「零均值的高频」几乎不放大。

#### 4.1.5 小练习与答案

**练习 1**：积分器的差分方程 \(y[n] = y[n-1] + x[n]\) 里，用到乘法了吗？用到几个寄存器？

> **参考答案**：没有用到乘法，只用了一次加法；需要一个寄存器来保存上一拍的累积和 \(y[n-1]\)。

**练习 2**：为什么说积分器是 IIR（无限脉冲响应）环节？

> **参考答案**：因为它的输出 \(y[n]\) 依赖上一拍输出 \(y[n-1]\)，存在**反馈/递归**；一个脉冲输入后，其影响会通过累积和「无限」地延续下去，故为 IIR。

### 4.2 梳状器（Comb）

#### 4.2.1 概念说明

**梳状器（Comb）** 是 CIC 的第二个「半身」，它本质上是一个**带延迟的差分器（differentiator）**：用当前样本减去若干拍之前的样本。对一个工作在低速率（见 [4.3](#43-抽取插值与多速率信号处理)）的梳状器，其差分方程为：

\[
y[m] = x[m] - x[m - M]
\]

其中 \(M\) 叫**差分延迟（differential delay）**，通常取 1 或 2。当 \(M=1\) 时，它就是「这一拍减上一拍」的一阶差分。

它为什么叫「梳状（Comb）」？因为它在频域的幅频响应呈一串等间距的「凹陷（null）」，像一把梳子的齿——这在 [4.4](#44-rnm-参数) 讲频率响应时会再点一次。

电路上，梳状器同样只需要一个**减法器**和一个能延迟 \(M\) 拍的**寄存器（或移位寄存器）**——**仍然没有乘法器**。

#### 4.2.2 核心流程

单个梳状器（\(M=1\)）一拍的处理流程：

```text
读入 x[m]
   │
   ├──────────────────────► 输出一路 x[m]
   │
   ▼
[ 延迟 M 拍 ]  ◄── 保存 x[m-M]
   │
   ▼
[ − ]  ◄──── x[m-M]
   │
   ▼
输出 y[m] = x[m] − x[m-M]
```

用 z 变换表示（注意此处 z 对应梳状器所在的**低速率**采样），单个梳状器的传递函数为：

\[
H_C(z) = 1 - z^{-M}
\]

这里**没有反馈**（输出不依赖自身历史），所以梳状器是一个**有限脉冲响应（FIR）**环节。

继续用「编写型」实践，把上一节的积分器输出喂给一个梳状器，观察「先积分后差分」能否把信号「还原」出来。代码为**示例代码**。

2. **操作步骤**：在上一段代码后追加：

   ```python
   # 示例代码：M=1 的梳状器，对积分器输出做差分
   M = 1
   comb_out = []
   for m in range(len(out)):
       past = out[m - M] if m - M >= 0 else 0   # 不足 M 拍时按 0 处理
       comb_out.append(out[m] - past)
   ```

4. **预期结果**：`comb out` 大致等于 `[1, -1, 1, -1, 1, 1, 1, 1]`，与输入吻合（待本地验证）。
5. **延伸思考**：如果中间不做任何降采样，积分+梳状基本抵消；CIC 的妙处在于**积分与梳状之间插入了降采样**，下一节就讲这点。

**练习 1**：梳状器 \(y[m] = x[m] - x[m-M]\) 用到乘法器吗？它是 IIR 还是 FIR？

> **参考答案**：不用乘法器，只用减法和延迟；输出不依赖自身历史，故为 FIR。

**练习 2**：为什么这种「当前样本减 M 拍前样本」的结构在频域会呈现「梳齿状」凹陷？

### 4.3 抽取/插值与多速率信号处理

#### 4.3.1 概念说明

把积分器和梳状器配成一对还不够，CIC 的精髓在于它是**多速率（multirate）**系统——积分器和梳状器工作在**不同采样率**上。

- **抽取（decimation，降采样）**：把采样率从高 \(f_s\) 降到 \(f_s/R\)，做法是「每 R 个样本保留 1 个」，记作 \(\downarrow R\)。
- **插值（interpolation，升采样）**：相反，把采样率从低升到高，记作 \(\uparrow R\)。

本实验面向**数字音频**，典型场景是 ΣΔ（Sigma-Delta）ADC 的**数字前端抽取**（见 [4.3.4](#434-代码实践) 与第 5 节综合实践），因此本讲以**抽取型 CIC（CIC decimator）**为主。

CIC 抽取器的关键布局（Hogenauer 经典结构）：

```text
        工作在高速率 f_s                          工作在低速率 f_s/R

 x[n] → [∫积分器]×N → ↓R → [梳状器]×N → y[m]
        （N 个积分器串接）  （N 个梳状器串接）
```

也就是：**N 个积分器先在高速率上跑 → 中间降采样 ↓R → N 个梳状器再在低速率上跑**。

为什么要把降采样夹在中间？这源于多速率信号处理里的 **noble identity（恒等变换）**：在满足一定条件下，「先滤波再降采样」可以等价地变成「先降采样再换一种滤波」。对 CIC 而言，把梳状器挪到低速率一侧后，**梳状器里那条「长延迟」可以缩短**——原本在高速率下需要延迟 \(M\cdot R\) 拍的差分，挪到低速率后只需延迟 \(M\) 拍，**大幅节省了寄存器**。这是 CIC 又省又快的第二个关键。

#### 4.3.2 核心流程

CIC 抽取器一拍（输入拍）的数据流：

1. **高速段**：新样本 \(x[n]\) 依次进入 N 个积分器，每个积分器做 \(y=y+x\) 的累加，全部工作在高速率 \(f_s\)。
2. **降采样**：每累计 R 个高速样本，只取 1 个送往下游（速率降为 \(f_s/R\)）。
3. **低速段**：被保留下来的样本依次进入 N 个梳状器，每个做 \(x[m]-x[m-M]\) 的差分，工作在低速率 \(f_s/R\)。
4. **输出**：得到低速率的抽取后序列 \(y[m]\)。

把上述通路的传递函数（折算到高速率参考下）写成：

\[
H(z) = \frac{(1 - z^{-MR})^{N}}{(1 - z^{-1})^{N}}
\]

读法：分子是 N 个梳状器的合作用（其延迟 \(M\) 在低速率下等价于高速率的 \(MR\) 拍），分母是 N 个积分器的合作用。这正是「Cascaded Integrator-Comb」的数学写照。

> 插值型 CIC（CIC interpolator）方向相反：**梳状器先在低速率跑 → ↑R → 积分器在高速率跑**。本实验以抽取为主，插值结构作为对照了解即可。

#### 4.3.5 小练习与答案

**练习 1**：CIC 抽取器里，积分器工作在高速率还是低速率？梳状器呢？

> **参考答案**：积分器工作在**高速率** \(f_s\)（降采样之前）；梳状器工作在**低速率** \(f_s/R\)（降采样之后）。

**练习 2**：为什么把梳状器放到降采样之后的低速率一侧，能节省寄存器？

> **参考答案**：根据 noble identity，梳状器的差分延迟从高速率的 \(M\cdot R\) 拍缩短为低速率的 \(M\) 拍，所需的延迟寄存器数量显著减少（外部知识，严格推导待确认）。

### 4.4 R/N/M 参数

#### 4.4.1 概念说明

CIC 的全部行为只由三个参数决定（这也是它「好调」又「难精调」的原因）：

| 参数 | 名称 | 含义 | 对设计的影响 |
| --- | --- | --- | --- |
| **R** | 速率比（rate change factor） | 抽取/插值比，采样率变化倍数 | R 越大，单级降得越多；直流增益随 R 升高，内部位宽变宽 |
| **N** | 级数（number of stages） | 积分器-梳状器**对**的级联数 | N 越大，阻带抑制越强，但资源近似线性增长、时序更紧 |
| **M** | 差分延迟（differential delay） | 梳状器差分间隔（常取 1 或 2） | 影响梳齿位置与零点分布；M 不在仓库文件名里 |

在本仓库里，**R 和 N 直接写进了每个报告的文件名**，例如 `R16_N4` 表示 R=16、N=4；而 **M 不出现在文件名中**，取值待确认。

**直流增益与位宽增长。** CIC 的直流（零频）增益为：

\[
G = (M\cdot R)^{N}
\]

这意味着信号经过 CIC 后幅值会被放大 \((M R)^N\) 倍，因此**内部寄存器必须加宽**以避免溢出。按 Hogenauer 的结论（外部知识），最大内部位宽约为：

\[
B_{\max} \approx B_{\text{in}} + \big\lceil N\cdot \log_2(M\cdot R) \big\rceil
\]

例如 \(R=16,\,N=4,\,M=1\) 时，增益 \(G=16^4=2^{16}=65536\)，需要多 **16 位**；若 \(R=64,\,N=6,\,M=1\)，则 \(G=64^6=2^{36}\)，需要多 **36 位**。这解释了为什么本仓库里 R、N 越大的配置，**寄存器资源显著上升**——这是后续 [u3-l1 资源对比](u3-l1-resource-comparison.md) 和 [u3-l3 R/N 扫描趋势](u3-l3-rn-sweep-trends.md) 的理论根据。

**频率响应。** CIC 的幅频响应是一个 sinc 形状的主瓣，配上等间距的「凹陷」（梳齿）。在 \(M=1\) 时，第一个凹陷恰好落在输出采样率 \(f_s/R\) 处，这刚好能压住「抽取后会混叠回基带」的那些频段——所以 CIC 天生可以充当抽取的**抗混叠**角色。其缺点是**通带下垂（passband droop）**明显，通常要在 CIC 之后再接一个 FIR 补偿滤波器（外部知识，推导待确认）。

#### 4.4.2 核心流程

给定一个目标应用，选 CIC 参数的典型思路：

1. 由「输入高速率 → 目标输出速率」算出抽取比 **R**。
2. 由「阻带抑制需求」选级数 **N**（N 越大抑制越好，但资源、时序代价越大）。
3. 由「梳齿/零点位置需求」选 **M**（常取 1 或 2）。
4. 用 \(G=(MR)^N\) 估算内部位宽，确定寄存器宽度。
5. 跑综合 + 实现，看资源（LUT/寄存器/DSP）与时序（WNS）是否满足——这正好回到本仓库的报告数据。

**练习 2**：为什么 R=64、N=6 的 CIC 比 R=16、N=4 的 CIC 占用更多寄存器？

## 5. 综合实践

把本讲四个模块串起来：画出 N=4 级 CIC 抽取器的完整结构，并解释它为何常作 ΣΔ ADC 数字前端的第一级抽取。

**任务 1：画出 N=4 级 CIC 抽取器结构框图**

1. 在纸上（或用文本）画出下面通路，标清每一段的**采样率**与**运算**：

   ```text
                高速率 f_s                                    低速率 f_s/R = f_s/16

   x[n] ─► [∫ I1] ─► [∫ I2] ─► [∫ I3] ─► [∫ I4] ─► ↓R=16 ─► [C 梳1] ─► [C 梳2] ─► [C 梳3] ─► [C 梳4] ─► y[m]
            累加      累加      累加      累加      降采样       差分       差分       差分       差分
            y=y+x    y=y+x    y=y+x    y=y+x    每16取1      x−x_{−M}   x−x_{−M}   x−x_{−M}   x−x_{−M}
   ```

2. 在图上标注：积分器段共 4 个、梳状器段共 4 个（N=4 表示「积分-梳状对」有 4 对，而不是总共有 4 个单元）。
3. 用一句话点出关键：**降采样 ↓R 必须夹在积分器组与梳状器组之间**，这是 CIC 又省又快（梳状器短延迟）的根本。

**任务 2：解释「为何 CIC 是 ΣΔ ADC 数字前端的第一级抽取」**

请用 3～5 句话覆盖以下要点：

- ΣΔ 调制器输出的是**高速、低位宽（常为 1 位）**的码流，需要大幅度降采样才能得到可用的低速高分辨率信号。
- 第一级抽取必须工作在**最高速率**上，因此最忌讳「慢且贵」的乘法器。
- CIC **没有乘法器**，只用加减法和寄存器，能在极高时钟下廉价运行，正好胜任第一级。
- CIC 的梳齿凹陷天然落在输出速率处，能起到**抗混叠**作用；其通带下垂由后级 FIR 补偿。
- 因此典型链路是：**ΣΔ 调制器 → CIC 抽取（第一级，无乘法） → FIR 补偿/整形（后级，有乘法） → 音频采样率**。

**自检**：你的结构图里，积分器是否都在 ↓R 的**左侧（高速）**、梳状器是否都在 ↓R 的**右侧（低速）**？如果画反了，请回到 [4.3.2](#432-核心流程) 重读。你的解释里是否点出了「无乘法器」这一点？这是 CIC 的头号卖点。

## 6. 本讲小结

- **CIC = Cascaded Integrator-Comb（级联积分梳状）**：由 N 对「积分器 + 梳状器」级联而成，全称已锚定到 [README.md:1](https://github.com/gitlab.upt.ro/elisei.ilies/CIC-filters.git/blob/e49b263d702c6fb0d4ea1d5b8390d307e6ba43d1/README.md#L1)。
- **积分器**是累加器 \(y[n]=y[n-1]+x[n]\)（IIR）；**梳状器**是带延迟的差分 \(y[m]=x[m]-x[m-M]\)（FIR）。两者都**只用加减法和寄存器、不用乘法器**——这是 CIC 适合高速前端的核心原因。
- CIC 是**多速率**系统：抽取器里 N 个积分器在**高速率**跑，经 ↓R 后，N 个梳状器在**低速率**跑；得益于 noble identity，梳状器延迟从 \(MR\) 拍缩短为 \(M\) 拍，节省寄存器。
- 三个参数：**R（速率比）、N（级数）、M（差分延迟）**。R、N 直接写在本仓库报告文件名里（如 `R16_N4`），R∈{4,8,16,32,64}、N∈{2..6}；**M 不在文件名中，待确认**。
- 直流增益 \(G=(MR)^N\) 决定了内部位宽增长 \(B_{\max}\approx B_{\text{in}}+\lceil N\log_2(MR)\rceil\)，解释了「R、N 越大、寄存器越多」的资源趋势（外部知识，推导待确认）。
- 本讲所有 CIC 原理均属**外部公认的 DSP 知识**，仓库内无理论文档与 HDL 源码佐证；本讲能真实引用的只有 README 对 CIC 的命名，以及报告文件名/头部里的 R、N。
