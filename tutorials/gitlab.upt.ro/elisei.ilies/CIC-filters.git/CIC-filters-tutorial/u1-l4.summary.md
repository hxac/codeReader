本讲是 FPGA 后实现评估的入门概念课，回答「这些 Vivado 报告到底在评估什么」，共四个最小模块。第一模块区分两个流程阶段：综合（synth）把 HDL 翻译成门级网表但未布线，实现（impl）在网表上完成优化、布局、布线；impl 报告含真实布线延迟，是论文「Post-Implementation 评估」的依据。判别阶段的可靠抓手是文件名里的 `synth`/`impl` 及 utilization 报告头部的 Design State 字段（Synthesized 或 Routed）。第二模块引入时序概念：以 Slack = Required − Arrival 衡量数据能否在一个时钟周期内稳定传递，核心指标 WNS（最差建立时间裕量）为正即满足约束；本设计 100 MHz 下 WNS = +6.274 ns，全部约束满足。报告在 Slow/Fast 双工艺角分析，违例多出现在 Slow 角。第三模块引入利用率概念：用 Used/Available 的 Util% 衡量资源占用，关键资源为 Slice LUTs、Slice Registers、DSP、Block RAM；本设计 LUT=155、寄存器=261、DSP=0、BRAM=0，印证 CIC 滤波器只用加减法、无需乘法器的特性。第四模块解析目标器件 xc7a100tcsg324-1（Artix-7、CSG324 封装、速度等级 -1 为最慢档），并指出 timing 报告头部无 Design State 字段、器件写法与 utilization 不同。后续 u2-l1、u2-l2 将逐节精读时序路径与利用率原语。
