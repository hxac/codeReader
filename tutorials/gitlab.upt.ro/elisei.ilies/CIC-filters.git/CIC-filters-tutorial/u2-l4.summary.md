本讲在固定实验条件（100 MHz、R=16、N=4、器件 xc7a100tcsg324-1）下，横向对比同一 CIC 抽取滤波器的三种 FPGA 实现方案，并梳理各自的参数覆盖差异。三方案通过报告头部 `Design` 字段区分：厂商 IP 方案 Xilinx CIC Compiler 名为固定的 `cic_compiler_0`；代码生成方案 MATLAB HDL Coder 名为 `CIC_R{R}_N{N}`（唯一随参数变化）；手写 RTL 方案 Open-source 名为固定的 `cic_d`。每种实现都留下独有的「特征签名」：CIC Compiler 用 `SRL16E` 移位寄存器 LUT 把梳状器延迟塞进 LUT（用 LUT 换寄存器），故 LUT 与寄存器最少；HDL Coder 用清一色 `FDCE`（异步清零）配 `LUT2`；Open-source 用 `FDRE` 配大量 `CARRY4` 进位链，且控制集翻倍（13），面积最费。三方案 DSP 与 BRAM 均为 0，共同印证 CIC 只含加减法、无乘法器、无需块存储。参数覆盖上，HDL Coder 完整覆盖 5×5 网格，Open-source 仅缺 R4_N2，CIC Compiler 完全没有 R4 和 N2、矩阵稀疏，这决定了后续可做的横向对比范围。关键概念包括 Design 名、SRL16E、CARRY4 与控制集。
