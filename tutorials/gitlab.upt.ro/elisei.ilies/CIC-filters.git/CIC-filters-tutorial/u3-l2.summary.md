本讲围绕四份 Vivado 实现阶段时序报告，从「读懂报告」升级到「下判断」，只盯时间维度，覆盖四个核心模块：时序裕量与收敛、多角分析、fmax 估算、TNS/Failing Endpoints 量化失败。引入的关键术语：WNS（最差建立裕量，≥0 即收敛，裕量占周期比例 <5% 属临界收敛）；TNS（负裕量总和，与 WNS≥0 互为充要）；Failing Endpoints（违例条数）；多角分析（PVT 波动下建立查 Slow 角最严、保持查 Fast 角最严，配 CPR 扣除时钟公共路径的虚假悲观）；fmax（最大频率，估算公式 fmax≈1/(T_clk−WNS)≈1/关键路径到达时间）。核心结论：可信 fmax 必须来自最贴近失败点的紧约束 run，宽松 run 因布局布线松散而偏悲观；本数据集全部收敛（TNS=0、Failing=0）。同配置下逻辑级数少者关键路径更短、fmax 更高（MATLAB HDL Coder 优于 CIC Compiler）。综合实践完成「估算→预测→实测」闭环，验证 R64_N6 在 300MHz 擦边收敛（WNS=0.103ns）。
