本讲教读 Vivado 后实现（impl）利用率报告，由 `report_utilization` 生成、靠目录分节，每节是同一张六列表（Site Type/Used/Fixed/Prohibited/Available/Util%），`Util% = Used÷Available×100%` 可手算复核。主分析对象为 CIC Compiler 方案（R16/N4/100MHz，器件 xc7a100tcsg324-1）。四项核心资源用量：Slice LUTs=155、Slice Registers=261、Block RAM=0、DSP=0。Memory 与 DSP 双零直接印证 CIC"只做加减、无乘法"的特性，DSP=0 几乎是其特征签名；Clocking 仅用 1 个 BUFG，单时钟域。Slice LUTs 拆分为 LUT as Logic（130）与 LUT as Memory（25，全部是 LUT as Shift Register）。Primitives 原语表信息量最大：CIC Compiler 用 FDRE(260)+SRL16E(41)+CARRY4(25) 搭建，触发器总数与 Slice Registers 自洽。引入的关键术语：SRL16E（用一片 LUT 实现的移位寄存器，承担梳状器差分延迟）、FDRE/FDCE（同步复位/异步清零 D 触发器）、CARRY4（进位链）、BUFG（全局时钟缓冲）、LUT 与寄存器的子类划分。对比伏笔：MATLAB HDL Coder 同配置下改用 FDCE(266)+LUT2(186)、无 SRL16E，体现"同功能、不同零件"的实现风格差异，承接 u2-l4 与 u3-l1 的跨方案对比。
