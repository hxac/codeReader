本讲义讲清 CIC（级联积分梳状）滤波器原理。积分器是累加器（IIR），梳状器是带差分延迟的差分器（FIR），两者都只用加减法和寄存器、不用乘法器，这是 CIC 适合高速前端第一级抽取的根本。CIC 属多速率系统：抽取器中 N 个积分器先在高速率运行，经 ↓R 降采样后，N 个梳状器在低速率运行；据 noble identity，梳状器延迟从 MR 拍缩短为 M 拍，节省寄存器。三个核心参数为 R（速率比）、N（级数）、M（差分延迟），直流增益 (MR)^N 决定内部位宽增长，解释了 R、N 越大资源越多的趋势。本仓库报告文件名编码 R∈{4,8,16,32,64}、N∈{2..6}，M 不在文件名中待确认；本讲原理属外部 DSP 知识，仓库内无理论文档与 HDL 源码佐证。
