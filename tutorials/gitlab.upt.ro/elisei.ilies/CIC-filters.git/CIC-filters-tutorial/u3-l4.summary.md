本讲把"读报告、做对比、看趋势"的能力落到音频 FPGA 选型上。核心结论：CIC 在 ΣΔ（Sigma-Delta）音频 ADC 数字前端中担任第一级大比率抽取，因只用加减法、无乘法器（仓库三方案 DSP=0 互证），能在调制器几兆赫兹码流上工作。引入术语：过采样比 OSR、抽取滤波链（CIC→补偿FIR CFIR→整形FIR PFIR）、总抽取比等于 OSR。CIC 直流增益 G=(MR)^N 驱动无溢出位宽 B_max=B_in+⌈N·log₂(MR)⌉，这是寄存器随 N 线性、随 R 对数增长的根因（R16→R64 实测 261→339、CARRY4 25→34 为证）。对音频，调制器时钟（MHz 级）远低于 fmax（百兆赫兹级），时序非绑定约束，位宽（SNR）与混叠抑制才是；CIC 占器件面积不足 0.5%、DSP/BRAM 均为 0，选型应由后级 FIR 的 MAC 需求与通道数决定。N 应在满足 SNR 前提下取最小。论文具体音频参数（OSR、采样率、M 值、最终方案）不在仓库内，均标注"待确认"。
