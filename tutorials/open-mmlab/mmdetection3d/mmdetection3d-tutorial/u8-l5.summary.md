本讲是 MMDetection3D 手册的工程收尾篇，讲如何证明代码正确并把它交出去。核心内容：tests/ 目录按镜像原则对应 mmdet3d 包结构，tests/data 内置单帧级迷你数据集，使测试无需下载真实数据即可精确断言解析数值；mmdet3d/testing 是随包发布的伪数据工厂，create_detector_inputs 产出 dict(inputs, data_samples) 模型输入契约，get_detector_cfg 从真实 config 建模并补齐 train/test cfg，setup_seed 固定全部随机源。测试分三种范式：裸函数式抓数值回归，类式抓数据契约与异常防线，冒烟式验证建模与前后向连通、只断言 loss 非负等环境无关不变量。CI 为 CircleCI 两级结构：路径过滤把纯文档 PR 降级为 lint-only，否则跑 lint、CPU 双版本串行、人工批准后 GPU 矩阵。贡献流程共六步，要点是基线选 dev-1.x、pre-commit 本地拦截风格、PR 保持原子、开 PR 后手动改 base。
