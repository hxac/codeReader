本讲讲解 mmdet3d 的数据契约 Det3DDataSample。它继承 mmdet 的 DetDataSample，以 property 三件套声明 gt_instances_3d、pred_instances_3d、多模态专用的 pts/img_pred_instances_3d、点级 gt/pred_pts_seg 等字段，setter 的 dtype 断言构成运行时类型防线。实例级数据装 InstanceData（N 实例同长），点级数据装 PointData（全一维、按点同长、可整体索引），eval_ann_info 是唯一裸 dict 字段；metainfo 与 data fields 分区存放，sample_idx、box_type_3d 等元信息全流程共享。生命周期主线：Pack3DDetInputs 按四组键名路由表生产 dict(inputs, data_samples) 并剥去 gt_ 前缀；预处理器追加 batch_input_shape 等 metainfo；模型 loss 模式读真值、predict 模式经 add_pred_to_datasample 写预测（键名由 bbox3d2result 统一）；评估器（如 KittiMetric）以 pred_instances_3d 与 sample_idx 消费结果。
