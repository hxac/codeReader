本讲以 PointPillars 对 KITTI 单帧点云（`.bin`，每点 4 个 float32）跑通首个推理 Demo。涉及模块：`demo/pcd_demo.py` 命令行入口、`LidarDet3DInferencer` 及其基类 `Base3DInferencer` 的主循环、推理专用加载器 `LidarDet3DInferencerLoader`、底层 API `init_model` 与 `inference_detector`。核心结论：推理分高层 Inferencer 一站式与底层 API 灵活可控两条路线，均经 `model.test_step` 前向；Inferencer 初始化时把测试管线首部的 `LoadPointsFromFile` 原地替换为可接受裸路径或 numpy 数组的加载器，其余 transform 不变；调用阶段按预处理、前向、可视化、后处理四段推进，产出 vis_lidar 图片与 preds JSON。关键术语：7 自由度 3D 框、`Det3DDataSample.pred_instances_3d`（含 bboxes_3d、scores_3d、labels_3d）、checkpoint 权重、测试管线 pipeline。另需记住：置信度阈值只影响可视化，JSON 保存全部预测；`inference_detector` 单帧返回 (result, data) 二元组；单目与多模态 demo 需额外提供含 cam2img、lidar2img 标定矩阵的 info pkl。
