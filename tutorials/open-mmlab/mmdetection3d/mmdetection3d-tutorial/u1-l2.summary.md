本讲分四个模块讲解 MMDetection3D 的环境安装与验证：依赖链条全景、setup.py 与 requirements、包入口版本断言、安装验证四步法。核心结论：依赖链为 PyTorch → mmengine/mmcv/mmdet → mmdet3d 的四层结构，因 mmcv 的预编译 CUDA 算子必须匹配本机 torch 与 CUDA 版本，安装顺序不可颠倒——先装 PyTorch，再用 MIM 安装三件套，最后可编辑安装（pip install -e .）mmdet3d；该命令只装 runtime 的十个包，不含 torch 与三件套，可选依赖经 extras 提供；setup.py 用 exec 读版本号、把 configs/tools 软链进 .mim 目录，本体不编译 CUDA 扩展。包入口三条断言以左闭右开区间限定 mmcv、mmengine、mmdet 版本（比较前须经 digit_version 数值化），是每次 import 都执行的运行时最后防线：缺库报 ModuleNotFoundError，越界报带修复建议的 AssertionError。验证按 pip list、对照区间、import mmdet3d、跑 demo 四层递进，静态检查不能替代动态检查。关键术语：依赖链条、可编辑安装、MIM、extras、左闭右开区间、版本断言、四层验证。
