本讲导览 projects/ 生态：子项目寄生在主库注册器上，按「注册进 mmdet3d 节点、包入口导出、config 声明 custom_imports、default_scope 路由」接入，README 三段式 milestone 清单标注成熟度。DETR3D 代表稀疏 query 路线：900 个 3D 查询持归一化参考点，以 3D-to-2D 方式经 lidar2img 投影采样多相机图像特征，解码器逐层精修参考点（detach），HungarianAssigner3D 一对一匹配、逐层深监督，NMSFreeCoder 免 NMS 输出。BEVFusion 代表稠密 BEV 路线：图像分支用 DepthLSSTransform（点云稀疏深度增强的 LSS）生成 BEV 特征，点云分支复用 SECOND 体系，ConvFuser 拼接融合，两分支分辨率须手工对齐至 180×180（0.6 米/格）是隐性契约。末尾给出 config 考古法：逐 type 判定来自主库、project 自有或 mmdet 前缀，三步法可通读任意新项目。
