本讲介绍 MMDetection3D 项目全景：OpenMMLab 生态中基于 PyTorch 的通用 3D 检测工具箱，既是命令行工具也是 Python 库。它支持 LiDAR、相机、多模态 3D 检测与 3D 语义分割四大任务，各分室内/室外场景，主力数据集含 KITTI、nuScenes、Waymo、ScanNet 等。依赖上立于 MMEngine（训练引擎）、MMCV（视觉基础库）、MMDetection（2D 组件）三层，包入口以左闭右开区间断言版本。仓库四大目录分工：mmdet3d/ 存实现、configs/ 存实验描述、tools/ 为命令行入口、projects/ 孵化前沿项目。本讲引入的关键术语有：3D 框（中心、尺寸、朝向角七参数）、点云、单目 3D 检测、多模态、配置驱动与注册器路由，后者是贯穿全库的骨架模式。
