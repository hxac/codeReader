本讲讲解 info pkl 的离线生成链路。`tools/create_data.py` 是数据准备总调度台：按数据集名分发到各 prep 函数，统一执行「生成 v1 info → 升级为 v2 标准格式 → 生成 GT 数据库」三步。KITTI 按 ImageSets 划分收帧，派生每框点数 num_points_in_gt，裁剪后的 velodyne_reduced 是训练配置硬依赖；nuScenes 从 json 数据库物化出六相机信息、沿 prev 指针回溯的 sweeps、雷达系速度与 valid_flag；室内三件套（SUN RGB-D/ScanNet/S3DIS）另产分割 info 与 1/ln(1.2+n) 形式的逐类 label weight。核心结论：info pkl 是 converter 与 dataset 的契约边界——转换器离线读原始数据并算好派生量，数据集类在线只做轻量加工；v2 格式顶层为 metainfo 加 data_list，单条分 images、lidar_points、instances 三段式。关键术语：v1/v2 格式升级、extra-tag 文件名前缀、GT 数据库、data 目录符号链接。
