本讲义讲解 mmdet3d 模型侧二次开发。官方将模型组件分为六类——encoder、backbone、neck、head、RoI extractor、loss，全部注册在同一 MODELS 节点下，扩展套路统一为「定义类并注册 → 导入 → config 挂接」三步范式，其中「导入」是易错环节，因为「import 即注册」：装饰器仅在模块被 import 时执行。两条导入路线：改主库 `__init__.py`（适合合入核心包）与配置 `custom_imports` 键（不动主库源码）。逐行解剖 example_project 模板：DummyResNet 跨库继承 mmdet 的 ResNet 却注册进 mmdet3d 的 MODELS，用 `**kwargs` 透传参数，配置仅 7 行，靠点号语法 `_base_.model.backbone.type` 单字段改写父配置；projects 目录依赖 PEP 420 隐式命名空间包机制（无 `__init__.py` 也可导入）。路由成功依赖 `default_scope='mmdet3d'` 与注册节点一致；脱离 Runner 手动 build 时须 `init_default_scope` 补齐。实战演示自定义 Anchor3DHead 子类的替换型改造闭环，并区分「替换」（零代码换 type）与「扩展」（重写方法、需读懂父类契约）两种深度。
