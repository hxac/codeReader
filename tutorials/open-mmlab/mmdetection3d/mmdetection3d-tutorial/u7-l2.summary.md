本讲讲解 tools/test.py 测试入口与 mmdet3d 评估指标体系。test.py 是薄入口，只按命令行改写配置（checkpoint、work_dir、可视化、TTA）后交给 runner.test()；关键辨析：命令行 --score-thr 只进可视化 hook，而 model.test_cfg.score_thr 在 box3d_multiclass_nms 前过滤预测，才真正影响 mAP。8 个 metric 类均继承 BaseMetric 两段式契约：process 逐批把预测攒为 CPU 结果、compute_metrics 全量结算，因 AP 需全数据集统一排序；format_only 可只转官方提交格式。NuScenesMetric 走官方 devkit 路线，按 BEV 中心距离（0.5/1/2/4 米）匹配，输出 mAP、五类 TP 误差（mATE/mASE/mAOE/mAVE/mAAE）与 NDS，LiDAR 模型属性由速度启发式兜底。KittiMetric 为自研 numba 实现：预测与真值均转回 KITTI 原生九字段，按图像高度、遮挡、截断分 easy/moderate/hard 三档，strict/loose 双 IoU 阈值，41 点 PR 单调化得 AP11/AP40，纯 LiDAR 的 2D AP 来自 3D 框投影。其余 Waymo 调官方 C++ 二进制、Lyft 走 devkit、室内指标复用 indoor_eval（3D IoU@0.25/0.5）。
