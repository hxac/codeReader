本讲从 3D 检测转入语义分割：模型对点云逐点输出类别，以 mIoU 评价。四个最小模块：一是 Seg3DDataset，与检测数据集平级，用两级标签映射把原始类别 id 归一到 0~18、无效类压入 ignore_index，scene_idxs 支持大场景重复采样，训练态把 dataset 对象注入 data_info 供 LaserMix/PolarMix 混合增强；二是分割器分层 Base3DSegmentor→EncoderDecoder3D→Cylinder3D/MinkUNet，postprocess_result 把 logits 取 argmax 写入 pred_pts_seg，测试逐场景推理、batch 恒为 1；三是 Cylinder3D，柱体分区（转柱坐标栅格化以均衡点密度）加不对称稀疏卷积，SegVFE 做点特征聚合，损失为 CE 加 Lovasz；四是 MinkUNet，立方体量化取每体素代表点，骨干可在 torchsparse/spconv/Minkowski 三后端间切换，分类头仅为 Linear。两路线共用的核心范式是点与体素的双向映射：体素化时动态生成 voxel_semantic_mask 与 point2voxel_map，训练按体素标签算损失，推理再查回逐点预测。
