本讲绘制 MMDetection3D 仓库源码地图：顶层目录分实现（mmdet3d 主包、projects 前沿孵化区）、描述（configs、demo）、入口与文档（tools、docs、tests）三组。mmdet3d 包六大子模块呈星形依赖：structures 位于最底层，定义 3D 框、点云与 Det3DDataSample 等数据契约，被 datasets（数据集与 transforms 管线）、models（全部模型组件）、evaluation、visualization 共同依赖，engine 以 Hook 横切训练循环；registry.py 的 17 个注册节点是路由中枢，其 locations 参数即「注册节点→源码目录」对照表。tools/train.py 与 test.py 仅做读配置、覆盖参数、Runner.from_cfg、启动训练/测试五步流程；create_data.py 把原始数据转成 info pkl。configs/_base_/ 四件套（模型、数据集、日程、运行时）经 `_base_` 继承加增量覆盖构成实验配置。核心方法是 grep class 反查 config 中 type 的源码位置；带 mmdet. 前缀表示从 MMDetection 跨库借用。VoxelNet 检测器一次贯穿八个模型子目录，可作为后续单元的阅读主线。
