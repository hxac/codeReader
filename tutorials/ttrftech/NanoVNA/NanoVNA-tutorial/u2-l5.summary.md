本讲剖析 NanoVNA 固件的调度骨架：低优先级 sweep 线程 Thread1 的主循环依次消费 sweep_mode、shell_function、operation_requested、redraw_request 四个共享标志，测量、UI、绘图收进同一线程顺序执行，故不启用互斥量也能保持线程安全。sweep 的 break_on_operation 参数以频点为最小打断单位响应 UI 输入；scan 命令调 sweep(false) 保证一次性输出完整数据，代价是执行期间 UI 冻结、结束后仪器停在暂停态。shell 通过 shell_function 函数指针把带 CMD_WAIT_MUTEX 标志的命令移交 sweep 线程执行。输入采用中断顶半部/底半部分离：中断只举旗，ui_process 统一消化；显示为请求-响应两级流水：plot_into_index 置位 redraw_request，draw_all 按位局部重画。关键术语：SWEEP_ENABLE/SWEEP_ONCE（后者为无人置位的保留位）、__WFI 睡眠等待与 dsp_wait 手搓信号量、volatile 单写者纪律、markmap 脏矩形、1 tick=100µs 计时。
