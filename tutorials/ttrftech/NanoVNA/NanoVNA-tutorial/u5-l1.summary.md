本讲剖析 NanoVNA 的 USB CDC Shell 与跨线程命令执行。固件以 CDC-ACM 描述符（VID/PID、bulk 端点对）枚举为虚拟串口，SDU1 以 BaseSequentialStream 流接口供 shell 读写，逻辑与 USB 细节解耦。自研 shell 仅约 90 行：readLine 单字节读取并回显，executeLine 把分隔符原地改 NUL 实现零拷贝参数切分，再线性查 commands[] 命令表（名字/函数/flags 三元组）分发，新增命令只需一个函数加一行表项。裁剪版 chprintf 新增 %q 频率 SI 前缀格式化（移位除法，规避 M0 无硬件除法）与 %F 自动前缀浮点，shell_printf 走 USB 流、plot_printf 写内存缓冲。核心机制 CMD_WAIT_MUTEX：互斥量与信号量被整体关闭，main 线程把命令递交 volatile 函数指针 shell_function 并轮询等待，sweep 线程在测量间隙执行并清零，命令与测量天然串行，WFI 可被 SOF 中断唤醒故暂停扫描时命令仍可用。capture 命令借双 DMA 分批回读显存（18 位转 RGB565）直吐二进制帧。综合实践为仿照现有命令新增 uptime 并注册进命令表。
