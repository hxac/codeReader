本讲是毕业项目：为固件实现「多次测量平均」，贯穿 sweep 链路、线程模型、properties_t 持久化与表驱动菜单。方案是在 Thread1 整帧层以 average_sweeps() 包裹 sweep()，对 measured 中的复数 Γ 做 1..8 遍相干平均，噪声标准差降 1/√n（n=8 约 9dB），且必须平均复数而非 dB 值。关键术语与结论：软浮点（M0 无 FPU，一次除法换多次乘法）；累加缓冲借用 spi_buffer，靠单写者、不与显示 DMA 并发保证安全；shell 命令按「函数＋表项」注册，average 只写单字节故无需 CMD_WAIT_MUTEX；平均次数存于 properties_t 的 _reserved[0]，读取时把旧槽的 0 钳制为 1 实现前向兼容；UI 菜单与 Python data 通道构成三端入口；注意 scan 命令直接调 sweep，会绕过平均路径。
