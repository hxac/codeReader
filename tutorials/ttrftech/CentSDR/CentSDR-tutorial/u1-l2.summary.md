本讲打通从源码到运行固件的完整链路。构建由 Makefile 驱动，用 arm-none-eabi- 工具链交叉编译到 Cortex-M4（Thumb 指令、硬浮点），编译规则来自 ChibiOS 的 rules.mk。固件三来源：ChibiOS 经 git 子模块钉住固定提交、CMSIS-DSP 仅取 5 个文件、自有代码逐个列在 CSRC。产物有 elf/bin/hex 三种格式，text/data/bss 三段分居 Flash 与 RAM。烧录主通道是 SWD 探针加 gdb 脚本（OpenOCD 或 st-util，make flash 默认后者），免探针可走 USB DFU 或 Nucleo U 盘拖拽。无硬件时可用 size/objdump 对照链接脚本核对 128k Flash、40k RAM 容量。
