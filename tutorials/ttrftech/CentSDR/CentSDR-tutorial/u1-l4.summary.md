本讲拆解 CentSDR 的人机控制链路。usbcfg.c 把 USB 枚举成 CDC 虚拟串口：描述符声明设备身份，EP1 批量端点传数据，主机侧生成 /dev/ttyACM*；SDU1 被抽象为 BaseSequentialStream，ChibiOS shell 框架跑在其上，应用只需提供 main.c 里 NULL 哨兵结尾的 commands 表（27 条命令），命令统一签名 (chp, argc, argv)。命令套路为“校验参数→调底层函数→更新 uistat→刷屏”：tune 设信号频率而 freq 直设本振；mode 前缀匹配切换，本质是替换 signal_process 函数指针实现解调热切换；stat 的 load 指标量化 DSP 实时余量；data 以十六进制转储内部缓冲区。python/centsdr.py 是 Python 2 的模块兼 CLI，以 ch> 提示符判定一条命令输出结束，用 %04x↔'>h' 编解码对把 data 输出解析成 numpy 数组抓波形。核心结论：扩展成本极低，固件侧加命令只需一个函数加表里一行，Python 侧加一个 send_command 模板方法。
