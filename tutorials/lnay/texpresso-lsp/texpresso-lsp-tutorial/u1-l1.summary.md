本讲建立 texpresso-lsp 的整体地图：它是用 TypeScript 写的实验性 LSP 服务器，作为「薄壳」包裹 TeXpresso 可执行文件，使任意支持 LSP 的编辑器获得 LaTeX 实时预览与正反向搜索能力。需区分二者——TeXpresso 是 C 写的命令行渲染工具；texpresso-lsp 只做 LSP 接入与 JSON 翻译转发，不碰渲染、编译、SyncTeX。

核心心智模型是「三层架构」：编辑器（LSP 客户端）⇄ texpresso-lsp（翻译官）⇄ texpresso 子进程（含本体与 texpresso-tonic 编译器）。编辑器与服务器走 LSP（基于 stdio）；服务器向 texpresso 发 JSON 命令写 stdin、收 JSON 事件读 stdout；反向跳转时服务器直接 spawn 编辑器命令，不走 LSP。子进程在 LSP onInitialize 握手阶段即启动。

功能现状：实时预览、反向搜索已实现；跟随光标的正向搜索 README 标为未完成，但代码已有借用 documentHighlight 触发 synctex-forward 的半成品。源码入口为 server.ts（另有 process-manager.ts 管理子进程、types.ts 定义类型），以 connection.listen() 发车。
