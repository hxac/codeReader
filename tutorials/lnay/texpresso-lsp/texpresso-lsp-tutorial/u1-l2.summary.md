本讲回答「texpresso-lsp 如何在本机跑起并接入编辑器」，覆盖三个最小模块。其一，`package.json` 定义四条 npm 脚本：`build`（tsc 编译）、`start`（跑 dist/server.js，须先 build）、`dev`（ts-node 免编译跑源码）、`watch`（增量编译）；`tsconfig.json` 的 rootDir/outDir 决定 src→dist 产物映射。其二，全局安装后 `texpresso-lsp` 命令链路为 `bin` 字段指向 `bin/texpresso-lsp.sh`，该脚本再 `require('../dist/server.js')`；`--stdio` 是 LSP 传输标志。服务器自身不带渲染器，握手时 spawn `texpresso` 子进程，故该可执行文件须在 PATH 中。其三，初始化选项（initialization options）含 `root_tex`、`texpresso_path`、`inverse_search`，经 `onInitialize` 用 `??`（空值合并）与默认值逐字段合并，写入 `connection.init_options` 并启动子进程，省略即回落默认值。
