本讲围绕 pipeline.py 中 main() 的 argparse 定义展开三个模块：参数组结构、默认值解读、SUPPRESS 条件默认值技巧。参数分为顶层输入（位置参数 workspace、--pdfs、--model）与 Server、VLLM、Beaker 三个参数组，对应本地 GPU、外部 API、本地多卡、集群提交四种运行形态。核心结论：默认值（workers=20、max_concurrent_requests=1600、pages_per_group 动态 500）面向自有 GPU 批量场景，走外部计费 API 时应显式调小并发闸门与页组大小；README 的 --help 快照已过时，查参数以 argparse 源码为准。关键机制：parse_known_args 把未识别参数（unknown_args）在启动内部 vLLM 时原样转发给 vllm serve；argparse.SUPPRESS 使未设置的参数不在命名空间中，hasattr 探测后按 --api_key 有无为 pages_per_group 赋 50 或 500 的条件默认值；--stats 与 --beaker 是提前返回的短路开关。
