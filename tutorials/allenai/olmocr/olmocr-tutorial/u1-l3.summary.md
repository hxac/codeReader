本讲首次运行 olmocr，用「工作区 + --markdown + --pdfs」把 PDF 转成 Markdown，涉及 pipeline.py、work_queue.py 与 pyproject.toml 三个文件。关键术语：workspace（工作区）是全部状态的唯一载体，五大产物为队列索引（zstd 压缩 CSV，每行含组哈希与路径）、done_flags 完成标记、worker_locks 并发锁、results（Dolma JSONL）与 markdown 输出，由此支持断点续跑与多机协同。核心结论：workspace 骨架与队列填充发生在 GPU 检查之前，--stats 在此短路返回，故无 GPU 的轻量环境也能建立并观察队列；组哈希是对组内路径排序后的 sha1，跨机确定一致；done flag 仅在整组完成落盘后写入，重跑以整文件覆盖保证最终一致。olmocr 命令经 pyproject 的 [project.scripts] 注册到 cli_main()，再由 asyncio.run() 桥接异步 main()。
