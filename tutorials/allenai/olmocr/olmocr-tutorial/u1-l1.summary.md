本讲通过精读 README 与 CHANGELOG 分三个模块：功能定位、评测表解读、版本演进。核心结论：olmOCR 是 AI2 开源的文档转换工具箱，底座为微调自 Qwen2.5-VL 的 7B 视觉语言模型（VLM），把 PDF/PNG/JPEG 转成 Markdown 与 Dolma（面向预训练的 JSON 文档格式）两种输出，凭版面语义理解（去页眉页脚、还原阅读顺序等）区别于传统 OCR。项目自带评测基准 olmOCR-Bench（1400 份文档、7000+ 条单元测试式断言）；v0.4.0 总分 82.4±1.1 居第一梯队，最强子项是基础转写 99.7，最弱是老扫描件 47.7，后者为全行业共同短板。演进分三代：v0.1 跑通并迁移到 vLLM，v0.2/v0.3 工程化迭代，v0.4 的 olmOCR-2 引入合成数据与 GRPO 强化学习。关键术语：OCR、VLM、Dolma、Markdown、olmOCR-Bench、置信区间、SFT 与 GRPO。
