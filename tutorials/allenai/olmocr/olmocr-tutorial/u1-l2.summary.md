本讲介绍 olmOCR 的环境搭建，覆盖 pyproject.toml 依赖体系、check.py 自检脚本与 conda 干净环境实践三个模块。核心结论：安装分两层——系统依赖（poppler-utils 及字体包，须用 apt/brew 装入系统；pdftoppm 把 PDF 页渲染成图片，模型识别的正是这张图片而非 PDF 本身）与 Python 依赖（pip 安装）。pip install olmocr 是轻量安装，不含 torch 等深度学习框架；本地 GPU、Beaker、评测等形态经 pip extras 按需追加，gpu 组精确钉死 transformers/vllm 版本，故须干净 conda 环境（Python≥3.11）。olmocr 命令由 scripts 入口注册，指向 olmocr.pipeline 的 cli_main。check.py 用 subprocess 探测 pdftoppm、用 find_spec 探测 sglang（历史遗留，推理引擎已改用 vLLM），以退出码报告成败；GPU 显存检查函数未被主流程调用。关键术语：系统依赖与 Python 依赖之分、poppler/pdftoppm、pip extras、conda 环境、退出码、find_spec。
