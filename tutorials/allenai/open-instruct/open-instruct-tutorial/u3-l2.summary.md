本讲覆盖统计、变换、缓存与本轮更新四部分。统计分两层：get_statistics.py 对原始 messages 分角色统计长度分布；count_tokens 用 Arrow 算子统计变换后数据的总 token 与可训练 token（label≠-100）。变换由 TRANSFORM_FNS 注册表驱动，get_dataset_v1 按函数名依次执行 map/filter，产出 input_ids、labels、attention_mask。缓存分两级：tokenized 数据集缓存（HF 仓库或本地目录）以 compute_config_hash 为键；numpy 预编码缓存再转成 OLMo-core 可 mmap 读取的 token_ids、labels_mask 与文档边界文件。本轮更新（#2300）在 tulu 分词路径渲染前用 _normalize_tool_call_arguments 把 JSON 字符串的工具调用参数解码成映射（null 视为 {}，解码失败或非 UTF-8 原样保留），added-token 过滤同步读解码后文本；因配置哈希感知不到代码变化，DATASET_CACHE_VERSION 升至 v10 强制旧缓存失效。
