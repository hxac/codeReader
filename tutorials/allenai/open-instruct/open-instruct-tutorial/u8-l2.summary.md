本讲剖析 MILES 配置系统：TOML run 文件由 RunSpec 加载并「加载即编译」，经 compile() 带来源追踪与冲突检测翻译成引擎层的 CoreConfig+RunConfig，全程 CPU-only，可先用 plan/validate 与 --set 排查；错误按无效配置/未实现/未验证三分类在训练前拦截。核心约束：[data] 五种数据选择器互斥；over_length 只取 fail/exclude；priority 提示提供者需配套 priority 字段并要求全局数据集；num_epoch 与 num_rollouts 互斥，epoch 预算默认只在最终更新落盘检查点；池采样 priority 与 prompt replay 互斥。本轮新增 score-centering 参数族的 CPU 预检（强制 fp32_lm_head、GRPO 优势估计器、TIS/MIS 参数与旧开关互斥）、判分输入声明字段 reward_final_answer_only 与 reward_reasoning_mode（required/none）、评估采样默认对齐（温度 1.0、top-p 0.95、响应上限 32768），维护示例按模型家族重组为 tiny/ 与 small/。
