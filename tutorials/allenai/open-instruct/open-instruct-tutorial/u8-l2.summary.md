本讲剖析 MILES 配置系统：TOML run 文件由 RunSpec「加载即编译」，compile() 把研究者视角的结构化节翻译成引擎选项，产出 RunConfig（CoreConfig + miles 选项）并整体校验，全程 CPU-only，可用 plan/validate 子命令与 --set 覆盖在预约 GPU 前排错；put() 是唯一写入口，带 origins 来源追踪与冲突检测；错误按 Invalid configuration / Not implemented / Not validated 三分类在训练前拦截。本轮更新三组语义：priority 提示提供者要求 provider=priority、必填 prompt_priority_field 三件套、rollout_global_dataset=true，且不与 selection/replay 组合；data.over_length 仅取 fail（默认）/exclude（排除只作用训练侧，held-out 仍严格失败）；num_epoch 与 num_rollouts 互斥，epoch 预算透传原生运行时换算，默认以 save_final_checkpoint=true 保存最终更新，wandb_group 缺省跟随 wandb_run_name 或 run 名。
