本讲剖析 MILES 配置系统：TOML run 文件由 RunSpec 加载并立即编译为 CoreConfig+RunConfig，全程 CPU 可校验；origins 追踪每个设置的来源并检测冲突，错误按非法配置、未实现、未验证三分类在训练前拦截。约束要点：数据选择器五选一；over_length 限 fail/exclude；epoch 与 rollout 预算互斥，epoch 默认仅存最终检查点；priority 提示提供者有联合约束；score-centering 带 CPU 预检；判分输入由 reward_final_answer_only 与 reward_reasoning_mode 声明；评估采样默认温度 1.0、top-p 0.95；SciCode 占位路径在 plan 期仅入 launch_warnings。示例基线：维护示例统一 token-mean 损失（省略时库默认仍为 response-mean），Tiny 学习基线 batch 2048、恒定 LR 6e-6；四个学习模板固化有界恢复保存——每 10 更新滚动留 2 份、50/100 更新永久里程碑加最终存档，配 auto_resume 自动恢复。
