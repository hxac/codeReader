本讲覆盖 MILES 配置包（run_spec、config、validation、constraints、score_centering、options）的最小模块集。核心结构是两层配置：研究者书写结构化 TOML run 文件（RunSpec 承载），引擎消费 CoreConfig 与 RunConfig，compile() 是带 origins 来源追踪与冲突检测的翻译器；「加载即编译」，全程 CPU-only，可用 plan/validate 子命令在预约 GPU 前排错。关键概念：InputError 与错误三分类（Invalid configuration／Not implemented／Not validated）、put() 唯一写入口、未知字段的 did-you-mean 提示。核心约束与语义：[data] 五种选择器互斥；over_length 只取 fail/exclude；priority 提供者三件套要求 provider=priority、prompt_priority_field 与 rollout_global_dataset，且禁与 replay 组合；num_epoch 与 num_rollouts 互斥，epoch 预算默认 save_final_checkpoint；池采样 data.sampling.priority 与 replay 互斥；判分输入由 reward_final_answer_only 与 reward_reasoning_mode（required/none）声明；score-centering 参数族（score_centering_is=tis/mis、强制 fp32_lm_head）经 score_centering.py CPU 预检；评估采样默认温度 1.0、top-p 0.95、响应上限 32768；SciCode 占位参考路径在 plan 期仅进 launch_warnings 警告并自动注入默认秘密，硬拒绝留给启动边界。判分数学、秘密链路与 priority 运行时语义分别由 u8-l12、u8-l9、u8-l5/l11、u8-l14 承接。
