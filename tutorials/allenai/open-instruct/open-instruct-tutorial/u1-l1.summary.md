本讲为 open-instruct 全景导论：它是 Allen AI 维护的开放后训练研究代码库，用公开数据集把基座模型训练成可用助手，主流水线为 Base → SFT（监督微调）→ DPO（偏好优化）→ RLVR（可验证奖励强化学习，主要用 GRPO 算法），支线是奖励模型（RM）训练，为 DPO 供给偏好数据。Tülu 1 至 3.1 与 OLMo 2、Olmo 3 系列模型均为这套配方的产物，每个阶段都发布可下载的中间模型。训练入口：SFT 用 finetune.py 与 olmo_core_finetune.py（OLMo-core 路线），DPO 用 dpo.py，RLVR 用 grpo.py、grpo_fast.py 或 python -m open_instruct.miles（MILES，面向 Olmo MoE 模型）。源码集中在 open_instruct/ 目录，scripts/ 放启动脚本。核心结论：这是不保证向后兼容的研究代码库，多套技术路线并存是常态，当前主推以 README 的 Training 一节为准。
