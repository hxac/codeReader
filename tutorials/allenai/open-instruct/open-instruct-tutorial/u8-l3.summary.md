本讲覆盖 MILES 执行层：workflow.execute 把一次 run 分为准备/训练/收尾三阶段，以规格指纹（规格排序 JSON 的 SHA-256）与 run 目录锁支撑中断恢复，仅运维字段（重试、缓存、存档节奏）允许改动；driver.train 是单次尝试的协调循环，启动期先做 validate_registry 注册表预检（为验证器计算 GradingPolicy，拒绝未声明输入契约的外部验证器），主循环为 rollout 收集→优化器更新→权重发布→存档边界；池耗尽、不可恢复的时间停、跑满预算均视为完成。epoch 预算与 num_rollout 互斥，rollout 总数由原生运行时在数据加载后解析，经 driver 返回的 num_rollout 驱动 workflow 完成判定，save_final_checkpoint 负责最终存档。本轮新增 SciCode 资产预检 validate_scicode_reference_path：占位参考路径在 plan 期进 launch_warnings 软警告，在 launch、workflow、evaluation 三道启动边界被硬拒绝。cluster.Supervisor 以统一启动预算、心跳与 judge 探针监管多副本启动，仅 head 运行 workflow。
