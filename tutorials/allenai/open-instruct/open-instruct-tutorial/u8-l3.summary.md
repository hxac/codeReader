本讲覆盖 MILES 执行层四模块：workflow 三阶段编排与指纹恢复、driver 协调循环、epoch 预算完成判定、集群 Supervisor 监管。workflow.execute 把 run 分为准备/训练/收尾，以规格排序 JSON 的 SHA-256 为指纹守卫 run 目录；resume 只允许改运维字段，模型/数据/训练视野必须一致，模型与数据产物凭身份清单复用、训练从最新 checkpoint 续训。driver.train 循环执行 rollout 收集、优化器更新、权重发布与存档边界；池耗尽、不可恢复时间停、跑满预算均算完成。本轮更新引入 epoch 预算：num_epoch 与 num_rollout 互斥、不再补默认值，rollout 总数由原生运行时数据加载后解析，经 driver 返回值判完成；save_final_checkpoint 在最后一个 rollout 落盘最终存档。Supervisor 以统一启动预算、心跳、judge 探针与失败文件传播监管各 Beaker 副本启动，任一副本失联即全体有序失败。
