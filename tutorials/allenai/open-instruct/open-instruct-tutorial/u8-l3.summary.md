本讲承接 run 文件的编译链，覆盖 MILES 执行层的三个模块。workflow 把一次 run 分为准备、训练、收尾三阶段，以指纹（规格的排序哈希）守卫恢复：仅重试、缓存、存档节奏等运维字段允许改动，模型、数据与训练视野必须一致。driver.train 是单次训练尝试的协调循环：本轮新增 validate_registry 启动预检，在分配任何 worker 前解析可信判分注册表、为每个验证器计算 GradingPolicy，拒绝未声明输入契约的外部验证器与不兼容的 reasoning 约定；主循环依次做采样收集、优化器更新、权重发布与存档。epoch 预算（与 num_rollouts 互斥）的 rollout 总数由原生运行时在数据加载后解析，经 driver 返回值参与完成判定，最终存档由 save_final_checkpoint 落盘。Supervisor 以统一启动预算、心跳与 judge 健康探针在 Beaker 副本内实现受监管启动。池耗尽、不可恢复时间停与跑满预算判为 complete，debug 退出与可恢复时间停仅算 stopped。
