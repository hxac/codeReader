本讲承接 u6-l3 的 verifier 注册表，讲代码类可验证奖励：CodeVerifier（注册表 "code" 项）从模型输出抽取 Python 代码，经 HTTP 交给判分服务，按测试通过率打分，可设通过阈值整流并按耗时打折。判分沙箱靠 should_execute 黑名单、每测试独立子进程加超时击杀、reliability_guard 屏蔽危险函数三层防护，但源码自明它并非安全沙箱，真正隔离靠部署边界。测试分 assert 式（每测试一进程、断言不抛异常即过）与 stdio 式（grade_stdio 单进程串行、mock stdin 捕获 stdout，先字符串后 Decimal 数值比对，错误码供诊断）。generic_sandbox 则是面向多轮工具调用 RL 的 Docker 环境，用 _BASH_WRAPPER 持久化工作目录与环境变量，奖励来自每步退出码。本轮更新把外部私有 code_execution_client 移入库内 execution_client 包：客户端只编码校验、绝不执行代码，以 ServiceError 与 ClientError 二分保证服务故障不被当成测试失败；complete_code 改为直接导入，测试 mock 简化为给 execution_verifier 打属性补丁。
