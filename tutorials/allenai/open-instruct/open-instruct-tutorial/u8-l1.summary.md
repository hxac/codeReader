本讲为 MILES 单元总览。MILES 与 grpo.py（Core/vLLM）、grpo_fast.py（DeepSpeed/vLLM）并列为三条 RL 训练路线，面向受支持的 Olmo MoE 模型，不弃用旧训练器。唯一入口是 python -m open_instruct.miles，提供 plan/validate/train/run/status 五个子命令与 records 记录分析；运行时延迟导入，plan/validate 无需 GPU 即可运行。架构分三层所有权：open-instruct 包装层负责配置校验、数据、奖励与 Beaker 提交；按 runtime.lock.json 锁定的私有 MILES 运行时负责 rollout 编排与共享 RL 机制；Core 适配器经 OLMo-core 训练、SGLang 服务。配置双轨：结构化 TOML（schema_version=1）编译为 RunSpec，run/status 仅接受结构化文件，低层 RunConfig 只支持 plan/validate/train。维护示例按模型家族组织：tiny 为力学/学习示例，small 为 OLMo 3.5 Small（A4B MoE）B300 三档实测配方；全部示例损失基线翻转为 token-mean（calculate_per_token_loss=true，库默认仍为 response-mean），Tiny 学习基线为 256×8、batch 2048、恒定 LR 6e-6。文档地图新增 grading.md（ResponseParts 共享判分契约）、abstention.md 与 olmo35-small.md。后续讲义将展开配置编译链、工作流执行、奖励体系与 Small B300 配方审计。
