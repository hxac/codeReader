本讲讲解 open-instruct 工具调用 RL 的三个模块。一是环境抽象：Tool（无状态工具）、RLEnvironment（函数调用驱动的有状态环境）、TextRLEnvironment（直接消费模型原始文本）三个基类，EnvCall/StepResult/RolloutState 数据结构，EnvironmentPool 以 acquire/release 保证并发 rollout 独享实例；一次 rollout 即「生成→解析→执行→观察写回」的循环，直至 done 或 max_steps。二是解析器与 MCP 集成：解析器做双向翻译（get_tool_calls 提取调用、format_tool_outputs 按角色模板包装观察），GenericMCPTool 可把整个 MCP 服务器展开为工具集。三是 ToolRL 离线打分：不执行工具，只比对模型调用与参考调用，语义分为调用名多重集 Jaccard 重叠加参数贪心匹配，归一化到 [-3,3]，加格式分后总分落在 [-3,4]，坏参考目标抛异常而非惩罚模型。每步环境奖励与验证器奖励在 RewardConfig.build 合并，经 Last/SumRewardAggregator 聚合成标量进入 GRPO 优势计算。本轮更新（PR #2250）为 score_response 新增可选 action 参数，供 MILES 判分共享选定动作文本，默认路径行为不变。
