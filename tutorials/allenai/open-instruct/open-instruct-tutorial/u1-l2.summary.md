本讲搭建 open-instruct 开发环境，覆盖三个模块：uv 依赖管理、Dockerfile 镜像构建、Makefile 质量工具链。核心结论：Python 钉死 3.12，pyproject.toml 用依赖分组隔离 dev 工具与互斥的 cuda12/cuda13 两套 CUDA 栈，默认装 dev+cuda12，CUDA 13 需显式指定组；tool.uv.sources 按组切换 torch/vllm 的 wheel 索引，平台 marker 把 vllm 等排除出 macOS；requirements.txt 由 uv.lock 自动导出，不可手改。Dockerfile 以 ARG CUDA_VERSION 多阶段构建出双 CUDA 镜像，镜像内用 --frozen 复用同一份声明，依赖层与代码层分离以保缓存。日常三命令：uv run pytest（conftest 自动跳过缺 vllm/GPU 的用例）、make style（ruff format）、make quality（nonlocal 关键字检查+ruff+compileall+ty）。文档可能滞后，冲突时以 pyproject.toml、uv.lock、Dockerfile 为准。
