本讲介绍 OLMo-core 推荐的新一代数据 API（data/composable/），以三层可组合抽象取代「一类一变体」的 NumpyDataset：TokenSource（一维 token 数组，契约含 fingerprint/children）→ InstanceSource（定长训练样本）→ ComposableDataLoader（注册名 composable）。DocumentSource 额外提供文档边界；实例生成器分 ConcatAndChunk（无视边界切块、零 padding）与 Packing（OBFD 整文档装箱、pad 处 label_mask=False）。组合子 +、*、sample、split 与 MixingTokenSource 支撑切片、上采样与按比例混合；calculate_sample_sizes 以归一化、重复上限与整体收缩因子决定各源实际采样量，核心结论是切分必须先于混合，否则串行布局破坏比例。DataLoader 负责 reshuffle 落盘全局索引、按 DP rank 不重不漏切批、指纹校验断点续训；ShuffleStrategy 与 sources_per_epoch 声明课程学习；visualize() 打印源树是首要调试工具。
