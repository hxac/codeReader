本讲是分布式训练单元的收官，覆盖四个最小模块：一是 `init_distributed()` 加固封装——NCCL 环境加固、无 torchrun 时的单进程兜底、set_device 先于建进程组的时机契约、backend 一致性检查与 validate_env_vars 校验；二是 rank 三层体系（全局 rank、local rank、fs local rank）与 world size、local world size、num_nodes 查询函数，区分进程组与环境变量两种来源；三是分布式透明的通信封装（all_gather、broadcast_object、all_reduce_value、do_n_at_a_time）及 autograd 兼容的 all-to-all 原语，单进程下自动退化、业务代码零分支；四是 run_distributed_test 在 pytest 内拉起真实多进程（默认双进程 gloo，CPU 可跑），配 BACKENDS 参数化。核心结论：全库追求 API 统一的单进程可退化设计，铁律是集合通信必须全体 rank 参与。
