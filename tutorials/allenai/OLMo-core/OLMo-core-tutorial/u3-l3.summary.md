本讲聚焦 olmo_core 的 nn/attention 模块（base、attention、backend、ring、kv_cache 等）。核心结论：Transformer block 的 attention 属性是 SequenceMixer 可插拔插槽，仅约定 TP/CP 接入、FLOPs 估算与权重初始化；Attention 是其标准多头自注意力实现，前向依次为 QKV 投影、QK norm、RoPE、SDPA、门控、输出投影，其中仅 SDPA 一步委托给可替换的 AttentionBackend。六种后端（torch、flex、flash_2/3/4、te）经 AttentionConfig.backend 枚举字段切换，用构造期能力断言声明各自边界，选择顺序为显式指定＞旧 use_flash＞SWA 自动选 flash_2＞默认 torch，无 GPU 时回落 torch。引入的关键术语：序列混合器插槽、GQA/MQA、滑动窗口注意力、KV cache、varlen（cu_doc_lens）、or/and 掩码、上下文并行（Ring/Ulysses 风格与 zig-zag/llama3 负载均衡），供后续核心组件与并行讲义承接。
