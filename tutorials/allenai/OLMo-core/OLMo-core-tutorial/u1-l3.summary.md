本讲绘制 OLMo-core 的源码心智地图。src/ 下五大区域各司其职：olmo_core/ 是库本体，test/ 为镜像其结构的单元测试，scripts/ 是官方训练脚本，examples/ 是教学示例，integration_tests/ 做端到端集成测试。库根 __init__.py 极轻、仅做环境准备，全库「按子包导入」，各子包 __init__.py 即门面（docstring、再导出、__all__、门面函数），训练遵循「准备环境→组装组件→fit()→清理」的生命周期骨架。定位口诀：模型→nn/、数据→data/、训练→train/、分布式→distributed/、优化→optim/；几乎每个子包都有自己的 config.py，体现「一切皆 Config」。测试按「目录镜像 + foo.py 改名 foo_test.py」组织，GPU 测试靠标记与 importorskip、pytest.skip 三层机制跳过。TransformerConfig、TrainerConfig、NumpyDatasetConfig 三大谱系均汇聚于 Config 基类；muP、CompletedP 等跨子包功能成对分布于模型侧与优化侧。
