本讲义建立 OLMo-core 源码心智地图。src/ 分五大区域：olmo_core/（库本体）、test/（单元测试）、scripts/（训练脚本）、examples/（教学示例）、integration_tests/（端到端测试）。根 __init__.py 不导出功能类、只做环境准备，故本库「按子包导入」；子包 __init__.py 是门面（docstring＋再导出＋__all__），训练骨架为「准备环境→组装组件→fit()→清理环境」。定位口诀：模型→nn/、数据→data/、训练→train/、分布式→distributed/；几乎每个子包都有自己的 config.py，「一切皆 Config」——TransformerConfig（经 ModuleConfig/ModelConfig）、TrainerConfig、NumpyDatasetConfig 谱系均汇聚于 Config 基类。测试布局遵循「目录镜像＋foo.py→foo_test.py 后缀改名」，约定 test_* 命名与 parametrize 优先，GPU 测试靠 gpu 标记＋pytest.skip＋importorskip 三层机制自动跳过。
