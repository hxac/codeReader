本讲主讲 `nn/transformer/config.py`：`TransformerConfig` 是描述模型全部形状的「图纸」，五个必填字段 `d_model`、`vocab_size`、`n_layers`、`block`、`lm_head` 定骨架，构造时即校验非法组合。`block` 有三种组织方式——单 block、命名 block 配 `block_pattern` 循环、`block_overrides` 逐层覆盖，由 `resolved_block_configs` 统一为每层一份配置；`build()` 按实现类型分发构建模型，支持 meta 设备占位与通配冻结参数；`num_params` 无需实例化即可精确预算参数量。预置工厂方法构成三层金字塔：规模档位（olmo2/olmo3 系列）委托架构预设（llama2 等）再委托家族装配（`llama_like`），配合 kwargs 覆盖，一行调用既选档位又改任意深层参数；olmo3 预设即 olmo2 加滑窗注意力模式与 flash_2 后端。关键术语：GQA（`n_kv_heads` 小于 `n_heads`）、`reordered_norm` 布局、RoPE theta、FFN 宽度推导公式，以及新增的可选 CompletedP 参数化字段 `completedp`（默认 None 不启用，机制留待后续讲义展开）。
