本讲核心是 Registrable 注册机制与多态配置字段，承接上讲的 Config 基类。Registrable 是外部包 dataclass-extensions 提供的 mixin，通过「@基类.register("名字")」装饰器把子类登记进基类名下的「名字→类」注册表（子类自身注册表为空）。序列化时 as_config_dict() 为每个多态节点写双线索：_CLASS_（完整类路径，精确门牌号）与 type（注册名，花名）；反序列化时 _CLASS_ 优先、解析成功即删除 type，手写 YAML 仅凭 type 由 decode 查基类注册表选定子类。多态字段即类型标注为基类的字段（如 optim: OptimConfig、sequence_mixer: SequenceMixerConfig），优化器、调度器、注意力后端、数据加载器四族均采用此模式，换实现只需换子类或 YAML 里的 type 字符串，build() 是统一构建出口；MuP/CompletedP 等缩放规则则选择组合字段而非注册子类。这为下讲 dotlist 命令行覆盖多态字段奠定基础。
