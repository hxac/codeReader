本讲围绕 config.py 与 optim 等模块讲解 Registrable 注册机制与多态配置字段。核心结论：Registrable 是外部包 dataclass-extensions 提供的 mixin，由 config.py 再导出；`@基类.register("名字")` 把子类登记进挂在基类名下的注册表（子类自身的注册表可能为空）。序列化时 as_config_dict() 为多态节点同时写 `_CLASS_`（完整类路径）与 `type`（注册名）双线索；from_dict 优先按 `_CLASS_` 动态 import 并删除 `type` 键，手写 YAML 仅含 `type` 时由 decode 查基类注册表选出子类。关键术语：注册表、mixin、多态字段（类型标注为基类，如 optim: OptimConfig、sequence_mixer 字段）。优化器、调度器、注意力后端、数据加载器四族共享此模式，build() 是统一构建出口；接入自定义实现只需注册装饰器、超参字段与 optimizer()/build() 实现三件套，无需改库源码。
