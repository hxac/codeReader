本讲确立 OLMo-core 的定位：它是 AI2 维护的 OLMo 系列模型训练库（PyPI 包名 ai2-olmo-core），提供建模与训练的可组合「积木」；OLMo 模型权重是它的产物，发布在 Hugging Face Hub，推理用 HF/vLLM，评测用 OLMo Eval/olmes，库本身站在生态生产侧。核心结论有三：一是库提供四类能力——组件库、官方训练脚本（torchrun 启动、--dry-run 预览配置、点号路径覆盖参数）、Docker/Beaker 镜像（含依赖不含源码）、推理与 HF 权重互转；二是仓库分四大区域——src/olmo_core（库本体）、src/test（镜像源码结构）、src/scripts、src/examples；三是核心仅依赖 PyTorch，flash-attn、grouped_gemm、torchao 等可选依赖经 try/except ImportError 按需挂载，解锁注意力后端、MoE、float8 等功能。末尾埋下伏笔：「一切皆 Config」设计（第 2 单元主题）与 190M 训练组件猜想（第 4 讲验证）。
