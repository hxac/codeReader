本讲确立 OLMo-core 的定位：它是 AI2 维护的 OLMo 系列模型训练库（PyPI 名 ai2-olmo-core），提供建模与训练的可组合「积木」组件；模型权重发布在 Hugging Face Hub，二者是「工厂与产品」关系，HF/vLLM 与评测工具属消费侧。讲义分三个模块：生态位、四类能力、仓库结构与可选依赖。四类能力指可组合组件库（src/olmo_core）、官方训练脚本（--dry-run 可零成本查看完整配置，支持点号路径命令行覆盖）、Docker/Beaker 镜像与启动器、推理与生态集成（chat、HF 互转）。仓库分四大区域：库源码、测试、脚本、示例；核心仅依赖 PyTorch，flash-attn、grouped_gemm、torchao 等可选依赖经 try/except ImportError 按需挂载。核心结论是「核心轻量、功能按需安装」；点号路径覆盖预示贯穿全库的「一切皆 Config」设计（第 2 单元主题），训练 190M 模型所需组件的猜想留待第 4 讲验证。
