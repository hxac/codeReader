本讲为系列开篇，勾勒 OLMo-core 全景。定位上，OLMo-core 是 AI2 的 OLMo 模型训练库（PyPI 包名 ai2-olmo-core），不是模型本身——模型权重发布在 Hugging Face Hub，二者是「工厂与产品」关系；纯推理只需 transformers/vLLM。它提供四类能力：可组合组件库、官方训练脚本（torchrun 启动，--dry-run 可零成本查看完整配置）、Docker/Beaker 镜像、推理与生态集成（beta chat、HF 权重互转）。仓库分四大区域：src/olmo_core（库本体）、src/test（镜像结构的测试）、src/scripts、src/examples。核心仅依赖 PyTorch，flash-attn、grouped_gemm、torchao 等可选依赖经 try/except ImportError 加 has_*() 探测函数按需挂载，解锁注意力后端、MoE、float8 等功能。命令行点号路径覆盖预示贯穿全库的「一切皆 Config」设计。本讲实践要求猜想训练 190M 模型（TransformerConfig.olmo2_190M）所需的最少组件，留待第 4 讲验证。
