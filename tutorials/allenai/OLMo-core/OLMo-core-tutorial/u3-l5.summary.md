本讲拆解 Olmo-core 的 MoE 层：路由器按 top-k 为每个 token 选路，N 个专家 MLP 与可选共享专家顶替 block 中的稠密前馈位，实现总参数大而每个 token 仅激活 K 个专家的稀疏结构。专家计算走 permute—分组计算—unpermute 三段式：容量型实现丢弃超出容量的 token，Dropless 型按需分组、不丢 token。负载均衡损失的读数含义为 1 即完美均衡、趋近 N/K 即路由坍缩；Z 损失压制路由 logits 量级；辅助损失经自定义 autograd 函数挂进计算图反传，权重默认按层数缩放；bias_gamma 提供无辅助损失的偏置均衡路线。MoE 完整前向依赖编译好的 CUDA 内核，router 与损失可在 CPU 单独实验。
