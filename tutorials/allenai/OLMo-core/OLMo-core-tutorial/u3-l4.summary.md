本讲拆解 Transformer 的四大积木。门控前馈 FeedForward 公式为 w2(act(w1x)⊙w3x)，SwiGLU 与 GeGLU 仅靠 activation 字段切换，参数量约 3dh、hidden 常取 8/3·d_model；归一化家族以 RMSNorm 为主力，weight_shape 与统计范围解耦以支持 QK-norm 每头增益，output_scale 把常数乘子折进增益、由 CompletedP 残差缩放消费；RoPE 由逆频率表生成 sin/cos 并按配置命名空间缓存，ABF/PI/Stepwise/YaRN 四种 scaling 通过改写频率表实现上下文扩展；LMHead 打包最终归一化、logits 裁剪、交叉熵/z-loss 与 fused_linear 免物化 logits 的 loss 实现，tie_word_embeddings 直接共享张量、省 d_model×vocab 参数且要求无 bias；SplitVocabEmbedding 拆「基础+扩展」词表服务多模态。核心结论：这些组件族均采用「name 枚举 + build() 分发」的多态模式而非 Registrable 注册表，自定义变体的零改库入口是子类化 Config 并覆写 build()。
