本讲在单卡视角拆解两个模块：顶层 Transformer 与 TransformerBlock。前向主链路：input_ids 经 embedding 查表变为 (B,S,d_model)，过 N 个 block 形状不变，末端由 lm_head 投影为 (B,S,V) 的 logits；带 labels 时返回含交叉熵损失的 LMOutputWithLoss。核心结论：形状只在两端变化，中间是 d_model 等宽的残差流；顶层只做编排，blocks 逐层独立 build、不共享参数；embeddings 与 lm_head 可为 None，为流水线并行预留直通；apply_* 方法在 build 后原地改造模型。每个子层为 norm＋子层＋ResidualStream；OLMo 2 默认 block 为 reordered_norm（norm 在子层输出侧）而非 pre-norm；self.attention 实为可插拔的 sequence_mixer 插槽。注意力内部、MoE、初始化与并行机制留待后续讲义。
