本讲在单卡视角讲解 OLMo-core 前向主链路的两个模块。顶层 Transformer 只做编排：embedding 查表、N 个 block 顺序前向、lm_head 投影出 logits 并计算交叉熵（返回 LMOutputWithLoss），另有 NormalizedTransformer、MoETransformer 等变体直接继承它；形状只在前向两端变化，中间是 d_model 等宽的残差流。TransformerBlock 约定「同形进同形出」，每层含注意力与前馈两个子层，各配 norm 与 ResidualStream——残差相加被独立成无参模块，支持 alpha 缩放，为回调观测与 CompletedP 参数化预留挂载点。核心结论：OLMo 2 默认采用 reordered_norm 摆法（norm 在子层输出、残差相加之前），而非 pre-norm；block 的 attention 字段实为可插拔 sequence_mixer 插槽；blocks 逐层独立实例化、互不共享参数；embeddings 与 lm_head 可为 None 系流水线并行的直通设计；apply_* 方法群在 build 之后由训练模块原地改造模型以接入各类并行。
