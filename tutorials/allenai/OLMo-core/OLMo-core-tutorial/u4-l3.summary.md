本讲覆盖 OLMo-core 数据混合的三条路线。官方 .txt 配方（DataMix 枚举）每行 label,path，含 {TOKENIZER} 占位符适配分词器，比例靠路径重复隐式表达上采样；SourceMixture 三件套（Config/List/DatasetConfig）把配方（target_ratio 之和必须为 1）与实验参数（requested_tokens、global_batch_size）分离，build() 按文件字节数统计 token，以 Hamilton 最大余数法把实例配额分摊到各文件，产出「每文件取多少 token」清单，源可用上限为 max_source_fraction 与 max_repetition_ratio 之积，容量不足直接报错；composable 路线的 MixingInstanceSource 借 calculate_sample_sizes 自动归一化比例，并以整体收缩因子实现「比例守恒的最少丢弃」分配，由 SamplingInstanceSource 执行采样与索引落盘。验证占比可用构建日志、visualize() 源树或统计 batch 内 token 频次。
