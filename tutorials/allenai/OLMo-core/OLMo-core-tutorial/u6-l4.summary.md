本讲拆解 OLMo-core 的 checkpoint 体系四个模块。Checkpointer 定义训练快照的磁盘布局：每 rank 一份训练状态（TrainerStateDict）、DCP 写出的模型与优化器分片、rank0 最后写入的 .metadata.json 有效性标记，并以「临时目录＋原子替换」保证快照要么完整、要么不存在。CheckpointerCallback 是保存决策者：save_interval、fixed_steps 与 max_checkpoints 管理永久 checkpoint，ephemeral checkpoint 为可抢占作业提供密集恢复点，删除时先摘元数据再清目录。底层分布式 checkpoint 模块封装 PyTorch DCP，凭记录全局张量视图的元数据实现跨 world size 的重分片（resharding），并可直写 S3/GCS 对象存储。断点续训由 LoadStrategy（if_available/always/never）控制：命中 save_folder 是续训语义，强制恢复 trainer 与优化器状态；命中 load_path 是初始化语义，默认不恢复 trainer 状态；RNG 仅在 world size 一致时恢复，max_steps 存而不取，训练总长由本次运行配置决定。
