本讲义在数据并行（u7-l1）之外补齐四个并行维度。张量并行（TP）切权重矩阵：注意力按头、FFN 按中间维、embedding/LM head 按词表维切，每层 all-reduce、宜同机 NVLink 域；TP 下交叉熵损失必须局部求和、再除以全局有效 token 数，且输出布局标 Partial 才会触发归约——提交 075a7892d 修复了误标 Replicate 导致静默跳过 all-reduce 的 bug。流水线并行（PP）按层把模型切成 stage、以 P2P 传激活，实际接线的是两个 custom 1F1B 调度，不支持 tied embeddings。上下文并行（CP）切序列，分 ring（zig-zag/llama3 负载均衡）与 Ulysses（all-to-all 换分片维度）两条路线。专家并行（EP）按「个」切 MoE 专家，与 TP 互斥、仅配 HSDP 且度数须等于分片度（复用 dp_shard 网格维）。组合中枢 build_world_mesh 的维度顺序固定为 pp→dp→ep→cp→tp，度数从 world size 逐级扣除；parallelize_model 按 PP 最先、DP 最后、init_weights 收尾的固定顺序应用。关键术语：DeviceMesh、DTensor 布局（Shard/Replicate/Partial）、微批次、气泡、序列并行、stage。官方参考：OLMo-2 32B 纯 HSDP 即够；OLMo-3 7B 长上下文用 HSDP＋CP（llama3）。
