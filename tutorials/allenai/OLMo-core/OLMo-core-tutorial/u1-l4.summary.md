本讲以自包含示例 examples/llm/train.py 为例跑通首个训练实验：一次实验即一份顶层 ExperimentConfig，打包五个 Config 积木——model、dataset、data_loader、train_module（含优化器与 FSDP 并行设置）、trainer（含回调）。核心是 build() 模式：Config 是图纸，组件按 model→train_module→dataset→data_loader→trainer 的依赖顺序构造，模型先在 meta 设备占位再由并行策略落位；global_batch_size 与 rank_microbatch_size 均以 token 计，二者比值决定梯度累积步数。脚本由 torchrun 拉起进程，prepare/teardown_training_environment 负责分布式初始化与收尾；命令行剩余参数经 config.merge 以 dotlist 覆盖任意嵌套字段，--dry-run 在环境准备前打印配置即退出，零数据零 GPU。Trainer.fit() 是编排者：恢复 checkpoint、pre_train 钩子、mock batch 预热后进入 epoch 循环，单步依次为 pre_step、train_batch、pre_optim_step、optim_step、zero_grads 与 post 钩子，前向反向和优化器更新全权委托 train_module。
