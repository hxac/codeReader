本讲精读自包含示例 train.py，确立「一次训练实验 = 一份 ExperimentConfig」：由 model、dataset、data_loader、train_module、trainer 五块 Config 积木组成，各组件经 build() 按依赖顺序装配——模型（meta 设备占位）→训练模块（含优化器与 FSDP）→数据集→数据加载器（需数据并行进程组）→训练器。训练由 torchrun 拉起，prepare/teardown_training_environment 统一完成分布式初始化与收尾。Trainer.fit() 只做编排：恢复 checkpoint、pre_train 钩子、mock batch 预热后循环单步（train_batch 前向反向、optim_step 更新、zero_grads 清梯度，回调钩子穿插其间），计算全部委托 train_module。关键术语：rank、FSDP、以 token 计的 global_batch_size 与 rank_microbatch_size、梯度累积、--dry-run 零数据预览与 dotlist 覆盖。
