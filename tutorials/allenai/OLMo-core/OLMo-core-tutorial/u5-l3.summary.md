本讲围绕训练稳定性防线，拆解四个模块：①SkipStepOptimizer 基类用默认 128 步滚动窗口的均值+kσ(默认 6σ)单边判据检测 loss spike 与梯度范数异常，结果 step_factor 是留在设备上的 0/1 张量，乘进更新而非提前 return，避免 host-device 同步并保证各 rank 决策一致；②SkipStepAdamW 把 step_factor 织入权重衰减、双动量、更新量与内部 step 计数，跳步是严格 no-op；③时序契约：裁剪发生在 TrainModule.optim_step() 内、optim.step() 之前，latest_loss(跨 rank 归约，#957 起为 token 加权全局均值)与 latest_grad_norm(裁剪前总范数)必须先于 step() 就位，OLMoDDPOptimizer 则把裁剪、喂信号、跳步全部内化；④grad_debug 仅在总范数非有限时逐参数定位 NaN/Inf 元凶，常态零开销。核心结论：裁剪压小单步梯度，跳步整步放弃可疑更新，有限性断言与 grad_debug 对付硬故障，三者互补构成防线。
