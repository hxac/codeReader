本讲覆盖训练稳定性防线，应对 loss spike(损失尖峰)：SkipStepOptimizer 基类维护 loss 与梯度范数的滚动窗口(默认 128 步)，以均值+kσ(默认 6σ)单边判据检测异常步；判定结果 step_factor 是留在设备上的 0/1 张量，乘进更新公式而非提前 return,避免 host-device 同步并保证各 rank 决策一致。SkipStepAdamW 把 step_factor 织入公式每一项(含内部 step 计数)，跳步是严格 no-op,OLMo 官方配方默认采用。梯度裁剪位于 optim_step() 内、step() 之前：latest_loss 须提前跨 rank 归约，latest_grad_norm 复用裁剪前总范数，两者须先于 step() 就位(时序契约)；OLMoDDPOptimizer 则把裁剪与跳步内化进自身 step()。grad_debug 的 debug_nan_inf_grad_norm 零开销早退、定位 NaN/Inf 梯度元凶。结论：裁剪压小梯度但仍执行，跳步整步放弃，二者互补。
