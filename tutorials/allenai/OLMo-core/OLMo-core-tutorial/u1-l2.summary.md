本讲围绕 OLMo-core 的环境搭建：安装、测试与代码检查。核心结论：PyPI 包名为 ai2-olmo-core，开发安装应先装匹配硬件的 PyTorch，再做可编辑安装 `pip install -e '.[all]'`；核心依赖仅 13 个包，flash-attn 等重功能拆入 extras 可选依赖组，all 为并集。关键概念：pyproject.toml 是依赖与 black/isort/ruff/mypy/pytest 工具配置的唯一事实来源；测试目录 src/test/ 镜像源码结构；GPU 测试采用「@pytest.mark.gpu 标记（仅供 CI 用 -m 筛选）+ 函数体内 CUDA 不可用即 pytest.skip() + importorskip 应对可选扩展缺失」的多层机制实现无 GPU 自动跳过，标记本身不产生跳过。贡献节奏为先 make style 自动格式化、再 make checks 三连检。官方 Docker 镜像只冻结难编译的 CUDA 依赖而不含源码，源码由 launch 流程现场克隆安装。config_test.py 中的 dotlist 覆盖断言预告了下一单元的 Config 主题。
