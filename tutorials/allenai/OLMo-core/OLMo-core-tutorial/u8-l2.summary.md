本讲拆解 OLMo-core 推理侧的 generate 包。核心是生成模块的 generate_batch 自回归主循环：prefill 喂整段 prompt、decode 每步只喂新 token，并用 logits_to_keep 避免物化全词表 logits；终止由 EOS/停止词与 max_new_tokens（优先于 max_length）决定，提前结束的行强制填 EOS 陪跑。sampling.py 构成采样流水线：贪心、temperature 缩放、top-k、top-p 核采样。KV cache 由 KVCacheManager 的 buffer 簿记，仅 flash 系注意力后端支持，左填充批次经 cache_leftpad 对齐，开 cache 须预定长度。from_checkpoint 只读 checkpoint 中 model 与 tokenizer 两块配置，可递归覆盖 dtype 与注意力后端，另支持多 checkpoint 权重平均（model soup）与 chat.py 交互式命令行。选型结论：训练侧自测用 OLMo-core，生态集成用 HF，在线服务用 vLLM。
