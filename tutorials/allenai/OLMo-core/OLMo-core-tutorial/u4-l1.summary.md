本讲是数据加载单元的第一讲，覆盖预分词数据集、数据加载器、collator 与分词器元信息四个模块。核心结论：OLMo-core 的数据底座是无文件头的裸无符号整型数组（须用 np.memmap 而非 np.save 生成），按字节偏移直读，内存映射使 TB 级语料只占实际访问页的内存；同一 token 流可组织成多种数据集变体——FSL 定长切块（默认）、Padded 按文档补齐、Packed 装箱、Interleaved 交错、VSL 分桶课程学习——均经 NumpyDatasetConfig 子类 build() 构建，prepare() 生成落盘索引缓存。NumpyDataLoader 提供三大保证：确定性（seed 加 epoch 洗牌、全局索引落盘共享）、可恢复（state_dict 含数据指纹校验与已处理批数跳批）、分布式不重不漏（batch 内按数据并行 rank 切片）；直接使用须先 reshuffle 后 reset。关键术语：global_batch_size 以 token 计、rank_batch_size 须被序列长度整除、TokenizerConfig 仅携带词表与特殊 token 元信息而非分词逻辑、DataCollator 负责补齐堆叠与词表越界校验、label_mask 使 padding 位置不计损失。下一讲进入 Composable 数据管线。
