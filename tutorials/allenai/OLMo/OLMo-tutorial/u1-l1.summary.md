OLMo 是 AI2（艾伦人工智能研究院）的开源语言模型训练与使用一体化框架，公开数据配方、训练配置、代码与每 1000 步 checkpoint，主打科学可复现（"为科学家设计，供科学家使用"）。本讲覆盖三个最小模块：一是项目定位——五大能力入口：预训练/微调用 scripts/train.py 与 configs/，HF 推理与量化走 hf_olmo/，评估在 olmo/eval/；OLMo-2 采用两阶段预训练（Stage 1 用 OLMo-mix-1124，Stage 2 用 Dolmino-mix-1124），32B 已迁移至 OLMo-core 仓库训练，1B/7B/13B 完整链路仍在本仓库。二是依赖与版本——发布名 ai2-olmo，可选依赖组 dev/train/all，训练推荐 pip install -e .[all]，版本号由 olmo/version.py 动态提供（当前 0.6.0），pip 包仅含 olmo、hf_olmo、olmo_data 三个包。三是包入口——olmo/__init__.py 以 star 导入提升 config/model/tokenizer 的公开符号，并提供 check_install() 安装自检；Trainer 等需按子模块路径导入。
