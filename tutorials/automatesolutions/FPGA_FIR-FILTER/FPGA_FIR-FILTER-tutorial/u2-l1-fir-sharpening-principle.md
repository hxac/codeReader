## 2. 前置知识

在进入正文前，先建立几个直觉。如果你已读过 **u1-l1（项目概览）**，下面的术语会眼熟，这里把它们讲透。

### 2.1 像素、灰度与 RGB

一张数字图像是由一个个**像素（pixel）**排成的网格。每个像素有一个亮度值。彩色图通常用 **R/G/B** 三个通道表示，每个通道取值范围常见为 0（黑）到 255（白）。本项目的锐化对 R、G、B 三个通道**各做一次完全相同的处理**，所以我们只需理解「单通道」的处理，再复制三份即可。

### 2.2 什么是「锐化」

一张看起来「发虚」的照片，往往是因为**边缘不够清晰**——黑白交界处过渡太平缓。**锐化（sharpening）/ 边缘增强（edge enhancement）** 的目标就是让这些交界处更「硬」、对比更明显。

实现锐化的核心思路是：**增强图像里变化快的部分（高频），同时保留整体亮度（低频）不变。** 这句话是本讲的「题眼」，后面所有内容都在解释它。

### 2.3 卷积与 FIR：换了个名字的「加权求和」

**卷积（convolution）** 在图像处理里的直觉非常简单：拿一个小小的「系数模板」（叫**核 kernel** 或**掩膜 mask**）贴在图像每个像素上，把模板盖住的几个邻域像素**加权求和**，作为这个像素的新值。

当这个加权求和的权重是**固定不变**的（不随像素位置变），它就是一个 **FIR 滤波器（Finite Impulse Response，有限长单位冲激响应）**。FIR 的「抽头（tap）」就是参与求和的每一个邻域像素，每个抽头乘以一个**系数（coefficient）**。

> 一句话：**FIR 滤波 = 用一组固定系数对邻域像素做加权求和。** 本项目是 7 抽头 FIR，也就是每次用到 7 个像素。

### 2.4 频率响应：滤波器的「身份证」

不同的系数组合会让滤波器表现出不同的「脾气」：有的让图像变模糊（低通），有的让边缘更突出（高通/锐化）。**频率响应（frequency response）** 就是描述这种脾气的曲线：横轴是「变化快慢（频率）」，纵轴是「这个频率被放大还是压低（增益）」。

- 如果频率响应在「高频」处比「低频」处更高 → 它增强细节 → 是锐化。
- 反之 → 它压低细节 → 是平滑/模糊。

Octave 的 `freqz` 函数就是用来画这条曲线的。

## 4. 核心概念与源码讲解

### 4.1 图像卷积与锐化

#### 4.1.1 概念说明

锐化的本质，是「在原图基础上，叠加一份高频细节」。可以这样理解：

- 原图 = 平均亮度（低频） + 细节边缘（高频）。
- 锐化 = 原图 + 额外的高频 → 边缘被「抬」出来。

用数学表达，一个 7 抽头的一维 FIR，对位置 \(n\) 的像素 \(x[n]\) 做加权求和得到输出 \(y[n]\)：

\[
y[n] = \sum_{k=-3}^{3} h[k]\cdot x[n+k]
\]

其中 \(h[k]\) 是 7 个系数。本项目的系数是：

\[
h = \frac{1}{32}[1,\ 0,\ -9,\ 48,\ -9,\ 0,\ 1]
\]

把中心系数 48 理解为「当前像素本身的权重」，两侧的 \(-9\) 是「邻域像素的负权重」，最外侧的 \(1\) 是更远邻域的小修正。这种「中间大、两侧负」的形状，正是锐化核的典型长相：它让当前像素与邻域的**差异**被放大——差异越大（即边缘）输出越突出，差异很小（平坦区域）输出接近原值。

#### 4.1.2 核心流程

判断一组系数到底是不是「纯锐化」，关键看两点：

1. **直流增益（DC gain）**：所有系数之和。它决定平坦区域（一片相同亮度的像素）输出是变亮、变暗还是不变。锐化要求**和为 1**，这样平坦区域亮度不变，只动边缘。

   \[
   \text{DC 增益} = \sum h[k] = \frac{1+0-9+48-9+0+1}{32} = \frac{32}{32} = 1
   \]

   和正好是 1，说明它**只增强细节、不改变整体亮度**——这是「干净」的锐化器。

2. **高频增益**：在高频处增益是否 > 1。这一点用 4.3 节的频率响应来验证。

把核拆成「直流部分 + 高通部分」会更清楚：

\[
\underbrace{\frac{1}{32}[1,\ 0,\ -9,\ 48,\ -9,\ 0,\ 1]}_{h}
= \underbrace{1\cdot[0,0,0,1,0,0,0]}_{\text{直流=原图}} + \underbrace{\frac{1}{32}[1,\ 0,\ -9,\ 16,\ -9,\ 0,\ 1]}_{\text{高通=细节}}
\]

（直流部分用了「和为 1」的事实：把中心权重 48 拆成 32 + 16，其中 32/32 = 1 正好是原图本身。）

这就把锐化说透了：**输出 = 原图 + 一份由 \([1,0,-9,16,-9,0,1]/32\) 算出的细节。** 中心那个 16 越大，细节加得越多、锐化越强。

#### 4.1.5 小练习与答案

**练习 1**：如果把系数 \(-9\) 全改成 \(0\)（即核变成 \([1,0,0,48,0,0,1]/32\)），它还是合格的锐化器吗？为什么？

**答案**：不再是「干净」的锐化器。此时系数和 \(=(1+48+1)/32 = 50/32 \approx 1.56 \neq 1\)，直流增益不为 1，会把整张图整体提亮并可能饱和。而且失去了「中间正、两侧负」的对比结构，边缘增强效果也变弱。

**练习 2**：为什么锐化核的「两侧」通常用**负**权重？

**答案**：负权重让邻域像素从当前像素中「减去」，从而放大「当前像素与邻域的差异」。差异大的地方就是边缘，于是边缘被突出——这正是锐化想要的。

### 4.2 可分离二维滤波

#### 4.2.1 概念说明

图像是**二维**的（有行有列），所以完整的锐化需要一个二维核。直接做二维卷积，意味着每个输出像素要在「行和列两个方向」上同时取邻域，抽头数会爆炸：一个 \(7\times7\) 的二维核需要 49 次乘加。

但本项目的二维锐化核有一个特殊性质：它**可分离（separable）**。也就是说，这个 \(7\times7\) 的二维核可以写成「一个竖向向量 × 一个横向向量」的**外积**：

\[
K_{2D} = \mathbf{v}\,\mathbf{h}^{T}
\]

当二维核能这样分解时，二维卷积就等价于**先沿垂直方向做一次一维卷积，再沿水平方向做一次一维卷积**：

\[
\text{二维卷积}(\text{图}, K_{2D}) = \text{水平卷积}(\text{垂直卷积}(\text{图}, \mathbf{v}),\ \mathbf{h})
\]

运算量从 \(7\times7=49\) 次乘加降到 \(7+7=14\) 次，**对硬件意味着节省大量的乘法器和存储**。本项目两个方向还**复用同一组系数**（\(\mathbf{v}=\mathbf{h}=h\)），所以硬件里垂直和水平可以共用同一种运算单元（`sharp_arith`）。

#### 4.2.2 核心流程

用伪代码描述可分离二维锐化的流程：

```
输入: img_in（二维/三通道图像）, 一维核 h = [1,0,-9,48,-9,0,1]/32
1. f_hor = h            （1×7 行向量，水平方向）
2. f_ver = h 转置        （7×1 列向量，垂直方向）
3. img_tmp = imfilter(img_in, f_ver)   # 先垂直方向 FIR：每个像素用上下 7 个邻居
4. img_out = imfilter(img_tmp, f_hor)  # 再水平方向 FIR：每个像素用左右 7 个邻居
输出: img_out（与原图同尺寸的锐化图）
```

这两步的顺序（先垂直还是先水平）理论上可以交换，结果相同（卷积可交换、可分离核两方向可换序）。

为什么这样拆是对的？因为可分离核 \(K_{2D}=\mathbf{v}\mathbf{h}^{T}\) 的二维卷积可以分解：

\[
y[i,j] = \sum_{p}\sum_{q} K_{2D}[p,q]\cdot x[i+p,j+q]
       = \sum_{p}\mathbf{v}[p]\underbrace{\left(\sum_{q}\mathbf{h}[q]\cdot x[i+p,j+q]\right)}_{\text{水平卷积}}
\]

先对每个 \(p\) 做水平求和（得到一个中间结果），再沿 \(p\) 做垂直求和——正好对应「先水平后垂直」；同理可写成「先垂直后水平」。

可以验证这个二维核也是「干净」的锐化器：它的直流增益 = \((\sum\mathbf{v})\cdot(\sum\mathbf{h}) = 1\times1 = 1\)，整体亮度依然不变。

#### 4.2.5 小练习与答案

**练习 1**：如果二维核**不可分离**（无法写成两个一维向量的外积），还能拆成「先垂直再水平」两次一维卷积吗？

**答案**：不能。可分离性是「二维 = 两次一维」成立的前提。不可分离的核必须老老实实做二维卷积（抽头数 = 行×列），硬件代价大得多。所以硬件图像处理偏爱可分离核。

**练习 2**：本项目垂直和水平用了**相同**的系数。如果两个方向想用不同强度的锐化（比如垂直强、水平弱），算法上要怎么改？硬件上还能共用同一个 `sharp_arith` 吗？

**答案**：算法上把 `f_ver` 换成另一组系数即可（外积 \(K_{2D}=\mathbf{v}\mathbf{h}^{T}\) 仍可分离，只要两方向各自是一维核）。但硬件里 `sharp_arith` 把系数**烧死**在乘加表达式里（见 4.1.3 引用的 `sharp_arith.vhd:34`），两方向若系数不同，就需要两个不同参数的运算单元，不能再无脑共用同一份代码。

### 4.3 频率响应 freqz

#### 4.3.1 概念说明

前面我们从「系数长相」推断这是锐化核。更严谨、更直观的办法是看它的**频率响应**：把滤波器看作一个「按频率分配增益」的黑盒，画出「输入不同频率的正弦波时，输出会被放大多少倍」。

- 低频（图像里缓慢变化的大块区域）对应平坦亮度；
- 高频（图像里快速跳变的边缘、纹理）对应细节。

锐化器应该「低频保持、高频提升」。`freqz` 就是画这条「增益—频率」曲线的 Octave 函数。

#### 4.3.2 核心流程

对一个 FIR 滤波器，频率响应定义为系数的离散时间傅里叶变换：

\[
H(\omega) = \sum_{k} h[k]\,e^{-j\omega k}
\]

我们关心两个极端频率：

1. **直流（\(\omega=0\)）**：所有 \(e^{-j\omega k}=1\)，于是 \(H(0)=\sum h[k]\)，即系数和。本项目为 1（增益 0 dB）。

2. **奈奎斯特（\(\omega=\pi\)，最高频）**：\(e^{-j\pi k}=(-1)^k\)，于是 \(H(\pi)=\sum h[k](-1)^k\)。代入本项目系数：

\[
H(\pi) = \frac{1(1)+0(-1)+(-9)(1)+48(-1)+(-9)(1)+0(-1)+1(1)}{32}
       = \frac{-64}{32} = -2
\]

幅度 \(|H(\pi)|=2\)，即约 **+6 dB**。

结论非常清晰：**直流增益 1（0 dB），最高频增益 2（+6 dB）**——低频不动、高频翻倍，这正是「锐化」的频率特征。`freqz` 画出来的曲线会从左端（低频）的 0 dB 上升到右端（高频）的约 +6 dB。

**实践目标**：亲眼看频率响应曲线，确认「低频 0 dB、高频 +6 dB」。

**操作步骤**：

1. 打开 Octave，加载 signal 包（脚本第 9 行 `pkg load signal`）。
2. 运行 `sharp_frequency_response.m`，或在命令行直接：

   ```octave
   pkg load signal;
   filter = [1, 0, -9, 48, -9, 0, 1]/32;
   freqz(filter);
   ```

3. 观察弹出的幅度响应曲线（上子图）：读出左端（归一化频率 0）和右端（归一化频率 1）的 dB 值。

**需要观察的现象**：曲线在左端约为 0 dB，向右端上升至约 +6 dB，整体单调上升。

**预期结果**：左端 0 dB（对应 \(H(0)=1\)），右端约 +6.02 dB（对应 \(|H(\pi)|=2\)）。这条「上升曲线」就是「锐化」的视觉证据。

**待本地验证**：图形窗口的具体外观以本地 Octave 版本为准；若想精确读数，可用 `[H,w]=freqz(filter);` 然后查看 `20*log10(abs(H(1)))`（直流）与 `20*log10(abs(H(end)))`（奈奎斯特）。

#### 4.3.5 小练习与答案

**练习 1**：如果把系数改成全正的平均核（比如 \([1,1,1,1,1,1,1]/7\)），频率响应曲线会是什么形状？

**答案**：会是一条**下降**曲线——低频增益高（=1），高频被压低。这是低通/平滑滤波器，效果是模糊而不是锐化。`freqz` 一画就能和锐化的上升曲线区分开。

**练习 2**：为什么本讲反复强调「直流增益必须为 1」对锐化很重要？

**答案**：直流增益 = 系数和，决定平坦区域的亮度缩放。若不为 1，锐化的同时会把整张图整体变亮或变暗（甚至饱和溢出），「只增强边缘、不改亮度」的干净效果就被破坏了。本项目精心选择系数使和正好为 1（=32/32）。

## 5. 综合实践

把本讲三个模块串起来，完成下面这个「改系数 → 看图像 → 看频响」的小闭环。这也是本讲规格里指定的实践任务。

**任务**：运行 `sharp_image_filter.m`，分别**增大**和**减小** `f_hor` 的中心系数 48，观察输出图像锐化强度的变化，并用频率响应解释原因。

**操作步骤**：

1. 先跑通原版脚本，得到基准锐化图 `Lindau_Harbour_sharp.jpg`（[sharp_image_filter.m:11-19](https://github.com/automatesolutions/FPGA_FIR-FILTER/blob/3f7aef90f4d34fa62f00ca72c260fc49c3c04a8c/FPGA-FIR-Filter-master/Octave/sharp_image_filter.m#L11-L19)）。

2. **实验 A：增大中心系数**。把第 13 行的 48 改成 56：

   ```octave
   f_hor = [1, 0, -9, 56, -9, 0, 1]/32;   % 中心系数 48 -> 56
   ```

   重新运行，另存为 `sharp_strong.jpg`。

3. **实验 B：减小中心系数**。把 48 改成 40：

   ```octave
   f_hor = [1, 0, -9, 40, -9, 0, 1]/32;   % 中心系数 48 -> 40
   ```

   重新运行，另存为 `sharp_weak.jpg`。

4. 三张图并排对比；同时用 `freqz(f_hor)` 画出三种系数的频率响应对比。

**需要观察的现象**（结合 4.1.2 的分解理解）：

- 关键事实——只改中心系数时，**高通部分 \([1,0,-9,16,-9,0,1]/32\) 不变**（因为中心 = 32[直流] + 16[高通]，改的是直流那 32）。变的是**直流增益**：
  - 实验 A（56）：系数和 \(=(56-16)/32=1.25\)，直流增益 > 1 → 整体**变亮**，亮区可能饱和发白；
  - 实验 B（40）：系数和 \(=(40-16)/32=0.75\)，直流增益 < 1 → 整体**变暗**，边缘相对暗背景可能显得更「跳」。

- 频率响应上：直流处（左端）不再贴着 0 dB——A 上移到约 +1.9 dB、B 下移到约 -2.5 dB；高频形状基本不变。

**预期结论**：单纯调中心系数主要改的是「整体亮度（直流增益）」，而非「锐化的频率形状」。这反过来解释了**为什么原设计要精确选 48**：只有 48 能让系数和 = 32、直流增益 = 1，做到「只锐化、不变亮」。若想真正改变锐化强度，应同步调整高通部分（例如同时改两侧的 -9 或中心的「16」那一份），保持系数和为 1。

**待本地验证**：图像的视觉差异、是否出现饱和发白，取决于具体测试图的内容，请以本地运行结果为准。频率响应的精确 dB 值可用 `[H,w]=freqz(f_hor)` 数值核对。

> 把这个结论记住，后面 **u2-l2** 会看到这组系数是怎么用 `fir1(8,0.5,"high")` 设计出来、再「放大 32 倍取整」定点化的——届时你会明白「32」和「48」这两个数字的来由。

## 6. 本讲小结

- 锐化 = 在原图上叠加高频细节；FIR 滤波就是「用固定系数对邻域像素加权求和」，本项目是 7 抽头。
- 本项目核 \([1,0,-9,48,-9,0,1]/32\) 的系数和 = 1，直流增益为 1，所以**只增强边缘、不改整体亮度**，是干净的锐化器。
- 二维锐化核**可分离**，所以二维卷积 = 先垂直、再水平两次一维卷积；运算量从 49 降到 14，且两方向同系数、硬件可复用运算单元。
- `sharp_image_filter.m` 的两行 `imfilter` 就是可分离滤波的算法原型，与硬件 `sharp_slice` 的「垂直抽头链 + 水平抽头链」结构同构。
- 频率响应（`freqz`）显示直流 0 dB、奈奎斯特约 +6 dB，从频域证实这是高频提升；曲线「上升」即可一眼判锐化。
- 单独修改中心系数 48 主要改变直流增益（整体亮度），不改变高通形状——这正是原设计选 48（使和=1）的精妙之处。
