本讲解读仿真测试台 sim_sharp.vhd：它把顶层 sharp 作黑盒例化为被测器件（DUV），无外部端口、自产时钟与复位。三大模块：（1）用 VHDL textio 库读写 ASCII PPM（P3）图像，输入图当视频源、输出图当锐化截图，逐像素读取时以 l'length<2 判断换行，写字符串须用 string'() 限定表达式消除 write 重载歧义；（2）重建简化视频时序：首行拉 vs、每行拉 hs 加 x_blank 拍水平消隐、有效区拉 de（同时充当行存储写使能），仿真采用 100 MHz 而非硬件 74.25 MHz、激励统一在 falling_edge 更新以留出半周期建立时间；（3）激励/响应双并发进程靠共享信号 end_tb 协调结束——响应进程以 hs_out='1' 起步、捕获满帧后 file_close 刷盘，真正终结仿真的是激励进程末尾的 assert false severity failure，响应进程则用永不成立的 wait 永久挂起。声明却未使用的 mismatch 信号预留给下一讲 u5-l2 的逐像素自校验测试台。
