本讲精读 sim_sharp_self-checking.vhd，引入自校验测试台（self-checking testbench）概念：在仿真内部持有一份由 Octave imfilter 生成的期望图像（expected），将硬件输出逐像素与之比对，仿真结束自动报 PASS/FAIL，无需人眼看图，是回归测试自动化的前提。三个核心要点：一、比对在 response_process 中随输出节奏现读 expected 像素做三通道比较，比对前先验尺寸一致性；二、须补偿 3 行垂直偏移（用 y_pos>2，源于 7 抽头垂直滤波中心抽头 v_tap(3) 落在当前输入行 3 行之前，sharp_control 的 delay=6 仅管时钟级对齐、管不了整行级），并跳过左/右各 3 列、上方合计 6 行的边缘像素（硬件行存储/移位寄存器未填满，与 Octave zero-padding 不可比）；三、mismatch 为跨进程共享信号，累加用 severity note 不中断仿真，末尾用 assert false … severity failure 强制停仿真，据 mismatch 是否为 0 报告 EVERYTHING OK 或 N MISMATCHES。
