本讲承接 u8-l2，核心是 **delegate（委托）**：它不是单个 kernel，而是把一段连续子图整体打包成 `BuiltinOperator_DELEGATE` 宏算子、卸载到加速后端的协议；结构体 `TfLiteDelegate` 薄而统一，仅含 `Prepare`、缓冲回调与 `flags` 位标志。

四大模块：①三幕流程——创建、`ModifyGraphWithDelegate`（备份原计划→`SwitchToDelegateContext`→`delegate->Prepare`→图冻结为不可变）、`Invoke` 走宏算子；②图分区——`PartitionGraphIntoIndependentNodeSubsets` 用 epoch（纪元）遍历把执行计划切成 `NodeSubset` 交替，被委托段合并成宏算子、其余节点原样留 CPU，跨段边界张量构成 `TfLiteDelegateParams`；③两级失败回退——应用期失败无条件整图回滚（靠 `pre_delegation_execution_plan_` 存档），运行期失败可选 `InvokeWithCPUFallback` 做 CPU 兜底（前提：输入可备份、模型无状态、调用方不缓存张量指针）；④GPU/NNAPI/XNNPACK 三后端遵循同一「构造 registration + 判定支持集 + `ReplaceNodeSubsetsWithDelegateKernels`」三段式，其中 XNNPACK 不需专用硬件，常作默认委托被自动应用。

供后续承接的术语：delegate、宏算子（macro-op/DELEGATE op）、backend、NodeSubset、graph partitioning、epoch、`TfLiteDelegateParams`、`SwitchToDelegateContext`/`SwitchToKernelContext`、应用期回滚 vs 运行期 CPU fallback。
