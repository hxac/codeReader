本讲为 TensorFlow 源码学习手册第一讲，目标是让读者打开巨大仓库时不再迷路，建立「全局认知」。覆盖三个最小模块：其一，通过 `README.md` 确立 TensorFlow 的定位——它是一个端到端（end-to-end）的机器学习开源平台，出自 Google Brain 团队，覆盖研究、训练、推理、部署全链路；并明确 Python 与 C++ 是稳定 API，其它语言绑定不保证向后兼容，TFLite 对应移动端部署。其二，精读 `tensorflow/__init__.py`，揭示这个刻意保持极简的 Python 入口如何工作：靠导入 `pywrap_tensorflow` 桥接底层 C++ 核心、以导入副作用拉起整个 Python API；公开的 `tf.*` 符号由各模块用 `@tf_export` 装饰器注册到一张全局「名字→符号」映射表再组装进命名空间，而非手写海量 import；末尾的 `del python`/`del core` 用于清理命名空间、防止内部子包泄漏。其三，给出通用的「仓库认知建立法」：握住定位（README）、构建（`configure.py`、`WORKSPACE`/`MODULE.bazel`，主构建工具为 Bazel）、语言入口（`__init__.py`）三类文件即可随时回到主干。引入的关键术语包括：张量（Tensor）、op/kernel、稳定 API、pywrap_tensorflow、tf_export、命名空间清理、Eager 执行模式，为后续讲义（u1-l2 目录布局、u1-l3 构建系统、u1-l4 导入链）承接。
