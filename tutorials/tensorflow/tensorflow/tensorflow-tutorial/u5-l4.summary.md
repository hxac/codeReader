本讲剖析 tf.keras 三层结构：Layer→Model→Functional。Layer 是「权重状态 + call 前向逻辑」的封装，统一入口 __call__ 负责按需 build（延迟创建权重）、mask/training 处理，经 add_weight 登记变量。关键在两种调用语义：输入为真实张量则执行计算，为 KerasTensor 则进入函数式构造模式——不计算，仅在临时图探测输出形状、用 Node 记录连通关系并给输出打上 _keras_history。Functional 沿 _keras_history 回溯做拓扑排序得 nodes_by_depth，调用时 _run_internal_graph 按深度降序重放内部图；Sequential 为其线性特例，Model.__new__ 的类替换使 Model(inputs, outputs) 自动返回 Functional 实例。Model 在 Layer 之上以三层解耦实现训练：train_step（GradientTape 录制 + optimizer.minimize，承接自动微分）、make_train_function（包进 tf.function）、fit（数据与回调编排）；compile 配置 optimizer/loss/metrics 并清空缓存的训练函数。
