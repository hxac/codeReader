本讲承接 u7-l1 的 MLIR 流水线，覆盖两个最小模块：`compiler.tf2xla`（TF→XLA 翻译官）与 `compiler.mlir.stablehlo`（可移植 IR）。XLA 是线性代数编译器，把整段子图做算子融合、缓冲区复用，编译成高效设备 kernel。tf2xla 对外暴露两个入口：经典路线 `ConvertGraphDefToXla` 靠 `XlaCompiler` 做符号执行，逐 op 调用 XLA 编译 kernel 往 `XlaBuilder` 追加 HLO（要求输入形状已知，参数分 `kConstant`/`kParameter`/`kResource`）；MLIR 路线 `ConvertGraphDefToXlaViaMlir` 则分导入、TF 标准 pipeline、legalize 到 MHLO 三段声明式 pass，并以 `enable_op_fallback`（`prefer_tf2xla`）在缺 pattern 时回退经典 kernel，二者是「主+兜底」而非互斥。翻译范围由 `tf2xla::Config`（feed/fetch/variable）指定。StableHLO 是从 MHLO 提炼的稳定、向后兼容子集，用于序列化为「可移植 artifact」做跨框架互通；TF 经 `tf-stablehlo` pipeline（TF→MHLO→Canonicalize→HloLegalizeToStablehlo）导出。MLIR 桥当前采用保守渐进式 rollout，未显式指定时默认禁用。
