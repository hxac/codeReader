本讲贯通自定义 op 的写、编、载、配梯度全流程。核心三件套为：`REGISTER_OP` 声明说明书，`OpKernel::Compute` 实现计算，`REGISTER_KERNEL_BUILDER` 把工人挂到说明书并指定设备。用 `tf_custom_op_library` 编译为 `.so`，其 `check_deps` 刻意禁止静态链接 framework，让符号运行时解析到 TF 主进程以保二进制兼容。加载走 `tf.load_op_library` 的「副作用 + 现场生成」流水线：dlopen 触发注册，watcher 只抓本库新增的 OpList，`GetPythonWrappers` 即时生成 Python 包装并 exec 成模块；对照 `core/user_ops` 的 `alwayslink` 静态链接路线（import 即用、无需加载）。梯度在 Python 侧用 `@tf.RegisterGradient` 注册（import 副作用），不可微用 `tf.no_gradient`，用 `tf.test.compute_gradient` 校验。进阶含 `Attr("T")` + `TypeConstraint` 类型参数化、`GetAttr` 两段属性校验、CPU 壳 + `.cu.cc` launcher + `GpuLaunchKernel` 的 GPU 范式。
