本讲以 ZeroOut/Fact 为例串起自定义 op 全流程。核心结论：自定义 op 由三件套构成——REGISTER_OP 声明说明书（输入输出、属性、形状推导），OpKernel::Compute 实现计算，REGISTER_KERNEL_BUILDER 把工人挂到说明书并指定设备。构建期用 tf_custom_op_library 把 C++ 编成 .so，刻意不静态链接 framework，运行时把符号解析到已加载的 TF 进程。load_op_library 是一条「dlopen 触发注册副作用 → watcher 抓取本库新增 OpList → 现场生成 Python 包装 → exec 成模块」流水线；对照 core/user_ops 走构建期 alwayslink 静态链接、import 即用。梯度需在 Python 侧用 @tf.RegisterGradient 单独注册（靠 import 副作用触发），不可微用 tf.no_gradient 显式声明。进阶套路包括 Attr 类型参数化、GetAttr 两段属性校验、CPU 壳加 .cu.cc launcher 的 GPU kernel。
