本讲覆盖 TensorFlow 构建的配置与依赖组织层，含四个模块。一是 Bazel 与 `.bazelrc`：TF 因跨语言跨平台规模须用 Bazel（可复现、增量、密封）；`.bazelrc` 用 `common` 设默认选项、用 `build:NAME` 定义配置档（`--config` 触发），默认关闭 Bzlmod 走 WORKSPACE。二是 `./configure` 与 `configure.py`：后者以环境变量优先、否则交互问答探测 Python/CPU/CUDA，把结论落盘到 `.tf_configure.bazelrc`，由 `.bazelrc` 的 `try-import` 加载。三是 configure.py 三大探测：Python 写 `--action_env`、CPU 用 `set_cc_opt_flags`、CUDA 用 `set_hermetic_*` 写成 `build:cuda --repo_env` 并落地 `--config=cuda`。四是依赖组织：WORKSPACE 用 `tf_http_archive`+sha256 密封下载，`cuda_configure` 消费 repo_env 产出 `@local_config_cuda`；实验性 MODULE.bazel 用 `bazel_dep`+BCR。核心链路：用户意图经 bash→Python→bazelrc→配置档→仓库规则变为构建行为；区分 `--action_env`（构建动作可见）与 `--repo_env`（仓库规则可见）是理解全篇的钥匙。
