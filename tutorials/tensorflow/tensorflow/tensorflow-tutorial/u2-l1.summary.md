本讲是「张量与基本概念」单元首讲，精读 `python/framework/dtypes.py` 与 `python/framework/tensor_shape.py` 两个最小模块，揭示现代 TF2 张量（`EagerTensor`）的两条核心元数据——dtype 与 shape——的 Python 实现来源。核心结论：张量可近似为「dtype + shape + 数据缓冲区」，而 `ops.py` 中的 `dtype`/`shape` 属性仅负责把 C++ 内核的枚举与形状元组翻译成 Python 对象——dtype 直查 intern table 返回单例，shape 则懒构造为 `TensorShape` 并缓存。关键术语：`DType`（以 C++ 枚举 `types_pb2.DataType` 标识，经 `_INTERN_TABLE` 单例化、`_NP_TO_TF`/`_TF_TO_NP` 与 numpy 互转、`as_dtype()` 统一入口转换）；`TensorShape`（仅持 `_dims` 一个字段，据此区分完全已知/部分已知/完全未知三类静态形状，rank、`num_elements`、`is_compatible_with`、`merge_with`、`with_rank` 为核心运算）。务必区分静态形状 `t.shape`（tracing 期已知、可含 `None`）与动态形状 `tf.shape(t)`（运行时 op，返回真实尺寸）。本讲为 u2-l2（constant_op）与 u2-l4（EagerTensor 全貌）奠定底层零件基础。
