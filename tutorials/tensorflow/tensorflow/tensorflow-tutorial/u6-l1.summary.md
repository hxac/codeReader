本讲覆盖 TensorFlow 运行时「设备」三个最小模块。其一，Device 是执行单元抽象，继承链 DeviceBase → Device → LocalDevice → ThreadPoolDevice/GPUDevice：DeviceBase 给出线程池、Allocator、Eigen 等能力骨架（多为 LOG(FATAL) 占位），Device 补齐面向 Session 的 Compute/Sync/ResourceMgr 与设备名属性；Compute 默认转交 OpKernel，Sync 因硬件而异设为纯虚。设备名遵循 /job:/replica:/task:/device:CPU:0 格式，构造时强制解析并据此建独立 ResourceMgr，另含非零随机 incarnation 作跨进程身份。其二，DeviceFactory 用工厂模式加静态全局对象自动注册：REGISTER_LOCAL_DEVICE_FACTORY 宏在 main 前把工厂写入函数局部 static 全局表，同一 device_type 多工厂按优先级裁决（高覆盖低、相等报错），默认 GPU=210 高于 CPU=60，故无显式指定时偏好 GPU。其三，op 落设备经 AddDevices 收集、DeviceSet 按优先级排序、Placer 选择，DeviceSet::DeviceTypeOrder 直接转调 DeviceFactory::DevicePriority，即工厂注册的 priority 决定无约束 op 的设备偏好，CPU 必须最先加且必须有作兜底。
