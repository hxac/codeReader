本讲解释 AutoGraph 如何把 Python 的 if/while/for 命令式控制流等价翻译成声明式 TF 图 op，以解决追踪期张量条件无法静态判断真伪、从而抛 OperatorNotAllowedInGraph 的问题。核心是两阶段设计：converter 在编译期做纯 AST→AST 改写，把 if/while/for 改写成 ag__.if_stmt 等调用（不碰 TF）；operator 在追踪期按运行期类型派发——条件是张量则发 tf.cond/tf.while_loop，否则退回原生 Python 语义。源码分三层：impl/api.py 为入口与流水线（PyToTF.transform_ast 串联十余个 converter，由 get_extra_locals 注入 ag__ 命名空间，转换后函数加 tf__ 前缀）；core/converter.py 提供不可复用的 Base 基类、ConversionOptions 与 Feature 开关，control_flow converter 依赖 pyct 静态分析；operators/ 实现 if_stmt/while_stmt/for_stmt 的类型派发。关键机制是状态外化：自动生成的 get_state/set_state 把闭包副作用搬进搬出，使 Python 副作用适配 TF 的纯函数加显式状态模型。tf.function 默认经 converted_call 开启 AutoGraph，可用 autograph=False 关闭，改写遵循 as-if 规则（行为与 Eager 一致或报错）。
