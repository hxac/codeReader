本讲讲清 Python 调用到 C++ 内核之间的桥梁机制。核心分三层：其一，C API（c/c_api.h）是语言无关的稳定边界，采用「不透明指针 + TF_Status + unsigned char 布尔」风格，不透明指针实为包裹 C++ 对象的壳，内部布局可自由演进而不破坏调用方。其二，存在两套 C API——稳定的 TF_ 图模式 API（TF_Session、TF_Graph、TF_SessionRun）与不稳定的 TFE_ 即时执行 API（TFE_Context、TFE_TensorHandle、TFE_Op、TFE_Execute）。其三，pywrap 用 pybind11 的 m.def 把 C 函数注册成 .so 模块，再经 Python 再导出层（pywrap_tf_session.py、pywrap_tfe.py）接入命名空间并做便捷包装。完整调用链为 Python→pywrap→C API→C++ kernel，其中 C 层只做翻译与转发，真正的放置、调度、执行 kernel 都在 C++。关键职责切分口诀：Python 做策略，C 做数据搬运（指针/张量转换、释放 GIL、TF_Status 翻译异常），C++ 做真正的活。释放 GIL（Py_BEGIN/END_ALLOW_THREADS）是 pywrap 层最重要的性能职责。
