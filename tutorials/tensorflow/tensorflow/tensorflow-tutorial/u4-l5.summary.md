本讲解释了 TensorFlow 里一个 op 从 C++ 声明到 Python 可调用 `tf.*` 函数的最靠近 Python 端的一层。核心结论是：C++ 的 `REGISTER_OP` 是唯一真相源，由可执行生成器 `python_op_gen_main` 读取全局 `OpRegistry` 的 `OpDef`、叠加 `ApiDef`（改 Python 名、补文档、控可见性）后自动生成 `gen_*_ops.py`；这些文件是构建期产物，不在源码树里，由 Bazel 宏 `tf_gen_op_wrapper_py` 把"编译生成器 → genrule 产出 .py → 打成 py_library"串成流水线。关键术语包括：薄包装 `gen_*_ops`、eager 快路径 `TFE_Py_FastPathExecute`、eager 慢路径 fallback、graph 回退 `_apply_op_helper`。生成的每个函数套用同一骨架：`if tld.is_eager:` 先走最快 C++ 路径，失败回退，graph 模式则建 `Operation` 节点。其上再叠一层手写厚包装 `math_ops`/`array_ops`，负责生成器做不到的事：签名归一、dtype 推导、按类型路由（如 `abs` 按复/实数分派）、静态形状回填、命名空间与历史 API 兼容；用户看到的 `tf.*` 名由手写层 `@tf_export` 决定，与 C++ op 名、生成函数名三者可各不相同。
