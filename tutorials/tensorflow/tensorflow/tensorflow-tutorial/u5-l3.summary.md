本讲讲解 SavedModel 的序列化与加载，覆盖磁盘结构、保存主链路、ConcreteFunction 序列化、加载主链路四个核心模块，并以 builder_impl 辅助说明 TF1 双轨。磁盘上由 saved_model.pb（结构）+ variables/（变量数值）+ assets/（外部资源）组成，魔法字符串定义在 C++ constants.h。关键结论有三：第一，saved_model.pb 内部「双轨并存」——MetaGraphDef（graph_def + signature_def，供 TF1/C++/serving）与 object_graph_def（供 TF2 Python 重建对象树）；第二，变量数值不在 pb 而在 checkpoint，体现「描述与数据分离」，与 _variant_tensor 同源。引入的关键术语包括：Trackable 对象图、MetaGraphDef、SavedObjectGraph、SignatureDef、capture 捕获张量、bound_inputs（对象图节点 id）、ConcreteFunction。保存侧 _write_object_proto 与加载侧 _recreate_default 是严格对称的「按类型分发」入口；ConcreteFunction 的捕获靠节点 id 而非名字重新接线。加载是两段式：先按 protobuf 重建对象（变量先建为未初始化形态），再用 checkpoint 统一灌入数值；返回对象默认是 AutoTrackable 而非原始类，Keras 还原依赖后续讲义的 revived_types 注册机制。
