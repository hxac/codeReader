本讲是「计算图与执行模型」单元首讲，讲解 TensorFlow 如何在 C++ 内核中表示计算图，共三个模块。其一，运行时 `Graph`/`Node`/`Edge` 三件套构成有向无环图（DAG）：每条边携带 `(src, src_output, dst, dst_input)` 四元组以标明数据流向；图构造时自动建立哨兵节点 `_SOURCE`（id 0）与 `_SINK`（id 1）并以控制边相连，普通 op 的 id 从 2 起；**控制边**用特殊端口值 `kControlSlot = -1` 表示，仅约束执行顺序不传数据；节点与边均经 arena 分配、id 不回收。其二，序列化的 `GraphDef`（protobuf 消息）是扁平的 `NodeDef` 列表，不设独立边对象，而是将边折叠进目标节点的 `input` 字符串（数据边为 `"name:idx"`，控制边为 `"^name"`）；`Graph::ToGraphDef` 完成转换时跳过 source/sink、控制边置末并排序以保证可复现。其三，Python 侧 `ops.Graph` 直接桥接 C++ 图，`FuncGraph(ops.Graph)` 在其上新增 `inputs/outputs/captures/control_outputs/outer_graph`，是 `tf.function` 追踪产物，靠 `_create_op_internal` 中的 capture 机制将外部闭包变量透明地搬进函数图。核心结论：图是 TF 的「中间语言」，同一条依赖在运行时是带端口的对象、在 GraphDef 中是字符串、在 C++ 中是 Edge 对象。
