本讲覆盖环境搭建与 MSDeformAttn CUDA 算子编译：Mask2Former 是 detectron2 插件项目，依赖按“PyTorch→detectron2→requirements.txt 及评估库→CUDA 扩展”四层金字塔自底向上安装。核心结论：ops/setup.py 的 CppExtension 分支是死代码，任何成功构建都走 CUDAExtension 并定义 WITH_CUDA 宏，因此无 GPU 机器也必须安装 CUDA toolkit，用 FORCE_CUDA=1 与 TORCH_CUDA_ARCH_LIST（指定计算能力）完成编译。CPU 推理回退发生在 Python 层 try/except：C++ 分发层对 CPU 张量抛错后由参考实现 ms_deform_attn_core_pytorch 接管，src/cpu 实现被编译但从不被调用。关键术语：CUDA_HOME、计算能力、MultiScaleDeformableAttention 扩展。
