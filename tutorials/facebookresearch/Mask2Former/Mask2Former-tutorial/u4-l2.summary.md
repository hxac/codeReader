本讲拆解 Mask2Former v2 解码器的三类积木与位置编码。序列统一为 (L, B, C) 格式，特征图经 flatten+permute 化为 token 序列；位置注入靠 with_pos_embed 逐元素相加，只进 Q/K、不进 V——位置只影响匹配打分，不污染传递的内容。query 侧用可学习 query_pos，图像侧用正弦 pos。SelfAttentionLayer 让 Q 个 query 互通分工；CrossAttentionLayer 让 query 从 memory 取证据，其 memory_mask 是 masked attention 的载体（True 即禁止注意）；FFNLayer 是逐 token 的两层感知机，注意与预测头中的 MLP 区分。pre-norm 与 post-norm 由 normalize_before 开关统一切换，本项目默认 post-norm。PositionEmbeddingSine 把归一化网格坐标编码为多频率 sin/cos，y/x 各占半通道，多尺度下尺度不变。解码器每层顺序为 cross→self→FFN；把这些积木组装成 masked attention 主循环留待下一讲。
