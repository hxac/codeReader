本讲精读 MaskFormer 推理三分支中的实例分割分支 instance_inference。核心机制：将 Q 个 query × K 个类别的分数表打平后取全局 topk，选出 N 个 (query, class) 对作为实例，再用扁平索引整除 K 还原 query 索引以取 mask；实例数由 TEST.DETECTIONS_PER_IMAGE 决定而非阈值，同一 query 可携不同类别重复入选。分类分数是先 softmax（no-object 留在分母）再切列得到的条件概率。关键术语：query×class 展开、重打分（最终分数＝分类分数 × mask 区域内平均 sigmoid 概率）、thing 过滤（panoptic_on 开启时按 thing_dataset_id_to_contiguous_id 剔除 stuff 类，判断依据是模型开关而非数据集类型）、全零占位 pred_boxes。结果挂载到 detectron2 Instances 的 pred_masks、pred_boxes、scores、pred_classes 四字段；挑选与定序分离——topk 只看分类分数，重打分仅影响排序与下游过滤。
