本讲处理代码演进后旧 checkpoint 的兼容问题。PyTorch 的 load_state_dict 会递归调用各模块的 _load_from_state_dict 钩子，可在装载前原地改写 state_dict 的 key；模块 _version 随保存记入 checkpoint 的 _metadata，加载时据此判断权重新旧。Mask2Former 有两处 _version=2 自动迁移：MaskFormerHead 钩子为 v1 内联 FPN 的 key 插入 pixel_decoder. 前缀并排除 predictor 子树；v2 解码器 MultiScaleMaskedTransformerDecoder 的同名钩子把旧参数名 static_query 改名为 query_feat；两者均用 scratch 旗标保证从零训练不告警。外部权重引入方面，convert-torchvision-to-d2.py 用四条有序规则改写 torchvision R50 的 key，且权重兼容=key兼容+预处理兼容（PIXEL_MEAN/STD、STRIDE_IN_1X1、INPUT.FORMAT）；Swin 转换脚本零改写，靠保留上游参数命名与 matching_heuristics 的后缀+形状启发式对齐。DetectionCheckpointer 的部分加载（多余 key 丢弃、缺失 key 随机初始化）是「仅 backbone 预训练、整模型从头训」可行的根基。
