本讲精读 `MaskFormerHead`（mask_former_head.py）：它注册于 SEM_SEG_HEADS_REGISTRY，是「backbone → pixel decoder → Transformer decoder」三段式结构中的组装器，自身无计算层，只持有 pixel_decoder 与 predictor（Transformer 解码器）两个子模块；from_config 按 TRANSFORMER_IN_FEATURE 推导解码器输入通道数，并经 build_pixel_decoder / build_transformer_decoder 注入子模块。layers 主链路固化两条接口契约：pixel decoder 须实现 forward_features 并返回三元组——mask_features 为 1/4 分辨率逐像素嵌入，multi_scale_features 依次为 1/32、1/16、1/8；predictor 以 (x, mask_features, mask) 形式被调用，第一参数 x 由 transformer_in_feature 四路分派（multi_scale_pixel_decoder 为 v2 默认，须配 MultiScaleMaskedTransformerDecoder；transformer_encoder 须配 TransformerEncoderPixelDecoder，否则前向断言失败）。最后是 `_version = 2` 的 _load_from_state_dict 迁移钩子：加载 MaskFormer(v1) 旧权重时自动把 key 挪入 pixel_decoder 前缀（predictor 除外）并将 static_query 改名 query_feat，实现旧 checkpoint 免重训加载。
