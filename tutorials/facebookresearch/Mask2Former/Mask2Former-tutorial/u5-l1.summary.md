本讲精读 matcher.py 中的匈牙利匹配器 HungarianMatcher：mask classification 范式输出固定 Q 个 query 预测而每图 GT 数量不定，须先解 LSAP（线性分配问题）做一对一匹配，未匹配 query 视为 no-object，匹配对预测集合排列不变。代价矩阵由分类（softmax 负概率近似 NLL）、mask BCE、Dice 三项加权合成（COCO 全景 2.0/5.0/5.0），后两者由 batch_sigmoid_ce_loss 与 batch_dice_loss 经 einsum("nc,mc->nm") 批量生成 (Q, M) 成对矩阵。主流程 memory_efficient_forward 逐图执行：所有 mask 共享一组归一化随机采样点（point_sample，K=12544），化解 1/4 分辨率预测与全尺寸 GT 的分辨率差异；@torch.no_grad() 不建计算图，autocast 关闭并强制 fp32 防止匹配抖动。深监督下每层 decoder 输出独立重新匹配一次，匹配权重与损失权重共用同一三元组，下一讲的 SetCriterion 是其唯一调用方。
