本讲精读仓库唯一的自研评估器 InstanceSegEvaluator：它继承 detectron2 的 COCOEvaluator，仅覆写 _eval_predictions 一个方法，生命周期与 COCO json 转换全部复用父类，只在 ADE20K/Mapillary 全景数据集且开启 INSTANCE_ON 时创建。核心结论有二：其一，覆写的硬理由是类别 id 反映射校验——全景注册用全集枚举构造 thing 到连续 id 的映射，值域稀疏不从 0 开始（ADE20K 为 7~149），原生实现的密集区间断言必然失败，覆写改为宽松的成员检查；其二，mask 分类范式没有真实框，pred_boxes 为全零占位，bbox 指标无意义，读指标只看 segm 表。本讲引入的关键术语：mask IoU、RLE 编码、PR 曲线与 101 点插值、AP/AP50/AP75、面积分桶 APs/APm/APl 与 AR、数据集原始 id 与模型连续 id 双空间及 reverse_id_mapping 反映射、输入契约四字段（硬二值化 mask、占位框、决定排序的重打分 score、待反映射的 pred_classes）。
