本讲拆解视频侧数据管线。load_ytvis_json 把「一条标注即一条贯穿全视频的轨道、缺帧处为 null」的 YTVIS json 解析成标注按 [帧][实例] 嵌套的视频 dict，类别 id 映射为连续、轨道 id 原样保留。YTVISDatasetMapper 训练时在参考帧窗口内有放回采 T 帧（推理取全帧），以 clip_frame_cnt 计数器实现 clip 一致增强；核心是跨帧行对齐：槽位表加 dummy 标注（id=-1、类别取 num_classes、空 mask）使每帧 Instances 恒 N 行、同行同轨道，空实例仅置 gt_ids=-1 不删行，prepare_targets 据此按行堆出 (N,T,H,W) 时空管道，gt_ids 即「一个 query 一条 tube」监督信号的跨帧关联来源。ytvis_annotations_to_instances 与 CocoClipDatasetMapper 属 IFC 遗产件、主流程未调用；builtin 注册六个 ytvis 子集（val 对应 valid/ 目录），测试加载器恒 batch=1。
