本讲精读 per_pixel_baseline.py 中的两个对照基线头，它们是论文为隔离 mask classification 范式收益而搭的控制变量阶梯：PerPixelBaselineHead 在共享像素解码器的 mask_features 上用静态 1×1 卷积做逐像素分类，损失为 head 内置的全分辨率交叉熵（先×4 上采样），训练返回 (None, losses) 二元组；PerPixelBaselinePlusHead 删除该卷积，换装 StandardTransformerDecoder 且 mask_classification=False，分类核改为「query 经三层 MLP 与 mask_features 点积」的动态核，须设 Q=K，深监督产生 loss_sem_seg 与 loss_sem_seg_i 系列键。mask_classification=False 的落点是：不建 class_embed、无 no-object 通道、输出与 aux 仅含 pred_masks，v1 解码器 query 从全零出发且层数不减一。接线结论：基线头的二元组契约与 MaskFormer meta arch 的 dict 契约不兼容，须配 detectron2 的 SemanticSegmentor，GT 取自 dataset dict 的 sem_seg 键（由 mask_former_semantic mapper 产出，同一数据管线兼服务两种范式）。三个头共用 build_pixel_decoder 工厂保证解码器受控，仓库未附带现成基线配置。
