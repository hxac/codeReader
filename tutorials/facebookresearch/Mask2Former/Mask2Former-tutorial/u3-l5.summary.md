本讲拆解 Mask2Former 默认像素解码器 MSDeformAttnPixelDecoder 的数据流：res3/4/5 经 input_proj（1×1 卷积+GN，按 res5→res3 顺序构建）拉齐到 256 维，送入六层多尺度可变形注意力 encoder——每个 query 仅在参考点附近跨尺度采样少量点，复杂度从 O(N²) 降为 O(N·L·K)；三个尺度被展平拼接成一条扁平序列，用可学习的 level_embed 注入尺度身份，spatial_shapes 与 level_start_index 负责切分记账。encoder 输出经 torch.split 还原为 2D 后，由 extra FPN 补足高分辨率：num_fpn_levels = log2(min_stride)−log2(common_stride)，默认配置下等于 1，即只补 res2 一层而非两层。forward_features 全程禁 autocast 并转 fp32（可变形注意力不支持半精度），最终兑现三元组契约：(1/4 的 mask_features、1/32 的 out[0]、按 1/32、1/16、1/8 排列的 multi_scale_features)，默认 multi_scale_pixel_decoder 模式下第二项无人消费。另提醒三个坑：encoder FFN 维度硬编码 1024，不受 DIM_FEEDFORWARD 配置影响；DEFORMABLE_TRANSFORMER_ENCODER_N_POINTS/N_HEADS 是无人读取的死配置；注意力头数实际取自 MASK_FORMER.NHEADS。
