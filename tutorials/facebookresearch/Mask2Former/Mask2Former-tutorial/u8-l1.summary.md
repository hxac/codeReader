本讲从「读」转向「写」，动手替换三段式架构中的 Backbone。三个最小模块：一是注册机制，类或工厂函数经 BACKBONE_REGISTRY 注册，且必须被 import 才生效——backbone 目录的新文件不会自动注册，需手动导入或补一行 import；二是接口契约，forward 返回特征名到特征图的字典、output_shape 上报通道数与 stride、size_divisibility 决定输入整除与批内 padding；三是适配器范本 D2SwinTransformer，双继承上游 Swin 网络与 Backbone 接口，只负责 cfg 翻译与元信息表维护。核心结论：注册后仅改 MODEL.BACKBONE.NAME 一行即完成切换；特征名须与 SEM_SEG_HEAD.IN_FEATURES 等消费方一字不差，错名在构建期抛 KeyError；沿用 res2..res5 命名可使 R50 下游配置零改动，接口命名的兼容性价值高于实现本身。综合实践实现 MiniCNNBackbone 并在 CPU 跑通完整模型前向。
