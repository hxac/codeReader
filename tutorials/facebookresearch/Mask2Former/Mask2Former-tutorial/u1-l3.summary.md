本讲俯瞰 Mask2Former 仓库组织，核心结论：它是 detectron2 插件式项目——引擎（配置系统、训练循环、分布式启动）全在宿主框架，仓库只含图像版包 mask2former、视频版包 mask2former_video、入口脚本 train_net.py / train_net_video.py、configs 配置库与 datasets 预处理脚本；根目录无 setup.py，源码原地使用。关键机制「import 即注册」：import 包即触发模块顶层语句，装饰器将 MaskFormer、D2SwinTransformer 等登记进 META_ARCH_REGISTRY、SEM_SEG_HEADS_REGISTRY、BACKBONE_REGISTRY 及项目自建 TRANSFORMER_DECODER_REGISTRY，数据集登记进 DatasetCatalog；漏 import 即报 Cannot find object。视频包是不引图像包的薄层，仅重写顶层模型、解码器、匹配损失与数据管线，复用靠入口脚本同时 import 两包。入口脚本三段式：setup 做多层配置叠加（get_cfg→add_deeplab_config→add_maskformer2_config→yaml→命令行，视频版再叠 add_maskformer2_video_config）、Trainer 子类覆写 build_* 方法接插件组件、launch 统一单多卡训练评估路径。
