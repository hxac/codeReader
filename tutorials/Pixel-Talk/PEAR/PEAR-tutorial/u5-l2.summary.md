本讲走读 PEAR 训练链路：train() 按配置→种子→设备→数据集→DataLoader→输出目录→模型→断点权重→主循环装配，`--ehm_model` 可加载 backbone/head 旧权重续训；OurPipeline 是普通类而非 LightningModule，借 Fabric + DDPStrategy(find_unused_parameters=True) 完成设备搬运、DDP 包装与 DataLoader 改造，optimizer 与 ViTPose 预训练权重须在 fabric.setup() 之前就位；run_fit 每步为 forward_step 前向（与推理同一份代码）→ EHM_v2 重建网格（梯度穿过）→ 双通道投影（DWPose 134 点按置信度门控、SMPL 44 点骨盆对齐，R/T 取自 pd_cam）→ 五项损失（dwpose_2d、smpl_2d、smpl_3d、param_smplx、param_flame）求和 → fabric.backward 反向。旁路为三联图可视化、run_val 仅渲染无指标、checkpoint 存 backbone/head/meta_cfg/global_iter。核心结论：学习率 1e-5、损失权重与各触发间隔全部硬编码，check_interval 与 loss_weight 是「读了没用」的死配置，forward() 是引用不存在属性的僵尸方法，读研究代码以「被谁调用」为准。
