本讲覆盖三个模块。依赖安装：conda 建 pear 环境，先装 requirements.txt，再单独以 --no-build-isolation 安装 pytorch3d 与 chumpy，因二者构建需复用环境内已装的 torch/numpy。资产约定：SMPL、SMPL-X、FLAME 受许可证保护须手动下载，放置位置由源码写死的路径决定——EHM_v2 将 assets/FLAME、assets/SMPLX 传给 FLAME、SMPLX 类，FLAME 模型须存两份；assets/SMPL 与 SMPLX2SMPL 仅训练链路使用，推理可暂缺。环境校验：app.py 顶部三连 import 分层探测 chumpy、pytorch3d 及编译扩展 _C，输出 All systems go 即通过；migrate_precompiled_packages 为 HuggingFace Spaces 预编译搬运方案，默认注释。脚本须从仓库根目录启动；网络权重 pear_model.pt 由 hf_hub_download 自动下载。
