本讲跑通 PEAR 的三个推理入口。核心结论：三者共享「读配置→建渲染器→下权重→建模型→前向→渲染→落盘」的组装套路，差异只在 256×256 人体 patch 的获取方式与落盘格式。inference_images.py 是唯一支持多人的入口：YOLOv8 检测（classes=0）后整图放大 2 倍、逐框裁剪推理并仿射贴回，产出 mesh_*.jpg 与按文件名序号合成的 video.mp4；inference_wo_detect.py 假设单人居中，用 pad_and_resize 整图入模，产出黑底纯网格 mesh_*.jpg 与 alpha=0.5 混合的 result_*.jpg；app.py 以 Gradio 做视频演示，截前 3 秒存入 uuid 会话临时目录（600 秒自动清理），对 body/flame/cam 参数做 Savitzky–Golay 平滑后输出浏览器友好的 mesh_video.mp4 与 results.npz（vertices 因收集语句被注释而为空）。引入术语：YOLO 检测、pad_and_resize、alpha 混合、Gradio、decord、会话临时目录。
