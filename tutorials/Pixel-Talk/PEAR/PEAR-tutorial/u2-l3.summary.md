本讲精读 inference_images.py，即 PEAR 唯一的多人推理入口，确立「检测框 → 归一化 patch → 推理 → 逆变换回贴」这一多人人体网格恢复的标准流水线。三个最小模块：其一，YOLOv8 检测（classes=0 只留人体、conf=0.5 为最重要可调参数），load_img 默认把图放大 2 倍，故输出图亦为原图 2 倍尺寸；其二，bbox 整形与仿射裁剪——sanitize_bbox 裁边并剔除退化框，process_bbox 以框中心为不动点先正方形化再外扩 1.25 倍以对齐训练裁剪分布，generate_patch_image 用三对点经 getAffineTransform 求出互逆的 trans/inv_trans，裁出 256×256 patch；其三，回贴即坐标系还原——1024 渲染图先缩回 256 与 patch 对齐，再用 inv_trans 做 warpAffine 贴回原图画布，布尔 mask（np.any>0）只覆盖网格像素、保留背景。关键术语：xyxy 与 xywh 两种框格式及互转、IoU 与 NMS（脚本内手写实现未被主链路调用）、重叠框场景后处理者覆盖先处理者的局限。
