本讲拆解 pose_transformer.py 的 TransformerDecoder：骨干特征图摊平成 192 个图像 token 作 K/V，零初始化 token 作 Query，经 6 层 TransformerCrossAttn 中的 cross-attention 汇聚成 (B,1024) 向量，交给下一讲的 9 个线性参数解码器。核心结论：零输入过线性层恒等于偏置，零 token 嵌入实为可学习常数（偏置加位置嵌入）；单 token 自注意力退化为逐点变换，cross-attention 是图像信息流入 token 的唯一入口。每层按 PreNorm 自注意、交叉注意、FFN 三段残差堆叠，FFN 等宽不扩张。引入术语：DropTokenDropout（整列删 token）与 ZeroTokenDropout（原位置零），PEAR 均未启用；context_list 逐层分发机制备而未用。解码器参数仅约 ViT 骨干 6%，重骨干轻解码。
