本讲精读 PEAR 的 ViT 骨干实现。PatchEmbed 用 kernel=stride=16、padding=2 的卷积把 256×192 人体 patch 切成 16×12 网格共 192 个 1280 维 token，padding=2 不改变 token 数，只让窗口左移并带来边界效应。Block 是 Pre-Norm 残差结构（多头注意力＋4 倍 MLP＋DropPath），共堆 32 层，DropPath 概率由 0 线性升至 0.55 且仅训练期生效。forward_features 加长度 193 的可学习位置编码（192 个 patch 槽＋1 个 cls 槽，cls 槽广播加到全部 token，以兼容 ViTPose 预训练权重），末尾把 token 序列 permute＋reshape 回 (B,1280,16,12) 二维特征图交给解码头。该配置为 ViT-Huge 规模约 6.3 亿参数，权重来自 ViTPose 姿态预训练；frozen_stages/freeze_attn/freeze_ffn 三套冻结开关机制完备但配置未启用，骨干整体参与训练。关键术语：token、embed_dim、pos_embed、Pre-Norm、DropPath、多头注意力。
