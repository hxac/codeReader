本讲是手册收尾，主题为 PEAR 二次开发。核心结论：三个推理入口共享「装配→前向→重建→渲染」骨架，差异只在获取 256×256 人体 patch 的方式；链路可分需权重的感知段与纯资产驱动的重建段（EHM_v2、Renderer2），PEAR 因此可当库嵌入。检测器可替换：现役为 YOLOv8，models/vitdet 提供 detectron2/ViTDet 备选入口 build_detector。最优中间产物是参数级 npz 导出：14 个参数字段加 pd_cam、faces、meta，体积仅顶点级的 3.5%，保留再编辑能力；项目自带导出未打通。离线回放仅凭 npz 与 assets 即可重建渲染，无需网络权重，但光栅化仍需 CUDA。接入自有数据即按 webdataset 契约打 tar（图像加 annotation.pyd 多人标注），注意 dataset/__init__.py 引用缺失文件会致导入报错。
