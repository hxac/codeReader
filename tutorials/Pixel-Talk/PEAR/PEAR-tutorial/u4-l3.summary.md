本讲拆解推理链路唯一使用的 flame 版 lbs.py。经典 lbs 五步：shape blend 捏体型、由顶点回归关节、pose blend（posedirs 作用于 R−I，根关节除外）、batch_rigid_transform 沿 parents 树做前向运动学、蒙皮权重混合。核心结论：逐关节矩阵 A 的语义是「顶点平移到关节 rest 位置→施加全局旋转→加回 posed 位置」，T 是 A 按蒙皮权重的逐顶点混合；lbs_wobeta 与经典 lbs 数学等价，仅把 shape 化外移给调用方，支撑 EHM_v2「shape 化→FLAME 换头→蒙皮」两段式流程；lbs_get_transform 只返回 A 与 posed 关节，经无人调用的接口备而未用。警示：仓库三份 lbs.py 中，smplx 版同名 lbs 的 T/A 返回顺序与 flame 版相反，混用 import 会静默出错。本讲引入的关键术语：LBS、轴角与 Rodrigues 公式、齐次坐标、parents 关节树、前向运动学、蒙皮权重、逐关节/逐顶点变换矩阵 A 与 T。
