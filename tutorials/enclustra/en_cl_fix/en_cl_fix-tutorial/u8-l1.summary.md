本讲是验证单元首课，只讲 cosim 的 Python 一侧（生成黄金参考）。核心结论：cosim 指用 Python 参考模型算出黄金参考、写盘后由 VHDL testbench 逐位对拍，是 en_cl_fix 证明三语言 bit-true 的手段。关键工具 `cosim_utils.py` 中，`get_data` 用 `min/max_value→整数区间→from_integer` 穷举某格式全部取值；`repeat_each_value`(F 序) 配 `repeat_whole_array`(C 序) 生成笛卡尔积，顺序为「b 外 a 内」。模板 `cl_fix_add/cosim.py` 嵌套穷举 `(a_fmt,b_fmt,r_fmt,rnd,sat)`，用 `cl_fix_add` 算黄金参考，顺手做 NarrowFix/WideFix 自检，并把 `get_data` 等无关循环外提优化。`data/` 下四类文件约定：`test{N}_output.txt`（非归一化整数）、`a/b/r_fmt.txt`、`rnd.txt`/`sat.txt`，同一行 i 描述同一用例。最关键的设计是「只存输出不存输入」：输入靠两侧用同一计数规则重生成。两个隐式契约须警惕——输入重生成顺序须对齐、枚举码往返依赖 Python `.value` 与 VHDL `'val` 位置一致。VHDL testbench 与 VUnit 调度留给 u8-l3、u8-l2。
