本讲讲解 en_cl_fix 的 MATLAB↔Python 桥接。每个 `cl_fix_*.m` 都是极薄转发壳，统一骨架为「记录形状 → `mat2py`/`wide.mat2py` 入方向转换 → 调用 `py.en_cl_fix_pkg.cl_fix_*` → `wide.py2mat` 出方向转换 → 还原形状」；算法仅 Python 一份实现，三语言因此天然 bit-true。`FixFormat`/`FixRound`/`FixSaturate` 等元数据以**对象引用**（非序列化）原样透传，`cl_fix_format` 用 `int64()` 保证类型正确。数据分两条通道：**narrow**（≤53 位，`float64`↔`double`，第三方 `mat2py`/`py2mat`）与 **wide**（>53 位，`object int`↔`fi()`），由 `wide.m` 用 `cl_fix_is_wide` 分流。wide 通道核心是 `matlab_interface.py` 的 `to/from_uint64_array`：把任意精度整数切成 ⌈w/64⌉ 段 uint64，用补码取模（打包 v+2^w、解包 u-2^w）做符号位重解释，段沿末维堆叠；该通道依赖 MATLAB Fixed-Point Designer 工具箱，narrow 不需要。
