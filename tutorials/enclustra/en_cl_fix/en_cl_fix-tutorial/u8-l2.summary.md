本讲精读 `sim/` 目录下三个构成验证「控制层」的 Python 文件。`common.py` 是验证地基，import 即执行：它通过 pip 的 `vunit-hdl` 加载 VUnit，扩展 `--simulator` 等命令行参数并校验，按仿真器归一出 `vhdl_standard_rtl` 与 `vhdl_standard_tb`（GHDL/NVC 下 RTL、TB 均 2008；Modelsim/Questa 下 RTL 93、TB 2008），并提供 `post_run` 覆盖率合并回调。`run.py` 是总调度，把 RTL、en_tb 扩展、testbench 按各自 VHDL 标准编入 `lib` 库，为 11 个运算 TB 注册 test 配置，其中 round/saturate/resize 用「一个 test + 多 config」展开 `meta_width_g` 取 0/8。核心是 `pre_config` 钩子：它在每个 test 仿真前调用对应 cosim 的 `run()`，把 u8-l1 的 Python 黄金参考生成与 u8-l3 的 VHDL 逐位对拍缝合成因果链。`cosim_runner.py` 是线程安全的「只跑一次」单例，用双重检查锁 + 自禁用保证每个 cosim 脚本在一整轮仿真里最多执行一次，避免并发争写 `data/` 目录；并用全局锁加临时改 `sys.path` 安全加载多个同名 `cosim.py`，`run()` 必须返回 True 否则 VUnit 视为失败。`--disable-cosim` 可让所有 `run()` 走快速路径跳过参考生成。一次仿真时序为：import common → create_test_suite → 编译 → pre_config 生成黄金参考 → TB 对拍 → post_run 收尾。
