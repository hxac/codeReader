本讲是单元 1 收尾课，目标是把 en_cl_fix 学习环境跑起来，不深入定点算法本身。它覆盖四个最小模块：一是依赖管理，`requirements.txt` 用 `==` 钉死 `numpy` 与 `vunit-hdl` 精确版本（README 另给最低门槛），`pip install -r` 一键安装；二是 Python 的 **unittest 风格测试**（`en_cl_fix_pkg_test.py`），靠人工挑选用例、`assertEqual` 逐条断言、`unittest.main()` 驱动，注意其路径 `sys.path.append` 相对 CWD，须在测试目录内运行；三是**穷举对拍测试**（`cl_fix_round_test.py`，本讲主实践），枚举所有取值，将待测函数与 WideFix 路径及 numpy 独立参考实现逐位比对，三份实现两两相等才算通过，能跑到 `Completed N tests.` 即代表零失败，其路径用 `dirname(__file__)` 故可从任意目录运行；四是 MATLAB 测试，`matlab_example.m` 经 MATLAB Python 接口调用同一份 `en_cl_fix_pkg`，再用原生算术自检。核心结论：两类 Python 测试跑通即标志环境就绪；MATLAB 侧仅是薄包装，三语言共享同一算法因而天然 bit-true。本讲引入的关键术语有：依赖钉死、穷举对拍、NarrowFix/WideFix 双路径、七种 FixRound 舍入模式、`cl_fix_constants` 简写常量，以及 `FixFormat/FixRound/FixSaturate` 三大类型——后者将由后续讲义系统展开。
