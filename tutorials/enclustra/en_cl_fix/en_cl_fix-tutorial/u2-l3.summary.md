本讲精读可综合 VHDL 包 `en_cl_fix_pkg.vhd` 的头部，呈现其类型与函数签名，它是 Python `en_cl_fix.py` 的 VHDL 镜像。核心类型有三：`FixFormat_t` 为三字段 record（`S` 限 0/1，`I/F` 为不受限 `integer`），与 Python 的关键差异是 VHDL 类型层不强制 `I+F>=0`，校验责任落在函数体断言；`FixRound_t`（7 种）、`FixSaturate_t`（4 种）与 Python 逐字对应；`RegisterMode_t` 是 VHDL 专属，控制 RTL 寄存器插入。哨兵常数 `NullFixFormat_c=(0,0,-1)` 表示「未指定结果格式」，使算术函数实现「缺省即全精度 mid_fmt」。头部函数分四类：Format Functions（纯格式/位宽计算，如 `cl_fix_width`、`cl_fix_add_fmt`，可编译期求值）、Type/String Conversions、Rounding and Saturation（round/saturate/resize，约定 resize 先 round 后 saturate）、Math Functions（统一三段式：mid_fmt→运算→resize）。函数普遍带默认值（`round:=Trunc_s`、`saturate:=Warn_s`），仅 `cl_fix_shift` 的 `result_fmt` 无默认值。本讲只讲签名，算法实现留待后续单元。
