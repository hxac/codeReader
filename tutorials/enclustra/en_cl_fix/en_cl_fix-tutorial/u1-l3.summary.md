本讲是 en_cl_fix 的结构导航课，不涉及定点算法。顶层目录按「一个算法、三种语言、四类产物」划分：`hdl/`（可综合 RTL，VHDL-93）、`bittrue/models/`（Python/MATLAB 参考模型）、`bittrue/cosim`＋`tb/`＋`sim/`（协同仿真与验证，VHDL-2008）、`lib/en_tb/`（内嵌通用 testbench 库）；同一运算名横跨多个目录，对应三语言 API 同构。术语 bit-true 即位级精确的软件参考模型。Python 包 `en_cl_fix_pkg` 以 `__init__.py` 的 `from .xxx import *` 做门面导出，聚合五个子模块：en_cl_fix_types（定义 FixFormat/FixRound/FixSaturate）、NarrowFix（≤53 位快速表示）、WideFix（任意精度）、en_cl_fix（cl_fix_* 主接口，在 narrow/wide 间分发）、matlab_interface（MATLAB 桥接）。`sim/run.py` 是验证驾驶舱，用 VUnit 编译 en_tb、lib 两个库，经 pre_config 钩子把每个 testbench 与对应 cosim 脚本缝合成「Python 写黄金参考文件 → VHDL 读文件对拍」的闭环；cosim_runner 用线程锁保证每个 cosim 整轮只跑一次。
