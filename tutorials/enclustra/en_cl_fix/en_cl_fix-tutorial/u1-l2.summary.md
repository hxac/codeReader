本讲建立 en_cl_fix 定点数的表示直觉，核心是 `[S, I, F]` 格式：S 为符号位（取值 0 或 1，1 即二进制补码），I 为整数位，F 为小数位，总位宽恒为 `S+I+F`（不可为负）。比特换算成数值依靠「位权（bit weight）」：小数点左侧整数位权重为 2 的非负幂、右侧小数位为 2 的负幂，通式 `w_k = 2^(k-F)`，有符号数的符号位权重为 `-2^I`。关键等价直觉：定点值 = 把比特当普通整数看、再乘比例因子 `2^-F`（README 示例 `1111110011100011` 在 `[0,11,5]` 下即 `64739/32 = 2023.09375`）。`I`、`F` 均可为负，表示小数点落到物理位之外、出现隐含为零的缺失位，改变粒度与表示范围但不影响位宽算法。最后点明格式迁移的两类处理：`F` 变少需舍入（7 种模式，差别仅在平局取舍），`I`/`S` 变少需饱和（4 种模式：回绕、钳位或告警）；二者实现细节留待单元 4。本讲验证仅用 `cl_fix_width`、`cl_fix_from_integer`、`cl_fix_to_real` 三个 Python 函数，不涉及任何算法实现。
