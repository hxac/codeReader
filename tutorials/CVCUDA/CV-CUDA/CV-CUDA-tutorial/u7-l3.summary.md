本讲剖析 bench/ 双语言基准体系：C++（nvbench）与 Python（cuda.bench）逐算子成对镜像，共用一份 bench/config JSON 配置（含轴、预热次数与内嵌 SKU 基线），关键概念是 config_key、tier、SKU 与基线。run_bench.py 测前锁 SM 时钟以消除频率漂移，输出 GPU Time、GPU Noise、BWUtil、Py overhead 等指标；质量门禁集中于 _internal/quality.py：噪声<10%，C++/Python 性能对齐（parity）相对差<10% 且绝对差<100µs，Python 明显偏慢通常指向绑定层缺陷。Python 基准是三段式模板（setup→run 闭包→注册），run 段只含一次 `_into` 调用且必须提交到 nvbench 的计时流；perf_utils 的 CvCudaPerf 属样例管线 NVTX 体系，与本基准是两套体系。预热由 WarmupPolicy 与 warmup.py 双语言同构实现，环境变量 CVCUDA_BENCH_WARMUP_CAP 统一封顶。compare_to_baseline.py 将运行 JSON 与仓库内 A100/H100 基线逐行比对，五类异常（回归、意外改进、缺失、新增、缺 SKU）任一非空即判失败，「变快也失败」用于逼出过期基线。
