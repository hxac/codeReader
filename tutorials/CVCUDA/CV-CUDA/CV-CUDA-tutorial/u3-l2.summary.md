本讲承接 u3-l1 的四连函数套路，把视野从单个算子扩展到算子族。核心结论：61 个 Python 算子按功能分族记忆——几何、色彩、像素值调整、滤波、归一化、统计、增强、批操作、融合九族，权威清单在 Operators.hpp 的导出声明。重点讲三个逐像素算子：cvtcolor 只给转换码即自动推导输出的格式、形状与位深；brightness_contrast 是一条仿射公式，参数分标量、单元素张量、N 元素张量三形态（N 个即逐图一套参数），输出 dtype 可与输入不同；normalize 输出与输入同形同 dtype，须先 convertto 转 float，SCALE_IS_STDDEV 标志把 scale 解释为标准差。最后引入各算子 C 头中的 Limitations 契约表（布局、通道、dtype、输入输出依赖、后端），它是支持矩阵的唯一权威，写管线前先查表。关键术语：逐像素算子、色彩空间、转换码、位深继承、广播规则。
