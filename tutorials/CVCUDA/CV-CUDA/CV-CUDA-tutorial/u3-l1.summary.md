本讲从数据类型层进入算子层，以 resize 与 flip 讲解 CV-CUDA 算子的通用套路：绑定层每个算子是「四连函数」（Tensor/变长批 × allocating/_into 两种变体），同名注册、按参数类型重载决议；变长批入口中可逐图变化的参数升级为张量（如变长批版 flipCode）。resize 输出形状由调用者指定，dtype 与 layout 继承输入；样例 read_image 恒返回 RGB8 的 HWC 张量。关键术语：cvcuda.Interp 为全库共享插值枚举，resize 实际支持 NEAREST/LINEAR/CUBIC/AREA，默认 LINEAR；flipCode 与 OpenCV 完全兼容（0 上下翻、正数左右翻、负数双轴）；C 头文件的 Limitations 契约表是各算子支持矩阵的权威来源；priv 层先校验后执行，LINEAR 插值要求源图至少 2x2，因双线性需 2x2 采样邻域。
