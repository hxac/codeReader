本讲剖析 CV-CUDA 临时内存的安全复用机制，覆盖四层：公开 API 的 `cvcuda::Workspace` 定义了 host/pinned/cuda 三通道临时缓冲模型，每块内存附带 `ready` 事件，契约是“用前在使用的流上等待、排完所有工作后记录”（pinned 用 `cudaEventSynchronize` 在 CPU 侧等，cuda 用 `cudaStreamWaitEvent` 在流上等）。Python 绑定层的 `WorkspaceCache` 提供每设备单例与 `WorkspaceLease` 租约语义，作用域结束自动归还复用权。C++ 侧 `PerStreamCache` 是核心算法：`put` 时用 `cudaEventQuery` 分流，未就绪进本流桶、已就绪进全局池；同流复用因流序天然安全而零同步，跨流必须事件确认；查找采用 best-fit（优先最小够用块）。基础设施包括 `SimpleCache`、`EventCache`、带禁计时标志的 `CudaEvent` 与 `StreamId`。核心结论：`ready` 事件必须记录在最后使用者所在流上且位于其工作之后——晚记只损失复用效率，早记会导致概率性数据竞争。
