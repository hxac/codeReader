本讲覆盖三个模块：安装通道与兼容性、hello_world 六步流水线、数据落点追踪。核心结论：Python 用户用 pip 安装 wheel（cvcuda-cu12 或 cvcuda-cu13）即获得 C++/CUDA 库与 Python 绑定；cu12/cu13 包不可共存，切换须先卸载，且 samples 目前仅官方支持 CUDA 12。hello_world.py 由 nvimgcodec 负责解码/编码，CV-CUDA 负责 resize、stack 批合并、gaussian 模糊与 zero_copy_split 拆批；像素全程留在 GPU 显存，CPU 只经手压缩字节流。引入的关键术语与概念：venv、as_tensor 零拷贝纳管、`__cuda_array_interface__`、stride（切批须用真实行距否则图像错位）、HWC/NHWC 布局、gaussian 的 kernel 尺寸与 sigma 参数、allocating 变体（隐式分配输出并提交到当前流）。
