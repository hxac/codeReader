本讲解剖 CV-CUDA 的 Python 绑定层（`_cvcuda` 模块），是 mkop 脚手架中 PythonBinding 文件的精读。核心结论：把 C++ 算子暴露为 `cvcuda.xxx` 需「三站接线」——绑定文件定义 `ExportOpXxx`、Operators.hpp 声明、CMakeLists 登记并由 Main.cpp 调用，漏站分别导致链接错误或静默缺失。绑定骨架是「四连函数」（allocating / `_into` × Tensor 批 / 变长批），函数体五步套路：流兜底、`CreateOperator` 取缓存算子、建 ResourceGuard、按 READ/WRITE/NONE 三档登记锁、`guard.run` 提交（同步屏障必须先于 kernel）。Main.cpp 类型区有两条顺序约束：基类先于派生类注册、被方法签名引用的 pybind11 类型先注册，循环依赖用「主体 + 延迟补挂」拆解，算子导出彼此无序。关键术语：PyOperator 包装类（`submit` 转发至 C++ 算子的 `operator()`）、算子对象缓存以构造参数为键、NvtxTrace 签名保持包装、CreateSameShapeImageBatch 变长批输出重建。综合实践为假想算子 invert3 手写完整绑定并接入三站。
