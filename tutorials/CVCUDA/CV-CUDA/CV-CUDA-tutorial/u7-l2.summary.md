本讲解析 CV-CUDA 的 Python 测试体系：`tests/cvcuda/python` 扁平目录中每算子一个 `test_op*.py`，辅以造数据、造测试、存类型全集三个基础设施模块，包装脚本另做依赖探测与符号卫生检查。核心结论：手写算子测试只断言元数据契约（形状/布局/dtype/批属性/`_into` 原样返回 dst），数值正确性由 C++ 系统测试的黄金参考负责，两套互补分工。关键机制是 `make_op_tests` 契约矩阵工厂：正例取支持集笛卡尔积，负例取全集差集并以基石三元组为基线一次只变一维，经 `globals().update()` 动态注册进 pytest，仅验证输入契约。白盒观测点集中于无兼容承诺的 `cvcuda.internal`（只读观测）与 `cvcuda._test`（故障注入）子模块，与公开 API 划清界限；带数值断言的官方范本是 remap 变长批测试的逐图 cpu() 读回比对。
