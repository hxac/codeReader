本讲以 cvcuda.flip 为例打通 CV-CUDA 算子的四层链路：①Python 绑定层做 pybind11 重载决议、输出分配、流兜底与资源记账；②C API 以 extern "C" 函数为界碑，公开 C++ 类仅内联转发；③priv 层用 exportData 把张量导出为 CUDA 视图，判空即拦截非显存数据；④legacy kernel 先校验 dtype、布局、通道，再按 dtype×通道查分派表发射 kernel。核心结论：C ABI 是异常不能穿越的界碑，异常与状态码经 ProtectCall/CheckThrow 互译；不透明句柄由 RAII 的 OperatorHandle 持有并经 dynamic_cast 还原类型；链路上有三个同名 Flip 类，分属公开、priv、legacy 三个命名空间。引入术语：不透明指针、RAII、pybind11、NVTX、exportData、分派表、NIX/VEC 访存优化。
