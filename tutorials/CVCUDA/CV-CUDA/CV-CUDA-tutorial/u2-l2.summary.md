本讲剖析 nvcv 类型层的两块基石。DataType = DataKind × Packing，只描述元素的位级信息：占多少位、通道如何切分、按什么数解释，字节数按位数向上取整到整字节，实现上是单平面 ImageFormat 的特例。ImageFormat 在其上叠加图像语义：颜色模型与颜色规范、色度子采样、内存布局（pitch/block-linear）、swizzle 通道顺序、多平面结构与 alpha 语义。核心结论：Y8 与 U8 内存相同而语义不同（Y8 为 BT601 有限值域亮度）；RGB8 与 BGR8 仅 swizzle 有别；交错格式推断为 NHWC，平面格式（p 后缀）推断为 NCHW，dtype 取 planeDataType(0)；NV12 因色度子采样且双平面分辨率不一而无法转 Tensor；as_image 须显式补格式而 as_tensor 丢语义即可。Python 端 cvcuda.Format 是脚本自动生成的枚举，cvcuda.Type 以 numpy dtype 面貌呈现且哈希一致。DataKind、Packing、Swizzle、平面、色度子采样等关键术语将由后续变长批处理与 DLPack 互操作讲承接。
