本讲以 Flip 为样本剖析 CV-CUDA 的 C++ 系统测试，覆盖五个模块：run_tests.sh 驱动机制（构建期由模板生成，标签按「与」语义过滤，附句柄泄漏检测）；NVCV_TEST_SUITE_P 参数化框架（ValueList 值表、UniqueSort 去重排序、MD5 后缀使测试名与参数强绑定）；CPU 黄金参考 FlipCPU（独立三重循环、字节级 stride 寻址）；四类用例（Tensor 正例、变长批正例、planar 奇偶校验、负例）；TestAPI 头文件兼容性模板测试。核心范式是五段式「固定种子随机数据→CPU 金标→GPU 算子→逐字节比对」。关键结论：值表应逼近 Limitations 契约表；新增 dtype 必须同步扩展金标，否则金标 default 分支静默漏配会造成「金标全零」的假失败；负例借 ProtectCall 断言返回 NVCV_ERROR_INVALID_ARGUMENT；planar 奇偶守护 NCHW/NHWC 双布局不变量。
