本讲以 Flip 为例，讲解不经 Python、用 C++ 类与纯 C API 直接调用算子。核心结论：每个算子都有 .h（纯 C 接口）与 .hpp（C++ 类）两份等价定义，C ABI 是最稳定的公共契约，C++ 类只是 C API 的零逻辑薄糖，两份文件可互相推导。C 侧为句柄式手动生命周期：Create 拿句柄、Submit 提交到流、nvcvOperatorDestroy 销毁，错误仅经 NVCVStatus 返回码传递；张量则是引用计数式（IncRef/DecRef），两种模型不可混淆。C++ 侧靠 RAII 全自动：失败抛 nvcv::Exception，析构恰好销毁一次，拷贝删除、移动转移防双重销毁。关键术语：不透明句柄、extern "C" 与 C ABI、ProtectCall/CheckThrow 的异常与错误码互译、TensorWrapHandle 非持有包装、ToDynamicRef 类型校验、Limitations 支持矩阵。流语义铁律：算子可在同步前析构，张量释放必须等流同步之后。
