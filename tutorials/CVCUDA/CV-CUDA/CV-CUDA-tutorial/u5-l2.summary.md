本讲聚焦 priv 实现与 CUDA kernel 之间的数据交接。核心机制是 `exportData`：把重量级 `nvcv::Tensor` 提纯为不拥有内存的 POD 视图（basePtr + 字节 stride + 元数据），再按 `bufferType` 标签 `cast` 成 `TensorDataStridedCuda`，唯一失败出口是标签不匹配返回 `NullOpt`，priv 层判空后抛 `ERROR_INVALID_ARGUMENT`，当前属防御未来缓冲形态的闸门。`TensorDataAccess` 三层访问器按布局标签（而非数字下标）查维、缺失维度 stride 归零，以 `sampleData/rowData/chData/planeData` 提供安全寻址，Planar 访问器同时兼容 NHWC 与 NCHW，是双布局支持的落点。kernel 侧由轻量 `TensorWrap` 接棒，设备端 `ptr(n,y,x)` 一行完成寻址，窄位 StrideType 是性能取舍。变长批 `ImageBatchVarShape::exportData` 需 stream 参数：导出会入队脏段 H2D 拷贝与 event 栅栏，脏区间机制使同批重复导出开销趋近于零。
