本讲为入门第一讲，四个模块：项目定位与场景、平台兼容矩阵、仓库目录地图、分层架构。核心结论：CV-CUDA 是 NVIDIA 开源的 GPU 加速视觉算子库，将 AI 管线中的预处理/后处理从 CPU 搬到 GPU，主打高吞吐低延迟，支持批处理与融合算子；兼容 x86_64/aarch64/WSL2、CUDA 12.2+ 与 13.x（cu12/cu13 双包不可共存）、SM7.5+、Python 3.10–3.14。代码分四层：Python 绑定（python/mod_cvcuda）→ C API → C++ 私有实现 → CUDA kernel（后三层在 src/cvcuda），nvcv 是贯穿各层的数据类型层（Tensor、ImageBatch），「数据与操作分离」是理解本仓库的钥匙；一次 cvcuda.resize 调用即沿此链穿越约 7 个文件。引入术语：算子、张量、pybind11、C ABI 句柄、cudaStream 流、变长批、DLPack、Limitations 支持矩阵、ResourceGuard 读写锁。
