本讲为执行模型单元首讲，确立 CV-CUDA 的流执行模型：一切算子都异步提交到流上。① cvcuda.Stream() 创建非阻塞流，Stream.default 包装 legacy 0 号流，Stream.current 取自每线程流栈，with 压栈/弹栈切换当前流；② 算子 stream= 参数缺省由当前流兜底，此后原样穿透绑定层、C API、priv 实现直至 kernel 启动第四参数，中途不偷换不同步；③ C++ 侧 CudaStream 是纯 RAII 句柄封装（save-set-restore 设备切换），无缓存无流栈；④ 跨流安全三层：手工 wait_stream（只约束已入队工作）、ResourceGuard 自动记账（kernel 前插事件等待，同流零开销快路径，跨设备或默认流哨兵退化为全设备同步）、CAI stream 字段协议。关键术语：非阻塞流、当前流、每线程流栈、ResourceGuard、syncThrough。
