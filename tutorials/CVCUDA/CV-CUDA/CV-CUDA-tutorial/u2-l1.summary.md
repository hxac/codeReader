本讲讲 CV-CUDA 数据类型层（src/nvcv）的三个模块：Tensor 本体、TensorShape/TensorLayout、stride 内存布局。核心结论：cvcuda.Tensor 是位于 GPU 显存、按 strided 寻址的 N 维数组，携带 shape/dtype/（可选）layout；数据永远在 GPU 上；不传 layout 时为 NONE（不猜测），由图像格式创建时交错格式如 RGB8 推得 NHWC、平面式推得 NCHW。TensorShape=Shape+TensorLayout，构造时强制秩一致；六个标签 N/C/F/D/H/W 是全仓库通用的维度语言，`find('C')` 等查询是算子同时支持 HWC/CHW 双布局的基础。需辨析：TensorLayout 管“维度是什么”，DataLayout.hpp 的 Packing/Swizzle 管“一个像素的位如何打包”，是两套体系。stride 以字节为单位，地址公式 addr=basePtr+Σi_d·s_d；行距默认对齐到设备纹理对齐属性（通常 32 字节），因此张量常是非紧凑的，跨框架传数据必须尊重真实 stride；as_tensor 只接受 CUDA 可访问的 buffer，并在元素/字节 stride 之间换算。
