本讲是第二单元收官，讲 CV-CUDA 与 Python 生态的零拷贝互操作，分四个模块。入口“三座桥”：pybind11 为 ExternalBuffer 注册自定义 type_caster，as_tensor 按 CAI 优先、DLPack 兜底探测协议，皆不通则 TypeError。导入校验在 ExternalBuffer：设备须 CUDA 可访问（CPU 数组被拒）、dtype 最多 4 通道且可映射、CAI 字节 stride 须整除元素大小、秩在 1~15。零拷贝落地在 Tensor::Wrap：元数据抄入 NVCVTensorData、只登记不分配显存，引用链 Tensor→ExternalBuffer→原数组保证生命周期，包装张量进缓存仅为安全析构、从不复用。导出用 tensor.cuda() 返回双协议 ExternalBuffer，也不搬数据。关键术语：DLPack（stride 以元素计）与 CAI（以字节计）、DLTensor、生产者流记账 seedLastStream、包装张量 layout 默认为 None，均为 u4-l1 流模型的伏笔。
