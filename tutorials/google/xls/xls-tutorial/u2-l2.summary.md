本讲讲解 DSLX 前端如何把源码文本变为抽象语法树（AST），分四个模块。词法扫描：Scanner 将文本切成 Token 流，每个 Token 携带 TokenKind、Span 与载荷，u8/u32 等内置类型名被当作关键字而非标识符。递归下降解析：Parser 继承 TokenParser，靠「peek 前瞻分派 + drop 消费」驱动，每条语法对应一个 ParseXxx 方法；Bindings 以带 parent 的链表实现词法作用域。AST 节点统一继承 AstNode，分表达式（Expr）与非表达式两类，核心节点有 Function、Param、NameDef、StatementBlock、Let、Match，遍历用 AstNodeVisitor 访问者模式。Module 是顶层编译单元，用 ModuleMember variant 持有函数、测试、结构体、import 等成员，以保序向量与按名哈希表双重索引。关键设计：所有节点须经 Module::Make 创建，所有权集中于 Module::nodes_，节点间用裸指针互引。核心结论：let 左值是 PatternTree（含 TuplePattern），右值是 Expr，二者在 Let 节点汇合；解析产出的是无类型 AST，后续交类型系统处理。
