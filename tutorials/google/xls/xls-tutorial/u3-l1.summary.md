本讲建立 XLS IR 的静态心智模型：IR 是一套「数据流图（sea of nodes）+ 类型化值」的数据结构，前端到代码生成全程只此一套，便于分析与变换复用。它刻意弃用控制流图而采用扁平的 SSA 有向无环图，以契合硬件天然并行的本质。

三层包含关系为：Package 是顶层容器，以 unique_ptr 拥有 Function/Proc/Block、经 TypeManager 管理编译期 Type、持有 Channel、文件号表、节点 id 计数器，并标记唯一 top 实体；它不可拷贝，因函数内持有指回 Package 的父指针。真正「持有一堆 Node」的基类是 FunctionBase（Function/Proc/Block 同源，靠 Kind 区分），用 std::list 存节点以保证优化 Pass 增删时指针稳定；Function 仅额外多一个返回值节点。Node 是图顶点，靠 operands（入边）与 users（出边）这对对称指针表达数据依赖，携带 Op 标签与产出 Type，常见节点用 InlinedVector<2> 优化。

运行期数据用 Value 表示，内部以 std::variant 装 Bits 或 vector<Value>，分 bits/元组/数组/token 四类；Bits 是任意位宽的紧凑二进制串，符号性由运算而非自身决定。贯穿全讲的关键区分是：Type 是编译期「形状」，Value 是运行期「内容」，二者经 GetTypeForValue 桥接。
