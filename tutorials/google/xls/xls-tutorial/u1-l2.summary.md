本讲讲解如何从源码构建并运行 XLS。XLS 采用 Bazel 构建系统，版本由 `.bazelversion` 锁定，推荐用 Bazelisk 自动取版本；第三方依赖通过 Bzlmod（`MODULE.bazel`）声明，并注册自带 LLVM 工具链以摆脱系统编译器依赖，`WORKSPACE` 仅作工作区标识保留。构建前需安装 `python3-dev`、`libtinfo6` 及关键的 `python-is-python3`。构建范围分两种：DSLX-only（排除 xlscc，约 2 小时）与全量（含 xlscc，可达 6 小时）。单工具命令形如 `bazel build -c opt //xls/dslx:interpreter_main`，产物落在 `./bazel-bin/`。引入的关键术语包括目标（target）、构建规则（rule）、依赖（deps）、`-c opt`、`--config=ci`、disk cache 与远程缓存。`--version` 由 Abseil 内置标志配合 `InitXls` 注入的构建标签实现。另有 Docker 镜像与 GitHub Release 二进制两条免构建路径。本讲对应工具链四环节的 interpreter_main、ir_converter_main、opt_main、codegen_main 四个目标，为后续讲义逐段走通 IR 转换、优化、代码生成奠定基础。
