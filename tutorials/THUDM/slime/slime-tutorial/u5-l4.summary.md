本讲讲解 slime 如何通过 `megatron_server.py` 把 Megatron 模型「反向复用」成一个只读前向 HTTP 服务，对外提供 token 级对数概率与热加载权重能力。核心结论：这是 slime 把训练消费者临时充当推理生产者，用于在线策略蒸馏（OPD）的教师 logprob 提供方，模仿 SGLang 的服务契约以便替换推理引擎位置。

最小模块覆盖四块：一是服务端「只读不训」的参数约束（`configure/validate_megatron_server_args` 锁死优化器、KL、critic）；二是 `SampleManager` 作为 HTTP 层与 Megatron 工人之间的请求队列，用提交—轮询把同步语义解耦成异步分布式前向，`run_megatron_dp_models_loop_worker` 以 `MAX_INFLIGHT_BATCHES = pp_size+1` 双缓冲保持流水线满载；三是 `TeacherLogpRayActor.compute_logp` 复用 `forward_only`，在 PP 末段、`tp_rank0 & cp_rank0` 单点序列化、CP 下 `all_gather` 拼回；四是 `logprob_utils.py` 的两阶段 TP 感知采样与 label-token logprob，不物化全词表。

关键术语：反向复用、OPD、SampleManager、双缓冲流水线、TP/PP/CP 感知采样、`/generate` 与 `/update_weights_from_disk`（换权重期间互斥返回 503、coalesce 去重）。
