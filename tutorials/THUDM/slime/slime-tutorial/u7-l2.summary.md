本讲讲清 slime 如何让现成 agent 运行时（Claude Code/Codex）驱动训练：核心是**适配器（adapter）**这层 HTTP 中间层，契约为「消息进、采样 token 出」。它把 Anthropic/OpenAI 协议历史翻译成 chat-template 消息，调 SGLang `/generate`（`return_logprob=True`），直接捕获 `(logprob, token_id)` 而非重分词文本，以保证 on-policy 正确性。关键术语：`BaseAdapter` 用**模板方法模式**写死 `_run_turn` 一轮流水线，子类仅填 6 个钩子与 `max_token_keys`/`stop_keys` 类属性；`AnthropicAdapter` 与 `OpenAIAdapter` 互为镜像，差异在端点、字段名与 tool 参数形状；**回放一致性不变量**要求存入轨迹的 `manager_message` 与客户端回传消息按字典相等匹配，否则每轮 fork；`session_id` 经 `X-SMG-Routing-Key` 做前缀缓存亲和；`finish_session` 把会话树线性化成带 `loss_mask`、`rollout_log_probs` 与完整 reward 的可训练 `Sample`。
