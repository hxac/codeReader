本讲建立 slime 的全局认知。slime 是面向 RL scaling 的 LLM 后训练框架，提供两大核心能力：高性能训练（连接 Megatron 与 SGLang）与灵活数据生成（自定义接口 + server-based engine）。系统由三大模块串成闭环：rollout(SGLang+router) 写入含 reward 的 Sample → data buffer 作桥梁 → training(Megatron) 读取训练，训后将权重单向同步回 rollout（training→rollout，不可逆）。设计哲学为 Versatile/Performant/Maintainable：拒绝为每类任务 fork 多框架，而以可注入自定义逻辑的数据生成接口统一应对 math/tool/sandbox/multi-agent 等场景；采用 SGLang-native 单一 rollout backend，--sglang- 前缀透传 SGLang 参数、直接读取 Megatron 参数，使上游升级近乎零成本。slime 经 GLM 系列等生产验证，验证的是完整 post-training loop 而非孤立 demo。
