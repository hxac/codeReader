本讲讲解 slime RL 闭环中负责「算分」的奖励分发层 rm_hub。核心入口 `async_rm` 按三级优先级分发奖励计算：逐样本 `sample.custom_rm_path`（最高，来自 eval 数据集配置）→ 全局 `args.custom_rm_path`（命令行 `--custom-rm-path`）→ 按 `rm_type` 内置分发；`rm_type` 同样逐样本优先（`metadata["rm_type"]` 压过 `args.rm_type`），未指定则抛 `NotImplementedError`。内置 rm_type 含 `math`/`deepscaler`/`dapo`/`f1`/`gpqa`/`ifbench`/`remote_rm`/`random`，多为 0/1 二值规则奖励（相对大小经组内归一化即可产生有效梯度）。关键概念：`boxed_` 前缀先用 `extract_boxed_answer`（基于括号深度计数，取最后一个 `\boxed{}`）把 response 收窄到答案再判分；`get_deepscaler_rule_based_reward` 是思考型数学模型专用二值奖励，切 `</think>` 取正文，用 `grade_answer_mathd`（字符串归一化）`or` `grade_answer_sympy`（符号化简，含 `should_allow_eval` 安全护栏）双重判等，而 `math`（`grade_answer_verl`）判等逻辑相同但不切 think。自定义奖励有单样本 `rm(args, sample)->float` 与 batch `rm(args, samples)->list[float]`（`--group-rm`，把算分推迟到整组生成后，评估阶段被禁止）两种互斥签名；所有 `--xxx-path` 接口统一由 `load_function` 把 import 路径字符串解析成函数对象。奖励写回 `sample.reward` 后流向优势估计。
