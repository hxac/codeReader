本讲讲解 slime 如何用 `--sglang-config` 这份 YAML 声明式描述异构推理拓扑。配置呈三层结构（`sglang` → 模型 → server group），对应三个 dataclass：`SglangConfig`/`ModelConfig`/`ServerGroupConfig`。核心概念包括：`worker_type` 决定引擎角色（regular/prefill/decode/placeholder/encoder），`num_gpus_per_engine` 经 `tp_size = num_gpus_per_engine // pp_size` 决定张量并行大小，`overrides` 优先级最高。`resolve()` 实现两条回退链（GPU/engine、model_path）并按 model_path 是否等于 `hf_checkpoint` 自动推断 `update_weights`，区分被训练模型与冻结模型（ref/reward）。引入 PD 分离（prefill/decode）与 EPD（含 encoder 两阶段启动）拓扑。物化时每个模型挂一个独立 router（`force_new`），PD 模型置 `pd_disaggregation=True`，引擎靠上报 `worker_type`/`bootstrap_port` 让 router 分阶段路由；全局硬约束为各组 num_gpus 之和须等于 `--rollout-num-gpus`。自定义 rollout 函数可通过 `get_model_url` 按模型名寻址对应 router。
