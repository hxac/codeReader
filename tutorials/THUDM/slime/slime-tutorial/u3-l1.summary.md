本讲精读 slime 中贯穿 rollout 与 training 两大模块的核心数据载体 `Sample`（定义于 `slime/utils/types.py` 的 dataclass）。其字段按三段生命周期组织：prompt 类字段在数据源取出时写入；生成类字段（`tokens`/`response_length`/`loss_mask`/`rollout_log_probs`）由 rollout 阶段的 `append_response_tokens` 增量写入，并在训练打包/loss 阶段被读取；`reward` 由奖励模型写入、供优势估计使用。关键约定：`loss_mask` 用 1/0 区分模型生成 token 与工具/环境注入 token；`rollout_log_probs` 记录行为策略对数概率，用于 off-policy 重要性采样修正；`rollout_id` 在一次执行拆多段时保证兄弟段同源聚合。`Sample.Status` 是五态状态机（`PENDING→COMPLETED/TRUNCATED/ABORTED/FAILED`），由推理引擎 `finish_reason.type` 驱动，支撑 partial rollout 续传与中断处理。rollout 函数的整批产出统一封装为 `RolloutFnTrainOutput`（`list[list[Sample]]`，外层对应 prompt 组、内层对应 GRPO 同 prompt 多采样）或 `RolloutFnEvalOutput`（dict），由 `call_rollout_fn` 做兼容包装。
