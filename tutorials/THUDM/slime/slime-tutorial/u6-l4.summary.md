本讲精读 slime 的 RL 数学核心。`compute_advantages_and_returns` 作为总分发入口，由 `--advantage-estimator` 把六种算法（GRPO/GSPO/CISPO/PPO/REINFORCE++/REINFORCE++-baseline）路由到不同计算分支，并提供 `--custom-advantage-function-path` 逃生口。关键分水岭是是否需要 critic：仅 PPO 用价值网络做 GAE，其余靠组内相对或基线/折扣得到优势；GRPO 系的组归一化前置在 rollout 侧的 `_post_process_rewards` 完成。`compute_approx_kl` 实现 k1/k2/k3(low_var_kl) 三种 KL 估计，k3 非负低方差最常用，并支持 importance_ratio 无偏化（DeepSeek-V3.2 风格）。GAE 有数值等价的 vanilla（反向递归 O(T)）与 chunked（chunk 内并行扫描、chunk 间递归状态）两种实现。优势算完后还可叠加跨 DP 组的白化（`distributed_masked_whiten`）与 OPD 蒸馏惩罚两道工序。
