本讲剖析 train.py 操控的三大对象。actor_model 与 critic_model 是本地门面 RayTrainGroup（普通 Python 类），内部持有一组训练工人远程句柄并 fan-out 聚合；rollout_manager 是 Ray 远程演员 RolloutManager 的句柄，自身不占卡、靠内部 SGLangEngine 推理。关键约定：RayTrainGroup 中以 async_ 开头的方法（仅 async_train）返回 ObjectRef 列表且不阻塞，其余方法内部已 ray.get 返回同步结果；RolloutManager 所有方法都经 .remote() 返回单个 ObjectRef，阻塞与否由调用方决定。训练工人遵循抽象契约 TrainRayActor，唯一实现 MegatronTrainRayActor 经 actor_cls 注入；critic 默认复用 actor 同一批 GPU，靠 offload_train 时分复用。三对象靠两次握手协作：actor 向 rollout_manager 下发 train_parallel_config，决定数据按 dp_size 切分份数；工人上报 start_rollout_id 并对齐，决定从第几轮续训。
