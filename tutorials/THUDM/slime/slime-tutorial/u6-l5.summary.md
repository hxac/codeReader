本讲解决 RL 后训练中的 off-policy（离策略）偏差问题，覆盖损失层的自定义与修正机制。核心要点：slime 损失统一从 `loss_function` 按 `args.loss_type` 分发；`--loss-type custom_loss` 配合 `--custom-loss-function-path` 可整体替换损失函数（签名 `(args, batch, logits, sum_of_sample_mean) -> (loss, metrics)`），适合结构级改写而非在 PPO 上加项。关键概念是三套对数概率：当前策略 `log_probs`（带梯度）、训练引擎重算的 `old_log_probs`（PPO clip 锚）、SGLang 采样时记录的 `rollout_log_probs`（行为策略）。后两者偏差即 off-policy 偏差来源。**TIS（截断重要性采样）** 用两次 logp 之比 ρ=exp(logπ_old−logπ_rollout) 修正偏差，内置 `vanilla_tis_function` 截断后乘到 pg_loss，`--custom-tis-function-path` 可换 MIS（token/sequence/geometric 三粒度 + truncate/clip/mask）。**OPSM（序列级掩码）** 在「负优势 ∧ 序列 KL 超阈值」时整条清零，与 TIS 正交可叠加。**CISPO** 对 clipped ratio 做 stop-gradient 使被截断 token 仍有梯度（canonical 单边 clip），**GSPO** 把 token 级 KL 换成序列级以降方差。所有自定义经 `load_function` 解析，与框架解耦。
