本讲是定制化接口的导览课，建立全景图与底层加载机制。核心结论：slime 把「采样→训练→权重同步」骨架写死，把每段「肉」做成可替换函数，共 21+ 个 `--xxx-path` 接口，值均为 import path 字符串，由 `load_function` 在运行时解析成函数/类对象后调用，使自定义代码与框架核心完全解耦。关键术语包括：hook（插入点）、function-path 参数、import path（如 `slime.rollout.sglang_rollout.generate_rollout`）。四个主接口呈层级包裹关系：`--data-source-path`（原料）→`--rollout-function-path`（整条流水线，包裹内层）→`--custom-generate-function-path`（生成工位）与 `--custom-rm-path`（打分工位）；换外层会让内层挂载点失效，故应优先用工位接口。一组易混的「过滤/钩子」接口按时机区分：动态过滤→样本钩子→样本过滤→buffer 过滤（默认 `pop_first` 始终生效）→全量后处理。`load_function` 仅 4 行核心逻辑（`rpartition` 切最后一点→`import_module`→`getattr`，加 `@cache` 记忆化），返回函数或类由各接口契约区分。最后，`tests/plugin_contracts/` 提供纯 CPU 契约测试，用「签名匹配+最小调用验返回+调用点稳定」三层断言、经 `SLIME_CONTRACT_*` 环境变量覆盖即可自检任意实现，无需 GPU。具体接口写法留待 u6-l2~u6-l5 展开。
