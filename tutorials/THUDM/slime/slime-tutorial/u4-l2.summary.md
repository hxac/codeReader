本讲精读 `slime/backends/megatron_utils/model.py` 的三个核心函数。核心设计是：slime 不重写流水线引擎，而把 Megatron 的 `get_forward_backward_func()` 当「执行器」，用 `forward_step` 闭包返回 `(output_tensor, 回调)` 注入 RL 损失，从而无损复用全部 TP/PP/CP/EP/DP 并行。`forward_only` 是只读路径，配合 `@torch.no_grad()` 与 `forward_only=True`，由 `get_log_probs_and_entropy` / `get_values` 回调产出 logprob/entropy/value（空张量占位 loss）供优势估计。`train_one_step` 是六拍单步：`zero_grad → before_hook → 流水线前后向 → 梯度 NaN/Inf 检查 → optimizer.step + scheduler.step → 释放梯度并归约指标`；其中损失缩放因子 `num_microbatches / step_global_batch_size * dp_world_size` 保证分微批梯度累积等价于整批前向。`train` 是多步外层循环，负责配置 DDP 五个同步回调、optimizer 状态重置、手动 GC 对齐与首步 pre-hook 自检。关键术语：micro-batch、num_microbatches、step_global_batch_size、normalizer、梯度累积、流水线并行、forward_step 闭包、forward_only 标志。
