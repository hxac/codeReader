本讲拆解 slime 默认 rollout 函数 `generate_rollout`（位于 `slime/rollout/sglang_rollout.py`）的完整执行流程，它由 `RolloutManager` 间接调用，产出正好 `rollout_batch_size` 组样本。整体采用「同步外壳 + 异步内核」结构：同步入口按 `evaluation` 分流，训练路径用 `run(coro)` 把协程丢进后台事件循环执行。

核心分三个最小模块。其一，`generate_rollout_async` 用双层 while 循环配 `asyncio.wait(FIRST_COMPLETED)` 实现「过采样补数 + 动态过滤」凑齐目标组数的流水线调度；`target_data_size`、`remaining_batch_size`、`over_sampling_batch_size` 三个量分别控制目标批量、在途任务数与补采粒度。其二，数据生成按职责分三层：底层 `generate` 最薄，仅调 SGLang 并把 token 与 logprob 写回 Sample；中层 `generate_and_rm` 负责信号量限流、custom_generate 分流、样本钩子与逐样本奖励；顶层 `generate_and_rm_group` 用 `gather` 并发整组并可选做整组奖励。奖励分两条路径：`group_rm=False` 时逐样本用 `async_rm`，`group_rm=True` 时整组用 `batched_async_rm`。其三，`abort` 机制在凑够后终止多余请求，引擎层 `abort_servers_until_idle` 轮询清空 SGLang 队列，应用层等所有在途任务结束；partial rollout 下回收半成品、打 `start_rollout_id`，经 `add_samples` 跨轮续传。关键术语包括过采样、动态过滤、三层生成函数、group_rm 与逐样本奖励、partial rollout、abort。
