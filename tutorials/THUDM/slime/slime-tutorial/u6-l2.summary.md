本讲聚焦 slime 的「自定义生成函数」接口 `--custom-generate-function-path`：它只替换默认 rollout 流水线最底层「单样本生成」工位，不碰外层调度、奖励与过滤。签名为 `async def custom_generate(args, sample, sampling_params) -> Sample | list[Sample]`，由 `load_function` 解析，可选声明 `evaluation` 形参区分训练/评估，奖励由框架在返回后统一计算。

关键术语与结论：①loss_mask 是与回复等长的 0/1 数组——模型生成 token 标 trainable=True（须带 rollout_log_probs），环境/工具 token 标 trainable=False（自动填 0），由 `append_response_tokens` 维护一致性；开 TIS 时必须用 SGLang 原始 token、不可重新分词。②多轮循环范式（以 search-r1 为范）：注入 stop 标签防引擎在闭合标签后吐垃圾 token，逐轮「生成→解析→调工具→拼观测」，按 abort/length/stop 映射 `Sample.Status`。③fan-out：一次执行可返回多个 Sample，兄弟样本必须共享同一 `rollout_id`，单总奖励拆 K 段按 reward/K 均摊，否则同次 rollout 被重复计数、奖励放大。
