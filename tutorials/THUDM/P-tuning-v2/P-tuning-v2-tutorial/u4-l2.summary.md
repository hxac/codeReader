本讲从分类任务过渡到**序列标注（sequence labeling）**，以 NER 为例说明它与分类的根本区别：每个样本不再预测单一标签，而是对每个词预测一个标签，评估取 `argmax(axis=2)`。

核心模块一：`tokenize_and_align_labels` 完成**标签对齐**。分词器用 `is_split_into_words=True` 把预先切好的词列表切成子词，再用三条规则把词级标签拉长到子词级——特殊符号置 `-100`、词的首子词保留真实标签、同一词的其余子词置 `-100`，保证「一词一监督信号」。模块二：`word_ids`（每个子词到所属原始词的编号）本仓库**手写构造**，逐词 `encode` 取子词数再复制编号，而非用 fast tokenizer 的 `word_ids()`，因为后者对慢速 tokenizer（`deberta-v2` 的 `USE_FAST=False`）不可用。**`-100`** 是贯穿训练（`CrossEntropyLoss.ignore_index`）与评估（`if l != -100`）的统一屏蔽约定，模型侧再叠加 `attention_mask` 屏蔽 padding。模块三：指标用 **seqeval 实体级 F1** 而非 token 准确率，因为实体边界与类型必须同时正确才算命中；评估前须用 `label_list` 把整数 id 还原成 `B-LOC` 字符串。

接线方面，`run.py` 派发到 `tasks.ner.get_trainer`，用 `NERDataset` 加 `ExponentialTrainer(test_key="f1")`，使实体级 F1 经 `BaseTrainer.best_metrics`（`best_eval_f1`）驱动最佳模型追踪。
