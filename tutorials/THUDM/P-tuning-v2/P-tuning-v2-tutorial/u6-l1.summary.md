本讲把 P-tuning v2 的前缀注入迁移到抽取式问答（SQuAD）。模型在冻结主干上接 qa_outputs 头，对每个 token 输出 start/end logits，把"找答案"转化为找起止 token 下标，损失为两段交叉熵的平均，故 num_labels 恒为 2（区别于分类的类别数）。前缀注入（get_prompt 生成逐层 past_key_values，拼到冻结主干前）与分类任务逐字相同，体现深度提示的任务无关性。评估需专用 QuestionAnsweringTrainer（继承 ExponentialTrainer，附带指数学习率衰减）：它重写 evaluate，先临时关 compute_metrics 只跑出原始 logits，再经 post_process_function（封装 postprocess_qa_predictions，用 offset_mapping 把 token 下标还原为答案文本）译成文本，最后算 F1/EM。因双指标与后处理需求，QA 不沿用 BaseTrainer 的 test_key 单指标机制，改硬编码 best_eval_f1 与 best_eval_exact_match 双指标，以 F1 为裁判刷新最佳、EM 仅顺带快照，且 log_best_metrics 不落盘 best_results.json，影响超参搜索脚本。
