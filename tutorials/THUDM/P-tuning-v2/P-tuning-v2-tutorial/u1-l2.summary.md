本讲承接上一讲 P-tuning v2 概念，目标是把一次训练「跑起来」。环境搭建分三步：conda 建 pt2 环境(Python 3.8.5) → conda 装 PyTorch 绑定 cudatoolkit=11.0 → pip 装 requirements.txt，其中 transformers==4.11.3、datasets、seqeval 等五个包均精确锁版本以保证可复现。run_script 下脚本顶部用五个 shell 变量表达超参：bs、lr、dropout、psl(对应 --pre_seq_len，把默认 4 覆盖为 128)、epoch，用 $ 展开到 run.py 命令行，分类(RTE)与序列标注(NER)配方不同。--prefix 是 P-tuning v2 总开关，经 arguments.py 解析后由 model/utils.py 的 get_model 据其走 PREFIX_MODELS 分支，不带 --prefix 才走全量微调分支。关键陷阱：参数量打印 total param 只在全量微调分支，带 --prefix 时主干在模型类构造函数里冻结、不打印，需自行统计 requires_grad 参数量，从而验证 prefix 可训练参数远小于主干。output_dir(如 checkpoints/rte-roberta/)决定产物落盘。引入术语：pt2 环境、--prefix 总开关、pre_seq_len、get_model 三分支、output_dir。
