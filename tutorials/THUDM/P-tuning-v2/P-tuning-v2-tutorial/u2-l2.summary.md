本讲以 `BertPrefixForSequenceClassification` 为例，讲清前缀如何进入被冻结的 BERT，聚焦「注入」一个动作，含三个最小模块。①`get_prompt`：把 PrefixEncoder 输出的扁平 `(batch, pre_seq_len, 2*L*H)` 经 `view→permute([2,0,3,1,4])→split(2)` 重排，得到长度为 L 的 tuple，每段即一层的 `(key, value)`，形状 `(batch, num_heads, pre_seq_len, head_dim)`，精确匹配 HuggingFace `past_key_values`（KV 缓存）的逐层格式；`view` 合法性靠恒等式 `2L×n×(H/n)=2LH`。②`prefix_attention_mask`：须在原 mask 前面拼 `pre_seq_len` 个 1，否则前缀被当 padding 屏蔽而失效。③注入发生在 `self.bert(..., past_key_values=...)`：BERT 每层把前缀 KV 拼在自己 KV 前面，每个 token 在每层都能看见前缀，即「深度注入」。冻结发生在 `__init__` 的 `requires_grad=False` 循环，可训练部分仅 PrefixEncoder + 分类头，`total_param = all_param - bert_param` 近似刻画；前缀是全 batch 共享的同一连续模板。关键术语：`past_key_values`、KV 缓存逐层格式、深度注入、`pre_seq_len`、`requires_grad`，供下讲与浅层 Prompt、全量微调对照。
