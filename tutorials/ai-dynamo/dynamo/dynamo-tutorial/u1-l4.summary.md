本讲讲解 Dynamo 从源码构建与开发环境搭建，覆盖四个最小模块：maturin 构建链、hatch_build.py 版本钩子、cargo 与 Rust workspace 独立构建、container 模板渲染。核心结论：构建是两条互不替代的产物线——被刻意排除出 workspace 的绑定 crate dynamo-py3 由 maturin 编成 Python 扩展 dynamo._core 装入 venv；cargo 编译 workspace 成员 crate 产出 Rust 库。引入术语：uv 与 venv、PyO3（#[pymodule] 注册 DistributedRuntime、make_engine 等，dynamo.runtime 仅是再导出层）、cdylib/rlib、abi3 稳定 ABI、hatchling 构建钩子在打包前为各组件生成带 git 短 SHA 的 _version.py（git 失败则降级为纯版本号）、Jinja2 单模板经 render.py 派生全部镜像变体并在渲染期校验组合合法性；生产 wheel 构建命令与本地同构但开启的 feature 更全。
