本讲拆解 Dynamo 从源码构建的五个最小模块：maturin 构建、版本注入钩子、cargo workspace、容器模板、依赖 overrides。核心结论：构建是两条独立产物线——绑定 crate dynamo-py3 被排除出 workspace，须由 maturin 编成 Python 扩展 _core.abi3.so 装入 venv；cargo 只编 workspace 成员产出 rlib。关键概念：PyO3 与 abi3 稳定 ABI、hatch_build.py 钩子按 git 短 SHA 生成各组件 _version.py、Jinja2 单模板经 render.py 派生全部 Dockerfile、uv --overrides 钉住被传递依赖击穿的版本地板。伏笔：import dynamo._core 即初始化，register_core 注册 DistributedRuntime、make_engine 等类型，并按 DYN_RUNTIME_* 预设 pyo3 异步桥接的 Tokio 运行时规模。
