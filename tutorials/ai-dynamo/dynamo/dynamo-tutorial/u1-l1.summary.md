本讲读 README、架构总览、系统架构三篇官方文档，建立全手册的心智地图：Dynamo 是运行在推理引擎（vLLM/SGLang/TensorRT-LLM）之上的数据中心级编排层，把多机 GPU 协调成一个推理系统，不取代引擎；单 GPU 单模型用引擎即可。四大核心能力构成因果链：分离式 Prefill/Decode、KV 感知路由、KVBM 多层 KV 缓存、Planner 自动扩缩。引入的关键术语：prefill/decode、KV cache、TTFT/ITL、架构三面（请求面/控制面/存储与事件面）、三个控制回路（服务/规划/韧性）、九步请求流程 S1–S9（S5 回传 disaggregated_params 元数据，S7 经 NIXL 点对点直传 KV 数据）、通信三面（发现/请求/事件，默认 etcd、TCP、ZMQ）、Distributed Runtime 四级层级、WorkerType 枚举（Encode、Aggregated 变体）、集成与 sidecar 两种后端接入、原生 Frontend 与 GAIE 两种路由拓扑。本地开发零外部依赖，无需 etcd/NATS，--discovery-backend file 即可起步，为下一讲运行实践铺路。
