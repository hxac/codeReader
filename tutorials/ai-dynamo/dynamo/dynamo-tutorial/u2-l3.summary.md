本讲分三模块：Context 生命周期、cancellation 示例三进程（client/middle/server，直连与代理两种拓扑）、取消传播闭环。核心概念：Context 是跨进程取消信号载体，Python 类为薄壳，状态由 Rust 侧 Controller 维护；三态状态机 Live→Stopped/Killed 单向流转，is_stopped() 判「非 Live」（Killed 蕴含 Stopped），stop_generating() 为幂等优雅取消，kill() 为硬终止。取消不走数据流，而是沿 link_child 建立的父子链接递归传播；建链后复查父状态以兜底竞态，子 context 继承父 id 可跨进程串联日志；中间层代理漏传 context 则取消链断裂、下游 worker 生成到底。worker 侧标准范式是每轮迭代先查 is_stopped() 再做昂贵工作，取消时抛 asyncio.CancelledError 并统计已发 token 收尾。框架只负责置位状态，真正停止取决于引擎自查；示例请求面用 nats（需本地 NATS，默认 tcp）。
