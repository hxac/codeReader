本讲覆盖 `lib/llm/src/http/` 的 OpenAI 兼容 HTTP 服务层。HttpService 是「一个 Router + 共享 State」：系统路由不做 inflight 记账（draining 期 `/live` 仍 200），推理路由被 track_inflight_inference 包住并做就绪门。核心结论：InflightPermit 是 RAII 记账器而非限流器，与 ServiceStage 三态机（Ready→Draining→Stopping）配合实现优雅关停，真正的准入控制在路由器与引擎侧。三类协议端点（OpenAI/Anthropic/Generate）共享同一 State，差异在请求整形深度；generate 端点按能力路由、以不透明信封透传 token_ids，由 GenerateMetricLifecycle 复用指标三件套从原始 token delta 补齐观测，span 摘要字段在 collector drop 时补写，模型名归一收敛为 unknown_model 哨兵以控 label 基数。其余承接术语：DeltaGeneratorState（chat 与 completions 共享流式状态，usage 对后端值取 max）、input_tokens 纯本地估算端点、embeddings 的 base64(LE f32) 内部线格式、按 ErrorType 的后端错误分类（InvalidArgument→400）、FinishReason 读宽容写保守（支撑 N-2 混部）。
