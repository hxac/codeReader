本讲剖析 `lib/llm/src/http/` 构成的 frontend HTTP 层。HttpService 本质是「一个 axum Router + 共享 State」：系统路由只叠 TraceLayer，推理路由额外包 track_inflight_inference 中间件，StateFlags 用 AtomicBool 支持端点运行时启停。核心澄清：InflightPermit 是并发记账器而非限流器——无上限、不拒绝请求，其职责是追踪「响应体未完成」的请求数，支撑 Ready→Draining→Stopping 三态优雅关停；许可以响应体流为生命周期，HTTP 层仅在非 Ready 时返回 503，真正准入在路由器与引擎侧。三类协议端点（OpenAI、Anthropic、引擎原生 Generate）共享同一 State，差异在 handler 整形深度与错误信封，Generate 走不透明信封加按能力路由。流式 chunk 由 DeltaGenerator 拼装，DeltaGeneratorState 统一持有响应身份、usage 累计与 TTFT 计时，被 chat 与 completions 端点共享。
