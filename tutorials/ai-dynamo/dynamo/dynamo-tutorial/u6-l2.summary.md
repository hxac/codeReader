本讲拆解 Rust 路由核心 RoutingHost：它以 RoutingPolicy 枚举挂载 KV、builtin、Direct、设备感知加权四类策略，统一拥有选点、分发、响应监控与清理的生命周期；PushRouter 管传输，KvRouter 管 KV 状态，三者职责分离。builtin 路径四种内置策略完全不看 KV（重合恒为 0），负载感知靠占用账本“选择并预订”的原子操作。KV 路径五步：组装请求部件、合并显式 pin 与会话亲和约束、best-match 打分（算块哈希、查 indexer 分层匹配、进调度器）、路由决策写回 indexer、分发。打分是成本模型：KV 重合度是从 prefill 负载中扣除的信用，按缓存层加权（显存 1.0、CPU 0.75、磁盘 0.25），可随负载衰减；温度 0 取最小 logit，大于 0 走 softmax 采样。KvScheduler 只做路由侧准入、策略类排队（DRR 赤字轮转）与负载记账，不是引擎侧 dynamic batching。关键术语：选择器、挑选器、占用、准入、重合信用、query-only 纯查询；观测三件套是 [ROUTING_INPUT]、Formula、[ROUTING] Best 日志。
