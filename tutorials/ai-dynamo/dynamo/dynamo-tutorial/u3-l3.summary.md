本讲拆解 dynamo-runtime 的引擎抽象，覆盖五个最小模块。Data 是 Send+Sync+'static 的 blanket-impl 标记 trait，AsyncEngineContext 提供 stop_generating 与 kill 等取消控制，二者构成引擎体系的公共底线；请求以 Context<T> 信封进入引擎。AsyncEngine<Req, Resp, E> 仅有 generate 一个方法，输出形态分 AsyncEngineUnary（单值）与 AsyncEngineStream（流式），配合 SingleIn/ManyIn/SingleOut/ManyOut 四个别名即四种 gRPC 风格，可机械判读任何引擎签名。ResponseStream 把普通流与 context 打包升格为合法引擎输出，经 Ingress::for_engine 挂上 endpoint；透传 ctx.context() 是取消链不断裂的硬性纪律。AnyAsyncEngine 用 TypeId 三元组做类型擦除与还原，当前是预留扩展点而非主链路。engine_routes.rs 与引擎抽象无关，只是 /engine/* HTTP JSON 回调注册表。Python 侧 worker 最终经 PythonBidirectionalEngine 实现汇入同一抽象。
