本讲从「Python 驾驶员」视角拆解 dynamo.frontend 启动主流程，含三个最小模块。其一，启动链三层：`__main__.py` 仅转发；`main()` 抬高 fd 上限并以 uvloop 启动事件循环；`async_main()` 依次完成参数解析、构建 DistributedRuntime、注册信号优雅关停。其二，FrontendConfig 参数体系：由 ArgGroup 分组（嵌套复用路由共享组）、add_argument 统一封装、多继承配置基类、from_cli_args 两步填充四条约定构成；优先级为 CLI 标志 > 环境变量 > 代码默认值；validate() 非纯函数，load_aware 会把 router_mode 改写为 kv。其三，make_engine 注入链：kwargs 经 EntrypointArgs(EngineType.Dynamic) 白名单跨 PyO3 边界交给 Rust，chat_engine_factory 由 Rust 在发现模型时反向回调 Python 构造处理器。核心纪律：FrontendConfig 解析后是唯一事实来源，不写回环境变量；最终 run_input 启动 HTTP 服务，Python 侧转入等待。
