本讲拆解 dynamo._core 扩展模块（crate dynamo-py3）如何把 Rust 暴露给 Python，分五个模块：M1 注册入口——`#[pymodule]` 的 register_core 是全部符号的唯一注册总表；M2 运行时交接——模块初始化时即把 RuntimeConfig 的 tokio_builder 交给 pyo3 桥，使 DYN_RUNTIME_* 环境变量对桥自建的 Tokio 运行时也生效，Worker::ensure_process_runtime 提供进程级共享运行时，双运行时只告警不报错；M3 wrapper+inner 模式——PyO3 类是薄壳，inner 持有 Rust 原生结构体，需回调 Python 的类另存 event_loop；M4 PythonAsyncEngine 把 Python 异步生成器桥接为 Rust AsyncEngine trait 实现，spawn_blocking 保 GIL 安全，__anext__ 按需拉取成 Stream，context 参数按签名探测注入；M5 再导出层——dynamo.runtime 管分布式原语，dynamo.llm 管 LLM 域符号，make_engine、EntrypointArgs 定义于 rust/llm/entrypoint.rs。符号定位三步法：包装层 import 行→lib.rs 注册行→Rust 定义文件；错误统一经 to_pyerr 出境。
