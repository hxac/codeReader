本讲以 H7CH 库为主样本，讲解 cell_list、LEF、verilog、CDL、liberty 五视图的一致性检查。核心结论：各视图单元集合不相等是常态——实测 cell_list 748、LEF 785、verilog 751、CDL 去重后 791；CDL 的 .SUBCKT 模板（TG、TSINV 等）重复定义必须去重；SDFFRQX3H7H 仅见于 CDL，疑似遗漏待确认。引脚核对须先剥离电源脚：LEF 每宏恰好一对 USE POWER 电源脚，CDL 端口表尾 VDD/VSS 标 B，标准单元 verilog 无电源端口而 IO 单元反而保留。方向翻译表为 INPUT/input/I、OUTPUT/output/O、INOUT/inout/B；ANT2H7H 与 IO 库 PAR 存在真实方向冲突，应以白名单管理。关键概念：视图职责差异、金标准问题（cell_list∪LEF 才是完整物理清单）、「单元×视图」矩阵、待确认标注。方法骨架是纯 Python 的分视图提取器＋集合运算＋分级报告＋baseline；标准单元 liberty 需下载后才能入列比对。
