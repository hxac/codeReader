本讲是 IO 单元家族（u4-l1）的物理侧续篇，解读 IO LEF 的 23 个 PAD 宏并剖析 _ecos 版适配。宏以 CLASS PAD、SIZE、SYMMETRY X Y R90、ORIGIN/FOREIGN、SITE 描述几何与对称性：R90 支撑四条边旋转复用，ORIGIN/FOREIGN 的 20μm 偏移对应压焊开口越出 SIZE 框。尺寸分三档：130×130（CORNER 与双压焊 PWE）、65×130（常规 pad）、0.005~50 宽九档 FILLER（1-2-5 面值，最小档无引脚）。核心结论：普通版宏均引用却未定义 IOSite，ecos 版在文件头补定义 IOSite（0.005×130，格点宽即最小 FILLER 宽）与 IOCorner（130×130），并修正 48 处引脚属性——46 处地引脚 USE SIGNAL 改 GROUND（保障 PDN 电源地网络识别）、2 处核心侧输出 DIRECTION 改 OUTPUT（PBMUX 的 C、PWE 的 XC）。据此可按「边长减两拐角、按 65 分摊、FILLER 贪心补缝」估算 pad ring。
