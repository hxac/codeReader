本讲讲解把 ICS55 PDK 装进开源 EDA 工具的三个模块。一是装载命令：OpenROAD 用 read_lef 先读 tech LEF、再读 cell LEF（SITE/LAYER 属名字引用，必须后读），read_liberty 读时序库；liberty 不在 git 内，需先 make unzip 解压，其内部文件名待解压后确认。二是 _ecos 选型：凡喂给开源工具的流程一律用 _ecos 版文件，增量包括布线层电容参数（无电容则线延迟被低估）、OFFSET 调整并删 DefaultTaper、信号脚补 MET2/VIA1 形状、IO 库补 IOSite 定义与 USE 修正；电源 ABUTMENT 脚两版皆有，非增量。三是装载核对：H7CH 期望基线为 7 个布线层、3 个 SITE（仅 core7 被宏引用）、785 个 MACRO、5069 引脚、POWER/GROUND 各 785；cell_list 的 748 非全集。grep 与纯 Python 脚本即可无工具完成同口径核对。
