本讲对比 ICS55 两份工艺 LEF，指出 `_ecos` 版与原版仅三类差异：7 个 ROUTING 层新增 `CAPACITANCE CPERSQDIST` 与 `EDGECAPACITANCE` 电容参数、7 层 `OFFSET` 由 0 0 改为 0.1 0.1、删除含悬空引用的 `NONDEFAULTRULE DefaultTaper`，其余内容（VIA、VIARULE、SITE）逐字节相同。引入寄生参数概念：方块电阻 R=RPERSQ·L/W，线电容 C=CPERSQDIST·WL+EDGECAPACITANCE·2L，过孔固定 2.5Ω，一阶延迟≈0.5RC，电容单位按 LEF 默认取 pF。量化结论：1mm 最小宽 MET1 约 1.25kΩ/137fF、延迟约 85ps，RC 随长度平方增长，厚金属 T4M2 的 RC 乘积约为 MET1 的 1/23；OFFSET 平移半节距使轨道穿过 site 中心并避开行边界电源轨道。选型规则：需做寄生/时序估计的开源流程必须用 `_ecos` 版，纯物理规则查询可用原版。
