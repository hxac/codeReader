本讲以三份 cell_list 为数据源盘点 ICS55 标准单元库。核心结论：标准单元区是 H7CH/H7CL/H7CR 三套平行库，分别对应 HVT/LVT/RVT 三种阈值电压，CDL 器件模型名 hvt/lvt/svt 与 README 注释互证；漏电随 Vth 呈指数变化，关键路径可换 LVT 提速、slack 富余路径换 HVT 省漏电，三库单元名除后缀外完全一致，支撑综合工具「同名换型」的多阈值优化。引入的关键概念：阈值电压 Vth、多阈值设计（multi-Vt）、驱动强度 X 编号（P 代替小数点）、库后缀 H7H/H7L/H7R；单元名按「功能助记符＋输入配置与变体字母＋驱动强度＋库后缀」四段解码，FILLCAP、TIEHI/TIELO 无驱动档。统计表明全库 748 个单元，与或复合门（AO/OA 系）占 40.6% 居首；三库覆盖差异仅 HVT 独有的 SDFFRX0P5H7H 一个；cell_list 不含 37 个 ANT 天线单元，不能当作全集。
