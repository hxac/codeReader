本讲解剖 ICS55 普通版单元 LEF（ics55_LLSC_H7CH.lef，785 个 MACRO）的抽象视图。核心结论：MACRO 头部六字段各司其职——CLASS CORE 与 SITE core7 约束行式布局，SIZE 高恒为 1.4 μm、宽必为 site 宽 0.2 的整数倍（0.2~12.8），FOREIGN 把抽象挂钩到同名 GDS 版图，SYMMETRY X Y 允许镜像复用。引脚采用 PIN→PORT→LAYER→RECT 四层嵌套：DIRECTION 表电学方向，USE（SIGNAL/POWER/GROUND）决定布线归属，SHAPE ABUTMENT 表示对接形；全库 5069 个引脚含 1570 个 INOUT（每单元一对 VDD/VSS），电源轨道矩形以行边界为中心越出 SIZE 边界，靠单元拼接天然成轨。OBS 声明布线障碍，54 个 ANT/FILLER 类单元无 OBS。关键事实：普通版所有几何均在 MET1 上，这是理解 _ecos 版补高层引脚的出发点。
