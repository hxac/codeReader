本讲解析 ICS55 仓库的目录结构与多视图文件族。顶层三大块：标准单元库（V1p10C100 版本目录下并列 H7CH/H7CL/H7CR 三套库，对应 HVT/LVT/RVT 三种阈值电压家族）、IO pad 库（23 个单元，核 1.2V/IO 3.3V 双电压）、全局唯一的 prtech 工艺 LEF——工艺规则与单元数据是两类资源。每库由七个固定视图子目录组成：cell_list 单元名单、liberty 时序功耗模型（综合用）、lef 物理抽象（布线用）、verilog 仿真模型、cdl 晶体管网表、gds 版图、doc 手册；核心约束是各视图必须描述同一批单元。git 仅跟踪 41 个文本文件，标准单元 liberty 与全部 gds 须经 make unzip 从 GitHub Release 下载补齐，IO 库 6 个小体积 liberty 因小留在 git 内。关键发现：cell_list 并非全集，H7CH 的 LEF 含 785 个 MACRO，多出 37 个 ANT 类天线单元；带 _ecos 后缀的文件是开源工具链适配变体。
