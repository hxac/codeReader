本讲解读 ICS55 工艺 LEF（N551P6M.lef）的层定义部分。文件以 UNITS（DATABASE MICRONS 1000）与 MANUFACTURINGGRID 0.001 确立 1nm 制造网格精度。20 个 LAYER 按 TYPE 分四类：OVERLAP、MASTERSLICE（器件层，零规则，仅登记名字供引用）、CUT（过孔层）、ROUTING（金属层），布线器实际使用后两类共 14 层。金属栈自下而上为 MET1–MET5、T4M2、RDL，走线方向水平/垂直严格交替；规格分三档：MET1 细线，MET2–MET5 均质中层，T4M2 厚金属与 RDL 封装再布线层为低阻大电流资源。关键术语：pitch（轨道节距）、方块电阻 RPERSQ（按 R=RPERSQ×L/W 估算互连寄生电阻）、DCCURRENTDENSITY（电迁移检查上限）。核心结论：本版 tech LEF 无任何 CAPACITANCE 参数，只能估电阻不能估电容，需 _ecos 版补齐；固定 VIA、VIARULE GENERATE 与 SITE 定义留待 u2-l2 展开。
