本讲解析 Ventus SM 的访存单元 LSU（主文件 `LSU.scala` 与 `MSHR.scala`）。LSU 是 SIMT 与 cache 之间的翻译层，把一条向量访存指令（每个 lane 一个地址）翻译成 cacheline 请求，对 cache 屏蔽 warp/lane/mask 概念。其内部由 InputFIFO、AddrCalculate、rspArbiter、MSHRv2、ShiftBoard 串成单向流水。核心要点：AddrCalculate 用六状态 FSM 完成"算地址→判路由→coalesce（访存合并）→更新 mask"循环——同一 cacheline（tag+setIdx）的 lane 合并成一次请求，不同 cacheline 分多拍发出；路由靠地址范围，活动 lane 全落 `[LDS_BASE, +128KiB)` 走 SharedMemory，否则走 DCache。三个关键 Bundle 各司其职：MshrTag 是指令身份卡（驱动写回与字节提取），DCacheCoreReq_np/ShareMemCoreReq_np 是 cacheline 请求，贯穿三者的 instrId 是请求—响应—MSHR 表项的对接钥匙。MSHRv2 用 currentMask 记录每条指令"还差哪些 lane"，分批乱序返回按 instrId 累积，归零即收齐，实现非阻塞访存。fence 借 ShiftBoard 的在途计数实现 per-warp 访存完成等待（fence_end=empty 解锁记分板）；另有 MSHR 表项上限（num_warp）与每 warp 在途上限（4）双重结构性反压。注意区分本讲的 MSHRv2 与后续 u6 的 cache 内部 MSHR。
