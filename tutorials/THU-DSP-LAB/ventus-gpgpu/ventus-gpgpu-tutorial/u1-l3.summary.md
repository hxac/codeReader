本讲建立 Ventus 仓库的「代码地图」。顶层分为五类：源码 `ventus/`、仿真 `sim-verilator/`（已取代废弃的 `make test`）、依赖 `dependencies/`、构建脚本与文档。自研 RTL 全部位于 `ventus/src/`，按功能域切为九个子目录：`pipeline`（SM 流水线，文件最多最复杂）、`cta`（CTA 调度器）、`L1Cache`（含 ICache/DCache/ShareMem/AtomicUnit）、`L2cache`、`mmu`（可选，受 `MMU_ENABLED` 默认关闭）、`axi`、`SRAMTemplate`、`config`、`top`。包名约定等于目录名，但定位代码须以 `package` 声明为准（如根级 `GvmDutApi.scala` 属 `package gvm`）。`dependencies/` 下五个 git 子模块（rocket-chip、inclusive-cache、hardfloat、fpuv2、Membox2.Scala）提供配置系统、浮点、缓存框架等能力。`top/GPGPU_top.scala` 是组装枢纽，通过 `import` 与 `Module(new ...)` 例化并连接各目录模块，串成 CTA→SM→L1→L2→AXI→DDR 数据通路；规模由 `top/parameters.scala`（num_sm/num_warp/num_thread）集中定义，生成 Verilog 入口为 `top/ExtMem_gen.scala`。
