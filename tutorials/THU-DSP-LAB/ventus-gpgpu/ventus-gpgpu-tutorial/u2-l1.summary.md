本讲建立 Ventus 的软件编程模型，含三个模块。其一，GPU 按 grid→block（workgroup/WG）→warp（wavefront/WF）→thread 四级展开：Ventus 以 num_thread（默认 32）个 thread 组成一个 warp 作为硬件调度单位，以 block 为 CTA 调度基本单元；同一 block 的所有 warp 只能落在同一 SM，默认规模 num_sm=2、num_warp=8、num_thread=32。其二，warp 启动时硬件向一组自定义 CSR（0x800~0x80c）写入运行时信息：CSR_TID（起始 thread id）、CSR_NUMW（block 内 warp 数）、CSR_NUMT（每 warp thread 数，默认=num_thread）、CSR_WID（warp id）、CSR_LDS（sharedmem 基址）等，满足 CSR_TID=wf_id_in_wg×num_thread；注意源码中 0x807 实为私有内存基址 pds_baseaddr，非文档所称的全局基址。其三，Ventus 不启用 MMU，靠地址范围区分内存：落在 [LDS_BASE=0x70000000, +128KiB) 内走片上 sharedmem，其余经 dcache→L2→DDR 访问 globalmem；.metadata 的 wf_size/wg_size 直接对应 CSR_NUMT/CSR_NUMW 且须与硬件 num_thread 一致。始终以源码为准。
