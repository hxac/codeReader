本讲（手册收尾）把 Ventus 从「能仿真」推进到「能上 FPGA」，覆盖三条主线。其一，`make fpga-verilog` 是三步串联：Chisel 生成 CHIRRTL；`firtool --split-verilog --repl-seq-mem` 把片上存储器（均由 `SRAMTemplate` 封装）剥离为黑盒并写入 `mem.conf` 清单；`gen_sep_mem.sh` 配合 `vlsi_mem_gen` 为每个存储器生成独立可综合的 SRAM 模型。其二，FPGA 综合顶层 `GPGPU_axi_adapter_top` 是 `GPGPU_axi_top` 的薄包装，把 AXI id 位宽从 16 压到约 5 以省资源；`fpga_test/` 提供基于 Vivado Block Design 的 SoC：MicroBlaze 软核当 host，经 AXI4-Lite 控制面（0x20000000）派发 kernel，GPGPU 经 AXI4 主口访问 DDR4 显存（0x80000000），器件为 VU37P/VCU128，顶层 `config_mb_wrapper`。其三，GPU 规模由全局 `object parameters` 统一决定，`num_warp`/`num_thread`/`num_sm` 与缓存规模是主要资源旋钮，寄存器堆（`num_vgpr`/`num_sgpr` 随 `num_warp` 线性扩张）是 BRAM 大头。引入的关键术语：综合/实现/比特流、SRAM 宏/BRAM、`mem.conf`、`--repl-seq-mem`、Block Design/MicroBlaze。注意 `naive_driver.h` 与 readme 存在滞后，应以 Makefile、`AXI4Lite2CTA.scala`、`project_gpgpu.tcl` 等源码为准。
