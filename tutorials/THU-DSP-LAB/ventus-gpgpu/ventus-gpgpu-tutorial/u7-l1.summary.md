本讲讲解 Ventus 可选 MMU（受 MMU_ENABLED 控制，默认关闭，关闭时地址不翻译）。翻译链为 L1TLB → L2TLB → PTW → L2Cache → DDR。SVParam（SV32/SV39）统一约定 VA/PA/PTE 格式，翻译时按 VPN 各级索引逐级读 PTE，用标志位 V/R/W 区分叶子、非叶子（PDE）与 page fault。L1TLB 每 SM 私有、全相联（ICache/DCache 各一），只缓存叶子翻译；L2TLB 全局共享，分 bank、扇区化（一次回填 32 条连续叶子 PTE）、带加速表（缓存中间级 PDE 以跳过上层遍历）。PTW 为逐级漫步状态机，每次读 PTE 顺带带回整条 cache 线，构成扇区化数据来源。AsidLookup 将 ASID 映射到页表基址 PTBR，并在 ASID 重建时驱动各级 TLB 失效。MMU 访存与普通访存复用 L2 端口，靠 source 字段最低位（isTLB）区分并分流。
