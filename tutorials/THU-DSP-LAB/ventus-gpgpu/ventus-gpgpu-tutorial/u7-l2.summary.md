本讲把 Ventus 从孤立 RTL 包装成可挂入 SoC 的标准 IP，对外仅暴露两条 AXI 总线：AXI4-Lite 从口（控制面）与 AXI4 主口（数据面）。控制面由 `AXI4Lite2CTA` 实现，内部维护 20 个 32 位寄存器，承载 `host2CTA_data` 全部派发字段（wg_id、num_wf、wf_size、start_pc、各资源量与基址、asid 等）；host 写完参数后向 `regs(0)` 写 1 触发一次性派发，硬件发完自动清零，完成回报锁存进 `regs(16/17)`，host 读取后须写 0 重新使能。AXI4-Lite 五通道遵循 valid/ready 握手，写交易走 AW→W→B、读交易走 AR→R。数据面由 `AXI4Adapter` 把 L2 的 TileLink A/D（Get/PutFullData）翻译成 AXI4 突发，并完成「宽 cacheline ↔ 64 位」位宽转换，用 TL `source` 当 AXI `id` 实现回程请求-响应配对，对接 L2 MSHR。`GPGPU_axi_top` 将两个适配器与 `GPGPU_top` 拼成「AXI4-Lite slave + AXI4 master」IP；`GPGPU_axi_adapter_top` 是 FPGA 综合用的薄包装（idBits 更省资源），经 `make fpga-verilog` 以其为顶层生成 Verilog。host 驱动流程为「写参数→置 valid→轮询归零→轮询完成→读 wg_id→写 0 重使能」；注意 `naive_driver.h` 的寄存器偏移表已过时，须以 `AXI4Lite2CTA.scala` 为准。
