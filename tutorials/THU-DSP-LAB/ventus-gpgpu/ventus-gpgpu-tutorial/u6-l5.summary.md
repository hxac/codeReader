本讲是缓存单元收尾，覆盖两个最小模块：单 SM 内 `L1Cache2L2Arbiter` 与 L2 缓存 `Scheduler`。前者用 Arbiter 把 ICache/DCache 两路请求仲裁成一路，去程在 source 最高位贴 1 位 cache_id，回程按该位分发；并接续 u2-l2 的三层互联，每层叠加 sm_id/cluster_id 标签，`l2Distribute` 不贴标、按地址 l2cidx 选 L2 bank，L2 对 source 透明仅 echo。引入的关键术语：TileLink 精简版（仅 A/D 通道）、包容性目录式写回 cache、MSHR、source 贴标/剥标路由。L2 Scheduler 由 SinkA/Directory/MSHR/requests/SourceA/SinkD/SourceD/BankedStore 八件套组成：目录是唯一真相源，命中走 dir_result_buffer 短路给 SourceD，miss 才分配 MSHR 并经二级 miss 合并复用同一次外部取数；BankedStore 用 set*ways+way 拍扁寻址，SourceD 用 8 状态 FSM 区分命中读/写、miss 回填与脏受害者写回。默认 L2 为 128 KiB、16 路、64 组、128 字节行、32 个 MSHR，source_bits=16（含 1 位 MMU 预留）。下一讲承接 MMU/TLB 把页表遍历请求送进 L2 的链路。
