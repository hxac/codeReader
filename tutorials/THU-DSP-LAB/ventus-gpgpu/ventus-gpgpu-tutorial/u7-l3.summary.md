本讲拆解 sim-verilator/ 仿真框架内部实现，说明 libVentusRTL.so 如何用软件建模「硬件、物理内存、内核拆分」三件事。框架分三块：libVentusRTL.so（仿真模型）、mini driver（示例调用者）、testcase/，其中核心结构体 ventus_rtlsim_t 持有 Vdut（被测硬件）、PhysicalMemory（DDR 模型）、Cta（软件派发器）三大件，对外以 C API 包 C++ 实现，生命周期为 init→add_kernel→step 循环→finish。step() 是四段式主循环：判终止→翻转 clock 并 timeInc(HALF_CYCLE_TIME=5)→按电平施加激励（负沿 Cta.apply_to_dut 派发 workgroup 与读写内存，正沿检测 host_req/host_rsp 握手）→eval 加波形与快照；两次 step 构成一个时钟周期（10 时间单位）。Cta 维护 kernel 队列，靠全局不重叠的 wg_id 区间逐 workgroup 派发并回收完成信号；Kernel 解析 .metadata（每 uint64 占两行、按 assignMetadata 固定顺序对号入座），以 WAITING/RUNNING/FINISHED 三态管理 workgroup；PhysicalMemory 用 std::map<页基址,页指针> 的稀疏分页字典建模 DDR，支持字节掩码写与 auto_alloc。关键术语：libVentusRTL.so、ventus_rtlsim_t、Vdut、Cta、Kernel、PhysicalMemory、host_req/host_rsp、wg_id、HALF_CYCLE_TIME、rtl_parameters、FST 波形、fork 快照回溯。
