Ventus（乘影）是用 Chisel 实现、支持 RISC-V 向量扩展（RVV）的开源 GPGPU，核心思路是用 RVV 向量指令充当 SIMT 指令。本讲含两个最小模块：整体架构、工具链组成。硬件由 Host 接口、CTA 调度器、若干 SM、缓存层次+AXI 四大件拼成；顶层 GPGPU_top 端口分两组：host_req/host_rsp 接 CPU，out_a/out_d 经 AXI4Adapter 接 DDR。主通路为 Host→CTA→CTA2warp→SM 流水线(取指/译码/执行/写回)→{指令缓存、数据缓存、共享内存}→L1Cache2L2Arbiter→三层集群互联(SM2clusterArbiter/l2Distribute/cluster2L2Arbiter)→L2(Scheduler)→DDR。每个 SM 内含 CTA2warp+pipe+InstructionCache+DataCache+SharedMemory；默认规模为 2 个 SM、每 SM 8 个 warp、每 warp 32 线程，MMU 与协同仿真默认关闭。关键术语：warp、CTA、SM_wrapper、parameters.scala 的 num_sm/num_warp/num_thread、GVM、sim-verilator。工具链边界：本仓库仅做硬件 RTL，编译器在 ventus-llvm，SPIKE 模拟器与 pocl 运行时在姊妹仓库，ventus-env 统一打包；仿真改用 sim-verilator（make test 已废弃），测试用例为 .metadata/.data，wf_size/wg_size 对应 num_thread/num_warp。
