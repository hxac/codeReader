本讲解释 Ventus（乘影）的 Chisel 源码如何变为可仿真/可综合的 Verilog。构建基于 Mill：build.sc 声明模块与依赖，common.sc 规定 ventus 主模块依赖 hardfloat、fpuv2、rocketchip、inclusivecache、Membox 五个 git 子模块（源码置于 dependencies/，首次须 make init 拉取）。Verilog 生成链路为 Scala(Chisel)→FIRRTL→firtool lowering→Verilog，当前唯一启用版本为 Chisel 6.4.0 + Scala 2.13.12（命令中 ventus[6.4.0] 即由此而来）。make verilog 以 top.GPGPU_gen 为入口、elaborate GPGPU_top，产出仿真用单文件 GPGPU_top.v，其顶层端口含 host_req/host_rsp 与 out_a/out_d；make fpga-verilog 则以 GPGPU_axi_adapter_top 为顶层，用 firtool 的 --split-verilog 与 --repl-seq-mem 将存储器分离到 mem.conf，再生成独立 .v，便于综合时替换为 BRAM 宏单元。此外 make test（chiseltest）已废弃，正式仿真改用 sim-verilator；elaborate 极耗内存（-Xmx32G），不足易致 OOM。
