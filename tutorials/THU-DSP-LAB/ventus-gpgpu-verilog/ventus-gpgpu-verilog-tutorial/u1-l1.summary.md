本讲建立 Ventus GPGPU 的顶层鸟瞰。它是清华「乘影」GPGPU 的 Verilog 版，支持 RISC-V 向量扩展 RV32V，以向量指令语义驱动 SIMT 硬件——一条指令广播给整个 warp 并行执行。顶层 GPGPU_top 连接四大部件：CTA scheduler（基于 MIAOW，查资源表把主机下发的 workgroup 派发到某 SM）、SM 核 sm_wrapper（内部 pipe 为取指→译码→发射→执行→写回流水线，含 icache/dcache/shared memory 与 vALU、vFPU、SFU、LSU、张量核、SIMT 栈等执行单元）、L2Cache（基于 SiFive block-inclusivecache，顶层 Scheduler.v，靠 MSHR 处理缺失）。数据流分两线：控制流 host_req→CTA→SM→host_rsp，须等 L2 刷完缓存才回报主机；访存流经 SM→互联→L2→外部，由 out_a/out_d 再转 AXI。规模总开关在 define.v：NUM_SM（核数）、NUM_WARP（每核 warp 数）、NUM_THREAD（每 warp 线程数=lane 数），仿真前须确认。
