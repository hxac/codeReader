本讲精读项目唯一渲染入口 render()，核心结论：它是参数组装器而非计算体，把相机几何量、模型经读时激活的属性与 pipe 开关打包成 18 字段的 GaussianRasterizationSettings（相机侧 8、模型侧 6、其余 4），连同各输入张量交给可微 CUDA 光栅化器做视锥剔除与逐像素 alpha 合成，返回六键 dict。关键术语：means2D 是 requires_grad=True 的全零梯度容器，backward 后的屏幕空间梯度充当致密化信号；visibility_filter 即 radii>0，标记剔除后仍可见的高斯；有效不透明度＝sigmoid(_opacity)×decay 因子×marginal_t，默认路径下该乘法在 CUDA 核内恰好发生一次，仅 Python 回退路径显式相乘，rot_4d 会令 σ_t 来源相差一个平方。仓库内 JIT 版光栅化包装未被 import，属遗留变体；CUDA 绑定与 markVisible、Python 回退与 env_map、opacity decay 分别留待后续讲义展开。
