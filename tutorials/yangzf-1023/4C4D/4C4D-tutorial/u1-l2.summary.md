本讲承接 u1-l1，讲清 4C4D 的环境构成与四个 CUDA 扩展。environment.yml 分两层：conda 层锁定 python 3.7.13、PyTorch 1.12.1、cudatoolkit 11.6 与做 SfM 数据准备的 colmap；pip 层用本地路径安装 simple-knn、pointops2、fused-ssim、diff-gaussian-rasterization 四个扩展，其中光栅化扩展在 yml 中写下划线目录名而实际目录用连字符，需手动 pip install 补装。扩展骨架统一为 CUDAExtension（声明模块名与源文件）、BuildExtension（PyTorch 构建器，做 ABI 检查）加 PYBIND11_MODULE（把 C++ 函数注册给 Python），编译产物是可 import 的 .so。四包入口各异：simple_knn._C 仅导出 distCUDA2，初始化时按近邻距离给出高斯空间尺度 log(sqrt(dist2))；pointops2 经 autograd 包装暴露 furthestsampling 与 knnquery，遵循变长批次 offset 约定；fused_ssim 按硬件后端三选一加载，用于 SSIM 损失与测试指标；diff_gaussian_rasterization 以 GaussianRasterizer/GaussianRasterizationSettings 封装 _C，承担 4D 可微光栅化前向、反向与 markVisible 视锥剔除。train.py 启动即沿四条 import 链加载全部扩展，任一缺失会在导入阶段报 ModuleNotFoundError。关键术语：可微光栅化、nvcc、pybind11、本地路径安装。
