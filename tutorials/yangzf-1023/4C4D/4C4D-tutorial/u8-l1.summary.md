本讲从 Python 包装层再下一层，精读 cuda_rasterizer 的纯 CUDA 实现，覆盖 config 与 auxiliary 工具、rasterizer_impl 的前向编排、forward.cu 两大前向核（preprocessCUDA 与 renderCUDA）及 backward.cu 反向。核心结论：前向是六阶段流水线——逐高斯预处理、前缀和、键值复制、基数排序、tile 区间划分、分块 alpha blending，一个线程块独占 16×16 tile，num_rendered 回传是唯一 D2H 同步点；ts、scales_t、rotations_r 集中在 computeCov3D_conditional 消费，经 Schur 补、marginal_t 时间衰减（阈值 0.05）与均值偏移完成时间边缘化，有效不透明度随 conic 打包进入混合；反向先从后往前递推出逐像素 alpha 梯度，atomicAdd 跨像素累加成有效不透明度梯度，再乘 marginal_t 折算回原始值。引入术语：tile 与 BLOCK_SIZE、共享内存合作预取、64 位排序键、三块状态缓冲与 fromChunk 重建、n_contrib 终止存档。
