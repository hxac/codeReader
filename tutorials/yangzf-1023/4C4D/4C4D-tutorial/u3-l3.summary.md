本讲回答「渲染某一帧时，4D 高斯如何变成 3D 椭球」。`build_scaling_rotation_4d` 用双四元数（左右一对，覆盖 SO(4)）组装 L=R·diag(s)，得 Σ=LLᵀ。条件协方差闭包在超平面 t=τ 上切片：协方差取 Schur 补 Σxx−ΣxtΣtx/σt²，均值偏移 mean_offset=Σxt/σt²·dt 必须加回 means3D，漏加则运动区域拖尾。`get_marginal_t` 给出时间衰减 exp(−dt²/2cov_t) 并乘入 opacity，0.05 剔除阈值对应时间半宽约 2.45√cov_t。渲染端 `covariance_activation` 按 rot_4d 绑定，CUDA `computeCov3D_conditional` 与 Python 逐行同构；陷阱是 `_scaling_t` 在 rot_4d 开/关下语义差一个平方。
