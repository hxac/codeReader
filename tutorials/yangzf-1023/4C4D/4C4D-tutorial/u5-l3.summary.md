本讲讲解 batch_size>1 时一次迭代的梯度累积与跨视角合并：B 个视角逐个 render → loss → (loss/B).backward()，凭 PyTorch「backward 累加、batch 末才 zero_grad」的语义，持久参数拿到 batch 平均梯度，等价于大 batch 单次反传但显存只需一张图。三类 per-view 输出各有合并规则：visibility_filter 取「或」（visibility_count>0）、radii 取最大（最坏屏幕尺寸）、viewspace 梯度逐视角取范数求和后乘 batch_size/visibility_count，数学上恰还原为「可见视角上的平均梯度」，使 densify_grad_threshold 对所有高斯口径统一（公平性来源）。统计入口两条：add_densification_stats（单视角，函数内取范数）与 add_densification_stats_grad（batch 模式，接收已归一化的 (N,1) 张量）；xyz_gradient_accum 与 denom 只对可见高斯递增，accum/denom 即「被统计的 iteration 上的平均」，致密化后统计清零重建。4D 时间中心 _t 走同款归一化，但须循环外读持久参数 .grad、先 clone 防写穿、累加带符号值不取范数；grads_t 目前被计算但未被 clone/split 消费。致密化判定算法留给 u5-l4。
