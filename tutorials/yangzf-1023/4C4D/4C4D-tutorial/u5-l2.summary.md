本讲聚焦训练主循环的 loss 阶段。核心结论：4C4D 总损失为 L=(1−λ)L1+λ(1−SSIM)，权重 λ 即 `lambda_dssim`，默认 0.2，L1 管逐像素保真、SSIM 管局部结构。`l1_loss` 是手写的逐元素绝对误差均值，比 L2 对离群像素更稳健；SSIM 用 11×11 高斯窗在亮度、对比度、协方差三方面比较结构，训练采用 CUDA 版 `fused_ssim`（`FusedSSIMMap` 这一 autograd.Function 前向预计算偏导、反向单 kernel），因处于训练热路径而比纯 PyTorch 版快数倍，后者保留给离线评估。batch 内逐视角执行 `loss/batch_size` 后 backward 实现梯度累积。评估侧引入 `psnr`（峰值硬编码 1.0，即 −10log10(MSE)，按通道分组），并区分两个口径：进度条 PSNR 未 clamp、取 batch 末视角；测试 PSNR 先 clamp 再在 held-out 相机上平均。`training_report` 每 100 迭代写 TensorBoard 曲线（含 total_points、opacity_histogram），其返回的 test PSNR 是 best checkpoint 的唯一判据。注意训练损失曲线实为 batch 末视角抽样而非均值。
