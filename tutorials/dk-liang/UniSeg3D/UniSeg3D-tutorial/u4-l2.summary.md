本讲拆解 UniSeg3D 的稀疏卷积骨干 spconv_unet.py。点云体素化后占用率约 1%，故用稀疏卷积只算活跃体素；SparseConvTensor 以 features 加 indices 描述稀疏数据。三种层各司其职：SubMConv3d 不改活跃点，SparseConv3d 做 k=2、s=2 下采样，SparseInverseConv3d 上采样。核心机制 indice_key 规则表复用：上采样层必须与配对下采样层共用同 key，才能精确还原下采样前的活跃点，跳连拼接因此能逐行对齐。ResidualBlock 是 pre-norm 残差块，通道不等时恒等分支退化为 1³ SubMConv3d 投影。SpConvUNet 通过递归自嵌套构成五级 U-Net（num_planes=[32,64,96,128,160]），每级依次「blocks→conv 下采样→递归→deconv 上采样→跳连拼接→blocks_tail」。主模型另建 input_conv（6→32 通道）与 output_layer（BN+ReLU）外壳；return_blocks 的多尺度列表被丢弃，extract_feat 只消费 32 通道最细层输出，经 scatter_mean 聚合成超点查询。坐标准备用 MinkowskiEngine、骨干用 spconv，两库以 indices 与 features 衔接。
