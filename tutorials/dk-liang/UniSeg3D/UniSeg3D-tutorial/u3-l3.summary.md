本讲剖析 UniSeg3D 数据管线中的 `AddSuperPointAnnotations`：把点级标注转换为模型训练用的超点级布尔矩阵 `gt_sp_masks`。核心链路是实例 id 清洗（未标注与 stuff 类置 −1）、连续重映射到 0..K−1、one-hot、`scatter_mean` 聚合、严格 `> 0.5` 二值化——即超点内多数投票，保证每列至多一个 True。关键概念：`gt_sp_masks` 的行布局为 K 个 base 实例行 + M 个 SAM3D 伪掩码行 + 21 个语义行（末行 unlabeled 兜底），`gt_labels_3d` 与 `is_novel` 与之逐行同长；`pts_instance_objextId` 保留 0 起原始 objectId 供文本/点提示对齐；测试旁路 `eval_ann_info` 采用 stuff=0/1、things 从 2 起的 +2 偏移评估 id 体系。训练专属 `merge_ov` 拼接伪掩码并标记 novel 行（仅掩码监督、标签占位），是开放词汇训练的数据侧准备；损失总调度按 `[:-n-1]`/`[-n-1:]` 切片消费该行布局。
