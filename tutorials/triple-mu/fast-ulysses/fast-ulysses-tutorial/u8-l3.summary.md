本讲模块：wheel_matrix.json、cli.py（wheel-url 与 _match）、_diagnose.py、setup.py、check_wheel.py、test_wheel_matrix.py。核心结论：一次 release 共 36 个 wheel＝8 个 torch minor×CUDA major 行×4 个 CPython，加 4 个去掉标签上 PyPI 的无标签行；PEP 440 局部版本参与排序、无标签 specifier 忽略候选标签、pip 取最高，三条规则合谋使裸 pip install 解析到最高标签行并静默把本机 torch 换成 2.13，根治须写全 local version 标签或走不含 torch 的专用索引；_match 按 machine→python→torch minor→CUDA major 四轴选行，CUDA 只比 major；导入失败由 _diagnose 以 _build_meta 构建事实对照现场环境归因：undefined symbol 属 torch minor ABI 失配，libcudart 缺失属 CUDA major 失配。关键术语：local version 标签（如 torch210cu128）、四轴匹配、built/live 对照、PyPI 行。
