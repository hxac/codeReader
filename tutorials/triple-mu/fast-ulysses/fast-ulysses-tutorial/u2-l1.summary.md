本讲精读 UlyssesGroup 构造。三个构造参数：process_group 默认 WORLD、任意子组可用；device 默认当前设备，统一归一化为带 index 的 torch.device；require_nvlink 默认 True（仅关键字传参），拒绝非全互 NVLink 组。构造是集合操作：NVLink 检查用 all_gather 收集全组设备号，enable_symm_mem_for_group 完成对称内存 bootstrap 注册，为首次窗口分配的 rendezvous 铺路；违反集合契约的后果是挂起而非报错。NVLink 检查分两层：Python 收集设备号保证全组结论一致，C++ 经 NVML（dlopen 加载、BDF 匹配）识别 GPU 直连与 NVSwitch 两种拓扑；其语义是失败开放——NVML 不可用时放行不误拒，两个 rank 共享一块 GPU 时跳过检查。子组按 group_name 寻址，rank/world_size 均为组内编号；destroy 先同步 comm 流再组内 barrier，是受支持的收尾路径。
