本讲为 fast-ulysses 项目总览。它解决长序列视频 DiT 训练的痛点：Ulysses 序列并行的两次 4D all-to-all 是关键路径，本库将其做成 torch 自定义算子，仅支持 NVLink 单机、ws≤8。三条特性：零 SM 传输——带步长 peer 拷贝由拷贝引擎（CE）直写对端对称内存，不占 SM、可与 GEMM 完全重叠，端到端零 SM 还需 out= 去掉同设备 copy_out；重排即步长——序列/头排列被编码为拷贝源/目的步长，基线 BASE（torch.distributed 路径）的两个 permute 重排内核消失，约占其开销 47–60%；不均匀分片是一般路径——按 rank 给出 seq_splits/head_splits 即可丢弃序列 padding，偶均分只是特例。实测对 BASE 快 1.60–2.17×，传输达 fabric 带宽上限 90–99%，面向每 rank 数百 MB 的大消息。SM、CE、对称内存、步长与视图、mode 0/1（序列⇄头分片两方向）等术语由后续讲义承接；下一讲 u1-l2 详解 Ulysses 原理。
