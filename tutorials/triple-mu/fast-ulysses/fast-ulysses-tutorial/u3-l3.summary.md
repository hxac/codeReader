本讲建立无 GPU 的布局测试：plan_bindings.cc 的 a2a_plan_debug 算子是 torch 与纯主机 plan 的唯一相遇点，返回与 GPU 路径同一份 build_plan 的 CopyOp 表；test_plan.py 用 numpy 缓冲重放每条拷贝，并与独立参照位精确比对。核心结论：重放通过即证明寻址正确，GPU 上的后续失败必属传输或同步，布局正确性与传输正确性由此解耦。关键概念：重放、参照（reference_scatter_head/reference_gather_head，scatter/gather 两模式的 numpy 权威表述，经锚定测试绑回 all_to_all_single + permute 语义）、位精确、负控制、往返一致性（两模式互逆）、窗口断言（window_numel 全 rank 一致且取全组最大输出）、零长度 shard 触发的跳过守卫、非 2 幂 world_size 仅对传输层 XOR 枚举与 sweep 补漏分支有意义而 plan 层无感。
