本讲拆解 Ulysses 序列并行的核心机制：mode 0 将每 rank 持有的「序列分片×全部头」张量 (b, s_local, n_global, d) 换成「完整序列×头分片」(b, s_global, n_local, d)，mode 1 是其严格逆变换；两次交换均为纯数据搬运，往返位精确。因缩放点积注意力按头独立，mode 0 之后的注意力计算完全本地、零通信，形成「mode 0 → 注意力 → mode 1」三明治结构：每 rank 注意力计算量摊薄为 1/ws，而通信字节随序列长度线性增长且每层固定付两次、不被摊薄，故成为长序列训练的关键路径。qkv 沿最后一维打包成 3*head_dim，字节不变而每层集合调用由六次降为两次（省的是握手与屏障延迟，不是带宽）。SPMD 调用契约要求所有 rank 发出相同的形状与 dtype 序列（新形状首次调用会触发集合性的对称内存窗口分配），违反的后果是挂起而非报错。
