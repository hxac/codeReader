本讲围绕 fast-ulysses 的不均匀分片机制展开。核心术语：seq_splits 与 head_splits 描述「组的切分几何」——每个 rank 的序列分片长度与头数，而非单次调用的收发量，因此 mode 0、mode 1 与 backward 复用同一对表，这与 all_to_all_single 需互换的 split_sizes 有本质区别。每个 rank 持有整张表，用前缀和免通信地算出全部偏移；表项可为 0、不可为负，须都传或都不传且全 rank 一致；窗口尺寸取全表最大以对齐。make_dims 的交叉校验只核对本 rank 可见的两根轴（mode 0 查本 rank 分片长与全组头数），且先于第一个屏障，被拒不挂起。不传 splits 即偶均分特例，由形状反推，仅要求被散射轴能被 ws 整除。平衡公式将余数摊给前几个 rank。实测：去 padding 时 baseline 付 5–11%，本路径因「不均分是一般路径」仅 1.00–1.03×。
