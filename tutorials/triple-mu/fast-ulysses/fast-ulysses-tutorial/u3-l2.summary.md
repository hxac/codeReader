本讲义精读 `build_plan` 的两种模式拷贝发射。mode 0（scatter head）读跨步、写连续：src_pitch 为满头行宽 N·D，dst_pitch 等于 width=n_p·D，源侧按头偏移 H_p 寻址、目的侧按序列偏移 S_r 寻址；mode 1（gather head）与之镜像，读连续、写跨步——因为「窗口即返回张量」，被散射的头轴位于输出每行内部，必须让拷贝引擎按步长直接落位到最终布局，从而免去本地交织内核。window_numel 取全组各 rank 输出元素数的最大值：同尺寸窗口才能保证 peer 偏移对齐与集合分配不挂起，且每 rank 持有完整 splits 所有权表，可免通信算出同一最大值。发射循环不特判 p==rank，本 rank 自份额同样走窗口，买下「窗口稠密前缀即完整输出」的不变量，使 copy_out 退化为一条平坦拷贝、零拷贝路径直接返回窗口视图。零长度分片在两模式各有守卫；两模式复用同一对 splits 所有权表而不交换，mode 1 是 mode 0 的精确逆，往返逐字节还原。
