本讲剖析 fast-ulysses 的可微性设计。核心模块是 C++ 算子 A2AFunction（torch::autograd::Function）：forward 把 group 智能指针、mode 与两张 splits 表存入 saved_data（IValue 用 None 保留「未传」语义），经 dispatch_below_autograd 重入调度器复用 u6-l2 的传输流水线；不需梯度时走无节点快速路径。数学结论：交换是排列矩阵、转置即逆，故 backward 就是 1−mode 的前向调用，位精确且不重算；splits 原样传递、不交换——它们描述组的切分几何而非单次收发量（与 all_to_all_single 的语义根本不同），倾斜切分下交换会挂形状校验。backward 永走 copying 路径（集合分配与单缓冲窗口和梯度语义不兼容），并经 apply() 递归建图以支持双重 backward。forward AD 因 C++ Function 无 jvp 钩子而在 Autograd 内核手工搬运 tangent：jvp 即同一排列，tangent 走第二条集合通信；jvp/linearize 可用，reverse functorch（grad/vjp/jacrev）因无法 lift C++ 节点而 raise，vmap 被显式拒绝；out= 与 async 形式对梯度输入显式 raise 而非静默丢弃。
