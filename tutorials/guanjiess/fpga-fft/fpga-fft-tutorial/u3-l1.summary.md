本讲讲清旋转因子在硬件中如何存储与寻址，覆盖三个最小模块。`RotatorMemory8` 用 `case` 硬编码 8 点层 N/2=4 个复数因子（Q1.16 量化，W=1 默认为 `(1<<16,0)`），仅适合小点数。`Rotator16` 首次改用厂商 ROM IP（实/虚分存两块 ROM），核心巧思是「计数器两用」：`r_addra` 低位作 ROM 地址、最高位作 `select`，把一个 PERIOD 对半切成前半段读真实因子、后半段补 W=1。`Rotator_address` 把地址/select 逻辑参数化抽出（`layer` 参数、MAX_ADDR=N/2），不再内置 ROM 与 mux，供 `fft_32` 及以上所有层复用。`fft_32` 则把 `rotator_valid`（来自 `butterfly_general`）→ `Rotator_address` → ROM → select mux → `multiplier` 拼成完整通路，成为后续高层同构模板。关键术语：`select` 经两级打拍对齐 ROM 读延迟、`rotator_valid` 作总开关、W=1 为稳妥默认直通值。
