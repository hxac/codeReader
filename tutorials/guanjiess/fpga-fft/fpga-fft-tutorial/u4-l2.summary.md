本讲承接 u4-l1 与 u3，精读流水线过渡的两级。fft_8（layer=3）延续朴素写法：4 拍反馈延时由 3 级寄存器加蝶形自带 1 拍实现，旋转因子用 RotatorMemory8 的 case 硬编码。fft_16（layer=4）是分水岭：8 拍反馈延时首次改用 RAM（delay #(.layer(4))），旋转因子首次改用 ROM IP（Rotator16，计数器低位当地址、最高位当 select 切换真实因子与 W=1），由此成为首个集齐「蝶形+RAM 延时+ROM 旋转因子+复数乘法」四件套的层级，是 fft_32 及以上所有高层模块的原型。切换根因是 SDF 延时深度=N/2=2^(layer-1) 随层级翻倍：寄存器在 fft_16 需 448 FF、到 fft_16k 需 50 万+ FF，物理不可行，唯有 BRAM 可随参数线性扩展。
