# FIR_x2 是什么：PCM 过采样 FIR 滤波器总览

## 1. 本讲目标

本讲是整个 FIR_x2 学习手册的第一篇，目标是让你从「完全不了解这个项目」到「能用一句话说清楚它是干什么的、输入输出是什么、能在什么硬件上跑」。

读完本讲你应该能够：

- 说清楚 FIR_x2 在一条数字音频信号链里扮演的角色（2 倍过采样滤波）。
- 认得它的输入信号 `MCLK_I / BCK_I / LRCK_I / DATA_I / NRST_I` 和输出信号 `BCKx2_O / LRCKx2_O / DATA_O` 分别是什么含义。
- 解释「过采样（oversampling）」和「FIR 滤波」在数字音频里的意义。
- 知道项目支持哪些 FPGA 器件、用什么仿真器、遵循哪个开源许可。

本讲**不**讲具体 RTL 实现细节（那是后续讲义的内容），只建立整体认知。

## 2. 前置知识

本讲尽量从零讲起，但下面几个名词先有个印象会更顺：

- **PCM（Pulse-Code Modulation，脉冲编码调制）**：把连续的模拟声音波形按固定间隔采样、再量化成一串数字，这就是数字音频最常见的形式。一个 CD 音质的 PCM 信号每秒采样 44100 次（44.1 kHz），每个样本用 16 位表示。
- **采样频率（Sampling frequency，fs）**：每秒采多少个样本，单位 Hz。常见的有 44.1 kHz、48 kHz；更高质量的 88.2 kHz、96 kHz、192 kHz 等。
- **FIR 滤波器（Finite Impulse Response Filter，有限脉冲响应滤波器）**：一种数字滤波器，输出是「最近若干个输入样本」与「一组固定系数」分别相乘再相加的结果。它的「长度」由系数个数（也叫抽头数，taps）决定。
- **过采样（Oversampling）**：人为提高采样频率，在原本相邻的两个样本之间「插入」新的样本。2 倍过采样就是把 44.1 kHz 变成 88.2 kHz、48 kHz 变成 96 kHz。
- **FPGA（Field-Programmable Gate Array，现场可编程门阵列）**：一种可以通过写代码（硬件描述语言）重新配置内部逻辑的芯片。本项目的滤波器就是用 Verilog 写、跑在 FPGA 上的。
- **Verilog**：一种硬件描述语言，本项目的源码全部用 Verilog 编写。

### 4.1 项目定位与音频背景

#### 4.1.1 概念说明

数字音频 DIY 圈子里，常常会把不同采样频率的信号拼到同一条链路上。比如你有一块解码器原生支持 96 kHz，但音源只有 44.1/48 kHz，这时就需要一个**升采样（upsampling）**环节，把低采样频率的 PCM「插值」成高采样频率的 PCM，再送去 DAC（数模转换器），从而让 DAC 工作在更高、更舒服的采样频率上。

FIR_x2 就是这个环节里的一颗「数字滤波器芯片（用 FPGA 实现）」：

- **输入**：一路普通采样频率（如 44.1 kHz 或 48 kHz）的 PCM 音频。
- **输出**：一路 **2 倍**采样频率（如 88.2 kHz 或 96 kHz）的 PCM 音频。

README 开头一句话就点明了定位：

> FPGA based PCM oversampling FIR filter (oversample ratio: 2).
> （基于 FPGA 的 PCM 过采样 FIR 滤波器，过采样比为 2 倍）

这里的「2 倍」就是关键：它在每两个原始样本之间插入一个新的、经过 FIR 滤波计算出来的样本，从而把采样频率翻倍。这在数学上叫**插值因子为 2 的内插（interpolation by 2）**。

#### 4.1.2 核心流程

从信号链的角度看，FIR_x2 在一条音频链路中的位置大致如下：

```
   原始 PCM           FIR_x2                 升采样 PCM
   (fs, 例 48kHz)  ───────────────►  (2×fs, 例 96kHz)  ──────►  DAC  ──►  喇叭
                  插值 + FIR 低通滤波
```

为什么过采样要配 FIR 滤波？因为「插入新样本」本质上会让频谱里出现镜像（image）成分，必须用一个**低通 FIR 滤波器**把这些镜像滤掉，输出才是一段干净的高采样频率音频。FIR_x2 把「插值」和「低通滤波」两件事合在硬件里一起完成。

它的内部数据通路是一条流水线（本讲只看骨架，细节留到后面）：

```
DATA_I ──► [输入数据缓冲] ──► 数据 ─┐
                                     ├──► [乘法 MULT] ──► [累加 ADD] ──► 饱和/舍入 ──► DATA_O
LRCK_I ──► [系数 ROM] ───► 系数 ────┘
                  └──► 派生出 2 倍过采样时钟 LRCKx2 / BCKx2 ──► 输出
```

一句话概括：**输入一段低采样频率 PCM，按 FIR 卷积算出插值样本，输出一段 2 倍采样频率的 PCM，同时输出配套的 2 倍时钟。**

关于「FIR 滤波器长度」的一个硬性约束，在 Notes 里：

[README.md:41-44](https://github.com/AUDIY/FIR_x2/blob/a06376b3aa726029e95f94f88236372533e650be/README.md#L41-L44) — 第 2 条 Note 写明：滤波器长度（抽头数）必须等于「MCLK_I 频率 / 采样频率」。

这条约束的直觉解释是：FIR_x2 采用**串行**结构，每个主时钟（MCLK）周期只算一次乘加，而一个采样周期 \(\,1/f_s\,\) 内一共有 \(\,\text{MCLK}/f_s\,\) 个主时钟周期，所以能算的抽头数恰好等于这个比值。举例：

\[
\frac{\text{MCLK}}{f_s} = \frac{22.5792\,\text{MHz}}{44.1\,\text{kHz}} = 512
\]

所以 22.5792 MHz 主时钟、44.1 kHz 采样时，滤波器正好 512 个抽头（这也解释了仓库里系数文件名里的 `FIR512`）。48 kHz 采样对应 24.576 MHz 主时钟，同样得到 512：

\[
\frac{24.576\,\text{MHz}}{48\,\text{kHz}} = 512
\]

> 注意：因为做了 2 倍过采样（多相分解），ROM 里实际存放的是经过奇偶分解后的系数，存储深度为 \(\,2^{\text{WADDR\_WIDTH}+1}=512\,\)。这个细节属于系数通路讲义（第 4 单元），本讲先记住「总抽头数 = MCLK / fs」即可。

#### 4.1.5 小练习与答案

**练习 1**：为什么过采样之后还要做「低通滤波」，不能直接在两个样本间插零？

> **参考答案**：直接插零会在频谱里产生镜像（原信号频谱的高频复制副本），听感上变成噪声/失真。低通 FIR 滤波的作用就是把这些镜像滤掉，只留下基带信号，输出才是干净的高采样频率音频。

**练习 2**：如果把主时钟 MCLK 提高到原来的 2 倍、采样频率 fs 不变，按 README 的约束，滤波器抽头数会变成多少？

> **参考答案**：抽头数 = MCLK / fs，MCLK 翻倍而 fs 不变，抽头数也翻倍。这说明在这个串行架构里，想用更长的滤波器，就得提供更高的主时钟（或更低的采样频率）。

### 4.2 I2S/PCM 时钟与数据信号

#### 4.2.1 概念说明

FIR_x2 的输入输出遵循数字音频里最常见的 **I2S 风格**接口约定。先认识三个时钟/控制信号：

- **MCLK（Master Clock，主时钟）**：整个系统的「心跳」，频率最高，FIR_x2 内部所有逻辑都用它做时钟。典型值是 22.5792 MHz（对应 44.1 kHz 系列）或 24.576 MHz（对应 48 kHz 系列）。
- **BCK（Bit Clock，位时钟）**：每一个比特传输一拍。一个音频样本有多少位，BCK 在一个采样周期内就翻转多少次。
- **LRCK（LR Clock，左右声道时钟）**：用来区分「现在是左声道样本还是右声道样本」。它的频率就等于采样频率 fs（每来一个 LRCK 完整周期，完成一对左右声道样本）。
- **DATA**：串行的 PCM 音频数据比特流。

FIR_x2 的输入就是这套原始的、**低采样频率**的 I2S 信号；输出则是配套的、**2 倍采样频率**的一套新信号，名字带 `x2` 后缀。

#### 4.2.2 核心流程

输入侧到输出侧的信号对应关系：

```
输入（原始 fs）                输出（2×fs）
─────────────────────────────────────────────
MCLK_I  ──────────────────►  （内部统一用 MCLK 做时钟）
BCK_I   ──────────────────►  BCKx2_O   （位时钟，2 倍频）
LRCK_I  ──────────────────►  LRCKx2_O  （左右声道时钟，2 倍频，即 2×fs）
DATA_I  ──────────────────►  DATA_O    （过采样后的 PCM 数据）
NRST_I  ──────────────────►  （复位，低有效）
```

关键直觉：

- `LRCKx2_O` 的频率是 `LRCK_I` 的 2 倍，因为它要在每个原始采样周期里输出**两个**样本（一个对齐原始样本，一个是新插值的样本）。
- 内部所有逻辑共用同一个 `MCLK_I`（单时钟域设计），`BCKx2_O` / `LRCKx2_O` 都是从 MCLK 分频/派生出来的，不是外部另给的时钟。

#### 4.2.5 小练习与答案

**练习 1**：`DATA_I` 和 `DATA_O` 为什么都要声明成 `signed`（有符号）？

> **参考答案**：PCM 音频样本是有正有负的（声音波形在零附近上下波动），必须用有符号数（二补码）才能正确表示正负幅度。声明成 `signed` 后，Verilog 里的乘法、符号扩展才会按有符号运算处理。

**练习 2**：为什么没有 `MCLKx2_O` 这个输出？

> **参考答案**：MCLK 是内部唯一的主时钟，FIR_x2 不需要向外部提供一个新的主时钟；外部下游器件（如 DAC）通常自带主时钟或另有安排。FIR_x2 只需要告诉下游「现在数据率和声道时钟都翻倍了」，也就是提供 `BCKx2_O` 和 `LRCKx2_O` 即可。

### 4.3 许可与适用器件

#### 4.3.1 概念说明

知道一个项目「能干什么」之后，还要知道「能在哪里、以什么条件使用」。FIR_x2 在这两点上都很明确：

- **许可（License）**：它不是软件协议，而是**开源硬件许可** CERN-OHL-W v2。它针对的是「硬件描述源码 + 文档」，并允许你据此制造实物产品。
- **适用器件**：作者在多种真实 FPGA 开发板上验证过，列出了具体的芯片型号和板卡。

> 名词解释：**CERN-OHL-W（CERN Open Hardware Licence - Weakly Reciprocal，弱互惠型）**，「Weakly Reciprocal」意味着你对这套源码的修改需要以同样许可开源，但把你**集成进更大产品**时，整个产品并不强制开源——相对宽松，适合 DIY 和商业产品混合使用。许可原文在仓库根目录的 `LICENSE` 文件里。

#### 4.3.2 核心流程

把一个 FPGA 项目「跑起来」通常分两条路，README 的 Usage 一节里都写了：

- **仿真路（Simulation）**：用 Questa 等仿真器跑测试激励，验证逻辑正确，不需要真实硬件。流程是「编译各模块 + 对应 `_TB.v` → 用 Questa 目录下的批处理脚本 → 启动仿真」。

## 6. 本讲小结

- FIR_x2 是一个**基于 FPGA、过采样比为 2 倍**的 PCM 过采样 FIR 滤波器，把 44.1/48 kHz 的 PCM 升采样到 88.2/96 kHz。
- 它在音频链中位于「音源」与「DAC」之间，同时完成**插值**与**低通滤波**两件事。
- 输入是标准 I2S 风格信号 `MCLK_I / BCK_I / LRCK_I / NRST_I / DATA_I`；输出是 `BCKx2_O / LRCKx2_O / DATA_O`，其中 `BCKx2_O`、`LRCKx2_O` 是输入对应信号的 **2 倍频**。
- 内部是**单时钟域**设计，所有逻辑共用 `MCLK_I`；滤波器抽头数受约束：\(\,\text{抽头数}=\text{MCLK}/f_s\,\)（如 24.576 MHz / 48 kHz = 512）。
- 项目遵循**开源硬件许可 CERN-OHL-W v2**，已在 Altera/Efinix/AMD/Gowin 共 7 款开发板上验证，并提供对应示例工程。
- 项目已宣告「不再维护、即将归档」，源码稳定、适合作为静态教材阅读。
