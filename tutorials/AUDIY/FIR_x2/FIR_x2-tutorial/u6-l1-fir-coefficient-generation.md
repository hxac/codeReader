# FIR 系数生成：firwin 与多相奇偶抽头分解

## 1. 本讲目标

前几讲我们一直把滤波器系数 ROM（`04_FIR_COEF` 里的 `.hex`）当成一个「现成黑盒」来读：SPROM 把系数读出来，MULT 拿去做乘法。本讲要回答一个更源头的问题——**这些系数从哪里来、怎么设计、又凭什么保证硬件不会溢出？**

本讲是整套手册第一次离开 Verilog、走进 Python 脚本 `11_fir_gen/fir_gen.py`。学完本讲你应当能够：

- 说清楚 `scipy.signal.firwin` + Hann 窗是如何设计出 2 倍过采样低通滤波器的；
- 解释浮点系数量化为 16 位有符号整数的公式，以及「在最前面补一个 0」对齐偶数抽头的原因；
- 推导出抽头和上界 `MAX_TOTAL = 2^(BIT-2) - 1` 与第 5 讲（u5-l3）输出级「丢低 14 位」之间的因果关系，理解为什么必须保证奇、偶抽头和都不超过它。

本讲对应进阶层（advanced），承接 u4-l1（系数 ROM 封装）与 u4-l2（系数地址的奇偶多相寻址），并为 u6-l2（十进制转十六进制）铺垫。

## 2. 前置知识

阅读本讲前，建议你已经建立以下概念（来自前序讲义）：

- **2 倍过采样与镜像**（u1-l1）：FIR_x2 把 44.1/48 kHz 的 PCM 升采样到 88.2/96 kHz，插值会产生镜像，必须用低通滤波器滤除。
- **多相寻址**（u4-l2）：`SPROM_CONT` 让系数地址最低位跟随 `LRCK_I`，于是在一个 `LRCK` 周期内**奇地址**与**偶地址**各被扫描 256 次，分别累加出两个过采样样点。
- **输出级定点截位**（u5-l3）：顶层最后一级 `always` 块把 48 位累加结果 `ADD_DATA` 截到 32 位输出，不饱和分支取 `ADD_DATA[45:14]`，即**丢掉低 14 位**。

此外需要一点点数字信号处理常识：

- **FIR 滤波器**：输出是输入与一组固定系数（抽头）的卷积和，系数一旦确定，频率响应就定了。
- **窗函数法**：先算理想低通的冲激响应（一个 sinc），再用窗（如 Hann）截断平滑，得到有限长系数。`firwin` 就是这个流程的封装。
- **定点量化**：把浮点系数控乘一个比例后四舍五入成整数，以便硬件用纯整数乘法器实现。

不需要你会写 Python，本讲会逐行解释脚本。

### 4.1 firwin 低通设计

#### 4.1.1 概念说明

2 倍过采样要做两件事：插值（在样点间补位置）+ 低通（滤掉插值产生的镜像）。这个低通就是本模块要设计的滤波器。

为什么需要低通？插值（零值内插）会在原信号频谱的镜像位置（新的输出采样率所对应的基带复制）产生「镜像」，若不滤除，听感上就是失真。因此过采样系统的核心是一个**抗镜像低通滤波器**，通带覆盖音频带（如 0~20 kHz），阻带压制镜像。

设计低通 FIR 最常用的工程方法是**窗函数法**：

1. 先写出理想低通的冲激响应——一个无限长 sinc 序列；
2. 因为硬件只能用有限长系数，用一个有限宽度的窗（本讲用 Hann 窗）去截断、平滑它；
3. 得到的有限长系数就是 FIR 的抽头。

`scipy.signal.firwin(numtaps, cutoff, window=...)` 把这三步封装成一个函数调用，返回的就是抽头数组。

#### 4.1.2 核心流程

脚本顶层只有三行参数和一行设计调用：

```
FC    = 20000/44100   # 归一化截止频率
BIT   = 16            # 系数位宽（硬件 COEF_WIDTH）
TAPS  = 512           # 目标抽头数（最终为偶数）

coef_float = signal.firwin(TAPS - 1, FC, window='hann') / 2
```

流程：

1. `firwin` 的第一个参数是**抽头个数**。这里传 `TAPS - 1 = 511`（奇数，得到 Type I 线性相位、冲激响应关于中心对称的低通）。
2. 第二个参数 `FC = 20000/44100 ≈ 0.4535` 是按奈奎斯特归一化的截止频率，对应音频带 20 kHz。
3. `window='hann'` 选 Hann 窗，兼顾主瓣宽度与阻带衰减。
4. 末尾的 `/2` 是为 2 倍过采样做的**增益归一**：原始低通在基带的直流增益为 1（系数和≈1），除以 2 后系数和≈0.5，为后面的定点量化留出余量（这一点在 4.3 会看到它直接决定了能否通过溢出检查）。

> 为什么要 `/2` 而不是 `×2`？因为本设计不追求「每路过采样输出增益为 1」，而是把每个多相分支的系数和压到约 0.25，确保定点化后落在溢出上界 `MAX_TOTAL` 之内，换取「全量程输入也永不饱和」的线性保证。代价是输出有约 6 dB 衰减，可由下游 DAC/音量级补回。

### 4.2 多相奇偶分解与定点量化

#### 4.2.1 概念说明

浮点系数不能直接进硬件——FPGA 乘法器只认整数。所以要把 `coef_float` 量化成 16 位有符号整数（对应硬件 `COEF_WIDTH = 16`）。但本模块还有第二个、更重要的任务：**把 512 个系数拆成「奇地址」和「偶地址」两组**，对应 u4-l2 里 `SPROM_CONT` 的两相扫描。

这就是**多相分解（polyphase decomposition）**：把一个 2 倍过采样的长滤波器，按地址奇偶拆成两个子滤波器，每个子滤波器负责一个过采样样点的卷积和。脚本用 `coef_int[1::2]`（奇地址抽头）与 `coef_int[0::2]`（偶地址抽头）把两组分开做溢出检查，正是这个思想的直接体现。

为什么要拆？因为硬件（u4-l2）就是这么算的：一个 `LRCK` 周期内，LRCK 高电平扫奇地址、低电平扫偶地址，每相各累加 256 次乘加，分别产出两个过采样样点。所以脚本里检查的「奇抽头和」「偶抽头和」，恰好就是硬件两相各自要累加的那一份系数和。

#### 4.2.2 核心流程

定点量化公式（`BIT = 16`）：

```
coef_int = np.int32(np.floor(((coef_float + 1)/2) * (2**(BIT + 1) - 1) + 0.5) - (2**BIT))
coef_int = np.insert(coef_int, 0, 0)
```

量化映射的直觉：它把浮点区间 \([-1, +1]\) 线性映射到 16 位有符号整数区间 \([-32768, +32767]\)，并做四舍五入。逐步拆开：

1. `(coef_float + 1)/2`：把 \([-1,1]\) 平移缩放到 \([0,1]\)；
2. `* (2**(BIT+1) - 1)`：再放大到 \([0,\,2^{17}-1]\)；
3. `+ 0.5` 后 `np.floor`：实现「四舍五入到最近整数」；
4. `- (2**BIT)`：把无符号范围搬回有符号范围，使 `coef_float=0 → 0`、`+1 → +32767`、`-1 → -32768`。

对实际的小幅浮点系数（量级约千分之几），上述映射等价于大约「乘以 \(2^{16}\) 后取整」，即每位系数是一个 16 位二补码小整数。随后 `np.int32` 保证它们按有符号整数存储（与 `dec2hex.awk` 的二补码转换、SPROM 里 `FFFF→-1` 的解读一致，见 u4-l3）。

紧接着的 `np.insert(coef_int, 0, 0)` 在**最前面补一个 0**：

- `firwin(511)` 返回 511 个系数（奇数），补 0 后变 512（偶数），满足硬件「抽头数必须为偶数」的要求；
- 这个补的 0 落在数组下标 0，进入**偶地址分支**（`coef_int[0::2]` 包含下标 0），等于让偶相多一个零抽头，不影响该相的累加和，但保证两相抽头数相等、地址对齐。

补零后，奇偶两相各自 256 个抽头，与 u4-l2「每相 256 次乘加」严格对应。

### 4.3 抽头和溢出检查

#### 4.3.1 概念说明

这是本讲最关键、也最容易被忽视的一步。脚本在量化之后并不急着存盘，而是先算「奇地址抽头和」「偶地址抽头和」，并与上界 `MAX_TOTAL = 2**(BIT-2) - 1` 比较，打印 OK 或 NG。

为什么要检查抽头和？因为**硬件累加器的输出会不会溢出，完全由系数决定**。u5-l3 告诉我们：顶层最后一级把 48 位累加结果截到 32 位输出时，不饱和分支取 `ADD_DATA[45:14]`，也就是**丢掉低 14 位**（相当于除以 \(2^{14}\)）。这一刀切下去之后，输出是否还在 32 位有符号范围内，取决于累加器能堆多大——而累加器能堆多大，又取决于「一个过采样样点对应的那些系数的和」有多大。

而一个过采样样点恰好由**一相（奇地址或偶地址）的 256 个抽头**累加得到（u4-l2、u5-l2）。所以必须分别检查奇相抽头和、偶相抽头和，二者都不能超过 `MAX_TOTAL`。这就是脚本第 26~28 行的来历。

#### 4.3.2 核心流程

先看脚本如何切分与比较：

```
Total_Odd  = np.sum(coef_int[1::2])   # 奇地址抽头和（LRCK 高电平那一相）
Total_Even = np.sum(coef_int[0::2])   # 偶地址抽头和（LRCK 低电平那一相）
MAX_TOTAL  = 2**(BIT - 2) - 1         # = 2^14 - 1 = 16383
```

`MAX_TOTAL` 的值不是拍脑袋定的，而是由 u5-l3 的 14 位下移严格推导出来。设一个多相分支的系数和为 \(S\)，输入为满量程直流 \(D_{\max}\approx 2^{31}\)（32 位有符号最大值），则该相累加器（256 次乘加）近似为

\[
A \;=\; \sum_{i} D_{\max}\cdot c_i \;=\; D_{\max}\cdot S .
\]

输出级把它右移 14 位：

\[
Y \;=\; A\,/\,2^{14} \;=\; D_{\max}\cdot S\,/\,2^{14}.
\]

要求输出不超出 32 位有符号范围（\(Y \le 2^{31}-1\)，且不触发饱和）：

\[
D_{\max}\cdot S\,/\,2^{14} \;\le\; 2^{31}
\;\Longrightarrow\;
S \;\le\; 2^{14} \;=\; 2^{BIT-2}.
\]

因此每个分支的系数和上限为整数

\[
S_{\max} \;=\; 2^{BIT-2}-1 \;=\; 2^{14}-1 \;=\; 16383,
\]

正是脚本里的 `MAX_TOTAL`。注意 \(14 = BIT - 2\)，所以 `MAX_TOTAL` 的指数 `BIT-2` 直接对应输出级丢掉的 14 位——两者是同一个数字的两种写法。

> 与 u5-l3 的呼应：u5-l3 的饱和判断依赖「`bit47` 恒等于 `bit46`」的前提，并注明「由 u6-l1 系数生成的 `MAX_TOTAL` 抽头和检查从源头保证」。本模块就是那个「源头保证」：只要奇、偶抽头和都 ≤ `MAX_TOTAL`，任何合法范围内的输入都不会让累加器越过线性区，饱和分支永不触发，滤波器在全量程内保持线性。

#### 4.3.5 小练习与答案

**练习 1**：若把 `BIT` 改成 14（系数 14 位），`MAX_TOTAL` 变成多少？输出级应丢掉多少位才能与之匹配？
> **答案**：`MAX_TOTAL = 2^(14-2) - 1 = 2^12 - 1 = 4095`。匹配的输出级下移位数为 `BIT-2 = 12` 位。这说明 `MAX_TOTAL`、系数位宽、输出级截位三者是绑定关系，改一处要同步改另两处。

**练习 2**：为什么检查要分奇、偶两次，而不是只检查全部抽头的总和？
> **答案**：因为硬件是按多相两相分别累加的（u4-l2），每个过采样样点只用到其中一相的 256 个抽头。可能存在「总和合格但某一相超标」的情况，所以必须对每一相单独检查，才能保证每一路过采样输出都不溢出。

**练习 3**：脚本里 NG 时只是打印警告、仍会照常保存 `.txt`。如果你拿到一份 NG 的系数直接烧进 ROM，u5-l3 的饱和分支会发生什么？
> **答案**：满量程输入时累加结果会越过线性区，u5-l3 的饱和分支被触发，输出被钳到 `0x7FFF_FFFF`/`0x8000_0000`，产生削顶失真；正因为如此，才要在系数生成阶段（本讲）就把 NG 的系数拦下来。

## 6. 本讲小结

- `firwin(TAPS-1, FC, window='hann')` 用窗函数法设计 2 倍过采样的抗镜像低通；末尾 `/2` 是为定点量化与溢出余量做的增益归一。
- 浮点系数通过「平移 + 缩放 + 四舍五入 + 搬回有符号」量化为 16 位有符号整数；`np.insert(coef_int, 0, 0)` 在最前补零，把 511 变成偶数 512，补的零进入偶地址分支。
- 奇地址抽头 `coef_int[1::2]` 与偶地址抽头 `coef_int[0::2]` 正是硬件 `SPROM_CONT` 两相扫描、各自累加 256 次的两个多相子滤波器——Python 的切片与硬件的寻址在此精确对应。
- 抽头和上界 `MAX_TOTAL = 2^(BIT-2) - 1 = 16383` 由 u5-l3 输出级「丢低 14 位」严格推导而来；保证每相抽头和 ≤ `MAX_TOTAL`，就能让全量程输入永不触发饱和，滤波器保持线性。
- 本讲只产出十进制 `.txt`；要进 ROM 还需经 `dec2hex.awk` 做二补码十六进制转换与重排，见 u6-l2。
