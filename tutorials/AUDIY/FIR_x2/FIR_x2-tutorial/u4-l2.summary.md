本讲打开被 FIR_COEF 当黑盒使用的控制器 SPROM_CONT，揭示它在单 MCLK 时钟域内完成的三件事：一、奇偶多相寻址——地址寄存器 CADDR_REG 由「高位每拍自增、最低位直接跟随 LRCK_I」一行拼接，使 LRCK 高电平扫奇地址、低电平扫偶地址，每相 256 次乘加，恰好填满一个 LRCK 周期；二、反向地址映射——真正送 ROM 的是其按位取反 CADDRO_REG = ~CADDR_REG，让系数按卷积所需的倒序读出，.hex 系数排布必须与此配套；三、过采样时钟派生——无需外部 PLL，LRCKx = CADDR_REG[W-1]（即 2×LRCK），它的一个完整周期恰等于累加一个过采样样点所需的时间，下降沿触发下游 ADD 输出并清零，BCKx = CADDR_REG[W-7]（即 2×BCK），并以 W≥8 选位、W≥7 决定派生或兜底 MCLK 两道阈值，前提是标准音频时钟比例（32 位立体声）。需注意本讲所见的 LRCKx_O/BCKx_O 是 FIR_COEF 打拍对齐前的「原始版」，且 NRST_I 虽声明但逻辑未用，寄存器全靠上电初值。关键术语：多相分解、CADDR_REG/CADDRO_REG、LRCKx_REG/BCKx_REG、ROM_ADDR_WIDTH（默认 9）。
