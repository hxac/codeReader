本讲承接 u2-l2，解答「配置值分好后如何守住软硬边界」。配置分两个可见性等级：VX_config（HW/sim 私有微架构参数）与 VX_types（软硬件共享的 ISA/ABI 契约）；内存映射、页表格式等真正契约被特意从 config 搬进 types，使公共运行时头 vortex2.h 刻意自包含。软件取配置走四条合法通道——VX_types.h、vx_device_query() 运行时查询、config.mk、gen_config.py --cflags 注入的 -D 标志——唯独不 include VX_config.h。两道 CI 守卫机械执行：守卫①check_config_boundary.sh 用一条 grep 禁止 sw/、tests/ include VX_config.h；守卫②check_sw_sim_boundary.sh 强制 sw/{kernel,runtime} 与 sim/+hw/ 双向隔离，且 #include 文本与 Makefile -I 路径双管齐下（opae 后端因 FPGA AFU 绑定显式豁免）。sw/common/ 是唯一合法的跨层共享通道，四层可访问、永不安装、不在任何守卫扫描范围内。
