本讲是 SimX 核心流水线最前端，覆盖 Scheduler、CtaDispatcher、BarrierUnit 与 IPDOM 栈四个最小模块。warp_t 持有 PC、线程掩码 tmask、发散栈 ipdom_stack 与 CTA CSR 快照，寄存器堆另置于 OpcUnit。Scheduler 用 active_warps_ 加 stalled_warps_（当前态）/stalled_warps_next_（下一态）双拍掩码管理就绪，schedule() 每拍派发新 warp、选首个就绪者、装填 trace 并 suspend，末尾统一推进状态，确保本拍释放者不会本拍重选——这是与 RTL cycle 级 model_parity 的前提。CtaDispatcher 把 KMU 产出的 CTA 按 ceil(block_size/NUM_THREADS) 切成 warp rank，用固定步长 LMEM 槽位接纳、cluster 成员占连续槽以支撑后续 DXA 多播，经 activate_warp 写入 warp 状态。BarrierUnit 以到达计数加代际 phase 实现本地与全局屏障，wait_mask 只记真正挂起的 warp、arrival_mask 跟踪全局到达，异步事件靠 events 计数延迟释放。IPDOM 栈在分支发散点压入汇聚掩码与 else 入口，SPLIT 先走线程较少一边、JOIN 两次汇聚，于最近共同后继重新合并。
