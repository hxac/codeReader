Vortex 是全栈开源 RISC-V GPGPU：从主机程序到 FPGA 比特流都在同一仓库，通过 libvortex.so 这一 stub 分发器按环境变量 $VORTEX_DRIVER 在 simx（C++ 仿真）、rtlsim、opae（Intel FPGA）、xrt（Xilinx FPGA）四种后端间切换，由单一驱动脚本控制。设计哲学是先在 simx 原型化、再前推到 RTL，且两者必须保持功能与时序一致（model_parity），调试时 simx 可作 RTL 的 oracle。

执行采用 SIMT 模型，每周期发射一个 warp：thread 是最小单位（各有 32 整型与 32 浮点寄存器），warp 内线程共享 PC、靠 thread mask 控制写回，多个 warp 按周期时间复用以隐藏延迟；硬件聚类层次中 socket 共享 L1、cluster 共享 L2，构成可扩展性的组织方式。Vortex 仅对 RISC-V 做最小化扩展，加入 TMC、WSPAWN、SPLIT、JOIN、PRED、BAR 六条类 GPU 控制指令，其中 SPLIT/JOIN 依赖 IPDOM 栈实现 warp 内分支发散与汇聚。核心是一条 6 级流水线 Schedule→Fetch→Decode→Issue→Execute→Commit（Schedule 含 Warp Scheduler 与 IPDOM Stack，Issue 含 IBuffer 与 Scoreboard，Execute 含 ALU/FPU/LSU/SFU/TCU），是 SimX 与 RTL 两套实现的共同骨架。
