本讲覆盖 Vortex 图形固定功能（FF）硬件栈三段：RASTER 光栅化、TEX 纹理采样、OM 输出合并（ROP）。三者 cluster 共享、全定点通路，遵循「FF 快路径 + 设备侧软件回退」双路原则。关键差异：RASTER 为 push 模型，由 draw launch 发 frame_kick 自驱动覆盖率行走（边函数求值、quad 覆盖测试），把覆盖 quad 推给 SIMT 核启动 fragment CTA；TEX/OM 则作为 SFU 处理单元，由 FS 经 vx_tex4/vx_om4 调用，操作数经 per-warp 的 gfx 寄存器窗口（记分板、按序退休）交接。每段配一套 cluster cache：tcache/rcache/ocache，唯 ocache 可写（写穿）并作 early-Z 相干读口。核心结论：early-Z 用「严格在后方」判定做遮挡剔除，与纯 ROP 路径像素一致，OM 始终为权威 late-Z；三者均 custom1 槽 RISC-V ISA 扩展，靠 funct3 区分并由配置宏门控。SimX 与 RTL 逐模块对应、early-Z 逐位对齐，是 graphics_parity 及 model parity（u7-l4）主线的物理基础。
