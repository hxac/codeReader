本讲承接 u5-l1 的 SimObject/SimChannel/SimPlatform 三基元，讲清 SimX 如何把零件组装成一台完整 GPU 并按下启动键。最小模块有四：一是 `main.cpp`，它是 SimX 的独立 CLI 入口，按「建 RAM 与 Processor → 写一组 KMU DCR → 按后缀加载镜像 → `while(cycle())` → 刷缓存 → 读退出码」推进，以「全 1」的 grid/block/cluster 维度配置出最小单 CTA 启动。二是 `Processor`，作为 GPU 顶层，用 Pimpl 模式持有全局唯一的 KMU、唯一 DRAM（`Memory`）、唯一 L3 和一组 Cluster，并按地址区间路由 DCR：KMU DCR 只发给 KMU，其余广播给 cluster 树，读 `CACHE_FLUSH` 则触发脏行回写。三是实例化层次 `Processor→Cluster→Socket→Core`，其中 `NUM_SOCKETS=NUM_CORES/SOCKET_SIZE`，共享边界为 socket 内共享 L1、cluster 内共享 L2、全局共享 L3/DRAM；L3 不使能时退化为透明仲裁器。四是运行循环：`cycle()` 用懒初始化隐式完成 reset 与 `kmu->start`，`any_running()` 仅在「所有 core 不运行且无在途 channel 包」时返回假，确保读回结果前所有写已落地。关键术语包括 KMU、CTA、DCR 路由、`VX_CFG_*` 配置宏与 `inflight_count`，供后续讲义承接。
