本讲拆解 Vortex 硬件光线追踪单元（RTU，代号 PRISM），它把 RISC-V 扩展为异步 BVH 遍历加速器，执行模型为「异步遍历 + 寄存器窗口 + 回调陷阱」：warp 用 TRACE2 提交射线立即拿 handle，RTU 离线遍历，命中结果经记分板化的图形寄存器窗口（32 槽、软硬件共享 ABI）送回；遇非不透明三角形或 procedural AABB 则 yield，warp 陷入异步回调陷阱（AHS/IS/CHS/MISS）跑着色器后用 CB_RET 释放。RTU 与图形固定功能共享 custom1 opcode 扩展与 RTCache，由 VX_CFG_EXT_RTU_ENABLE 门控。引入的关键术语有 BVH/CW-BVH、TLAS/BLAS 两层结构、Möller–Trumbore 与 slab 求交、仿射逆变换。SimX 四个最小模块为 rtu_unit（每核 SFU 前端，展开宏指令、管理 WAIT 的 park/revive）、rtu_walker（FlatWalker/Bvh4Walker 就近优先深度优先遍历，无界栈不漏命中）、rtu_isect（相交数学与 BoxPe/TriPe 流水周期代价「issues+LATENCY−1」）、rtu_core（集群 SELECT/EXEC 两相编排与回调重整）。核心结论：SimX 作为功能 oracle 用功能结果反推时序、逐模块对应 RTL 维持 model parity；v2 窗口 ABI 把十余条 marshalling 折叠成一条 trace 加一条 wait。
