本讲打开 Vortex 虚拟内存子系统（VM）。核心结论是 v3 模型：地址翻译只在两处发生——计算核每核硬件 MMU（位于 coalescer 之后、dcache 之前）与命令处理器 CP 的 DMA 软件遍历器 cp_translate；主机运行时 API 只认虚拟地址（VA），传输时不翻译，改由 CP 用 CP_SATP 走页表翻成物理地址（PA）。页表遵循 RISC-V Sv32（2 级、4B PTE、每级 10 位 VPN）/Sv39（3 级、8B PTE、每级 9 位 VPN），SATP 指向根表，逐级读页表项 PTE，叶子看 R/W/X，V=0 或 R=0&W=1 判无效触发页错误。SimX 每核含 dcache/icache 两个 TLB（32 项全相联 CAM、MRU 替换、换 SATP 即 flush）与内嵌 PTW（4 状态加层级计数器 FSM，通用支持 Sv32/Sv39，PTE 读经同一缓存端口靠 PTW_TAG_MARKER 区分，做真实页错误检查）。主机 VMManager 维护 PA/VA 双分配器与影子页表，按 PT 页批量 DMA flush，并用 page_table_walk 断言往返一致。待确认差异：RTL PTW 当前硬编码 Sv32 两级、不查权限标志，页错误与 Sv39 尚未交付，FPGA 上仅 RV32/Sv32 VM 可用。
