本讲义讲解 Vortex 的张量核（TCU，Tensor Core Unit）——一个把 RISC-V 扩展为矩阵乘加速器的硬件单元，由 `VX_CFG_EXT_TCU_ENABLE` 开启。核心区分两类指令：WMMA（单 warp、操作数全来自寄存器）与 WGMMA（warpgroup 协同、B 必来自本地内存 LMEM）。WGMMA 靠「共享 B 广播 + 每块私有 A」最大化算术强度。分块几何仅由 `NT=NUM_THREADS` 与 `NRC` 决定，衍生出微块 `tcM×tcN`、每 warp 输出瓦片 `xtileM×xtileN` 与 K 归约 `tileK`；一条宏指令被展开为 `k_steps*NRC` 条 uop（顺序 k 外、n 中、m 内）。kernel 侧经 `vx_tensor.h` 的 fragment 抽象与 `wgmma_sync` 内联函数把矩阵乘编码成 custom0 指令（`func3=1` 表 WGMMA），并用 32 位 smem 描述符把 LMEM 矩阵交给硬件。SimX 用三件套建模：`TcuUnit`（FuncUnit 壳）、`TcuUopGen`（uop 展开）、`TcuTbuf`（Q+1 路 line cache 仲裁到单一 LMEM 端口），遵循基数规则与 CTA lockstep 不变量（共享 bbuf 单 CTA 占有），与 RTL 逐模块对应实现 model_parity。此外支持 2:4 结构化稀疏（独立 `*_SP` opcode + 位置元数据 gather，K 步数减半）与 MX 块缩放量化（A/B 独立 scale SRAM）。FEDP 点积后端（DPI/DSP/BHF/TFR）延迟随配置不同，由 channel delay 承载。本讲承接 u6-l4 的 FuncUnit 模型，为 u9-l2（DXA 异步拷贝）的「DMA 喂数据 → TCU 消费」通路铺垫。
