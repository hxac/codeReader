本讲承接 u14-l1，从「Vortex 如何上板」转向「如何被综合、如何产出 PPA 报告」。核心是 `hw/syn/` 下四条共享同一骨架的综合流程：Xilinx Vivado（XRT 主路径，产出 `.xclbin`）、Altera Quartus（已废弃）、Yosys（开源 ASIC）、Synopsys Design Compiler（商用 ASIC）。统一骨架为：人类可读的 `CONFIGS` 经 `gen_config.py` 投影成完整 `XCONFIGS` 宏集，`extensions.mk` 据此按 TCU/DXA/RTU 等扩展接线，`gen_sources.sh` 收集并预处理 RTL 生成 VCS 风格 `sources.txt`，`PREFIX` 隔离多构建——四条流程的差异只在最后调用的工具命令。FPGA 与 ASIC 都额外提供 DUT 流程，把单个子部件剥离平台外壳单独综合以快速评估 PPA。ASIC 双轨的核心差异在 SRAM 处理（黑盒估算 / 工具推断 / 真实宏单元 wrapper）与库选择（`LIB_TYPE` 驱动 NanGate/ASAP7/SAED14），SRAM 面积统一用位宽×深度×0.1+100 公式估算。PPA 三件套：Fmax 由时序报告的 WNS 经 `1000/(周期−WNS)` 反推，面积在 ASIC 读 µm²、FPGA 读 LUT/FF/BRAM/DSP 个数，功耗分动态与静态；功耗分析的关键二分是 vectorless（默认 12.5% 翻转率基线）与 SAIF/VCD 活动标注（真实负载），用 `SAIF_INST` 剥离 testbench 前缀对齐信号。关键术语包括 WNS/TNS、`XCONFIGS`、`extensions.mk`、`NUM_CORES` 语法糖、`OPT_LEVEL`、`SAIF_INST`，其中 `gen_config.py --cflags` 是综合侧与配置真相来源的唯一接口。
