本讲解析 ADI HDL 的 `library/jesd204` 分层框架——它是数据转换器（ADC/DAC/收发器）与 FPGA 之间高速串行链路 JESD204 的实现，严格遵循「物理 / 链路 / 传输 / 应用」四层模型。物理层由 FPGA 决定（`util_adxcvr`/`axi_adxcvr` 等 GT 收发器，可选软 PCS `jesd204_soft_pcs`，做 8B/10B 或 64B/66B 编解码）；链路层由方向决定（`jesd204_rx`/`jesd204_tx`）；传输层由转换器类型决定（`tpl_adc` 解帧、`tpl_dac` 组帧）；应用层留给用户。关键术语包括 lane、链路参数 L/M/F/S/N/NP/K，以及 link clock、device clock、SYSREF、LMFC、CGS、ILAS 等时序与握手概念，并由 `LINK_MODE` 区分 JESD204B 与 JESD204C。核心结论：`axi_jesd204_rx/tx` 给纯协议核心套 AXI4-Lite 壳，复用 `up_axi` 桥，寄存器按地址段拆给 common/sysref/rx(tx) 三个子模块、读数据按位或合并；传输层把链路字节流与通道采样互换，位宽完全由 JESD 参数决定，`tpl_dac` 另含 DDS、IQ 校正与 pattern 发生。真实工程通过 `ad_xcvrcon` 与 `link_data/valid/sof` 等信号把四层串成从 RF 采样到 PS DDR 的完整通路。
