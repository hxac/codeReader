本讲拆解库侧打包主入口 *_ip.tcl 与共用原语库 adi_ip_xilinx.tcl，核心结论有三。其一，「Verilog→IP」固定三步走：adi_ip_create 建工程、做版本校验并注册 ADI library 为 IP 仓库以引用子 IP；adi_ip_files 按后缀分流源码与约束并设顶层；adi_ip_properties 经 package_project 升格为 IP，先清空接口，再固化推断出每个 ADI IP 必备的 AXI4-Lite 寄存器从接口 s_axi 及地址映射（大小由地址线位宽推算）。其二，接口描述走两条路：命名标准时用 adi_ip_infer_mm_interfaces 自动推断，命名不标准或自定义时用 adi_add_bus 显式列出端口-逻辑信号映射；adi_add_bus_clock 据复位名是否以 n 收尾判定极性，adi_set_bus_dependency 按参数值控制接口显隐，adi_if_define/adi_if_infer_bus 用于自定义总线。其三，adi_ip_bd 与 adi_ip_ttcl 仅在打包时把 bd.tcl、*.ttcl 登记进 component.xml，二者分别于块设计时、IP 综合时执行；bd.tcl 的 propagate 判定时钟域异步关系并写 ASYNC_CLK_*，ttcl 读之按需生成 CDC 约束，构成反馈环。关键术语：VLNV、IP-XACT/component.xml、块设计（BD）。
