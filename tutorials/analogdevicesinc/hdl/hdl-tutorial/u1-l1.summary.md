本讲是 ADI HDL 学习手册的开篇，只建立全局印象，不涉及代码细节。核心结论：ADI HDL 仓库是一套面向 ADI 评估板（载有 ADC/DAC、射频收发器等器件）的 FPGA 参考设计素材库，交付物为 Verilog/VHDL 源码加 Tcl 脚本，最终产物是烧入 FPGA 的比特流，而非可执行程序。

本讲覆盖三个最小模块。其一，项目定位与用户：仓库回答「FPGA 该放什么逻辑才能对接 ADI 芯片」，服务于芯片评估者、产品开发者与学习者。其二，library 与 projects 的分工：library/ 是近百个可复用 IP 积木（如 axi_dmac、axi_ad9361）；projects/ 是按「评估板/载板」两层结构拼好的整板参考设计，顶层 Makefile 自动发现目标，命令 `make projname.carrier` 即定位到对应子目录。其三，软硬件配套：hdl 只产硬件，软件驱动分别由 no-OS（裸机）与 linux 仓库提供，三者经 AXI 寄存器映射对接。

引入的关键术语包括：综合/实现/比特流、工具链（Vivado/Quartus/Lattice）、Tcl 自动化、AXI 总线、参考设计、no-OS/Linux、寄存器映射（regmap）。构建入口为命令行 make；生产用 release 分支、尝鲜用 main，二者对应不同工具版本。后续讲义将承接目录结构、工具链版本与首个工程构建。
