本讲是 ADI HDL 文档体系的「索引导览」。核心结论是：`docs/` 是一个独立的 Sphinx 文档项目，其总入口 `docs/index.rst` 通过三个 toctree 把内容划分为三大栏目——面向「用 HDL 的人」的线性操作手册 **User Guide**（架构、构建、移植、编码规范）、面向「查某个 IP 的人」的查阅型数据手册 **Library / IP Cores**（每个 IP 一页）、以及面向「查某块评估板工程」的 **Projects**。导航结构本质就是 toctree 的嵌套。引入的关键术语包括：reStructuredText（rst）标记语言、Sphinx 文档生成器、toctree 目录树、以及 ADI 自研扩展 **adi_doctools**（版本钉死 0.3.47，在 `conf.py` 中声明）。该扩展注册了一批 `hdl-*` 自定义指令——如 `hdl-regmap`、`hdl-parameters`、`hdl-interfaces`、`hdl-component-diagram`，配合 `cosmic` HTML 主题，实现「从源码与文本自动生成表格」。单 IP 文档遵循统一「四件套」结构：组件图→框图→参数→接口→寄存器→原理；其中寄存器表采用「文本源与渲染分离」设计，源文件位于 `docs/regmap/*.txt`（含 TITLE/REG/FIELD 块），由 IP 页面用 `.. hdl-regmap:: :name: XXX` 按简称匹配渲染。本地构建文档属开发者用途，按 README 四步执行：升级 pip→装依赖→（推荐）构建库生成 IP 元数据→`make html`，产物在 `docs/_build/html`；其中构建库一步为参数/接口表提供打包产物（如 component.xml），跳过则部分表格为空。本讲为后续讲义（u2-l1 三层架构、u3 构建系统、u5 IP 深读）提供查阅入口。
