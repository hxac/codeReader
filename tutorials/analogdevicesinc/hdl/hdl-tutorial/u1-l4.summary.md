本讲是入门层收尾篇，以 `projects/fmcomms2/zcu102` 为样本，讲清「命令行 `make` 到 FPGA 比特流」的完整流水线。核心结论：构建链分三段且依赖驱动——顶层 `Makefile` 用 `wildcard`+`foreach` 自动发现工程，把目标名（如 `fmcomms2.zcu102`）的点换斜杠映射到目录并 `make -C` 递归进入；工程 `Makefile` 用 `PROJECT_NAME` 声明工程名，用 `M_DEPS` 收集需直接引用的文件、用 `LIB_DEPS` 收集 library IP 名字，再 `include project-xilinx.mk`；该公共脚本把每个 `LIB_DEPS` 翻译成 `component.xml` 打包目标（即「依赖一个 IP = 依赖其打包产物」），并定义最终产物 `system_top.xsa` 的规则，最终执行 `vivado -mode batch -source system_project.tcl`。引入的关键术语：GNU Make 依赖驱动、比特流、`.xsa` 硬件交付文件、Tcl 脚本、`system_project.tcl` 作为 Vivado 入口脚本按「准备→`adi_project` 建工程搭块设计→`adi_project_files` 加源码→`adi_project_run` 综合实现出比特流」四阶段调度 Vivado；`adi_*` 过程定义于 `adi_project_xilinx.tcl`/`adi_board.tcl`。本工程共依赖 10 个 library IP（如 `axi_ad9361`、`axi_dmac` 等）。块设计拼装、Tcl 原语细节留待后续讲义承接。
