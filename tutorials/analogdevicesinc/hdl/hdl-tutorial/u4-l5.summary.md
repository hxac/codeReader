本讲讲解软件如何控制硬件寄存器，覆盖三层。`up_axi` 是 library/common 下厂商无关的 AXI4-Lite 翻译桥，把五通道握手简化为 `up_wreq/up_wack`、`up_rreq/up_rack` 两对请求/应答，字节地址去掉最低两位得到字地址，并内置看门狗，读超时返回魔数 `0xDEADDEAD`。每个 IP 的 `*_regmap.v`（如 `axi_dmac_regmap.v`）按字地址用 `case` 分派读写，与 docs/regmap/*.txt 寄存器表一一对应，体现位域、读写属性（RW/RW1C/R）与综合参数裁剪语义。CPU 物理地址 = 架构偏移 + IP 基地址 + 寄存器偏移，架构偏移由 `sys_zynq` 经 `ad_cpu_interconnect` 按架构（Zynq-7000 为基准，ZynqMP/Versal 各加不同常数）决定，使同一份评估板脚本可跨载板复用。诊断口诀：读到 `0xDEADDEAD` 说明地址已路由到 IP 但该寄存器无人实现，而总线错误说明地址根本未路由对。
