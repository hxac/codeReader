本讲承接「硬件构建」讲义，回答如何把 HDL 产出的 `system_top.xsa` 打包成 SD 卡上可启动的 `BOOT.BIN`。`BOOT.BIN` 是片上 BootROM 读取的单一容器，由 FSBL、比特流、U-Boot（ZynqMP 另加 PMUFW 与 `bl31.elf`）等分区按 `.bif` 清单经 `bootgen` 拼装。打包引擎 `adi_make_boot_bin.tcl` 用 `hsi` 探测 CPU 型号分派 Zynq/ZynqMP 家族，借 `xsct`/Vitis 自动生成 FSBL 并组装镜像；`adi_make.tcl` 的 `adi_make::boot_bin` 则封装该引擎，为 Vivado 控制台提供一键入口。发布上 ADI 每半年发一个 release 分支、绑定固定工具版本，官方推荐用最新 release 分支，main 的预构建文件未经硬件测试。关键术语：BOOT.BIN、FSBL、PMUFW、bl31.elf、.bif、bootgen、xsct。
