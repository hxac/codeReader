本讲剖析 ADI HDL 中复用最广的 DMA 引擎 `axi_dmac`，负责把数据转换器采样搬进/搬出 PS DDR。顶层是「瘦壳」，仅例化寄存器面 `axi_dmac_regmap` 与数据面 `axi_dmac_transfer`：CPU 经 AXI4-Lite 写寄存器并置 `TRANSFER_SUBMIT`，regmap 打包成 DMA 请求，数据面搬完后回 `TRANSFER_DONE` 与中断；burst 尺寸、缓冲容量与 `ID_WIDTH` 均在综合期由 `localparam` 算定。数据面核心是 `request_arb`：源/目的端各在 MM/Stream/FIFO 三种可插拔通道中三选一，中间夹 store-and-forward 缓冲，两侧靠 burst 级 ID 解耦。`request_generator` 发出 ID，`response_generator`（无外部响应时凭空生成 `RESP_OKAY`）或 `response_handler`（消费真实 AXI `B` 响应）回收 ID 形成闭环；ID 用格雷码自增（`inc_id.vh`）、经 `sync_bits` 跨时钟域。`data_mover` 是流式/FIFO 源侧复用的突发引擎，按 beat 计数、末拍拉 `last`，支持 `SYNC_TRANSFER_START` 与提前 TLAST 的 `rewind`。2D 与 Scatter-Gather 均为「请求展开器」，把矩形或内存描述符链展开成统一格式的一维请求，下游 `request_arb` 无感知；仿真入口 `tb/dma_read_tb`（MM→FIFO）可跑通验证。
