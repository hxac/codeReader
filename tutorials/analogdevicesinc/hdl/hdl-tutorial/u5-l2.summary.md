本讲以 `axi_ad9361` 为例剖析 ADI 数据转换器 IP 的「双通路」结构：寄存器控制面由 CPU 经 AXI4-Lite 写 `up_*` 寄存器配置，`up_axi` 把同一组请求广播给 RX/TX/TDD 子模块、应答按位或汇合（靠 BASE_ADDRESS 分区认领）；数据流通面对外统一用 ENABLE/VALID/DATA 三线表达一路通道，样本恒按 16 位对齐（ADC 符号扩展、DAC 取高位），使 pack/unpack 与 DMA 与具体位宽解耦。采集链为 `axi_ad9361(ADC)→util_wfifo(跨时钟域 l_clk→divclk)→util_cpack2(4×16→64)→axi_dmac(fifo_wr→AXI-MM)→PS DDR`，由 SYNC_TRANSFER_START 同步起拍；回放链方向相反，用 CYCLIC 循环、`util_upack2` 解包、`util_rfifo` 跨时钟域。采集用 wfifo 关注溢出、回放用 rfifo 关注欠溢，整链靠 `util_ad9361_divclk` 把跨时钟域压缩到这两处。延时校准则分两段：构建末尾在 `adi_project_run` 之后 source 的 `axi_ad9361_delay.tcl` 仅报告每根 RX 线的布线延时到日志，运行时由软件据此写 `up_delay_cntrl`（RX 基址 0x02、TX 0x12）寄存器施加抽头，二者不自动闭环。该级联模板可横向迁移至 adrv9001 及 JESD204 类数据转换器。
