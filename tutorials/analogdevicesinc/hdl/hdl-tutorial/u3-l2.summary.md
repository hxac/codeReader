本讲拆解所有 Xilinx 工程共享的公共脚本 project-xilinx.mk。工程 Makefile 用 PROJECT_NAME、M_DEPS（文件依赖）、LIB_DEPS（IP 依赖）「报菜名」，公共脚本用 foreach 把 LIB_DEPS 展开成 library/&lt;ip&gt;/component.xml，汇总出最终产物 system_top.xsa 的依赖。覆盖四个模块：总装配（.xsa 目标经 skip_if_missing 与 build 调 system_project.tcl 驱动 Vivado）、component.xml 打包（模式规则委派库侧 make xilinx，库跑 *_ip.tcl 生成 IP，工程与库职责分离）、flock 并行安全（按 IP 目录加排他锁串行化打包，避免多工程争抢损坏产物；REQUIRED_VIVADO_VERSION 经 make 参数透传到 adi_env.tcl）、CFG 参数化（用 DIR_NAME 子目录隔离变体产物）与 MODE=incr 增量编译（用上轮实现的 system_top_routed.dcp 拷成 reference.dcp，供 Tcl 侧 impl_1 的 incremental_checkpoint 复用以加速时序收敛）。关键结论：工程 Makefile 只声明与触发依赖，真正的 Vivado 执行封装在 Tcl 入口；Make 准备检查点、Tcl 消费检查点，二者协作完成构建。
