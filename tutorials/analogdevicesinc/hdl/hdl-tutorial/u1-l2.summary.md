本讲义把 ADI HDL 仓库「拆开」，讲清各内容放在哪里、为何放在那里。核心有三：其一，顶层分四类——设计源码（`library/` 可复用 IP 积木、`projects/` 整板参考设计）、构建自动化（`Makefile`、`quiet.mk`、三处 `scripts/`）、文档、项目元信息（多份 `LICENSE*`）；仓库无传统程序入口，入口是工程目录下的 `make`。其二，`library/` 是扁平 IP 积木（约 90 余个模块，含 `axi_*`、`util_*` 及 `jesd204`/`spi_engine` 框架）；`projects/` 为「评估板 + 载板」两层结构，工程目录是标准五件套（顶层 Verilog、块设计 Tcl、建工程 Tcl、约束、Makefile），几乎不含新 RTL，只做拼装连线；注意 `projects/common/`（载板基设计）与 `projects/<eval>/common/`（评估板公共设计）的 `common` 含义不同。其三，三处脚本按服务对象分层：全局环境在 `scripts/`（`adi_env.tcl` 声明工具版本）、建工程在 `projects/scripts/`、打包 IP 在 `library/scripts/`。
