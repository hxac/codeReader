本讲为整本手册入门篇，不涉电路细节，依据 README.md 建立学习坐标。核心结论：tiny-gpu 是用 Verilog/SystemVerilog（硬件描述语言）写成的教学型最小 GPU，专为「从零理解 GPU 硬件」优化，区别于追求功能完整的开源 GPU（Miaow、VeriGPU）。

关键概念：须区分 GPU 编程（软件层，如 CUDA）与 GPU 硬件（电路层），本项目只攻后者，kernel 指运行在 GPU 上的代码。三大学习主题——架构、并行化、内存——是后续单元主线，递进关系为：拆分部件→core 内并行→内存带宽成瓶颈需控制器节流；并行的根基是 SIMD（单指令多数据）。源码为 src/ 下约 12 个 .sv 文件，覆盖顶层、派发、core、内存控制器及取指/译码/ALU/访存/寄存器/PC 等部件。

简化是项目「tiny」之本：一次单 kernel、数据与程序内存分离且容量小、cache 仅占位、PC 收敛假设（即忽略分支分歧 branch divergence）、无流水线、无 warp 调度；这些被砍掉的优化正是真实 GPU 重点，留待 Unit 7 讨论。
