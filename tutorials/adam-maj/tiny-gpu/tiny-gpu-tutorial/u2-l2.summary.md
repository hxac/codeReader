本讲解析内核启动的最小模块 DCR（dcr.sv）与 Dispatcher（dispatch.sv），由顶层 gpu.sv 串接。DCR 是一个 8 位寄存器，主机经 write_enable + data 写入 thread_count（非阻塞赋值，下一拍才生效），设定本次内核线程数。Dispatcher 按向上取整式 total_blocks = (thread_count + TPB - 1) / TPB 把线程切成 block，每拍执行「派发 + 回收」两个循环：向 core_reset=1 的空闲核派发 block，并回收 core_start && core_done 的核以复用。关键术语包括：thread_count、THREADS_PER_BLOCK（TPB）、block、total_blocks、core_reset/core_start/core_done 握手信号，以及 blocks_dispatched / blocks_done 计数器。核心结论：派发用阻塞赋值使一拍内能向多核依次派不同 block，控制信号用非阻塞故下一拍才对 core 生效；最后一块走尾数分支 thread_count - blocks_dispatched*TPB；done 在所有 block 收回、blocks_done==total_blocks 命中后下一拍才拉高。core_done 源自 core 内 scheduler 跑到 RET 指令，其内部状态机细节留待后续讲义展开。
