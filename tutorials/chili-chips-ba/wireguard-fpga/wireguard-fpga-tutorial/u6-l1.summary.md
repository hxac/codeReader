本讲是 Unit 6 软件控制面首篇，围绕 picoRV32 软核上跑的裸机 C/C++ 固件讲三件事。一是软件架构：以 WireGuard Agent 为核心实现 Noise 握手，外围是 curve25519、chacha20poly1305、blake2s、hkdf、random、timer 等密码与 I/O 原语，均裁剪成无 OS、无 libc、无动态分配形态；握手完成后经 HAL/CSR 把会话密钥与路由写入数据面表，线速转发交硬件承担。二是 bare-metal 启动：boot_crt.s 充当最小 CRT（C Run Time），完成搬运 .data、清零 .bss、设 sp/gp 后 call main 三步，main 返回死循环兜底；关键在于哈佛架构下 .data 的 LMA（加载地址，在 IMEM）与 VMA（运行地址，在 DMEM）不同，启动时必须跨存储器搬运。三是内存映射：CPU 地址空间分 IMEM 0x0000_0000（指令 BRAM）、DMEM 0x1000_0000（数据 BRAM）、CSR 0x2000_0000（MMIO 外设）三段。核心结论是三者基址由 link_map.lds、csr.rdl 的 wireguard addrmap、HAL csr_vp_t 硬编码基址三方维护、完全一致；而 CSR 作为内存映射 I/O 在链接脚本里没有独立段，靠 HAL 指针加 soc_fabric 地址译码访问。
