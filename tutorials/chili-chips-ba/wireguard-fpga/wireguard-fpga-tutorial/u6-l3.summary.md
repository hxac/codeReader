本讲讲解运行在 picoRV32 软核上的裸机网络栈与 CLI。最小模块含三块：ethernet.c 把 cpu_fifo 的 128 位 AXIS beat 收发封装为 eth_send/eth_receive_packet，暴露带 dst/src/bypass 元数据的 eth_raw_packet_t，发送用 tkeep 收紧末 beat、接收用数低位连续 1 反推长度，二者互逆。network.c 是极简协议栈，仅实现 IP 解析、ARP 应答、ICMP Echo 应答与 Internet 校验和（16 位大端字累加、进位绕回、取反），所有 CPU 应答置 bypass_all=1、dst=src 原路绕过 DPE 加解密流水线；协议头用 uint8_t 字节数组按网络大端序描述以回避字节序。string_bare.c 是无 libc 裸机环境下的迷你字符串库加数值/IP 解析。CLI 用 strcmp 链派发，config routes 以逐项问卷交互，写硬件路由表（external regfile，tdp_ram 实现）前后用 FCR 的 pause/idle 握手包成原子区间。主循环单线程协作式，UDP 分支仅识别，为 WireGuard 握手 Agent 预留挂载点。
