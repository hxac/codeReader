本讲建立 wireguard-fpga 的「两层架构」心智模型：系统按职责分为控制面（控制 plane）与数据面（数据 plane）。控制面是跑在片上软 CPU（picoRV32）里的 C 固件，以 WireGuard Agent 为核心，配 Curve25519、BLAKE2s/HKDF、Routing DB Updater 等组件，负责低频但需复杂逻辑的握手与路由管理；数据面是纯 RTL 的 DPE（Data Plane Engine），由接入层（PHY/MAC/FIFO）、流水线（Parser/Disassembler/Decryptor/IP Lookup/Encryptor/Assembler/Mux/Demux）和 ChaCha20-Poly1305 加密核组成，以线速（≥4Gbps、~6Mpps）做加解密转发。两者分离的依据是「软件灵活但慢、硬件快但死板」。系统有两类流量：稀疏的握手控制流量（必须进控制面被处理）和线速用户数据流量（全程在数据面闭环，不进 CPU）。两个面之间唯一的桥梁是 CSR HAL，由一份 csr.rdl 经 PeakRDL 自动生成硬件 RTL 和软件 HAL，承担三类通信——包级（cpu_fifo 把 128 位 AXIS 拆成 32 位 CSR）、表级（routing_table/cryptokey_table 用 tdp_ram 双口 RAM）、控制级（FCR 的 pause/idle 做原子更新）。关键术语 CSR、HAL、DPE、AXIS、FCR、tdp_ram 将在 u2-l2（顶层模块）、u2-l4（总线 fabric）、Unit 3（CSR 细节）承接。需注意当前 HEAD 处于 Phase1 PoC：完整 WG 加解密链源码已写好，但 top.filelist 编入的是直通的 dpe_dummy_switch，bitstream 实为明文直通加软件桥接。
