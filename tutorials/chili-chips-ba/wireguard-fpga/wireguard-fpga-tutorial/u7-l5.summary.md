本讲是 Unit 7 仿真协同验证的收尾，补齐最后三块「胶水」。其一，mem_model 是一块 C 实现、按需分页的稀疏内存，扮演 C++ 用户代码与 HDL 测试台之间的「跨域共享黑板」：C++ 端经 WriteRamWord/ReadRamWord 直通、HDL 端经 Avalon 风格四套端口（寄存器单字、突发读、突发写、SRAM 写）由 DPI 落到同一副本，多实例与所有 VProc node 共享。其二，VUserMainPcap 用 node1/3 按 PCAP 时间间隔发 idle 回放、node2/4 用回调录制，以 GMII 的 8 ns tick 对齐 TX/RX 时间戳，测出「开始到开始」延迟；录制 node 必须持续发 idle 推进时间，回调才会被触发（承接 u7-l4「接收搭发送便车」）。PcapIO.h 靠四种魔数识别大小端与微秒/纳秒。其三，4.sim/rtl/ 下逐模块测试台脱离 VProc、用纯 Verilator 跑，分「定向激励型」与「PCAP 驱动型」（dpe_pcapreader/writer 当黄金向量）两种风格，是开发期快迭代利器。
