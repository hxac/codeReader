本讲把 u7-l2 的 VUserMain0 从「手写测试代码」升级为 rv32 RISC-V 指令集模拟器（ISS）的宿主程序：以预编译库 librv32lnx.a 提供的 rv32 嵌套在 VProc 之上，加载并解释执行真实 RISC-V 二进制（read_elf 或 -B 裸二进制），用软件解释替代 RTL CPU 逐拍推进以加速仿真，丢失的逐拍精度由 timing model 补回。

核心机制有二。其一是**外部访问区**：ISS 每次访存回调 ext_mem_access，由 -x/-X 划定的半开区间 [base,top) 决定该访问走 HDL 总线（VWriteBE/VRead）还是 mem_model 稀疏内存（WriteRamWord/ReadRamWord）；典型分工为 CSR（0x20000000 起）走 HDL、IMEM/DMEM 走 mem_model，默认区间为空即全不走总线，无总线期间以 max_sync_diff=1000 延迟同步压低 DPI-C 往返。其二是 **timing model**：指令分 linear/jump/load/store/trap/mul_div/float 七类、各赋周期数，预置 7 个核模型（DEFAULT、PICORV32 等），用 -V 在 vusermain.cfg 切换，使 mcycle 贴近真实核。改二进制或 vusermain.cfg 无需重建仿真，仅改 HDL 或 usercode C++ 才需重编。
