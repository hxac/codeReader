本讲讲解测试台里可替换的 CPU 子系统——VProc 虚拟处理器。它在 HDL 里只留空壳，靠 DPI-C 接收主机原生编译的 C++ 程序下发的读写与推进请求，用户线程与仿真器以每次 write/read/tick 为同步点 lock-step 推进，故称协同仿真。核心 API 为 write(addr,data)、read(addr,&data)、tick(n)，地址为字节地址，tick(GO_TO_SLEEP) 供程序末尾长睡。soc_cpu.VPROC 是适配器，用几个组合门把 VProc 通用总线翻译成本地 soc_if，并按地址高位区分 IMEM（本地 mem_model）与总线访问，端口与 RTL 版 soc_cpu 一致，可插拔顶替 picoRV32；每个 node 有一个 C 链接入口 VUserMain<n>，node 0 即 soc_cpu 的 VUserMain0。其上还有自动生成的协同仿真 HAL（csr_cosim.h），与硬件 HAL（csr_hw.h）类层级同名，靠 VPROC 宏经 wireguard_regs.h 二选一，使同一份应用源码在真硬件与协同仿真间零修改切换，并附 VTick 注入随机时序压测。后续 u7-l3 将把入口换成 rv32 指令集模拟器跑真实 RISC-V 固件，u7-l4 用 node 1–4 的 VProc 驱动以太网 VIP。
