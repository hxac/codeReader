本讲为《ncnn_llm 学习手册》开篇，建立项目全局画像。核心结论：ncnn_llm 是构建于 ncnn 之上的轻量级 C++ 推理运行时（非训练框架），面向边缘设备、桌面 CPU 与 Vulkan GPU 的本地推理，起源于 nihui 对 ncnn kvcache 的实验性工作。其统一管线仅接受文本、图像、音频三类输入，产出文本与向量两类输出，中间由按 model.json 切换的共享运行时调度；共支持 LLM、VLM、OCR、ASR、翻译、嵌入六大类十一个模型，对应 llm_ncnn_run、ocr_main 等示例 target。贯穿全书的设计主线是跨模型族共享 decoder 与 KV cache 运行时。本讲确立了 ncnn（通用推理引擎地基）与 ncnn_llm（负责分词、RoPE、KV cache、prefill/generate、采样的上层调度）的分工，经 xmake.lua 的 add_requires("ncnn master") 显式链接。引入的关键术语含 runtime、KV cache、tokenizer、embedding、自回归与采样，供后续讲义承接。
