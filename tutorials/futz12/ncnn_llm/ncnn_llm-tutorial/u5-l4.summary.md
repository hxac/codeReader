本讲把前几讲的零件拼成完整的图文 prefill 流水线，聚焦 `ncnn_llm_gpt::prefill(input_text, bgr, ctx)` 这一带图像、带历史上下文的重载。结论是它与纯文本首发共享约七成骨架（embed、两段 decoder、proj_out、argmax），差异集中在四个最小模块。第一，`clone_ctx` 先克隆调用方 ctx 再在副本上修改，靠 `ncnn::Mat` 浅拷贝加「读旧写新」保护历史上下文，支撑多轮分叉与回退。第二，视觉前端 `get_visiual_features` 把 BGR 图变成 `image_embeds (hidden_dim, H)` 并输出 patch 网格；`inject_image_embeds` 把文本里唯一的 `<|image_pad|>` 占位符展开成 H 个真实图像嵌入，序列因此变长。第三，图像分支用多轴 mRoPE（标准按 `mrope_section` 切 t/h/w，或 Qwen3.5-VL 的交错变体硬编码 {11,11,10}），图像 token 在时间轴上被压缩成「行数」步，故 position_id 推进量是 `token_ids.size() − H + num_patches_w/spatial_merge_size`，而非逐 token +1。第四，带历史 KV 的因果掩码宽度为 N + 历史KV行数，历史块全 0 可见、本批块因果下三角，本质是多轮机制而非图像特有。prefill 末尾只做贪心 argmax 产出首个 token，采样交给 generate，返回的 new_ctx 携带更新后的 KV cache、cur_token、position_id 供续写。
