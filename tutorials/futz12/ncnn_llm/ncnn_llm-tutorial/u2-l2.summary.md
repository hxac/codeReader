本讲精读 `ncnn_text_runtime.h/.cpp` 暴露的四个自由函数，它们是「跨模型族共享 decoder + KV cache 运行时」设计主线的落地。首先确立 ncnn 调用三步模式：`create_extractor()` → `input("inN", …)` → `extract("outN", …)`，输入输出靠字符串插槽名（默认 `in0/out0`）绑定。四个函数依次构成推理链：`llm_run_text_embed` 把 token id（单/多）经 embed 网络变 embedding，含「外部指针 + `.clone()`」内存安全模式；`llm_run_decoder_with_kv` 是核心，按层号拼接 `cache_k%d/cache_v%d`（入）与 `out_cache_k%d/out_cache_v%d`（出）这一与导出脚本的隐式契约读写 KV cache，并用 `is_prefill` 开关决定 prefill 走 `emplace_back` 追加、decode 走原地覆盖；`llm_run_lm_head` 将 hidden states 投影为词表 logits，prefill 需先 `row_range` 切最后一行；`llm_select_next_token` 是带 repetition penalty 的共享版采样，对历史 token 的分数「负乘正除以 ρ」后再走贪心或 softmax+top_k+top_p+离散抽样，与基类 `sample_logits` 构成本项目两套采样实现。这四函数被 LLM/OCR/ASR 三模态原样复用，唯一例外是带 `sconv_cnt`/`gdr_cnt` 的 Qwen3.5 混合架构在 generate 里内联展开 decoder。关键术语 `is_prefill`、`attn_cnt`、`LlmTokenSampleConfig`、`KVCache` 将由 u2-l3、u2-l4 承接。
