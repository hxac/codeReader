本讲讲解 Qwen3-ASR 语音识别运行时 ncnn_llm_asr，将 PCM 波形转写为文字。端到端链路：PCM → log-mel 频谱 → 分块卷积 audio_conv → audio_encoder → 拼入文本 decoder → lm_head → 贪心解码。运行时继承 ncnn_llm_base，自带 6 个子网（mel/audio_conv/audio_encoder 与 text_embed/text_decoder/lm_head）。核心换算：16kHz 单声道每秒约 100 mel 帧，每 100 帧压成 13 个音频 token（即每秒约 13 个），由静态函数 feat_out_len(n) 用 Python floor 除法复刻导出脚本给出。注入机制：prompt 放 L 个 <|audio_pad|> 占位符，text_embed 查表后用音频嵌入逐行覆盖，再复用 u2-l2 的共享运行时函数走 prefill/generate。两个关键取舍：RoPE 用 theta=1e6 适配长音频序列；构造时关闭所有 fp16/bf16 走纯 fp32 以保数值精度。generate 比文本 LLM 多了特殊 token 跳过解码过滤，transcribe 则按 <|asr_text|> 标记把输出切成语言与文字两段。
