本讲彻底打开 `generate` 自回归循环里「选下一个 token」的黑盒，核心是 `sampling.cpp` 四个自由函数与两条采样链路。最小模块包括：`softmax_vec`（带温度的数值稳定 softmax，先减最大值再除温度再 exp，原地改写 logits 为概率）；`apply_top_k`（用 `nth_element` 按「个数」硬截断）与 `apply_top_p`（核采样，按「累计概率」软截断，需全排序），两者均「置零但不重归一化」，靠下游 `std::discrete_distribution` 内部归一化兜底；`sample_from_probs` 用进程级全局 `static std::mt19937` 按权重抽样。`llm_select_next_token` 才是 `generate` 真正调用的完整采样器：先对 `history`（去重的存在性集合，即出现即惩罚）按「负乘正除」做 repetition penalty，再据 `do_sample` 与 `temperature<=0` 判定贪心或采样，抽样前用 `sum` 校验防全零或 NaN 回退 argmax。关键术语包括 logits、temperature、top_k、top_p（核采样）、repetition penalty、贪心解码。本讲强调项目存在两套逐字符相同的采样实现：基类 `sample_logits`（无重复惩罚、成员 `rng_`、仅 NLLB 用）与共享运行时 `llm_select_next_token`（有重复惩罚、全局 `rng`、服务 LLM/VLM/OCR/ASR），两者并存是历史演进产物。
