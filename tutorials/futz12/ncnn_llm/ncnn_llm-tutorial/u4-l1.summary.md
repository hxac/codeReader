本讲打开 prefill 流程里 `generate_rope_embed_cache` 这个「黑盒」，只覆盖纯文本单轴 RoPE，对应 `rope_embed.cpp` 里四个生成函数与 `ncnn_llm_gpt.cpp` 中 `setting.rope.type` 的四选一接线。核心机制：RoPE 把每对相邻维度视作二维向量做旋转，旋转角 θ(m,i)=m·inv_freq_i，其中 inv_freq_i=1/θ_base^(2i/d)，由此形成「低维转得快、高维转得慢」的频率分布，关键性质是点积只依赖相对位置。四个生成函数负责预算 cos_cache/sin_cache 两张表（形状为 (d/2, seqlen)）。**基础版**直接套公式，长位置下高频维度对角度过大导致外推崩坏。**NTK** 用 ntk_theta=θ·α^(d/(d-2)) 差异化拉伸：高频不动、低频周期放大 α 倍。**YaRN** 在本仓库实现里退化为 NTK 的 inv_freq 公式加上 mscale 注意力对比度缩放，经典 yarn_ramp 波长混合为计算但未生效的遗留代码。**LongRoPE** 给每个维度对一个独立、搜索出的因子（SHORT/LONG 两套，按 seqlen 是否超过 original_max_position_embeddings 切换），精度最高、可扩到 128k+。关键术语：inv_freq、rope_head_dim、rope_theta、mscale、short_factor/long_factor、position_id（首轮为 0、续写为当前 token 总数）。type 字段大小写敏感，不匹配会静默回退到基础 RoPE。视觉场景的多轴 mRoPE 与 Hunyuan xdrope 留给下一讲。
