本讲精读纯文本入口 `ncnn_llm_gpt::prefill(input_text)`，把一段字符串变成模型生成的第一个 token，与 generate 的逐 token 续写相对。最小模块按序为：分词（`bpe->encode` + 可选 bos）→ 生成 RoPE cos/sin cache（按 `rope_type` 在基础/NTK/YaRN/LongRoPE 四变体中四选一）→ `embed_net` 把 token id 查表成 `token_embed` → 构造因果掩码 → 两段式 `decoder_net` → `proj_out_net` + argmax。核心结论是 pop_back 两段式设计：主体 N-1 个 token 批量跑 decoder 只取 KV cache、不取 `out0`；末位 token 单独走一遍单 token decode，喂回旧 cache、产出单行 hidden state 经投影得到 logits，同时把 cache 补齐到完整 N 行。关键术语：prefill、KV cache、因果掩码（用 `-1e38f` 屏蔽未来，主体为 (N-1)² 方阵，末位退化为全 0 列向量）、RoPE cache（首轮 position_id 从 0 起算，末位为 N-1）、插槽约定（`in0..in3`、`cache_k%d`、`out_cache_k%d`）、`attn_cnt`、`rope_head_dim`。prefill 末尾为纯贪心 argmax，采样留给 generate。返回的 ctx 携带 `kv_cache`、`cur_token`、`position_id=N` 交给 generate 续写。
