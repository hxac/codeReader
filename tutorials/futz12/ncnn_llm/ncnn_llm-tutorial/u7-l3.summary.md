本讲承接 u7-l2 工具调用机制，补全「工具描述/路由表」与「OpenAI JSON 解析/清洗」两个工程层。核心是两个成对工厂：`make_builtin_tools` 生成供模型阅读的工具描述 JSON 列表，`make_builtin_router` 生成「名字→lambda」路由表，二者因消费者（模型 vs 程序）与访问模式（顺序读 vs 按名查）不同而必须解耦；真正的分发发生在 `tool_callback` 中，靠路由表按名查表执行，补全 u7-l2 留白的回调内部实现。`tool_name_from_openai_tool` 从 `function.name` 取工具身份，`merge_tools_by_name` 据此按「base 优先」去重合并；`parse_messages`/`extract_content` 把多模态 `messages` 压扁成内部 `Message`，仅保留 `type:"text"` 分片；`sanitize_utf8` 把非法 UTF-8 字节替换为 `?`，`strip_image_payloads` 借 `looks_like_base64` 启发式（够长且合法率≥98%）擦除图片载荷。关键术语：工具描述层、实现层、路由表、base 优先去重。工程现状：两个工厂属活路径，`merge_tools_by_name` 及整套 `json_utils` 为 OpenAI 兼容服务端预备、已编译待接线的积木。
