本讲承接 u4-l1 的单轴 RoPE，转向视觉语言模型（VLM/OCR）特有的多轴位置编码。核心动机：图像 patch 是二维网格，单轴递增 position_id 无法区分「水平相邻」与「垂直相邻」，故须把 head_dim 的 d/2 个旋转对按轴配置切分成多段，各段分别携带不同位置轴。讲义覆盖三种解码器侧生成函数：标准 mRoPE 把维度连续切成 t/h/w 三段，由 `mrope_section` 决定段宽，图像 token 时间轴恒定、高度轴用行号、宽度轴用列号；交错 mRoPE 专供 Qwen3.5-VL，按 (t,h,w) 三元组循环排列，硬编码 {11,11,10}、merge_size=2 且仅旋转一半维度；Hunyuan xdrope 扩为 linear/w/h/t 四轴，由 `xdrope_section` 前缀划分，并用 NTK-alpha 基放大频率以扩展上下文。关键术语：`mrope_section`、`xdrope_section`、`pos4`、`spatial_merge_size`、`image_pad_index`、`image_embeds_size`、NTK-alpha。结论：三种函数产物均为 (d/2, seqlen) 的 cos/sin cache，差异仅在各轴 position_id 取值；且解码器侧 mRoPE/xdrope 与 ViT 内部的 `generate_vision_rope_cache_2d` 是两条独立线路。
