本讲在 u6-l1 文本嵌入基础上，给 `ncnn_embedding` 类补齐了图像能力。核心机制是：`model.json` 中 `model_type` 为 `"clip"` 时才创建并加载 `vision_encoder_net`，对外用 `supports_image()`（即该指针非空）做能力探测，图像 API 入口据此守卫、不可用时安全返回空向量。关键术语：**对比学习**——CLIP 用双编码器把图文各自独立编码到同一**共享空间**，只在末尾比相似度，这与 u5 的 VLM（把图像特征注入 token 流、自回归生成）是两条本质不同的路线。`preprocess_image` 做两件事：双线性插值缩放到 `image_size_`（默认 224），逐通道 `(v/255−μ)/σ` 归一化（默认 ImageNet RGB 统计量），输出 ncnn 平面布局。API 分两层：`encode_image`（像素字节→向量）为核心层，`encode_image_file`（路径→解码→BGR 翻转回 RGB→转核心层）为便捷层；翻转是因为底层 `load_image_to_ncnn_mat` 给 BGR、而 CLIP 预处理要 RGB。视觉网络 `out0` 已是 pooled 向量，故 C++ 侧只 `normalize`、不做 `mean_pool`，与 CLIP 文本侧对称。最终因两侧均归一化，图文余弦相似度退化为点积，前提是 `text_embed_dim_` 与 `vision_embed_dim_` 相等，从而支持「以文搜图」检索。
