本讲介绍 `ncnn_embedding` 文本嵌入运行时。它是与 `ncnn_llm_gpt` 平行的独立类，不继承 `ncnn_llm_base`，无需 KV cache、不自回归、不采样，只跑一次编码器前向。构造函数将 `model.json` 翻译为成员变量：按 `model_type`（`embedding`/`clip`）分流加载网络，按 `tokenizer.type`（`unigram`/`bpe`/`bbpe`）选择分词器，所有异常被 catch 成 `ok_=false`。核心 API `encode_text` 的链路为：分词→截断到 `max_seq_len_`→生成 RoPE（`RoPE_full` 或普通版）→`in0/in1/in2` 输入、`out0` 输出→后处理；`encode_text_batch` 仅串行循环，未做真 batch 前向。关键后处理是非 CLIP 模型走 `normalize(mean_pool(...))`：mean_pool 将序列压成单向量，normalize 拉到单位球面使点积等于余弦相似度；CLIP 因用特殊 token 代表整句而跳过 mean_pool。`embedding_main` 用 `cosine_similarity` 打印相似度矩阵，是嵌入模型最经典的使用范式。引入的关键术语：文本嵌入（固定维向量）、mean_pool、normalize、cosine_similarity、`RoPE_full`、`max_seq_len_`、`model_type`。本讲只讲文本，`encode_image` 等图文多模态部分留给 u6-l2。
