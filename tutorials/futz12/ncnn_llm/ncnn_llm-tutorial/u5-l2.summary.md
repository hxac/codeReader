本讲打通「磁盘图片如何变成可喂视觉网络的张量」，四步链路位于 get_visiual_features 内：load_image_to_ncnn_mat 用 stb_image 解码、强制 3 通道、RGB→BGR，失败返回空 Mat，只解码不缩放。get_image_size_for_patches 从 scale=1.0 按 0.02 步长缩小，把目标宽高对齐到 patch_size*2 倍数，保证 patch 行列数均为偶数且总数不超 max_num_patches。bgr_to_pixel_values 切出 num_patches 个 patch，每行一个 patch_size²*3 维 planar RGB 向量并做 (x/255-mean)/std 归一化（Qwen3.5-VL 改用 0.5/0.5、除 255.5）。reorder_patches_for_merge 按 2×2 块把光栅顺序重排为「块内连续」以服务后续 merger，像素 patch 与位置编码须用同一规则各重排一次。关键概念：patch、patch 网格、spatial merge（2×2 合并）、planar RGB。产物 pixel_values 与 pos_embeds 将在 u5-l3 经 patch embed、ViT（含 merger）变为 image_embeds；全链依赖构造函数从 model.json 读取的 patch_size/patch_dim/max_num_patches/spatial_merge_size 四项配置。
