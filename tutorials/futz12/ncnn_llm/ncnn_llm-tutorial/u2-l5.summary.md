本讲把单次 prefill/generate 升级为多轮会话，核心是推理上下文 ctx。`ncnn_llm_gpt_ctx` 将 KV cache、`cur_token`、`position_id` 打包为「会话状态」对象，是跨轮记忆的唯一载体；它构成多态层次——纯 Transformer 用 `ncnn_llm_gpt_base_ctx`，Qwen3.5 混合架构用 `qwen3_5_ctx`（额外携带 `sconv_cache`/`gdr_cache`）。关键机制是 `clone()`：prefill/generate 都先克隆输入 ctx、改副本、返回新 ctx，原 ctx 不被污染，由此支持记忆累积、会话分叉与回退；其安全基础是 ncnn::Mat 引用计数浅拷贝配合 decoder「读旧 cache、写新分配」模式。`position_id` 跨轮连续递增，不变量是恒等于已处理 token 总数。`run_cli` 以 system prompt 预填建立基线 ctx，再循环 `ctx = prefill(...); ctx = generate(...)`，模型回复靠 generate 扩展 KV cache 进入上下文，无需重新 prefill 文本。本讲为 VLM 多轮 prefill 与工具调用回填上下文打底。
