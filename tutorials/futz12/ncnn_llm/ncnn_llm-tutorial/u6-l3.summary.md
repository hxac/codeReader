本讲介绍 OCR 运行时 `ncnn_llm_ocr`，采用「一个外壳、两条路径」设计：构造时读取 `model_type`（`glm_ocr` 或 `hunyuan_ocr`）分流，两条路径共用 vision、text_embed、text_decoder、lm_head 四个 ncnn 子网。GLM-OCR 路径把图切成 patch、按 2×2 空间合并块重排成 strip，视觉网络带 2D mRoPE，prompt 中预放 N 个占位符再原位替换为图像特征，文本 decoder 用三轴 mRoPE，图像段时间轴被压缩。HunyuanOCR 路径用 smart_resize 加 CHW 整图预处理，视觉网络无 RoPE，按特殊 token id 直接装配序列，文本 decoder 用 NTK-alpha 缩放的四轴 xdrope，时间轴不压缩。两条路径的 prefill 产出首个 token 后，`generate` 均克隆 ctx，退化为对共享文本运行时四函数（embed→decoder→lm_head→采样）的循环调用，差异仅在停止条件、特殊 token 跳过与每步 RoPE。本讲引入的关键术语包括 patch、spatial merge、strip、CHW、mRoPE、xdrope、NTK-alpha。
