本讲介绍 ncnn_llm 自研的极简测试框架，仅涉及 `tests/test_framework.h` 与 `tests/test_llm.cpp` 两文件，被测对象为 `prompt.cpp` 的纯函数。核心是 `TestRunner` 类（负责注册、运行、统计用例并返回退出码）与 `TEST_ASSERT(cond, msg)` 宏（断言失败时打印错误并 `return false`，只终结当前用例）。`run_all` 用 try/catch 兜底每个用例、失败仍继续跑、最终返回 `failed>0?1:0`，使测试结果可接入 CI 与 shell 串联。关键结论是测试用例分流：10 个纯逻辑测试验证 ChatML 模板拼装与 `make_function_tool` 生成的工具 JSON 契约，无需模型、clone 即可全绿；2 个模型级测试做端到端冒烟验证。引入的关键术语包括断言、用例、运行器、退出码，以及 `has_model` 跳过机制（无模型时打印 `(skipped)` 并返回 `true`，代价是跳过与真通过在统计上无法区分）。模型级断言刻意宽松（仅查不崩、产出非空），以规避采样随机性导致的 flaky。新增单元测试只需写返回 bool 的用例函数、在 main 中 `add_test` 注册、构建运行三步。
