本讲承接 u5-l2，解决两个问题：已切好的 patch 像素如何变成图像嵌入 image_embeds，以及图像嵌入如何注入文本序列。核心含四个最小模块。其一，`get_visiual_features` 是图文 prefill 的视觉前端，对 seq_len 个 patch 逐个调用 `vision_embed_patch` 子网得到 `patch_embeds`，再经 `vision_encoder` 前向输出 `(hidden_dim, H)` 的 image_embeds；空图早返回使同一函数兼顾纯文本。其二，`vision_encoder` 有两条前向分支：有可学习位置嵌入 `vision_embed_pos` 时喂「patch+位置嵌入+2D RoPE」一次过；否则走窗口注意力，前后各按 `window_index` 重排与还原，二者都遵循 `in0..in3→out0` 调用。其三，`inject_image_embeds` 采用「单占位符展开」：文本只放一个 `<|image_pad|>`，找到后删掉、原位插入 H 个真实图像嵌入，展开后 decoder 读的是图文混合的 `token_embed`，`token_ids` 仅用于撑对长度。其四，inject 顺带产出 `image_pad_index`，它与 `image_embeds_size` 圈定图像 token 区间，供 mRoPE 分配 t/h/w 轴、供 position_id 推进单独计算图像段时间步（约 `num_patches_w/spatial_merge_size` 步）。`image_pad_id` 用 `.find()` 解析、缺省为 −1，体现可选配置静默降级的设计。
