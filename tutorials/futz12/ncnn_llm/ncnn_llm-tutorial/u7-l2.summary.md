本讲阐述工具调用（tool/function calling）的完整闭环，含四个最小模块。一、`make_function_tool<Ret,Args...>` 用 `json_type_name` 把 C++ 类型推断为 JSON Schema 类型，折叠表达式展开参数包，一行生成 OpenAI 风格的函数工具 JSON。二、`define_tools` 经 ChatML 模板把工具 JSON 拼进 system 文本并 `prefill` 进推理上下文 ctx；若模型未配置特殊 token `tool_call_id`/`tool_call_end_id`（缺省 -1），整个注入降级为 no-op，模型看不见工具。三、`generate` 主循环凭这两个 token id 驱动「普通文本态↔工具调用态」两态状态机，调用态下偷偷累积 JSON、不输出给用户，结束 token 触发 `handle_tool` 并 `continue` 跳过本步 decoder。四、`handle_tool` 调用 `GenerateConfig.tool_callback` 取结果，包进 `<tool_response>` 模板 prefill 回填 ctx，让模型看到结果并续写。关键术语：函数工具 JSON、`<tool_call>`/`</tool_call>` 特殊 token、`setting.functions` 配置、tool_callback 回调、工具路由表（名字→可调用对象）。
