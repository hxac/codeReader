vLLM-Omni 是在 vLLM 之上做「增量扩展」而非重写的全模态（omni-modality，覆盖文本/图像/音频/视频/动作）推理与服务框架，复用 vLLM 的高效 KV Cache，并新增流水线阶段重叠与基于 OmniConnector 的全解耦。它有三大扩展目标：非文本输出、非自回归结构（尤其 DiT 扩散 Transformer）、与 vLLM 核心兼容。主流模型归为 AR 与 DiT 的三种组合：DiT 为主（Qwen-Image）、AR 为主（BAGEL）、AR+DiT 联合（Qwen-Omni）。五大核心组件：OmniRouter 路由请求、EntryPoints 提供 API 入口并由 AsyncOmniEngine/Orchestrator 协调、AR 继承 vLLM、Diffusion 原生加速、OmniConnector 基于 E/P/D/G 做阶段间全解耦。在 Qwen3-Omni 中，Thinker/Talker/Code2wav 被声明为独立 stage，由 Orchestrator 经 StageEngineCoreClient/StageDiffusionClient 运行时路由。包入口用「🟡 修改 / 🔴 新增」二分法组织扩展，并严格规定 version 检查→patch→注册 configs→暴露 OmniModelConfig→懒加载 Omni/AsyncOmni 的初始化顺序，其中 version 必须先于 patch 以防版本不一致时导入报错。
