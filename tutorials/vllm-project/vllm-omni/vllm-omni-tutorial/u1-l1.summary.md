vLLM-Omni 是在 vLLM 之上做增量扩展（而非重写）的全模态推理与服务框架，复用其高效 KV Cache，新增流水线阶段重叠与基于 OmniConnector 的全解耦。核心范式：AR（自回归，逐 token 生成）与 DiT（扩散 Transformer，固定步数去噪、整块输出），二者组合分三类——DiT 为主（Qwen-Image）、AR 为主（BAGEL）、AR+DiT（Qwen-Omni）；由此引出阶段间数据流转与调度问题。五大核心组件：OmniRouter 负责路由、EntryPoints 提供入口并经 AsyncOmniEngine/Orchestrator 协调多阶段、AR 继承 vLLM 特性、Diffusion 原生加速、OmniConnector 按 E/P/D/G 做阶段间全解耦；以 Qwen3-Omni 为例，Thinker/Talker/Code2wav 被声明为独立 stage，运行时由 Orchestrator 路由。包入口以「🟡 修改 / 🔴 新增」二分法组织所有扩展，初始化顺序为版本对齐检查→打 patch→注册 configs→暴露 OmniModelConfig→懒加载 Omni/AsyncOmni；版本对齐（对齐偶数 minor）既是发布约定也是代码强制检查。
