本讲讲解 vLLM-Omni 的源码安装。核心结论：vLLM-Omni 是依附于 vLLM 的贴身扩展，必须先装对齐版本的 vLLM（主次版本一致，如 0.26.x 配 vLLM 0.26.x），再以可编辑模式从源码安装，推荐 Python 3.12 + Linux + 干净环境。涵盖四个最小模块：安装总览（含 CUDA 三步流程与 NPU「vLLM+vLLM-Ascend+vLLM-Omni」三方钉版本的特殊流程）；硬件感知安装——setup.py 的 detect_target_device() 按环境变量→ReadTheDocs→torch 探测→CPU 的优先级判定设备，从 requirements/{device}.txt 加载依赖；版本号生成——setuptools-scm 从 git 标签推导并追加设备后缀（CUDA 不加，其余加 +rocm/+npu 等）写入 _version.py，pyproject.toml 定义 console_script 与 general_plugins 入口；版本对齐告警——version.py 在导入早期比较主次版本，不一致即发 RuntimeWarning，且必须早于 patch 执行。
