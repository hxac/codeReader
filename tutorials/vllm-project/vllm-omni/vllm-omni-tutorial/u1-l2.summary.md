本讲讲解如何从源码安装 vLLM-Omni。核心结论：vLLM-Omni 依附于 vLLM，必须先装对齐版本的 vLLM，再以可编辑模式（`uv pip install -e .`）从源码安装，官方推荐 Python 3.12 + Linux + 干净环境。

涵盖四个最小模块：(1) 安装总览——建环境→装对齐 vLLM→克隆并以 `-e` 安装；(2) 硬件感知安装——`setup.py` 的 `detect_target_device()` 按「`VLLM_OMNI_TARGET_DEVICE` 环境变量 → READTHEDOCS → torch 后端探测（cuda/rocm/npu/xpu/musa）→ CPU 兜底」判定设备，从 `requirements/{device}.txt`（含 `-r common.txt`）加载平台依赖；(3) 版本号与元数据——`setuptools-scm` 从 git 标签推导版本并追加设备后缀（CUDA 不加，其余加 `+rocm`/`+npu`），写入构建时生成的 `_version.py`，`pyproject.toml` 定义 extras、`vllm-omni` console_script 及把 omni 模型注册挂到 vLLM 的 `general_plugins` 插件入口；(4) 版本对齐告警——`version.py` 在导入早期比较两者主次版本（`version_tuple[:2]`），不一致即发 `RuntimeWarning`，且该检查必须早于 patch，否则版本不一致时 patch 阶段会先崩溃。
