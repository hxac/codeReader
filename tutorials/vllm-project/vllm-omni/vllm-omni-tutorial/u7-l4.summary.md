本讲是 U7（Diffusion 加速）的全局编排篇，讲解 vLLM-Omni 扩散子系统的并行体系。核心是 `RankGenerator`：它用固定顺序 `tp-sp-pp-cfg-dp` 连乘分解 world_size，通过 mask 在同一方程里生成五种正交并行组——TP（切权重行列）、SP（切序列长度）、PP（切模型层）、CFG（切正/负双前向）、DP（切不同请求），任意两组 rank 最多相交一个元素。`initialize_model_parallel` 把这些 rank 列表注册成 `_DP/_CFG/_SP/_PP/_FS` 全局单例，并同步 TP/PP 给上游 `vllm_parallel_state` 以复用 vLLM 并行层；SP 组内部再拆 ulysses/ring/allgather 子组，承接 u7-l2 的 `ring_degree × ulysses_degree = sequence_parallel_size` 校验。模型代码通过 `get_sp_group()`/`get_cfg_group()`/`get_dit_group()` 等访问器拿到通信组，在需要同步的瞬间触发 all-reduce/all-gather。两种侧挂优化：CFG 并行把串行双前变并行（all_gather 后本地合并，scheduler 步进无需广播）；HSDP（`fs` 维）用 FSDP2 切权重让大模型装入小显存，与 TP 互斥；VAE Patch 并行把解码切成带 overlap 的 tile 分布执行。本讲为 u7-l5（Diffusion 批处理）的 DP 维度铺垫。
