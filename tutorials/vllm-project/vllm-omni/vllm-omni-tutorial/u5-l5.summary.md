本讲是 U5 Diffusion 模块收尾，把视角从单条 pipeline 拉高到「模型库 + 通用适配器」。核心结论有三：其一，扩散模型库由注册表 `_DIFFUSION_MODELS` 统一管理，以 architecture 名为 key 映射到实现类三元组并登记 post_process_func，覆盖图像、视频、音频、全模态、VLA 等 50+ 架构；pipeline 能力（图像输入、音频输出、步级执行、组件发现）通过 `interface.py` 的 Protocol 声明而非硬编码。其二，`DiffusersAdapterPipeline` 是黑盒通用适配器，把整条流水线委托给 diffusers 的 `from_pretrained().__call__()`，零代码上线任意 diffusers 模型，但放弃 CFG 并行、序列并行、TeaCache、步级连续批处理，由 `--diffusion-load-format diffusers` 路由。其三，自定义 pipeline 借 `diffusion_load_format="dummy"` 配合 `custom_pipeline_args` 与 `CustomPipelineWorkerExtension`，在已有 pipeline 上叠加逻辑而无需 fork 源码。引入的关键术语：architecture 名、注册表、能力协议、原生实现与黑盒适配器、diffusion_load_format。
