本讲拆解 `pkg/classification` 包，回答「信号如何被一次性算出、如何交给决策引擎」。三个最小模块：其一，`Classifier` 是胖编排器，持有 keyword/embedding/domain/jailbreak/pii 等全部信号族的后端指针但不做推理，构建期以函数式选项加 errgroup 并行组装，运行期只暴露 `EvaluateAllSignals*` 入口。其二，`evaluateAllSignalsWithContext` 实现「并发扇出＋懒求值＋就绪门控」：以 `usedSignals && ready` 这条与门决定每个信号是否起 goroutine，用一把 mutex 保护 `SignalResults` 写入，收尾串行算投影并反写置信度；懒求值由 `getUsedSignals` 递归收集决策规则树引用的信号并展开投影依赖。引入 `SignalResults`（协议无关事实容器，含 `MatchedXxxRules`、`SignalConfidences`、`SignalValues`、`ProjectionTrace`）与就绪表、负载闸门等术语。其三，信号→决策桥接：`evaluateDecisionInternal` 把 `SignalResults` 逐字段搬成 `decision.SignalMatches`，使 decision 包零依赖 classification，同一份信号只算一次即跑引擎；extproc 侧 `performDecisionEvaluation` 串起「抽信号→写回上下文→跑引擎→落模型」全链路，所有失败路径兜底 default model，authz 失败作硬错误。
