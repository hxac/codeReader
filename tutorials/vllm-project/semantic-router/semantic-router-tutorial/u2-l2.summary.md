本讲深入 vLLM Semantic Router（SR）路由流水线的最前端——信号层。核心结论是：SR 维护 **16 个核心信号族**，每一族负责从一次请求里抽取一类"事实"，结果汇聚进 `SignalResults` 容器，供投影层与决策层消费。

信号按判定方式分两大类：**规则型 / 启发式**（keyword、context、structure、language、authz）靠人写规则，命中即布尔；**学习型 / 模型驱动**（domain、embedding、complexity、modality、fact_check、jailbreak、pii、kb、preference、reask、user_feedback）靠嵌入或分类器，输出带概率或相似度灰度。项目官方用 `heuristic/` 与 `learned/` 目录区分。

关键术语与概念：信号声明遵循 `SIGNAL <族> <名> { 族专属字段 }`，有 DSL 与 YAML 两种等价写法；每条信号携带**两个数值通道**——`SignalConfidences`（置信度）与 `SignalValues`（原始值），键统一为 `"族:名"`。最关键的规律是：规则型命中置信度恒为 1.0，学习型写入真实概率/相似度；投影层读置信度有兜底，命中但无显式置信度时取 1.0，这正是规则型等价满权重、而"难度分"更爱用学习型信号的根因。此外 SR 只求值决策真正引用的信号以省算力。

本讲不讲信号如何组合成分数或路由带，那是 u2-l3（投影层）与 u2-l4（决策层）的任务。
