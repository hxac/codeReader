本讲覆盖 Semantic Router 请求路径上的四类治理控制。限流链用 first-deny 语义：多个 Provider（local-limiter 的 RPM/TPM 双预算、envoy-ratelimit 全局限流）顺序 Check，任一拒绝即短路回 429，全放行则合并取最严格配额；TPM 用"请求期估扣输入、响应期补扣输出"两段记账，provider 故障由 fail-open/closed 决定，但明确拒绝永远优先。在途计数（inflight）靠时间戳老化自愈，超 10min 自动驱逐，漏调 End 也不泄漏，是负载感知选择与指标的唯一真相源。缓存热度（cache warmth）用 TTFT 估计 KV 缓存命中概率，原始分经"计数×分布×新鲜度"三因子 reliability 与先验 0.5 融合，证据不足诚实回退，且只能影响下一次选择。授权（authz）套用 Kubernetes RoleBinding，把用户/组翻译成角色信号，配置了绑定却缺身份即报 403、无身份绝不静默放行、格式校验全前移到启动期。四者共享"请求期薄、失败显式、全局状态+包级读函数"的设计哲学。
