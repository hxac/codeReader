本讲讲解 SR 的语义缓存子系统：按查询嵌入相似度缓存完整请求-响应对，命中发生在请求阶段并以 `ImmediateResponse` 直接回包，未命中才登记 pending、待响应阶段补全。核心模块有三：一是 `CacheBackend` 统一契约（`model` 为精确分区键、`FindSimilarWithThreshold` 支持分类阈值、`LastSimilarity` 供可观测性，工厂接内存/Milvus/Redis/Valkey/Hybrid/Qdrant 六种后端）；二是 Hybrid 两级缓存——内存 HNSW 图只存向量做检索、Milvus 存响应体做按 ID 回取，write-through 双写、启动重建、FIFO 淘汰并延迟整图重建；三是用户作用域隔离的两层防线：软隔离靠 HMAC 命名空间前缀重复三次把不同用户在向量空间推远，硬隔离靠检索后 `entryEligible`/Milvus model 过滤做 namespace 精确相等校验，共同杜绝跨租户泄漏。关键术语：`CacheEntry`、`CacheBackend`、`SimilarityTracker`、`scopeNamespace`、`USER_SCOPE_NAMESPACE_SECRET`、`entryEligible`。此外命中 RAG/memory 等个性化插件时整条缓存路径被跳过。
