本讲是整本学习手册的概念底座，覆盖三个最小模块。项目定位：vLLM SR（vLLM Semantic Router）是面向异构 LLM 基础设施的可编程路由层，位于客户端与模型后端之间，在不把路由逻辑硬编码进应用的前提下，同时改善质量（quality）、成本（cost）、延迟（latency）、隐私（privacy）、安全（safety）五个维度。核心理念：Mixture-of-Models（MoM，混合模型）——承认「最好的模型是一个组合」，通过 Signals（信号，项目维护 16 个信号族）→ Projections（投影，将相互竞争的信号协调为命名路由带）→ Decisions（决策，用 AND/OR 布尔规则求值）三层，把信号变成可执行的路由。工程形态：以 Envoy External Processor（ext_proc）控制面落地，Envoy 负责搬流量、SR 负责做智能决策，使路由成为可观察、可配置的基础设施层。引入的关键术语包括 routing、signal、control plane、entrypoint、recipe、backend、plugin；其一句话执行流程为 entrypoint → recipe（signals + projections + decisions）→ select backend(s) → apply plugins，这正是后续请求处理主链路讲义的骨架。项目由 5 个核心研究问题驱动演进；仓库为多语言 monorepo（Go 路由内核位于 `src/semantic-router/`、Python CLI/编排位于 `src/vllm-sr/`），唯一公开文档树为 `website/`。
