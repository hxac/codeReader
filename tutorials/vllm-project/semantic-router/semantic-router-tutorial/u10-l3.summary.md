本讲讲 SR 的两条工具通路。一是进程内语义工具库 ToolsDatabase（pkg/tools）：对工具描述生成嵌入，检索时线性点积扫描（归一化下即余弦相似度）、过阈值取 top-k，由 tool_selection 插件增补或裁剪请求的 tools 字段；检索抽象为 ToolRetriever 接口与策略注册表，默认策略 EmbeddingRetriever 先用 EffectivePoolSize（TopK×5 与地板 20 取大）放大候选池，再由 relevance.go 做嵌入、词法、标签、类别、名称的加权精排（向量召回+符号精排）；嵌入来源双通道，优先注入的 embedding.Provider，缺席回退 candle CGO。二是 MCP 客户端 pkg/mcp：MCPClient 接口 + BaseClient 公共基类 + stdio/streamable-http 两套传输，ClientFactory 按 transport_type、command、url 优先级分派；ToolFilter（allow/block）在 loadTools 加载期与 CallTool 调用期两层强制，空配置为直通。关键定位：MCP 客户端当前并不向请求注入工具，而是充当 classification.MCPCategoryClassifier 的类别分类后端（配置类型 MCPCategoryModel），ConvertToolToOpenAI 这一格式桥已就绪待用。
