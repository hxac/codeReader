本讲拆解 Semantic Router 域/类别信号的算法，含三个最小模块。其一类别匹配：MMLU-Pro 域分类模型输出全概率分布，经 CategoryMapping（类索引→MMLU 名）与 translateMMLUToGeneric（MMLU→通用名）两层翻译，写回 SignalConfidences["domain:<名>"]，未映射标签原样保留。其二熵分析：用归一化 Shannon 熵衡量不确定度，very_low/low 时只报 top-1，medium 以上时报出所有过 CategoryModel.Threshold 的类别，使域信号天然支持多类别并立。其三 KB 增强分类：示例驱动的自定义旁路，预嵌入示例聚成原型簇，按 Score=w·best+(1-w)·support 打分，过阈值后映射成与 domain 对称的 kb:* 信号。核心结论：决策引擎里 domain 是唯一被特殊匹配的信号类型，matchesDomainCondition 同时支持直接命中与经 mmlu_categories 的别名命中，化解决策词汇粗、模型词汇细的粒度错配；熵分析还被复用于「是否启用推理模型」的更高层判断。
