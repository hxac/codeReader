本讲讲解 SR 的 Prompt 压缩（promptcompression 包）：一个纯函数、不调 LLM 的文本预处理，由 compressSignalEvaluationText 在信号抽取前触发，结果仅用于分类、绝不改写发给上游模型的请求。核心是「四信号打分选句」：对每个句子计算 TextRank（句子相似度图上跑 PageRank 幂迭代，奖励代表性主干）、位置加权（用正弦 U 形曲线刻画 Lost in the Middle，首尾得分高）、TF-IDF（以句子为文档算 IDF 近似 token 自信息，奖励含稀有词的高信息句）、新颖度（1 减去与质心余弦，捞取越狱前缀、PII 等离群句）四个 [0,1] 分数，按可配置权重加权成 Composite 综合分，再「先硬保留首尾 N 句、再贪心选高分」装入 MaxTokens 预算，按原文顺序拼回。其中 TextRank 奖励典型、新颖度奖励离群，方向相反，故默认权重一高一低；越狱与 PII 信号另由 skip_signals 默认保护，始终跑在未压缩原文上，security 画像则把新颖度权重提至 0.30。
