本讲聚焦 pkg/selection，回答「决策命中后，从候选模型里选哪一个」。

核心契约是 Selector 接口：以 SelectionContext（查询、候选模型、决策名、成本/质量权重）为输入，SelectionResult（选中模型、分数、置信度、AllScores）为输出，且强制选中模型须属于候选，把算法幻觉转为可观测失败。Registry 是线程安全注册表，全局 Select 走「请求方法→static→第一个候选」三级降级，保证模型选择永不整体失败。

重点精读两种算法：Elo 借国际象棋等级分，用 Bradley-Terry 模型把评分转成选择概率取最高分，偏好反馈按 R'=R+K(S−E) 在线更新（爆冷涨分多），支持分类级评分；Hybrid 把 Elo/RouterDC/AutoMix 加权融合，对子算法失败容错，置信度来自子算法一致性。

Factory.CreateAll 一次注册 13 种算法，按 supported/experimental 两档分级，实验性算法的外部依赖仅探测告警、不阻断启动。
