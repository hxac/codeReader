本讲是「信号-投影-决策」心智模型的收尾，回答路由器如何用已有的信号与投影选出路由与模型。三个最小模块：(1) ROUTE 的 WHEN 是一棵布尔规则树，叶子为信号/投影引用，组合节点为 AND/OR/NOT；编译后成为 RuleNode，由决策引擎递归求值，并产出匹配置信度——AND 取子项平均、OR 取命中项最大值、NOT 在子项为假时返回 1.0。(2) 排序由 TIER 与全局 strategy 决定：一旦任意匹配路由标了 TIER 便进入分层选择，TIER 升序为主键，PRIORITY 仅在同 TIER 内做微调；每个配方必须有一条无 WHEN 的最终兜底路由保证永不落空。(3) MODEL 分两层：顶层 MODEL 块是模型货架（capabilities/quality_score/tags/modality），ROUTE 中的 MODEL 引用负责挑模型并下发 reasoning/effort；元数据本身不决定命中，而供后续选择算法与成本感知消费。关键术语：Decision、match、PRIORITY/TIER、strategy、RuleNode、匹配置信度、ModelRef、ModelReasoningControl。
