本讲讲解 Semantic Router 的 `pkg/vectorstore` 层：把「文档上传→切块→嵌入→写入向量库→相似度检索」做成一套对齐 OpenAI Vector Stores API 的能力，底层向量库抽象为可替换后端。它由四个最小模块构成：①向量库 API——采用「厚模型（VectorStore、VectorStoreFile、EmbeddedChunk、SearchResult 等）+ 薄接口（VectorStoreBackend 仅 7 方法）」设计，Manager 在「后端存向量、StoreRegistry 存元数据」之上做双写/双删，并维护进程内索引；②摄入流水线——异步六步（读→解析→切块→嵌入→写入），用根 context 贯穿生命周期取消，区分取消与真实故障记账；切块分 auto 与 static（默认 800/400，步长=maxSize−overlap）；③多后端抽象——内存走暴力余弦（原生支持混合检索），Milvus/Qdrant/Valkey 走服务端 HNSW，LlamaStack 连嵌入都由服务端代劳，工厂 NewBackend 按类型字符串切换，GenericHybridRerank 为不支持文本重排的后端提供通用回退；④Milvus 生命周期——共享包 pkg/milvus 把「连接、集合 ensure/load、瞬时错误指数退避重试」抽成纯函数供多子系统复用。关键术语：collection、chunk、embedding、topK、threshold、HNSW、IP（内积，归一化向量下与余弦等价）。本讲承接 u9-l1 进程内 HNSW，把检索能力下沉给外部向量库，并为后续语义缓存、记忆子系统奠基。
