本讲收尾专家层，讲清分类器与选择模型的权重如何训练、评估并加载上线。`src/training/` 下：`model_classifier` 用 LoRA（W=W₀+BA，rank=16）覆盖序列分类与 PII 的 token 分类，参数砍 99%+，每目录配 Go 验证器做 Python↔Rust 数值一致性校验；`model_selection` 先打基准测 performance 与 response_time，再以 1038 维特征（1024 嵌入⊕14 类别 one-hot）训练 KNN/KMeans/SVM/MLP，共用 score=0.9·quality+0.1·speed。评估分三层：单模型质量、MMLU-Pro/ARC 学术基准（可反哺配置）、用真实 Go/Rust 代码的 `validate.go` 做生产路径验证，另以多评委脚本审计数据集标签。产物进运行时分两路：LoRA 分类器靠 `model_discovery.go` 按目录命名自动发现，ML 选择模型经 `persistence.go` 读 JSON、CGO 加载后由 `ml_adapter.go` 适配进选择系统。性能基准严格二分：`perf/` 组件微基准每 PR 跑、门禁只卡硬件无关的 allocs/op 与 B/op（ns/op 仅 advisory）；`bench/` 路由质量基准需真实后端、测准确率与稳定性。
