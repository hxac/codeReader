本讲（u7-l1）讲解语义路由 DSL 的语法与 AST 结构，覆盖三大模块：块语法、AST 节点、WHEN 布尔表达式。DSL 是 config.yaml 的「人友好版」，由 SIGNAL/PROJECTION/MODEL/PLUGIN/ROUTE/RECIPE/ENTRYPOINT/ROUTING/DECISION_TREE/TEST 十类顶层块组成，其中 ROUTE 与 DECISION_TREE 不可共存。源码经词法分析、raw 解析树、resolved Program AST 三步处理；AST 分两层：raw 层是 participle 文法的直接映射，resolved 层（Program 及各类 *Decl）经 rawToProgram 清洗去引号、归一化后供编译器与校验器消费。关键词法细节：Float 先于 Int、Ident 允许 `.`/`/`/`-`（故带斜杠点号的模型名为单个标识符）、字段用冒号而路由头与模型选项用等号。WHEN 布尔表达式优先级为 NOT>AND>OR、括号最高，三层 raw 结构经 toBoolExpr 折叠为左结合的递归 BoolAnd/BoolOr/BoolNot/SignalRefExpr 树。Parse 带错误恢复，按顶层关键字切块逐个解析。本讲只讲「字符串如何变成树」，编译为 RouterConfig、反编译与 dsl 命令行工具分别留待 u7-l2、u7-l3，运行时布尔树求值见 u6-l1。
