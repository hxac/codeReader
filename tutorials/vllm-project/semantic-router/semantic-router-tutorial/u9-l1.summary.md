本讲讲解 pkg/hnsw——纯 Go 实现的 HNSW（分层可导航小世界）进程内向量索引库，为语义缓存、记忆与工具检索提供底层近邻搜索能力。HNSW 借鉴跳表把节点分层（底层稠密、上层稀疏），节点层级按 P(level≥l)=M⁻l 的指数分布抽样，期望层数约 logₘn，从而把相似度搜索从暴力 O(n) 压到近似 O(log n)。三个关键参数 M、EfConstruction、EfSearch（默认 16/200/50）分别控制图密度与内存、建图质量、查询的召回率与延迟取舍。建图流程为抽层加逐层 beam search 选邻居加双向连接加剪枝；查询为上层贪心下沉、底层 beam search 再重排取 top-k，核心遍历用 min-heap 定扩展顺序、max-heap 保留最近 ef 个，并配合提前终止判据控制成本。距离定义为负点积——嵌入已 L2 归一化，故点积即余弦相似度；点积是性能热点，`dotProductSIMD` 在 amd64 按运行时 CPU 能力分派 AVX-512/AVX2/标量三条路径，非 amd64 走纯标量回退。本包仅支持 Add/AddBatch/Search/SearchAll/Clear，无按节点删除（删除语义交给外部向量库的服务端 HNSW），构建标签为 !windows && cgo，须启用 CGO。
