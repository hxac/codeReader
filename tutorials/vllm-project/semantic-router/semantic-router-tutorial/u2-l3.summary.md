本讲讲解 SR 请求流水线中的**投影层（Projection）**——介于"信号抽取"与"决策"之间的协调层，负责把杂乱、互相竞争的原始信号压缩成少量干净的**命名路由带**（如 `balance_simple`/`balance_complex`），供决策层消费。投影分三类**串行接力**的操作：**partition（分区）**用 `softmax_exclusive`（带温度）对 domain/embedding 两类互斥候选选出原始置信度最高的赢家，以归一化概率重写其置信度并删除所有败者，无人命中时合成 `default` 兜底成员保证分类不落空；**score（评分）**用 `weighted_sum` 把多个异类信号按可正可负的权重加权求和成连续分数（如 `difficulty_score`），负权重压低（简单证据）、正权重推高（复杂证据），输入取值分 binary/confidence/raw 三种，规则型信号缺省置信度兜底 1.0；**mapping（映射）**用 `threshold_bands` 按声明顺序首带命中，并以 `sigmoid_distance` 把"分数到最近边界距离"经 sigmoid 翻译成 0~1 置信度——离边界越远越笃定、贴边界越犹豫（≈0.5）。mapping 产出的命名带以 `"projection:名字"` 反写进 SignalConfidences，决策层 ROUTE 的 WHEN 正据此写 `projection("balance_complex")` 这类规则。全程由版本化 JSON 的**投影追踪（projection trace）**记录 partition 候选/赢家/margin、score 逐项贡献、mapping 各带匹配，保证投影完全可解释。
