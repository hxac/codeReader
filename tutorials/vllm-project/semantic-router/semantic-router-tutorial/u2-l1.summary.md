本讲建立 SR（vLLM Semantic Router）的端到端数据流心智模型：把一次请求切成「信号→投影→决策→模型+插件」四层流水线。信号层从请求抽取 16 族事实，每条信号带 0~1 置信度，只抽取不做路由决定。投影层用 partition（softmax 互斥分区）、score（加权和）、mapping（阈值分带加 sigmoid 距离校准）三类数学方法，把相互竞争的原始信号协调成少数命名路由带（如 balance_simple/medium/complex/reasoning），供决策消费。决策层以 ROUTE 为单元，用 AND/OR/NOT 在「信号+投影」上写 WHEN 规则，按 PRIORITY 从高到低顺序匹配、首条命中者胜出，末尾保留无 WHEN 的兜底路由保证永不落空。选中的 ROUTE 驱动 MODEL 分发（含 reasoning/effort 参数）与按路由启停的插件链（如 router_replay 审计），从而实现按需升级、按需省钱。
