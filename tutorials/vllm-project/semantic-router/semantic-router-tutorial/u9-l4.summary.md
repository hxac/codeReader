本讲讲解 vLLM Semantic Router 的智能体记忆子系统 `pkg/memory`，它让路由器跨会话记住关于用户的事实，并在请求时检索注入模型上下文。全讲围绕三个最小模块展开。其一，Store 接口与存储抽象：定义统一的增删改查与 `Retrieve` 语义检索接口，实现可替换为进程内、Milvus、Valkey、Qdrant，后端装配在 extproc 工厂，调用方只认接口，配合全局单例 `globalMemoryStore`。其二，Memory 与三种记忆类型：借鉴认知科学分为 semantic（事实/偏好）、procedural（步骤）、episodic（事件）；`Memory` 结构除 Content、Embedding（不进 JSON）外，含作用域（UserID 为用户隔离主键）、时效留存（AccessCount、Importance）与溯源字段，Content 须自包含上下文。其三，混合检索与重排：一次 Retrieve 是"向量召回扩大 topK→混合重排（复用 vectorstore 的 BM25 与 n-gram，weighted/RRF 融合）→自适应阈值找 elbow 断层并设基础阈值地板→截断→异步累加访问计数"的流水线。核心结论有二：用户隔离靠 `milvusUserScopeFilter` 用 `%q` 转义防 CWE-943 注入（硬防线，区别于缓存的 HMAC 软隔离）；检索后的 MemoryFilter（默认启发式 ReflectionGate，不调 LLM）在请求路径上做时效衰减、去重、token 预算，会改写最终注入分数。记忆与缓存的关键区别是：记忆存提炼出的事实、跨会话长期生效，缓存存完整请求-响应对、命中即省一次推理。
