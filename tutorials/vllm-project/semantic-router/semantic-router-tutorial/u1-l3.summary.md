本讲讲解 vLLM SR 的两条安装/运行路径。其一为面向终端用户的 `install.sh` 一键安装器：在隔离 venv 中安装 Python CLI `vllm-sr`，并通过薄启动器（thin launcher，仅 `exec` 到 venv 内真实可执行文件）使其全局可用，主流程为「解析参数→打印安装计划→装 CLI→确保运行时→首次 serve→打开 dashboard（默认端口 8700）」，默认 dev 渠道、serve 模式。其二为面向开发者的 `make` 目标体系：根 `Makefile` 是薄分发器，靠一条静态模式规则把任意目标委托给用 `-f` 加载全部 `tools/make/*.mk` 组合而成的规则集。本讲还引入本地环境三元组 `cpu-local`/`amd-local`/`nvidia-local`，统一由 `VLLM_SR_PLATFORM`（构建期）与 `--platform`（运行期）驱动，并改写镜像名、Dockerfile 与目标架构。核心约定是 local image flow：本地开发一律本地构建镜像、用 `--image-pull-policy never` 启动，绝不隐式拉取远程镜像。关键术语 venv、CGO、容器运行时、recipe、Envoy 入口（8801）供后续讲义承接。
