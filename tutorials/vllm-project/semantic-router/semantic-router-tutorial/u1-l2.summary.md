本讲承接 u1-l1 的路由概念，从工程师视角梳理 vLLM Semantic Router 多语言 monorepo 的目录组织，覆盖三个最小模块。第一，资产边界：顶层目录按归属和生命周期划分所有权，`config/` 拥有配置与 recipe，`deploy/` 拥有部署产物，`website/` 是唯一公开文档树；仓库故意没有根 `docs/`、`scripts/` 兜底目录，根文件受 `tools/agent/structure-rules.yaml` 的可执行白名单约束。第二，核心子系统映射：路由内核 `src/semantic-router/`(Go) 执行决策，`src/vllm-sr/`(Python) 做本地编排，各 `*-binding/`(Rust) 提供推理能力，并主动抽取 `pkg/milvus/` 等共享层。第三，入口定位：本地服务从 `src/vllm-sr/cli/main.py` 进入，Go 路由器从 `cmd/main.go` 进入。最后须区分目录级的 High-Risk Areas 与文件级的 Known Hotspots，改动热点遵循「抽取优先」。
