本讲解决 MoE（混合专家）模型量化校准的两个特有难题。难题一是专家稀疏激活：路由使每个 token 只激活 top-k 个专家，校准集又小，导致部分专家收到的 token 极少、量化统计不可靠。对策是专家感知校准上下文 `moe_calibration_context`：它翻转全局开关 `get_calibrate_all_experts_flag`，让 `LinearExperts2D.forward` 在校准时给每个专家喂全部 token、但仅把路由命中位置的输出写回，从而统计充分且输出等价。难题二是融合 3D 权重：transformers 把多专家权重融合成 3D 张量，而量化算法只认 2D Linear。对策是线性化（linearization），用装着 E 个 2D Linear 的 `LinearExperts2D` 数值等价替换融合模块。两条路径：加载后转换 `linearize_moe`（兜底、较慢）与加载时转换 `load_quantizable_moe`（推荐、最快）。`get_non_linearized_moes` 通过 `FusedExpertsProtocol` 与 `_registry` 识别未线性化模块，`oneshot` 检测到时回退转换并警告。`conversion_mappings` 维护两张表：`ARCH_TO_IMPORT_PATHS`（架构→专家类）决定认不认识，`ARCH_TO_2D_MAPPINGS`（架构→2D 重命名）决定能否直接 2D 加载；大多数架构仍走回退路径。
