本讲精读 llm-compressor 中 GPTQ（基于激活校准的权重量化算法）的实现，覆盖两个最小模块：GPTQModifier（双继承 Modifier 与 QuantizationMixin，编排四个生命周期钩子）与 gptq_quantize.py（含 make_empty_hessian、accumulate_hessian、quantize_weight、_apply_activation_ordering 等纯算法）。核心结论：GPTQ 恒需校准数据，因其依赖校准激活经 calibrate_module forward hook 逐 batch 累积 Hessian 矩阵 H=2X^TX；真正改权重发生在 on_sequential_epoch_end 钩子的 quantize_weight：阻尼加 Cholesky 求逆后按 block_size 分块逐列量化，再用逆 Hessian 把每列误差补偿到剩余列，求逆失败则退化为 RTN。关键术语：Hessian 与逆 Hessian、dampening_frac（percdamp，默认 0.01）、actorder（默认 static，按 diag(H) 排序且推理零开销）、g_idx（分组量化时列到分组映射，仅 actorder=GROUP 写入模型）。GPTQModifier 与 QuantizationMixin 分工为「mixin 搭台、子类唱戏」。
