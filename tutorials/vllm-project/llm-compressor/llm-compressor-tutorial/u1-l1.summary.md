本讲是 llm-compressor 的全局导论，覆盖五个最小模块。核心定位：llm-compressor 是面向 vLLM 部署的大模型压缩库，输入为 HuggingFace 模型加压缩配方（及可选校准数据），输出 compressed-tensors 格式的可部署 checkpoint，自身不做推理，与 vLLM 通过该格式衔接。量化数学直觉：用缩放因子 scale 和零点偏移 zero-point 将高精度值映射为低位整数，误差源自 round，合理选 scale 是各算法的核心权衡。精度方案（scheme）决定量化位数与格式，如 W8A8、FP8、NVFP4、W4A16，命名中 W 指权重、A 指激活，方案选择由 GPU 架构决定（Blackwell 用 NVFP4、Hopper 用 W8A8-FP8、Ampere 用 W4A16）。压缩算法决定怎么压缩，包括 RTN、GPTQ、AWQ、SmoothQuant、AutoRound、Rotation-based 与针对 MoE 的 REAP 剪枝；AWQ、SmoothQuant 等属先变换再量化类。三大核心概念为后续源码阅读骨架：modifier 封装单个压缩动作，recipe 是 modifier 的有序集合，oneshot 是主入口函数，一次校准完成压缩；变换类 modifier 须排在量化类之前。注意稀疏压缩（2:4）已不再支持。
