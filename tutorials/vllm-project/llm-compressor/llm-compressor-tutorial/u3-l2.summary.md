本讲精读 QuantizationMixin（继承 HooksMixin）——被 QuantizationModifier/GPTQModifier/AWQModifier 混入的脚手架类。核心设计是：mixin 只负责挂卸装备，不自己算 scale/zero-point。它用三个方法驱动模块状态机：initialize_quantization 给命中模块（由 resolved_targets 决定，而非顶层 targets 字段）挂 quantization_scheme 并关闭量化；start_calibration 按 scheme 选择性挂 observer（权重 observer 强制降级为 memoryless 省内存）与经 HooksMixin.register_hook 注册、可被 disable_hooks 临时禁用的 calibration hook，状态切到 CALIBRATION；end_calibration 卸 hook、freeze 删 observer、置 FROZEN 并保持量化开启。取整由子类在 on_sequential_epoch_end 显式调 observe+update_qparams 完成，使 mixin 同时服务 RTN（直接取整）与 AWQ（先变换后量化）等算法。此外，group_size 整除性（仅 GROUP/TENSOR_GROUP）在 initialize 阶段提前校验，避免校准跑完才失败，可用 bypass_divisibility_checks 跳过。observer 与 hook 的内部细节留待下一讲。
