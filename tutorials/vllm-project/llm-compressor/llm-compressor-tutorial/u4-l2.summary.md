本讲讲解 AWQModifier——一种「变换型 modifier」，与 GPTQ/RTN 不同，它自己不量化，只对权重做等价缩放重排（smoothing），真正取整交给紧跟其后的 QuantizationModifier；Recipe 的 validate_model_after 强制要求 AWQ 之后必须存在 QuantizationMixin 子类，否则校验阶段即报错。核心数学：对 smooth layer（如 RMSNorm）做 γ←γ/s，对 balance layer（如 Linear）做 W←W·s，使 Linear 输出逐元素不变，却抬高关键（激活大）通道的权重幅值，降低 4bit 量化相对误差。架构配对靠 AWQ_MAPPING_REGISTRY 按模型类名查 smooth↔balance 的 regex 规则，覆盖 Llama/Qwen/Phi/Gemma/Cohere 等，缺省时由 on_initialize 自动推断。缩放向量 s 由网格搜索确定：枚举候选 s，每个都「真做一次量化」挑输出 MSE 最小者，duo_scaling 控制是否纳入权重幅值（且禁止与逐张量量化搭配）。整套流程靠生命周期钩子串起：on_initialize 推断 mappings、on_calibration_start 解析并挂激活缓存 hook、on_sequential_epoch_end 搜索并重排权重、on_calibration_end 卸 hook，依赖 SequentialPipeline 逐子图校准。
