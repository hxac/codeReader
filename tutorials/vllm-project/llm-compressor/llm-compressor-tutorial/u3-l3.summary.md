本讲钻进校准的执行细节，回答「统计如何变成 scale」。核心结论：Observer 只是统计收集器，它把张量变成 `min_vals`/`max_vals`，换算 scale/zero-point 委托给 `compressed_tensors.calculate_qparams`，且统计在 `get_qparams` 后被一次性删除，故 `update_qparams` 必须紧跟 `observe`。引入的关键概念包括：`base_name` 命名约定（`weight`/`input`/`output`/`q`/`k`/`v`）及 `ACTIVATION_OBS`/`WEIGHT_OBS` 两套分组；三种 MinMax 策略（memoryless/static/EMA）的差异在于多次观测合并方式，权重 observer 被强制降级为 memoryless 省内存；MSE/IMatrix 用网格搜索裁剪离群值，IMatrix 再以 `E[x²]` 做通道重要性加权。取整三连 `observe → update_qparams → freeze` 是模块级纯函数：激活统计由 `calibrate_input/output_hook` 跨 batch 累积（输出 hook 还做伪量化使误差逐层传播），epoch 末只 update；权重无 hook 需主动 observe+update。进阶机制有 `TENSOR_GROUP`（NVFP4）下 `FusionHandler` 让融合层共享 `global_scale` 并协作式删除统计，以及 DDP 下按 `_act_sync_dict` 声明的 reduce 操作 all-reduce 激活统计（权重各卡相同不同步）；`HooksMixin.disable_hooks` 用类变量做全局开关供 sequential 管线临时关 hook。
