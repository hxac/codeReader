本讲解决 llm-compressor 在多卡（DDP）环境下如何让每张卡得到完全一致的量化结果。核心设计哲学是「尽量不侵入抽象层」：sequential pipeline 完全无感 DDP，仅 modifier 与 observer 需分布式感知，单卡脚本改三处（`init_dist`、`get_rank_partition`、`torchrun`）即可多卡运行。DDP 把多卡加速拆成两个正交维度：**数据并行校准**（各卡切分校准样本，靠 all-reduce 汇总激活统计）与**权重并行压缩**（用贪心装箱把模块分配给各 rank 并行算，再广播补齐）。关键术语包括：observer 的声明式同步表 `_act_sync_dict`（不同统计语义对应 MIN/MAX/AVG/SUM 不同 reduce 操作，权重统计因各卡相同而永不同步）、`GPTQModifier` 的四步流程（贪心装箱分配 → `reduce(SUM)` 部分Hessian与num_samples归约到拥有者 → 拥有者独占压缩 → `broadcast_qparams_and_cleanup` 广播 weight/scale/zero_point/g_idx 并清理 observer 统计）。核心结论：GPTQ 须广播 `weight` 本身（因仅拥有者改写了权重），而 RTN 只广播 scale/zero_point；`only_update_onload` 与 `skip_cpu` 用于避免多卡并发写共享的 offload 权威副本。最终各 rank 经「同步统计 + 广播参数」收敛到位级一致的量化结果。
