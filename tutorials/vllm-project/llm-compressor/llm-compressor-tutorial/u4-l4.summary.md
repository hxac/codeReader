本讲聚焦 `AutoRoundModifier`——llm-compressor 接入外部 `auto_round` 库的「变换/量化」类 modifier，本质是适配器而非量化数学本身。核心区别：RTN 贪心取整且用全局 min/max 裁剪，AutoRound 则引入可学习的**取整权重 V、裁剪范围 α/β**三类参数，以**块级重建损失**为目标、用 **SignSGD** 在少量步数（默认 `iters=200`）内逐层优化，在 sub-4-bit 低比特场景显著优于 RTN，仍属 PTQ。`AutoRoundModifier(Modifier, QuantizationMixin)` 在 `on_calibration_start` 给解码层挂**输入捕获 hook**，在 `on_sequential_epoch_end` 调 `ar.quantize_block` 逐层优化，并冻结模型全部参数只优化 V/α/β。关键适配包括：**重写 `start_calibration`** 跳过 observer 注册；`_mapping_config_to_autoround` 做**方案映射**（预设名直返、如 `W7A16` 无预设则显式构造）；`_postprocess_qparams` 做**参数回写**（把 `auto_round` 的 `scale` 等命名映射回 compressed-tensors 的 `weight_scale` 等，并对 MXFP4/MXFP8/NVFP4 特判）。特殊处理：`SequentialPipeline` 检测到该 modifier 即**强制 `propagate_error=False`**，因为 AutoRound 逐层独立优化且自带 `q_input` 层间耦合，叠加会重复，故每个子图只跑一遍前向。`utils.py` 提供 GPU 分组（`LLMCOMPRESSOR_GPUS_PER_GROUP`）与 attention mask 归一化（全 1 时置末位 0）。该 modifier 也是「逐层优化型」自定义 modifier 的完整范例。
