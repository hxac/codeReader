`SequentialPipeline` 是需要校准数据算法（GPTQ、W8A8、AWQ、SmoothQuant）的默认校准管线，核心是「切子图 → 逐子图两遍前向 → 缓存中间激活」三步。切分层由 `infer_sequential_targets` 推断，未指定时回退到 HF 模型的 `_no_split_modules`（通常为 decoder 层类）；`trace_subgraphs` 用 `torch.fx` 追踪并按拓扑分桶生成可执行 `Subgraph`，经验上子图数 ≈ decoder 层数 + 1。每个子图跑两遍前向：第一遍 Calibrating 开校准 hook 收集激活统计，末尾触发 `SEQUENTIAL_EPOCH_END` 完成权重量化；第二遍 Propagating（仅 `propagate_error=True` 时）关 hook，捕获量化后输出喂给下一层，使量化误差跨层累积。误差传播的真正发生点是 `calibrate_output_hook` 中的 `forward_quantize` 伪量化；`AutoRoundModifier` 因逐层独立优化被强制设为 `propagate_error=False`。`IntermediatesCache` 以「写即 offload 到 CPU、读即 onload 回 GPU」的方式，将峰值显存与模型层数、校准样本数解耦，`consumed_names` 使中间值在最后一次消费后立即释放，`sequential_offload_device` 与 `sequential_prefetch` 是显存↔速度的两个旋钮。关键术语：子图、sequential_targets、propagate_error、IntermediatesCache、consumed_names、Calibrating/Propagating 两遍前向。
