本讲承接 u3-l3，讲解如何自定义 observer。核心契约是 Observer 基类的两阶段流水线：Observe 阶段的 forward 按 strategy 切块后调用子类的 update_statistics_from_observed 累积统计；Compute 阶段的 get_qparams 调 calculate_qparams 换算 scale/zero_point 并删除统计，故只能调一次。子类通常只需实现唯一抽象方法 update_statistics_from_observed，用 @Observer.register 登记名字。三种 MinMax observer 仅在跨 batch 合并与 DDP 同步（_act_sync_dict）上不同：memoryless 覆盖不同步、static 取极值用 MIN/MAX、moving-average 用 lerp 配 AVG。MSE/IMatrix 用网格搜索收缩范围裁离群值，IMatrix 额外经 attach 挂 hook 收集 E[x²] 做通道重要性加权。挂载链路：QuantizationModifier 的 weight_observer/input_observer/observer 字段经 _apply_observer_overrides 写入 QuantizationArgs.observer，再由 initialize_observer 用 load_from_registry 按名字实例化挂载。关键结论：权重 observer 被 forward 短路并降级为 memoryless，恒只观测一次；observer 类必须在 oneshot 前 import 以触发注册副作用。
