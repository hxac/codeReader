本讲覆盖两个最小模块：`llmcompressor` 包的安装与 `llmcompressor.entrypoints` 的 `oneshot` 入口。安装上，`pip install llmcompressor` 即可，要求 Python ≥ 3.10，核心依赖为 torch、transformers、compressed-tensors、accelerate 与 datasets。核心结论是：第一次量化推荐用 RTN + FP8 动态量化（`QuantizationModifier(targets="Linear", scheme="FP8_DYNAMIC", ignore=["lm_head"])`），它不依赖校准数据，最小调用只需 `oneshot(model, recipe)` 两个参数，最后用 `model.save_pretrained()` 落盘。本讲引入的关键术语包括：PTQ（训练后量化）、RTN（就近取整，无需校准）、FP8 动态量化（权重静态、激活动态算 scale）、compressed-tensors 格式（`config.json` 里的 `quantization_config` 是量化生效的证据，vLLM 原生可加载）。机制上，`oneshot` 是薄包装，内部由 `Oneshot` 类完成「`pre_process` → `apply_recipe_modifiers` → `post_process`」三阶段（详细生命周期留待 u1-l4）；保存有「显式 `save_pretrained`」与「传 `output_dir` 自动保存」两种等价方式。`recipe` 参数可接受 YAML 路径、modifier 实例或 Recipe 对象。
