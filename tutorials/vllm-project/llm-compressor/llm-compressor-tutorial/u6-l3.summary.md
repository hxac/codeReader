本讲专讲量化后权重的「保存与序列化格式」这一收尾环节。核心机制：在 oneshot 三阶段里，`pre_process` 提前调用 `modify_save_pretrained`，用闭包（弱引用 + `_overridden` 幂等标志）把 transformers 原版 `save_pretrained` 包装成 `save_pretrained_wrapper`，接上外部库 compressed-tensors 的 `ModelCompressor` 序列化引擎；`post_process` 才真正调用它落盘。两个关键旋钮：`quantization_format` 决定磁盘字节布局（可从 scheme 自动推断，如 pack/float-quantized），`save_compressed` 决定权重是 `compressed` 打包态还是全精度 `frozen` 态。落盘除写 `config.json`/safetensors 外，还会 re-tie 相等的 embeddings、转 accelerate、回写 `quantization_config`、落 `recipe.yaml`、复制 modeling python/MTP 权重，分布式下仅 source 进程写盘。产物即 compressed-tensors 格式：safetensors 权重 + `config.json.quantization_config`，其中 `quant_method: "compressed-tensors"` 是 vLLM 分发加载器的唯一钥匙，`config_groups`/`ignore`/`kv_cache_scheme` 与 `QuantizationModifier` 字段一一对应；稀疏压缩（含 2:4）已被废弃。
