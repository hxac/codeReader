AIBrix 是一个开源、云原生的 GenAI 推理基础设施，以 Kubernetes 为地基，交付一组可组合的「构建块（building blocks）」来部署、管理和伸缩大模型推理（非训练），面向企业需求强调成本、稳定性与多租户。项目在架构上分为四大子系统：① 控制平面（Go，CRD + 控制器 + Webhook，负责模型部署、自动伸缩、LoRA、分布式编排，是系统大脑）；② LLM 网关（Go，基于 Envoy ExtProc，做请求路由、限流、状态同步，是用户请求唯一入口）；③ 运行时边车（Python，注入每个推理 Pod，做指标标准化、模型下载、引擎生命周期管理）；④ 分布式 KV Cache（Python + CUDA，L1/L2 两级跨节点缓存复用）。控制平面与数据平面（网关）分离：前者后台「摆棋局」，后者「前台接待」。运行时边车同 Pod 辅助推理引擎，向上暴露标准化指标供网关与伸缩器消费，多网关副本经 Redis 同步状态、做分布式限流。README 的八条核心特性（高密度 LoRA、网关路由、推理感知秒级自动伸缩、统一运行时、分布式推理、分布式 KV Cache、异构降本、GPU 故障检测）均可一一对应到某子系统，构成建立全局认知的特性矩阵。安装分依赖→CRD→组件三步，CRD 与 operator 分离是云原生典型做法。这些子系统、CRD 清单与控制平面/数据平面划分将贯穿后续讲义。
