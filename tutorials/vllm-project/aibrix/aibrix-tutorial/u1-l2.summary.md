本讲义是 AIBrix 仓库导览，拆为三个最小模块：顶层目录职责、Go 代码组织、Python 代码组织。核心结论：AIBrix 是 monorepo（Go 与 Python 共仓），靠目录约定分层——入口看 `cmd/`、逻辑看 `pkg/`、类型看 `api/`、Python 看 `python/`、部署清单看 `config/`、示例 CR 看 `samples/`。Go 遵循 kubebuilder 三段式 `api→pkg→cmd` 单向依赖，控制平面（`cmd/controllers`）与网关（`cmd/plugins`）共用同一个 `go.mod`，仅入口不同；`api/` 分 autoscaling、model、orchestration 三组，对应自动伸缩、模型适配、分布式编排三大能力域。Python 则是 `python/` 下两个独立发行包：`aibrix`（运行时边车/OpenAI 兼容前端/模型下载/指标）与 `aibrix-kvcache`（含 `csrc/` CUDA 源码的分布式 KV Cache），且须区分「外层项目目录」与同名 import 包的双层结构。引入的关键术语包括 monorepo、go module、CRD、kustomize、Feature Gate、`zz_generated` 代码生成与 Python 双层包结构，供后续讲义承接。
