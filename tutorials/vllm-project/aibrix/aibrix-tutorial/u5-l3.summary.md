本讲讲解 AIBrix 控制平面的 KVCache 控制器：它把 KVCache CR 翻译成 K8s 对象，采用两层结构——主控制器按 backend 注解分发到 BackendReconciler，后端再以 KVCacheBackend 接口注入差异，新增后端几乎不碰主循环。后端分两条路径：vineyard 独立一类（Deployment + etcd + 无 watcher），distributed（hpkv/infinistore）共用一类（StatefulSet + Redis + watcher，走 RDMA）。元数据存储二选一：内置单副本 Redis，或外部托管 Valkey/Redis（ExternalConnection）。外部路径遵循「先校验后清理」铁律——validateExternalConnection 校验 host:port 地址与 Secret 存在通过后，才用 cleanupInClusterRedis 删除旧内置 Redis Pod/Service，避免两头空。密码经 SecretKeyRef 由 kubelet 注入 watcher、不进控制器内存。关键限制是 ReconcilePodObject 只 reconcile 镜像，修改外部地址或密码 Secret 名后需重建 watcher Pod 才生效（Secret 值轮换则由 kubelet 重启自动重读）。控制器受 KVCacheController Feature Gate 控制，并通过标识标签反向 Watch Pod。
