本讲剖析控制平面二进制 `cmd/controllers` 的启动与装配流程，覆盖 main.go、controller.go、features、config、cert 等模块。启动是一条流水线：解析 flag → 校验并初始化 Feature Gate → 构建 rest.Config → 条件化注册 Scheme → 用 `ctrl.NewManager` 建空壳 Manager → 签发 webhook 证书 → 两阶段注册控制器 → 挂载 healthz/readyz → `mgr.Start` 阻塞运行。关键术语：controller-runtime 的 Manager（统管 Client/Cache/Webhook/选举的容器）与 Scheme（runtime.Scheme 类型注册表，未注册的类型无法序列化）。AIBrix 借鉴 Kruise，用 `controllerAddFuncs` 统一签名切片实现两阶段注册——`Initialize` 在建 Manager 前同步收集各控制器的 Add 函数，`SetupWithManager` 在证书就绪后异步遍历装配，分阶段的根因是控制器依赖 webhook、而证书由 cert-controller 异步生成；单控制器遵循 `Add→newReconciler→add`（Builder 链 `For/Watches/Complete`）模板。Feature Gate（`--controllers`）决定加载哪些控制器与对应 Scheme，并对缺失的可选依赖（如 KubeRay CRD）优雅降级。此外接线了基于 Lease 的领导选举（默认关、生产开启）与 healthz/readyz 探针，二者经 `certsReady` channel 与异步证书流程串联。
