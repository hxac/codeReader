本讲拆解 AIBrix 网关 `pkg/cache` 的感知层，含三模块。Pod 发现用 `discovery.Provider` 接口把 K8s informer 与静态 YAML 统一为 `WatchEvent`，后端一律吐出 `*v1.Pod`（静态 `host:port` 由 `addressToPod` 伪装成 Ready Pod），经 `addPod` 落地为 `metaPods`↔`metaModels` 双向映射；`Pod`/`Model` 结构携带模型归属、实时指标及挂载的 `OutputPredictor`。GPU 画像（`ModelGPUProfile`）是按 `(输出,输入)` token 的 `log2` 二维网格索引的性能表（吞吐/TTFT/TPOT/E2E），从 Redis 扫描加载、按 `Created` 版本择优、按 deployment 名查询，`GetSignature` 用对数域二分+容差夹中定位网格点。输出预测器（`SimpleOutputPredictor`）用「输入 token 分桶的滑动窗口直方图+加权随机」预估输出长度，由请求完成的 `DoneRequestTrace` 在线喂料。预测结果经 `RoutingContext.Features()` 统一出口，被 SLO 排队（`slo_queue`）与 pending-load 路由（`pending_load_provider`，用 Little's Law 合流预测特征与画像性能表算归一化负载）消费；易错点：VTC 路由用的是自己的 `SimpleTokenEstimator`，并不直接消费此预测器。
