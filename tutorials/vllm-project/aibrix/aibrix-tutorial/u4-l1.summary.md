本讲讲解 AIBrix `ModelAdapter` 控制器对 LoRA 适配器（参数高效微调产物，体积小、可高密度挂载于基座模型）的声明式生命周期管理。主循环 `DoReconcile` 为四步管线：`reconcileReplicas`（`Spec.Replicas` 省略即加载到所有匹配 Pod，为 1 则由调度器选单 Pod）→ `reconcileLoading`（经 `loraClient` 调引擎加载，仅成功才计入 `Instances`）→ `reconcileService`（建同名 headless Service）→ `reconcileEndpointSlice`（以已加载 Pod 的 IP 填端点）；并辅以 10 秒周期同步循环修复漂移、注解记录重试状态配合指数退避。关键术语：`ModelAdapter` CR 及其 Phase 状态机、`Instances/Candidates/ReadyReplicas` 计数器、作为唯一 HTTP 出口的 `loraClient`（靠 `BuildURLs` 与 `DetectRuntimeSidecar` 适配直连 vLLM/SGLang 与运行时边车，加载前先查 `/v1/models` 实现幂等短路）、finalizer 保证删除时先卸载引擎适配器、Service/EndpointSlice 借 OwnerReference 级联 GC。调度策略见 u4-l2，运行时边车深入机制见 u9-l1。
