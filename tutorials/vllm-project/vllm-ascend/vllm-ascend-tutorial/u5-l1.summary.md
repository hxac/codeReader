本讲围绕 `AscendAttentionBackend`（位于 `vllm_ascend/attention/attention_v1.py`），讲解标准注意力后端如何接入 vLLM。核心有两条独立机制：用 `@register_backend(AttentionBackendEnum.CUSTOM, "ASCEND")` 把后端「登记」进注册表，由平台钩子 `NPUPlatform.get_attn_backend_cls` 依三元组 `(use_mla, use_sparse, use_compress)`「选中」它。后端本身是「工厂+配置」：`get_impl_cls` 返回真正算注意力的实现类、`get_builder_cls` 返回元数据构建器，二者均按 `enable_dcp()` 在普通实现与上下文并行实现间分流。关键术语：注意力后端、KV cache、分页块管理、注意力元数据、DCP（上下文并行）。KV cache 形状 `(2, num_blocks, block_size, num_kv_heads, head_size)` 中第一维「2」用于叠放 Key(`[0]`)与 Value(`[1]`)，内核块大小固定 128。元数据分两层：`AscendCommonAttentionMetadata`（含 NPU 必需的 CPU 端字段）经 `AscendAttentionMetadataBuilder.build()` 翻译为 `AscendMetadata`；`AscendAttentionState` 五种枚举驱动算子分支，掩码由进程级单例 `AttentionMaskBuilder` 按需缓存。后续 MLA/SFA/DSA（u5-l2）与上下文并行（u5-l3）均建立于此注册与元数据机制。
