本讲讲解 vllm-ascend 的配置体系。`additional_config` 是 vLLM 留给硬件插件的自由配置 dict，由 `AscendConfig` 用 `.get(key, {})` 切片解析成 `AscendCompilationConfig`、`EplbConfig`、`SchedulerConfig`、`SparseKVOffloadConfig` 等子配置类。配置值遵循三级优先级：`additional_config` 显式值 → 环境变量 → 默认值，由 `_get_config_value` 统一实现，项目正把 `VLLM_ASCEND_*` 环境变量迁移到 `additional_config`。`AscendConfig` 以模块级 `_ASCEND_CONFIG` 做单例缓存，由 `init`/`get`/`clear` 管理生命周期，在 `NPUPlatform.check_and_update_config` 中构造；`envs.py` 用 `env_variables` 字典加模块级 `__getattr__` 实现惰性求值。新增的 `SparseKVOffloadConfig` 将稀疏注意力 KV 卸载到主机内存，硬性要求模型具备 `index_topk`、默认仅 PD 分离 D 节点可用，且与 `enable_sparse_sfa_c8` 互斥。
