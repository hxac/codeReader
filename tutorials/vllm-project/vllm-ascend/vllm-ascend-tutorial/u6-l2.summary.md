本讲是「自定义算子三层体系」第二层 Triton 算子层，覆盖 `ops/triton/` 目录。用 Triton 重写算子有三大动机：融合省访存、填补 GPU 专属算子空白（fla/mamba/kda 线性注意力）、精度适配。昇腾运行模型为「核数定 grid、UB 定 tile」：以 `grid=(num_vectorcore,)` 静态切分 batch，用 `UB_SIZE=87040` 反推每轮 token 数，`insert_slice`/`extract_slice`/`get_element` 为 tile 重组积木。主角融合算子 `split_qkv_rmsnorm_rope` 把 split + Q/K RMSNorm + Q/K RoPE 压进单 kernel，中间量全留统一缓冲，按芯片型号在默认版与 A5 SIMT 版间分发，由 `qknorm_rope_fusion_pass` 编译期自动改写。`fla/chunk.py` 是 Triton + AscendC 混合体，重活下沉 `torch.ops._C_ascend.*`，并支持 PCP 跨 rank 隐状态修正。这些算子仍走 u6-l1 的四段式注册、受 `HAS_TRITON` 保护；AscendC 实现见 u6-l3，融合 pass 见 u8-l2。
