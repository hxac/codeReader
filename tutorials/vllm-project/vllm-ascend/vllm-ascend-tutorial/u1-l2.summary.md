本讲绘制 vllm-ascend 源码地图。仓库代码分三类：纯 Python 包 `vllm_ascend/`（插件主体）、C++/AscendC 内核 `csrc/`（高性能算子，每个算子含 `op_host` 推导与 `op_kernel` 执行）、工程配套（setup/CMake/docs/tests）。`vllm_ascend/` 一级目录按职能分组：平台与配置（`platform.py`、`ascend_config.py`、`envs.py`）、集成核心 `patch/`、执行主链路 `worker/`、算力（`attention/`、`ops/`、`lora/`、`quantization/`）、分布式、编译、模型加载与进阶特性。核心结论是主干五件套：`__init__.py`、`platform.py`、`patch/`、`worker/`、`ops/`。引入的关键术语包括：entry points 入口点、`NPUPlatform`（平台身份证）、`AscendConfig`（配置对象）、`adapt_patch()` 两阶段补丁——`patch/platform/`（全局、引擎核心生效）与 `patch/worker/`（单卡执行生效）；`ops/` 分 Python 注册、Triton 内核、FusedMoE 引擎三层。插件发现链路为：vLLM 扫描 `vllm.platform_plugins` entry points → 调用 `register()` → 返回 `NPUPlatform` 字符串路径供 vLLM 延迟 import；`_ensure_global_patch()` 保证平台级补丁每进程只打一次。
