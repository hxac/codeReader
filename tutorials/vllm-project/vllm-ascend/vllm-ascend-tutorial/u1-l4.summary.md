本讲是 vllm-ascend 快速上手，围绕 examples/ 的最小离线示例展开，无需 NPU 即可读懂并改写代码。核心最小骨架为：建 SamplingParams → 建 LLM(model=...) → llm.generate() → 解析 output.outputs[0].text。引入的关键术语：离线推理（用 LLM 类在前端进程一次性生成，对应在线服务 vllm serve）、采样参数（与模型权重解耦）、张量并行 TP（权重切到多卡、经 HCCL 合并）。两条关键结论：其一，所有 NPU 示例须在导入 vLLM 之前设两个环境变量——VLLM_USE_MODELSCOPE=True（从魔搭拉模型）与 VLLM_WORKER_MULTIPROC_METHOD=spawn（让 worker 子进程全新初始化 CANN/HCCL，避免 fork 继承父进程设备句柄而出错）；其二，示例中无 import vllm_ascend，插件由 vLLM 按 entry points 自动发现加载、对用户透明并选中 NPUPlatform，这正是「可插拔硬件」的体现。examples/ 另覆盖多卡 TP（tensor_parallel_size、enforce_eager、max_model_len 等参数权衡）、睡眠模式（sleep/wake_up 分时复用显存）、Embedding（runner="pooling" + embed）、请求级指标（disable_log_stats=False）。后续 u1-l5 将拆解插件注册与发现机制。
