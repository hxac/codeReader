本讲是「自定义算子三层体系」的第一层，聚焦 Python 层算子注册。核心是 vllm-ascend 把 NPU 专属逻辑封装成 `torch.ops.vllm.<name>` 自定义算子，根本动机是让 `torch.compile` 与 ACL Graph 把集合通信当原子黑盒，避免被拆碎。关键工具是复用上游的 `direct_register_custom_op`，采用 **impl（真实现）/ fake（形状推导）/ register（注册到 vllm 命名空间并绑定 `dispatch_key="PrivateUse1"`）/ wrap（调用点）** 四段式，承接 u4-l2 前向里 `torch.ops.vllm.xxx` 的调用。重点拆解了四个**序列并行（SP）辅助算子** `maybe_chunk_residual`、`maybe_all_gather_and_maybe_unpad`、`maybe_pad_and_reduce`、`maybe_all_reduce_tensor_model_parallel`：它们处理 SP 边界处的聚合/切分与条件 all-reduce，行为依赖 u2-l3 引入的 `_EXTRA_CTX` 前向上下文，并用 `try/get_forward_context` 兜底以便单测退化为直通。本讲还区分了三套并存的注册机制：函数型 `direct_register_custom_op`、类级替换 `register_ascend_customop`（构建「层名→Ascend 子类」映射逐个 `register_oot`，不走 dispatcher）、占位融合算子 `register_dummy_fusion_op`（注册 `torch.ops._C_ascend.*` 供 torch.fx 融合 pass 图跟踪），三者均由 `NPUWorker.__init__` 触发，函数型算子另靠 `ops.__init__` 的 import 副作用注册。
