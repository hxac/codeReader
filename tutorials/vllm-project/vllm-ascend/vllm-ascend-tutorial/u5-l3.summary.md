本讲讲解 vllm-ascend 的上下文并行注意力（CP），实现为 Decode Context Parallel（DCP）：在 TP 组内部沿序列维度分片 KV cache，消除冗余存储且不增加进程数。开关 `enable_dcp()`（`decode_context_parallel_size > 1`）让各后端的 `get_impl_cls`/`get_builder_cls` 延迟 import 返回 CP 变体，CP 是后端特化而非独立后端。平台按 `(use_mla, use_sparse, use_compress)` 路由后端，模型只走其一，故 MLA 与 SFA 可各自独立做 CP。关键术语：DCP group、interleave 感知的本地长度（`get_dcp_local_seq_lens`）、LSE、`common_cp.py` 的两个 Mixin。三类分片策略：GQA 按 head 切并 gather Q、MLA 在隐空间 gather KV 恢复请求连续顺序、SFA 复制 indexer 而分片大 KV 并重映射 sparse 索引、DSA-CP 按 token 切（需 SP）。合并核心是「在线 softmax」，各 rank 局部结果经 LSE 合并后与单卡全序列注意力数学等价、结果无损。
