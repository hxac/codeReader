本讲讲解 vllm-ascend 如何被 vLLM 发现与注册。`setup.py` 在 `vllm.platform_plugins` 组登记 `ascend = vllm_ascend:register`，vLLM 启动时扫描该组、import 插件并调用 `register()`。`register()` 仅返回字符串 `vllm_ascend.platform.NPUPlatform`（延迟 import，避免重型 import 与循环依赖），vLLM 据此选中 `NPUPlatform` 为当前平台，再调其 `pre_register_and_update` 应用平台级补丁。插件共登记五把钩子：`register` 决定平台身份；`register_connector`、`register_model_loader`、`register_service_profiling`、`register_model` 属通用插件组，靠副作用注册 NPU 版连接器、加载器、profiling 配置与新模型，运行于 engine-core 子进程。关键概念：import 副作用（triton 兼容桩、日志配置、import 即打补丁）；`_ensure_global_patch` 为每进程一次的幂等闸门，因 spawn 子进程不继承父进程补丁而借通用插件回调重打；两阶段补丁由 `adapt_patch(is_global_patch)` 分发 platform、worker 两类补丁。
