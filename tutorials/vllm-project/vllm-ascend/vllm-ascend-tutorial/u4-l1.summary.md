本讲覆盖 vllm-ascend 最贴近硬件的一层——NPUWorker。它继承上游 WorkerBase，是每个 worker 子进程的核心对象，负责单卡资源管理与生命周期编排，前向本身委托给 NPUModelRunner。生命周期主线为：__init__ 重打 worker 级补丁（spawn 子进程不继承父进程补丁）→ init_device 做 DP 设备号偏移、NPU 绑定与 HCCL 分布式世界/并行组建立 → load_model → compile_or_warm_up_model 捕获 ACL Graph 并做 ATB 预热 → determine_available_memory 探测显存 → initialize_from_config 分配 KV 缓存 → execute_model 进入推理循环。execute_model 是 PP/SP 衔接层，用 irecv/isend_tensor_dict 在 rank 间收发中间张量，异步发送句柄靠 _pp_send_work 跨轮回收。本讲还引入三类运维机制：睡眠/唤醒（CaMemAllocator 按 tag 卸载/丢弃/恢复显存，SleepWakeupManager 清重建 HCCL 与 ACL Graph）、在线权重更新（_weight_update_active 驱动的三步状态机），以及调 npu-smi 的健康检查。
