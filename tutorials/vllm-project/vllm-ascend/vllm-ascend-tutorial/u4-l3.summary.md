本讲介绍 vllm-ascend 单卡前向的第二代实现 NPUModelRunner v2（MRV2）。其核心是「紧跟上游 v2 + 最小 Ascend 定制」：直接继承上游 GPUModelRunner，用上下文管理器包一层并精准替换若干子系统，区别于 v1 在巨型类里大面积重写。v2 默认关闭，仅由环境变量 VLLM_USE_V2_MODEL_RUNNER 启用（platform 补丁去掉了上游的白名单逻辑）。贯穿全讲的矛盾是：上游废弃了 CPU 端 seq_lens_cpu，而 NPU 注意力后端仍需它。由此引入状态三件套——AscendRequestState（保留 num_computed_tokens_cpu）、AscendInputBatch（新增 seq_lens_np、attn_state）、AscendInputBuffers（提供 seq_lens_cpu 的零拷贝 numpy 视图），并经独立 NPU stream 异步拷回 num_computed_tokens、在下一轮用 Event 同步后拼出 seq_lens_cpu。此外，AscendModelState 重写 prepare_attn 组装注意力元数据，build_attn_state 将批次形态翻译为 AscendAttentionState 枚举（如 PrefillNoCache / DecodeOnly / ChunkedPrefill）以驱动内核分支；AscendPCPManager 在 model_runner 层切分批次并刷新本地 seq_lens_np/attn_state（区别于注意力层内部的 CP）；ModelAclGraphManager 接管 CUDA Graph，flashcomm_dispatch_wrapper 处理序列并行 padding。v2 仍属实验性架构，部分特性待对齐。
