本讲聚焦 `NPUModelRunner`（v1 runner），它继承上游 `GPUModelRunner`，仅在采样器、注意力后端、输入批、图机制与 CUDA→NPU 兼容处做最小改写。一次前向主链路为 `_update_states`→`_prepare_inputs`→`_build_attention_metadata`→`_model_forward`→`_sample`，由 `execute_model` 与 `sample_tokens` 承载；前者返回 None，中间结果经 `ExecuteModelState` 接力，支撑 vLLM v1 异步调度。引入的关键术语包括 `AscendAttentionState` 状态机（驱动不同注意力路径）、携带 CPU 端 seq_lens 的 `AscendCommonAttentionMetadata`（避免 device→host 同步）、注入图模式与 MoE 通信方式的 `set_ascend_forward_context`。另讲一次性生命周期方法 `initialize_kv_cache` 中 `apply_layerwise_kv_cache_plan`（#12852）在分配张量前重排描述符、使多层分时复用有限物理缓冲以回收 HBM，并点出稀疏 KV 卸载（#13026）在初始化与元数据构建的挂载点。
