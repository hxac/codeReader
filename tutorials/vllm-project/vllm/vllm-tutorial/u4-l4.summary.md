本讲讲解 vLLM 的 KV 缓存显存管理。PagedAttention 借鉴虚拟内存分页，把 KV 缓存切成等大 block（block_size 默认 16），用块表将逻辑块映射到物理 block_id，消除外部碎片、把内部碎片压到最多 block_size-1 个槽；block_size 同时是分配粒度与前缀缓存命中粒度。所有块由 BlockPool 在构造时一次性建好并统一持有，运行期不新建块对象，靠引用计数 ref_cnt 与空闲块双向链表管理分配、命中复用（touch，ref_cnt+1）与释放（归零才回收），ref_cnt 正是多请求共享同一物理块的基础。KVCacheManager 是调度器的高层接口，核心入口 allocate_slots 按「算需求→判容量→touch 命中→取新块→缓存满块」五步工作，块不足时返回 None 触发调度器抢占（preemption）。分配结果封装为 KVCacheBlocks，经 get_block_ids 把块转成整数 ID 送往 worker，向调度器隐藏管理器内部结构。
