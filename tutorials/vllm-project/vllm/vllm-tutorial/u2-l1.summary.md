本讲围绕离线推理入口 `vllm.LLM` 讲透四个最小模块：构造、`generate`、`chat` 与返回结构。核心结论是 `LLM` 仅为 `LLMEngine` 的门面——构造时把所有参数打包成 `EngineArgs`，再由 `LLMEngine.from_engine_args` 真正加载模型、分配 KV 缓存显存并起 worker。`generate(prompts, sampling_params)` 接收原始文本 prompt，自动做连续批处理，`sampling_params` 可为单个、等长列表或 `None`（取模型默认）。`chat(messages)` 接收结构化对话，先用 chat template 渲染成纯文本，再走与 `generate` 完全相同的 `_run_engine` 同步 busy loop（`while has_unfinished_requests(): step()`）。两者唯一差别在入队前的渲染。离线路径把每个请求 `output_kind` 设为 `FINAL_ONLY`。返回值为两层结构：`list[RequestOutput]`（请求级，含 prompt、prompt_token_ids）内含 `list[CompletionOutput]`（候选级，含 text、token_ids、finish_reason），其长度由 `SamplingParams.n` 决定，取文本用 `output.outputs[0].text`。引入的关键术语：离线/在线入口、EngineArgs、OfflineInferenceMixin、_run_engine、FINAL_ONLY、RequestOutput/CompletionOutput，供后续讲义承接引擎架构与采样细节。
