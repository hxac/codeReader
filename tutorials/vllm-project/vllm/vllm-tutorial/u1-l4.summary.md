本讲拆解 vllm/__init__.py 的公共 API 与懒加载机制。核心结论：import vllm 只做两件必做之事——读 __version__、运行 env_override 设置环境变量并给 PyTorch 打补丁，并不立即加载 LLM 等重型对象。懒加载靠 MODULE_ATTRS（「名字→模块:属性」的字符串映射表）配合模块级 __getattr__（PEP 562）实现：首次访问某名字时，才 import_module 动态导入对应子模块、再用 getattr 取出对象并缓存到命名空间；if typing.TYPE_CHECKING 分支只在静态分析时为 IDE 与 mypy 提供类型信息，运行时不执行，从而兼顾启动速度与类型友好。本讲确立的三大公共对象为离线推理入口 LLM、采样参数 SamplingParams、模型注册表 ModelRegistry（负责把 HF 架构名映射到 vLLM 实现类）。输出数据结构分两层：请求级 RequestOutput 内含 outputs 列表，列表中每条是候选级 CompletionOutput（承载 text、token_ids、finish_reason 等字段），并配有 finished 标志；可用 sys.modules 直接验证「访问前后对应子模块是否被加载」的按需导入行为。
