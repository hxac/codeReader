本讲是 vLLM 学习手册首篇，重在建立全局认知而非代码细节。vLLM 定位为「快速、易用的 LLM 推理与服务库」，核心是在相同硬件上提升吞吐、降低延迟并兼容大量 HF 模型；入口分离线推理的 vllm.LLM 类与在线服务的 vllm serve。

讲义覆盖四个模块：PagedAttention 借鉴分页思想，把 KV 缓存切成固定大小的块（block），用块表把逻辑序列映射到物理块、按需分配，消除朴素连续 KV 缓存的内外碎片；连续批处理、分块预填充与前缀缓存让调度器每步动态增减请求、将长 prefill 切块与 decode 混算、复用共享前缀的 KV 块，使 GPU 每 step 满载，三者均依赖按块管理 KV；量化（FP8/INT8/INT4 等）与高性能内核压低显存与带宽，并在初始化时完成分片与量化以防峰值显存爆炸。

引入术语：推理、服务、KV 缓存、吞吐、block、块表、Sequence、prefill/decode、Engine Core 进程，供后续讲义承接。
