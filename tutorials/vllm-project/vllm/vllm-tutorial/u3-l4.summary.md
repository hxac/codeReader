本讲剖析 AsyncLLM：API Server 眼中的「引擎客户端」，前端进程通往后台 EngineCore 进程的异步代理。核心是区分两层易混抽象——上层接口 EngineClient 屏蔽引擎实现，下层 EngineCoreClient（异步为 AsyncMPClient）封装 ZMQ、划出进程边界；构造时输入/输出处理器均住前端进程，仅构造引擎核心客户端时拉起后台进程。请求处理为生产者-消费者：add_request 预处理输入并「双侧登记」（本进程登记队列、跨进程发请求）后返回每请求队列，generate 仅消费并 yield；唯一后台 output_handler 批量搬运并分发输出到各请求队列。进阶用法 InputStream 把 prompt 化为异步流逐块喂入，靠哨兵请求宣告输入结束。请求级元数据 session_id 逐层透传，经 EngineCoreRequest 字段跨进程序列化落地到 Request，AsyncLLM 仅搬运不消费。
