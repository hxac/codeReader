本讲义拆解 `vllm` CLI 从敲下命令到 HTTP 服务就绪的全链路，含四个最小模块。其一，CLI 总入口：`vllm` 是 `pyproject.toml` 声明的 console script，指向 `main:main`，以基类 `CLISubcommand` 配 `CMD_MODULES` 清单实现子命令分发，子模块在 `main()` 内懒加载，`cli_env_setup()` 将多进程方式设为 `spawn`。其二，`serve.py` 的 `ServeSubcommand` 负责编排：解析位置参数 `model_tag`、推算 `api_server_count`，分派到多端口、无头、多服务、单服务四条路线，默认单服务走 `uvloop.run(run_server)`；参数集中定义于 `cli_args.py` 的 `make_arg_parser`。其三，`launcher.py` 的 `serve_http` 是最外层 HTTP 壳，用 uvicorn 监听已绑定 socket，含 watchdog 与优雅关闭。其四，`api_server.py` 建引擎与 FastAPI app 并绑定端口。核心结论：三层职责分明——serve.py 决策、api_server.py 建引擎并绑 socket、launcher.py 跑 uvicorn。关键术语：console script、子命令分发、FlexibleArgumentParser、uvloop、OpenAI 兼容服务、headless、watchdog。
