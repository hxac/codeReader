本讲讲解 `SamplingParams`——连接用户采样意图与 V1 采样器的参数容器（`msgspec.Struct`，字段语义对齐 OpenAI text completion API），覆盖五个核心字段：`temperature`（默认1.0）控制分布尖锐度，接近 0 时由 `__post_init__` 判定为贪婪采样，并复位 `top_p/top_k/min_p`、要求 `n==1`；`top_p`（核采样）、`top_k`、`min_p` 是三种互补的截断手段，在采样链中「施温度后、抽签前」生效，可叠加取交集；`max_tokens`（默认16）与 `min_tokens`（默认0）控制生成长度，后者在未达最小长度前屏蔽 EOS；`n` 让一个 prompt 产出多条独立候选，贪婪下只能为 1 且受 `VLLM_MAX_N_SEQUENCES` 约束。采样路径经 `SamplingType`（GREEDY/RANDOM/RANDOM_SEED）分流，实际消费者为 `vllm/v1/sample/sampler.py` 的 `Sampler`。
