本讲下钻 worker 上的运行中枢 GPUModelRunner：它把调度器产出的 SchedulerOutput 翻译成模型 forward 所需的扁平张量，跑一次前向并产出 logits。核心有三条主线：一是持久缓冲区——所有输入张量按 max_num_batched_tokens/max_num_seqs 预分配为 CpuGpuBuffer（CPU/GPU 双端、非阻塞拷贝），每步只改内容不重建，这是 CUDA Graph 与高效 H2D 拷贝的共同前提；二是 InputBatch（代码类名，记作 GPUInputBatch）用一张二维 token 表 token_ids_cpu 承载跨 step 的状态，由 add_request 写入、condense 压实空洞保证有效请求排在前 N 行，前向时经 _prepare_inputs 用 np.repeat/index_select 拍平成一维快照；三是 execute_model 主线「更新批状态→拍平→H2D→_model_forward→暂存 execute_model_state→sample_tokens 采样」，异步调度下前向与采样分两阶段以重叠 CPU 调度与 GPU 计算。另讲 CUDA Graph 按固定 shape 预捕获典型 batch、运行时靠 padding 对齐后 replay 的机制；以及本版本把 routed experts 捕获的绑定 bind_routed_experts_capturer 与 attn-gid 推导外移到 capturer 模块、并新增 get_routed_experts 快照方法的重构。
