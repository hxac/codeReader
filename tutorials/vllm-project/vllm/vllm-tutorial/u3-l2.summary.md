本讲覆盖 vLLM 配置体系三个最小模块：`VllmConfig`、`ModelConfig`、统一构造签名 `__init__(*, vllm_config, prefix)`。`VllmConfig` 是聚合十余块子配置（model/cache/parallel 等）的「引擎级全局状态」，由 `@config` 装饰的 Pydantic dataclass，默认 `extra="forbid"`；其 `__post_init__` 负责跨配置校验与派生（如推导 `quant_config`、决定 V2 model runner 回退），`compute_hash` 为编译缓存生成指纹，`model_config` 默认 None 故构造时不下载模型。`ModelConfig` 描述模型本身，借 `is_moe`、`architecture` 等属性驱动调度与并行决策。核心结论：所有模型构造签名被统一（Uniformity），使 model runner 能用同一句话创建任意模型、便于组合 VL 模型；张量并行分片与量化在初始化时完成，避免大模型峰值显存爆炸；`prefix` 标识各层在 checkpoint 中的位置，是非均匀量化的关键。引入的关键术语：引擎级全局状态、`@config`/Pydantic dataclass、跨配置校验、`compute_hash`、`set_current_vllm_config`、`prefix`、初始化时分片/量化。
