vLLM V1 采用多进程架构以分离关注点、最大化吞吐，含四类进程：API Server 负责 HTTP 接入与 tokenize/多模态预处理（CPU 多线程，不碰 GPU）；EngineCore 是调度与执行编排核心，跑 busy loop（收请求→step：schedule→execute_model→update_from_output），其中 execute_model 非阻塞返回 Future，使 CPU 调度与 GPU 计算重叠；GPU Worker 每卡一个，由 Executor 拉起，跑 forward 与 KV 缓存实际存储；DP Coordinator 仅 DP>1 时存在（1 个，住 rank 0），做跨 rank 负载统计发布与 MoE wave 同步。进程间用 ZMQ 通信，每个 API Server 经 DEALER/ROUTER、PUSH/PULL 连到所有 EngineCore，形成多对多拓扑，同机 IPC、跨机 TCP；worker 间则走 NCCL 集合通信。进程总数 = A + DP + N（DP>1 再+1），N = DP×PP×TP。核心类：EngineCore/EngineCoreProc、AsyncLLM、EngineZmqAddresses、DPCoordinator。动机是让 CPU 输入、调度、GPU 计算各占独立进程，互不抢占 GIL。
