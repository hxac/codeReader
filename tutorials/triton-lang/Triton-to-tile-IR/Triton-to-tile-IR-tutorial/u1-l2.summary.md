本讲解决「如何安装本仓库、如何在两个后端间切换、如何确认当前走哪个后端」，分三个最小模块展开。

源码安装：在仓库根目录用 `pip install -e .`（可编辑，适合开发）或 `pip install .`（装好即用），沿用上游 Triton 流程，故称安装方式不变，仅多一个运行期开关；前提是已装 CTK 13.1。

wheel 并存安装：用 `pip install --no-deps --target DIR ./nvtriton-...whl` 把带 TileIR 的 nvtriton 装进隔离目录，不碰 site-packages 里的 oait。并存三要素为隔离目录、跳过依赖、运行期用 `PYTHONPATH` 切换；且 wheel 内嵌 `tileiras`/`ptxas`，无需另装 CTK。

切换与验证：`PYTHONPATH` 决定加载哪个 triton 包，`ENABLE_TILE=1` 决定激活哪个 driver，二者须同时满足。关键术语：oait 指上游 OpenAI Triton（走 PTX 后端，默认），nvtriton 指本仓库发布的 wheel（走 TileIR 后端）。源码真相在 `driver.py` 的 `_create_driver()`：把 `ENABLE_TILE=="1"` 置于最优先分支，无条件返回 `TileIRDriver()`；`driver.active` 为惰性缓存属性，故开关须在 `import triton` 之前设置。验证金标准是两条命令：`triton.__file__` 确认加载层，`type(driver.active).__name__` 确认 driver 层。
