本讲为整套手册起点，建立 Triton-to-tile-IR 仓库的全局认知：它是上游 Triton 之上的孵化器仓库，新增（非替换）了 CUDA Tile IR 后端这条编译路径，两后端共享前端（Python 内核→TTIR），区别仅在 TTIR 之后的走向。核心开关为 `ENABLE_TILE=1`，依赖 CUDA 13.1 的 `tileiras`/`ptxas`/`libnvvm.so`，仅支持 Blackwell GPU。关键差异：PTX 是默认后端，旋钮为 `num_warps`、`range_*`、`static_ranges` 等；TileIR 旋钮完全不同，以 `occupancy`（1–32）、`num_ctas`（dot 类负载推荐 2）、更宽的 `num_stages` 为主，暂不支持 `num_warps`，配置不能直接互搬。TileIR 当前仅支持无序内存模型（unordered memory model），全局别名访存或跨 tile 块传递（splitK/streamK）可能算错，需 memory token 显式排序；默认关闭 approx 与 FTZ 两类数值优化。已知限制含小 GEMM、旧式指针 load/store 性能差，及 `tt.gather`、`cf.cond_br`、`math.erf` 等算子与部分 TMA 特性尚未支持。本讲只读不写代码，为后续安装运行、目录结构、端到端编译链路（`make_ttir`→`make_tileir`→`make_cubin`）打基础。
