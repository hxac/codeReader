本讲建立学习 Triton 的全局心智地图，覆盖三个最小模块：项目定位、技术栈概览、硬件与平台支持。核心结论：Triton 是一门编写深度学习算子的小语言加编译器，定位在 CUDA（极致但难写）与通用 DSL（省事但不灵活）之间，靠块级编程加编译器自动调度兼得灵活与高效。技术栈分三层：Python 前端、C++/MLIR 编译器、硬件后端；一条 kernel 的编译主线为 AST → TTIR → TTGIR → LLIR → PTX/amdgcn → cubin/hsaco，其中 TTIR 是逻辑层 IR、TTGIR 是带 GPU 布局的物理层 IR，皆基于 MLIR 自定义方言。本讲引入的关键术语：JIT 即时编译、program/grid 并行度、triton.jit、triton.language（tl）、autotune、triton.compile。平台仅官方支持 Linux，NVIDIA 需 Compute Capability 8.0+，AMD 需 ROCm 6.2+，CPU 后端开发中；支持 Python 3.10–3.14（对应 Triton 3.8.0），无 GPU 可用 TRITON_INTERPRET 解释器模式学习。
