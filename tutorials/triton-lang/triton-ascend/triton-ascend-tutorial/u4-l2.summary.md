本讲精读 Ascend 后端 ttir_to_linalg 链中的首个结构化 pass——triton-to-structured，职责是把「一维指针算术 + 复杂掩码」逆向工程成结构化块访存。它引入两套对称中间表示：PtrState（基址 + 标量偏移 + 每维 (stride, shape)）与 MaskState/dimInfo（每维一个比较），二者按维分解以便逐维对齐匹配。指针分析是一棵递归 AST 遍历（visitOperand 派发 addi/muli/divsi/remsi/make_range/broadcast 等），其中 DivSI/RemSI（x//D、x%D）能把一维索引分裂成二维、产生零步长的广播维，这是触发本 pass 的根因。核心闸门 shouldLinearize 仅在指针含广播维时为真，此时 LoadConverter/StoreConverter 才改写访存，并用 materializeImplicitBroadcast/Reshape/Permute/Select 补回被抽走的结构；一维连续访存（如 vector-add）则原样保留。本 pass 受「整除/块大小」硬性限制：除数、步长、形状须互为倍数，掩码仅支持 slt/sge/ult/uge 四种比较，不满足时分析失败，访存留给后续 u4-l3（离散掩码）、u4-l4（标量化）处理。
