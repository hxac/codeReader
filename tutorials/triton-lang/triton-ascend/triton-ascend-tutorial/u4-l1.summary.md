本讲是 Ascend MLIR pass 流水线总览，讲解 compiler.py 中 ttir_to_linalg（ttadapter 阶段）的 pass 编排：用 ir.pass_manager 经 ascend.passes.ttir.add_* 按固定顺序登记十余个 pass，由一次 pm.run 统一执行，输入输出均为 IR 文本。主线顺序为控制流优化→结构化（跑两次，第二次兜底）→离散掩码转换→annotation→标量化→hivm/hfusion/llvm 方言 lowering→bubble-up→add_triton_to_linalg 完成 TTIR→Linalg→可选 CV 流水线。核心结论：登记顺序即执行顺序；门控字段皆源自 NPUOptions，经 core compile 的 **options.__dict__ 灌入 metadata；两大总开关为 compile_on_910_95（950，影响个别 pass 内部分流）与 enable_dynamic_cv_pipeline（950 默认开启，门控整块分支及 metadata 改写）。pm.get_pipeline_str() 与 triton-opt --pass-pipeline 对应，可命令行复现调试。各 pass 内部变换留待后续精读。
