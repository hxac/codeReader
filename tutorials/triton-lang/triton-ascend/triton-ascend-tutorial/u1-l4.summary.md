本讲是「认识 Triton-Ascend 与第一次运行」单元的收尾，以 `tutorials/01-vector-add.py` 为例在 Ascend NPU 上跑通第一个 kernel，串起三个最小模块：`@triton.jit` 把普通 Python 函数变成目标无关的「待编译 kernel」，首次调用经 `JITFunction.run` 按需编译为 TTIR 并缓存，方括号语法 `kernel[grid](...)` 源自 `KernelInterface.__getitem__`；`grid` 决定开启的 program 数（由 `cdiv(n_elements, BLOCK_SIZE)` 向上取整），`tl.program_id(axis=0)` 让每个 program 处理一块；`tl.load/tl.store` 用「指针+偏移+掩码」分块访存，`mask` 屏蔽末块越界位置。由此引入 kernel、block、grid、program、`constexpr`、TTIR 等术语。校验用 PyTorch 原生结果与 `assert_close` 比对，逐元素加法误差恰为 0。核心结论：本例位于 `third_party/ascend/` 却复用 core 通用语法，体现 u1-l2 分层原则；这条「定义 kernel→切分 grid→块级访存→校验」闭环是后续所有 kernel 的骨架。
