本讲在可组合 epilogue 骨架（EpiOp 生命周期、fn_port 端口、@gemm_epilogue 契约）上精读 quack/epilogue/ 四个领域模块，心法是「领域 op = 新 EpiOp + 一个端口方法」：函数体是组合点（计算顺序显式），op 是扩展点（资源生命周期写一次即可与所有 op 组合）。rotary 把 cos/sin 来源封装成 value 端口 op，分表加载（TMA 默认，head 广播靠拷贝坐标，因 TMA 无法编码 stride-0）与内核内 sincos（float-float turns 数学）两路，非旋转布局编码为零频率数据。GroupedColStatsBase 抽象「主存储前算分组统计、再逐元素应用」：作 prepass sink 无浮点原子地折叠进寄存器（蝶形 + smem plane），又作 value 端口广播定稿值；HeadRstd（rsqrt(mean+eps)）是其最小实例。scaled_exp 用每（行，N-tile）幂次偏移稳定存 exp（MaxLog2 prepass + 主函数 exp2(acc·log2e−k) + ColVecReduce sum_exp + GroupedColStatsOut 写 k），LSE 另有 OnlineLSEReduce（耦合 max,sum）与 ColVecSelect（逐行 gather）。BlockScaleFactorStore 在 store_convert 前对最终 fragment 原地量化（amax → rescale），使普通 convert 出量化值，与 DStore 共享 store 钩子。
