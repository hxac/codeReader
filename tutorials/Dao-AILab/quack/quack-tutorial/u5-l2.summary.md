本讲拆解 Hopper（SM90）持久化 GEMM 内核 `GemmSm90`（继承 `GemmTmaBase`），覆盖配置几何、TMA 加载与 cluster 多播、WGMMA 主循环、epilogue 分区四个模块。配置核心是 `atom_layout_mnk`：coop 模式沿 M/N 拆多个 WGMMA atom 合力算一个 tile；pingpong 模式固定 `(1,1,1)` 由两个 WG 交替算相邻 tile 以重叠 MMA 与 epilogue；多出的一个 WG 充当 producer。输入侧 producer warp 用 TMA 把 A/B 灌进多级缓冲，cluster=(1,2) 多播 A、(2,1) 多播 B，靠事务屏障 `complete_tx::bytes` 信用与按多播 peer 数放大的 consumer 到达计数同步。计算侧分 SS（A 来自 SMEM、`wait_group(1)`）与 RS（A 来自寄存器、装载夹在 WGMMA 之间、等待更深）两条 WGMMA 主循环，`transform_a` 强制走 RS。epilogue 用 `partition_for_epilogue` 按 epi 子 tile 切分张量、`StMatrix` 存进 SMEM 再由 TMA 存走，驱动循环在基类。关键结论：SM90 默认关闭 dynamic persistent——Hopper 无硬件 CLC，动态只能靠 GMEM 原子计数器工作偷取，开销高于静态光栅化的负载均衡收益，仅 varlen 场景例外。引入的关键术语 TMA、WGMMA、cluster、atom_layout、coop/pingpong、SS/RS 主循环、wait_group、producer/consumer、PersistenceMode（NONE/STATIC/DYNAMIC/CLC）、epi_tile、StMatrix，供后续 SM100（Blackwell）讲义承接。
