本讲解决「如何把 QuACK 在本机跑起来」，覆盖三个最小模块。安装与开发环境：分发名 `quack-kernels`、导入名 `quack`；开发用 `pip install -e '.[dev]'`（editable 模式 + dev 工具组，含 pytest-xdist、ruff、pre-commit），CUDA 13 改用 `[dev,cu13]` 且禁用 uv；依赖与 extras（cu13/heuristics/jax/bench/dev）全部声明在 `pyproject.toml`，版本号动态取自 `quack.__version__`。pytest 运行：内核测试因参数化爆炸、冷编译慢、依赖 GPU 而需精确切片，核心用 `-x`（遇错即停）、`-k`（关键字过滤）、`-n`（xdist 多卡并行）、`--async-compile=N`（冷编译交后台 worker 池与测试重叠，缓存热时零开销）。测试夹具 `tests/conftest.py` 做三件项目专属的事：import 期就完成 xdist worker 对 GPU 的 round-robin 分配（须早于任何 CUDA 触摸）、收集后打印用例数汇总、用例 OOM 时清显存自动重试一次。核心测试哲学：每条用例必须与 PyTorch 参考实现做带 dtype 相关容差的数值比对，而非只查形状。
