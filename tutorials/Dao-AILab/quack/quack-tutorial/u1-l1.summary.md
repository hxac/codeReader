本讲确立 QuACK 的项目身份。它是「Quirky Assortment of CuTe Kernels」——一组用 Python（CuTe-DSL）编写、由工具链编译成接近手写极限的机器码、供 PyTorch 调用的高性能 GPU 内核，区别于传统 CUDA C++。目标硬件为三类最新 NVIDIA GPU：H100（SM90/Hopper）、B200·B300（SM100/Blackwell 数据中心）、RTX 50（SM120/Blackwell 消费级），同一算子按 SM 编号分发不同实现，如 `gemm_sm90/100/120.py`。共提供七个内核：RMSNorm、Softmax、Cross entropy、Layernorm 四个归约算子，外加三种 GEMM。需注意分发名 `quack-kernels` 与导入名 `quack` 不同，最核心的依赖是被锁定为 4.7.0 的 `nvidia-cutlass-dsl`（CuTe-DSL 本体）。顶层公开 API 很小，由 `quack/__init__.py` 的 `__all__` 暴露 `rmsnorm`、`softmax`、`cross_entropy`，当前版本 0.6.4。本讲引入的关键术语为后续承接：CUDA 内核、CuTe-DSL、SM（流多处理器）、包与 extras。
