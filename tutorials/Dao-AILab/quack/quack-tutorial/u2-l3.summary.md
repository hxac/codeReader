本讲讲解 softmax 反向内核及 autograd 集成。数学推导得闭式公式 dx_i = y_i(dy_i − dot)，dot = Σ dy_j·y_j，只需一次行内点积归约。SoftmaxBackward 继承 ReductionBase，设 stage=1、reduction_dtype=Float32，同时加载上游梯度 dy 与 softmax 输出 y，分配双 SMEM，OOB 填 0（而非前向的 −∞），用 row_reduce 算 dot 后逐元素得下游梯度 dx；因双 SMEM 占用，其线程数与 cluster 阈值较前向更保守。SoftmaxFunction 用 torch.autograd.Function 接入微分：forward 仅 save_for_backward 保存 y（不存输入 x），backward 取回 y 调 softmax_bwd。因前向 CUDA 内核异步、反向需读同一 y，eager 模式取 grad 前须 torch.cuda.synchronize() 以防竞态。公开 API quack.softmax 经 Function.apply 与 @cute_op 自定义算子（mutates_args 标注原地输出）、compile 到达设备内核，反向链路对称。
