本讲在公共 GEMM API 之上搭出三个仅做自动微分编排、不含 CUDA 内核的高层算子。Linear 前向压成一次 gemm；fuse_grad_accum 借 gemm_add_inplace 的 β·C 项把「算 dW」与「累加进 .grad」合为一次 GEMM，并置空 .grad 规避 PyTorch 重复累加，因就地改写叶子 .grad 而与 torch.compile 不兼容，编译期自动回退普通路径。MLP 用 gemm_gated 把门控激活（swiglu）压进一次 GEMM；recompute 路径反向重算 preact 以算力换显存；concat_layout 让 gate/up 交错存储免拷贝。Fused Linear-CE 沿 batch 分块，使 logits 峰值显存从 (B·L,V) 降到 (chunk,V)，logits 与 dlogits 复用同块显存，dw 以 fp32 跨块累加，最后一块推迟到反向，把缩放与精度下转 fold 进一次 GEMM。关键术语：配置包（_XxxOps）、fuse_grad_accum、gemm_gated、recompute、concat_layout、chunked、scaled-exp 流水线。
