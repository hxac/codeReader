本讲聚焦 PD 分离架构的**接收侧与控制平面**，覆盖 `receive_server.py` 与 `wire.py` 两个模块。核心要点：一是「双轨设计」——控制平面走 TCP 传小 JSON（长度前缀帧 `send_msg/recv_msg` + 16MB 上限护栏），数据平面走 RDMA 传 KV 字节，二者并行；二是「缓冲即地址预约」——`ReceiveServer` 启动期按 `max_seq_len` 预留一块连续显存，由 `ModelProfile` 的 `buffer_bytes`/`hello_layout` 算出 kv/pe/ki 三平面绝对地址并注册给 RDMA 引擎，接收端零拷贝，靠预约地址把多段写入拼成完整请求。关键术语包括 `hello_msg` 信封、`derive_rid` 请求 id 归一化、`layout_version`（随 cache dtype 变，fp8 基值、bf16 加 40，把错配挡在握手期）、`MAGIC`、`sender_ranks`、`ReceivedRequest`、`done_ranks` 状态机。握手期由发送端读 hello 做四项校验（magic/layout_version/transport/max_seq_len），接收端对 seq_len 另有重复拦截。完成判定用 `done_ranks >= sender_ranks`，机制为多 rank 而设计；因 MLA 潜在 KV 在 TP 间复制，`sender_ranks={0}` 实际退化为等 rank 0 一人，且采用 bs=1 单槽位 `_current` + 锁实现一次只服务一个请求。
