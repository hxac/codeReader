本讲聚焦 `ShowHandsDSALayer`——Generator 的「牌桌管家」，负责把 Python 装配的模型树搬上 8 卡并交给 C++ 后端。它构造廉价（只记配置），真正的 8 卡加载发生在 `from_pretrained` → `_init_weights`。三大模块：(1) 多线程分卡权重加载：`_init_weights` 利用离线转换产生的 `*_dev_{id}` 键名分区，为每卡起一个线程并行读分片、装配 `Dsa` 树，并递归压扁成 `(intermediates/temp_vars, caches, params, profile_logs)` 四元组，天然并行无冲突；(2) V2 P2P：卡 0 持 `peer_bufs`「通讯录」、卡 1..7 各建 `ll_buf` 接收缓冲，8 线程 join 后由主线程把各 `ll_buf` 的 GPU 地址回填进卡 0 的 `peer_bufs`，替代传统 allreduce；(3) `prepare_money`：把四类扁平张量交给 C++ 后端并捕获 CUDA Graph，MTP 模式调两遍（完整图+主模型子图）。关键时序链为 `ll_buf` 创建 → join → 地址回填 → `prepare_money`，任一前置都会致地址无效或图固化错误地址；采样参数固化在图里，运行时改参需先 `go_home` 释放旧图、改 `SAMPLING_CONFIG` 槽、再 `prepare_money` 重捕。引入的关键术语：`prepare_money`/`show_hands`/`go_home` 控制算子族、四元组张量契约、`peer_bufs`/`ll_buf`/`partial_buf`、`Dsa` 容器、CUDA Graph 捕获。
