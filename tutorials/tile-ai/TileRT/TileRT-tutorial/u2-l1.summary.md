本讲精读 tilert/models/base.py 的 Python 侧抽象，讲清 TileRT 如何用「壳」组装模型。TileRTModule 是所有算子与容器的共同基类（继承 nn.Module + ABC），统一计算核类型白名单校验、运行环境记录与状态标志，并以 @abstractmethod 强制子类实现双前向契约：golden_forward 为纯 PyTorch 参考实现（用于数值对拍），tilert_forward 调后端 .so 高性能算子。算子用 algorithm 枚举标明融合实现，其字符串值与转换器方法名 convert_to_<algo> 隐式绑定以驱动离线转换分发；同时持有两套一一对应的权重别名——ref_weights_alias（HF 侧长名，转换时取）与 tilert_weights_alias（TileRT 侧短名，运行时认），均以可调用对象实现。容器基类 SerializableTileRTModule 用 exec_seq 配合 prefix_seq/suffix_seq/retain_weights_seq 四个等长平行列表装配子算子，聚合方法遍历 exec_seq 递归汇总，天然支持容器嵌套。关键方法 init_tilert_weights 按 prefix + alias + suffix 从扁平 state_dict 匹配权重，再以短别名交给子算子——位置感知隔离在容器层，叶子算子只认短名；remove_selected 用完即删以降峰值显存，retain_weights 则保留 head/embedding 等共享权重。基类契约、权重别名、容器装配与键名匹配四点，构成阅读任意 modules/ 与 ops/ 代码的执行契约基础。
