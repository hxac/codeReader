本讲解析 `python -m tilert.generate` 如何一步步变成一次模型生成，覆盖参数解析、权重目录解析、生成器分发三个最小模块。核心 key 是 `model_type`（`deepseek_v3_2`/`glm5`），同时决定加载哪个后端、构造哪个生成器类、从配置读哪个权重键。`parse_args()` 用 argparse 定义参数，短横线 flag 解析后转下划线属性名。`get_weights_dir()` 按「`--model-weights-dir` > `~/.tilert/config.toml` 的 `[weights][model]`」两级优先级解析权重目录，缺失时有引导式报错。`get_generator()` 是分发枢纽：先 `tilert.load_backend(model_type)`（单进程互斥的懒加载入口）加载后端，再延迟 import 对应生成器类并构造。两个反直觉点：`use_topp` 非独立开关，由 `top_p < 1.0` 隐式推导；基准模式下 `--with-mtp` 被忽略、生成器强制以 `with_mtp=True` 加载。`__main__` 把三者串成「解析参数 → 解析权重 → 决定 with_mtp → 构造生成器 → 加载权重 → 交互或基准 → cleanup」的完整链路，CLI 分交互模式与基准模式两条分支。生成器内部的 `from_pretrained/generate/cleanup` 生命周期留待后续讲义详讲。
