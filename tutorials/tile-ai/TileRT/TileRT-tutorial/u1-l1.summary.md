TileRT 是面向超低延迟 LLM 推理的运行时，以 TPOT（单 token 延迟）而非总吞吐为优化标尺，区别于 vLLM 类追求吞吐的系统；它不靠缩小模型或降低质量换速度，而在小 batch（甚至 bs=1）下把 TPOT 压到毫秒级。其核心是 tile 级运行时引擎：由编译器把大算子分解为细粒度 tile 任务，运行时再动态重排，使计算、IO、通信高度重叠，从而最小化硬件空闲。本讲引入的关键术语包括 TPOT、prefill/decode、tile、tile 级运行时、decomposed、overlapped，以及上游技术 TileLang/TileScale。能力边界上，支持 DeepSeek-V3.2 与 GLM-5/5.1 两个模型，各自编译为独立后端共享库（libtilert_dsv32.so 与 libtilert_glm5.so），且一进程只能加载一个；硬件与依赖为精确 ABI 绑定：8× NVIDIA B200、CUDA 13.2、torch 2.11.0+cu130、Python 3.12。本仓库仅为 Python 驱动与模型组装层，真正的运行时大脑编译进 .so 后端库，具体加载机制留待后续讲义展开。
