本讲讲解 DeepSeek-V3.2 的 MLA 注意力在 TileRT 8 卡上的**非对称拆分**：device 0 用 `SparseSelectMlaV2` 独自承担 NSA 稀疏选择，跑索引头算出本轮应关注的历史位置 `IDX_SELECTS`（末维恒为 `index_topk=2048`，与序列长度无关）并广播给其余 7 卡；device 1..7 用 `PureMlaV2` 只做标准「压-算-展」真注意力，消费广播的选择结果，最后经 `unproj_o_allreduce` 在 7 卡组内归约。关键术语包括：MLA（多头潜注意力，靠 `kv_lora_rank=512` 压缩 KV 省 cache）、NSA（原生稀疏注意力）、V2 P2P（device 0 的 `peer_bufs` 通讯录存其余卡 `ll_buf` 显存地址，直接写对端替代 allreduce）、`partial_buf`（仅 device 0，因它既是选择之源又是部分输出之汇）。三层缓存 `ki_cache/kv_cache/pe_cache` 在两类里布局一致。头切分非对称：device 0 每卡 16 头，device 1..7 补齐对齐到 20 头（`mla_num_devices=7`）。地址回填须在 CUDA Graph 捕获前完成。
