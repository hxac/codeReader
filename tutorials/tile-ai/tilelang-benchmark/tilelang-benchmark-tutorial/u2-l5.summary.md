本讲剖析 tilelang-benchmark 中编号 0 的 cuBLAS 参考基线（CUDA C++ 测试床），它是整套对比框架的标尺。涵盖四个模块：CMake 构建系统查找 cudart/cublas/curand 依赖，目标架构被覆盖为 80（与目录名暗示不符）；tensor.h 的 Tensor<T> 用 cudaMalloc+shared_ptr 实现显存 RAII，rand 用模板特化间接支持 half/int8，pad_dim 为 int8 Tensor Core 把 m 补齐到 4 倍数；计时核心 time_gemm 用 host 侧 std::chrono 配 cudaDeviceSynchronize 屏障，自适应重复 numRepeats=max(5,100/(periter_us×1e3)) 因放大因子实际恒退化成 5；cublasGemmEx 一个函数靠模板类型 T1 编译期分派 fp32/fp16/int8 三路径，algo 与 math mode 切换 Tensor Core。关键结论：CSV 表头写 usec 实为毫秒（单位陷阱），下游 data/*.py 取 [-2] 即 fp16 Tensor Core 列作为 cuBLAS 代表值。引入的术语 cublasGemmEx、Tensor Core、host 侧计时、dp4a、列主序为后续 Triton/TileLang 计时对照奠定基础。
