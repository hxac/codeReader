本讲聚焦 AMD/HIP 平台的 tvm.tl 卷积内核，含四个最小模块。一是区分同一 TileLang DSL 的两种宿主：TVM 内置的 tvm.tl 变体（`from tvm import tl`、显式 `profiler="tvm"`、autotune 返回 3 元组）与独立 tilelang 包（返回对象）；区分依据是 import 路径、profiler 与返回值结构，而非 target——`target="hip"` 仅表示目标硬件为 AMD（HIP≈AMD 版 CUDA），两种变体在 CDNA 上都用。二是以 im2col 思路把 NHWC 卷积「拍扁」成块级 GEMM：输出与权重用 T.Buffer 视图零拷贝重排为 (N·OH·OW, F) 与 (F, KH·KW·C)，data 因映射非线性只能加载时逐元素换算地址。三是给出地址公式 access_h=oh·S+kh·D−P、access_w=ow·S+kw·D−P，配 in_bound 掩码用 T.if_then_else 把 padding 区回退为 0，一行同时编码 stride、dilation、padding。四是调优用 itertools.product 暴搜 192 个配置、无 Roller 分支，k_pack 与 coalesced_width 为写死旋钮，shell 逐 shape 产日志、再用正则抽 Best TFlops。
