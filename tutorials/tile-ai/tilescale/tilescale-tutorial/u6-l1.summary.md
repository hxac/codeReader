本讲是分布式单元的地图课，只画认知地图不深入原语参数。核心结论：README 宣传的 HDA（层次化分布式架构）愿景要把 compute/memory/network 三类资源统一抽象成一个 mega-device，并以 T.Scale、T.Kernel(device=, cta_cluster=) 表达层级化 SPMD，但这些原语在源码树中均未实现，目前属「待确认」。真正落地的是「多进程 + NVSHMEM」务实路线：launch.sh 用 torchrun 每卡拉一个进程，每个进程即一个 PE，各跑同一份单机 T.Kernel，靠远程原语显式通信，SPMD 发生在进程之间而非单次 kernel 启动之内。分布式子系统分五块：前端 DSL 原语（tilelang/language/distributed/）、主机运行时（utils.py）、pynvshmem、tilescale_ext（C++ 扩展）与 DeepEP。引入的关键概念：PE 与 rank 同义，分属 NVSHMEM 路线（get_pe/get_pe_num、putmem、signal、barrier）与 CP-engine 路线（get_rank/get_num_ranks、put_block/get_block、wait_*）两套原语；对称显存与 IPC handle 用于跨 PE 远程寻址；远程基址表通过 kernel.initialize(allocator=...) 注入编译好的 kernel；tilescale_ext 在顶层 import 可选、在 import tilelang.distributed 时必需。
