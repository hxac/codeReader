本讲讲解 TileLang 在 threadblock 内部的循环与控制流，承接 u2-l1 的 kernel 启动配置。核心是说明 TileLang 的循环并非普通 Python 循环，而是「带语义标注的 for 帧」（ForFrame），前端据此生成 TIR 的 For 节点，真实 GPU 代码由后续编译 pass 生成。共介绍五种循环原语：`T.Parallel` 标记元素级并行，用于迭代独立的逐元素计算；`T.Pipelined` 标记软件流水，是 GEMM/Attention 的 K 维 tile 迭代骨架，通过 `num_stages` 控制多缓冲数量，让 `T.copy`（生产者）与 `T.gemm`（消费者）重叠以隐藏访存延迟；`T.serial` 为顺序循环、`T.Unroll` 请求编译期展开（`explicit` 完全展开与 `unroll_factor` 部分展开互斥）、`T.Persistent` 构造持久化线程块（块数固定等于 SM 数）循环处理所有 tile。关键工具 `T.ceildiv` 用向上取整计算 tile 数以保证覆盖残余 tile。带步长循环由 `SerialForWithStep`/`UnrollForWithStep` 折算。控制流 `if`/`while`/`break`/`continue` 条件需为 TIR 表达式，且 `LegalizeSafeMemoryAccess` pass 会自动处理大部分越界保护。
