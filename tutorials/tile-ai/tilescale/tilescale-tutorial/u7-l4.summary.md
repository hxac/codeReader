本讲把镜头从「流水线全景」推进到「单个 pass 的内部实现」，并讲解如何新增一道 pass。核心剖析四道 pass：InjectFenceProxy 用 ProxyKind 代理状态机单遍扫描语句序列，仅在 Generic→Async 边插入 fence.proxy.async，对未知 call 保守按 generic 处理，并顺带把 tma_store 改写为 arrive/wait 三连。LetStmt 内联分两路：激进 LetInline（由 tl.force_let_inline 触发）与 Simplify 内的保守内联（CanInlineLetStmt 加 used_in_buffer_def 双闸门，保护 Buffer 定义里的变量）。关键澄清：tensor_checks 并非独立 TIR pass，而是 MakePackedAPI 与 ArgBinder 在生成 host stub 时织入的断言（num_args、非空指针、dtype/shape/strides/device），含 nullable 规则、不可关闭。LowerThreadAllreduce 经 IsWarpReduction 选路，把 tvm_thread_allreduce 降为 warp shuffle、两阶段 shuffle+staging 共享内存或共享内存树形规约，规约维度须连续。新增 pass 四步：写 .cc（CreatePrimFuncPass+TVM_FFI_STATIC_INIT_BLOCK，glob 自动编译）→Python 包装→接入 phase.py→加测试；诊断类可走纯 Python prim_func_pass 挂 PreLowerSemanticCheck。
