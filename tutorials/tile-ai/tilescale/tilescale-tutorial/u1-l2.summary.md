本讲讲清如何把 `tilelang`（TileLang 单机能力的 Python 包名）装起来并 import，分三个最小模块。其一，依赖与版本：tilelang 非纯 Python 包，安装时要把 C++ 编成 `.so`；运行时依赖见 `pyproject.toml`——`apache-tvm-ffi` 做 Python↔C++ FFI、`torch` 兼做张量容器与构建 `tilescale_ext._C` 所需的 libtorch、`z3-solver` 做 SMT 约束求解、`nvidia-nvshmem-cu12` 仅 Linux 供分布式；源码安装须 `--recursive` 拉 `3rdparty/tvm` 子模块、加 `--no-build-isolation`，Python 以元数据 `>=3.9` 为准。其二，CUDA 对齐：`docker/` 下有 cu118~cu128 与 rocm 版 Dockerfile，原则是容器 CUDA ≤ 驱动 CUDA。其三，`.so` 加载：`import tilelang` 由 `env.py` 算出 `TL_LIBS`，经 `libinfo.find_lib_path` 找到 `libtilelang.so` 并 `ctypes.CDLL` 加载，pip 安装在 `tilelang/lib`、开发模式在 `build/lib`，找不到时报 `RuntimeError` 并列出候选目录。分布式扩展 `tilescale_ext` 可选，缺失时 import 仍成功但 `tensor`/`get_allocator` 为 None。
