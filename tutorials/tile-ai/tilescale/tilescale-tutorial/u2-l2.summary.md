本讲义讲清 TileLang 如何用 scope 字符串把抽象 tile 绑定到 GPU 各级显存（global / shared.dyn / local.fragment / local 等）。核心结论：分配原语 `alloc_shared`/`alloc_fragment`/`alloc_local`/`alloc_var` 均是对 `alloc_buffer` 的薄封装，唯一区别是写死的默认 scope。关键术语：`fragment`（元素打散分布在 warp 线程上、对接 tensor core、是 `T.gemm` 累加器的硬性要求）区别于 `local`（线程私有标量）；`T.empty` 返回 `OutTensor` 仅声明 JIT 输出张量、不分配显存；代理对象 `T.Tensor`/`make_tensor` 默认 global、连续 strides，`T.Buffer` 已废弃应改用 `T.Tensor`。分配原语与代理对象共用同一套 scope 命名，是连接 Python 语法与硬件存储的统一抽象。典型数据流为 global → shared → fragment → global。
