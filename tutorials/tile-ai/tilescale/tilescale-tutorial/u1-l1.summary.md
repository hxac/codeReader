本讲是 TileScale 全局认知导论。核心结论：TileScale 是 TileLang 的分布式扩展（Python 包名 `tilelang`，建于 TVM 之上），把 tile 级编程推广到多 GPU/多节点/分布式芯片，目标是把芯片内与芯片间资源统一抽象成单一「mega-device」。

关键术语与模块：HDA（层次化分布式架构）是硬件抽象基石，建立在 compute（thread→warp→SM→GPU→node）、memory（可共享/可分发）、network（NoC/NVLink）三类基础资源上；tile 接口分 compute/memory/communicate 三类，对应上述资源，同一原语可用于不同 scale；系统含 frontend/compiler/tile-kernel/cost model/backend 五模块，后端可配置、可编译到任意 HDA 架构，cost model 为 compiler 提供性能反馈。

最关键判断（供后续承接）：README 宣传的 `T.Scale` 原语与 `T.Kernel(device=/cta_cluster=)` 属「愿景」，代码未实现；真正落地的是「单机 `T.Kernel` + NVSHMEM 多设备原语（依赖 `tilescale_ext`）」这条务实路线。
