本讲介绍与 u5-l1 Autotuner「穷举实测」互补的调参思路：用代价模型在编译前预测优质 tile 配置。Carver 是基于 tile 结构的调度策略推荐框架，产出排好序的 Hint（描述 block、warp、rstep、use_tc、pipeline_stage 等调度参数），而非可执行 kernel，目前需人工翻译进 tilelang，自动集成仍为 TODO。其代价模型由四部分组成：TileDevice 把 smem_cap、warp_size、sm_partition、transaction_size、bandwidth 等硬件参数抽象成统一接口，供 cuda/cdna/metal/cpu 复用；DefaultPolicy 以「访存量×波数」（即 `(traffic+1)×num_wave`）为优先级做 best-first 搜索，经 shared 与寄存器上限裁剪后贪心分配线程产出 Hint；BestFit 在代价模型内部用 best-fit free-list 配合活跃变量分析仿真 shared memory 峰值占用；TensorCorePolicy 在其上叠加 mma/wgmma 约束（rstep 取 16 倍数、块不小于 intrin 形状、按 warp tile 切分、加 padding 防 bank conflict、按 sm 版本设流水级数与异步拷贝）。Carver/Roller 负责给出高质量小候选集，可与 Autotuner 串联：先用它缩小搜索空间，再交 Autotuner 实测选优。
