本讲是分布式单元（Unit 6）收尾实战课，将前几讲的 NVSHMEM 原语、CP-engine 远程拷贝、pynvshmem 运行时与 allocator 等零件组装为五个经典分布式算法，分属三类：集合通信（allgather、all-to-all）、分布式 GEMM（SUMMA、Cannon）、融合通信算子（gemm+reduce-scatter）。

核心结论有三条 overlap 范式：kernel 内「广播-计算流水」（SUMMA）与「环形移位」（Cannon），靠双缓冲 + 两组信号计数（`_to` 接收计数 / `_from` 消费计数）+ 持久化 kernel 协调；以及跨 CUDA stream 的第三范式（gemm-rs），用 device 侧 `atom_add` 行段完成信号配 host 侧 `cuStreamWaitValue` 对接 GEMM 流与 reduce-scatter 流。allgather 用 grid 维度枚举 peer 做一对多 one-sided 推送；all-to-all 用前缀和表 `splits_cumsum` 驱动不等长路由，靠 `signal_op`/`signal_wait_until` 完成握手。

关键术语：one-sided put/get、对称堆、`putmem_signal_nbi_block`、`T.Amo.SIGNAL_ADD`/`SIGNAL_SET`、`T.CmpType`、skew 错位、PE 网格（`pe_mn`/`pe_k`）、两条运行时路线（NVSHMEM 的 `init_distributed`+pynvshmem 对称堆 vs CP-engine 的 `init_dist`+allocator 远程基址表）。
