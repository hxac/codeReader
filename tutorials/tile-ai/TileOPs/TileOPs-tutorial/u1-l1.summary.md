本讲为 TileOPs 手册首篇，建立全局心智模型。项目定位：TileOPs 是建于 TileLang 之上的 LLM GPU 算子库，主攻 Hopper（SM_90），依赖仅 TileLang、PyTorch、einops，以 Spec-driven、Roofline-evaluated、Auto-tuning、Lightweight 四属性立身，性能对照硬件理论上限（Speed-of-Light，效率＝理论最短时间／实际时间）而非基线。双层分离：每算子劈成 Op（L2 主机侧无状态入口，负责校验/布局及 torch.compile 兼容）与 Kernel（L1，TileLang 硬件相关实现），两层边界严格、互不越界；形状与 dtype 在调用时推断，编译支持逐 op 声明。Spec-driven：tileops/manifest/ 为算子接口唯一真相来源，含 signature、workloads、roofline、source；信任模型为人审改规约、Agent 只读生成、Validator 于 CI 强制一致，冲突时改代码或标 status: spec-only，代码服从规约。系统由 M1–M8 八模块与四条数据流（Op Delivery / Perf Tuning / HW Calibration / Publish）组成，现仅 Op Delivery 流完成，余皆 partial。
