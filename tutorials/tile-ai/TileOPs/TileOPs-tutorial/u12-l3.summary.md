本讲以 Mamba-2 的 State-Space Dual（SSD，状态空间对偶）家族为例，汇聚 Op(L2)/Kernel(L1) 双层分离、多 kernel 协作与 func 模式 roofline 三条线索。核心结论是：SSD 分解把串行 SSM 递归拆为「块内并行（因果下三角 GEMM，吃满 tensor core）+ 块间轻量扫描」，把时间依赖从每 token 压到每 chunk，扫描长度由 S 降为 NC=S/Q。端到端的 `Mamba2FwdOp` 是不写 kernel 的复合 Op，以五步流水线 DaCumsum → CBProducer → SSDChunkState → SSDStatePassing → SSDChunkScan 串成，全程 GPU 不回主机，并把 P*N 扁平化以复用 state-passing kernel。推理分两条路径：预填充走两段式 `SSDChunkScanFwdKernel`，解码走单步原地更新状态的 `SSDDecodeKernel`，后者要求 state 连续且 float32。本讲引入并供后续承接的关键术语：chunk_len（Q）、耦合矩阵 cb（仅含 C@B、不含 decay）、prev_states、dA_cumsum 非增性保证不上溢、anchor 分解、状态传递（唯一真串行环节）。manifest 层面确立 variant_of 模式与「No Optional[Tensor]」规则：可选张量（dt_bias/seq_idx/initial_states）各成一条条目，每条绑定独立 func 模式 roofline，共享 cost helper、只翻转一个 has_* 标志，证明多输入 dtype 与条件张量的字节记账无法用 inline 单一 elem_bytes 表达。
