本讲把 u1-l1 建立的「Op(L2)/Kernel(L1) 双层分离、Spec-driven」心智模型落地为可运行环境，覆盖三个最小模块：前置依赖、`make install` 安装、Quick Start GEMM 示例。核心结论：TileOPs 依赖分三层——系统层（Hopper/SM_90 GPU + CUDA 12.x）、底座层（PyTorch ≥2.1<2.11、TileLang ≥0.1.9<0.2.0）、项目层（einops、pyyaml），出问题多在底座层。标准安装入口 `make install` 等价于可编辑安装加 `[dev]` 依赖再装 pre-commit 钩子，验证用 `pytest tests/ -q`（必须 CUDA GPU，首次因 JIT 编译明显变慢）。引入的关键术语：NT 布局（`trans_b=True`，`gemm(a,b)` 数学上等于 `a @ b.T`，kernel 用布局标志读转置权重而免物理转置）、input-inferred（形状/dtype 调用时推断而非构造时绑定）、`__call__ → forward` 代理契约、按 `(m,n,k,dtype)` 懒编译缓存与快路径复用。并以 PyTorch 为地面真值（ground truth）验证算子正确性，末尾点名 `eval_roofline()` 为后续性能讲义的入口。
