本讲以一维张量复制为例，串起 GPU 并行的三个层级：单线程串行（1 block × 1 thread）跑通 `@tilelang.jit` 骨架；多线程（同一 block 内 `threads=256`）提速但受限于单个 SM；多 block 分块（`N // BLOCK_N` 个 block）占满多个 SM。核心结论是：`T.copy` 作为 TileOp 自带「自动并行 + 自动向量化」，从串行切到多线程时函数体一行不改、只调 `threads=`，而要突破单 SM 上限则需引入多 block。

本讲确立的关键术语与概念：thread / block / grid / SM、TileOp、向量化、块索引（`T.Kernel(...) as pid_n`，对应 CUDA 的 `blockIdx`，题目注释里的 `bx` 仅为同名别名）、`BLOCK_N`（编译期超参，在 `compile` 时绑定）、tile 子张量切片、tiling（分块）范式、`T.ceildiv` 处理整除边界；并强调同一 block 内线程可共享 shared memory 与同步、跨 block 不可同步。下一讲将进入元素级运算与 `T.Parallel`。
