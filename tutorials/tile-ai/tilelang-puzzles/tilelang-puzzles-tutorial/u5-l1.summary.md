本讲是「卷积、量化与性能工程」单元首讲，用 Puzzle 09 的朴素 1D 卷积（Conv1D Naive）组装前几讲积木，覆盖三个紧咬的模块。其一，滑动窗口卷积：采用 torch 互相关约定（卷积核不翻转），定义为 O[i,j]=Σ 𝟙[j+k<L]·X[i,j+k]·K[k]，相邻输出共享 KL−1 个输入，形成强数据复用，这是它区别于元素级算子的本质。其二，shared memory halo：把一个输入 tile 连同多出约 KL 列的 halo 区域一次性搬入 block 共享内存，让多个输出复用同一份数据；存储取舍为 X_local 用 T.alloc_shared、K_local/O_local 用 T.alloc_fragment。其三，嵌套循环：外层 (i,j) 用 T.Parallel（输出独立、可并行），内层 k 用 T.Serial（累加写依赖、必须串行），并需 T.clear 清零、相乘前各自 .astype(float32)，以 if j+k<L 作边界护栏。核心结论：朴素版手写乘加、正确但未用 T.gemm，是下一讲 im2col+T.gemm 优化的基线。引入的关键术语：滑动窗口、互相关、数据复用/依赖、halo 区域。
