本讲是手册首篇，目标仅是认识项目、跑通环境，不深入 kernel 语法。TileLang 是面向高性能深度学习 GPU kernel 的领域特定语言（DSL），用 Python 风格描述分块计算并编译成接近手写 CUDA 的代码。TileLang Puzzles 借鉴 Triton Puzzles 等项目，把学习拆成 10 个由浅入深、含 TODO 的未完成 kernel，补全后用 PyTorch 参考结果验证。引入的关键术语：tile（分块）、kernel、block（线程块）、DSL、JIT（@tilelang.jit）、共享内存。仓库核心目录：puzzles（题目带 TODO）与 ans（参考答案，编号一一对应）、common（test_puzzle 验证正确性、bench_puzzle 测性能）、docs（中英讲解）、scripts（环境自检）。学习路线分三档：Easy（01–05）→ Medium（06–09）→ Hard（10）。环境就绪的标志是 scripts/check_tilelang_env.py 能真正编译并运行一个 GEMM、且与 torch.matmul 比对为 True。
