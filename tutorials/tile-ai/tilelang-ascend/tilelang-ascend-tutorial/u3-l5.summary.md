本讲聚焦 TileLang-Ascend 在 Vector 核上的逐元素计算，围绕三个最小模块展开。其一，`T.Parallel` 在 IR 层只是一个 `ForKind::kParallel` 循环，前端极薄，语义是「Tile 内逐元素独立并行」，支持 1D/2D 写法但禁止 3D 及以上嵌套；它隐藏了 Ascend Vector 指令一次处理整块数据的硬件细节，是与 CPU「循环+整块向量化」等价的抽象。其二，`AscendLowerParallelToVector` pass 是把并行循环翻译成向量指令的核心，落在 `LowerAndLegalize` 阶段，通过 TIR→Ascend 算子映射表驱动 `DecomposeExpression` 递归拆解表达式，分支覆盖 copy、unary、binary、标量变体与广播；无法向量化的循环会被降级为 `kSerial` 兜底，3D 则直接报错。其三，`T.tile.*`（ascend_tile）是与符号 API 语义等价、生成代码一致的显式向量范式，每次调用直接发射 `tl.ascend_*` intrinsic，标量变体带 `s` 后缀。关键结论：复杂表达式会膨胀出多个临时 UB 缓冲，故需开启 `TL_ASCEND_MEMORY_PLANNING` 做缓冲复用；广播在两条路线处理方式不同——`T.Parallel` 路线由 pass 自动广播，`T.tile.*` 路线需用户显式调用 `T.tile.broadcast`。引入的关键术语有 `kParallel`、`DecomposeExpression`、`ascend_*`/`ascend_*s` intrinsic、UB 临时缓冲、缓冲复用，供后续 `T.Pipelined` 与 Cube/Vector Scope 讲义承接。
