本讲讲解 Ascend 上 Cube↔Vector 的**跨核流水（inter-core pipeline）**，用于掩盖两核经 GM workspace 中转数据时的 GM 往返延迟。核心思想是让 Cube 领先若干拍连续写 workspace、Vector 滞后消费，使第 i 拍的 GM 往返被第 i+1 拍的 Cube 计算重叠掉；`num_stages` 即「领先拍数+1」=环形缓冲副本数，取 2 为双缓冲，总耗时约 `N+(num_stages-1)` 拍。

引入的关键术语：`write_wk1`/`read_wk1`（写读 workspace）、`cross_interval`（核间同步稀疏度旋钮，默认 1 表示每拍同步）、外层波循环与内层 `stage_loop`、workspace 环形缓冲、`stage_loop` 与 `tl_cross_interval` 两个握手注解。

`CrossCorePipeline` pass（`src/transform/cross_core_pipeline.cc`）做三件事：①`CrossCoreDetector` 依循环体是否同时触碰 Cube（`shared.l1`/`wmma.*`）与 Vector（`shared.ub`/`local.var`）scope 判定跨核；②把单层 `T.Pipelined` 拆成「外层波 + 内层 stage」两层循环，原下标由 `outer*num_stages+i` 还原；③给 workspace 与跨 stage 复用 buffer 加 `num_stages` 维做成环形缓冲。该 pass 自身不插同步，仅留下 `stage_loop`/`tl_cross_interval` 注解，由 u5-l1 的 `CombineCV` 消费，落地条件化的 `set/wait_cross_flag`（写方 `stage_var % interval == interval-1` 或末拍置位、读方 `stage_var % interval == 0` 等待）。

两条硬约束：①核间流水与核内流水不可同开（`CrossCorePipeline` 抢在核内流水 pass 之前执行，且 `ICHECK` 保证全函数仅一条跨核流水）；②跨核流水必须同时开启 `TL_ASCEND_AUTO_CV_COMBINE` 与 `TL_ASCEND_AUTO_CV_SYNC`。实战样本 `flash_attn_bshd_pipeline.py` 在单条 `T.Pipelined` 内用三块 workspace 实现 Cube↔Vector 双向交换，是理解跨核流水的最佳读物，后续 u5-l3（Vid 消除）、u5-l4（Workspace 消除）、u7-l1（FlashAttention）将在此基础上承接。
