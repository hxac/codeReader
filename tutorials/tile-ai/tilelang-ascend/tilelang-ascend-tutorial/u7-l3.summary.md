本讲围绕 tilelang 算子接入工程化的两个痛点——JIT 依赖与逐算子下发的 HostBound——给出两个最小模块。第一是 `torch_tl_ascend` 集成包：用 AOT 在打包阶段复用 JIT 链把算子编成 `libop.so`，再用极小 Python C 扩展 `_inner.cpp` 通过 `TORCH_LIBRARY` 把 `call` 符号包装成 `at::Tensor` 算子、注册到 `torch.ops.tl_ascend` 命名空间，挂载到 torch-npu 的 `PrivateUse1` 分发键，靠 `import` 触发静态注册，并以 `-rpath,$ORIGIN` 让两个 `.so` 同目录互链。关键结论是 AOT 与 JIT 产物同构，集成包只是胶水不参与计算。第二是 ACLGraph 入图：用 `torch.npu.NPUGraph` 把一串小算子 capture 成静态图、`replay()` 整体重放，省掉逐次 host 交互；它不做算子融合，收益纯来自省 host 开销，算子越小越多收益越大。tilelang 能被正确捕获的根因在于 `forward` 向当前 stream 下发、用 `data_ptr` 稳定地址调 `lib.call` 且全程无同步，故 JIT 与 `torch.ops` 两种调用都可入图；入图时所有同步须在编译期经 `AUTO_CV_SYNC` 等开关插好。
