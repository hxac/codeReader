本讲把 tile-lang 的 TIR 改写流水线整体看全：编排函数 `lower()` 依次调用两个阶段函数，外加收尾的 `device_codegen`。两阶段分工遵循「先让它对、再让它快」的原则——`LowerAndLegalize`（15 步）负责把高层语义降级并合法化为正确的底层 TIR（推断 buffer scope、向量化、展开 tile op、补跨核 GM 中转、加内存边界保护）；`OptimizeForTarget`（20 步）再在此之上做硬件优化（软件流水、CV 分离、存储重写、内存规划、同步插入）。各 pass 的顺序由数据依赖硬约束，同步类 pass 因依赖结构稳定而排在阶段二最末。配置方面引入统一字符串键体系 `PassConfigKey`（继承 `str`，分 `tl.*` 与 `tir.*` 命名空间），C++ pass 以「注册键 + `GetConfig` 读默认值 + 关闭即原样返回」的自门控范式控制开关。`process_default_pass_config` 在 `compile()` 最前按 target 填充 per-target 默认（仅 pto 默认开 VS），遵循「用户显式设置优先」且先于缓存键计算以防污染；配置经 `with PassContext(config=...)` 送达 C++，平台代际 A2/A3/A5 则经 PrimFunc 的 `npu_platform` 属性这一独立通道传递。
