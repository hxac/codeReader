本讲讲清 TileLang kernel 里「循环」与「控制流」怎么写，是 u2-l1（kernel 定义）在函数体层面的延续。核心结论有二：一是所有循环原语本质都是 TIR 的 `For` 节点加上一种 ForKind 调度提示；二是条件分两种——Python 常量在解析期被折叠、不进 TIR，而像 `i < N` 这类 TIR 表达式作为真实分支保留到运行期，这是最易踩坑处。控制流用标准 Python 的 `if / 三元 / while / break / continue` 写，其中 `break` 底层 lowering 为 `tl.loop_break` intrinsic。五种循环原语中，`T.serial`（顺序大循环）与 `T.unroll`（小固定循环展开）来自上游 TVM 的薄封装；`T.Parallel`（元素级并行、映射到 Vector 向量指令）、`T.Pipelined`（软件流水，用搬运掩盖计算，由 `num_stages` 控制重叠度）、`T.Persistent`（让相邻 tile 归同核以提升 L2 cache 命中）是 tile-lang 自定义原语。其中 `T.Pipelined` 与 `T.Persistent` 仅讲基本形态，三段式调度与 pass 实现留待 u3-l6/u3-l7 展开。
