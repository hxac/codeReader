本讲承接 u3-l1，讲清 Ascend 上数据搬运的两个原语。其一为统一搬运原语 T.copy(src, dst)：前端只声明「从哪块 buffer 搬到哪块 buffer」，走哪条 DMA 指令完全由 src.scope() 与 dst.scope() 自动派发。本分支里 T.copy 实为 npu_copy_v2，由 C++ 的 AscendCopy::Lower 按 scope 选出 copy_xxx 模板，最终落到 DataCopyPad 等真实指令，覆盖 GM↔L1、GM↔UB、L1→L0A/L0B、L0C→GM、UB↔UB、UB↔L1、L0C→UB 等全部路径，不支持的组合直接 LOG(FATAL)。其中 UB→L1 与 L0C→UB 属 Cube↔Vector 的「跨 CV」搬运，物理上需经 GM/L2 中转；源切片只给起点、搬运量由目标 buffer 决定。其二为原子累加写回 T.tile.atomic_add(dst_gm, src_local)：方向固定为本地 tensor（UB 或 L0C）→ GM，底层是 SetAtomicAdd + 普通 copy + 关闭原子开关三件套；它属累加而非赋值，调用前必须清零 GM 输出，用完必须关闭原子模式以免污染后续搬运。核心术语——scope 派发、copy_xxx 模板、跨 CV、partial sum 原子累加、validRow/validCol/pad_value——将承接后续矩阵计算、同步、Workspace 消除与 Tail Mask 各讲。
