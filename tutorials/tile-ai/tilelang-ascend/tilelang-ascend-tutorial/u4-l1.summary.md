本讲聚焦 tile-lang 在「内存分配」上 Developer 与 Expert 两套抽象的差别。Developer 用 `alloc_shared`/`alloc_fragment`，scope 为 dynamic，物理位置由 `AscendInferBufferScope` pass 推断；Expert 用五个原语 `alloc_L1`/`alloc_ub`/`alloc_L0A`/`alloc_L0B`/`alloc_L0C` 把 scope 直接钉死，分别对应 Ascend 的 L1、UB 与 Cube 寄存器级三块存储（L 系列属 Cube，UB 属 Vector）。执行域由 `T.Scope("C")`/`T.Scope("V")` 显式声明，它在 TIR 层只给 block 贴一个 `resource_scope` 属性（C→0、V→1），由 `CombineCV` pass 据此把语句分到 Cube/Vector 核；Developer 模式下该标记由 pass 自动打。把 Developer 的 `T.gemm_v0` 展开成显式 `T.copy(L1→L0A/L0B)` 加 `T.mma`，本质是把 L1→L0 搬运从模板内部掏出来变可见语句，换取更细的搬运与缓冲控制权。两者可在同一 kernel 内混用，并常与自动同步 pass 搭配。
