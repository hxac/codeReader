本讲讲解 Ascend 上 vid（vector id，表示某 tile 内第几个 Vector 子核）的消除机制与自动 CV 配比。C:V=1:2 硬件要求把 UB 数据沿第 0 维对半切，旧写法把这一硬件细节泄漏到前端，需在 UB 形状、GM 偏移、循环范围三处手动除以 2，并维护 VEC_NUM 常量。本讲引入的关键写法 T.Kernel(threads=2) 同时声明 CV 配比并触发 vid 消除：Python 侧只返回单个 cid（vid 对前端不可见），C++ 的 KernelLaunch 把 vid 绑到 threadIdx.x（extent=2）并写入 npu_cv_ratio 属性（cv_1_1/cv_1_2），此即「自动 CV 配比」。核心 pass 为 AscendVidReduction（注册名 tl.AscendVidReduction），必须排在 AscendInferBufferScope 之后，仅当 threadIdx.x extent==2 时生效，完成五类改写：UB 第 0 维 shape 减半、GM 注入 vid 偏移、tile op 与 reduce 的 size 减半、索引 vid-UB 第 0 维的循环范围减半；threads=1 时整 pass 为 no-op。另一关键术语是 skip-set（buffers_skip_vid_reduction）：gather（间接索引，GM 下标含 UB BufferLoad）目标 UB 不减半、形状保留，以 PrimFunc 属性传给下游 AscendWorkspaceReduction，构成两 pass 间的契约。
