tilelang-ascend 是 tile-lang 面向华为昇腾 NPU 的专用变体，建立在 tile-lang 语法与 TVM/TensorIR 编译基础设施之上，用 Pythonic 语法描述算子，由编译器自动完成内存搬运、同步插入与缓冲复用。Ascend 片上存储分为 GM、L1（属 Cube 核）、Unified Buffer/UB（属 Vector 核）以及 L0A/L0B/L0C，在 tile-lang 中被抽象为 shared 与 fragment 两层，编译器按上下文自动落到具体物理存储。后端有 Ascend C（稳妥主线）与 PTO（更新、支持 A5 仿真）两条路线，均先降级到 TensorIR 再 codegen，最终由毕昇编译器（bisheng）编成 .so；执行采用 JIT 模式，@tilelang.jit 装饰后首次调用即触发「lowering → Ascend C 生成 → bisheng 编译 → ctypes 加载执行」全链。编程抽象分 Beginner（尚未支持）、Developer（主力，基于 Tile 库原语）、Expert（线程级、同步、寄存器控制）三层，可在同一 kernel 内混用。Ascend 的 Cube 与 Vector 经 GM/L2 中转交换数据，由此衍生自动 CV 分离、跨核流水、workspace 消除等核心机制。
