本讲解决昇腾 NPU 上 Cube 核（L0C）与 Vector 核（UB/L1）之间无硬件直连的跨核搬运问题。核心结论是：这类搬运物理上必须经 Global Memory 两阶段中转，由 `AscendWorkspaceReduction` pass 自动完成。该 pass 在 lowering 阶段先由 `AscendCopy::Lower` 给 `copy_l0c_to_ub`/`copy_ub_to_l1` 打上 `virtual_channel` 标记（表示「虚拟意图，尚未落地」），再将其原地改写为第一阶段写 GM（`copy_l0c_to_gm`/`copy_ub_to_gm`），并在真正读该 buffer 的语句之前延迟插入第二阶段回拷（`copy_gm_to_ub`/`copy_gm_to_l1`），靠 `rw_mask` 读位判定以减少片上驻留。引入的关键术语包括：虚拟跨核搬运、workspace（形状 `[total_core_nums, M, N]`，按 `cid` 偏移多核隔离，`threads=2` 时叠加 `vid` 偏移、每个 vid 读一半）、延迟回拷，以及两种 workspace 分配通道——用户用 `workspace_idx` 显式声明（如 SFA）与编译器经 `auto_gm_indices` 属性自动分配，两者均在运行时由框架对调用者透明申请。限制：需静态 shape、配合 vid 消除、仅 2D、仅 Cython 后端支持自动分配。
