本讲义解析 `T.Kernel` 启动上下文，对应 `tilelang/language/kernel.py`、`src/ir.cc` 与 `src/transform/materialize_kernel_launch.cc`。核心结论：`@T.prim_func` 描述「算什么」（计算规格与张量形状），`with T.Kernel(*blocks, threads=...)` 描述「怎么启动」——`blocks` 定 grid（`gridDim`），`threads` 定每块线程数（`blockDim`，默认 128，经 `_normalize_threads` 归一化为三维）。`as (bx, by)` 解包的 **block 绑定** 是编译期 TIR 循环变量，最终映射为 `blockIdx.x/y`，用于定位每块负责的输出 tile。关键设计：C++ 侧 `KernelLaunch` 按固定顺序生成 target 中立的 `kThreadBinding` 帧（1~3 个 grid 帧 + 恒 3 个 thread 帧 + 1 个主体 block，故用 `frames[0:-4]` 取出 grid 绑定），再由 `MaterializeKernelLaunch` pass 物化——SIMT 后端（CUDA/ROCm/MACA/Metal）转为 `thread_extent` 属性语句，CPU 后端退化为串行 `for`，从而同一份 kernel 可编译到任意后端。另引入 `T.ClusterKernel`（SM90+ 线程块集群变体，底层复用同一帧结构、仅多带 `cluster_dims` 属性，MACA 不支持）。
