本讲是手册首讲，建立贯穿全本的全局地图，覆盖三个最小模块：项目定位、编译流程总览、metax 分支差异。

TileLang 是构建在 TVM 之上的领域特定语言（DSL），长得像 Python 却被编译成高性能 GPU/CPU kernel。它提供三档编程接口：Beginner（硬件无关）、Developer（硬件感知 + Tile Library 原语）、Expert（线程原语精细调优），三档可在同一 kernel 内混用。其本质是一个编译器——用户写的是计算规格，真正运行的是生成的代码。

它通过六步下译流程把 Tile Program 转为硬件可执行文件：输入端三种写法汇入 IRModule 中间表示，再经 Source Code Generation 生成按后端分目录的源码（CUDA/HIP/MACA），最后编译为可执行件。关键节点是 IRModule 与后端相关代码生成。

tilelang-metax 是 tilelang 的分支，核心增量是面向 MetaX GPU 的 MACA 后端（MACA 类比 NVIDIA 的 CUDA），使 MetaX 与 cuda/rocm/metal 平级为一等后端。MACA 代码分布在 Python 侧 tilelang/maca/ 与 C++ 侧 src/maca/，主要插手代码生成与 runtime 两步。关键差异：MACA 的 warp_size 为 64（CUDA 为 32）。后续讲义将依次深入编译流水线、代码生成及 MACA 后端。
