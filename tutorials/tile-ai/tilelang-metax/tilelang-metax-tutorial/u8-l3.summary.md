本讲解决「如何对编译好的 TileLang kernel 做可信测量」这一问题，由四个最小模块构成。其一，`JITKernel.get_profiler()` 返回的 `Profiler` 类把「自动造输入 + 正确性校验 + 计时」三件事打包，它接受 `KernelParam` 列表与 `result_idx`（输出张量下标），造输入时跳过输出张量，且自身可被直接调用（等价跑一次 kernel）。其二，真正计时引擎是 `bench.do_bench`：它先用默认 256MB 的 buffer 冲刷 L2（解决 cache 污染），再用 5 次估算把以毫秒为单位的「时长目标」（`warmup=25`、`rep=100`）自动换算为重复次数，使快慢 kernel 都测得稳定，结果以毫秒返回。其三，三种计时后端 `event`（默认，逐轮 CUDA Event）、`cupti`（基于 torch.profiler，能剔除冲刷自身耗时，返回单一均值，不支持 `return_mode`/`quantiles`）、`cudagraph`（图回放消除 host 开销，冲刷须放在图外）。其四，`TensorSupplyType`（Integer/Uniform/Normal/Randn/Zero/One/Auto）控制输入分布，默认 `Auto` 按 dtype 智能挑选；校验宜用 Normal/Randn 以提高区分度，动态 shape 须用 `dynamic_symbolic_constraints` 把符号换具体值。核心结论是延迟到吞吐的换算范式 `TFLOPS = 2·M·N·K / latency_ms · 1e-9`；本讲是 autotuner 评分函数的测量基础，为后续资源剖析与真实算子优化提供「延迟 + TFLOPS」这一北极星指标。
