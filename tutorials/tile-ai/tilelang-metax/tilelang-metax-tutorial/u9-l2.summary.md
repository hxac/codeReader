本讲讲解如何为 TileLang 新增 tile 算子。核心是抽象基类 TileOperatorNode，规定三个纯虚接口：Lower()（由 LowerTileOp pass 调用，把算子降级为底层 TIR）、InferLayout()（由 LayoutInference pass 调用，推断 fragment 寄存器布局）、Clone()。算子经宏 TIR_REGISTER_TL_TILE_OP 登记进 TLOpBuilder 表，运行期由 ParseOperator 把 tl.tileop.xxx 的 TIR Call 还原成算子对象。Lower() 有两种风格：copy/transpose 的自包含 SIMT 降级（用 MakeSIMTLoop 生成按线程并行的循环、再按 target 分派实现注册表）与 gemm 的外包 Python 降级。InferLayout() 对不涉及 fragment 的 SIMT 算子返回空，对张量核算子则主动声明 Fragment 布局。最后 Python 侧用 tirx.call_intrin 暴露为 T.xxx，Python 算子名、C++ 注册宏、TVM_REGISTER_OP 三处字符串须严格对齐，否则算子不会被降级。
