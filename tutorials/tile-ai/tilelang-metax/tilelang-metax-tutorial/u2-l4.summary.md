本讲承接 u2-l2/u2-l3，解决 kernel 中 buffer 的「分配、搬运、初始化」三件事。核心是 GPU 四级显存层级（scope）及其 DSL API：`global`（显存，`T.Tensor`/`alloc_global`）、`shared.dyn`（`alloc_shared`，块内共享）、`local.fragment`（`alloc_fragment`，寄存器 tile）、`local`（`alloc_local`，线程私有）。这些 API 在源码层极薄，本质是带特定 scope 调 `T.sblock_alloc_buffer`；scope 层级在 C++ `scope_level` 中固化为 fragment/local=2、shared=1、global=0。

关键差异：fragment 的逻辑下标与物理寄存器不一一对应，由 Layout Inference Pass 自动把整块 tile 分发到各线程，适合做张量核（MMA/WGMMA/MFMA）累加器；local 则是普通线程私有数组，不做布局分发。`T.copy(src, dst)` 是唯一主力搬运原语，作用域无关，前端只规整 region 并下译成 `tl.tileop.copy` intrinsic，具体走 TMA/cp.async/普通循环由 C++ 侧 `Copy::Lower` 按 target 与 scope 自动选择；另提供 `async_copy`/`tma_copy`/`maca_async_copy` 等显式变体供手动同步。`T.clear`/`T.fill` 负责初始化，`clear` 即 `fill(buf, 0)`，累加器累加前必须清零。其内部机制（layout 推断、自动选指令）在 u4 系列展开。
