本讲承接 u5-l3，聚焦 `src/tl_templates/`：一个 header-only 的设备端 C++ 模板库，不参与 `libtilelang.so` 编译，而是被 codegen `#include` 进生成代码、交由设备编译器展开。因为张量核指令的形状/类型/布局均为编译期常量，用模板做编译期特化比 codegen 手拼内联汇编更可维护。CUDA 按架构代际提供三套封装：`mma.h`（`tl::mma_sync`，SM70–89）、`wgmma.h`（`tl::wgmma_ss/rs`，SM90，操作数为 shared memory descriptor）、`tcgen05mma.h`（`tl::tcgen05mma_ss/ts`，SM100，累加器位于 TMEM），统一采用「泛型主模板+全特化表+`static_assert` 安全网」模式。HIP 走手写 swizzle+`__builtin_amdgcn_mfma_*`，MACA 复用 CUTE（`TiledMMA`+`MACA_16x16x16_*`），两者公开入口均为 `tl::gemm_ss/gemm_rs`。整条接线链路为：`op/gemm.cc::SelectInst` 返回指令键（cuda.mma/wgmma/tcgen05）→ 算子 `Lower` 产生 builtin 调用 → codegen visitor 印出 `tl::xxx<...>` 字符串并置 `need_*` 标志 → `Finish()` 按标志印 `#include`。指令选择发生在算子层 `SelectInst`，codegen 只负责把该调用的那一行印出并备好头文件。
