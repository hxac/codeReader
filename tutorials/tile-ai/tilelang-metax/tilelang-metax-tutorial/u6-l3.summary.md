本讲是 GEMM 系列收口讲义，把内存层级、软件流水线、gemm 分派、张量核发射器等前置知识串成端到端链路，覆盖四个模块：最小 GEMM kernel 全链路、persistent kernel、调参维度、边界处理。

核心锚点 `example_gemm.py` 浓缩了「搬进来—算—搬出去」范式：`alloc_shared`/`alloc_fragment` 分配中转与累加器，`T.clear` 清零，`T.Pipelined(num_stages)` 软件流水，`T.copy` 搬运（搬运指令按 target 自动选），`T.gemm` 自动分派 mma/wgmma/mfma，末尾搬回 global。

引入的关键术语：persistent kernel（持久化线程块）只启动等于 SM 数的常驻块、用 `T.Persistent` 遍历所有输出 tile，省 launch 开销且可借 `group_size` 做 L2 友好的 tile swizzle；普通版用 `T.use_swizzle` 达到同目的。调参维度为 block_M/N/K、num_stages、threads，需在算力利用率与 shared/寄存器占用间取舍，无万能配置。边界处理两套机制：`LegalizeSafeMemoryAccess` pass 对 global 访问自动加守卫（shared/local 仅告警），用户也可主动写 `if`。`JITKernel` 的 `get_kernel_source`、`get_profiler().do_bench` 分别是看生成代码与量延迟的入口。
