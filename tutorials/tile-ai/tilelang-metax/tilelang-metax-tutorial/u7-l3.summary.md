本讲深入 MACA 后端最核心的 mfma 张量核指令的发射与布局，覆盖发射器、指令命名、lane 映射、指令选择四个最小模块。mfma 是 MetaX GPU 的矩阵乘加张量核指令，原子输出瓦片为 16×16。核心结论：TensorCoreIntrinEmitter 是 Python 侧总装车间，兼具生成 T.tvm_mfma 指令与产出 T.Fragment 布局两项职责。关键差异在于 WARP_SIZE=64（CUDA 为 32）：lane 映射把 16×k_dim 操作数一一分给 64 个线程，每线程持 k_dim/4 个元素，构成双射。指令命名 mma_suffix=16x16x{k_dim}{abbrv}，k_dim 由输入 dtype 位宽反向决定（fp16→16、tf32→8、int8 依赖卡号序号取 16 或 32）。C++ SelectInst 恒返回 "maca.mma"，经 resolve_gemm_impl 映射到 GemmMMA，最终 codegen 印成 __builtin_mxc_mma_*，dense 路径不经 CUTE 模板。
