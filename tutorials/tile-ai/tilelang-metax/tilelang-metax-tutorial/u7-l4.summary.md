本讲承接 u7-l1/u4-l1，聚焦 MACA 编译流水线如何把 Tile IR 串联降级为设备可编译的 TIR。核心结论是：MACA 流水线以「复用 CUDA 骨架 − Hopper/Blackwell 专属 pass ＋ 唯一专属 pass `LowerMACAIntrin`」实现，通过 `register_pipeline(PassPipeline("maca", ...))` 注册，引擎用 `resolve_pipeline(target)` 按 target kind 名分派。关键澄清：`LowerMACAIntrin` 只下译 L2 persistent 的 stream access policy 调用（`__tvm_maca_stream_set/reset_access_policy_window`），**不**碰 mfma 计算指令（后者由 codegen + intrin_rule 处理）。由此引入三个承接概念：L2 persistent（提示硬件把 global buffer 钉在 L2）、其三段式落地链路（DSL 注解 → 复用的公共 pass `LowerL2Persistent` 写 `l2_persistent_map` 属性，以 buffer 名为 key → MACA 专属 pass 发 runtime，target 差异推迟到最后一步），以及 2:4 结构化稀疏 GEMM（压缩矩阵 A＋元数据 E，C++ 侧 `SelectInst` 恒返回 `"maca.mma.sp"`，warp 划分沿用 `warp_size=64`）。
