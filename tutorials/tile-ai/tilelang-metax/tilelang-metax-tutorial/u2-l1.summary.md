本讲是 TileLang DSL 的语法地基，覆盖 kernel 签名层的四个最小模块。核心装饰器 `@T.prim_func` 在编译期把带类型注解的 Python 函数重写并执行成一棵 TIR `PrimFunc`（tilelang 用自有实现覆盖了 TVM 版，额外支持 eager JIT 与专属属性），它不执行你写的计算，而是生成构造 TIR 的程序。`T.Tensor((shape), dtype)` 声明全局、连续的输入输出张量，底层产出 `tirx.Buffer` 并自动按行优先推算 stride，`T.Buffer` 是其废弃别名。dtype 有三种等价写法（字符串、`T.float32`、`torch.float32`），经打补丁的 `dtype.__new__` 统一归一化为 `tvm.DataType`，另支持向量打包 `xN` 与低精度浮点族。形状来源分三类：具体数值烘焙（编译期已知，换尺寸需重编译）、`T.const`（eager JIT 专属，运行时从真实张量形状经 phase1 建模板、phase2 回填两阶段确定）、`T.dyn`/`T.dynamic`（命名 TIR 符号变量，可参与循环边界与表达式推导）。区分 lazy（内层 prim_func + 编译期烘焙）与 eager（`T.const` 即时风格）两种 JIT 是后续循环、内存层级与 JIT 缓存讲义的前提。
