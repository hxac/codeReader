本讲（u3-l2）承接 u3-l1，把 tile op「DSL 留占位、后按硬件展开」的模型推广到四类非矩阵乘计算原语，四者共享同一套机制。

填充（`T.fill`/`T.clear`→`tl.tileop.fill`）并行初始化片上缓冲；铁律是累加型操作前必须清零（sum→0、max→−∞、min→+∞）。分块归约（`T.reduce_*`→`tl.tileop.reduce`）分线程内归约与跨线程 AllReduce 两步，C++ 仅支持 local.fragment，shared 输入会被 macro 搬到临时 fragment；CUDA 后端发射 `tl::AllReduce<...>::run`，SM90+ 用 NamedBarrier，batch>1 用 run_batch 省 barrier，sum 的 clear=True 走「临时buffer+加回」避免 warp 重复累加。原子（`T.atomic_add/max`）有两条 lowering 路径：标量地址走元素级 intrinsic（支持 return_prev、memory_order），整块 tile 走 `tl.tileop.atomicadd`，仅当多线程/多 block 写同一地址（split-K、scatter）时才用。扫描（`T.cumsum`/`cummax`）是 inclusive scan，输出与输入同形状，必须经 shared memory 且 C++ 强制线性布局，fragment 输入会中转到 shared，reverse 反向扫描。

综合实践：在线 softmax=fill+reduce_max+reduce_sum+在线合并公式；split-K 归约=reduce_sum+atomic_add 写回。关键术语：tile op 占位（`tl.tileop.*`）、AllReduce、clear/batch/nan_propagate、memory_order（relaxed/acquire/release/seq_cst）、inclusive scan，供后续讲义承接。
