本讲(承接 u4 编译总流程)回答「用户的 Python 函数如何变成 `PrimFunc`」,覆盖 `tilelang.language.eager` 与 `tilelang.language.frame` 两个最小模块。核心是三层机制:其一,eager builder 即 `Builder`,把执行函数体视为向 TVM IRBuilder 逐条追加 TIR 节点,用 `frames` 栈管理作用域、线程局部 `current()` 让 `T.Kernel`/`T.const` 等 DSL 原语定位自己;其二,`@T.prim_func` 背后由 `mutate()` 驱动的 AST 改写器 `DSLMutator`,把 `if`/`for`/赋值/表达式逐条译成对 `__tb` 钩子的调用并包成 `IRGenerator`,`BaseBuilder` 给 Python 语义、`Builder` 覆盖为 TIR 语义;其三,`JITFunc` 分 lazy/eager 两种风格,eager 采用 phase1 建模板、phase2 填形状的两阶段机制,由 `Builder.eager_jit` 字段与 `T.const` 切换,实现一份模板通吃多种 shape。典型语句落地:`with T.Kernel`→`ctx_with`,赋值→`bind`/`assign_slice`,`for`→`ctx_for`,`T.copy` 等表达式语句→`eval`。`frame.py` 的 `FrameStack`/`LetFrame` 负责 let 绑定别名跟踪,与 `Builder.frames` 是两套互补的栈。引入术语:eager builder、frame 栈、DSLMutator、IRGenerator、钩子、phase1/phase2、TirTemplate、constexpr。
