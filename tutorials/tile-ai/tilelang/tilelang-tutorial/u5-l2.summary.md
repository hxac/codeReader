本讲承接 u5-l1，讲清 tilelang 前端把 Python AST 翻译成 TIR 的两条通路：TVMScript 风格的 language/parser（dispatch 表 + visit_* 访问者）与 eager 的 DSLMutator（把 AST 改写成 __tb 钩子调用），当前默认的 T.prim_func 走 eager。parser 把 For/Assign/With/If 等节点一一映射到 IR builder 调用（T.serial、T.buffer_store、T.evaluate），operation.py 负责运算符重载到 TIR 表达式。language/overrides 用「同键后注册覆盖」改写 Assign/AugAssign/AnnAssign，新增链式赋值与 local.var 标量缓冲写回两类语义，覆盖生效靠 common.py 里「先 tir.common、后 overrides」的导入顺序。language/ast/ir.py 是经 _ffi_api 落到 C++ IRBuilder 的薄积木层，为两条通路共享，返回 frame 表达作用域嵌套。最后，T.copy 在前端只产生 tl.tileop.copy intrinsic 占位，真实搬运指令留待后端 lower_tile_op Pass 展开。
