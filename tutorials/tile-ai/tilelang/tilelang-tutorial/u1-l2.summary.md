本讲解决「源码如何变成可 import 的包，以及 import 时 C++ 引擎从哪加载」。安装有三条路径：PyPI 稳定版、nightly、源码构建，统一用 `python -c "import tilelang"` 验证。源码构建由 scikit-build-core 驱动 CMake，依赖 TVM 子模块、CUTLASS、Composable Kernel，后端由 `USE_CUDA/ROCM/METAL/LLVM` 控制（显式优先、否则平台默认）。两个核心最小模块：`tilelang.env` 以 `EnvVar` 描述符和 `Environment` 类集中管理运行时环境变量，并产生原生库搜索根 `TL_LIBS`（安装版指向 `TL_ROOT/lib`，开发版指向 `build/lib`）；`tilelang.libinfo` 的 `find_lib_path` 跨平台拼出库名（Linux 为 `libtilelang.so`、Windows 特例为 `tvm_compiler.dll`）并在 `TL_LIBS` 中定位，`__init__.py` 经 ctypes 完成加载，并支持「轻量导入」跳过。关键术语：原生库、stub 库（使无 GPU 机器也能 import 但不能跑 kernel）、`version_provider` 动态拼出带后端标签与 git hash 的版本号。
