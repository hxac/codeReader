本讲介绍 tilelang 的 Carver 切分提示推荐框架。它不运行 kernel，仅凭硬件模型与启发式静态分析，毫秒级产出一组张量核友好、放得下 shared memory、并行度合理的 tile 候选清单，喂给 Autotuner 实测取优。框架为 arch/template/roller 三层正交架构：template 用 TVM te.compute 搭算子的等价 PrimFunc；arch 把硬件数值化为被动查询的约束常量（smem_cap、warp_size、张量指令形状、transaction_size 等）；roller 读 PrimFunc 与 arch，枚举 tile、用 bestfit 内存分配器估 shared memory 峰值、按访存量×波数打分排序。关键术语含 tile hint、template、roller、DefaultPolicy 与 TensorCorePolicy、bestfit、栅格化，以及张量核分流函数 get_tensorized_func_and_tags：算子可张量化且 dtype 受硬件张量核支持则走 TensorCorePolicy（按 warp 切分、带 pipeline_stage/intrin_info），否则退回 DefaultPolicy（按 thread 切分）。核心结论：Carver 用静态分析压缩搜索空间，与负责实测取优的 Autotuner 构成上下游调优链路。
