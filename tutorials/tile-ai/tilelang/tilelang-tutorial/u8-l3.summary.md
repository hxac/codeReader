本讲承接 Autotuner（u8-l1），讲解 tilelang 的 GPU 性能测量工具链，回答「kernel 是否又快又对」。核心由四个最小模块构成：通用计时引擎 `do_bench(fn, warmup, rep, backend, ...)` 通过 5 次试跑估计单次耗时、按 ⌊warmup/estimate⌋、⌊rep/estimate⌋ 自动推断迭代数，并在每次正式计时前用 256MB buffer 冲刷 L2 以消除 launch 开销与缓存残留两类噪声；它提供三种后端——`event`（默认，通用、支持分位数）、`cupti`（设备侧最准，回归首选）、`cudagraph`（回放消除 launch 开销）。`Profiler` 是一个 dataclass，把「输入供给 + adapter + 正确性校验 + do_bench」编成一站式接口，由 `JITKernel.get_profiler()` 一行注入，其 `do_bench` 用 `partial(adapter, *ins)` 包成零参闭包；并要求测延迟前先 `assert_allclose`（对照参考实现）与 `assert_consistent`（查 race condition）。`TensorSupplyType` 枚举控制输入分布，`Auto` 对 fp8/fp4 做安全特化（小范围整数避免溢出），`torch_assert_close` 允许一定比例元素超差以适配低精度。吞吐换算公式为 `TFlops = total_flops / latency_ms * 1e-9`，FlashAttention 与 MLA 两例共同示范了「合适供给 + 参考对照 + 足够 warmup + 一致后端」的标准性能报告范式。
