本讲把 tilelang 的调试工具划分为两类正交的工具：**编译期**（看 IR/结构树如何变形）与**运行期**（看实际数值）。

编译期三个最小模块均基于「保存原始方法 → 透明替换 → before/after 捕获 → 完全可逆还原」的 monkey-patch 四步模式。`tilelang.utils.pass_diff_hook` 由 `TILELANG_PASS_DIFF` 触发，是最简形态的逐 Pass IR 文本差分，核心卖点是**零开销**——模式为 `None` 时安装函数首行即返回，不打任何补丁、不额外 import。`tilelang.tools.lower_trace` 由 `TL_LOWER_TRACE` 触发，是 pass_diff 的严格超集与官方推荐主力，叠加**三层 hook**（Pass / PassPipeline / codegen FFI）：提供 phase 上下文标签、原始 `.tir` 落盘、崩溃安全的增量 HTML，以及「基线/工作副本/本次输出三文件协作」的 codegen 编辑重编译工作流（仅 source-only FFI 可真正重编译）。`tilelang.tools.pass_visualizer` 则换视角，把每个 Pass 后的 IR 渲染成 **SBlock 结构树**做行级 diff，并对 tile op / 同步原语 / 硬件 intrinsic 三类做语义高亮，最适合直观观察 `LowerTileOp` 把 `T.gemm` 展开成 `ptx_mma` 的瞬间。

运行期 `T.print` 按 buffer scope 分发到 `debug_print_*` extern 调用：fragment/shared 默认只在 main_lane 线程打印防刷屏，fragment 须先搬运到 shared 才能逐元素读。关键结论：所有钩子捕获的是 `script()` 文本，「文本变了」不等于「语义或性能变了」；`TILELANG_PASS_DIFF` 与 `TL_LOWER_TRACE` 共用同一 hook 点、不可同时开启。引入的关键术语：lower trace、pass diff、SBlock 结构树、phase 上下文、monkey-patch、main_lane、source-only FFI。
