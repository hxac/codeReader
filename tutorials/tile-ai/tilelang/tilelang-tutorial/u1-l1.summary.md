本讲建立 tilelang 的全景认知，覆盖三个最小模块。其一为定位：tilelang 是构建在 TVM 之上的 tile 级（分块级）领域专用语言（DSL），用 Pythonic 语法描述高性能 GPU/CPU kernel，兼顾开发效率与极致性能；相比手写 CUDA/CUTLASS 更高效，相比 Triton 更显式地暴露 shared/fragment 内存层级、软件流水线与 swizzle，便于压榨 TMA/WGMMA 等硬件特性。其二为编译链路：tilelang 本质是一个编译器，主干为 Python DSL 函数 → TVM 张量中间表示（TIR）→ 语义检查（PreLowerSemanticCheck）→ Pass 流水线 → host/device IR 拆分 → 设备代码生成（device_codegen）→ Kernel Adapter 包装 → 可调用 kernel；编译入口为 tilelang.engine.lower()，内部由 lower_to_host_device_ir 完成检查与 Pass。其三为硬件与算子：用 target 描述目标硬件，支持 auto/cuda/hip/metal/llvm/webgpu/cutedsl/c，其中 auto 按 CUDA→HIP→Metal 顺序探测；主战场算子为 GEMM、FlashAttention、MLA、稀疏注意力等可分块、计算密集、内存层级敏感的大模型核心算子。另需记住：import tilelang.language as T 默认即为 CUDA 方言，其它后端需经 tilelang.⟨backend⟩.language 显式引入；import tilelang 还有轻量导入模式以加快启动。
