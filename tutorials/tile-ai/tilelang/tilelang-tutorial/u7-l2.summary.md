本讲承接 u7-l1，讲清单个 PrimFunc 如何拆成 host/device 两半并各自落地。SplitHostDevice 做物理拆分：把含 target 的 device region 切成「host 留一句 GlobalVar 调用 + 新建 device 函数」，搬运 cluster_dims/smem_alignment_map 等属性，但自身不设 calling convention。紧接 MakePackedAPI 把 host 函数标准化为 C-PackedFunc（kCPackedFunc，前缀 __tvm_ffi_），device 函数因无 host target 被跳过；LowerDeviceKernelLaunch 才给 device 函数盖 kDeviceKernelLaunch 章、提取 launch 参数并改写调用点。lower() 据此用 Filter 把模块分拣成 host_mod/device_mod，device codegen 再 ICHECK 这枚章。落地分两路：tvm_ffi 走 host_codegen 注册表（与 device codegen、execution backend 同构）产出 TVM rt_mod，device cubin 由 C++ 回调 Python 的 tilelang_callback_cuda_compile、经 CUDABinaryCache 编译；cython/nvrtc/torch/cutedsl 则走 wrapper 包 init()/call() + libgen 拼 nvcc/hipcc/g++ 命令编出 .so。关键结论：编译选项必须进缓存键，以防 fast-math 假命中。
