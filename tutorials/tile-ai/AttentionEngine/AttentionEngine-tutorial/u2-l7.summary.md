本讲是「降级三件套」的第三件，讲解 `lower_custom_inputs` 如何把用户在 CustomIO 里声明的额外输入张量（如 softmax_bias）从 global 降级到片上。核心判据是张量形状是否含 kv 序列维（片上映射为 block_N，常量 `RECURRENT_DIM`）：不含走分支①，注册 `CopyMap` 交由通用 `lower_kernel` 生成循环前 prologue 加载、只搬一次；含 block_N 且多维走分支②，经 global→shared→fragment 两段、分配 shared 缓冲并标注 swizzle、每轮重载；含 block_N 但单维或首维为 "1" 走分支③，每轮直接 global→fragment。本讲围绕三个最小模块展开：GPU 三级内存 global/shared/fragment 映射；shape_idx 下标推导（靠四张映射表把逻辑维翻译成 global 切片下标与片上分块形状，由 `load_op`/`store_op`/`copy_op` 落成 `T.copy` 或标量赋值）；swizzle layout（`make_swizzled_layout` 消除 shared memory 的 bank conflict，仅分支②启用，经公共字段 `lower_output.swizzle_shared` 全局收集、由模板 `T.annotate_layout` 统一注入）。
