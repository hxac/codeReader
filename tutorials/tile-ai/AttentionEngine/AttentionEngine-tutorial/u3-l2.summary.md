本讲义讲解 `lower_tl`——AttentionEngine lower 层的总编排函数，把用户描述缝合渲染成完整 TileLang 源码。主流程七步：性能配置选择 → 构建 kernel_options → 降级三件套（`lower_custom_inputs`/`lower_score_mod`/`lower_online_func`）登记张量 → 计算 idx_list → `lower_kernel` 翻译 → mask 降级 → 模板渲染，按因果性选 dense 的 `TlAttnTemplate` 或 blocksparse 的 `TlBlockAttnTemplate`。

关键术语：`KernelOptionsBase` 是「张量簿记本」，三件套经 `add_output/input/intermediate_tensor` 登记、建 `CopyMap`，`lower_kernel` 再统一翻译成 input_args / output_args / alloc / epilogue / prologue 五段分配与搬运代码。

核心结论：前向 block 默认 128/128，`dimv>256` 特例降为 64/64 且 `shared_fuse=True`；反向按 `max(dimqk,dimv)` 分档；前向 `block_M` 切 Q、反向切 KV，语义转置。`output_idx_list = range(3+n, 3+n+1+m)`（n 为 custom 输入数、m 为 final_rowscales 数），`bwd_output_idx_list` 起点为 `4+n+m+doosum`；`isused_doosum` 由 backward 是否引用 `doosum_rowscales` 动态探测，会平移反向下标，blocksparse 下两列表整体 +1。
