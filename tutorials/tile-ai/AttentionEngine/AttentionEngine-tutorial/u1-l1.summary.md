AttentionEngine 是一个统一的可定制注意力框架，核心目标是化解「自定义注意力要么灵活（PyTorch 张量运算，访存大、慢）要么高性能（手写 fused kernel，门槛高、难复用）」的矛盾：用户仅用约 80 行 Python 描述注意力逻辑，框架即可自动生成性能对标 FlashAttention 的 fused kernel。它本质是一个编译器——前端用 Python 函数描述注意力，后端把该描述翻译成 GPU 设备代码，形成「用户 API → 符号 IR → 降级 → 模板 → 引擎」的编译链。

框架支持两条计算路线：transformer 注意力走 `AttentionEngine`，以 `score_mod`（逐元素分数变换）、`mask_mod`（下标布尔遮蔽）、`online_func`（行级在线算法，如 online softmax，含 `online_fwd` 与 `online_fwd_epilogue` 两段）及 `custom_fwd_inputs` 描述；线性注意力走 `LinearAttentionEngine`，对应 `q_mod`/`k_mod`/`v_mod`/`decay_mod`。它采用 online（在线）分块算法，逐块更新 `online_rowscales`、`final_rowscales` 等状态，避免物化整张 scores 矩阵。

生成后端有两种：`tl`（TileLang，生成 Python kernel，默认）与 `cute`（CuTe C++，面向 Hopper，暂不支持反向）。两后端输入相同、产物形态不同，切换不需改用户描述。引擎在构造时按 `backend` 分流、按输入形状分发降级函数（仅 tl），并通过 md5 缓存加 importlib 动态加载，把生成代码挂成可 `mod(q,k,v)` 调用、可 `.backward()` 的 PyTorch 模块。`attn_script/mha.py` 是贯穿全册的标准 softmax 参照样本。
