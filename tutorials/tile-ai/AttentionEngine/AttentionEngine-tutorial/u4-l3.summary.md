本讲聚焦解码场景（q_seqlen<kv_len，GQA 解码断言 q_seqlen==1）。引擎在 _select_lower_template 按形状自动分发：q_seqlen!=kv_len 走解码，再据 head 与 head_kv 是否相等区分 GQA 解码（lower_decode_gqa）与 MHA 解码（lower_decode）。解码沿 Query 方向无并行度，故引入 split-kv：将 KV 序列切成 num_split 段，用 grid 第三维 sid 换并行，GQA 解码另以「切 Query 头」补充。因每个 split 仅扫一段 KV，final_rowscales（lse）须各自落盘，全局形状从训练的 [batch,heads,seq_len] 扩为 [batch,heads,num_split,seq_len]，多出的 num_split 维是 split-kv 的直接产物。combine kernel 沿该维做 online softmax 归约：求 lse_max、对 exp2(lse_s−lse*) 求和得全局 lse、再按该权重累加各 split 的部分输出；num_split==1 时退化为单 kernel。解码掩码因 q_seqlen=1 退化为逐 KV token 的一维稠密向量，由 create_mask（非块级稀疏的 create_block_mask）生成、在 KV 循环内 if_then_else 施加。关键术语 decode、split-kv、num_split、combine kernel 为下一讲 MLA 解码 combine 打基础。
