本讲讲解 IKA32010 片内数据 RAM 通路，核心是 `IKA32010_ram` 子模块。它是 **256×16 位的简单双口 RAM**：读端口寄存输出（`o_DOUT` 滞后 `i_ADDR` 一拍），写端口受 `i_WE`/`i_DMOV` 控制；子模块只认 `i_EMUCLK` 不认 `cyc_ncen`，靠整周期信号稳定保证每拍重复写入幂等。8 位 RAM 地址 `ram_addr` 由指令字 **bit7 二选一**：bit7=0 走**直接寻址** `{DP, 位移[6:0]}`，仅限 DP 决定的当前 128 字页；bit7=1 走**间接寻址** `AR[ARP][7:0]`，可达全 256 字并可带 AR 自增/自减与 ARP 改写（由 bit5/4/3/0 控制的译码片段驱动）。默认 `register_wrbus_source_sel = WRBUS_SOURCE_RAM`，使 RAM 读出的数据自动经 `reg_wrbus` → 移位器 A → ALU 端口 B，算术指令无需额外声明；写 RAM 则统一经 `reg_wrbus` 选源 + `ram_wr` 门控（SACL 取累加器、SAR 取 AR 等）。本讲引入的关键术语：数据页指针 DP、辅助寄存器 AR/ARP、直接/间接寻址、`reg_wrbus` 汇流、读端口寄存输出。最后介绍 **DMOV** 这一子模块级硬件特性：`ram_dmov=1` 时强制写、写地址同页 +1、写数据取读端口输出，实现 `RAM[addr+1]←RAM[addr]`，并被 **LTD** 复用以单周期完成「取数+乘加+移位」，为 FIR 延迟线服务，并引出后续 u2-l8 乘法器与 u2-l7 ALU。
