本讲总览 torch_ops_extension：它是把前五单元讲解的 Ascend C 算子（aclnn C 接口）包装成 PyTorch 可调用算子的适配层。setup.py 用两条 glob 规则自动收集 15 个 .cpp，经 torch_npu 提供的 NpuExtension 编成扩展模块 custom_ops_lib，build_and_install.sh 三步完成清理、编 wheel、pip 安装。csrc_base 公共层分工：ops_def_registration.cpp 以 TORCH_LIBRARY_FRAGMENT 在 custom 命名空间注册 18 条算子 schema，并用 pybind11 绑定 8 个 autograd 封装函数；ops_common.h/.cpp 负责 at::Tensor 与 aclTensor 的类型转换，以及 aclnn 符号的运行期 dlopen/dlsym 动态查找，EXEC_NPU_CMD_V1 宏将「GetWorkspaceSize+执行」两段式调用、workspace 分配与异步下发封装成一行。包入口 __init__.py 再把 torch.ops.custom 下算子挂载到 torch_npu 模块。核心约束：必须先装 u1-l4 的算子 run 包并 source 环境，再装 wheel，因为 .so 加载瞬间即读 ASCEND_CUSTOM_OPP_PATH 初始化符号查找路径。
