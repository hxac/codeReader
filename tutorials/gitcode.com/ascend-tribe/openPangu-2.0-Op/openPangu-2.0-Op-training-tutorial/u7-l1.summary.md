本讲介绍 pypto 编程模型：以 Python DSL 编写 NPU 设备侧向量算子，`@pypto.frontend.jit` 将带类型标注的 Python 函数即时编译为设备代码，标本是 QAT 非对称分组量化算子（前向 + 反向）。核心概念：kernel 签名即张量契约，`pypto.Tensor` 标注形状与 dtype（DYNAMIC 维运行期确定），无标注参数为 Host 预计算标量；输出走目标传递风格，由 wrapper 用 `torch.empty` 分配后按位置传入，参数顺序是硬契约。数据流三原语为 view（取块）、cast（BF16 输入输出、FP32 内部计算）、assemble（镜像写回），配合 torch 风格计算原语。切分内嵌 kernel：`loop_unroll` 按 unroll_list 大块优先、余量降级收尾；`set_vec_tile_shapes` 按归约模式定制 tile 形状且可中途重设；runtime_options 与 pass_options 是编译期调优旋钮。结论：一个 .py 文件（kernel + wrapper）替代 ascendc 四层结构，import 即部署；STE 梯度推导留给 u7-l2/u7-l3。
