本讲拆解 pypto 算子 st（系统级精度测试）体系：一个公共 utils.py 加六个「前向/反向 × per_tensor/per_channel/per_group 三种量化粒度」测试文件，统一套用「import、golden 工厂、造数、参数化、驱动」五段式模板。核心模块有三：create_input 造数引擎，分布可控且函数内重置种子保证可复现；forward_test 与 backward_test_autograd 通用执行接口，反向基准梯度由 torch autograd 自动求出；precision_compare_triple 三方判分。关键概念：三方对比（kernel、benchmark、FP64 golden）、MARE/MERE/RMSE 误差指标、大/小值域切分（小值域只数坏点个数）、L0/L1/L2 精度等级（默认按最严 L2 档比值 2/1.2/1.2 判定）。核心结论：比值判定使 BF16 kernel 的误差只需落在 torch 同精度基准的受控倍数内，避免绝对阈值难以标定；assert_allclose 仅记日志，compare 抛异常才是硬门槛；与 ascendc st 判定标准同源但工程形态不同。
