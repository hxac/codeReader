本讲总览 FA 前向算子 flash_attention_score_enhance：计算为「打分（scale·q·kᵀ，可加 MLA rope 项与 pse）→掩码→online softmax→dropout→乘 value」；接口为 18 输入（query/key/value 必选，可选含 rope 对、多种 mask、两种互斥 sink 机制、varlen 元数据与外切索引）、4 输出、14 属性，仅支持 TND 变长排布（B、S 合轴成 T，以累加长度描述各 batch 边界）。核心结论：online softmax 分块滚动维护行最大值与指数和，落盘为 softmax_max/softmax_sum（FP32），与 softmax_out、attention_out 一并被反向算子全部消费——这是训练 FA 比推理 FA 多输出的根源；五个 varlen 元数据输入带 ValueDepend，声明下标 7~11 与 tiling 侧 TilingInputsDataDependency 精确互锁。tiling_common.h 是跨 tiling 实现共享的平台编译信息结构体 CompileInfo，由 TilingParse 一次探测填充。接口契约以 _def.cpp 与 aclnn 头文件为准，文档可能滞后。Tiling 切分细节留 u4-l2，Kernel 模板 u4-l3，反向 u4-l4。
