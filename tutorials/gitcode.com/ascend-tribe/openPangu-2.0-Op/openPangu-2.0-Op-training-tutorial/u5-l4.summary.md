本讲为 MHC 家族第 4 讲，讲清 post 前向与两个反向算子的关系。post 把 Sinkhorn 归一化后的双随机矩阵转置作用于 n 路残差，再与 Atten/MLP 输出按 h_post 加权求和，得到下一层 [T,n,D] 输入；因 n≤8 矩阵极小，选 AIV_ONLY 以 Muls/Axpy 实现，读码需留意 H_res 的 [j,i] 转置索引。其 tiling 为单模板两级组织，16 字段 TilingData 含分核、D 维切分与对齐三标志，kernel 据此分发 8 路模板。核心结论：post_grad（AIV_ONLY 纯向量）与 mhc_post_grad（AIC:AIV=1:2 混合核）数学完全等价，是同一反向的两种实现；后者由 AIV 并行算 grad_x、grad_h_out、grad_h_post 三路（逐元素加归约），AIC 用 Cube 矩阵乘算 grad_h_res（K 分段累加），两侧无同步无竞争。反向验证金标准为 CPU fp64 加 autograd 一次取四路梯度。
