本讲是第1单元收官，讲解ascendc工程如何从源码变成已安装的自定义算子包。build.sh是薄壳脚本，将-c（目标芯片）、-n（算子白名单）等参数翻译成CMake的-D变量，主流程为set_env→clean→cmake_config→build_package；CANN包路径按五级fallback定位，bisheng编译器为硬依赖，每次构建全量清理、增量靠ccache。CMakeLists用glob自动发现算子目录并按白名单过滤，产出opapi、opsproto、optiling、ops_aclnn、ops_kernel五类目标；aclnn接口源码由CANN的op_build工具在配置期从_def.cpp生成至autogen/目录。最后CPack与makeself把产物封装成自解压run包，安装即释放到opp/vendors/omni_training_custom_transformer/下，source厂商目录的set_env.bash后算子即可被运行时发现。
