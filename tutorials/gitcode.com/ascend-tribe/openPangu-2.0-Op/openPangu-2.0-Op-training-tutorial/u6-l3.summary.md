本讲以 MHC post 家族为标本，讲解 torch_ops_extension 的 Python 侧适配层：converter 与 test。核心结论：converter 是 torchair 的 fx2ge 转换器，经 @register_fx_node_ge_converter 把 torch FX 图节点静态翻译为 GE 算子（torchair.ge.custom_op：类型字符串、inputs、attrs、outputs），仅服务 torchair 图模式，eager 与 aot_eager+NPUGraph 路径均不经过它；其签名须逐参对齐 torch schema（含 .default 重载与 meta_outputs 尾参），inputs/outputs 名与 _def.cpp 的 Input/Output 逐字一致，类型字符串照抄 OP_ADD 类名。全仓库仅 post 家族三算子配齐「csrc+converter+test」三件套，各件可按使用方式裁剪；converter 注册靠各级 __init__.py 逐级 import * 完成，但导入链在顶层断开、需使用方显式导入。test 为五段式冒烟脚本（参数、造数、调用、断言、main），只断言 shape 与 dtype，无数值验证，精度防线在 ST 测试。综合实践为 pre 算子补全三件套并编写 eager wrapper，确立三层分工：csrc 定义能力边界、converter 让算子进图、wrapper 让接口好用。
