本讲剖析 SparseLightningIndexerGradKLLossEnhance 算子：它是 LightningIndexer 的反向并融合 KL Loss，一次调用同时产出 d_query_index、d_key_index、d_weight 三路梯度与 loss 标量。核心结论：训练损失 L=Σ D_KL(p‖Softmax(I)) 的反向梯度为 dI=Softmax(I)−p（元素和恒为零），链式展开得 dW、dS'（乘 ReLU 次梯度掩码）与 dQ/dK；dK 因同一 key 行被多个 query 选中必须 ScatterAdd 原子累加。关键概念：目标分布 p 由主注意力打分全头归约并复用 FA 前向保存的 softmax_max/softmax_sum；预测分布 q 由 indexer 打分经 W 加权、G_index 归约后 softmax，两者经 psySync workspace 交换汇合。工程要点：Host 侧 tiling 按因果行长做负载均衡分核（bS1Index[]）；设备侧 AIC:AIV=1:2 混合核六级流水配 runInfos 三槽软件流水，Cube 手写五级流水完成四次 Mmad（ReLU 融入 Fixpipe），确定性模式改跨核轮转保证可复现。
