本讲以 npu_aggregate_hidden.cpp 为标本，讲清单个算子 csrc 适配的四件套：一是 EXEC_NPU_CMD_V1 宏——csrc_base 桥接层在运行期用 dlopen/dlsym 按名解析 aclnn 两段符号（自装 run 包优先、CANN 内置库兜底），ConvertType 重载完成 at::Tensor 到 aclTensor 的零拷贝转换（optional 空值转 nullptr、标量透传），库路径在 import 瞬间初始化，故必须先装 run 包并 source 环境再 import；二是 NPU 前向/反向函数——用 at::empty_symint 预分配输出，实参顺序须与 _def.cpp 的 Input/Output 声明严格一致（参数顺序契约，跨四层对齐）；三是 torch::autograd::Function 子类——forward 加 AutoDispatchBelowADInplaceOrView 守卫防递归、save_for_backward 保存现场，backward 调反向算子且返回个数与 forward 参数对齐，不可微参数（bool 掩码、标量）返回未定义张量表示无梯度；四是三路 TORCH_LIBRARY_IMPL 注册——PrivateUse1 挂真实计算（含反向积木）、AutogradPrivateUse1 只挂前向包装、Meta 挂形状推导，__init__.py 再把 torch.ops.custom.* 挂载为 torch_npu 的属性。关键术语：dispatch key、PrivateUse1、AutogradPrivateUse1、Meta 设备、未定义张量。
