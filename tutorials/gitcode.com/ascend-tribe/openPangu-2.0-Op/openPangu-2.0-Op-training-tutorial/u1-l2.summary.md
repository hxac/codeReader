本讲建立昇腾自定义算子的四层心智模型：op_def 原型注册（`_def.cpp` 声明输入输出、类型格式与芯片支持，OP_ADD 入注册表）、op_host 侧 Tiling（`_tiling.cpp` 校验输入、按核数切分数据，产出 TilingData/tilingKey/workspace/blockDim）、op_kernel 设备侧 Ascend C Kernel（入口按 TILING_KEY_IS 选分支，Init 绑 GM 地址并配 UB，Process 走 CopyIn→Compute→CopyOut 流水）、op_api 即 aclnn 两段式接口（先 GetWorkspaceSize 规划，再带 stream 执行）。以 mome 家族的 ai_infra_aggregate_hidden 为解剖标本。核心结论：四层靠算子名对齐；tilingKey 由 Host 写、Device 读，是跨侧分支信号；芯片适配分编译期 AddConfig 与运行期 socVersion 白名单两层；多数算子缺 op_api 源码，其 aclnn 符号由已安装算子包在运行期提供，torch 扩展用 EXEC_NPU_CMD_V1 按名动态解析补齐。
