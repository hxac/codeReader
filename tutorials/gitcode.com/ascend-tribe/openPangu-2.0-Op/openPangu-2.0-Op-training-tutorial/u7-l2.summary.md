本讲在 u7-l1 的 pypto 编程模型之上，讲解对称量化感知训练（QAT）算子 per_tensor 与 per_channel 的前向与反向 kernel。前向是四步公式链：scale 防零保护（max(s,ε)）、归一化、round+clamp 伪量化、反量化；round 不可导，靠直通估计器 STE（x 加 detach 掉的取整差值）让梯度直通。反向两大结论：STE 下 grad_weight 的 scale 因子精确相消，即 grad×mask；grad_scale 由乘法与除法双路径相加再乘 scale 掩码。界内掩码用整数差技巧（clip(abs(rounded−clamped),0,1)）纯向量算术生成，故 min_v/max_v 须为浮点型整数；反向采用无缓存设计、重算前向。两种粒度的差异是 scale 形状的连锁：per_tensor（标量 (1,1)，Embedding 场景）可将 scale 保护外提循环、需 expand_clone 物化、grad_scale 需全局累加器并禁用 combine_axis；per_channel（(N,1)，Lm Head 场景）块内天然对齐、仅沿 M 归约、无累加器。下一讲 u7-l3 讲非对称 per_group 量化，引入 offset 与分组 scale。
