本讲精读 pypto QAT 系列中算法最复杂的非对称分组量化算子（前向与反向）。前向是九步公式链「减 offset → 归一化 → clip → 乘 n_levels 减 shift → round → 加 shift → 反归一化 → 乘 alpha → 加 offset」，关键术语：可学习零点 offset、半幅刻度数 n_levels=2^(bit-1)、半格平移 shift=0.5、LSQ+（scale 与 offset 均可学习）、per_group 分组量化（每组 group_size 个元素独立持有 scale 与 offset）。核心结论：clip_val=0.99 与 shift=0.5 组合使重建格点恰为 2^bit 个且关于 offset 对称；STE 下界内元素前向近似恒等，反向三路梯度可统一为 grad_weight=g⊙mask、grad_offset=Σg⊙(1−mask)、grad_scale=n_levels·1[s>ε]·Σg⊙(q−u⊙mask)。kernel 沿组维度 loop_unroll([512,256]) 大块优先、余量降级；反向无缓存重算前向，掩码用差值放大截断的纯向量算术生成。反向 ST 测试以一份 torch golden 同时做 BF16-autograd 基准、FP64-autograd 金标准与 NPU kernel 的三方梯度对比，按 MARE/MERE/RMSE 比值加小值域计数判定精度。
