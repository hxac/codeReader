本讲剖析稀疏 FlashAttention 前向与反向算子对。核心结论：稀疏化把 softmax 分母从整个 S2 收窄为「索引选中∩因果允许」的 token 子集，由 sparse_indices（int32，每行存选中的 KV 块编号，-1 尾部填充）与因果阈值 threshold 界定。前向 tiling 以 GET_TPL_TILING_KEY 模板参数自动编码 tilingKey；kernel 为 MLA 专用（512+64 拼 576 维、MQA），取数分 C_TEMPLATE（Cube 按索引离散搬 K）与 V_TEMPLATE（Vector 先 MergeKv 聚合，块≤4 时启用）两种。反向 tiling 走责任链，唯一模板 bs1_basic 按 s1 行分核；kernel 每行 Gather→五矩阵乘→ScatterAdd 把 dk/dv 累加回原位。索引生产者 lightning_indexer 留待下讲。
