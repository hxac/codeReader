本讲补齐四层算子模型的最后一层 op_api（对外 aclnn 接口），标本为 flash_attention_score_enhance（多数算子无 op_api 源码，它因需自定义布局预处理才入仓）。核心结论：aclnn 是两段式接口——第一段 GetWorkspaceSize 在 Host 上校验参数、按需做连续化/Pad/Transpose 布局预处理，把含预处理算子在内的整条任务流水线记入 executor 并汇总 workspace；第二段仅 4 个参数，由 CommonOpExecutorRun 把任务下发到 stream。op_api 内部分两级：L2（aclnn_ 前缀文件）是对外契约与适配层，L0（namespace l0op）负责补可选参数默认值、将 IntArray 张量化，再经 INFER_SHAPE 与 ADD_TO_LAUNCHER_LIST_AICORE 两个宏把算子录入 executor。透传结论：标量参数走 Attr 通路（如 input_layout、sparse_mode、head_num）被 tiling 的 GetAttrs 读取，数组参数张量化后走 Input，op_api 由此与 tiling/kernel 解耦；读接口以头文件为准，docs 示例可能滞后。
