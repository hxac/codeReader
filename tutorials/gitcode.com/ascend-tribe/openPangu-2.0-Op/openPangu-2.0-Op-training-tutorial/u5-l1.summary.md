本讲解析 MHC（流形约束超连接）家族的 SinkhornEnhance 前向算子：MHC 要求多路残差分支的混合矩阵 H'_res 为双随机矩阵（行、列和均为 1），算法上用 Sinkhorn 迭代实现——先 softmax 初始化保证正性与行和为 1，再行、列交替除以「和+ε」防除零。训练路径（out_flag=1、tilingKey=0）把每轮归一化的 norm_out[k] 与分母 sum_out[k] 共 2×num_iters 份落盘（t=B×S 折叠至末维），专供反向算子 ai_infra_sinkhorn_grad 复用，属空间换反向时间。工程要点：两级 tiling——tiling_base 薄入口挂责任链，SinkhornTilingBase 以优先级 2000 注册，负责属性校验、核间/核内切分与 tAlign UB 预算；训练 kernel SinkhornGeneralized 先转置为 [n,n,t] 布局使向量指令满载，softmax 对应 Max/Exp/Add/Div，行列归一化对应 ReduceSum+Adds(ε)+Div 原语；推理路径（tilingKey=1）另走 pad-8 免转置实现。
