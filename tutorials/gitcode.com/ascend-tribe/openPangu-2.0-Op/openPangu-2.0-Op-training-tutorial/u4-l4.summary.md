本讲是 u4-l3 FA 前向 Kernel 的续篇，讲解 FlashAttentionScoreGradEnhance 反向算子。核心题眼是「重获前向没存的东西」：前向 online softmax 不落盘注意力矩阵 P，反向须用 Q·K^T 重算打分，并复用前向保存的 softmax_max/softmax_sum（均须 fp32，shape 为 (b,n1,s1,8)）免 max 免 sum 重建 P；softmax 行修正项则用 attention_in 直接算 rowsum(dy⊙O)，等价于 rowsum(dP⊙P)。计算骨架为三个 Matmul 对象打五次（mm1 两打：dY·V^T 与 Q·K^T；mm4：dQ；mm3 两打：dK、dV），dP 本身由向量侧 (dP_raw−r)⊙P 得到，非矩阵乘。Tiling 入口三段式（粗校验→空输入快路径 tilingKey=0→九模板责任链，优先级 10~16000，SameAb 最优先）；kernel 入口用 64bit tilingKey 位域（UB0/UB1/Block/IsSameAB/布局/稀疏等）经 if constexpr 编译期分发到 Pre→Sfmg→主计算→Post 三段式，AIC:AIV=1:2 混合核分工。basic_modules 把 vec（SubGrapA 重建 P / SubGrapB 算 dP）与 cube（L1/L0 ping-pong 流水）拆成可复用积木。确定性版本用每核独立 workspace 加固定顺序合并换 bit 级复现，代价是额外显存与更窄能力子集（仅 TND、无 PSE），开关为 torch.use_deterministic_algorithms。下讲 u4-l5 转向稀疏 FA。
