本讲解剖 op_host 的 Tiling 层（标本 ai_infra_aggregate_hidden）。核心结论：Tiling 是 Kernel 启动前的 Host 侧“作战规划”，不搬数据、不做计算；经 gert::TilingContext 读入 shape 与平台信息（AIV/AIC 核数、socVersion），产出四项契约——SetBlockDim（核数）、SetTilingKey（0=BF16、1=FP16，Host 写 Device 读）、序列化 TilingData（RawTilingData 字节流）、workspace 大小。关键术语：GM/UB 两级存储、TilingData 结构三组字段（baseX/baseXTail/baseXCnt）、AHInfoParser 的平台探测与五步合法性校验（OP_CHECK_IF＋OP_LOGE 防御式风格）、CoreSplit 的 H→B→S 三级级联切分（H 按 UB 全载上限 4096 切并做核数整除特判，blockDim 为三 Cnt 之积、目标 AIV 核满载）、IMPL_OP_OPTILING 注册。Kernel 用 GetBlockIdx() 对 Cnt 取余反推本核 tile，契约闭环。
