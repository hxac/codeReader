本讲进入 flash_attention_score_enhance 的设备侧 kernel 层。入口把 64bit tilingKey 的约 20 个位段（layout、dtype、稀疏模式、Bmm1Format 等）直接映射为 C++ 模板参数，用 if constexpr 在编译期分发到 7 类 layout/场景模板（含空输入早退），实例清单按 dtype 隔离编译。主力模板 S1s2Bn2gs1 以 extraInfo[3] 三槽环形缓冲驱动三级软件流水线——发射 bmm1(i)、softmax(i-1)、bmm2 与累加写回(i-2)，尾部加两个空转迭代排空；online softmax 由 SoftmaxFlashV2 的首块/更新两模式落地，含 sink 初始化特例；多 layout 支持的本质只是四套 GM 偏移公式。边界处理两件套：drop_mask_adapter 在 s2Size%8≠0 或变长多 batch 时把 bit 打包 dropout 掩码展开为对齐 bool 掩码写入 workspace，SyncAll 后主算子改读；empty_tensor 由 KernelTypeKey=1 触发早退，仅清零 softmaxMax/softmaxSum/attentionOut 三输出即返回。关键术语：模板参数化 kernel、AIC/AIV 混合核（1:2 混排）、ND/NZ 格式、bit 打包掩码、online softmax。
