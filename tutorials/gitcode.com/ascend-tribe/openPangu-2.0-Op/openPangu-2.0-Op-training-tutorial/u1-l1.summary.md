本讲建立 openPangu 2.0 训练算子库的全景认知：training/ 下分三大板块——ascendc（用 Ascend C 编写的融合训练算子主体）、pypto（Python DSL 算子，当前仅 QAT 量化一族）、triton（仅 .gitkeep 占位预留）。ascendc/src/ops-transformer 按算法家族组织：attention（9 算子＋common 公共目录）、mhc（7）、mome（2），共 19 个目录；训练算子前向与 _grad 反向成对出现是训练库的典型特征。每个算子目录标准五件套为 README、docs、op_host、op_kernel、tests（op_api 可选），推荐阅读顺序 docs→op_host→op_kernel→tests；README 目录树滞后于磁盘，应以实际目录为准。本讲引入的关键术语：昇腾 NPU 与 CANN 工具链、aclnn 接口前缀、融合算子、QAT 量化感知训练、STE 直通估计器（detach 伪量化）、pypto 的 @pypto.frontend.jit 装饰器、torch_ops_extension 包装出的 torch.ops.custom 调用方式。mome 家族的 ai_infra_aggregate_hidden（一维分组卷积）因结构最简且前反向齐全，被选为后续讲义的第一个精读算子。
