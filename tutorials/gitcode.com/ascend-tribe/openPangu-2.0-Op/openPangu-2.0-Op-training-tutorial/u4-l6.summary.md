本讲精读 LightningIndexerEnhance：稀疏注意力链路的「索引生产者」，为稀疏 FlashAttention（u4-l5）产出每个 token 的 TopK 索引，算法为「ReLU(QKᵀ) 打分 → 组内 W 加权求和 → TopK」，注意没有 softmax。内容覆盖五个模块：_def.cpp 接口清单（6 输入、2 输出、9 属性，A2/A3 双芯片）；proto.cpp 以 K=⌈sparse_count/sparse_block_size⌉ 推导输出形状 [B,S,N2,K]；调度器 LIPreload 在 AIC:AIV=1:2 混合核上，用 CrossCoreSetFlag/WaitFlag 跨核事件加 (loop%2) 双缓冲，使 Cube 侧（手写五级流水做打分矩阵乘，ReLU 顺带做在 Fixpipe）与 Vector 侧（DoScale 加权、沿 g 规约、Sort/MrgSort 归并树 TopK、因果截断、LD 跨核归并）逐基本块乒乓。tiling 为 Host 粗切、Device SplitCore 细分。关键术语：GQA 组大小 g、sparse_indices/sparse_values（-1 尾部填充）、sparse_mode=3 右对齐因果、LIMatmul/LIVector。
