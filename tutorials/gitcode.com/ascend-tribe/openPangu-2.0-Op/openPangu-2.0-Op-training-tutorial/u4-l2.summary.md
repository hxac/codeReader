本讲深入 FA 前向算子 flash_attention_score_enhance 的 op_host 层，分四模块。模块一 Tiling 入口三段式：粗校验、空输入快路径（置 tilingKey=1，仅规划输出清零）、责任链调度六个按优先级注册的切分模板，其中 DropMask 模板填参后故意让位接力，TilingParse 钩子在编译期缓存平台参数。模块二 InferShape 仅凭静态 shape 与 head_num 等属性推四输出：softmaxMax/Sum 恒为 fp32，softmaxOut 置零占位（不物化注意力矩阵），attentionOut 复制 query 形状、末维经 H 轴反推改为 N1·D2；变长张量 actual_seq_qlen 留待 tiling 阶段消费。模块三 general tiling 将 BSH/SBH/BSND/BNSD/TND 五种布局归一化为 B/N2/G/S1/S2/D 逻辑轴，按 fractal=16 对齐选出能放进 UB 的 basic block（通用 UB 预算公式或模板经验值），任务块按 B·N2·G·S1Outer 均分 AIV 多核。模块四 tilingKey 为 64bit 位域编码：Host 侧约 20 个参数按位组装，kernel 侧按位段反查并绑定 TilingData 结构。
