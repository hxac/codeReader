本讲义总览 framework_normal UT 框架，覆盖 common 公共件（tiling_context_faker、tiling_case_executor）与 op_host/op_api/op_kernel 三个入口目录及 ut.cmake 构建总线。核心结论：仓库 UT 分三类——op_host UT 测 tiling/InferShape 的 Host 侧逻辑（17 个用例）、op_api UT 仅测 aclnn 两段式第一段 GetWorkspaceSize（8 个用例）、op_kernel UT 基建备而未用；三者均无需 NPU。关键术语：faker（伪造被测代码的输入环境 TilingContext，区别于替换下游依赖的 stub）、TilingContextPara（用例参数包：算子名、张量描述、属性、伪造平台参数 socVersion/coreNum/ubSize）、TilingContextFaker（继承 CANN builder 组装真 context）、DO_TILING 八步执行器（含伪造平台 JSON 戏法）、ExecuteTestCase 断言四连（返回值→workspace→tilingKey→TilingData 串，支持 * 通配）与无断言版 ExecuteTiling、聚合机制（whole-archive + so/dlopen/注册表，用例文件名 test_*_tiling.cpp 为 glob 硬约定，加算子零改动框架）。本讲是 u8-l2 编写 tiling 用例与 u8-l4 运行 UT/ST 的地基。
