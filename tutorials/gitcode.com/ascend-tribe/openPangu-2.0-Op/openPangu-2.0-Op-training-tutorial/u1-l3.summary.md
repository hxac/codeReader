本讲讲解昇腾 NPU 开发环境搭建。核心结论：环境分三层——驱动装在宿主机，CANN 工具链与 torch_npu 框架适配层装在容器镜像内，二者经设备透传（davinciN 计算设备与 davinci_manager 等管理设备）及挂载卷（宿主机驱动目录、ascend_install.info 等）打通。镜像按芯片代际分 A2/A3/A5，tag 中写死 CANN 与 torch_npu 的配套版本；A3 对应 build.sh -c 参数的 ascend910_93。容器内每次新开 shell 须 source set_env.sh 导出 ASCEND_HOME_PATH 等变量；build.sh 按五级 fallback 解析 ASCEND_CANN_PACKAGE_PATH，加载包内 setenv.bash、校验毕昇编译器 bisheng 后传给 cmake。环境自检三件套为 npu-smi info、which bisheng、import torch_npu。本讲为 u1-l4 的编译与安装奠基，并预告算子包装好后需二次 source vendors 下的 set_env.bash。
