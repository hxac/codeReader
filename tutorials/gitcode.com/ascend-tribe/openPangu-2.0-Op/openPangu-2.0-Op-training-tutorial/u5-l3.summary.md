本讲精读 MHC 前处理算子 pre 及其反向 pre_grad。pre 是 MHC 训练步的入口生产者：对 n 路残差输入做 RMS 统计与一次融合矩阵乘（φ 共 n²+2n 行，称 fusionSize），一次产出 h_in、H_post，以及交 Sinkhorn 做双随机归一化的 H_res；out_flag=1 时额外落盘三个反向必需的中间量（inv_rms、mm_res、h_pre），故训练必须开 out_flag。本讲借这一家族中唯一带完整 op_api 的算子走读全链路：aclnn 外层负责校验、连续化与输出回拷，l0op 内层负责分配输出、推 shape 并把算子挂入发射列表以触发 tiling。tiling 以单模板实现双模式：T 超 180、带 gamma 或 out_flag=1 时走分块迭代的基础 kernel；小 T 解码走 split_ND，在 1:2 混合核上以 V0→AIC→V1 三段流水线沿 K（nD）轴切分并做部分和归约，代价是不支持 gamma 与落盘。pre_grad 与前向目录逐层镜像，把落盘中间量声明为必选输入。关键术语：BSND/TND 变长折叠、fusionSize、部分和归约。
