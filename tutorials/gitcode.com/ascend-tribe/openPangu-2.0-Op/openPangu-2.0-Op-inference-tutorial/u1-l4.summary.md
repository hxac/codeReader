本讲收尾第 1 单元：讲解 torch_ops_extension 如何打包成 omni_custom_ops wheel 包（「方向盘」）并挂载算子。setup.py 用两条 glob 规则自动收集 csrc 源码，经 NpuExtension 配好昇腾编译参数，新增算子无需改打包脚本。关键机制：C++ 扩展 custom_ops_lib 被 import 时用 TORCH_LIBRARY_FRAGMENT 把算子签名注册进 torch.ops.custom 命名空间，各算子 csrc 用 TORCH_LIBRARY_IMPL 按调度键挂实现——PrivateUse1 为 NPU 真算、Meta 只推形状；__init__.py 再把算子镜像到 torch_npu 模块。核心结论：torch.ops.custom.npu_xxx 与 torch_npu.npu_xxx 两种写法等价，前提是脚本必须 import omni_custom_ops（挂载靠 import 副作用而非 pip 安装）；输入需 .npu() 上设备，多输出按签名解包；csrc 底层经 aclnn 接口借道 run 包完成真实计算，故顺序必须先装 run 包再装 wheel；图模式依赖 converter，eager 与图模式两种用法及数值对拍可参照 example 与 ST 测试。
