本讲解读 MHC（流形约束超连接）的一对推理算子：pre 算子是系数发生器，从输入 x 经 phi 投影产出每 token 的门控系数 h_post 与残差混合矩阵 h_res；sandwich 算子是融合执行器，消费这两组系数，把 RMSNorm_0、MHC_Post、RMSNorm_mid、MHC_Pre、RMSNorm_1 五阶段深度融合为一次 kernel 调用。核心结论有三：tile 切分上 dimTile 取 min(D,2560) 并按 128 对齐，规格限定 N=4、D 仅支持 2560/5120；分支策略上 pre 用 TilingKey 编译期分派 single_tile/multi_tile 两份二进制，sandwich 恒设 key 0、靠 TilingData 字段运行期分派 singlecore/dualcore/dualcore_mt 三路；双核协同（token 少于核数一半时启用）有两种代价模型——pre 按 phi 行对半、两核冗余算 RMSNorm、零同步，sandwich 按 head 对半、经 GM workspace 交换部分和、以 sense-reversing 自旋屏障对齐，共通哲学是以冗余计算换跨核同步。另介绍 v2 接口的 return_h_in_f32：把 kernel 内现成 fp32 中间值按需导出，替代 v1 分配占位张量的浪费。
