本讲承接 aclnn 登记，讲解 host 侧 Tiling 计算。Tiling 在算子执行前经 gert::TilingContext 读取形状与平台信息（PlatformInfo 或编译期缓存的 CompileInfo，双来路），算出数据切分与分核参数，打包为 TilingData 下发，是 kernel 的「施工图」。TilingData 用宏定义，是 host/device 两端的序列化契约：host 在 PostTiling 中 SaveToBuffer 写入，kernel 入口用 GET_TILING_DATA 解包。仓库所有 tiling 类继承 TilingBaseClass，其 DoTiling() 固化七步：GetShapeAttrsInfo→GetPlatformInfo→IsCapable→DoOpTiling→DoLibApiTiling→GetWorkspaceSize→PostTiling，真正承重的是第 2、4、7 步；三态返回值（GRAPH_SUCCESS/GRAPH_FAILED/GRAPH_PARAM_INVALID）支撑注册表按 priority 轮询多个 tiling 类。TilingKey 是分支暗号：host 侧算值、框架 SetTilingKey 落账、kernel 侧 TILING_KEY_IS 对号入座。tiling 逻辑可用 UT 框架在纯 CPU 上验证。
