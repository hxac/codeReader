本讲精读 op_host 的 *_def.cpp：以继承 OpDef 的类登记算子原型（签名），声明输入、输出与 Attr；ParamType 分必选/可选/动态三种；DataType/Format/UnknownShapeFormat 三个等长列表按下标对齐成组合表，各输入共享同一组合编号。OpAICoreConfig 能力开关（动态 shape/rank/format 等）经 AddConfig 登记到 ascend910b、ascend910_93 等 SOC。核心结论：def 只声明签名、不含计算逻辑，供 aclnn 执行器与图引擎查表校验；算子被发现分两层——编译期算子目录被 CMake GLOB 收集并编入原型库 cust_opsproto_rt2.0.so，运行期 OP_ADD 宏静态注册进全局注册表；目录名须等于 def 文件名去掉 _def 后缀，类名为其大驼峰形式。
