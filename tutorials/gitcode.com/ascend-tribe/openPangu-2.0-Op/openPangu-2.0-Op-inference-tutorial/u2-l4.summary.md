本讲进入 op_kernel 层，以最小算子 scatter_block_update 为主标本、mhc_sandwich_norm 为对照，讲 AscendC kernel 三个模块：一是入口函数，须加 extern "C" __global__ __aicore__ 修饰，参数布局是固定契约——按 OpDef 的 IO 声明顺序排列、末尾追加 workspace 与 tiling，DTYPE_* 为编译期类型宏；二是 GET_TILING_DATA 在 device 侧解包 host 下发的 TilingData「施工图」，TILING_KEY_IS 按 TilingKey 让 kernel 对号入座，key 双侧数值须硬编码一致否则静默空跑，MHC 示范了按 TilingData 字段运行期分派的替代方案；三是 Kernel 类 Init/Process 两段式：Init 绑定 GlobalTensor、读 tiling 字段、用 TPipe 的 InitBuffer 划拨 UB；Process 以 GetBlockIdx 领区间（尾核用 tailCoreIndexCount 兜余数）、按 maxIndicesPerLoad 分批循环 CopyIn/ScatterOut，TQue 双缓冲使 MTE2 搬运与计算重叠。关键术语：GM/UB 两级内存、MTE2/MTE3 搬运通道、AIV 向量核、Alloc/EnQue/DeQue/Free 成对队列 API、HardEvent::MTE2_S 标量读同步。
