本讲横向解剖稀疏注意力算子家族。核心结论：稀疏性不体现在公式，而体现在输入——sparse_indices（int32，有效值前置、-1 尾部填充）按 sparse_block_size 指向被选中的 KV block，actual_seq_lengths_kv 截断尾块，rightDownCausal mask 保证因果性；收益是计算量降一个量级，代价是离散访存。三个主算子递进：GQA 版非量化打底，复用 FiaTilingRegistry 按 priority 编码轮询 tiling 模板；Pioneer 版面向 MLA-absorb 结构，新增 rope 拆分与 Sink Token，K/V 共享一份存储；KV 量化版存算 int8/float8、Per-Tile-128，量化系数混拼进 key 行。配角两类：lightning indexer 与 esa_select_topk 负责选块、产出 sparse_indices；AICPU 上的 metadata 算子预计算分核方案，供 pioneer/kv_quant 消费，串成完整的稀疏注意力推理流水线。
