本讲拆解 ops_common 适配层的三个模块。一是符号查找：GetOpApiFuncAddr 全部走运行期 dlopen/dlsym，按六级优先链首命中即返回，ASCEND_CUSTOM_OPP_PATH 与 vendors load_priority 指定的 libcust_opapi.so 最优先，自定义算子库因此压过 CANN 内置库。二是类型转换：ConvertType/Release 重载族把 at::Tensor、Scalar、IntArrayRef、optional 桥接为 aclTensor* 等 ACL 描述符，其中 Tensor 转换零拷贝、IntArray 内部有拷贝、optional 缺省传 nullptr、标量透传。三是总装宏 EXEC_NPU_CMD_V1：参数一次打包成 tuple 两段共用，先同步调 GetWorkspaceSize 回填 workspace 尺寸与 executor，再按需分配 NPU workspace，经 RunOpApiV2 在闭包内异步下发执行段，ReleaseConvertTypes 必须在闭包内、晚于执行段统一销毁描述符以防悬垂指针。「符号找不到」类报错来自本层 TORCH_CHECK，根因多为 run 包未装、vendors 未登记或符号拼写错误。
