本讲解读 posembedding 算子族。kv_rms_norm_rope_cache 把 MLA 推理中的 RMSNorm、RoPE、可选量化与按 index 散射写 KV Cache 融为一次 kernel 调用；cache_mode、rotary_mode、quant_mode 三个模式旋钮与 V1/V2 规格、MTP/B1SD 切分组合，由 host 侧决策树编成 18 个手工分段 TilingKey，device 侧按 TILING_KEY_IS 链分发至 9 个 kernel 头文件；量化是否生效由 scale/offset 张量在场实证，而非属性字符串声明。Ascend 950（arch35/regbase）另起一套模板轮询：DS→D 全载→二分重算，D 全载按 UB 预算放不下即交棒（key 10000/20000）。独立算子 rotary_mul 仅做 rotate-half，以换半、取负、乘加三原语覆盖五种 layout。
