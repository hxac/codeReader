本讲剖析 ops-nn 的 AiInfraMatmul：它不是又一个独立算子，而是被多个上层入口共享的矩阵乘基建，复用层次为 aclnn 图分发层 → l0op 薄封装层（AiInfraMatmulCommon）→ 共享算子本体，公共逻辑沉淀在 matmul.cpp、matmul_util.cpp 等 7 个公共文件。核心机制：GenSimplifiedKey 拼接的 simplified_key 在编译期查 binary.json 选预编译二进制、运行期查 runtime_kb.json 调优知识库；host 侧 DoL2CacheTiling 计算 L2 分块并产出 l2CacheFlag，kernel 侧转为 SetL2CacheHint；ND 输入经 ND2NZ 转成 Cube 核偏爱的 FRACTAL_NZ 排布（fp16 时 c0=16），由 MatrixAtoNZV2 决策树与双缓冲的 KernelND2NZMM 完成，CVP 路径实现 AIC 算、AIV 搬的真并行。结尾对比了 ops-nn 与 ops-transformer 两套 tiling_base 的平行实现（同一套七步框架）。
