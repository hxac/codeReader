本讲讲解自定义算子的图模式适配：csrc 管即时执行（eager），converter 管图执行（graph mode），两者共用同一 torch 算子签名；torch.compile 捕获 FX 图后由 torchair 转成 GE 图（fx2ge 流水线），自定义算子必须自带 converter 才能进图，否则 graph break 回退 eager。converter 以「算子 + overload」为键，经 register_fx_node_ge_converter 装饰器注册进 torchair 转换表，靠包 `__init__.py` 的 import 副作用生效，文件存在不等于已注册；形参须与 ops_def 的 schema 逐一对齐，尾参固定为 meta_outputs。函数体用 torchair.ge.custom_op 三件套：张量入 inputs、标量以 attr.Int/Float/Str/Bool 包成 attrs、outputs 与 torch 返回元组对应。变体涵盖 dtype_promote、int4 预处理子图、多输出裁剪、无张量输入时把 SOC/流信息烤进 attrs，以及 aclgraph 静态 workspace 替换。现状盘点：7 份 converter 仅 6 份被激活，declare_supported 支持范围声明只 import 未调用——「有 csrc 不等于有图模式」。
