本讲四个最小模块：一阶段回退、两阶段回退、错误码规范、日志体系。回退（fallback）是算子在 AICore kernel 之外注册的 host 侧执行路径：host 执行函数把图引擎的 gert::Tensor 转成 acl 描述符，借道 aclnn 两段式接口下发，使一份 L0 实现同时服务 eager 与图两条路径；注册入口为 OpExecuteFunc，HostInputs 声明哪些输入数据需在 host 侧读取。一阶段宏 EXEC_OPAPI_CMD 在一次调用内完成查符号（自定义 vendors 优先于 CANN 内置库）、参数转换、执行与释放，仓库内 3 个注意力算子接入；两阶段 EXEC_OPAPI_PREPARE_CMD 只做登记托管、执行交框架统一 launch，预置未用。错误处理分层：op_api 层用 OP_LOGE 与 CHECK_RET，区分参数错（PARAM_*）与内部错（INNER_*）；op_host tiling 层用 OP_CHECK_IF 与 OPS_REPORT_VECTOR/CUBE_INNER_ERR 统一上报 E89999/E69999；OP_LOGE 为同名宏，两层首参含义不同。日志分 D/I/W/E 级，OPS_LOG_E 打日志兼报 EZ9999，DEVICE_OP_TILING_LIB 宏切换 host/设备双实现，op_kernel 层完全无日志。
