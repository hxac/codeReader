本讲打通 inference/ascendc 的编译安装全链路。环境侧：预置 Docker 镜像内含 CANN 开发套件（toolkit）与毕昇编译器 bisheng，进容器后 source set_env.sh 注入环境变量，build.sh 启动即自检 bisheng 并按优先级探测 CANN 路径。build.sh 本质是参数翻译器：-c（目标 SOC 版本，默认 ascend910_93）、-n、--tiling_key、-u 被逐个转成 ASCEND_COMPUTE_UNIT、ASCEND_OP_NAME 等 CMake 变量拼入 CUSTOM_OPTION，再分派到全量 run 包、host/kernel 裁剪、UT 等构建分支；CMake 侧用 GLOB 收集算子目录并按 -n 过滤（op_add_subdirectory），配置阶段经 prepare.sh 起内层 CMake 预生成 autogen 与 aclnn 代码。产物为三个动态库——cust_opapi.so（aclnn 接口）、cust_opsproto_rt2.0.so（算子原型）、cust_opmaster_rt2.0.so（tiling 实现），统一安装到 vendors/omni_custom_transformer/ 下，由 CPack 加 makeself 打成 CANN-omni_custom_ops-*.run 自解压包。安装即把 run 包释放到 opp/vendors/ 再 source set_env.bash 生效，version.info、install.sh 均为构建产物；顺序为先装 run 包、后装 wheel 包。
