本讲深入公共 Tiling 框架的三块机制。其一，模板轮询：一个算子的多个 tiling 类按 priority 升序排成责任链，由 DoTiling 的三态返回值驱动——GRAPH_PARAM_INVALID 表示“本模板不支持”并交棒下一优先级，成功与失败均立即终止轮询，不支持误写成失败会挡死全链；注册靠 static 全局对象在 .so 加载期自动完成，同 priority 禁止重复，ops-nn 与 attention 族另各有注册表。范本 kv_rms_norm_rope_cache 以 DS、D 全载、二分重算三级模板链，靠 isRegbase_ 与 UB 预算两级交棒。其二，TilingKey 编码分 GET_TILINGKEY 十进制按位拼装（10^19 偏移防撞车）与手工分段两派，host 侧「算子名_key」TilingData 注册名与 kernel 侧 TILING_KEY_IS 构成数字镜像契约，多个 key 可共用一份 TilingData。其三，ops-nn 的 TilingCache＋MurmurHash（哈希初筛、全量比对防冲突、读写锁、500 条上限）为预留基建且暂无调用点，matmul 实际经 TilingParse 委托 legacy 公共库的调优缓存。
