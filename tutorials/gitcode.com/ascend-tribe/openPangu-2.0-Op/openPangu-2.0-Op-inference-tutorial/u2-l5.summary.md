本讲覆盖三个最小模块：InferShape 函数、proto 定义、shape 测试。核心结论：InferShape 是 op_host 层可选的静态推导函数，供图引擎在构图阶段静态推算输出 shape 与 dtype；aclnn 直调场景输出形状由调用方给出，故仓库 18 个算子目录仅 11 个注册 IMPL_OP_INFERSHAPE。套路是取输入 shape、判空、推导后用 SetDimNum/SetDim 写回，配套 InferDataType 可写死或继承输入，以 OpDef 类名为键注册——类名也是 def 与推导实现的关联键。`*_proto.cpp` 与 `*_infershape.cpp` 本质相同（proto 为旧称），都编入 opsproto 目标；def 的输入输出声明顺序必须与 proto 索引常量严格对齐。复杂推导以 matmul 公共库为教材：广播、转置属性、未知维度 -1/-2 短路与 InferShapeRange 区间交集。shape 测试可零硬件运行：InfershapeContextPara 给输入真形状、输出留空，ExecuteTestCase 查 OpImpl 注册表直调断言。
