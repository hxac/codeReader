本讲精读 MoE 路由分发算子 ai_infra_moe_init_routing_v3，它是「模式组合爆炸」的典型：非量化/静态/动态量化 × GATHER/SCATTER × DropLess/DropPad × 单核/多核排序等维度组合出 30 余个 kernel 头文件。三大模块：一是 SOC 配置——op_host/config/<soc>/ 下的 binary.json（预编译二进制清单，本算子 7 条 dtype 组合，bin_filename 带内容哈希）与 simplified_key.ini（控制 opc 的 --simplified_key_mode），由构建系统消费实现多芯片二进制分发；二是 TilingKey 位段编码——host 侧单一 tiling 模板类将模式组合编为 uint64（10^6 + sortMode×10^5 + (quantMode+1)×10^4 + rowIdxType×10^3 + dropPadMode×10^2），另有空张量、全载、性能打点等快车道 key，kernel 侧用 TILING_KEY_IS 宏链式分发，两侧数值硬编码镜像、靠 UT 断言兜底；三是 kernel 模板族——按排序/计数排序/全载/统计/搬运分族，用 C++ 模板参数正交展开变体，int8 输入经 if constexpr 剪枝。核心纪律：host 与 kernel 的二级谓词（如计数排序判定）必须同步修改，动态量化 DropPad 场景由 MoeV3SrcToDstAndGather 融合映射与搬运。
