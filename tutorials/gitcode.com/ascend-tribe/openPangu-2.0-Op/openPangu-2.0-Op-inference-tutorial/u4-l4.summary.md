本讲讲解线性注意力（Gated Delta Net）推理流水线的三个配套算子。核心结论：ai_infra_fused_causal_conv1d 的本质是缓存状态机而非卷积——conv_states 原地读写（aclnn 层须 CreateView），stateLen = K-1+m 兼顾滑窗历史与投机解码候选，cache_indices 为二维即开启 APC 前缀缓存；Host 侧以 TilingKey 路由 prefill/decode 路径，文档称不支持的 run_mode 实为路由开关。ai_infra_chunk_gated_delta_rule_recurrence 只做块间串行递推：单 chunk 内 Cube 核三次矩阵乘与 Vector 核衰减/相减经 CrossCoreSetFlag 接力，gexp 仅取每块末值，initial_state 原地更新；其 TilingData 为手写 8 字段 POD，enableMSplit 做运行期分派。lower_triangular_inverse 承担块内解耦，尺寸集合与 chunk_size 一致。验证新算子的标准方法是 example 脚本的 NPU/CPU 对拍。
