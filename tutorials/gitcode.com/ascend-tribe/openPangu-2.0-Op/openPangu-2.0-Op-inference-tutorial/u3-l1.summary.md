本讲讲解 csrc 适配层的算子注册机制：先在 ops_def_registration.cpp 的 TORCH_LIBRARY_FRAGMENT 块用 m.def 集中声明所有算子签名（schema），再在各算子 csrc 文件用 TORCH_LIBRARY_IMPL 把实现挂到调度键上，「先定义、后实现」两步缺一不可。schema 语法涵盖 Tensor/Tensor?/Tensor(a!) 等参数类型及对应 C++ 形参、默认值、`*` 后仅限关键字传参、多返回值与 `-> ()` 原地版。每个算子挂两个调度键：PrivateUse1 为 NPU 真算，构输出后经 EXEC_NPU_CMD_V1 调 aclnn 接口；Meta 只推形状不计算，服务 meta 设备与图编译期推导。原地与非原地算子共用同一 aclnn 接口，非原地语义靠 csrc 层 clone；新算子 csrc 文件须按约定目录层级放置才会被 setup.py 自动收集。EXEC_NPU_CMD_V1 宏的内部机制留待下一讲 u3-l2 展开。
