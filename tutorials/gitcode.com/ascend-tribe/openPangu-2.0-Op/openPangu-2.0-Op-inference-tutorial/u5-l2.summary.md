本讲讲解昇腾多核合跑一个算子的并行机制，以 FIA Sink 与 MHC sandwich 为样本。四个模块：（1）AIV/AIC 分工：FIA Sink 以 KERNEL_TYPE_MIX_AIC_1_2 混合核启动，Cube 核（AIC）负责 Mmad 矩阵乘并使用 L1/L0 私有存储，Vector 核（AIV）负责 softmax/规约并只用 UB，两类核经 GM workspace 交换数据，分工封装为三个 Block 服务；（2）跨核同步：CrossCoreSetFlag/CrossCoreWaitFlag 实现任务内 mm1→vec1→mm2→vec2 四级乒乓接力，信号挂在 PIPE_FIX/PIPE_MTE3 之后保证数据先落地，ExecuteTask 用深度 3 的软件流水掩盖两类核空转；（3）FlashDecode：decode 场景把并行维度从任务数切到 KV 序列，各核产出局部输出与统计量，规约阶段纯 AIV 按在线 softmax 公式跨分片合并，无跨核信号；（4）MHC dualcore 对照：两颗 AIV 按 head 对半分工，经 GM workspace 与 sense-reversing 自旋屏障交换部分和，以冗余计算换零同步。两条路线分别代表「数据流水」与「数据交换」两种多核协同范式。
