本讲拆解推理镜像的分层构建。L1（Dockerfile.base，设备层）回答「昇腾程序能不能跑」：源码编译 Python，安装 torch/torch_npu 与 CANN，并把 Ascend 环境变量写入 bashrc；L2（Dockerfile.omniinfer，应用层）回答「推理服务在不在」：以空设备模式（VLLM_TARGET_DEVICE=empty）安装 vLLM 壳，构建 omniinfer 主仓的 omni-npu/omni-proxy，注入自定义算子，入口为 start_server.sh。两级镜像由编排脚本 docker_build_run.sh 以 --build-arg BASE_IMAGE 衔接，Dockerfile 自身不感知 L1；分层动机是按变更频率复用，L1 稳定沉淀、L2 分钟级重建。关键概念：CANN 安装分 whole 整包与 split 分包两模式；--build-target 取 L1/L2/both/skip；自定义算子注入链为 --custom-ops 路由到 codes 脚本、AscendC 编译 .run 装入 opp/vendors、set_env 写入 bashrc、再装 torch extension 供 torch.ops 调用；--npu-platform 决定算子编译目标。README 与源码多处不一致，应以源码为准。
