本讲确立项目全景：openPangu-2.0-Infer 是一个部署仓，用 ansible 与 docker 在昇腾 NPU（Ascend910C/A3）上以 PD 分离形态部署 openPangu-2.0 系列 MoE 模型，含 Flash（92B，典型 1P1D 两机）与 Pro（505B，典型 2P1D）两种规格，ansible 配置按规格分目录。PD 分离的依据是两阶段资源画像不同：Prefill 计算密集、Decode 访存密集；P 节点任 kv_producer、D 节点任 kv_consumer（由 --role 与 --kv-role 参数区分），KV Cache 经 KV_CONNECTOR（默认 LLMDataDistConnector）跨节点传输；C 节点跑 nginx + proxy 作统一入口（默认 7000 端口，请求 model 字段须匹配 SERVED_MODEL_NAME）。组件职责地图：omni-npu 是 vLLM 的 out-of-tree NPU 平台插件，配合镜像中的 vllm 0.14.0+empty 空壳实现零改 vLLM 源码，属地基；omni-proxy 是请求调度引擎（即 C 节点）；omni-cache 将 KV 从 HBM 卸载到主机内存再传输；omni-eplb（OmniPlacement）做 MoE 专家动态编排。读懂仓库的钥匙是两份顶层 README 与 tools/ansible 下的 inventory 和模板。
