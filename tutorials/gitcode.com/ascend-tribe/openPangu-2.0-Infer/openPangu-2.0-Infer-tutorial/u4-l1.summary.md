本讲义讲 PD 分离部署中 KV 传输的配置面。关键术语：role（prefill/decode，实例职能，供 llmdatadist 组网与 DP 形态判断）与 kv_role（kv_producer/kv_consumer，KV 传输方向，供 vLLM Connector）是两个独立参数；kv-transfer-config 是四字段 JSON（kv_connector、kv_role、kv_rank、kv_parallel_size），前两者为字符串、后两者为数字。核心结论：JSON 由 pd_run.sh 用 heredoc 装配，经 ansible 模板变量、docker exec 环境变量、start_api_servers.py 逐层传到 vllm serve，connector 名须与 omni-npu 注册表逐字符一致，本部署用 LLMDataDistConnector（脚本默认值 AscendHcclConnectorV1 仅兜底）；规模规则为 PREFILL_POD_NUM 等于 P 组不同 host_ip 数，KV_PARALLEL_SIZE = PREFILL_POD_NUM + 1，P 实例 kv_rank 由 inventory 从 0 连续指定、D 侧固定取 PREFILL_POD_NUM，一实例一 rank，端口按 kv_rank×10 推导；部署后以 run_prefill/run_decode 日志的 KV_TRANSFER_CONFIG 回显核对。KV 实际传输机制留待下一讲。
