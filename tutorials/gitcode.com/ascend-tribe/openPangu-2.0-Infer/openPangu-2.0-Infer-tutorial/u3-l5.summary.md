本讲为模型实现精读单元收官，回答「一次 decode 能否算出多个 token」。模块一 MTP 投机解码：draft 层藏在主模型 checkpoint 中（层号 ≥ num_hidden_layers 的 K 个 MTP 层），加载时 target 跳过、draft 收取完成权重分流；draft 层由 enorm/hnorm 归一化、eh_proj 拼接投影、复用主模型 DecoderLayer 的 mtp_block 与 shared_head 组成，embedding 与 lm_head 经 set_shared_weight 共享省显存，层选择按 spec_step_idx % K 轮转；--num-speculative-tokens（k）经 ansible 脚本链变为 speculative_config 传入 vLLM，k 与 MTP 层数是两个独立旋钮。模块二采样器：NPUSamplerV1 以融合算子 npu_top_k_top_p_sample 一步完成 top-k/top-p 截断与采样，随机数在 dsa_stream 旁路流预生成（Gumbel-max 指数竞赛），贪心请求用 1e-6 温度归一进随机路径。模块三拒绝采样：NPURejectionSampler 验证 draft，贪心接受条件为猜中 target argmax，随机为 p(t)/q(t) ≥ u；拒绝后从残差分布 p − q 采样恢复 token，cumprod 实现前缀截断，bonus token 保证每步至少前进一个，三者合力使输出分布与 target 严格一致（无损加速）。
