本讲精读部署链路收口脚本 pd_run.sh：约 40 个长参数按 llmdatadist、昇腾、mock、多 API Server、vLLM、PD 分离六类分拣，经手写 case 解析后三路输出——命令行参数、环境变量、kv-transfer-config JSON；export 段存在硬编码覆盖（VLLM_USE_V1=1）与条件导出（HCCL_BUFFSIZE、ASCEND_RT_VISIBLE_DEVICES），排障以"Current Configuration"回显为准。ranktable（局部/全局两份花名册）供 llm_datadist 组网寻址，pd_run.sh 仅 export 路径与 ROLE、POD_NUM、IP 列表，omni-npu 侧唯一消费点是读 DECODE_POD_NUM 计算 P 侧起始 rank。start_api_servers.py 遵循「一 server 一 DP」：decode 侧 16 个 TP1 server 组成 DP 集群并追加 --data-parallel-rank，prefill 为单 TP16 独立引擎；跨机 D 实例靠 server_offset 修正全局编号（VLLM_DP_RANK=rank+offset/tp）。多机实例凭 NODE_IP_LIST 走 Ray 分支（head 拉起、从节点连集群），最后 bind_cpu.sh 按每 Worker 20 核领地完成绑核收尾。
