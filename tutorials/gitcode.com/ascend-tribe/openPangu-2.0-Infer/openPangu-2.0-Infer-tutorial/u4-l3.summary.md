本讲义从端口视角拆解 P/D 分离部署的通信矩阵。核心结论：系统采用控制面与数据面分离——ZMQ 承载回执与双向心跳（小消息），llm_datadist 走 RoCE 搬运 KV 张量（大流量），两套端口互不重叠。关键术语与结论包括：ZMQ 三种模式（PUSH/PULL、PUB/SUB、IPC），bind 方监听、connect 方发起；D→P 心跳与回执复用 5568 端口（P 的 rank0 监听，以 `decode_hb:` 前缀区分消息），P→D 心跳走 PUB/SUB 15566（由 15567 减 1 推导），P 节点内超时通知走 IPC；心跳间隔 5 秒、超时 60 秒，超时后双向清尸（close_link/force_unlink）。数据面中 P 侧每进程监听 15567+local_rank（TP16 即 15567～15582），D 侧不监听、永远是惰性建链发起方；cluster_id 是 int64 地址牌，按 ip(32位)|port(16位)|tp−1(8位)|pp−1(8位) 编码，P 侧 port 带 15567 偏移、D 侧即全局 rank，用于控制面寻址与 IPC 定位目标 rank。本机 IP 靠 UDP connect 查默认路由发现（多网卡隐患），P 侧 IP 列表按 p_node_list→Ray→本机三级回退，且本形态下 prefill DP 恒为 1。综合实践要求用 ss/netstat 将实际端口与 README 端点矩阵逐行核对。
