本讲是 jointfix 单元收官，打通「BF16 权重 → 量化 → 可部署模型 → 服务」的最后一公里。三个模块：一、compressed-tensors「装箱标准」——config.json 的 quantization_config 声明式描述量化对象、粒度与 ignore 豁免名单，vLLM 据此自动识别，部署零量化参数；二、finalize_model 把逐层中间产物按原模型分片布局组装回可加载模型，未校准权重走 RTN 兜底量化、其余 BF16 透传，ignore 列表由「二维权重全集减实际带 weight_scale 的模块」数据驱动推导，且 finalize 与 quantize 的 skip 标志必须一致，否则 MTP 共享专家会被误量化；三、w8a8 部署模板与 BF16 模板仅差 8 行，全是显存富余兑换的批量、并发与 INT8 KV Cache 参数。
