本讲拆解 jointfix 工具方法层的 JointFix。核心结论：平滑是数学等价变换，联合平滑因子 s=x^a/w^b 在激活与权重两侧二维分配量化难度，由两阶段搜索（反对角粗扫加方框细搜）配“永不劣于不平滑”的安全网求出；目标函数为输出重建 output-recon，以伪量化前向对 BF16 真值输出的 MSE 度量。gate/up 与 down 两组平滑参数相互耦合，用 K=2 坐标下降交替优化，并靠统计量解析刷新免重跑校准。本讲引入的关键术语：吸收拓扑（÷s 吸收进上游、×s 吸收进本层，不量化的路由器与 indexer 须补偿，漏补偿曾致大量路由翻转）、写出双轨（写回残差流的 o_proj/down_proj 用 GPTQ，输入侧用 RTN）、skip 名单与 --skip-shared-experts（共享专家每 token 必经，故留 BF16）、搜索轨迹文件 joint_search_traces.json。产物为 int8 权重加 scale 加 BF16 透传，交下一讲组装部署。
