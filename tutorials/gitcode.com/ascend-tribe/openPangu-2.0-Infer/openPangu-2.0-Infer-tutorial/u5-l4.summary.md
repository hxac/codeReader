本讲讲 token 生成之后、返回客户端之前的输出侧加工，覆盖四个模块。PanguReasoningParser 把原始输出切成 reasoning（思考）与 content（正文），兼容新旧词表双标记（<think>/[unused16] 等），环境变量 PANGU_TOOL_CALL_ENDS_THINKING=1 可开启「工具起始符隐式结束思考」语义，且标记须保留在 content 头部作下游锚点。PanguToolParser 从 <|tool_call_start|>/<|tool_call_end|> 标记对中提取 JSON 数组格式的 tool_calls，流式下用残缺 JSON 增量解析加前缀差分发送参数。_streaming_relay 用 ContextVar 中继抢救 vLLM v0.14.0 在多 token 边界块（MTP-K≥2）丢思考文本的流式 bug。思考控制走 logits 层：thinking_token_budget 超限把 </think> 的 logit 抬至 1e9 强制收场，ban_tool_call_in_thinking 三态状态机在思考中禁工具符、思考后禁重复结束符（-inf），请求级 think=False 只关展示。核心结论：非流式是全文判定树，流式是跨 delta 状态机，两解析器以标记字面量为接口约定，整套机制经 patch_thinking_limit 补丁接入 vLLM。
