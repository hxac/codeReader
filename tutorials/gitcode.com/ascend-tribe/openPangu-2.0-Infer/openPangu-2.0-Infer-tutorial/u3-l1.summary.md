本讲总览 openPangu-2.0（92B/505B）的 vLLM 实现 pangu_v2_moe.py 的骨架。模型为五层积木：OpenPanguV2MLP（稠密 FFN，兼作共享专家）、OpenPanguV2MOE（路由 gate＋共享专家＋融合路由专家）、DecoderLayer（注意力＋FFN＋三明治 RMSNorm＋可选 mHC）、Model（堆层与 PP 切分）、ForCausalLM（lm_head 与权重加载）。层类型以 first_k_dense_replace 为界二选一：前段 Dense、其余 MoE；共享专家整卡复制不切 TP，路由专家按 EP 分卡。模型识别有三条独立链路：AutoConfig/ModelRegistry 架构注册、match_hf_configs.json 超参指纹反查模型规格、is_deepseek_mla 补丁使 vLLM 按 MLA 处理。load_weights 是跳过/合并/专家/普通的四分支路由器，TP/EP 切分由各参数自带的 weight_loader 完成，专家按本卡区间落卡。共享/路由专家、TP/EP/PP、MLA、mHC 残差流、MTP 等概念由 u3-l2～u3-l5 分讲承接。
