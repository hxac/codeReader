本讲以 npu_pangu.py 为主战场拆解 openPangu-2.0 的混合注意力：NPUPanguSparseAttention 按层号把各层判为 SWA、MTP、DSA、MLA 四类，只有 DSA 层（index_topk>0）配 Indexer 与 DSAAttention 封装。Indexer 是一组小线性层（wq_b、wk、k_norm、weights_proj），逐头打分选出 top-k 个历史 token 下标（topk_indices），稀疏注意力只算这些下标加可学习 sink token，复杂度由 O(T²) 降为 O(T·k)。稀疏 FA 的 value 传 dummy 占位源于 MLA 权重吸收：注意力在 latent 空间进行，W_UV 升维推迟到 epilog。DSA 的 KV Cache 分两段：kv_cache[0]（latent+rope，576 维）供主注意力，kv_cache[1]（128 维）供 Indexer，分区支撑 decode 双流并行。算子分三族：torch_npu 内置融合、torch.ops.custom（omni_custom_ops 定制的打分与稀疏 FA）、torch.ops.vllm 自注册不透明包装——mutates_args 留空把副作用藏进算子边界，靠“返回被改张量、下游消费”建 SSA 边防编译器重排写缓存。CrossLayerSharedOp 用固定地址持久缓冲跨层共享 FA tiling 元数据，兼顾去重与 aclgraph 捕获安全。注意力后端注册表 NPU_ATTENTION_BACKEND 存名字到路径字符串，可被 omni.attention_backends entry point 插件同名覆盖，DISABLE_PLUGIN_BACKENDS 为逃生舱。
