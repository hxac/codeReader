本讲承接 PD 分离架构，讲解部署配置。ansible 配置按规格分为 92B（Flash）与 505B（Pro）两个目录，模板文件名编码「拓扑+规格+精度+特性」四要素，与 inventory 自由组合。inventory 用 P/D/C 三组分配角色：kv_rank 给不同 P 实例编号（跨机），node_rank 给同一实例内机器编号，host_ip 指向实例主节点，多机实例据此实现「一实例一端点」；16 卡列表被模板换算为张量并行度。端口为三级体系：proxy 7000 是客户端入口；node_port 8000 段，P 按 kv_rank×10 划块、D 固定 8100；api_port 9000 段供 proxy 转发。拓扑 1P1D/3P1D 为单机 P 实例，2P1D/4P81D16 含多机实例。BF16 与 w8a8 模板仅差批量、GPU 水位与 KV Cache 精度等参数，部署骨架一致；w8a8 权重由 jointfix 量化产出，计算精度仍为 bfloat16。
