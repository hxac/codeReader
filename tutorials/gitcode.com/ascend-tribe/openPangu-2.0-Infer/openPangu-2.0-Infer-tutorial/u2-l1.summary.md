本讲阐释 vLLM 的零侵入（out-of-tree）插件机制：镜像中 vLLM 以空设备后端安装，NPU 能力全部来自 omni-npu 插件。核心概念是 entry points——发现靠包元数据，加载靠「模块：属性」字符串延迟 import。vLLM 约定两个入口组：vllm.platform_plugins 负责平台发现（入口函数须返回平台类路径字符串或 None），vllm.general_plugins 是通用启动钩子。omni-npu 在 pyproject.toml 注册三个入口：omni-npu（plugin() 探测 torch_npu，返回 NPUPlatform 类路径，失败返回 None 让位）、omni_npu_patches（应用运行时补丁）、omni_custom_models（注册 OpenPanguV2ForCausalLM 与 MTP 模型）。NPUPlatform 声明 device_type=npu、HCCL 通信、ASCEND_RT_VISIBLE_DEVICES，并把 worker 类改写为 NPUWorker；部署侧以 VLLM_PLUGINS 逐字点名三个插件。NPUPlatform 方法精读留待 u2-l2，补丁机制留待 u2-l4。
