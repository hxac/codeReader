本讲补齐 DecoderLayer 剩余组件，分三个模块。mHC 残差流：NPUmHC 以 mhc_pre/mhc_sinkhorn/mhc_post 三段式管理 S 条并行残差流，Sinkhorn 归一化把流间混合矩阵约束到近双随机以防深层堆叠后数值爆炸，融合算子按是否 Ascend950 分 torch_npu 与 torch.ops.custom 两族，加载后预乘 phi.weight 与 norm_gamma。算子替换层有两条路线：@register_oot 隐式全局替换（NPURMSNorm、NPUSiluAndMul，触发链为 pre_register_and_update 引发 import layers，漏挂 __init__.py 会静默失效）与模型文件显式 import（NPUVocabParallelEmbedding、NPUParallelLMHead、NPULogitsProcessor）；RMSNorm 用 npu_add_rms_norm 融合「残差相加+归一化」，量化以 {"x_int8","pertoken_scale"} 字典协议贯通 W8A8；FlashCommLinear 家族相对 vLLM 原生 Linear 增加了权重转置、FRACTAL_NZ 布局、按层 x/y 通信变换与权重预取。logits 计算分 TP all-gather 与 DP/local 分片 all_to_all 两条路径，后者补齐到类属性 _dp_pad_n 后用廉价 hidden all_gather 换掉词表维通信大头。方法论结论：新增 NPU 自定义层三件套为实现文件、挂入 layers/__init__.py、mock 式单测。
