本讲精读 NPUPlatform 类，即 omni-npu 对 vLLM 平台抽象层的 NPU 实现，分四个最小模块。设备声明：以 device_type=npu、dispatch_key=PrivateUse1、dist_backend=hccl 等类属性向 vLLM 标识昇腾设备。配置改写：check_and_update_config 将 worker 类替换为 NPUWorker、block_size 未指定时兜底 128、关闭三个 CUDA 融合 pass、整图模式清空 splitting_ops。HCCL 通信：NPUCommunicator 继承 CudaCommunicator 复用进程组簿记，把 all_reduce、all_gather 等集合通信原语转调 torch.distributed（HCCL 后端），变长 all_gatherv 用循环 broadcast 模拟。注意力后端注册表：get_attn_backend_cls 按 use_mla/use_sparse 三分支选出 NPUDSA、NPUMLA 或 VLLM_NPU_ATTN，再查 NPU_ATTENTION_BACKEND 全局字典，第三方插件可经 entry point 同名覆盖内置实现。核心结论：NPUPlatform 是零侵入适配与插件化扩展的中枢，后续讲义将承接 NPUWorker、NPUDSA 后端与图编译等线索。
