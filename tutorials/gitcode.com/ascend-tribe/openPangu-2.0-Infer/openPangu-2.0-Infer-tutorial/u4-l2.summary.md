本讲精读 PD 分离中真正搬运 KV Cache 的 LLMDataDistConnector。它是 vLLM KVConnectorBase_V1 接口的门面类，按 role（SCHEDULER/WORKER）× kv_role（kv_producer/kv_consumer）两个正交维度，把职责分派给 Prefill/Decode 两侧的 Scheduler 与 Worker 四个协作类，名字经 register.py 注册进 vLLM 工厂。P 侧核心是延迟释放：request_finished 把块号、ZMQ 地址与 host_cluster_id 打包成“取件码”（kv_transfer_params）随请求发给 D，收到 D 回执或 600 秒超时才释放块；D 侧是传输主动方：get_num_new_matched_tokens 声明可省算的外部 token 数，start_load_kv 做本地/远端块号对齐后经单线程池异步 pull_blocks，TP 组 barrier 后由 rank0 发回执、get_finished 恢复调度。LLMDataDistManager 统一管理 llm_datadist 会话：cluster_id 是编码 ip/port/tp/pp 的 int64 地址牌，host_cluster_id 带时间戳以识别 P 重启，链路惰性建立（首次拉取才 register_link）；容错三层递进——可重试错误码重试、close+register 重建链路、双向心跳（5 秒发送、60 秒超时 force_unlink）清尸。控制面 ZMQ（回执 5568、心跳 15566、本机 IPC）与数据面 RoCE 15567 零拷贝传输分离。
