本讲收尾 omni-cache 单元，聚焦配置面与运维面。配置全集为七类环境变量加 kv-transfer-config JSON，核心概念「三层默认值」：代码 os.getenv 兜底、文档默认、ansible 模板显式值依次升高，排障以模板 if 分支的 export 与运行日志回显为准；ENABLE_OMNI_CACHE 是总开关，断开即回退原生 LLMDataDist 链路，ENABLE_HOST_MAPPING 控制 D 侧 MMU 直读。大页运维两层脚本分工：set_hugepage_limit.sh 管宿主机内核预留总量，写 sysctl 持久化、杀占用进程、先归零再写目标，可增可减；setup_hugetlbfs_2MB.sh 由模板在容器内自动建池，挂载 hugetlbfs、truncate 后逐页写零，页数只增不减，且特权容器内的改动即宿主机内核改动。切回普通部署三步：重启容器释放大页、执行 set_hugepage_limit.sh --target-pages 262144（约 512GiB）恢复默认预留、以 free 与 HugePages_ 计数验证；NUM_GPU_BLOCKS_OVERRIDE 须小于每层预算按本地 DP 与单 block 字节数摊薄的容量。
