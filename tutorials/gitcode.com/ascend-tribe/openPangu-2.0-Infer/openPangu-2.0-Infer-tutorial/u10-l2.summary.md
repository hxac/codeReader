本讲讲解 omni-npu 组件的测试组织与本地跑测流程：测试树镜像源码树，命名 test_<源文件名>.py，分 unit（mock 验证逻辑契约，无需 NPU 设备但需 torch_npu/vllm 软件包，宜在推理容器跑）与 integration（需真机，靠 NPU_AVAILABLE 探测加 skipif_no_npu 自动跳过）两层，unit/layers/st/ 是需真机的例外；分层依据是被测对象的粒度。pytest.ini 是权威配置（--strict-markers 强制注册标签），按目录筛选比 marker 筛选可靠。两个 conftest.py 筑起防线：顶层猴子补丁过滤 omni.* entry points 以隔离兄弟插件并提供 default_vllm_config fixture，unit 子树使 vLLM 自定义算子注册幂等。run_tests.sh 是统一入口，含 -- 透传 pytest 参数、--durations-out 记录耗时、.coveragerc 覆盖率配置；多容器 CI 把 16 卡主机切成 4 容器，用 pytest-split 按历史耗时分组并行。综合实践示范为指纹匹配函数 parse_hf_config 补最小单测。
