本讲是 jointfix 单元第一讲，只讲工具组织，量化算法精读留给后续。核心概念：W8A8 = 权重 8bit per-output-channel 静态量化 + 激活 8bit per-token 动态量化；jointfix 是面向昇腾 NPU 的 PTQ 工具箱，输入 BF16 模型，输出 vLLM 免 --quantization 直接加载的 compressed-tensors 模型，压缩约 1.9×。架构为三层正交：backends/ 是模型轴（pangu 生产、hf 实验），methods/ 是方法轴，加新模型与加新方法互不影响，core/ 负责校准主循环。registry 模式靠装饰器在 import 时把类注册进模块级字典，--backend/--method 字符串经查表解析成类。CLI 分 quantize（默认一步到底、自动 finalize）与 finalize（组装并对未标定层 RTN 兜底）两个子命令，方法专属参数由方法自己经两遍解析注入 parser。NPU 上必须 --no-deps 安装，否则 pip 会拉 CPU 版 torch 覆盖 torch_npu，废掉 NPU 后端。
