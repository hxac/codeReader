本讲精读 omni-eplb 源码，将 OmniPlacement 专家重排拆为三个最小模块：planner 调度、专家映射、分布式算子。核心结论：重排由 Python 推理主线程与 C++ worker 线程协作——worker 线程周期采集激活、贪心求解新排布并分批搬运权重，主线程每步仅调 place_experts() 收割，二者以原子标志 buf_ready_flag_ 握手，「每卡每批最多一条指令」保证服务不中断。关键术语：逻辑专家与物理专家（冗余槽位）、placement pattern 三维 0/1 矩阵、selector（逻辑→物理，带副本维）与 pos_to_ep（物理→逻辑）两表经共享 NPU 显存热更新、npu_activation_count 零拷贝激活计数、ChangeInstruction（ADD/REMOVE）增量指令、rootinfo 引导的独立 HCCL 通信域、OmniPlanner 元类单例；vLLM 侧经 patch_eplb_parallel 补丁掏空 EplbState，仅保留 step 钩子作为驱动衔接点。
