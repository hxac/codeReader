本讲讲透 omni-npu 的图执行与编译链路。vLLM 的 CUDAGraphMode 与 BatchDescriptor 概念被原样复用，底层以 torch.npu.NPUGraph 实现 ACL Graph。ACLGraphWrapper 按直通、捕获、重放三态工作，以 BatchDescriptor 缓存静态图；注意力算子每步变化的序列长度等动态参数由 graph task 机制在重放后经旁路流刷新。编译路线：NpuGraphExAdaptor 把 FX 图交给 npugraph_ex，开关集中在 npugraph_ex_config；GraphPassManager 注册 NPU 图优化 pass；GE 全图编译（TORCH_COMPILE_GE、torchair、gear 档位，最多六档）是另一条可选路线，生产模板未启用。NPUGraphDispatcher 靠 padding 对齐 token 数、relax 泛化批结构，决定每步走图还是回落 eager。生产部署 P 侧 enforce-eager、D 侧 FULL 图模式，正对应 prefill 形状多变、decode 小而齐的负载特征。
