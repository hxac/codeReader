本讲以 roi_align 家族讲解「组合式算子」：算子无自研 kernel，目录中缺 op_kernel、def 与 tiling，仅保留嵌在 op_host/op_api 下的 aclnn 实现与 L0 封装，核心计算由 CANN 内置 RoiAlign 设备核承担。RoIAlign 语义是把任意大小候选框池化成固定尺寸输出：框坐标乘 spatialScale 映射到特征图坐标系，格子内做双线性插值采样后取 avg/max。V1 第一段接口是登记式流水线：Contiguous、TransData 转 NC1HWC0、Reshape/Cast/ConcatD 拼 (numRois,5) 的 rois、经 l0op::ROIAlign 与 ADD_TO_LAUNCHER_LIST_AICORE 登记内置核、再转回 NCHW 并 ViewCopy 到 out，空输入走 Fill(0) 捷径；L0 封装负责隐形 InferShape 与任务登记。V2 将 batch 索引内联进 boxes(n,5)、以 aligned 推导 roiEndMode。experimental 下的 RoiAlignV2 为自研 Ascend C 双轨实现，tiling 按 ROI「基准+余数」在核间切分；rotated 与 grad 亦全自研，构成「组合复用→自研替代」演进线。关键术语：组合式算子、L0 算子、登记式流水线、双线性插值、spatialScale。
