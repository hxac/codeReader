ops-cv 是 CANN（昇腾 NPU 计算架构）算子库中面向计算机视觉的高阶算子子库，覆盖图像处理（image 类，如 resize_bilinear_v2、grid_sample）与目标检测（objdetect 类，如 roi_align、sorted_nms）两大方向，算子按类别组织在 image/ 和 objdetect/ 两个顶层目录下。本讲引入的关键概念包括：NPU、AI Core 与 AI CPU 计算单元、算子、aclnn API、Atlas 硬件系列（A2 对应 ascend910b、A3 对应 ascend910_93、950 系列对应 ascend950）。核心结论：源码随 CANN 版本配套发布，实际编译运行须用配套 tag 分支而非 master；环境搭建有 CANNLab、Docker、手动安装三条路线，编译态仅需 toolkit 包，运行态还需驱动固件与 ops 包，操作前须 source set_env.sh。文档体系分三层：README 入口、QUICKSTART（以 AddExample 走通“编译→运行→开发→调试→验证”闭环）、docs/README.md 进阶索引（含 install/develop/debug/invocation/context 目录与 op_list.md 算子清单）。运行样例时 --soc 必须与编译一致，否则报 error 161001。
