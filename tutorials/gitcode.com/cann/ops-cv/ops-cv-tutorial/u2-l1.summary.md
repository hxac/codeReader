本讲拆开 aclnn 单算子调用的黑盒，覆盖三个模块。其一，两段式接口规范：第一段 `aclnnXxxGetWorkspaceSize` 做参数校验并产出 workspaceSize 与 `aclOpExecutor`（执行器，封装全部计算流程与输入信息），第二段 `aclnnXxx` 拿 workspace、executor 和 stream 异步下发任务；第二段签名全局统一且不可对同一 executor 重复调用，重算须重走两段。其二，基础数据结构：`aclTensor` 是「描述符 + device 指针」（含 shape、strides、dataType、format），不拥有数据；输出空间由用户预分配；workspace 为算子所需临时内存，为 0 可跳过申请；属性参数（如 `aclFloatArray`、`aclIntArray`）有配对的创建/销毁接口。样例遵循九步骨架：Init → 构造 Tensor/属性 → 第一段 → 申请 workspace → 第二段 → 同步 → D2H 拷回 → 清理 → Finalize，其中 `aclrtSynchronizeStream` 不可省略。其三，初识 op_api 公共层：`aclnn_check.h` 的 `IsRegBase()` 用于芯片架构判断（如 DAV_3510），按架构区分分支。下一讲将切换到实现者视角走读 aclnnResize 的 op_api 源码。
