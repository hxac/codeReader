本讲义建立算子调用的“两类场景 × 三种方式”选型框架：快速调用用 `build.sh --run_example <op> <mode> [pkg_mode]` 一条命令编译运行样例（mode 取 eager/graph，自定义包还需 vendor_name 与 soc）；业务集成需自建 cpp + CMakeLists + run.sh 工程调用 aclnn API，关键分歧在链接对象——自定义算子链 vendors 目录的 `libcust_opapi.so`，内置算子链 `libopapi_cv.so`，静态库模式用 g++ 链三个静态库。第三模块剖析 fast_kernel_launch_example：不走算子包交付链，而是把 Ascend C Kernel 直接编入 PyTorch 扩展 `_C.abi3.so`，核心是“注册四件套”——`TORCH_LIBRARY_FRAGMENT` 声明 schema、Meta 实现推导 shape、`__global__ __aicore__` 核函数、`PrivateUse1` 调度键实现（tiling 加 `<<<numBlocks, nullptr, stream>>>` 核启动，包在 `OpCommand::RunOpApi` 中保证时序一致）；空的 `PyInit__C` 仅靠 import 触发静态注册。选型口诀：验证用快速调用，C++ 业务用 aclnn 自建工程，PyTorch 训推用扩展集成；GE 图模式留待 u2-l4。
