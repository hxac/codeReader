本讲讲解 ONNX/TF 框架插件适配层：它是模型解析器（domi）的一部分，只做「ONNX/TF 节点到 GE 算子」的名字映射与属性翻译，不做任何计算，`ImplyType::TVM` 声明执行交给算子编译框架。插件标准骨架为 `REGISTER_CUSTOM_OP` 链式注册（GE 算子名、FrameworkType、OriginOpType 多 opset 穷举、解析回调），配合 `ParseParamsXxx` 完成属性翻译。关键术语包括 OriginOpType、opset、NodeProto、四种解析回调（ParseParamsFn、ParseParamsByOperatorFn、ParseOpToGraphFn、FusionParseParamsFn）。模块覆盖：`common/inc/framework/onnx_common.h` 四件公共工具（GetOpName/Vec2Tensor/CreateScalar/ChangeFormatFromOnnx）；两级插件源（`common/src/framework` 与算子内 framework 目录）经 `add_onnx_plugin_sources()` 的 GLOB 自动收集进同一 OBJECT 目标并编为 `liboponnx_plugin_<pkg>.so`，需 `--whole-archive` 保留注册代码，TF 插件默认关闭自动收集。进阶样本 roi_align 演示子图改写（三输入转两输入、opset 双注册）与 TF 融合补默认属性；psroi_poolingV2 展示 JSON 属性解析与 NCHW 格式统一。核心结论：插件只翻译不计算，新增插件文件即自动参与编译。
