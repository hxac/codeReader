本讲以 resize_bilinear_v2 为解剖对象，首次贯通算子工程完整链路：op_api 外层 aclnn 接口（参数校验与执行链编排）→ op_api 内层 l0op 封装 → 框架按 OpDef 路由 → op_host 的 infershape 与 tiling → op_kernel 核函数按 TilingKey 分发。核心结论是「第一段登记、第二段执行」：aclnn 层不直接启动 kernel，而是通过 ADD_TO_LAUNCHER_LIST_AICORE 把算子任务登记进 aclOpExecutor，由框架统一下发。引入的关键概念包括：OpDef 算子注册（def 文件声明端口、dtype/format 白名单、属性、opFile.value 绑定 kernel 实现）、L0 算子封装、InferShape/InferDataType（继承输入 shape 后覆盖 H/W 维）、Tiling 两阶段（TilingParse 编译期取核数与 UB、Tiling 运行期选策略并 SetTilingKey/SetBlockDim）、TILING_KEY_IS 按 ключ 分发到策略模板类，以及登记属性↔def 属性、同名 TilingKey 常量、TilingData↔GET_TILING_DATA 三组 Host-Device 跨侧约定。本讲为 u3-l2、u3-l3、u4-l1、u4-l2 的逐层深读提供全景地图。
