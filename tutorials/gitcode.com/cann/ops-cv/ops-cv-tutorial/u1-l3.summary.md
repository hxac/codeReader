本讲走读 ops-cv 仓的编译体系：build.sh 是薄入口，通过 source 加载 scripts/ 下 8 个子脚本（build_conf、build_options、build_cmake、build_lib 等），由 main() 按开关依次调度参数解析、CMake 配置、编库、编二进制、打包、UT 等阶段。参数经 checkopts 解析并做互斥校验（如 --pkg 与 -u 互斥），再由 assemble_cmake_args 翻译为 CMake 变量：--ops 转 ASCEND_OP_NAME（逗号变分号）、--soc 转 ASCEND_COMPUTE_UNIT（白名单校验），每次配置前清 CMakeCache.txt。根 CMakeLists.txt 用 option 开关接收变量，cmake/ 目录分工明确：variables.cmake 定义编译范围（NEED_COMPILE_OPS 与 COMPILED_OPS 对账）、安装路径与 AICPU_INCLUDE；opbuild.cmake 调 op_build 工具从 *_def.cpp 生成 aclnn 接口代码；gen_ops_info.cmake 为全部芯片生成算子信息、只为目标芯片编二进制。本讲重点引入 HOSTCPU 常量折叠编译开关：add_all_modules_sources 新增 HOSTCPU 参数与 add_aicpu_host_kernel_modules 函数，在 built-in 整包且算子显式开启时把 AiCPU 源码额外编译为 x86 OBJECT（定义 OPS_CV_AICPU_HOST_KERNEL 宏），最终链接成 libopconstant_folding_cv.so 供图引擎 host 侧常量折叠；目前尚无算子接入，属框架地基。实践环节完成以 add_example 为例的单算子编译与产物（autogen、tbe、build_out 的 run 包）验证。
