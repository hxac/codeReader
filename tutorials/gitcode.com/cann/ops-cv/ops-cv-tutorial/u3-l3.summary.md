本讲以 add_example 为例精读运行期 TilingFunc 的实现。核心结论：Tiling 是 Host 侧在 aclnn 第一段接口阶段提前算好的「分工方案」——核间并行由 blockFactor 与 SetBlockDim 决定（CeilDiv 二次收缩 usedCoreNum 避免空核），核内分批由 ubFactor 决定（UB 容量 ÷ 元素大小 ÷ buffer 块数再 FloorAlign 对齐，AddExample 因 2 输入 1 输出 × double buffer 故除以 6）。TilingFunc 标准四步：取平台信息（核数/UB）、解析 shape 与 dtype 校验、申报 workspace（此处为 0）、填充 TilingData 并设 BlockDim 与 TilingKey，经 IMPL_OP_OPTILING 注册。TilingData 是 Host/Kernel 共享同一头文件定义的纯数据契约，kernel 侧经 REGISTER_TILING_DEFAULT 与 GET_TILING_DATA_WITH_STRUCT 解包，末核尾块由 remainderLength 自行处理。TilingKey（按 dtype 设 0/1）用于选择 kernel 实现分支，是 u3-l4 多策略机制的伏笔。公共层 TilingBaseClass 把流程模板化为 8 个钩子，返回三态支持多候选降级，add_example 的自由函数写法是其简化同构。
