本讲以 add_example 为例精读运行期 TilingFunc，拆成四个模块：注册链路、TilingFunc 四步实现、TilingData 跨侧传递、公共层 TilingBaseClass 框架。核心结论：Tiling 是 Host 侧提前算好的切分决策——核间并行由 blockFactor 与 SetBlockDim 决定（usedCoreNum 需用 CeilDiv 重算以收缩空核），核内分批由 ubFactor 决定（UB 容量除以元素大小与 buffer 块数再向下对齐；double buffer 使 3 个队列翻倍为 6 块）。TilingFunc 标准步骤为取平台信息→解析 shape/dtype→申报 workspace→填充 TilingData→设 BlockDim 与 TilingKey，经 IMPL_OP_OPTILING 注册。TilingData 是 Host/Device 共享同一头文件的纯数据契约，kernel 用 GET_TILING_DATA_WITH_STRUCT 解包，末核尾块由 remainderLength 自行处理。TilingKey 按 dtype 区分实现分支（float=0/int32=1），为 u3-l4 多策略机制伏笔；公共层 TilingBaseClass 把流程模板化为 8 个钩子，三态返回值支持多候选降级。关键术语：AIV、UB、GM、BlockDim、TilingKey、blockFactor、ubFactor、CeilDiv/FloorAlign、double buffer。
