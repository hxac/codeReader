本讲以仓库自带教学算子 AddExample（y = x1 + x2）为对象，打通 QUICKSTART 第一阶段「编译→安装→运行」闭环：用 build.sh --pkg --soc --ops 编出自解压 run 包，安装到 opp/vendors 目录，导出 LD_LIBRARY_PATH 指向算子包 op_api/lib，再用 build.sh --run_example 跑样例。核心结论：编译与运行的 --soc 必须一致，否则在第一段接口报 error 161001；只改样例代码无需重编算子包。引入的关键术语：两段式接口（GetWorkspaceSize 负责校验、生成 aclOpExecutor 并告知 workspace 大小；aclnnXxx 异步下发到 stream，需 aclrtSynchronizeStream 同步）、九步样例骨架（Init→构造 aclTensor→两段调用→同步→D2H 拷回→清理）、图模式 geir（REG_OP 原型注册、op::AddExample 建节点、Session::AddGraph/RunGraph 同步整图执行，结果落盘 bin 文件）、soc_version 取值对照，以及 README 参数表、样例构造与 proto 原型三者的契约对应关系。下一讲（u2-l1）将精读 aclnn op_api 实现原理。
