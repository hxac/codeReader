本讲讲解 op_host 侧的 InferShape/InferDataType 机制：推导函数经 `IMPL_OP_INFERSHAPE(算子名)` 宏注册（挂 `.InferShape` 与 `.InferDataType`），在 kernel 执行前由框架回调，通过 `gert::InferShapeContext` / `gert::InferDataTypeContext` 完成读写。核心模块包括：add_example 的最简直通模式（输出 shape/dtype 逐项复制输入）；resize_bilinear_v2 的按值推导模式（用 `Ops::Cv::IsConstTensor` 判断常量输入 `size`，读其值覆盖输出 H/W，需 def 文件 `ValueDepend` 配合注册处 `InputsDataDependency`）；dtype 推导的两类规则（直通继承 vs 由 `dtype` 属性驱动、默认 float32 并校验输入/输出组合合法性）。关键结论：动态维度用 `UNKNOWN_DIM`(-1)、UnknownRank(-2) 整体置 -1 且视为推导成功；aclnnResize 的 `scales` 参数在 aclnn 层按 `⌊inDim×scale⌋` 截断换算为 int32 `size` 常量张量后再进入推导，def 中的 scales 属性仅为兼容保留。下一讲 u3-l3 将进入 Tiling 机制。
