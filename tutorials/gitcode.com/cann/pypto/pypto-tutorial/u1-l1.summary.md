PyPTO 是华为 CANN 面向 Ascend 等 AI 加速器的高性能编程框架：开发者以声明式 Tensor 运算描述算子，框架经多层 IR 编译自动完成切分、搬运与调度。架构分用户接口、图编译、代码生成、调度执行四层；核心编译链路为 Tensor Graph → Tile Graph → Block Graph → Execution Graph → PTO 虚拟指令 → 平台代码，各层由一组 Pass 变换，上层硬件无关以保留优化空间，下层贴近硬件兑现性能。PTO 范式四要点为 Tensor 级抽象、声明式编程、基于 Tile 的计算、计算图驱动；Tile 是恰好放进核内私有缓存（UB/L1）的子张量；当前版本仅开放 Tensor 层次编程，Tiling 由框架自动完成，编程模板为 @pypto.jit 装饰、Tensor 类型标注与 out[:] 写回。设备侧按 MPMD（依赖驱动的多程序多数据）模型执行，避免 SPMD 式全局同步。本讲还引入 IR、Pass、JIT、CodeGen、Tensor Op/Tile Op、View/Assemble、SymbolicScalar 等术语，并以 README、hello_world 示例与源码目录验证了文档与代码的对应关系。
