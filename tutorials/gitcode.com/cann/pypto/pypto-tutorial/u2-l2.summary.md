本讲梳理 PyPTO 的算子 API 体系：op 目录按算子类别分文件组织，顶层 `pypto.xxx` 仅是门面转发；`op_wrapper` 装饰器统一互转 Python 门面对象与 C++ base，op 函数本身不做计算，只在计算图上落一个 `pypto_impl` 节点。三类核心算子：逐元素算子把标量包成 `Element` 常量节点，`precision_type` 在快与准间权衡；归约算子统一 `dim/keepdim` 签名，输出 shape 由 host 侧自备；矩阵乘 `out_dtype` 必填、按维数分派 Matmul/BatchMatmul，K 维在编译期校验，`extend_params` 可把 bias/relu 融合进同一 Cube 节点。融合算子即在单个 jit kernel 内组合多个图算子、中间结果不落全局内存；官方文档可能滞后，算子签名以源码为准。
