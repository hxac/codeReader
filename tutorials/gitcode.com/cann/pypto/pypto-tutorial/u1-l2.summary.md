本讲解决 PyPTO 环境搭建与运行首个算子。环境分三层：驱动固件、CANN 软件层（toolkit 属编译态依赖、ops 属运行态依赖）、Python 与编译工具；按有无真机选 CANNLab、Docker 或手动安装；CANN 9.1.0 起已内置 PyPTO，源码编译则用 build_ci.py 产出 run 包再安装。hello_world 示例确立算子三要素：@pypto.jit 装饰器（首次调用触发 JIT 编译）、Tensor[...] 类型标注（自动推断 shape/dtype）、out[:] 写回语法（内核不支持返回值），并以 set_vec_tile_shapes 声明 tile 形状，框架按 tile 自动切分数据。运行模式分 RunMode.NPU（真机执行，需 torch_npu，用 TILE_FWK_DEVICE_ID 选卡）与 RunMode.SIM（主机侧仿真，无需真机），算子代码对模式无感知，仅 runtime_options 不同；运行成功后 output/ 目录生成计算图与泳道图产物。
