本讲以 add 算子为例讲授算子规格文档的阅读方法，分三个最小模块：算子 README、产品支持表、aclnn 接口文档。核心结论：仓内每个算子的 README 结构统一，固定包含产品支持情况、功能说明（计算公式）、参数说明、调用说明四板块，会读一个即会读所有；「算子级支持」与「aclnn 接口级支持」是两层独立规格，可能不一致（如 add 算子级支持 310p 而 aclnnAdd 接口不支持），使用前须两层表都查，并留意接口文档中按型号动态渲染的特例注释。关键术语：算子 README 四板块、算子级/接口级支持、aclnn 两段式接口（GetWorkspaceSize + 执行段）、Inplace/Scalar/V 版本接口变体（V 版本选最高）、错误码 161001（空指针）与 161002（参数非法）、类型互推导规则表（类似 PyTorch Type Promotion，如 FLOAT16+FLOAT→FLOAT，×组合直接报错）、broadcast 约束与 8 维上限、非连续 Tensor 支持。README 公式描述算子本质（y=x1+x2），接口文档描述 API 完整语义（out=self+alpha×other）。查接口入口为 op_api_list.md 总表。下一讲 u2-l2 将进入 add_def.cpp 的 OpDef DSL 注册。
