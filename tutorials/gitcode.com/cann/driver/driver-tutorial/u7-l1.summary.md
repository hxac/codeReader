本讲聚焦昇腾 HAL 层的 RoCE 模块，讲解在 rdma-core 基础上裁剪定制出的 **RDMA Lite** 用户态驱动。核心思路是把通信拆为**控制面**与**数据面**：Device 侧固件已建好 QP/CQ/doorbell 内存，控制面通过 HAL 的 `halHostRegister` 把这些 Device 虚拟地址（DVA）映射成 Host 虚拟地址（HVA），在 Host 侧重建「影子上下文」；数据面则由 Host 直接把 Work Request（WR）翻译成硬件 Work Queue Element（WQE）写入映射缓冲、写 doorbell、再靠 owner 位轮询 CQE——全程不陷内核、不经 verbs 重路径，从而在高频小消息场景下超越标准 verbs。关键术语包括 QP（含发送队列 SQ、接收队列 RQ）、CQ、doorbell、属性快照、ops 函数指针表门面。`rdma_lite.c` 为纯转发门面，靠 `struct rdma_lite_ops` 表把接口与 HNS 硬件实现解耦；`roce_hal_api` 提供 NUMA 感知缓冲、预留内存两阶段 populate 与 `phy_id→devid` 桥接，是 RoCE 接入 HAL/UDA 体系的落点。Lite 驱动编译为 `libascend_rdma_lite.so` 并链接 HAL，集合通信通过组合下发 WR 实现高级算子。
