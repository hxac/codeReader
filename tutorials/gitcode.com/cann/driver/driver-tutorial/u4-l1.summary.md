SVM（共享虚拟内存）是 HAL 层设备侧内存管理模块，为上层 Runtime 提供申请/释放/拷贝/共享等 hal* 接口，核心套路是「先预留虚拟地址段、再 mmap 映射、再进内核申请物理页」。SVM 按 `build.sh --soc` 二选一编译 v2（ascend910B）与 v3（ascend950），同一公共接口 halMemAgentOpen 背后是两套实现；v3 把 v2 集中式大文件拆成按职责分层、靠注册表协作的架构。初始化分两层：svm_master_init 做进程级一次性初始化（双检锁守护、打开 Host 设备）；svm_device_open 做每设备初始化（幂等打开、dev_status 守护）。Host↔Device 通道是字符设备 /dev/davinci_manager + ioctl，svm_ioctl_dev_init 经 UDA 翻译设备号、打开字符设备、ioctl 陷入内核，再回调各子模块自注册的 post-init。关键术语：halMemAgentOpen、svm_master_init、svm_ioctl_dev_init、Host 设备、post-init 回调表、DEVMM_SVM_MEM_START、DAVINCI_INTF_IOCTL_OPEN。
