HDC（Host-Device Communication）是昇腾驱动栈中 HAL/SDK 各模块（DSMI、DMC、prof、Runtime 等）共用的通信底座，一套 API 同时支持 PCIe、Socket、UB 三种链路。其核心由 client/server/core/epoll 四个公共骨架组成：client 与 server 是同一通信原语的两个朝向，分管会话生命周期（建链 `halHdcSessionConnectEx`、接受 `drvHdcSessionAccept`、关闭），管理带柔性数组的 `hdc_client_head`/`hdc_server_head` 容器；core 承担库自动初始化（`__attribute__((constructor))`）、消息描述符 `drvHdcMsg` 管理与阻塞式 `halHdcSend`/`halHdcRecv`。链路可插拔依赖全局配置 `g_hdcConfig` 的 `trans_type`/`h2d_type` 两开关做分发，所有用户态操作最终经 `hdc_ioctl` + `union hdcdrv_cmd` 陷入内核 `drv_hdcdrv.ko` 到达设备，这是唯一的用户态→设备通道。关键术语包括：以 `HDC_SESSION`/`sockfd`（实为内核会话编号）为收发句柄、`HDC_MAGIC_WORD` 做句柄校验、`serviceType` 区分业务频道并以 `HDC_SERVICE_LEVEL_0/1` 做 QoS 分级、epoll 通过 `hdc_epoll_ops` 虚表实现事件驱动收发（只通知就绪、取数据仍靠 recv）。
