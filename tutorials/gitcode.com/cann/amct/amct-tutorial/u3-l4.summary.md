本讲围绕 `amct_pytorch/quantization/bit_policy.py` 的 `BitPolicy` 展开，它是 `--bit_config` yaml 加载到内存后的「位宽策略查询服务」，只负责查位宽和校验配置，不做量化本身。

核心数据约定：位宽只有 `_ALLOWED_BITS = (4,8,16)` 三种取值，16 表示不量化；每个 Linear 层的位宽是成对的 `(w_bits, a_bits)`，分别对应权重和激活。yaml 结构为「顶层全局默认 → 分组（attn-linear/mlp/moe 三个 `_LINEAR_GROUPS`，用 w/a 对；attn-cache 单独的 `_CACHE_GROUP`，用单值）→ 子分组（moe.routed/shared）→ 叶子（真实层名）」。

三层校验：结构（顶层必须 dict）、取值（叶子必须是 int 且∈{4,8,16}，用 `type is int` 拒绝 bool/str）、完整性（任意嵌套节点提到 w/a 之一就必须成对）。缺省位宽恒为 16，故空配置等价于全 fp16 基线。

`linear_bits(name, group)` 是算法核心：沿 dotted 路径向下收集真实存在的节点构成 chain，再逆序向上回退，返回第一个 w/a 成对完整的节点，否则回退顶层；由此支持「组级默认 + 叶子覆盖」混用。`_GroupBits` 是绑定 group 的下标代理，让下游用 `bp["mlp"]["down_proj"].w` 自然取值，最终在 `QuantGatedMLP` 中把 `(w,a)` 分别喂给 `QuantLinear` 与 `ActivationQuantizer`。`ensure_bit_policy` 提供无 yaml 时用零散 `--w_bits/--q_bits` 拼配置的兜底。关键术语：BitPolicy、LayerBits、_GroupBits、linear_bits 回退、attn-cache 单值、ensure_bit_policy。
