本讲是 AMCT 开篇，仅建立全局认知，不涉及命令与源码实现。AMCT 全称 Ascend Model Compression Toolkit，即昇腾模型压缩工具包，是昇腾 NPU 原生的模型量化压缩工具。其部署链路为三段式：浮点模型 → AMCT 量化 → 昇腾 NPU 低比特推理，AMCT 只负责中间的压缩环节。三大亮点为硬件亲和、多精度全栈、大模型就绪。本讲引入的关键术语包括量化、推理、NPU/昇腾、CANN、PTQ/QAT、LLM。支持五种精度格式 INT8/INT4/MXFP8/MXFP4/HiFloat8，体积收益仅由 bit 数决定：8-bit 系列相对 16-bit 浮点 ↓50%，4-bit 系列 ↓75%。量化范围分 W（仅权重，缓解带宽瓶颈）与 W+A（全量化，追求算力），各有配套算法。仓库代码分两大块：amct_pytorch（核心量化源码）与 amct_ops（独立 NPU 自定义算子层，Ascend C kernel 实现），二者职责分离。
