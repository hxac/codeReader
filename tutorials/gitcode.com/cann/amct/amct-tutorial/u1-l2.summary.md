本讲把 AMCT 量化链路落地为可执行命令，覆盖四个最小模块：运行依赖、build.sh 构建选项与产物、setup.py 打包机制、requirements.txt 依赖清单。核心结论：环境分系统级（bash/GCC/CMake/Python）与昇腾级（CANN 与驱动固件）两层，须区分「编译态」（仅需 CANN Toolkit）与「运行态」（驱动+固件+Toolkit+Ops 必备）；NPU 场景反直觉地要求装 CPU 版 torch（2.7.1+cpu）配 torch_npu，否则加速器冲突。裸跑 build.sh 不产出分发包，须带 --torch/--pkg/-u 之一；--torch 产物为 amct_pytorch-<version>-py3-none-<platform>.tar.gz，版本读自 amct_pytorch/.version，平台串由 CMAKE_HOST_SYSTEM_PROCESSOR 注入；--experimental 经 build.sh → cmake -D → 环境变量 → setup.py 四跳决定是否打包试验目录。关键术语：编译态/运行态、CANN（Toolkit/Ops）、CPU 版 PyTorch、torch_npu、分发包(sdist)、双版本口径（version.info 9.0.0 与 .version 1.1.0）。
