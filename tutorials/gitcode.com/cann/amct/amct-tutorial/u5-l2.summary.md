本讲讲清 AMCT 如何用一套 PTQ 主流程支持十余个模型：所有适配器继承模板方法基类 BaseModel，用 `@MODEL_REGISTRY.register(name, family)` 装饰器靠 import 副作用登记进全局 `MODEL_REGISTRY`，工作流用 `MODEL_REGISTRY.get(model_name)` 路由到具体类——新增模型只动适配器、主流程不改。`--model_name` 填注册键（如 qwen3_5、hy_v3），非模型路径且无归一化。13 个适配器分 deepseek/longcat/qwen/glm/hyv3 五家族，dense（quant_target=mlp）与 MoE（=moe）成对出现。适配器分两层覆写：必须覆写的插槽 `__init__` 四件套、`get_layer_weight_prefix`、`build_quant_block`、`parse_quant_mode`；按需覆写的扩展点 `attn_norm_name`、`load_layer_weight`、`iter_deploy_bindings`、`_embed_base_prefix`。Qwen3 是最薄 dense 模板。MoE 公共件 `moe_common.py`（QuantGatedExperts 包装专家量化视图、pack_gated_expert_weights 堆叠门控专家权重）被多家族复用，MoE 适配器须重写 deploy 绑定把 `expert_modules.` 中缀映射回 checkpoint 键。复杂案例 HyV3 演示 load 阶段键重映射（remap→pack）与 tensor 粒度 deploy 元数据（generate_tensorwise_quant_layers / bits_scheme）。新变体应优先继承同家族适配器而非从 BaseModel 重写。
