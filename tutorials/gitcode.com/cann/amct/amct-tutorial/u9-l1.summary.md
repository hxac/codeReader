本讲讲清 AMCT Classic 经典压缩流程的运行时机制。`ModelOptimizer` 是与量化无关的通用 pass 编排器，按 `add_pass` 顺序逐个执行 `run(model)`；module 级 pass 均继承 `BaseModuleFusionPass`，复用其「先全量匹配 `match_pattern`、再统一改写 `do_pass`」的两段式框架，用 `setattr` 原地换子模块。量化算子替换分两阶段：`quantize()` 经 `InsertQuantizeModulePass` 把原算子换成伪量化模块（查 `AlgorithmRegistry.algo` 表），中间留白给用户训练算 scale；`convert()` 经 `ReplaceNpuQuantModulePass` 换成 NPU 部署算子（查 `quant_to_deploy` 表），无需 config、由模块属性定 W-only 或 W+A。两表以「伪量化模块类型」为共同 key 衔接两次替换。另有一套基于 ONNX 计算图的 graph_based 工具箱（张量分解/知识蒸馏/通道剪枝），跑在第二个带 `graph` 参数的 `ModelOptimizer` 上，`auto_channel_prune_search` 以 Taylor 一阶敏感度 ‖g⊙w‖₁ 评估通道重要性、以 bitops 估代价、贪心搜索输出剪枝配置。
