本讲是 amct_ops 算子开发的收口课，回答新增 NPU 算子要建哪些目录、写哪些文件、是否改构建脚本、注册到哪个命名空间。核心结论：新增算子第一步是判断范式。直接扩展范式（样板 hifloat8_cast）kernel 自包含编进 .so，目录含 op_kernel 与 op_extension；open project 范式（样板 svd_quant）kernel 经 CANN 工具链编译、host 侧用 aclnn host API 调用，多出 op_host 层写算子 IR 定义与 tiling。构建上，ops_build.sh 的自动发现（扫描 CMakeLists.txt 与 python/<pkg>/）仅对直接扩展范式成立，新算子免改脚本；open project 算子需在 build_op 里硬编码特判，打包走 build_op 编 .so、collect_op 汇进 staging/、根 setup.py 打 wheel 的四步流水线。注册上，所有算子必须注册到唯一的 amct 命名空间，标准四件套为 TORCH_LIBRARY_FRAGMENT 声明 schema、PrivateUse1 挂 NPU 实现、Meta 挂形状推导（torch.compile/图模式必需）、Python load_library 加载 .so。新增算子一律以 README 为准。
