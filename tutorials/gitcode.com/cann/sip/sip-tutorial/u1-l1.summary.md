本讲是 SiP 学习手册第一讲，通过精读 README、官方 overview 文档与头文件库文件说明，建立项目全景地图。核心结论：SiP（AscendSiPBoost，昇腾信号处理加速库）基于昇腾 NPU，深度适配硬件算力、存储与带宽，面向信号处理与 AI 模型两类场景，支持 C++ 直接调用与 PyTorch 适配（sip_pta）。官方自述六大组成：框架、FFT、BLAS、复数基础计算、信号领域融合算子、Solver；部分模块文档标注滞后于代码，学习应以源码为准。引入的关键术语：Host 侧（include 与 core，负责算子管理、tiling、执行计划）与 Device 侧（ops，NPU kernel）分层、ACL 运行时、BLAS 三级接口、asd 接口前缀、asdsip.h 总入口、「句柄→MakePlan→workspace→绑流→执行→同步→销毁」的固定调用套路、AspbStatus 返回码。文档分三层，优先查仓库内 docs 目录。
