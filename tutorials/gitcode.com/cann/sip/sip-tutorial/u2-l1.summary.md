本讲建立 SiP 公开 API 的接口地图：总入口 asdsip.h 是伞形头文件，聚合且仅聚合六个模块头——Base（base_api.h）、BLAS（blas_api.h）、FFT（fft_api.h）、Filter（filter_api.h）、Interpolation（interp_api.h）、Domain（domain/rs_api.h）；是否在聚合清单内是判断公开 API 的唯一标准，blas_common.h 即内部头反例。六模块分两类风格：BLAS/FFT 为有柄风格，遵循句柄→MakePlan→workspace→执行→同步→销毁；Base/Filter/Interpolation/Domain 为直调风格，stream 直接传参，执行函数与 GetWorkspaceSize 成对出现。BLAS 接口名可按首位字母解码：S/C/H/I 分别表示单精度、复数、半精度、返回下标，尾缀 Batched 表批量。依赖梯度上 fft_api.h 最轻（前向声明 aclTensor、extern "C"），blas_api.h 最重（需 aclnn 头路径）。全部接口返回 AspbStatus、张量统一用 aclTensor 指针描述，且六头一库——统一链接 libasdsip.so，libasdsip_core.so 由其自动依赖。该地图是 u2-l2 编程模型及后续模块讲义的公共索引。
