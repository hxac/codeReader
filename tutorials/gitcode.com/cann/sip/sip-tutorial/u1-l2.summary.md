本讲绘制 SiP 仓库源码地图，核心结论：目录划分即架构分层——include 发布公开 API，总入口 asdsip.h 聚合六个模块头文件，接口前缀与模块一一对应；core 是 Host 侧算子管理与执行框架，只调度不做数学；ops 是 Device 侧算子实现，每算子一目录、固定分层。以 Conj 为例梳理五跳调用链：core 组装 OpDesc（算子名加参数结构体）调用 RunAsdOps，Ops 单例按算子名查 Operation，GetBestKernel 选 kernel，tiling 计算切块，AscendC 核函数在 NPU 执行。引入术语：Host/Device 分层、tiling、注册宏 REG_OPERATION/REG_KERNEL_BASE、OpDesc、op_list.yaml 编译清单、公开 API 与内部 API 之别（Conj 属内部接口）。要点：目录只是粗地图，算子名才是精确坐标；tiling 虽在 ops 目录却跑在 Host 上。
