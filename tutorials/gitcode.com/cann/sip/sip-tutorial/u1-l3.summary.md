本讲是手册的动手起点，围绕三个最小模块讲解 SiP 的环境搭建与编译构建。模块一「依赖安装」：依赖分三层——系统工具层由 install_deps.sh 以幂等的「检测-安装-复查」模式安装，且分必需（python/gcc/cmake/git，失败即 exit 1）与可选（pigz/dos2unix/googletest，失败仅告警）两档；Python 层由 requirements.txt（numpy/setuptools/wheel）安装；CANN 层（toolkit 与 ops 包）需手工装 .run 包并 source set_env.sh。模块二「芯片架构配置」：configs/build_config.json 的 targets 开关决定编译哪些架构（默认仅 910b 与 950 为 true），由 build_util.py 的 get_build_target_list() 消费，可用 BUILD_CONFIG_FILE 指自定义文件；不支持的架构必须关闭，否则报 simd_vf 错。核心术语：CANN、ASCEND_HOME_PATH、SoC version、makeself/run 包、ABI、MKI（ascend-boost-comm 平台抽象层）。核心结论：bash build.sh（默认 --dev）流程为参数解析→自动 clone 并编译 MKI 与 catlass→干净目录 cmake+make+install→makeself 打 .run 包；CMake 经 ASCEND_HOME_PATH 找 CANN 头文件与库；产物含 libasdsip.so、libmki.so、version.info 与 .run 安装包；--ut 分支设 TEST_TYPE=UT 并引入 lcov/googletest，是测试体系入口。
