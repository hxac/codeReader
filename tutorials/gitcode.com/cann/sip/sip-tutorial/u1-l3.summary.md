本讲是 SiP 学习手册的动手起点，覆盖三个最小模块：依赖安装、芯片架构配置与 build.sh 编译主流程。核心结论：依赖分三层，install_deps.sh 以「检测、安装、复查」的幂等模式安装系统工具，requirements.txt 管 Python 库，CANN 的 toolkit 与 ops 包须手工安装并 source set_env.sh，其设置的 ASCEND_HOME_PATH 是 CMake 定位 CANN 头文件与库的关键；build_config.json 的架构开关由 build_util.py 的 get_build_target_list() 解析，只决定 Device 侧 kernel 的编译范围，Host 侧架构无关，为不支持的架构编译会因指令集不匹配而失败；build.sh 是总调度，首次编译自动拉取并现场编译 MKI 与 catlass，经 CMake 构建、makeself 打包，产出 libasdsip.so、libmki.so 与 .run 安装包。关键术语：SoC 架构、CXX11 ABI、run 包、TEST_TYPE=UT。
