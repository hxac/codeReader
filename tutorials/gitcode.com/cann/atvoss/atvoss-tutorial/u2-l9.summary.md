本讲沿 `blockOp.Run` 进入 **Block 层**，讲清单核如何把任务切成 Tile 并循环执行。核心结论：`BlockBuilder` 只是「编译期 Policy（`TileShape`+`MemMngPolicy`）+ 运行期 `DefaultBlockConfig`」的载体，真正的切分与循环逻辑在 `DefaultBlockSchedule`。`Run` 现场算出 `wholeLoop = totalElemCnt / BASIC_BLOCK`、`tileCnt = totalElemCnt % BASIC_BLOCK`（`totalElemCnt` 由 Kernel 层 `CalCurCoreEleCnt` 填入，`BASIC_BLOCK` 由 `TileShape` 编译期累乘得到），`Process` 据此把单核任务拆成「整 Tile + 尾 Tile」，逐个构造 `ContextData`（含 `gmOffset`、`elementNum`、`pingPong=i&1`）下传给 `Tile::Evaluate`，执行 CopyIn→计算→CopyOut。本讲引入的关键术语：UB 三段划分（IN/OUT 双缓冲 ping-pong 各 2 槽、CALC 单缓冲 1 槽）、`UB_TILE_SIZE = UB_SIZE / MAX_BUFFER_COUNT`、由 `BlockBufferEx` 物理分配；`BlockTensor` 作为「GM 指针 + UB LocalTensor」轻量封装，`CopyIn/CopyOut` 落到 `DataCopyPad`；求值器用 MTE2→V→MTE3 的 Mutex 锁链配合双缓冲隐藏搬运延迟；编译期 `TileCheckAssert` 拦截 TileShape 过大。`Tile::Evaluate` 与缓冲分配细节留给 u3 系列承接。
