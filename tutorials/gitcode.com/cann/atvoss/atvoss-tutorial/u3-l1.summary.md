求值器系统（Evaluator）是 ATVOSS 把编译期表达式树翻译成 Ascend C 硬件指令的桥梁，本质是一台「编译期解释器」。核心机制是 `Evaluator<T>` 的「主模板 + 偏特化」递归求值：由 `Tile::Evaluate<Expr>` 点火，运算节点特化内部对子表达式再次构造求值器，递归在编译期内联展开、运行时零开销；脱壳特化 `Evaluator<Expression<T>>` 公有继承 `Evaluator<T>`，剥离外层 `Expression<>` 外壳，使所有特化只针对裸节点编写。

四个最小模块：其一，叶子 `Param`/`LocalVar` 凭编译期序号 `N`（1 起，下标取 `N-1`）从 `ContextData` 取出真实 `LocalTensor`——`Param` 取自 `argsTensors` 且仅 `IN` 参数允许隐式类型转换，`LocalVar` 取自 `tmpTensors`，二者序号空间独立。其二，`OpAssign` 表示「一条计算指令」，通用版走 `Assign(dst, src)`，但绝大多数算子命中更具体的 `OpAssign<T, OpXxx<...>>` 特化。其三，`OpAndThen` 表示「语句边界 + 同步」，在顺序求值左右子树前插入 `PipeBarrier<PIPE_V>()` 强制排空 Vector 流水线，避免相邻语句复用 UB buffer 时的 RAW/WAW 竞争，单个 `OpAssign` 不触发屏障。其四，`math_evaluator.h`/`transcendental_evaluator.h` 为每个 `OpXxx` 配对提供特化，经薄包装 `XxxAssign`、结合 `OperationShape`（`GetShape` 取 axis0/axis1）落到 Ascend C 指令；二元算子用 `if constexpr + is_scalar_v` 在编译期完成标量分派（Add/Adds、Mul/Muls，Divs 常量倒数优化）。该机制是 u3-l2 Tile 层映射与 u3-l4 线性化 Pass 的地基。
