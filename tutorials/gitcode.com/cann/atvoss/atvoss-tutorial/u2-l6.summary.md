本讲打开 Host 侧算子入参构造的黑盒，主角是 `ArgumentsBuilder`。它只是空标签入口，真正累积状态的是 `ArgumentsBuilderImpl`，采用「不可变构造器 + 类型累积」设计：每次链式调用都返回一个模板参数更宽的新对象，累积进度编码进 C++ 类型里。其内部持有两个 Collector 分工管理：`InputOutputCollector` 用 `std::forward_as_tuple` 按引用存张量与标量，`AttrCollector` 用 `std::make_tuple` 按值存 `AttrMap` 键值对，二者均靠 `std::tuple_cat` 拼接，且可任意交错调用。`inputOutput` 入口处两条 `static_assert` 禁止指针、只允许 `Atvoss::Tensor` 与标量，目的是配合消费端 `TransformArgs`「标量透传 / Tensor 取指针」的二分分派。`.build()` 产出两层 `std::tuple`：第 0 位是 inputOutput 实参、第 1 位是 attr 键值对。核心顺序契约为 `PlaceHolder<N>`（1-based）对应 inputOutput 第 N 个实参，消费端 `DeviceAdapter` 用 `std::get<N-1>` 取参；attr 则是供 tiling/调度配置使用的扩展通道。
