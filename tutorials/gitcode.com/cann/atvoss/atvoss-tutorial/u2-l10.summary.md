本讲以 muls 样例收束进阶篇，把表达式模板、运算符重载与 ArgumentsBuilder 串成可运行算子，引出三个机制。其一，标量操作数直接用裸标量类型声明（不包 Tensor），求值器借 is_scalar_v 自动分派到标量广播指令 Muls 而非逐元素 Mul；标量误包 Tensor 会降级为 MulAssign。其二，当输入与计算类型不一致（如 int32→float）时，用 Cast 声明转换、用 PlaceHolderTmpLike 派生 LocalVar 接住结果，逗号表达式 OpAndThen 串联成「先转后算」，宽化转换取 CAST_NONE 无需舍入。其三，单 Config 多 Compute：多套 Compute 共享 TileShape 与调度策略、各自组装独立 DeviceOp 类型别名，运行时用 if constexpr 按数据类型编译期分派，未命中分支不实例化，避免类型不匹配的 Compute 被编译。关键术语：Muls/Mul、Cast/CastMode、Param 与 LocalVar 两套独立序号空间（LocalVar 不进 ArgumentsBuilder，缓冲由框架自动在 UB 分配）、OpAndThen 顺序执行。本讲现状是 main 仅跑 int32→float 的 PromtIn 路径，float 同类型路径已写好但未触发；后续 u3 将深入求值器递归求值、缓冲 Alloc/Free 与表达式线性化及图优化 Pass。
