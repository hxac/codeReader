本讲是 ATVOSS 学习手册首篇，建立「是什么、为什么、能在哪用」的总体认知。ATVOSS（Ascend C Templates for Vector Operator Subroutines）是一套基于 Ascend C 的 Vector 算子模板库，专攻昇腾硬件上的逐元素与融合 Vector 算子。它通过分层架构与表达式模板，把多核切分、Tiling 分块、GM↔UB 内存搬运、流水同步等硬件调度细节封装起来，开发者只需用声明式表达式描述计算逻辑；底层仍调用 Ascend C 基础 API，性能上限与手写一致、零运行时开销。引入的关键术语包括：算子、昇腾 AI Core、Vector 计算单元、Ascend C、Tiling、表达式模板、融合算子，以及 Device/Kernel/Block/Tile/Basic 五层架构。能力边界为擅长逐元素计算（含归约/广播扩展），不主攻矩阵乘；环境门槛需 Ascend 950PR/950DT、CANN 不低于 8.5.0。
