本讲抽出 ATVOSS 专用于描述数据的五类基础类型，构成后续调度、求值、图优化的地基。`Tensor<T>` 是 Host 侧轻量包装，仅存设备指针与运行期形状，不持有内存。`Shape<int...>` 把形状编码进类型，是 `TileShape` 的底座，元素总数在编译期累乘得到。`Layout/OperationShape` 将 `Shape` 翻译为带语义的轴（一元用 axis0、二元用 axis0/axis1），并强制维度 ≤ 2。`patterns.h` 汇集四个策略枚举：`Pattern`（归约/广播方向）、`CastMode`（类型转换舍入方式）、`MemMngPolicy`（AUTO/MANUAL，决定走 FullAutoDag 还是 ManualDag）、`MemLevel`（三级缓冲复用，默认能激进就激进）。`ContextData` 是单核单 Tile 的上下文包裹，把入参张量、临时变量、缓冲池、`gmOffset`、`elementNum`、`pingPong` 六类信息下传给求值器。贯穿主线：ATVOSS 用编译期 `Shape<>` 与运行期 `Tensor` 两套形状表示，以 `ContextData` 桥接 Tile 切分与求值，以枚举开关在各维度切换算子行为。
