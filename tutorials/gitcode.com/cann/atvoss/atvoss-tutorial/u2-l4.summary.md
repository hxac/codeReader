本讲承接逐元素算子，介绍两类会改变张量形状的算子：归约（ReduceSum）与广播（Broadcast）。二者均为带 Pattern 编译期模板参数的 UnaryOp，产出零开销的表达式节点。

核心是 Pattern 枚举：AR/RA 用于归约，AB/BA 用于广播。约定 axis0 为行（HEIGHT）、axis1 为列（WIDTH），字母顺序对应轴，'A' 表示保持目标大小，'R' 表示压成 1，'B' 表示从 1 扩开。故 AR 沿列归约得 [axis0,1]，与 AB 沿列广播互逆；RA 与 BA 互逆。rms_norm 样例即用 ReduceSum<AR> 配 Broadcast<AB> 实现每行平方和再广播回去。

真正的维度变换由求值器特化（Evaluator<OpAssign<dst, OpReduceSum/OpBroadcast<...>>>）完成：归约侧直接复用 AscendC Pattern 枚举，广播侧拆成"广播轴 + srcShape"映射到 Ascend C API。求值器只认二维 {axis0, axis1}，故归约/广播当前仅面向二维 Tile。含归约的表达式在图层会被特殊处理（边界插 Copy、划分为 PreReduce/Reduced 段），细节见 u3-l6。
