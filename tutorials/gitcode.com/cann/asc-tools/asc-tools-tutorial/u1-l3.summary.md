本讲讲解编译运行 asc-tools 前如何搭建环境，覆盖三个最小模块。核心结论：CANN（昇腾异构计算软件栈）是 asc-tools 的地基，分 toolkit（必选核心工具链）与 ops（按 SoC 型号的可选算子信息），须装到同一路径。环境准备有云开发环境、CANN 镜像 Docker、DevContainer 三种：前两者已预装 CANN，DevContainer 只只读挂载宿主机驱动、CANN 须手动装，适合生态贡献。依赖分运行态（NPU 驱动/固件，仅 CPU 仿真可省）与编译态（gcc/cmake/python/ccache 等系统工具链）。关键术语：装完须 `source set_env.sh`，它导出 ASCEND_HOME_PATH 等变量，是 build.sh 按优先级定位 CANN 路径的关键；install_deps.sh 装系统工具链，install_dep_tar.py 下载第三方源码包，职责不重叠。asc-tools 不能独立升级，须搭配版本匹配的 CANN 包；读源码可发现文档与脚本的版本漂移。
