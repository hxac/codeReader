本讲以 `ascendc_npuchk_report.py`（唯一核心文件，约 180 行）为研究对象，讲解它如何把机器向的 `*_npuchk.log` 翻译成人读报告。核心是 `parse_log` 的手写文本状态机：靠 `###`、`[Error`、`# BackTrace #` 三个标记切分半结构化日志，把每条错误打包成 `err_info = [错误行, 内建函数签名, bin:addr 帧…]`。引入的关键术语有：name mangling（名称修饰）与反修饰工具 `c++filt`、嵌入 DWARF 调试段的 `-g` 二进制、去重 key（错误码 + 全部堆栈地址拼接，使同源反复触发的同一错误在报告中只出现一条）、以及丢弃 `.so` 库帧的规则。最后 `addr_to_line` 把 `addr2line -f`（地址→修饰函数名 + 文件:行号）与 `c++filt` 串成地址翻译链，`execute_cmd` 用 10 秒超时兜底；报告按「错误行 → Rule → 内建函数签名 → 逐帧源码定位 → 错误统计」拼装。
