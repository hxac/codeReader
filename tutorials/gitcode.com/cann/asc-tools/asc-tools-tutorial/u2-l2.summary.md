本讲以 asc-tools 的 `add.asc` 为唯一教材，拆解一份完整的 Ascend C 算子源码。源码分三层：宿主侧（`main`/`kernel_add`）负责分配显存并通过 `<<<>>>` 启动，`__global__` 核函数（`add_custom`）仅做装配，算法逻辑封装在 Kernel 类（`KernelAdd`），复杂度逐层下沉。核心机制：`Init` 用 `GetBlockIdx()` 为每个 block 切分 `GlobalTensor` 视图；以 CopyIn/Compute/CopyOut 三段式对应 NPU 的 MTE2/Vector/MTE3 三条流水，配合 `BUFFER_NUM=2` 双缓冲实现搬运与计算重叠；`TQue` 通过 `AllocTensor↔FreeTensor`、`EnQue↔DeQue` 四原语管理 `LocalTensor` 在 Unified Buffer 上的生命周期，必须严格成对。关键结论是守恒等式 `loopCount × TILE_LENGTH = BLOCK_LENGTH`，故改 `TILE_NUM` 只影响性能不影响正确性。引入的关键术语：`__aicore__`/`__gm__`/`GM_ADDR`/`__global__`/`__vector__` 修饰符、`GlobalTensor`/`LocalTensor`、`TQue`/`TPipe`、block 与 tile 划分。本讲只讲源码结构，多核 fork 仿真、API 校验、npu check 留待后续讲义承接。
