本讲讲解 cpudebug 如何在 CPU 上「重新发明」NPU 专有的低精度浮点类型（fp16/bf16/fp8/fp4/hif8），使孪生调试的比特布局与 NPU 完全一致。仿真类型分为两类：**计算型**（fp16/bf16，即 `struct half` 与 `Bf16T`，以单个 `uint16_t val` 持有比特并配完整算术运算符，可直接参与标量运算）与**传输型**（fp8/fp4/hif8，仅提供构造、赋值与边界转换，不含算术，真正运算交给 NPU 指令）。仿真的可信度集中在类型转换：`FloatToFp16` 按上溢/下溢/常规三段处理，并以就近偶舍入（RNE，`IsRoundOne`）保证精度，反向 `Fp16ToFloat` 为无损拓宽。提交 `c6f35b0` 为 `half`/`Bf16T` 补全一元 `operator-()`，取负应以翻转符号位实现，以保留 ±0 与 NaN payload。`half` 的实现开源于 `kernel_fp16.cpp`，而 `Bf16T` 及该一元运算符的函数体位于闭源模型库。
