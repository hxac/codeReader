本讲建立了对 ops-transformer 的整体认知：它是华为 CANN 算子体系中面向 transformer 类大模型的进阶算子库，特点是算子粒度大（融合多层子计算）且贴近训练/推理真实业务。仓库按算子域组织顶层目录，涵盖 attention（最大模块，含 FA/FIA、量化与稀疏注意力）、moe（路由与 token 重排）、mc2（通信-计算融合）、ffn、gmm、mhc、mamba、posembedding 等。核心约定：每个算子目录承载全部交付件；查算子走 docs/zh/op_list.md 与算子 README 的产品支持表；多 V 版本选最高版本；算子分「标准算子」（支持 aclnn 与图模式）和「简易算子」（fast_kernel_launch，仅 PyTorch）两种交付形态。版本配套是关键约束：硬件（A2/A3/950 系列）对应 soc_version 编译参数（ascend910b/ascend910_93/ascend950），源码标签须与所装 CANN 版本按 release-management 仓库对应，不可随意用 master。关键术语包括 NPU、CANN、算子（host/device 侧）、SoC 代际简称（A2/A3/A5）、ACL/aclnn 两段式 API。三大学习入口：README 看定位与动态、QUICKSTART 跑通 add_example 全流程、docs/README.md 文档中心按场景索引进阶文档。
