本讲围绕 ffn 域展开：FFN 主算子把「两段 matmul + bias + 激活（含 GLU 门控）+ 可选量化/伪量化」融合为一次 kernel 下发，核心收益是省掉 [M,N1] 中间矩阵的 GM 往返与多次 kernel 启动，代价是约 2000 行 tiling 与更大的 workspace。关键机制：可选输入 expertTokens（Host 侧 aclIntArray）使同一算子覆盖 FFN 与 MoEFFN 两种形态，承接 u5-l1 的 MoE 路由输出；def 中每输入 dtype 列表长度 10、按下标组合取值的「场景组合」约束；tiling 分别为 MM1/MM2 生成 Cube 计划、用 tiling key（量化/伪量化/GLU/MSD/ONE_MATMUL 特征位）路由到 op_kernel 变体文件，并要求 Cube baseM 与 Vector baseM 整数倍对齐、workspace 精确报价。另归纳 ffn 域「主算子通用 + 场景变体贴场景」的组织方式：swin_attention_ffn、swin_transformer_ln_qkv 等变体固定 shape、仅 fp16、无 aclnn 层、tiling 写常量、重心在 op_graph；与 attention 域五层目录范式相同但重心不同。本讲为 u5-l3 的 mc2 通信计算融合做铺垫。
