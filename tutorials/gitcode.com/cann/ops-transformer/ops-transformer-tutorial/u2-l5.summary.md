本讲承接 u2-l3 的 AICore 核函数，转向昇腾 NPU 上的另一种算子载体 AICPU——片上通用 CPU 核，用标准 C++ 开发，无需 tiling 与 UB 内存管理，适合控制流复杂、可复用现成 C++ 逻辑的场景，但吞吐低于 AICore。最小交付件包括：算子信息库 json（dtype 白名单与 engine: DNN_VM_AICPU 路由信息）、`_aicpu.h/.cpp` 设备侧实现（算子类继承 `CpuKernel` 基类、重写 `Compute(CpuKernelContext&)`、以 `REGISTER_CPU_KERNEL` 注册）、以及 infershape；没有 def 和 tiling 文件。核心结论：Compute 中拿到可直接解引用的指针，dtype 分发靠运行期 switch（对比 AICore 的编译期 tiling key 路由），框架不做广播/越界校验，语义需自行保证。构建上，`--genop_aicpu` 从 add_example_aicpu 模板复制骨架并做名字替换，`--opkernel_aicpu` 置位 ENABLE_AICPU_KERNEL 将 `*_aicpu*.cpp` 编入 libtransformer_aicpu_kernels.so。UT 用 `RUN_KERNEL(node_def, HOST, ...)` 在 HOST 直接执行，无需 NPU。编译完成后算子同样自动获得 aclnn 两段式接口。
