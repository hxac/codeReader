本讲介绍 ops-transformer 的 common 公共库与 fallback 机制。common 是全仓库共享的公共代码：include 按「消费者」分层（op_host/op_api/op_kernel/op_graph/err/util/fallback/framework/tiling_sink 等，分别服务 tiling、aclnn 层、AscendC 核函数、图注册等），src 按「产物」分层；CMake 中以 OBJECT 库形式被各算子 .so 吸纳，复用公共头通常零 CMake 改动。代表性工具有 EnsureNotScalar（标量 shape 归一为 {1}）、GET_TPL_TILING_KEY（tiling 模板注册）、ops_err.h 的 E89999/E69999 统一错误上报宏，add_example 与 ffn 已在复用。fallback 机制解决 mc2 通信算子图模式与 eager 实现复用问题：通过 IMPL_OP(...).OpExecuteFunc(...) 注册 host 侧执行函数，运行期将 gert::Tensor 转为 aclTensor（ConvertMmType/ToAclDataType），用 dlsym 按 libcust_opapi → libopapi_transformer → libopapi 顺序查找符号（cust 优先体现用户覆盖原则），再用 EXEC_OPAPI_CMD（或两阶段变体 EXEC_OPAPI_PREPARE_CMD）完成两段式调用；workspace 仍由调用方分配，此处调用方是图框架 host_api_ctx。
