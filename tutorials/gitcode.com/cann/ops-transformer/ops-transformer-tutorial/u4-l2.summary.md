本讲精读 FA 算子 op_api 层（aclnn_flash_attention_score 家族），覆盖四个最小模块：头文件声明约定、参数校验漏斗、预处理流水线与 l0 base 调用、多版本接口共用 base 的组织。核心结论：op_api 层是算子库「前台」，负责翻译参数、修整输入、打包执行计划，不做计算；校验按「空指针→空输出短路→format→dtype→shape/组合约束」五层漏斗组织，便宜检查在前；预处理流水线（Contiguous→PreprocessQKV→l0 base→Postprocess→ViewCopy）由 FaShapeInfo 标志驱动，挂在 StrideLimited() SoC 总开关之下。引入关键术语：l0/L2 分层（l0op::FlashAttentionScore 为 base 层）、DFX 打点宏、OP_LOGE_FOR_INVALID_*_WITH_REASON 结构化日志、CommonOpExecutorRun、INFER_SHAPE/ADD_TO_LAUNCHER_LIST_AICORE。追踪了 scale_value 从 C API double 到算子属性 float 的路径（终点隐式截断）；13 组 L2 接口共用唯一 31 参数 base，新版本仅做入口填空，第二段完全模板化。
