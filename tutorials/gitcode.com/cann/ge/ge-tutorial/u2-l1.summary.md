本讲义建立 AscendIR（GE 的统一中间表示）的「四层对象模型」骨架：`ComputeGraph → Node → OpDesc → GeTensorDesc` 自上而下组合嵌套，四层均为 has-a 关系且统一采用 Pimpl 模式隔离实现。核心结论有二：一是 AscendIR **不存在独立 Edge 对象**，连边完全由节点内嵌的 Anchor 互相引用表达；二是遵循「静态图 + 属性扩展」原则——核心拓扑为编译期固定的静态 DAG，所有易变编译状态通过 `AttrHolder` 属性附加。`ComputeGraph` 作为图容器提供节点管理、图查询、拓扑排序三类接口，节点列表用 `std::list` 支持频繁中间增删，支持嵌套子图表达控制流，排序失败即图中有环。引入的关键术语包括：四层模型各层职责、静态图与静态 Shape 图的区分（判别开关 `GetGraphUnknownFlag()`，对应 v1/v2 执行器）、`GetAllNodes`/`GetDirectNode` 的递归差异、Node 持有 OpDesc 与 Anchor、以及「只读遍历优先用裸指针 `*Ptr()` 版本」的项目性能约定。后续讲义将承接 Anchor 连边、OpDesc 属性与算子注册。
