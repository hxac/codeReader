本讲义精读 LLM-DataDist 初始化与集群建链的源码实现。核心结论：Initialize 是两层 Pimpl 管线——api 层 `LlmDataDistImpl` 做选项翻译与补齐（`llm.DeviceId` 必填），实现层 `LLMDataDistV2` 装配 TransferEngine、CacheManager、CommEntityManager 等五大组件并创建独立 ACL context，失败逆序回滚；`TransferEngineFactory` 是后端唯一分叉点（默认 HCCL / hixl）。建链由 `LLMLinkManager` 编排：每集群一个任务进 16 线程池并发执行，控制面走自定义 TCP 协议（`kConnect/kDisconnect/kStatus` 三种消息），载荷为 `LLMExchangeInfo`（含 cache table 地址、req/resp 缓冲区、comm_res）；两端对称执行 `ExchangeInfoProcess`，各建 `CommEntity` 入 `CommEntityManager` 台账，并拼出相同的 `hcclCommName` 配对 HCCL 通信域。rank table 在握手时现算：交换两端 comm_res 后由 `RankTableGeneratorFactory` 按 version 就低协商选 V1/V2，有序容器保证两端独立合并结果一致，rank id 按 server_id 字典序分配。关键术语：CommEntity、comm_res、rank table、PrepareMem、force_link；重复建链报 `LLM_ALREADY_LINK`，SetRole 须先断链（`LLM_EXIST_LINK`），实质是监听 daemon 启停。
