本讲深入 CS 数据面三大构件。EndpointStore 是 server 侧端点台账（map<EndpointHandle, EndpointPtr>），MatchEndpoint 用按协议定制的 operator== 把 client 的 EndpointDesc 翻译成句柄（HCCS 比 commAddr.id、UB 系比 EID、RoCE 比 IP），失败报 PARAM_INVALID；Endpoint 还托管内存登记（含 UBOE/UBG/UBC_CTP 的 host VA 映射分支）、导出/导入与 Channel 表，销毁按 Channel→内存→端点后建先拆。Channel 创建靠两端一致的 channelName（client/server commAddr + server 监听端口 + channel_index 拼成）配对，HcommChannelCreate 异步发起后以 1µs 间隔轮询 GetStatus（0 完成、1 进行中、2/3 终态失败）。TransferPool 是 per-device 单例槽位池（默认 128 槽、引用计数共享），每槽预置 ctx/stream/Hcomm thread/notify/err_flag；正常 Release 清 err_flag 归还，失败闩锁触发 Abort 原地重建；thread 上下文增删经 HixlSyncTransferContext 内核同步（DELETING 中间态 30 秒重试）。client 侧共享槽（shared_ptr 引用计数）允许多传输复用 active_slot_，内核按 128 条 desc 分块、每 1920 条插一次 notify wait。
