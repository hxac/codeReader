本讲是 FabricMem 模式的概念课与地图课。核心问题：超节点内 NPU 与远端主机 DRAM 间的 D2RH/RH2D 传输中，RoCE 带宽仅约 20GB/s，传统 HCCS 不支持 D2RH，中转模式又占用 HBM 带宽；FabricMem 借 A3 的 FabricMemory 统一编址技术，让 NPU 经 HCCS 直达远端 DRAM（路径为 NPU→L1→L2→对端 L1→CPU→DDR，不经 HBM），带宽达百 GB/s 级。底层依托 CANN VMM 三步机制（申请物理内存、预留虚拟地址、建立映射），进程间交换共享句柄后即可 SDMA 直访。关键术语：超节点、VMM、共享句柄（ShareHandleInfo，含导出/导入双向）、AsyncSlot、AsyncRecord、VirtualMemoryManager 单例。架构上，FabricMemEngine 是 Engine 抽象的第三个实现、工厂第一优先级分支，定位薄门面，编排 TransferService、LocalMemory、ControlServer、Statistic 四组件；传输服务按 enable_aicpu_unfold 选 Host 或 AICPU 实现。并发核心是 submit_gate 读写锁（提交并行、断链独占先 drain 再 abort）。模块按内存、控制、传输、通道槽位、配置统计五组组织，细节留给 u5-l2 与 u5-l3。
