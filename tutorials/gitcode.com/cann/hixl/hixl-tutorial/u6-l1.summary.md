本讲是单元六首课，只建全景地图不深入实现。核心结论：LLM-DataDist 是面向 KV Cache 语义的上层传输接口，服务于 PD 分离场景下推理引擎（vLLM/SGLang）的 KV Cache 搬运；它通过 `llm.TransferBackend` 选项把 HIXL Engine 作为可插拔传输后端之一，配置仅透传，链路决策仍在 HIXL。公开类 `LlmDataDist` 采用 Pimpl 设计，15 个接口分四组：生命周期（Initialize/Finalize/SetRole）、链路（Link/UnlinkLlmClusters，批量建链）、Cache 管理（Allocate/RegisterKvCache 两条获得 Cache 的路径）、传输（Push/Pull 的 Cache/Blocks 版本及本地 Copy）。关键术语：`CacheIndex`（cluster_id+cache_id+batch_index 三级寻址）、`CacheDesc`、`KvCacheExtParam`（layer range 部分传输，最大层索引 = num_tensors/tensor_num_per_layer − 1）、错误码 0x5010Bxxx 段（判断入口统一为 == LLM_SUCCESS，另有一套 `ge::` 枚举体系）。角色模型要点：`LlmRole`（kPrompt/kDecoder/kMix）仅为业务标签，不影响传输；Server/Client 由是否配置 `OPTION_LISTEN_IP_INFO` 决定；`SetRole` 可运行期切换角色但须先断链（否则 LLM_EXIST_LINK）。后续讲义将按 api/link_mgr/cache_mgr/transfer_engine 等目录逐层展开实现。
