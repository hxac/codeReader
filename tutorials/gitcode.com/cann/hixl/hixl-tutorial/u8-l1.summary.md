本讲介绍 HIXL 的性能基准体系。基准采用「shell 入口（run_all_bench.sh）→ Python 编排（run_all_benchmarks.py）→ C++ 测量内核」三层结构：编排器用笛卡尔积枚举 transport×内存×内存×op 全组合并按平台过滤（如 HCCS 不支持的方向显示「不支持」即被 [SKIP]），一键脚本仅支持单机。两类基准分工明确：comm_benchmark 测裸 block 传输带宽（128MiB 总量按 16K→2M 阶梯切分，TransferSync 批量下发、steady_clock 计时）；kv_benchmark 模拟 KV Cache 池化负载（8 进程模拟推理 rank，rank 0 put、全体 get，模型规格来自 models.json，A3/A5 默认走 fabric_mem）。关键概念：有效带宽按十进制 GB/s 计算而参数 K/M 按二进制解析；首轮含 warm-up，稳态看 loops>1；方向记号（如 D2rD）由 initiator/target 内存类型与 op 决定；block 越小描述符固定开销占比越高、带宽越低；异步模式耗时拆分 submit/wait 可区分提交瓶颈与链路瓶颈；host 参与的方向系统性偏低。performance.md 是手动维护的多平台基线（对比用），perf.md 是自动生成的单平台数据；瓶颈定位按「小 block 低属正常 / 均匀低查环境 / 首轮低是 warm-up」的因果链排查。
