本讲聚焦 LLM-DataDist 的 Python 接口层，分为四个最小模块：包结构与 whl 打包、LLMDataDist 主类与 LLMConfig 配置、CacheManager 与核心数据类型、异步分层传输。核心结论：`llm_datadist` 是「纯 Python 外壳 + wrapper .so」混合包，经 bdist_wheel 发布，v1 遗留类懒加载；`LLMDataDist.init` 按是否启用 CacheManager 双路由到 v2/v1 wrapper，全进程单例并有 atexit 兜底 finalize；`LLMConfig` 以属性风格生成选项字典，`llm.TransferBackend`（HIXL 后端）有强校验（须开 CacheManager、RemoteCacheAccessible 并配 listenIpInfo）。`CacheManager` 方法遵循「校验→pack 元组→调 wrapper→状态码转异常」四段式，寻址分 CacheKey（按请求）、CacheKeyByIdAndIndex（按槽位）、BlocksCacheKey（按块表）三类，对应 C++ 侧 CacheIndex 机制。关键术语：`link_clusters` 新式建链（返回状态码不抛异常）、register/allocate 两条获得 Cache 的路径、建链后禁止注册 remote_accessible Cache。`transfer_cache_async` 由 Python 线程实现「层到即传」：逐层等 `LayerSynchronizer.synchronize_layer` 回调后下发 `transfer_cache_v2`，`CacheTask.synchronize/get_results` 聚合/细化结果，超时返回 LLM_TIMEOUT。两个样例（同步 Pull 与异步分层传输）构成接口对照基础，供 u7-l3 PD 分离端到端承接。
