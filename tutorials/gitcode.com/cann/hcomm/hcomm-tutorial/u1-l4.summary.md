本讲义通过运行 examples/01_communicators 下的官方示例，首次把 HCCL 对外接口“跑一遍”。核心内容分四个模块：其一，root info 方式初始化通信域——由 root rank 调用 HcclGetRootInfo 生成 4108 字节不透明标识（HcclRootInfo），经外部机制（示例用 MPI_Bcast）广播给全部 rank，各 rank 再调 HcclCommInitRootInfoConfig 建链；其二，HcclCommConfig 配置结构——头部 24 字节 size/magic/version 协商区加尾部追加字段实现 ABI 兼容，必须用 HcclCommConfigInit 初始化，未设置项保持 0xffffffff 哨兵值；其三，AllReduce 执行与异步语义——HcclAllReduce 按元素个数（非字节数）+ 数据类型 + 归约类型描述操作，任务下发到 stream 即返回，读结果前必须 aclrtSynchronizeStream；其四，初始化方式对比——rank table 方式（HcclCommInitClusterInfoConfig 读共享 JSON 文件）与单进程多线程变体。关键术语：通信域、rank、root info、流（stream）、Device/Host 内存、ACLCHECK/HCCLCHECK 宏。还澄清：示例包含的 hccl.h 来自 CANN 安装目录，本仓库 HCOMM 提供的是 weak symbol 实现。释放顺序固定为通信域销毁→设备重置→ACL 去初始化。
