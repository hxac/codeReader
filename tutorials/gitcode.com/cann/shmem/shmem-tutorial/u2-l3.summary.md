本讲拆解 SHMEM 初始化第一阶段「Bootstrap 建链」的内部实现。核心结论：Default/UniqueID 模式的控制面是以 PE 0 为中心的 TCP 星型拓扑——PE 0 进程内嵌 AccStoreServer（监听器 + 内存 KV 表），每个 PE（含 PE 0 自连）各持一个 TcpConfigStore 客户端连向同一服务地址。主库按初始化 flags 用 dlopen/dlsym 动态加载 bootstrap 插件（config_store 或 mpi），以 g_boot_handle 中的函数指针为契约，session_magic 隔离多次 init/finalize 会话。最重要的设计思想是把集合通信降解为 6 个 KV 原语（SET/GET/ADD/APPEND/REMOVE/CAS）：barrier 靠 ADD 返回的到达序号，最后到达者写完成标志，其余 PE 带超时等待；allgather 靠带 rank 前缀的 APPEND 总长度判完成，再按 rank 排序展开。这些能力经 aclshmemi_control_barrier_all 被 init、malloc/free、finalize 复用；finalize 与 plugin_init 严格对称，g_store_ref 引用计数保护多实例共享的 Store 资源。后续讲义中对称堆 slice 信息的交换将直接消费本讲的 allgather。
