本讲解析 aclshmemx_init_attr 初始化接口与三种 bootstrap 模式。初始化属性分两层：必选层 aclshmemx_init_attr_t 含 my_pe、n_pes、ip_port、local_mem_size、comm_args 等字段；可选层 option_attr 提供版本号、通信引擎位掩码与默认 120 秒超时。三种模式即三种「介绍人」：DEFAULT 由库自带 Config Store 插件自建服务，ip_port 优先、uid 回退；MPI 模式控制面直接转调 MPI 集合通信；UNIQUEID 模式由 SHMEM 签发 uid 凭证、交外部信道分发。库内部按 UNIQUEID→MPI→DEFAULT 顺序选定插件并经 dlopen 动态加载。UID 模式标准四步：仅 PE 0 生成 uid、按字节整体广播（internal 区对用户不透明）、各 PE 以 set_attr_uniqueid_args 构造属性后完成初始化。aclshmem_my_pe 与 aclshmem_n_pes 只能在初始化成功后查询。
