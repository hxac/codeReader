本讲讲解 SDMA 与 UDMA 两个传输管理器。SDMA 是本地资源准备型引擎：初始化只查 AIV 核数、建 STARS 流、准备共享工作区并激活 AICPU 搬运算子，不建链、不注册内存，仅 A3 平台编译支持。UDMA 是远端建链型引擎：解析 rootinfo 与拓扑、经 bootstrap allgather 交换 EID 信息，用 HCOMM 接口为每个真实 peer 建 endpoint 与 channel，就绪后把队列上下文打包成 udmaInfo 表下发 device，仅 Ascend950 支持、依赖 CANN≥9.1.0。关键术语：HCOMM、EID、STARS、self-send（自发送）、topo_list、channel（语义等价 QP）。核心约束：UDMA 不支持自发送，本 rank 的路由、channel 与 AMO scratch 均不建立；双层防御为 entity 层不通告本 rank 的 UDMA 位、device 分派宏加 pe≠mype 守卫，自发送一律回落 MTE。
