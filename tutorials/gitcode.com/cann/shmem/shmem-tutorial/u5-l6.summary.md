本讲厘清 device 数据面两层 API 的边界：高阶接口按 topo_list[pe] 位掩码自动挑选引擎，阻塞版等价于「_nbi 调用＋同引擎 quiet」；engine 直驱层则把 UB 暂存区、sync_id、qp_idx 等引擎参数交给开发者。四引擎各具特色：MTE 提供非连续拷贝并兜底本 PE 拷贝，SDMA 支持 L2 预取与事件记录，UDMA 有 QP 直发、聚合提交与 relay 绕路，RDMA 可直写 WQE。QP 专属 roce 接口仅多 qp_idx 参数（限 XSCALE 后端），普通版写死 QP0，多 QP 并行可提升小消息带宽。核心结论：UDMA 不支持自发送，由「entity 层不为本 rank 通告 UDMA 位、分派宏排除本 PE」双层防御兜底，本 PE 拷贝安全回落 MTE，且守卫只存在于高阶层，直驱层靠调用者约定。选型原则：求可移植用高阶，求性能与并行用直驱。
