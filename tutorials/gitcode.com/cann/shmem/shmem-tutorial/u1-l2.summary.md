本讲解决「SHMEM 怎么构建与安装」，分四个模块：环境依赖全景、build.sh 编译入口、CMake 构建内核、安装方式与产物。核心结论：SHMEM 非 自包含，强依赖 CANN 工具链与 bisheng 编译器——Host 侧普通 C++、Device 侧 AscendC 双模式分别编成 OBJECT 库，链接成同一个 libshmem.so；configure 期强制检查 ASCEND_HOME_PATH，按 SOC_TYPE 选 NPU 架构，用 try_compile 探测 CANN 能力，非 950 平台在构建层排除 UDMA。关键术语：异构编译、-xasc/-xcce 编译模式、后端名 910/950、makeself 自解压 run 包、多后端 wheel、set_env.sh（SHMEM_HOME_PATH、LD_LIBRARY_PATH）、RDMA 后端 XSCALE/HNS_1825、CXX11 ABI。引擎可用性在编译期由 CANN 版本与芯片型号锁定：UDMA 仅 Ascend950，SDMA 仅 A3。
