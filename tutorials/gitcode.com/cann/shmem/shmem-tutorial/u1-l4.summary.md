本讲解析 examples/init 示例，确立 SHMEM 程序通用调用骨架：aclInit → aclrtSetDevice → aclshmemx_init_attr → 业务逻辑 → shmem_finalize → aclrtResetDevice → aclFinalize，顺序不可颠倒；初始化与终结均为集体操作，缺一个 PE 其余进程会阻塞至默认 120 秒超时。本讲引入关键概念：ACL 运行时（SHMEM 建立于其设备内存之上）、Bootstrap 引导建链（Default、MPI、UniqueID 三种模式）、条件编译（一份 main.cpp 经编译宏分派五种模式）。核心 API 三件套为 aclshmemx_get_uniqueid（仅 PE0 生成 uid 后广播全组）、aclshmemx_set_attr_uniqueid_args 与 aclshmemx_init_attr(bootstrap_flags, attributes)，属性结构体 aclshmemx_init_attr_t 携带 my_pe、n_pes、ip_port、local_mem_size、comm_args 等字段。run.sh 把 -mode/-pesize 翻译成 cmake -DRUN_MODE 再编译并拉起多进程，故换模式必重编译；default 模式由脚本循环拉起进程，PE 编号 = f_pe + idx。身份查询接口 aclshmem_my_pe/aclshmem_n_pes 只能在初始化成功后调用。
