本讲走读 shmem_init.cpp 中的 aclshmemi_init_attr_impl，把初始化拆为三个阶段：Bootstrap 建链，加载插件建立 CPU 控制面，产出 g_boot_handle 上的 allgather/barrier 能力；HYBM 建堆，由后端对象 init_manager 先 reserve_heap 预留 GVA，再 setup_heap 分配物理 slice 并经控制面交换、mmap 远端映射，heap_base 按 my_pe 对齐错开；子模块就绪，在堆上初始化分配器与 signal/team/sync，update_device_state 把 g_state 镜像到 NPU 元数据区，末尾全组 barrier 后 init 才返回。顺序由依赖决定：建堆靠控制面交换 slice，子模块住在堆上。finalize 按逆序释放，两道 aclshmemi_control_barrier_all 分别确保全组都进入 finalize、堆全拆完才拆控制面。关键术语：控制面与数据面、对称集体调用、g_state/g_boot_handle/init_manager 全局状态、init_abort_guard 失败本地回滚、is_aclshmem_created 与 is_aclshmem_initialized 三态。Bootstrap 细节留待 u2-l3，堆与寻址机制留待 u2-l4/l5。
