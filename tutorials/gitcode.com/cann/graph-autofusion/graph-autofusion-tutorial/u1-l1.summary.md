graph-autofusion 是面向昇腾芯片的轻量级、解耦式融合加速组件集合，仅依赖 AscendC 与 runtime，不绑定特定深度学习框架。它含两个正交、可独立选用的开源组件：SuperKernel 针对算子调度开销，凭编译期先验信息用 JIT 把整网重编译为单个「超核」，省 N-1 次调度，并叠加 ICache 预取、Early-Start、同步优化、子核拆分四项深度优化；Autofuse 针对相邻 Vector 算子的 Memory Bound，作为基于 AscendC 的自动融合编译器，提供融合范围识别、codegen、Auto Tiling 及动态 shape 与混合精度支持。二者解耦由顶层 CMakeLists 的 BUILD_AUTOFUSE 选项与 build.sh 的 --no-autofuse 保证。后续手册以 Autofuse 数据流（graph_metadef→ascir→optimize→att→codegen→compiler）为主线精读，SuperKernel 为并行线。本讲引入术语：融合、调度开销、Memory Bound、超核、codegen、Auto Tiling、ASCIR、解耦。
