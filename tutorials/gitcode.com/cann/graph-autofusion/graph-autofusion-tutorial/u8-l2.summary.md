本讲义覆盖 kernel 代码生成（`Kernel`/`Code` 抽象体系）、代码打印（`CodePrinter`）、tiling 数据生成（`TilingLib`）三大模块。核心结论：Autofuse 用「C++ 类描述 C++ 代码」的方式生成 kernel——`Code` 为可打印根，`Variable`/`Axis`/`Tensor`/`TQue`/`TBuf` 建模语法元素（`Axis` 多重继承 ascir 轴与变量，体现一份图数据两种视图），`Tiler`/`TPipe`/`Kernel` 组装成完整 kernel，`Kernel::Generate` 按固定顺序打印；`CodePrinter` 是文件级排版器，主要服务 ATT 侧。`TilingLib` 的三个入口（`Generate`/`GenerateCVFusion`/`GenerateForInductor`）产出「文件名→内容」映射，拆为入口翻译单元加原子头以支持按内容缓存。本次更新引入两个关键改动：一是 CV tiling wrapper 复用编译——wrapper 精简为纯接口，Python 侧按内容 cache key 编为共享 so（文件锁+原子替换），配合 C++ 侧 `CallCubeTiling` 运行期 tiling 结果缓存，形成编译期/运行期两层缓存；二是 dtype 感知 CV 融合——Cast/取整类算子统一按 `curAivM/curAivN` 二维组织参数，N 方向 stride 按 dtype 做 `BlkAlign` 32 字节块对齐。此外，Inductor 多阶段 PGO 候选稳定化：measured 候选按 `canonical_repr` 去重、过滤不快于 default 的候选，default 始终保有兜底位，保证 PGO 不劣于基线。关键术语：CV 融合、tiling wrapper、canonical_repr、TopN 候选、modeled/measured 两阶段。
