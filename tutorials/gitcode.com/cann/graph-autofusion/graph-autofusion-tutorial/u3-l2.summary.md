本讲是 Autofuse 的「地图课」，确立其编译器定位：输入框架送来的计算子图，输出 C++ kernel 源码与 tiling 数据。源码以「目录即模块」组织，六大主线模块沿数据流排开：graph_metadef（图 IR 容器）、ascir（ASCIR 类型与算子注册）、optimize（调度切分，产出 fused_schedule_result）、att（自动 tiling）、codegen（生成 kernel）、compiler（pyautofuse 编排输出），另有 ascendc、inc、common、v35 等辅助目录。关键结论有二：逻辑上 att 在 codegen 之前，实现上却是 codegen 通过 att::GenTilingImplAutoFuseV3 反向调用 att 生成 tiling；optimize/att/codegen 的源码合流进同一共享库 aihac_codegen，graph_metadef 与 ascir 为独立库再被链接，pyautofuse 单独装入 site-packages。Autofuser 是 Python 绑定入口，持有 Optimizer 与 Codegen，提供 autofuse_backend、schedule、codegen 三种调用粒度。
