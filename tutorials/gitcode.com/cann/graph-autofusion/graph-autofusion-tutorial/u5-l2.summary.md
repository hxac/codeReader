本讲承接 u5-l1，深入 ASCIR 注册三元组中的 codegen 实现侧，讲解 reg_func 如何为算子计算片上临时缓冲大小。reg_func 并非注册宏本身，而是 codegen 实现类 `CalcTmpBufSize()` 的外置实现体，调用链为 `REG_ASC_IR → XxxCodegenImpl::CalcTmpBufSize → CalcXxxTmpSize`，统一返回 `vector<TmpBufDesc>`。以 reduce.cpp、compare.cpp 为样本：reduce 按被归约轴（R 轴）与保留轴（A 轴）分离、并区分是否需要累加，compare 按 dtype × mode 分发；所有尺寸均用符号表达式（`Expression` + `sym::` 运算符）表示以支持动态 shape。`TmpBufDesc` 仅含 `size`（待求解的字节公式）与 `life_time_axis_id`（`-1` 为 API 级、`≥0` 为 loop 级）两字段，是给下游 tiling（ATT）与内存分配（buffer_allocate）的占位契约。`GetTmpBuffer` 将单块缓冲钳到硬件上限 65312 字节，无特殊需求的算子可复用 `CalcDefaultTmpSize`（8192 字节，tanh 为最简样例）；reg_func 同时读取算子属性（dtype、`GetType()`、`mode`）来决定 sizing。
