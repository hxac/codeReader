本讲是 Autofuse 数据流中 att（自动 Tiling）阶段的开篇：把 u6-l3 AutoSchedule 枚举的候选 scheduled graph 建成一份可求解的性能模型 ModelInfo，交下一讲求解器挑选最优 tiling。覆盖三个最小模块：性能建模思想——把 tiling 选择转成「最小化执行时间、受硬件与对齐约束」的优化问题，目标用按 PipeType 分桶的符号表达式 objects（map<PipeType, Expr>）表示，约束存 hardware_cons/eq_exprs/leq_exprs；gen_model_info 接口——ATT 顶层入口，固定三步 parser 翻图→expr 生成（含 pipe 性能）→pass 收集，输出总账本 ModelInfo；api_perf_register——以自注册模式（EvalCosts 单例 + ApiPerfFactory）把算子名映射到 cost 函数。核心公式为某 pipe 总耗时 Cost_p = Σ t_n·c_{n,p} + H_p，其中单次耗时 c 对 elementwise 是线性模型 k·repeat_time+b、对搬运是带宽模型；因支持动态 shape，目标与约束全用符号 Expr 表达，cost 数据来自 v1/perf_param_v1.cpp 的内嵌 JSON（kParamV1Info）。关键术语：ATT、ModelInfo/objects、PipeType（AIV_MTE2/VEC/MTE3）、TuningSpace、PipePerfExpr、自注册、PerfParamTableV1。
