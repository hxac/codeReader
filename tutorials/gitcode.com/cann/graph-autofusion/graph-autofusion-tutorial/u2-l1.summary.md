本讲阐释 SuperKernel 的动机与原理。调度开销指算子越多越小时，主机下发与同步等待等摩擦成本反超纯计算耗时；核心思想是借助编译期掌握的全部先验信息，用 JIT 把整网 N 个子算子缝合成一个超核二进制、运行时只下发一次，省下 N−1 次调度与同步。SuperKernel 为 JIT（Python 编译期生成代码）与 AOT（C++ 运行时图优化）双层结构，经公共 C 头 super_kernel.h 对接，入口分别为 compile() 与 aclskOptimize。因合并需插入同步会削弱收益，其真正价值在于四项深度优化：ICache 预加载减少取指 Miss、Early-Start 让搬运与初始化并发、按 Kernel Type（AIV/AIC/Mix）缩小同步范围、子 Kernel 拆分缓解多核地址争用，并支持内存语义的 Notify/Wait 事件。融合决策与任务切分留待后续讲义。
