本讲是 Autofuse 组件的原理铺垫。先建立硬件直觉：昇腾 AI Core 有大容量全局内存（HBM）与小而快的片上统一缓冲（UB）两级存储，Vector 算子经 MTE2 搬入、Vector 计算、MTE3 搬出三段执行。由此引出核心问题 Memory Bound：elementwise（逐元素）算子计算量小而搬运量大，相邻算子的中间结果在全局内存反复读写，瓶颈卡在内存带宽。自动融合（Auto Fusion）的解法是把相邻 Vector 算子合并成一个 kernel，让中间结果只在 UB 流转；单链上 N 个算子的全局内存访问可从 2N 次降到 2 次，profiling 上体现为 aiv_mte2_time/aiv_mte3_time 下降，并产出 `autofused_算子名_拓扑哈希` 形态的单一 kernel。Autofuse 还承诺动态 shape 与混合精度：块内统一升到 fp32 累加、边界保留原 dtype，故累积舍入误差不劣于 Eager。其内部数据流骨架为 graph_metadef → ascir → optimize → att → codegen → compiler，细节及未融合算子的 fallback、使能开关均留给后续讲义展开。
