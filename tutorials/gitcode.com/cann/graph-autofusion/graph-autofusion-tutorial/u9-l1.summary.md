本讲义讲解 Autofuse 编译器对外的 Python 接口层，覆盖四个模块。`pyautofuse` 扩展模块用原生 CPython C API（非 pybind11）暴露三类核心对象：`Autofuser`（配 `AutofuserOptions`，一站式调度+代码生成，返回 tiling_data/tiling/kernel 源码三元组）、`Schedule`（只做调度，`schedule` 映射 `Optimize` 重载 B、`scheduleV2` 映射重载 A）、`CodeGen`（host/device/PGO 多入口，返回嵌套字典）；CV 融合在绑定层表现为一份调度结果生成 ub/common 两套代码。`compile_adapter.py` 把编译编排为 host/device/all 三个 stage，host 源码按内嵌 SPLIT 标记切成公共头+原子 .cpp 以支持按内容缓存，Inductor PGO 旁路仅在 host stage 额外产出 PgoRunner 与 PgoDeviceSource。新增的 `ascir_api.py` 提供函数式建图 API，核心是按图名隔离的全局 `GraphMetadata`（算子计数器、data/output 索引），负责唯一命名、IO 编号与视图推导（`_infer_or_set_view`），与 C++ 侧 `AssignDefaultIoIndex` 语义对齐互为兜底。末端 `ascendc_compile.py` 调毕昇编译器产 `.so`，CV tiling wrapper 以六元内容寻址 key（源内容、ASCEND_PATH、machine、soc_version、编译选项、stage）加文件锁与原子替换实现跨图共享缓存。本次增量在 `REGISTERED_OPS` 花名册新增 I0/I0e/I1e、Chebyshev、Hermite 等特殊函数算子，Python 包装须与 C++ 花名册成对维护。
