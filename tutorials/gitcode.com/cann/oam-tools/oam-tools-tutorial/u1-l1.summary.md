OAM-Tools 是华为 CANN 的开源运维工具集，为昇腾 AI 处理器开发者提供故障定位与性能调优两大核心能力，四大组件相互独立又共享 CMake + build.sh 构建体系，打成 .run 包后释放到 CANN 安装目录 tools/ 下。组件分工：asys（纯 Python，一键故障信息采集与诊断，含 info/health/collect/launch 等 8 个子命令）；msaicerr（Python，AI Core Error 报告解析、Dump 文件解析与类型转换、环境检查，-p/-d/-e 三种模式）；msprof（C++ collector 与 Python 分析 wheel 分离，采集与分析解耦）；hccl_test（C++，集合通信正确性与带宽测试）。本讲引入的关键术语：CANN、OAM、AI Core Error、HCCL、Dump 文件、.run 包、npu-smi info。硬件支持范围：910B（关键字匹配含 910B1~910B4 子型号，ops 包代号 910b）、910_93（即业内别称"910C"，代号 A3）、950（代号 950）；CPU 架构支持 aarch64 与 x86_64。各组件文档入口位于 docs/zh/ 下 asys、msaicerr、profiling、hccl_test 四个目录（注意性能文档目录名是 profiling 而非 msprof）。核心结论：README 与磁盘目录结构一致，asys 与 msaicerr 的分工是“采集现场”与“深度解析”。
