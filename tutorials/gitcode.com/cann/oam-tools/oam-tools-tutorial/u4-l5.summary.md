本讲从实现者视角切换到 msprof 使用者视角，覆盖三类采集触发方式：命令行（`msprof [options] <app>`，任意框架通用，对应 u4-l2 精读的 msprofbin 入口与 ProfileParams）、环境变量（`PROFILING_MODE` 取值 true/false/dynamic，配合 JSON 字符串 `PROFILING_OPTIONS` 配置 output、task_trace、aic_metrics、storage_limit 等采集项，仅适用 TensorFlow 训练/在线推理，ACL/TF Adapter 接口优先级更高）、acl.json/ACL API（离线推理 C&C++ 程序的声明式与编程式起停，接口须成对调用）。核心结论：三者采集项命名基本同构；延迟采集（--delay/--duration，定时闹钟）与动态采集（--dynamic=on 交互模式 start/stop，手动快门，分 launch 与 attach 两法）互斥；文档参数与 input_parser.cpp 参数表、application.cpp 环境变量注入存在精确的文档↔源码对应关系。
