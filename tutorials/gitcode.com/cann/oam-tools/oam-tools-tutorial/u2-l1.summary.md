本讲义剖析 asys 工具入口 `src/asys/asys.py` 的主流程，覆盖三个最小模块：`main()` 主流程、`EXECUTE_CMD_FUNC` 子命令分发、输出目录创建与 tar 压缩。核心结论：asys 是“入口薄、实现厚”的纯 Python 工具，`main()` 依次完成参数去重（`_check_args_duplicate`）、恢复 SIGINT 默认行为、`CommandLineParser` 解析参数入 `ParamDict` 单例、环境类型检查（RC 环境仅允许 `launch` 和不带 `run_mode` 的 `collect`）、`AsysConfigParser` 加载配置、创建时间戳输出目录、字典分发执行、按 `--tar` 参数压缩。asys 共有 8 个子命令（collect/launch/info/diagnose/health/analyze/config/profiling），通过 `EXECUTE_CMD_FUNC` 字典映射到实现类，统一约定“无参构造 + `run()` 方法”的隐式接口，新增子命令只需加目录、import 和字典项。关键术语：`ParamDict`（全局参数单例）、`Constants` 常量类、`create_out_timestamp_dir()`（仅 collect/launch/analyze 落盘时建 `asys_output_<毫秒时间戳>` 目录，路径经 `ParamDict().asys_output_timestamp_dir` 交接给压缩方）、`compress_output_dir_tar()`（替换式压缩为 `.tar.gz` 后删原目录）、纯展示命令（info/diagnose/health 等）提前 `close_log()`。本讲主流程是后续 u2-l2（命令行体系）等讲义的骨架。
