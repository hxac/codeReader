本讲义讲解 oam-tools 提交 PR 前的本地工程门禁体系。贡献流程以 CONTRIBUTING.md（面向人类，要求签 CLA、非简单修复先提 Issue）和 AGENTS.md（面向 agent 的快速上手卡片）为入口。核心模块有三：一是 OAT 开源合规检查，OAT.xml 定义 License（Apache-2.0/华为版权）策略与文件豁免，oat_check.sh 作为本地钩子只扫 staged（--diff-filter=ACM）文件，仅对 Invalid File Type 与 License Header Invalid 两类确凿问题阻断，工具自身故障一律放行；二是 .pre-commit-config.yaml 编排的钩子链（clang-format、OAT、ruff、pylint、incremental-codecheck、bandit、codespell），通过 exclude 实现「存量豁免」（新规则只对新增目录生效），版本锁定源于 CI 的 Python 3.9 约束；三是 incremental_codecheck.py，用「ruff 全量检查 + 只保留命中 staged 改动行的告警」在本地复现云端增量 codecheck，关键概念是存量违规与增量违规之分——本地门禁不得比云端更严。六条 ruff 规则映射华为云端规范（如 E501→行宽 120、T201→禁 print）。下一讲进入 .run 包打包与安装升级。
