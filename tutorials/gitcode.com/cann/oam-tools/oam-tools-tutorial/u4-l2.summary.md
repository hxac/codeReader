本讲义深入 msprof 命令的入口层 msprofbin，覆盖四个最小模块：msprof_bin.cpp、input_parser.cpp、msprof_manager.cpp 与 running_mode.cpp、msprof_task.cpp。核心结论：main 是薄入口，按「保存环境 envp → 驱动/平台两级初始化 → msopprof 分流 → 参数解析 → MsprofManager 初始化 → 注册 SIGINT → 委托执行」固定顺序串联，任一步失败即非 0 退出；命令行解析是表驱动的，LONG_OPTIONS 表与 ArgsMsprofCmd 枚举构成全部选项的唯一定义点，ProcessOptions 按枚举区间路由到四族校验器，并完成 Hz→毫秒的翻译，结果统一收敛进 ProfileParams。关键术语包括：ProfileParams（唯一参数载体）、RunningMode 六种模式（App/System 采集组与 Parse/Query/Export/Analyze 分析组）、白名单/必需/禁止三集合的规则集检查、SplitApplicationArgv 划分 msprof 选项与业务程序参数。MsprofManager 按 app > devices > host_sys > hostSysUsage > parse > query > export > analyze 优先级生成模式；离线分析以子进程调 msprof.py 实现，C++ 与 Python 仅靠路径契约衔接。MsprofTask（子类 ProfSocTask 走 SOC 通道、ProfRpcTask 走 devmgr RPC）遵循「启动-阻塞-唤醒-落盘」节奏，Stop 链路保证 Ctrl+C 时数据 Flush 并写 done 标记。下一讲进入 profapi 插件体系。
