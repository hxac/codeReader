本讲义剖析 msaicerr 工具入口 msaicerr.py：采用单层 argparse 加顺序 if 分发的设计，环境检查（ASCEND_OPP_PATH、目录可写）先于参数解析，按 -d > -p > -e 优先级分发三条路径——-d 走 convert_dump_data 至 DumpDataParser，-p 走 analyse_report_path 至 Collection 加 AicoreErrorParser，-e 走 test_env。关键概念包括：自定义 Action RequireOtherArgs（扫描 sys.argv 强制校验附属参数搭配约束）、parse_known_args 统一未知参数报错、sys.excepthook 全局异常钩子（置 GLOBAL_RESULT 为 False、Ctrl+C 交还原生钩子）、Constant 错误码体系与 main 返回值即退出码契约。核心结论：-p 路径分两阶段，Collection 类按六步流水线（校验、收集 plog、提取 dump 信息、搬 dump、取 kernel 名、搬编译产物与图文件）归档现场到输出目录 collection/ 下，并从日志内容反推四个场景标志（collect_level L0/L1、ffts_flag、is_sk 超长文件名重命名）；输入输出隔离与 mapping.csv 不跨 device 回退是防静默收集错误现场的防御设计；tar 分支为不可达预留代码。AicoreErrorParser、DumpDataParser 细节留待后续讲义。
