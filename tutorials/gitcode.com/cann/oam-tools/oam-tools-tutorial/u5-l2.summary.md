本讲深入 hccl_test 的类组织与建链机制。核心内容：三层继承体系 `HcclTest`（底盘：参数解析、MPI、rootinfo 建链、数据量循环、内存管理）→ `HcclOpBaseTest`（中间层：dtype→count 换算、数值溢出判定、统一结果打印）→ `HcclOpBaseXxxTest`（每算子一个类），是典型的模板方法模式。关键概念：rootinfo（`HcclRootInfo` 建链信息字节串），其建链三步曲为 root 进程 `HcclGetRootInfo` 生成 → `MPI_Ibcast` 广播（失败广播 "invalid" 全体退出）→ 全体 `HcclCommInitRootInfo` 建通信域，这也解释了 hccl_test 必须用 mpirun 拉起的原因。算子测试主体固定节奏：溢出判定、灌数、预热、event 计时轮、重灌单跑校验、算带宽打印；计时与校验分离。每算子差异收敛于四个覆写点（`init_malloc_Ksize_by_data`、`init_send_recv_size_by_data`、`hccl_op_base_test`、`init_buf_val`/`check_buf_result`）；带 root 的算子（如 Reduce）额外多传 `root_rank` 且仅 root rank 生成期望值与校验。新增算子测试仅需一对 `.h/.cc`（含工厂函数 `init_opbase_ptr`）加 Makefile 的 LIST 与 SRC 映射。溢出判定按 dtype 精度（如 int8 为 7 位）与 rank_size 阈值自动关闭校验（`no_verification`）。
