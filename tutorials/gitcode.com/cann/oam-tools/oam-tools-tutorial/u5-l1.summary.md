hccl_test 是 oam-tools 中基于 HCCL（华为集合通信库）单算子 API 的 C++ 测试工具，用 MPI 编排多进程/多机，对 11 种集合通信算子做正确性校验（`-c 1` 逐元素比对）与带宽/时延测量。核心工程结论有三：一是「Makefile 编译、CMakeLists 安装」双入口——因依赖装机后才确定的 CANN 与 MPI 路径，.run 包只搬运源码，用户现场 `make ASCEND_DIR=... MPI_HOME=...` 编译出 11 个二进制；二是全部二进制共享 `hccl_test_main.cc` 一份 main，通过每算子一份的工厂函数 `init_opbase_ptr`（链接期决定实现）实例化 `HcclOpBaseXxxTest` 类，main 按「初始化→测试→分级 goto 清理」编排；三是目录分 `common/`（公共骨架，含 `HcclTest` 基类）与 `opbase_test/`（每算子一对 `.h/.cc`），算子覆盖归约、聚集散射、全交换、广播四族，V 后缀表变长，Broadcast 源文件保留 `brocast` 历史拼写。hostfile 是 MPI 的多机节点清单（MPICH `ip:进程数` / Open MPI `slots=`），仅启动阶段与 rootinfo 广播使用，`-n` 须等于节点数×每节点 NPU 数。基类骨架精读留待 u5-l2。
