本讲梳理 oam-tools 仓库目录结构与四大组件入口。`src/` 下并列六个目录：asys（故障收集，Python）、msaicerr（AI Core Error 分析，Python）、msprof（性能调优，C++ collector）、hccl_test（HCCL 性能测试，C++），外加辅助的 operator_cmp 与 third_party，由根 CMakeLists 统一挂载。asys 入口 `asys.py` 只做守门（参数查重、解析、环境检查、配置加载、建时间戳输出目录），经字典分发结构 `EXECUTE_CMD_FUNC` 将 collect/launch/info/diagnose/health/analyze/config/profiling 八个子命令映射到实现类，每个子命令对应 `src/asys/` 下一个同名目录；软链接 `asys -> ./asys.py` 配合 shebang 与 CMake install 规则，使安装后可不带 python3 直接调用。msaicerr 入口采用 `-p`/`-d`/`-e` 三种互斥模式分发（-d 优先级最高），并用 `sys.excepthook` 保证异常退出码正确。C++ 组件入口为“构建入口 + main 函数”：hccl_test 由 Makefile 编出 11 个测试二进制共享一份 `hccl_test_main.cc` 的 main；msprof C++ 入口在 `msprof_bin.cpp`，分析侧以 Python wheel 打包期引入。关键术语：入口文件、软链接、install() 规则、子命令、字典分发，这些是 u2 单元精读 asys 各子命令的导航基础。
