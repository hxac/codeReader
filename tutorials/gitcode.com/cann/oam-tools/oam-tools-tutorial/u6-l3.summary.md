本讲覆盖 .run 包的完整生命周期：打包生成、安装/升级/卸载与黑盒验收测试。核心结论：`version.cmake` 是版本唯一源头，经 `cmake/package.cmake` 的 `pack_built_in()` 将安装脚本族装入 CPack 组件，最终由 makeself 后端生成 `build_out/` 下的 .run 包；`oam_tools.xml` 是“装什么、装到哪、什么权限”的声明式单一事实源；`install.sh` 作为统一入口分发 install/upgrade/uninstall 三种操作，靠 `iter_i` 计数器保证单选，`precleanbeforeinstall` 支撑同路径覆盖安装，实际文件搬运委托 `opp_*.sh` 与 cann-cmake 的 `install_common_parser.sh --copy_all`。关键术语：makeself staging 目录、ascend_install.info/version.info/scene.info 三元元数据、`cann_uninstall.sh`（反向转调 uninstall.sh）、解压/安装树一致性断言。三组 ST（install/upgrade/uninstall）纯黑盒，只断言退出码、无 `[ERROR]` 与磁盘产物，WARNING 有意不断言，因其为设计内非致命告警。
