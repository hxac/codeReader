本讲义剖析 msprof 采集端「落盘前的最后一站」——analyze 模块。其开源形态是九个头文件构成的接口契约（.cpp 实现在提交 64ebbaa 中删除，可考古）：`Analyzer` 门面按文件名走 if-else 谓词链分发数据；`AnalyzerBase` 基类提供跨 chunk 缓冲拼接三件套、syscnt/频率换算及 static 共享中间表；五个子分析器分管五类原始数据——device 侧 hwts（硬件 trace 起止时间）、ts（timeline/关键点）、ffts（STARS 子任务日志），host 侧 ge（算子名/modelId 查询）、rt（host 下发时间）。核心设计是一条完整算子记录由跨分析器拼装、经 `Analyzer` 撮合上传；`OpDescParser` 单例解析 64 字节定长的 ACL 算子订阅记录 ProfOpDesc（定长存索引、变长名字反查）。关键术语：ProfileFileChunk、end_info 清场、friend 门面、三种 profile 模式（STEP_TRACE/SINGLE_OP/STATIC_SHAPE）。
