本讲讲解 PTO 中 GM 与 tile 存储之间的数据搬运指令 TLOAD/TSTORE。核心结论：GlobalTensor 只提供 shape/stride 寻址元数据，tile 提供落点与有效区，实际搬运量由 validRow/validCol 决定；两条指令 API 均为「TSYNC 等待 → IMPL 执行 → 返回 RecordEvent」薄壳，分别挂 MTE2/MTE3 流水线，跨流水线依赖靠事件表达。关键术语：有效区裁剪（尾块不越界写回）、PadValue 填充语义（Null/Zero 填 0，Min/Max 填 ±inf 或极值）、TSTORE 变体（AtomicAdd 原子写、preQuantScalar/TSTORE_FP 写回量化）、Acc→GM dtype 白名单、布局硬约束（Vec 同构 ND/DN/NZ，Mat 额外支持 ND→NZ/DN→ZN 边搬边分形）。本讲还对比 CPU 仿真（逐元素循环求正确）与 NPU（shape/stride 折算成 nBurst/lenBurst/gap 的 burst DMA 求性能）双实现，两端 *_IMPL 签名逐字相同、按架构×后端互斥编译，并预告下一讲 TASSIGN/缓冲管理。
