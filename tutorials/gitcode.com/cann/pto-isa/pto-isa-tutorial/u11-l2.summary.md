本讲剖析 PTO 的 A5/A6 后端组织与跨代迁移。核心结论：include/pto/npu 按 SoC 代际分目录，a2a3 与 a5 为全量实现，a6 为增量实现——仅重写六条行为不同的指令，其余经组合头复用 A5，由 arch_macro.hpp 的语义宏互斥挂载。A5 引入三种新形态：SIMT（warp 级线程模型，数据经 D-cache 直达寄存器，性能取决于局部性）、Int64 双 lane 软件模拟、MX 缩放地址指令。以 TMatmul 为标本对比三代：a2a3 带运行时对齐参数与 m==1 规避 hack，a5 将 GEMV 控制编译期化并新增 mad_mx，a6 以分派宏扩展混合精度。关键术语：intrinsic、warp、RegTensor、能力位（ArchTraits）、L0C 容量（A5/A6 较 A2A3 翻倍）。取舍原则：公共 API 薄壳与有效区语义跨代统一，实现头自由重写，代际差异尽量编码为编译期拦截，向下迁移更易触 dtype 白名单。
