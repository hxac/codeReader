本讲精读 A2/A3 上逐元素二元与标量指令族的 NPU 实现。核心是两个策略模式编排模板：`TBinOp.hpp`（二元，17 条指令共用）与 `TBinSOp.hpp`（标量变体，约 10 条，如 TADDS 走 `vadds`，标量按值经寄存器广播）。指令文件只需提供约 15 行的策略类（如 `AddOp`，含两个仅 repeatStride 不同的 `BinInstr` 重载）映射到 `vXXX` intrinsic，遍历编排全由模板承担，体现控制反转。分派树按形状与连续性选择 Norm 模式（`set_mask_norm`，repeatStride 让硬件跨行，指令数最少）或 Count 模式（`set_mask_count` + SetVectorCount，鲁棒但步长退化），并受 repeats/repeatStride 均 255 的 8 位上限约束。整体分层为：公共 API 薄壳（TSYNC + MAP_INSTR_IMPL）→ `*_IMPL` 契约检查（dtype 白名单、行主序、有效区一致）→ 内核层（tile 降 `__ubuf__` 指针）→ 模板 → intrinsic。关键反例 TFMOD：无单条 `vmod` intrinsic，用 vdiv/vconv/vmul/vsub 四步组合加 `pipe_barrier(PIPE_V)` 逐行实现，证明模板成立前提是硬件有 1:1 intrinsic。结论：新增一条二元指令需触达固定约 6 处文件，唯一设计决策是 NPU 侧走模板还是手工组合，对用户 API 完全透明。
