本讲覆盖 PTO 四条集合通信指令 TREDUCE/TBROADCAST/TGATHER/TSCATTER，以 A2/A3 的 CollEngine::AIV 实现为主线，涉及 comm_types.hpp 的 ParallelGroup 与公共枚举、pto_comm_inst.hpp 的 API 薄壳与后端路由、a2a3 各实现头及 CPU 仿真与 ST 用例。核心结论：集合通信采用「root 单方执行」模型——ParallelGroup 是零分配的跨卡 buffer 视图（经窗口映射），rootIdx 为组内下标，只有 root 执行指令序列，非 root 调用属未定义行为。AIV 路径下集合指令无专用硬件原语，本质是 TLOAD/TSTORE 加普通计算指令（ReduceOp 映射 TADD/TMAX/TMIN）与事件闭环的编排；数据超 tile 时自动 2D 滑窗分块并用动态掩码保护尾块，ping-pong 双 tile 重叠搬运与计算。TBROADCAST 为纯搬运不过 Vector，TGATHER/TSCATTER 沿 DIM_3 拼接/切分（落点偏移 r×perRankRows×stride3），延迟 TSTORE 需 hasPending/pendingRank 状态机排水。AllReduce 需 TREDUCE+TBROADCAST 组合并配 TNOTIFY/TWAIT 同步点；CCU 引擎为 A5 独有，CostModel 后端无通信指令。
