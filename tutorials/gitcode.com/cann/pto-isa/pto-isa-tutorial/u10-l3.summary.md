本讲剖析 `__COSTMODEL` 后端：真实执行 kernel 并逐指令记录，再用流水线仿真推演周期，回答「多快」而非「对不对」，不替代真机 profiling。三个最小模块：①轻量 CostModel 按四级分发估算单指令周期——A5 VF 曲线、搬运带宽、TMATMUL 解析式、逐元素线性公式，参数（slope、bias）源自真机 profiling 拟合的 CSV，缺失组合 WARN 回退 0 并由兜底公式垫底；②perf_sim 走记录、归并、仿真、报告四步，以 8 条流水段队列与计数器事件通道推演并行，报告 Total cycles、各段 busy 占比与 Chrome Trace 时间线（busy 之和可超 Total），stuck 条目预示真机死锁；③A5 改用七元组曲线键（VfCurveKey）查表加四种公式求值，覆盖以向量指令为主。运行入口为 run_costmodel.py 的 st/st_fit/st_a5_fit 套件。
