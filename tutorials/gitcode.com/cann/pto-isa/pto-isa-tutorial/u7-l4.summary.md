本讲覆盖 A2/A3 异步通信三个模块：异步指令语义、通信引擎分工、tget_bandwidth 带宽实测。TGET_ASYNC/TPUT_ASYNC 与同步版的本质区别是绕过 UB staging tile，由独立 DMA 引擎直接做 GM 到 GM 搬运，立即返回 AsyncEvent 句柄，之后用 Wait（阻塞轮询）或 Test（非阻塞）确认完成，从而支持通信与计算重叠。使用套路为 BuildAsyncSession 建会话→发起搬运→等事件；SDMA 以 SQE 描述符加 doorbell 提交，用单调递增 post ID 实现 quiet 语义——等最后一个事件即等此前全部完成，同一 session 限 64 个未完成操作，操作数须为同类型、扁平连续一维的 GlobalTensor 视图。引擎是与指令正交的维度：DmaEngine（SDMA 通用、URMA 仅 3510）管点对点异步，CollEngine::CCU（A5 独有，CKE 门触发）管集合通信，均在编译期选定。实测结论：同步 TGET 受 UB 吞吐封顶约 4 GB/s，SDMA 直达在 64 KB 以上反超、4 MB 时约 10.5 GB/s，小块因协议固定开销略慢；异步指令仅有真机实现，CPU 仿真不可用。该“异步预取加计算重叠”模式是下一讲 gemm_ar 融合算子的基础。
