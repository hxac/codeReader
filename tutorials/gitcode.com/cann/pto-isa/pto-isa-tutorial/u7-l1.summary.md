本讲为单元七通信指令集的全景导览，核心结论：PTO 通信扩展 ISA 共 11 条指令、四大类——同步点对点 TPUT/TGET、异步点对点 TPUT_ASYNC/TGET_ASYNC、信号同步 TNOTIFY/TWAIT/TTEST、集合通信 TGATHER/TSCATTER/TBROADCAST/TREDUCE。关键概念包括：staging tile（远端读写经 UB 中转，与计算指令同级的 tile 抽象）、数据与信号分离的两段式跨卡握手、comm_types.hpp 中的 ParallelGroup（零分配视图）、Signal/Signal2D（int32 信号量）、NotifyOp/WaitCmp/ReduceOp/DmaEngine/CollEngine 枚举、AsyncEvent/AsyncSession 异步句柄。「驱动多引擎」指一条 API 可路由到 MTE staging、Vector/AIV、SDMA/URMA DMA、GM 原子直写及 A5 独有 CCU 五条通路，引擎选择全部在编译期经架构宏与 if constexpr 完成（a2a3/a5/cpu 三套 IMPL 互斥分发）；Kirin 与 A6 架构通信整体不可用。CPU 桩仅验证功能，dcci/dsb 缓存维护、分块与 ping-pong 需真机验证。这些为后续 TGET/TPUT 精读与计算-通信融合打基础。
