本讲以 add_example_aicpu 样例为主线讲解 AI CPU 算子开发。AI CPU 是昇腾芯片上的通用 CPU 核，算子用普通 C++ 编写（区别于 AI Core 的 Ascend C），适合逻辑复杂、计算量小或移植已有 CPU 实现的场景，但吞吐低且硬件支持受限（仅 A2/A3）。核心交付件为 op_kernel_aicpu 三件套：`*_aicpu.h` 声明继承 `CpuKernel` 的算子类、`*_aicpu.cpp` 实现 `Compute(CpuKernelContext&)` 并用 `REGISTER_CPU_KERNEL` 注册、`*.json` 算子信息库声明 engine（DNN_VM_AICPU）、kernelSo 与类型列表。关键结论：AI CPU 工程无 tiling、无 `*_def.cpp`、aclnn 适配自动生成；算子名须在 json、注册宏、`IMPL_OP_INFERSHAPE` 三处严格对齐；infershape 与 AI Core 版逐字同构，证明其与硬件实现解耦。构建走 aarch64 交叉编译，UT 可直接在主机用 `RUN_KERNEL` 执行。与 AI Core 版 add_example 全链路对照后收束到选型判断：越偏 C++ 原生逻辑越宜 AI CPU，越大规模并行越宜 AI Core。
