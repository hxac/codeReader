本讲承接 u7-l1 的 UT 总框架，深入 Device 侧 Kernel UT 并介绍 ST 系统测试。核心结论：Kernel UT 借助 CANN 的 tikicpulib 仿真库把 Ascend C kernel 编译为 x86 主机代码执行，无需真实 NPU；三个核心原语是 ICPU_RUN_KF（仿真执行）、ICPU_SET_TILING_KEY（选模板分支）、AscendC::GmAlloc/GmFree（仿真 GM 内存）。用例骨架为：申请仿真内存、手工构造 TilingData、设 tiling key 与 AIV 核模式、仿真执行、校验落盘；模板入口需直接 include kernel 源文件触发实例化。引入的关键概念包括：仿真 GM、tiling key 与模板实例需人工对齐、golden（金标准）对账、公共测试数据框架 kernel_ut_data_helper/executor（Python 造数 gen_data.py + C++ 仿真 + compare_data.py 对账的闭环）、AddOpTestCase 构建注册，以及 ST 侧的 atk 用例清单 json、executor 参考实现、golden 函数注册表与 fuzz csv。参考实现必须与 kernel 采用同一数学定义（如 GELU 的 tanh 近似）。UT 管逻辑与内存安全、ST 管真机精度与集成，二者互补；新算子最小测试集为 tiling UT + 带对账的 kernel UT + 一条最小 ST。
