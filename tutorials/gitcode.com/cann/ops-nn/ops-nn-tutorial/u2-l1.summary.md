本讲义以 aclnnGelu 为例拆解 aclnn 算子调用的完整机制。核心是两段式接口设计：第一段 `aclnnXxxGetWorkspaceSize` 在 Host 侧完成参数校验（空指针、dtype、format、shape），把算子调用登记进 executor（aclOpExecutor，一张执行清单），并计算 workspace 大小；第二段 `aclnnXxx` 把 executor 异步提交到 stream 执行，不返回计算结果。关键概念包括 Host/Device 侧分工、aclTensor 描述符、workspace 临时内存、stream 异步任务队列。适配层（op_api）中一次用户调用可能展开为多个底层算子串联：gelu 即 Contiguous→Gelu→ViewCopy，登记与执行分离；l0 层函数通过 ADD_TO_LAUNCHER_LIST_AICORE 把 AI Core kernel 挂到执行列表。调用样例遵循七步骨架：初始化→构造 aclTensor→第一段→按需申请 workspace→第二段→同步→拷回验证，换算子只需改 API 名与输入构造。错误处理上适配层把参数问题映射为不同 ACLNN_ERR_* 错误码，头文件注释是参数约束的第一手文档；正确流程必须先 aclrtSynchronizeStream 再取数，避免竞态。
