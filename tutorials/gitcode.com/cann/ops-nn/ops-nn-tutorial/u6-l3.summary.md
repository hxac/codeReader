本讲是 ops-nn 仓库的算子大类巡礼：全仓库共 14 个算子大类、约 540 个算子目录，查算子能力（aclnn/图模式/执行硬件单元）的总入口是 docs/zh/op_list.md；大类 CMakeLists 用 file(GLOB) 自动收集子目录，新增算子目录无需登记。四个代表算子揭示大类差异：norm 类 rms_norm 属归约型算子，输出依赖输入整行，按 shape/芯片在 NORMAL/SPLIT_D/MERGE_N/SINGLE_ROW 四种 tiling 模式中选择，tilingKey 用位段加权编码，kernel 按模式拆平级文件；loss 类 cross_entropy_loss 展示 attr（reduction）参与 shape 推导、多输入+可选输出、base/特化两层继承及「升 float 计算」精度套路；index 类 gather_v2 属不规则访存，AI CPU 标量实现与 AI Core arch35 的 SIMT（__simt_vf__ + LAUNCH_BOUND）实现并存，tilingKey 用大数常量区分变体；vfusion 类按 __CCE_AICORE__ 宏分芯片代际，generic/high_perf 双轨演进，TILING_KEY_IS 分发到双模板参数实例。核心方法论：接到新算子需求时，按「输出依赖多少输入元素」的语义特征去对应大类找参考实现。
