本讲义是 u3-l1（算子原型定义）的背景知识补全篇，围绕四个最小模块展开。数据类型（dtype）：存在三套写法的对照——def 源码写 `ge::DT_*`、aclnn 层真实类型为 `ACL_*`、文档用不区分大小写的简写（如 FLOAT16、FLOAT8_E4M3FN、FLOAT4_E2M1），dtype 决定元素字节宽度、精度与预编译二进制/tiling key 分支的选择。数据格式（format）：ND 是无轴语义的通用格式，绝大多数 API 仅支持 ND；NCHW/NHWC 等 CNN 格式要求维度数与字母数一致；FRACTAL_NZ/Z 等私有格式是 Cube 单元内部偏好的分块排布，不对外暴露——对外接口是 ND、内部分块由算子自行完成。非连续 Tensor：以 (shape, strides, offset) 三元组描述视图，元素物理位置 = offset + Σ(下标×stride)；处理路线有 def 文件声明式 `AutoContiguous()`（add_example 采用）与 aclnn 适配层显式插入 Contiguous（gelu 采用）两种取舍。aclnn 返回码：161xxx 参数错误（dtype/format 组合不在 def 候选槽位时返回 161002）、361xxx runtime 错误、561xxx 内部异常（561003 常因二进制包未安装），详情可用 `aclGetRecentErrMsg` 获取。核心结论：def 文件中 DataType 与 Format 两列表按下标一一配对成候选槽位、允许重复（quant_batch_matmul_v4 的 84 槽位即枚举所有合法量化组合的极端例），def 声明就是参数校验的第一道闸门。
