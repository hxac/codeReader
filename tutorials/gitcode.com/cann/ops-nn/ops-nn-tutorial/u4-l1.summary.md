本讲以 add_example 为载体讲解 Tiling 机制：Tiling 运行在 Host 侧，由框架经 gert::TilingContext 回调，产出 TilingData（POD 结构体，Host 写、Device 按字节拷贝读）、BlockDim、TilingKey 三样交付件。核心是两级切分：核切分用 blockFactor = ⌈totalIdx/coreNum⌉，再反推 usedCoreNum 避免起空核，经 SetBlockDim 决定启动核数，kernel 按 blockFactor×核号划分 GM 窗口；UB 切分算 ubFactor，由 UB 容量、元素宽度、缓冲块数（2 输入+1 输出×双缓冲=6）与 32 字节向下对齐共同决定，与输入规模无关。取整方向由越界代价决定：向上防漏元素，向下防 UB 越界。SetTilingKey 是 kernel 模板分支选择器（float→0、int32→1），与 def 声明、kernel 模板构成三道独立类型闸门。切分只影响性能不影响语义。关键术语：TilingData、blockFactor、usedCoreNum、ubFactor、TilingKey、BUFFER_NUM、CeilDiv/FloorAlign，供后续讲义承接。
