本讲义解读算子原型定义文件 `*_def.cpp`（算子信息库）。核心结论：它是单一职责的规格层，只声明算子是谁、输入输出规格与芯片适用范围，不含计算、shape 推导（`*_infershape.cpp`）或 tiling（`*_tiling.cpp`）逻辑；注册机制为继承 `OpDef` 基类并在 `namespace ops` 内经 `OP_ADD` 宏静态注册进全局算子注册表，使上千算子免于集中清单。关键术语：`Input`/`Output` 链式声明的 `ParamType`（REQUIRED/OPTIONAL/DYNAMIC）、`DataType` 与 `Format` 按下标配对成候选槽位（两列表长度必须一致），构成参数校验第一道闸门；`UnknownShapeFormat` 服务动态 shape，`AutoContiguous` 声明式处理非连续内存（gelu 改在 aclnn 适配层解决）；`OpAICoreConfig` 编译开关（`DynamicShapeSupportFlag`、`DynamicRankSupportFlag`、`PrecisionReduceFlag` 等）及 `AICore().AddConfig("<soc>", ...)` 决定芯片交付范围，`ExtendCfgInfo("opFile.value", ...)` 绑定 kernel 入口文件。每个 dtype 槽位对应 binary json 中一份独立预编译二进制，`shape: [-2]` 表示动态 shape。综合实践为 AddExample 增加 `DT_INT16`，验证「def 放行 + tiling 白名单与 tiling key 分派 + kernel 模板分支」三层缺一不可，并提示 `TYPE_SIZE` 元素宽度常量这类隐式性能依赖。
