本讲是入门单元收官实践，围绕 AddExample 算子完成「改内核→重编译→重装→重跑验证」的开发闭环。核心模块有三：一是 Ascend C 矢量算子的三段式流水（CopyIn 从 GM 搬入 UB、Compute 在 UB 上用 LocalTensor 纯计算、CopyOut 搬回 GM），计算与搬运解耦，故把 `AscendC::Add` 换成 `AscendC::Mul` 一行即改算子语义，且矢量指令约定「输出在前、输入在后、元素数最后」；二是 kernel 入口机制：入口函数用 `GET_TILING_DATA_WITH_STRUCT` 读取 Host 写好的 tiling data，按 tiling key（0 对应 float、1 对应 int32_t）经 `if constexpr` 分发到模板实例，改模板类对两分支同时生效；三是 aclnn 两段式调用样例的五步骨架：初始化、构造 aclTensor（含 strides 计算）、GetWorkspaceSize 返回 executor、下发执行、同步拷回打印。关键经验：改算子源码必须重新 `--pkg` 编译并安装 run 包，只改样例直接重跑 `--run_example`；修改 shape 时 shape 乘积与输入输出 vector 长度三者必须一致，否则越界。
