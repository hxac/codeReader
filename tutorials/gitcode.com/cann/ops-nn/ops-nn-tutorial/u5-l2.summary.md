本讲在 u5-l1 三段式结构基础上深入矢量算子 kernel 的入口与搬运细节，覆盖四个模块：kernel 入口函数、TilingData 的 Device 侧获取、DataCopyPad 与 32 字节对齐、公共取整工具。核心结论：入口是 `__global__ __aicore__` 模板函数，形参固定为「def 声明顺序的输入/输出 GM 地址 + workspace + tiling」，模板参数即 tiling key，用 `if constexpr` 编译期分发多份专用二进制；Device 侧经 `REGISTER_TILING_DEFAULT` 与 `GET_TILING_DATA_WITH_STRUCT` 在每个核入口从 GM 按字节还原 TilingData（POD 契约，字段只可尾部追加）；搬运方面，`DataCopyParams.blockLen` 单位是字节（元素数乘 sizeof(T)），`DataCopy` 要求 32 字节整倍，`DataCopyPad` 接受任意长度且仅在 UB 侧硬件补齐，GM 侧精确写出；尾块长度 currentNum 须贯穿 CopyIn/Compute/CopyOut 三阶段，pad 字节不参与计算、不落 GM；Init 用 `SetGlobalBuffer` 按核偏移收缩 GM 窗口；`kernel_utils.h` 提供 Ceil/CeilAlign/CeilDiv/FloorDiv/Aligned 等带除零保护的取整函数，口诀「向上防漏元素、向下防越界」。这些术语与「入口→tiling→搬运」阅读框架将由后续讲义（u5-l3 生产算子 gelu 精读）直接复用。
