本讲进入 Device 侧，讲解矢量算子 Kernel 的结构与流水。核心硬件约束是：AI Core 的矢量计算单元只能访问片上 UB，故任何 kernel 天然是「GM→UB→计算→UB→GM」结构。关键抽象包括：GlobalTensor（GM 远程视图，不可直接计算）与 LocalTensor（UB 上可计算），二者类型区分使「忘记搬运」在编译期暴露；TPipe 负责 UB 分配，TQue（VECIN/VECOUT 方向、深度即 BUFFER_NUM）连接搬运与计算两类异步硬件，以 AllocTensor→EnQue→DeQue→FreeTensor 构成缓冲借还闭环。标准骨架为 CopyIn-Compute-CopyOut 三段式，主循环边界来自 tiling 的 totalNum/blockFactor/ubFactor 三字段，尾块用 currentNum 贯穿三阶段防越界漏数据。双缓冲（BUFFER_NUM=2）使搬运与计算时间重叠，理想耗时由二者之和降为取大；kernel 侧 BUFFER_NUM（每队列块数）与 Host 侧 tiling 的 BUFFER_NUM=6（全部队列总块数）是必须同步修改的两个量，ubFactor 依赖后者计算。入口函数经 GET_TILING_DATA_WITH_STRUCT 读 tiling data，用 if constexpr 按 tiling key 分发模板实例，以 Init→Process 驱动 Kernel 类。DataCopy/DataCopyPad 与 32 字节对齐细节留待 u5-l2。
