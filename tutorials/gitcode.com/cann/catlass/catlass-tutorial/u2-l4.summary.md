本讲拆解 Kernel 层无状态设备侧类 `BasicMatmul` 的三个最小模块。其一为 Params/Arguments 双层视图：`Arguments` 只装 problemShape 与三矩阵 GM 指针，`ToUnderlyingArguments` 用 `MakeLayout` 把尺寸补成带 stride 的 Layout（A 为 M×K、B 为 K×N、C 为 M×N），构成所有 GM 偏移计算的地基。其二为 SPMD 步长分核循环：以 `GetBlockIdx()` 为起点、`GetBlockNum()` 为步长，将 C 的基本块无重复无遗漏地分摊到各 AICore；AIC 负责矩阵乘、AIV 本例为空。其三为 BlockScheduler（默认 `GemmIdentityBlockSwizzle`）三件套 `GetCoreLoops`、`GetBlockCoord`、`GetActualBlockShape`，分别给出块总数与循环上界、把一维块号映射为二维网格坐标（默认行主序）、以及触边裁剪后的真实块尺寸。核心结论：单块链路为「块坐标乘 L1TileShape 得逻辑偏移 → layout.GetOffset 得 GM 偏移 → 传入 blockMmad」；Kernel 层不切 K，K 维累加留待 Block 层完成，本讲是 U4、U5 的入口。
