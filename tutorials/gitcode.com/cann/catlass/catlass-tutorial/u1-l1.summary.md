CATLASS（CANN Templates for Linear Algebra Subroutines，昇腾算子模板库）是面向昇腾 NPU 的高性能矩阵乘（GEMM）类算子模板库，设计理念类比 NVIDIA CUTLASS，但针对昇腾硬件独立设计。核心结论：它通过分层模块化把 GEMM 解耦为可拼装的模板组件，使算子白盒化、可复用、可替换、可局部修改，并支持上层逻辑共享、底层硬件差异特化（AtlasA2、Ascend950）。

本讲引入的关键术语：五层抽象 Device → Kernel → Block → Tile → Basic，分别对应 Host 入口、多核编排、单核主循环、可组合微内核、硬件指令；矩阵乘被建模为三层嵌套循环，外层切 M/N 由 Kernel 并行、中间切 K 由 Block 累加、内层算 tile 落到 Basic 层的 AscendC::Mmad 指令；固定的五步组装范式——先组装 BlockMmad，配 BlockEpilogue 与 BlockScheduler，组合成 BasicMatmul，再用 DeviceGemm 包装，改需求时只替换对应一步的模板参数（DispatchPolicy、GemmType、TileShape、Swizzle）。本讲是后续逐层拆解源码的导航基础。
