本讲覆盖 Ascend C 矢量计算基础 API 三大类：双目接口（Add/Sub/Mul/Div/Max/Min 及融合型 AddRelu、MulAddDst 等）、单目接口（Exp/Sqrt/Rsqrt/Reciprocal/Abs/Relu 等）、比较选择接口（Compare/Compares 产生位掩码，Select 按掩码挑选）。三类接口统一遵循分级模型：Level 2 用 count（元素个数，非负，非字节）描述连续计算，底层自动换算为 mask/repeat，初学首选；Level 0 用 mask/repeatTime/repeatParams（含 BinaryRepeatParams/UnaryRepeatParams 步长）精细控制非连续布局。核心结论：所有矢量计算跑在 V 流水线，与搬运的 MTE2/MTE3 流水线相互独立，同一 V 流水线上的写后读依赖须 PipeBarrier<PIPE_V>()，跨流水线用 PipeBarrier<PIPE_ALL>()；多步运算可串联成 V 计算链（如 z=exp(x+y)、GELU 多项式近似），能用融合接口时优先用，单目接口在 3510/5102 上非线性运算多带 Config 模板参数。引入关键术语：count、SIMD、位掩码（uint8_t，8 个源元素压成 1 字节）、CMPMODE（LT/GT/EQ/LE/GE/NE）/SELMODE、原地写（dst==src）、自然块对齐（32 字节）。
