本讲承接 u2-l1 的 Host/Device 边界划分，讲解 Host 如何启动 Kernel 及数据如何在主设备间流动，拆为三个模块。其一，`<<<>>>` 内核调用符仅在 Host 侧使用，向下发执行配置：SIMD 为 3 参数 `<<<numBlocks, dynUBufSize, stream>>>`，SIMT 为 4 参数（多出 `threads_per_block`）。启动后每个核获得逻辑 ID `block_idx` 用于切分数据，且须满足 `numBlocks × blockLength ≥ totalLength`。其二，ACL Runtime 提供 Host/Device 内存分离模型：Device 用 `aclrtMalloc/aclrtFree`，Host 锁页内存用 `aclrtMallocHost/aclrtFreeHost`，二者靠 `aclrtMemcpy` 按方向（H2D/D2H/D2D）搬运；标准生命周期为 8 步，申请与释放严格对称。其三，Kernel 启动是异步的，Stream 是先进先出的有序任务队列，Host 读结果前必须 `aclrtSynchronizeStream` 同步，否则读到脏数据。将 add 改为 4 核×4096 后结果不变，性能呈「并行度下降 vs 搬运粒度上升」的权衡。
