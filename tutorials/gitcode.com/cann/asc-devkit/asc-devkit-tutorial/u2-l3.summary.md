本讲把 u2-l1 的单源模型与 u2-l2 的 ACL 运行时真正跑成可执行程序，覆盖三个模块。一是样例布局：区分「自包含」（`add`：一个 `.asc` 含 Kernel + Host 调用 + 数据生成 + 校验四合一，编出 `demo` 自检）与「脚本式」（`add_tpipe_tque`：数据/校验交 Python，靠 `.bin` 衔接算子与校验两个进程）。二是编译运行：由 CMake 驱动，`find_package(ASC)` 加载昇腾工具链，`project(... LANGUAGES ASC CXX)` 启用 ASC 语言，`--npu-arch` 经生成器表达式 `$<$<COMPILE_LANGUAGE:ASC>:...>` 仅透传给昇腾编译器；`CMAKE_ASC_RUN_MODE` 在 `npu`/`cpu`/`sim` 三种运行模式间切换，切换前须 `rm CMakeCache.txt`；端到端流程为 `source set_env.sh` → `cmake` → `make` → `./demo`。三是数据校验：确定性输入可用 `std::equal` 精确比对（Host 与 Device 执行同一 IEEE-754 加法），随机或低精度输入应改用 `np.isclose` 带容差比对，且须满足约束 `totalLength == numBlocks × blockLength`。Kernel 内部的 `GlobalTensor`/`LocalTensor`/`DataCopy`/`Add` 暂作黑盒，留待 U3（内存与搬运）、U4（矢量计算）展开。
