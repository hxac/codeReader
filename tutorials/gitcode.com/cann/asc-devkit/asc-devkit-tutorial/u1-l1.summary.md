本讲为 Ascend C 学习手册开篇，建立项目定位与多层级 API 架构的全局认知。核心结论：Ascend C 是 CANN 推出的昇腾算子开发语言（原生 C/C++、最小化扩展），asc-devkit 是承载其 API 的开源仓库；秉持高性能、完备性、易编程、可调试、兼容性五大目标与「没有银弹」「渐进式学习」理念。本讲引入的关键术语：三类完备能力接口——框架编程 API（Tpipe/Tque，自动管内存与同步）、基础 API（C++ Tensor，自主管理）、语言扩展层 C API（SIMD/SIMT，C 指针）；两类效率工具——高阶 API、算子模板库。选型按算子形态（离散/连续）、语言偏好（C/C++）、目标取向（易用/极致）三维度决策。贯穿约定：算子统一基于 `<<<>>>` 调用与 Host/Device 混合编译开发，且不同芯片对各 API 的支持范围不同。
