本讲为 CANN Runtime 手册第一讲，建立全局认知。核心结论：本仓由 Runtime 组件（设备、流、Event、内存、任务调度）与维测组件（msprof 性能调优、adump 精度调试、log 日志，均位于 src/dfx/）构成，不含算子数学实现与内核态驱动。关键概念：Host-Device 异构编程模型——两侧内存独立、数据显式拷贝、任务异步下发进 Stream、显式同步收结果；Device、Context、Stream、Task 逐层 N:1，同 Stream 严格保序、跨 Stream 并行，多数 API 靠线程绑定的 Context 隐式确定设备。四层架构为接口层（src/acl 与 src/runtime/api）、特性层、核心层（src/runtime/core）、驱动适配层（driver 与 config），以用户态动态库部署，经 /dev/davinci* 进入内核态驱动 ascend_km。并以 aclrtSetDevice 调用链示范全仓通用阅读范式：aclrtXxx→rtXxx→Api::Xxx→具体对象。
