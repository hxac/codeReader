本讲建立 HCCL 仓库的目录地图。顶层分为 src（源码）、include（对外头文件 hccl.h 与 hccl_mc2.h）、experimental（社区试验代码，与 src 同构但不编入商用版本）、test（ut/st）、docs、examples 与 build.sh。src 仅含 common（通用横切模块，含跨仓解耦通道 hcomm_dlsym）与 ops。核心是 src/ops 的组织原则：一个算子一个目录，每目录按「入口 _op + selector（选算法）+ executor（编排执行）+ template（按 aicpu/aiv/ccu 引擎分目录的具体搬运算法）」标准化，由 AGENTS.md 四条架构硬约束（分层依赖、控制面/数据面分离、HCCL 与 HCOMM 经 dlsym 解耦、新算子落标准结构）规定；selector/executor/template 为算子私有，topo 适配 rankGraph 拓扑、属控制面基础设施而全体共享于 op_common。本轮演进新增「代价模型选择器 + Tuner 插件」体系：op_common/selector 下 selector_engine、cost_model、cost_table、hccl_algo_dims 等，common/tuner 负责插件加载（导出符号 hcclTunerPlugin_v1），examples/06_tuner_plugin 为参考实现。关键术语：算子、算法、引擎、代价模型、四大组件。
