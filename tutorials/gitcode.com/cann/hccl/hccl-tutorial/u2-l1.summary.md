本讲义梳理 HCCL 对外 API 的稳定入口：`include/hccl.h` 用 `extern "C"` 声明了 14 个通信算子 C 接口，分为集合通信 11 个（Broadcast、AllReduce、ReduceScatter 及其变长 V 版、AlltoAll 系列等）与点对点通信 3 个（Send、Recv、BatchSendRecv）。核心结论是所有算子共享一套统一参数模型：缓冲区、数据量 count、`dataType`、归约类型 `op`、寻址（root 或 destRank/srcRank）及执行上下文 comm/stream。其中 count 表示元素个数而非字节，且其基准因算子而异：AllReduce 与 ReduceScatter 的 recvCount 按输出计，AllGather 的 sendCount 按输入计。引入的关键术语包括：集合通信与点对点通信二分、变长（V）算子用 counts/displs 数组替代标量、跨仓类型 `HcclDataType`（HCCL_DATA_TYPE_*）与 `HcclReduceOp`（HCCL_REDUCE_*）定义在 hcomm 仓的 hccl_types.h 中、归约类算子才有 op。此外区分三种执行形态：单算子模式与图捕获（aclgraph）都走 hccl.h 的 C 接口，图模式（Ascend IR）则经 Graph Engine 通过 REG_OP 调度，不经 hccl.h。本讲为 Unit 2 单算子执行主链路奠定对外接口认知。
