本讲讲解算法执行器 Executor：它接住 Selector 产出的 algName，负责「算资源 + 编排执行」。抽象基类 InsCollAlgBase 定义三大生命周期方法——CalcAlgHierarchyInfo（把物理拓扑切分为子通信域）、CalcRes（产出资源需求单 AlgResourceRequest）、Orchestrate（按顺序编排 template 搬数据）；前两者在 host 资源计算阶段调用，后者在执行阶段调用。注册表 CollAlgExecRegistryV2 采用「单例 + 二级 map + 工厂」设计，REGISTER_* 宏在编译期把拓扑匹配器与 N 个 template 绑进 executor 类模板，运行时以 (opType, algName) 查表即得绑好的实例。门面函数 HcclExecOp 三步走：查表实例化 → HcclGetAlgRes 算资源（含缓存复用与资源不足回退 AICPU_TS）→ 引擎分发调 Orchestrate。具体执行器 InsV2AllReduceSequenceExecutor 用 4 个 AICPU 模板顺序编排实现分级 AllReduce（RS-节点内 → RS-节点间 → AG-节点间 → AG-节点内），步骤串行使 thread/notify 取 max 复用。关键约束：algName 须与注册宏参数严格一致，否则查表失败。
