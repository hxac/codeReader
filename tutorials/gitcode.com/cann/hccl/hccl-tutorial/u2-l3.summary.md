本讲在 u2-l2 入口链路基础上深入三层：一是 OpParam——HCCL 贯穿「入口→Selector→Executor→Template」的中央参数结构，自身不申请 ctx（device 资源挂 resCtx），关键字段含 tag（topoInfo 缓存键）、inputPtr/outputPtr、三个旋钮 opMode/engine/algType、opType 及 DataDes 联合体（由 opType 决定有效成员，如 AllReduce 用 count+dataType）；FillAllReduceOpParam 负责 API 入参装配，用 DATATYPE_SIZE_TABLE 把元素 count 换算为字节数（AllReduce 输入输出等长），engine 留待 HcclGetOpExpansionMode 填写（u2-l4）。二是入参校验：遵循「廉价优先、尽早失败」，RPT_INPUT_ERR（EI0003 结构化上报）+ CHK_PTR_NULL/CHK_RET 二段式拦截，CheckCount/CheckDataType(needReduce)/CheckReduceOp 承担业务校验，与跨算子复用的 HcomCheck* 系列并存。三是本轮新增拓扑特征 TopoInfoWithNetLayerDetails::hostDpuOnly（CalcHostDPUOnly 判定框间仅 Host DPU 可达，序列化同步对齐）与 ENGINE_PREFIX_MAP/ENGINE_STR_MAP 引擎前缀反查表，为 true 时新选择器仅保留 HOSTCPU 引擎。
