本讲覆盖 AIV 引擎模板家族的最小模块：抽象基类 `AivAlgTemplateBase`、工具集 `hccl_aiv_utils`（`AivOpArgs` 参数包、kernel 二进制注册与下发）、以及 Mesh 1D 下的 one-shot/two-shot AllReduce 两个模板。核心结论：AIV 把算法逻辑固化在 Vector Core 上的预编译 kernel 中，Host 只组装参数包并 launch，路径短、延迟低，但挤占向量核，适合小数据场景；AIV Cache 以七元组（通信域名、算子类型、count、数据类型、归约算子、root、核数上限）为键，首次调用录制指令序列，后续命中直接重放，旁路 Selector 与资源计算，故入口分发链中 `HcclAivCacheCheckAndReplay` 位于 Selector 之前。one-shot 全量直写、scratch 为 rank 数，适合微消息；two-shot 拆成 ReduceScatter+AllGather、scratch 为常数，适合中等消息。关键术语：`AivOpArgs`、`ExecuteKernelLaunch`、`AivInstruction`、编译期属性 `TemplateProp props`（isNhr 影响代价模型组网类型）、静态代价标定 `CalcCostCoeff`（申报 A/B/C 系数，空返回表示未标定不参与比价，供 u8 代价模型选择器使用）。
