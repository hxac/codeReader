op_common 是 hccl 算子的「公共骨架」，由四大组件构成：selector（选算法，产出 algName 字符串）、executor（编排执行并算资源）、template（下发 kernel 搬数据）、topo（全体算子共享的拓扑适配，产出 TopoInfoWithNetLayerDetails）。前三个每算子私有，topo 抽至 op_common 共享。对外门面是两个函数：Selector() 负责拓扑计算与算法选择，HcclExecOp() 负责查表、算资源、编排执行，二者靠 algName 字符串接力，且 HcclExecOp 可在资源不足时经 FallbackOp 回退重选。

核心是三大注册表（均为单例 + 工厂 + 静态初始化）：SelectorRegistry（键 opType/priority）、CollAlgExecRegistryV2（键 opType/algName）、InsAlgTemplateRegistry（键 template 名），对应注册宏 REGISTER_SELECTOR_BY_OPTYPE、REGISTER_EXEC_V2、REGISTER_TEMPLATE_V2。关键设计：executor 与 template 在注册宏中编译期绑定（template 作 executor 模板参数），运行时以 algName 查 executor 注册表即得「已绑好 template 的 executor」。整条数据流 selector→executor→template 由 algName 这一脆弱字符串契约串联，新增算法须在 selector 产出端与 executor 注册端同步。
