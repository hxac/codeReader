本讲展开 op_common 第四组件 topo（拓扑适配），它是全体算子共享的通信域控制面基础设施，只向 RankGraph 查询、不下发数据。核心分四个模块：一是输入快照数据结构 TopoInfo 与 TopoInfoWithNetLayerDetails，关键字段含 topoLevelNums（算法可见层级数，某层单一实例覆盖全部 rank 即停止累加）、level0Topo（CLOS/MESH 形状）、netLayerDetails（每层实例数与大小明细）；二是匹配器抽象 TopoMatchBase 与纯虚接口 MatchTopo，executor 经注册宏在编译期以模板参数绑定 TopoMatch1D（扁平单级，对应 SoleMesh 类算法）或 TopoMatchMultilevel（多级，对应 MeshNHR 类算法），产出多级子通信域描述 AlgHierarchyInfoForAllLevel；三是 TopoMatchMultilevel 的 TopoForLayer0/1/2 自底向上切分：Layer1/Layer2 按「取模同位 + 物理链路校验」取跨层同位卡，非对称场景按 GCD 细切 Layer0；四是本轮新增的 CalcHostDPUOnly 与 hostDpuOnly 字段，按「多机、多层、最外层 CLOS 全覆盖且 endpoint 全在 Host 侧」判定框间仅 Host DPU 可达的专用拓扑并随快照序列化，下游使 SelectorEngine 只保留 HOSTCPU 引擎、CostTable 剔除依赖 device 链路的算法，并令两级 CLOS 场景退化为「Layer0 单卡 + Layer1 全组」。数据流分两段：Selector 阶段 HcclCalcTopoInfo 算出并缓存 topoInfo，Executor 阶段 MatchTopo 现切 algHierarchyInfo 供后续资源计算与 template 分级编排。
