本讲是 Unit 1 实践收尾，把前置概念落成可运行的 HCCL 单算子程序，覆盖三个最小模块：examples 目录样例定位、HcclAllReduce 参数模型、完整生命周期串联。核心结论：单算子程序生命周期为 aclInit → HcclGetRootInfo → HcclCommInitRootInfo → 算子下发 → aclrtSynchronizeStream → 资源释放。样例采用单进程多线程模型，一个进程开 R 个线程各绑一张 NPU，所有 rank 共享 rank0 生成的同一份 rootInfo 建立通信域。引入的关键术语与概念：rootInfo（建域共享凭证）、HcclComm（通信域句柄）、HcclDataType/HcclReduceOp、device/host 内存与 stream（异步任务流，算子异步下发后须同步流方得可靠结果）。HcclAllReduce 输入输出等长；与之对照，AllGather 无 op 参数、recvBuf 长度为 sendCount × R（只拼接不归约），这是综合实践将 AllReduce 改写为 AllGather 的核心考点。需注意通信域管理类 API 及 HcclRootInfo/HcclComm 等类型来自 CANN 工具包头文件，不在本仓库 include/ 内。
