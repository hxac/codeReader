本讲剖析 metadef 最基础的两个枚举体系：`ge::DataType` 与 `ge::Format`。核心结论：二者的 C++ 枚举均逐项转发自 `c_types.h` 中的纯 C 枚举（`C_DataType`/`C_Format`），取值顺序是 ABI 契约，只能尾部追加不可插入。`GetSizeByDataType` 为 inline 查表函数，小于 1 字节的类型（如 DT_INT4）以 `kDataTypeSizeBitOffset(1000)+比特数` 编码大小，返回 -1 表示不定长或非法。`Format` 运行时是 32 位位域：低字节主格式、中间 2 字节 sub-format、bit24–27 存 c0 编码，配套 `GetPrimaryFormat`/`GetSubFormat`/`GetC0Format`/`GetC0Value` 完成编解码（`GetC0Value` 按 2 的 k-1 次幂还原），解码纯位运算不做范围校验。`GetSizeInBytes`/`GetFormatName` 走「types.h 声明 → TypeImpl 实现 → libmetadef.so 符号」链路，含 int64 乘法溢出检查与比特向上取整（CeilDiv）。关键术语：位域编码、C0（矩阵单元分形颗粒）、primary/sub-format、`GetTypeId<T>`（静态变量地址做类型 ID，为下一讲 AnyValue 埋伏笔）、pkg_inc 层的指针/整数互转工具。
