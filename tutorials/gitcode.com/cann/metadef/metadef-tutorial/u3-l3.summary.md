本讲讲解 metadef exe_graph 体系中算子 Tiling 阶段的上下文。核心结论：TilingContext 是框架调用 TilingFunc 时传入的唯一参数，继承链（KernelRunContext→KernelContext→ExtendedKernelContext→TilingContext）零新增数据成员、纯类型化视图，末尾 static_assert 固化标准布局 ABI 契约。全部接口本质是「槽位下标公式 + 指针类型解释」：输入 shape/tensor 占前 inputs_num 槽（可按 StorageShape/Tensor/TensorV2 多视角解释），输出 shape 紧随其后，compile_info、platform、tiling_func、deterministic 等隐藏槽位以 inputs+outputs+N 算式追加在输入段尾部；按 IR 序号访问经 AnchorInstanceInfo 翻译为物理槽位，REQUIRED/OPTIONAL 是 DYNAMIC 取第 0 实例的语法糖。tiling 结果统一写入 TilingOutputIndex 枚举定义的输出槽位（tiling key、SimdNumBlocks、TilingData、workspace、SimtBlockDim 等），Set/Get 成对、失败返回 GRAPH_FAILED 或哨兵值，枚举值即下标、只能尾部追加。GetTilingData&lt;T&gt; 将结构体覆写进字节流并登记长度，类型正确性无运行期检查。TilingParseContext 是加载期一次性上下文，把编译期 json 反序列化写入框架预分配的 CompiledInfo，供后续 GetCompileInfo 读取。关键术语：tiling data、TilingOutputIndex、TilingData 容器、CompileInfo、PlatformInfo、确定性开关，为 u3-l4 推理上下文三兄弟与 u3-l5 TilingData 宏专题做铺垫。
