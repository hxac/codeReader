本讲讲解 metadef 的 op_impl_registry 体系，即算子实现函数（行为）的注册与发现机制，与 u4-l3 的原型注册（OpDefFactory 存创建函数）相对。核心结论：体系分四层——注册入口 OpImplRegisterV2（IMPL_OP 宏链式配置）、本地单例 OpImplRegistry（op_type 到函数集的 map）、C 导出 api 层（GetRegisteredOpNum 与 GetOpImplFunctions(V2) 两步协议跨 so 传递）、聚合层（OpImplRegistryHolder 管理 so 快照与 dlopen 句柄，OpImplSpaceRegistry 跨 so 逐函数融合）。关键技巧是拷贝构造触发注册：链式调用配置临时对象，拷贝到静态变量时以「非空才覆盖」语义写入单例，故注册全部发生在静态初始化期、无需加锁，且必须写在同一条链上。关键概念：OpImplFunctionsV2（约 20 个阶段函数指针如 InferShape/Tiling/TilingParse，加位标志、private_attrs 与 st_size/version/reserved 三重 ABI 守护，V1/V2 靠继承切片互转）；Space 合并规则为「先到先得、重复告警、不覆盖」，同一算子各阶段函数可来自不同 so；Holder 按 so 内容去重。AddSoToRegistry 链路是下一讲 u4-l5（opp 包结构与 so 搜索）的入口。
