本讲覆盖 metadef 张量描述体系的四个最小模块：gert::Shape/Stride、StorageShape 与 gert::Tensor/TensorV2、TensorData 所有权管理、ge::Tensor 与 gert::Tensor 双体系对比。核心结论：gert::Shape/Stride 是定长（最多 25 维）POD，拷贝只复制有效维度，GetShapeSize 连乘溢出返回 INT64_MIN，且不处理未知维度（-1/-2 当普通数参与乘法）；Tensor 由 StorageShape（origin 与 storage 双视角）、StorageFormat、DataType、TensorData 组成，TensorV2 额外携带 Stride 与 offset 以描述非连续张量；TensorData 禁拷贝只移动，用函数指针 manager 配三种操作码在 POD 里模拟多态，完成取址、释放、共享计数，kFollowing placement 表示数据紧跟结构体（CreateFollowing 头体连续分配）。对比结论：ge::Tensor 是图编译期的 shared_ptr<Impl> 壳，支持 unknown shape/ShapeRange；gert::Tensor 是执行期全 POD 值语义，同名接口契约不同（如 GetShapeSize 对标量分别返回 0 与 1）。关键术语 origin/storage shape、placement、TensorAddrManager、Following 布局、TensorV1/V2 将由后续 KernelContext 讲承接；老头文件 exe_graph/runtime/tensor.h 已弃用，应改用 runtime_tensor.h。
