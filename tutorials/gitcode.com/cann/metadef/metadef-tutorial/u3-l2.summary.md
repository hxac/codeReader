本讲沿上下文继承链上移一层，精读四个模块：KernelRunContext 纯 C 结构体的 48 字节布局契约（头部计数、两个 void* 扩展指针、output_start、values[1] 柔性指针数组，实际分配按槽数扩展，槽序列输入在前输出在后扁平排列）；ExtendedKernelContext 以 protected 继承 KernelContext 且零新增数据成员，仅靠两处 static_cast 把 compute_node_info/kernel_extend_info 指针类型化为 ComputeNodeInfo/KernelExtendInfo，并对外提供 GetInputDesc、GetDynamicInputDesc、GetAttrs、GetKernelName 等十几个 Get* 方法（勘误：并无 with* 方法）；引入 AnchorInstanceInfo 承担「IR 索引→物理槽位」翻译，REQUIRED/OPTIONAL 读取是 DYNAMIC 读取第 0 个实例的语法糖；KernelExtendInfo 为 72 字节含 56 字节保留字段。框架侧 Builder 在裸内存上逐字段赋值构造 KernelRunContext，经 reinterpret_cast 换视图；TilingContext 等派生类零成员，专属数据是追加到 values 尾部的槽位，由 Offset 模板按位置解释。安全性由 static_assert、ABI 偏移测试与全线空值失败语义三层兜底。
