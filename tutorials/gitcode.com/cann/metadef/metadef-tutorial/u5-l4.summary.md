本讲围绕 metadef 的 ABI（应用二进制接口）兼容性展开：因大量预编译 `.so` 依赖 `libmetadef.so`，接口变更必须保持 ABI 兼容（不重编译依赖方也能正确互操作），这是 README 的硬性贡献约束。核心模块是 exe_graph（gert）体系的三道分层守护防线：头文件末尾约 27 处 `static_assert(std::is_standard_layout)` 拦截破坏标准布局的改动（如加虚函数）；`abi_compatibility_for_exe_graph_unittest.cc` 用硬编码常量断言 25 个结构体的 `sizeof`（如 Shape=248、Tensor=752）与逐成员偏移量，分别拦截总大小变化与内部错位。关键概念包括 POD/标准布局、零新增成员的类型化视图（七个上下文类 sizeof 均为 48）、`reserved_` 保留字段（从尾部预留空间切出新字段实现安全演进），以及 ge 老体系靠 pimpl 与 `AnyValue` 类型擦除软隔离的对照策略。核心结论：ABI 演进正解是并列新版本（如 `TensorV2`），坚持「尾部追加、老取值不复用」。
