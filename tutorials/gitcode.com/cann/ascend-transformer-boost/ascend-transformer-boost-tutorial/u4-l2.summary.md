本讲讲解 ATB 中两个核心归一化算子 `LayerNormOperation` 与 `RmsNormOperation`，承接 u3-l1 的 `OperationBase` 骨架。数学上 LayerNorm 减均值除标准差、带 γ/β；RMSNorm 只用均方根、通常仅 γ，更轻量，ε 用于防除零且被强校验（小于 2e-38 即拒建）。二者均用「`layerType` 三态（NORM/PRENORM/POSTNORM）+ 量化字段」组合表达多种结构，而非拆成多个算子，与 u4-l1 的 `LinearParam` 同属「单 Param 覆盖 N 种行为」的设计哲学。输入输出个数由 `layerType × quantType × dynamicQuantType`（RMSNorm 再加 `rstd`/`precisionMode`/`modelType`）共同决定，`GetInputNum`/`GetOutputNum` 是 `VariantPack` 装填依据。`InferShapeImpl` 基线为 `out[0]=in[0]`，再按量化（改 int8、加逐 token 的 scale/offset 并砍最后一维）、PRENORM（残差透传）、RMSNorm rstd（gamma 维置 1）做增量。Runner 分派规律为 Ascend950 走 aclnn 融合算子、其它芯片走 ops 后端，后者把全部变体收敛到同一个 `NormOperation` kernel 节点，仅靠张量接线与标志位区分。另介绍 `CohereLayerNorm` 这一 Command R Plus 风格变体（归一化到 [0,1]，仅 910B 支持）。
