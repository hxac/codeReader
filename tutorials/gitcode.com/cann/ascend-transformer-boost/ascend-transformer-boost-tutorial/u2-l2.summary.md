本讲义讲解用 Python 包 torch_atb 调用 ATB 算子的轻量方式。`import torch_atb` 时，`__init__.py` 先以 `RTLD_GLOBAL` 按依赖顺序预加载 libmki、libasdops、libatb 等 6 个动态库并设置 `ATB_HOME_PATH`，再导入 pybind11 编译的 `_C` 扩展，顺序不可颠倒。算子调用三步走：构造 `Param`（如 `LinearParam`）→ `Operation(param)`（按 Param 类型匹配 C++ 构造函数）→ `forward([输入张量])`，一行 `forward` 等价于 C++ 的 Setup+Execute+流同步。

桥接机制是核心：`ConvertToAtbTensor` 将 `torch::Tensor` 零拷贝指针共享为 `atb::Tensor`，输出张量由 ATB 推导形状后在 NPU 自动创建；Context 经 `GetAtbContext` 以 `thread_local` 自动托管并绑定 TorchNPU 当前流；workspace 由 `MemoryManager` 自动管理，故 Python 端无需手动建 Context、分内存。最后引入图算子：`Builder` 经 `add_input`/`add_node`/`mark_output` 组图，`build()` 返回的图算子同样是 `Operation`，统一用 `forward` 执行，收益为统一调度、复用 workspace、缓解 Host Bound。本讲引入 Param、Operation、OperationWrapper、Builder、thread_local Context 等关键术语，供后续讲义承接。
