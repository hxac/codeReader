本讲讲解 ATB 服务 KV Cache 与分页注意力的算子族。KV Cache 让自回归推理免于重算历史，推理分为 prefill（写初始 KV）与 decode（每步读历史 KV）两段；PagedAttention 借鉴 OS 分页，将 KV Cache 切成固定 block，用 blockTable 记录逻辑到物理块的映射，按需申请、共享 block 池，化解长序列多请求下的显存碎片与浪费。引入的关键术语有：block、blockTable、contextLens（Host 上每 query 实际 KV 长度）、slotMapping（写入槽位映射）、mlaVHeadSize（MLA 合并 KV）。PagedAttentionOperation 输入基线 5 个（query/keyCache/valueCache/blockTables/contextLens），随 maskType、quantType、calcType、mlaVHeadSize 等开关动态增减；InferShapeImpl 以 query 为基线、末维取 V 的 head_size；CreateRunner 按芯片分派（950 走 aclnn，非 910B 经 RunnerPool 复用 910A，910B 新建）。写入算子 KvCacheOperation 最朴素：Param 仅 rsv、输入恒 5、输出 0、in-place 写回 past；ReshapeAndCache 按 slotMapping 寻址，PagedCacheLoad 反向将分页 cache 读回连续张量。它与普通 SelfAttention 的差异集中于 K/V 来源（完整张量 vs 分页缓存指针）、blockTables 间接寻址、contextLens 显式长度三处。承接 u4-l4，下接 u4-l6（RoPE）与 u4-l7（MLA）。
