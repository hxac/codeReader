本讲围绕 `atb::Context` 展开——它是一组 Operation 共享的运行时环境，集中托管执行流集合、异步 Tiling 拷贝流/事件、Host/Device TilingBufferPool、RunnerPool 与 Allocator 等跨算子可复用的全局资源。Context 为纯虚抽象类，须用工厂函数 `CreateContext`（三个重载：默认、自定义 Allocator、自定义池块数）与 `DestroyContext` 管理生命周期，释放顺序为「算子→流→Context→aclFinalize」。执行流分单流 `SetExecuteStream` 与多流 `SetExecuteStreams`（配合算子级 `SetExecuteStreamId` 路由到不同 stream）。本讲引入两个正交的下发枚举：`ExecuteType`（NORMAL/PRELAUNCH/LAUNCH，控制一次 `Execute` 做「PreLaunch + Launch」中的哪几段，值存于 `thread_local` 变量，服务于两段式并发下发）与 `LaunchMode`（KERNEL/GRAPH，控制单算子还是整图下发，为 Context 普通成员，默认 KERNEL；整图模式配合 `aclmdlRICapture` 缓解 Host Bound，并使 Tiling 缓冲改走 Allocator 而非池）。本讲为 u1-l6（Operation 接口）的前置铺垫。
