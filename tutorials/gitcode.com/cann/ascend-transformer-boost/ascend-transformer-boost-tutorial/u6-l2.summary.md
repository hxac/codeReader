本讲聚焦自定义算子 Kernel 层的三个最小模块：Tiling、AscendC Device Kernel、MKI 注册，以 `customize_blockcopy`（KV Cache 块拷贝算子）为贯穿案例。核心结论：Tiling 是 Host↔Device 唯一信使，`TilingData` 字段顺序为隐式契约，算法负责按核切工作量（`blockDim`/`perCore`/`tail`）并设 dtype 分支码（`tilingId = TILING_DTYPE_IDX * typeByte`）。AscendC Kernel 采用三段式流水（CopyIn→Compute→CopyOut），数据须在片上 UB（`LocalTensor`）处理，靠 `TQue` 双缓冲（`BUFFER_NUM=2`）以搬入掩盖计算、消除访存延迟；产物为标量时可省 CopyOut。MKI 注册靠 `KernelBase`（`REG_KERNEL_BASE`，管 Tiling）与 `OperationBase`（`REG_OPERATION`，管选 Kernel）两个基类，注册名三处一致（`opDesc`/`GetKernelByName`/`add_kernel`）为铁律；多芯片（910B/310P）共用 Kernel 类名、各写一份 Device `.cpp` 实现分流。关键术语：`TilingData`、`BlockDim`、`TilingId`、`TQue`/双缓冲、`TILING_KEY_IS`。
