ATB（Ascend Transformer Boost）是位于深度学习框架与 CANN/昇腾 NPU 之间的加速库，专为 Transformer 训练与推理设计，将自注意力、KV Cache 等高频结构做成融合算子。推理时 Host（CPU）将算子逐个下发到 Device（NPU），经合法性检查、InferShape、Tiling、Workspace 分配、Launch Kernel 等步骤，前几步在 Host 完成，仅 Launch Kernel 让 NPU 真正计算；Host 下发慢于设备执行即出现 Host Bound，ATB 主要解决此问题。它提供三大能力：融合算子（高性能单算子，含 Kernel 融合）、图算子（用 GraphOpBuilder 组合多算子统一调度、复用 Workspace，但不做 Kernel 融合）、插件机制（自定义算子接入框架），辅以 Tiling Cache、调度优化、内存优化等运行时优化。代码为六层分层架构，公共 API 集中于 include/atb/，由总入口 atb_infer.h 汇总，核心符号为 Operation、Context、Tensor/VariantPack、GraphOpBuilder。
