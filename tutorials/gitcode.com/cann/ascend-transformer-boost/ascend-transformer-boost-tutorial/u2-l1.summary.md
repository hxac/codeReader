本讲是「算子调用实战」首篇，以 faupdate（Flash Attention 局部统计量归并算子）的 C++ demo 为例，确立用 C++ 调用任意 ATB 算子的固定「五段式骨架」：资源初始化 → 创建算子并装填 VariantPack → Setup → Execute+流同步 → 资源释放。初始化是 ACL 管底层（aclInit/aclrtSetDevice/CreateStream）、ATB 管高层（CreateContext）的混用；算子由模板工厂 CreateOperation 按 Param 创建，输入输出装入 VariantPack，顺序须与算子定义一致。Setup 在 Host 侧做校验与 Tiling、输出 workspaceSize，由调用方分配 workspace；Execute 异步下发 Device，须 aclrtSynchronizeStream 才能取结果。释放按创建逆序：tensor/workspace 先、算子次之（算子先于 context）、最后 aclFinalize。build.sh 的核心是 CXX11 ABI 自动对齐（以 PyTorch ABI 为准）加 -I/-L/-l 对接 ATB 与 CANN 的头文件和库，所有 op_demo 共用同一编译模板、仅 Param/Tensor 不同。本讲为后续 Python 调用（u2-l2）与参数体系（u2-l3）奠基。
