本讲下钻 ASC Dialect 的 Operation 定义与 Op Interface，核心是「模板族＋统一接口＋参数顺序约定」三件套。Base.td 用 class 继承链与 multiclass 沉淀公共结构，一行 defm 展开成 L0/L1/L2/L3 四个 Op 变体，参数差异对应 Ascend C 三条原型（单 mask、数组 mask、calCount）。APIOpInterface 声明 getAPIName 与 getDst/getSrc0 等访问器，方法名与 td 形参名对齐，使 VecBinary.h 里一个 C++ 发射模板可服务约 20 个同族 Op。参数顺序约定把 Ascend C「运行时×模板×必选×可选」四象限签名按「运行时必选→模板必选→运行时可选→模板可选」重排为 IR 与 Python 形参；可推导的类型模板参数（typename T）不进 IR，不可推导者（isSetMask）殿后为 UnitAttr，发射层再从 tensor 类型逆向拼回模板实参。关键术语：defm 展开、extraClassDeclaration、paramTypeLists 编码、data_copy 七变体共享 apiName、反推四步法（分类→删除→重排→落地）。注意 L3 变体目前无 Python 前端入口；下一讲承接 TableGen 四条生成管线的实现。
