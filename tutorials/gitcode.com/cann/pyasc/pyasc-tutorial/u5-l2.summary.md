本讲下钻 ASC Dialect 的 Type 与 Attribute，覆盖 Core/Types.td（手写复杂 TypeDef）、API/Types.td（参数结构体类型清单与自动生成）、Attributes.td（枚举属性）、Types.cpp（Tensor 家族手写解析打印）。核心结论：Ascend C 写在尖括号里的模板参数被编入 MLIR 类型的 parameters，发射层再原样拼回 C++ 模板实参；类型有两条来源——TBuf、TQue、QueBind、Matmul、Tensor 等复杂类型在 Core/Types.td 手写五件套（基类、parameters、assemblyFormat、builders、extraClassDeclaration），上百个参数结构体类型只在 API/Types.td 登记名字、由 gen-api-typedefs 展开成薄定义，分流开关是 APIType 模板参数是否为空。引入术语：I32EnumAttr 一一镜像 Ascend C 枚举并生成 stringify/symbolize；pretty 打印让枚举印成 vecin，未接 custom directive 的枚举印成 0 : i32；Matmul 类型携带十七个参数充当模板实参包（含 MatmulConfigAttr）；BaseTensorImpl 以 CRTP 手写 Tensor 的 parse/print；registerTypes 统一注册全部类型。
