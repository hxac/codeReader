本讲打开 pyasc 自研 TableGen 后端这个黑盒：`lib/TableGen/` 下 7 个后端编入 `ascir-tblgen`，靠文件级静态 `Emitter::OptClass` 对象注册，`main.cpp` 仅 20 行，CMake `tablegen()` 规则声明「td → 后端 → .inc」的逐条触发。`-gen-pybind-defs` 遍历全部 Op 记录，按 `fetchArguments` 的类型映射（Variadic/Optional/UnitAttr 等到 C++ 类型与默认值）批量打印 `create_asc_<类名>` 绑定，方法名用类名（如 `AddL2Op`）而非 API 名，方言 `ascendc` 特判缩写为 `asc`；产物被 include 进 `OpBuilder.cpp` 的 `.def` 链中间。发射线由 td 两位字段驱动：`genEmitter`（带 `AscConstructor/AscMemberFunc/AscFunc` 任一 trait 即置位）是闸门，`paramTypeLists` 的 `-3..6` 整数编码描述「IR 参数 → C++ 模板实参/函数实参」映射，空表则委托运行期 `autoPrintOp` 三分支模板；`AscendCOpEmit.h.inc/.cpp.inc` 分别拼进 `Translation.cpp` 的 `PrintableOpTypes` 元组与函数体，经 `TypeSwitch` 分派。关键结论：无 trait 的 Op（Add 家族）走手写发射，带 trait 者全托管生成器，判据只看 td；`APIType` 支线展示「td 生成 td」两段式生成。承接概念：TableGenMain、pybind11 具名参数、`LogicalResult`/`FAIL_OR`、`autoPrintOp`，为 u5-l5 pybind 桥接层与 u6-l5 发射细节铺垫。
