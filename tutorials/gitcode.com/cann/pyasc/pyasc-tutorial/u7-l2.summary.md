本讲承接 u7-l1，精读 pyasc 高阶 API 的激活与归一化部分：softmax/swiglu 定义于 activation.py，tanh/exp 等逐元素数学函数在 math.py（经 math_op_impl 量产，builder 方法名字符串派发），rmsnorm 在 normalization.py，均由 adv/__init__.py 统一汇入 asc.adv 命名空间。核心结论：高阶 API 的 Python 前端极薄，只做可选参数判空、标量经 _mat 物化（RuntimeNumeric 兼容设备侧值）后建单个 create_asc_XxxOp，多步计算在 Ascend C 内联实现中展开；归约类 API 需 RmsNormTiling 这类切分说明书，倒数等量由 Host 编译期算好。围绕 06_gelu、07_swiglu、08_rmsnorm 三例讲清 TBuf 两种复用（多步草稿与常驻常量）、同一 UB 缓冲上连续向量计算需 pipe_barrier(PIPE_V) 排序、跨流水线仍用 set_flag/wait_flag，并归纳融合算子三模式：手工组合、一步融合 API、高阶 API 加 tiling；Host 侧统一为推 launch 参数、补齐、下发、对 torch 校验，纯向量算子声明 AIV_ONLY。
