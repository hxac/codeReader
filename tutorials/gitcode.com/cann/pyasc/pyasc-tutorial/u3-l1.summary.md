本讲精读 runtime/jit.py 的 JITFunction。`@asc.jit` 以 fn 是否为 None 区分带/不带括号两种写法，装饰时即捕获源码与 AST，并做两道守门检查：选项名须在 CodegenOptions、CompileOptions、LaunchOptions 三个选项袋字段拼成的配置关键字白名单内，形参名不得与配置关键字撞名，否则装饰行即抛错。`kernel[核数, 流](...)` 由 `__getitem__` 实现：构造 LaunchOptions 暂存到实例并返回绑定方法 _run，故 LaunchOptions 不参与缓存 key。`_run` 六步：合并默认选项（调用时覆盖装饰器）、extract_kwargs 抽走并删除选项键（禁撞名的根因）、签名绑定、split_args 切分运行时参数与 ConstExpr、两级缓存查找（always_compile 全绕过）、launcher 下发。JITFunction 以 codegen、compiler、launcher 三个类属性组合整条链路，子类覆写其一即可替换一段策略，是 pyasc 首个扩展点；不带中括号的直接调用走 Function 基类 __call__ 执行原始 Python 函数。
