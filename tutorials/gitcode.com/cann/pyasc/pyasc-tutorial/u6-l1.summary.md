本讲是 Pass 优化单元的开篇地图讲，梳理 pyasc 后端全部 16 个自定义 Pass。每个 Pass 按「三件套」组织：Passes.td 声明（注册名、作用域、工厂函数、依赖方言），TableGen 生成 Passes.h.inc 作粘合，Passes.h 注册，lib/Dialect/Asc/Transforms 下同名 .cpp 派生基类并覆写 runOnOperation 实现。作用域分 ModuleOp 与 FuncOp（嵌套 Pass，经 addNestedPass 挂载）。调度由 compiler.py 三个函数装填为 lowering（补全惰性张量形态）、optimizing（同步重建链 EraseSync→HoistQueBind→InsertSync）、postprocessing（发射铺路）三阶段，insert_sync、matmul_cube_only、verify_sync、strip_loc 四个开关控制条件 Pass。DetectKernelType/DetectEnableDebug 打 asc.compile_mix、asc.enable_debug 属性实现后端向前端回传，供推导 kernel_type 与 enable_debug。单 Pass 调试可用 ascir-opt 单跑或 print_ir_before_all 观察逐 Pass IR。Noop 为不参与调度的最小模板 Pass。
