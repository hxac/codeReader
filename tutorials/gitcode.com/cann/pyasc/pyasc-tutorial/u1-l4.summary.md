本讲逐行精读 Add 示例，端到端跑通第一个算子。核心结论：@asc.jit 把 Python 函数包装成 JITFunction，函数体被编译为设备代码而非按 Python 语义执行；由 kernel[核数， 流] 中括号启动的是 Kernel，被其他 jit 函数调用并内联的是 Device 侧执行函数。引入的关键概念：GM 与 UB 两级存储；MTE2 搬入、V 计算、MTE3 搬出三条异步并发流水线；GlobalTensor 经 set_global_buffer 绑定 GM 地址，LocalTensor 以 TPosition、字节偏移与长度在 UB 上手工排布；block_length 与 tile_length 两层多核切分，双缓冲 BUFFER_NUM 使搬运与计算重叠；set_flag/wait_flag 按 MTE2_V、V_MTE3、MTE3_MTE2 三方向手动配对同步；另有 data_copy、asc.add、GlobalAddress、get_block_idx 等接口。运行模式由 config.set_platform 在 Model 仿真器与 NPU 真机间切换。
