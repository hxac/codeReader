本讲覆盖 postprocessing 收尾链的五个 Pass：DeclarePyStruct、GenerateBoilerplate、LegalizeKernelArgs 及 DetectKernelType/DetectEnableDebug，职责是为发射 Ascend C 铺路。核心结论：ascendc.cpp 里的样板代码由“Pass 在 IR 上种内容、发射层按属性打印”生成，而非 Python 拼接——include 来自按特征 Op 插入的 emitc.include，extern "C" __global__ __aicore__ 入口则由发射层依据 ascendc.global 属性打印。LegalizeKernelArgs 构成 kernel 参数 ABI 闭环：给形参打 emitasc.kernel_arg 属性、末尾追加 ffts_addr 隐藏参数并插桩 set_ffts_base_addr 与 MIX 跨核同步，前端经 getKernelArgAttrs 读表、Launcher 按表注入实参。DeclarePyStruct 递归收集 PyStructType 并保序去重，发射为 #pragma pack(push,8) 结构体，与前端 ctypes 的 _pack_=8 成对约定。两个 Detect Pass 写模块属性 asc.compile_mix、asc.enable_debug 向 Python 回传，据此推导 kernel_type（MIX/AIC/AIV）并点亮 debug 链路；asc.matmul_cube_only 则演示前端到后端的反向属性流转。
