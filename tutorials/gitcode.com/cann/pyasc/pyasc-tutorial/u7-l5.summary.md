本讲覆盖四个最小模块：ascir-opt、ascir-translate、ascir-lsp 与构建开关 PYASC_SETUP_DEVTOOLS。三个工具都是「几十行入口＋MLIR 框架主函数」的薄封装，差异只在注册内容与链接库。ascir-opt 可对 PYASC_DUMP_PATH 落盘的 codegen.mlir 单跑或串联指定 Pass（选项名即 Passes.td 注册名），是 Pass 调试核心手段；ascir-translate 的 -mlir-to-ascendc 与 Python 的 ir_to_ascendc 共用同一 C++ 发射函数 translateToAscendC，故翻译 ascir.mlir 可逐字节复现 Python 导出的 ascendc.cpp；ascir-lsp 按 LSP 协议为编辑器提供 .mlir 诊断。公共注册在 Registration.h：先收上游全部方言，再插入 ascendc/emitasc 并追加自定义 Pass。PYASC_SETUP_DEVTOOLS 仅认 1/true/ON，开启后才构建三工具并装入环境 bin/，默认只构建 libpyasc。lit 测试用 RUN: 行配 FileCheck 断言，check-ascir 目标先建工具再跑测试。
