pyasc 是用 Python 标准语法编写昇腾（910B/910C）自定义算子的编程语言：代码经编译器译为 Ascend C，再由毕昇编译器编成 Kernel 在 NPU 上执行，其接口与 Ascend C 类库一一对应。架构分五大核心模块：前端含编译和运行、Python 前端、AST 转 ASC-IR 三个模块，后端含 ASC-IR 定义（基于 MLIR Dialect）与 Ascend C 代码生成两个模块。核心数据流为 Python 源码→AST→ASC-IR→Ascend C 代码→Kernel 二进制→NPU 多核执行。关键概念：@asc.jit 拉起 JIT，小括号传编译参数、中括号传核数与流；Kernel 函数区别于 Device 侧执行函数；PYASC_DUMP_PATH 可导出中间产物。环境需 Atlas A2/A3、Python 3.9-3.12 及版本匹配的 CANN，无 NPU 时可用 Model 仿真模式。
