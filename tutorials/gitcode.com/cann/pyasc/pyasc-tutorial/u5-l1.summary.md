本讲建立 ASC-IR 的「地图」。核心结论：ASC-IR 本质是一个 MLIR 模块，ascendc 自定义方言逐条镜像 Ascend C API，控制流、算术等通用语义复用 scf、func 等上游方言。讲义覆盖四个模块：MLIR 四大概念 Dialect/Operation/Type/Attribute 与 ASC Dialect 四大件的对应；Dialect.td 声明与 Dialect.cpp 注册，实现全由 TableGen 生成；Base.td 模板族（AscendC_Op、APIOp、genEmitter、paramTypeLists），一条 defm 经 multiclass 展开同族 API 的 L0/L1/L2/L3 变体；三段式命名规则与 Core/Basic/Adv/Fwk 四目录组织。基本功是「四名合一」反查法：IR 名 ascendc.类名.成员函数 ↔ td 记录 AscendC_类名成员函数Op ↔ C++ 类 ↔ Python 的 create_asc_*；注意 dump 前缀是 ascendc. 而非 asc.（pybind 生成器的缩写），该反查技能是阅读 Pass 与发射层源码的前置。
