本讲剖析 pyasc 前端枚举与昇腾硬件概念的映射。TPosition 表示队列/缓冲区在数据流中的逻辑角色：矢量组 VECIN/VECOUT/VECCALC 与矩阵组 A1~CO2，分别映射到 Hardware 物理存储层次 UB 与 L1/L0，LocalTensor 支持清单不含 GM。HardEvent 按生产者_消费者命名：set_flag 在源队列举旗、wait_flag 在目的队列等待；方向是编译期属性（最终成为 Ascend C 模板参数），event_id 是运行时实参。Add 示例以 BUFFER_NUM=2 双缓冲（乒乓）让搬入、计算、搬出三段异步流水重叠，三对同步构成 MTE2→V→MTE3→MTE2 闭环：MTE2_V 保证读前搬完，V_MTE3 保证搬出前算完，MTE3_MTE2 借传递依赖防止跨轮覆写缓冲。set_flag 与 wait_flag 文本相邻但分属不同硬件队列，相邻不等于串行。枚举的完整传递路径为：Python IntEnum → IR I32EnumAttr → C++ 模板参数。
