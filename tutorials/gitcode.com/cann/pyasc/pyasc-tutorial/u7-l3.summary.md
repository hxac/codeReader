本讲剖析 lib/host 子包，它把 CANN 的 Host 侧 tiling 引擎接入 Python。Loader 三步走：查文件缓存、在线编译 bindings/*.cpp、importlib 加载 libhost 扩展；缓存 key 含扩展后缀与 CANN version.cfg，天然按 Python/CANN 版本隔离，进程内再以单例复用。wrappers.py 是纯类型存根，ProxyMeta 元类以类名为跨语言查找键，把构造与属性访问转发给 pybind11 的 C++ 类。tiling 链路：get_ascendc_platform() 取平台单例，tiling 对象用 set_* 描述问题，get_tiling 经 addressof 与 reinterpret_cast 零拷贝直写 TCubeTiling 内存，安全性依赖两侧结构体字段名、类型、顺序与 _pack_=8 四重对齐。同一 TCubeTiling，Host 侧走 ctypes 读取普通 int，Device 侧生成 emitasc.member 逐核实时读取；tiling 是运行时参数，改值不触发重编译。bindings 以源码形态随 wheel 分发，与 lib/runtime 的在线编译模式同构。
