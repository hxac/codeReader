本讲精读 runtime 侧的 launcher.py 与 memory_handle.py，走完主链路最后一环：把编译产物下发设备执行。kernel[核数， 流] 语法生成 LaunchOptions，只描述本次下发、不参与缓存 key。expand_kernel_args 把杂散实参规整为两类：定宽 numpy 标量与 MemoryHandle 设备指针，Python int/float 一律按 int32/float32 传参。launch_kernel 按参数 ABI 把全部参数拼成 8 字节对齐的连续字节流（参数 blob），切成 uint64 字数组下发，同步后回拷结果并释放显存。关键术语：参数 blob、MemoryHandle「上设备、回拷、释放」三段生命周期、NPU 张量零拷贝、FftsAddr 隐藏参数注入、enable_debug 尾追的 75 MiB dump 缓冲、DRY_RUN 只编译不下发；每次 run 结束还会注销全部已注册二进制，rt 底层原语的 ctypes 封装留待下一讲。
