本讲剖析 pyasc 前端 tensor.py 的 Tensor 抽象，覆盖 BaseTensor 及其子类 GlobalTensor、LocalTensor 与两套形状机制。核心结论：Tensor 不持有数据，只是 dtype 加 MLIR 值句柄的包装，方法调用都在 JIT 编译期向 IR 追加操作。GlobalTensor 是 Global Memory 视图，二段式创建：空构造后用 set_global_buffer 从带类型指针绑定地址并取得 dtype。LocalTensor 描述 Unified Buffer 的手工排布，四参构造给出 TPosition、addr（字节）与 tile_size（元素），须自行保证缓冲不重叠；重载经 OverloadDispatcher 分发，也可由 from_ir 从 IR 重建。切片 t[k:] 仅允许有 start 无 stop/step，生成 subindex 节点，表示偏移 k 个元素的新视图并返回新对象。TensorShape 是编译期元组、不进 IR；ShapeInfo 是进入 IR 的设备侧运行时形状。
