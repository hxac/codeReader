本讲覆盖 ASC-IR 发射为 Ascend C 源码的最后一步。核心结论：Translation 的 emitOperation 以白名单 PrintableOpTypes 配合 TypeSwitch 分派，每个 Op 命中一个 printOperation 重载并统一补注释与分号；未登记的 Op 直接失败，经 LogicalResult 逐层上传至 Python 抛异常。printOperation 有两条供给线：无 Asc* trait 的 Op 手写发射并手工登记，带 trait 的由 -gen-op-emit-defs 生成，空参数表时委托 autoPrintOp 三分支（构造/成员/命名空间函数）。CodeEmitter 以 TypeID 映射表提供类型、属性发射与变量声明原语；EmitNameStack、ScopedHashTable 与 RAII Scope 三件套产出 v1、c8_i32 等唯一且可读的 C++ 变量名。Kernel 的 extern "C" __global__ __aicore__ 样板由 FuncOp 发射函数按 ascendc.global 属性打印——Pass 只种属性，发射层才落纸。
