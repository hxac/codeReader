本讲把「Python 源码→ASC-IR→Ascend C」编译链路落到磁盘目录：前端在 python/asc，其中 language 是用户编程 API、codegen 负责 AST 转 IR、runtime 负责编译调度执行、_C 存放 pybind 产物，python/src 是前后端之间的 C++ 桥接层；后端在 include/ascir（声明）与 lib/（实现），bin/ 放 ascir-opt 等三个开发者工具。最重要的规律是目录镜像：language 下的 basic/adv/core/fwk 四象限，与后端 Dialect/Asc/IR 及 lib/Target/AscendC 的同名大写目录一一对应。据此得到检索链：API 文件中的 create_asc_XxxOp → 同象限 .td 里的 defm 定义 → Target 下的 printOperation 发射实现；找不到同名 cpp 时改找 include/ascir/Target/Asc 下的同名 .h。本讲引入术语：TableGen 与 .td 文件、Dialect（描述 Ascend C API 的 Asc 方言与贴近 C 语法的 EmitAsc 方言）、Pass、发射。参考代码分工：examples 教写端到端算子，python/test（pytest）回归前端行为，test（lit 加 .mlir）回归后端 IR 与代码生成。
