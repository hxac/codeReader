本讲深入 `Compiler.run` 的最后一步：把 Ascend C 源码编译成可在昇腾 NPU 上执行的 Kernel 二进制。核心模块有四：一是 `CompilationTarget`，纯函数式推导目标架构——平台折叠为 Ascend910B/910_93，给出芯片代号 c220，核类型决定单目标 `dav-c220-vec`/`dav-c220-cube` 或 MIX_AIC_1_1/1_2 的双目标组合，并附带五件套公共选项；二是 `_gen_dst_kernel` 编排器，按 KernelType 分三条路径：MIX 双目标「编 cube + 编 vec + 链接」、其余 MIX 单目标「编译 + 链接」、纯 AIV/AIC「编译 + 自链接」，最终统一为 `-Ttext=0 -static` 的可执行 ELF 镜像；三是 `_get_compiler_cmd` 命令行组装，把 `opt_level`、`auto_sync`、`debug` 等语义选项映射为 `-x cce`、`--cce-aicore-arch`、`--cce-aicore-only` 及 `ASCENDC_DUMP`、`__MIX_CORE_MACRO__`、`__NPU_TILING__` 等宏；四是 `CompiledKernel` 不可变产物信封，装二进制字节、CoreType（MIX 双目标归 AiCore，AIV 系归 VectorCore，AIC 系归 CubeCore）、调试开关与 kernel 参数 ABI 表。毕昇编译器 bisheng 与链接器 ld.lld 分别经 `PYASC_COMPILER`/`PYASC_LINKER` 定位，头文件依赖 `ASCEND_HOME_PATH`；编译失败时有 `-disable-machine-licm` 降级重试。产物交由下一讲 Launcher 完成参数打包与任务下发。
