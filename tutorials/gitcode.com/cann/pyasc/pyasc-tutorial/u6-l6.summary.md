本讲覆盖 EmitAsc 方言、External 六文件（Func/Scf/Arith/Math/MemRef/Emitc）与 scf.for 全链路降级三个模块。核心结论：EmitAsc 是承载「C 形状、无 Ascend C API 对应物」语义的第二方言，含 ptr_offset、verbatim、member、declare_py_struct 等 12 个操作及 PyStruct 类型、kernel_arg 属性；它没有独立降级 Pass，而是与 ascendc 及通用方言平权进入统一发射。发射层要点：函数据 ascendc.global 属性分别打印成 Kernel 入口或 always_inline 内联函数；scf.for 按「结果预声明、iter_args 初始化、for 头、发射体并跳过 yield、回写赋值、关括号、拷贝结果」七步完成 SSA 到命令式翻译；scf.while 译为 while(true) 加尾部 if-break。min、ceildivsi 等无对应 C 运算符的操作内联展开为三目或公式，白名单外操作才报错。
