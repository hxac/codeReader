本讲从 Python 使用侧讲清前端如何创建 IR。核心机制：所有 language 层 API 经 `language/core/utils.py` 的模块级单例 global_builder 现取 builder（非 thread-local），其生命周期被 `jit.py` 的 `_run_codegen` 用 try/finally 夹住——set_ir_builder 建 builder 与模块并把插入点设在模块头，teardown 逆序回调置空 builder；require_jit 以 builder 是否就位作 JIT 编译期判据，on_teardown 是 TPipeManager 等复用的清理扩展点。API 文件遵循固定三段式：`@overload` 存根、`@require_jit` 加 check_type 白名单守门、OverloadDispatcher 变体内经 `to_ir()` 与标量漏斗 materialize_ir_value（`_mat`）转句柄后调 create_asc_XxxL{0,1,2}Op，同族 API 由 op_impl 量产。出口包装分简单包装、双构造器（handle 分支 + from_ir）、手工搭 IR（MatmulIterator 自建 scf.while 并 save/restore 插入点）三形态。掌握五步读码清单后可不依赖文档读懂任何陌生 API 文件。
