本讲讲解 pyasc 的环境搭建与源码构建，核心文件为 setup.py 与 CMakeLists.txt。环境准备分云开发环境、CANN 镜像、手动安装 CANN 包三条路；构建期与运行期依赖须区分，仅编译源码不需要 NPU 与驱动固件。setup.py 经 cmdclass 把 build_ext 换成 LocalBuildExt，将 C++ 编译外包给 CMake 与 Ninja，产出 pybind11 扩展模块 libpyasc.so（位于 asc/_C）。LLVM 应手动设置 LLVM_INSTALL_PREFIX，自动下载仅内部环境可用；PYASC_SETUP_* 系列变量控制构建目录、类型与诊断选项。构建产物按平台后缀集中在 build/ 目录，用 pip3 list 验证；-e 模式下改 Python 即时生效、改 C++ 需重新编译。
