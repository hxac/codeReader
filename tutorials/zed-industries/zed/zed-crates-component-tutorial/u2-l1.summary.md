本讲逐方法精读 component crate 中 Component trait 的定义。核心结论：它是「类型级契约」，七个方法全部是无 self 的关联函数，注册时由 register_component 逐个求值一次、抄录进 ComponentMetadata 并以 id 为键存入全局注册表，因此 dyn Component 不可用。默认值派生链：name() 默认取 std::any::type_name 完整类型路径，id() 将其包为 newtype ComponentId；界面显示用 scopeless_name() 去前缀短名，页面身份与持久化用 id()。记忆口诀「两必须（description、preview）、一强烈（scope）、四随意（id、status、name、sort_name）」；name 管显示与过滤，sort_name 管分组内排序（如 ButtonA 式家族聚组），两者解耦。preview 签名为 fn(&mut Window, &mut App) -> AnyElement：注册时只存裸函数指针、渲染时才执行，AnyElement 类型擦除使任意元素树可入注册表。关键术语：关联函数、newtype、类型擦除、ComponentMetadata；注册表与元数据的完整 API 留待下一讲。
