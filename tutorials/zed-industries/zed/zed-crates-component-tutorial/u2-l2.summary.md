本讲覆盖三个最小模块：`ComponentMetadata`、全局态 `COMPONENT_DATA` 与 `ComponentRegistry`。核心结论：`register_component` 将 `Component` trait 七个关联函数各求值一次，固化成 `ComponentMetadata` 纯值快照——因方法无 `self`，无法用 `dyn` 对象存储；字符串经 `SharedString::new_static` 零拷贝包裹，`preview` 存裸 fn 指针，注册时复制地址、渲染时才调用。`COMPONENT_DATA` 是 `LazyLock<RwLock<ComponentRegistry>>`：写锁仅在 `component::init()` 期间逐组件获取，`components()` 拿读锁整表克隆后立即放锁，快照语义决定 `init()` 必须早于首个消费者。`ComponentRegistry` 七个读 API 分借用、拥有、整表三种视图，树内实际只用 `sorted_components` 与 `component_map`。后续承接的关键术语：值快照、fn 指针、快照语义、两层排序（注册层按完整 `name`、预览层组内按 `sort_name`）、`get` 以完整类型路径为键、`scopeless_name` 去前缀短名、查询走 `Option` 容错回退而不 panic。
