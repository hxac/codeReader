本讲讲解 `component_layout.rs` 中的四个 preview 辅助函数：`single_example` 造变体卡片、`example_group(_with_title)` 造分组，均为构造器语法糖；`empty_example` 表达「合法的空渲染」（空态文档化），且不在任何 prelude，需写全路径。核心范式为「变体分组 + Example Usage」（范本 `Divider::preview`，Switch 同构印证）：顶层 `v_flex().gap_6()`，分组名 = 维度名、卡片名 = 取值名，策展而非穷举组合，末组展示真实用法；卡片例子应用组件公开 API 构造，无尺寸组件（如垂直 Divider）需包一层容器提供布局上下文。综合实践以 PracticeBadge 走通新建组件、挂 mod、运行 component_preview 验证的完整闭环。
