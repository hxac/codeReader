本讲聚焦 BufferDiffSnapshot 的 hunk 查询 API 家族与过滤机制，前提是 hunk 已存于 SumTree（承接 u2-l2）。核心结论：hunks、按锚点/按行/按 base 字节的三种相交查询、range_to_hunk_range 及 raw/rev 变体全部汇入共用实现 hunks_intersecting_range_impl——先以 SumTree filter 按子树摘要剪枝，再把每个 hunk 拆成两条「锚点+载荷」记录，经 summaries_for_anchors_with_payload 一次有序批量解析成 Point，按对消费组装公开的 DiffHunk，失效锚点被 is_valid 静默跳过。引入的关键概念：闭区间「触边即命中」相交语义；行尾扩展规则（结束点落在行中且未到 buffer 末尾时推进到下一行行首并重新锚定）；raw 视图绕开 pending/secondary 乐观状态、供 staging 写索引路径；rev 变体轻量、专供只取最后一个 hunk；range_to_hunk_range 用正向取首、反向取尾拼外包络。按 base 字节剪枝的查询，产出仍解析到 buffer 坐标，editor 的 git 集成依赖此特性。
