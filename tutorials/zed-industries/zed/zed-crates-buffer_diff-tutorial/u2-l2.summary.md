本讲讲 buffer_diff 的存储层：`BufferDiffSnapshot` 用两棵 SumTree 存差异——`hunks: SumTree<InternalDiffHunk>` 存真实差异，`pending_hunks: SumTree<PendingHunk>` 存 stage/unstage 乐观 UI 状态，两者共享摘要类型 `DiffHunkSummary`，元素经 `compute_hunks` 逐个 `push` 入树。核心是 sum_tree 三件套：`Item` 定义单元素摘要（`added_rows` 为锚点行号差，`removed_rows` 依赖预存的 `diff_base_point_range`，因 `Summary::Context` 仅携带主 buffer 快照）；`Summary` 定义合并代数——`add_summary` 区间取外包络并集、计数累加，`zero` 用 min..min 哨兵区间保单位元，故 `changed_row_counts()` 读树根即得全 buffer 的 (+N, −M)；`SeekTarget` 由 `Anchor` 与 `usize` 各实现一份，分别按 buffer 坐标与 base 字节偏移二分导航，游标 `start()`/`end()` 为前缀摘要且须先 `next()`。filter 谓词作用于子树摘要，实现整子树剪枝，是区间查询性能来源。
