本讲主讲 buffer_diff 的 HunkSink——imara-diff 行号输出与 SumTree 存储之间的翻译层。它先用 compute_line_offsets 为 base 文本建「每行字节长度」的前缀和表（token 含行尾符，不重不漏），再由 process_change 把每个 hunk 换算成 InternalDiffHunk。imara-diff 的输出只有 before/after 两个半开行区间：纯插入时 before 为空、纯删除时 after 为空，与 status() 的三态判定一一对应。换算产出三套坐标：base 侧字节区间 diff_base_byte_range（供 usize SeekTarget 剪枝与 base 范围查询）、buffer 侧锚点区间 buffer_range（在 diff 计算瞬间铸锚，空区间两端同用 anchor_before，保证 Added/Deleted 判定跨编辑稳定）、base 侧 Point 区间 diff_base_point_range——因 SumTree 摘要上下文只有主 buffer 快照、拿不到 base Rope，它提前存好 base 行数，removed_rows 由其两端行号相减得出，changed_row_counts 据此返回增删行计数。
