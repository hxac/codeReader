本讲为 buffer_diff 总览，覆盖三个最小模块：Cargo 依赖清单、源码头部 use 导入、下游消费者。核心结论：buffer_diff 是 Zed 的行级差异引擎，将 buffer 当前内容与基准文本对比产出 hunk，以快照加事件的形式供 UI 查询；自身不渲染界面、不读 git 仓库，基准文本由 project 灌注，editor、git_ui、agent_ui 等共 12 个 crate 消费。引入的关键术语：hunk（差异块）；diff base 与 DiffBaseKind 四变体 Head、Index、Oid、Custom，仅 Head 基准可 stage；BufferDiff 是 gpui 实体，经 DiffChanged 等事件通知订阅者；BufferDiffSnapshot 是不可变快照，用两棵 SumTree 存 hunk 与 pending hunk；位置分 Anchor 与 Point 两种。依赖分工：imara-diff 提供算法，rope/text/language 提供文本与语法，sum_tree 提供存储，settings 仅测试启用。
