本讲教你运行并仿写 buffer_diff 的单元测试。测试全部位于源文件底部 `#[cfg(test)] mod tests`，经 `use super::*` 可访问私有项；标准签名是 `#[gpui::test] async fn(cx: &mut gpui::TestAppContext)`，由 gpui 提供的假应用上下文与测试调度器驱动异步测试。`BufferDiffSnapshot::new_sync` 是测试专用同步通道：内部经 `new_with_base_text`（行尾归一化为 LF、建只读基准 buffer、前台 block_on 等待算完、set_snapshot 写回）一步返回已算好 hunk 的快照，属整份重算而非增量更新。`assert_hunks` 以四元组断言 hunk：buffer 行区间、删除文本（切基准原文）、新增文本（切 buffer）、状态；状态构造器为 added_none/deleted_none/modified_none，`DiffHunkStatus = kind + secondary`。运行方式是仓库根目录 `cargo test -p buffer_diff <测试名子串>`。另引入 pretty_assertions（红绿 diff 失败输出）、unindent（去缩进）、Buffer 经 Deref 可当 BufferSnapshot 用、min_max 锚点取全部 hunk。
