本讲补全 HunkSink::process_change 的词级差异（word diff）分支，贯通 buffer_diff 与 language 两个 crate。word diff 仅在四条件同时成立时计算：diff 选项存在、buffer 侧非空、两侧行数相等、行数不超过 MAX_WORD_DIFF_LINE_COUNT（5），即只有等行数的小型修改 hunk 才有词级高亮。设置 word_diff_enabled 经 build_diff_options 译为 Option<DiffOptions>，关闭时得 None，词级 diff 从头不算；测试环境无 SettingsStore 恒为开启。产出两种表示：buffer_word_diffs 以 anchor_after 铸锚（buffer 可继续编辑），base_word_diffs 存相对 hunk base 切片起点的字节偏移（base 只读不过期，加基址留给消费端）。算法 word_diff_ranges 复用 imara-diff：tokenize 按字符类别（词/空白/标点，随语言 scope 而变）切词后二次 diff，相邻区间相接即合并，「换 token 粒度即换 diff 粒度」。词差异还参与 hunk 相等性判定，仅词变化也触发 DiffChanged；下游 multi_buffer 统一两路坐标，editor 仅在修改态 hunk 上按视口过滤绘制。
