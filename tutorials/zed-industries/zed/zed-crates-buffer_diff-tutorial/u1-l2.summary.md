本讲只覆盖 buffer_diff.rs 一个文件中的核心数据结构，不涉及 diff 算法本身。BufferDiff 是可变的 gpui 实体，持有服务 buffer 标识、只读的基准 buffer、最近一次快照、secondary_diff 与 base_kind 五个字段，异步 diff 计算结果回写到它身上；BufferDiffSnapshot 是不可变的可克隆快照，由 hunks 与 pending_hunks 两棵 SumTree 加基准与 buffer 快照组成，尚未计算 diff 时 snapshot() 会返回 base_text_exists 为 false 的空兜底快照。DiffHunk 描述一块差异：buffer 侧用锚点区间 buffer_range（查询时换算为 Point 行区间 range），base 侧用字节区间 diff_base_byte_range，词级差异两侧分别用锚点和整数偏移表示；status() 依次按 buffer 侧空为 Deleted、base 侧空为 Added、否则 Modified 推导。DiffBaseKind 有 Head、Index、Oid、Custom 四种变体，仅 Head 基准使 is_stageable() 为真，因为对其他基准做 stage 会改写已提交内容。构造函数 new、new_unchanged（零差异快路径）与测试专用的 new_with_base_text 也被引入，为后续讲义奠基。
