gpui_wgpu 是 Zed 基于 wgpu 的 GPUI 平台实现：依赖方向为 gpui_wgpu → gpui，它实现 PlatformAtlas 与 PlatformTextSystem 抽象、消费 Scene 绘制数据，由平台 crate gpui_linux / gpui_web 接入真实窗口并每帧调用 draw，gpui 本身不反向依赖。本讲只精读 Cargo.toml 与 10 行库根 gpui_wgpu.rs，并确立 crate 的两条主线：渲染主线是 WgpuContext（instance/adapter/device/queue，跨窗口共享的 GPU 连接）、WgpuRenderer（每窗口一个，draw 返回是否成功提交）、WgpuAtlas（精灵图集，etagere 装箱）；文本主线是 CosmicTextSystem（cosmic-text 整形、swash 光栅化，RwLock 包内部状态，支持无系统字体构造）。关键术语：平台 trait 模式、文本整形、精灵图集、CompositorGpuHint、汇聚式再导出（pub use wgpu 保证版本对齐）、font-kit 可选 feature、wasm 目标叠加 webgl feature。
