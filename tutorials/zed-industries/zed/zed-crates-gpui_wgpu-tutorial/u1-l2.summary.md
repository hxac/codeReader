本讲义精读 gpui_wgpu 仅 10 行的库根与 Cargo.toml，读懂其代码组织与构建方式。核心结论：四个私有模块经汇聚式 pub use 构成门面模式，并再导出 wgpu 本身以统一版本；渲染主线为 wgpu_context、wgpu_atlas、wgpu_renderer（GPU 连接、精灵图集、每窗口渲染器），文本主线为 cosmic_text_system，图集与文本模块分别实现 gpui 的 PlatformAtlas、PlatformTextSystem 两个平台扩展点；GpuContext 类型别名支撑多窗口共享与设备恢复。构建上，[lib] path 指定与 crate 同名的库根，font-kit 是纯内部行为的可选特性（仅 gpui_linux 开启，公开 API 不变），依赖按 wasm 目标拆成两套（原生 pollster，wasm 侧追加 webgl feature）。四个 WGSL 文件不是 Rust 模块，经 include_str! 拼接成 storage、webgl、subpixel 三种着色器变体。结构特征：实现厚、接口薄。
