本讲剖析 streaming_diff 的私有打分矩阵 Matrix：用一维 `Vec<f64>` 加 rows/cols 字段自制可增长二维表，采用列主序布局（下标换算 col*rows+row），契合按列填表的 DP 访问模式；get/set 带行列双重越界检查，越界即带语义 panic。resize 委托 Vec::resize 尾部补零：只要 rows 不变（本 crate 恒为 old_len+1），扩容就等价于右侧新增全零列、旧值原位保留，rows 改变则数据串列。swap_columns 是全 crate 唯一的 unsafe 块，用 as_mut_ptr 加 std::ptr::swap_nonoverlapping 整列交换，col1==col2 早退分支是满足“不重叠”契约的安全防线。adjacent_columns_mut 用一次 split_at_mut 借出上一列（只读）与当前列（可写），把 DP 单向数据流编码进类型签名，current_col 为 0 会 panic。三者合成 push_new 骨架：交换滚动→扩容补零→逐列填表，矩阵可无限复用同一缓冲区。关键术语：列主序、边界列（初始列）、相对列号、split_at_mut、swap_nonoverlapping。分数常量留待 u2-l2，填表主循环留待 u3-l2。
