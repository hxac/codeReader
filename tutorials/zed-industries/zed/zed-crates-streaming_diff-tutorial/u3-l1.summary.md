本讲聚焦 `StreamingDiff::new` 构造函数与 DP 初始化，覆盖三个模块：构造函数把旧文本转成 `Vec<char>` 以支持 O(1) 随机访问，将矩阵 resize 成 (old_len+1)×1 的单列并把第 0 列填为 i×删除分，同时初始化锚点（old_text_ix / new_text_ix）与相等游程双缓冲；Matrix::resize 先扩容、set 带越界检查后写入，顺序不可颠倒。关键概念：DP 状态 S(i,j) 表示旧文本前 i 个字符与新文本前 j 个字符的最优对齐分，有插入（左格 −1）、删除（上格 −20）、相等（左上格加游程奖励）三个递推方向，错配取负无穷；边界上第 0 列（−20i）只依赖旧文本、构造时一次算死，第 0 行（−j）依赖不断增长的新文本、由 push_new 逐列现算。核心结论：本实现是 Needleman-Wunsch 的流式改造，差异为浮点分数、不对称 gap 代价（删贵插贱）、连续相等游程指数奖励与自由终点锚定（在末列取分数最大行为新锚点，属半全局对齐），为下一讲 push_new 的滚动列带与增量填表铺垫。
