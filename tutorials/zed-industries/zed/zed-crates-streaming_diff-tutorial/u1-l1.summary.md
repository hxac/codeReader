本讲为 streaming_diff 的定位总览。核心结论：它解决旧文本固定、新文本分块流式到达时的增量字符级差异计算问题，并可将字符操作折叠为行级差异；核心不变量是任意分块下操作序列按序应用到旧文本必重建完整新文本。覆盖两个最小模块：Cargo.toml（运行依赖仅 rope 与 ordered-float，criterion 等仅开发期使用）与 crate 目录结构（单文件库根 src/streaming_diff.rs，含全部实现与 16 个单元测试，另有 criterion 基准）。引入的关键术语：StreamingDiff（new/push_new/finish 流式入口）、CharOperation（Insert 带 String，Delete/Keep 只带字节数）、LineDiff 与 LineOperation（消费字符操作、借 rope 的 Point 折叠为行操作）、私有打分矩阵 Matrix。两层松耦合：字符级生产、行级消费。真实调用方为 agent 的 edit_session（仅字符级）与 agent_ui 的 buffer_codegen（字符级加行级）。
