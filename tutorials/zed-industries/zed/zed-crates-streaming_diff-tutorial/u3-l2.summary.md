本讲拆解 push_new 主循环的三段式：①滚动——swap_columns 把上一轮末列（即锚点列）整列换到第 0 列作边界，矩阵经 resize 只随单块长度伸缩，与新文本总长无关；②增量填表——adjacent_columns_mut 提供前一列只读、当前列可写，逐列自上而下取插入、删除、相等三候选最大值，第 0 行须用绝对列号 j 计分以保证跨轮可比；相等游程由 previous/current_equal_runs 双缓冲维护：每列 fill(0) 清零、匹配格对角继承前驱加一、列尾 mem::swap 换位，返回时恰持有锚点列游程；③锚定回溯——在末列自 old_text_ix 起取最大分行为新锚点（严格比较，并列取最小行），新侧锚点恒取 new.len()，且必须先回溯后更新锚点。关键不变量：Keep 偏移从旧锚点起算、须按序拼接；old_text_ix 单调不减；空块为无操作；分块不改变递推，与整表重算数学等价。backtrack 仍作黑盒，留待 u3-l3 拆解。
