本讲确立 multi_buffer 的三层核心抽象：Buffer 是真正存文本的真相来源（内部为 rope，支持协作编辑与锚点）；Excerpt 是「buffer id + 范围」的目录项，不复制文本；MultiBuffer 把若干目录项按序装订成逻辑文本，读取时才逐段回底层取内容。关键术语：ExcerptRange 双范围——context 为实际展示范围，primary 为其中待高亮的搜索命中行，由 build_excerpt_ranges 按上下文行数向两侧整行扩展；范围以 text::Anchor 存储以随编辑稳定移动，按 PathKey 装入 SumTree，Excerpt 还缓存 text_summary 与 has_trailing_newline 供坐标换算与拼接。MultiBuffer 实体持可变状态：RefCell 内的 snapshot 靠 buffer_changed_since_sync 脏标志惰性同步，另有 buffers、diffs、subscriptions、singleton、history、title、capability；实体层 is_empty 问「有无 buffer」，快照层问「拼接文本是否零长」。singleton 是「单 buffer 单 excerpt」的标志位而非另一套结构，构造仍走通用装配入口，仅让标题推导、边界迭代等行为走快路径。
