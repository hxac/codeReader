multi_buffer 是 Zed 的文档模型层 crate，把一个或多个 language::Buffer 的 Excerpt（片段）按序拼接成一份可编辑逻辑文本：普通文件编辑即 singleton 形态（单 buffer 全文 excerpt，仅是标志位特例），项目搜索与 git diff 视图走多 excerpt 形态，editor、search、git_ui、vim 等下游反向依赖它。MultiBuffer 是 GPUI 实体，用 RefCell 持有不可变的 MultiBufferSnapshot，读取走惰性同步（底层 buffer 变化先置标志，取快照时才重建），变化经 Event 枚举对外通知。源码五文件：multi_buffer.rs 为主体（实体、快照、坐标系、读取、编辑、diff 集成）；anchor.rs 的 Anchor 提供跨编辑稳定的位置引用；path_key.rs 的 PathKey 是 excerpt 排序身份并集中管理增删改；transaction.rs 的 History 支撑跨 buffer 撤销；multi_buffer_tests.rs 为测试与实验场。依赖四组：gpui（实体底座）、language/text/rope（文本基础）、sum_tree（增量树，维护快照中 excerpts 等多套索引）、buffer_diff（diff 集成），模型层不依赖 UI 层。关键术语：Excerpt、singleton、实体与快照分离、惰性同步、Anchor、PathKey、ExcerptRange 的 context（展示范围）/primary（高亮范围）双范围。
