本讲围绕不可变字符串类型 SharedString 展开三个最小模块：构造、读取与真实用法。核心结论：构造有三条路径——new_static 是 const fn，专供编译期常量，参数须为 &'static str；new 接受 impl AsRef<str>，用于运行时借用构造；From<&str> 与 From<String> 配合 .into() 是 zed 中最常见的惯用法，目标类型由使用位置的类型注解锚定。读取有两种姿势：显式 as_str() 返回 &str 借用，或依赖 Deref<Target = str> 自动解引用直接调用 str 的只读方法；Display/Debug 转发使 format! 与打印直接可用。不可变性由类型系统保证（无 DerefMut、无修改方法）；克隆经内部 SmolStr 透传，近似 O(1)，远廉于 String 的 O(n) 逐字节复制，这是视图状态文本字段选它的原因。Default 实现为 new_static("")，空串零分配。真实用法以 hello_world 示例的 text 字段与 .into() 惯用法为例。下一讲将精读 newtype 封装与 SmolStr 的内联/Arc 双模式存储机制。
