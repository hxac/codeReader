本讲覆盖 gpui_shared_string.rs 中集中实现的 12 个手写 From impl，它们构成 SharedString 与 Rust 字符串生态（&str、String、Box<str>、Arc<str>、Cow、char 等）的「转换矩阵」：转入 10 个方向（借用型与所有权型），转出 2 个（Arc<str> 与 String），加上标准库恒等 From<T> for T 共 13 个可用方向。核心结论：借用型来源必然复制字节（≤23 字节内联零分配，长串堆分配拷贝）；所有权型来源尽量接管缓冲，Arc<str> 转入零拷贝，转出 String 则必然新分配加拷贝。关键概念：泛型边界 impl Into<SharedString> 处没有自动解引用强转，这解释了实现体与 From<&str> 完全相同的 From<&mut str>、From<&String> 为何必须单独占位；本讲还确立了 font_family 的 Into 边界设计与 new_static 作为 const fn 的不可替代性（const ELLIPSIS），为下一讲跨类型比较做铺垫。
