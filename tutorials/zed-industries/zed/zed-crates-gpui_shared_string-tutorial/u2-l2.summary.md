本讲精读 gpui_shared_string 中 Deref、AsRef、Borrow 三个手写 impl，核心结论：三者殊途同归，都只是把内部 SmolStr 以 &str 视角零复制交出，但服务对象不同。Deref<Target = str> 供编译器隐式使用（方法解析自动解引用、引用间的解引用强制转换且可多跳），因未实现 DerefMut，不可变性焊死在类型上；AsRef<str> 供泛型 API 使用，使 new(impl AsRef<str>) 能接收 &str、String、&SharedString，可多方向但不被隐式链式使用；Borrow<str> 供 HashMap 等容器跨类型查键，其契约要求与 str 的 Eq/Ord/Hash 一致，由 derive 委托 SmolStr 按内容成立，且只看内容、与存储方式无关。关键术语：DST 与胖指针、方法解析链、deref coercion、Borrow 契约、newtype 透明代理。zed 惯用法是「键存 SharedString、查询用 &str」（主题注册表、语义 token 修饰符查表）。下一讲 u2-l3 转入 From 转换矩阵。
