本讲概览 Zed 仓库中最小的 crate 之一 gpui_shared_string：全部源码仅一个 212 行文件加一份 17 行清单。核心结论：SharedString 是不可变、克隆近似 O(1) 的共享字符串，在概念层统一抽象 Arc<str> 与 &'static str，解决 GPUI 实体、元素与异步任务之间高频复制文本的问题。它以 newtype 模式包裹私有字段 SmolStr，文档中的「currently」表明底层实现可替换而不破坏下游；自带 new_static（const fn，静态字面量）、new（运行时构造）、as_str 三个固有方法，其余约 20 个 impl 块（Deref、From、serde、JsonSchema 等）多为向底层转发，留待后续各讲精读。工程层面：Cargo.toml 仅依赖 smol_str、serde、schemars 三个库，通过 .workspace = true 继承版本、publish 与 lints 约束，并以 [lib] path 指定与 crate 同名的库根文件；gpui 用 pub use 将其整体再导出，应用层走 gpui::SharedString 入口，而 env_var、language_core 等非 UI crate 直接依赖它，避免为一个字符串类型拖入整个 UI 框架。本讲引入的关键术语：newtype、workspace 继承、re-export 再导出、克隆成本 O(n) 与 O(1)。
