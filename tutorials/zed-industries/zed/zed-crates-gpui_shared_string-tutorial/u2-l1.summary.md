本讲深入 `SharedString` 的实现层，分三个模块。封装：newtype 模式用私有字段包住 `SmolStr`，底层实现可随时替换（文档 "currently" 即此承诺），公共 API 仅构造、读取、克隆；六个 derive 沿「委托内层、按 str 内容生效」的委托链工作，相等、排序、哈希只看文本内容，故可作 HashMap/BTreeMap 键；故意不 derive Copy（堆变体含引用计数），Default 手写为零分配空串。存储：SmolStr 固定 24 字节，≤23 字节（按 UTF-8 字节数计）或缩进特例（连续换行接连续空格）走内联、零堆分配，超限进堆并由引用计数共享；new_static 永不分配；类型整体不可变。成本：String 克隆为 Θ(n) 深拷贝加堆分配，SharedString 克隆封顶 24 字节复制或一次原子计数加一，即 O(1)；这支撑 GPUI 每帧重建元素树的高频克隆需求，代价是放弃可变性。关键术语：newtype、私有字段封装、derive 委托链、内联存储、堆共享、WS 特例、O(1)/Θ(n)、不可变性。
