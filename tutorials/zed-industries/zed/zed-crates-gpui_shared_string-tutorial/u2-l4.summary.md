进阶单元收官讲，阐明 SharedString 的相等、排序与哈希语义。核心结论有三：其一，结构体派生的 Eq、PartialEq、PartialOrd、Ord、Hash 由 derive 逐字段委托给内部 SmolStr，而 SmolStr 按字符串内容实现这些 trait，故相等、哈希、字典序只由字节内容决定，与静态、内联、堆三种构造路径无关，同一文本不同构造彼此相等且同哈希；其二，derive 之外手写了四个跨类型 PartialEq（与 String 双向、与 str、与 &str），统一套路是经 as_ref() 把自身化归为 &str 再比较，方向不对称，字面量在左侧无法编译，而为 String 反向实现之所以合法，靠的是孤儿规则中「trait 参数含本地类型」的例外；其三，HashMap 键需 Eq+Hash、BTreeMap 键需 Ord，本类型与 &str 的哈希、相等、序完全一致，配合 Borrow<str> 即可用 &str 查键命中，兑现了 u2-l2 立下的 Borrow 契约，语义高亮与主题注册表是现成下游用例。关键术语：内容语义、委托链、哈希一致性、跨类型 PartialEq、孤儿规则例外、Borrow 契约。下一讲进入 serde 与 schemars 序列化。
