本讲覆盖 editor crate 悬浮层家族四个模块：hover_popover.rs 的 HoverState 状态机——防抖延迟、sticky 粘性策略、鼠标靠近的几何判定与 Escape 经 dismiss_menus_and_popups 统一关闭，show_hover 将延迟拆两段与 LSP 请求并行并组装信息/诊断卡片；hover_links.rs 的 HoverLink 识别优先级链——LSP documentLink 优先于 find_url 启发式 URL 检测，再退到 find_file 多候选文件解析，定义链接总是额外追加；document_links.rs 负责链接缓存与防抖刷新；signature_help.rs 的 SignatureHelpState 按光标新旧位置的括号包围自动开合，hidden_by 先到先得，与补全菜单单向互斥。核心变化点是 show_hover 构造本地诊断改用 DiagnosticEntry::new 配 anchor_before..anchor_after 锚定区间，且 related_information 移入 DiagnosticEntry，使诊断及关联位置随编辑漂移，为下一讲诊断块铺路。关键术语：HoverState、HoveredLinkState、HighlightKey、锚定区间、EditorLspTestContext 模拟鼠标测试套路。
