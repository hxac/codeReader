本讲拆解 sum_tree 骨架层的四个模块。Node 枚举：Internal 含 height、summary、child_summaries（路由表）与 child_trees，Leaf 含 items 与平行的 item_summaries；只有叶子存元素，内部节点只做路由，叶子高度 0 是方法约定。「汇总存两份」的冗余让游标只扫连续纯值数组、免解引用孩子指针，代价是修改后须同步回写。TREE_BASE：测试构建为 2、正式为 6，且 cfg(test) 按 crate 生效，下游测试仍按 6 编译；上限 2*TREE_BASE 触发分裂，下限为欠溢线，根高度满足 n ≤ C^(h+1)。unwrap_oob 因元素类型不要求 Debug，用十行把「必不越界」的内部不变量变成显式断言。SumTree 即 Arc<Node>：克隆只是引用计数加一（快照），修改走 Arc::make_mut 写时复制、只克隆根到叶一条路径；== 按内容比较，共享与否需用 Arc::ptr_eq 探测。
