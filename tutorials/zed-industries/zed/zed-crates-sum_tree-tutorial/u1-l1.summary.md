本讲是 sum_tree 的总览。sum_tree 是 Zed 的并发友好 B+ 树：叶子存元素与逐元素 Summary，内部节点只存子树汇总，单节点容量上限为 2×TREE_BASE（测试构建 4、正式构建 12），从而以 O(log n) 完成前缀汇总查询；整树由 Arc<Node> 串成不可变结构，修改只复制根到叶路径，克隆即克隆根指针，实现廉价快照与多版本共存。它被 rope、multi_buffer、editor 等 13 个 crate 依赖，是文本栈地基。crate 仅四个源码文件：sum_tree.rs（根模块，定义 Item、Summary、Dimension 等 trait 及构建/查询/编辑 API）、cursor.rs（Cursor/FilterCursor/Iter 读取中枢）、tree_map.rs（TreeMap/TreeSet 应用层）、property_test.rs（proptest 工具）。根模块以私有 mod 加精选 pub use 收敛 API 面；Cargo.toml 中库根为 src/sum_tree.rs，heapless 定容存储、rayon 并行建树，test-support feature 拉起 proptest 供下游测试。关键术语 Summary、TRE E_BASE、结构共享将由后续讲义承接。
