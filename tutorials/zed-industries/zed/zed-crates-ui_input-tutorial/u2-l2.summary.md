本讲拆解 ui_input 中 InputField::render 的实现。元素树分两层：外层 v_flex 纵排标签、输入框、错误文案；内层 h_flex 才是输入框本体，横排起始图标、编辑器、眼睛按钮，child 书写顺序即视觉顺序。样式方法与 Tailwind 同名同值（1rem=16px）。颜色一律取自全局主题并快照进 InputFieldStyle：聚焦时换 border_focused，出错时覆盖为 error_border，fluent 样式后写覆盖先写，故错误优先于焦点。可选部件用 FluentBuilder 的 when/when_some 组合子内联装配，Option 字段按值传闭包。内芯经类型擦除渲染为 AnyElement，作为普通 child 嵌入外壳。
