本讲介绍 Zed 组件预览系统如何让 InputField 可视化，覆盖四层：component crate 的 Component trait（方法全为静态关联函数，须实现 description 与 preview，InputField 仅额外把 scope 覆盖为 ComponentScope::Input）；#[derive(RegisterComponent)] 借 inventory 实现分布式注册，component::init 启动时遍历登记项，把含 preview 函数指针的 ComponentMetadata 存入全局注册表，无需中心清单；single_example 卡片与 example_group 分组这对 RenderOnce 布局助手组织演示内容，与实现 Render 的有状态 InputField 形成两种组件形态对照；component_preview 面板经 workspace: open component preview 命令打开，按 scope 分组导航，渲染时才调用 preview 现场生成 AnyElement。核心结论：面板顶部过滤框本身就是一个 Entity<InputField>，因此打开面板隐式依赖 editor::init 注入 ERASED_EDITOR_FACTORY，与上一讲的工厂机制闭环。
