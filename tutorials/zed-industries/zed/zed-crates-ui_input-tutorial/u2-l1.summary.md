本讲覆盖 ui_input 的 input_field.rs（InputField 本体）与 crate 根的 ERASED_EDITOR_FACTORY，只讲数据模型与 API，渲染细节留给 u2-l2。核心结论：InputField 是「外壳＋内芯」结构，外壳的 label、placeholder、min_width、tab_index、tab_stop、masked、error 等字段只存配置与展示状态，文本等可变状态全在内芯 editor: Arc<dyn ErasedEditor>（类型擦除，承接 u1-l1）；Option 字段为三态，None 表示不启用该行为，如 masked 为 None 即非敏感字段、不渲染眼睛按钮。new 从全局工厂取构造函数（未初始化则 panic），造出内芯后立即把占位文本推进内芯，再以默认值组装外壳，签名只要 &mut App。builder 方法统一「mut self -> Self」，属构造期配置；set_error 等运行期方法用 &mut self 并需 cx.notify() 触发重渲染。Focusable 与 text、set_text、clear、is_empty 均为向内芯的委托，修改文本只需 &self，因为可变性在内芯实体；editor() 是逃生舱访问器。注意 label_min_width 名不副实，实际设置输入框的 min_width。
