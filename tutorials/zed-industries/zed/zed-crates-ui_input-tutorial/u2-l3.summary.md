本讲是第二单元收尾，专讲 InputField 随用户交互而变化的状态。焦点方面：外壳通过 Focusable 委托与 track_focus 和内芯 editor 共享同一个 FocusHandle，装饰性焦点样式因此挂在外壳上；tab_index 与 tab_stop 是构造期配置，render 时按显式序号、显式排除、默认原样三分支写到句柄并同步进全局焦点表，Tab 导航由 TabStopMap 跳过 tab_stop == false 的节点，边框判定用 contains_focused 而非 is_focused。错误方面：set_error 是唯一运行期可变展示字段，写字段后必须 cx.notify()，下一帧出现红色边框与提示文案，且错误边框后写覆盖焦点边框。masked 用 Option<bool> 三态表达敏感性与初始遮蔽，外壳是单一事实来源，render 每帧同步进内芯；眼睛按钮由 cx.listener 适配点击——弱引用找回实体、翻转外壳状态、同步内芯、请求重渲染。核心纪律：改内芯 editor 实体无需外壳 notify（内芯自行通知），改外壳字段必须 cx.notify()。两次触及类型擦除边界，为下一单元 ErasedEditor trait 与事件模型的解析铺垫。
