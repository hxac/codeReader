MarkdownPreviewView（定义于 markdown_preview_view.rs）含十三个字段，按上游绑定、内容渲染、同步状态、瞬态工作四组理解，写入点集中于构造函数与 set_editor。MarkdownPreviewMode 分 Default（固定绑定触发编辑器、按 buffer 复用）与 Follow（跟随活动编辑器、全窗格唯一），以 0/1 序列化，未知值兜底为 Default。构造前半段两模式公共，Follow 用 observe_in 高频感知活动条目，Default 用 subscribe_in 只监听条目增删以避开光标热路径，均汇聚于唯一换绑入口 set_editor：幂等短路、把编辑器与订阅打包为 EditorState 保证换绑原子性、立即更新内容并广播 MarkdownPreviewEvent 触发持久化。PreviewLinkTarget 分标题锚点与行列位置两类导航目标。内容引擎是 markdown crate 的 Markdown 实体：视图只调 reset 塞文本并订阅变化，相同文本短路、换内容保留旧解析防闪烁。以上结构与事件分类是后续防抖更新、滚动同步、渲染与链接导航各讲的基础。
