本讲剖析 Zed 设置系统与 markdown_preview 预览的两个配置入口。核心结论：设置分两层——内容层 SettingsContent（字段全为 Option，负责合并与序列化）与消费层（各 crate 实现 Settings trait，经 from_settings 转成强类型并补默认值）；注册由 RegisterSetting 派生宏经 inventory 自动完成，get_global 仅是 TypeId 哈希查找，可在 render 中放心调用；settings.json 改动经文件 watcher、recompute_values、refresh_windows 即时生效。MarkdownPreviewSettings 将 limit_content_width 与 max_width 两个 JSON 键压缩为单个 Option<Pixels> 字段，渲染端用 max_w 加 mx_auto 实现限宽居中，体现「策略前移到转换层、消费代码保持简单」。预览字号归属 ThemeSettings，取值优先级为内存覆盖、文件值、UI 字体回退（每档 clamp）；字号动作由 persist 参数分流——true 经 update_settings_file 保留注释原子写回，false 只写运行期全局（默认键位均为 false）；文件值变化会清除内存覆盖，文件始终权威；WithRemSize 使整个预览随字号等比缩放。
