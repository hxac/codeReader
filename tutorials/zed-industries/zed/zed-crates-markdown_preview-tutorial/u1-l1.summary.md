markdown_preview 是 Zed 内置的 Markdown 预览面板 crate，定位「胶水 + 面板」：解析交给 markdown crate，标签页与会话恢复交给 workspace，编辑回写交给 editor。crate 仅三个文件：lib 根 markdown_preview.rs 以 `[lib] path` 指向同名文件（Zed 规范），用 actions! 宏定义滚动类动作并重导出 OpenPreview，唯一入口 init(cx) 负责注册可序列化条目并观察新 Workspace；markdown_preview_settings.rs 定义 MarkdownPreviewSettings（仅 max_width 一项，默认 800px 居中）；markdown_preview_view.rs 占 97% 代码，是绝对主体，核心 MarkdownPreviewView 支持 Default/Follow 两种模式与 200ms 防抖重解析。16 个运行时依赖分五层：UI 框架（gpui/ui/theme）、解析（markdown）、编辑器（editor/language）、平台（workspace/project/db/zed_actions）、工具层。消费方为 zed 主程序、project_panel、auto_update_ui 与 vim。
