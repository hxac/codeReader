`gpui_macros` 是 GPUI 专属的过程宏（proc-macro）crate，编译成动态库供 rustc 在编译期加载，自身不参与运行时。本讲覆盖其 `Cargo.toml` 配置与库入口 `gpui_macros.rs` 的模块组织。核心结论：过程宏必须放在标记 `proc-macro = true` 的独立 crate 中；运行依赖仅 `syn`（解析 Token 流）、`quote`（生成代码）、`proc-macro2`（基础设施）、`heck`（命名转换）四个，`gpui` 作为 dev-dependency 反向出现在测试里，不构成循环依赖。入口文件采用「薄入口 + 厚实现」：19 个宏入口（派生、属性、函数式三类）对应 11 个实现模块，其中 9 个样式宏共享 `styles.rs`，反射宏 `derive_inspector_reflection` 仅在 `inspector` feature 或 `debug_assertions` 下编译。上游 `gpui` 通过 feature 转发与再导出（8 个宏）把宏能力交给业务代码；测试由 3 个集成测试加 doctest 组成，可用 `cargo test -p gpui_macros` 验证。
