本讲确立 text crate 的定位：它是 Zed 的协同文本缓冲区，约 6600 行、10 个源文件，上承 editor、language、project 等 29 个 crate，下靠 rope（文本存储）、clock（Lamport 时钟与版本向量）、sum_tree（摘要树）、collections 四块基础设施。三个模块：一、读 Cargo.toml，确认库根为 src/text.rs 而非 lib.rs，test-support feature 专为测试工具（如模拟网络）开启；二、读 text.rs 的 mod 声明区绘制模块地图，Anchor、Locator、Patch 等私有模块经 pub use 组成对外门面，pub use rope::* 使 text 成为文本类型的唯一入口；三、建立 Buffer 总体印象——「会记账的文本容器」，edit 依次开事务、领 Lamport 时间戳、应用编辑、记历史与版本、关事务，返回可广播的 Operation，对端以 apply_ops 重放，乱序操作暂存 deferred_ops；BufferSnapshot 是可廉价克隆的只读快照，内含 visible_text 与 deleted_text 两根绳，删除不擦除而入墓碑，这是撤销与协同合并的地基。
