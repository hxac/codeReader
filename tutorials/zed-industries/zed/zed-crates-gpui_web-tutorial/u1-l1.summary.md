gpui_web 是 GPUI 面向浏览器（WebAssembly）的平台后端，与 macOS/Windows/Linux 桌面后端并列：核心类型 WebPlatform 实现 gpui 的 Platform trait，并总装其余七个模块——window（实现 PlatformWindow，一个窗口即一个 canvas）、events（把 DOM 事件翻译为 PlatformInput）、dispatcher（PlatformDispatcher，基于 setTimeout/rAF 与 wasm 线程池）、display、keyboard（占位布局）、http_client（用 Fetch 实现 HttpClient）、logging（转发到浏览器控制台）。平台硬约束：只支持一个顶层窗口，重开返回 WebWindowError；图形初始化是异步的，默认 WebGPU 优先、WebGL2 兜底，可用再导出的 WebBackendPreference 指定；浏览器给不了的能力（如文件选择对话框）以错误返回，即「能力降级」。入口文件以私有 mod 加精选 pub use 收敛 API 面；顶部的 #![cfg(target_family = "wasm")] 与 Cargo.toml 中仅作用于 wasm 目标的依赖表互为双保险，使原生目标编译为空库，门面 crate gpui_platform 因此可无条件依赖它；默认开启的 multithreaded feature 联动 wasm_thread 与 scheduler 的 wasm-threads，运行时再探测 SharedArrayBuffer 决定是否真用多线程。渲染与文本系统由兄弟 crate gpui_wgpu（WgpuContext、CosmicTextSystem）提供，应用通常经 gpui_platform 的 application_with_web_backend 装配本后端。
