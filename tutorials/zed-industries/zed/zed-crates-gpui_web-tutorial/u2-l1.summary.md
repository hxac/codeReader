本讲精读 platform.rs 的三块内容：WebPlatform 构造、异步图形初始化、窗口生命周期状态机。核心结论：构造函数 new_with_backend 装配 dispatcher、前后台执行器、内嵌 8 个 ttf 的 CosmicTextSystem 与显示器，图形相关字段（wgpu_context、prepared_window、window_lifecycle）留空延迟填充；浏览器上的 Platform::run 不接管事件循环，仅 spawn_local 异步初始化图形，成功后先填充字段再调 on_finish_launching，因此开窗必须写在 run 回调里。Auto 策略先试 WebGPU，因一个 canvas 只能绑定一种上下文类型，失败后须移除旧 canvas、造新 canvas 重试 WebGL2，双失败则在页面插入错误段落。关键术语：WebBackendPreference（Auto/WebGpu/WebGl）、WgpuContext、PreparedWebWindow（canvas 与 surface 成对移交）、四态单向状态机 WebWindowLifecycle（Available→Open→Closed，可跌入 Unavailable，由 run、open_window 与 WebWindow 的 Drop 三方共享维护）、WebWindowError 五变体（仅 GraphicsInitializationPending 可重试），以及 prepared_window 的 take() 从数据结构上封死第二块顶层窗口。
