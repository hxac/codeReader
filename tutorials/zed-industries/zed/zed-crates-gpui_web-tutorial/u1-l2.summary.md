本讲跑通 hello_web 示例，讲透让 GPUI 应用带着线程跑进浏览器的完整构建链路。五个最小模块：一是工程骨架——示例用空 workspace 表脱离主仓库，工具链钉在 nightly；二是 trunk 打包——以 index.html 为入口，页面主体为空，canvas 由 WebWindow 运行时创建并命中预置样式；三是响应头——trunk.toml 的 COOP/COEP 让 crossOriginIsolated 成立，这是 SharedArrayBuffer 与 wasm 多线程的部署前提，WebGPU 另要求安全上下文；四是链接参数——.cargo/config.toml 以 atomics、import-memory、TLS 导出符号配合 build-std 重编标准库，补齐编译期条件；五是入口流程——web_init → application_with_web_backend → open_window → Render 三步舞，后台计算走 background_spawn，回填后 notify 重绘。日志与 panic 由 ConsoleLogger 送进控制台。关键术语：跨源隔离、wasm-bindgen、web-time、WebBackendPreference、allow_multi_threading。
