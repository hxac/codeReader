本讲讲解如何从源码构建并运行 Zed，覆盖五个模块：workspace 清单、工具链固定、平台依赖安装、编译 profile、script 脚本目录。核心结论：根 Cargo.toml 声明 250 个 workspace 成员（243 个 crates 加 extensions 与 tooling），default-members 指向 crates/zed，因此裸 cargo run 只构建编辑器主程序及其依赖闭包，产物是 target/debug/zed。引入的关键术语：Cargo workspace、default-members、[workspace.dependencies] 共享依赖表、[patch.crates-io] 补丁替换、rust-toolchain.toml（钉死编译器 1.97.1 与 wasm 交叉目标）、.cargo/config.toml 的 rustflags 与别名、四档 profile（dev/dbg/release/release-fast）、build-override、FFI 系统依赖、script/linux 与 script/clippy。工程要点：RUSTFLAGS 环境变量会覆盖仓库固定配置，是构建排错头号嫌疑；profile 支持按包覆盖，proc-macro 与 tree-sitter 等热点单独 opt-level=3；贡献前须用 ./script/clippy 替代 cargo clippy。crates/zed/src/main.rs 是启动入口，留待 u1-l4 展开。
