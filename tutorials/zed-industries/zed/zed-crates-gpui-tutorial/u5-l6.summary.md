本讲讲解 GPUI 的拖放与触摸手势。拖放是值语义的：on_drag 交出负载 T，on_drop::<T> 按 TypeId 匹配接收，中转站是 App 上全局唯一的 active_drag（AnyDrag）；位移超过 2px 才开拖（源元素须先 .id() 存放跨帧按下状态），松手投给最上层悬停且 can_drop 通过者，无人接收则取消。拖动视图每帧以鼠标位置减 cursor_offset 为原点单独绘制、浮于最上层。反馈 API 有 on_drag_move（Capture 阶段、不做命中过滤）与 drag_over 声明式样式。文件拖入被翻译为内部拖拽：FileDropEvent 各变体合成鼠标事件，负载为 ExternalPaths（Render 为 Empty，图标由平台画）；拖出窗口时经惰性 resolver 产出 ExternalDragPayload::Files 移交平台，由 PlatformOwnedDrag 状态机管理挂起与恢复。gestures 模块以手势竞技场从触摸事件识别手势并复用语义事件（tap→ClickEvent、pan→ScrollWheelEvent）；OngoingScroll 用主轴锁定与定向解锁过滤触摸滚动，GestureTuning 提供手感常量，PlatformGestures 为平台钩子。
