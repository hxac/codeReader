本讲覆盖 GPUI 无障碍（a11y）集成的四个模块：每帧树构建、role/aria 标注、辅助技术动作响应、合成子节点。核心结论：a11y 树在 prepaint 阶段把「有 GlobalElementId 且 a11y_role 非 None」的元素投影为 AccessKit 的 TreeUpdate，NodeId 由全局 ID 哈希而来，跨帧稳定即语义稳定；A11yNodeBuilder 靠节点栈推导父子关系，同帧重复 ID 在 release 下被静默丢弃。整体为懒激活：适配器置原子标志并强制重绘，帧首快照保证整帧一致。应用侧用 .id()+.role()+.aria_*() 标注语义（约二十个 setter）；text! 的 ID 源自调用处源码位置，循环中须 with_id 补救。AT 动作经 ActionRequest 派发到 handle_a11y_action，显式 on_a11y_action 优先，Click/Focus 有内置回退（合成中心点鼠标事件/查焦点表）。自定义元素经 a11y_synthetic_children 钩子与 A11ySubtreeBuilder 一个元素呈现多个节点，aria_active_descendant 以焦点门禁支撑复合控件；可用 debug_a11y_tree_json 验证树结构。
