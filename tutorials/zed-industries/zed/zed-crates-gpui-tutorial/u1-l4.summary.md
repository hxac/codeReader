本讲把 examples 目录当作学习地图：共 43 个示例 target，README 分新手起点、布局样式、交互、图片绘制动画、窗口行为、专用六区索引，但可能漏收录（如 a11y、view_example），需与 Cargo.toml 的 [[example]] 声明交叉验证——文档会过期，构建配置不会。所有示例共享三段式骨架：run_example() 装着 u1-l2 的启动四步曲，原生 main 与 wasm start 都只是调用它；读示例先看 impl Render，再看 open_window 前的配置。代表示例：uniform_list 演示等高虚拟化列表，框架把可视行号区间传给渲染回调，只为可见行创建元素，条目需 .id 才可交互；input 是交互全集，涵盖 actions! 定义动作、bind_keys 键位绑定、key_context/track_focus/on_action 加 cx.listener 的标准写法、自定义 Element 三阶段绘制与输入法对接；window 是 WindowOptions/WindowKind 试验台，prompt 为异步对话框；testing 同一份代码可当应用运行亦可当测试（需 test-support feature），核心是 gpui::test 与 run_until_parked。
