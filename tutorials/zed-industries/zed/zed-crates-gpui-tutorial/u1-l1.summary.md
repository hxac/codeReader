本讲只读 README、Cargo.toml、src/gpui.rs 与 gpui_platform 四处外围文件，不涉实现代码。核心结论：GPUI 是 Zed 团队开发的 GPU 加速、混合立即/保留模式的 Rust UI 框架，独立发布于 crates.io——“立即”指元素树每帧由根视图 render 重建，“保留”指应用状态存于跨帧存活的实体。引入的关键术语：三种编程层级（语域），即 Entity 状态管理、Render 声明式视图（div，Tailwind 风格 API）、Element 命令式元素（用于虚拟化大列表与自定义布局），三层可按需混用且各配 context。crate 分工：gpui 是跨平台核心（状态、元素、布局、样式，并定义 Platform trait），gpui_platform 是按 target_os 挑选 gpui_macos/gpui_windows/gpui_linux/gpui_web 的约百行门面；default features 四项在 Linux 上仅 wayland/x11（空 feature 纯 cfg 开关）有效。核心依赖有 taffy（布局引擎）、accesskit（无障碍）、slotmap（实体存储）等。src/gpui.rs 是 crate 注册表：pub use 扁平化导出、README 经 include_str! 成为 crate 文档，并定义 AppContext/VisualContext 等 trait；从 pub use 反查定义文件是后续讲义的阅读基本功。
