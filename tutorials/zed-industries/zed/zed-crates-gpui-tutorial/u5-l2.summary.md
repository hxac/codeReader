本讲拆解 GPUI div 元素的交互机制，覆盖四个最小模块：Interactivity 结构体、Stateful<E> 与 ElementId、hitbox 命中测试、paint_mouse_listeners 监听器注册与 click 合成。核心结论：div 的全部交互配置（id、样式补丁、各类监听器、遮挡标志）汇聚于 Interactivity 结构体，链式方法只是写字段或 push 闭包；`.id()` 返回 Stateful<E> 才解锁 StatefulInteractiveElement 的有状态方法（on_click、active、on_hover、overflow_scroll 等），缺 id 在编译期即失败，因为跨帧状态以 (GlobalElementId, TypeId) 为键存于窗口元素状态表，同层兄弟 id 撞车会导致状态串扰。hitbox 在 prepaint 阶段插入，命中测试逆序遍历使视觉上层优先，BlockMouse/BlockMouseExceptScroll 实现浮层遮挡与滚动穿透。监听器在 paint 阶段经 window.on_mouse_event 注册、只活一帧，每帧重申报换取零陈旧引用。click 是合成事件：按下时记录 pending_mouse_down 并 window.refresh() 使 active 样式即时生效，Capture 阶段配对、Bubble 阶段触发，移动超 2 像素拖拽阈值即取消。hover/active 样式按 base→focus→hover→active 顺序 refine 合成，悬停转移触发重绘依赖有 id 的 hover_state。
