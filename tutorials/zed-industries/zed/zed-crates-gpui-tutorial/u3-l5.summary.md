本讲覆盖 GPUI 四个内置内容元素（均实现 Element，可直接作 div 的 child），并引入元素三阶段直觉：request_layout 申报并测量尺寸、prepaint 记录 bounds、paint 提交绘制。文本 API 分四层：字符串直接作 child、text! 宏（按源码位置生成无障碍稳定 ID）、StyledText（高亮区间延迟到布局期才与继承样式合成 TextRun，端点须落在 UTF-8 字符边界，TextLayout 跨帧缓存测量）、InteractiveText（区间可点击/悬停/tooltip）。img 的关键是 ImageSource 多种来源与 StyledImage 样式（grayscale、object_fit、超 200ms 才显示的加载/失败替身、动图帧由布局阶段自驱）。svg 支持 path/external_path/data 三种字节来源，颜色取自 text_color，不设色则不绘制；Transformation 仅影响绘制不影响布局与命中盒。canvas 是命令式绘制逃生舱：两个 FnOnce 回调映射 prepaint/paint，泛型 T 在两阶段间传状态，因无 ID 而无跨帧元素状态，持久数据须放实体。SharedString 表达零拷贝存储，SharedUri 标记 URI 语义。核心结论：显示内容优先选内置元素，其次 canvas，最后才自定义 Element。
