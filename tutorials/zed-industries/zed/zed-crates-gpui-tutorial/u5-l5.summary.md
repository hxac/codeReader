本讲剖析 GPUI 焦点系统。存储模型：窗口级单值 FocusId 加 App 级 FocusMap，FocusHandle 为仅含 ID 的引用计数句柄，与 Entity 同构。接入分两路——实体侧 Focusable trait、元素侧 track_focus/tab_index，均在 prepaint 把句柄挂到派发树，每帧重申报。Tab 导航并非内置行为：应用自定义动作并调用 focus_next/focus_prev 查询上一帧登记的 TabStopMap，按 tab_group 路径、tab_index 与登记序排序。焦点是路径而非单点，contains_focused/within_focused 沿上一帧派发树上溯，帧末 diff 焦点路径并派发 on_focus_in/on_focus_out。focus、in_focus、focus_visible 三种样式条件各异，focus_visible 依输入模态区分键盘与鼠标聚焦；键盘激活（enter/space 合成 click）以 focus_generation 防 ABA 误触发。
