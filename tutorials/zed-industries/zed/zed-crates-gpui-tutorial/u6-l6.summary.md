本讲解读 GPUI 的文本换行与测量。换行由文本系统自算而非布局引擎 Taffy，分两条路径：整形前用 LineWrapper::wrap_line 逐字符累加宽度做贪心断行，超宽时回退到最近词边界，服务于截断，产出字节下标 Boundary；整形后用 compute_wrap_boundaries 按字形 x 坐标精确求断点，服务于渲染，产出 WrapBoundary。两者共享 is_word_char 词字符白名单：CJK 字符可任意断，粘性符号成词不拆；断点还携带悬挂缩进。LineWrapper 经 LineWrapperHandle 按字体与字号池化复用，并配 ASCII 数组加 HashMap 的两级字符宽度缓存，摊薄单字符整形开销。截断家族 truncate_line 与 truncate_wrapped_line 是 text_ellipsis、line_clamp 的实现，截断前先整形量真实宽度以防逐字符累加高估导致误截。核心心智模型：不为每个视觉行单独建布局，而是在未换行 LineLayout 上记录断点，绘制时 WrappedLine 命中断点即折行；内容高度 = 行高 ×（断点数 + 1），对齐基于 wrap_width。
