本讲拆解 GPUI 应用生命周期三个模块。其一，三层结构：Application 只是 Rc<AppCell> 的配置期包装，AppCell 即 RefCell<App>，App 是持有实体表、窗口表、键位表与执行器的唯一全局状态容器，其 this 字段用 Weak 回指以避免引用环；配置钩子有 with_assets、with_http_client、with_quit_mode 等。其二，借用模型：前台代码全部跑在单一前台线程，run 回调全程独占可变借用，重入（如在其中调用 AsyncApp::update）会运行时 panic；AsyncApp 持 Weak、每次调用短暂借用；最外层更新结束时 flush_effects 消化 Notify、Emit、Defer 等效果。其三，事件循环与退出：run 把控制权交给 Rc<dyn Platform>，桌面平台阻塞至应用结束，wasm 等宿主须改用 run_embedded 拿 ApplicationHandle 反复进入；退出链为 cx.quit → 平台 on_quit 回调 → App::shutdown，on_app_quit 的异步收尾仅 200ms 预算；QuitMode 决定最后一个窗口关闭是否自动退出；on_window_closed 与 on_app_quit 返回 drop 即注销的 Subscription，detach 可延长生命。为下一讲 EntityMap 与 Entity 所有权模型铺垫。
