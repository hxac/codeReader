本讲拆解 gpui 样式合成机制：Style 是全字段有确定值的完整样式；StyleRefinement 是全 Option 的补丁，由 Refineable 派生宏编译期生成，也是链式 API 的真正存储。核心结论：Style 每帧由 default 出发逐层 refine 合成，优先级唯一来源是 refine 的调用顺序，div 的 compute_style_internal 按 base、focus、hover、active 依次叠加，故状态样式恒胜基础样式。继承仅发生在 Style.text 字段（类型即补丁 TextStyleRefinement），由 Window 的 text_style_stack 实现：div 在布局与绘制两阶段经 with_text_style 压栈，window.text_style() 从栈底向栈顶折叠成最终 TextStyle，子元素覆盖父元素。Cascade 是分层补丁容器，体现「主题即低优先级大补丁」；HighlightStyle 则按颜色混合叠加而非覆盖。易错点：Style 默认 display 为 Block，裸 div 走块布局。
