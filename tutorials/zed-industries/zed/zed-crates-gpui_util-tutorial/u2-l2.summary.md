本讲拆解 gpui_util 的日志引擎 log_error_with_caller，即 ResultExt 各方法的公共出口。#[track_caller] 让函数经 Location::caller() 取到调用点：值是编译期常量、'static、零运行时开销，可沿 log_err 调用链逐级透传。引擎用两次 split_once（"crates/" 与 "/src/"）从文件路径反推模块串，填入 target 作为过滤主键；规范化路径填 module_path 供 zlog 提取 crate 名；路径不含 crates/ 时 target 为空串——上一讲 demo 谜题的答案。它不用 log::error! 而手工构造 log::Record，以控制运行时 level、正确的 file/line 与 target。适配器 DebugAsDisplay 借 Display 执行 {:?}，使 anyhow::Error 在 Display 约束下输出回溯。
