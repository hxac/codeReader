本讲确立 gpui_util 的定位：它是 zed 工作区最底层的公共基础工具箱，被 gpui、fuzzy、lsp、collections 等约 16 个 crate 依赖，自身零 GPUI 依赖，以此避免循环依赖并让轻量 crate 免于背负 UI 框架。三个最小模块：一是 crate 定位与依赖图；二是 Cargo.toml 的「极简依赖＋平台门控」——全平台依赖仅 log 与 anyhow，which 只在 Windows 目标下生效，版本、发布策略与 lint 均由 workspace 继承统一管理；三是 lib.rs 门面——顶部历史注释记录了 FluentBuilder、FutureExt、Timeout 的迁出痕迹，导入只用 std，唯一子模块 arc_cow 定义了 Borrowed/Owned 二选一的 ArcCow 智能指针。关键术语：workspace 继承、#[cfg] 条件编译与平台门控依赖、公开项清单表。清单表罗列 new_std_command、ResultExt、defer、TypeIdHasher、部分排序工具等全部公开项，是后续各讲解的取材地图，其中仅 get_windows_system_shell 为 Windows 专属。
