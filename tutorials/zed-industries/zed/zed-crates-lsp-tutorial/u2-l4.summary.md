本讲围绕 LanguageServer 的关闭路径，覆盖 shutdown 方法、收尾管线与 Drop 实现。LSP 规定两步关闭：先发 shutdown 请求并限时等待（SERVER_SHUTDOWN_TIMEOUT，五秒），再发 exit 通知，最后 kill 进程。shutdown() 用 Option::take 取走 io_tasks，构造不借用 self 的 'static 关闭 future，重复调用返回 None，天然幂等。future 内 select! 让 Shutdown 请求与外层定时器竞争，ConnectionResult 四类分支只影响日志，收尾无条件执行：清空响应表 → 经序列化通道发 Exit → 关通道触发排空级联 → await output_done barrier 确认 Exit 已 flush → kill 子进程，barrier 保证「Exit 先落盘、进程后被杀」，kill_on_drop 为第二道保险。Drop 仅三行：spawn().detach() 把异步收尾发射到后台；应用层（如 LspStore）显式 await 同一 future 以获得确定的完成点。关键术语：两步关闭、output_done barrier、序列化闭包通道、ConnectionResult、$/cancelRequest、幂等。
