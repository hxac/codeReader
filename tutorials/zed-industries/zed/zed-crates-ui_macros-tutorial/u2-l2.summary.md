本讲精读 ui_macros 中 dynamic_spacing.rs 的 derive_spacing 生成阶段：用 quote 把 u2-l1 解析得到的 DynamicSpacingInput 拼装成完整的 DynamicSpacing 枚举与 impl 块，结构为“两轮备料 + 一次组装”（先造 match 分支 spacing_ratios 与变体名/文档对，再填入总模板）。核心概念：`#变量` 插值可插入任何实现 ToTokens 的数据，数值经历 token→数值→token 往返、丢失原 span；`#(...)*` 重复语法要求各 Vec 等长“齐步走”，逗号写在重复体内会产生合法的尾随逗号；format_ident!("Base{:02}", n) 生成变体名，XX 取 Default 档像素值（Single 取 n，Tuple 取中间值 b）；`#[doc = #doc_string]` 动态注入文档，与 `///` 等价。生成代码里的 `::theme::` 绝对路径及 App、rems、px 等裸名字由调用方 ui crate 的 use 导入与依赖负责解析，ui_macros 自身只依赖 syn 和 quote；末行 TokenStream::from 完成 proc_macro2 到 proc_macro 的跨界转换。验证手段是手工展开推导生成代码。
