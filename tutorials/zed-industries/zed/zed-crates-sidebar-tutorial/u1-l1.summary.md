sidebar crate 是 Zed 的多项目 Agent 线程与终端侧边栏，不是文件树项目面板，列表覆盖窗口内所有项目分组，因此挂在 MultiWorkspace 而非单个 Workspace 上。库根 sidebar.rs（无 lib.rs）承载 Sidebar 实体、订阅接线、重建管线与渲染；sidebar_tests.rs 仅测试编译、体量约为实现两倍；thread_switcher.rs 是自包含的 ctrl-tab 风格线程切换器模态。核心架构约束：任何变化经 schedule_update_entries 去抖后由 update_entries→rebuild_contents 从当前世界状态全量重推导列表，禁止增量协调状态。依赖即分层：sidebar 组合 agent_ui（AgentPanel、ThreadMetadataStore）、workspace（Sidebar 契约 trait）、project/git 与 gpui/ui，自身不做持久化和 git I/O。装配发生在 zed crate：observe_new 捕获新 MultiWorkspace，defer 后 cx.new 创建实体并经 register_sidebar 存为 Box<dyn SidebarHandle>，由 SerializeNeeded 事件触发宿主持久化。
