本讲讲 sidebar 测试脚手架的搭建，测试世界分四层：`init_test` 铺全局，缺任一即 panic，本地轻量版与 agent_ui 重装版以“是否需要真实 AgentPanel”为分界；`init_test_project` 家族用 FakeFs 与 `Project::test` 造项目，多项目变体插 `.git` 以触发 git 逻辑；`cx.add_window_view(MultiWorkspace::test_new)` 开窗口并把 `TestAppContext` 升级为 `VisualTestContext`（经 Deref 保留旧能力）；`setup_sidebar` 家族复刻生产装配的 `Sidebar::new` 加 `register_sidebar` 两步，closed 版服务关闭语义测试，toggle 版服务列表与键盘测试。关键术语：`run_until_parked`（确定性执行器里异步收敛的唯一手段）、`save_thread_metadata` 播种家族（按 session_id 稳定 thread_id，写后自动触发列表重建）、断言出口 `visible_entries_as_strings`。空列表仍含一个项目分组头。
