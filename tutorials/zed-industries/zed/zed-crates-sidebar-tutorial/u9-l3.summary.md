本讲为 sidebar 手册收官。核心是不对称双通知集合：notified_threads 靠记忆字段检测 Running→Completed 跳变（边沿触发），跨重建继承、本窗口看到即清除；notified_terminals 读面板 has_notification 布尔（电平触发），每轮现算不继承。消费三层：行徽标（ThreadItem::notified）、折叠分组头圆点、状态栏圆点，末者经 WorkspaceSidebar::has_notifications trait 契约跨 crate 传递，宿主仅在通知有无翻转时被唤醒。另辨三种提示形态：持久徽标、一次性 StatusToast（挂 workspace toast 栈，用于标题再生成失败）、常驻导入横幅（外部 Agent 与跨通道两条，Dismissable 键值持久化，verbose 文案由 Option<bool> 首帧定档冻结以防宽度跳变）。调试上，dev::DumpWorkspaceInfo 把多工作区分组与面板 ID 一致性倾倒进只读 Editor，DISAGREES 与 workspace ID mismatch 即分组错乱的烟枪。
