本讲区分 sidebar 侧边栏两个易混状态字段。selection 是键盘焦点所在的行下标（Option<usize>），属易失交互状态：点击或输入搜索词即清空、列表重建后需钳制、仅侧边栏持有焦点时才显示高亮。active_entry 是全局活跃条目，ActiveEntry 枚举含 Thread（thread_id、session_id、workspace）与 Terminal 两变体，无分组头变体；写入点分面板事件同步（权威来源）、用户乐观预写、生命周期清理三类。matches_entry 采用双钥匙匹配：thread_id 相等，或双方 session_id 均为 Some 且相等——因 ThreadId 是本地铸造的 UUID、跨窗口恢复可重铸，SessionId 是 ACP 远端会话身份、恒稳定；终端仅比 terminal_id，草稿靠 zip 避免 None 误匹配。is_active_workspace 以实体句柄相等判定当前工作区，分组头活跃由重建时推导。同步链 sync_active_entry_from_panel 设宿主存活与活跃面板两道防线，pending_thread_activation 作防抖：未消解时保留现状，靠 session_id 兜底维持高亮。
