本讲覆盖侧边栏线程行与终端行的渲染层。核心组件是 ui crate 的 ThreadItem：RenderOnce 纯展示组件，一行分主行（图标槽、标题槽、悬停操作槽）与可选元数据行，两槽各有优先级链——图标槽依次为 Running 旋转图标、状态图标、agent 图标（icon_char 最优先），标题槽依次为 title_slot、生成中脉冲、HighlightedLabel、普通 Label。render_thread 是 ThreadEntry 到 builder 参数的纯翻译层，注意命名陷阱：is_selected 实为活跃条目（背景高亮），focused 才是键盘选中（边框）。render_terminal 更薄，独有「标题装饰前缀图标化」：terminal_title_prefix 检测符号前缀，pick_icon_glyph 剥一层括号、把省略号浓缩、取首字素簇，split_leading_icon_char 再按 UTF-8 字节偏移平移并丢弃落入前缀的高亮位置；字素簇保证多码点 emoji 完整。agent-thread-worktree-label 特性开关经 apply_worktree_label_mode 在渲染期裁剪 worktree/branch 徽标，仅触发重渲染、不改数据模型与行高。关键术语：AgentThreadStatus、ThreadItemWorktreeInfo、icon_char、字素簇。
