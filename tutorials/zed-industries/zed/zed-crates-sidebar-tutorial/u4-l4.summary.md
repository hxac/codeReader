本讲为渲染层收官，覆盖 sidebar.rs 四个模块。其一，workspace_menu_worktree_labels 在菜单打开时现算工作区标签：多根才显示文件夹名；git worktree 显示「主名/worktree 名」，主仓固定为 main，linked worktree 用 linked_worktree_short_name 短名（撞名退父目录名）；无仓库则仅文件夹名、无图标。其二，分组头尾部两颗按钮：「+」按组内有无打开工作区分流，非空弹 New Thread In… 菜单并附 Create New Worktree… 子菜单；「⋯」菜单用 build_persistent 确认后保持打开以支撑 Move Up/Down 连续排序，需关闭的条目手动发 DismissEvent。其三，DefaultBranchCache 按 ProjectGroupKey 为键、缺失/Pending/Resolved 三态、只增不减，由 update_entries 末尾预热，把异步 git 查询挪出同步菜单路径；无仓库时刻意保持缺失以便重试，Resolved(None) 是不重试的终态。其四，两个薄委托适配器：create_worktree_in_workspace 转发 git_ui_core 的 handle_create_worktree（选项由 worktree_create_targets 推导，词汇借道 zed_actions），connect_remote 作为回调注入 MultiWorkspace::find_or_create_workspace，侧边栏只编排不实现 git 操作与远程连接。
