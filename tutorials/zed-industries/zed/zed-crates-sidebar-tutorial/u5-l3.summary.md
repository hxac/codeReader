本讲覆盖侧边栏搜索支线：filter_editor 是单行 Editor 实体，其 EditorEvent::BufferEdited 订阅在读到非空查询时先 take 掉 selection，再调度刷新并选中首个匹配行；空查询则两者皆不动。过滤裁决位于 rebuild_contents 的搜索支线，对分组标签、线程标题、终端标题、worktree 名四路匹配，任一命中即保留，全空则连分组头一并丢弃。fuzzy_match_positions 名为 fuzzy，实为 ASCII 大小写不敏感的连续子串匹配（不支持跳跃），返回字节偏移，空查询返回 Some(vec![])。highlight_positions（字节偏移）一路传给 ThreadItem 与 HighlightedLabel 绘制高亮；终端行由 split_leading_icon_char 剥离装饰前缀并重映射位置：落入前缀者丢弃，其余左移前缀字节数。退出搜索有三条路径（搜索框 Escape 两段式、列表 Escape、清除按钮），共用 reset_filter_editor_text，其返回值区分「已清」与「本来就空」；has_filter_query 驱动空态文案、清除按钮显隐等 UI 分支。搜索压倒折叠：折叠分组内命中照常浮出。
