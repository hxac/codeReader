本讲解析 sidebar 线程归档的完整流水线：归档不止翻转数据库 `archived` 标志，还级联删除空草稿、处置工作区、存档 git 状态并删除 linked worktree 目录。五个最小模块：一是主编排 `archive_thread`（Closed 行先补开工作区再递归重入）；二是归档根推导（`RootPlan` 快照须过四道门槛：被打开 project 加载、是 linked worktree、位于托管目录、确系 Zed 创建）；三是阻塞谓词 `thread_blocks_worktree_archive`（非草稿或含用户内容的草稿必阻塞）支撑三道防线；四是级联清理（纯归档工作区整区移除、混合工作区只关命中条目保布局）；五是磁盘事务 `archive_worktree_roots`（persist 产出 WIP 游离提交对、DB 记录与防 GC ref，再删目录，失败或取消即逆序回滚）。核心顺序约束：根推导必须先于工作区移除，因实体销毁后不可再查。磁盘任务分绑定版（挂入 `in_flight_archives`，失败自动 `unarchive`、用户可取消）与分离版（终端/草稿专用，失败仅记日志）；`archive_and_activate` 是落锤，标记归档并交接邻居条目；用户取消工作区移除则整链终止、线程不归档。
