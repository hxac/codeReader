本讲义绘制 rope crate 的源码地图：六个文件呈「叶子—躯干—门面」三层。rope.rs 经 `[lib] path` 兼任 crate 根，用私有 `mod` 加 `pub use` 再导出收窄 API 面，内部居住 `Rope`、游标 `Cursor`、迭代器 `Chunks`/`Bytes`/`Lines`、摘要 `TextSummary`/`ChunkSummary` 与 `TextDimension` trait，位图等细节以 `pub(crate)` 留在内部；chunk.rs 是躯干，定义不超过 128 字节的定长块 `Chunk`（四张位图把块内统计变成位运算）、零拷贝切片 `ChunkSlice`，测试配置将位图缩为 u16 以便触发边界路径；point.rs、point_utf16.rs、offset_utf16.rs 是只依赖 std 的坐标叶子，分别对应字节口径 `Point`、UTF-16 口径 `PointUtf16` 与 `OffsetUtf16`；unclipped.rs 提供零开销的 `Unclipped<T>` 未裁剪坐标标签。核心结论：crate 内模块允许互相引用；`Point` 加法是「位置+位移」语义且不可交换；`Point` 与 `PointUtf16` 字段相同而单位不同，混用必须显式换算。
