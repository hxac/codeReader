本讲为单元3收官，覆盖 Platform trait 三组能力。光标样式是「paint 期收集、帧末结算」的延迟链路：`.cursor()` 声明由 div 借 hitbox 登记 CursorStyleRequest，帧尾倒序折叠命中，仅被悬停的窗口才调 set_cursor_style，拖拽中的窗口级光标优先；hide_cursor_until_mouse_moves 与 is_cursor_visible 成对服务「打字藏光标」。五平台落地各异（NSCursor、cursor-shape-v1/XCursor、HCURSOR、CSS），共享「隐藏期间不覆盖、弹出层期间跳过」守卫。window_appearance 四平台皆可查询，Linux 值来自 xdg-desktop-portal 的 color-scheme；set_window_appearance 仅 macOS 生效，因其窗口 chrome 由 AppKit 渲染，VibrantLight/VibrantDark 变体亦为 macOS 独有。外部拖放中 ExternalDragPayload（当前仅 Files/FileDragPaths）懒解析，拖出视口后经 promote_external_drag_to_platform 过四道闸门晋升为系统拖拽，状态挂起为 PlatformOwnedDrag::Suspended 且拖回源窗口可恢复；仅 macOS 与 Wayland 实现，X11/Windows/Web 走默认 can_start_external_drag() == false。反向拖入由 FileDropEvent 承载，留待后续。
