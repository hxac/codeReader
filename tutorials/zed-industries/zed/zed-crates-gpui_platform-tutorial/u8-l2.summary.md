本讲讲解 gpui 的纹理图集与渲染后端。PlatformAtlas 是以绘制参数为键、瓦片位置为值的平台无关缓存：AtlasKey 分字形、SVG、图片三类，并按单色、彩色、亚像素三类纹理归类；AtlasTile 是嵌入 GPU 实例缓冲的取件凭证。paint_glyph 等链路先量化亚像素相位、组装 RenderGlyphParams 等键，再经 get_or_insert_with 取件——未命中才做 CPU 光栅化，使纹理切换由精灵数级降至纹理数级，Scene 随后按纹理标识合批。Windows 侧的 DirectXAtlas 用 etagere 分桶装箱、free_list 回收纹理槽位，设备丢失时清空重建、恢复折叠进正常 paint。所有权链为全局设备一份、渲染器每窗口一份、图集每渲染器一份，经 sprite_atlas() 以 Arc 交付 gpui；路径图元不走图集而走每帧 MSAA 中间纹理。MetalAtlas 同型但无亚像素组，体现同一契约在不同 GPU API 上的落地差异。
