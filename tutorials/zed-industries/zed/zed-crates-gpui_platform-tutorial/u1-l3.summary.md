本讲读 gpui_platform 的 Cargo.toml 与各平台 crate 目录。核心结论：workspace 根对 gpui 家族统一声明 default-features = false，把 feature 开关权上收给最终消费者；按目标划分的四段依赖保证任何编译目标恰好链接一个平台 crate。门面 7 个 feature 全是透传电线：wayland/x11 经 gpui_linux 拉起系统绑定库，font-kit、runtime_shaders 属 macOS，screen-capture 覆盖桌面三平台，test-support 通往测试设施。引入概念：feature 可加且全图统一、dep:/? 与可选依赖、透传链。运行期暗线：guess_compositor 仅在对应 feature 开启时探测环境变量，零 feature 构建只能得到 headless 后端。目录方面，gpui_linux 的 wayland/、x11/ 两目录整体受 feature 门控，其余平台 crate 基本扁平。
