本讲剖析 gpui_windows 的 DirectX 渲染栈四层结构：设备层 DirectXDevices（全应用一份的适配器/工厂/D3D11 设备四元组，逐卡枚举并要求结构化缓冲支持）、渲染器层 DirectXRenderer（每窗口一份，交换链加八条管线，覆盖阴影、矩形、路径、下划线与三类精灵）、图集层 DirectXAtlas（实现 PlatformAtlas 契约，用 etagere 把字形与图标装箱进 Monochrome/Subpixel/Polychrome 三类纹理）、窗口层 WindowsWindow。核心结论：帧驱动由独立 VSyncProvider 线程承担，每垂直同步周期 RedrawWindow 失效全部窗口，schedule_frame 走默认空实现，与 Wayland 按需唤醒形成对照；GPU 设备丢失由 vsync 线程检测并触发跨线程重建链路；DirectWrite 与渲染栈深度耦合（GPUState 光栅化 emoji、伽马与对比度参数注入每帧 GlobalParams）；亚像素文本采用 dual-source blending 专属混合，路径图元走 4x MSAA 两阶段渲染；direct_manipulation 借系统 Direct Manipulation API 把精密触控板手势分类翻译为 ScrollWheelEvent 与 PinchEvent。
