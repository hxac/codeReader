本讲剖析 GPUI 的单前台线程模型与执行器体系。核心结论：全部实体状态与 UI 绘制都限定在主线程——ForegroundExecutor 用 PhantomData<Rc<()>> 在编译期锁死非 Send，App::new_app 再用 is_main_thread 断言兜底，由此免锁并与平台事件循环对齐。执行器契约是 Platform trait 的 background_executor 与 foreground_executor 两方法：平台只造一个 PlatformDispatcher，用同一实例构造前台、后台两个执行器，分别经 dispatch_on_main_thread 与 dispatch 投递任务。分工上，cx.spawn 允许非 Send future、按序跑主线程且优先级被忽略；cx.background_spawn 要求 Send、支持优先级与专用线程。Context<T>::spawn 自动传 WeakEntity<T> 防止实体泄漏。Task 被 drop 即取消，管理方式有 await、detach/detach_and_log_err、存字段三种。hello_web 素数计数流水线是标准范本；下一讲 u4-l2 深入 PlatformDispatcher 契约。
