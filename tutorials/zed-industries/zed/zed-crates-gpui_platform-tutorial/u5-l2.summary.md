本讲深入 Linux 第三后端 headless 的实现。进入无头有两条路：显式 `headless()`（布尔参数短路，优先于环境探测）与隐式经 `guess_compositor()` 兜底（`ZED_HEADLESS` 存在即触发）。核心是 `HeadlessClient`——`LinuxClient` 契约的最小实现，其方法分五类姿态：空操作、返回 None、返回假数据（唯一假屏 `HeadlessDisplay`、合成器名 "headless"）、显式报错（屏幕捕获）、真实工作（`open_window`、`run`）。无头窗口 `HeadlessWindow`「存在但不显示」：布局、文本整形与实体管线照常运行，首帧由 `App::open_window` 强制绘制；此后 `frame_waker` 为 None 且 `on_*` 回调被丢弃，`cx.notify()` 只标脏不重绘，等待一帧的代码永不 resolve，多帧须手动 `window.draw` 驱动。`HeadlessAtlas` 只分配 tile 不上传像素。事件循环是自建的纯 calloop，仅含前台任务与系统唤醒两种事件源；文本系统取决于编译 feature 而非后端。工程意义：CI 与无显示服务器可跑通 GPUI 全链路，零 feature 构建天然 headless。
