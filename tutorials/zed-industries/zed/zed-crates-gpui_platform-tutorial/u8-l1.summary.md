本讲解析 PlatformTextSystem——gpui 的跨平台字体引擎契约，方法分字体管理、度量查询、整形光栅化、渲染策略四组；它是唯一以 Arc 共享且 Send+Sync 的平台设施，各实现以 RwLock 包状态。核心管线：Font 经 font_id 解析成进程内句柄 FontId（GlyphId 是字体文件内部编号），连同 FontRun 交给 layout_line 整形，产出 LineLayout（ShapedRun、ShapedGlyph，带 UTF-8 字节下标供光标定位）；再打包成可哈希的 RenderGlyphParams（直接充当图集 key），经 rasterize_glyph 输出灰度掩码或 BGRA emoji 位图，交给下一讲 PlatformAtlas。gpui 主 crate 的 TextSystem 是包住平台实现的缓存层，带回退字体栈。四套实现：macOS 用 font-kit+CoreText；Linux 与 Web 共用 cosmic-text+swash（CosmicTextSystem）；Windows 用 DirectWrite 并内嵌 D3D11 光栅化彩色 emoji；无引擎时退化为 NoopTextSystem。关键约定：descent 取负值、字号 next_up() 打断跨 run 连字、UTF-16 下标换算、recommended_rendering_mode 各平台自定；并纠正旧印象——font-kit 仅存在于 macOS 路径。
