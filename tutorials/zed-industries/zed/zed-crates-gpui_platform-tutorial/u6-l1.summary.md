本讲剖析 gpui_macos 五个模块，讲解 Platform 契约的 macOS 落地。platform.rs 用一把 Mutex 管全部状态，以 ctor 注册的 ObjC 委托类实现控制流倒置：委托方法经 ivar 取回 Rust 指针操作回调槽位；启动回调延迟到 DidFinishLaunching 才执行，quit 投递 GCD 主队列以防锁重入；AppKit 主线程约束令测试须单线程运行。events.rs 无状态地把 NSEvent 译为 PlatformInput，做 y 坐标翻转、command 归一为 platform，并区分布局无关的 key 与布局相关的 key_char。pasteboard.rs 用文本哈希侧车校验元数据一致性，另封装系统级查找粘贴板。display_link.rs 以每屏永生 CVDisplayLink 加窗口订阅者规避停止竞态。window_appearance 做外观名与枚举互映。末尾归纳契约门控四式：编译期 cfg、默认 no-op、必需方法与 feature 门控。
