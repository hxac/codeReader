本讲是第 7 单元（Web 平台）收官实战，以 hello_web 示例贯通 GPUI wasm 应用全貌。核心结论：一个 wasm 应用由七个文件拼成——rust-toolchain.toml 锁 nightly 工具链、.cargo/config.toml 配 atomics/共享内存链接参数与 build-std、Cargo.toml 以空 [workspace] 表把示例摘出主 workspace、index.html 内嵌 trunk 构建指令、trunk.toml 用 COOP/COEP 响应头开启跨域隔离；trunk 经 wasm-bindgen 生成 JS 胶水并自动调用 Rust main。关键概念：requested_backend 用 URL 查询参数在 WebGpu/WebGl/Auto 间切换渲染后端，同一二进制免编译对照；跨域隔离决定 SharedArrayBuffer 与 supports_threads，缺失即回退单线程人格。核心范本 start_search：计算切 NUM_CHUNKS=12 块并行，每块是「background_spawn 纯计算内核 + cx.spawn 主线程壳」两层结构，this.update 回主线程、cx.notify 驱动进度，_tasks: Vec<Task<()>> 持有任务防 drop 即取消，clear() 即作废旧一轮。移植要点：std::time::Instant 换 web_time、多窗口收敛为单窗口。
