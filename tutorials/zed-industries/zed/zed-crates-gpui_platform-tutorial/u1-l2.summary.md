本讲把 u1-l1 的门面结论落成可运行代码：`application()` 即 `with_platform(current_platform(false))`，平台选择在编译期由条件编译与按目标分组的依赖共同完成，运行期无需判断，wasm 目标自动走 web 后端。`with_platform` 是平台注入点（依赖注入）：`App::new_app` 从 `Rc<dyn Platform>` 抽取前后台执行器、文本系统、键盘布局，默认装空 HTTP 客户端，且必须在主线程构造。`Application::run` 把启动回调交给平台事件循环并阻塞，回调在启动完成后于主线程执行一次，是开窗初始化的正确时机；开窗链路经 `Window::new` 把应用层 `WindowOptions` 翻译为平台层 `WindowParams`，再调用 `Platform::open_window`，返回前强制绘制一帧。`headless()` 与 `application()` 仅差 headless 布尔：无头模式下窗口逻辑存在但不上屏、系统能力空操作，事件循环（Linux 为 calloop）照常运转。引入的关键术语：`Rc<dyn Platform>` 平台注入、`WindowOptions`/`WindowParams` 分层、`WindowHandle`、`build_root_view`、`HeadlessClient`、`guess_compositor()` 环境变量探测。
