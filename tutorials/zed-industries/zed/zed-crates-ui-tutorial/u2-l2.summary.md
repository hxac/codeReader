本讲覆盖 ui crate 的 Label 模块（label.rs、label_like.rs）与排版系统（styles/typography.rs、styles/units.rs）。核心结论：Label 是薄门面，仅持 LabelLike 基座、文本与代码片段开关，size/color/weight 等 13 个 LabelCommon trait 方法全部一行委托给基座，HighlightedLabel 等兄弟组件复用同一基座；LabelLike::render 是排版汇总点，渲染期查主题解析语义色、按 LabelSize 档位应用样式，未显式设置时字重默认跟随用户 UI 字体。三种单行截断同构：min_w_0 + overflow_x_hidden + whitespace_nowrap + 省略号位置（text_ellipsis/start/middle）；line_clamp 需叠加 text_ellipsis 才显示末行省略号。TextSize 是文字版设计令牌（Large/Default/Small/XSmall 固定四档 + Ui/Editor 跟随档），经 rems_from_px（÷16）换算为 rem，由 StyledTypography 扩展 trait 提供 text_ui* 等方法。关键机制：窗口 rem 基准由 theme_settings 的 setup_ui_font 设为 ui_font_size，故调 UI 字体即整体缩放界面（不存在 ui_scale 设置）。关键术语：LabelCommon、LabelLike、LabelSize、LineHeightStyle（TextLabel/UiLabel）、TextSize、StyledTypography、Headline、rem 换算链。
