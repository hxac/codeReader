ui 是 Zed 基于 GPUI 的官方组件与样式库，处于「gpui 框架 → theme/icons/component/ui_macros 支撑层 → ui → 业务 crate → zed 应用」的分层中枢：约 71 个 crate 依赖它，而它不依赖任何业务 crate。兄弟分工：gpui 供框架能力，theme 供 ActiveTheme 主题令牌，icons 供 IconName 图标资产，component 与 ui_macros 服务组件预览体系。lib 根是 src/ui.rs（由 Cargo.toml 的 [lib] path 指定），声明 6 个顶层模块，其中 components、styles、traits 为私有模块，经 `pub use ...::*` 扁平 re-export 倾倒到 crate 根，换来 `ui::Xxx` 短路径与内部重构自由。src/components.rs 是 42 个组件的「目录页」，mod 声明与 pub use 一一对应；组件分单文件与目录型（模块根 .rs 加同名子目录）两种形态，定位组件以该声明为准而非磁盘文件。以 Button 为例的五跳导出链（定义 → button 模块根 → components → crate 根，另经 prelude 殊途同归）是后续讲义定位组件源码的通用方法。
