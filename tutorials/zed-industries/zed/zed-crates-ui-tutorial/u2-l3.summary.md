本讲讲解 ui crate 的密度感知间距令牌 `DynamicSpacing`。核心结论：间距禁止硬编码像素，组件构建期只存 `BaseXX` 语义键，渲染期经 `rems(cx)` / `px(cx)` 按当前 `UiDensity`（Compact / Default / Comfortable 三档实验性设置）解析，延续 u2-l1 语义颜色的「语义键＋渲染期解析」模式。枚举共 14 档，由 spacing.rs 的一张间距表经 `derive_dynamic_spacing!` 函数式过程宏生成，支持三元组与单值（±4 公式）两种输入，变体名取 Default 档像素值；密度设置由 theme_settings 持有、经 `ThemeSettingsProvider` 全局桥接，ui 仅依赖 theme 而与设置实现解耦。关键认知：两个出口都随 UI 字体（rem 基准）缩放，「Base04＝4px」仅在 16px rem＋Default 密度下成立；`ui_density()` 只用于非间距的结构或既有令牌切换，间距一律走 `DynamicSpacing`。
