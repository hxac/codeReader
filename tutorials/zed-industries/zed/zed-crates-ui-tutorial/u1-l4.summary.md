本讲覆盖布局原语三个模块：stack.rs、group.rs、styled_ext.rs，均可经 ui::prelude 引入。核心结论：h_flex() = flex+flex_row+items_center，v_flex() = flex+flex_col，交叉轴对齐上的不对称是刻意设计；h_group_sm/lg/xl 及纵向版本是成组控件容器，只设 flex 与固定 gap（子元素间距），四档对应 2/4/6/8px，样式方法数字后缀按 N×4px 换算、以 rem 表达。ui 封装分三层：gpui Styled 原子方法 → StyledExt 组合方法（blanket impl 覆盖一切实现了 Styled 的元素）→ stack/group 快捷函数；函数做链起点、方法做链中段，#[track_caller] 保住 panic 定位。flex_1() 提供弹性留白，debug_bg_* 提供调试底色。综合实践以「图标组 + Divider 分隔线 + 弹性留白 + 主按钮」搭出工具栏骨架。
