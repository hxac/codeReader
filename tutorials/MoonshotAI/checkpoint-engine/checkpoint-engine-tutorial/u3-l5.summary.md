本讲补齐 update 广播主流程的两个输入来源：bucket_size 怎么定、桶清单怎么切。H2DBucket(size, ranges, items) 是流水线的调度单位；BucketRange(idx, offset, size) 描述桶内字节的“取货清单”，本地装填时当切片下标用，P2P 远端读时当绝对地址用。切桶纯函数 _gen_h2d_buckets 按 owner 分组绝不混桶，bucket_size 是软上限、以整个对齐槽位为原子，绝不切开单个张量，一个桶的 ranges 可跨多块锁页 buffer；ranks 为空（Broadcast/colocate）时 owner 即 receiver。_detect_bucket_size 借一次 all_reduce(MIN)（负数技巧捎带取全集群最大 ZMQ 计数器）以最小空闲显存定预算：启用 h2d_buffer 时预算为 free/3，最大单张量放不下则禁用 h2d_buffer 改为 free/2，最终 bucket_size = min(max(PS_MAX_BUCKET_SIZE_GB 默认 8GiB, 最大张量), 预算)，连 free/2 都装不下则断言报错。调参旋钮为 PS_MAX_BUCKET_SIZE_GB 与 mem_fraction/PS_MEM_FRACTION，且探测必须先于 ZMQ socket 绑定。
