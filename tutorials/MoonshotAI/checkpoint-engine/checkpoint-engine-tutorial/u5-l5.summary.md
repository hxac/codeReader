本讲精读 p2p_store.py 与 device_utils.py 的 RDMA 网卡发现链。P2PStore 是 mooncake TransferEngine 的防腐层：初始化以 8 次随机退避重试规避端口冲突，对外仅批量注册、注销、同步读三个平行数组接口；RDMA 单边读要求两侧内存都注册——owner 锁页池与接收侧以 `__ipc_buffer__` 注册的 GPU 缓冲。网卡发现走三级优先级：`PS_P2P_STORE_RDMA_DEVICES` 原样采用、`NCCL_IB_HCA` 经解析器（= 精确、^ 排除、^= 组合、端口剥离、32 上限）、兜底全部 ibverbs 设备。`_get_my_rdma_device` 按网卡数与 GPU 数的整除约束静态均分：网卡少时连续 rank 共享一块，网卡多时每 rank 独占多块的逗号拼接；网卡名同时是传输路径与「网卡名@主机IP」拓扑键。未装 mooncake 时优雅降级、Broadcast 不受影响，XPU 上 P2P 被直接拒绝。
