本讲解决「怎么装、怎么跑、怎么验收」，精读 pyproject.toml、README 与 examples/update.py，兼及 worker.py、api.py、ps.py 的 auto_pg 参数和 tests/。核心结论：安装分两档，基础包仅支持 Broadcast 更新，`[p2p]` extra 才引入 mooncake-transfer-engine（延迟导入，缺它不影响整包 import）；vLLM 侧须用 `--worker-extension-cls` 注入 VllmColocateWorkerExtension，依赖 `/collective_rpc` 端点，并配 `--load-format dummy` 免去磁盘加载。引入的关键术语与概念：extra 可选依赖、torchrun 与 RANK/WORLD_SIZE、worker extension、colocated 部署、控制面走 HTTP 而数据面走 ZMQ 加 CUDA IPC、checkpoint 按文件与按张量两种均分、组首进程（rank 对 P 取余为零）、auto_pg 进程组自动销毁重建、join 复用模式、gpu marker。主流程为 init_process_group、barrier、register_checkpoint、gather_metas、update（broadcast）、睡两秒后再 update（p2p）；验收用 pytest 选 not gpu 在纯 CPU 跑单元测试。
