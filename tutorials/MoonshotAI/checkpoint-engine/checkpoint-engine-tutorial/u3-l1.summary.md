本讲精读 ParameterServer 构造函数（ps.py），旁及 DeviceManager 与 P2PStore。核心结论：初始化顺序敏感——先选定本机设备，再取设备 UUID、按能力开关创建 P2PStore，TCPStore 最后建立。关键公式 local_rank = rank % gpu_count，隐含各机 GPU 数相同、rank 按主机优先连续分配的部署假设。TCPStore 默认占用 MASTER_PORT+1 以避开 torchrun 的会合端口，充当全组控制面公告板，之后套自增前缀的 PrefixStore 支撑进程组反复重建。DeviceManager 是唯一硬件入口，按 npu、xpu、cuda 优先级探测，统一暴露设备模块、通信后端与能力开关。_device_uuid（CUDA 读设备属性，NPU 用 npu-smi 反查）是 PS 命名与 worker 寻址 ZMQ 抽象 socket 的共同钥匙；_memory_pool、_p2p_store 等将由后续讲承接。
