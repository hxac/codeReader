本讲讲解锁页内存（pinned memory）与两种 pin 策略。锁页是异步 H2D 与 RDMA 传输的前提：pageable 源须经驱动 staging 同步中转，物理页锁定后 non_blocking=True 才真正异步，因此昂贵的 pin 被放在 register_checkpoint 注册阶段一次完成、更新阶段反复受益。两种策略的产物统一由 MemoryBuffer 承载：扁平 uint8 锁页 buffer、按排布顺序的 ParameterMeta 列表（offset 由 aligned_size 逐个累加隐含）、manually_pinned 标志（决定注销时是否需手动 cudaHostUnregister）。_normal_pin_memory 先用 torch.empty(pin_memory=True) 分配再拷入：按 max(4GiB, 最大张量) 贪心切桶、参数名字排序保证布局确定、32 线程两级流水，槽位按 256 字节对齐。_inplace_pin_memory 针对 /dev/shm 中的 safetensors：torch.from_file 映射后用 cudaHostRegister 原地锁页、不搬数据，并删除源文件防双倍内存，其槽位大小取文件自身布局。分派上 named_tensors 恒走 normal，非 CUDA 后端与共享内存池模式强制关闭 inplace。
