本讲下潜到 inplace pin 的底层实现与手动 unpin。inplace 路径不拷贝权重：用 `torch.from_file` 把 `/dev/shm` 下的 safetensors 文件整体 mmap，手工解析「8 字节小端长度前缀 + JSON 头」定位数据区，按 `data_offsets` 排序重建 `ParameterMeta`，`aligned_size` 取 end−start（异于 normal 路径的 256 字节向上取整），以两条断言保证文件布局即 buffer 布局，每个文件独占一个 `MemoryBuffer`（桶粒度即文件粒度）。锁页经 `torch.cuda.cudart()` 调 `cudaHostRegister`（flags=0，先 set_device）；解页先用 `ctypes.CDLL(None)` 调 `cudaHostGetFlags` 校验（断言 0x02）再 `cudaHostUnregister`，整体遵循「先校验、先解页、后删池」的防御式顺序，由 `manually_pinned` 标志判定是否手动解页，注册失败的回滚同样复用 `unregister_checkpoint`。解析完成后随即 `os.remove` 源文件：tmpfs 是内存盘，unlink 只删目录项，数据页由映射引用继续持有，锁页 buffer 成为权重唯一驻留形态，避免二次占用内存与配额。该路径仅 CUDA 支持且要求 `/dev/shm` 下的 `.safetensors` 文件，其余一律回落 normal pin，注销后以 `host_empty_cache` 收尾。
