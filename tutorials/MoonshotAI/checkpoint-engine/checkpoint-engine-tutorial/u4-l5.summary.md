本讲讲控制面的 HTTP 外壳，精读 `api.py` 与 `__main__.py`。核心结论：`_init_api(ps)` 是 FastAPI 应用工厂，以闭包捕获把 7 个 REST 端点（注册/注销、gather-metas、metas 读写、update、healthz）一一映射到 `ParameterServer` 方法；`wrap_exception` 把业务异常统一转成 500 加异常文本，pydantic 校验失败则返回 422 且 PS 方法不被调用。update 端点把声明式请求体「编译」为闭包 `update_func`：`update_url` 为 None 早退、`inference_group_ranks` 对 rank 序的 socket_paths 做下标过滤、`ranks` 独立决定 Broadcast/P2P，通知维度与传输维度正交；`request_inference_to_update` 借 httpx 的 `HTTPTransport(uds=...)` 切换 TCP/UDS 双通道，向 vLLM 的 `/collective_rpc` 发 `update_weights_from_ipc` 调用，闭包由 PS 数据面线程而非 HTTP 线程执行。部署采用 UDS-only 的 `python -m checkpoint_engine --uds`，必须 `auto_pg=True` 使进程组按需建毁；测试范式为 MagicMock 加 TestClient 纯 CPU 覆盖。
