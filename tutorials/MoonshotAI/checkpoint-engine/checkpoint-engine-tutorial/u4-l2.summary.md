本讲补上 u4-l1 留下的两条接缝。VllmColocateWorkerExtension 是纯适配器：经启动参数 --worker-extension-cls 注入 vLLM worker，由 /collective_rpc 端点按方法名调用；PS 不直接依赖 vLLM，只调用注入的 req_func，组首按实例切片、仅向本节点 vLLM 发送本实例 P 条 ZMQ 地址（抽象 UDS 仅主机内有效）。设备 UUID 是 PS 与同卡 worker 跨进程配对的钥匙，CUDA/NPU/XPU 三平台生成规则不同（NPU 用 npu-smi 反查物理芯片合成），两侧输出必须逐字符一致，否则查表 KeyError。_load_weights 每桶执行一次，同一份全量权重清单同时喂主模型与 MTP drafter（投机解码草稿模型），由各模型按名字各取所需；_post_hook 与「第二个 None」绑定，在全部桶装载完毕后执行一次 process_weights_after_loading，补上被热更新绕过的权重后处理，也是 FP8 补丁的伏笔。
