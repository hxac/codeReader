本讲精读 ParameterServer 的注册与注销生命周期，核心心智模型：register_checkpoint 是事务，`_memory_pool` 是账本，unregister_checkpoint 是逆事务。注册统一处理 files 与 named_tensors 两种输入，空输入合法返回空列表（“空注册”），支撑高秩 rank 分不到权重的场景；内存层分派器将其分流为 normal pin 与原地锁页（仅 CUDA、/dev/shm 的 safetensors，成功后删源文件）。锁页之外还须向 p2p store（mooncake transfer engine）报备地址，命名规则为 memory_pool_<名>_<idx>；共享池模式下注册名恒为 `__shared_memory_pool__` 且只在首次注册——地址不变则注册不变，这是 join 复用模式的物理基础。注销分三岔：not-found 幂等返回、共享池“让位”（保留池与 p2p 注册，供下代权重零拷贝复用）、真释放（p2p 注销→手动解页→删账本→host_empty_cache）。注册失败按失败点分四种回滚情形，存在重复注销 KeyError 与首次 p2p 注册失败后不再重试两处边缘行为。
