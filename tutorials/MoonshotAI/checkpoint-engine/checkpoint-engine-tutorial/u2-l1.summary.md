本讲剖析 data_types.py，它是 PS 与 worker、Python 与 JSON 之间的通用数据语言。先用 Annotated 配 PlainValidator/PlainSerializer/WithJsonSchema 定制 _TorchDtype、_TorchSize、_TorchTensor 三个类型，使 torch 对象能通过 pydantic 校验并与 JSON 无损往返。核心模型：ParameterMeta（name/dtype/shape/aligned_size 四字段，不含 offset，aligned_size 按 256 字节向上对齐，诞生于 checkpoint 加载）；H2DBucket 配 BucketRange（NamedTuple）描述桶的字节来源区间，按 owner_rank 分组、桶大小为软上限；聚合链 MemoryBuffer→MemoryBufferMetas→MemoryBufferMetaList→DataToGather，all_gather_object 只广播元数据（指针加参数清单，不传张量），返回后裁剪掉 host_ip/device_uuid。设计取舍：跨进程/JSON 边界用 BaseModel，纯进程内用 NamedTuple 或 TypedDict（如 worker 侧 FlattenedTensorMetadata）。两条 JSON 出口：FastAPI 的 /v1/metas 端点与 TypeAdapter 驱动的 metas 文件导出/导入（join 复用模式的基础）。
