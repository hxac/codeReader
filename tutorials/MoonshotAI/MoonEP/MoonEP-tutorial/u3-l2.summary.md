本讲拆解在线规划器的 Phase A：各 rank 把本地 tokens_per_expert（tpe）直方图经对称内存远程写入 rank0 的 TPE 区，rank0 计算 tpe_cumsum（沿源 rank 维前缀和，供 Phase C 用）与 group_tokens（按 e//epn 归并到 home group 粒度），再跑 surplus/deficit 贪心平衡循环：每轮取最过剩群组与缺口最大群组配对，move=-balance[u] 一次填满接收方，产出迁移矩阵 z。核心结论是 z 满足三条不变量：守恒、完美均衡（每 rank 恰收 CAP=S×K，maxvio 归零）、每列至多一个非零；末条意味着每个目的 rank 至多从一个远程 home group 接收 token，直接支撑 NvS=S×K+(token_padding−1)×2×epn 的容量公式。超调（过剩方翻转为接收者）属正常，轮数至多 R−1；平局取小下标的确定性使单 warp GPU 内核与 PyTorch 参考实现逐元素对拍相等。
