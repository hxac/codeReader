本讲承接 u2-l2 的分配-映射模型，解决 shareable 句柄如何跨进程分发的问题。核心结论：POSIX fd 是进程局部的内核引用，编号跨进程无意义、仅限同节点，`_exchange_ipc_fds` 通过 unix datagram socket 的 SCM_RIGHTS 让内核把 fd 复制进每个接收进程，两个 barrier 分别保证「收件箱先就绪后发送」「全员收完才清理」；fabric handle 则是 64 字节不透明字节串，由 NVLink fabric 全局背书、可跨节点，当作普通张量走 all_gather 分发，没有 fd 生命周期问题。模式由环境变量 `MOONEP_MEM_HANDLE_TYPE`（auto/fabric/fd）决定，`_use_fabric_for_group` 用集合通信汇总全组支持性以保证决策整组一致：fabric 强制、auto 任一 rank 不支持即静默回退 fd，探测须真实试分配确认可用。两通道与子集发送者设计被对称内存、组播对象、单 owner 缓冲三个调用点复用。
