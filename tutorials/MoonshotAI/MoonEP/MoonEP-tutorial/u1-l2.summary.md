本讲解决 MoonEP 构建、安装与运行测试的工程问题，核心结论：代码分两层——Python 内核层(moonep/,以 CuTe DSL 编写、运行时 JIT 编译)与 C++ 扩展 moonep._C(由 csrc/ 预编译，封装 VMM 对称内存、fabric 句柄、NVSwitch 组播等 CUDA 驱动 API,补足纯 Python 做不到的部分)。setup.py 是唯一构建入口，可编辑安装与就地构建均产出 moonep/_C.so;bindings.cu 是 pybind11 绑定层，导出符号仅由 buffer.py 消费。测试必须由 torchrun 启动，conftest 凭 RANK 环境变量判定(缺失则跳过)并按 LOCAL_RANK 绑卡；autouse fixture 在每测后销毁 Buffer,释放进程级 VMM/组播资源。六组内核测试(planning、dispatch、combine、e2e、grad_reduce、prefetch)需多 GPU 且卡间 NVLink 互联。
