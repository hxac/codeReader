本讲为 u4 通信内核单元的地基，精读 _common.py 与 dispatch.py。核心结论：CuTe DSL 内核分三层——@cute.kernel 写设备代码、@cute.jit 做宿主入口、cute.compile 按形特化，const_expr 把 H/S/K/stages 等形状烧成编译期常量，launch 几何构造期定死，运行期只换指针不换几何；_common.py 用 llvm.inline_asm 封装 14 个共享 PTX 助手（原子、带内存序加载、位运算、块拷贝），以 .gpu/.sys 作用域区分卡内与跨 rank 同步；因 DSL 两个 TMA lowering 限制（box 256 元素上限、mbar 状态空间不匹配）须直发 cp.async.bulk，G2S 走 mbarrier 事务计数、S2G 走 bulk_group 编组，且仅 lane 0 单线程发射；grid_sync/cross_warp_sync 由 release 原子加 acquire 自旋拼成自复位屏障并带看门狗；PDL 以前驱先 fence 后放行、后继 use_pdl 启动并等待配对隐藏启动延迟；_get_compiled 用覆盖全部 const_expr 的 lru_cache 键缓存 cubin，stages 依设备 smem 预算自适应。
