本讲建立全系列通用的符号体系并跟踪一次前向的完整数据流。构造参数为 S、K、E、R、B、H、H′；派生量满足 N=S×K（每个 rank 收发恒为此数）、epn=B（默认）=E/R、NvS=S×K+(token_padding−1)×2E/R。NvS 是用户可见的接收槽位，NvS_padded 是 VMM 粒度对齐后的物理行数，用户不可见。_create_context 在构造期一次算定全部尺寸并预分配 hidden_buf 与 meta_buf（一根 int32 缓冲按 16 字节对齐切出多个区段）。数据流方面，dispatch 把 token-major 的 [S,H] 打散成 expert-grouped 的 [NvS,H]，同时产出 cu_seqlens（[E+B] 分段偏移）与通信计划 plan；专家 FFN 原地变换；combine 按 plan 加权归并回 [S,H]。核心结论：静态形状把每专家负载波动从「形状」降为驻留 GPU 的数据，cu_seqlens 全程不回主机，逐层宿主同步与动态分配归零；训练必须取 B=E/R。
