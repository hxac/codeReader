本讲精读 `DispatchEpilogueKernel` 及其宿主封装 `launch_dispatch_epilogue`。去重使同一 token 落到同一目的 rank 时仅传一份 payload（主行），其余重复槽在 dispatch 后留空；epilogue 纯本地地把主行经 smem 扇出到每个重复组的全部重复槽，使 NVL shard 成为完整的 `[NvS, H]` 用户可见布局，本质是用本地显存带宽换 NVLink 带宽。内核为 64 线双 warp 流水线：warp 0 用 G2S（mbarrier 事务计数）暂存主行，warp 1 用 S2G（bulk_group 编组）扇出，stage 延迟 stages−1 批释放以防覆写未读完的 smem。启动几何上 B 自大到小选档以保双缓冲（一 lane 一组头决定 B≤32），组批次 round-robin 分派到恒为 num_sms_dedup 的 grid。核心结论：n_groups 取自 dup_counts[0] 且在设备端读取，配持久化 while 循环实现零宿主同步；epilogue 与 dispatch 同流先后衔接、可选 PDL 加速，自身无跨 rank 通信、不需跨 rank 屏障。关键术语：主行/重复槽、去重三件套（dup_groups/dup_loffs/dup_counts）契约，将由 u4-l5 combine prologue 以「归约回主行」的镜像方式承接。
