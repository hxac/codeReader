本讲为手册收官，聚焦三个最小模块。一是类型注册表 `_ELEM_TYPES`：把 torch.dtype 映射为（CuTe 类型, 字节数），参数化 smem 预算与 TMA 事务计数，使权重通路成为设计好的 dtype 扩展点（新增 fp16 仅改两行）；hidden 与梯度通路硬编码，扩展成本高一个量级。二是 Buffer 生命周期：destroy() 幂等且须在拆除进程组之前执行，顺序为同步通信流、同步设备、集合屏障、按视图先于属主释放引用；旋钮 B（训练须为 E/R）、token_padding、num_sms 分别控制预取容量、显存与内核启动几何。三是构建双轨：AOT 编译的 moonep._C 链接 CUDA 驱动 API，其 11 个导出符号即新设备最小 C++ 移植面；CuTe DSL 走 JIT 并按 dtype 缓存 cubin；新设备移植还需替换 PTX inline asm 助手与 torch.cuda 假设，仓库无后端抽象，Zhenwu PPU 支持仅为 README 承诺（待确认）。
