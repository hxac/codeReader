本讲绘制 MoonEP 全仓库代码地图。仓库分三层——Python 内核层（moonep/，CuTe DSL 内核、首次调用时 JIT）、C++ 绑定层（csrc/ 编译为 moonep._C）、验证层（tests/ 对拍测试与 benchmarks/ 基准）；公共 API 仅 Buffer 与 MoonEPCommPlan。moonep/ 的十三个文件分五组：门面（`__init__`/api）、内存基础设施 buffer（对称内存，`_C` 的唯一消费者）、共享工具（`_common` 的 PTX 原语、constants 的位宽常量）、规划器 planning、七个通信内核（dispatch、dispatch_epilogue、combine、combine_prologue、prefetch、grad_reduce、inter_rank_sync），每个内核以 `launch_*` 为对外入口。用 ast 构建 import 邻接表验证：api.py 出度 10，是唯一汇聚点；Buffer.dispatch 按可选同步→规划→派发→epilogue 编排，combine 为镜像流程。测试方法论引入 KernelCase 参数化与 assert_all_ranks 全体报错；基准直接计时 `launch_*` 拆分算子成本。这张依赖图即后续讲义的文件索引与改动影响半径表。
