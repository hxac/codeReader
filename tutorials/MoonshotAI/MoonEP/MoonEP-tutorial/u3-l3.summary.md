本讲义精读规划内核的 Phase B 与 Phase C 两个模块。Phase B 把 Phase A 产出的群组级迁移矩阵 z[h,d] 贪心展开为专家级分配 alloc[e,d]：初始 token 全留 home，单 warp 寄存器化循环以“最大配额 rank ↔ 最热本地专家”配对，take 取剩余与配额的较小值，同一专家的 token 可被拆分到 home 与远程；再沿目的 rank 维做前缀和得 alloc_cumsum，作为后续 passB 二分定位目的 rank 的查找表。Phase C 先做 top-B 远程专家选择：按 (token 数， 专家号) 降序取 B 个写入 experts_to_copy，平局取大专家号、空槽写 -1，remote_stats 分别记录非零远程专家数与专家被预取次数；再做 padded 段布局：接收缓冲分为 E+B 个段，被预取专家的本名段置空、token 挂到预取槽段，段长向上对齐 token_padding，产出 cu_seqlens、expert_offsets 与 zero_fill_ranges。核心结论是 NvS 容量公式 S·K+(tp-1)·2E/R，其根基为 z 矩阵每列至多一个非零元的不变量。
