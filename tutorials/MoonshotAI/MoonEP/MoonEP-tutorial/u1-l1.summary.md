本讲为 MoonEP 学习手册首讲，仅涉及 README、moonep/__init__.py 与 tests/generate_topk_routing.py 三个文件，目标是建立概念框架。核心结论：MoonEP 是通过动态冗余专家让各 rank token 负载完美均衡的专家并行（EP）通信库，负责 MoE 层 token 的派发（dispatch）与归并（combine）。引入的符号系统：S 为每 rank token 数，K 为 top-k，E 为专家总数且均分到 R 个 rank（每 rank 持 E/R 个 home 专家），B 为权重预取槽数，NvS 为派发槽位，H/H′ 为隐藏/中间维；每 rank 派发 S×K 份拷贝，均衡时每专家期望接收 R·S·K/E 个。路由不均衡用 maxvio=max(Te/T̄)−1 量化，代价是木桶效应、动态形状与显存碎片 OOM；bias_ratio 以对数正态分布控制偏置程度。三大设计环环相扣：在线规划选出热门远程专家复制到本地预取槽，使每 rank 恒接收 S×K 个 token，均衡进而带来静态形状与零拷贝。公共 API 仅导出 Buffer（dispatch/combine/prefetch/reduce_grad 四入口）与不可变规划快照 MoonEPCommPlan（需跨前向反向保存）。
