本讲把 FlashKDA 代码当作可改造对象，主题为消融实验、调参旋钮与 head_dim 扩展影响面。三个编译期消融开关（`BLOCK_LEVEL_K1`/`BLOCK_LEVEL_K2`、`TMA_DISABLE_ALL`）以预处理器宏裁剪 kernel 启动块或 K2 的访存流水线，关闭必须传负值（`#if` 条件为 `>= 0`，传 0 无效）；消融版本是计时骨架而非功能回退，测试预期失败，用基线、去 K1、去 K2、去 TMA 流水线四版本对照做耗时归因。调参重在约束边界：K2 共享内存存在匿名 union 钳制效应，流水线深度从 (3,2) 降到 (2,2) 不省 smem；`fast_math` 与 bit-exact 对拍互为因果。支持 D=64 是全链改造：host 校验、显式实例化表、K1 硬编码线程映射、K2 每 warp 两列块的分工假设、workspace 契约与 torch_ref 参考实现都要手工同步，只有从 shape 推导的量自动适配。CHUNK 与 lower_bound 经指数域不等式（下界 -126）耦合，CHUNK 上限 17，故 16 近乎唯一取值。二次开发标准流程：开分支→改一处→重编译→exact-match 回归→benchmark→记录。
