本讲解读 host 侧 launch_fwd 的启动配置。gmem 布局上，q/k/v/g/out 共用 (H,T,D):(D,D·H,1) 一份布局（形状步长全同、仅基地址不同），beta 拉平一维、state 合并为 (N·H,D,D)，皆为 TMA 寻址与对齐服务。workspace 按 n_ht=H×total_tiles 前缀和切成 k_decayed/q_decayed/k_restored/g_total/INV/Mqk 六段（13824 字节/tile）加尾部 tile_prefix，各段 128 字节对齐；total_tiles 区分分配口径（上界 ⌈T_total/16⌉+N）与启动口径（batched 为精确值）。以 make_tma_copy 编码 22 个 TMA 描述符（TensorMap，按值传入 kernel 参数空间），其中 K1 的六个 STORE 与 K2 的六个 LOAD 同型同源，构成位一致契约；state 描述符按 StateFP32 编译期二选一，无状态时用哑指针。K1 grid=(total_tiles,H)、256 线程、tile×head 全并行，varlen 多余块 early-return；K2 grid=(N,H)、192 线程、序列内 tile 串行递推，其约 98KB 动态 smem 需 cudaFuncSetAttribute opt-in；BLOCK_LEVEL_K1/K2 为编译期消融开关。
