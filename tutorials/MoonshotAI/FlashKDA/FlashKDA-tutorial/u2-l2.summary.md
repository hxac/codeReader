本讲剖析 csrc/flash_kda.cpp 的 pybind 绑定层（模块 flash_kda_C）。get_workspace_size 给出 K1/K2 双 kernel 间传递中间量的 workspace 大小公式：H × tile 数上界 × 每 tile 13824 字节，再加 128 字节对齐的尾部前缀和缓冲；上界取 T_total 除 16 上取整再加 N，加 N 是为吸收 varlen 每条序列至多一个尾 tile；每 tile 13824 字节由三段 16×128 bf16 矩阵、fp32 的 exp(g_total)（乘性整块衰减因子）与两段 16×16 bf16 矩阵构成，static_assert 在编译期固化每段 128 字节对齐，是后续 TMA 按段切分 workspace 的前提。fwd 前半是「先失败先报」的 TORCH_CHECK 校验链，顺序为设备/连续、dtype、状态 dtype、维度形状、D==128、cu_seqlens、状态形状 [N,H,D,D]（N 由 cu_seqlens 定出）；workspace 只查设备与连续、不查大小，由 Python 包装层按同一公式分配保证。校验后三项预处理：token 轴展平为零拷贝 reshape、beta 转置成每 head 连续（唯一真实拷贝，使 1D TMA 免除 T 对齐约束）、gate_scale 预乘 log2(e) 换底令 kernel 全程用 ex2。total_tiles 上界、per_tile_bytes、tile_prefix、state_fp32 等术语由后续讲义承接。
