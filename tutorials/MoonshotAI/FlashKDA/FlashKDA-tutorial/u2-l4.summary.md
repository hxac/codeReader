本讲只讲布局、不讲计算，分三个模块。模块一 CuTe Layout 基础：Layout 是「坐标→偏移」的编译期整数函数，记作 shape:stride，cosize 决定缓冲区字节数；q/k、beta、g_total、L 等朴素缓冲取行主布局，cosize 与 WorkspaceSizes 六段字节数逐项对账吻合。模块二 GMMA atom 与 tile_to_shape：K_INTER/MN_INTER/K_SW32 atom 是 Swizzle∘smem 标记∘线性布局的 ComposedLayout 积木，以比特定义再 upcast；K_INTER 行主无异或（配 LDSM_N），MN_INTER 是同一内存的转置视图（配 LDSM_T），SW32 用于 fp32 状态；tile_to_shape 把 atom 铺满 (16,128)/(16,16)/(128,128)。项目实际用 SM80 HMMA，atom 仅作 TMA 读写与 LDSM 直读共用的规范排布。模块三 TMA smem 布局：普通布局用 prepend 补哑模式，ComposedLayout 须拆 layout_a/offset/layout_b 再 composition 重组（MMALayout→TMAVOLayout）；核心结论是 workspace 位一致契约——K1 store 与 K2 load 用同一 gmem 张量加同一 TMA 布局类型，保证 K1 写下的比特即 K2 读到的比特。
