本讲绘制 FlashKDA 的项目地图：`flash_kda.fwd` 经 Python 包装层（仅分配 workspace）、pybind 入口（输入校验、布局预处理、七分支模板分发）、launch 层（构造 gmem 视图与 TMA 描述符、切分 workspace、两次 kernel 启动）到达两个 CUDA kernel。仓库采用单翻译单元策略，kernel 源码以 `.cuh` 实现头汇入唯一的 `.cu`。核心结论是双 kernel 划分：Kernel 1（prepare）按 (tile, head) 全并行做块内准备，Kernel 2（recurrence）按（序列, head）并行、序列内沿 tile 串行递推，grid 分别为 (total_tiles, H) 与 (N, H)，靠同一 stream 的顺序语义衔接。workspace 是两级流水线的传送带：每 tile 13824 字节，切成 k_decayed、q_decayed、k_restored、g_total、INV、Mqk 六段（varlen 模式另加 tile_prefix 尾部），两个 kernel 按 ws_idx = head·total_tiles + tile 一致寻址。K2 内部是 warp 专用化的生产者—消费者流水线（4 个 MMA、1 个 LOAD、1 个 STORE warp）。
