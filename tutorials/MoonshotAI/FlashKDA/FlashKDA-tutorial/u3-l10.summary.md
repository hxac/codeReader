本讲讲解 FlashKDA 的测量工具链：bench_fwd.py、ncu.sh、generate_benchmark_md.py 及其生成的 BENCHMARK_H20/GB200 报告。核心内容：计时框架 bench_fn 用 cuda.Event 批量记录（轮首同步、连续入队、轮末同步），按 warmup/iters/repeats 三级采样输出 mean/min/max，max(warmup,1) 保证 ncu 传 0 时仍有热身。run_case 按 len(seq_lens)>1 区分 fixed/varlen 两种模式，被测对象共五个：flash_kda 的无状态、bf16、fp32 三种 state 模式，加 FLA 基线 chunk_kda 与 chunk_gated_delta_rule；chunk_kda 的对照配置正是 u3-l11 中 FLA 自动分发所用的参数。口径上 bench 测端到端包装层耗时，ncu 用 -k 正则剖析 K1/K2 两个 kernel（排除前缀和 kernel），两者互补。报告生成器以正则解析 bench 的 stdout（脆弱契约：改 print 即断链），只取 fp32 state 口径渲染对比表。核心结论：varlen 下加速比更高（H20 最高 2.29×），而对 GDN 优势小、个别场景甚至落后。
