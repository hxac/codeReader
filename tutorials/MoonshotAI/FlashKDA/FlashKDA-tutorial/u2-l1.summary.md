本讲精读 torch_ref.py——它是用 PyTorch 书写的 kernel 行为规格：把 KDA 逐 token 递推等价改写为 CHUNK=16 矩阵形式，并以数值工具箱逐操作复刻硬件行为（fp32_fma 单次舍入、ex2+ftz、tanh 近似 sigmoid、蝶形归约顺序、bf16 量化点），支撑 torch.equal 级 bit-exact 测试。引入的关键术语：门控激活与 inclusive cumsum（gc、g_total）；衰减四变体 k_decayed、k_inv、q_decayed、k_restored，凭衰减系数拆分恒等式把时序耦合折进矩阵乘；块内三件套 L（fp32、严格下三角）、Mqk（bf16、保留对角线，对应“先擦后写、写完再读”）、INV=(I+L)⁻¹ 前代换；随后解 U、算输出并更新状态（状态 bf16 存储、fp32 单次舍入更新）。K1 仅向 workspace 写入六个中间量，U、L 不落盘。
