本讲在进入 CUDA 代码前厘清 KDA（Kimi Delta Attention）的数学骨架。线性注意力把记忆压缩为与序列长度无关的状态矩阵 S∈R^{V×K}；KDA 逐 token 递推为：按通道遗忘 S̃=S·diag(e^g)、求差 u=β(v−S̃kᵀ)、写入 S=S̃+ukᵀ、读出 o=qSᵀ。「先擦后写」的 delta 修正使重复 key 的新值能精确替换旧值。关键术语与结论：门控 g 逐通道取值，由 g=lower_bound·σ(e^{A_log}(g_raw+dt_bias)) 激活，恒在 (lower_bound, 0) 内，只遗忘不放大；beta 是 sigmoid 后的写入强度，与 g、beta 均传激活前 logits 的约定一致；q/k 需做 L2 归一化（q 另乘 scale=1/√D，v/g 不归一化），这是替换性质与块内 (I+L) 良态的前提。torch_ref 参考实现把同一递推按 CHUNK=16 打包为矩阵形式（k_decayed/k_inv/k_restored 与 (I+L)^{-1}），状态存 bf16、更新走 fp32，为 u2-l1 的 chunk 算法精读做铺垫。
