本讲义讲解 Kimi-VL-A3B-Thinking-2506 的多图推理实践，覆盖多图理解、Thinking 生成参数、思维链输出口径三个模块。多图输入沿用双通道机制：占位通道（messages）放 N 个图片分片作占位符，像素通道（processor）按同序传 N 个 PIL 对象，两边数量与顺序必须严格一致。Thinking 模型输出 = 思维链（CoT）+ 答案，官方推荐 max_new_tokens=32768，预算不足会截断在推理中途、丢失最终结论；温度口径为 Thinking 0.8（探索型推理）、Instruct 0.2（感知求稳定），temperature 需配合 do_sample=True 才确定生效。输出处理口径：按输入长度裁剪后以 skip_special_tokens=True 解码，思考/答案分界标记需用 False 解码实测，再切分提取答案。2506 版平均思维长度缩短约 20% 而推理精度提升。
