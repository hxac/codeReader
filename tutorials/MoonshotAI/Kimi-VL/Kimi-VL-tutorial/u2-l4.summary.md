本讲是第 2 单元收尾，从「怎么跑」转向「怎么选、怎么配」，含三个模块。变体能力矩阵：Instruct、Thinking-2506 与已废弃的旧版 Thinking 规格完全相同（16B 总参、约 2.8B 激活、128K 上下文），差异全部来自后训练（长思维链 SFT 与 RL）；纯感知、成本敏感选 Instruct，深度推理或混合负载默认 Thinking-2506。采样参数：官方推荐 Instruct 温度 0.2（感知求稳）、Thinking 0.8（推理求活），温度通过缩放 softmax 改变采样分布，仅在 do_sample=True 时生效；两者生成预算 512 与 32768 相差 64 倍。上下文与分辨率规格：128K（131,072 token）是视觉 token、文本与生成输出共享的总预算；2506 单图上限 3.2M 像素（1792×1792，初代 4 倍），MoonViT 原生分辨率使像素数与视觉 token 近似成正比，故分辨率提升须依托长上下文；vLLM 部署层对应 --max-model-len 与 --limit-mm-per-prompt 两个旋钮。
