Kimi-VL 采用三段式架构：MoonViT 视觉编码器 → MLP 投影层 → MoE 语言解码器；图像被切成视觉 token 后嵌入文本序列中的图像占位符处，两条路径在进入解码器前汇合成单条序列。MoonViT 约 400M 参数、原生分辨率设计，按 14×14 patch 切图并展平打包（NaViT 风格 Patch n' Pack），配插值绝对位置嵌入与 2D RoPE，从 SigLIP-SO-400M 初始化；2×2 pixel shuffle 将视觉 token 压至四分之一，上限图约 4096 token。MoE 解码器总参 16B、每 token 仅激活约 2.8B（「A3B」由来）：64 个路由专家选 top-6 加 2 个共享专家常开，首层为稠密层，注意力为 DeepSeek-V3 式 MLA。128K 上下文是预训练末段长上下文激活阶段从 8K 经两次 4 倍扩展所得，RoPE 基础频率从 50,000 重置为 800,000。关键术语：token、patch、稀疏激活、路由器、投影层、rope_theta。
