本讲为收官综合实战，把此前各讲的模型加载、消息构造、Thinking 参数与 vLLM 部署等孤立片段组装成多模态问答应用，链路分输入解析、图像入口、消息组装、推理后端、输出解析五段。核心设计是后端抽象：统一 ask(image_paths, question) 接口，本地 Transformers 与 vLLM 服务各实现一类，上层 CLI 不感知差异。图像输入双通道：本地走 PIL 对象（统一转 RGB），服务走 base64 编码拼 data URL，base64 传输约膨胀 4/3，视觉 token 可按像素÷784 估算。部署形态以并发、生命周期、计量三问选型：本地进程内冷启动分钟级、token 数需张量相减自算；vLLM 常驻服务高吞吐、自带 usage 官方计量。输出解析是双后端汇合点：split_thinking 把 Thinking 原始输出切为思维链与答案；计时公平要求把加载放构造器、仅在 ask 内计时。实践产出双后端 CLI 工具，JSON 输出 thinking、answer、usage 与耗时。关键术语：后端抽象、data URL、usage 统计、冷启动/热服务、split_thinking。
