本讲建立对 Kimi-VL 的整体认知：它是月之暗面开源的 MoE 视觉语言模型，总参数 16B、语言解码器每 token 仅激活约 2.8B（A3B 即“约 3B”），支持 128K 上下文，主打多模态推理、长上下文与 Agent 三大能力；架构由 MoonViT 原生分辨率视觉编码器、MLP 投影层、MoE 语言解码器三件套组成。三个变体 Instruct、Thinking-2506 与已废弃的旧版 Thinking 规格完全相同（16B/3B/128K），差异全部来自后训练，推荐温度 Instruct 为 0.2、Thinking 类为 0.8。仓库形态方面，本仓库是发布型仓库，不含任何 Python 源码，模型实现与权重托管在 HuggingFace，经 trust_remote_code=True 动态加载。引入的关键术语包括：MoE 稀疏激活、激活参数与总参数、原生分辨率编码、后训练（SFT/RL）、trust_remote_code，以及“事实卡→规格表→代码定位”的仓库阅读方法论。
