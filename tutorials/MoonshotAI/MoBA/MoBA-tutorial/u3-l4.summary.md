本讲解析 varlen trick：把稀疏的块选择掩码 gate_mask 重组为 flash-attn varlen 接口可直接消化的张量。核心思想是把「每个 query 对每个选中块」的一次注意力伪装成 varlen 批次里一条独立的单头短序列，头维折叠进批次维。关键产物：moba_q_indices 由掩码 nonzero 得到，行主排序天然形成「块优先、头次之」的分段选中清单；moba_seqlen_q 记录每个（块×头）段收集的 query 数，moba_q 按清单拷贝 Q（允许重复，代价由下讲 LSE 合一补偿）；moba_q_sh_indices 用取模与整除把 (h s) 坐标换算回输出缓冲的 (s h) 展平坐标，是前向合并与反向搬运共用的地址簿；moba_kv 经 rearrange+split+cat 对齐同一（块，头）段序，因候选块全是满块，moba_cu_seqlen_kv 退化为等差数列，Q 侧则需前缀和；零 expert（无 query 选中的段）必须从 Q、KV 两侧同步裁剪，否则反向梯度可能 NaN，两个 assert 分别做防御自检与段数一致性检查。全部张量最终打包传入 MixedAttention.apply，衔接下讲的 LSE 在线合并。
