本讲解读仓库唯一的正确性测试 test_moba_attn.py，采用「黄金参考」策略：以直白的 naive 实现为标准答案，对高效实现做前向输出与反向梯度的双重对齐。generate_data 固定三处种子，用 random.sample 不放回抽样构造无空序列的 cu_seqlen；324 个参数化用例覆盖末块不满，以及 chunk 超过序列长度时退化为纯因果注意力的捷径分支，但未覆盖 GQA 与 topk=1；梯度比较须两路共用上游梯度、快照先 clone 后 zero_ 清零。三层容忍度 allclose、max、mean 分别抓大偏差、局部尖峰（如块选择翻转）与系统性偏差，阈值源于 bf16 机器精度。核心结论：对齐通过即证明两种实现在 gate 选块、varlen 重组、LSE 合并与手写反向上数学等价，同时守护 fp32 gate 打分的 top-k 一致性。
