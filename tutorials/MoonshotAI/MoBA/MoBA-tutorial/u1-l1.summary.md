本讲只精读 README 与配置，不深入源码。核心结论：全量注意力的计算量与显存随序列长度平方增长，flash-attn 只省显存不省计算；window/linear attention 各有偏置或近似代价，MoBA 秉持 less structure 原则，让模型自主决定注意哪里。关键概念：块稀疏注意力——KV 按 moba_chunk_size 分块，query 与块内 K 均值内积得到无参数 gate 分数，据此为每个 query 选 moba_topk 个块，当前块必选、未来块被因果规则排除，计算量占比约为 topk×chunk_size/n；MoBA 需 continue training 而非 drop-in，支持全量/稀疏无缝切换。仓库提供 moba_naive（基于 attention mask 的教学参考，可可视化块选择）与 moba（基于 flash-attn==2.6.3 的生产实现，相对 naive 最高 40 倍），经 register_moba 注册为 transformers 注意力后端。
