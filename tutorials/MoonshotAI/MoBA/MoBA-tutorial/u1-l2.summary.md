本讲解决「让 MoBA 在自己环境里跑起来」，覆盖三个最小模块：安装、配置、后端注册。安装上，`pip install .` 只装 moba 包，flash-attn==2.6.3 被精确锁定，因为高效实现直接调用其内部 API，跨版本易失效。MoBAConfig 是唯一配置对象，仅含 moba_chunk_size 与 moba_topk 两个无默认值字段（分别控制 KV 分块大小与每 query 选块数），进程级全局生效，二者乘积约为每 query 实际参与的 KV 数。register_moba 用 partial 把适配层 moba_layer 分别与高效实现、naive 参考实现及配置预绑定，写入 transformers 的注意力注册表 ALL_ATTENTION_FUNCTIONS，得到 moba 与 moba_naive 两个后端；注册必须先于 from_pretrained，加载时经 attn_implementation 参数选用后端。examples/llama.py 演示注册→加载→贪心生成三步，另可用内置 flash_attention_2 作全量基线；序列短于一个块时高效实现退回普通自注意力兜底，故短提示下各后端输出一致——示例与单测验证的是接线正确，而非稀疏效果（MoBA 需继续训练才能发挥稀疏注意力收益）。
