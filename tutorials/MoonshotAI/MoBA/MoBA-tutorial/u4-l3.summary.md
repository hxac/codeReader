本讲以 tests/test_moba_speedup.py 为载体，讲授 GPU 基准测试方法并量化 MoBA 相对 flash-attn 全量因果注意力的加速比。核心要点：GPU 计时铁律为 warmup 预热、计时前后双端 torch.cuda.synchronize()、用 time.perf_counter 测 wall time，否则异步执行只会测到 kernel launch 时间；被测对象是前向加反向整体，flash 基线与 MoBA 用同一份固定种子 varlen 数据、逐行对称的计时代码。引入关键概念：加速比、稀疏度（每 query 参与约 topk×chunk_size 个 KV）、理论加速上限 ≈ (S/2)/(topk×chunk_size)，以及 gate 打分、filtered_kv/索引重排、LSE 合并等 O(S) 级 glue 开销。核心结论：实测加速比恒低于上限；README 的 40x 是相对 naive 教学实现、对 flash-attn 理论仅约 2.7x；topk 拉满、topk=1 退化分支、chunk 过小、序列过短四类配置下 MoBA 收益消失甚至变慢。
