本讲精读 moba_naive.py 的 moba_attn_varlen_naive 前向，拆为五个最小模块：①每条 varlen 序列按 moba_chunk_size 独立分块（最后一块可不满），以块内 K 均值构造无参数代表向量 key_gate_weight；②在 fp32 中内积得到打分矩阵 gate [H,S,N]，每头独立打分，避免 bf16 精度翻转 top-k 决策；③因果修正：当前块置 +inf 必选（兼防全 -inf 行 NaN）、未来块置 -inf 必不选，top-k 后用 gate_idx_mask（scatter 精确名单）防 -inf 平局多选，得块选择掩码 need_attend；④gate 原地改写为 0/-inf 加性掩码，repeat_interleave 从块级展开到 token 级并叠加 tril 因果；⑤fp32 带掩码 softmax 注意力，结果回写全局输出。核心结论：gate_idx_mask 与 token 级 tril 构成双保险；每个 query 实际注意约 topk×chunk_size 个 key，是 MoBA 加速来源；chunk_size 不小于序列长时退化为全量因果注意力；naive 实现可作为校验高效实现的黄金参考。
