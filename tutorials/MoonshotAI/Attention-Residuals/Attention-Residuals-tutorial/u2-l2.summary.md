本讲精读 README 的 forward 调度伪代码，分四个最小模块：双状态调度、partial_block 部分和、块边界判断、两次 attn_res 位点应用。核心结论：Block AttnRes 用双状态取代单一残差流——blocks 是封存后只读（write-once）的已完成块缓存，partial_block 是当前块内按权重 1 累加的可写部分和，二者靠显式 return 跨层传递（张量重绑定不返回即丢失）。块边界条件为层号整除 block_size//2：block_size 按 ATTN+MLP 子层计数（每层 2 个），商 k 即每块层数；层号 0 起点下第 0 层恰把词嵌入封存为单元素 blocks[0]。部分和来源有两条：非边界层继承上层继续累加，边界层经 None 哨兵由 attn_out 白纸起算。边界判断位于位点 1 之后，旧块封存前被完整读最后一次。每层注意力前/MLP 前两个 attn_res 位点各持独立 proj/norm 参数对（每层约 4d，边际开销），子层读 norm(h)、只写 partial，PreNorm 与 drop-in 结构保留。候选数每 k 层才加一，显存开销由 O(Ld) 降至 O(Nd)。
