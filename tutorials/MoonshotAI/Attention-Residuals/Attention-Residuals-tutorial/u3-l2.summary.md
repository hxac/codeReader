本讲解读 README 的 scaling law 证据，将其拆为两个命题：AttnRes 在所有计算预算下持续占优（曲线整体下移而非小规模优化便利），且 Block AttnRes 匹配 1.25 倍计算基线。围绕三个最小模块展开：一是幂律拟合，L(C)=aC^(-b) 在双对数空间做线性回归，导出等损失计算乘数 M=(a_base/a_att)^(1/b)，读图验算 Block≈1.21×、Full≈1.27×，与 1.25 在读数误差内一致；二是计算量对齐，横轴用训练 FLOPs（C≈6ND）而非墙钟，采用 iso-step 规模阶梯，两臂除残差接线外超参数全同；三是迷你多规模扫描，四档阶梯、配对种子、final val 口径拟合两条幂律并计算乘数区间。核心纪律：M 对斜率 b 指数敏感，须报区间；迷你实验比论文规模（48B/1.4T tokens）小 4～7 个数量级，只复现趋势与方法、不复现数字，「无显著差异」是合法结论。关键术语：计算乘数、等损失计算比、iso-step、PFLOP/s-day、双对数拟合。
