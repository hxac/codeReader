本讲逐行精读 README 伪代码中的 block_attn_res——Block AttnRes 的最小计算单元。输入为 N 份已完成块表示 blocks 与当前块部分和 partial_block，经 torch.stack 沿新增深度维拼成候选张量 V [N+1,B,T,D]。核心是键值分离：打分用 K=RMSNorm(V)（尺度不变，只看方向不看幅度），聚合用原始 V（凸组合保证输出有界）。计算由两次 einsum 完成：伪查询 w_l（直接取 Linear 的 weight，不经输入投影）与 K 逐 token 点积得深度 logits，softmax(0) 沿深度归一化后加权聚合原始 V，输出 [B,T,D]。关键术语：深度维、部分和、伪查询、键值分离、凸组合。结论：权重逐 token 非负且沿深度和为 1；初始化时接近均匀（约 1/(N+1)），选择性由训练习得；proj/norm 以参数注入，供各层注意力前与 MLP 前复用；forward 的块调度逻辑留给 u2-l2。
