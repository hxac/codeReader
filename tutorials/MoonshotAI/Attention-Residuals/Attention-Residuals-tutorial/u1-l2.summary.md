本讲拆解标准残差连接为何会稀释与膨胀。模块一：递推 h_l = h_{l−1} + v_l 展开后即全部子层输出按固定权重 1 的等权求和——权重与输入无关、无任何缩放，词嵌入视作第 0 项。模块二：PreNorm 把 Norm 置于子层入口，残差主干不被归一化，子层输出规模稳定而主干只加不减，幅度随深度按 √l 至线性无界增长；PostNorm 相反，幅度有界但梯度捷径被切断。模块三：膨胀与稀释是同一求和的两面——项数增多使主干范数增大，单层相对占比约 1/√(l+1) 递减，梯度范数也随之跨层不均；实验三联图中 Baseline 印证此象，Block AttnRes 则幅度有界、梯度均匀。关键术语：残差主干、子层输出 v_l、PreNorm/PostNorm、forward hook 逐层范数探针。注意 Block AttnRes 块内仍保留标准残差；解药是以 softmax 权重 α_{i→l} 替换全 1 权重，留待下一讲展开。
