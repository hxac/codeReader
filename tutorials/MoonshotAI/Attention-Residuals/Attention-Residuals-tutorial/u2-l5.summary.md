本讲义在 u2-l4 实验台上验证 README「训练动态」两句主张，最小模块有三：把定性主张译为可证伪命题 M1（幅度有界）与 M2（梯度均匀）；用 PyTorch hook 造可开关的 Probe 探针，同时记录三种深度剖面——P1 层间状态、P2 子层输入、P3 逐层 qkv 参数梯度；分别完成幅度与梯度的测量。训练动态指深度轴上的剖面，与步数轴的损失曲线互补。核心结论：baseline 主干项数随深度线性增长，幅度剖面单调膨胀、增长比 R 远大于 1；Block AttnRes 的 P1 呈周期 k 的锯齿且包络不抬升，P2 因 softmax 凸组合被最大候选范数封顶，有界且与深度无关；梯度均匀性以变异系数 CV 衡量，须同一步、同一固定批配对测量并交叉验证 hook 记录，差异落在噪声内须如实报告。引入的关键术语：深度剖面、M1/M2、增长比 R、变异系数 CV、Probe、P1/P2/P3、锯齿剖面、预注册流程（register_full_backward_hook 因 Block 返回列表而不可靠）。
