本讲给出 AttnRes 核心公式：把标准残差的全 1 累加换成对历史表示的 softmax 加权聚合，权重非负、和为 1（凸组合），故输出幅度被最大候选封顶、与深度无关。权重由伪查询 w_l 产生——每层（注意力与 MLP 前各一处）一个可学习的自由参数向量，不经输入投影；输入依赖来自逐 token 的键侧归一化表示，注意力只作用于深度轴、逐 token 独立。两种变体：Full AttnRes 候选为全部历史，显存 O(Ld)；Block AttnRes 块内保留标准残差累加、块间仅对 N+1 份块级表示打分，显存 O(Nd)，约 8 块即恢复大部分收益，为论文实用形态。主实践用两次 einsum 加 softmax(0) 实现了 full_attn_res 并验证归一性与幅度上界。关键术语：凸组合、伪查询、跨深度注意力、drop-in 替换、块表示与部分和。
