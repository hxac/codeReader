本讲剖析 `examples/toy_train.py` 的 `__main__` 入口与训练主循环，是全脚本最精简的可运行形态。入口按「解析参数→注册日志→装配模型与数据→装配优化器→选设备→建调度器→进循环」七步线性推进；确认 `--wd` 被解析但从未转发给 `get_optimizer`，优化器在模型搬往设备前创建亦安全（状态惰性创建）。核心概念包括：cosine warmup 调度（LambdaLR 改写 param_groups 中的 lr），第 0 步学习率为 0、热身 100 步后达峰、随后余弦退火趋近 0，且日志中 LR 在调度后读取、显示的是下一步的学习率；训练步五连「forward→backward→optimizer.step→scheduler.step→zero_grad」，其中梯度为累加语义，zero_grad 不可省略（注释掉即训练异常），该语义也是梯度累积的基础；`labels=input_ids` 依赖 CausalLM 内部错位 shift 实现下一 token 预测。本讲还搭建了窗口平均 loss 与梯度范数的观测仪表盘，供后续 Muon 与 AdamW 对比实验复用；循环本身省略了梯度裁剪、验证与 checkpoint 等生产级部件。
