本讲转向使用侧，讲解 Moonlight-16B-A3B 推理，分四个模块。其一，官方发布 base 与 Instruct 两个权重：base 只会续写，Instruct 经指令微调按对话作答；16B 为含嵌入的总参数，A3B 为每 token 激活参数。其二，transformers 加载三参数：trust_remote_code 经 auto_map 执行仓库内建模/分词远端代码、torch_dtype 按配置载入 bf16、device_map 由 accelerate 自动切分；显存账为 bf16 权重约 32GB、MLA 压缩的 KV cache 每 token 约 30KB，小卡可退 4-bit 量化。其三，chat template 是 tokenizer_config.json 里的 Jinja 模板，特殊 token 包裹消息，add_generation_prompt=True 追加助手前缀，生成止于 <|im_end|>。其四，与 DeepSeek-V3 同构使 vLLM/SGLang 可直接部署；中间检查点已发布，以 PDF 与 HF 页面为准。
