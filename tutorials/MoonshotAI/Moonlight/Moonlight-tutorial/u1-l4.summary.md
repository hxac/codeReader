本讲解读 toy_train.py 的数据管线：MoonDataset 经别名表加载 openwebtext-100k 语料，用 Qwen2Tokenizer（词表 151936，须与模型 vocab_size 同源）逐篇分词、拼接成一维 token 长流并缓存为 .bin——缓存键只含数据集名，改窗口长度可复用缓存，换分词器则须手动删除。随后按 max_length（默认 512）无重叠切块，样本数为 token 总数对窗长下取整、尾部丢弃，样本会跨越文档边界；DataLoader 以 batch_size 16 组成 [16,512] 的 long 张量。定长分块使批内无需 padding 与 attention mask，各批 loss 可直接平均；且 loader 步数决定 cosine 调度总步数，改窗口会同时改变每步计算量与学习率曲线，对比实验须分开归因。关键术语：BPE 分词、Dataset 协议、拼接再切块范式；综合实践为 512 对 256 对比实验及评估函数 evaluate_lm_loss（训前 loss 约 11.9），供后续优化器对比复用。
