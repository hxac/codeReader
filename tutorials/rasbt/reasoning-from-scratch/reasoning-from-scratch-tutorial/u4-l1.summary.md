本讲为数学评测搭建「数据、模板、模型」三件套。load_math500_test 以本地优先、GitHub 回退的方式加载 MATH-500 数据集：500 道竞赛题、六字段，评测仅消费 problem 与 answer。render_prompt 将角色设定、格式指令、题干与作答起点拼成 zero-shot 提示模板，其 \boxed{ANSWER} 输出契约是下游答案提取的机器可解析锚点。load_model_and_tokenizer 以 which_model 统一加载 base（裸文本分词器）与 reasoning（套聊天模板、开 thinking）两种变体：二者架构相同，差异仅在权重文件与分词器配置。核心结论：提示模板是评测协议变量，只改几个词即可令准确率在 20% 与 70% 之间波动，且同一改动对 base 与 reasoning 方向相反。评测四步链路「渲染→生成→提取→判分」中，本讲交付前两步原料，答案提取与判分由后续讲义承接。
