本讲概览附录 F 的三类评测范式。MMLU 选择题评测给出三种实现：字母匹配（生成后扫描 A/B/C/D，易因不吐字母或词内字母误截而失分）、logprob 评分（一次前向比较四个字母 token 分数，核心是 token 对齐以处理 BPE 边界合并，实践首选）、教师强制（对完整候选答案取平均 logprob，每题四次前向但对推理模型公允）；同一 0.6B 模型三法得分在 21.48%~34.44% 间差异巨大，随机基线约 25% 并带约 2.6% 噪声带。排行榜部分从成对胜负还原排名：Elo 为在线顺序更新、总分守恒、依赖赛序，Bradley-Terry 为全局最大似然拟合、顺序无关、需零锚点，二者经 R=s·400/ln10 互换尺度。LLM-as-judge 由 Ollama 本地运行裁判模型按 rubric 量表打 1~5 分，要点是流式 REST 调用与 parse_score 正则解析陷阱。
