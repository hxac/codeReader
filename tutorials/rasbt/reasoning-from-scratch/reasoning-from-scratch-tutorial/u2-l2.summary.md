本讲拆解 Qwen3 TransformerBlock 的两个基础组件。RMSNorm 是 LayerNorm 的简化版：不减均值、无偏移参数，仅除以均方根再乘可学习缩放 scale，eps 加在方差上防除零；qwen3_compatible 开关先升 fp32 计算再转回原 dtype，不改变输出精度类型，只保证中间计算与官方实现数值对齐。它用于每层 norm1/norm2、模型级 final_norm，以及 GQA 的 q_norm/k_norm（QK-Norm，下讲详述）。FeedForward 采用 SwiGLU 门控结构 fc3(silu(fc1(x))×fc2(x))：门控支路过 SiLU 激活、内容支路保持线性、fc3 降维，hidden_dim 取 emb_dim 的 3 倍，每层约 9.44M 参数、约占 block 的 60%。两组件均形状守恒，(b, t, d) 进出不变，这是 Pre-Norm 残差相加成立的前提；TransformerBlock 返回 (x, next_cache)，KV 缓存逐层产生、逐层更新。关键术语：RMSNorm、SiLU、SwiGLU、Pre-Norm、形状守恒、QK-Norm。
