本讲完成环境搭建与首次运行。核心结论：项目要求 Python 3.10–3.14、torch ≥2.10 且 <3；pip 路线装的是 PyPI 发布包，uv 路线（作者推荐）装本地工作区并自动管理虚拟环境；硬件上第 2~4 章 CPU 即可，第 5~6 章建议 GPU。主角脚本 generate_simple.py 展示最小推理流水线：get_device() 按 CUDA→MPS→XPU→CPU 优先级自动探测设备，--reasoning 开关在 base 与 reasoning 两套权重及分词器配置间切换，加载 .pth 权重后逐 token 流式贪心生成（KV 缓存加速），并报告耗时与 tokens/sec 吞吐。由此引入关键术语：虚拟环境、token 与 tokenizer、权重文件、base/reasoning 变体、贪心解码、KV 缓存。排查原则：下载失败先用浏览器核对 URL；SSL/代理错误属环境问题而非代码问题；torch.compile 非必需可跳过。
