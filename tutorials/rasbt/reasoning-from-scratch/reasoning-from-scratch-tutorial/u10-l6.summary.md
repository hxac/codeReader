本讲用 Chainlit 把 from-scratch 模型包装成流式 Web 聊天应用。模块一：应用骨架——on_chat_start/on_message 双回调驱动、模型模块级一次性加载全会话共享、CHECKPOINT_PATH 环境变量挂自定义权重、EOS 双 token 监控。模块二：单轮流水线——编码、发空消息占位、逐 token stream_token 推送、update 定稿，底层是贪心流式生成器。模块三：多轮记忆——role/content 历史存 user_session，每轮手工拼 Qwen 聊天模板全量重编码并把回复写回历史，跨轮不复用 KV 缓存；存在默认编码二次包装模板的隐患。模块四：上下文裁剪——硬约束 L+N-1≤C（末 token 免前向），trim_input_tensor 左截断至 keep_len=max(1,C-(N-1))，默认配置 prompt 预算恰为 2049。测试借 ast 只提取辅助函数避免加载权重。
