本讲将自回归生成拆为 prefill（整段预填 prompt，同时把全部位置的 K/V 写入缓存）与 decode（每步仅送 1 个新 token）两阶段。核心模块与结论：KVCache 是"每层一个槽位"的纯列表容器，存 GQA 返回的 (keys, values) 元组；模型级位置游标 current_pos 生命周期为初始化 0 → 读作 pos_start → 前向成功后更新为 pos_end → reset_kv_cache() 归零，且必须与新建 cache 成对使用。有 cache 时掩码切片的含义是"新 token 只被禁止看到严格晚于它的位置"：prefill 还原为严格上三角 (T, T)，decode 得到全 False 的宽行并升维向 batch 与头广播；pos_end 超过 context_length 抛 ValueError，越界检查先于一切状态修改，被拒调用不污染游标与缓存。GQA 沿 token 维（dim=2）torch.cat 增量拼接新旧 K/V，且发生在 repeat_interleave 之前，故缓存存的是压缩版 K/V；RoPE 以 offset=start_pos 按绝对位置旋转新 token，与缓存中已旋转的旧 K 同坐标系；缓存路径与整段无 cache 前向的 logits 完全一致。
