本讲是单元二的最后一讲，讲解 qwen3.py 中的 Qwen3Tokenizer：底层分词委托给 HF 库，自己只管三件事。一是特殊 token 表与分割正则：_SPECIALS 收录 13 个保留 token，_SPLIT_RE 按「形状」把文本切成特殊/普通交替片段，特殊片段查表取 id，其余走 BPE。二是 eos 决策：按文件名推断，名字含 base 且不含 reasoning 则用 <|endoftext|>，否则用 <|im_end|>，pad 恒为 <|endoftext|>。三是聊天模板：apply_chat_template、chat_wrapped、add_generation_prompt、add_thinking 四个开关组合出四种形态——裸文本、仅用户消息块、生成提示加模型自写 <think>、预填空 <think> 块（跳过思考直接作答）。decode 保留特殊 token，供后续章节做答案提取；eos_token_id 将由单元三生成循环消费以提前停止。
