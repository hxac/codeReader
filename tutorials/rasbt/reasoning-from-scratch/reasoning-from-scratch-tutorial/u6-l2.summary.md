本讲引入启发式打分器 `heuristic_score` 与推理时扩展方法 Best-of-N。`heuristic_score` 是不需要模型的纯 Python 函数：三档互斥加分（含 `\boxed{}` 加 2.0、可提取数字加 1.0、全文兜底 0 分），再加按字符数指数衰减的简洁奖励 1.5e^(-|a|/500)；分档复用 `extract_final_candidate` 的三种 fallback 行为，靠占位参数 `prompt` 对齐统一的可插拔 `score_fn` 接口，属于不看标准答案的奖励塑形（判分与选择分离）。档间 1.0 分差可被简洁奖励跨越（约 556 字符阈值），加大 `boxed_bonus` 可锁死档序。`best_of_n_math500.py` 对每个样本的完整生成文本打分，以严格大于更新最优，且不能提前停止采样。MATH-500 实测（n=3）：Best-of-N 配 heuristic 得 40.6%，低于纯投票的 43.2%，换 `avg_logprob_answer` 追平投票；混合方案（投票为主，打分仅在平票时按组内最高分裁决）配 logprob 达 44.8% 最佳——Best-of-N 的上限由打分器质量决定。`heuristic_score` 将被下一讲的自我精炼循环直接用作 `score_fn`。
