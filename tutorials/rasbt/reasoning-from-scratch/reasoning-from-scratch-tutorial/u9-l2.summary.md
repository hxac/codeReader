本讲义实现硬蒸馏路线的数据管线，把教师模型生成的 JSON 转成可直接喂损失函数的训练样本。核心模块：load_distill_data 以「本地缓存优先、HF 主源加 Backblaze 备源」加载四个分区的蒸馏数据（两教师 × math-train/math500）；format_distilled_answer 把教师的双流输出（message_thinking 与 message_content）包装成 `<think>…</think>` 加空行接正文的单一监督目标；build_examples 三步走：prompt 经聊天模板编码、answer 裸编码（chat_wrapped=False）、末尾拼 eos，坏行逐条跳过计数，每条样本只存 token_ids 与 prompt_len 两键；compute_length 与 filter_examples_by_max_len 做长度体检并按总长不超过阈值过滤，2048 阈值删约 44% 样本。核心结论：硬蒸馏即把教师文本当标准答案做 SFT，一次编码、多 epoch 复用；prompt_len 是下一讲损失只对答案区（含 eos）计算交叉熵的切片锚点。
