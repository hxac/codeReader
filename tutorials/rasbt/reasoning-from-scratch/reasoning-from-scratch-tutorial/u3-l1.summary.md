本讲精读 ch02.py：get_device 按 CUDA→MPS→XPU→CPU 优先级探测设备并返回 torch.device，仅 CUDA 分支开启 TF32 加速。generate_text_basic 是最朴素的贪心解码自回归循环：整段前向、取末位 logits、argmax 选 token、拼接、切掉 prompt 只返回生成部分，输出确定可复现。eos_token_id 提前停止把 max_new_tokens 从「必须」变为「最多」，检查放在拼接之前，故 EOS（base 模型为 <|endoftext|>，id 151643）不入输出。核心结论：无 KV cache 时总前向量为 LN+N(N-1)/2，生成量翻倍、耗时超翻倍，这正是引入 KV cache 的动机。关键术语：设备探测、TF32、自回归、贪心解码、argmax、EOS 提前停止，以及共享同一循环骨架的四代生成函数族（basic/cache/stream/stream_cache），为下一讲流式生成与 KV cache 版铺垫。
