本讲拆解 Qwen3 的 GQA 注意力：16 个 query 头两两分组、共享 8 个 KV 组（MHA 与 MQA 的折中），K/V 投影与每 token 的 KV cache 减半、计算量几乎不变，且缓存保存的是 repeat_interleave 展开前的压缩版。前向链路为投影→view+transpose 分头成 (b,H,t,dh)→逐头 QK-Norm（RoPE 前的 RMSNorm，稳定注意力分数）→K/V 沿头维展开对齐 Q→分数除以 √d_h 并做 masked_fill 因果掩码后 softmax 加权 V→out_proj 投回原宽，形状守恒以支持残差相加。RoPE 与 KV cache 生命周期留待下两讲。
