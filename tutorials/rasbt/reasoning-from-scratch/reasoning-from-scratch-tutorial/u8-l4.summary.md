本讲是「GRPO 改进」系列第三讲，首次改造奖励端：把单一正确性奖励扩展为线性组合「正确性分 + w×格式分」（w 即 format_reward_weight，默认 1.0），优势在组合奖励上做组内标准化。新函数 reward_format 在 token id 层面检测生成段中 `<think>` 是否先于 `</think>` 出现，任一标签缺失记 0 分。提示工程路线实测更差被弃用，最终改训预训练已会写 think 标签的 reasoning 变体模型，格式奖励只需筛选强化该既有行为。核心结论：权重过大触发奖励黑客——「答错但格式好」的 rollout 总分超过组均值而获正优势、被策略强化；真实日志中 w=1.0 已使格式合规率钉在 1.0、eval 反跌至 9.4%，对策为降权至 0.1 或 conditional_reward 门控（格式分乘以正确性分）。格式奖励兼任防优势坍缩的稳定器、可缓解 KL 崩溃，并新增 format_reward_avg 监控指标；7_6 脚本是 clip、KL（默认关闭）与格式奖励的叠加。
