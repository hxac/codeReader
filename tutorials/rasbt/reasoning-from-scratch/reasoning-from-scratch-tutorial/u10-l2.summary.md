本讲精读 qwen3_batched.py，主题为批量推理与吞吐优化。核心结论：批处理提升吞吐而非降低单条延迟，代价是显存上涨，弱设备上可能反而变慢。关键概念：左填充（pad 居行首、真实 token 靠右对齐，生成永远发生在右端）；attn_mask 填充掩码与因果掩码取或合并，pad 查询嵌入置零使缓存条目为无害零向量；apply_rope_with_pos_ids 提供按行位置编码接口，因 RoPE 相对性（注意力分数只依赖位置差），各行共享列号即与单条生成数学等价；float32_upcast 默认开启，手写 padding 稳定 softmax 消除全掩码行 NaN 并抑制 bf16 近并列翻转；generate_text_basic_batched_cache_stop 用双坐标系（全批输出坐标与幸存者计算坐标）实现逐行提前停止，shrink_kv_cache_inplace 沿批维收缩 KV 缓存，两版输出 token 级一致。基准显示 H100 批量评测约 5.6× 加速，收益取决于生成占比与批内长度齐整度。
