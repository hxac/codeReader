本讲是全书地图课，不涉及模型运行。仓库为《Build a Reasoning Model (From Scratch)》配套代码：在预训练 Qwen3 0.6B 基座模型上，以推理时扩展（第4~5章，不改权重）、强化学习 RLVR/GRPO（第6~7章）、蒸馏（第8章）三条路线从零构建推理模型。仓库三线组织：chXX 章节文件夹是教学 notebook，每章入口为 chXX_main.ipynb，第1章无代码；reasoning_from_scratch 包沉淀可复用实现，一章对一模块，qwen3.py（模型+分词器+权重加载）是全书公共地基；tests 提供 pytest 回归。pyproject.toml 要求 Python ≥3.10，依赖 torch、sympy 等，包版本号 0.2.0 动态取自 `__init__.py`。本讲引入基座模型与推理模型、思维链、推理时扩展、RLVR/GRPO、蒸馏等关键术语，供后续讲义承接。
