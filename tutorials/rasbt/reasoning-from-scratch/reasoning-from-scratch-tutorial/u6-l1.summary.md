本讲把生成模型改造成打分器：给定文本，反问模型它的概率有多大（序列似然打分）。核心机制是 teacher forcing——因果掩码保证整段已知文本一次前向即得各位置的合法分布，再用错位配对索引抽出每个真实 next token 的分数（与 torch.gather 等价）。三个函数层层递进：概率版连乘联合概率易下溢；log 版改用 log_softmax，化乘为加且数值稳定；avg_logprob_answer 只对答案区间打分（起点为 prompt 长度减一）并对逐 token 分数取均值，消除求和版天然惩罚长答案的长度偏差，但代价是丢失长度与完整性信息——它度量的是流畅置信度而非正确性。该分数可包装为可插拔的 score_fn，与 heuristic_score 互换，充当后续自我精炼循环的裁判。
