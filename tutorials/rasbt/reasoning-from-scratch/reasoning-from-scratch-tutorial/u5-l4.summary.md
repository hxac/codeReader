本讲讲解自一致性投票：不改权重，对同一问题多次温度采样，提取短答案后用 Counter 多数投票取众数，即「采样→提取→计票」三阶段流水线。理论前提是单链正确率 p>0.5，否则投票会放大错误；实验上 base 模型配 CoT 从 33.4%（单次采样）升至 52.0%（n=10），耗时随 n 近似线性增长。关键术语：可插拔生成引擎适配器 generate_text_stream_concat_flex（generate_func 注入、参数透传）；平票时 final_answer=None 并返回 counts/groups/majority_winners（统计与裁决分离，兜底交给调用者）；early stop 在票数严格大于 n/2 时停止采样；batched 版把同 prompt 的 n 个采样并成一个 batch，吞吐换显存、无需 padding、不能提前停止。与 Best-of-N 的区别：众数共识择优而非打分择优。
