本讲承接多数投票集成（u7-l1），讲解以数据制造多样性的 bagging 与 boosting 两族。bagging 用有放回的 bootstrap 采样造出多份数据副本，并行训练同配方的不剪枝深树再聚合，主要降低方差；每轮约 36.8% 未抽中样本构成袋外（OOB）集，可免费估计泛化误差。AdaBoost 是串行样本重加权：SAMME 公式由加权错误率 ε 确定学习器话语权 α，分错样本权重升、分对降，用深度 1 的树桩等弱学习器逐步压低偏差。梯度提升让新树拟合损失函数的负梯度（残差为特例），小学习率需配大轮数；XGBClassifier 兼容 sklearn 接口、可进 Pipeline，但要求标签从 0 编码。Wine 二分类上深单树测试准确率 0.833，三种集成均达 0.917：集成改善的是方差还是偏差，取决于基学习器本身的偏差-方差结构。
