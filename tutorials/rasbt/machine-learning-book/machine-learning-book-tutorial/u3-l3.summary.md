本讲为第3章收官，讲解决策树、KNN与不纯度指标。熵、基尼不纯度、分类误差均在p=0.5处最大、端点为0；基尼与熵形状相近且计算更快（sklearn默认），分类误差为折线、对概率变化不敏感，宜剪枝不宜用于生长。决策树按信息增益（父节点不纯度减去按样本量加权的子节点不纯度）选特征与阈值递归切分，决策边界由平行坐标轴的线段拼成；max_depth预剪枝抑制过拟合，tree.plot_tree可视化树。KNN是惰性学习：fit只存数据，预测时取k近邻投票，参数有n_neighbors与p（Minkowski距离：1为曼哈顿、2为欧氏）。核心结论：基于距离的KNN必须标准化特征，基于阈值的决策树不需要；维数灾难使KNN在高维失效；树深度与k同调偏差-方差权衡。
