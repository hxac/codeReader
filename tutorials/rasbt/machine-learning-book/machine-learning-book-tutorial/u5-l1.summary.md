本讲以 wine 数据集（13 特征）为例讲解 PCA：一种无监督线性降维，只用特征 X、不用标签 y，以「投影方差最大」为准则构造新坐标轴。五步流程：标准化→求协方差矩阵→特征分解→按特征值降序取前 k 个特征向量拼成投影矩阵 W→投影得 XW。核心结论：标准化是前提，否则量纲悬殊的特征会独占第一主成分；均值、标准差与主成分方向只能在训练集估计，测试集只做 transform，防数据泄漏；特征值即各主成分的方差，特征向量单位正交，实对称协方差矩阵宜用 eigh 分解；选 k 靠方差解释率 explained_variance_ratio_ 的累计方差图（wine 前两个主成分约占 55% 方差）；手写与 sklearn 结果可能整体差一个正负号，属正常现象。引入术语：主成分、方差解释率、累计方差图、载荷、投影矩阵，衔接下一讲 LDA（监督降维）与核 PCA。
