本讲基于仓库 ch14 真实代码讲解两个手写 CNN：MNIST 数字分类与 CelebA 微笑二分类，并澄清大纲中的 CIFAR-10、resnet18 微调与 Top-5 实验在仓库中不存在，仅作概念讲解。模块一：图像输入管线——torchvision datasets 配 transforms.Compose 与 DataLoader 堆批，用 Subset 切分验证集；训练集用随机裁剪翻转做数据增强，验证测试用确定性变换；ToTensor 是除以 255 的区间缩放而非 z-score 标准化。模块二：CNN 结构——卷积块堆叠加分类头，MNIST 用 Flatten 双全连接（展平 3136 维由卷积输出尺寸公式手推），CelebA 用全局平均池化加单全连接。模块三：train 双阶段循环——model.train() 走五步训练，model.eval() 加 torch.no_grad() 只前向统计，dropout 随模式切换；多分类 logits 配 CrossEntropyLoss，二分类 sigmoid 配 BCELoss。残差连接与 Top-1/Top-5 错误率为概念储备，供 u14-l3 迁移学习承接。
