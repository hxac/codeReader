本讲把全连接 GAN 升级为 DCGAN 并改用 WGAN-GP 训练。判别器用 stride=2 卷积做学习式下采样（替代池化），生成器用 ConvTranspose2d 反卷积上采样，二者参数严格倒排、尺寸链互为镜像；噪声取 (B,z,1,1) 形状使生成器自首层起纯卷积，末端 Tanh 对齐数据的 [-1,1] 值域。理论引入 EM 距离（分布不相交时 JS 散度梯度为零）、critic（输出分数而非概率）与 1-Lipschitz 约束：原始 WGAN 的权重截断是硬约束，容量浪费且梯度病态，仓库未实现；WGAN-GP 改为在真假连线插值点惩罚梯度范数偏离 1，属软约束。WGAN 训练循环与 BCE 版的三处差别：损失为均值差加梯度惩罚（λ=10）、每批先训 critic 5 次、BatchNorm 换 InstanceNorm。
