本讲为 RNN 单元首讲，锚定 ch15_part1.py：用 torch.matmul 手算隐状态递推 h_t=tanh(W_xh·x_t+W_hh·h_{t-1}+b_h)，结果与 nn.RNN 输出逐步一致。核心结论：RNN 权重沿时间共享、隐状态充当记忆，解决前馈网络输入维度固定、无记忆、参数不共享三大硬伤。关键术语：时间步、隐状态、双偏置（bias_ih 与 bias_hh 手算须都加）、h_0 置零初始化；nn.RNN 每步输出即隐状态本身，无任务输出层，实际任务需另接全连接层。tanh 提供非线性并把记忆压入 (-1,1)，其导数饱和导致长程梯度消失，是下一讲 LSTM 的直接动机。另梳理五种序列架构（一对一、一对多、多对一、异步/同步多对多，情感分类属多对一、字符级语言模型属同步多对多）与 batch_first=True 下的 (batch, seq_len, feature) 维度约定。
