本讲介绍 rasbt/machine-learning-book 仓库，即《Machine Learning with PyTorch and Scikit-Learn》一书的官方配套代码库，为后续全部讲义建立导航基础。核心结论有三：其一，根 README 的 19 章目录表是全仓库地图，主题脉络为经典机器学习（ch02–ch10，感知机、分类器、预处理、降维、评估、集成、文本、回归、聚类）→ numpy 手写神经网络与 PyTorch（ch11–ch13）→ 深度学习前沿（ch14–ch19，CNN、RNN、Transformer、GAN、GNN、强化学习）。其二，各章代码以 .ipynb 与 .py 双文件等价存在：.py 由 notebook 经自动转换脚本生成，markdown 单元格变为 # 注释；故读码与引用行号优先用 .py，交互实验用 .ipynb；例外形态包括 ch01 无脚本、ch12 起拆分多 part、ch16 用连字符命名、ch19 代码在子目录。其三，ERRATA 目录按章维护勘误并附 issue/PR 来源，多数错误已修入代码，书与代码不一致时以代码为准。引入的关键术语：代码仓库、Jupyter notebook、Python 脚本、勘误、永久链接。
