本讲解读 ch02.py 中的 AdalineGD（自适应线性神经元）。它与感知机的本质区别是：训练时用恒等激活函数保持输出连续，以均方误差（MSE）为光滑可导的凸代价函数，把「比较」从阶跃之后挪到之前，阶跃仅在 predict 中以阈值 0.5 使用。fit 实现整批梯度下降：每轮用全部样本计算一次梯度并更新一次权重，核心更新式为 w←w+η·(2/n)·Xᵀe，每轮代价记入 losses_；向量化更新与逐权重循环数学等价且更快。学习率实验表明：η=0.1 在未标准化数据上发散（代价按数量级增长），η=0.0001 收敛过慢，η 是梯度下降最敏感的超参数；收敛条件为 0<η<2/λmax，特征未缩放导致各方向曲率差异巨大，由此引出下一讲的特征标准化与 AdalineSGD。
