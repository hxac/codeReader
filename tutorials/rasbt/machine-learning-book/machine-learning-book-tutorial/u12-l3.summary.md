本讲把第 11 章手推的反向传播交给 PyTorch：前向计算自动构建计算图，`loss.backward()` 沿图按链式法则把梯度累加进每个 `requires_grad=True` 叶子张量的 `.grad`，由于梯度是累加语义，每批更新后必须 `optimizer.zero_grad()` 清零；「前向、算损失、backward、step、zero_grad」五步训练循环是贯穿全书的通用骨架。网络可用 `nn.Linear`（权重形状 `(out, in)`）、`nn.Sequential` 或自定义 `nn.Module` 子类三种方式搭建。激活函数分两岗：隐藏层提供非线性（现代默认 ReLU）；输出层按任务匹配——二分类用 sigmoid（配 BCELoss），多分类必须用 softmax（配交叉熵），因为对多个输出单元各自套 sigmoid 得到的值相互独立、加和不为 1，不构成概率分布；logits 指输出层未归一化的原始输出。模型保存分整个模型对象与 `state_dict`（官方推荐，需先搭同结构再 `load_state_dict`）两种，加载后应 `eval()`。综合实践扫描 XOR 网络隐藏宽度 1/2/4/8 并画柱状图，验证 XOR 至少需要 2 个隐藏单元。
