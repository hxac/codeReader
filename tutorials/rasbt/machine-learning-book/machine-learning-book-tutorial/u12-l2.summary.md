本讲介绍 PyTorch 输入管线的两大组件：Dataset 与 DataLoader。核心是 Dataset 契约——只需实现 `__len__`（报样本数）与 `__getitem__`（按下标返回单样本元组）即可被 DataLoader 接受（duck typing），`TensorDataset` 是将特征与标签张量按下标绑定的官方实现，与手写 JointDataset 等价。DataLoader 在其上自动新增 batch 维、把元组各位置分别堆叠成批；batch_size、shuffle、drop_last 分别控制批大小、每 epoch 洗牌与尾批去留，批数为 N/B 向上或向下取整；同一加载器可跨 epoch 反复迭代且 x、y 配对不散，按类排序的数据必须洗牌否则梯度震荡。磁盘数据集只存路径与标签，`__getitem__` 被调用时才惰性读图，经 transforms（ToTensor 转 [0,1] 的 CHW 张量、Resize 统一尺寸）方能堆批；`torchvision.datasets` 的 CelebA、MNIST 与手写 ImageDataset 遵守同一协议。
