本讲介绍 out-of-core（核外）流式学习：数据不全装入内存，内存峰值只由批大小决定、不随数据总量增长。核心三件套：stream_docs 生成器用 yield 把 CSV 逐条惰性读出（一次性迭代器，依赖「每行文本,标签」格式）；get_minibatch 切出 1000 条小批量，流枯竭时经 StopIteration 返回 (None, None) 哨兵；HashingVectorizer 用哈希技巧把词映射到 2**21 维固定下标，无词表、无状态、免 fit，代价是哈希冲突且下标不可逆；SGDClassifier(loss='log') 用 partial_fit 逐批增量更新（fit 则清空重来），首次调用必须传 classes 钉死标签空间。45 批×1000 条训练后在 5000 条测试批上准确率约 0.868，比全量 TF-IDF 加网格搜索的 0.899 低约 3 个百分点，以少量精度换内存可扩展性。另须注意：CSV 落盘前必须打乱行序，否则类别块状排列会使在线训练近乎失败。
