本讲主题是特征选择：样本有限时特征过多会加剧过拟合与维数灾难，需从 wine 数据集的 13 个特征中挑出小子集，方法分过滤式、包裹式、嵌入式三流派。核心一是手写 SBS 类（序列后向选择，包裹式代表）：从全集每轮贪心删掉一个使内部验证分最高的特征（内部再切验证集以防数据泄漏），13 降到 1 共调用 91 次 fit，subsets_、scores_、indices_ 记录搜索轨迹。KNN 驱动下选出 3 特征子集，外层测试准确率 0.9259，仅比全特征 0.9630 略低，内部验证分有选择性乐观偏差。核心二是随机森林 feature_importances_（嵌入式代表，基于平均不纯度减少）：一次训练即得全部特征排序且无需标准化，SelectFromModel 可按阈值筛选。两种排序部分重合、部分冲突，源于评估器差异与相关特征分摊重要性——特征重要性是相对特定模型的概念。
