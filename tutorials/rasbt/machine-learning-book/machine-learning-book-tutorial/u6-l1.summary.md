本讲以乳腺癌数据集（二分类、30 特征，分层划分后测试集锁定）讲模型评估工作流。Pipeline 把预处理与模型绑成一个估计器，令交叉验证每折自动重拟合缩放器，从机制上杜绝数据泄漏。分层 K 折（StratifiedKFold 与 cross_val_score 对分类器等价）保证各折类别比例与整体一致，以均值±标准差汇报性能，n_jobs 可并行各折。学习曲线（横轴为样本数）依偏差—方差分解诊断：两线齐低且汇合为高偏差（欠拟合），训练高、验证低、间隙大为高方差（过拟合）；本管线呈轻微过拟合。验证曲线（横轴为超参数、对数轴）用「步骤名__参数名」双下划线命名扫描单个超参数，逻辑回归的 C≈0.1 为甜蜜点。调参与曲线只在训练集上进行，最终性能以锁定的测试集评估。
