本讲承接 u11-l1 的前向传播，讲解两层 MLP（MNIST 手写数字，隐藏层 50 单元）如何学习，覆盖五个模块：minibatch_generator 打乱下标、切批、惰性产出，每 epoch 重新洗牌（55000 样本、batch=100 即每轮 550 批）；mse_loss 可导、是反向传播的求导对象，accuracy 仅做评估；compute_mse_and_acc 复用切批器分批前向、一次同时算损失与准确率；backward 按链式法则以矩阵运算推出输出层与隐藏层的权重、偏置共四组梯度，关键在于 delta 误差信号的逐层复用；train 把各零件组装成逐批「前向→反向→参数减学习率乘梯度」的 mini-batch SGD 循环。引入 epoch、iteration、minibatch、delta 等术语。核心结论：未训练模型基线 MSE 约 0.25、准确率约 10%；训练 50 轮后测试准确率约 94%~95%；backward 的损失按样本数 n 而非 n×C 取平均，相差常数倍由学习率吸收；中心差分数值梯度检验可验证手写梯度。
