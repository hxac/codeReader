本讲基于 ch17_part1.py 从零实现全连接版 MNIST GAN。生成器把 20 维潜在向量映射为 784 维图像，Tanh 输出 [-1,1] 与数据管线 Normalize(0.5,0.5) 对齐；判别器是二分类器，Sigmoid 输出真图概率，隐藏层用 LeakyReLU 并以 Dropout 正则。潜在向量先验可选 uniform 或 normal 两种。对抗训练共用 BCELoss、靠翻转标签实现：训练 D 时真图标 1、假图标 0 两项相加；训练 G 时假图标 1（非饱和技巧），两个独立优化器确保每步只更新一方参数。监控看损失曲线、D 对真假图输出围绕 0.5 拉锯及固定噪声样本逐轮进化。评估用高斯核 MMD 度量真假分布距离，值越小生成分布越贴近真实分布（带宽自适应；仓库实现依赖 GPU 且存在真假图值域不一致瑕疵）。核心结论：GAN 训练依赖 G/D 强度平衡——D 过强致 G 梯度消失，过弱则 G 缺乏精进压力，这为下一讲 DCGAN 与 WGAN-GP 埋下伏笔。
