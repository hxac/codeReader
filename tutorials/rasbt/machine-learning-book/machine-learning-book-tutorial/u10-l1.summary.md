本讲从监督学习转入无监督聚类。k-means 以 SSE（畸变）为目标函数，交替执行「样本分配给最近质心、质心移到成员均值」两步循环；KMeans 拟合后以 labels_、cluster_centers_、inertia_ 暴露簇标签、质心坐标与最终 SSE。目标非凸导致对初始化敏感，以 n_init 多次重启取最小 inertia_ 与 k-means++（初始质心互相远离）双管齐下缓解。簇数 k 无标签可交叉验证，改用两个互补工具：肘部法找 inertia_ 随 k 下降曲线的拐点，但肘部可能圆滑难辨；轮廓系数 s=(b−a)/max(a,b) 度量簇内紧凑、簇间分离，需至少 2 个簇，用 silhouette_samples 可画排序堆叠的「刀片图」并配平均虚线目测。合成三团数据（make_blobs）上 k=3 刀片均匀无负值，k=2 暴露两团被并的失败模式。k-means 依赖特征标准化、需预先指定 k、只擅凸形团块，这些局限留待下一讲层次聚类与 DBSCAN 回应。
