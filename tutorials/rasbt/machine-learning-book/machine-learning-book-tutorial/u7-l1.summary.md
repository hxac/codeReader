本讲从零实现多数投票集成。理论部分用二项分布推导集成错误率公式：只要成员错误率低于 0.5 且错误相互独立，投票就能指数压缩误差，反之会放大误差。主体是手写的 MajorityVoteClassifier：以组合模式聚合多个估计器，fit 用 LabelEncoder 将标签编码为从 0 开始、以 clone 训练成员副本；预测分硬投票（类别加权计数取众数）与软投票（概率加权平均）两条路径；get_params 把成员参数展开为「成员名__参数名」，让网格搜索能直接调集成内部超参数。实验以逻辑回归、决策树桩、1 近邻三个异质模型为成员，经 10 折交叉验证与测试集 ROC 曲线对比，集成均值最高、波动最小。核心结论：集成收益来自成员多样性（错误独立）而非成员数量，为下一讲的 bagging/boosting 铺路。
