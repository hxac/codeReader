本讲是 Transformer 单元收官讲，精读仓库脚本 ch16-part3-bert.py，用 DistilBERT 微调 IMDb 影评情感分类。最小模块：数据管线（复用第 8 章已打乱数据，按行切为 35000/5000/10000 三份）；WordPiece 子词分词（分词器必须与预训练权重同名配套，影评截断至 512 子词）；IMDbDataset 返回与模型前向参数对齐的字典，labels 键使模型内部自动计算损失；Trainer 与 TrainingArguments 封装训练，compute_metrics 回调用 np.argmax 解码。核心结论：BERT 是双向编码器，取 [CLS] 表示做分类，序列分类头随机初始化；Trainer 与手写循环双路评估对拍一致（93.27% 与 92.50%），差异属随机波动而非框架优劣。
