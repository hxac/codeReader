本讲精读 ch11/neuralnet.py 中 NeuralNetMLP 的前向传播部分，覆盖四个模块：int_to_onehot 标签编码、权重矩阵形状与初始化、sigmoid 激活函数、forward 前向传播。核心结论：独热（one-hot）编码把整数标签变成每行恰一个 1 的矩阵，使其与网络输出同形、同量纲，MSE 损失才能逐元素计算；参数遵循「行=目标单元、列=来源特征」约定，weight_h 形状为 (num_hidden, num_features)，权重用固定随机种子的小随机数初始化以打破对称性问题，偏置置 0；sigmoid 光滑可导，导数为 a(1−a)，值域 (0,1)，既匹配独热目标又提供非线性，否则多层网络塌缩为线性模型；forward 是两步「线性变换+激活」的堆叠，形状 (n,784)→(n,50)→(n,10)，.T 转置使按单元存行的权重与按样本存行的批量输入维度相消，偏置靠 numpy 广播逐行相加，同时返回 a_h 与 a_out，隐藏层激活 a_h 供反向传播复用。注意 a_out 由 sigmoid 逐单元独立产生，行和不等于 1，预测时用 argmax 取相对最大者。关键术语：one-hot 编码、对称性问题、净输入、激活函数、广播。反向传播与 minibatch 训练循环留给下一讲 u11-l2。
