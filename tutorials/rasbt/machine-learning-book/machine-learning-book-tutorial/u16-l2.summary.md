本讲在「预训练—微调」两阶段范式下，于 IMDb 影评上微调 GPT-2 做情感二分类（仓库未收录 GPT-2 微调代码，零件取自 DistilBERT/BERT 章节组装）。要点：AutoModelForSequenceClassification 加载时主体权重来自预训练 checkpoint、分类头随机初始化，须训练后才能预测，因果模型取最后词元隐状态作整句表示（BERT 取 [CLS]）；requires_grad=False 冻结主体即特征提取，可训练参数从约 1.24 亿降至 1536，小数据集上防过拟合；数据侧以 truncation、padding 与 attention_mask 处理变长文本，compute_accuracy 用 no_grad 加 argmax 累计，凭训练/验证准确率曲线诊断过拟合；AdamW 解耦权重衰减，配 warmup 爬升与线性衰减的学习率调度，调度器每批 step 一次。
