本讲以 PyG（PyTorch Geometric）替代上一讲手写的图卷积、池化与批处理，在 QM9 分子数据集（原子为节点、化学键为边）上做图级回归：预测 19 个物性标签中的各向同性极化率（MSE 损失），而非大纲所称的图级分类。核心概念：Data 对象以类字典张量存整张图；edge_index 稀疏边表与稠密邻接矩阵等价；NNConv 为边条件卷积，由边特征生成逐边变换矩阵，求和聚合、不归一化，GCNConv 为其度归一化变体；PyG 的 DataLoader 自动拼批并生成 batch 向量，global_add_pool 完成全局求和池化；训练沿用五步循环，改图级分类只需多类输出头加交叉熵。
