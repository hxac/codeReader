本讲从零实现卷积运算：手写 conv1d/conv2d 皆为「核翻转→零填充→按步幅滑窗取内积」，输出尺寸由公式 O=⌊(N+2p−M)/s⌋+1 决定（高宽各算一遍）。核心澄清：真卷积需把核旋转 180°，而 nn.Conv2d 等深度学习框架实为不翻转的互相关；核可学习时二者等价，核固定时必须区分。随后引入多通道卷积（权重形状 (C_out, C_in, kH, kW)，各输入通道结果求和为一个特征图）、MaxPool2d（无可学参数）、Dropout，以及特征图、感受野、稀疏连接、参数共享等关键概念。逐层推演 MNIST CNN：28×28→14×14→7×7→展平 3136 维接全连接头，参数效率源自稀疏连接与参数共享。完整训练流程留给下一讲 u14-l2。
