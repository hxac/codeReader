本讲为 PyTorch 张量入门，核心图景是「张量≈ndarray＋设备位置＋自动微分」。覆盖四个模块：①创建与属性：torch.tensor 复制数据、from_numpy 共享内存，张量三大属性为 shape、dtype、device；②类型与形状变换：to() 可换 dtype 或搬设备（跨设备为复制语义、返回新张量可链式），transpose 交换维度、reshape 摊平重排、squeeze 删长度 1 的维度；③运算按结果形状分三类：逐元素乘（广播从末维向前对齐）、mean 等归约沿 axis 压缩、matmul 要求中间维度相消，另有 linalg.norm 求 L2 范数；④切分与拼接：chunk 按块数、split 按块长切开，cat 沿已有维度接长不增维，stack 沿新维度堆叠增一维。核心结论：transpose 与 reshape 可得同形状但元素排布不同；cat 与 stack 之别在于是否新增维度；切分与拼接是下一讲 DataLoader 切 batch 的概念前奏。
