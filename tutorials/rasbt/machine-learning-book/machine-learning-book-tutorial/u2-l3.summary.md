本讲承接上一讲 AdalineGD，主题有二。一是特征标准化（z-score 标准化）：每列特征减均值、除标准差，代价曲面由扁椭圆变近似同心圆，学习率可选范围大幅放宽——未缩放数据上 0.1 即发散，标准化后 0.5 仍平稳收敛；书中手写实现与 scikit-learn 的 StandardScaler 等价，后者 fit_transform 学参数、transform 只变换新数据以防信息泄漏。二是随机梯度下降 AdalineSGD：单样本梯度是整批梯度的无偏噪声估计，fit 采用「按轮-逐样本」双层循环，每轮先洗牌（防按类排序数据造成周期摆动）再逐样本立即更新权重，同轮数下收敛快于整批 GD 但曲线更抖；权重以小随机数初始化、random_state 保证可复现。partial_fit 沿用已有权重、仅首次初始化，实现流式在线学习，与 scikit-learn 同名约定一致。
