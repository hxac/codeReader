本讲以 COVID 胸片二分类为载体讲解迁移学习，覆盖四个模块：CNN 两段式解剖、requires_grad 冻结机制、训练循环复用、Top-1/Top-5 评估。关键概念：分类 CNN 由卷积基座（特征提取器）与全连接分类头构成，ResNet18 的特征维度为 512；迁移学习两步改造法是先冻结基座再替换 fc 头；特征提取适合小数据集，冻结后可训练参数从千万级降至数百；微调则解冻末层并配分组小学习率，防止破坏预训练特征。train() 训练循环与模型解耦，可原样复用。Top-1 严格、Top-5 宽容，k 不能超过类别数，二分类只报 Top-1。核心结论：小数据集上「预训练 + 微调」优于从零训练，因可训练参数骤减、优化起点更优。仓库未收录该节代码，迁移改造部分均为示例代码。
