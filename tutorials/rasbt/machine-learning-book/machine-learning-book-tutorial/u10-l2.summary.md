本讲承接 k-means 需预设簇数、只擅凸形的局限，讲解凝聚式层次聚类与 DBSCAN。pdist 产出浓缩距离矩阵，误把还原后的方阵传给 linkage 是静默错误；linkage 记录逐次合并、画成树状图，按高度剪树即得簇；complete 连接偏好紧凑团块，single 连接有链式效应、可沿细长形状延伸；sklearn 的 AgglomerativeClustering 直接输出标签，点距参数 metric 旧名 affinity。DBSCAN 用 eps 与 min_samples 定义稠密，把点分为核心点、边界点、噪声点（标签 -1），簇为密度相连点的极大集合：无需指定簇数、能分离月牙形非凸簇、自带离群点检测，但对 eps 敏感，调参可查簇数与噪声点数。贯穿结论：各算法形状偏好不同。
