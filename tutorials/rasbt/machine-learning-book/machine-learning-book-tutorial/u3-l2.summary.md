本讲以 SVM 为主题，覆盖最大间隔与软间隔线性分类、核技巧与 RBF 核、gamma 与 C 的分工、决策区域图 test_idx 高亮四个模块。核心结论：SVM 在所有可分超平面中选间隔最大者，边界仅由少数支持向量决定；软间隔用松弛变量容忍违例，参数 C 沿用逻辑回归语义（正则化强度的倒数），过大易过拟合、过小易欠拟合。核技巧无需显式构造高维映射，仅凭核函数（RBF 高斯核）即可在高维空间找线性边界，解决 XOR 等线性不可分问题；gamma 决定单个样本的影响半径，过大使边界碎成孤岛、过小则近线性。SVM 基于内积与距离，标准化是硬前提；test_idx 按行号圈出测试样本（range(105,150)）。
