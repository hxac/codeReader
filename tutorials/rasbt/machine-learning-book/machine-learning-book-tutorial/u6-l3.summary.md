本讲在锁定的测试集上对模型做全面评估：先用混淆矩阵把准确率拆解为 TP/FP/FN/TN 四种结局并用 matshow 画热图；再由四格导出查准率（报警准不准）、查全率（漏没漏）、F1（调和平均，惩罚偏科）与 MCC，多分类按 micro（恒等于准确率）、macro（少数类同权）、weighted（按样本量加权）三种方式平均。关键结论：二分类指标默认 pos_label=1 且静默生效，正类方向必须对齐关心的少数类，可用 make_scorer(f1_score, pos_label=…) 显式声明，使调参目标与评估口径一致。ROC 曲线经 predict_proba、roc_curve、auc 三步生成：扫过所有阈值画 (FPR, TPR) 点，AUC 度量与阈值无关的分数排序能力，平均 ROC 需 interp 插值到统一网格。最后是类别不平衡陷阱：全预测多数类的傻瓜模型可得约 90% 准确率而正类 F1=0，用 resample 有放回上采样少数类后基线跌回 50%。
