本讲逐行讲解 ch02.py 中的 Perceptron 类（全书首个机器学习模型）。net_input 计算线性净输入 z=wᵀx+b；predict 用单位阶跃激活函数按 z 的符号输出 0/1，决策边界即直线 z=0；fit 逐轮（epoch）逐样本实现感知机学习规则：只有分错的样本推动更新，权重加 η(y−ŷ)x、偏置加 η(y−ŷ)；errors_ 记录每轮误分类数，归零即收敛。plot_decision_regions 铺网格整体预测后填色，为全书复用的可视化工具。核心结论：线性可分数据上感知机必收敛，且预测只依赖净输入符号，η 仅整体缩放权重，学习率几乎不影响收敛快慢；其局限（仅线性边界、不可分不收敛、阶跃不可导）引出下一讲 Adaline。
