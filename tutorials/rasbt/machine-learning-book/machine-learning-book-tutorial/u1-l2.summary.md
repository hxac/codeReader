本讲围绕“为本书代码搭一个可复现的 Python 环境”展开。核心结论：书中代码依赖 2021 年前后的固定版本组合（Python 3.9、numpy 1.21.2、scikit-learn 1.0 等），必须用虚拟环境隔离，路线有二：conda 单命令创建，或 pip + virtualenv。引入的关键术语包括：虚拟环境、conda 与 pip 的分工、conda-forge 频道、语义化版本（`=` 钉死与 `>=` 下限的差别）、YAML 格式的 environment.yml 环境配方，以及 Makefile 目标封装（install 目标产出 pyml-book 环境，create 目标按 yml 原名重建）。可复用组件是根目录的 python_environment_check.py：它用动态 import 和 LooseVersion 做"最低版本体检”，逐项输出 OK/FAIL，且被后续各章代码开头导入的 check_packages 函数复用，是全书代码的第一道门。注意其依赖的 distutils 在 Python 3.12 已移除，按 Python 3.9 建环境即可避开。无 GPU 或不愿装环境时可改用仓库自带的 Google Colab 指南运行各章 notebook。环境就绪后，下一讲将打开 ch02 notebook，跑通鸢尾花数据读入与可视化。
