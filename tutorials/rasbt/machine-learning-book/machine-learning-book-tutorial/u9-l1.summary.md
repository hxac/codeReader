本讲以 Ames 住房数据集预测房价，从分类转入回归任务（预测连续数值而非离散类别）。模块一：手写 LinearRegressionGD，其梯度更新式与 AdalineGD 完全同构，区别仅在预测端不做离散化；量纲悬殊时须对特征与目标分别标准化，预测后再还原。模块二：sklearn 的 LinearRegression 基于最小二乘解析解（正规方程），参数存于 coef_（斜率）与 intercept_（截距），斜率可直接解读为每平方英尺的房价增量。模块三：RANSAC 随机样本共识实现鲁棒回归——随机子集拟合候选模型、按残差阈值（缺省用 MAD 中位数绝对偏差自动估计）区分内点与离群点，内点掩码在 inlier_mask_，最终模型在 estimator_，离群点不再拉歪回归线。模块四：残差图与 MSE、MAE、R² 构成诊断体系，漏斗形残差提示异方差，回归的数据划分不做分层抽样。核心结论：五特征线性模型 train/test R² 为 0.77/0.75，属轻微欠拟合而非过拟合，为下一讲正则化回归与非线性模型埋下伏笔。
