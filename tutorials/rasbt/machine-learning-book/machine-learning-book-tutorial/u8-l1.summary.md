本讲以 IMDb 影评情感分析为例，讲解如何把非结构化文本转为数值特征。CountVectorizer 实现词袋模型：丢弃词序、只统计词频，产出「文档-词」稀疏矩阵，词表按字母序编号；TfidfTransformer 用逆文档频率给处处出现的词降权，注意 sklearn 变体公式 tf×(log((1+n)/(1+df))+1) 且默认逐行 L2 归一化。文本清洗三件套：preprocessor（去 HTML、保留表情符号）、普通分词与 Porter 词干提取两种 tokenizer、NLTK 停用词过滤；ngram_range 与 min_df/max_df 控制词表规模。实践上用 Pipeline 串联 TfidfVectorizer 与逻辑回归，交给 GridSearchCV 五折搜索——向化器必须放进管线、每折重建词表以防数据泄漏；best_score_ 是五折平均 CV 准确率（0.897），测试集另得 0.899。胜出组合（不滤停用词、不用词干、C=10、l2）表明 idf 降权已部分替代停用词过滤，高维稀疏文本特征宜用弱正则。
