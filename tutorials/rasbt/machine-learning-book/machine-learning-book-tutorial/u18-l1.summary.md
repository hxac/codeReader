本讲从零实现图卷积层：图由邻接矩阵 A（编码结构）与节点特征矩阵 X（编码内容）共同表示，二者行序必须对齐。图卷积公式 H=AXW2+XW1+b，按「0/1 矩阵左乘即按行求和」的行视角理解消息传递：W2 变换邻居消息、A 聚合、W1 保自身信息；它是节点级操作，对任意大小的图共享同一组参数。NodeNetwork 串联两层卷积、ReLU、global_sum_pool 与全连接层完成图分类；global_sum_pool 用 0/1 成员矩阵 B 左乘，把不定行数的节点表示读出为每图一个定长向量。因图大小不一无法堆叠成批，collate_graphs 将一批图拼成块对角不连通大图并以成员矩阵区分各图，批前向与单图前向一致；dict 样本的 Dataset 必须给 DataLoader 传自定义 collate_fn。关键术语：消息传递、度、全局池化（读出）、块对角邻接矩阵、成员矩阵。遗留局限：求和聚合未按度归一化，下一讲 PyTorch Geometric 的 GCNConv 将引入归一化聚合。
