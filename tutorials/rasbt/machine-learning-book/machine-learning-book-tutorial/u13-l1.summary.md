本讲拆解 PyTorch 动态计算图与自定义层。动态图（define-by-run）指计算图由每次前向实际执行的运算即时构建，forward 中可写 if/for 分支，两次调用可得到不同的图；autograd 靠 requires_grad、.grad_fn、.grad 三个属性诊断梯度沿图回传并在叶子上累加。参数注册是核心规则：张量必须包成 nn.Parameter（或经子模块、nn.ModuleList）才会被 parameters()、to(device)、state_dict() 认领，普通张量属性会静默失踪。自定义层与自定义模型的套路相同：__init__ 注册参数（如 NoisyLinear 采用 (in, out) 权重形状与 Xavier 初始化）、forward 定义计算；NoisyLinear 以「if training」条件分支实现训练时加噪正则化、评估时关噪的双重行为，与内置层 model.train()/eval() 切换 self.training 的机制思想一致，model(x, True) 经 __call__ 把开关传给 forward。综合实践仿写 NoisyReLU 并扫描噪声强度，为下一讲 state_dict 模型保存与加载铺垫。
