本讲核心：PCA 无监督地选方差最大的投影方向，LDA 则是监督降维，利用标签构造类内散布矩阵 SW 与类间散布矩阵 SB，解广义特征值问题 SW⁻¹SB，取「类间散、类内紧」的投影方向；因 SB 秩至多为类别数减一，LDA 判别方向数上限为 c−1（wine 三类取 2，二分类取 1）。sklearn 的 LinearDiscriminantAnalysis 的 fit_transform 须传入标签，测试集只做 transform。线性方法对月牙形等非线性数据失效；核 PCA 借核技巧在核空间做 PCA，分解 n×n 核矩阵（对偶视角）；核参数 gamma、coef0 无内在无监督评分，须用 GridSearchCV 包裹「KernelPCA＋逻辑回归」流水线、以下游交叉验证准确率选取（RBF 核不用 coef0）。关键术语：Fisher 判别准则、散布矩阵、广义特征值问题、核矩阵、双下划线参数网格、make_moons。仓库事实：ch05.py 非线性一节实收 t-SNE（无 transform、仅宜可视化），KernelPCA 相关代码均为示例。
