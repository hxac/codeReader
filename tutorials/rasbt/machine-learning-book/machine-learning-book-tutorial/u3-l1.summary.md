本讲开启 scikit-learn 分类之旅，覆盖四个模块：一是估计器统一的 fit、predict、score 接口范式，换模型只换类名、流程不变；二是用 train_test_split 做划分，stratify 分层抽样保持类别比例，固定随机种子保证可复现；三是 StandardScaler 遵循「只在训练集拟合、测试集仅变换」原则，防止测试集统计量造成数据泄漏；四是手写 LogisticRegressionGD：以 sigmoid 把净输入映射为类别概率，以对数似然损失（log loss，二元交叉熵）为凸代价，几率与 logit 给出概率解释，其梯度更新式与 AdalineGD 同构，仅激活函数不同。最后介绍 sklearn 版逻辑回归：predict_proba 输出每行和为 1 的概率矩阵，predict 即逐行取最大；默认 L2 正则化，参数 C 与正则化强度互为倒数，C 越小权重收缩越强，借以抑制过拟合；多分类采用 OvR 策略。这些接口与概念（估计器范式、数据泄漏、C 的倒数关系）将被后续 SVM 等讲义直接承接。
