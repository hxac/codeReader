本讲以 MNIST MLP 为载体讲解 PyTorch Lightning 的工程化训练范式：用户在 LightningModule 里只写每个 batch 的一步（training/validation/test_step 返回损失）与 configure_optimizers，epoch 循环、backward 三件套、设备搬运与 train/eval 模式切换全部交给 Trainer，self.log 统一记日志。LightningDataModule 用 prepare_data、setup 与三个 dataloader 方法封装「下载—划分—加载」数据管线。Trainer 提供 fit/test/predict 入口，logger 可插拔（TensorBoard 或 CSVLogger），断点续训用 ckpt_path，max_epochs 是绝对总轮数。ModelCheckpoint 回调按 monitor 指标自动保存最优权重，实证 best ≠ last；评估用 ckpt_path='best'，推理用 load_from_checkpoint 重建。工程版把纯模型与训练逻辑分离，辅以 _shared_step 复用、log 指标对象与 save_hyperparameters。批判性读码点：softmax 概率喂 cross_entropy、训练 loader 未 shuffle；仓库基于 Lightning 1.5.x，2.x 多处 API 已更名。
