本讲以 IMDb 影评二分类搭建第一个 RNN。模块一：文本数值化流水线——分词得到词元，仅用训练集按词频建两万词的词表，加上 `<unk>` 与 `<pad>` 共 20002 项，再经 Embedding 查表把整数编号转为可学习的稠密向量。模块二：模型三件套 Embedding→nn.RNN→Linear，输入为句长优先的 [L,B,E]，output 含全部时间步隐状态，hidden 为最终步隐状态。模块三：many-to-one 分类，取 hidden.squeeze(0) 过全连接得 logit，配 binary_cross_entropy_with_logits，训练循环沿用五步范式。核心结论：Embedding 占总参数约 98%；简单 RNN 因梯度沿隐状态权重连乘数百步而消失，叠加 padding 对隐状态的稀释，cost 躺平在 ln2、测试准确率仅约 46%，这一负结果构成下一讲 packed sequences 与 LSTM/GRU 的出场动机。关键术语：词元、词表、特殊词元、词嵌入、隐状态、many-to-one、BucketIterator、梯度消失。
