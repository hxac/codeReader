本讲以 u2-l3 的 MLP 基线（测试准确率 97.54%）为对照，精读仅差几行的两份 notebook，讲解两种正则化。核心概念：泛化缺口（训练准确率−测试准确率）；train/eval 双模式——model.train()/eval() 翻转 self.training 标志，Dropout 与 BatchNorm 是行为随其改变的两类标准层，评估函数中 net.eval() 管层行为、torch.no_grad() 管梯度；inverted dropout——训练时以概率 p 置零并将存活单元放大 1/(1-p) 以保持期望不变，评估时恒等通过，函数式 F.dropout 须显式传 training=self.training；BatchNorm1d 双轨机制——训练用当前批统计并同步更新 running stats，评估改用 running stats，γ/β 为可学习参数，经典位置在 Linear 之后、激活之前，参数是通道数而非输入特征数。对照实验结论：Dropout 把泛化缺口从 1.46 压到 0.81，但测试准确率降至 96.71%；BatchNorm 收敛最快、测试准确率最高（97.82%）而缺口最大（1.79）。方法论结论：正则化并非越多越好，强度应与基线过拟合程度匹配；「克隆基线、只改一处」的受控对比值得沿用。
