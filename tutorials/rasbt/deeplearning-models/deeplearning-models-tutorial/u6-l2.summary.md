本讲沿两条线索修复 u6-l1 简单 RNN 分类器的失败。一是打包序列：padding 既浪费算力又稀释最终隐状态，`pack_padded_sequence` 把补齐张量与真实长度重排为 `PackedSequence`，让 RNN 跳过 padding；前提是 batch 内长度降序（`include_lengths=True` 与 `sort_within_batch=True`）。打包后同一 RNN 测试准确率由 46% 升至 74%，训练提速三倍多。二是门控单元：LSTM 以 cell state 加法传送带与遗忘、输入、输出三道门对抗梯度消失，返回 `(hidden, cell)`；GRU 仅更新、重置两道门、无独立 cell，接口同 `nn.RNN`，参数约为 LSTM 的 3/4。受控对比下 LSTM 与 GRU 均约 85% 且几乎打平、GRU 更快。三份「只改一处」的 notebook 为下一讲双向、多层循环与 GloVe 初始化铺垫。
