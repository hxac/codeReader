本讲关注训练过程本身的调节，基于 tricks 目录三份 notebook。LR Range Test 让学习率在训练初期线性爬升并记录损失，按曲线为循环学习率定出 base_lr 与 max_lr。循环学习率（CLR）按 batch step 在两边界间周期往返，含 triangular、triangular2（振幅逐周期减半）、exp_range（指数衰减）三种模式，手动改 lr 写回 optimizer.param_groups；短期大步长有助跳出尖锐极小值。梯度裁剪防梯度爆炸，须插在 backward 与 step 之间：clip_grad_value_ 逐元素截断，hook 加 clamp 可设非对称区间但会系统性偏置更新，clip_grad_norm_ 按整体梯度范数等比缩放、保方向、最常用。batch size 退火依据噪声尺度 g≈εN/(B(1−m))，衰减学习率可等价换成增大批量。读码应以变量来源为准：仓库 CLR 训练 cell 因 batch_step 未重置，实际并非锯齿调度。
