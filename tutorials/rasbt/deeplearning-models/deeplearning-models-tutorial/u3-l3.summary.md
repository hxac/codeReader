本讲沿架构演进精读 VGG16/19、NiN、All-Conv 与「全连接-卷积等价」实验四个模块。VGG 用 3×3 小核深堆叠替代大核：同感受野下参数省约 44%，五个卷积 block 配置化组织，但巨型全连接分类头把输入尺寸锁死于 flatten 维度。NiN 的 mlpconv 块以 1x1 卷积（逐像素全连接）做跨通道升降维，末层直接输出类别数通道并接全局平均池化（GAP），分类头参数近零且与输入尺寸解耦。All-Conv 用 stride=2 步长卷积取代池化做下采样。等价实验数值证明 Linear 可改写为 kernel 覆盖全图或 1x1 的卷积，且 GAP 与线性可交换，故「GAP+Linear」与「1x1 卷积+GAP」精确等价，这是 NiN 分类头的数学根基。实验还实证深网络对初始化极敏感、训练不足时更深未必更好，为下一讲 ResNet 的残差连接埋下伏笔。
