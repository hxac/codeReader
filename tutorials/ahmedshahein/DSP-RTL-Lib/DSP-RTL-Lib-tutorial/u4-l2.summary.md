本讲精读 CIC 插值器 `filt_cici`,它是 u4-l1 抽取器 `filt_cicd` 的镜像。核心拓扑由 noble 恒等式对偶形式给出:数据流从「积分→↓R→梳状」翻转为「**梳状→↑L→积分器**」——梳状先在慢域做差分,再零插值,最后积分器把稀疏脉冲积分成阶梯保持波形。贯穿两条铁律:**积分器永远在快域、梳状永远在慢域;变速器(↑L)夹在两段之间**。与抽取器单时钟不同,插值器需两个外部时钟:`i_clk`(慢,驱动梳状 `shift_register`)与 `i_fclk`(快,驱动 `upsample` 与积分器 `dff`),且约定快时钟频率为慢时钟的 L 倍。`upsample` 原语用"模 L 计数器 + 零填充移位寄存器"实现零插值,`w_load` 每 L 拍选一次真实样本、其余拍输出 0,`gp_phase` 选相位。关键结论:积分器跑快时钟才能在每个输入后用"加 0 保持"产出 L 个输出;梳状输出在 L 个快周期内准静态,跨域无需同步器。位宽沿用 Hogenauer 公式(细节留待 u4-l3),GRM 用 `filter(H^N, upsample(data))` 给出比特真答案。
