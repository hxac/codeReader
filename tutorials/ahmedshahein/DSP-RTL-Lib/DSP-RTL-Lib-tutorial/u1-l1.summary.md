DSP-RTL-Lib（DRL）是 Ahmed Shahein 开发的开源库（BSD 2-Clause），提供「可参数化、可综合」的通用 DSP 硬件模块，面向 ASIC/FPGA 前端设计与 DSP 学习。其核心理念是 mix-and-match（M&M，混搭组合）：把系统拆成基本组件（如数字前端 DFE = 混频器 + 抽取级 + 信道选择），设计者挑选、参数化、连线拼装成完整系统。全库统一采用三位一体架构：每个模块同时拥有 Verilog 2001 的可综合 RTL、SystemVerilog 2012 的测试台、Octave 的 GRM（黄金参考模型）；验证闭环为「GRM 提供标准答案 → 测试台喂激励并逐样本比对 → RTL 接受检验 → error_count 判定 PASSED/FAILED」，输出逐比特一致即称比特真（bit-true）。当前有 7 个 Stable 模块族（FIR、MAC、CIC 含抽取 filt_cicd 与插值 filt_cici、PPD、PPI、NCO、CORDIC），2 个 Planned（DC、IIR）。当前 RTL 为常规实现，不做面积/功耗优化，核心价值在于正确性、可参数化与可复用。后续讲义将聚焦仓库骨架、构建脚本 dsp_rtl_lib.sh、编码风格约定及定点数源码精读。
