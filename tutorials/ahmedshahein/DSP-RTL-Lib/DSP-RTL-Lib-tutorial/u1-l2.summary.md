本讲讲清了 DSP-RTL-Lib（DRL）仓库的目录组织契约。顶层分三类：文档入口（README/LICENSE/PDF）、构建脚本 `dsp_rtl_lib.sh`、两个只读隐藏库——`.drl_param`（参数库，存放「键=值」三列的 `.param` 文件）与 `.drl_src_code`（源码模板库，含 8 个 Stable 模块：filt_cicd/cici/fir/mac/ppd/ppi、sgen_cordic/nco）。全库 8 个模块目录结构完全统一，含 `log / octave / rtl / sim/{testbench, testcases/{response,stimuli}}` 六个子目录，外加构建时才生成的 `vvp / vcd`；脚本用 `FOLDERS`、`SUB_FOLDERS` 两数组在克隆后做完整性自检，任一缺失即 `exit 5`。核心结论是区分「源码模板」与「构建产物」：模板只读且被 git 跟踪，产物由 `-d` 流程经 `cp` 复制加 `sed` 注入参数生成、不入库。`.param` 优先级高于模板默认值。关键术语包括源码模板、构建产物、`.param` 参数库、`empty_file` 占位文件、`.gitignore`，以及参数命名约定 `<模块>_<实例号>.param`。
