本讲讲解无乘法器的 CIC（级联积分梳状）抽取滤波器与 `filt_cicd` 实现。核心结构为「N 级积分器（快域）→ ↓R → N 级梳状（慢域）」：下采样插在中间是 Hogenauer 的关键观察，使梳状只处理 1/R 的样本，整体传递函数恰为长度 RM 滑动平均的 N 次幂，天然稳定。四个最小模块：输入端用 MSB 符号扩展补齐到统一输出位宽 `gp_oup_width`（依 Hogenauer 公式 B_out=B_in+N·⌈log₂(RM)⌉）；积分器为累加器 1/(1−z⁻¹)，由 `dff` 加反馈实现、跑快时钟；一位热码环形计数器每 R 拍产脉冲 `w_sclk`，`gp_phase` 选相位，再用 `.i_ena(w_sclk)` 的 `dff` 完成快慢域换速；梳状为差分器 1−z⁻¹ᴿᴹ，用 `shift_register` 做 z⁻ᴹ 延迟、使能接慢域脉冲。关键术语：抽取比 R、差分延迟 M、级数 N、`w_sclk`、`gp_phase`、符号扩展、比特真、黄金参考模型。设计靠复用 `dff` 与 `shift_register` 原语、改 `i_ena` 切换快慢域；默认参数（R=4、N=3、M=1）下单位冲击的抽取响应为 [1, 12, 3]。
