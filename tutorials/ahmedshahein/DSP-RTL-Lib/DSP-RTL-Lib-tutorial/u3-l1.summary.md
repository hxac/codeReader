本讲讲解 FIR 原理与 filt_fir 结构。FIR 本质是离散卷积 y[n]=Σh[k]x[n-k]，硬件由延迟线（dff 串）、乘法器与加法树实现。filt_fir 用 generate 块按 gp_tf_df 切换转置型（TF）与直接型（DF），二者算同一卷积，区别仅在寄存器插在加法链还是输入延迟线。位宽自动推导：c_mul_oup_width=输入位宽+系数位宽，再累加 $clog2(抽头数) 得输出位宽；gp_oup_width 写成 parameter 默认表达式，可被顶层覆盖或留空自动算。gp_symm 仅将系数数组 c_coeff 取半并靠镜像下标复用，不省乘法器。系数与 RTL 解耦：Octave 的 gen_coeffs.m 把量化整数写成 filt_coeff.v，经 `include 钩入主模块，负数写成 -q'sd|值|。RTL 的 $clog2 与 GRM 的 ceil(log2) 用同一公式，是比特真根基。
