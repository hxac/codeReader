本讲讲主机如何用 XRT 编排 AIE 图与 PL 内核。`runGraphs()` 用 `graph.run(0)` 把 AIE 图置为自由运行，节奏全由主机经 GMIO 投递驱动，内核依 Kahn 数据驱动「数据就绪才 fire」。`bp()` 以四层循环逐脉冲喂数据：slowtime 整块投递、RC 按距离线逐条投递、像素按 switch 切片每脉冲重推，并用 RTP `rtp_dump_img_in` 控制——前 601 脉冲置 0 只累加跨调用持久的 `m_img`，末脉冲置 1 才 dump 出完整聚焦图像。PL 包路由器 `dma_pkt_router` 经 `set_arg`/`start` 非阻塞启动，按包头 `instance_id` 计算 `ddr_offset`，把 224 个重建核的乱序输出重排进同一 img buffer 的不重叠区段。所有 GMIO `async` 与 RTP `update` 均非阻塞、异步句柄被丢弃；`bo.sync(FROM_DEVICE)` 是 `bp()` 唯一阻塞点，既把 DDR 图像搬回主机，又充当「等 PL 写完」的栅栏。
