本讲把 AIE 图与 PL 内核在「编译→链接→打包」主线上缝合。system.cfg 由 Makefile 在编译 PL 内核（.xo）时自动生成，内容随 common.h 的 AIE_SWITCHES 宏伸缩，含三类指令：nk 声明实例化若干份 dma_pkt_router；stream_connect 把每个 AIE PLIO 输出 plio_pkt_rtr_out_0_i 接到对应 PL 实例的 pl_stream_in（端口名两端共享同一从 0 起的 switch 计数器）；sp 把每个 PL 实例的 ddr_mem 主写口绑到 DDR。随后 v++ -g -l 以 system.cfg 为接线说明，将 libadf.a 与 dma_pkt_router.xo 链接成 XSA（完整硬件设计），其 --save-temps 留下的 Vivado 工程供后续度量复用。v++ -p 再把 XSA、host elf、启动链（BL31/u-boot/内核/rootfs、DTB 仅 hw）与输入 CSV 打包成 SD 卡镜像，其中 defer_aie_run 把 AIE 图运行时机交给主机程序显式控制。system.cfg 系构建产物，被 .gitignore 忽略，system_cfgs/ 目录仅以空 .gitkeep 占位。
