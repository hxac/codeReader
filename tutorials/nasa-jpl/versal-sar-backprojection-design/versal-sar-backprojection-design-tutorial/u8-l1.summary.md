本讲讲解在 VCK190 上板前如何验证反投影设计的功能、速度与功耗，是「仿真、度量与优化」单元首讲。三个最小模块：（1）三个递进的 AIE 仿真目标——aiesim 做纯功能仿真并产出 PLIO trace CSV，aiesim_profile 加 --profile --dump-vcd 产出 aie.vcd 波形与停顿/吞吐报告，aiesim_xpe 用 vcdanalyze 把波形转成 .xpe 功耗文件；三者共用 libadf.a，属「验证旁路」而非主线构建。（2）graph.cpp 中被 __AIESIM__/__X86SIM__ 宏守卫的独立仿真 main，是 aiesimulator/x86sim 的测试台，内联复刻主机读 CSV、解卷绕、生成像素并驱动图，其 gm2aie_nb 投递顺序（slowtime 一次、RC 每脉冲、像素每 switch、RTP 末脉冲置 1）与真实主机 bp() 一一对应，唯一差异是仿真用 run(PULSES) 有界计数、主机用 run(0) 自由运行。（3）sw_emu/hw_emu/hw 三档 TARGET 的本质区别，以及 Makefile 两道校验关卡——禁 aiesim+sw_emu（aiesim 无法加载 x86sim）、禁 run+hw（run 只服务仿真启动器）。下一讲 u8-l2 将把 aie.vcd/XPE 与性能功耗度量体系串联。
