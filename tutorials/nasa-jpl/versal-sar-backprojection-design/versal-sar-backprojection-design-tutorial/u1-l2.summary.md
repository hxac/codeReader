本讲带读者「先认路、再读码」，覆盖三个最小模块。一是**仓库目录与域归属**：代码按 Versal 三引擎域分层——`design/aie/`（AI Engine 反投影内核与 ADF 图，C++/ADF）、`design/pl/`（FPGA 上的 HLS 包路由器内核）、`design/host/`（ARM 控制程序），`design/common.h` 是三域共享的唯一配置头；另有 `helper_scripts/`、`design/exec_scripts/`（部署运行）、`Makefile`（构建）、`doc/`（文档）。需注意本仓库是多仓库项目之一，应经 versal-manifest 拉取依赖。二是 **GOTCHA 测试数据集**：分 slowtime（每行 4 列浮点，记录平台几何，对应 `BC_ELEMENTS=4`）与 phdata（每行 `RC_SAMPLES` 列复数 `a+bi`，记录距离压缩回波）两类；phdata 按 `RC_SAMPLES` 取值（64/128/256/512）各存一份，Makefile 依 `common.h` 自动选对文件。slowtime 含完整 360° 约 4.2 万行，但运行时 host 的 `fetchRadarData()` 仅读前 `PULSES`（默认 602）行。三是 **Git LFS**：大文件仓库中只存指针，须 `git lfs install && git lfs pull` 才能得到真实数据。
