本讲是「AIE 图拓扑」单元首讲，只讲静态拓扑结构（图里有谁、谁连到谁、数量怎么算），不涉及包交换、端口位宽与内核算法。整张反投影图分两层：顶层图 `BackProjectionGraph` 与子图 `BackProjectionSubgraph`（即 bpCluster）。顶层只放一个 Data Broadcast 内核 `data_bc_km`，负责接收主机经 GMIO 送入的 slowtime（天线几何）与 RC（距离压缩样本），再扇出广播给全部重建内核；把广播放顶层是为了避免主机重复送 7 份数据。顶层用成员数组 `bpCluster[AIE_SWITCHES]`（默认 7）把一整组计算簇复制多份，从而把并行度参数化。每个 bpCluster 内含 1 个 Pixel Demux 内核 `px_demux_km`、32 个 Image Reconstruction 内核 `img_rec_km`（类形式，用 `kernel::create_object<ImgReconstruct>(id)` 构造），以及一对 `pktsplit<32>`/`pktmerge<32>`（上限 32 路）。默认配置下三类内核总数为 1+7+224=232，重建核数 `IMG_SOLVERS = AIE_SWITCHES × IMG_SOLVERS_PER_SWITCH`。顶层穿透子图边界，把 slowtime/rc 广播到每个重建核的 `in[0]/in[1]` 并施加 `single_buffer`（关闭双缓冲以省存储），像素包经 demux→pktsplit 进 `in[2]`，RTP 进 `in[3]`，重建结果经 pktmerge→PLIO 输出。每个重建核处理 `(PULSES×RC_SAMPLES)/IMG_SOLVERS`=1376 个像素，由 `m_img` 缓冲持有，受整除约束保证。两个全局计数器 `bp_graph_insts`/`bp_subgraph_insts` 借 C++ 成员声明顺序构造的特性，自动为端口名与内核 id 生成全局唯一编号（后者用于 PL 侧把乱序图像包写回正确 DDR 偏移）。
