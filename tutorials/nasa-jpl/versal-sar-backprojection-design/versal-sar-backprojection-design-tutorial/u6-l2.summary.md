本讲讲解 PL 包路由器 dma_pkt_router 的仿真 testbench，核心思想是「站在 AIE 视角」：用 aiesim 录制的 PLIO trace CSV 作回放激励，把内核当被测单元，以 hls::stream<ap_axiu<128>> 连接。三大模块：(1) CSV 反序列化——每行 DATA: 的 D0~D3 四个 32 位字拼成 128 位 data，配 TLAST/TKEEP 副信号（TKEEP 兼容 -1/0x../十进制/空串）；(2) csim/cosim 流程，Tcl 脚本用 set_part（VCK190 器件）与 create_clock（312.5 MHz）锚定仿真，csim 总会跑，hls_exec 控制其后档位（综合/协同仿真/导出），pkt_router_config.cfg 为同一配置的命令行版；(3) make plsim_router 的依赖链，用「CSV 存在性守卫」在激励缺失时先跑 aiesim，链路为 design/aie → libadf.a → aiesim → PLIO CSV → csim → output_img.csv。testbench 用 7 次 pl_kern 外层循环 × 内核内 32 次 IMG_KERNEL_LOOP，复现「7 个 PL 实例共写同一块 DDR、偏移由内核按 instance_id 自算」的场景；其 output_img.csv 与主机 writeImg() 在格式串、换行、元素总数上完全一致，可逐字段对账、单独验证 PL 重排正确性。
