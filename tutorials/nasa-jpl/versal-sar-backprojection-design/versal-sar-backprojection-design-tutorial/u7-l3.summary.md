本讲讲清从主机 make 完成到 VCK190 板卡跑起 sar_backproject.elf 的端到端部署链，按通路三分工：JTAG 烧 BOOT.BIN（含 FSBL/ATF/U-Boot/PDI 的引导镜像，OS 起来前唯一灌入通道）、TFTP 送内核 Image 与 pxelinux 配置、NFS 送整个 rootfs（含应用）。前提是主机程序为 aarch64 交叉编译，必须 link Yocto 导出 SDK 的 sysroot；env_setup.sh 经 source 注入路径与交叉编译器，make package 再把 Yocto 产物与 XSA、libadf.a、host elf 打包成 BOOT.BIN。pxelinux 的 default-arm-versal 用 nfsroot/ip 等 bootargs 指定 NFS 服务器与板卡网络，须与 /etc/exports、U-Boot 三处网段一致。flash_bootbin_xsct.tcl 经 JTAG 五步（算路径、connect、选 Versal 目标、rst 复位、device program）灌入 BOOT.BIN，复位须先于编程。
