本讲深入 `SARBackproject` 类构造函数，讲解主机在反投影启动前的三件事：打开设备加载 xclbin、分配映射 buffer、建立 AIE 图与 PL 内核句柄。讲义围绕三个最小模块展开。模块一梳理类成员的三类「家当」：配置参数、设备资源句柄（`m_device`、`m_uuid`）、数据 buffer 与映射指针；指出 `m_iter` 与 `hid_t file` 是声明但主流程未充分使用的预埋字段，图/内核/run 句柄用 `std::vector` 存是为支持多实例（当前 `INSTANCES=1`）。模块二讲初始化列表：`m_device(0)` 打开设备 → `load_xclbin` 得 `m_uuid` → 三个输入 `xrt::aie::bo`（slowtime/目标像素/RC）构造 → `.map<T*>()` 映射；强调初始化顺序由类内声明顺序决定；三个 buffer 大小由 `common.h` 宏给出（广播 `PULSES·BC_ELEMENTS·4`、目标像素 `PULSES·RC_SAMPLES·4·3`、RC `PULSES·RC_SAMPLES·8`），均写死 bank 0 以匹配 GMIO 通道绑定。模块三讲函数体按实例循环建立三类句柄：`xrt::kernel`（内核对象）、`xrt::run`（运行把手）、`xrt::graph`（AIE 图把手），内核名字字符串须与 `system.cfg` 的 `nk=` 实例名一一对应。核心结论：`m_img_buffers` 用 `kernels[0].group_id(1)` 选 bank，因其为被 PL 内核 `ddr_mem`（arg 1，`m_axi bundle=gmem`）直接寻址的普通 `xrt::bo`，bank 须与 m_axi 绑定一致；而三个输入 `xrt::aie::bo` 走 GMIO，bank 由通道绑定决定（写死 0）。引入的关键术语：XRT、xclbin、buffer object（bo）、`xrt::aie::bo`/`xrt::bo`、GMIO、bank/memory group、`group_id`、`xrt::kernel`/`xrt::run`/`xrt::graph`。
