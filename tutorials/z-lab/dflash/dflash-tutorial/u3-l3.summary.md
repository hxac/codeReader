本讲承接 u3-l2，处理含 GDN（门控增量网络）的混合架构模型（如 Qwen3.5）在投机解码中的状态回滚，仅涉及 dflash/model_mlx.py。核心结论：GDN 层的状态由卷积状态 conv_state（定长滑窗）与 delta 递归状态（增量累积矩阵）组成，融进了全部历史 token，无法用 trim 删尾，故 can_trim_prompt_cache 对其返回 False。解法是「重放重建」而非删除：从干净检查点 init_state 出发，只用被接受的前 accepted+1 个 token 重放递归。机制上引入 _GDNStateCapture，靠 monkey-patch 替换 GatedDeltaNet.__call__，在验证前向抄录每层的 conv_input 与 gdn_inputs（含 init_state），生命周期为 patch→clear→rollback→close，用全局锁防并发改写。回滚由 _target_can_trim × _HAS_GDN 分流：可裁剪走 _trim_recent_cache，不可裁剪且有 GDN 走 rollback，二者皆无则 RuntimeError fail-fast 避免静默错乱。两条核心公式：delta state 从 init_state 重放前 accepted+1 列得到，conv_state 切片为 conv_input[:, accepted+1:accepted+K]（收尾于第 accepted 个 token）。
