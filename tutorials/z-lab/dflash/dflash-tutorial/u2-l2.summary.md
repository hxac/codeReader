本讲打开 DFlash 草稿模型这个黑盒。`DFlashDraftModel` 小而「残缺」：有 layers、norm、rotary_emb、fc、hidden_norm，却无 embed_tokens 和 lm_head（生成时向 target 借，即两个「借」）；它复用 Qwen3 组件以获得 from_pretrained 权重加载能力。配置上 `num_hidden_layers` 是草稿自身层数（极易混淆），`num_target_layers` 才是 target 层数；block_size 放 config 顶层（必填），target_layer_ids 与 mask_token_id 则放可省略的 dflash_config 字典。`build_target_layer_ids` 在 [1, num_target_layers-3] 区间等距采样若干层（故意跳过最前 1、最后 3 层，用银行家舍入），单层时取正中。`forward` 的核心是 target_hidden = hidden_norm(fc(target_hidden))：fc 把多层拼接的 target 特征（层数×hidden_size）投影压回 hidden_size，充当 target 与 draft 两种表示空间之间的「翻译器」；它返回的是隐藏状态而非 logits，再由 target.lm_head 转成 logits。配套的 `extract_context_feature` 用 offset=1 跳过嵌入层、沿特征维 cat 拼接，保证 fc 输入维度与 target_layer_ids 三者一致。每层 `Qwen3DFlashDecoderLayer` 同时拿到噪声嵌入与投影后上下文两路输入，但注意力内部如何拼接 key/value 留给 u2-l3。
