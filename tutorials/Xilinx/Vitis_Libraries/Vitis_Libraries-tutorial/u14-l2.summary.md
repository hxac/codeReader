本讲教读者从零编写一个符合仓库规范的 L1 流式内核，以 `stream_dup` 为最小可复制范本。完整交付物是五个文件：内核侧模板头件 `.hpp`，用例侧 `test.cpp`、`Makefile`、`hls_config.tmpl`、`description.json`；其中 Makefile 完全通用、可逐字复制，新建用例只需改其余三件。模板头件须先引 `types.hpp` 把 `AP_INT_MAX_W` 撑到 4096 再引 `ap_int.h`，收于 `xf::common::utils_hw` 命名空间，采用前向声明加实现两段式，主循环用 `pipeline II=1`，参数约束靠 `XF_UTILS_HW_STATIC_ASSERT` 编译期拦截。DUT 是模板内核的 `extern "C"` 实例化壳，钉死模板参数、关闭 name mangling，其名须与 `description.json` 的 `topfunction`、`hls_config.tmpl` 的 `syn.top` 三处一致，并与 testbench 经 `__SYNTHESIS__` 宏共用同一份 test.cpp。end flag 采用前瞻式消费约定（N 个数据配 N+1 个 flag），testbench 须喂 N 个 false 加 1 个 true 并校验输出。TARGET 分派中 csim 只仿真、csynth 只综合，后者报告的 II、Latency、资源三项是内核质量验收的核心指标。
