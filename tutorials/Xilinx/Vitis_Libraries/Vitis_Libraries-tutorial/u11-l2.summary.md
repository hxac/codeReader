本讲以 Vitis `ultrasound` 库为样本，演示 L1→L2→L3 三层抽象的层层组合。L1 是一盒 NumPy 风格的向量/矩阵原语（`mulMM`/`sumVV`/`squareV`/`sqrtV`/`diffSV`/`norm_axis_1`/`outer` 等），每个原语≈一个 `for` 循环加一条 `aie::` 向量 intrinsic，模板四件套为 `T/LEN/INCREMENT/VECDIM`，意在 NumPy 与 AIE SIMD 之间做最近映射；声速 `SPEED_OF_SOUND=1540` 是贯穿全局的常量，延时 τ=距离/c。L2 是用 L1 原语经 ADF 数据流拼出的波束合成功能单元，核心结论是「Focusing 即欧几里得范数」——`diffSV→squareV→sumVV→sqrtV`，以及「PW 延时=距离÷声速−起始时刻」。L2 并存两条路线：拼原语式功能图（可读、可组合）与整块式包装图（省核、直调 intrinsic），数学等价。组合的载体是 ADF graph，呈现「图里套图」：L3 只见 L2 图端口、L2 只见 L1 原语端口，层间靠 `connect` 解耦，换 SIMD 宽度不影响上层。L3 是完整 Beamformer，PW/SA/ScanLine 三种模式复用同一盒 L2 积木，差别集中在发射端：PW 用 `delay_pw`，SA/ScanLine 用 `delay`，SA 额外挂发射侧 `focusing_sa`+`apodization_sa`；接收端共用 Delay-and-Sum 骨架。关键术语包括 AIE/SIMD/intrinsic、`adf::input_buffer`/`output_buffer`、PLIO、`mm2s`/`s2mm`、`xrt::graph` 的 `init/run/end` 生命周期及 x86sim/aiesim 四档仿真。
