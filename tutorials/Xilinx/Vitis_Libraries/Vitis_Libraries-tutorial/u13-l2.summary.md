本讲以 PL+AIE 混合示例 vss_fft_ifft_1d 为线索，覆盖主机控制 ADF 图、system.cfg 拓扑、SD 卡打包、hw_emu 启动四块。

xrt::graph 是 AIE 图的主机侧遥控器，reset()/run()/end() 对应仿真侧 aie.cpp 的 init()/run()/end()；本例设 NUM_ITER=-1 让图自由运行，靠 PL 搬运内核 s2mm 收够数据终止整条流水线，故主机只调 reset()/run()——先 graph.run() 就绪图，再并发 start mm2s/s2mm，以 s2mm_run.wait() 当闸门收尾，全程不建线程。

system.cfg 是链接期系统拓扑说明书：nk= 实例化内核、sp= 绑存储 bank（决定主机 group_id）、sc= 焊接 PL↔AIE 边界的 AXI Stream（条数 = 2×SSR）。

v++ --package 在嵌入式 Versal 平台产出整张 SD 卡（输入 XSA 与 libadf.a），--package.defer_aie_run 把图启动权交给主机，主机须 aarch64 交叉编译并链 -ladf_api_xrt。hw_emu 用 QEMU 跑整个 Versal 系统，run_script.sh 设 XCL_EMULATION_MODE=hw_emu 后跑 host.elf，外层靠 grep "TEST PASSED, RC=0" 判定 CI 成败。
