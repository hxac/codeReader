本讲从 PL 路线切到 AIE 路线，系统盘点 `dsp` 库在 AI Engine 上的内核家族，分五大类：FFT/频域（mixed_radix_fft）、DDS 变频（dds_mixer）、FIR 全家桶（fir_sr_asym 等）、矩阵/线性代数（matrix_mult/GeMM）、排序与卷积（bitonic_sort、conv_corr）。核心结论是每个内核遵循「kernel + traits + utils」三件式加一个运行时 `.cpp`：类定义放头文件、含 `static_assert` 防御检查与构造函数但不含 intrinsics，运行时函数含 intrinsics 另放 `L1/src/aie`，这套拆分源于 AIE 的两阶段编译（图级无 intrinsics、核级才有）。关键术语包括：`TT_`（类型形参）与 `TP_`（非类型形参）命名约定、用户实例化的 L2 graph 包装（`kernel::create_object` + `connect` + `dimensions`）、`TP_CASC_LEN` 级联、SSR 多路并行、window/stream 两种数据交换、cint16/cfloat 等原生复数类型。matrix_mult 的 tiling 方案按数据类型查表决定、用户只保证维度是 tile 整数倍；FIR 在构造期逆序系数以适配向量 intrinsics。AIE 测试在 `dsp/L2/tests/aie`，`flow=aie`，按 `param_set` 的 `*_aie1_*`/`*_aie2_*` 为 vck190/vek280 挑参数，用 UUT/REF 双图比对配 `DIFF_TOLERANCE` 误差门限判 PASS/FAIL，分 x86sim（功能）与 aiesim（周期精确）两档仿真。
