本讲是「HLS 内核与流式数据模型」单元首讲，围绕 `utils` 库四个最小模块讲清内核间数据流动方式与顶层函数写法。**hls::stream** 是单向 FIFO，元素只能顺序单次读写（`read/write` 阻塞、`read_nb/write_nb` 非阻塞），强制流式访问以映射 II=1 的硬件流水。**end-flag 约定**：流不携带长度信息，须配一条伴生 `hls::stream<bool>` 标记结束；`stream_dup` 采用前瞻式消费，对 N 个数据读 N+1 个 flag（生产者写 N 个 false + 1 个 true），且 end 流拓扑随数据拓扑走——`stream_dup` 各路独立结束用 end 数组，`stream_split` 同生同灭共享单流。**ap_int<N>** 表达任意位宽整数，`.range(hi,lo)` 是宽 beat 切多路窄通道的切片刀，位宽直接放大带宽；`types.hpp` 须在引入 `ap_int.h` 前把 `AP_INT_MAX_W` 设为 4096。**extern "C" DUT** 是模板内核的实例化壳：钉死模板参数、压平签名、关闭 name mangling 以供主机 XRT 按名查找，名字与 `description.json` 的 `topfunction` 对应；`test.cpp` 靠 `__SYNTHESIS__` 宏同时充当 DUT（综合）与 testbench（仿真）。
