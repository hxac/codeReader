本讲解析 Vitis motor_control 库——面向永磁同步电机（PMSM）驱动的纯 PL（HLS）垂直库，提供 FOC、SVPWM_DUTY、PWM_GEN、QEI 四个算法级 L1 API。FOC 是控制律核心：经 Clarke/Park 变换把三相电流解耦到 dq 轴，由三路 PID（速度/磁通/力矩）加解耦、弱磁闭环，反变换输出三相电压命令（II=5）。SVPWM 拆为前后端：前端用 min-max 零序注入把电压命令换算成 0~1 占空比，后端生成带死区的 6 路门控脉冲与 ADC 同步信号，靠占空比流在 DATAFLOW 中按不同速率解耦并发。QEI 经滤波→捕边→计数从编码器 A/B/I 脉冲还原转速与角度，输出 RPM_THETA_m 与 FOC 输入完全对齐，可直接串联。四个内核统一采用 AXI Stream（数据流）+ AXI-Lite（配置，bundle 按 offset 读写）+ ap_none（状态回读）三段式接口，专为 Vivado IPI 图形化集成设计。默认用 ap_fixed 定点实现（Q15.16、查表替代三角函数），新增 models_fp 浮点参考分支（含可综合 *_fp32 与模板黄金参考两套）用于量化定点精度误差，不替代默认实现。
