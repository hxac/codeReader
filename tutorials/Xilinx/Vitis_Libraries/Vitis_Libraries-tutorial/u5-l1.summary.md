本讲以 dsp 库 vss_fft_ifft_1d 示例（PL+AIE 混合系统）贯穿，讲清 L2 层如何用 v++ 三段流水线把 C++ 内核组装成可上板系统。三段为：v++ -c（编译）逐个内核 C++→XO，PL 内核得 .xo、AIE 图（带 --mode aie）得 libadf.a；v++ -l（链接）按 system.cfg 拓扑拼成硬件容器，Versal/AIE 产出 .xsa、纯 PL 直接 .xclbin；v++ --package/-p（打包）把 xsa 封成 xclbin，嵌入式平台另生成整张 SD 卡。system.cfg 是链接阶段灵魂，用 nk（内核实例化）、sp（存储端口绑 DDR/HBM bank，即主机 group_id 源头）、sc（AXI Stream 流连接）描述系统拓扑。三种 target 保真度递增：sw_emu（2025.1 起移除）、hw_emu（开发迭代默认）、hw（上板交付），三段 -t 必须一致。
