本讲建立对 Vitis_Libraries 项目的全局认知。Vitis 加速库是 AMD Vitis 平台开源、性能已优化的加速库集合，主打「极少甚至零代码改动即获硬件加速」，支持 C/C++/Python/Matlab，可部署到边缘、本地或云端。仓库为单体多库（monorepo），含 9 个活跃库（utils、data_mover、dsp、solver、blas、vision、security、motor_control、ultrasound）；自 2025.2 起 7 个旧库（codec 等）被废弃，但仅限 PL 路线，AIE 库不受影响。库间依赖由 dependency.json 描述，主干链为 utils ← data_mover ← dsp ← solver，utils 是多数库的根依赖。加速分两条路线：PL（可编程逻辑，即 FPGA，经 HLS 高层综合）跑在 Alveo 与 Zynq 上；AIE（AI Engine）跑在 Versal（VCK190/VEK280/VEK385）上，用 ADF 图编程，AIE-ML 为其机器学习增强变体；同一功能（如 FFT）可同时有两条路线的实现。Alveo 旧平台 U200/U250/U280 不再支持，改用 U50/U50LV/U55C，platform_map.json 维护 Versal 平台逻辑名到 .xpfm 的映射。
