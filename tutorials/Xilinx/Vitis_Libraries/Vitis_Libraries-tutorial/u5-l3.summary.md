本讲介绍 Vitis 加速库 L3（Level 3）抽象：把视角从单内核抬升到完整应用。核心结论是 L3 把多个内核（或 L1 算子函数）缝合成端到端流水线，让中间数据在片上以 `xf::cv::Mat` 形式直连流动，把「多次 DDR 往返」压成「一次进、一次出」。讲义区分两种组合范式：硬件内 DATAFLOW 拼接（vision 代表，多算子写进同一 `extern "C"` 顶层函数、综合成单内核，主机只 `enqueueTask` 一次）与主机侧软件 API 编排（blas 代表，用 `xfblasCreate/Gemm/GetMatrix` 封装内核与缓冲细节）。关键术语包括 L3 流水线、`#pragma HLS DATAFLOW`、片上 Mat 直连、`description.json` 的 `flow=system` 与 `containers` 声明。另介绍 benchmarks 评测目录（统一输入数据 + 多平台对照 + 吞吐延迟对比，与 tests 验证对错互补），并指出 DATAFLOW 稳态吞吐由最慢 stage 决定。
