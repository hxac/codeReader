本讲义讲解 Vitis `blas` 库的三级抽象与 GEMM 跨层实现。核心是 README 定义的「module / kernel / software-API」三级抽象，恰好映射到 Vitis 工程 L1/L2/L3 目录，须与按运算对象划分的 BLAS 数学 Level 1/2/3（向量/矩阵–向量/矩阵–矩阵）相区分。GEMM（C←αAB+βC）跨多层提供：L1 模块级以脉动阵列 `SystolicArray` 为计算核，用 `DATAFLOW` 把 `gemm`、`gemmBufferC`、`scal`、`axpy` 串成任务级流水，体现原语互相复用；L3 软件 API 级提供形似 cuBLAS 的 `xfblasCreate`/`xfblasGemm` 等，采用指令式模型——`xfblasGemm` 经 `addGEMMOp` 把主机指针翻译成页偏移指令入队而非即时执行，且仅支持 C=AB（OP_N/OP_N、α=β=1）。关键术语包括模块级 `Gemm`/`SystolicArray`、WideType 打包与 `t_ParEntries` 并行度、指令队列、`GemmArgs`、状态码 `xfblasStatus_t`、引擎 `xfblasEngine_t`。L1 测试由 `run_test.py` 测试总线配合 `Makefile`、`blas_gen.mk` 三件套，按 profile 笛卡尔积批量生成（`blas_gen_bin` 生成器）与运行，写 `statistics.rpt` 并用 exit code 判定 CI。
