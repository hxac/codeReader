本讲给出理解整个 Vitis_Libraries 仓库的两条心智主线：L1/L2/L3 三层抽象与 PL/AIE 两种加速范式。

L1 是可复用算法原语（一个 HLS C++ 函数，做功能与资源验证），L2 把原语包成可上板内核并配主机程序（OpenCL/XRT）产出 xclbin，L3 把多个内核串成端到端流水线应用。三层是基础递进关系，但并非每个库都齐全，如 dsp 目前仅交付 L1/L2，而 blas、vision 三层齐全。

PL（可编程逻辑）走 HLS→RTL，跑在 Alveo 数据中心卡与 Zynq 上，极致可定制但开发慢；AIE（AI Engine）走 ADF 数据流图，由编译器映射到 Versal 的 AI Engine 阵列，数据流友好、编译快。两者常混合为 PL+AIE：PL 的 mm2s/s2mm 搬数据、AIE 图做计算。同一功能（如 FFT）可能同时有 PL 与 AIE 两套实现，选型取决于目标硬件。

构建流程分两套：L1 走 HLS 五阶段大写 TARGET（csim→csynth→cosim→vivado_syn→vivado_impl，保真度与代价逐级递增）；L2/L3 走 Vitis 三档小写 target（sw_emu→hw_emu→hw），AIE 路线另含 x86 与 SystemC 两段专属仿真。本讲引入的关键术语包括 HLS、XRT、xclbin、ADF 图、kernel、stream 与 AIE-ML，并强调大写 TARGET 与小写 target 分属两套流程、极易混淆。
