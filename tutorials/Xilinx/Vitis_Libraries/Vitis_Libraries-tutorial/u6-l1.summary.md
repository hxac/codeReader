本讲以 dsp 库 L1 的 HLS FFT 为切入点，拆解真实加速库内核的用法与测试方式，覆盖两个独立库：一维 `vitis_fft` 与二维 `vitis_2dfft`，各自含 fixed/float 双路线，全部为 header-only 模板。对外 API 是 `xf::dsp::fft::fft<参数结构体>(in[R], out[R])`，配置采用「继承 `ssr_fft_default_params`、覆盖若干静态常量」的通用命名参数模式，默认 N=1024、R=4、自然序、正变换。核心概念 SSR（Super Sample Rate，超采样率）指每周期并行吞吐 R 个样本，理论吞吐为 R×f_clk，代价是输入须按 `inData[j][i]=x[iR+j]` 重排成 R 条流并消耗约 R 倍面积；R 与 N 均被断言为 2 的幂。内部主链为 `fft()`→`FFTWrapper`→递归 `FFTStageClassS2S`（级间 dataflow）→`fftStageKernelS2S`（II=1 蝶形）。二维 FFT 即行方向加列方向两次一维 FFT，对外 `fft2d` 用宽流（memWidth）接口与行/列两套参数结构体。L1 用例遵循「目录即用例 + 大写 TARGET」，用 `make run TARGET=csim` 跑软件仿真，因定点/浮点非 bit 精确，PASS/FAIL 由 SNR 与误差样本比例两道阈值判定。本讲承接 u3-l2 的 pipeline/unroll/dataflow 心智模型，为下一讲 u6-l2 转入 AIE 路线 FFT 做铺垫。
