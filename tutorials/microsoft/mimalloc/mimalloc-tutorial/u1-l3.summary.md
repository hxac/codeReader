本讲是 mimalloc 的代码地图课，不涉算法细节。仓库分四块：include/（公共 API 与内部头文件，全部核心结构体集中定义于 types.h）、src/（实现本体，prim/ 为 OS 抽象层）、test/（测试兼官方示例）。核心结论：分配主链路按文件漏斗下沉——alloc.c 做入口与快路径（从当前页 free list 弹块），失败转 page.c 做慢路径与页管理，底层内存由 arena.c 以原子位图批发；释放走 free.c，经 page map 把指针反查成所属页，再按本线程/跨线程分流。本讲引入的术语：翻译单元合并（alloc.c 等直接 include 其他 .c，使快路径完全内联）、所有权链 heap→theap→页队列→page→block、页内三条 free list 及其不变式、mi_memid_t 记录内存产地、prim 层以「prim.h 接口＋平台子目录实现＋选择器」隔离平台差异，移植新平台只需实现 prim 层。
