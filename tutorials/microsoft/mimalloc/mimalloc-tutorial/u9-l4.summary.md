本讲讲 mimalloc 的堆遍历机制，覆盖四个模块：遍历 API 合同（`mi_heap_visit_blocks` 的两级回调——先以 `block==NULL` 报告区域、再逐存活块回调，返回 false 即短路终止；`mi_heap_area_t` 七字段）；堆级页发现（实现在 arena.c 而非 theap.c，沿 heap 在各 arena 的 `pages` 注册位图枚举，chunkmap 跳空、O(页数)、按地址序）；单页块枚举（无每块元数据下先 `_mi_page_free_collect(force)` 收割三条 free list 合一，再用栈上 free 位图 + `mi_ctz` + 魔数快速除法推导存活块，满页/单例页走快速路径，遍历有副作用即「观测即改变」）；abandoned 页可见性与 GC 集成（遗弃不清登记位故 heap 级遍历默认包含 abandoned 页，旧 theap 级遍历则看不见，v1/v2 的 visit_abandoned 选项已无读取者；`mi_subproc_visit_heaps` 支持全分配域扫描，遍历假定独占堆/停世界，服务于 GC、泄漏检测与堆快照）。
