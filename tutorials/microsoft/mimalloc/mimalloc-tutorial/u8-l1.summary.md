本讲义拆解 mimalloc 的无锁基础设施，覆盖三个模块：bits.h（指针宽度探测、架构识别、mi_ctz/mi_bsf 等位扫描原语的「内建→intrinsic→纯 C」多级分发）；atomic.h 的宏拼接机制（mi_atomic(name) 一套名字映射到 C11 stdatomic、C++ std::atomic 与 MSVC Interlocked 三个后端，原子类型只用 uintptr_t 与指针两种）；以及锁与一次性原语。核心结论：内存序编码进函数名，全库只用 relaxed/acquire/release/acq_rel 四种，无 seq_cst；thread_free 用 CAS weak acq_rel（失败序 acquire 供重试），page map 与 arena_pages 用「relaxed 快查 + acquire 复查 + release 发布」双检模式，锁内与纯计数敢用 relaxed。mi_lock_t 本质是 OS 互斥体（SRWLOCK/pthread_mutex/std::mutex），兜底为 CAS 自旋加有界 yield，无指数退避；mi_atomic_guard 抢不到即跳过（唯一实例 arena purge）；mi_atomic_do_once 以 tid 哨兵实现每调用点一次性。可用 MI_DEBUG_TSAN 验证无数据竞争。u8-l2 的 free list 分片与 u8-l3 的原子位图均建立在本层原语之上。
