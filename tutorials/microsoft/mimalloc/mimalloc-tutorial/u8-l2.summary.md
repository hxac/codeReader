本讲综合已学机制，阐明 mimalloc 两大核心创新：free list sharding（每个 mimalloc 页一条独立 free list，而非每个 size class 一条全局链）与 free list multi-sharding（每页再分出属主的 free/local_free 与跨线程的 xthread_free 多条链）。核心结论：分片不消除 CAS，而是消除 CAS 之间的碰撞——属主分配与本地释放零原子操作，跨线程 free 仅一次落在页私有字段上的 CAS（低位兼作所有权位），收割以整链交换按 1/k 摊销；碰撞概率约 1/P，竞争被自然稀释到全堆（跳表类比），故无内部竞争点。第一层分片还带来地址连续的局部性与页可达全空。xmalloc-testN、sh8bench、larsonN 兑现并发交接优势，leanN、sh6bench 兑现局部性收益。
