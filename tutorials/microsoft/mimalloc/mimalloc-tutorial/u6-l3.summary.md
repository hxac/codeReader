本讲覆盖 src/arena.c 与 src/bitmap.h/c。核心结论：arena 是 mimalloc 从 OS 批发、全进程共享的内存区，再以 slice 为单位零售——slice 64KiB（位图 1 bit）、bchunk 32MiB、单 arena 32MiB–16GiB、默认保留增量 1GiB 并指数扩张、进程上限 160 个。mi_arena_t 挂 free/committed/dirty/purge 四张位图，元数据自举于开头的 info slices。约定 free 位图 set 表空闲，分配即一次原子找连续 1 并清零（mi_bbitmap_try_find_and_clearN），查找与占有合一，故无锁、免 ABA，失败则回滚；归还先调度 purge 再置回 1。位图分 bfield/bchunk/chunkmap 三层，chunkmap 是保守近似（只许多报不漏报）；slices_free 用分箱位图 bbitmap，chunk 按 SMALL/MEDIUM/LARGE/HUGE 尺寸箱标记，仅搜目标箱与全空箱以抑制碎片。关键术语：slice、bchunk、尺寸箱、独占 arena（mi_reserve_os_memory_ex、mi_heap_new_in_arena、mi_arena_contains）、memid 产地证。
