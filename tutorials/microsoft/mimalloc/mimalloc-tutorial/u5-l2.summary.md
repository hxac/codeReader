本讲分析 mimalloc 跨线程释放路径（src/free.c 的 `mi_free_block_mt` 与 src/page.c 的收割实现）。核心结论：当释放者不是页属主时，经 xtid 异或判定进入 `mi_free_block_mt`，它以 Treiber 栈 push 方式——先写块内 next，再一次 `mi_atomic_cas_weak_acq_rel` 把块头插进页的原子字段 `xthread_free`，全程无锁、不碰 `used`/`local_free` 等非原子字段；push 加收割端整链交换使其天然免 ABA，`used` 计数兜底防页被并发释放。`xthread_free` 最低位是所有权位，一次 CAS 可顺手认领被遗弃页，随后 `mi_free_try_collect_mt` 依次尝试释放、reclaim、reabandon-to-mapped，否则归还无主。账目由收割修正（alive = used − |thread_free|）：属主在分配慢路径等时机原子抢整链、数块销账、挂到 `local_free`，一次收割摊平 N 次跨线程 free。free list 多碎片化把争用打散到每页一个点，故跨线程 free 仅贵一次 CAS。
