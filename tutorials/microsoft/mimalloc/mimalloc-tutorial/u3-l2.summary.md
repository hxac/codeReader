本讲深入剖析 `mi_page_t`：mimalloc 页是只装一种 size class 块的定长容器，空闲块头 8 字节复用为 `next` 指针（`mi_block_t` 侵入式链表），块地址由页起点加序号乘块长纯算术得出。核心是三条 free list 的分工：`free` 供 malloc 快路径弹出；`local_free` 暂存本线程释放，使「free 耗尽」成为确定性事件以支撑单调心跳（延迟回收回调）；`xthread_free` 用一次 CAS 头插暂存跨线程释放且不改动 `used`，令拥有线程分配完全零原子操作。块单向迁移：CAS 收割入 `local_free`，再 O(1) 头搬回 `free`。计数不变式：`used ≤ capacity ≤ reserved`，`capacity = used + |free| + |local_free|`，`alive = used − |thread_free|`；由此导出页状态判定（满页即 `reserved==used`），`capacity` 由 extend 每次约 8KiB 分批初始化，`used==0` 触发 retire（约 16 个管理周期后才真正释放）。位编码技巧：`xthread_id` 低 2 位存页标志，配合一次 XOR 把 free 分流到本地/跨线程四条路径；`xthread_free` 最低 1 位是所有权位，跨线程释放可一次 CAS 同时推块入链并认领无主页。结论：断言与宏是契约，注释可能滞后。
