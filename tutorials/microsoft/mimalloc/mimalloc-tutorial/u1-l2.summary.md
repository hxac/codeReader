本讲义讲 mimalloc 的构建。cmake 一次配置默认产出四类目标：共享库、静态库、单目标文件与测试程序；构建目录名以 debug、secure 等结尾可自动推断构建类型与安全模式，非 release 构建还会把类型追加进库名（如 libmimalloc-debug.so）。构建开关遵循「cmake 选项→C 宏→源码 #if 分支」链路：MI_OVERRIDE 默认开启以导出 malloc/free 同名符号，MI_SECURE 分 ON/FULL 两级缓解，MI_DEBUG 三级断言在 release 中削为空宏、零开销，并联动 MI_GUARDED 守卫页采样。src/static.c 把全库叠入单一翻译单元生成 mimalloc.o，置于链接命令最前即最可靠的静态覆盖，因目标文件符号优先于库文件。test 目录是安装后的官方示例工程，演示四种链接与覆盖方式，main.c 引出一等堆等 mi_ API 用法。
