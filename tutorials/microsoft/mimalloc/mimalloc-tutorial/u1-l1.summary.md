本讲只读 readme 与 release notes，不涉源码。核心结论：mimalloc 是约 1 万行 C 的通用分配器，出身 Koka/Lean 运行时，是 malloc 的 drop-in 替代，LD_PRELOAD 即可零改动接入。其灵魂是两层分片：free list sharding 使每个 mimalloc page（约 64KiB、单一 size class）各持一条独立链表，局部性升、碎片降、页更易整体变空；multi-sharding 再在页内分出本地 free 与跨线程 thread_free 链表，跨线程释放退化为一次 CAS。本讲引入并供后续承接的术语：分配器、free list、size class、mimalloc page、CAS、虚拟内存 reserve/commit/purge，以及五大支柱 eager page purging、secure、first-class heaps、bounded、fast。版本谱系上 v1/v2/v3 并行维护，差异主要在 OS 内存管理方式，本手册基于 v3。
