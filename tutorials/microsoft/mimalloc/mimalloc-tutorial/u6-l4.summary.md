本讲主讲 mimalloc 的遗弃（abandon）与认领（reclaim）机制，涉及 arena.c、free.c、page.c、theap.c。线程退出或页面填满时，含活块的页不释放内存，而是把 xthread_id 置为 0（遗弃）或 4（abandoned-mapped，已登记可检索），并放弃 xthread_free 的所有权位，slice 原地保留；非满 arena 页按 size class 登记进 pages_abandoned 位图（heap 级 abandoned_count 做零成本预判），满页不进位图、以块指针为索引。认领有两条路径：分配慢路径先查位图（reclaima）；跨线程 free 一次 CAS 同时挂块与夺权，再择一执行释放、收编、重登记或放权（reclaimf），碰撞时由位图忙等化解（waits）。另有两条延时回收：retire 让全空页滞留数个管理节拍防抖，purge 延迟 decommit 已归还的 slice。page_reclaim_on_free 等选项控制认领激进度，默认保守，跨线程复用主要靠分配时认领。
