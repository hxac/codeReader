本讲建立 mimalloc v3 的对象地图：五层所有权为 subproc（根，持有 arena 与 heaps 链）→ heap（一等堆，跨线程身份与页登记账本）→ theap（v3 新增的线程本地堆，真正拥有页并服务分配）→ page queue（theap 内按 bin 组织页的队列数组）→ page（只装一种 size class）→ block（用户指针本体，空闲时复用作 free list）。v3 拆出 theap 使任意线程能在同一 heap 上无锁分配，_Atomic 字段分布即共享层与线程私有层的分界。mi_memid_t 是各结构记录自身内存来源的「产地证」，arena 分支含 slice 区间，供释放时归还。首次 mi_malloc 时 TLS 默认指向静态空 theap，快路径自然落空进入 generic 慢路径，触发主堆静态自举与本线程 tld/theap 创建，再向 arena 领 slice 建页切块；释放由指针经 page map 反查 page->heap，全程不查 TLS。
