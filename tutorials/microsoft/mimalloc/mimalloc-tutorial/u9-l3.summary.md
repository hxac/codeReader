本讲剖析 mimalloc 统计系统（mimalloc-stats.h 与 src/stats.c）。核心结构 `mi_stat_count_t` 分 total/peak/current 三列，字段清单集中在 `MI_STAT_FIELDS()` 宏，用 X-macro 技法在结构体定义、合并、打印、JSON 四处展开；结构体头部 size/version 双哨兵构成 ABI 护栏。更新原语分 `_mt`（原子，写共享账本）与非 `_mt`（普通写，写线程私有账本）两套，adjust 用于修正重复计数，跨线程合并时 peak 只能近似。账本分 theap→heap→subproc 三层，合并是「搬运即清零源」的破坏式，取数因此有副作用，且进程统计不等于各堆之和（OS/arena 底账直记 subproc、元数据堆被刻意隐藏）。取数 API 分 theap/heap/subproc 聚合/独占四档粒度；`MIMALLOC_SHOW_STATS` 输出 blocks/pages/arenas/process 四段报表，行尾 not all freed 暴露泄漏；MI_STAT 编译级别决定埋点是否存在；`mi_stats_get_json` 导出带 stat_version 的 JSON，可作 CI 内存回归基线。
