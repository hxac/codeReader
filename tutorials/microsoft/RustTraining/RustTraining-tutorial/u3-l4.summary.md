本讲按 async-book 三段式拆解异步 Rust，覆盖四个模块：Future/poll 契约、Pin 与 Unpin、执行器与运行时生态、生产模式与陷阱，并以 capstone 多房间聊天服务器收束。核心结论：Future 惰性、poll 绝不阻塞，返回 Pending 前必须登记 Waker 并复查条件（查→存 Waker→再查），忘记 wake 则程序静默挂起；async fn 会被编译为可能自引用的状态机，Pin 在类型层禁止移动，Unpin 是多数类型的逃生舱；执行器即「有人 wake 就 poll、否则睡觉」的循环，属协作式调度，tokio::spawn 要求 Send + 'static。生产五大陷阱：阻塞执行器（用 spawn_blocking 修）、跨 await 持 std 锁、取消即 Drop、无 async Drop、select！ 饥饿与假并发（连续 await 实为顺序执行）；两大模式：watch 通道优雅关停、有界通道背压；调试测试用 tokio-console 与 #[tokio::test]。
