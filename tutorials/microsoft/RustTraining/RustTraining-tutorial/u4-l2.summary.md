本讲围绕 Docker 自托管部署路线展开，覆盖四个模块：多阶段构建、预编译回退策略、两层构建缓存、CI 冒烟测试。核心结论：builder 阶段安装 Rust 工具链并执行与本地相同的 xtask build；runtime 阶段以非特权 nginx 镜像仅通过 COPY --from 取走 site/ 静态产物，最终镜像不含 Rust、mdbook 与书源。引入的关键术语与概念：多阶段构建、构建上下文（必须为仓库根）、镜像层缓存、BuildKit、TARGETARCH 与目标三元组、构建期断言、RUN --mount=type=cache 缓存挂载（不进镜像层）、CI 侧 type=gha 层缓存（mode=max 存中间层）、build-only 策略、冒烟测试、try_files。工具安装优先下载预编译二进制、404 时回退 cargo install --locked 源码编译；CI 流水线只构建不发布，用路径过滤触发，curl 断言守护 nginx 就绪、落地页 title、async-book 可达（堵住 build_to 缺书仍退出 0 的盲区）及无扩展名链接解析（对齐 Pages 行为），盲区为其余六本书缺失与页面内容正确性。
