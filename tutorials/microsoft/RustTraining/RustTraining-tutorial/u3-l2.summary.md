本讲以 async-book 的 ch02 为标本，从 u3-l1 的宏观体系深入到单章内部，拆解仓库书籍统一的写作范式：标题难度 emoji（🟢🟡🔴）→ What you'll learn 目标框 → 正文（Mermaid 图 + 自包含 Rust 代码块）→ Key Takeaways 收束，该范式精确覆盖全部 15 个内容章。核心结论：目标框用 blockquote 充当读者与作者的学习契约，与章末 Key Takeaways 首尾呼应；Mermaid 是两阶段渲染，构建期 mdbook-mermaid 预处理器改写代码块，浏览器期 JS 把文本编译为 SVG 并适配明暗主题；Rust 代码块分三档，普通 rust 块带 playground 运行与编辑按钮、无 fn main 时自动注入隐藏 main 包装，rust,ignore 仅着色不可运行，写作黄金规则是示例自包含；练习用 details 元素折叠答案，章内练习嵌套两层（题目、解答分别折叠），独立练习章 ch15 单层只折解答。全部要素由 book.toml 三处配置支撑，作者只写 Markdown，本讲为 u4-l5 的真实贡献做铺垫。
