本讲以 async-book 为标本，解剖一本书的 book.toml 配置层与 SUMMARY.md 结构层。核心结论：七本书共用同一套配置模板，仅 title 不同；单书构建的 build-dir 输出在批量构建时会被 xtask 传入的 --dest-dir 覆盖。引入的关键术语：书根目录——additional-js 路径相对书根解析，mermaid 的两个 JS 资产就放在书根；预处理器与渲染器——mdbook-mermaid 在构建期改写 mermaid 代码块，浏览器期再由 JS 绘成 SVG，缺它则构建直接失败；playground——editable 与 line-numbers 是全局开关，无 fn main 的片段会被注入隐藏的 main 包装，ignore 注解可按块排除。SUMMARY.md 语法要素：前缀章不编号、Part 分部标题不可点击、编号章跨 Part 连续（1–17 对应 ch01–ch17）、分隔线与草稿章。引言章手写目录与 SUMMARY.md 构成双源、已现漂移。工作流是 mdbook serve 下的「修改→观察→还原」循环。
