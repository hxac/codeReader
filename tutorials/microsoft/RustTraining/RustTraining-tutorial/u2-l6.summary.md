本讲接续 u2-l5，精读 xtask 内置静态服务器 `cmd_serve` 的后半程，覆盖三个模块。`guess_mime` 用 `extension().and_then(to_str)` 的 `Option` 流水线加 `match` 查表，把文件扩展名映射为零分配的 `&'static str` 作为 `Content-Type`（即 MIME 类型）；未知或非 UTF-8 扩展名一律兜底 `application/octet-stream`，宁可触发下载也不错标类型。三条响应路径不借任何 HTTP 库，用 `format!` 手拼 HTTP/1.1 报文，骨架为状态行、CRLF 头部、空行加正文：200 携带 `Content-Type` 与文件字节长度，301 仅 `Location` 头（目录补尾斜杠重定向），404 返回 13 字节字面量；写错误被吞掉，HTTP 方法也被完全忽略，均为"本地预览够用"的刻意简化。`ctrlc_exit` 借 xtask 唯一外部依赖 `ctrlc` crate 注册 Ctrl+C（SIGINT）处理器，闭包内 `std::process::exit(0)`，使阻塞于 accept 的进程以退出码 0 干净退出。本讲引入的关键术语：MIME/Content-Type、Content-Length、CRLF、SIGINT、`&'static str`、TOCTOU 竞态。
