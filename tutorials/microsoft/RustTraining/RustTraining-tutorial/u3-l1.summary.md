本讲是内容层首讲，从目录层解析七本书的组织体系。核心结论一：五级分类（Bridge/Deep Dive/Advanced/Expert/Practices）呈「三个平行入口 + 四个专项深化」——三本桥梁书按语言背景三选一，后四本（异步、模式、类型驱动、工程实践）按方向选读，共同前置是先走完一座桥；分类由 README 两张表与 xtask 的 BOOKS category 字段以「一义三源」方式维护，人读侧与机器侧已出现漂移。结论二：Part 分部是教学阶段划分而非排版分组，有三种策略——async-book 认知递进式、须线性整读，engineering-book 工作流式、章章独立可跳读，桥梁书按难度断层切分。三本桥梁书共享几乎同名的 14 章主线，Part 边界切在读者认知断层处（python-book 自第 7 章所有权切入）；章节序号与导航完全由 SUMMARY 条目顺序决定，与文件名无关。关键术语：桥梁书、深潜书、一义三源、配速表、Part 分部。
