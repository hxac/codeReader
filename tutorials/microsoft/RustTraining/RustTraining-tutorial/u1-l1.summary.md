本讲给出仓库全景：RustTraining 是文档工程——主体是七本 mdBook 培训书，唯一的 Rust 代码是构建工具 xtask（根 Cargo workspace 仅此一个成员），部署走 GitHub Pages 与 Docker。核心结论：七本书构成五级难度体系，三本 Bridge 书按 C/C++、C#、Python 背景分流入门，Deep Dive、Advanced、Expert、Practices 分别覆盖异步、模式、类型驱动正确性与工程实践；书籍元数据双源维护——README 表格供人读，xtask 的 BOOKS 常量（slug、title、description、category 四元组，slug 即磁盘目录名）供机器用，二者语义一致但存在字面差异，新增书须两处同步。许可证双轨：代码 MIT，文档 CC-BY-4.0（复用须署名），微软商标不在授权内，贡献需签 CLA。本讲引入的关键术语：mdBook、Cargo workspace、xtask 模式、BOOKS 注册表、五级分类。
