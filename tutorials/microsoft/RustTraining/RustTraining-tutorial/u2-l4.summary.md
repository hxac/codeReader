本讲拆开 u2-l3 留下的黑盒 `write_landing_page`，源码集中在 xtask/src/main.rs。核心模块有三：一是 `BOOKS` 常量，四元组 (slug, title, description, category) 注册表作为单一数据源被两个消费者解构——构建循环只取 slug、缺目录则跳过告警，落地页四字段全用却不检查目录，死链卡片仍会生成且退出码为 0，故新增书须先建目录再注册；二是 `category_label`，用 match 加 `_ => cat` 兜底把类别 slug 译成人类标签，类别又直接拼成 CSS 类名 `cat-{cat}`，两条通路均依赖字符串精确匹配，新增类别需多处同步；三是模板拼接，iterator 链生成卡片片段再以整页 `format!` 注入 `{cards}`，零模板引擎依赖，关键技巧为花括号 `{{ }}` 转义与 `r##"…"##` 原始字符串。颜色经 CSS 变量链路（`:root` 的 `--clr-*` 绑定 `--stripe`）统一驱动卡片竖条、药丸标签与图例；卡片 href 的尾斜杠与 u2-l5 将讲的内置服务器 301 重定向相配合。
