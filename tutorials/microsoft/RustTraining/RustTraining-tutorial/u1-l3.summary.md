本讲义讲如何在本地把整个 mdBook 书库跑起来，分三个模块：一是安装工具链，构建需要 `mdbook`（静态站点生成器 SSG，读 book.toml 与 SUMMARY.md 把 Markdown 编译成 HTML）和 `mdbook-mermaid`（预处理器，因每本书配置了 `[preprocessor.mermaid]` 而必需），维护者路径用 `cargo install` 钉住版本以保证可复现，产物进 `~/.cargo/bin` 依赖 PATH 查找；二是解释 `cargo xtask` 合法性的来源——仓库 `.cargo/config.toml` 中的 `[alias]` 把它展开为 `cargo run --package xtask --`，`--` 之后的内容经 `env::args().skip(1)` 传入 main 分发，别名随仓库分发即 xtask 模式；三是 build/serve/deploy/clean 四个子命令：build 全量构建七本书加落地页到 `site/`，serve 隐含一次 build 后在 127.0.0.1:3000 起不监视文件变化的服务器（实时预览需单本书 `mdbook serve --open`），deploy 输出到 `docs/` 供 GitHub Pages 用，clean 删两目录。引入的概念有退出码（0 成功）、stdout/stderr 分流、`check_mdbook` 静默探测子进程、先删后建的干净构建与 `.nojekyll`。
