本讲聚焦主机程序唯一入口 `software/main.cpp`，是「认识项目」单元收官篇。`main()` 是线性六段骨架：`fopen` 打开 `output.dat` → 用 `#ifdef SIMULATION / #elif ICE40` 宏 `new` 出对应后端对象 → 分配 `image_input/image_input2/image_output` 三块像素数组 → 用 `HEADER_PIXEL` 宏解码 `.h` 图像 → 一次只激活一个 `test_*`（靠注释切换）→ `fprintf` 落盘后 `fclose`。图像格式为 GIMP 导出的「每 6 位编一个可打印字符」编码，4 个字符（24 位）正好解出 3 个 RGB 字节，主机只取 R 通道作单通道灰度值。所有 test 函数签名统一、通过纯虚基类 `Image_processing *` 多态指针与后端解耦，共享「三明治」套路：`send_params → send_image → switch_buffers → 发运算 → wait_end_busy → switch_buffers → read_image`。其中 `switch_buffers` 控制 input/storage 双缓冲切换，`wait_end_busy` 靠轮询状态字节 bit0 的 busy 位同步等待硬件完成。结果按 gnuplot `matrix` 格式（每行 `image_width` 个空格分隔数字）写入 `output.dat`。本讲只建立「接口调用 ↔ 硬件动作」的概念映射，字节级报文打包与硬件 FSM 细节留待后续讲义。
