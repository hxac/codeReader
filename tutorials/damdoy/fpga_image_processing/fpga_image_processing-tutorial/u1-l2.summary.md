本讲把「一个核心 HDL + 两套可替换后端」的架构落到磁盘上，给出仓库的目录地图。仓库采用三段式划分外加主机软件：`hdl/` 放唯一的与平台无关的核心模块 `image_processing.v`，它只暴露存储器接口和通信接口，被两套后端以不同方式接入（仿真用 Verilator 编成 `Vimage_processing`，硬件用 `top.v` 的 `include` 例化）；`simulation/` 是仿真后端，用 C++ 数组模拟 RAM、用 FIFO 队列模拟通信，靠 `main_loop_clk()` 手动翻转时钟驱动模型；`ice40/` 是硬件后端，内部再分 `hdl/`（FPGA 侧 Verilog，由 Makefile 经 yosys、arachne-pnr、icepack 综合并用 iceprog 烧录）和 `software/`（主机侧 C++，经 FTDI/MPSSE 收发 SPI，由 `build_ice40.sh` 编译）；`software/` 存放两套后端共用的资产。核心结论是：核心模块与两套后端被物理隔离，因为运行环境完全不同；主机程序 `main.cpp` 一份共用，仅靠 `SIMULATION`/`ICE40` 宏在 include 与 new 对象两处切换。本讲引入的关键术语包括综合（synthesis，由 yosys 把 Verilog 变成比特流）、编译（g++ 编主机可执行文件）、顶层模块 `top.v`、引脚约束 `io.pcf`、纯虚基类 `Image_processing` 与 `Commands` 枚举构成的统一契约、双后端多态切换、以及 `hdl/image_processing.v` 与 `main.cpp` 这唯二被共享的文件。
