本讲回到主机侧，讲「如何用位移+字节构造卷积核」。要点：定点核系数用 1.3.4 定点，字节值=实数×16，以 `(n)<<4` 类位移写出（`(1)<<4`=1.0、`(1)<<3`=0.5、`(1)<<2`=0.25），负数用 uint8_t 表示并由硬件符号扩展。两条设计原则：模糊核字节和=16（归一化，匀强区亮度不变），代表为高斯核 1-2-1/2-4-2/1-2-1；梯度核字节和=0（零和，匀强区响应为 0）。非显然结论：clamp=true 会把负响应钳到 0，故梯度核只响应单一极性，边缘检测须用 4 个核（上/下/左/右=2 轴×2 极性）而非 2 个 Sobel 核。多核累加靠 add_to_output：第 1 核 false 覆盖初始化 storage，后续核 true 叠加，source_input 恒 true 使源图不变。收尾统一套路 switch_buffers+read_image：结果恒写回 storage、read_image 恒读 input，须先互换地址再读回。关键术语：定点位移、归一化、梯度、极性、Sobel 算子、可分离高斯核。
