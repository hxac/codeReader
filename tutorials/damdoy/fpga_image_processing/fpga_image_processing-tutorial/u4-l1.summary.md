本讲解析 `image_processing.v` 运算 FSM 中的 `STATE_PROC_UNARY`，这是被 add、threshold、invert、mult 四种运算复用的逐像素处理状态。核心结论是：由于单端口 RAM 读延迟一拍且不能同拍读写，处理被拆成两拍流水——偶拍（`proc_memory_addr_counter[0]==0`）发起读，奇拍（`==1`）运算并写回，地址计数器最低位天然充当节拍器。每个 16 位存储字打包两个 8 位像素（高字节、低字节独立运算），一个时钟沿内并行处理双像素。写回用 `addr <= {proc_memory_addr_counter[31:1], 1'b0}` 清最低位，把写地址还原为读地址，实现 in-place 读改写，无需第二块结果缓冲。引入的关键术语包括：两拍流水、单端口 RAM 读延迟、`proc_counter_read`（每字减 2，`> 2` 终止）、`processing_command` 分派、busy 位（`~(state_processing==STATE_IDLE)`）、钳位函数 `apply_clamp` 与 `apply_clamp_fixed16`（后者取 `[11:4]` 做定点还原，细节留待 u4-l2）。
