本讲解析模块的存储器门。128KB 片上 SPRAM 经参数 MEMORY_SIZE、BUFFER_SIZE、BUFFER2_LOCATION 切成两块各 64KB 连续区间，每块恰好装一幅 256×256 单通道灰度图。两块角色由可改写基地址寄存器 buffer_input_address、buffer_storage_address 决定：发图写 input、运算在 storage、读出又从 input。COMMAND_SWITCH_BUFFERS 用两条非阻塞赋值在一个时钟沿互换两寄存器，只换标签不搬数据，是零拷贝链式运算的关键；COMMAND_PARAM 兼任初始化，把 input 设 0、storage 设 BUFFER2_LOCATION。主机逐字节送来的像素在 STATE_SEND_IMG 里两两凑对塞进 16 位字，靠 memory_addr_counter[0] 区分偶/奇，凑满两字节才置 wr_en=1，addr 末位清零得字地址。打包使整条通路按字走：写入「2 进 1」、读出「1 出 2」、运算一次处理 2 像素，吞吐翻倍，前提是图像像素数为偶。
