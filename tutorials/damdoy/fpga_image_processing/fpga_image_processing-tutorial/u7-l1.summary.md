本讲把前六单元的零件「装回一台完整的机器」，是综合实践单元的开篇。核心洞察一句话：**外壳可换，内核不变**——`image_processing.v` 模块及其逐字节相同的命令协议是**共同内核**，时钟、传输介质、存储、反压实现是**可替换外壳**（仿真用内存队列+手动时钟，硬件用 SPI+真实晶振）。

端到端通路分五层：业务（`main.cpp` 多态调用）→后端→传输→内核（双 FSM 派发与交接）→存储（RAM）。以 `send_add` 为样例，两套后端产出完全相同的 4 字节序列，内核按 `counter_read` 逐字节消费、一次性交接给运算 FSM。

通路有**三个独立握手点**：输入握手（`comm_data_in_valid`，开环，无 `comm_data_in_free`，靠主机自律）、输出握手（`comm_data_out_valid`+`comm_data_out_free`，闭环反压）、存储握手（`rd_en`+`data_read_valid`，吸收单端口 RAM 读延迟）。输入开环、输出闭环是最关键的不对称；仿真用 `counter_free` 与大循环常数做**时间型**估计，硬件用组合逻辑与 `STATUS_FPGA_RECV_MASK` 重试做**信号型/闭环**确认。回查是「拉」非「推」，靠 `COMMAND_GET_STATUS` 读 busy 位。

四项架构取舍均源于 iCE40 约束：16 位字打包 2 像素、双缓冲（零拷贝链式运算）、1.3.4 定点数（主机放大 16 倍、内核除以 16 配对还原）、单端口 RAM 两拍流水（牵动面最大，决定 unary/binary/convolution 三类状态机复杂度）。
