本讲讲解用开源 IceStorm 工具链把 iCE40 硬件后端跑起来。核心是四步流程：yosys（synth_ice40 流程）综合 Verilog 成 BLIF 网表 → arachne-pnr 布局布线 → icepack 打包成比特流 top.bin → iceprog 烧录，产物链 top.v→top.blif→top.asc→top.bin。引入关键概念：综合、布局布线（P&R）、引脚约束 io.pcf（用 set_io 把 clk、三色 LED、SPI 四线锁定到 iCE40UP5K 的 SG48 物理引脚）。综合入口是 top.v，它以 include 纳入核心模块 image_processing.v。烧录分两种：make prog 写易失 SRAM（掉电丢失），make prog_flash 写 FLASH（持久）。主机软件 soft_ice40 由 build_ice40.sh 编译，用 -DICE40 宏选后端（与仿真模式的 -DSIMULATION 对称），用 -lftdi 链接 FTDI 库经 USB↔SPI 与 FPGA 通信。本讲只解决构建运行链路，top.v 内部连线、SPI 从机协议、主机命令封装留给后续讲义。
