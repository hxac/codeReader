本讲把 `image_processing` 模块当黑盒，理清其 14 个端口，分三类：时钟复位（clk、reset）、存储器接口（6 根线）、通信接口（6 根线），对外只有「存储」「通信」两扇门。核心是「只认接口、不认实现」：模块不含 RAM，存储器由仿真后端（C++ 数组）或硬件后端（4 片 SPRAM）提供，故能在两套后端复用。存储字宽 16 位、每字装 2 个像素，字节粒度地址用 `addr[0]` 区分字内高低字节。通信是模块与主机唯一通道：输入靠 `comm_data_in_valid` 握手，输出靠 `comm_data_out_valid` 加 `comm_data_out_free` 反压握手；两个握手均由对端置位（`data_read_valid` 由存储器端，硬件中用流水线对齐 SPRAM 读延迟；`comm_data_out_free` 由主机/通信端）。`clk` 是唯一同步时钟，`reset` 虽声明却未被使用，初始化全靠 `initial begin`（FPGA 上电与 Verilator 构造时各执行一次）。
