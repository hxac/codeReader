本项目是一个用 Verilog 在低端 iCE40 UltraPlus FPGA 上做单通道灰度图像处理的系统，其所有设计取舍都源于一个核心约束——资源受限（功耗低、价格低、片上内存仅 1Mbit）。由此衍生出定点数代替浮点、单口 RAM 分两拍、两像素打包进一个 16 位存储字等节流做法。

架构上采用「一个核心 HDL 模块 + 两套可替换后端」：核心模块 `image_processing.v` 只认「命令 + 数据」，不绑定通信方式；仿真后端用 Verilator 把 Verilog 编成 C++，硬件后端经 SPI 与真实芯片通信。两套后端由编译宏在 `main.cpp` 中切换，并通过纯虚基类 `Image_processing` 形成统一契约，使主机业务逻辑与底层彻底解耦（多态调用）。

引入的关键术语包括：FPGA、iCE40、Verilog/HDL、Verilator（仿真）、yosys（综合比特流）、抽象接口与双后端、8 位定点数（1 位符号 + 3 位整数 + 4 位小数）。

支持的图像操作分三大类——逐像素运算（unary）、双图运算（binary，含取绝对差）、3×3 卷积，外加缓冲管理与状态查询；硬件侧由「操作码 + 变长参数」的命令触发。

存储采用双缓冲（input / storage）模型：图像从 input 进出、在 storage 运算、结果写回 storage，两缓冲地址相邻且可经一条命令零成本互换（仅交换地址寄存器，不搬数据）。这些概念将在后续讲义逐层展开。
