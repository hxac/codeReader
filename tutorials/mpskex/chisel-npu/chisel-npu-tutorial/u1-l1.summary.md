本讲是整本手册的入口，建立对 chisel-npu 的全局认识：它是用 Chisel 6.7.0（Scala 2.13.12）实现的开源 NPU RTL 设计，面向低功耗边缘 SoC，配套 FPGA 验证平台与 Linux/Python 驱动。工具链 firtool/Verilator/SystemC/Vivado 统一封装于 Docker，链路为「Chisel 写 RTL → firtool elaborate 成 top.sv → Verilator/SystemC 仿真 → Vivado 综合上 Kintex-7」。三大核心组件为 MMALU（K×K 脉动矩阵引擎）、VALU（K 通道向量 ALU）、多宽度寄存器堆。引入并钉死三个全局参数：N(bits)=8 基础通道位宽、L=32 个 VX 寄存器（须被 4 整除）、K 为 SIMD 通道数且在 backend 边界 K==mmalu.n；并引入 VX/VE/VR 三类寄存器共享同一块物理存储（L×K×N/8，默认 256 字节）的别名视角。给出 NCoreBackend 数据流：Frontend → InstrDecoder（输出 DecodedMicroOp）→（RegisterFile、MMALU、VALU）；MMALU 流水线长 3K-2 拍、INT32 结果直写 VR 不截断，可与 1~2 拍的 VALU 重叠执行。需注意完整 backend 定义在 SimpleBackend.scala，根目录 top.sv 当前仅 elaborate 出 MMALU。
