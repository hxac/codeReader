本讲讲解 Xilinx XDMA 内核驱动 `xdma.ko` 及配套 C 工具，确立主机到 NPU 硬件的软件接口契约。三个最小模块：其一，`xdma.ko` 在 `/dev/xdma0_*` 下创建三类字符设备节点——`_h2c_*`（主机写出口）、`_c2h_*`（主机读入口）、`_bypass`/`_user`（AXI-Lite 控制 BAR 窗口）。其二，两条本质不同的访问路径：`reg_rw` 经 `mmap` 加指针解引用做单字 MMIO 寄存器读写；`dma_to_device`/`dma_from_device` 经 `write`/`read` 加 `lseek` 触发 SGDMA 批量搬运，且文件偏移即 AXI 地址。其三，`ctrl_lite` 三比特控制协议（`start` 写、`done`/`busy` 读，`done` 被锁存故轮询稳健）。kick 之后 `npu_dma_master` 自主完成读 A/B/ACCUM、喂 MMALU、等 `io_clct`、写 OUT，staging 地址表固定在 `0x4000_0000/0100/0200/0400`。一次完整 MMALU 计算的 C 工具序列为：三条 `dma_to_device` 暂存、一条 `reg_rw` kick、轮询 `done`、一条 `dma_from_device` 回读 OUT。vendor 工具通用，NPU 特有契约活在 RTL，主机侧编排交由 Python 驱动或 SSH 测试框架承担。
