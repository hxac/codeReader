本讲介绍 chisel-npu 的官方 FPGA 验证平台——Kintex-7 `xc7k480t`。核心内容为四块：其一是**平台拓扑**，数据通路为主机 PCIe → XDMA IP（转 128 位 AXI4）→ 各级 AXI 桥（时钟转换 clkconv / 位宽转换 dwidth / 交叉开关 xbar）→ MIG → 双片 DDR3，V10 用单一 `npu_subsys`（`ctrl_lite` + `npu_dma_master` + MMALU）挂入统一的 4 GB 地址空间，主机仅靠「写数据到 DDR3 + 向 `ctrl_lite` 写 start 位」即可让 DMA master 自主完成搬运-计算-回写，这正是后续 u8-l2/u8-l3 驱动对接的接口。其二是**时钟域**：125 MHz `axi_aclk`（PCIe）、200 MHz `fabric_aclk`（MMCM 倍频，MMALU 计算域）、133 MHz MIG `ui_clk`（DDR3），250 MHz PCIe PHY 时钟以 `set_false_path` 豁免。其三是**时序收敛**：K 从 16 放大到 32 引发 22608 个违例端点，经 DataFeeder 逐 lane 重构（扇出 1025→2）、降频至 200 MHz、MMALU 内插流水寄存器三层手段闭合到 0 违例；其中 WNS=−0.151 ns 的 `reg_h`→13 级逻辑→PE 乘加链违例由 `pipe_a/pipe_b/pipe_ctrl` 切断，代价是脉动阵列延迟由 3n−2 变为 3n−1。其四是**构建流程**：`make build-fpga` 走宿主机 Vivado 批处理，量产用 `build_npu.tcl`、调试带 ILA 用 `build_npu_with_ila.tcl`，产物为 `top_npu.bit`。关键术语 AXI/XDMA/MIG/CDC/WNS/MCP 供后续讲义承接。诚实边界：V10 仅验证 MMALU 单射语义，K=64 因超容量不可用，上板 K=32。
