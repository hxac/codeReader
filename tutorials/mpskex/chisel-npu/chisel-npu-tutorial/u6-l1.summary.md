本讲讲解 `NCoreBackend` 作为 NPU 中央执行单元如何把译码器、多宽度寄存器堆、MMALU、VALU 四个子模块连线总装。核心结论有三：一是参数对齐约束（MMALU 的 `n/nbits/accum_nbits` 须等于 `K/N/4N`）靠把 K/N/4N 当作构造实参传入保证，比运行期 `require` 更强；唯一 `require` 仅查 `L%4==0`。二是寄存器堆端口为稀缺资源，按端口分配表分配：VX 读 port 0 喂 MMALU in_a，port 1/2 喂 VALU，port 3 与外部读、MMALU in_b 分时复用；写端口中 MMALU 的 INT32 结果无截断直写 VR port 1，VALU 三类输出按 `regCls` 写回 VX/VE/VR port 0。三是养成「以代码为准」习惯，本讲实指三处注释落后于代码的偏差（VX port3 复用、in_b 实为 VX、VX 写 port1 未用）。引入的关键术语包括 `NCoreBackend`、端口分配表、时分复用、无截断直写 VR、`dec.valu` 整块赋值、`W` 宽度常量，以及 `isVALU`、`isNarrowCvtOut`/`isWideCvtOut`/`isReduceToVR`/`isSetLut` 等写回守卫（留待 u6-l2 详述）。
