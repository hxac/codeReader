本讲是测试单元 U9 的开篇，确立 chisel-npu 全部 21 个 spec 采用 Chisel 6 自带的 `chisel3.simulator.EphemeralSimulator`（用完即弃，每次现场 elaborate→firtool→verilator 编译），而非老牌 `chiseltest`（build.sbt 里虽有 chiseltest 依赖但全仓零 import，属遗留物）。核心范式为 `simulate(new Module){ dut => poke / step / peek / expect }` 四原语：`step(0)` 只求值组合逻辑、`step()` 推进寄存器一拍；负数位模式用 `& 0xFF` 或 `(x.toLong & 0xFFFFFFFFL).U` 处理。引入共享工具包 `testUtil`：`PrintHelper` 把仿真 `Vec[SInt]` 经 `peek().litValue` 打印成矩阵（带 peek 副用），`WidthConst` 镜像 `VecWidth` 枚举数值。最重要的心智模型是 **ChiselEnum 端口 `poke` 合法、`expect` 非法**，校验 enum 输出须 `peek().litValue` 间接比较或走间接功能验证。现代 spec 用 `NpuAssembler` 构造 32 位指令字 `poke io.instr`，额外覆盖译码器路径。日常跑单测用 `tool/test-specific-spec.sh <类名>`。
