本讲讲解 Python 用户态驱动 chisel_npu_py，它在 u8-l2 的 C 工具之上提供 numpy 优先的高层 API。核心设计是一条 pybind11 安全边界：把 fd、DDR 地址、寄存器偏移、DMA 传输全部关进 C++ 模块 NativeXDMA，Python 只剩「按名字搬 buffer + 一个控制字」。四个最小模块自下而上为 pybind11 边界、按名字寻址的 XDMADevice、封装 start/done/busy 三位协议的 CtrlLite、门面 ChiselNPU。关键术语有 operand（按 A/B/ACCUM/OUT 命名的操作数）与 staging table（名字到 DDR 地址与字节数的暂存表，是地址唯一权威）。ChiselNPU.mmalu 编排 stage→kick→wait→collect 四步完成一次 MMALU 计算周期，kick 前查 busy、超时抛 NPUTimeoutError，输入 int8[K]、输出 int32[K]。无硬件时可用纯 Python 的 FakeNative 注入测试，它同样守边界纪律，只验证搬运与协议编排、不做矩阵乘，算术正确性仍需在真实板上 bit-exact 校验。
