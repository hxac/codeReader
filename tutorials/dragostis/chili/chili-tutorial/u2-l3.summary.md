本讲讲解 worker 线程与共享上下文。核心结构 Context 用一把 Mutex 包住 LockContext 调度账本：time 时间戳、is_stopping 停机旗、shared_jobs 任务货架、heartbeats 心跳登记表，外加 job_is_ready 等两个条件变量；因共享路径是冷路径，敢用一把粗锁，热路径完全不碰锁。execute_worker 主循环为「锁内弹一个共享任务、锁外执行、持锁查停机旗再睡」；首轮经 Barrier(W+1) 与主线程汇合，保证池构造返回时全部 worker 就绪。shared_jobs 以 scope 编号（心跳 Arc 的指针地址）为键，entry 去重使每个 scope 至多挂一个任务，pop_earliest 实按键序出队而非投递时间。Drop 持锁置旗后 notify_all，先 join worker 再 join 心跳线程；wait_for_sent_job 的等待者也消费货架任务，「等待即帮忙」是下一讲的入口。
