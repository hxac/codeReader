本讲只读 README 与 Cargo.toml，分三个模块给出 chili 全景。定位：chili 是 Spice 的 Rust 移植版，一个低开销 fork-join 并行原语，API 语义与 rayon::join 几乎一致。关键概念：fork-join 模型（fork 分叉、join 汇合）；“may 并行”语义——join 只保证两闭包结果正确汇合，是否真正跨线程由调度决定，只影响耗时不影响结果；适用场景是“大量小计算＋难以估计分支剩余工作量”，典型示例为二叉树求和（满二叉树节点数 2^L−1）。基准解读需会算加速比与每节点摊销耗时：大规模下接近 8 核理论上限（x7.83），1K 节点时并行必然更慢而 chili 亏得最少，每节点开销约 3.5ns 且不随线程数增长。工程上运行时零第三方依赖（仅 dev 依赖 divan 与 rayon 对照），核心代码为 src/lib.rs（Scope、join、ThreadPool）与 src/job.rs。
