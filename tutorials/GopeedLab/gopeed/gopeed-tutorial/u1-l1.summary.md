本讲建立 Gopeed 的总体架构地图。Gopeed 是「Go 核心 + Flutter 外壳」的开源高速下载管理器，协议覆盖 HTTP/HTTPS、BT/磁力链接、ed2k（代码中另有 HLS、FTP，README 未列全），产品形态覆盖桌面、移动、Web、CLI 与 Go 库五种。核心结论是「一个核心、多种外壳、一份业务实现」：三条通信通道（桌面 Dart FFI、移动 gomobile、Web REST）最终都汇入同一个 Dispatcher 与 ApplicationService（pkg/api/service.go），原生端本地 REST 服务器默认关闭，仅 Web 形态必须走 REST。bind/ 桥接层刻意小而稳定，业务入口只有 InvokeAsync 一个，请求序列化为 method/path/query/body 字符串，新增 API 桥接层零改动；CLI 则通过 Boot() 链式 API 无桥直连核心。持久化采用嵌入式键值库 bbolt。关键术语：FFI、gomobile、REST、MCP、Dispatcher、ApplicationService、InvokeAsync。
