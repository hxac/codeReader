本讲解决「把 Gopeed 从源码构建并跑起来」。核心结论：单一 Go module 通过「不同入口包＋构建参数」产出五种形态——CLI（cmd/gopeed）、开发用最小 API 服务（cmd/api）、Web 服务端（cmd/web）、桌面 c-shared 动态库（bind/desktop）、移动端 gomobile 绑定（bind/mobile）。关键概念：web 标签是 cmd/web 的编译门禁，go:embed 要求先有 Flutter Web 产物；nosqlite 只作用于依赖库，配合 CGO_ENABLED=0 实现纯 Go 交叉编译；-ldflags -X 注入 Version（缺省为 dev）与 InDocker（决定容器内默认下载目录）；Docker 为多阶段构建加 PUID/PGID 权限映射；cmd/web 配置优先级是配置文件、GOPEED_ 环境变量、命令行参数；可用 /api/v1/info 验证注入效果。
