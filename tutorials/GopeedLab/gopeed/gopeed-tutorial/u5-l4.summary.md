本讲收束 HTTP 协议深潜，覆盖三个模块。完成判定分两级：checkCompletion 仅供慢启动循环决定是否扩张连接，onDownloadComplete 才做最终裁决，规则是完整性错误压过字节计数与连接完成度，403 在文件大小已知时被容忍；收尾顺序为关文件、verifyChecksum、定态、经 doneCh 通知 Wait()。ChecksumOption 为 opt-in 校验：Validate 在 Start 时快速失败（算法归一化、哈希长度 32/40/64、合法十六进制），比对忽略大小写；失败不删文件，但置 checksumFailed 原子标志，重试时触发截断与全量重下。OptsExtra 七字段分三类：Connections、Checksum 由 Fetcher 消费；AutoTorrent、AutoExtract 等五个联动字段由 Downloader 在任务 done 后经 postDownloadExtra 消费，*bool 三态为任务级显式设置覆盖全局配置。
