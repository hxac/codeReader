本讲把 Gopeed 当作 Go 库使用，用 Boot() 链式 API 写出命令行下载器，覆盖三个最小模块。其一是 Boot 链式构造器：背后是包级单例 defaultDownloader，链式方法仅收集配置，Create 把它们组装成 Request 与 Options 交给 CreateDirect，协议按 URL 自动路由，返回即任务已启动或进入 wait 队列；默认配置含五个协议管理器、350ms 刷新与内存存储。其二是 Listener 事件回调：共七种 EventKey，finally 是紧跟 done/error 的合成事件且恰好触发一次，以 event.Err 判成败，progress 由全局循环周期发射，回调为同步调用。其三是 Options 与协议专属 Extra：Options.Extra 为 any 类型，HTTP 的 Connections 经任务级、全局、默认值三级回退，由慢启动控制器分批建连，多连接加速依赖服务器支持 Range。综合实践产出带进度条与连接数参数的迷你下载器 mydown。
