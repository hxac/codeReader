本讲覆盖 `pkg/download/category.go` 与 `pkg/base/model.go` 的自动分类与目录决策模块。核心模型 `DownloadCategory` 定义「扩展名列表→目录」映射，内置分类以 `NameKey` 标识并用 `IsDeleted` 软删除，开关 `AutoCategorize` 采用 `*bool` 三态，未设置即视为关闭。`categoryForResource` 仅路由单文件资源，扩展名经 Dart 对齐的归一化（`asciiLower`、`dartTrimSpace` 等）后按配置顺序 first-match-wins 匹配，重命名（`opts.Name`）不参与。目录决策两次分离：Resolve 阶段 `suggestedDownloadDir` 给 UI 建议目录（只读，出错返回空串），`prepareTask` 阶段 `decideDownloadDirForTask` 决定最终目录并写 `Opts.Path`，永远按当时配置重决策。分组任务（TaskGroup）走快速路径：跳过分类、直接落入预留组目录，且不二次展开占位符。`WhiteDownloadDirs` 是进程级安全白名单，`filepath.Match` glob 匹配、校验发生在占位符展开之后，失败分级处理——分类目录被拒回退基础目录，基础目录被拒才报错；`AsDefaultPath` 须与 `SkipAutoCategorize` 同设才能改写全局默认目录。
