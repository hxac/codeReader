本讲沿 `pkg/download/downloader.go` 讲解任务主链路的六个模块。Resolve 做资源预览，把 Fetcher 实例（而非 Resource）以 rrId 缓存进 fetcherCache，扩展短路产出资源时 ID 为空、只能走直建；三类建任务入口——CreateDirect（延迟解析）、Resolve→Create（消费解析缓存）、批量 CreateDirectBatchWithResult（rid 优先、opts 整体替换、部分成功、可建组）——最终在 doCreate 汇合装配 Task 骨架并先落盘；createResolved 以写锁「取出即删除」保证单一创建者，未落盘时归还缓存、落盘即被消费；满载任务置 wait 态入 waitTasks 队列，由 notifyRunning 异步 FIFO 唤醒队首；doStart 分 statusMut 同步段与异步 handler 两段，以 runGeneration 代数核对防暂停竞态；prepareTask 借 NeedsPreparation 做一次性目录决策与重名改名（分组任务旁路分类、落预留组目录），采用「先存候选后发布」，checkDuplicateLock 须用 defer 罩住 fetcher.Start()，使查重、改名与建文件成为原子段。
