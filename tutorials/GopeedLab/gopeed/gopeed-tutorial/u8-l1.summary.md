本讲精读 pkg/api：与传输无关的服务层。核心是 RouteSpec 自研路由表（Match 按段数严格相等匹配、参数段解码恰好一次、cleanPath 归一化路径）与 Service.Dispatch/JSON 进程内分发，共 29 条 /api/v1 路由。核心结论：handler 只接触纯数据的 Context/Response，不接触网络对象，REST、FFI、测试三端共享同一实现，新增接口桥接层零改动；业务错误为 HTTP 200 加信封错误码，资源级错误才返回真 404。关键术语：Result 响应信封、TaskFilter（单任务操作与 query 的 id/status/notStatus 统一归一为过滤器）、CreateTaskBatchResult（批量建任务响应由 ID 数组改为 taskIds 加可选 parentId，指向 TaskGroup 任务分组，部分成功语义、全败聚合报错，旧入口 CreateDirectBatch 保留为兼容薄包装）。
