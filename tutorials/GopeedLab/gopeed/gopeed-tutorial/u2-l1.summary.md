本讲义是整个手册的「词汇表」，定义于 pkg/base 与 pkg/protocol，讲一次下载的三要素：Request 表达「从哪下、以何身份下」（RawURL 与 URL 分离，代理三态 follow/none/custom）；Resource 是解析（Resolve）阶段的产物，回答「那里有什么」，FileInfo 可内嵌逐文件请求；Options 表达「怎么下」，SelectFiles 空即全选，入口处经 InitSelectFiles 展开为显式下标，CalcSize 覆盖式重算大小。Extra 为 any 的协议私有参数，由幂等泛型函数 ParseReqExtra/ParseOptExtra 在 JSON 边界把 map 翻译回 ReqExtra/OptsExtra；各协议不对称：HTTP/FTP 选项丰富、BT 仅请求侧 Trackers、ED2K 皆无。批量模型 CreateTaskBatch 以批级 Opts 加成员 Req/Rid/Opts 组装三要素，规则为 rid 优先、成员 opts 整体替换、部分成功；Group/GroupName 建立 TaskGroup 共享预留目录并以 ParentID 关联，响应统一为 CreateTaskBatchResult。
