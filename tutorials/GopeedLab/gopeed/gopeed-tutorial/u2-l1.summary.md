本讲是全手册的词汇表，讲解一次下载的三要素。下载分解析与传输两阶段：Request 是解析输入，RawURL 保留用户原始地址而 URL 是实际请求地址，重定向、扩展改写与 Patch 只改后者，代理分 follow/none/custom 三态；Resource 是解析输出，含 Name、Size、Range、Files 与 Hash，FileInfo.Req 可逐文件携带独立请求；Options 贯穿两阶段表达下载意图，SelectFiles 以文件下标选择、空即全选，入口先校验下标、由 InitSelectFiles 展开为显式列表，CalcSize 覆盖式重算大小。两侧 Extra 均声明为 any，由幂等的 ParseReqExtra/ParseOptExtra 在 JSON map 与各协议 ReqExtra/OptsExtra 间翻译：HTTP 有方法、请求头、连接数等，FTP 有 TLS 模式，BT 仅 Trackers，ED2K 皆无。
