本讲解析 Gopeed 的 BT 实现：全进程共享一个 BT 客户端（torrent.Client），懒加载创建，单任务关闭只 Drop 自己的种子，由 FetcherManager.Close 在 Downloader 关闭序列中统一销毁；提交 cd19772 令 initClient 遵循「必须持锁调用」契约，新增 addTorrentSpec 把临界区从客户端初始化延伸到种子添加完成，消除与 closeClient 的竞态。addTorrent 分四条解析分支：本地路径、file://、data: URI 与磁力链接；磁力的 InfoHash 直接取自 URI 的 xt 参数、文件列表需等 peer 提供元数据，种子文件的 InfoHash 则由库对 info 字典本地计算。torrentFileLayout 与 updateRes 把种子元数据映射为通用 Resource，并保证展示与落盘路径一致，有无根名决定 Resource.Name 是否为空。关键术语：InfoHash、metainfo、tracker/DHT/PEX、私有种子、做种、NoName 无根布局、ParseName、deferredFileStorage；BT 路由声明为 magnet scheme、.torrent 扩展名与 data URI MIME 三类指纹，协议注册顺序 ftp→hls→http→bt→ed2k。
