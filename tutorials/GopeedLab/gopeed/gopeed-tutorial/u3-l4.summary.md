本讲实战从零实现 mock:// 协议的最小 Fetcher 并注册进 Downloader，打通 resolve 到 done 的全流程。核心模块与结论：FetcherManager 九个方法分身份、路由、工厂、配置与持久化四组，DefaultConfig 返回 nil 会让整个 Setup 失败；Resolve 只做幂等的资源发现，Start 只负责启动传输、中途失败经 DoneCh 上报，单文件资源 Name 必须留空，目标文件用 ctl.Touch 一步创建；DoneCh 完成通知契约为容量一、非阻塞发送、恰好通知一次，nil 表示成功、暂停时静默退出；Store/Restore 是两段式持久化契约，Restore 返回空模板加构造器，支撑跨重启续传；注册即把 Manager 放入 FetchManagers 切片，顺序即协议优先级且会整体替换默认五协议，Boot() 单例无法注入自定义协议，必须 NewDownloader 自行构造。关键术语：DefaultFetcher 基类、setupFetcher 注入时机（Build 之后、业务方法之前、每实例一次）、generationTestManager 最小参考实现。
