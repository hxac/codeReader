本讲讲解如何搭建 OH! 本地仿真环境：安装 iverilog（Icarus Verilog 编译型仿真器）与 gtkwave（VCD 波形查看器），并掌握仿真三步流程——build.sh 编译出 dut.bin、sim.sh 运行、view.sh 查看波形。前提是用 source setenv.sh 设置环境变量 OH_HOME 指向仓库根目录，必须用 source 而非直接执行，否则 export 仅在子 shell 生效。引入的关键术语包括：Verilog 2005（IEEE 1364-2005，全库统一语言标准）、VCD 文件、.emf（OH! 事务激励格式，每行一个对被测器件 DUT 的事务，字段细节留待 u4-l2）、testbench。编译命令 iverilog -g2005 -DTARGET_SIM=1 -DCFG_ASIC=0 中，-g2005 锁定标准，两个 -D 分别切换仿真专用代码分支与 soft(RTL) 实现；libs.cmd 用 -y 按文件名查找模块定义、+incdir+ 查找头文件，自动拼装分散源码。运行时 sim.sh 把指定 .emf 软链接为 test_0.emf 喂给 dut.bin，产出 waveform.vcd。关键排错结论：仓库脚本存在历史路径问题——scripts/libs.cmd 实际位于 stdlib/testbench/libs.cmd，common/、memory/、src/ 等目录当前不存在，遇到路径报错应优先怀疑这些遗留问题。
