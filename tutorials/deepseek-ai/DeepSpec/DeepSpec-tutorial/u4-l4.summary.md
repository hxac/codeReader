本讲精读 DSpark 损失模块 compute_dspark_loss（由 trainer 的 run_batch 调用）。总损失为三项 alpha 加权和：ce_loss_alpha×带位置衰减的 CE、l1_loss_alpha×L1 蒸馏、confidence_head_alpha×置信度 BCE，默认 0.1/0.9/1.0，蒸馏为纲；DFlash 把权重改成 1/0/0 即退化成纯 CE。三项共享同一份 loss_weight_mask，由 eval_mask 乘槽位衰减 e^(−t/γ)（loss_decay_gamma=4）构成，因前缀接受是连乘，块首槽位杠杆最大。核心等式：接受率 a = 1 − TV(p,q)，故 L1 = 2(1−a)，最小化 L1 即最大化投机解码的期望接受概率；tau_probabilistic 用 cumprod+1 免费解析估计期望接受长度。置信度头以 detach 后的接受率为 BCE 目标，切断自我指涉。工程上分子留本地、分母跨 rank all_reduce、返回值乘 world_size 抵消 FSDP 梯度平均，保证全局 token 平权。
