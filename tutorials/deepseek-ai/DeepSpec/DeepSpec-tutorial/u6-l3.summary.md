本讲精读 verify_draft_tokens，打开投机解码的验证黑盒。核心结论：草稿 token 以概率 min(1, p/q) 被接受，首个被拒位改从残差分布 max(p−q,0) 归一化后采样，接受与修正两路概率合并后严格等于目标分布——输出无损，草稿质量只决定速度：单位置接受率 α=1−TV(p,q)，与 L1 蒸馏损失互为两面。实现要点：目标与草稿分布必须同温度、同函数归一；accept_prefix_mask 用 cumprod 求最长连续被接受前缀，其期望恰为各级接受率连乘，衔接 accept_rate@k 与期望接受长度；停止 token 截断前缀并同步 effective_proposal_length；committed_tokens 恒为「接受前缀＋一个 residual 或 bonus token」，空提议也保证每轮至少提交一个；主循环据此推进游标、裁剪目标 KV cache。末尾以蒙特卡洛实验验证理论接受长度与分布无损。
