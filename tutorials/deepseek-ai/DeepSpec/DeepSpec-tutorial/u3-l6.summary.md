本讲精读 metrics 与 training_logger 两模块。add_metric 只累积不通信：比值型（ratio）指标分子、分母分别累积，flush 时全局 sum(num)/sum(den) 加权，避免各卡先除再平均在数据倾斜下的偏差；标量型（scalar）按 mean/last 等窗口归约，dp_ 前缀再跨 rank 归约。flush 含集合通信须全员执行，写 TensorBoard 与终端打印仅 rank 0。training_logger 封装 init/start_session/on_optimizer_step/close 会话生命周期：lr、grad_norm 每步以 last 记录，ETA 按会话起点线性外推。关键术语：日志窗口（logging_steps）、指标 kind、schema 一致性校验、TB 横轴为 optimizer step、DSpark 的 train/loss 为 rank 0 均值而 Eagle3 用 dp_mean。
