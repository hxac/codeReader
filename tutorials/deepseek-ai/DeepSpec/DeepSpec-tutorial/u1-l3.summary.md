本讲覆盖三个最小模块：train.py 启动链路、eval.py 的 EVALUATORS 分发、init_dist 的全局 rank 推导。train.py 是极薄入口：每个 spawn 子进程各自 parse_args（配置加载、--opts 点路径覆盖、回填来源供续训），再实例化配置里直接存放的 Python 类 trainer_cls 并调用 train()，体现「配置即代码」。eval.py 则由父进程解析参数后共享给子进程，凭 draft checkpoint 的 architectures[0] 字段查 EVALUATORS 字典分发 Evaluator，标签由各模型族 build_draft_config 深拷贝目标 config 时写入，Eagle3DraftModel 为兼容别名。两入口均用 torch.multiprocessing.spawn 自举，进程数完全由 CUDA_VISIBLE_DEVICES 决定；init_dist 以 rank = node_rank × local_world_size + local_rank 推导全局 rank，本仓库 RANK/WORLD_SIZE 为节点粒度，异于 torchrun 语义，BaseTrainer 与 BaseEvaluator 构造时对称调用它，一套分布式自举服务双入口。
