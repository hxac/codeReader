本讲围绕 ckpt_manager.py 讲清检查点系统。save_checkpoint 四阶段由 barrier 排成全序：rank 0 先回写 train_config.py；全体 rank 以 FSDP gathered 完整形态取权重，由 rank 0 存成 HF 标准 checkpoint；各 rank 另存 training_state.rank{r}.pt，内含 next_micro_step、优化器状态、并行布局三元组与四套 RNG 状态。存盘仅允许在同步微批边界，step_latest 指针最后翻转，因此必指向完整目录；safe_symlink 以临时链接加 os.replace 实现原子替换，修复旧实现「先 unlink 再建链」崩溃后静默从零训练的缺陷。启动时发现 step_latest 即自动续训：恢复权重并重新冻结、恢复优化器与 RNG、断言并行布局一致、按 next_micro_step 推导采样偏移。train_config.py 回写为原配置拷贝加 --opts 赋值行，类型与运行时严格一致。
