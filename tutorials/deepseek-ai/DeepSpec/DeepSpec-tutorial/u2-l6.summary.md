本讲讲解目标缓存的训练侧读取，覆盖 CacheDataset、CacheCollator 与 CUDAPrefetcher 三个模块。CacheDataset 以 mmap 加 56 字节定长索引实现对约 38 TB 缓存的 O(1) 随机读取：分片 mmap 懒打开并按 LRU 淘汰，文件句柄不随 pickle 进入 DataLoader worker；bfloat16 以 uint16 比特位视图无损读写；因写入端按真实长度截断、缓存样本无 padding，读取端直接跳过 attention_mask 段。CacheCollator 把变长样本右侧零填充成形状整齐的 batch，并按真实长度重建 int64 的 attention_mask，「零填充＋双掩码」使损失计算天然忽略 padding。CUDAPrefetcher 用后台线程取数、独立 CUDA 侧流做异步 H2D，构成双缓冲，靠 wait_stream 与 record_stream 做同步，使步长从串行之和逼近 max(tc,td)，pin_memory 是异步拷贝前提；input_ids 到 GPU 后才由 int32 转 int64 以供 embedding 查表。
