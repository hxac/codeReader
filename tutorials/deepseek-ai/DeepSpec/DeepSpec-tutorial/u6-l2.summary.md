本讲精读 base_evaluator.py 中的投机解码主循环 generate_decoding_sample，核心结论是「骨架固化、差异下沉」：循环只实现算法无关的验证前向、游标推进与统计收集，草稿算法差异全部交给 init_context、propose、update、post_verify 四个钩子，DSpark 与 Eagle3 由此共用同一循环，钩子间以 DraftProposal、VerificationResult 两个数据类为合同。关键概念：prefill 后首 token 由目标分布直采、不经验证，充当草稿提议的锚点；循环不变量是目标 KV cache 长度恒等于游标 start 且对应已提交前缀；每轮提交「被接受草稿数 a 加 1 个兜底 token」，轮末用 DynamicCache.crop 裁掉被拒草稿的废料 KV；acceptance_lengths 等三个统计量在循环内诞生，流向 accept_len 与 verify_rate 指标。拒绝采样的数学证明留给下一讲 u6-l3。
