本讲义精读 `deepspec/utils/distributed.py`，覆盖三块内容。其一 `init_dist`：不用 torchrun，由 spawn 传入的 local_rank 与环境变量自举进程组，核心公式为全局 rank = 节点序号 × 每机 GPU 数 + local_rank，world_size = 节点数 × 每机 GPU 数；本仓库的 `RANK`/`WORLD_SIZE` 是节点粒度语义，与 torchrun 的进程粒度不同，不能混用；不设环境变量即默认单机多卡零配置启动。其二两级主进程分工：global main（全局 rank 0）负责建目录、写 TensorBoard、提交评测、执行挂起等全作业仅一次的动作；local main（每机 0 号进程）负责每机一份的运行日志；另有 `main_process_first` 做 rank 0 先行的顺序控制。其三 `StatelessResumableDistributedSampler`：数据流是 (seed, epoch, rank, 偏移) 的纯函数，每 epoch 用独立 Generator 以 seed+epoch 洗牌取前 total_size 个，各 rank 按 stride 切分（rank r 取排列的 r::R），借“位置↔(rank, 本 rank 步数)”双射保证不重不漏；断点续训只需恢复 `next_micro_step`，经“偏移 = next_micro_step × local_batch_size、epoch_idx = 偏移 // 每 rank 每 epoch 样本数”换算即可无缝衔接，且恢复时强制沿用相同并行布局。
