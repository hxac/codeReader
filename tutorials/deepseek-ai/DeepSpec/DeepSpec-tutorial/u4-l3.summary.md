本讲解读 DSpark 草稿模型的 Markov 头：块式并行产出的整块 logits 缺少块内 token 级依赖，VanillaMarkov 用低秩双线性偏置（markov_rank=256，查表加投影）在冻结 lm_head 的 logits 上加一阶可学习修正。训练走 apply_block_logits，teacher forcing 下前驱 token 由锚点 token 拼右移真值标签，整块并行修正后才进蒸馏损失；推理走 sample_block_tokens，从锚点起逐槽位「修正→采样→推进前驱」，并返回采样实际使用的 corrected_logits 供拒绝采样。markov_rank=0 时头为 None，DFlash 由此退化为整块独立采样；markov 嵌入另被置信度头复用。
