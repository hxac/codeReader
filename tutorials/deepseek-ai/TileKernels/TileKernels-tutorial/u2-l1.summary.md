本讲解剖 TileLang 算子的统一骨架。一个算子是固定的「三层套娃」：最外层 `@tilelang.jit` 装饰器标记 JIT 构造器并传入编译开关（`pass_configs`），中间层 kernel 构造函数接收编译期参数（如 `num_experts`、`shape_mod_128`、`dtype`），最内层 `@T.prim_func` 内核函数描述每块的计算、形参为启动时张量。核心结论在于「编译期 vs 运行时」的切分：编译期参数被烤进编译产物、不同取值各自特化；运行时维度用 `T.dynamic('名字')` 声明为符号，可出现在张量形状、步长（`T.StridedTensor`）和网格表达式里，由启动时的张量提供具体值，使一段产物复用多种输入，但符号不能在 Python 层做确切判断。`with T.Kernel(各维度, threads=N) as (pids):` 定义网格与每块线程数，grid 维度数须等于绑定的 pid 数，转置用三维网格、topk 用一维网格。wrapper 是用户真正入口，固定四步：校验、分配输出、触发或命中 JIT 缓存编译、按 prim_func 形参顺序启动，零规模守卫也在 wrapper 做。掌握了这套骨架，后续算子都是往里填肉。
