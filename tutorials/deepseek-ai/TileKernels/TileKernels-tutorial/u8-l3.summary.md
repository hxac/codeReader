本讲聚焦 mhc 包「四层」结构中的 ops 层——位于底层 TileLang kernel 与 functional 之间的「桥接层」，用 `torch.autograd.Function` 把单个 kernel 包成可微算子。`ops/__init__.py` 是 9 个算子的纯再导出枢纽，与 functional 层（只组合编排、不写封装）形成封装与编排的职责分工。两个样板承接了关键技巧：极简桥接 `_SinkhornNormalize` 在 forward 一次性编译 fwd/bwd kernel，把 bwd_kernel 挂到 `ctx` 属性实现「前向编译、反向复用」，仅 `save_for_backward(x)` 体现重计算策略；核心样板 `MHCHeadComputeMix` 建立本讲最重要的反向归约模式——带 token 维的梯度（`input_mix_grad`）直接写、无竞争，而不带 token 维的小参数梯度（标量 `mhc_scale_grad`、小向量 `mhc_base_grad`）则让每个 SM 一个持久化 block 各写一份 `*_grad_partial`（零原子竞争），再在 Python 层 `.sum(0)` 聚合，分块数选 `num_sms` 以填满一个 resident wave。引入的关键术语包括：ops/functional 分层、`ctx` 存 kernel 对象、per-SM partial + `.sum(0)` 的 split-K 归约、小尺度 rematerialization。由此归纳出三种反向归约策略的适用边界：sinkhorn 无需归约、head_compute_mix 用 Python `.sum(0)`、engram `grad_w_reduce` 用专门 reduce kernel。
