本讲承接 u3-l1，从转置 kernel 内部跳到外部测试，讲 TileKernels 如何用 pytest 同时钉死正确性与性能。正确性遵循三件套对拍范式：参数生成器枚举形状、数据生成器造输入、被测 kernel 与 PyTorch 参考用 assert_equal 做位精确（bitwise exact，按 uint8 逐字节）判等——转置无舍入故用位精确，区别于量化算子的浮点相似度 calc_diff。twice_stride 故意把行步长翻倍构造非连续（strided）输入，配合 kernel 的 T.StridedTensor 与运行时符号 stride_x，验证其不依赖输入连续的隐藏假设。性能用有效带宽衡量：count_bytes 统计读加写字节、benchmark_timer 经 CUPTI 测延迟、benchmark_record 写出稳定 key 的 JSONL 并按 15% 阈值做回归检测，公式 bandwidth_gbs = num_bytes/t_us/1e3。参考实现分专用（收纳于 tile_kernels/torch/）与内联（如转置的 x.T.contiguous()）两种风格，取舍标准是参考实现的复杂度与复用度。
