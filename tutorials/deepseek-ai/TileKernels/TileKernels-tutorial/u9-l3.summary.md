本讲围绕测试基础设施的两个最小模块展开。**模块一（插件装配）**：pytest 有两条独立的插件加载路径——`conftest.py` 自动发现（隐式）与 `pytest_plugins` 显式注册（显式）。`tests/conftest.py` 是极薄的「装配清单」，自身不写 hook，仅靠 `pytest_plugins` 列表挂载插件。`pytest_benchmark_plugin.py` 故意不命名为 `conftest.py`，以避免同一模块同时走两条路径被 pluggy 重复注册，触发 `conflicting option string` 或 `Plugin already registered` 错误。**模块二（随机种子）**：`pytest_random_plugin.py` 用 `autouse=True` 的 `seed` fixture，按 `seed = base + sha256(nodeid) % 2^31` 派生每个测试的专属种子并 `torch.manual_seed` 注入全局 RNG。关键术语包括：nodeid（测试唯一身份证，含参数化后缀）、pluggy、`pytest_addoption`、autouse fixture。核心结论：`sha256` 的确定性保证稳定可复现，雪崩效应保证不同 nodeid 互不干扰；该方案在 xdist 并发下依然可复现，因为种子只由 nodeid 决定。
