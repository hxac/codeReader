本讲精读 TileKernels 的 Sinkhorn 归一化前向与自定义反向，覆盖 `_mhc_sinkhorn_fwd`、`_mhc_sinkhorn_bwd` 两个 TileLang kernel 及其 `torch.autograd.Function` 封装。核心结论：Sinkhorn 归一化经 softmax 加 eps 预处理后交替做行/列除法，把 mhc 的 M×M 混合系数 `comb_mix` 推向近似双随机矩阵，从而平衡多股残差流的混合强度。前向 kernel 在单个 fragment 上原地串行迭代（轮间有依赖故用 `T.serial`）。由于前向是编译后的 CUDA 黑盒、fragment 原地更新破坏 autograd 版本计数、纯 PyTorch autograd 又会随 repeat 线性爆显存，故必须手写反向，采用「只存输入 x、反向重算」的 rematerialization 策略。反向 kernel 两段式：先按前向顺序把每步矩阵快照 `xs[t]` 与归一化和 `sums[t]` 写入 shared memory，再逆序用 `inv_step%2` 区分行/列，按 (grad−sum2)/(s+eps) 回传，最后过 softmax 反向。引入的关键术语：双随机矩阵、Sinkhorn 迭代、重计算/激活检查点，以及行/列归一化反向公式（分母 s=Σx 依赖 x，故比「除以常数」多出 −sum2 修正项，这正是必须保存每步 x 与 s 的根因）。
