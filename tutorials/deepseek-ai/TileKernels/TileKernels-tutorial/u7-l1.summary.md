本讲是 Manifold HyperConnection（mhc，流形超连接）单元首篇，建立整条 mhc 数据流水线的心智模型，并精读三个最基础算子。核心思想：把标准 Transformer 的单股残差流升级为 `mhc_mult` 股并行残差流（残差张量从 `(...,H)` 变为 `(...,M,H)`），子层（attention/FFN）对多股流无感知。流水线分四段：**expand → pre → sublayer → post**——pre 把多股压成单股喂子层，post 把子层输出展开混回多股；普通残差是 `mhc_mult=1` 的退化特例。当前实现仅 `mhc_mult=4` 保证可用（post kernel 内 `assert mhc==4`）。三个算子：**expand**（`expand_kernel.py`）前向「读一次写 M 次」复制，反向沿 mhc 维求和，纯带宽算子；**norm_fn**（`norm_fn_kernel.py`）是「分组 RMS 归一化投影」，拆成 `fwd_mul`（tensor core GEMM + 平方和）与 `fwd_norm`（rsqrt 归一化求和）两步，产出 `mhc_mult3 = mhc_mult*(mhc_mult+2)` 个 mixes 通道；**post**（`post_kernel.py`）用 `y = c·d + a@b` 重组子层输出与多股残差，反向对 `a/c` 小矩阵用 `alloc_reducer` 跨 hidden 归约。关键术语：`mhc_mult` 残差维度、mixes 混合系数（后续切成 `pre_mix/post_mix/comb_mix` 三段）、`ctx=(post_mix,comb_mix)` 不透明耦合元组。入口 `functional.py` 用 `torch.is_grad_enabled()` 在推理（`pre_big_fuse` 大融合）与训练（四步拆分）间切换。更复杂的 `pre_split_mixes`/`sinkhorn`/`pre_big_fuse` 留待后续讲义。
