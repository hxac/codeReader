本讲（u1-l2）解决 TileKernels 的安装、运行测试与 benchmark 读取三件事。安装分两种：开发版 `pip install -e ".[dev]"`（可编辑、含 pytest 等开发依赖）与发布版 `pip install tile-kernels`（仅运行时依赖）。运行依赖为 `torch>=2.10`、`tilelang>=0.1.9`，pytest/pytest-xdist/pytest-repeat 归入 `dev` 可选项，版本号由 `setuptools-scm` 从 git 动态生成；CUDA 13.1+ 与 SM90/SM100 GPU 属系统级依赖，故安装成功不等于能跑。测试基于 pytest，三种姿势：正确性 `-n 4`、加基准 `--run-benchmark`、压力 `TK_FULL_TEST=1 --count 2`。根 conftest 经 `pytest_plugins` 加载随机种子与 benchmark 两个自带插件，文件刻意不叫 conftest 以规避 pluggy 重复注册；benchmark 用例默认跳过。随机种子由 `base + sha256(nodeid)` 派生，保证可复现且互不干扰。性能用 `benchmark_timer`（CUPTI 计时，rep=30，单位微秒）与 `count_bytes`（统计读+写）算带宽 `num_bytes/t_us/1e3`，与 `benchmark_baselines.jsonl` 比对，回归阈值默认 15%，超出则 pytest 退出码非 0。两个环境变量切换行为：`TK_FULL_TEST` 扩展边界参数（仅正确性用例生效），`TK_PRINT_KERNEL_SOURCE` 打印 TileLang 生成的 CUDA 源码。
