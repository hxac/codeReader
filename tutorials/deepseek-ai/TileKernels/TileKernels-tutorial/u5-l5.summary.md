本讲为 MoE 路由单元收尾篇，串起三个后处理算子，并以纯 PyTorch 的 top2_sum_gate 拼成端到端路由流水线。normalize_weight 做 top-sum 权重归一化，分母加 1e-20 以与融合版 kernel 数值对齐。mask_indices_by_tp 用 ep_of % num_tp_ranks 判 TP 归属，非本卡专家置 -1，本卡的扣偏移、抽空洞改写为连续本地下标。aux_fi 算辅助损失负载指标 f_i=count·N/(num_tokens·num_aux_topk)，以 shared 局部直方图加 global 归约的两级结构缓解原子竞争，block 数随硬件伸缩但结果不变。top2_sum_gate 以 11 步串起打分、加偏、分组粗筛、top-k、归一化、共享专家、logical→physical 映射与 EP/TP 掩码；logical→physical 用 (ep_rank+token*23333)%logical_count 在 token 与 rank 两维度摊开冗余副本，bias 仅决定选谁而不改权重。
