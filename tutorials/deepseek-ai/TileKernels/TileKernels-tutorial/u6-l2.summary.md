本讲承接 u6-l1，讲 engram 门控反向与权重梯度归约。前向保存四个 fp32 中间量供反向复用：`dot`（未归一化原始点积 raw_dot，而非归一化后的门控输入）、`gate_score`（最终门控值 g）、`rstd_x`、`rstd_k`。反向 kernel 三段式：算门控值上游梯度 G、经门控导数得 `dldg_r`（signed-sqrt 符号在求导中抵消，无需显式 sign），写 `grad_v`，再流水写 `grad_x/grad_k` 并把 `dldg_r·x·k` 累加进每块寄存器。核心设计：激活梯度（grad_x/grad_k/grad_v）带 token 维、各持久化 block 直写无需归约；唯有参数梯度 `grad_w` 按块写成 `grad_w_partial`，需二次归约（split-K 风格，避免上百 block 竞争同地址原子加）。`grad_w_reduce` 一口融合三事：跨 `num_persistent_blocks` 求和、按链式拆成融合权重 w_h/w_e 各自梯度、就地 `+=` 进既有 fp32 缓冲。当参数带 `main_grad` 时，直接当作累加目标并对其返回 `None`，避免临时 .grad 与重复累加；backward 返回元组逐位对应 forward 的 7 个输入。
