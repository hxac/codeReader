本讲精读 train.json 的单条事件，分四模块：八字段解剖、ph 阶段、cat 类别全量统计、元数据映射。八字段各答一问：ph 定类型、cat 定类别、name 定具体事、pid/tid 定轨道、ts/dur 定区间（微秒，可验嵌套）、args 装各类细节。本仓库仅出现五种 ph：X 完成事件（唯一有 dur、可嵌套）、M 元数据、s/f 流箭头（按 id 配对）、i 即时戳记；时间统计只算 X。cat 构成派生链 cpu_op→cuda_runtime→kernel/gpu_memcpy，train.json 共 14240 条（ac2g 4876、cpu_op 4387、cuda_runtime 3853、kernel 963 等），kernel 集中于 GPU 0 的 stream 7（计算主流）与 stream 27（通信流）。ph:"M" 的 process_labels/thread_name 把数字 pid/tid 译成可读轨道名：pid 1166 是 CPU 主线程（主线程 TID=PID），tid 2571 是 autograd 反向工作线程；stream 名带尾随空格，脚本匹配需 strip。CPU 与 GPU 异步：一次内核启动在 CPU 侧留 cuda_runtime、GPU 侧留 kernel 两条记录，ac2g 箭头连接两端，GPU 执行晚于 CPU 提交。
