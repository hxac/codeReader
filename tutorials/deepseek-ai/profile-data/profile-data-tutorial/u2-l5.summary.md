本讲解析 decode.json（EP128 解码轨迹）中的 DeepEP 低延迟内核 dispatch_ll/combine_ll：两者各执行 235 次，占 GPU 内核总时长 19.0%，轨迹中无任何 normal 版内核。实测推翻「独立通信流」预期：ll 内核与计算内核同在 stream 7，通信-计算重叠靠「RDMA 飞行时间不占 SM」实现，时间线呈「发送段（约 17µs，发完即释放 SM）→ 计算填隙（另一微批的计算，约 105µs）→ 等待段（60~80µs）」三段式，dispatch_ll 时长双峰分布即两段的指纹。本讲引入术语：SM、low-latency（`_ll`）内核、CUDA Graph——整条解码前向由一次 cudaGraphLaunch 回放，3437 个内核共享同一 correlation，使逐内核反查 CPU 算子的方法失效。与 train 的 normal 内核（独立流 27、毫秒级、占 47.1%）构成两代内核形态对比。
