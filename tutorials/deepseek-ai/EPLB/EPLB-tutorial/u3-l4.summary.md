本讲从调用者视角讲 EPLB 的工程集成：闭环是「框架统计 → 负载估计 → rebalance_experts → 应用映射」，库只占中段放置计算，是无状态纯函数；负载预测（README 建议滑动平均）与权重迁移、路由切换都归集成方。上游用 EMA 估计器压制统计噪声，系数 α 权衡响应速度与滞后。下游两表两用：phy2log 驱动权重 gather 重排，log2phy 与 logcnt 驱动路由；-1 padding 须按 logcnt 掩码（第 0 槽位恒有效，可作安全默认），路由须向各副本均分流量以兑现均分假设。重排节奏与迁移开销的权衡也在调用方：迁移量可按新旧 phy2log 差异估算，迟滞触发可拦截无效重排；prefill 与 decode 对应层级/全局两条独立闭环。综合实践产出闭环模拟脚本（漂移负载 + EMA + 每轮重排 + IB 对比），是 u3-l5 变体实验的载体。
