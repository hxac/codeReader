本讲拆解 EPLB 唯一公开入口 rebalance_experts 的三段式结构：输入规范化（weight 统一转 CPU 上的 float32，防整数截断与跨设备同步开销）→ 按整除性分派策略 → 组装逆映射返回。分派条件「num_groups 能被 num_nodes 整除」本质是组-节点对齐可行性检查：可行走层级策略（对应 prefill 较小的 EP 规模），不可行走全局策略（对应 decode 较大的 EP 规模）。核心结论：全局策略没有独立的算法代码，而是「退化复用」——以 (num_replicas, 1, 1, num_gpus) 调用同一个层级函数，其三步自动退化为恒等置换、全局复制与 GPU 级装箱（commit e1100fe 的重构，修复了旧实现只复制不装箱的负载不均）。关键概念：log2phy 是变长副本列表的定长张量化——取全局最大副本数 maxlogcnt 作第三维并以 -1 哨兵铺底，用混合进制扁平地址 phy2log * maxlogcnt + phyrank 一次 scatter_ 写入槽位号，-1 恰落在副本数不足的尾部槽位；phyrank 被入口消费而不外泄，phy2log 与 log2phy 因此构成互逆映射。
