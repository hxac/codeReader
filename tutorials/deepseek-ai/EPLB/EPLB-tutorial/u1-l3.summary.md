本讲覆盖环境搭建、入口接口与输出解读三个模块。EPLB 仓库无打包文件，`eplb` 是纯 Python 模块，唯一第三方依赖是 torch，入口函数统一把计算搬到 CPU，故 CPU 版 PyTorch 即可跑通两层 12 专家示例。唯一公开 API 是 `rebalance_experts`：按 `num_groups` 能否被 `num_nodes` 整除分派层级/全局策略，全局策略以退化参数复用同一实现，并用 scatter 压平索引组装 `log2phy`。三个输出是同一放置方案的三种读法：`phy2log` 为正向表（物理槽位→逻辑专家）、`logcnt` 为副本计数、`log2phy` 为反向表（第三维长为 maxlogcnt，无副本处用 -1 补齐）。物理槽位按「节点→GPU→槽内位置」编码，可用整除公式还原放置图。关键不变量：每行 logcnt 之和恒等于 num_replicas，副本与同组专家不跨节点；参数须满足整除约束且 num_replicas 不小于逻辑专家数，违反即断言报错。
