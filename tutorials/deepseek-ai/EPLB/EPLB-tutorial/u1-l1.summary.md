本讲基于 README 建立概念，不读算法代码。核心问题：专家并行（EP）下各专家负载差异大且随 workload 漂移，“每 GPU 专家数相同”不等于负载均衡，木桶效应使整体速度被最重的 GPU 锁死。解决思路是冗余专家策略：复制重载的逻辑专家形成物理专家以摊薄负载，再启发式装箱到各 GPU；物理专家总数 num_replicas 必须被 GPU 数整除。策略由组数能否被节点数整除分派：能整除走 hierarchical（组打包到节点、节点内复制、再装到 GPU，适配 prefill 小 EP 规模），否则走 global（无视分组全局复制，适配 decode 大 EP，代码中以退化参数复用层级实现）。输出核心是 phy2log 张量，即 [层数×物理专家数] 的“槽位→逻辑专家”表，编号出现两次即被复制，副本成对落在同一节点。EPLB 只负责“负载估计→放置方案”这一步，负载预测（滑动平均）与权重重排均由外部完成；启发式不保证最优，是后续评估实践的伏笔。
