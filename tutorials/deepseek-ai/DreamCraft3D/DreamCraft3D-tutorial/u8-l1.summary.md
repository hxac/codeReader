本讲剖析课程式调度引擎 C() 与 C_max()，前者位于 threestudio/utils/misc.py，后者位于 utils/config.py。C() 解析四种规格：标量直通；三元组补零；四元组（步、值、值、步）做两端钳制的截断线性插值；六元素以上为多段接力，拐点共享、曲线连续。end_step 为 int 按 global_step、为 float 按 epoch 调度，这是隐藏开关；一步宽窗口（如 2000 到 2001 步）是实现阶跃跳变的惯用法，粗阶段正则增压即此。C_max() 取全部拐点值的最大值即全程可达上界，经 cmaxgt0 resolver 在配置期联动 requires_normal、return_comp_normal 等数据与渲染开关；自定义 resolver 须在 load_config 之前注册，custom_import 注入来不及。运行期消费分三类：损失门控、损失加权（self.C 查 lambda_ 表）、引导组件 update_step 刷新扩散时间步区间；时间源必须用 true_global_step，否则导出模式下调度错位到第 0 步。关键术语：课程式调度、截断线性插值、配置期与运行期、可达上界、连续插值与离散换挡之别。
