本讲聚焦训练产物与网格导出。试验目录 `outputs/<name>/<tag>@时间戳>/` 由 `ExperimentConfig.__post_init__` 创建；`parsed.yaml` 已固化 timestamp，故导出与续训写回原目录。目录内容由回调与日志器仅在 `--train` 模式填充：`ckpts`（ModelCheckpoint，save_last、每阶段末存档）、`code`（CodeSnapshotCallback）、`configs`（parsed.yaml 与 raw.yaml 快照）、`tb_logs`、`csv_logs`，`save/` 承接渲染图与导出资产。`--export` 借道 `trainer.predict`：`on_predict_start` 按 `exporter_type` 注册名构建 mesh-exporter 并共享 system 的 geometry/material/background，`on_predict_epoch_end` 才真正导出，产物为 `save/it{N}-export/` 下的 obj+mtl+贴图，命令须传 `resume=` 以恢复 true_global_step，否则 N 为 0 且权重随机初始化。mesh-exporter 烘焙流程为 xatlas UV 展开、UV 空间光栅化、反查表面坐标、逐像素查询颜色 MLP、inpaint 补缝；导出器与渲染器各持独立的 NVDiffRasterizerContext，gl/cuda 后端按环境分别配置。
