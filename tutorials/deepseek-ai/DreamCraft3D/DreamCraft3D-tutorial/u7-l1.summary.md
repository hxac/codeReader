本讲精读 prompt processor：base 基类与 deep-floyd/stable-diffusion 两个子类。它在系统 configure 阶段一次性把 prompt 编译为嵌入——构建 side/front/back/overhead 四方向模板，spawn 子进程编码并按 md5(模型名+文本) 缓存到 .threestudio_cache，训练期只查表。运行时由 PromptProcessorOutput.get_text_embeddings 做视角相关提示（缓解 Janus 多面问题）：方位角经 shift_azimuth_deg 归一到 [-180,180)，按阈值（默认 45/45/60，严格不等式；texture 阶段收紧为 30/30）选方向嵌入，返回 cond 在前、uncond 在后的 2B 行。perp-neg 三段式嵌入将正向条件按方位角在 front/side/back 间线性插值，两条负向嵌入配移位指数衰减权重（端点归零），coarse 开启、texture 关闭。两个子类的分工由 guidance UNet 交叉注意力维度决定：coarse 用 T5（77×4096），texture 用 CLIP（77×768/1024），故 processor 与 guidance 必须共用同一模型路径。
