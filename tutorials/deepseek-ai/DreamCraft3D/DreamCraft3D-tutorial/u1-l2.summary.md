本讲解决 DreamCraft3D 流水线跑通前的环境关卡。核心结论：显存门槛以 README 的 ≥20GB 为准（docs/installation.md 的 6GB 属上游 threestudio 数字）；官方仅测试两套 torch+CUDA 版本组合。安装最大坑点是三个需现场编译却不在 requirements.txt 里的 CUDA 扩展——nerfacc、tiny-cuda-nn、nvdiffrast，须先装 torch 与 ninja 再装它们，预处理另需 carvekit、gdown。Docker 路径基于 CUDA devel 镜像固化安装顺序，按显卡架构改 TORCH_CUDA_ARCH_LIST 可提速，容器内需加 context_type=cuda 规避 OpenGL 光栅化报错。预训练权重分两类：Zero123（stable_zero123.ckpt）与 Omnidata 深度/法向模型须手动下载并放入 load/ 下被代码硬编码的子目录（load/omnidata 需自建，放错路径即报 FileNotFoundError）；DeepFloyd IF（gated 模型，需同意许可并登录）与 Stable Diffusion 2.1 则由 HuggingFace Hub 首次运行时自动下载缓存。load/ 自带的 tets、lights、images 及 Zero123 结构配置分别服务于 DMTet 几何、网格导出光照与示例数据。
