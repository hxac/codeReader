本讲拆解 FPDT（全流水线分布式 Transformer，即 Ulysses-Offload 的底层系统）：把全局序列按 chunk 切块、逐块做前向与反向，块内复用 Ulysses 的 all-to-all，块间以 fp32 流式 softmax（lse 合并）保证与整段注意力数值等价，激活峰值从整段序列降到常数个 chunk。模块包括 FPDT_InputConstruct（几何校验、因果尾部 padding、round-robin 负载均衡分块，#9059）、全驻 GPU 与 SequenceChunk 双缓冲主机卸载两条分块注意力路径（只算 k≤i 的块对、仅对角块加因果掩码）、FPDT_LogitsLoss 分块损失。核心契约：padding 标签用 0 加零权重（backward 按标签直接索引，不认 ignore_index）；使用方须先在零权重位置把损失置零（防 inf*0=NaN），再除以 SP 全局权重和（容忍空 rank）；因果性保证真实 token 看不见 padding。
