本讲义绘制 DeepSpeed 仓库代码地图。顶层目录按「使用时刻」分四类：运行期核心 deepspeed/、安装期工具 op_builder/ 与 accelerator/、内核源码 csrc/、工程设施（bin/、tests/、docs/ 等）；训练运行时的心脏在 deepspeed/runtime/（引擎、配置、ZeRO、流水线、混合精度优化器）。公共 API 面由 deepspeed/__init__.py 的 import 块定义，日常入口仅 initialize() 与 init_inference()，并恪守「懒加载」与「import 不初始化 CUDA」两条约束（HAS_TRITON 延迟计算、dist 延迟绑定）。关键术语：「算子三件套」＝csrc CUDA 源码＋op_builder 编译配方＋deepspeed/ops Python 前端，顶层目录经 symlink 双轨同时服务安装期与运行期；「模型族包」deepspeed/models/（首个家族 glm_moe_dsa，import deepspeed 不导入，可选依赖仅由该家族用户承担）。本周期新增模块均落位已有目录：segment-KI 段式内核注入、fused_glu 三件套、TP=2 custom_collective all-reduce、affine 链路标定；initialize() 另新增 AutoSP 前置校验并自动创建 mesh device。
