本讲义绘制 DeepSpeed 仓库代码地图。核心结论：顶层目录按使用时刻分四类——运行期核心 deepspeed/、安装期工具 op_builder/ 与 accelerator/、内核源码 csrc/、工程设施（bin、tests、docs 等），沿「安装→导入→启动」生命周期给每个目录定位。主包分层：runtime 是训练运行时心脏（engine、config、zero、pipe、fp16 等子系统，文件名即功能名）；ops 为算子 Python 前端；op_builder 为编译配方；csrc 为 CUDA 内核。精读 deepspeed/__init__.py 得出公共 API 面很小，日常入口仅 initialize 与 init_inference 两个函数。引入关键术语：懒加载（HAS_TRITON 延迟计算、dist 延迟绑定、import 不得初始化 CUDA）、符号链接与双轨布局、算子三件套、门面包、JIT 编译。产出物为读者自标注的目录地图，作为后续讲义的坐标系。
