本讲绘制 DeepSpeed 仓库代码地图。核心结论：顶层目录按使用时刻分四类——运行期核心 deepspeed/、安装期工具 op_builder/ 与 accelerator/、内核源码 csrc/、工程设施 bin/tests/docs 等；主包呈「runtime→ops→op_builder→csrc」四层分工，runtime/ 是训练运行时心脏（引擎、配置、ZeRO、流水线、混合精度优化器均在其子树）；一个高性能算子由三件套构成：csrc 内核、op_builder 编译配方、ops Python 前端，三个 symlink 打通安装期与运行期双轨。关键术语：公共 API 面（由 __init__.py 定义，日常入口仅 initialize 与 init_inference）、懒加载（HAS_TRITON 延迟计算、dist 延迟绑定）、「import 不初始化 CUDA」约束、JIT 编译、门面包再导出、模型族包 deepspeed/models/（首族 glm_moe_dsa 对应 GLM-5.2，不被 import deepspeed 导入，可选依赖 TileLang 仅由家族用户承担，入口在建模后、initialize 前调用）。
