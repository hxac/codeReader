本讲精读 `DeepSpeedZeroOptimizer`（stage_1_and_2.py）：ZeRO-1/2 参数不切分，仅切优化器状态（Stage 1）与梯度（Stage 2）。核心是 IPG（独立并行梯度）流水线：反向中梯度就绪即入桶，桶满立即 reduce-scatter（默认）或 all-reduce，结果落入本 rank 梯度分区，通信与反向计算重叠，桶大小与 overlap_comm 双缓冲决定重叠深度。step() 时序为溢出检查→全局范数→裁剪→更新 fp32 分区→写回 bit16→all-gather。关键术语：IPG 桶、expert-DP/EP 组、折叠（AutoEP+AutoTP）、请求边界、host 梯度分区、紧凑梯度分区（Muon 组除外）。修复要点：Adagrad 构造期初始化状态，须用 param_groups 重建；从主机恢复梯度前先清零共享 scratch；折叠专家范数改为在 expert-DP 与 EP owner 组上求和、豁免专家平均；CPU 卸载累积重构为按分区组主机累计器，紧凑分区在请求边界发布、仅当 host 可逐位恢复才释放（retain_gpu_grad_partition_until_step），每步清零 FP32 分区梯度防空闲参数复用旧和，溢出检查针对 cast 到 host 精度后的值。
