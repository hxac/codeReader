本讲为 ZeRO 单元框架篇。混合精度训练每卡模型状态显存为 16Ψ 字节（参数与梯度各 2Ψ、优化器状态 12Ψ），ZeRO 按数据并行度依次切分优化器状态、梯度、参数，构成 stage 1/2/3，每卡显存逐级下降，stage 3 降至 16Ψ/N_d。ZeroStageEnum（int 枚举）是阶段语义的权威定义；引擎 _configure_zero_optimizer 负责分发：stage 0/1/2 共用 DeepSpeedZeroOptimizer（以 partition_grads 区分 1 与 2），stage 3 走 DeepSpeedZeRoOffload 或 Stage3 优化器。配置面由 pydantic 模型 DeepSpeedZeroConfig 承载，卸载分 offload_optimizer（stage 1/2/3）与 offload_param（仅 stage 3），对应 ZeRO-Offload/Infinity。本周期新增 retain_gpu_grad_partition_until_step（默认 false），仅作用于 ZeRO-2＋CPU 优化器卸载＋fp32 累积的紧凑梯度分区路径：默认在请求边界释放 GPU 分区、下次 backward 从 host 恢复；置 true 则驻留至 step()，以显存换主机拷贝且不改变训练结果。关键术语：模型状态、请求边界、紧凑梯度分区、卸载。
