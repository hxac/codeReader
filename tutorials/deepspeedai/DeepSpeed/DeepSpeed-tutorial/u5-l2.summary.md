本讲承接 u5-l1，讲解 zero.Init 上下文如何把 ZeRO-3 参数切分提前到模型构造期：它 patch nn.Module.__init__，在每个子模块构造完成的瞬间广播对齐初值并 partition()，拆掉「单卡须先装下完整 fp32 模型」的构造期显存墙；切分后 param.data 只是 0 元素占位符，数据存于各 rank 的 ds_tensor 分区，规则是按 world size padding 后等长分桶，小于持久化阈值的参数可豁免。取回由句柄家族承担：默认合并 all-gather，可配置 all-reduce，单 rank 走 NoGather；#8843 起混合 dtype 分区按 dtype 拆桶。register_external_parameter 为不在宿主 forward 里使用的权重补上取回/释放钩子。#8843 收尾钩子 _keep_in_fp32 在模块 __init__ 末尾、检查点加载前，把 transformers 点名的参数/缓冲就地转回 fp32 分区，修复 bf16 下 MoE 路由 bias 塌缩；量化分区保持量化，参数卸载只保 buffers。
