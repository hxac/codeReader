本讲是全书第一讲，不写代码，只建立读源码的坐标系。核心结论：DeepSpeed 是面向超大模型训练与推理的底层加速库，解决三大痛点——显存墙（混合精度+Adam 下模型状态约需 16Ψ 字节，7B 模型即超百 GB）、通信墙（卡间通信时间逼近计算时间）、训练吞吐。代表性创新为 ZeRO、ZeRO-Infinity/Offload、3D 并行（数据+张量+流水线）、Ulysses 序列并行与 DeepSpeed-MoE。关键术语：参数量 Ψ、数据并行（每卡存完整副本，是显存冗余根源）、ZeRO（把优化器状态/梯度/参数切分到各卡，以通信换显存）。本讲测绘三个门面文件：README 是能力矩阵（新闻看方向、集成表看生态位——它是被 Transformers/Accelerate/Lightning 调用的库、CI 表暗示多硬件抽象层的存在）；docs/_pages/training.md 是官方能力矩阵展开版，暴露核心 API（initialize/backward/step/checkpoint）；版本传递链为 version.txt（0.19.9）→ setup.py → deepspeed.__version__/__git_hash__。方法上强调 README News 与 git log 双轨对照，当前活跃方向是 ZeRO 卸载、专家并行（AutoEP）、混合引擎/张量并行。
