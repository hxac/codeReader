本讲为 DeepSpeed 建立全景：它是大模型训练的底层加速库，直面显存墙、通信墙、训练吞吐三大痛点。显存墙源于数据并行每卡复制完整模型状态（约 16Ψ 字节）；招牌技术 ZeRO 反其道行之，把优化器状态、梯度、参数逐级切分到各卡、用时再聚合，以通信换显存，同族创新还有 ZeRO-Infinity/Offload、3D 并行（数据+张量+流水线）、Ulysses 序列并行与 MoE。本讲只读门面文件：README 提供能力矩阵与生态位——它是被 Transformers 等上层框架集成的库，多硬件 CI 预示加速器抽象层；training.md 是官方特性清单，核心 API 仅 initialize、backward、step 等几个；版本号由 version.txt 经 setup.py 传递为 `__version__` 与 `__git_hash__`（当前 0.19.10）。方法上以 README News 与 git log 双轨对照判断项目活跃方向。
