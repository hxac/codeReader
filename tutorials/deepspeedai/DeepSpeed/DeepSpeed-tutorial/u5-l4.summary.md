本讲讲解 ZeRO-Offload：offload_optimizer 设为 cpu 或 nvme 时，优化器计算都会搬到 CPU（参数卸载则仅 ZeRO-3 可用）。卸载后 GPU 只留 bit16 参数，fp32 主权重分区、梯度分区与 moments 移至 CPU；参与搬运的缓冲默认页锁定（pin_memory），non_blocking 拷贝因此真正异步。DeepSpeedCPUAdam 由薄 Python 壳与 C++ SIMD 内核构成：惰性创建 Adam 状态，按「参数精度×状态精度」五种组合分发向量化实现，较 torch AdamW 快 5–7 倍。本周期新增基类 DeepSpeedCPUOptimizer 覆盖 load_state_dict，修复 torch 将 fp32 优化器状态静默降为 bf16 的缺陷——经 restore_optimizer_state_dtype 按保存值恢复；契约是：step() 用什么 dtype 维护状态，加载时就还回什么 dtype。
