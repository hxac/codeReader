本讲剖析 DeepSpeedConfig：它是「声明式 JSON 到强类型引擎属性」的翻译层，支持字典、hjson 文件、base64 三种输入，构造期依次完成解析（拒绝重复键与已移除键）、batch size 三选二补全、挂载确定性开关与一致性检查，无分布式环境时回退 world_size=1。核心结论：三个 batch 参数满足恒等式「有效 batch＝单卡 micro batch × 梯度累积步数 × 数据并行宽度」，默认值均为 None，写二可推一；读取分两路——顶层标量走 get_scalar_param，嵌套块走 pydantic 模型 DeepSpeedConfigModel（禁止未知字段、过滤 "auto"）；本周期新增的 deterministic_mode 采用「解析在 config、应用在 engine」两阶段设计，应用仅支持 NVIDIA CUDA 且需预设 CUBLAS_WORKSPACE_CONFIG；DeepSpeedConfigWriter 以模板加覆盖反向生成配置。引擎视配置对象为唯一事实来源。
