VisualGen 是与 LLM 后端平行的独立子系统，专做扩散模型（DiT）的图像/视频生成。它复用底层原语（Mapping、QuantConfig、TrtllmAttention 等），但执行器、调度器、请求/参数/输出与流水线架构全部独立，因服务的是去噪而非自回归解码。公共 API 三件套与 LLM 对称：VisualGenArgs（引擎级，≈TorchLlmArgs）、VisualGenParams（请求级，≈SamplingParams，字段默认 None 表"用模型默认"）、VisualGenOutput（≈RequestOutput，带 .save() 落盘），产物是像素张量而非 token。多 GPU 用进程而非线程，每 GPU 一个 worker 经 ZeroMQ 通信，rank 0 当协调器、rank>0 在构造时转 worker 退出，调用链为 VisualGen→DiffusionRemoteClient→DiffusionExecutor→BasePipeline.infer→denoise 循环→VAE 解码，seed 在公共边界一次性定死。核心纪律是"通用上浮、特有下沉"：模型特有旋钮走 pipeline_config/extra_params，由注册表与 ExtraParamSchema 声明、validate_visual_gen_params 校验；公共面（tensorrt_llm/visual_gen/）与内部面（_torch/visual_gen/）二分，规矩见 ENGINEERING_CRITERIA.md。
