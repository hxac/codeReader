本讲拆解 TRT-LLM 注意力的「四层栈」：模块层、后端层、运行时契约、KV 缓存语义。标准 `Attention(nn.Module)` 是围绕后端的外壳，做 QKV 投影、TP/CP 切分、RoPE、`convert_qkv` 格式适配与输出投影，不碰 softmax 与 QK^T；分数计算和 KV 缓存读写都在后端 `self.attn.forward`。MLA（DeepSeek 系）用低秩压缩把 KV 压成潜表示，generation 路径用「权重吸收」把上投影 W_UK 折进 Q、在潜空间算注意力而免解压历史 KV，context 路径则展开成完整 K/V 走标准 MHA。引入的关键术语：`AttentionMetadata`（批次级、每步一份、所有层共享）、`AttentionForwardArgs`（每层现造）、`KVCacheParams`/`CacheType`、`rope_fusion`、潜缓存（`kv_factor=1`，区别于标准 K/V 的 `kv_factor=2`）；模块层与后端的唯一正式数据通道是 `(q,k,v,metadata,forward_args)`，`**kwargs` 仅为临时兼容。改 attention 前须读 `ATTENTION_DEVELOPER_GUIDE.md` 做四问 fit 检查，优先扩模块层扩展点、再扩 TRTLLM 后端、最后才考虑新后端；后端家族与分页 KVCacheManager 留待后续讲义展开。
