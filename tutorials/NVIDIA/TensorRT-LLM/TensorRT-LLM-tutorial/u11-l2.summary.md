本讲讲分离式服务（disaggregated serving）：把 prefill（context 实例，算力密集）与 decode（generation 实例，带宽密集）解耦到不同 GPU 池，由 OpenAI 兼容的编排器 orchestrator 串联两阶段、跨节点搬 KV cache，从而独立优化 TTFT/TPOT。它不是新引擎，ctx/gen 实例就是普通 trtllm-serve。

三个最小模块：(1) 分离角色——编排器给请求注入 request_type（context_only/generation_only），context 算 KV 与首 token，generation 跳过 prefill 直接接力。(2) KV 搬运——KvCacheTransceiverV2 把请求占用的物理 block 封成 KVSlice 经会话异步收发，接收侧轮询并做全 rank 共识判定完成，底层 NIXL/UCX/MPI/MOONCAKE 可替换。(3) 协调与身份——coordinator（owner 版 DisaggCoordinatorService 或代理版 CoordinatorClient）+ worker fleet（SO_REUSEPORT）水平扩展编排器；雪花算法本地自产全局唯一 disagg_request_id 配对 KV；token identity 两道闸：router 的 Harmony 感知分词保证 block 哈希一致，C++ 按 pool 解析 attention cache dtype 保证 KV 字节精度正确。
