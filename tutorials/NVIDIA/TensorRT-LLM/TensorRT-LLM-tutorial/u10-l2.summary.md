本讲解析 TRT-LLM 量化子系统：量化以更窄低精度类型表示权重/激活/KV cache，靠缩放因子补偿精度，缩放粒度（per-tensor/per-channel/per-block）决定精度与开销折中。核心是三层结构：描述层中 QuantConfig 为纯描述、不含计算，QuantAlgo 字符串枚举经 QuantMode.from_quant_algo 翻译为 QuantMode 位标志（须与 C++ 头文件 quantization.h 同步）供 kernel 查询，LayerQuantConfig 支持逐层混合精度；加载归一化层用适配器模式把 ModelOpt legacy/flat、compressed-tensors、原生 fp8/mxfp4/nvfp4/mxfp8 等多种 checkpoint 格式归一化为统一 QuantConfig 并做合法性校验（如 FP8_BLOCK_SCALES 只认 group_size=128）；kernel 层量化 op 挂 trtllm:: 命名空间，命名遵循 trtllm::<精度>_<算子>[_<后端>] 与 QuantAlgo 基本一一对应，权重布局 preprocess_weights_for_mixed_gemm 在加载期一次性完成。KV cache 量化（FP8/INT8/NVFP4）由 kv_cache_quant_algo 正交叠加。关键术语含 QuantConfig/QuantAlgo/QuantMode、custom_ops、torch.library.custom_op 与 mutates_args=() 纯函数语义（为 u10-l4 CUDA Graph/torch.compile 埋伏笔）、exclude_modules 逐级上溯匹配。
