本讲打开 u3-l2 单步循环中被当作黑盒的「前向」，覆盖三个模块。ModelEngine 是引擎的抽象契约：须实现 forward 与 get_max_num_sequences，可选覆盖 warmup，使 PyExecutor 与具体后端解耦。PyTorchModelEngine.forward 以 ScheduledRequests 与 ResourceManager 为输入，内部先构造注意力元数据，再把请求翻译成 inputs 张量字典，经 CUDA Graph 回放或 eager _forward_step 两条路径，最终汇聚到同一次 self.model.forward，产出含 logits 的字典。加载侧，ModelLoader 经校验配置、建骨架、装权重、post-load 四步把 checkpoint 变成可前向模型；ModelConfig 包裹 HF 的 pretrained_config，并携带量化、并行、注意力后端等运行时开关，创建后即冻结，桥接加载期与前向期。引入的关键术语：ModelEngine、PyTorchModelEngine、ModelLoader、ModelConfig、attn_metadata、logits、CUDA Graph 回放、warmup、load_format。
