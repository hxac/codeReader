本讲打开 TensorRT-LLM 中被当作黑盒的 MoE（混合专家）子层，围绕 `fused_moe/` 目录讲清三个最小模块：路由（router 给每个 token 选 top-k 个专家，实现稀疏激活，以「大总参数、小单次算力」翻越算力墙）、`ConfigurableMoE` 编排器（以组合而非继承拼装「后端（纯计算）+通信+EPLB+调度器」四个独立组件，拥有模块生命周期、前向委托调度器）、后端家族与工厂选择（由 `moe_backend` 经工厂按「量化方案×SM 代际」匹配，不匹配时回退 Cutlass）。引入的关键术语：专家、门控/路由、top-k、专家并行（EP）、slot、融合 GEMM、EPLB、EXTERNAL_COMM 与 FUSED_COMM 两套调度器（前者 host 编排 dispatch/combine、后者通信融进 kernel、零 token 也须启动）、MegaMoE。核心结论：后端只做纯计算并以 `can_implement`/`scheduler_kind` 声明能力；Triton 是 Hopper/GPT-OSS 的 legacy 后端、DeepGemm 是 Blackwell/FP8 Block Scales 的新路径后端；EPLB 用 slot 间接层动态迁移热点专家，统计在 GPU、迁移在 CPU 重叠；新功能须走 ConfigurableMoE+Backend+Scheduler 架构，后端不得内嵌通信或前向策略。
