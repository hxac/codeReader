本讲解答模型架构自带的「最佳实践默认值」如何合并进 `llm_args`，含三个模块。一是模型默认值：模型类覆盖 `get_model_defaults`，返回一个与 `TorchLlmArgs` 结构同构的嵌套字典，于 `ModelLoader.load_config_and_apply_defaults`（加载 config 之后、构建模型之前）注入。二是三层深度合并 `apply_model_defaults_to_llm_args`，优先级为「框架默认 < 模型默认 < 用户显式」——靠 `model_dump(exclude_unset=True)` 单独抽出用户字段叠到最上层，从而保证用户永远赢、模型默认只填空；合并时重建对象触发 Pydantic 校验，并禁止默认值携带 `cache_transceiver_config` 以防越权。三是 `auto` 占位符在合并后统一解析：`use_kv_cache_manager_v2` 取模型默认值、无则退回 False；`transceiver_runtime` 采纳模型 `get_preferred_transceiver_runtime` 偏好，但后端不支持时降级到 C++，且未启用分离式服务时不擅自造配置。`_compute_applied` 返回真正生效的默认值供日志使用。核心设计原则贯穿始终：用户意图优先、模型建议补位、安全护栏兜底。
