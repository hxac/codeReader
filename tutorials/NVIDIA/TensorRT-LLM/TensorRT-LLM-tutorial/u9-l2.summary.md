本讲承接 u9-l1 的 Mapping 拓扑，讲解分布式推理中 rank 间「如何通信」，核心是区分控制面与数据面。控制面传输 Python 对象与小标量（采样参数、调度元信息），由抽象基类 Distributed 承担，按 MPI / torch.distributed 分裂出 MPIDist 与 TorchDist，经 lru_cache 全局单例化，提供 broadcast/allgather 及 TP/CP/PP 分组变体；数据面传输大张量，由 AllReduce、MoeAlltoAll 与流水线 P2P 通信承担。AllReduce 是张量并行最高频通信，AllReduceStrategy 从通用 NCCL 到专用 MULTIMEM 共十档，正交叠加 AllReduceFusionOp 融合算子；其实现遵循「初始化探测能力、forward 逐层尝试并失败回退」模式，依次试 symm_mem_allreduce（NVSwitch + MULTIMEM 硬件多播规约，小张量低延迟）、MNNVL，最后退到 AUTO/NCCL；而 allreduce_helper 则用 IPC 缓冲加 Lamport 三缓冲管理自定义 kernel 工作区，覆盖面更广且支持融合。MoeAlltoAll 是专家并行的定向交换：dispatch 按路由散出 token、combine 收回专家输出并加权合并、中间夹 GroupGEMM，由 phase 状态机强制配对，负载由 router 决定，区别于 AllReduce 的「全员相同结果」。DeviceMesh 则把 pp→tp→cp 拓扑维度映射为 ProcessGroup，内层连续以适配 NVLink。
