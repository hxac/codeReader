本讲承接 u1-l1 的高空视图，解决 TensorRT-LLM 的落地安装问题，核心结论是：它是 Python + C++/CUDA 混合库，Python 部分可 pip 安装，C++/CUDA 二进制只能来自预编译 wheel 或本地编译——这是区分三种安装方式的钥匙。内容分三个最小模块：一是依赖声明，仓库已升级到 CUDA 13 系列（`cu130`），强绑定 PyTorch `>=2.11.0,<=2.13.0a0`、Python `>=3.10`，transformers/flashinfer 精确钉版，版本错配会因 ABI 不对齐而崩溃；`requirements.txt` 经 `setup.py` 的 `parse_requirements()` 固化进 wheel，pip constraints 文件用于锁住 torch 防被替换。二是安装指南，按从简到繁为预构建容器、pip 安装、从源码构建，NGC 容器分 `devel`/`wheel`/`release` 三镜像，`docker run` 须带 `--ipc host` 等标志。三是构建脚本，`setup.py` 作为二进制发行（`BinaryDistribution`）负责版本、入口命令（`trtllm-serve`/`bench`/`eval`）与 `sanity_check`，`TRTLLM_USE_PRECOMPILED=1 pip install -e .` 是纯 Python 开发的免编译极速路径，真正编译 C++ 的入口是 `scripts/build_wheel.py`。
