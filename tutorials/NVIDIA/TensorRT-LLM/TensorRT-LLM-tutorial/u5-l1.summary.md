本讲剖析 PyTorch 后端 decoder-only 模型的三段式架构范式。核心结论是「三层分工 + 复用多覆盖少」：`DecoderModelForCausalLM` 作外壳，统一负责 lm head、logits、权重加载、流水线切分与投机解码挂载，其 `forward` 不含任何模型特有逻辑，由元类 `PostInitCaller` 自动串联 `__post_init__`（量化/create_weights）与 `__pp_init__`（切层），配合 meta 设备省显存；`DecoderModel` 作骨干，提供「embed→逐层→norm」的最小契约模板；`DecoderLayer` 抽象基类规定单层 forward 签名并提供 PP 的 `skip_forward`。引入的关键术语：骨干/外壳二分、`(hidden, residual)` 残差流、RMSNorm 融合调用、跨层 norm 链（`setup_aliases` + `skip_input_layernorm`）、`get_model_defaults` 模型默认值。重要命名澄清：仓库无字面 `Decoder` 类，「Decoder」即 `DecoderModel`，Llama 骨干是 `LlamaModel`。写新模型工作量几乎全在 `Model` 与 `DecoderLayer` 两个类，外壳零成本——为 u5-l3 添加新模型铺垫。
