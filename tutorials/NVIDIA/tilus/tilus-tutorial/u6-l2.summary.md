本讲讲解后端如何用「发射器（emitter）」把单条 Tilus 指令翻译成 Hidet IR，核心方法是 emit(inst)。BaseInstEmitter 作为基类继承 StmtBuilder，提供 get_or_allocate_var（张量↔变量惰性映射）、sync、线程组查询等通用能力；具体发射器近乎无状态，共享上下文集中在 FunctionCodegen 上。全局注册表 REGISTRY 是「指令类 → {target → 发射器类}」两层字典，由 @register_emitter 在 import 期填充，缺省 target 为 gpgpu_any，重复登记即报错。派单分两步：resolve_inst_emitter 用 issubclass 定桶取首个命中，match_target 用 Target.supports 过滤后取算力最高者。visit_Instruction 要求发射器为 inst.output 建立 tensor2var 映射。以 CastInst 为样本，它用 (src_dtype, dst_dtype) 特化表在 PTX 向量化实现（prmt/lop3/f16x2）与逐元素通用 cast 间分派并按对齐自动回退；同指令在 NVIDIA/AMD 上挂不同发射器，体现 target 分发价值。
