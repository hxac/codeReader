本讲讲解 RegisterLayout 的静态结构与映射机制，回答寄存器张量元素如何分配给线程。核心是 mode 与 mode_shape：把张量维度细分为多个 mode，grouped_modes 记录每个维度含哪些 mode。RegisterLayout 由四个字段唯一确定——shape、mode_shape、spatial_modes、local_modes，须经 register_layout 工厂校验并规范化。mode 分两类：spatial modes 跨线程分布（线性化得 thread_id），local modes 区分线程内槽位（得 local_id），二者不可共用同一 mode；负数 mode -k 表示复制，元素被 k 个线程共持，使 get_spatial 返回列表。三个不变量为 spatial_size（线程数）、local_size（每线程元素数）、size（总元素数）。MultiFunction 把「逻辑索引→线程号集合」抽象为可复合的多值函数，spatial_mfunction 即此映射，get_local/get_spatial/get_global 提供正反查询，无复制时为自洽双射。
