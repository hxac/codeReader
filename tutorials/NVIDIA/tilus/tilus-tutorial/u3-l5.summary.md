本讲介绍阅读与调试 Tilus IR 必备的四件套工具，均建立在只读访问者 `IRVisitor` 之上，按「校验、打印、收集」三个最小模块展开。`verify(prog)` 是 `build_program` 的第 0 步合法性校验，由增量式 `IRVerifier` 收集全部 `Diagnostic` 后一次性抛出 `VerificationError`，接收 `Program`，新增检查只需添加 `visit_<InstClass>` 方法。`IRPrinter`（配 `PrintContext`）将 IR 渲染成形似 Python 的可读文本，依靠身份相等的 dict 对张量/变量自动命名（`%r0/%s0/%v0`）、折叠长布局、行尾加类型注释，并经 `IRNode.__str__` 无缝接入，`print(func)` 即可用。`collect(node, types)` 复用 `IRVisitor.memo` 做通用过滤；`collect_instructions(func)` 按 `visit_Instruction` 顺序累加指令，接收 `Function`，是测试里统计指令数量的标准工具。关键陷阱：`visit_Expr` 不下钻 Hidet 标量表达式，`collect` 收不到藏在表达式内部的 `Var`，须改用 `hidet.ir.tools.collect`。这三件套构成「校验→打印→收集」的典型调试工作流，并为后续 Pass 框架奠基。
