本讲承接「通用指令+硬件指令组」分层模型，讲三块通用层能力。控制流：`self.range` 比内置 range 多一个 `unroll`（None/"all"/n）提示，被转译成 `ForStmt`，渲染为 `#pragma unroll`，是提示而非强制展开。线程组：`with self.thread_group(thread_begin, num_threads)` 把一段代码的执行权收窄到一段连续线程，`single_thread / single_warp / warp_group` 是其快捷方式；`thread_begin` 相对父组，经 `ThreadGroupStack` 累加成绝对线程号，可嵌套以做 producer-consumer 分工；`single_thread()` 默认 elect-any（begin=-1），让硬件用 elect.sync / 统一谓词挑选线程、避免发散；`self.sync()` 只同步当前线程组。assume：`self.assume(a % c == 0)` 是单向编译期承诺（不检查、不报错），经 `lower_assume` 解析为 `metadata.param2divisibility`（多次取 lcm）并消除指令，再被标量分析消费以支撑界感知化简；真正的编译期断言改用 `static_assert`。三者在 IR 里分别产出结构性语句（ForStmt、ThreadGroupStmt）或提示性指令（AssumeInst）。
