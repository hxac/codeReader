本讲讲解 `ops/` 下的布局代数——把「逻辑索引→物理位置」映射当对象做代数运算的函数库，是布局推理（u4-l5）与后端发射器（U6）的共同底座。要点：(1) 三大构造原语 `spatial`（全分布到线程）、`local`（全存线程局部）、`replicated`（多线程各持一份，以负数 mode 表示复制），且 `RegisterLayout.__mul__`/`__truediv__` 即 compose/divide；(2) 核心运算 `compose(outer, inner)` 逐维度把 outer 的 mode 置前、inner 置后拼接，shape 逐维相乘、mode 总数相加，spatial/local 各自重编号后顺序拼接而类别不变；(3) `divide`/`left_divide` 是 compose 的右/左逆，分别剥除后缀内层与前缀外层，除不尽抛 `LayoutOperationError`；(4) 形状变换中 `reduce` 把归约维的 spatial mode 改为复制而非删除以广播结果，`reshape` 只能在 mode 边界切分，`permute` 同步重排 mode 与类别；(5) `MultiFunction` 上的 `cover`（判断线程映射的覆盖关系）与 `collapse`（塌缩维度区分度）是布局等价性验证工具，被 `AssignRule` 等推理规则调用。
