本讲是「后端与代码生成」单元首讲，聚焦 `build_program` 流水线中的降级步骤 `generate_ir_module`：它把高层 Tilus IR（`Program/Function/Stmt/Instruction`）翻译成贴近 CUDA C 的底层 Hidet IR（`IRModule`），自身不做优化，优化交给后续 `optimize_ir_module`。

核心模块有三个。其一，`ProgramCodegen` 为每个 `Function` 新建一个 `FunctionCodegen`，而一个 Tilus 函数会裂变为一对 hidet 函数：`cuda_kernel`（设备）与 `public`（主机 launch），二者由 `LaunchKernelStmt` 连接。其二，`FunctionCodegen` 作为 `IRFunctor` 子类，采用双重分派——语句骨架（循环/分支/线程组、unroll、elect-any）由 `visit_*` 用 `FunctionBuilder` 复刻，叶子上的指令则交给发射器。其三，指令到发射器的映射走全局 `REGISTRY`（`{指令类:{target:发射器类}}`），`resolve_inst_emitter` 先按 `issubclass` 匹配指令类、再用 `match_target` 挑算力最高者；`launch_kernel` 则在主机侧完成动态共享内存上限设置、`host_params + extra_params` 参数拼接与 `normalize_dim3` 规格化。

关键术语包括：两层 IR、设备/主机函数分离、发射器（继承 `BaseInstEmitter`）、target、`tensor2var`/`extra_params`、`EmitContexts` 九上下文、`visit_Instruction` 注释溯源钩子。本讲只覆盖调度骨架，发射器内部实现与 `EmitContexts` 细节留待后续讲义。
