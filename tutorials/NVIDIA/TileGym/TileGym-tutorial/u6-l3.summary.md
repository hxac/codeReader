本讲承接 u6-l1 的 FMHA 与 u6-l2 的 Split-KV，讲解 DeepSeek 系列的多潜注意力（MLA）。MLA 用低秩潜向量压缩 K/V 以压低 KV 缓存；因 RoPE 与低秩吸收不兼容，改用解耦位置编码——注意力分数 = 内容相似度 q·k（维 D）+ 位置相似度 qpe·kpe（维 D_PE），两段共享同一 softmax，缩放取 1/sqrt(D+D_PE)。内核落地为「同一分数瓦片上累加两次 mma」，这是 MLA 区别于 FMHA 的唯一算术差异，其余 causal 掩码、在线 softmax、exp2、mma(p,v) 均复用 u6-l1。本讲覆盖三个内核：prefill tile_mla（多 query 行 + GQA + tune-once 调优，仅前向、无反向）；单步解码 mla_decoding（query 1 行，按头并行 TILE_H=16，吸收态 kv 兼作 K/V，整条 KV 串扫，返回 (o, l)）；长上下文 mla_decoding_split_kv（沿 KV 切分，kv_len_per_split 控并行度，调 splitk_reduce 按 LSE 合并，仅返回 o）。结论：两种解码 kv 布局完全相同，差别仅在调度；长上下文（CTA 填不满 SM）选 split 版提并行度，短上下文选普通版省合并开销。引入术语：联合位置编码、qpe/kpe、吸收态、按头并行、kv_len_per_split、LSE 合并。
