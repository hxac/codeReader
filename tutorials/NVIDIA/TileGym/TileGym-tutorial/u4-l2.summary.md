本讲以 cuTile 版 silu_and_mul 为唯一样本，讲解如何把手写 GPU 内核接入 PyTorch autograd，含四块：① 用 torch.autograd.Function 的 forward/backward 静态方法封装内核，须经 .apply() 调用才在计算图上登记，且 backward 返回值个数须与 forward 输入（不计 ctx）一一对应；② save_for_backward 与 saved_tensors 是前向留给反向的唯一数据通道，本算子只保存原始 input、不存任何中间激活；③ 反向重计算策略：反向内核从 input 重算 a/b/sigmoid(a)/silu(a)，以可忽略的额外算力换取每个 N×H 激活约 32MiB(fp32) 显存，前提是反向的 sigmoid 近似（flush_to_zero、RMd.APPROX）须与前向逐字一致，梯度公式 db=dc·silu(a)、da=dc·b·silu'(a)，分别写入两个输出缓冲后 cat 回 2H 布局；④ requires_grad 分支：训练走 apply 建图存上下文、推理直调内核并支持 out= 就地写入，requires_grad=True 时禁止 out=；装饰器顺序为 register_impl 在外、ensure_contiguous 在内，不可对调；是否实现反向是逐后端能力——cutile 有完整 autograd、tilecpp 无（测试直接 skip）。
