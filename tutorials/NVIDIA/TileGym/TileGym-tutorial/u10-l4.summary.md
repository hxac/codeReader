本讲解析 TileGym 的 liger suite 训练内核族：算子经 ops.py 的 `@dispatch` stub 统一暴露，cuTile 实现靠 `cutile/__init__.py` 导入副作用注册、受后端可用性门控，与核心 ops 同构。核心覆盖四类：①策略梯度损失 `grpo_loss`，在 grid=(B,L) 一个 block 内串起在线 logsumexp、目标 token 的 logp、PPO 重要性比 `coef_1=exp(logp-old_logp)`、四种 loss_type 分支与可选 KL，一套内核覆盖 GRPO/DAPO/CISPO/SAPO/VESPO 等 RL 变体；②分类与散度损失 CE/JSD/KL/TVD 共用行级在线归约骨架，FLCE 按 4GB 阈值在 single-pass 与 chunked backward-in-forward 间切换，把 logits 峰值显存从 (BT,V) 降到 (chunk,V)，CE 更前向原地写回 d_logits 使反向近免费；③归一化变体 fused_add_rms_norm/poly_norm/dyt 示范持久化寄存器累加、原子累加进 (4,) 缓冲、唯一位置散列三种跨行权重梯度归约范式；④激活 swiglu/dyt 延续 u4-l2 的反向重计算，前向只存原始输入、反向重算激活并叠加原地写回与更快近似（在容差内）。关键术语：stub、`@register_impl`、在线 logsumexp、重要性比、backward-in-forward、原地梯度、持久化调度。
