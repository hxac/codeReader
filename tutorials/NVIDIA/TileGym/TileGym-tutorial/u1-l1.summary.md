本讲为 TileGym 建立全局认知：它是基于 CUDA Tile 的 GPU 内核库，兼具 cuTile 教学场与 LLM 加速示例库两大角色。核心概念是 tile 编程模型——把大数据切成瓦片搬到快速片上存储中反复计算，以绕开内存墙，由此引入 GPU 内核、内存墙、片上存储等术语。

四大特性为内核示例、实用算子实现（覆盖线性代数、Attention、归一化、激活、MoE、RoPE）、性能基准、端到端 LLM 集成。硬件需 Blackwell（CUDA 13.1+）或 Ampere（CUDA 13.2+），软件依赖 PyTorch、Triton 及运行时编译器 tileiras（cuTile 这套 tile DSL 靠它编译）。

关键设计是多后端机制：同一算子名可由 cuTile（默认）、tilecpp、triton、cutile-rs（可选）四种后端实现，由分发机制按当前后端切换，对应顶层 API set_backend 等；再经 monkey-patch 接入 HuggingFace，支持 Llama 3.1、DeepSeek V2、Qwen、Gemma-3 等真实模型。
