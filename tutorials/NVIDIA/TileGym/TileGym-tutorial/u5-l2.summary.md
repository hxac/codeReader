本讲在 u5-l1 分块矩阵乘基础上讲 cuTile 的高阶调度层。核心是「静态持久化 grid-stride 调度」：内核启动与问题规模脱钩、只受 SM 数封顶的 CTA（grid = min(NUM_SMS // num_ctas, num_tiles) × occupancy），每个 CTA 用「起始号 + 固定步长」的循环跨步连续领取多个输出瓦片，复用的是执行体而非累加结果（每瓦片都要归零累加器）。引入 CGA（线程块簇）概念：num_ctas 把多个 CTA 绑成协作组、NUM_SMS // num_ctas 把 SM 数折算为簇槽位，仅 sm90+ 支持；num_ctas 与 occupancy 是编译器 hint，经 replace_hints 一次性烤进带独立 JIT 缓存的新内核对象并与最优配置共缓存，而 TILE_SIZE_*、LOAD_LATENCY、TRANSPOSE 等是内核参数，由 ct.launch 传入。针对大 tile 在小/矩形 GEMM 上把 grid 卡死、闲置 SM（stranded SM），sm100+ 候选本轮新增 128×128 小 tile 把 num_tiles 撑大约 4 倍。group_gemm 则用 last_problem_end 累计偏移把一组形状各异的矩阵乘缝合成一条瓦片流，一次启动算完。
