本讲解析 C++ 运行时中「中间状态如何被自回归步进复用」的缓存管理机制。运行时只对外暴露一个 HybridCacheManager，它组合两个子管理器并按绝对层号路由：KVCacheManager 为每个 attention 层分配线性 KV 缓存 [batch,2,numKVHeads,maxSeqLen,headDim]，随序列长度线性增长、支持 FP16/FP8，是显存大头；MambaCacheManager 为递归层分配固定大小的 recurrent state（SSM 隐状态）与 conv state（卷积滑窗），与序列长度无关，是 SSM 长上下文省内存的根源。两类状态共享「past/present 同址绑定」的原地更新契约，但进度记账不同：attention 靠共享 device 长度张量显式累加，Mamba 则隐式编码在状态中。HybridCacheManager 还统一编排 compactBatch（batch 驱逐压缩）、captureKVCache/restoreKVCache（系统提示缓存）及投机解码的 intermediate 中间态与 scatterAccepted 回写。逐层 layer_types、numLinearAttnLayers 承接 u2-l1，缓存归属 SharedResources 而非执行器，承接 u5-l3。
