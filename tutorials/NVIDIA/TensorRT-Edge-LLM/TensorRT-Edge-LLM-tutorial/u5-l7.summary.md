本讲是 u5 C++ 运行时核心的收尾篇，补齐流水线的两端：输入端分词与输出端采样。采样模块（`cpp/sampler/`）在 GPU 上批量地把 `[batch, vocab]` 的 logits 变成 `[batch,1]` 的 token id。引入四个采样旋钮——temperature（对 logits 乘 1/T 起作用）、topK、topP 及 greedy。由 `shouldUseNonGreedySampling` 分流：默认三元组与近零温度走轻量 `selectAllTopK`（argmax），其余走 `topKtopPSamplingFromLogits`；其中 top-k 是两阶段归约+softmax+curand 采样，top-p 是 softmax+早退+降序排序+前缀和采样，两者二选一。关键术语含 logits、softmax、greedy、top-k、top-p/核采样。分词器（`cpp/tokenizer/`）是 EdgeLLM 自研的纯 C++ BPE 实现，兼容 tiktoken（按 vocab rank 合并）与 SentencePiece（merges 优先级+byte fallback）两种风格；加载需三件 sidecar 文件。编码链路为 `partitionSpecialTokens → normalizer → preTokenizer → BPE`，解码为 `piece 拼接 → byte fallback 还原 → decoder 替换 → UTF-8 清洗`，流式输出靠 `emitDelta` 攒字节保证合法 UTF-8。一次完整 token 来回即字符串→分词→input ids→模型→logits→采样→next token→解码→文本。
