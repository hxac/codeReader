本讲梳理运行时地基 `cpp/common/` 的三个最小模块。**Coords** 是值类型的形状描述，最多 8 维（`kMAX_DIMS`）、可按值传递，提供 `volume()` 连乘元素总数与 `getTRTDims()` 双向桥接 TensorRT 的 `nvinfer1::Dims`，并据此算出行优先步长。**Tensor** 用 RAII 封装一块线性布局内存，区分 **owned**（自申请自释放，按设备走 `cudaMalloc`/`cudaMallocHost`，可 `reshape` 且新体积不超 `memoryCapacity`）与 **non-owned**（外部内存视图，析构不释放）两种所有权。其设计关键为：删除拷贝以防双重释放、仅允许移动并把源置空以维持唯一所有者，这是 `std::vector<Tensor>` 得以工作的前提；子字节类型（INT4/FP4）被 `getTypeSize` 显式拒绝。公共工具含永不析构的进程级单例 `EdgeLLMLogger`（规避 TRT 插件注册表的 use-after-free，级别越小越严重，`LOG_*` 宏直接调 `instance()`）、懒求值的 `ELLM_CHECK`/`CUDA_CHECK` 校验宏，以及 `safetensorsUtils`（`load` 用 owned 构造配 `std::move`、`save` 只用只读接口按设备决定 D2H）。这些是后续 `TensorMap`/`TensorRegistry` 与 KV 缓存视图模式的基础。
