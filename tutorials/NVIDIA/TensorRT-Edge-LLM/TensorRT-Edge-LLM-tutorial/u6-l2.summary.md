本讲讲解 Qwen3-Omni 音频流水线在 C++ 运行时中的三个最小模块。输入侧 `Qwen3OmniAudioRunner`（`MultimodalRunner` 子类）把原始 PCM 提取为 mel 频谱图、跑音频编码器产出 audio embedding，并以占位 token `<|audio_pad|>` 在 prefill 时替换行的方式融合进 thinker 序列；它自持 mel 提取（GPU fbank 优先、CPU 兜底，契约相同），编码器在 preprocess 阶段已跑完，故 `infer()` 为 no-op。输出侧 `Qwen3OmniTTSRuntime`（独立运行时，非 MultimodalRunner）管理 Talker 与 CodePredictor 两台 LLM 引擎，逐帧生成 RVQ 码：每帧第 0 个 code 由 Talker 采样，其余（Omni 共 16 个 code、num_code_groups 主键）由 CodePredictor 用多个 lm_head 动态换绑逐层补齐；Talker 的 KV 跨帧复用、CodePredictor 每帧重置，并有纯文本 TTS、非流式、流式（thinker/talker 同流靠 per-token 回调交错）三种入口。最后声码器 `Code2WavRunner` 将 RVQ 码（需从帧优先转置为层优先）解码为 24kHz 波形，运行时探测 FP16/FP32 dtype，长音频走分块带重叠裁剪拼接。关键常量：帧率 12.5 Hz、`kAudioSamplesPerFrame=1920`、`kAudioSampleRate=24000`。
