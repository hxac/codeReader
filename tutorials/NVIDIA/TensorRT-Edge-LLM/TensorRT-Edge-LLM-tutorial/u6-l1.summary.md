本讲核心是 `MultimodalRunner` 抽象基类，用统一接口 `preprocess → infer → getOutputEmbedding` 调度十几种视觉/音频编码器，`create()` 工厂按 `model_type` 实例化子类。两条视觉范式并存：Qwen-VL 家族采用动态分辨率、`VisionSpan` 双视图（ViT 视图 `gridT/H/W` 与 LLM 视图由 `mergeSize` 换算）、MRoPE（T/H/W 三维位置编码）与 `cu_seqlens`，token 数连续可变；InternVL/Phi4-MM 采用固定块模型，每块硬编码 256 个 token，图像 token 数必须为 256 的倍数，多块图附缩略图，并用标准 RoPE。图文融合的核心约定是「图像 token id ≥ vocabSize」：`textPreprocess` 写入从 `vocabSize` 起递增的占位 id，在 prefill 时由 `embeddingLookupWithImageInsertion` 替换成 ViT 输出行，使 LLM 主干对图像无感。视觉引擎采用 user-managed 上下文内存，与 LLM 执行器复用同一块 `mSharedExecContextMemory`。
