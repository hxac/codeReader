本讲精读路由器数据面的会话密钥管理，主角是 peer.rs 的 KeyWheel 状态机。核心要点：peer 用三层句柄表达——PeerInner 是真实状态、Peer 是可克隆共享引用、PeerHandle 是不可克隆所有权句柄，drop 即删除 peer。KeyWheel 维护 current/previous/next 三个密钥槽：current 用于加密，previous 用于解密仍在路上的旧报文，next 存响应方待确认的新密钥，轮转呈「高位到低位」单向流动。发送只用一个 EncryptionState（单密钥+nonce，存于 peer），接收需多个 DecryptionState（按 receiver id 存于设备级 recv 表，含 AntiReplay），反映收发不对称。add_keypair 双分叉：initiator 密钥进 current 并立即发包确认，非 initiator 进 next；二者同步更新 recv 表并返回退役 id 交还握手层。响应方靠首报文触发 confirmed.swap 完成静默确认，confirm_key 用三次 mem::swap 把 next 转正。无密钥时数据包暂存 staged_packets（容量 1024，Wrapping 覆盖），密钥就绪后 send_staged 补发。Drop 全清理、zero_keys 半清理，密钥材料由 Key::Drop 自动清零。
