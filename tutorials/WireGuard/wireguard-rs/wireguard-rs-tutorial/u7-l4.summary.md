本讲（收尾篇）讲 wireguard-rs 如何在无真实网卡、无 root 时端到端验证「握手→加密→路由→解密」链路。核心是 dummy 平台用 mpsc 通道替代系统调用，使协议核心能在 cargo test 里跑通；test_pure_wireguard 把两个实例背靠背对接做核心回归，断言报文逐字节相同、按序送达。make_packet 用确定性 PRNG 填充载荷，借 pnet 构造字段合法的 IP 测试报文。本讲引入三类测试术语：回归测试、proptest 属性测试（验证 cookie 的 mac1/mac2 闭环与 DH 共享密钥唯一性，能收缩最小失败用例）、对保序队列 Queue 的并发模糊测试（守护「恰好一次、按序、最终排空」三不变量）。路由器数据面另用 EventTracker 把异步回调转为可按序断言的事件流。
