本讲为 wireguard-rs 建立全局视角。核心结论：WireGuard 的设计哲学是「握手与数据面分离」——握手模块用 Noise IK（Curve25519 DH）协商出对称会话密钥，交给路由器（packet protector）对传输报文做对称加解密（ChaCha20-Poly1305）与路由；二者均跑在 UDP 隧道之上，定时器驱动密钥过期与重握手。wireguard-rs 是 WireGuard 的纯 Rust 用户态实现，对标官方内核模块，README 建议生产 Linux 改用内核模块，其价值在于无内核模块的平台及作为可嵌入协议库；协议核心 src/wireguard/ 刻意不依赖具体 IO，既可配 platform::linux 跑生产，也可配 platform::dummy 跑测试。引入的关键术语：Noise IK、会话密钥、握手/路由器分离、packet protector；三大外部接口——TUN（与内核交换明文 IP 包）、UDP（交换密文报文，延迟绑定）、UAPI（文本控制协议，对接 wg(8)）；三大顶层模块 configuration→wireguard→platform，依赖方向自上而下。启动顺序：先绑 UAPI、再建 TUN（均需 root）→ 立即降权 → 默认 daemonize → 起工作线程。
