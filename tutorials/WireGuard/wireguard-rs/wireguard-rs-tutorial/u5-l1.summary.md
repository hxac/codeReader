路由器是 WireGuard 的数据面引擎，只做加解密与 cryptokey 路由，密钥由握手模块以 KeyPair 注入。设备状态集中在 DeviceInner，含入站的 receiver id→解密状态表、出站的目的 IP→peer 路由表与任务派发队列。核心是两层队列模型：ParallelQueue 作为 crossbeam 单发多收通道负责并行派发，per-peer 的保序 Queue 靠 contenders 原子接力棒按入队顺序串行完成副作用，实现「并行加密、有序发送」。worker 对入站出站对称处理：先 parallel_work 加解密并置 ready，再 consume 只处理队首已就绪任务、串行执行副作用——consume 是并行到有序的唯一桥梁。出站 send 按目的 IP 选 peer 并分配 nonce（无密钥则暂存 staged_packets 并请求握手），入站 recv 按报文头 receiver id 查表定位解密状态。发送用 EncryptionState（计数 nonce）、接收用 DecryptionState（防回放 AntiReplay），对应「发送计数 nonce、接收防回放」的不对称职责。DeviceHandle 持状态与线程句柄，Drop 用 close+join 借通道排空后断开语义优雅关闭线程池。
