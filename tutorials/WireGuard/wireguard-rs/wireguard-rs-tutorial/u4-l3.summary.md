本讲解析 `src/wireguard/handshake/noise.rs`，即 WireGuard 握手 `Noise_IKpsk2_25519_ChaChaPoly_BLAKE2s` 的密码学核心。握手由两个随握手推进的状态量驱动：链密钥 C 与转录哈希 H——每次 DH 经 HKDF 揉进 C，每段收发数据经 HASH 揉进 H，H 兼作 AEAD 的附加认证数据。引入预计算常量 `INITIAL_CK`/`INITIAL_HS` 与 `HASH/HMAC/KDF1-3/SEAL/OPEN` 六个原语宏；`shared_secret` 用常时间 `ct_eq` 拒绝零共享密钥，抗小子群攻击并与内核行为对齐。四个函数成对称结构：`create/consume_initiation` 完成首报文，做预计算 ss（静态×静态）与 es（临时×静态），加密静态公钥与时间戳；`create/consume_response` 完成次报文，做 ee、se 与 psk2（混入 PSK），末尾由 `KDF2(ck, [])` 拆出收发密钥。两边故意交换 t1/t2 归属使收发方向匹配，组装成 Drop 清零的 `KeyPair`，其 `initiator` 字段区分「已确认/未确认」密钥以驱动后续 KeyWheel。中间状态经 `State::InitiationSent` 与 `TemporaryState` 传递；四个函数体皆包于 `clear_stack_on_return_fnone`，连同 `Key::Drop`、`State::Drop` 构成密钥材料三层清零。
