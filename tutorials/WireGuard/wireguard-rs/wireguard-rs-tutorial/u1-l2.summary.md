本讲义讲解如何把 wireguard-rs 从源码编译为可运行进程。核心模块为 Cargo.toml 三段：[package] 决定二进制产物名 wireguard-rs 与版本 0.1.4；[dependencies] 按密码学（ring、chacha20poly1305、x25519-dalek、blake2）、并发同步（crossbeam-channel、parking_lot、dashmap、spin、hjul）、网络零拷贝（treebitmap、zerocopy）、平台工具（仅 Unix 的 libc）四类组织。引入的关键术语包括 Cargo feature 编译期开关与 #[cfg] 条件编译、TUN 虚拟网卡、UAPI 控制套接字（/var/run/wireguard/）。两个可选 feature：profiler 拉 cpuprofiler 做 CPU 剖析，start_up 注入假 TunEvent::Up(1500) 使启动即拉起网卡，默认零开销。构建用 cargo build --release，stable 默认可用、nightly 非必需。运行 wireguard-rs wg0 需 root 先完成绑 UAPI 与建 TUN 两件特权操作，之后才降权到 nobody 并 daemonize，顺序不可颠倒；生产 Linux 应改用内核模块。
