本讲打通「被 mIoU 指标丢弃的逐点掩码」到彩色点云的完整链路，覆盖 `predict()` 出口的 mask dump 旁路、离线工具 `export_grounding_ply.py` 与写入器 `grounding_viz.py` 三个模块。核心结论：dump 由环境变量 `MASK_DUMP_DIR` 或配置项 `save_viz_dir` 开启，环境变量优先；逐场景以 object 数组落盘预测与 GT 掩码，按场景名与同名点云 bin 配对；批量评估须用 `--mask-dump` 镜像目录树，防止同场景被子任务静默覆盖。导出分 combine 与 per_qa 两种模式，`--group N` 使颜色在每组内重新起算。染色规则：每个 dump 条目（一条 QA 或多轮的一轮）经行并集后至多占一个区域，单条 QA 内多个指称会被并成同色；颜色按五色调色板循环、重叠处先到先得；`max_frac` 双判据滤除空掩码与全 True 退化掩码（零查询哨兵经阈值所致）；背景乘 `dim_bg` 调暗后写出二进制 PLY。
