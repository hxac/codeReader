本讲剖析 Ground3D-LMM 训练损失如何由预测变成可反传的标量。核心模块三个：Part3dGlammCriterion_v2 组合器是无可训练参数的纯组装者，把解码器预测、sp_gt_masks、language_losses 与 original_queries 分发给两个子损失器并合并字典，输出 text_seg_loss 与 cot_loss 两键，由 mmengine parse_losses 求和；语言与分割的相对权重只能调各子损失器的 loss_weight。CoTCriterion 语言损失是仅落在 assistant 回复 token 上的交叉熵（preprocess_chatml 把提问置 -100），先场景内平均、场景间再 macro-average。TextPrompt_Criterion_Glamm 分割损失对逐超点掩码做 BCE+Dice，依托「<p> 数量契约」行对齐而无需匈牙利匹配；关键概念有有效行过滤（零向量查询且 GT 全 NaN 的行剔除，零查询判定必须在投影前的 original_queries 上做）、dice_scale=4 的 Dice 放大、fix_mean_loss 的无效场景补偿、五层 1/i 递减加权的辅助深监督。GT 侧 sp_gt_seg 逐 QA 生成后拼接为逐场景张量，与查询行、掩码行三方对齐。
