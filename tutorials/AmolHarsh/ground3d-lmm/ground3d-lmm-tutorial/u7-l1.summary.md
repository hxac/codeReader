本讲把 Ground3D-LMM 迁移到 ScanRefer 与 Reason3D 两个外部基准，做逐数据集微调后评估（非零样本）。模块一：整场景转换链——共享基类以标注 JSON 的场景键为权威、复用 ScanNet 基座，外部 QA 以 qa_data 整段写入 pkl，v2 规范化借用 reason3d 例程（'scanrefer' 不是合法转换 key）；模块二：超点级 GT 生成——ScanRefer 为实例级指称分割，GT 取 gt_sp_masks_ins 的 object_id 行、答案回显描述原句，Reason3D 为语义级推理分割，GT 取 gt_sp_masks_sem 行、答案为类别名，GT 缺失以 NaN 整行占位；模块三：用 linspace 为每场景确定性抽取 20 张 RGB 视图；模块四：2×2 评估配置矩阵（数据集 × 3D/3D+2D），解码器拆为 Eval_Text 与 Eval_MultiImg，LoRA 统一 r=32，mIoU 基线 38.72/41.30/36.35/41.29，加入 2D 视图稳定涨点，证明架构不限于自建数据；复现需隔离四路输出目录、容忍约一点多方差。
