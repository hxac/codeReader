本讲为整套手册的起点，界定 Ground3D-LMM 的定位：在室内点云（XYZ+RGB）上做细粒度点级接地与空间推理，同时输出自然语言回答与逐点分割掩码；训练数据约 247 万问答对，子任务分部件/物体接地、数值测量、空间关系与存在判断三组。架构四组件：SpConvUNet 稀疏编码、超点池化（scatter-mean 把海量点压缩为超点 token）、Qwen3-VL-4B 语言底座（LoRA 微调）、6 层 256 维 Mask2Former 式查询解码器。核心巧思是 `<SEG>` 机制：回答中 `<SEG>` 位置的隐状态被复用为分割查询，语言与分割在同一前向内对齐；超点特征并行投影为 `<|point|>` token 与解码器 K/V 两路。项目发布 Joint（3D+RGB）与 3D-only（仅点云）两变体，配置仅差三字段，LoRA rank 与 checkpoint 不匹配时 adapter 会被静默忽略。本讲引入的关键术语：点云、接地（grounding）、超点、LMM、LoRA、特殊 token（`<|point|>` 与 `<SEG>`）、OpenMMLab 配置注册机制。
