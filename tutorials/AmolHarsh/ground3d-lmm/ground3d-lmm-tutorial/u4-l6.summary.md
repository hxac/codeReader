本讲拆解 Ground3D-LMM 的 2D 图像分支两种变体。Joint 变体除点云 token 外，通过 Qwen-VL 原生 message 里的 image 条目注入一帧 RGB 图像，max_pixels 与 min_pixels 经智能缩放把像素钳在固定区间，封顶视觉 token 预算；图像与点 token 策略一致，只在首条 user 消息注入一次。3D-only 无独立代码分支：image_dir 为 None 时 image 条目变 image=None，由 _prepare_messages_data 统一过滤，序列零视觉 token，两变体共享全部解码代码。配置仅差三字段 lora_r、lora_alpha、image_dir；LoRA rank 与 checkpoint 失配会被 strict=False 静默吞掉，模型无声退回基座 Qwen，是重大隐患。训练解码器 Grounded_Decoder_Joint 恒有图，按场景名在双图像目录分流。抽帧工具链由 infos pkl 驱动，产出 image_dir 下的「场景/帧号.jpg」目录树，与解码器的路径拼接构成纯字符串契约。
