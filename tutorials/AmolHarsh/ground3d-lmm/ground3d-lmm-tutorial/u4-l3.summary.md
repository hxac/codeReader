本讲聚焦训练语言分支 infer_reason_train 的四个模块：(1) 将 selected_qa_data 展平为 qa_pairs 并拼成 ChatML 多轮 messages，仅第 0 轮注入图像与 n_points 个 <|point|> 占位，assistant 消息即 GT 回复（teacher forcing）；(2) processor 编码后附加 point_embeds 与 point_mask（input_ids==point_token_id），以「占位数==特征行数」契约经钩子 masked_scatter 注入点特征；(3) preprocess_chatml 构造 labels，将提问与角色头置 IGNORE_INDEX(-100)，语言损失只落在 assistant 正文及其 <|im_end|> 终止符；(4) 训练时超点数超 max_point_tokens(2000) 则用零参数 FPS 聚合（优先质心位置、兜底特征距离），只压语言侧 token，不影响分割解码器的 K/V。遗留隐患：preprocess_chatml 工作在文本坐标系，图像占位被 processor 展开后可能与 input_ids 错位，u4-l4 的 get_query_tokens_id 将以 id 定位规避。
