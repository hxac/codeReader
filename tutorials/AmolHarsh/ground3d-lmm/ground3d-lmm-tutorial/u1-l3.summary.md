本讲梳理仓库分层与 OpenMMLab 注册机制。仓库为插件式：configs/ 只写声明，uniseg3d/ 只写实现，tools/ 仅 train.py 与 test.py 构建 Runner，data/ 由用户填充。「注册表」把配置中的 type 字符串映射为真实类：custom_imports 触发导入 uniseg3d，靠 import 副作用执行各模块顶层 register_module 完成注册；注册名默认即类名，尾下划线为继承上游的改版类。mmengine Config 支持 _base_ 跨包继承、递归覆盖与 _delete_ 重建，_3d 变体仅覆盖 3 个字段即成完整配置；--cfg-options 点路径数字即列表下标。
