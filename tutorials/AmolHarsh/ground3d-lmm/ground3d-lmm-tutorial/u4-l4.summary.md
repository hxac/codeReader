本讲讲解 <SEG> 查询提取：如何从语言塔最后一层隐状态得到解码器可用的 256 维分割查询。关键澄清：源码提取的并非 <SEG> token 本身，而是 <p>…</p> 之间指称文本隐状态的均值池化。训练用 get_query_tokens_id 在 input_ids 中定位 assistant 回复区间（id 坐标系，可避免带图序列图像 token 展开造成的文本计数错位，取代文本坐标系的 get_query_tokens）；推理用 get_query_tokens_eval，输入仅生成段、全局搜索无需切轮。每条 QA 最多 2 个查询，与数据侧 GT 形状契约逐行对齐。查询经 query_proj 投影到 256 维；因 Linear 带偏置使零向量投影后非零，无效查询须在投影前的 original_queries 上识别：损失侧以「零向量 ∧ GT 非 NaN」双重过滤，推理侧将零查询的 mask 置为常数 1e-4。
