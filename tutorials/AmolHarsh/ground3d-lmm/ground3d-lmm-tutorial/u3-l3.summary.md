本讲是单元 3 收官，讲清「几十万点 → 几千超点 token」的压缩机制。collate() 把 batch 点云组装成稀疏卷积四件套（coordinates、features、inverse_mapping、spatial_shape）：坐标平移并除以 voxel_size 量化、第 0 列拼样本编号，TensorField.sparse() 做体素去重，inverse_mapping 记录每个点到所在体素的回溯；训练专用 elastic_coords 只替换量化坐标，点特征与逐点标签仍保持对齐。extract_feat() 用一行 scatter_mean 把体素特征经 inverse_mapping 广播回点级、再按全局超点编号分组求均值，得逐超点特征并按 batch_offsets 切回逐场景，它既作 LMM 的 point token 也作分割解码器的 K/V。point_positions 用同一 scatter_mean 对原始米制坐标求超点质心，仅训练且超点数超过 max_point_tokens 时供 FPSPositionAggregator 做 FPS 降采样，推理不聚合。
