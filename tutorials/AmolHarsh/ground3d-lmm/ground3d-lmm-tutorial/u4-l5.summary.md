本讲精读评估解码器 `Grounded_Decoder_Eval` 的推理分支 `infer_reason_eval`：推理时语言侧分裂为「生成回答」与「提取查询」两阶段，每条 QA（多轮则每轮）需两次完整 LLM 前向。`_generate_response` 以贪心解码加重复惩罚 1.2 生成含 `<p>…</p><SEG>` 的回答；随后把 prompt 与生成段重组为完整序列做 teacher-forcing 二次前向，取最后一层隐状态、切片对准生成段，交 `get_query_tokens_eval` 全局搜索指称区间得到分割查询。单轮 QA 独立成对话、按三级键写入预测 JSON；多轮为 LLaVA 式滚动历史，点 token 与图像仅第 0 轮注入，记录带 `turn_idx`。推理不做 FPS 聚合；`save_pred_qa_dir` 须显式开启否则写盘报错；JSON 先于分割解码写出且与 mIoU 通道独立；回答保留特殊标记供文本指标，无 `<p>` 时查询退化为零向量、其 mask 被置为 1e-4。
