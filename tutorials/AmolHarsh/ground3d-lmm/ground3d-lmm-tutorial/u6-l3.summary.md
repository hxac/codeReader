本讲剖析 Ground3D-LMM 的文本评测工具 evaluate_text_metrics.py：它与 mIoU 独立，经 --stages 选择 ape、judge、gmdelta 三阶段。关键概念：任务感知的递归展平（flatten_with_task、gather_samples）把任意嵌套或多轮的预测 JSON 展平为带 _task 标签的扁平样本列表，标签按「meta_info.group → 最近包裹键 → 路径目录名」三级回退；ape 阶段先用文本 LLM 按任务形状抽取数字，再逐对计算 APE 与 δ@1.25，预测缺数被「罚 0」（APE=100%、δ=∞、成功=0），GT 为 0 的对跳过，任务内对 QA 宏观平均、overall 池化平均；judge 阶段用 Qwen3-VL-4B-Instruct 对全部任务打 1-10 分，仅聚合幻觉与完整性两维，贪心解码保证可复现，clean_text 定义了但未接线；GM-δ 要求点级掩码 IoU>0.3 且该 QA 全部数值对 δ≤1.25 同时成立，文本与掩码两通道靠「目录镜像＋场景同名＋按位对齐」的纯字符串契约 join（掩码来自推理时 mask dump 落盘的 npy），须显式开启并提供 --mask_dump_dir。核心结论：能量化的数值误差用硬公式与 --selftest 单测覆盖，难量化的幻觉与完整性才交给 LLM 裁判。
