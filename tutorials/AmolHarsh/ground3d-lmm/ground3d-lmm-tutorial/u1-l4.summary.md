本讲以复现 README 快速上手为主线，覆盖三个模块：tools/test.py 执行主线、评估配置的任务切换旋钮、预测 JSON 产物结构。核心结论：test.py 是 mmdet3d 通用测试入口，不含任何模型特有逻辑，配置驱动、CLI 优先——`--cfg-options` 按点路径合并进配置（数字即列表下标），checkpoint 位置参数无条件覆盖 `load_from`。评估任务由 `QA_Generation_Test` 的三层旋钮 `task_level`/`task_type`/`sub_task` 决定，None 表示该层不过滤，过滤是严格匹配、拼错静默为空；点路径 `pipeline.2.transforms.2` 的两个下标分别指向 `MultiScaleFlipAug3D` 与该变换；`save_pred_qa_dir` 开启逐场景文本预测 JSON（question/gt_answer/pred_answer 三字段，多轮加 turn_idx），由解码器在 `infer_reason_eval` 中直接写盘；分割 mIoU 则由 `Part3DGlamm_SegMetric` 聚合，两条输出通道相互独立，JSON 不含掩码且写盘先于分割解码。关键术语：checkpoint、snapshot_download、TestLoop、`<p>…</p><SEG>` 接地标记。务实习惯：先零 GPU 干跑配置核对覆盖落点，再跑真推理。
