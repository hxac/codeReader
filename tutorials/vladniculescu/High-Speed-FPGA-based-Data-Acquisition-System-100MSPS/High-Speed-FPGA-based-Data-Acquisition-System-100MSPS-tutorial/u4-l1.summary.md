本讲讲解 PC→FPGA 方向的 UART 接收机 serial_rx（VHDL），含三个最小模块：①用 generic M 将系统时钟整数分频出采样节拍 rs_tick，关系 f_baud = f_clk/(16M)；②四态状态机 s_waiting/s_start/s_bit/s_stop——s_waiting 检测起始位下降沿，s_start 以 counter=7 做半位偏移实现中点对齐，s_bit 以 counter=15 每 16 拍在位中央采一位、共 8 位 LSB 先收，经右移寄存器还原字节；③与 TOP 的握手，收完一帧以 d_avail 单拍脉冲通知、d_out 给出字节，TOP 在 wait_state 借 conf_index 把单字节命令扩展为两步式配置（命令字+参数字节）。关键术语：16× 过采样、中点对齐、rs_tick、d_avail 脉冲、conf_index。源码待改进处：起始位复查逻辑被注释、d_avail 跨 50→200 MHz 时钟域无同步链；波特率约 1.5625 Mbaud 与 clk_UART 精确频率均待本地验证。
