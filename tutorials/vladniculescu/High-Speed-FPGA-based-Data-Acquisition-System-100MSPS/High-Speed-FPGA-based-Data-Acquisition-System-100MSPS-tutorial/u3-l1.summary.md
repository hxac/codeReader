`Fourier` 是 Xilinx FFT 黑盒 IP 的纯封装壳，自身零运算，仅做端口改名转接。一次变换分四阶段握手：`start` 启动 → `rfd`/`xn_index` 加载输入 → `busy` 计算 → `edone`/`done`/`dv`/`xk_index` 卸载输出；输入 `xn_re` 接补码 `decoder_out`、`xn_im` 恒 0，输出 `xk_re`/`xk_im` 各 10 位。核心是自驱动加载/卸载：核自己的 `xn_index` 经 `mux_ram1` 回送成 ram1 读地址、样本经 `decoder` 自动喂回 `xn_re`，`xk_index` 直接当 ram2 写地址，状态机无需手动遍历地址。TOP 主 FSM 在 `fft_state` 等 `edone`（早 `done` 一拍）跳到 `fft_write_state`，以提前打开 ram2 写使能、不漏第 0 个输出点，再等 `index_out==1022` 跳 `square_state`。静态配置 `fwd_inv=1` 选正向变换，`scale_sch=12'b001010101011` 为定点防溢出的每级缩放编码。FFT 跑在 `clk_100`（100 MHz），靠 ram1 组合读桥接 200 MHz 域；输出复数分量后续由 Square+Sum 算成 re²+im² 写入 ram2，幅度计算见 u3-l2。
