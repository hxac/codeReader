本讲义打开顶层 TOP.v，建立系统全局数据流地图。核心是 8 步流程：ADC 采样存 ram1 → Fourier 核算 FFT → 两个 Square 平方器加 Sum 加法器合成 Re²+Im² 存 ram2 → Root_square 开方（8 拍延迟）得幅度存 ram3 → serialt 经 UART 发 PC，整个过程由 PC 串口命令触发。引入的关键术语：双端口 RAM、FFT 复数输出（实部 Re/虚部 Im）、幅度公式 |X|=√(Re²+Im²)、多时钟域（FFT 100MHz、RAM 与开方 200MHz、UART 50MHz、ADC 独立时基）。三块 RAM 分工：ram1（SRAM，10 位）存 ADC 原始采样；ram2（SRAM2，21 位）存平方和，位宽因平方运算膨胀；ram3（SRAM3，10 位）存开方后幅度。波形从 ram1 经 buffer 旁路与频谱共用 serialt 发送。TOP.v 仅做例化编排与主状态机调度。注意文件名常与模块名交叉（ram2.v↔SRAM、SRAM.v↔SRAM2、Radical.v↔Root_square），读代码一律认模块名。
