本讲含三个最小模块。一是目录结构识别：仓库分三类——可读源码（`readme.md` 及 `verilog files/` 下 14 个 `.v`、`vhdl files/` 下 6 个 `.vhd`）、二进制产物（`TOP.bit` 比特流、`.vi` LabVIEW 工程、Altium 的 PCB 文件、`Vivado Project.rar`）、说明文档；二进制产物须用 Vivado/LabVIEW/Altium 等专用工具打开，无法文本精读。二是混合语言工程组织：Verilog 与 VHDL 并存，顶层模块为 `verilog files/TOP.v` 中的 `TOP`，其端口直接对接板级物理信号（时钟、ADC 并行数据、串口）；关键防坑点是文件名常与模块名不一致（如 `Radical.v` 实为 `Root_square`、`ram2.v` 实为 `SRAM`），查找例化须以文件内部 `module`/`entity` 声明为准，且 VHDL 目录里的 `defs.vhd`、`aux_vlad.vhd` 是 package 而非可例化实体。三是三步复现法：烧 `TOP.bit` 到 Nexys 4 DDR → 复现并连接 PCB 模拟前端 → 打开 LabVIEW GUI 连 PC，分别让 FPGA 逻辑、信号通路、上位机显示就位，顺序不可乱。此外 readme 的目录标签（`hw`/`sw`/`doc`）与实际目录名有出入，应以实际目录为准；纯源码学习时三步皆可跳过。后续讲义将进入 TOP.v 内部，串起 ADC→ram1→FFT→平方求和→ram2→开方→ram3→UART 的数据流。
