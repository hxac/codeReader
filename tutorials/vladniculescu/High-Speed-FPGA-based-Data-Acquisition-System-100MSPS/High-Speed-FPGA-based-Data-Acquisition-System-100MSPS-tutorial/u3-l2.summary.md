本讲承接 u3-l1，把 FFT 输出的复数 xk_re/xk_im（10 位有符号补码）转成幅度平方 re²+im²，开根号留给下一讲 u3-l3 的 Root_square。核心是两个模块：Square 封装 Xilinx mult 乘法器 IP，做 10×10→20 位，TOP 用 sq_real、sq_im 两个实例分别平方实部与虚部，靠把 a、b 接成同一信号让通用乘法退化为平方；Sum 封装 Xilinx adder 加法器 IP，做 20+20→21 位，把两个平方加成 sum。位宽沿 10→20→21 膨胀，规律是乘法翻倍、加法进位，这正是 ram2 选 21 位宽的根本原因。注意 mult 必须配成有符号模式，否则负数补码会被当成大正数算错。整条 xk_re/xk_im → Square×2 → Sum → ram2 是纯组合逻辑，发生在 fft_write_state 期间，靠 we2 打开 ram2 写使能，index_out 同时充当频点号与写地址；结果存入 ram2 供开方。术语提醒：Square（平方）≠ Root_square（开方），名字相像但方向相反。
