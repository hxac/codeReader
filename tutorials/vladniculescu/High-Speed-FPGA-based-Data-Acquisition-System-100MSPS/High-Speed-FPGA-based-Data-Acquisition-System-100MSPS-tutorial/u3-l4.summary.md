本讲把前三讲拆开的 DSP 零件装回一条完整幅度谱计算链：adc_read → ram1（时域采样）→ decoder（偏移码转补码）→ Fourier（FFT，clk_100 域）→ Square×2＋Sum（平方求和）→ ram2 → Root_square（CORDIC 开方）→ ram3。位宽沿链呈「膨胀—压缩」：10 → 20（平方）→ 21（求和进位）→ 11 取 10（开方）。三块 RAM 充当级间缓冲，隔离采集、FFT 卸载、慢速开方三级不同节奏；ram1 还被读两次（喂 FFT 与上传原波形）。核心结论：平方求和是纯组合逻辑，搭 FFT 卸载便车「免费」完成；开方逐点串行、每点约 13 拍，是最慢一级，独占约六成帧时间（整帧约百微秒量级）——这正是开方放在最后、最终幅度存入 ram3 的原因。主状态机用 we／we2／we3 三个写使能按阶段独占调度三块 RAM，阶段切换时及时关闭旧写使能。关键术语：幅度（magnitude，√(re²+im²)）、平方求和、CORDIC 开方、级间缓冲、写使能、主状态机、时钟域（clk 200 MHz 与 clk_100）。
